# 概要

本世界線では廃藩置県が起きず、島津・毛利・鍋島・徳川・前田・那珂川といった大領主が[領主権](/institutions/lordship-rights.md)を保ったまま存続した。ユーザーは、近代化そのものも史実より速いペース（20年程度早い）で進む可能性が高いと確定させている。理由は、**大領主の間で必ず主導権争いが起きる**からである。[^u028] さらにユーザーは、**中小領主は大領主を寄親として改革を進める**とも確定させた。[^u028]

ここでいう寄親・寄子関係は、戦国期の軍事的な主従関係とは違う。**近代的な政治・経済同盟**として再定義されたものである。中小領主は出資・土地・人材・元老院での票を提供し、大領主から技術・設備・販路・鉄道接続・教育機会を得る。[^u028] こうして大領主を中心とする「寄親圏」ができ、各圏が競い合いながら近代化を連鎖させていく。

この構造を一言でまとめると、「**明治政府による中央集権化が成功しなくても、領主たちの競争によって日本全体が近代化してしまう**」ということになる。[^u028]

# 寄親・寄子関係の内容

## 中小領主が寄親を求める理由

たとえば三万石の領主が、近代的な兵営・軍学校・電信設備・製鉄所・鉄道を一人で整えるのは困難である。大領主の事業に加われば負担を分け合える。こうした関係は、軍事的な従属ではなく経済的な理由から生まれる。[^u028]

| 中小領主の負担・提供 | 大領主から得る利益 |
|---|---|
| 軍費や兵員の提供 | 軍学校・装備調達・軍事顧問 |
| 工業事業への出資 | 工場設備・技術者・販路 |
| 鉄道用地の提供 | 鉄道網への接続 |
| 留学生の派遣費用 | 海外留学・技術教育の共同制度 |
| 元老院での政治的協力 | 政策調整や中央政府への働きかけ |

[^u028]

この関係があれば、中小領主は必ずしも[領主権を奉還](/institutions/lordship-surrender.md)しなくてよい。自分の領地と家格を保ったまま、有力領主の経済圏に加われるからである。[^u028]

なお、軍費・兵員の提供は当初の想定である。その後、領主が独自の軍を持たず軍費を金で納める方式に修正されたため、寄親関係の軍事面は帝国軍の将官人事や軍需受注をめぐる協力へと性格を変える（後述）。[^u030]

## 主な寄親圏（例示）

| 有力領主 | 政治的・経済的な基盤の例 |
|---|---|
| 島津家 | 南九州の産業・海運・対外貿易。製鉄・造船 |
| 毛利家 | 中国地方西部の交通・工業・軍事教育 |
| 鍋島家 | 北部九州の工業・技術教育。機械工業 |
| 徳川宗家 | 旧幕府の官僚・金融・商業のネットワーク |
| 前田家 | 北陸の産業・交通整備。鉄道・繊維 |
| 那珂川公爵家 | 常陸の産業・教育、江戸（会話の当初の表記では「東京」）近郊との経済関係 |

[^u028][^u045] 各家の基盤は例示であり、固定された同盟になるとは限らない。同じ中小領主が、鉄道事業では島津家と組み、元老院では鍋島家に同調する、という**重層的な関係**こそが近代的な政治経済の特徴とされる。[^u028] 那珂川家については[那珂川公爵家と公現法親王](/people/nakagawa-ducal-house.md)を参照。

# 近代化を速める仕組み

## 連鎖の構造

1. **大領主の軍事・産業投資**: 工場・鉄道・教育・港湾の整備。
2. **中小領主の共同事業への参加**: 出資・土地の提供・人材の育成。
3. **地域経済圏の形成**: 鉄道網・金融・工業・流通の統合。
4. **他の大領主圏との競争**: さらなる技術導入と制度改革への圧力。

[^u028]

この競争の中で、複数の領主家が共同出資する鉄道会社・製鉄会社・港湾会社など、近代的な企業や銀行が生まれる。[^u028]

## 模倣と政策実験

全国に複数の政策実験の場ができることも、改革を速める。ある領主が義務教育や工業教育で成功すると、周辺の領主が学校を作り、大領主の教育機関へ留学生を送る。さらに元老院では、成功した制度を全国標準として採用する議論が起こる。こうして地方の制度改革が中央の政策へ発展する。[^u028]

## 加速の三条件

1. 大領主の間で軍事・経済・政治上の競争が続くこと。
2. 中小領主が、寄親である大領主の資本・技術・人材を使えること。
3. 中央政府が市場と技術の全国統一を進め、領主間の競争を国内の分断に変えないこと。

[^u028]

三つ目の条件は特に重要である。寄親圏ごとに貨幣・鉄道規格・商取引の制度が分かれると、全国の経済発展の妨げになる。そのため中央政府には、鉄道規格・通貨・度量衡・郵便・電信・商法を全国で統一する強い理由が生まれる。これらは領主権を廃止しなくても実現できる改革である。[^u028] 実際の展開は[全国標準化政策](/institutions/national-standardization.md)を参照。

## 欧米視察と知識の分散流入

1870年代には、中央政府の使節団とは別に、各領主家が専門の視察団や留学生を継続的に送り出した。帰国者が全国の領主家へ戻り、鉄道・銀行・学校・裁判制度の改革を競う。知識が複数の政治経済圏へ同時に流れ込み、近代化競争の起爆剤になった。[^u043] 関心の向きも家ごとに違う。島津・鍋島は英国の造船・機械・製鉄、徳川・前田はドイツの連邦制度・鉄道・軍制、中小領主や商工業者は米国の鉄道会社・銀行・地方自治に関心を向ける。[^u043] 詳細は[岩倉使節団と欧米視察](/events/iwakura-mission.md)を参照。

## 規格競争

標準化は単なる協調政策ではなく、「**自家の規格を帝国標準として採用させる競争**」にもなる。たとえば前田家の経済圏が鉄道や製糸の規格を整えれば、周辺の中小領主もそれに合わせる動機を持つ。そのため、早く規格を整えた大領主ほど全国市場で有利になる。標準化は、大領主が寄子を取り込む手段でもある。[^u044]

# 政治・軍事への波及

## 元老院の会派構造

[元老院](/institutions/genroin.md)では、大領主とその寄親圏が主導権を争う。中小領主は独立して投票できるが、財政的に大領主へ依存していれば、その政策に同調する動機を持つ。[^u028] 1870年代に衆議院ができると、二重の競争構造が生まれる。「**元老院では領主連合が競争し、衆議院ではその領内で育った経済勢力が競争する**」。[^u028] 元老院で劣勢な領主連合が衆議院の創設を支持して均衡を変えようとする、という展開も想定される。[^u035]

## 軍事面の競争

大領主が独自の軍を持たず、軍費を金で納めるようになると、競争の対象は次のものに移った。[^u030]

* 帝国陸海軍の将官を輩出すること
* 兵器・艦船の発注を獲得すること
* 陸軍士官学校・海軍兵学校へ人材を送り込むこと
* 軍事予算・軍備政策への影響力

大領主は「軍事力そのものではなく、軍事力を生み出す産業・人材・政治的影響力を保持する」。[^u030] 詳細は[帝国軍](/military/imperial-army.md)を参照。

## 対外政策の利害

対外政策でも、寄親圏ごとに利害が分かれる（例示）。[^u037]

| 領主・領主連合 | 主な関心 |
|---|---|
| 宗家・西日本の通商関係者 | 朝鮮との交易、港湾の開放、航路の安定 |
| 毛利家・中国地方の領主連合 | 日本海の安全保障、対馬海峡、半島への交通 |
| 島津・鍋島などの領主連合 | 海軍整備、海外貿易、軍需産業 |
| 徳川・前田などの大領主 | 国家財政、産業振興、海外市場、戦費負担 |

各家の立場は単純に開戦派と反戦派に分かれない。たとえば毛利は外交への関与を支持しつつ軍事衝突の回避を求め、島津は海軍拡張を支持しつつ即時の戦争は望まない。[^u037]

## 北海道開拓への参加

北海道の分領支配では、前田家が開拓資本・港湾・交通に投資する。徳川家は旧幕臣の再就職先として移住事業を担う。中小領主は寄親である大領主と共同で参加する。領地を得る家と投資だけをする家は区別される（検討案）。[^u066] 詳細は[北海道（分領支配）](/regions/hokkaido.md)を参照。

# 長期的な帰結

## 「経済は速く、領主制は長く」

各領主が投資を進めて近代化に成功するほど、中央政府に行政権を渡す理由は薄れる。寄親関係が強くなれば、中央政府は一人の小領主ではなく複数の領主の政治連合と交渉しなければならない。その結果、**経済・技術の近代化は史実より早く進む一方、地方自治や世襲領主制度は史実より長く残る**。[^u028] 「政治的近代化は先行するのに封建領主制は長く存続する」という点で、ドイツ帝国に似た国家になる。[^u027]

## 成長要因としての位置づけ

本世界線の日本の成長要因として、次の四つが挙げられる。[^u080] 詳細は[重工業化と国力の推移（1870〜1930）](/economy/heavy-industrialization.md)を参照。

1. 1860年代からの近代法制と統一市場
2. 大領主（島津・毛利・鍋島・徳川・前田など）の産業投資競争
3. 領主家の技術官や留学生の長期派遣による、欧米からの分散的・継続的な技術導入
4. 1889年の講和による早期の資本形成

## 1930年時点の領主系資本

1930年には、領主制は強みと弱みの両方を見せている。[^u132]

* **強み**: 大領主の企業集団が1870年代以来、機械工業・製鉄へ継続的に投資し、技術の蓄積が残る。
* **弱み**: 領主系企業が独占契約や公共調達での優遇を求め、全国的な効率を妨げる。

そのため1930年には、領主系資本の再編、企業間の競争、独占の規制が重要な経済政策の課題となる。[^u132]

# 史実との比較

* 幕末の雄藩はすでに競争によって近代化を進めていた。薩摩の島津家は1850年代から集成館事業で造船・製鉄・紡績に投資し、最盛期には約1,200人の職工が働いた。肥前の鍋島家は反射炉で鉄製大砲を造り、精煉方で蒸気機関・電信を研究し、三重津で造船と海軍教育を行った。[^u028]
* 史実では廃藩置県によって、こうした取り組みは中央政府に吸収された。本世界線では各領主家の継続的な投資競争へ発展する。[^u028]
* 寄親・寄子は戦国大名の家臣団編成に由来する語である。本世界線では、領主間の近代的な同盟関係を指す語として使われる。

# 却下・修正された案

* **近代化の開始は20年早まらないという留保**: 立憲政治と地方制度は10〜20年先行しうるが、鉄道・工業化は資本・技術・財政に依存するため必ずしも先行しない、という留保が付けられた。[^u027] ユーザーの「大領主間の主導権争いが必ず起きる」という指摘を受け、大領主間の競争を過小評価していたとして撤回された。[^u028]
* **寄子からの兵員提供**: 寄親関係に軍費・兵員の提供を含める想定は、帝国軍が統一国軍となり、領主が独自軍を持たない方向に修正されたため、軍事面では将官人事・軍需受注・軍事予算への影響力をめぐる協力に置き換わる。[^u030]

# 未決の論点

* 史実と比べて近代化がどれだけ先行するか（20年先行するかどうか）。国内の資本蓄積、技術者の育成、機械輸入、税収と債務の状況次第とされる。[^u028]
* 個々の中小領主がどの寄親に属するか、具体的な寄親圏の地理的範囲。
* 寄親関係を制度化するか（共同出資会社の法人格、元老院の会派の公認など）。
