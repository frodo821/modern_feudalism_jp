# 概要

**近代封建制**は、本 wiki が本世界線の日本の国家体制を指して用いる呼称である。その核心は、世襲領主（旧大名家）が朝廷から安堵された[領主権](/institutions/lordship-rights.md)――領内の行政・徴税・警察・司法――を保持したまま、日本が成文憲法・二院制議会・統一された帝国軍・全国統一市場を備えた近代国家になったという点にある。[^u017][^u036]

この体制は意図された設計ではなく、1866年の[無血の幕府解体](/events/bloodless-dissolution-1866.md)の条件から生まれた。朝廷は将軍への軍事委任を更新しない代わりに諸侯の所領を安堵したため、新政府の成立そのものが領主権の保障を前提とし、史実の版籍奉還・廃藩置県に当たる改革が不可能になった。[^u015][^u017] その結果、「明治維新に相当する政権交代は史実より穏やかに進む一方、封建制度の解体ははるかに長期化する」。[^u017]

ただし領主制は近代化の障害とはならなかった。大領主間の主導権争いが産業投資を加速し、領主たち自身が元老院を通じて全国標準化の主体となったため、本世界線の日本は史実より早く工業化する。「この世界の日本がアメリカに追いつくための最大の武器は、領主制を廃止したことではなく、領主同士の競争を全国的な産業発展へ転換できたこと」と総括される。[^u028][^u044][^u080]

# 成立の論理

## 「藩の負担」から「領主権の安堵」へ

井伊直弼失脚後の幕府にとって、幕藩体制のまま中央集権化を進めることは根本的に矛盾していた。幕府の権威を支えるのは中央集権化で権限を奪われる大名自身だからである。[^u003] 幕府が試みたのは、1861年の[公武協定](/diplomacy/kobu-agreement-1861.md)によって軍役を「将軍への封建的奉仕」から「皇国防衛のための国家的義務」へ再定義することだった。[^u009] しかしこの協定は将軍の軍権を朝廷の委任へと変え、1866年に朝廷が委任を引き取ると、諸侯は「朝廷の名のもとで所領を安堵されるなら幕府に拘る理由はない」という立場をとった。[^u010][^u015]

1866年の交換条件は、朝廷が所領・家格・家臣の身分俸禄を保障し、諸侯が新政府への服属・外交権の一元化・全国軍費の負担・藩兵の一部移管を受け入れるというものだった。廃藩置県ではないが、藩主の自由裁量は縮小した。[^u016] この取引の帰結として、天皇は「天下の土地は究極的には天皇のものだが、各家の封土は従前どおり安堵する」という伝統的な封建論理に立つことになる。[^u017]

## 史実の明治国家との出発点の違い

史実の明治政府は戊辰戦争の勝者として旧大名から土地人民を回収できたが、本世界線の新政府は諸侯連合として成立した。「明治が始まっても日本は領主たちによって分割統治されている」。[^u020] 政府の課題は徳川家との戦争ではなく、諸侯連合体制を近代的中央政府へ変えることだった。[^u020]

# 構造的特徴

## 領主権

領主権は中央から委任された行政権ではなく、朝廷に安堵された世襲的な固有権限であり、1869年頃の段階ではほぼ「領邦主権」に近い。[^u036]

| 権限 | 領主 | 中央（帝国） |
|---|---|---|
| 一般行政 | 原則として領主 | 全国共通事項 |
| 徴税・地方財政 | 領内徴税と予算 | 国税・軍費負担 |
| 警察・治安 | 領主直属の警察・警備隊 | 広域治安・国家安全保障 |
| 民事裁判 | 領主の裁判機関 | 跨領事件・上訴・共通法 |
| 刑事裁判 | 通常犯罪の審理・処罰 | 国家犯罪・重大事件・上訴 |
| 官吏任免 | 領内官吏 | 中央官吏・国司 |
| 軍事 | 限定的な領内警備のみ | 帝国陸海軍・対外戦争 |
| 外交 | なし | 専管 |

（表は検討案として示された権限配分。司法権・治安権を含むことはユーザー確定）[^u036]

制度的には次の三つの区別が領主権を支えている。

* **爵位と領主権の分離**：爵位は宮廷での格式、領主権は実際の領地支配であり、別個に法制化される。無領の公爵家（旧摂関家・[弾正尹](/institutions/danjodai.md)家）もあれば、伯爵でも大所領を持つ家もありうる（検討案）。[^u024] → [華族制度と華族令](/institutions/kazoku-system.md)
* **国・領主権・領地の分離**：藩を廃して律令国を行政区画とし、領主権はその区域の全部または一部に設定される別個の権利とする（[廃藩置国](/institutions/kokugun-system.md)）。一国多領主もありうる。[^u021]
* **領主権の司法的保障**：領地境界・相続・交換などの紛争は[領主権裁定院](/institutions/lordship-tribunal.md)が裁定する。中央は「領地を取り上げる機関」ではなく「領主権を裁定する唯一の上位機関」として権威を得る（「司法的な統一を先行させる中央集権化」、検討案）。[^u022]

財政難の小領主は爵位を維持したまま領主権を返上できる（[領主権奉還](/institutions/lordship-surrender.md)）。その結果、小領主・財政難領主は年金・公債収入へ移り、島津・毛利・徳川・那珂川などの大領主は領主権を維持するという二極化が進む。[^u027]

## 元老院

議会の上院は史実の貴族院ではなく、領主権の代表機関としての[元老院](/institutions/genroin.md)である。領主議員・華族互選議員・勅選議員の三種を一院に収め、憲法・衆議院より先に1867年に成立する。[^u025][^u026][^u034]

* 定数300（領主議員180・華族互選議員75・勅選議員45）は仮案。領主議員は領主本人でなくてもよく、ドイツ連邦参議院のように領主家が代表を任命・交代する（検討案）。[^u025][^u026]
* 議決要件は議案によって異なる。一般法案・予算は過半数、国軍の基本制度は特別多数、領主権の一般的変更は特別多数＋領主議員の過半数、憲法改正は3分の2以上＋勅裁、個別領主の所領変更は当事者同意または特別裁定（検討案）。[^u026]
* 元老院は「領主権を守る機関」であると同時に「領主権を維持したまま全国市場を統一する機関」でもある。[^u044]

## 憲法

[大日本帝国憲法](/institutions/imperial-constitution.md)は名称こそ史実と同じで天皇の詔によって公布されるが、天皇を君として全領主の総意に基づく協約的な性格を持つ。[^u025][^u033] 諸侯は天皇に無限の権限を認めないため、憲法は史実のように1880年代末まで遅れず、1869年頃に制定される。[^u034]

* 参照モデルは1871年のドイツ帝国憲法型の「君主制＋領邦連合制」で、後に[アメリカ連邦制](/institutions/federalism-reception.md)の連邦法優位・州際通商・連邦司法が加わる。「ドイツ帝国型君主制＋アメリカ型連邦法制」の独特な立憲帝国となる。[^u025][^u045]
* 仮想条文（検討案）：第一条「大日本帝国ハ万世一系ノ天皇ヲ君主トシ、諸侯ノ協同ニ依リ統治セラル」、第三条「諸侯ノ世襲領主権ハ帝国ノ保障スル所トシ、法律ニ定ムル場合ヲ除ク外、之ヲ侵スコトヲ得ス」、第十二条「領主ハ其ノ領内ニ於テ、行政、徴税、警察及司法ノ権ヲ行フ。但シ帝国ノ憲法及例ニ違背スルコトヲ得ス」。[^u025][^u036]
* 標語として「形式は欽定、成立の実態は協約、統治原理は立憲君主制と領主自治の両立」が示されている（検討案）。[^u033]

立憲化の順序は「諸侯による君主権の制限 → 成文憲法の成立 → 人民による政治参加の要求 → 二院制への発展」であり、民撰議院設立建白書は「立憲政治を始めよ」ではなく「すでに存在する立憲政治に人民も参加させよ」という要求になる。[^u034][^u035]

## 帝国軍と統帥権

当初は領主系部隊を予備軍として抱える連合軍型の軍制も検討されたが、近代常備軍を維持できる領主は少なく、大領主も自軍を持つ合理性がないため、**領主は軍費を金納し、国軍が軍事を独占する**形に収斂した。[^u029][^u030] 大領主の競争は将官の輩出・兵器艦船の受注・士官学校への人材送り込み・軍事予算への影響力をめぐるものとなる。[^u030] → [帝国軍](/military/imperial-army.md)

この点で本世界線の日本は、構成邦が軍を維持したドイツ帝国とも異なる。「領主制は残っているが、軍隊はすでに近代的な国民国家の軍隊になっている」。[^u030]

軍の権限は1866年に朝廷が回収し、1869年の憲法で諸領主との合意のもとに再構成されたものであるため、**天皇に固有の統帥権は存在しない**。軍が天皇の権威のみに基づいて政府の指令を拒否することはできず、史実1930年の統帥権干犯問題は起きない。[^u124] 軍の政治的影響力は、元老院・衆議院の政治勢力との結合を通じて合法的制度の内側で行使される。[^u124] → [統帥権（本世界線）](/institutions/supreme-command.md)

## 財政

財政は「帝国の恒常財政」「諸侯の法定拠出」「領国財政」の三層からなる。諸侯の負担は個々の領主が兵を出す方式ではなく、元老院が承認した法定拠出制度であり、負担率・算定基準は元老院で決まる。[^u126] → [帝国財政と諸侯の法定拠出](/economy/imperial-finance.md)

1920年の中核モデル（検討案）では、帝国固有の税・事業収入23.5億円に諸侯の法定拠出2.5億円を加えた帝国恒常歳入26億円に対し、諸侯に残る地方財政収入は9億円で、連結歳入35億円（国民所得の17.5％）となる。国防費10億円は帝国歳入の約38％を占め、領主制ならではの財政制約となる。[^u126]

財政の分権は対外政策を強く規定する。領主議員は自領の鉄道・製鉄所・港湾への投資を背景に戦争の機会費用を具体的に計算でき、「領主の財布と帝国の財布が別でも、資本市場は同じ」という認識を持つ。[^u088] そのため日本は「ロシアと戦えるだけの国力を育てることには積極的でも、実際に戦争することには非常に慎重な国家」になる。[^u088]

## 法体系

明治維新後最初の大仕事は律令格式の整理であり、最終的に格を廃して法形式は**詔・勅（命令）／例（制定法）／式（施行規則）**に整理される。勅と式は例に反することができず、天皇の命令と全統治者を拘束する制定法とが区別される。[^u031][^u032] → [法体系（詔・勅・例・式）と司法制度](/institutions/legal-system.md)

司法は領主裁判所（領内の通常事件）・帝国裁判所（共通法事件・領主間事件・上訴）・弾正台（違法な権力行使の調査と訴追）に分かれる。長期的には「領主権の衰退は軍事権の喪失よりも司法権の統一によって進む」と見込まれる（検討案）。[^u036] 商事法は全国共通、裁判所は領主ごとという組合せから、商人の統一解釈要求が司法統一を促す。[^u044]

# 近代化のメカニズム

近代封建制が史実より速い近代化を生む理由は、大領主間の主導権争いである。[^u028]

1. **競争**：島津（南九州の産業・海運）、毛利（中国地方西部の交通・工業）、鍋島（北部九州の工業・技術教育）、徳川宗家（旧幕府の官僚・金融・商業網）、前田（北陸の産業・交通）、那珂川（常陸の産業・教育）などの有力領主圏が投資を競う（例示）。[^u028]
2. **寄親・寄子**：中小領主は大領主を寄親とし、軍費・出資・用地・元老院での協力を提供する代わりに、技術・販路・鉄道接続・留学機会を得る。→ [寄親・寄子制と大領主間の近代化競争](/concepts/yorioya-yoriko.md)[^u028]
3. **模倣と政策実験**：各領国が政策の実験場となり、成功した制度が模倣され、元老院で全国標準化される。[^u028]
4. **標準化**：領国間通商の障害を除くため、度量衡・貨幣・関所廃止・鉄道軌間・郵便電信・商事法の統一が進む。「経営主体は分散していても、制度と規格は全国共通」。[^u044] → [全国標準化政策](/institutions/national-standardization.md)

「明治政府による中央集権化が成功しなくても、領主たちの競争によって日本全体が近代化してしまう」構図であり、「元老院では領主連合が競争し、衆議院ではその領内で育った経済勢力が競争する」。[^u028]

1889年の日清戦争後には、賠償金の分配をめぐる争いが全領国に益する[帝国交通整備計画](/economy/transport-plan.md)へ転換される。「領主権を取り上げずに、領主たち自身の利益によって経済統合を進める」という近代封建制の典型的な解決である。[^u083]

# 対外行動への帰結

| 局面 | 近代封建制ゆえの特徴 |
|---|---|
| 征韓論相当（1870年代） | 征韓論を唱えるのは旧士族ではなく領主権を保障された現役の世襲統治者。武家の名誉観が元老院を通じて外交へ持ち込まれる [^u042] |
| 朝鮮独立保障（1884） | 世襲の権利を尊重しつつ上位の政治関係を変えるという1866年の論理が、李氏王統の保障に国内的説得力を与える [^u055] |
| 日清戦争（1887〜89） | 領主議員は自らの憲法上の統治権ゆえに外国君主の統治権への武力干渉に反対し、清の追加派兵で主戦論一色となる [^u067] |
| 論功行賞（1889） | 国軍が統一されているため、領主家・将兵・領主系企業の誰の功績かが争われ、「誰に何万石を与えるか」が再燃する [^u078] |
| 対露政策（1890年代） | 元老院の「金がない」という現実が開戦を抑え、軍備維持には賛成だが先制戦争には反対という合意が生じる [^u088] |
| 第一次世界大戦（1914） | 「負けたら損失が大きすぎるから戦う」と判断し、財政慎重派こそ参戦を支持する [^u096] |
| 戦間期の中国 | 外国資本と中国軍閥の結合が、元老院の領主系金融資本を介して日本政府を既成事実へ引きずり込む [^u106] |

# 長期的変容

領主権の性格は時代とともに変化する。「朝廷から安堵された世襲的権利」から「憲法によって保障される統治権」へ、さらに衆議院成立後は「世襲領主を長とする地方政府の自治権」へ移り、領主権は消滅せず、憲法・法律で制限され、領内行政に住民参加が導入されていく。[^u045]

領主権奉還の進行により、1880〜90年代には律令国のかなりの部分が直轄地となり、薩摩・長州・旧徳川領・那珂川領などに強い領主権が残る政治地図が想定されている（検討案）。[^u027] 1890年代の姿は「強大な統一帝国軍を持ちながら、国内ではなお世襲領主が警察・裁判所・行政機構を保持している」立憲国家である。[^u036] 新たに獲得した領土には既存の領主権が及ばず、北海道の分領・樺太の直轄・台湾の帝国特別領という三つの統治類型が生まれる。[^u066] → [新領土の統治制度](/institutions/new-territory-governance.md)

1930年に至っても、大領主の企業集団による継続投資という強みと、領主系企業の独占契約・調達優遇要求という弱みが併存しており、領主系資本の再編や独占規制が経済政策の課題となっている。[^u132]

ドイツ帝国との比較では、君主制と領邦の権限分配、元老院の領主代表制は類似するが、構成邦が軍を保持したドイツと異なり軍は統一されていること、諸侯が皇帝を選ぶ必要がないことが相違点である。[^u025][^u030] アメリカとの比較では、米上院が州代表であるのに対し元老院は領主家の代表であり、構成原理が異なる。[^u045]

# 却下・修正された案

* **領主軍の連合軍としての帝国軍**：帝国常備軍＋領主系予備軍・郷土防衛軍＋領主系軍需企業の三層軍制案は、常備軍を飼える領主は少ないとのユーザー指摘で撤回され、統一国軍に修正された。[^u029][^u030]
* **近代化は20年早まらないという留保**：大領主間の主導権争いを過小評価していたとして撤回され、近代化は史実より「巻きで」起きるとされた。[^u027][^u028]
* **憲法の1880年代制定案**：諸侯は天皇に無限の権限を認めないため、史実同様の遅い制定は不自然として退けられた。[^u033][^u034]
* **律令格式の四分類再定義**：律・令・格・式を近代法に対応させる案は、格を廃し律も消えるという方向で撤回され、詔・勅・例・式に整理された。[^u031][^u032]

# 未決の論点

* 「全領主の総意」を全員一致と解するか特別多数と解するか。[^u025]
* 領主権の基本内容を憲法で直接保障するか、例（法律）に委ねるか。[^u036]
* 国司を置くか、朝廷任命か最大領主兼任か、国司が領主の命令を取り消せるか。[^u021]
* 元老院の議席配分、領主権奉還の補償条件と進度、残存領主の分布。[^u026][^u027]
* 内閣・元老院・軍司令部の権限分配、軍部大臣現役武官制に当たる制度の有無。[^u124]
