# 概要

本世界線の幕末政治は、一つの問いから組み立てられている。明治維新が起きなかったとして、幕政は無限に続けられるのか。言い換えれば、**朝敵認定を避けつつ、諸藩の反発も抑え、なおかつ中央集権を強化して藩の自治を有名無実化する妙手はあるのか**。[^u003]

答えは、幕府の存続と近代国家としての中央集権化は根本的に矛盾する、というものである。幕府の権威を支えているのは、中央集権化によって権限を奪われる当の大名たちだからだ。徳川家は**幕府の存続を優先すれば中央集権化が進まず、中央集権化を優先すれば従来の幕府そのものを解体せざるを得ない**。戊辰戦争を回避できるかどうかよりも、その後どうやって幕藩体制を解体するかの方がはるかに難しい問題となる。[^u003]

本世界線は、このジレンマを「徳川家が自らの権力を削る」方向で進み、最終的には朝廷の権威を借りて始めた中央集権化が、同じ朝廷の権威によって徳川将軍の軍事権を停止させるという経過をたどる。ただしその代償として諸侯の世襲領主権が強く保障され、封建制の解体は史実よりはるかに長期化した。これが[近代封建制](modern-feudalism.md)の起源となる。[^u015][^u017]

# 矛盾の構造

## 中央集権化で諸藩が失うもの

江戸幕府の支配は、各大名の領国支配を認めることで成立していた。中央集権化の各施策は、そのまま諸藩の権限喪失を意味する。[^u003]

| 改革 | 諸藩が失うもの |
|---|---|
| 全国共通の徴税制度 | 独自の財政権 |
| 藩兵の中央軍への統合 | 軍事的自立 |
| 藩法の廃止と司法統一 | 領内の司法権 |
| 全国統一の官僚制度 | 藩士の人事権 |
| 藩境を越える行政区画の再編 | 世襲領国そのもの |

これらを一度に進めれば譜代大名でさえ抵抗しかねない。しかも徳川家が強行すれば、朝廷や雄藩にとって「徳川家による天下の私物化」と批判する格好の材料になる。戦争に勝った史実の新政府でさえ、1871年の廃藩置県には薩長土の御親兵という軍事的後ろ盾を必要とした。諸藩の合意によって存続している幕府には、さらに大きな困難がある。[^u003]

## 「幕府」と「幕藩体制」の区別

「幕府」という言葉は二つに分けて考える必要がある。第一に徳川家が代々将軍を務めるという意味での幕府、第二に幕府と諸藩がそれぞれ独自の行政権を持つという意味での幕藩体制である。両者は必ずしも同じ運命をたどらない。[^u003]

| 体制 | 長期的な存続条件 |
|---|---|
| 従来の幕藩体制 | 列強への対応、軍事・財政の統一で深刻な制約 |
| 諸侯連合型の幕府 | 藩の自治を残せるが、中央政府の権限は限定的 |
| 立憲化された徳川政権 | 徳川家の統治権を法律や議会で制限すれば存続の余地 |
| 天皇を元首とする統一国家 | 徳川家の役割が縮小し、事実上の幕府解体へ進む可能性 |

立憲化された徳川政権が成立しても、それが永久に徳川家の世襲政権として続くとは限らない。議会政治を広げれば、徳川家以外の人物を政府首班に求める勢力が生まれ、受け入れれば幕府は性格を変え、拒めば対立が再燃する。[^u003]

## 雄藩の論理

幕府が全国一律の軍事制度を導入しようとすれば、薩摩藩は「なぜ我々が自費で育てた軍隊を、江戸の中央政府に引き渡さなければならないのか」と問うだろう。これを克服するには、雄藩が中央政府の中で相応の権力を得られるようにする（閣僚・将官への登用、諸侯議政院への予算権付与）必要があるが、そうすれば徳川家の独占的権力は弱まる。これは避けがたい交換条件である。[^u003]

# 妙手の候補（検討案）

## 権限より先に負担を移す

幕末の藩の多くは財政難に苦しんでいた。そこで、藩主から領地を取り上げると宣言するのではなく、まず実際の行政負担を中央が引き受け、藩が名目上残っていても財政・軍事・外交の基本機能を中央に依存するように仕向ける。（検討案）[^u003]

| 中央政府が引き受けるもの | 諸藩が差し出すもの |
|---|---|
| 諸藩の債務の一部 | 関税・主要税収の徴収権 |
| 藩士への俸禄支払い | 独立した軍事行動を行う権限 |
| 海防・軍艦建造などの高額な軍事支出 | 外国との独自交渉権 |
| 幹線道路・港湾・通信設備などの整備費 | 一定の司法権・行政権 |

ただし重大な循環がある。中央が諸藩の負担を引き受けるには先に十分な税収が要るが、税収を中央へ移すには諸藩の合意が要り、その合意を得るには中央の財政力が要る。この循環をどう突破するかが難題とされた。[^u003]

## 朝廷の権威で「日本国の改革」にする

井伊直弼の失脚後に早期の公武合体が成立すれば、中央集権化を徳川家の権力拡大ではなく、「諸侯の合意と朝廷の裁可を経て日本国の行政を統一する」改革として示せる。（検討案）[^u003]

仮想・公武合体中央政府の構造は次のとおり。[^u003]

| 階層 | 役割 |
|---|---|
| 天皇・朝廷 | 国家の正統性、重要改革の裁可 |
| 将軍・中央政府 | 行政・外交・軍事・財政 |
| 諸侯議政院 | 立法・予算承認・改革協議 |
| 各藩・地方行政 | 当初は広い自治、次第に中央政府の法令に従う |

これは史実の公議政体論、特に1867年に西周が構想した「議題草案」（徳川慶喜を行政の頂点に置き、議政院が立法を担う）を1860年代前半に前倒しする発想である。しかし議政院が否決した政策を将軍が強行できるのか、将軍が拒否権を持たないならそれはもはや幕府ではなく「徳川家を行政の中心に据えた立憲国家」ではないか、という本質的な矛盾が残る。[^u003]

## 改革過程の構想

| 時期 | 段階 |
|---|---|
| 1862〜1865年 | 公武合体と諸侯会議の制度化。将軍が行政を主導する代わりに、有力諸侯を国政に参加させる |
| 1865〜1870年 | 財政・外交・海軍の統合。対外交渉・関税・主要港湾・海軍を中央管理へ |
| 1870〜1880年 | 地方行政と陸軍の再編。藩主を世襲的統治者から中央の制度に組み込まれた役職へ |
| 1880年代以降 | 立憲体制への移行。徳川家は世襲的地位を保ちつつ行政を議会と内閣へ委ねる |

（検討案）[^u003]

この筋書きなら明治維新のような政権交代を経ずに中央集権国家へ移行することも一応は考えられるが、全段階で利害調整に成功する必要がある。予想された帰結は、戊辰戦争の代わりに**1870年代に「徳川政権の権力をどこまで制限するか」をめぐる政治危機**が起こる、というものだった。[^u003]

## 最大の難所としての軍の統一

財政・法制度は段階的に改められても、軍事権の統合だけは別格である。中央の命令で動かない藩兵が存在すれば、地方の政治的自立を武力で支えられるからだ。一方で徳川家直属の軍を増強すれば諸藩は警戒する。そこで、徳川家の私兵ではなく朝廷の権威を背景にした「日本国軍」を、藩兵の出向 → 中央による軍費負担 → 将校の共同養成 → 新規採用の中央一本化、の順に作る構想が示された。しかしその指揮権を将軍・朝廷・諸侯政府のいずれが握るかが解決しない限り、中央集権化は完成しない。[^u003]

この問題は、その後の[全国常備軍（公武合体軍）](../military/standing-army-1861.md)の忠誠構造の議論へ引き継がれる。最初にできるのは「国軍」ではなく「諸侯連合軍」であり、俸給・家族扶助を中央が払う、軍籍を藩籍から分離する、将校任命権を中央に置く、藩別編成を解体する、の四条件を満たして初めて真の常備軍となる。[^u011]

# 二つの時計

ジレンマを一層厳しくしたのが、対外的な期限である。黒船はすでに来航し、清国が列強に打ち負かされる様子を日本は目の当たりにしていた。1860年は英仏軍が北京を占領し、円明園を破壊した年でもある。[^u008]

| 時計 | 期間 | 課題 |
|---|---|---|
| 外交・軍事上の期限 | 1860〜1863年 | 列強との衝突を避け、国内の対外軍事行動を統制する |
| 国家制度改革の期限 | 1860〜1870年代 | 税制・陸海軍・官僚制・地方行政を統一する |

（年代は目安）[^u008]

最初の期限が1863年頃とされるのは、それまでに外交・軍事の指揮系統を整えなければ、国内の一部勢力が独断で外国と戦争を始めてしまうからである（史実では長州の下関砲撃、薩英戦争）。決定的な分岐は「**1863年頃までに、外国から見て日本政府は国内の軍事行動を統制できていると認識される状態を作ること**」であり、成功すれば10〜20年をかけて制度を再編する余地が得られる。1860年の幕府には「国内改革を完成させる時間」はないが、「改革を始めて外交・軍事の主導権を確保する時間」はまだある。[^u008]

この順序から、中央集権化は二段階となる。[^u008]

1. **初期**: 諸藩の自治を残したまま、外交権の一元化、対外軍事行動の統制（藩の独断砲撃・外国人攻撃の厳罰による禁止）、海軍・沿岸防衛の中央化を先行させる。
2. **1860年代後半以降**: 全国的な行政・財政改革へ移る。

諸藩に「国家の独立を守るために軍事費を負担してほしい」と求めるのは比較的容易だが、「軍隊を幕府へ渡してほしい」と求めれば抵抗される。また、清朝が太平天国への対応などで軍事力を地方有力者に集中させてしまった構図を、日本は避けねばならない。諸藩に近代化を任せれば雄藩が強くなり、幕府が独占すれば専制強化と警戒される。この板挟みから、将軍直属軍ではなく朝廷の権威を背景とした「日本国の軍隊」という発想が改めて重要になった。[^u008]

# 本世界線での展開

## 最初の実例としての水戸処分

本世界線の中央集権化は、全国の藩を一挙に廃止することではなく、[水戸藩処分（1860年）](../events/mito-domain-disposal-1860.md)から始まった。御三家でさえ秩序に背けば領国を失い、「大名家の存続と特定の領国を世襲統治する権利は別問題」という論理が生まれた。ただし懲罰としての処分であり、一般大名への領地替え権に直結するものではない。[^u005][^u006]

さらに旧水戸領を朝廷の御料として幕府が預かる構想は、「領主の世襲権を尊重しつつ統治実務を中央へ委ねる」改革の先例となりうるものとして示された（[旧水戸領と禁裏御料預地](../regions/former-mito-domain.md)）。[^u007]

## 朝廷権威の導入とその逆説

幕府は水戸旧領の献上と引き換えに朝廷から全国海防の勅命を得て、諸藩に軍費と兵員を負担させる根拠とした（[1861年公武協定](../diplomacy/kobu-agreement-1861.md)）。これは「日本国の改革」という妙手の具体化だったが、同時に将軍の軍事権が朝廷からの委任であることを明文化し、徳川将軍による独占的統治の終わりを制度化する協定でもあった。[^u009][^u010]

1866年、家茂の死に際して朝廷は軍事委任を更新せず、諸侯の所領を安堵することで、ほぼ無血のうちに幕府を解体した（[1866年の無血の幕府解体](../events/bloodless-dissolution-1866.md)）。「軍事権を統一しなければ独立を守れない」という原則は幕府自身が確立したものであり、朝廷はそれを流用した。[^u015][^u016]

## ジレンマの帰結

* 幕府存続か中央集権化かというジレンマは、徳川将軍職の消滅という形で決着した。幕府を終わらせた決定的な行為は「徳川家を倒すこと」ではなく、「次の将軍に軍事権を再委任しないこと」だった。[^u015]
* しかし所領安堵によって幕府を解体したため、諸侯の世襲領国支配はかえって強く保障され、廃藩置県に相当する改革は一層難しくなった。中央政府には諸侯の領地を一方的に没収する権限がない。[^u015]
* 新政府の成立自体が領主権保障を前提とするため、版籍奉還も困難となる。「明治維新に相当する政権交代は史実より穏やかに進む一方、封建制度の解体ははるかに長期化する」。ジレンマは「幕府対諸藩」から「朝廷政府対世襲領主」へと形を変えて持ち越された（[なし崩しの維新](gradual-restoration.md)、[領主権](../institutions/lordship-rights.md)）。[^u016][^u017]

# 史実との比較

* 史実の公議政体論にも、各藩が会議の決定に従う保証や、決議を実行する強制力が不足しているという同様の問題があった。[^u003]
* 西周の「議題草案」（1867年）は国立国会図書館に現存する。[^u003]
* 史実では、戊辰戦争に勝利した新政府が1869年に版籍奉還、1871年に御親兵を後ろ盾として廃藩置県を断行し、ジレンマを軍事的勝利によって突破した。[^u003][^u017]
* 史実の幕府も1862年に西洋式歩兵・騎兵・砲兵による将軍直属の常備軍編成へ動いており、本世界線ではこれが前倒し・拡大される。[^u008]
* 1866年の改税約書で輸入関税が原則5％に引き下げられ、幕府の財政政策の自由度は大きく制限された。[^u008]

# 未決の論点

* 「負担の先行移転」に必要な中央の初期税収をどう確保したか（財政面の循環の突破方法）。[^u003][^u008]
* 諸侯議政院に相当する機関が幕府時代に設けられたか。[^u003]
* 朝廷政府が諸侯から独立した統治権力を得るための軍事基盤（史実の御親兵に相当するもの）を、1861年以来の全国常備軍からどう作り出すか。[^u016]
