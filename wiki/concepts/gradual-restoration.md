# 概要

「なし崩しの維新」は、本世界線における明治維新の性格を表す概念である。1866年に[徳川家茂](../people/tokugawa-iemochi.md)が死去し、朝廷が将軍への軍事委任を更新せずに幕府を解体したのち、幕府の権限を引き継いだ朝廷政府は、そのまま中央集権化を進めていった。明治維新のような国家改革は、ここから「なし崩しに」始まった。[^u016]

史実の明治維新は、戊辰戦争の勝利を軍事的な基盤とし、版籍奉還（1869）と廃藩置県（1871）で封建領主制を一挙に解体した革命的な変革であった。これに対し本世界線の維新は、倒幕戦争ではなく[1861年公武協定](../diplomacy/kobu-agreement-1861.md)に基づく政権移行から始まり、諸侯との合意を積み重ねて進んだ。そのため史実よりも「諸侯に優しい」ものとなり、次の逆説的な性格を帯びる。[^u016][^u017]

> 明治維新に相当する政権交代は史実より穏やかに進む一方、封建制度の解体ははるかに長期化する。

[^u017]

> 1867年に明治時代が始まっても、日本は依然として領主たちによって分割統治されている。

[^u020]

# 起源: 幕府の延命策が幕府解体の基盤になる

なし崩しの過程は、1860年に幕府の延命を目的として始められた改革にさかのぼる。[^u016]

1. 井伊直弼が生還し、水戸徳川家が処分され、幕府は一時的に権威を回復する。
2. 国防のために朝廷と協定を結んだ結果、将軍の軍事権が朝廷からの委任として再定義される。
3. 家茂の死によって、その委任を更新する必要が生じる。
4. 朝廷は委任を更新せず、徳川家の所領を保障しながら新しい政府を置く。

[1861年公武協定](../diplomacy/kobu-agreement-1861.md)の時点で、すでに「大政奉還が1861年から少しずつ進む」構造が埋め込まれていた。軍費を負担する諸侯が使途への発言権を求め、やがて国家軍の指揮権と財政権が中央政府の制度に組み込まれていく。徳川幕府は朝廷との協定を通じて、段階的に自分自身を解体していった。[^u010]

その背景には、幕府の存続と中央集権化が根本的に矛盾するという構図がある（[幕藩体制と中央集権化のジレンマ](centralization-dilemma.md)）。幕府の存続を優先すれば中央集権化は進まず、中央集権化を優先すれば幕府自身を解体せざるをえない。[^u003]

# 中央集権化の推進力: 軍事統一論の転用

## 薩英戦争の教訓

1863年の薩英戦争は、雄藩の薩摩でさえ列強海軍から沿岸施設や都市を守りきれないことを示した。生麦事件では幕府が英国に10万ポンドの償金を払い、薩摩も別に賠償を求められた。そこから「一藩の軍備では列強海軍に対抗できない。一藩の外交問題で日本全体が戦争に巻き込まれる」という教訓が導かれた。これは常備軍の増強だけでなく、諸藩が独自に軍を持ち外国と衝突する権限そのものを制限する理由となった。[^u016]

## 論理の転用

| 年 | 主張者 | 主張 |
|---|---|---|
| 1863 | 家茂 | 諸藩がそれぞれ独自に軍備を整える時代は終わった。皇国の防衛は、朝廷の命を受けた将軍が一元的に担当しなければならない |
| 1866 | 朝廷 | 皇国の防衛は一元的に運営しなければならない。ゆえに将軍の死によって軍事行政を停止させるわけにはいかない。今後は朝廷の下に恒久的な軍務機関を設ける |

[^u016]

軍事権を統一しなければ日本の独立を守れない、という原則は幕府自身が確立したものである。しかしこの原則は、徳川家が統治を続けなければならない理由にはならなかった。[^u016]

列強の脅威が続く限り、中央政府は追加改革を正当化し続けることができた。「海軍維持のためには全国統一の財政制度が必要である」「外国との戦争に備えるには藩ごとに異なる軍制を廃止する必要がある」「軍費の公平な負担には全国共通の税制が必要である」という論理である。ただし、最初に所領を安堵された諸侯は、その約束を根拠に改革に反対することもできた。[^u016]

# 「諸侯に優しい」維新の構造

## 1866年の交換条件

| 朝廷が保障するもの | 諸侯に求めるもの |
|---|---|
| 現在の所領と家格 | 新政府への服属 |
| 藩主家の存続 | 外交権の中央政府への一元化 |
| 家臣の身分・俸禄の当面の保障 | 全国軍費の負担 |
| 中央政務への参加 | 藩兵の一部を国家軍へ移管 |

これは廃藩置県ではない。しかし外交・財政・軍事の一部を中央が握ることで、藩主が領国内で自由に決められる範囲は少しずつ狭まっていった。[^n1][^u016]

薩摩にとってこの体制は、天下を取る地位ではなく「徳川幕府を介さず国家の軍事政策に直接参加する資格」を意味した。新政府は薩摩の軍事指導者を中央軍の幹部に登用するなどの妥協を必要とした。[^u016]

## 領主権の温存

新政府の成立自体が諸侯の領主権の保障を前提としているため、藩主を中央任命の官僚（知藩事型）にすることは難しい。朝廷は「天下の土地は究極的には天皇のものだが、各家の封土は従前どおり安堵する」という伝統的な封建の論理をとった。藩主権はほぼそのまま[領主権](../institutions/lordship-rights.md)として認められ、版籍奉還は新政府が成立時の約束を破ることになるため、きわめて困難となった。[^u017]

1869年頃の領主権は、行政・徴税・警察・司法を含む包括的な固有の権限であり、「領邦主権」に近いものだった。[^u036]

# 展開の諸段階

なし崩しの維新は、次の段階を経て進んだ（各項目の詳細はリンク先を参照）。

| 年 | 出来事 | 意味 |
|---|---|---|
| 1861 | [1861年公武協定](../diplomacy/kobu-agreement-1861.md) | 将軍の軍権を朝廷の委任とする |
| 1866 | [無血の幕府解体](../events/bloodless-dissolution-1866.md) | 軍事委任の不更新と全諸侯への所領安堵 |
| 1867 | [明治改元](../events/meiji-era-proclamation-1867.md) | 践祚と同日の改元。明治の開始と廃藩置県が切り離される |
| 1867 | [元老院](../institutions/genroin.md)、[領主権裁定院](../institutions/lordship-tribunal.md)、[弾正台](../institutions/danjodai.md)、[華族令](../institutions/kazoku-ordinance-1867.md)、[皇室典範](../institutions/imperial-house-law.md) | 領主権を保障しつつ、それを裁定・監察する上位機関を置く |
| 1868 | [廃藩置国と国郡制](../institutions/kokugun-system.md) | 藩を廃して律令国を行政区画とし、領主権を国郡村単位で登録 |
| 1869頃 | [大日本帝国憲法](../institutions/imperial-constitution.md) | 天皇と諸領主の権限を明文化した「領主のための憲法」 |
| 1870年代 | 軍費の金納化 | 領主が独自軍を縮小し、国軍が軍事を独占していく |
| 1874〜1876 | [民撰議院設立建白書と衆議院](../institutions/house-of-representatives.md) | 「すでに存在する立憲政治に人民も参加させよ」 |
| 1870〜1890年代 | [領主権奉還](../institutions/lordship-surrender.md) | 財政難の小領主が領主権を自発的に返上 |

[^u015][^u020][^u021][^u030][^u034][^u035]

## 1866〜1870年の当初の見通し

1866年時点での見通しは、1867〜1870年に朝廷主導で国家改革を進め、諸侯会議を通じて外交・海軍・財政を中央に統合し、地方統治の再編に着手するというものだった。藩主は地方行政の責任者として残り、中央の軍事・外交・財政権だけが先に強化される。[^u016]

## 司法的統一の先行

本世界線の中央集権化は、領地を取り上げることからではなく、領主権を「裁定する」ことから始まった。[領主権裁定院](../institutions/lordship-tribunal.md)は、既存の領主権の保障を実効あるものにする機関として発足した。朝廷政府は諸侯の領主権を保障する代わりに、その領主権を裁定する唯一の上位機関となった。「領主権を温存することが、逆に中央政府の権威を強める」という「司法的な統一を先行させる中央集権化」である。[^u022]

長い目で見ると、領主権の衰退は軍事権の喪失よりも、司法権の統一によって進むと見込まれる。[^u036]

## 律令格式の再編としての維新

本世界線では、明治維新後の最初の大仕事は律令と格式の整理であった。法体系は最終的に詔・勅・例・式に整理される（[法体系](../institutions/legal-system.md)）。この世界の明治維新は「廃藩置県を中心とする改革ではなく、律令格式の再編纂を通じて諸侯の自治と中央政府の権限を整理する改革として記憶される」。[^u031]

## 立憲化の順序

諸侯は天皇に無限の権限を認められないため、憲法は史実より20年早く制定された。立憲化は次の順序で進む。[^u034]

1. 諸侯による君主権の制限
2. 成文憲法の成立
3. 人民による政治参加の要求
4. 二院制への発展

史実の立憲化が「民権派の要求→政府による欽定憲法」の順だったのに対し、本世界線では「領主のための憲法」が先にあり、それを「臣民のための憲法」に改める運動として自由民権運動が起こる。諸侯が自らの権利を守るためにつくった憲法が、領民が政治的権利を求める根拠になるという逆説がここにある。[^u035]

# 近代化の速度

本世界線の近代化は、史実より20年程度早いペースで進んだ。その理由は、大領主のあいだで主導権争いが起きたことにある。中小領主は大領主を寄親として改革を進める（[寄親・寄子制と大領主間の近代化競争](yorioya-yoriko.md)）。[^u027][^u028]

| 分野 | 史実との比較 |
|---|---|
| 立憲政治 | 大幅に先行 |
| 全国常備軍 | 1860年代から整備 |
| 地方行政 | 律令国の再編は早いが、領主権の解消は長期化 |
| 政党政治 | 早く形成 |
| 経済・技術 | 大領主間の競争で加速 |

[^u027][^u028]

> 明治政府による中央集権化が成功しなくても、領主たちの競争によって日本全体が近代化してしまう。

[^u028]

政治的近代化が先行するのに、封建領主制は長く存続する。この組み合わせはドイツ帝国に似ている。[^u027]

# 残された課題

なし崩しの維新の最大の課題は、諸侯との合意で成立した朝廷政府が、どの段階で諸侯から独立した統治権力を獲得できるかであった。史実では戊辰戦争の勝利と御親兵の編成が新政府の中央集権化を支えた。本世界線では、それに相当する軍事的基盤を、1861年以来の[全国常備軍](../military/standing-army-1861.md)から生み出せるかが争点となった。[^u016]

最終的に領主たちは独自軍を持たず、軍費を金納する道を選び、国軍が軍事を独占した。1894年には「領主制は残っているが、軍隊はすでに近代的な国民国家の軍隊になっている」状態に至る。[^u030]

# 史実との比較

| 項目 | 史実の明治維新 | なし崩しの維新 |
|---|---|---|
| 始点 | 1867年の大政奉還・王政復古、1868年の戊辰戦争 | 1861年公武協定、1866年の軍事委任不更新 |
| 政権交代の手段 | 内戦 | 勅命と所領安堵（無血） |
| 主導勢力 | 薩長 | 朝廷と諸侯連合（徳川家を含む） |
| 明治改元 | 1868年10月23日（慶応4年9月8日） | 1867年2月13日（践祚と同日） |
| 封建制の処理 | 1869年版籍奉還、1871年廃藩置県 | 領主権として存続。廃藩置国（1868）は区画の再編にとどまる |
| 憲法 | 1889年に欽定 | 1869年頃、諸侯との協約的性格 |
| 議会 | 1890年に帝国議会 | 1867年に元老院、1876年に衆議院（第一回総選挙） |
| 後世の記憶 | 廃藩置県と中央集権化 | 律令格式の再編纂と領主権の整理 |

[^u017][^u020][^u031][^u034]

# 編集注：未決の論点

- 廃藩置県に相当する改革（領主権の全面的な解消）が最終的に起きるのかどうか、起きるならその時期（1937年末時点では領主249家が存続しており、全面的な解消には至っていない）。[^u017]
- 朝廷政府が諸侯から独立した統治権力を獲得した時点をどこに置くか。[^u016]
- 領主権と国家の財政統一の衝突をどう処理するか（行政権の買取、年金、実務の委任など）。[^u017]

# 編集注：却下・修正された案

- **近代化の先行幅**: 当初は「近代化の開始そのものは20年早まらず、立憲・地方制度が10〜20年先行しうる」と留保されていた。しかし、大領主間競争の効果を過小評価していたとして撤回され、近代化そのものが巻きで進むという設定に改められた。[^u027][^u028]
- **領主の軍事力**: 領主系予備軍などを含む「諸侯連合型」の軍制案は、常備軍を維持できる領主は少ないという指摘を受けて撤回された。領主は軍費を金納し、国軍が軍事を独占する方向に修正された。[^u030]
- **憲法制定時期**: 史実どおり1880年代後半に憲法を制定する案は、諸侯が天皇に無限の権限を認めるはずがないとして退けられ、1869年頃の制定となった。[^u034]
