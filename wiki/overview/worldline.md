# 概要

本世界線は、**アメリカ南北戦争が史実よりあっさり終わる（または起きずに和解する）**ことと、**1860年の桜田門外の変が失敗し井伊直弼が生き延びたまま押込で失脚する**ことの二つを出発点とする改変歴史である。[^u001][^u002] 薩長の武力倒幕に有利な条件が失われ、幕府は水戸藩処分と朝廷との取引（1861年公武協定）によって全国常備軍の整備を始めるが、その取引こそが将軍の軍権を「朝廷からの委任」に変え、1866年の家茂死去を機に幕府は流血なく解体される。[^u009][^u010][^u015]

新政府は諸侯の所領を安堵することで成立したため、史実の版籍奉還・廃藩置県に当たる改革が行えない。その結果、日本は**世襲領主が行政・徴税・警察・司法を保持したまま、元老院・成文憲法・統一国軍・全国市場を備えた立憲帝国**となる。本 wiki ではこの体制を[近代封建制](/concepts/modern-feudalism.md)と呼ぶ。[^u017][^u036]

この日本は領主間の近代化競争によって史実より早く工業化し、1887〜1889年に前倒しの日清戦争を戦い、三国干渉も日露戦争も経験しないまま英国と金融・通商・海軍で結びつき、第一次世界大戦では連合国の工業・海運供給国となって債権国へ転じる。戦間期の焦点は中国大陸の利権秩序をめぐる日英仏と米独の対立、ワシントン・ロンドン両軍縮会議、金本位制離脱後の円の国際化である。[^u077][^u095][^u125][^u137]

1930年のロンドン条約で米国が日英の海軍を一体として数えたことから、日英は同年に海上通商防衛協定を結び、1932年の追加議定書で「限定的な海上通商防衛同盟」となる。満洲事変は起きず、日本は国際連盟に残る。1936年末に海軍軍縮体制が全面的に失効すると、航空主兵論に転じた日英と、工業力で対抗する米国との建艦競争が1937年に始まる。1937年の日本はGDPが米国の28.0%、英国本国とほぼ同じ規模で、資源を英国経済圏と[中国諸省聯合](/diplomacy/china-federation.md)から輸入し、資本と海運で稼ぐ国になっている。[^e011][^e053][^e054][^e061][^e065][^e097]

# 世界線の前提原則

本世界線の設定作業で一貫して用いられている原則を以下にまとめる。

| 原則 | 内容 | 典拠 |
|---|---|---|
| 分岐は日米のみ | 日本とアメリカ以外の環境・所与の条件（清・朝鮮・欧州列強の内部条件など）は史実通り。変化は日米の変化が第三国へ及ぼす影響として扱う | [^u047] |
| 史実の事件は「起きない理由」を要する | 江華島事件・サラエボ事件・血の日曜日事件などは、構造的原因が日米の分岐と無関係なら本世界線でも起きる前提で考える | [^u041][^u094][^u112] |
| 経過と結果は変わりうる | 事件が起きることと、それが史実と同じ規模・帰結に至ることは別。日付・人物・規模は史実から機械的に移さない | [^u094][^u112] |
| 領主は武家出身 | 元老院を構成する世襲領主は武家であり、対外政策は名誉・武威の観念から武断的に傾きやすい | [^u042] |
| 戦争は財布で判断される | 領主は自領への投資の機会費用を理解しており、「勝っても儲からない戦争」には消極的だが、「負けたら失うものが大きい戦争」には踏み切る | [^u088][^u095] |
| 暦と首都 | 1867年が明治元年（史実より約1年早い改元）。首都は京都のままで、「東京」の地名は生まれず江戸が存続する | [^u020][^u133] |
| ダイスで未知数を決める | 会話ログ2では、構造的に決めきれない成否（技術開発・制度改革・産業の合理化など）を1d100の判定で決める。成功・失敗とクリティカル・ファンブルは確定設定として扱う | [^e063][^e074] |
| ダイスは数値までは決めない | 「ダイスの成功は産業の発展を確定させるが、対米労働生産性の具体的百分率まで確定させるものではない」。経済推計は目標値（対米28%や42%）に合わせず、産業構造から自然に導かれる数字を採る | [^e087] |
| 共通価格で積算する | 1937年の経済規模は「1937年米国価格基準の億ドル相当」で産業別に積算し、円建ての名目値は1920年の国民所得200億円から実質成長率と物価指数で別途延ばす | [^e086][^e098] |
| 1938年以降は保留 | 1937年の経済基本設定を基準値とし、1938年以降の成長・軍拡・日英技術協力は予測シナリオにとどめて確定しない | [^e103] |

## 二つの分岐点

* **アメリカ側の分岐**：南北戦争が史実より早く終わる、または起きずに和解する。米国の対日関与が維持され、英国が対日貿易で突出する状況が生じず、戦後の余剰銃の流入など戊辰戦争を支えた条件も変わる。終結時期を「1862年以前」とする案が示されているが、早期終結か回避かは確定していない。[^u001] 詳細は[南北戦争の早期終結と幕末日本](/events/american-civil-war-avoided.md)。
* **日本側の分岐**：1860年3月の桜田門外の変で襲撃が失敗し、井伊直弼は生き延びるが、彦根藩重臣による押込で大老の実権を失う。幕府は暗殺による権威失墜を免れつつ政策転換できる。[^u002] 詳細は[桜田門外の変の失敗と井伊直弼の押込](/events/sakuradamon-incident-failed.md)。

南北戦争を回避した米国は州権が強く残り、連邦制が日本の領主制の参照モデルとなる（後述）。また1914年の大統領がウィルソンである保証がないなど、米国自身も史実と異なる発展をとげる点に注意を要する。[^u045]

# 各時代の要点

## 幕末（1858〜1866）

井伊直弼の失脚後、幕府は水戸藩を処分し、旧水戸領35万石を皇室へ献上する見返りに「全国海防の勅命」を得て全国常備軍を整備する。しかしこの協定は将軍の軍権を朝廷の委任に変え、若い将軍家茂の強硬路線が勅許なき第二次長州征討で破綻すると、家茂死去に際し朝廷は軍事委任を更新せず、諸侯の所領安堵と引き換えに幕府を無血で解体し、そこから「なし崩し」の国家改革が始まる。「幕府を終わらせる決定的な行為が『徳川家を倒すこと』ではなく『次の将軍に軍事権を再委任しないこと』になる」。[^u012][^u014][^u015][^u016] → [通史：幕末（1858〜1866）](/history/1858-1866-bakumatsu.md)

## 明治国制の建設（1867〜1881）

1867年の明治改元とともに皇室典範・華族令・元老院が整備され、1868年に藩が廃されて律令国が行政区画として復活する（廃藩置国）。1869年頃には天皇と諸領主の協約的性格を持つ大日本帝国憲法が詔で公布され、1874年の民撰議院設立建白を経て衆議院が加わる。法体系は詔・勅・例・式に再編され、領主間の主導権争いと寄親・寄子関係、元老院による全国標準化が近代化を加速させる。[^u020][^u021][^u026][^u028][^u032][^u034][^u035] → [通史：明治国制の建設（1867〜1881）](/history/1867-1881-state-building.md)

## 朝鮮問題（1870〜1886）

対馬宗家の外交特権を接収して外交を一元化した結果、朝鮮との国書問題が早期に表面化し、武家領主が主導する元老院で強硬論が高まる。江華島事件と朝鮮開国、1882年漢城危機の手打ち、清仏戦争を好機とした1884年の介入と朝鮮国独立保障を経て、清の干渉に追い詰められた高宗が日本公使館に避難し、1886年には袁世凱を逮捕させるに至る。[^u041][^u048][^u055][^u060] → [通史：朝鮮問題（1870〜1886）](/history/1870-1886-korea-question.md)

## 日清戦争と下関条約（1887〜1889）

清の朝鮮征討で始まった戦争は、追加派兵とともに元老院を主戦論で塗りつぶし、目的は高宗保護から北洋艦隊の無力化、台湾・澎湖割譲へと拡大する。講和の制約は清の支払い能力であり、日本は英国中心の銀行団と賠償借款を調整し、英仏の利権を先に既成事実化したうえで1889年に下関条約を結ぶ。遼東を求めないため三国干渉は起きない。[^u071][^u077][^u079] → [通史：日清戦争と下関条約（1887〜1889）](/history/1887-1889-sino-japanese-war.md)

## 列強競争と日英協調（1889〜1914）

賠償金は全領国に益する交通網整備に投じられ、重工業化が進む。日本にとって最も怖いのはロシアだが、戦っても得るものがないため、英国の権益と朝鮮独立保障を組み合わせた抑止で臨む。英国権益への挑戦では英国が第一の当事者で、日本は単独で前面に出ない。日露戦争は起きず、清朝では袁世凱が敗戦責任で処刑され、清末から民国への移行は史実より不安定になる。[^u083][^u084][^u088][^u089][^u105] 清の軍制改革は多極化し、1900年の義和団事件を経て、載灃の強引な集権化が地方を離反させる。1911年の革命で溥儀は退位せずに亡命し、「清朝の滅亡は史実より容易だが、代わる統一国家の成立は史実より困難」となる。[^e015][^e018][^e019][^e020] → [通史：列強競争と日英協調（1889〜1914）](/history/1889-1914-great-power-rivalry.md)

## 第一次世界大戦（1914〜1918）

サラエボ事件から欧州大戦が起き、日本は「英国が負けると失うものが大きい」として英国側で参戦する。陸軍の大規模欧州派遣は見送り、海軍による東方海域の防衛代行と軍需品・船舶供給で連合国を支える。日米の物資供給はかえってロシアの人的損耗を増やし、帝政の崩壊を早める。日本は英仏への大口債権国となる。[^u095][^u119] → [通史：第一次世界大戦（1914〜1918）](/history/1914-1918-world-war-one.md)

## 戦間期（1919〜1930）

対独産業賠償と英国の戦時債務整理を通じて、日本は英国の中国権益に資本参加する。中国は統一国家とならず、旧清朝の契約を承継する中国諸省聯合（北京・南京・武漢）を日英が支え、米国は門戸開放を掲げて広州の中華民国やドイツと接近する。1926年に始まる北伐は湖北・江西で膠着し、1928年の武昌公邸火災事件で聯合は指導者を失う。ワシントン会議は主力艦建造停止のみ成立し、それ以外は決裂する。天皇に固有の統帥権がないため統帥権干犯問題は起きず、1925年に金本位制を法的に廃止していたため金解禁論争も生じない。1930年のロンドン条約は日英海上通商防衛協定と一体で成立する。[^u102][^u124][^u125][^u137][^e011][^e025][^e032][^e034][^e041] → [通史：戦間期（1919〜1930）](/history/1919-1930-interwar.md)

## 1930年代（1930〜1937）

1931年の欧州通貨危機で日本は英国の信用秩序を支えつつ金本位制の維持には加担せず、円・ポンドの協調を築く。恐慌下では公債による公共投資と資源の戦略備蓄で需要をつくり、1932年のオタワ会議には特別オブザーバーとして参加し、資源輸入と円建て投資の優遇を得る。同年の第一追加議定書で、日英は一方の商船だけが攻撃された場合や適法な海上封鎖も対象とする共同防衛義務を負う。1933年のナチス政権成立後も日独は接近せず、1935年のエチオピア危機では日本が英国の海上封鎖を引き止める。第二次ロンドン会議は全面決裂し、1936年末に軍縮体制が終わる。1935年の日英共同航空攻撃試験の大成功から日英は航空主兵論を採り、1937年に建艦競争が始まる。[^e042][^e043][^e049][^e051][^e053][^e054][^e058][^e061][^e063][^e064] → [通史：1930年代（1930〜1937）](/history/1930-1937-thirties.md)

# 未決の論点

世界線全体に関わる主な未決事項は次のとおり（個別の未決は各記事を参照）。

* 南北戦争が「早期終結」か「回避」か、その時期。米国が幕府の協力者となるか新たな圧力となるか。[^u001]
* 1861年公武協定の軍事委任が将軍個人への委任か徳川家への世襲保障か（無血解体は前者を前提とする）。[^u010][^u015]
* 憲法公布の正確な年、元老院の議席配分（定数300＝180/75/45は仮案）、衆議院の設置年。[^u026][^u034]
* ロシア革命の具体的経過（ボリシェヴィキ政権掌握と単独講和は十分合理的とされるが、日付や指導者は確定しない）。第一次世界大戦の終結年（1918年終戦のシナリオBが作業の中心）。[^u112][^u119]
* 溥儀のロシア革命後の処遇、中国諸省聯合が正式な国家を名乗るか、黎元洪の後継者、武昌公邸火災事件の真相。[^e025][^e034][^e035]
* 日英海上通商防衛協定の第二追加議定書（事前協議・事前通告）。米国への航空試験情報の伝達失敗が偽情報か分析の失敗か。[^e058][^e064]
* 1937年時点の国内政治（政党・議会・元老院）、税制と領国財政、陸軍の編制、海軍の実保有艦艇、円・ポンド・ドルの為替相場、1930年代の中国・欧州・米国の情勢。[^e100][^e103]
* 1938年以降の展開（成長・軍拡・日英技術協力の判定は振られずに保留）。[^e102][^e103]

前編で未決とされた事項のうち、辛亥革命と中国の承認問題（清帝は亡命し、日英は中国諸省聯合を承認）、ナチス政権の成立（1933年に史実どおり成立）、1930年のロンドン会議の帰結（100：85：65の総量規制と日英海上通商防衛協定）は会話ログ2で解決した。[^e011][^e025][^e054]
