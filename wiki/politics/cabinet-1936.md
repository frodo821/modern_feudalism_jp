# 概要

1936年は、元老院の第12回改選と衆議院の第16回総選挙（初の男女普通選挙）が重なった両院同時改選の年である。この改選の後、1930年から続いた国民進歩党・社会民権党の連立が解消した（ダイス判定：難易度40、出目14・失敗）。[^p009] 政権の再編では、衆議院の政党間で先に政権協定が結ばれた。元老院は倶楽部の間で統一協定を結べなかったが、衆議院側の首相候補を人物本位の投票で受け入れた。その結果、**国民進歩党と立憲改進党（いずれも仮称）を与党とする少数与党連立内閣**が成立した。[^p080]

与党は衆議院300議席のうち128議席（42.7%）しか持たない。だが、国民協同党（仮称、46議席）と正式な閣外協力協定を結び、支持基盤は174議席（58.0%）となった。[^p081] 首相は国民進歩党の出身で、閣僚の中枢は衆議院出身者が占めた。元老院には公式の与党会派を持たず、有力議員との個人的な協力関係で支持を確保した。内閣は1937年度予算を両院で大きな修正なく成立させ、1937年末まで存続した。[^p080][^p081] 首相の人名は未定である。[^p080]

この政権の成立は、「**首相の選出権は元老院にあるが、政権形成の主導権は衆議院の政党間交渉に移りつつある**」という慣行を定着させる事例とされる。[^p081]

# 背景

## 憲法上の内閣形成手続

内閣首班の指名権は元老院にあり、出席議員の半数以上の賛成で指名する。新内閣が組閣されると、衆議院は直ちに組閣拒否（不承認）決議案を諮らなければならず、これを否決することで新内閣への信任を示す。衆議院は出席議員の半数以上で組閣拒否・不信任を決議できる。棄権した議員は欠席として数え、可否同数なら可決となる。衆議院に解散はなく、両院の改選でも内閣は自動的には解散しない。議員は領主を除き他の公職と兼任できず、閣僚にもなれない。[^p002] 制度の全体は[内閣制度と両院関係](/institutions/cabinet-system.md)を参照。

衆議院の積極的な信任は不要である。野党が不承認・不信任の動議で結束しなければ、少数与党内閣でも存続できる。[^p080]

## 進歩・民権連立の時代（1930〜1936年）

1930年の元老院改選の直後、国民進歩党と社会民権党を中核とする開発・社会政策連立内閣が成立し、1932年の総選挙で基盤を強めた（社会民権党の初入閣：ダイス判定 難易度55、出目69・成功）。この連立は、世界恐慌に財政支出による需要創出で対応した。[^p008] 1932年の連立与党は衆院167議席（55.7%）であった（検討案）。経緯は[内閣の系譜と政党内閣の慣行](/politics/party-cabinets.md)を参照。

1936年の改選の後、連立は解消した。原因は選挙制度改革や国内政策をめぐる両党の対立であり、再軍備をめぐる対立による政権崩壊は回避された（ダイス判定：難易度45、出目26・失敗＝崩壊せず）。国防費の拡大については両院と主要政党の間で合意が成立していた（ダイス判定：難易度30、出目46・成功）。[^p009]

## 衆議院の政権協定

衆議院では、政党間の政権協定が元老院の首班指名に先行して成立した。国民進歩党が中核の地位を保ち、立憲改進党が参加した。国民協同党は入閣しなかった。[^p080] 両党の政策協定の内容案は次のとおりである（検討案）。[^p080]

| 政策分野 | 方針 |
|---|---|
| 財政 | [1925年財政原則](/economy/fiscal-principles-1925.md)を維持 |
| 公共投資 | 交通・電力・産業基盤の整備を継続 |
| 経済政策 | 民間設備投資・輸出産業の振興 |
| 労働政策 | 既存の労働保護制度を維持 |
| 社会保障 | 既存制度の安定運営を重視 |
| 国防 | 両院の国防政策上の合意を維持 |
| 外交 | 対英経済関係・国際協調を維持 |
| 領主制度 | 公私財政分離と家門自治を維持 |
| 金融政策 | 信用秩序の回復・企業金融の円滑化 |

社会民権党が連立から離れたため、労働者保護や社会保障の急速な拡張には慎重になる。他方で、国民協同党の協力なしには衆議院の運営が難しいため、女性の就業・教育・母子保護に関する要求を無視できない。[^p080]

## 元老院の首班指名

元老院では、倶楽部の幹事の間で首班指名の統一協定はまとまらなかった。しかし、衆議院の政権協定で一本化された候補の議会活動・行政経験・人脈を評価した議員が個別に支持し、初回の採決で首相が指名された。[^p080] 倶楽部別の投票の内訳案は次のとおりである（検討案）。[^p080]

| 倶楽部 | 議席 | 連立側候補 | その他の候補 | 棄権 |
|---|---:|---:|---:|---:|
| 宗交会 | 63 | 28 | 32 | 3 |
| 交友倶楽部 | 60 | 42 | 16 | 2 |
| 興業会 | 57 | 39 | 16 | 2 |
| 諸侯協同会 | 43 | 23 | 18 | 2 |
| 六合会 | 32 | 17 | 13 | 2 |
| 同文会 | 31 | 18 | 11 | 2 |
| 北辰会 | 11 | 7 | 3 | 1 |
| 無所属 | 13 | 6 | 5 | 2 |
| **合計** | **310** | **180** | **114** | **16** |

投票者294人に対して必要票数は147票で、連立側候補は180票を得た。全会一致の倶楽部は一つもないが、すべての倶楽部から支持を得ている。元老院に正式な与党会派がないまま、衆議院で成立した政権協定を尊重する形で首相が指名された。[^p080]

## 衆議院の不承認動議

組閣後、衆議院は直ちに組閣拒否（不承認）動議を諮った。国民協同党46人が全員棄権した場合、不承認賛成126票（協同党以外の野党）、反対128票（進歩・改進両党）となる。投票者254人に対して可決には127票が必要で、動議は**1票差で否決**される。この採決結果は暫定案である。[^p080]

国民協同党は、入閣しない、首相候補は条件付きで容認する、不承認動議には棄権または反対する、という立場をとった。社会保障は案件ごとに協力し、女性の権利と教育では独自の要求を示し、予算は個別に交渉する（検討案）。[^p080]

## 1936年進歩・改進・協同三党協定（仮称）

国民協同党との正式な閣外協力協定が結ばれ、女性・家庭関連の政策が大幅に盛り込まれた。協定の内容案は次のとおりである（検討案）。[^p081]

| 政策分野 | 協定内容 |
|---|---|
| 内閣の存続 | 原則として不承認・不信任動議に協力しない |
| 予算 | 合意された政策を実施する予算に賛成する |
| 女子教育 | 中等・職業・高等教育への進学機会の拡大 |
| 女性の就業 | 就業機会の拡大と不合理な就業制限の見直し |
| 母子保護 | 妊産婦医療・乳幼児保健の拡充 |
| 労働保護 | 産前産後の休業制度と女性労働者の保護 |
| 家族法 | 婚姻・離婚・相続・財産管理制度の調査と見直し |
| 社会保障 | 遺族・母子世帯への給付制度の整備 |
| 行政参加 | 女性の公職・行政機関への参加機会の拡大 |

協定に盛り込まれたことと、1937年末までに法制化されたことは区別される。一般国民の家族法の改正と、1924年以降の華族の家門自治権（華族家法）への介入は別の問題である。男女の相続・財産管理の平等化を求めても、女性による爵位・領主権の継承がただちに認められるわけではない。[^p081] 家門自治権は[家門自治権と家門司法権](/institutions/family-autonomy.md)を参照。

## 閣僚構成

閣僚の配分は円滑に決着した。首相を含む15人の内閣とした場合の配分案は、国民進歩党8人（53.3%）、立憲改進党6人（40.0%）、無党派の専門家1人（6.7%）、国民協同党0人である。8対6の配分は両党の議席比72対56にほぼ対応する。[^p081] 元老院出身者は主要閣僚に起用されず、首相・財政・内政・外交などの中枢は主に衆議院出身者が担った。入閣する議員は兼職禁止の規定に従って議員職を離れた。閣僚の数と省庁の編成は未確定である。[^p081]

## 元老院との関係

内閣は元老院に公式の与党会派を持たない。各省の大臣や首相が、有力議員と個別に協議した。たとえば予算案を出す前に、宗交会の有力領主、交友倶楽部の金融関係者、興業会の工業資本家、諸侯協同会の代表者などに説明し、重大な反対が出ないよう調整する。元老院の幹事長を集めて包括的な連立協定を結ぶのではなく、案件ごとに協力者を確保する手法である。[^p081] 宮廷は憲法上の権限を保ったが、会派を調整する恒常的な機構はなかった。[^p078][^p081]

## 1937年度予算

1937年度予算は両院で大きな修正なく成立した。[^p081] 予算交渉の中心は、国防費以外の公共投資・社会保障・女性と家庭の政策・地方財政への配分であった。国防政策については両院に広い合意があり、国民協同党や社会民権党も国防予算そのものを全面的には否定しなかった。[^p081]

| 国防費 | 18.8億円（GDP比4.70%、帝国経常歳入比33.2%） |

## 1937年末の各党の立場

政権の支持基盤は拡大しなかった（ダイス判定：難易度50、出目50・失敗）。これは政権が不安定になったことではなく、当初の協力関係を越える恒常的な協力者を得られなかったことを意味する。[^p081]

| 国民協同党 | 46 | 閣外協力 |
| 社会民権党 | 42 | 野党・社会政策で部分的に協力 |
| 日本労農党 | 40 | 野党 |
| 立憲保守党 | 39 | 野党・国防などで部分的に協力 |
| その他 | 5 | 個別に対応 |

[^p081] 国民進歩党は社会民権党との連立の復活も、立憲保守党の取り込みもできなかった。そのため、国民協同党は政権の外にいながら1937年末まで大きな政策交渉力を保った。[^p081]

[^p081] 政権の支持基盤174議席と1937年末までの存続は確定である。閣外協力協定の具体的な内容、閣僚の数と配分、不承認動議の票数、首班指名の票数は暫定案である。[^p081][^p082]

この世界の議院内閣制は、衆議院の多数派を基礎とする通常の制度とも、貴族院主導の内閣制度とも異なる。元老院が衆議院側の候補を受け入れる法的義務は生じておらず、首相個人の調整能力が政権の安定を大きく左右する。[^p080][^p081]

政権の政策傾向として、国民進歩党は全国的な社会資本整備と財政調整を、立憲改進党は自治を保ったままの行政の近代化を、国民協同党は教育・医療・母子保護の地域格差の是正を重視するとみられる（党綱領としては未確定）。[^p095] 1930年代のその他の政治潮流は[1930年代の政治潮流](/politics/politics-1930s-currents.md)を参照。

# 史実との比較

史実の1936年は二・二六事件の年で、その後は広田弘毅内閣など軍部の影響が強い非政党内閣が続いた。本世界線では統帥権が独立しておらず、軍の政治的影響は議会内のロビー活動の形をとる。[^p001]1936年の政変は、衆議院の政党間交渉と元老院の倶楽部政治による連立の組み替えとして起きた。

# 却下・修正された案

* **1937年度の帝国経常歳出53.6億円・経常剰余3.0億円・資本的支出14.0億円（会話ログ3、P93）**: 艦艇建造費を経常会計に置いた内訳。建艦公債の承認を予算に反映するため艦艇建造費約3.5億円を資本会計へ移し、経常歳出50.1億円・経常剰余6.5億円・資本的支出17.5億円に改めた（作者確定）。[^p093]
* **国民進歩党・立憲改進党・国民協同党の三党連立内閣**: 1936年総選挙の結果を受けた第一の検討案。[^p009] 国民協同党の入閣判定が失敗し（ダイス判定：難易度30、出目23・失敗）、進歩・改進の二党連立と協同党の閣外協力の形になった。[^p080][^p081]
