# 概要

本世界線の女性参政権運動は、1925〜1932年に全国的な政治運動となった。[^n1][^p008] 男子普通選挙運動が繰り返し全国化に失敗していたのに対し、女性参政権運動は大きく成功し、選挙改革の主導権を握った。運動の最大の論拠は、「選挙資格が財産と納税によって決まるのであれば、同等の納税義務を負う女性を排除する理由は何か」という問いであった。制限選挙そのものを否定せずに性別要件を崩せるこの論理によって、まず女性に男性と同等の納税資格による選挙権・被選挙権が認められ（1934年）[^n2]、続いて納税資格そのものが撤廃されて男女普通選挙が成立した（1935年）。[^n2][^p008][^p009]

運動からは独立した有力政党**国民協同党**[^n3]が生まれた。[^n4]女性だけを党員とする政党ではなく、女性の政治参加を出発点に、教育・母子保護・家計の安定など広い生活政策を掲げる階級横断的な政党である。1936年の第十六回総選挙（最初の男女普通選挙）で46議席を得て第三党となった。[^p009] 1936年の政変では入閣しなかったが、国民進歩党・立憲改進党の少数与党内閣と正式な閣外協力協定を結び、女性・家庭関連の政策を政権協定に盛り込ませた。1937年末まで、閣外にありながら政権の存続を左右する重要な交渉力を保った。[^p080][^p081]

# 運動の背景と担い手

## 経済的な背景

1937年の日本では、女性の近代的な非農業部門への就業がほとんど進んでいない。[^n5]企業・官公庁の結婚退職慣行、男性世帯主を前提とした賃金制度、職業教育の男女別進路のもとで、片働き世帯が一般的になっている（→[1937年の就業構造と社会](../economy/labor-society-1937.md)）。[^e096] 都市世帯の家計も、主たる稼得者一人の所得に家族の副収入を組み合わせる形が普通である。[^p092]

このため、女性参政権運動の中心は女性工場労働者ではなく、女性教育者・資産を持つ女性・婦人団体であった。[^n6][^p008] 女性の経済的自立が進んでいなかったからこそ、独立した政治的代表を求める運動が強まった、と解釈される。[^p009]

## 支持基盤

| 社会集団 | 主な要求 |
|---|---|
| 女性教育者・知識人 | 政治的権利の男女平等 |
| 女性資産所有者 | 納税者としての選挙権 |
| 女性実業家 | 経済活動に見合った政治参加 |
| 女性労働者 | 労働条件と社会保障の改善 |
| 婦人団体 | 教育・衛生・児童福祉政策への参加 |
| 華族・領主家の女性 | 慈善・社会事業から政治活動へ |

運動の支持基盤は上表のように整理される。[^n6][^p008]

## 納税者の論理

本世界線では1876年以来、衆議院の選挙資格は納税資格による制限選挙であり、1924年の大幅緩和後もその原則は続いていた（→[衆議院選挙制度の変遷](election-system.md)）。この制度のもとでは、女性の資産所有者・納税者を排除する理由を説明しにくい。女性参政権運動はこの点を突き、制度の全面否定ではなく、制度の論理を一貫させることを求めた。[^p008]

この結果、本世界線の民主化は史実の一般的な段階論とは異なる経路をとった。

| 一般的な段階論 | 本世界線 |
|---|---|
| 男子制限選挙 | 男子制限選挙（1876〜） |
| ↓ 男子普通選挙 | ↓ 男女制限選挙（1934年）[^n2] |
| ↓ 男女普通選挙 | ↓ 男女普通選挙（1935年成立、1936年初実施）[^n2] |

1933年以降は、納税資格の撤廃と性別要件の撤廃が別々の政治問題として扱われた。[^p008]

# 選挙権の獲得（1933〜1936）

1933〜1937年に、女性の参政権は次のように成立した。[^p009]

| 事項 | 結果 |
|---|---|
| 女性に男性と同等の納税資格による選挙権 | 1937年までに実現[^n7] |
| 選挙資格からの納税要件の撤廃 | 1937年までに実現[^n8] |
| 女性の被選挙権 | 実現[^n9] |
| 女性参政権運動から独立した政党の形成 | 実現（国民協同党）[^n4] |

改革は女性納税者への選挙権付与が先行し、それによって納税資格そのものの合理性が改めて問われるという順序をたどった。[^n2][^p009] 1936年の制度では選挙権は満25歳以上、被選挙権は満30歳以上で、性別要件も納税資格もない。有権者は1932年の約850万人から約3,600万人へと約4倍になった（概算）。[^p009]

1937年末の女性の地位は、政治参加では男性と同等の法的選挙資格を持つ一方、経済参加は依然として限定的である。[^p009]

# 国民協同党

## 結党と性格

国民協同党[^n3]は、女性参政権運動を母体に男女普通選挙の成立前後に結成された。運動の全国化と新党結成がともにきわめて大きな成功を収めたため、小規模な婦人参政権政党にとどまらず、1936年総選挙で有力政党の一つとなった。[^n1][^n4][^p009]

| 分野 | 基本政策案 |
|---|---|
| 政治制度 | 男女の政治的・法的平等 |
| 教育 | 女子教育・中等教育の普及 |
| 社会保障 | 母子保護、疾病保険、児童福祉 |
| 経済 | 家計の安定、生活必需品価格の安定 |
| 産業 | 女性の就業機会と労働条件の改善 |
| 地方自治 | 衛生・教育・福祉行政の充実 |
| 国家制度 | 立憲秩序の維持、漸進的改革 |
| 外交・国防 | 党内に複数の立場が存在 |

党の基本政策は上表のとおりである。[^n6][^p009]

組織基盤は婦人団体と生活協同組織で、女性労働者だけでなく、農家の女性、家庭を持つ女性、教育者、女性資産家、慈善団体を組織した。女性票が必ずしもこの党に集中したわけではない。[^p009]

## 社会民権党との違い

| 項目 | 社会民権党 | 国民協同党 |
|---|---|---|
| 組織基盤 | 労働組合 | 婦人団体・生活協同組織 |
| 社会政策 | 労働者の権利 | 家庭・児童・生活保障 |
| 所得再分配 | 賃金・社会保険 | 家計・教育・福祉 |
| 政治的背景 | 民権運動・労働運動 | 女性参政権運動 |
| 階級的性格 | 労働者中心 | 階級横断的 |

両党の違いは上表のように整理される。[^n6][^p009] 1937年の領国間の行政サービス格差については、国民協同党は教育・医療・母子保護の地域格差の是正を求めるとみられる。[^n10][^p095]

## 1936年総選挙

1936年の第十六回総選挙で、国民協同党は46議席（定数300の15.3%）を得た。国民進歩党72、立憲改進党56に次ぐ第三党である。同じ選挙で躍進した日本労農党（40議席）と合わせ、新興の二党が86議席を占めた（→[政党の系譜と衆議院の議席推移](political-parties.md)）。[^p009]

# 1936年の政変と閣外協力

## 入閣の見送り

1936年の改選後、国民進歩党・社会民権党の連立は解消した。当初は国民進歩党・立憲改進党・国民協同党の三党連立内閣（174議席）が構想されたが、国民協同党の入閣は実現しなかった。[^n11][^p009][^p080] 政権は進歩・改進の少数与党内閣（128議席）となった（→[1936年の政変と進歩・改進連立内閣](cabinet-1936.md)）。

本世界線の憲法は衆議院の積極的な信任を要求せず、棄権は欠席として扱われる。そのため国民協同党の投票行動が内閣の成否を決めた。新内閣は最初の不承認動議を乗り切った。[^n12] 採決では協同党46人が全員棄権し、協同党以外の野党126人が賛成、与党128人が反対して、投票者254人・可決必要127票に1票届かず否決された。[^n13][^p080]

入閣を見送った時点の協同党の対応は次のとおりである。[^n6][^p080]

| 項目 | 国民協同党の対応 |
|---|---|
| 入閣 | しない |
| 首相候補 | 条件付き容認 |
| 不承認動議 | 棄権または反対 |
| 社会保障政策 | 案件ごとに協力 |
| 女性の権利・教育政策 | 独自の要求を提示 |
| 予算案 | 個別に交渉 |
| 内閣不信任 | 政策対応によって判断 |

## 三党協定

続いて、協同党と政権の関係が正式なものとなった。[^p081]

| 事項 | 結果 |
|---|---|
| 国民協同党との正式な閣外協力協定 | 成立[^n14] |
| 協同党の要求による女性・家庭関連政策の政権協定への盛り込み | 実現[^n15] |
| 内閣の存続期間中の衆議院の政権支持基盤の拡大 | 実現せず[^n16] |

閣外協力によって政権の衆議院支持基盤は174議席（58.0%）となり、予算や内閣の存続に関わる採決では過半数を確保できた。ただし協同党は政府提出法案のすべてに賛成する義務を負わない。[^p081] この協定は「1936年進歩・改進・協同三党協定」[^n17]と呼ばれ、内容は次のとおりである。[^n6][^p081]

| 政策分野 | 協定内容案 |
|---|---|
| 内閣の存続 | 原則として不承認・不信任動議に協力しない |
| 予算 | 合意された政策を実施する予算に賛成する |
| 女子教育 | 中等教育・職業教育・高等教育への進学機会の拡大 |
| 女性の就業 | 就業機会の拡大と不合理な就業制限の見直し |
| 母子保護 | 妊産婦医療・乳幼児保健の拡充 |
| 労働保護 | 産前産後の休業制度と女性労働者の保護 |
| 家族法 | 婚姻・離婚・相続・財産管理制度の調査と見直し |
| 社会保障 | 遺族・母子世帯への給付制度の整備 |
| 行政参加 | 女性の公職・行政機関への参加機会の拡大 |

協定に盛り込まれたことと、1937年末までにすべてが法制化されたことは区別される。[^p081] 1937年度予算は両院で大きな修正なく成立し[^n18]、予算交渉の中心は国防費以外の公共投資・社会保障・女性家庭政策・地方財政配分であった。[^n6][^p081] 労働保護・母子保護の制度的背景は[労働保護法制・社会保険と労使政協議](labor-social-policy.md)を参照。

政権の支持基盤はそれ以上広がらなかったため、国民協同党は閣外にありながら1937年末まで重要な政策交渉力を保った。[^n6][^p081]

# 華族制度との緊張

衆議院での男女平等が実現した一方、華族制度の内部では女性の権利は制限されたままである。

* **爵位・領主権の継承**: 華族家の相続制度では、女性当主による爵位の継承も、領主権の継承も認められなかった。[^n19]養子や非血縁者による家督継承は認められるため、華族家は血統よりも法的な家門の存続を重んじる制度になっている。ただし、女性が爵位を継げないことと、家産を相続できないことは別の問題として扱われる。[^p035]
* **家法と家門自治権**: 1924年以降、華族の家門は家法によって家督・家門構成員・婚姻・養子・懲戒などを自ら定める（→[家門自治権と家門司法権](../institutions/family-autonomy.md)）。男女の政治的平等が成立した1930年代には、家法による家門構成員の権利制限が政治的な争点になりうる。[^n6][^p027]
* **家族法改正との区別**: 三党協定の家族法見直しは一般国民の家族法を対象とし、華族の家法への介入は別問題である。国民協同党が男女の相続・財産管理の平等化を求めても、女性による爵位・領主権の継承がただちに認められるわけではない。[^p081]

この対照から、華族制度の改革が国民協同党にとって新たな政治課題になる可能性が指摘されている。[^p035]

# 史実との比較

* 史実の日本では、1924年に婦人参政権獲得期成同盟会（翌年、婦選獲得同盟）が結成され、1930〜31年には婦人公民権案（地方参政権）が衆議院を通過したが貴族院で否決された。国政の女性参政権は1945年12月の選挙法改正で実現し、1946年4月の総選挙で女性議員39人が当選した。本世界線ではおよそ10年早く、しかも男子普通選挙と同時に女性参政権が実現する。
* 史実の英国では、財産資格を持つ女性納税者が19世紀後半から地方選挙権を得ており、1918年に30歳以上の女性に国政選挙権、1928年に男女平等の選挙権が認められた。納税者の論理から男女制限選挙を経る本世界線の経路は、これに近い。
* 女性参政権運動から独立した有力政党が生まれ、議会で第三党となった例は史実の主要国にはほとんどない。
