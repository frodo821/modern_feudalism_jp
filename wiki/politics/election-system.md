# 概要

本世界線の[衆議院](../institutions/house-of-representatives.md)選挙は、1876年の第一回総選挙で始まった。任期は4年で、任期途中の解散はないため、総選挙は4年ごとに定期的に行われる。[^p002] 当初の制度は、一定額以上の直接税を納める男子だけが投票できる制限選挙で、投票は記名式であった。[^n1][^p003]

この選挙制度は約60年のあいだ制限選挙のまま続いた。特徴は二つある。第一に、[元老院](../institutions/genroin.md)の互選に由来する「投票は公的な責任であり、誰に投票したかを明らかにすることは政治的誠実さの証明である」という思想が衆議院選挙に持ち込まれ、公開の記名投票が長く維持された。[^n2][^p006] 第二に、普通選挙運動は何度も全国化に失敗し、選挙権の拡大は既成政党による納税資格の緩和として進んだ。[^p006][^p007]

選挙制度の転換は1920年代後半から起きた。1926〜1927年に秘密投票が導入され、1928年の第十四回総選挙が最初の秘密投票による総選挙となった。[^p008] その後、女性参政権運動の全国化[^n3]を背景に、まず女性に男性と同等の納税資格による選挙権・被選挙権が認められ（1934年[^n4]）、続いて納税資格そのものが撤廃されて男女普通選挙となった（1935年[^n4]）。1936年の第十六回総選挙が最初の男女普通選挙である。本世界線の民主化は、**男子普通選挙を経ずに、男子制限選挙→男女制限選挙→男女普通選挙**という経路をとった。[^p009]

# 初期の制度（1876年）

第一回総選挙は1876年に行われた。[^p002] 当初の制度の内容は次のとおりである。[^n5][^p003]

| 項目 | 内容 |
|---|---|
| 議員定数 | 300人[^n6] |
| 選挙区 | 律令国・郡を基礎とする人口比例選挙区 |
| 選挙方式 | 小選挙区と複数人区の混合 |
| 選挙権 | 満25歳以上の男子で、一定額以上の直接税を納める者 |
| 被選挙権 | 満30歳以上 |
| 投票方式 | 記名投票 |
| 選挙管理 | 帝国政府 |
| 任期 | 4年（解散なし） |

納税要件に帝国税だけを算入するか、領国税も算入するかは大きな問題であった。帝国税だけなら領国ごとの財政制度によって政治参加の機会に差が生じ、領国税も算入するなら領主の税制変更が有権者数を左右する。選挙資格の全国統一は初期議会の争点となった。[^n7][^p003]

選挙区画と選挙管理を帝国政府が担ったことで、領主による選挙干渉は早くから排除された。1876〜1888年には初期衆議院選挙の独立性が確保され、領主による恒常的な選挙支配は防がれた。[^n8][^p004]

# 制限選挙の長期維持（1876〜1916）

選挙資格の緩和は、19世紀から1916年まで三度試みられ、いずれも実現しなかった。[^p004][^p005][^p006]

| 事項 | 結果 |
|---|---|
| 1888年までに選挙資格の緩和 | 実現しなかった[^n9] |
| 1900年までに選挙資格の緩和 | 実現しなかった[^n10] |
| 1916年までに納税資格の緩和 | 実現しなかった（制限選挙が強固に維持）[^n11] |
| 1916年までに男子普選運動が全国的社会運動となる | 実現しなかった[^n12] |

## 記名投票の思想

1916年までに秘密投票が確立しなかった理由は、元老院の互選制度の発想がそのまま衆議院選挙に持ち込まれたことにあるとされる。[^p006] 元老院の互選では、投票者は一定の社会的地位と公的責任を負う政治主体として扱われる。そこから次のような投票観が生まれた。

* 選挙権は私的な権利であると同時に、公的な職責である。
* 投票者は自らの政治的判断に責任を負う。
* 誰に投票したかを明らかにすることは、政治的誠実さの証明である。
* 秘密投票は、政治的責任の所在をあいまいにする。

1900年代には、都市化と労働運動の発展にともない、雇用主や取引先の圧力から有権者を守るために秘密投票を求める運動が起きた。しかし改革案は否決され、むしろ**公開投票を立憲政治の原則とする思想が強化された**。[^p006]

1916年時点の制度は次のとおりである。[^n13][^p006]

| 項目 | 1916年の制度 |
|---|---|
| 投票方式 | 記名投票 |
| 本人確認 | 必須 |
| 投票記録 | 選挙管理機関が保存 |
| 投票内容 | 原則として公開 |
| 投票の強制・脅迫 | 違法 |
| 選挙資格 | 納税資格による制限選挙 |
| 秘密投票 | 改革案が否決され、導入されず |

選挙の独立性は確保されていたので、記名投票だからといって領主が有権者の投票先を恒常的に支配していたわけではない。本世界線の衆議院選挙では、**領主からの選挙干渉を排除する制度と、投票行為を公開する制度が併存していた**。問題になるのは、むしろ雇用主・地主・金融業者・取引先による社会経済的な圧力である。制限選挙のもとでは有権者の多くが経済的に自立していたため公開投票は維持しやすかったが、選挙権の拡大とともにこの矛盾が表面化していく。[^p006]

1916年までの政党政治は、制限選挙のもとで地方名望家に依拠する「名望家立憲政治」であった（→[政党の系譜と衆議院の議席推移](political-parties.md)）。[^p006]

# 納税資格の大幅緩和と公開投票論争（1917〜1924）

1917〜1924年には、選挙権の拡大が普通選挙運動ではなく既成政党の主導で進んだ。[^p007]

| 事項 | 結果 |
|---|---|
| 男子普選運動が全国的な大衆運動に発展する | 実現しなかった[^n14] |
| 1924年までに納税資格の大幅緩和 | 実現した[^n15] |
| 1924年までに男子普通選挙 | 実現しなかった[^n16] |
| 公開投票制度をめぐる改革運動が全国的な政治争点となる | 実現した[^n17] |

この経過は普通選挙への過渡期というより、**制限選挙制度そのものの再構築**と解釈される。既成政党が自党の支持基盤を広げるため、地租中心の直接税に加えて所得税・営業税などの納税者にも選挙権を認めた。[^n13] 新たに選挙権を得たのは中小商工業者、俸給生活者、自作農、熟練工、比較的高所得の労働者である。低所得労働者、小作農の一部、失業者、女性はなお選挙権を持たなかった。中間層の相当部分が有権者となったことで、普選運動は一時勢いを失った。[^p007]

選挙権が俸給生活者や労働者に広がると、「有権者は経済的に独立した責任ある臣民である」という公開投票の前提が崩れ、投票の秘密が全国的な争点となった。[^p007]

| 公開投票維持派 | 秘密投票導入派 |
|---|---|
| 投票は公的責任を伴う行為 | 選挙権の自由な行使が優先される |
| 投票内容の公開は政治的誠実性を示す | 公開によって経済的圧力が生じる |
| 記名投票は不正票の検証を容易にする | 本人確認と投票内容の秘密は両立できる |
| 元老院互選以来の制度的伝統 | 元老院互選と一般国民の選挙は性質が異なる |

1924年の第十三回総選挙は、なお公開投票で行われた。この論争の中で、「元老院互選は公的身分を有する者による責任ある選任行為であり、衆議院選挙は臣民個人による政治的権利の行使である」という**両院選挙制度分離論**が生まれ、のちの秘密投票導入の根拠となった。[^n13][^p007]

# 秘密投票の導入（1925〜1932）

1925〜1932年には、男子普通選挙は僅差で実現せず、秘密投票は成立した。[^p008]

| 事項 | 結果 |
|---|---|
| 1932年までに男子普通選挙 | 実現しなかった[^n18] |
| 1932年までに衆議院選挙の秘密投票 | 実現した[^n19] |
| 女性参政権運動が全国的な政治運動となる | 実現した[^n3] |

男子普選が僅差で実現しなかったのは、衆議院では普選案が支持されたものの、元老院で財産資格の完全撤廃について合意が成らなかったためである。[^n13][^p008]

秘密投票の改革は1926〜1927年に行われ、1928年の第十四回総選挙が最初の秘密投票による総選挙となった。[^n20][^p008]

| 項目 | 改革前 | 改革後 |
|---|---|---|
| 投票者の本人確認 | あり | あり |
| 投票用紙 | 記名式 | 無記名式 |
| 投票内容 | 公開 | 非公開 |
| 選挙資格 | 納税資格 | 納税資格を維持 |
| 元老院互選 | 記名投票 | 記名投票を維持 |
| 衆議院選挙の理念 | 公的責任としての投票 | 個人の政治的権利としての投票 |

この改革で初めて、元老院の互選と衆議院の選挙が、異なる憲法的理念にもとづく制度として明確に区別された。[^p008]

# 男女普通選挙の成立（1933〜1936）

1933〜1937年には、女性の選挙権と納税資格の撤廃がそれぞれ別個の改革として成立した。[^p009]

| 事項 | 結果 |
|---|---|
| 1937年までに女性に男性と同等の納税資格による選挙権 | 実現した[^n21] |
| 1937年までに選挙資格から納税要件を撤廃 | 実現した[^n22] |
| 女性の被選挙権 | 実現した[^n23] |

経緯としては、女性納税者への選挙権付与が先行し、それによって納税資格そのものの合理性が改めて問われた、と整理される。女性参政権運動の論拠「選挙資格が財産と納税で決まるなら、同等の納税義務を負う女性を排除する理由は何か」は、制限選挙を前提にしながら性別要件を崩す論理であり、それが通ると今度は納税要件が問われた（→[女性参政権運動と国民協同党](womens-suffrage.md)）。[^p008][^p009]

| 年 | 制度 |
|---|---|
| 1876年 | 男子制限選挙（納税資格・記名投票） |
| 1924年 | 納税資格の大幅緩和 |
| 1926〜1927年 | 秘密投票の導入（衆議院のみ） |
| 1928年 | 最初の秘密投票による総選挙 |
| 1934年[^n4] | 男女制限選挙（女性の選挙権・被選挙権） |
| 1935年[^n4] | 男女普通選挙（納税資格撤廃） |
| 1936年 | 最初の男女普通選挙による総選挙 |

二つの改革がいずれも1936年総選挙より前に成立したことで、同年の政党勢力の変化は一体的に説明される。[^p009]

## 1936年の選挙制度

| 項目 | 内容 |
|---|---|
| 選挙権年齢 | 満25歳以上 |
| 被選挙権年齢 | 満30歳以上 |
| 性別要件 | なし |
| 納税資格 | なし |
| 投票方式 | 無記名の秘密投票 |
| 任期 | 4年、任期途中の解散なし |
| 選挙区 | 律令国・郡を基礎とする人口比例 |
| 元老院互選 | 従前の制度（顕名投票）を維持 |

年齢要件・選挙区は従前の制度を維持した。[^n24][^p009] 1937年末の選挙制度は「男女普通選挙・華族顕名互選」とまとめられる。[^p081]

# 有権者数の推移

有権者数の推移は次のとおりである。[^n25][^p007][^p009]

| 年 | 有権者数 | 総人口比 | 制度 |
|---:|---:|---:|---|
| 1876 | 65万人 | 1.8% | 男子制限選挙 |
| 1892 | 90万人 | 2.2% | 同上 |
| 1904 | 120万人 | 2.5% | 同上 |
| 1916 | 160万人 | 2.9% | 同上 |
| 1920 | 210万人 | 3.6% | 同上 |
| 1924 | 650万人 | 10.5% | 納税資格の大幅緩和 |
| 1932 | 850万人 | ― | 同上（1928年から秘密投票） |
| 1936 | 3,600万人 | ― | 男女普通選挙 |

1924年の有権者は1916年の約4倍、1936年は1932年の約4倍になった。1936年の有権者数は、総人口7,800万人から3,500万〜3,800万人程度と見積もられる。有権者が一挙に4倍になったため従来の選挙結果はほとんど参考にならず、地方組織の形成に何度も失敗していた立憲保守党は大きな打撃を受けた。[^p009]

# 元老院互選との対比

元老院の領主互選・無領華族互選は、衆議院の秘密投票導入後も記名（顕名）投票のままである。[^p008] 互選は全国一括の選挙区で、顕名の単記投票により行われ、自分への投票は禁止される。同数得票者は決選投票で決め、得票者が定数に満たないときは補充投票を行う。[^p020] 互選制度と定数の詳細は[元老院の構成と互選制度](../institutions/genroin-composition.md)を参照。

| 項目 | 衆議院選挙（1936年） | 元老院互選 |
|---|---|---|
| 選挙人 | 満25歳以上の男女 | 領主家当主／無領華族 |
| 投票方式 | 無記名の秘密投票 | 顕名・単記 |
| 投票の理念 | 個人の政治的権利 | 公的身分による責任ある選任行為 |
| 選挙区 | 律令国・郡を基礎とする人口比例 | 全国一括 |
| 任期 | 4年 | 6年（勅選議員は終身） |

衆議院が男女普通選挙に移ったことで、元老院の代表性が新たな政治問題となりうる。[^p009]

# 史実との比較

* 史実の衆議院は1890年に開設され、直接国税15円以上を納める満25歳以上の男子（人口の約1.1%）に選挙権が与えられた。投票は記名・押印による公開投票であったが、1900年の改正で秘密投票（無記名）となった。本世界線では元老院互選の思想が持ち込まれたため、秘密投票の導入は約四半世紀遅い。
* 史実では1925年に男子普通選挙が成立し（1928年初実施）、同年に治安維持法が制定された。女性参政権は1945年まで認められなかった。本世界線では男子普通選挙を経ずに、1930年代半ばに一挙に男女普通選挙へ移る。
* 史実の英国では1918年に男子普通選挙と30歳以上の女性の制限的な選挙権が導入され、1928年に男女平等の普通選挙となった。女性の納税・財産資格を足がかりにした本世界線の経路は、英国の地方選挙における女性納税者の選挙権に近い論理をとる。
