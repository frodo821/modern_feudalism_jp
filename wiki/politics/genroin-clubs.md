# 概要

**衆議院は政党政治、元老院は倶楽部政治**である。普通選挙で選ばれる衆議院では綱領・党組織・党議拘束を持つ政党が発達した。一方、華族の互選と勅選で構成される[元老院](../institutions/genroin.md)では、家門間の関係、地域的な人脈、共同出資、個人的な親交を基礎とする**議員倶楽部**が発達した。元老院の会派は、地域的な寄り合い所帯や個人の結びつきに基づくクラブとしての性格を持つ。[^p079]

元老院の会派は、1867年の創設時から互選での相互推薦と票の調整を行う領主連合として生まれた。[^p019] 20世紀に入ると、中小領主の共同金融組織や実業家華族の会派が加わり、出自を越えた政策会派へと発展した。[^p023][^p026] 1936年の第12回改選（総定数310）の結果、宗交会・交友倶楽部・興業会・諸侯協同会・六合会・同文会・北辰会[^n1]と無所属の8勢力が並立した。最大会派でも63議席（20.3%）にとどまり、首班指名には最低三会派の協力が必要になった。[^p078][^p079] この状態は「**経済的な寡頭制と政治的な多極化の同時成立**」と要約される。[^p078]

互選の規則と定数は[元老院の構成と互選制度](../institutions/genroin-composition.md)を参照。

# 会派の形成史

## 互選が生んだ領主連合（1867〜1880年代）

元老院の互選は全国一括の顕名単記投票である。誰が誰に投票したかが公開されるため、投票そのものが家同士の関係の表明になる。[^p019] 会派の基盤には、次の関係がある。[^n2][^p020]

* 一門関係（本家・分家・同族）
* [寄親・寄子](../concepts/yorioya-yoriko.md)の関係
* 婚姻（領主家同士、領主家と公家）
* 地域（隣接する領国）
* 政策（産業振興・外交・国防・領国自治）
* 経済（共同出資・金融・交通事業）

票を調整できる大領主が会派の中心になりやすい。一方、無領華族の互選では、摂関家・清華家などの高爵位家が家格と朝廷の人脈で影響力を持ち、数の多い羽林・名家・半家系の子爵・男爵は独自の推薦組織をつくりうる。旧公家の家格秩序と一人一票の原則との間には緊張がある。[^n2][^p020] 元老院の内部では、1876年の衆議院開設より前から選挙運動・推薦組織・政策協定・会派が発達していた。[^p011]

1880年代には、領国自治と伝統秩序を重んじる保守系会派と、産業振興と制度整備を進める改革系会派が並び、それぞれ衆議院の立憲保守党・立憲改進党[^n1]と連携した。[^n2][^p004] 両院の会派と政党の関係は[政党の系譜と衆議院の議席推移](political-parties.md)を参照。

## 金融圏と互選（1870年代〜1920年代）

大領主による中小領主への金融支援が恒常的な制度となり、大領主を中心とする**領主金融圏**が成立した。金融圏は、元老院の互選での票と結びついた。[^p023] 詳細は[領主金融圏と諸侯共済会](../economy/lord-financial-spheres.md)を参照。

| 事項 | 結果 |
|---|---|
| 金融支援を受けた中小領主が元老院互選で寄親と恒常的に協力する | 実現した[^n3] |
| 中小領主が寄親の政治的意向から一定の独立性を維持する | 実現しなかった[^n4] |
| 旧幕府時代の一門・譜代関係を越えた新しい領主連合が形成される | 実現した[^n5] |
| 複数の大領主金融圏の間で中小領主の獲得競争が発生する | 実現しなかった[^n6] |
| 大領主から独立した中小領主による共同金融組織が成立する | 実現した[^n7] |

[^p023] こうして寄親・寄子の関係は長期に固定化し、互選の票の流れも固定化した。大領主金融圏とは別に、中小領主が共同出資と相互保証で結びつく水平的な連合、**諸侯共済会**[^n1]が生まれた。諸侯共済会は1910年代に領主互選で独自の会派を形成した。[^n2][^p023]

1917年頃の元老院は、領国自治派・産業開発派・立憲改革派・勅選議員の諸会派からなっていた。[^n2][^p006] 北海道で独立授封された24家の分家は資金を本家に頼るため、本家の政治的影響下に置かれやすい。北海道進出に積極的な大領主は、元老院内でも勢力を広げた。[^n2][^p034]

## 出自横断の政策会派へ（1920〜1930年代）

功績叙爵による実業家・学者の華族の増加と、二度の議席配分改革を経て、元老院の会派は身分別の代表から政策別の会派へ移った。[^p026]

| 事項 | 結果 |
|---|---|
| 旧公家と実業家華族の間で婚姻・経済的連携が広く発達する | 実現した[^n8] |
| 実業家華族が独自の恒常的な元老院会派を形成する | 実現した[^n9] |
| 学術・教育系華族が独自の政治会派を形成する | 実現した[^n10] |
| 領主権奉還家が無領華族互選において独自の会派を形成する | 実現しなかった[^n11] |
| 旧公家・新華族・旧領主が出自を越えた政策会派を形成する | 実現した[^n12] |

[^p026] 奉還した旧領主家は集団としての結束を失い、旧公家系・実業家系・社会改革派・旧寄親系の会派などに分散した。領主時代に寄親と債務関係のあった家は、奉還後も旧寄親の影響下に残ったとみられる。[^p026]

1930年代の会派は、次の6つの類型に整理される。[^n2][^p026]

| 類型 | 主な構成 |
|---|---|
| 大領主系会派 | 大領主とその金融圏、協力する実業家 |
| 中小領主系会派 | 諸侯共済会、独立志向の中小領主 |
| 商工業系会派 | 独立系の実業家華族、産業振興派の領主 |
| 学術教育系会派 | 学者・教育者・医師、専門職系の勅選議員 |
| 宮廷系会派 | 旧公家、宮廷関係者、一部の勅選議員 |
| 立憲改革系会派 | 出自を問わず憲政・行政改革を重視する議員 |

選出区分（領主互選・無領華族互選・勅選）と政治会派は別のものである。領主議員が過半数を占めても一枚岩ではない。[^p026]

## 大領主家の政治的性格

領主家ごとの経済史は、元老院での立場にも影響した（各家の経済史は[領主家の経済史と家産](../economy/lord-houses-economy.md)を参照）。[^n13]

* **伊達家**: 東北の中小領主を、金融だけでなく農産物の販路でも結びつけ、東北の政治的盟主となった。1936年の改選で伊達系の会派は前田系・島津系に対して相対的に影響力を増したとみられる。[^p041]
* **細川家**: 銀行主導の企業集団を持ち、領主権維持に加えて産業への長期資金・公共投資・電力開発を重視する政策会派へと発展した。[^p042]
* **鍋島家**: 技術と製造業では全国的な地位を持つが、領主金融圏の形成に大きくつまずいたため[^n14]、元老院で自家以外の議員を組織的に送り込む力が乏しい。実業家華族・学術系華族・勅選議員との政策的な連携で補い、1924年の華族特権拡張には好意的であった。[^p044]
* **尾張徳川家**: 元老院では尾張系の小会派をつくりつつ、首班指名や重要議案では徳川宗家系と協力する。[^p045]
* **紀伊徳川家**: 宗家から独立した資源・電力資本で、元老院でも宗家とは別の政治連合に属する。[^p046]
* **那珂川家**: 寄親圏を持たず、協力する領主・実業家華族・学術系華族・勅選議員と政策的に結ぶ小規模な会派を持つ。独自会派の形成は際どいところで成功し[^n15]、各会派の間の調整に関わる集団となった。[^p047]

徳川宗家の純資産約90億円の家も純資産53万円の小領主も、互選では同じ一票である。この一票の平等が、中小領主への信用供与や共同の資産運用に政治的な重みを与えている。[^p069]

# 1936年元老院選挙

## 前提

1936年は元老院の第12回改選と衆議院の第16回総選挙が重なった両院同時改選の年である。第二次元老院改革によって総定数は310（領主互選160・無領華族互選110・勅選40）となった。選挙人は領主華族251家、無領華族512家であった。[^p077] 領主互選は全国一区・顕名・単記・自家への投票禁止で、同票なら決選投票、得票者が定数に満たなければ補充投票を行う。[^p077]

1936年の領主251家は、17の金融圏・連合・独立層に分かれていた。[^n16][^p077][^p078] 大領主系の金融圏は14勢力である。単一の大領主が領主階級全体を握っているわけではない。[^p077]

## 選挙協力・会派形成の状況

| 事項 | 結果 |
|---|---|
| 領主金融圏内で組織的な候補者推薦・票の配分が普及する | 実現しなかった[^n17] |
| 大領主系金融圏同士で選挙協力が広く成立する | 実現した[^n18] |
| 諸侯共済会が独自の候補者推薦組織を形成する | 実現した[^n5] |
| 諸侯共済会系領主が統一的な政治会派を形成する | 実現した[^n19] |
| 金融圏に依存する領主が投票・立法活動で独自性を維持する | 実現しなかった[^n20] |
| 領主と無領華族を横断する産業・経済政策会派が発達する | 実現した[^n9] |
| 1936年までに恒常的な全国規模の元老院会派が形成される | 実現した[^n21] |
| 宮廷・勅選議員を中心とする会派間調整機構が成立する | 実現しなかった[^n22] |
| 首班指名に際して複数会派による連立交渉が常態化する | 実現した[^n23] |
| 単一会派による元老院過半数の獲得を回避する | 実現した[^n24] |

[^p078] 産業・経済政策会派の項目は、その存在ではなく1936年までの発展の規模を指す。[^p077]

その帰結は次のとおりである。[^p078]

* 大領主系の金融圏は、融資・債務保証・家門関係による政治的拘束力が強い。ただし推薦は大領主による個別の推薦で、票の配分は非公式にとどまる。金融圏を越えた推薦協定は広く成立した。徳川宗家の推薦候補に票が過剰に集まり、推薦されなかった寄子が落選するようなことも起きる。
* 諸侯共済会は組織的な推薦と比較的計画的な票配分を行い、当選後も統一会派として行動した。
* 宮廷による恒常的な会派調整機構は成立しなかった。勅選40人が一体となって政権形成を主導することはない。

# 倶楽部政治

## 政党と倶楽部の比較

| 項目 | 衆議院の政党 | 元老院の倶楽部 |
|---|---|---|
| 結合の基礎 | 思想・政策・支持階層 | 地域・家門・職業・個人的人脈 |
| 候補者 | 全国的に擁立 | 個人的推薦・相互推薦 |
| 綱領 | 明文の綱領 | 簡単な会則・趣意書 |
| 党議拘束 | 比較的強い | 原則として弱い |
| 組織 | 党首・執行部・地方支部 | 幹事・世話人・会員総会 |
| 資金 | 党費・献金・支持団体 | 会費・有力会員の負担 |
| 連携 | 政党間の連立協定 | 有力議員間の合意・会派間の協議 |
| 離脱 | 影響が大きい | 比較的自由 |

[^p079] 倶楽部としての拘束は弱いが、金融圏を通じた個人的な信用関係による拘束は強い。[^p079]

## 三層構造

元老院の政治組織は次の三層からなる。[^n2][^p079]

1. **第一層: 領主金融圏・家門関係** - 議会の外の恒常的な人間関係。徳川系・前田系・伊達系・井伊系・諸侯共済会など。選挙での推薦と信用の供与を担う。
2. **第二層: 議員倶楽部** - 議会活動の基本的な所属単位。協議、委員の選任、首班指名、議事運営を担う。
3. **第三層: 横断的な研究会・懇談会** - 産業・金融・国防・農林業・憲法・教育など、政策ごとの集まり。

たとえば南部家は、佐竹家・酒井家と同じ倶楽部に属しつつ、鉄鋼政策では那珂川家・鍋島家と共同の産業研究会に参加する。[^p079]

1936年の改選後、元老院は次の8勢力に分かれた。[^n1][^n25][^p078][^p079]

| 倶楽部 | 領主互選 | 無領華族互選 | 勅選 | 合計 |
|---|---:|---:|---:|---:|
| 宗交会（そうこうかい） | 43 | 12 | 8 | 63 |
| 交友倶楽部 | 26 | 30 | 4 | 60 |

商工業系の交友倶楽部と興業会を合わせると117議席で、うち無領華族互選は59人である。1867年の制度設計で大領主勢力への対抗軸とされた無領華族の枠は、新興の実業家への叙爵と出自横断的な会派の発達によって、1936年には「領主対無領華族」の構図を薄めている。[^p078]

議席数は政策への賛否の分布をそのまま示すものではない。宗交会63人のうち産業振興策を支持する議員が20人程度いても不自然ではない。[^p079]

## 内部運営

倶楽部には、会長（対外的な代表・儀礼）、幹事長（日常の議会活動の調整）、幹事（地域別・人的集団ごとの意見集約）、世話人（会員間の交際・新会員の推薦）、会員総会（重要案件の協議）、常任幹事会（他会派との連絡・委員人事の調整）が置かれる。入会は既存会員の紹介によるのが一般的で、倶楽部によっては複数の推薦を要する。[^p079]

各倶楽部は京都に会館や集会所を持ち、閉会中も研究会・会食・講演・社交行事を開く。重要な交渉は議場よりも、会館や有力領主の邸宅で行われることが多い。[^p079]

| 農業・商業政策 | 地域・職業による |
| 個別の法案 | 低い |
| 個人の信条に関わる問題 | 原則として自由 |

重要案件での倶楽部内の投票一致率は[^n27]、衆議院の主要政党90〜98%に対し、諸侯協同会85〜95%、宗交会75〜90%、北辰会75〜90%、交友倶楽部70〜85%、興業会65〜85%、六合会60〜80%、同文会55〜80%である。同じ寄親に依存する議員が、倶楽部とは別の集団として投票することもある。[^p079]

## 財政政策への関心

元老院の勢力は、出自によって財政への関心が異なる。[^n2][^p094]

| 勢力 | 財政上の関心 |
|---|---|
| 大都市・工業領主 | 租税負担の抑制、産業基盤の整備 |
| 資源・電力領主 | 鉄道・港湾・電力への投資 |
| 農業領主 | 農業振興、財政調整 |
| 北海道領主 | 開拓補助、交通網の整備 |
| 小規模領主 | 拠出金の減免、財政調整、共同事業 |
| 実業家華族 | 公共投資、国債市場、企業金融 |
| 学術・専門職華族 | 教育・研究・医療への支出 |

中小領主を支持基盤とする諸侯協同会にとって、財政調整制度は家門の救済ではなく、領主権に伴う行政責任を果たすための制度である。中小領主は財政支援を求めつつ、行政監督の強化には反対する傾向がある。[^p094] 財政調整制度は[領国の類型・財政と財政調整交付金](../economy/fief-finance-1937.md)を参照。

# 首班指名と倶楽部

首班指名は投票者の半数以上で決まり、棄権は欠席扱いとなる。310人全員が投票すれば155票が必要である。[^p078] 1936年の構成で成立しうる組み合わせは次のとおりである。[^n2][^p078]

| 組み合わせ | 議席 | 指名の可否 |
|---|---:|---|
| 宗交会＋交友倶楽部＋興業会 | 180 | 可 |
| 宗交会＋交友倶楽部＋諸侯協同会 | 166 | 可 |
| 宗交会＋興業会＋諸侯協同会 | 163 | 可 |
| 交友倶楽部＋興業会＋諸侯協同会 | 160 | 可 |
| 宗交会＋交友倶楽部＋六合会 | 155 | 可 |
| 宗交会＋交友倶楽部＋同文会 | 154 | 1票不足 |
| 交友倶楽部＋興業会＋同文会 | 148 | 7票不足 |

最大の二会派を合わせても123議席で、最低三会派が必要である。諸侯協同会の43議席がキャスティングボートとなり、中小領主が政権形成で大きな交渉力を持つ。[^p078]

元老院の首班指名は人物本位である。首相候補には、衆議院政党の党首・元党首、元老院の有力領主、元老院の実業家華族、元官僚・元法曹、超党派的な元議員などがありうる。[^p079] 元老院政治史の中心は「どの会派が政権を取ったか」より、「どの人物が、どの家門・倶楽部・衆議院政党の支持を得て首相になったか」にある。[^p079]

1936年の首班指名では、倶楽部の幹事の間で協議がまとまらなかった。[^n28] それでも、衆議院の政党間協定で一本化された候補が人物本位の投票で初回に指名された。連立側候補は180票を得て、全倶楽部が非全会一致ながら連立側候補に票を投じた。[^n29][^p080] 経過は[1936年の政変と進歩・改進連立内閣](cabinet-1936.md)を参照。

# 編集注：却下・修正された案

* **政策志向の会派名（立憲保守会・商工経済会・産業振興会・諸侯協同会・地方振興会・憲政研究会・北方開発会）**: 1936年の会派構成の第一案。[^p078] 元老院は政党ではなく、地域的な寄り合い所帯や個人の結びつきによるクラブが発達するはずだという作者の方針を受け、「衆議院の政党政治に引き寄せすぎ」として倶楽部名に改められた。議席数は維持された。[^p079]
* **領権会・興業会・立憲会・公正会・尚武会**: 1937年の国内政治を概観した段階で示された身分横断的な政治会派の仮称。[^p009] 会派史の検討を経て8倶楽部に置き換えられた。
* **元老院は大領主とその寄親圏が主導権を争う場、中小領主は依存先の大領主に同調する**（前編）: [^u028] 基本構図は維持される。ただし、中小領主の共同金融組織である諸侯共済会が統一会派（諸侯協同会）となり、どの大領主圏にも属さない第三の勢力として加わった。[^p023][^p078]
