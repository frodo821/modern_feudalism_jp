# 概要

本世界線の[衆議院](../institutions/house-of-representatives.md)は1876年の第一回総選挙で始まり、解散がないため4年ごとの定期総選挙を重ねた。[^p002] 政党は、地方名望家を基盤とする**立憲保守党**と都市商工業者を基盤とする**立憲改進党**の二大名望家政党として1880年代に成立した。1910年代に改進党が分裂して**国民進歩党**が生まれ、労働組合と旧民権派が合流した**社会民権党**が加わって四党体制となる。1920年代後半には社会民権党から革命社会主義派が分離して**日本労農党**が結成され、1936年の初の男女普通選挙では女性参政権運動から生まれた**国民協同党**が躍進した。1937年末の衆議院は、六党を中心とする多党制である。[^n1][^p004][^p006][^p008][^p009]

政党の発達を左右したのは、本世界線に特有の憲法運用だった。首班指名権は[元老院](../institutions/genroin.md)にあり、衆議院は組閣拒否と不信任しか持たない。さらに議員は閣僚を兼ねられない（詳細は[内閣制度と両院関係](../institutions/cabinet-system.md)）。[^p002] このため、政党は議会部門（議員団）と行政部門（入閣のため議員を辞した党員）が分かれた二重指導体制をとる。元老院は政党ではなく倶楽部単位で動く（→[元老院の倶楽部政治と1936年元老院選挙](genroin-clubs.md)）。[^p002][^p079]

本記事の議席数は定数300に対する配分である。[^n2][^p009][^p078][^p079]

## 初期政治集団（1876年）

第一回総選挙の時点では全国的な政党組織はまだなく、当選者は個人の名望と地域の人脈で選ばれた。1874年の民撰議院設立建白を支えた勢力も、衆議院の設置という目的では一致していたが、その後の方針までは一致していなかった。[^n3][^p003]

| 政治集団[^n1] | 主な支持基盤 | 主張 |
|---|---|---|
| 民権派 | 豪農・知識人・旧下級武士 | 臣民の権利、選挙権拡張 |
| 改進派 | 都市商人・実業家・留学経験者 | 法制度統一、産業振興 |
| 保守派 | 地主・地方名望家・領主家関係者 | 領主権維持、漸進改革 |
| 国権派 | 旧武士・海運業者・一部実業家 | 国防強化、対外主権の確立（各派にまたがる潮流とみる案もある） |
| 無所属 | 地域の有力者 | 地域利益の代表 |

初期の議会は固定的な二大政党制ではなく、政策ごとに連携相手が変わる会派政治であった。たとえば領国司法の扱いでは、民権派・商工業者・改革派領主が手を組み、地方自治の擁護では保守的領主と中央集権を警戒する民権派が協力した。[^n3][^p003]

## 名望家二大政党の成立（1876〜1888）

1876〜1888年に、二大名望家政党が成立した。[^p004]

| 事項 | 結果 |
|---|---|
| 初期衆議院選挙の独立性確保（領主の恒常的選挙支配を防ぐ） | 実現した[^n4] |
| 民権派の全国政党組織形成 | 実現しなかった[^n5] |
| 都市商工業者を基盤とする改進派の独立政党形成 | 実現した[^n6] |
| 地方名望家を基盤とする保守派の全国政党形成 | 実現した[^n7] |
| 政党と元老院改革派・保守派会派の恒常的連携 | 実現した[^n8] |

* **立憲改進党**[^n1]: 都市商工業者・銀行家・海運業者・知識人・改革志向の旧武士層が基盤。商法・民法の全国整備、領国間の経済障壁の撤廃、行政合理化、産業振興、教育普及を掲げる。元老院の商工業育成派領主や近代行政を重んじる勅選議員と連携した。当初は普通選挙を支持しない19世紀型の自由主義政党である。[^p004]
* **立憲保守党**[^n1]: 地方名望家・大地主・地方商人・農業関係者・旧上級武士層が基盤。領国自治・既存秩序・財産権・農業振興・漸進改革を掲げる。選挙の独立性が確保されたため領主家の御用政党にはならず、地方住民の利益のために領主政府と対立することもある。元老院の領国自治派領主会派や保守的華族会派と協力した。[^p004]
* **民権派の三分裂**: 全国組織化に失敗した民権派は、立憲自由主義者が改進党へ、地方自治派・農村民権派が保守党や地方組織へ、急進派が独立の政治結社・院外運動へと分かれた。普選運動は既成政党の外から起こることになる。[^p004]

元老院会派と衆議院政党は一致しない。たとえば薩摩系の領主家が元老院で一つの政治圏をつくっていても、その領国の都市商工業者が衆議院で反薩摩系の政党を支持することはありうる。元老院対衆議院の対立と、保守対改革の対立も一致しない。[^n3][^p001][^p003]

## 地方支部組織化の失敗（1889〜1900）

1889〜1900年には、二大政党の全国的な地方支部組織化が完全な失敗に終わり[^n9]、民権派の再結集も実現しなかった。[^n10][^p005] これにより「中央政党による地方政治組織の統合」そのものが失敗した。[^n3] 中央党本部は議員団の調整機関にとどまり、候補者選定は地方政治結社と名望家に、選挙資金は候補者と地方支持者に依存した。一般党員制度はほとんど普及せず、離党・移籍・会派再編が起こりやすかった。領主による選挙支配が復活したわけではなく、領主からも中央政党からも独立した地方名望家層が強まったのである。この組織的弱さは、のちの普通選挙時代に新有権者を組織できない弱点として残る。[^p005]

一方、交通整備・産業振興をめぐる両院横断の開発政治[^n11]と、選挙結果を首班指名に反映する慣行[^n12]が成立し、1900年までに最初の本格的政党内閣が成立した。[^n13] 内閣史の詳細は[内閣の系譜と政党内閣の慣行](party-cabinets.md)に譲る。[^p005]

## 四党体制の成立（1901〜1916）

1901〜1916年には、労働者政党の成立と既成政党の分裂が起きた。[^p006]

| 事項 | 結果 |
|---|---|
| 既成二大政党の地方支部の再建・統合 | 実現しなかった[^n14] |
| 独立労働組合の全国組織化 | 実現した[^n15] |
| 労働者・急進民権派を基盤とする第三の全国政党 | 実現した[^n16] |
| 既成二大政党の一方に重大な分裂 | 実現した[^n17] |
| 1916年までに男子普選運動が全国的社会運動となる | 実現しなかった[^n18] |

* **社会民権党**[^n1]: 旧民権派（地方政治結社・知識人）、労働組合（都市・鉱工業労働者）、小農・小商工業者、社会改革派（法律家・教員・記者）が合流し、1900年代後半〜1910年代前半に結党した。[^n19] 普通選挙・社会立法・労働者保護を掲げる。全国組織を持つが、制限選挙のもとで議席はごく少ない。党員と労働組合を中心とし、党費と組合拠出で運営され、院外活動が強く、選挙権を持たない支持者を多く抱えた。日本で最初の本格的な大衆組織型政党である。[^n3][^p006]
* **国民進歩党**[^n1]: 立憲改進党の分裂から生まれた。[^n20] 工業化と労働保護立法の進展によって、改進党の内部で産業振興と国家の積極的経済介入を求める勢力が、企業活動の自由・財政規律を求める勢力から分かれた。1912年総選挙で64議席として登場する。[^p006]

1916年の四党の性格は次のとおりである。[^n3][^p006]

| 政党 | 政治思想・政策 | 支持基盤 |
|---|---|---|
| 立憲保守党 | 領国自治、農業振興、社会秩序 | 地方名望家、地主、農業団体 |
| 立憲改進党 | 経済自由主義、財政規律、行政改革 | 商業、金融、専門職 |
| 国民進歩党 | 積極財政、産業振興、国防、社会改良 | 工業資本、技術者、開発派 |
| 社会民権党 | 普通選挙、社会立法、労働者保護 | 労働組合、民権派、知識人 |

保守党と進歩党は公共事業で、改進党と社会民権党は政治制度改革で協力しやすい。単純な左右対立ではなく、政策ごとに連合が変わる議会である。[^p006] 1914年の参戦時には超党派の戦時協力内閣が成立した。[^n21][^p006]

## 大衆政党化と五党体制（1917〜1932）

1917〜1924年には、戦後の政党間協調が崩れ[^n22]、競争的な連立政治に移った。それでも両院協調は保たれた。[^n23][^p007] 社会民権党は強固な大衆組織を確立し[^n24]、既成政党も大衆政党への組織改革に成功した。[^n25] 既成政党の改革は、地方の政治結社を解体するのではなく、正式な加盟組織として認め、個人党員制度と組み合わせた連合型組織であった。[^n3][^p007]

| 項目 | 1916年 | 1924年 |
|---|---|---|
| 中央党組織 | 議員団中心 | 議員団と党本部の分化 |
| 地方組織 | 独立した政治結社 | 正式な加盟組織・支部 |
| 一般党員 | 限定的 | 広く募集 |
| 選挙資金 | 候補者個人に依存 | 党費・団体拠出も利用 |
| 政策決定 | 有力議員による協議 | 党大会・政策委員会 |
| 候補者選定 | 地方名望家中心 | 地方組織と中央党の協議 |

ロシア革命の影響で急進社会主義運動が拡大した[^n26]が、広範な弾圧は避けられた。[^n27] 社会民権党の内部には社会民主派（議会政治・社会立法）、労働組合派（団体交渉・労働自治）、革命社会主義派（資本主義と領主制の廃止）の三派が生まれ、1924年までは前二者が主流であった。[^n3][^p007]

戦後処理をめぐる四党の立場は次のとおりである。[^n3][^p007]

| 争点 | 立憲保守党 | 立憲改進党 | 国民進歩党 | 社会民権党 |
|---|---|---|---|---|
| 戦時利得課税 | 限定的に支持 | 慎重 | 財源確保のため支持 | 強く支持 |
| 戦後財政 | 経常収支均衡 | 歳出削減 | 積極的産業投資 | 社会政策優先 |
| 対外債権 | 安全な資産運用 | 民間金融・貿易重視 | 国家戦略に活用 | 収益の社会還元 |
| 労働政策 | 保護主義 | 労使自治 | 産業協調 | 労働者の権利拡大 |
| 選挙改革 | 限定的緩和 | 都市有権者の拡大 | 納税資格の緩和 | 普通選挙 |

1925〜1932年には、既成三党が大衆政党組織の維持に失敗した。[^n28] 1920年代の企業献金と名望家資金で拡大した組織が、[1927年の金融危機](../events/financial-crisis-1927.md)と世界恐慌で維持できなくなったためと解釈される。[^n3] ただし国民進歩党は政権実績で組織の弱さを補った。[^n3][^p008] 社会民権党からは革命社会主義派が分離し[^n29]、**日本労農党**[^n1]が結成された。生産手段の社会化と領主制の廃止を掲げるが、思想取締法の制定が回避されていた[^n30]ため合法政党として活動できた。反領主制運動は拡大しなかった[^n31]ため、当初は小勢力にとどまった。分離によって社会民権党の性格は明確になり、元老院改革派からも連立相手として認められやすくなった。[^p008]

社会民権党は初めて連立内閣に参加した。[^n32] 積極財政派の政権獲得[^n33]と合わせ、1930年の元老院改選直後に**国民進歩党・社会民権党の開発・社会政策連立内閣**が成立し、1932年総選挙で基盤を強めた。[^n34] 両党の共通政策は、世界恐慌に対する財政支出による需要創出である。[^p008]

## 六党多党制へ（1933〜1937）

1933〜1937年には、男女普通選挙（→[衆議院選挙制度の変遷](election-system.md)）のもとで政党が再編された。[^p009]

| 事項 | 結果 |
|---|---|
| 進歩党・社会民権党の連立が1936年改選後も維持される | 実現しなかった[^n35] |
| 立憲保守党が地方組織の再建に成功する | 実現しなかった[^n36] |
| 立憲改進党が新たな支持基盤を獲得する | 実現した[^n37] |
| 社会民権党が労働者以外の中間層に支持を拡大する | 実現しなかった[^n38] |
| 日本労農党が全国的な有力政党へ成長する | 実現した[^n39] |
| 女性参政権運動から独立した政党が形成される | 実現した[^n40] |
| 退役軍人・国防強化派の独立した政治勢力が形成される | 実現しなかった[^n41] |

* **国民協同党**[^n1]: 女性参政権運動から結成された。女性だけの政党ではなく、女性の政治参加を出発点に教育・母子保護・家計の安定など広い生活政策を掲げる階級横断的な政党である。詳細は[女性参政権運動と国民協同党](womens-suffrage.md)を参照。[^p009]
* **日本労農党の躍進**: 経済崩壊による革命運動ではなく、それまで政治参加から排除されていた層が代表を得た結果と説明される。支持基盤は低所得労働者、小作農、零細自営業者、社会保険から外れた非正規・臨時労働者、急進的知識人、一部の若年層である。社会保険の対象拡張が実現しなかった[^n42]ことで、大企業・組織労働者という「制度内労働者」は社会民権党に、未組織労働者・小農という「制度外労働者」は日本労農党に向かう「左派政治の社会的分化」が生じた。[^n3][^p009]
* **立憲改進党**は新しい都市中間層を獲得し、**社会民権党**は労働者中心の政党にとどまった。**立憲保守党**は地方組織の弱さが続き、普通選挙で最も大きな打撃を受けた。[^p009]
* 独立した国防政治勢力は形成されなかったので、権威主義的潮流は独立政党ではなく既存政党の内部に現れた（→[1930年代の政治潮流](politics-1930s-currents.md)）。[^p009]

# 衆議院の議席推移（定数300）

1876年は政党ではなく政治的傾向による分類である。[^n43][^p004][^p005][^p006][^p007][^p008][^p009]

## 1876〜1900年

| 勢力 | 1876 | 1880 | 1884 | 1888 | 1892 | 1896 | 1900 |
|---|---:|---:|---:|---:|---:|---:|---:|
| 保守系・立憲保守党 | 70 | 98 | 120 | 133 | 127 | 124 | 134 |
| 改進系・立憲改進党 | 60 | 92 | 109 | 118 | 128 | 139 | 132 |
| 民権系 | 65 | 42 | 28 | 19 | 15 | 12 | 9 |
| 無所属・その他 | 105 | 68 | 43 | 30 | 30 | 25 | 25 |
| 二大政党の占有率 | 43.3% | 63.3% | 76.3% | 83.7% | 85.0% | 87.7% | 88.7% |

# 1936年の政権再編と1937年末の各党

1936年の改選後、進歩・民権連立は解消した。連立解消の原因は選挙制度改革や国内政策をめぐる対立であり、再軍備をめぐる対立による政権崩壊は回避された。[^n44] 国防費の拡大については両院・主要政党の合意が成立した。[^n45][^p009]

政権形成では衆議院の政党間協定が先行し[^n46]、国民進歩党が中核を維持した。[^n47] 立憲改進党は政権に参加した[^n48]が、国民協同党は参加しなかった。[^n49] その結果、進歩・改進の少数与党連立内閣（衆議院128議席、42.7%）が成立し、国民協同党が正式に閣外協力して[^n50]政権支持基盤は174議席（58.0%）となった。この内閣は1937年末まで存続した。[^n51] 経緯の詳細は[1936年の政変と進歩・改進連立内閣](cabinet-1936.md)を参照。[^p080][^p081]

1937年末の各党の立場は次のとおりである。[^n52][^p081]

| 政党 | 1936年議席 | 1937年末の立場 |
|---|---:|---|
| 国民進歩党 | 72 | 与党（首相を出す） |
| 立憲改進党 | 56 | 与党 |
| 国民協同党 | 46 | 閣外協力 |
| 社会民権党 | 42 | 野党、社会政策で部分協力 |
| 日本労農党 | 40 | 野党 |
| 立憲保守党 | 39 | 野党、国防などで部分協力 |
| その他 | 5 | 個別対応 |

政権の支持基盤は拡大しなかった。[^n53] 国民進歩党は社会民権党との連立を復活させることも、立憲保守党を取り込むこともできず、国民協同党が1937年末まで大きな交渉力を保った。[^n3][^p081]

## 自治と平等をめぐる政策傾向（推定）

1937年の領国間の行政サービス格差（→[領国の類型・財政と財政調整交付金](../economy/fief-finance-1937.md)）について、各党の政策傾向は次のように推定される。これは各党の支持基盤からの推定であり、党綱領そのものではない。[^n54][^p095]

| 政党・勢力 | 想定される政策傾向 |
|---|---|
| 国民進歩党 | 全国的な社会資本整備と財政調整 |
| 立憲改進党 | 自治を維持しながら行政を近代化 |
| 国民協同党 | 教育・医療・母子保護の地域格差是正 |
| 社会民権党 | 全国共通の社会保障・労働者保護 |
| 日本労農党 | 居住地域によらない社会的権利の保障 |
| 立憲保守党 | 領国自治と財政規律の維持 |
| 元老院の中小領主勢力 | 財政支援の拡充と自治権の保全 |

# 政党組織の特徴

* **議会部門と行政部門の分離**: 議員は領主を除いて他の公職と兼任できず、閣僚にもなれないので、首相・閣僚になるには議員を辞めなければならない。政党は党総裁・衆議院議員団長・元老院議員団長・首相と閣僚・幹事長からなる二重指導体制をとり、首相は議決権を持たず与党議員団を直接統率しない。党の役職は公職ではないので、党総裁と首相の兼任は可能である。[^n3][^p002]
* **定足数なし・棄権＝欠席の議決規則**: 少数政党は棄権によって事実上の閣外協力ができる。1936年の不承認動議では国民協同党の棄権が内閣存続を左右した（126対128、棄権46[^n55]）。[^p002][^p080] 定足数を設ける憲法改正は1937年末までに成立した（→[1930年代の政治潮流](politics-1930s-currents.md)）。[^p009]
* **既成政党と新興政党の組織の違い**: 既成三党は議員団・名望家・企業献金に依存し、経済危機に弱い。社会民権党は労働組合と党費、国民協同党は婦人団体と生活協同組織、日本労農党は未組織労働者と小作農に依拠する。[^p006][^p008][^p009]
* **元老院との関係**: 元老院は政党ではなく、家門・地域・個人の人脈に基づく倶楽部で動く。衆議院政党との関係も、政党ごとの系列ではなく、有力議員との個別の協議による。[^p079][^p081]

# 史実との比較

* 史実では1890年に帝国議会が開設され、自由党・立憲改進党の流れから立憲政友会と憲政会（立憲民政党）の二大政党制が生まれ、1918年の原敬内閣が最初の本格的政党内閣とされる。[^p001][^p003] 本世界線では衆議院が14年早く1876年に開設され、首班指名権を元老院が握り、衆議院の解散がないため、政党政治は異なる形をとった。
* 史実の無産政党（社会民衆党・労働農民党など）は、1925年の普通選挙法と治安維持法のもとで分裂を重ね、議席は少なかった。本世界線では社会民権党が1900年代に先行して大衆組織政党となり、日本労農党も1936年に40議席を得る。
* 史実では女性参政権は1945年まで実現せず、女性を基盤とする独立政党は戦前には成立していない。

# 編集注：未決の論点

* 各時期の議席数（1876〜1932年）は暫定配分であり、選挙区別の積算をしていない。[^p009]
* 二大政党のどちらが分裂したかはダイスで決まっておらず、立憲改進党の分裂は仮定である。社会民権党の結党年、国民進歩党の登場年（1912年）も検討案である。[^p006]
* 党首・首相などの人物と、歴代内閣の首班政党は未定である（1936年の首相が国民進歩党出身であることを除く）。[^p080]
* 帝国秩序維持例（仮称）のもとで日本労農党が全面禁止されるか、議員資格が剝奪されるかは1938年以降の問題として残されている。[^p009]
* 正式な党名（すべて仮称）。

# 編集注：却下・修正された案

* **三極の政党体系案**: 会話ログ3の冒頭で示された保守政党・自由商工政党・労働社会政党の三極案は、以後のダイス結果に基づく系譜に置き換えられた。[^p001]
* **1916年時点の暫定政党名**: 「立憲政友会（開発保守）・立憲改進党・立憲保守党・国民党」の四党案は判定前の仮置きで、立憲政友会と国民党の名は以後使われない。[^p003]
* **1936年の三党連立案**: 判定前には国民進歩党・立憲改進党・国民協同党の三党連立内閣が第一案とされたが、国民協同党の政権参加判定が失敗し（出目23）、進歩・改進の二党連立と国民協同党の閣外協力に修正された。[^p009][^p080]
