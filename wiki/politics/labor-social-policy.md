# 概要

本世界線の日本では、政治参加の民主化よりも労働者保護と社会政策が先に進んだ。1916年までに工場法を含む包括的な労働保護法制が成立し（ダイス判定：難易度35、出目96・クリティカル）、独立した労働組合の全国組織も生まれた。[^p006] 衆議院はなお納税資格による制限選挙と公開投票のもとにあったから、1917年の日本は「名望家立憲政治と社会的保護主義が併存する体制」と性格づけられる。[^p006]

その後、1919〜1924年に政府・使用者団体・労働組合の三者協議制度（中央労働協議会、仮称）と疾病保険が成立し、1925〜1932年には老齢保険と失業保険が新設された。労働運動を国家から排除するのでも、国家が労働組合を統制するのでもなく、独立した労働組合を前提に政策決定へ組み込む**社会的協調主義**が、本世界線の労使関係の基調である。[^p007][^p008]

1937年の到達点は、主要工業部門での原則1日8時間労働、恒常的な三者協議、労災・疾病・老齢・失業の各保険である。ただし社会保険の対象を広範な労働者に広げる試みは失敗し（難易度25、出目22）、農業・零細事業への適用は限られる。社会保険の種類は豊富だが適用範囲の格差が大きく、制度から外れた労働者・小農が日本労農党の躍進を支えた。[^p009]

## 支持連合

労働保護立法は、社会主義者や労働運動だけの成果ではない。[元老院](../institutions/genroin.md)の領主層にとって領国の住民は単なる労働力や納税者ではなく、統治と保護の対象であり、領主権の正当性を保つには臣民の生活を守ることが重要であった。こうして、立場の異なる勢力が同じ立法を支持した（検討案）。[^p006]

| 政治勢力 | 労働保護立法を支持する理由 |
|---|---|
| 領主層 | 臣民保護の責務、領国の社会的安定 |
| 立憲保守党 | 家族・地域社会の維持 |
| 立憲改進党の社会改革派 | 労働生産性、健全な産業発展 |
| 帝国官僚 | 公衆衛生、労働力の維持 |
| 軍部 | 国民の健康状態と兵員の質 |
| 労働組合 | 労働条件の改善 |

## 1916年までの労働法制

クリティカルの効果として、単独の工場法にとどまらず、関連する複数の制度が整えられた（各項目の具体値は検討案）。[^p006]

| 分野 | 制度 |
|---|---|
| 成人労働時間 | 原則1日10時間を上限とする |
| 年少労働者 | 年齢制限と労働時間の短縮 |
| 女性労働者 | 深夜労働・危険業務の制限 |
| 休日 | 原則として週1日 |
| 労働災害 | 使用者による補償義務 |
| 工場衛生 | 換気・照明・安全設備の基準 |
| 工場監督 | 公的な工場監督官制度 |
| 労働組合 | 合法的な結社として承認 |
| 労働争議 | 行政による調停制度 |

1916年時点で全国一律の8時間労働制までは導入されていないが、鉱山や重工業など特に危険な業種に限った短時間労働制はありうる。労災補償の制度は、のちの疾病保険へ発展する基盤となった。[^p006]

## 社会民権党と労働組合

全国的な労働組合組織は、それまで二度にわたり全国政党の形成に失敗していた民権派に新しい組織基盤を与えた。旧民権派と労働運動が合流して**社会民権党**（仮称）が結党され、普通選挙・社会立法・労働者保護を掲げた（→[政党の系譜と衆議院の議席推移](political-parties.md)）。制限選挙のもとで議席は少なかったが、労働組合を基盤とする大衆組織型の政党であった。[^p006]

# 戦時協力と戦後の社会政策（1914〜1924）

## 戦時の労使協議

1914年の第一次世界大戦参戦時に超党派的な戦時協力体制が成立した（難易度25、出目95・クリティカル）。社会民権党と労働組合にも、戦時生産への協力と引き換えに、労働条件・賃金・食料供給について政府と協議する機会が与えられた（検討案）。戦時経済の成功が特定政党や軍部だけでなく立憲体制全体の成功と受け止められたことは、のちの労使関係に大きな影響を残した。[^p006] 戦時利得と物価は重大な政治争点となった（難易度15、出目17・成功）が、体制の危機には至らなかった。[^p006]

## 1917〜1924年の判定

| 判定 | 難易度 | 出目 | 結果 |
|---|---:|---:|---|
| 戦時物価上昇・食料問題による大規模な社会騒擾を回避する | 45 | 46 | 成功 |
| 戦時利得に対する追加課税・累進課税が実現する | 40 | 57 | 成功 |
| 労働組合と政府・経済団体の恒常的な協議制度が成立する | 25 | 68 | 成功 |
| 疾病保険など初期社会保険制度が成立する | 30 | 57 | 成功 |
| ロシア革命の影響によって急進的な社会主義運動が拡大する | 45 | 66 | 成功 |
| 政治結社への広範な弾圧を伴わず、急進的政治運動に対処する | 35 | 48 | 成功 |

[^p007]

社会騒擾の回避は際どい成功であった。1918年前後には局地的な食料価格への抗議、労働争議、商店への集団的抗議が起きたが、全国的な暴動や内閣の強制退陣には至らなかった（検討案）。[^p007] 戦時利得への追加課税・累進課税は、所得再分配を意識した税制改革として実現した。[^p007]

## 三者協議制度の成立

1919〜1924年に、次の制度が成立した（機関名は仮称、内容は検討案）。[^p007]

| 制度 | 内容 |
|---|---|
| 中央労働協議会 | 帝国政府・使用者団体・労働組合の代表による協議。賃金・労働条件・保険を扱う |
| 産業別協議会 | 造船・鉄鋼・鉱業・繊維・運輸などの産業別労使協議 |
| 労働争議調停 | 公的機関による調停・任意仲裁 |
| 疾病保険 | 使用者・労働者の拠出を中心とする保険制度 |
| 労災補償 | 既存の使用者補償義務を保険制度へ発展 |
| 領国労働行政 | 帝国法にもとづく領国政府の監督・執行 |

領国政府は、帝国共通の最低基準を上回る独自の社会政策を行うこともできる。[^p007] この体制は、国家が労働組合を統制する国家協調主義とは異なり、独立した労働組合の存在を前提とする社会的協調主義に近い。[^p007]

ロシア革命の影響で急進社会主義運動は広がったが、包括的な思想取締法はつくられなかった。合法的な領主制廃止論・共和主義・社会主義と、武装蜂起・暴力による政府転覆とが区別され、領主権の廃止を主張するだけでは違法とならなかった。[^p007]

# 恐慌下の社会保険拡張（1925〜1932）

## 判定

| 判定 | 難易度 | 出目 | 結果 |
|---|---:|---:|---|
| 主要工業部門で原則8時間労働制が成立する | 30 | 10 | 失敗 |
| 労使政三者協議制度が経済危機下でも維持される | 30 | 36 | 成功 |
| 社会保険制度が老齢・失業等にも拡張される | 40 | 60 | 成功 |
| 社会民権党が初めて連立内閣に参加する | 55 | 69 | 成功 |
| 積極財政派が1932年までに政権の中心勢力となる | 20 | 26 | 成功 |

[^p008]

1930年の元老院改選直後に、国民進歩党と社会民権党を中核とする開発・社会政策連立内閣が成立した（時期は検討案）。共通政策は世界恐慌に対する財政支出による需要創出である。社会保険については、国民進歩党は労働力・産業の安定を、社会民権党は労働者の生活保障を目的とし、労使協議についても前者は生産活動の安定、後者は労働者の政策参加を重んじた。[^p008]

社会民権党が入閣しても、8時間労働制の法制化は失敗した。経済危機のもとでは、労働時間の短縮よりも雇用の維持と失業者の生活保障が優先されたと解釈される。[^p008]

## 1932年の制度

| 分野 | 状況 |
|---|---|
| 法定労働時間 | 原則10時間制を維持（検討案） |
| 8時間労働制 | 全国的な法制化には失敗 |
| 産業別労働協約 | 個別に8時間制を採用する余地あり |
| 疾病保険 | 既存制度を維持 |
| 労災保険 | 制度化済み |
| 老齢保険 | 新設 |
| 失業保険 | 新設 |
| 労使政三者協議 | 経済危機下でも維持 |
| 労働組合 | 独立した合法的組織 |

[^p008]

失業保険は、既存の労働組合が運営していた共済制度を公的制度に組み込む方式もありうる。1937年の失業率が2.4%と低いため、恐慌期に成立した失業保険は1930年代後半には比較的安定した財政に移ったと考えられる（検討案）。[^p008]

## 財政原則との関係

積極財政といっても、[1925年財政原則](../economy/fiscal-principles-1925.md)は維持された。建設公債を財源とする公共投資と、租税・保険料を財源とする経常的な社会保障支出は区別される。[^p008]

## 法定労働時間と実際の労働時間

会話ログ2の社会構造判定では、労働時間の短縮・休日制度の普及がクリティカル（出目98）で、1920年代前半に1日8時間・週48時間制が普及し、1934〜37年には週40〜44時間制が主要産業に広がったとされる（→[1937年の就業構造と社会](../economy/labor-society-1937.md)）。[^e096] 一方、会話ログ3の判定では、8時間制の法制化は1932年まで失敗し、1937年までに主要工業部門で成立した。[^p008][^p009]

両者は、**法定の基準**と**実際の労働慣行**の違いとして整合させる（整合案）。法律上の原則は1916年以来の1日10時間制が長く残ったが、大企業・官公庁では産業別労働協約や企業慣行によって8時間制と週休の拡大が先行し、1930年代半ばに主要工業部門で法定化が追いついた。中小製造業・小売・農林水産業など法定8時間制の外にある部門では、実際の労働時間も長い。週40時間制や有給休暇の日数は、法制度としては確定していない。[^e096][^p008]

## 社会保障の財政

1937年度の社会保障関係の経常支出は次のとおりである（単位：億円）。[^p093]

| 区分 | 帝国政府 | 地方（領国）政府 | 合計 |
|---|---:|---:|---:|
| 社会保障・生活給付（扶助） | 6.5 | 3.9 | 10.4 |
| 恩給・退職給付等 | 1.5 | ― | 1.5 |
| その他民間向け経常移転 | 1.0 | ― | 1.0 |
| 社会保障等の経常移転（計） | 9.0 | 3.9 | 12.9 |

社会保障等の経常移転12.9億円は名目GDP400億円の3.23%にあたる。このほか医療・公衆衛生に帝国2.5億円、地方3.0億円が支出される。[^p093] 詳細は[1937年度の帝国財政と連結政府財政](../economy/public-finance-1937.md)を参照。都市部4人世帯の月間家計72円のうち、租税・社会保険料などは3円（4.2%）である（検討案）。[^p092]

## 社会保障の効果と限界

* **資産格差への効果**: 社会保障制度は低所得者の資産の取り崩しを抑えた（難易度40、出目59・成功）。ただし最低生活と既存資産の保全には役立っても、資産の再分配はしない。1927年以降の金融危機で一般国民の資産格差は拡大した（難易度30、出目75・成功）。[^p085]
* **地域格差**: 領国ごとの行政サービスの差は、財政調整交付金が成立しても大きく残った。社会保障の実効性の暫定指数（全国平均＝100）は、都市工業領国135、資源・電力領国110、農業中心領国80、北海道開拓領国85、小規模領国65である（検討案）。[^p095]
* **適用範囲の格差**: 社会保険の種類は豊富だが、農業・零細事業、非正規・臨時労働者への適用は限られる。就業者3,220万人のうち第一次産業が1,260万人（39.1%）を占めるため、適用外の層は大きい。社会保険の対象者数は積算されていない。[^p009][^p096]

# 政党政治との関係

## 左派政治の分化

社会保険の対象拡張の失敗は、1936年総選挙での左派の分化を生んだ。大企業・工場の組織労働者は労使協議と社会保険を通じて既存制度に組み込まれ、社会民権党を支持した。制度の外にいる低所得労働者、小作農、零細自営業者、非正規・臨時労働者は、土地改革と資本制度の変革を掲げる日本労農党（40議席、ダイス判定：難易度65、出目98・クリティカル）へ向かった（検討案）。[^p009]

| 層 | 状況 | 支持政党 |
|---|---|---|
| 制度内労働者（大企業・工場・組織労働者） | 労使協議・社会保険に包摂 | 社会民権党 |
| 制度外労働者・小農（零細事業・小作・未組織労働） | 社会保険から排除 | 日本労農党 |

## 1936年の政権交代と社会政策

1936年の改選後、進歩・民権連立は解消し、国民進歩党・立憲改進党の連立内閣が成立した。両党の政策協定は「既存の労働保護制度の維持」「既存の社会保障制度の安定運営」を掲げ、社会民権党の離脱により労働者保護や社会保障の急速な拡張には慎重になった（検討案）。[^p080] 一方、閣外協力する国民協同党との三党協定には、産前産後の休業制度と女性労働者の保護、妊産婦医療・乳幼児保健、遺族・母子世帯への給付などが盛り込まれた（ダイス判定：難易度25、出目89・成功。協定の内容は検討案）（→[女性参政権運動と国民協同党](womens-suffrage.md)）。[^p081]

野党に転じた社会民権党は社会政策で部分的に協力した。再軍備には全面反対せず、労働条件、国防費の財源、社会保障支出の維持を条件とした。[^p009][^p081] 1937年度予算の交渉の中心は、国防費以外の公共投資・社会保障・女性家庭政策・地方財政配分であった（検討案）。[^p081]

各党の政策傾向は、社会民権党が全国共通の社会保障・労働者保護、日本労農党が居住地域によらない社会的権利の保障、国民協同党が教育・医療・母子保護の地域格差是正、と推定される（党綱領としては未確定）。[^p095]

# 史実との比較

* 史実の工場法は1911年に公布され、施行は1916年であった。適用は常時15人以上の工場に限られ、女子・年少者の就業を1日12時間に制限するなど、本世界線の包括的な10時間制よりはるかに限定的であった。労働組合法は戦前には成立していない（1931年に衆議院を通過したが貴族院で審議未了）。
* 史実の健康保険法は1922年に公布され、1927年に施行された。失業保険は戦前には導入されず、厚生年金の前身である労働者年金保険は1941年である。本世界線では老齢・失業保険が恐慌期に新設されている。
* 史実の労使関係は、1938年の産業報国会に代表される国家協調主義へ向かった。本世界線の中央労働協議会は、独立労組を前提とする社会的協調主義として、ワイマール期ドイツや北欧の労使協議に近い。
* 国際労働機関（ILO）は1919年に1日8時間・週48時間を国際基準とし、1935年に週40時間の原則を条約化した。[^e096]

# 未決の論点

* 1916年・1932年の法定労働時間（10時間制）と適用範囲の具体値は、社会制度を詳しく検討する際に確定するとされた暫定案である。[^p006][^p008]
* 法定8時間制と、会話ログ2の週40〜44時間制の普及（労働協約・企業慣行）との関係の細部。[^e096]
* 就業者3,220万人のうち社会保険の対象者数。[^p009]
* 中央労働協議会などの機関名（仮称）と構成。[^p007]
* 三党協定の女性労働者保護・母子保護が1937年末までにどこまで法制化されたか。[^p081]
