# 概要

本世界線の内閣は、[元老院](../institutions/genroin.md)が首班（首相）を指名し、[衆議院](../institutions/house-of-representatives.md)が組閣拒否と不信任によって存立を統制する制度のもとで成立する（→[内閣制度と両院関係（首班指名・組閣拒否・不信任・勅令）](../institutions/cabinet-system.md)）。[^p002] このため政党内閣の成立は、首班指名権が衆議院に移ることではなく、**元老院が特定の政党と結びついた人物を首班に指名する政治慣行**が成立することを意味する。[^p003][^p005]

1867年の第一回帝国議会（元老院のみ）から1880年代までは元老院主導の非政党内閣が続き、1876年に衆議院が開かれてからは「議会の政党化が政府の政党化に先行」した。日清戦争後の論功行賞をめぐる両院対立と、両院横断の開発政治を経て、1890年代前半から半ばに最初の本格的政党内閣が生まれ、20世紀初頭には政党内閣が憲政慣行として定着する。第一次世界大戦では超党派の戦時協力内閣が組まれ、戦後は競争的な連立政治となった。1930年には国民進歩党と社会民権党の開発・社会政策連立内閣が恐慌対策を担い、1936年の両院同時改選の後には国民進歩党・立憲改進党の少数与党連立内閣が1937年末まで続く。[^p004][^p005][^p006][^p007][^p008][^p009][^p080]

各内閣の首相・閣僚の人名は本記事では扱わない。[^n1][^p080] 各政党の系譜は[政党の系譜と衆議院の議席推移（1876〜1937）](political-parties.md)を参照。

# 時期区分

衆議院の政党史と内閣史は次のように区分される。[^n2][^p009]

| 時期 | 位置づけ | 内閣の主な形 |
|---|---|---|
| 1867〜1875年 | 元老院単院の帝国議会 | 元老院主導の内閣 |
| 1876〜1888年 | 名望家政党形成期 | 元老院主導の非政党内閣（政党の閣外支持あり） |
| 1889〜1900年 | 開発政治・政党内閣成立期 | 最初の本格的政党内閣 |
| 1901〜1913年 | 産業社会化・労働政治形成期 | 政党内閣の定着 |
| 1914〜1918年 | 超党派的戦時協力期 | 戦時協力内閣 |
| 1919〜1924年 | 大衆政党化・社会保障成立期 | 競争的な連立政党内閣 |
| 1925〜1929年 | 秘密投票・領主制近代化期 | 連立政党内閣 |
| 1930〜1932年 | 開発・社会政策連立政権期 | 国民進歩党・社会民権党連立 |
| 1933〜1935年 | 普通選挙・憲法改革期 | 同上 |
| 1936〜1937年 | 多党制再編・思想統制・再軍備期 | 国民進歩党・立憲改進党の少数与党連立 |

政治上の対立軸は、1876年頃の「領主権の維持か臣民の権利拡張か」から、1888年頃の「国防・対外介入か戦費・租税負担か」、1896年頃の「積極的産業開発か財政規律・行政改革か」、1908年頃の「企業・資本の自由か労働者保護・社会立法か」、1916年頃の「既存の財産代表制か大衆的政治参加か」へと重なりながら移っていった（以前の争点も消えない）。[^p003]

# 元老院主導の内閣（1867〜1888年）

第一回帝国議会は1867年に開かれ、1870年に憲法施行後の第一回元老院改選が行われた。この時期の帝国議会は元老院だけで、内閣は元老院の指名によって成立した。1876年の第一回衆議院総選挙で二院制となる。[^p002]

1876〜1888年には、立憲改進党・立憲保守党[^n3]の二大政党が成立し、両党と元老院の改革派・保守派会派との恒常的な連携も成立した。[^n4] しかし1888年までに政党を基盤とする内閣は生まれなかった。[^n5] 一方、重大な両院対立による長期の内閣不在は回避された。[^n6][^p004]

この時期の内閣の形は次のとおりである。[^n7][^p004]

| 内閣の形 | 1888年までの成立 |
|---|---|
| 元老院主導の官僚内閣 | 成立 |
| 元老院会派を基盤とする内閣 | 成立 |
| 政党の閣外支持を受ける内閣 | 成立 |
| 政党幹部を一部閣僚に迎える内閣 | 成立しうる |
| 政党を主体とする内閣 | 未成立 |

たとえば元老院の改革派が元官僚・元議員を首班に指名する前に立憲改進党と政策協議を行い、改進党は政策の実施を条件に組閣拒否案に反対した。1880年代の内閣は「非政党的だが反政党的ではない」。この段階で成立した憲政慣行が、**元老院が首班指名の前に衆議院主要政党の意向を確認すること**である。[^n7][^p004] 1888年の日本は「政党政治は成立しているが政党内閣は成立していない」、すなわち議会の政党化が政府の政党化に先行した状態にあった。[^p004]

# 論功行賞危機と最初の政党内閣（1889〜1900年）

## 論功行賞をめぐる両院対立

1889年の日清戦争終結後、領主への加増・新規授封・非華族への叙爵をめぐって元老院と衆議院が対立し、その調整は円滑に進まなかった。[^n8][^p005] 元老院が加増・授封案を出すと衆議院はこれに反対し、論功行賞の元老院勅令に対する衆議院の90日以内の無効決議、さらには内閣不信任も視野に入る対立となった。この危機が、両院間の権限と報償制度の再検討、領主権と臣民の権利の立法調整、政党内閣の成立へとつながった。[^n9][^p005] 加増が実際にどの程度行われたかは[日清戦争後の論功行賞](../events/reward-distribution-1889.md)を参照。

| 争点 | 元老院側の論理 | 衆議院側の論理 |
|---|---|---|
| 戦勝の主体 | 天皇と帝国を構成する諸領主 | 帝国国家と国民 |
| 加増 | 伝統的な報償 | 公的戦果の私的帰属 |
| 賠償金 | 功績に応じた報償にも使える | 原則として帝国財政 |
| 新規授封 | 天皇の権限 | 国民の権利・財政への影響 |
| 軍人への報償 | 爵位・領地・金銭 | 爵位・勲章・年金・金銭 |

[^p005]

## 開発政治

同じ時期、対清賠償金を原資とする[帝国交通整備計画](../economy/transport-plan.md)を軸に、元老院と衆議院を横断する公共事業の政治連合が成立した。[^n10] 領主は領国経済と家産収益のため、地方名望家は販路と地価のため、都市商工業者は全国市場と輸送費低下のため、金融業者は設備投資のため、帝国官僚と軍は全国基盤と兵站のために鉄道・国道・港湾・電力・教育への投資を支持した。公共事業の利益誘導・汚職は全国的な政治問題にならなかった。[^n11][^p005]

## 最初の本格的政党内閣

1900年までに最初の本格的な政党内閣が成立した。[^n12] 成立の時期は**1892年総選挙後から1896年総選挙後までの間**である。[^n13] 論功行賞問題で元老院主導の非政党内閣では安定した政策遂行が難しいという認識が広がり、交通整備・産業振興という共通政策が政党中心の内閣の余地を作った。[^p005] 本格的政党内閣は次の要件で定義される。[^n7]

| 項目 | 内容 |
|---|---|
| 首班 | 特定の政党の指導者または元指導者 |
| 首班指名 | 元老院の正式な決議 |
| 閣僚 | 政党関係者を主要閣僚に起用（入閣する議員は議員を辞職） |
| 政策 | 政党の綱領・政策を基礎とする |
| 衆議院 | 当該政党を中心に組閣拒否を否決 |
| 元老院 | 協力会派による継続的な政策支持 |

[^p005]

最初の政党内閣の与党は立憲改進党または立憲保守党である。[^n14]

## 民意尊重の慣例

選挙結果を首班指名に反映する憲政慣行も成立した。[^n15] これは第一党の党首を自動的に指名する慣行ではなく、元老院が選挙結果を尊重しつつ、第一党に協調性がなければ第二党や超党派の人物を指名することもできるという慣行で、「**民意尊重の慣例**」と呼ばれる。[^n16][^p005]

ただし同時期、既成二大政党は全国的な地方支部組織の確立に大きくつまずいており[^n17]、議会の中では政党政治が成熟しているのに、社会における政党組織の発達は著しく遅れた。1900年の日本は「立憲主義は発達しているが、民主主義の大衆化は進んでいない国家」と評される。[^p005]

# 政党内閣の定着と戦時協力内閣（1901〜1918年）

1901〜1916年には、政党内閣が一時的な現象に終わらず恒常的な憲政慣行となり[^n18]、両院の協調も維持されて長期の組閣不能は起きなかった。[^n19][^p006] 1912年頃に立憲改進党が分裂し、産業振興派が国民進歩党[^n3]を結成した。[^n20] これにより衆議院は立憲保守党・立憲改進党・国民進歩党・社会民権党の四党体制となった。[^p006]

1914年の第一次世界大戦参戦に際しては、超党派的な戦時協力体制がきわめて円滑に成立した。[^n21] 元老院の主要会派、衆議院の主要政党、帝国政府が共同で戦時政策を立てる**超党派の戦時協力内閣**と、**両院合同の戦時政策協議会**が置かれた。[^n22] 協議会は憲法上の議決機関ではなく、予算・軍需生産・対外金融・海上輸送を事前に調整する機関である。社会民権党や労働組合にも、戦時生産への協力と引き換えに労働条件・賃金・食料供給を政府と協議する機会が与えられた。戦時経済の成功は、特定の政党や軍の功績ではなく「立憲体制全体の成功」として認識された。[^p006] 対外的な参戦の経緯は[第一次世界大戦と日本](../events/world-war-one.md)を参照。

1917年の時点で、首班は議員経験者から選ぶ慣習が成立していた。[^p002] この時期の体制は「名望家立憲政治と社会的保護主義が併存する体制」と性格づけられる。[^p006]

# 戦後の競争的連立政治（1919〜1929年）

戦時協力内閣は1919年頃に首相の判断で解散し、元老院の首班指名を経て通常の政党内閣に移った。[^n7] 戦後は主要政党間の協調が崩れた[^n23]が、両院の協調と立憲政治の安定は1924年まで保たれた。[^n24] 「政党政治の競争は激化するが、憲法上の統治機構は正常に機能する」展開である。[^p007]

戦後処理をめぐる四党の立場は次のとおりである。[^n7][^p007]

| 争点 | 立憲保守党 | 立憲改進党 | 国民進歩党 | 社会民権党 |
|---|---|---|---|---|
| 戦時利得課税 | 限定的に支持 | 慎重 | 財源確保のため支持 | 強く支持 |
| 戦後財政 | 経常収支均衡 | 歳出削減 | 積極的産業投資 | 社会政策優先 |
| 対外債権 | 安全な資産運用 | 民間金融・貿易重視 | 国家戦略に活用 | 収益の社会還元 |
| 労働政策 | 保護主義 | 労使自治 | 産業協調 | 労働者の権利拡大 |
| 選挙改革 | 限定的緩和 | 都市有権者の拡大 | 納税資格の緩和 | 普通選挙 |

1924年の両院同時改選後の衆議院[^n25]では、立憲保守党87・立憲改進党73・国民進歩党82・社会民権党46で、既成三党のうちどの二党を組み合わせても過半数（151）に達する一方、社会民権党は既成の一党と組んでも過半数に届かなかった。[^p007] 1927年の[金融危機](../events/financial-crisis-1927.md)は「領主系銀行を政府が救済するのか」という形で政治化したが、銀行監督の強化は実現せず、代わりに領主家資産と領国財政の分離が大きく進んだ。[^n26][^p001][^p008]

# 開発・社会政策連立（1930〜1936年）

1925〜1932年には、社会民権党が初めて連立内閣に参加し[^n27]、積極財政派が1932年までに政権の中心勢力となった。[^n28] 両者を同一の政治過程とみる整理では、**国民進歩党と社会民権党を中核とする開発・社会政策連立内閣**が1930年の元老院改選の直後に成立し、1932年の総選挙で政権基盤を強化した。[^n29][^p008] 1930年の元老院改選は、金融危機と領主金融圏の動揺を強く反映した改選と位置づけられる。[^p023]

| 政策分野 | 国民進歩党 | 社会民権党 |
|---|---|---|
| 公共投資 | 産業基盤の整備 | 雇用の創出 |
| 財政支出 | 生産力の拡大 | 生活の安定 |
| 社会保険 | 労働力・産業の安定 | 労働者の生活保障 |
| 労使協議 | 生産活動の安定 | 労働者の政策参加 |
| 国防 | 工業力・軍備の強化 | 財政負担・文民統制を重視 |
| 選挙改革 | 漸進的改革 | 普通選挙の実現 |

[^p008]

両党の共通政策は、世界恐慌に対する財政支出による需要創出である。1930年以降の公共投資拡大と景気回復は、この連立政権の政策による。ただし[1925年財政原則](../economy/fiscal-principles-1925.md)は維持され、建設公債による公共投資と、租税・保険料を財源とする経常的な社会保障支出は区別された。[^p008] 1932年の総選挙[^n25]では進歩99・民権68で、連立与党は167議席（55.7%）を占めた。[^p008] 恐慌下でも反議会主義・権威主義運動は拡大せず[^n30]、両院の協調と立憲秩序は保たれた。[^n31][^p008]

本世界線には満洲事変・関東軍・統帥権干犯問題・金解禁不況がないため、1930〜32年の恐慌でも政党政治は崩れず、選挙は「緊縮か積極財政か」の政策選挙となり、健全財政派・開発財政派・社会政策派のうち開発財政派が1930年代の主流になる、という見通しが当初から示されていた。[^p001]

# 1936年の政変と進歩・改進連立内閣

1936年は両院同時改選の年で、初の男女普通選挙による第16回総選挙が行われた。改選後、国民進歩党と社会民権党の連立は選挙制度や国内政策をめぐる対立で解消した。[^n32] 一方、再軍備をめぐる対立による連立崩壊は起きておらず[^n33]、両者は区別される。[^p009]

1936年の衆議院（推計）は国民進歩党72・立憲改進党56・国民協同党46・社会民権党42・日本労農党40・立憲保守党39・その他5の計300議席である。[^p078] 政権形成では、衆議院の政党間協定が元老院に先行し、国民進歩党が中核に残り、立憲改進党が参加したが、国民協同党は入閣しなかった。元老院は衆議院側の首相候補を受け入れ、人物本位の投票で初回採決により首相を確定した。こうして国民進歩党出身の首相[^n34]による**国民進歩党・立憲改進党の少数与党連立内閣**（衆議院128議席）が成立し、最初の不承認動議を乗り切って、1937年末まで存続した。[^n35][^p080] 元老院の会派は政党ではなく家門・地域・個人の結びつきによる倶楽部であり、首班指名では「どの会派が政権を取ったか」より「どの人物が、どの家門・倶楽部・衆議院政党の支持を得て首相になったか」が重要になる。[^n7] 1936年には、元老院出身の首相と衆議院出身の首相が交互に現れていても不自然ではない段階にあった。[^p079]

国民協同党は正式な閣外協力協定を結び、女性・家庭政策が政権協定に盛り込まれた。衆議院の政権支持基盤は174議席（58.0%）である。内閣の主要閣僚は衆議院出身者が中心で、元老院出身者は主要閣僚に起用されなかった。元老院には公式の与党会派を持たず、有力議員との非公式な協力で案件ごとに支持を集めた。1937年度予算は両院で大きな修正なく成立した。[^n36][^p081] この政権は「衆議院主導型政権」と総括され、「首相の選出権は元老院にあるが、政権形成の主導権は衆議院の政党間交渉に移りつつある」ことを示す重要な事例となった。ただし元老院が衆議院側の候補を受け入れる法的義務は生じていない。[^p081] 詳細は[1936年の政変と進歩・改進連立内閣](cabinet-1936.md)を参照。

# 内閣の系譜（概略）

各内閣は、形態と与党の組み合わせで示す。[^n37]

| 時期 | 内閣の形 | 与党・支持勢力 |
|---|---|---|
| 1867〜1888年 | 元老院主導の非政党内閣 | 元老院の改革派・保守派会派。政党は閣外支持[^n38] |
| 1889年前後 | 論功行賞をめぐる憲政危機 | ―[^n39] |
| 1892〜1896年頃 | 最初の本格的政党内閣 | 立憲改進党または立憲保守党[^n40] |
| 1900年代〜1913年 | 政党内閣の常態化 | 二大政党（1912年頃から四党体制）[^n41] |
| 1914〜1919年頃 | 超党派の戦時協力内閣 | 元老院主要会派・衆議院主要政党[^n38] |
| 1919年頃〜1930年 | 競争的な連立政党内閣 | 既成三党の組み合わせ[^n7] |
| 1930〜1936年 | 開発・社会政策連立内閣 | 国民進歩党・社会民権党[^n42] |
| 1936〜1937年末 | 少数与党連立内閣 | 国民進歩党・立憲改進党（国民協同党が閣外協力）[^n41] |

# 史実との比較

* 史実では1918年の原敬内閣が最初の本格的政党内閣とされる。本世界線では衆議院開設が1876年と史実（1890年）より14年早く、最初の本格的政党内閣も1890年代前半から半ばに成立する。[^p001][^p003]
* 史実の首相は元老の推薦にもとづき天皇が任命し、議会の議決は不要だった。本世界線では元老院が議決で首班を指名し、衆議院が組閣拒否と不信任を持つ。史実と違って議員と閣僚の兼任はできず、内閣は衆議院を解散できない。[^p003]
* 史実の1930年代は満洲事変・統帥権干犯問題・世界恐慌・政党不信が同時に進み、政党内閣が途絶えた。本世界線ではこれらの条件が欠け、恐慌期にむしろ開発・社会政策連立が政権を担い、1937年末まで政党内閣が続く。[^p001]

# 編集注：未決の論点

* 歴代首相・閣僚の人名と各内閣の名称・存続期間。[^p080]
* 最初の本格的政党内閣の具体的な年・首班・与党。[^p005]
* 論功行賞危機の具体的経過（元老院勅令・無効決議・不信任の有無）。[^p005]
* 立憲改進党の分裂（1912年頃）は判定では「二大政党の一方の分裂」であり、改進党とするのは提案側の仮定。[^p006]
* 1919〜1930年の連立の具体的な組み合わせ。
* 1936年の内閣の閣僚数・省庁編成・閣僚配分（国民進歩党8・立憲改進党6・無党派1の15人は案）。[^p081]
* 1938年以降の政治史は保留。[^p081]

# 編集注：却下・修正された案

* **二院協調型議院内閣制（P1）**: 当初の提案では、衆議院の多数派を基礎に成立し重要政策で元老院との合意を要する内閣が想定されたが、P2で作者が元老院の首班指名を中心とする制度を確定させた。[^p001][^p002]
* **立憲政友会・国民党（P3）**: P3で提案された1916年の暫定政党体系（立憲政友会・立憲改進党・立憲保守党・国民党、いずれも仮称）は、P4以降のダイス結果に基づく系譜に置き換えられ、立憲政友会と国民党の名は使われなくなった。[^p003][^p004]
* **1936年の三党連立案（P9）**: 国民進歩党・立憲改進党・国民協同党の三党連立内閣が第一案とされたが、P80の判定で国民協同党は入閣せず、二党連立と閣外協力に修正された。[^p009][^p080]
