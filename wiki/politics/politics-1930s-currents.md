# 概要

1933年にドイツでナチス政権が成立すると、本世界線の日本でも権威主義的な政治運動が広がった（ダイス判定：難易度55、出目57・成功）。しかしそれは独立したファシズム政党や軍人政党の台頭ではなく、既存政党の内部や青年団体・知識人のあいだの潮流にとどまった。退役軍人・国防強化派による独立した政治勢力は生まれず（ダイス判定：難易度45、出目13・失敗）、第二次ロンドン会議の決裂後の国防費拡大は、両院と主要政党の合意によって議会の手続のなかで決められた（ダイス判定：難易度30、出目46・成功）。[^p009]

一方で、急進的な政治運動に対する包括的な思想取締法の制定回避はファンブルとなり（ダイス判定：難易度30、出目1・ファンブル）、仮称「**帝国秩序維持例**」が成立した。軍の独裁や議会の停止ではなく、**議会自身が思想・結社の自由を制限する立法を行う**という形である。また、議決の正当性を確保するために元老院・衆議院の定足数を定める憲法改正が1937年末までに成立した。立憲秩序と両院の協調は1937年末まで維持された（ダイス判定：難易度20、出目61・成功）。[^p009]

その結果、1937年末の日本は「世襲領主による上院、普通選挙による下院、独立した労働組合、社会保障制度、議会による思想統制が一つの国家の中に併存し」、単純に自由民主主義国家とも権威主義国家とも分類しがたい国家となる。[^p009]

# 背景

## 恐慌期にはファシズムが育たない

史実の1930年代前半を特徴づけた満洲事変・関東軍の独走・統帥権干犯問題・金解禁不況は、本世界線では起きない。天皇に固有の統帥大権がないので、軍人が政府を無視して行動することは難しい（→[統帥権（本世界線）](../institutions/supreme-command.md)）。[^p001] 1925〜1932年の判定でも、世界恐慌下の反議会主義・権威主義運動は拡大せず（ダイス判定：難易度50、出目47・失敗）、包括的な思想取締法の制定も回避された（ダイス判定：難易度35、出目73・成功）。恐慌への対応は、国民進歩党・社会民権党の連立内閣による公共投資が担った（→[内閣の系譜と政党内閣の慣行（1867〜1937）](party-cabinets.md)）。[^p008]

それ以前の1917〜1924年にも、ロシア革命の影響で急進的な社会主義運動が拡大したが（ダイス判定：難易度45、出目66・成功）、政府は政治結社への広範な弾圧を伴わずに対処した（ダイス判定：難易度35、出目48・成功）。合法的な領主制廃止論・共和主義・社会主義と、武装蜂起・暴力による政府転覆とは区別され、領主権の廃止を主張するだけでは違法とならなかった（その実現には憲法改正が必要）。[^p007]

## 1933年以降の圧力

圧力が強まるのは1933年以降である。ドイツの権威主義体制の成立と、国内の革命社会主義運動の拡大が重なった。とくに1936年の初の男女普通選挙で日本労農党（仮称）が躍進すると（ダイス判定：難易度65、出目98・クリティカル）、思想取締の議論は急激に強まった。元老院の領主議員にとって、革命社会主義政党が合法的な政治勢力として成長することは、自らの憲法上の地位にかかわる問題だったからである。[^p009] 国際面の経緯は[1933年の国際秩序再編とナチス・ドイツ](../events/nazi-germany-1933.md)を参照。

# 権威主義的潮流

権威主義運動は拡大したが、独立した国防政治勢力の形成には失敗したため、1937年時点の権威主義は次のような潮流として既存の組織の内部に存在する（AIの整理）。[^p009]

| 政治潮流 | 主な活動の場 |
|---|---|
| 国家統制経済論 | 国民進歩党の一部、産業官僚 |
| 伝統主義的権威主義 | 立憲保守党の一部、華族団体 |
| 国家改造論 | 青年団体、一部の知識人 |
| 国防強化論 | 各政党、退役軍人団体 |
| 反共主義 | 元老院および各政党の一部 |

これらは共通の思想も統一された党組織も持たない。とくに**領主制と中央集権的な権威主義の間には根本的な緊張関係**がある。帝国政府への極端な権力集中は、元老院と領国の権限を侵すからである。[^p009]

AIは会話ログ3の冒頭で、「一国一党・一人の指導者・中央集権国家」という思想は大領主層にとっても脅威であり、**元老院の世襲領主がファシズムに対する制度的防波堤になる**という逆説を示した。極右の青年将校が「腐敗した政党と財閥と領主を一掃せよ」と唱えれば、領主層は鎮圧する側に回る。二・二六事件のような事件が仮に起きても、それは天皇親政を求める運動というより「反議会・反領主・国家改造運動」となり、国軍の指揮系統が政府に属するため成功率は史実より低い（検討案）。[^p001]

# 国防政治と再軍備

## 議会内軍事ロビー（検討案）

統帥権が独立していないため、軍の政治的影響力は「軍事官僚の独立政治」ではなく、軍人・退役軍人・軍需企業・安全保障強硬派が議会の内部で勢力をつくる「**合法的な議会内軍事ロビー**」の形をとる、とAIは見通した。元老院には軍歴を持つ領主・華族議員がおり、衆議院にも国防強化派がいる。1936年の第二次ロンドン会議の決裂と1937年の建艦競争でこの勢力は伸びるが、「軍部が内閣を倒して軍人内閣を作る」のではなく「国防派が総選挙や連立交渉で勢力を増す」形になる。[^p001]

実際の判定では、国防強化派は独立した政治勢力にすらならず（出目13・失敗）、国防強化論は各政党の内部の潮流にとどまった。[^p009]

## 両院合意による再軍備

[第二次ロンドン海軍軍縮会議](../diplomacy/second-london-conference.md)の決裂後の再軍備について、両院と主要政党の間で合意が成立した（出目46・成功）。再軍備をめぐる対立で連立政権が崩壊することもなかった（ダイス判定：難易度45、出目26・失敗＝崩壊回避）。[^p009] 社会民権党は1936年に野党へ転じても国防政策そのものに全面的には反対せず、労働条件・国防費の財源・社会保障支出の維持を条件とする立場をとる。国防費の拡大は軍による政治権力の掌握ではなく、**議会による国防政策の決定**として行われた。1937年の国内政治の基本設定では、軍事制度は「文民統制・議会による国防財政決定」とされる。[^p009]

| 1937年の国防負担 | 値 |
|---|---|
| 国防費 | 18.8億円（GDP比4.70%） |
| うち海軍費 | 12.8億円（GDP比3.20%） |
| 帝国政府経常歳入 | 56.6億円 |
| 国防費／帝国経常歳入 | 33.2%（建設公債による支出を含みうるので、経常財源の負担率ではなく規模の比較） |

[^p009][^p097]

1936年に成立した国民進歩党・立憲改進党の連立内閣は、1937年度予算を両院で大きな修正なく成立させた。予算交渉の焦点は国防費以外（公共投資、社会保障、女性・家庭政策、地方財政配分）にあり、国民協同党・社会民権党も国防予算を全面的には否定しなかった。[^p081] 予算の内訳は[1937年度の帝国財政と連結政府財政](../economy/public-finance-1937.md)を参照。[^p093]

## 1937年政治の核心（検討案）

AIは、1937年政治の核心を「**軍艦を造るかどうかより、造った軍艦を維持するために増税するか**」とみた。[1925年財政原則](../economy/fiscal-principles-1925.md)のもとでは、艦艇の建造には建設公債を使えても（作者確定）、給与・燃料・訓練・維持費には使えない。海軍建艦派・財政保守派・社会政策派・民生公共投資派が衝突するが、これは議会政治を壊すのではなく、本格的な政策論争をもたらす。[^p001] 建艦計画そのものは[1937年の建艦競争と海軍財政](../military/naval-buildup-1937.md)を参照。

# 思想取締法（帝国秩序維持例）

## 成立

包括的な思想取締法の回避判定がファンブル（出目1）だったため、単なる暴力行為の取締強化では済まない。他方で立憲秩序の維持には成功しているので、成立したのは議会が制定する法律である。名称は仮に「**帝国秩序維持例**」とされ、規制は暴力行為の準備に限られず、非暴力的な思想活動にも及ぶ（内容・名称はAIの案）。[^p009]

| 規制対象 | 内容（案） |
|---|---|
| 革命的政治結社 | 一定の目的を持つ団体への解散命令 |
| 宣伝活動 | 憲法秩序の破壊を目的とする宣伝の規制 |
| 外国政治組織 | 外国組織からの指令・資金提供の規制 |
| 出版・集会 | 禁止対象となった政治活動への規制 |
| 政治団体監督 | 資金・役員・活動内容の届出 |
| 司法手続 | 政治犯罪に対する刑事訴追 |

[^p009]

制定時期は1936〜37年頃とされる。規制対象を共産主義に限るか、ファシズムや反議会主義も含めるかは別の問題として残された。[^p009]

## 日本労農党の扱い

日本労農党の成長はクリティカルで決まっているため、法律によって直ちに全面禁止されるとその意味が失われる。そこで1937年末の状態は次のように想定される。[^p009]

* 日本労農党は衆議院に議席を持つ合法政党として存続する。
* 党内の革命主義的組織や一部の関連政治結社が取締の対象となる。
* 出版・政治活動への規制や、党関係者に対する刑事事件が起きる。
* 法律の適用範囲をめぐって、議会・司法・政党の間で論争が続く。
* 労農党は議会活動を維持するため、合法的な政治活動と革命運動の関係を見直す。

全面禁止や議員資格の剝奪まで至るかは、1938年以降の問題として保留されている。1937年末の日本は、複数政党による競争的な議会政治を維持しながら、思想・結社の自由に重大な制約を抱える国家となった。[^p009] 労農党は、大企業の組織労働者を基盤とする社会民権党と異なり、低所得労働者・小作農・零細自営業者・社会保険から外れた非正規労働者などを基盤とする（→[政党の系譜と衆議院の議席推移（1876〜1937）](political-parties.md)）。[^p009]

## 華族の家門司法権との衝突

1920年代の改革で全華族に認められた家門司法権は、家門構成員に対する事実上の不逮捕特権を伴う（→[家門自治権と家門司法権（1924年の華族特権改革）](../institutions/family-autonomy.md)）。このため、たとえば革命社会主義運動に加わる学者が華族の家門に属していれば、帝国警察は通常の手続だけでは逮捕できない。思想取締法の制定にあたっては、次のような立場の論争が起こりうる（検討案）。[^p029]

| 立場 | 主張 |
|---|---|
| 華族自治権擁護派 | 政治犯罪についても家門司法権を尊重すべき |
| 帝国司法権重視派 | 国家の存立に関する犯罪は帝国の専属管轄とすべき |
| 立憲自由主義派 | 家門特権の有無によって政治的自由に格差が生じる |
| 治安重視派 | 家門自治権が思想取締を妨げるべきではない |

1920年代に成立した特権を1930年代に一方的に制限することは政治的に難しい。[^p029] さらにユーザーは、ある事項が帝国裁判所の専管となるには「例」による明文の規定が必要だという法理を確定させた。したがって、思想取締法で禁止行為を定めることと、その事件を帝国裁判所の専管とすることは別個の立法事項になる（→[三元的司法制度（帝国・領国・家門）](../institutions/tripartite-judiciary.md)）。[^p031]

# 定足数の憲法改正

## 経緯

ユーザーは、ナチス・ドイツの成立後に定足数要件を追加する憲法改正案が審議されていると設定した。[^p002] 従来の憲法には定足数がなく、棄権者は欠席扱い、可否同数は可決とされていたため、極端な場合はごく少数の出席議員だけで首班指名や内閣不信任が成立しうる。1936年の普通選挙による政党体系の変化を考えても、議決制度の明確化は重要になった。[^p009]

改憲案の提出（ダイス判定：難易度15、出目86・成功）と、1937年末までの成立（ダイス判定：難易度55、出目61・成功）がいずれも確定した。[^p009] 同じ1933〜1936年には、元老院の定数を310に増やしつつ領主の制度的過半数を保つ第二次の元老院改革も行われており、両者をあわせて大規模な憲政改革として扱える（検討案）。[^p026]

## 改正の内容（検討案）

具体的な割合や棄権者の扱いは、ユーザーの当初設定を変える部分なので、改憲成立という結果とは区別してAIの暫定案とされた。[^p009]

| 項目 | 改正前 | 改正後の案 |
|---|---|---|
| 通常議決の定足数 | なし | 総議員の3分の1以上 |
| 首班指名・内閣不信任・組閣拒否の定足数 | なし | 総議員の2分の1以上 |
| 棄権者 | 欠席扱い | 定足数には算入、表決数からは除外 |
| 議決要件 | 出席表決者の半数以上 | 維持 |
| 可否同数 | 可決 | 維持 |
| 衆議院の解散権・元老院の首班指名権 | 解散権なし・指名権あり | 変更なし |

改正の主眼は、権力配分を変えずに議決の正当性を確保することにある。衆議院300議席なら、改正後の不信任決議には150人以上の出席が必要となる。ただし棄権者が多い場合は依然として少数の賛成票で重要決議が成立しうるため、重要決議の有効表決数の最低要件を設けるかどうかが課題として残る。[^p009] 制度全体は[内閣制度と両院関係（首班指名・組閣拒否・不信任・勅令）](../institutions/cabinet-system.md)を参照。

# 左派の分化と新しい参加層

1930年代の政党政治は、普通選挙によって新たに有権者となった層の組織化をめぐって再編された。日本労農党の躍進は、経済崩壊型の革命運動ではなく「政治参加から排除されていた層の代表獲得」と説明され、組織労働者を基盤とする社会民権党と、制度の外にいる労働者・小農を基盤とする労農党へと「左派政治の社会的分化」が進んだ。女性参政権運動からは国民協同党（仮称）が生まれた（ダイス判定：難易度55、出目97・クリティカル）。[^p009] 詳細は[政党の系譜と衆議院の議席推移（1876〜1937）](political-parties.md)と[女性参政権運動と国民協同党](womens-suffrage.md)を参照。

社会構造の面では、元老院が資産所有者と専門エリートの利益を、男女普通選挙の衆議院が農民・労働者・都市中間層の利益を反映し、両院の政策対立の基礎となっている。[^p085] 財政調整をめぐっても、国民進歩党は全国的な社会資本整備、立憲保守党は領国自治と財政規律、日本労農党は居住地域によらない社会的権利を掲げるなど、自治と平等をめぐる対立がある（各党の傾向はAIの推定）。[^p095]

# 1937年末の国内政治の基本設定

| 分野 | 1937年末の設定 |
|---|---|

# 史実との比較

| 論点 | 史実 | 本世界線 |
|---|---|---|
| 思想取締法 | 1925年に普通選挙法と同時に治安維持法。「国体の変革」と私有財産制度の否認を処罰 | 1924年・1932年までは制定を回避。1936〜37年頃に議会が帝国秩序維持例（仮称）を制定 |
| 軍の政治関与 | 統帥権の独立を根拠に軍部が政治化し、五・一五事件・二・二六事件を経て政党内閣が途絶 | 統帥大権がなく、国防強化派は独立勢力にもならない。国防費は両院合意で決定 |
| ファシズム | 軍部・革新官僚・右翼運動が結びつき、1940年に大政翼賛会 | 既存政党内の潮流にとどまり、世襲領主の元老院が中央集権化への歯止めとなる |
| 1930年代の内閣 | 1932年以降は政党内閣が途絶 | 1937年末まで連立政党内閣が続く |
| 議会の議決 | 定足数あり | 定足数なしの憲法を1937年までに改正 |

史実の治安維持法は天皇主権の「国体」の変革を処罰したが、本世界線では天皇主権の国体論が弱く、領主権が憲法上の政治的権利で、社会主義者の批判の対象も天皇制に限られない。そのためAIは当初、取締の対象は「国体変革」ではなく、領主制の暴力的廃止・私有財産制の革命的変更・軍隊や警察への反乱扇動になると見ていた。[^p001]

# 却下・修正された案

* **暴力革命処罰型の取締法（P1）**: AIは当初、史実の治安維持法のような法律は成立しにくく、制定されても暴力革命・武装蜂起・反乱扇動を罰する程度の法律にとどまると想定した。P9の判定がファンブル（出目1）となり、非暴力的な思想活動にも及ぶ包括的な思想取締法の成立に改められた。[^p001][^p009]
* **国防派の急伸（P1）**: AIは当初、1930年代の軍の政治化を「軍国主義政党」化、すなわち国防派が総選挙や連立交渉で勢力を伸ばす形で予想したが、P9の判定で退役軍人・国防強化派の独立勢力は形成されず、国防強化論は各政党内の潮流にとどまった。[^p001][^p009]
* **定足数改憲の審議継続案（P2）**: P2の段階では、1937年末時点でもなお審議中とする案があったが、P9の判定で成立が確定した。[^p002][^p009]

* 日本労農党の全面禁止や議員資格の剝奪の有無（1938年以降の問題）。[^p009]

* 定足数改憲の具体的な割合・棄権者の扱いと、重要決議の有効表決数の最低要件。[^p009]
* 権威主義的潮流と国防強化論の具体的な担い手・団体名。
