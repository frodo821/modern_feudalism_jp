# 凡例

この年表は、1853年のペリー来航から1937年の建艦競争の開始までの、本世界線（[近代封建制](/concepts/modern-feudalism.md)の世界線）の出来事を年代順に並べたものである。世界線全体の前提は[世界線の概要と前提原則](/overview/worldline.md)を参照。

| 列 | 内容 |
|---|---|
| 年月日 | 西暦で示す。旧暦の日付が意味を持つ場合は括弧で和暦を添える。本世界線では明治元年＝1867年なので、明治の年数は史実より1年ずれる（1868年＝明治2年） |
| 出来事 | 本世界線で起きたこと。「史実から変化」の行は、末尾の括弧に史実を記す |
| 区分 | **本世界線**＝史実にない本世界線独自の出来事／**史実どおり**＝本世界線でも史実と同じく起きる出来事／**史実から変化**＝史実の出来事が時期・形・結果を変えて起きる、または起きない |
| 確度 | **確定**＝ユーザーが決定・同意した設定（出来事の骨子が確定で、年次や細部だけが提案段階の場合は出来事欄に「年次は検討案」等と注記する）／**検討案**＝AIの提案で、明示的な同意がないもの |
| 関連記事 | その出来事を詳述する記事 |
| 出典 | 会話ログの該当ユーザー発言とその応答（`[^u###]` は前編の会話ログ、`[^e###]` は1930〜1937年を扱う会話ログ2、`[^p###]` は1867〜1937年の国内政治・華族制度・領主家経済と1937年経済の確定版を扱う会話ログ3） |

* 1866年の月は会話ログの表記（和暦の月に近い）による。
* 第三国の内部条件は原則として史実どおりで、日本と米国の変化が及ぼす影響だけを変化として扱う。[^u047]
* 日付がチャンク間で食い違った箇所は、後のユーザー決定を優先した。採否は「日付の食い違いと採否」節にまとめる。
* 会話ログ2は1930年代を論じる前提として、1889〜1930年の中国史と1917〜1929年の通貨・金融史を遡って確定させた。これらは該当する時代の節に加え、前編の記述と矛盾する行は会話ログ2（後の決定）に合わせて改めた。
* ダイス（1d100）で決まった設定は確定として扱い、出来事欄に判定を併記する。会話ログ3の判定は「（ダイス判定：難易度35、出目52・成功）」の形で記し、出目が難易度と同値の場合は失敗とする。出目95以上はクリティカル、5以下はファンブル。
* 会話ログ3は、前編・会話ログ2で空白だった1867〜1937年の国内政治（政党・選挙・内閣・元老院・華族・授封・奉還）と領主家の経済史を遡って設定し、1937年の経済・財政を再積算して確定させた。前編・会話ログ2と食い違う行は会話ログ3（後の決定）に合わせた。衆議院の議席数、領主家の所得構成・毀損率など AI が配分・解釈した数値は検討案として扱う。ただし華族・領主家の家数（1867年華族令の414家、奉還60家、新規授封35家、功績叙爵360家、爵位返上27家、各改選年の配分など）は作者確定である。人名・党名・倶楽部名の多くは仮称である。
