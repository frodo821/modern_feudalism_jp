# 概要

1937年の本世界線の日本は、**電力・石炭・石油の用途別分業**というエネルギー構造を持つ。固定設備の動力は水力を中心とする電力、製鉄と工業用熱源は石炭、自動車・商船・航空機は石油が担う。[^e089]

電力部門では、1929年までの大規模水力開発、1930年代の貯水式発電所への公共投資、領国間の送電網と電力融通制度、工場の個別電動機化、幹線鉄道の電化という五つのダイス判定がすべて成功し、発電設備1,350万kW・総発電量650億kWh（水力比率77%）と、史実の約2.15倍の発電量に達した。[^e079] 一方で国内炭鉱の露天掘り開発と坑内掘りの機械化はいずれも失敗し、国内石炭生産は1930年の4,800万tから1937年の3,800万tへ**減少**した。[^e079] 石油は国内油田の探査がクリティカルで成功して国内原油100万tを得たが、自動車と商船の普及で需要は1,250万tに達し、石油自給率は7.5%にとどまる。[^e081][^e089]

「**水力発電では比較優位を持つが、化石燃料の採掘では比較劣位にある日本**」という構造であり、電化に成功して国内炭鉱が縮小したことは政策の失敗ではない。[^e079] ただし石油の輸入依存は深刻で、[日英海上通商防衛協定](/diplomacy/anglo-japanese-maritime-defense-agreement.md)の経済的な重要性をいっそう高めている。[^e089]

# 電力

## 水力開発の三段階

史実でも日本は1912年に水力発電設備の出力が火力を上回り、1917年に工場動力の電化率が50%を超え、大正期に長距離送電が実用化された。史実1937年の総発電量は302億kWh（水力73%、水力約221億・火力等約82億kWh）、電気事業者の設備容量は618万kWである。[^e078]

本世界線の水力開発は次の三段階をたどる。[^e078]

| 時期 | 内容 |
|---|---|
| 1890〜1914年 | 工業都市周辺の水力発電・地域送電網 |
| 1914〜1929年 | 大規模水力発電・長距離高圧送電 |
| 1930〜1937年 | 貯水式発電所・広域送電網・地域間連系 |

1930年代前半の公共投資のうち15%が発電・送電網に配分されていた。[^e078]（→[1925年財政原則と恐慌期の公共投資](/economy/fiscal-principles-1925.md)）

## 領国間電力融通制度

判定82の結果、電力事業は国有化されず、**領主系電力会社を残したまま、送電網と卸売電力市場を広域的に統合する制度**が成立した。[^e079]

| 項目 | 1937年の制度 |
|---|---|
| 発電所の所有 | 領主系企業・民間企業・公営企業 |
| 地域配電 | 各地域の電力会社 |
| 幹線送電網 | 帝国政府と電力会社の共同整備 |
| 電力融通 | 地域間の契約に基づく融通 |
| 技術規格 | 帝国共通規格への統一を推進 |
| 電力料金 | 地域差は残るが卸売価格は収斂 |
| 非常時 | 帝国政府による供給調整 |

[^e079]

水力発電の季節変動を地域間の融通で補えるため、各領国が個別に大規模な予備火力を持つ必要は小さくなった。経営主体は分散しつつ制度と規格を全国で共通化するという本世界線の原則（→[全国標準化政策](/institutions/national-standardization.md)）の、電力分野での具体化である。[^e079]

## 電力業の付加価値

総発電量から損失・所内消費を除いた販売電力590億kWhを用途別単価（製造業0.85セント/kWh、家庭3.50セント等、平均1.36セント）で評価すると販売額8.02億ドル、自家発電分を除いた電力業の総産出は7.5億ドル相当となる。電力の純付加価値は4.12億、都市ガス0.72億、上下水道1.10億、電力・ガス・水道の合計5.94億ドル相当で、水力主体のため燃料費が小さく減耗が大きい。就業者は発電5万・送配電保守9万・営業事務3万・都市ガス4万・上下水道7万の計28万人である。[^e094] 史実の米国1937年の平均販売単価は家庭4.39セント、大口1.15セント、全平均2.19セントである。[^e094]

# 石炭

## 国内炭鉱の停滞

| 判定事項 | 閾値 | 出目 | 結果 |
|---|---|---|---|
| 国内炭鉱の露天掘り開発が進展する | 1d100 > 55 | 49 | 失敗 |
| 坑内掘り炭鉱の機械化・集約化が成功する | 1d100 > 40 | 27 | 失敗 |

[^e079]

失敗の理由は技術的能力の欠如ではなく、**安価な外国産石炭との競争によって大規模な合理化投資を回収できる見通しが立たなかった**ことにある。恐慌期に不採算炭鉱が閉鎖され、工業生産が回復しても国内の採掘能力は戻らなかった。[^e079] 炭田別の露天掘り適性は、石狩・留萌が一部で高く、筑豊・常磐が部分的、釧路・三池・宇部は低いとされ、露天掘り比率は約5%にとどまる。坑内掘りでも機械化に成功した個別の大規模炭鉱はあるが、産業全体の構造は変わらなかった。[^e078][^e079]

| 1930 | 4,800万t | 5,500万t |
| 1932 | 4,200万t | 5,300万t |
| 1934 | 3,950万t | 5,900万t |
| 1937 | 3,800万t | 5,700万t |

[^e079][^e089]

1930〜37年の国内石炭生産は年率−3.3%で、同期間に粗鋼生産は年率7.3%で伸びている。[^e098]

## 石炭産業の生産性と就業者

史実の1936年日本の石炭産業は生産4,180万t・労働者約19.8万人（一人211t）、1937年の米国の瀝青炭・褐炭は一人当たり約822t（労働者49.2万人）である。本世界線では採掘労働者18万人と技術・管理・事務2万人の計20万人、一人211tで、対米の物的生産性は約26%である。合理化の判定には失敗したが既存技術は失われておらず、不採算炭鉱が閉山して高生産性の炭鉱が残ったことによる。[^e090]

| 計 | 250万台 | | | 528万t→530万t |

（密度0.75kg/L）[^e089]

商船隊900万総tの推進機関は、石炭燃焼蒸気船45%（405万総t）、重油燃焼蒸気船30%（270万総t・重油約170万t）、ディーゼル船25%（225万総t・約80万t）で、漁船等の約60万tと合わせ船舶用石油は310万tとなる。史実の1936年英国商船隊（約2,017万総t）は内燃機関船348万総t・重油燃焼蒸気船588万総tである。[^e089]

## 石油調達の構造

石油は、国内原油生産／日本企業の海外油田持分生産／長期購入契約／国際市場購入の4区分で扱う。出資が必ずしも現物の引取権を伴うわけではない。[^e080] 海外油田の権益保有は自給率に含めない。[^e089]

石油需要を850万tとしていた段階（E81）の調達構造は次のとおりである。需要1,250万tへの修正後の輸入先別内訳は再設定されていない。[^e081]

| 調達先 | 量 | 比率 |
|---|---:|---:|
| 国内 | 100万t | 12% |
| 英領ボルネオ・ブルネイ | 150万t | 18% |
| ビルマ | 50万t | 6% |
| イラク・ペルシャ | 100万t | 12% |
| 蘭領東インド | 210万t | 25% |
| 米国 | 150万t | 18% |
| ソ連 | 40万t | 5% |
| その他 | 50万t | 6% |
| 計 | 850万t | 100% |

英国系供給圏から300万t、その他の海外から450万tを調達し、米国への依存は18%にとどまる。対米関係が悪化しても直ちに途絶はしないが、日英の海上交通が同時に妨害されれば脆弱である。[^e081] 輸入原油1,050万tの輸入額は約1.26億ドル、石油製品192万tは約0.60億ドル相当である。[^e098]

# 却下・修正された案

* **国内石炭生産**: 1930年の既存設定4,800万tからの延長として、E66で「1937年6,000〜7,000万t」案 → E72で「5,700万t（需要7,200万t、自給率79%）」案 → 炭鉱合理化の失敗（E79）により**3,800万t**に修正。[^e066][^e072][^e079]
* **石炭需要**: E79の6,400万t（原料炭1,600万t、純輸入2,600万t、自給率59.4%）→ 製鉄の原料炭原単位と鉄道・船舶の燃料を積算し直して**5,700万t**（原料炭1,100万t、海外調達1,900万t、自給率66.7%）。鉄道用は350→500万t、船舶用は200→350万tへ上方、工業炉・ボイラーは2,100→1,800万tへ下方修正。[^e079][^e089]
* **石油需要**: E80・E81の850万t（道路180万t）→ 自動車保有250万台と道路用180万tが整合しないとしてE87で1,070〜1,200万t・道路400〜530万tの幅を示し、E88で1,150万t案 → E89で**1,250万t**（道路530万t、船舶310万t）。[^e080][^e087][^e088][^e089]
* **精製能力**: E81の能力1,150万t・処理900万t → E88・E89で能力1,450万t・処理1,150万t。[^e081][^e088][^e089]
* **石油自給率**: E72の5%（国内原油45万t）→ E81の約12%（100万t／850万t）→ E87の8〜9% → E89の**7.5%**。[^e072][^e081][^e087][^e089]
* **石炭産業の就業者**: 42万人（一人90t、対米11%で史実日本の半分以下）は過大として**20万人**へ修正。鉱業全体は64万人から40万人へ。[^e090]
* **電化による製造業の生産性修正候補**（鉄鋼・非鉄55→58〜62%、電力・公益72.5→80〜85%など）は、製造業の判定と検証で別途置き換えられた。[^e079][^e088]

# 未決の論点

* 50Hz/60Hzの周波数問題が本世界線に存在するか、全国単一周波数か（電力融通の成功だけでは確定しない）。[^e079]
* 地域ごとの電力供給能力と水力の季節変動の検証。[^e081][^e089]
* 石油の持分生産量・長期契約量・市場購入量の区別、需要1,250万tに対応する輸入先別内訳、備蓄・精製損失を含む厳密な石油収支。[^e080][^e089]
* 鉄道・海運・一般工業用燃料は概算であり、発電設備の季節別稼働や製品別の精製収率は厳密に検証されていない。[^e089]
