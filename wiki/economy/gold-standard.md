# 概要

本世界線の日本は、1930年の時点で金本位制を停止している。1917年に英国などと同様に金輸出を停止して以来、その状態を解除せず、1920年代を通じて金兌換に依存しない通貨制度へ移行していった。[^u133][^u136]

その理由は、第一次世界大戦で蓄積した**円建ての長期対外債権**と、国内の重工業化に伴う**銀行信用の急拡大**にある。国全体の対外純資産は増えても、代金を円建て債権で受け取るため中央銀行の金準備は増えず、金兌換を再開すれば国内信用の引締めを迫られる。「十分に豊かな債権国であるにもかかわらず、金本位制の下では国内信用を思うように拡大できない」という矛盾が、金本位制離脱を説得力のある選択にした（検討案）。[^u136]

経済が輸入偏重でないため、史実のような「金解禁しなければ日本経済を正常化できない」という議論は政治的な主流にならず、1930年の日本には金解禁を公約とする有力な政治勢力が存在しない。金輸出停止の継続が既定方針である（確定）。[^u137]

# 経過

## 1917〜1930年の通貨制度の推移（検討案）

| 時期 | 通貨制度 |
|---|---|
| 1917年 | 英国などと同様に金輸出を停止。戦時信用供与を拡大 |
| 1918〜1920年 | 円建て対外債権が蓄積。工業化と国内銀行信用が拡大 |
| 1920〜1923年 | 戦後不況と震災に対応し、中央銀行の流動性供給制度を強化 |
| 1920年代中盤 | 金輸出停止の恒久化、発券準備制度の改定を検討 |
| 1930年 | 金本位制復帰を目標とせず、管理通貨制に近い制度を採用 |

[^u136]

1917年の金輸出停止だけでは直ちに完全な管理通貨制へ移行したことにはならない。史実でも金輸出は禁止されたが、金貨兌換の法的な仕組みや正貨準備制度は残り、本格的な移行は1931〜1932年であった。本世界線ではその制度的な切替えが1920年代に前倒しされる。[^u136]

## 関東大震災と金輸出停止の評価

1923年の[関東大震災](/events/great-kanto-earthquake.md)に際し、京都の中央政府は金輸出停止の下で中央銀行による流動性供給や復興公債の発行を行い、信用収縮を抑えつつ建築・鉄鋼・セメント・機械への需要を維持した。この経験から、金輸出停止の柔軟性が有効だと認識される（検討案）。ただし通貨発行で失われた建物や設備が戻るわけではなく、インフレ・為替下落・輸入資材の価格上昇という制約は残る。[^u133][^u137]

## 英国の金本位制復帰（1925年）

英国が1925年に史実どおり金本位制へ復帰した場合、日英間の通貨関係をどう扱うかが問題となる。日本だけが金本位制の外にいれば、復帰した国々との間で決済・為替上の摩擦は避けられない。[^u134] しかし日本には追随しなければならない決定的な理由がなく、1929年の世界恐慌の発生後は、国内の金融政策を拘束する金本位制への復帰に対する反対がさらに強まる（検討案）。[^u137]

# 離脱の論理

## 「円不足」ではなく「金と信用の不均衡」

「対外債権が100億円あれば100億円のマネタリーベースが必要になる」わけではない。円建て戦時信用は次のように形成される（検討案）。[^u136]

1. 英国政府が日本から軍需品10億円分を購入する。
2. 日本の銀行団が英国政府の円建て債権10億円を保有し、輸出企業へ預金で代金を支払う。
3. 国内で企業預金が増え、雇用・設備投資・企業間決済が拡大する。

この段階で10億円の現金を新たに印刷する必要はない。問題はその後で、銀行は換金困難な英仏政府債務を大量に保有しながら、国内の短期決済や預金引出しに対応しなければならず、中央銀行にはそれを支える流動性供給能力が求められる。**金準備の増加速度よりも銀行信用の拡張速度が速いと、金本位制の制約が強く意識される**。代金を金で受け取れば金準備は増えるが、長期の円建て債権で受け取れば金は流入しない。この状況で金兌換を完全に再開すれば、資本流出の局面で中央銀行は金利引上げや信用収縮を迫られる。[^u136]（円建て債権の詳細は[円建て対外債権と円の国際化](/economy/yen-claims.md)を参照）

## 産業政策との衝突

日本は1860年代から工業化を始め、1889年以降は全国交通網を整備し、第一次世界大戦を通じて巨大な工業国家へ成長した。企業の運転資金、設備投資、鉄道建設、造船、海外貿易の信用需要が大幅に拡大し、領主系企業と銀行が全国的な金融市場を形成している。金本位制を厳格に維持すれば海外の金利や金移動に応じて国内金融を引き締めねばならず、工業投資と金融安定を重視する[元老院](/institutions/genroin.md)には受け入れにくい（検討案）。[^u136]

## 金解禁を求める動機の弱さ

史実で金解禁が求められた理由は三つに整理される。[^u134]

1. **為替相場の安定**：円相場の変動が貿易や海外投資を妨げていた。
2. **国際金融市場での信用回復**：金本位制への復帰が健全な通貨・財政運営の証明とされた。
3. **国際金融制度への参加資格**：国際連盟財政委員会や国際決済銀行に関わる制度で、金本位制への復帰が重視された（連盟加盟に法的に必須だったわけではない）。

本世界線ではこれらの動機が変質する。

| 動機 | 本世界線での変化 |
|---|---|
| 為替安定 | 必要性は依然強い（海外資源の輸入、海運、中国投資、英国への信用供与）。ただし旧平価の金本位制復帰が唯一の手段ではなく、金輸出停止のまま対ポンド為替の安定を優先する政策がとれる |
| 国際的信用 | 日本は英仏へ信用を供与した有力な債権国であり、信用を得るために金本位制へ復帰する圧力は弱い |
| 国際金融制度での地位 | 英国は日本の債務者。「日本を参加させるために金解禁を要求するのか、日本の参加を得るために制度側が柔軟になるのか」という交渉力の関係が史実と逆転する |

[^u134]

さらに円建て債権が大きいため、円の国際的地位は既に獲得済みであり、金解禁論は「円の地位を獲得するため」ではなく「その信用を維持するのにどの通貨制度が適切か」という議論になる。[^u135]

## 国際収支の構造

| 指標 | 史実の1920年代日本 | 本世界線の日本 |
|---|---|---|
| 主力輸出 | 生糸・繊維製品など | 機械・鉄鋼・船舶・化学製品・電機など |
| 輸入 | 原料、燃料、機械など | 鉄鉱石、原料炭、石油、綿花など |
| 対外金融 | 債権も持つが国際金融市場での地位は限定的 | 英仏への円建て債権と海外投資が大きく、利息・配当収入も期待できる |
| 為替安定 | 金本位制への復帰が有力な手段と認識された | 金兌換以外の安定策を選ぶ余地が広い |

[^u137]

重要なのは輸入額の大小ではなく、輸出や海外投資所得で支払いを賄えるかどうかである。ただし既存の設定から貿易収支の黒字までは自動的に導けず、設備投資が旺盛なら資本財輸入で赤字になることもある。[^u137]

# 政策の選択肢と政治勢力

## 三つの政策（検討案）

| 政策 | 利点 | 問題 |
|---|---|---|
| 旧平価で金本位制に復帰 | 国際的信用と為替の安定 | 円高・デフレの危険 |
| 新平価で金本位制に復帰 | 実勢に近い為替相場で固定できる | 平価変更に伴う政治・契約上の問題 |
| **金輸出停止を維持** | 金融政策の自由度を保つ | 為替変動と対外信用への対応が必要 |

当初は新平価での復帰と金輸出停止下の為替安定政策が有力とされ、検討が進むにつれて後者に収斂した。[^u134][^u136][^u137]

## 勢力配置

- **元老院の領主系産業資本**（製鉄・造船・鉄道・化学・電力に投資）：旧平価復帰による輸出不振、設備投資の停滞、借入金の実質負担増を警戒し、強く抵抗する。[^u133][^u137]
- **銀行・金融・商社系資本**（英国への債権を持ち海外で事業を展開）：為替安定や国際的信用を求めるが、必ずしも旧平価での金本位制復帰を必要とはしない。[^u134][^u137]
- **国内の銀行・商社・海運会社**：1929年までに為替安定を求める声を強める。[^u134]

（検討案）

# 金に代わる円の信用

金輸出停止は為替の完全な自由放任を意味しない。日本は金兌換・金輸出を停止しつつ、中央銀行が為替安定のために介入する制度をとる（検討案）。[^u133] 1930年の通貨政策は「金輸出停止を継続しながら、円建て貿易と円建て国際借款を発展させ、円相場の安定を外国為替市場への介入や日英間の金融協調によって維持する」と整理される（検討案）。[^u135]

円の価値を支えるのは金兌換だけではなく、日本の工業生産力、対外取引、金融機関の信用、債務者（英国）による円需要である。ただし英国の円需要は償還が進むにつれて減る。[^u137] 海外の銀行にとっては、金に兌換できない円の価値の安定が問題であり、日本の中央銀行や外国為替銀行が円の流動性と為替市場を維持する必要がある。そのための手段として、英国との通貨スワップに相当する相互信用枠、ポンド準備の保有、ロンドンでの円建て手形市場の整備が考えられる（検討案）。[^u136]

金本位制からの離脱は必ずしも通貨価値の不安定を意味しない。財政規律、中央銀行の信用、外国為替市場、国内の生産能力が十分なら、金兌換に依存しない通貨制度は維持できる。ただし輸入原料への依存が大きいため、円相場の急落は工業生産に深刻な打撃を与える。対英ポンド・対米ドルの変動をどう抑えるか、外国人の円資産をどう保護するかは、別途制度化が必要である。[^u136][^u137]

# 影響

- **世界恐慌への対応**：国際需要の減少は避けにくいが、国内の金融収縮や急激なデフレの程度は政府と中央銀行の政策で変わる。日本には旧平価で金解禁することなく、円建て債権の信用を維持しながら国内の金融緩和と産業投資を続ける選択肢がある（検討案）。[^u132][^u135]
- **昭和恐慌の不再現**：1930年まで金輸出停止を継続しているため、史実の昭和恐慌をそのまま再現する必要はない。[^u133]
- **ロンドン海軍軍縮会議**：金解禁のために財政を緊縮するという政策目標が存在しないため、史実の浜口内閣のような「金解禁・緊縮財政・海軍軍縮」の一体政策はない。軍縮の動機は財政均衡そのものではなく、恐慌下の資源配分と日英共同防衛に必要な艦隊編制の合理化となる（検討案）。[^u136][^u137] 詳細は[ロンドン海軍軍縮会議（1930）](/diplomacy/london-naval-conference-1930.md)を参照。

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 1917年 | 金輸出禁止 | 同様に金輸出停止 |
| 1920年代 | 金貨兌換の法的仕組み・正貨準備制度は残存。1928年に大蔵省で発行額の40%を正貨準備とする比例準備制度を検討 | 金輸出停止の恒久化、発券準備制度の改定を前倒しで検討 |
| 1930年1月 | 旧平価で金解禁 | 金解禁なし |
| 1931年12月 | 金輸出再停止 | 該当なし（既に停止中） |
| 管理通貨制への本格移行 | 1931〜1932年 | 1920年代に前倒し |
| 金解禁論の主体 | 浜口内閣、為替安定・国際競争力回復を中心論理とする（日銀『百年史』） | 有力な政治勢力が存在しない |

[^u133][^u134][^u136][^u137]

史実の日銀券発行高は1916年末約6.0億円、1919年末約15.6億円、1920年末約14.4億円であった。発券制度は正貨準備による発行に加え、公債・商業手形などを担保とする保証発行を認めており、すべての紙幣に同額の金準備を必要とする制度ではなかった。戦争景気で金が流入したため当初は増発と正貨準備の増加が並行したが、1920年代には正貨流出を防ぐため保証発行の柔軟性が重要になった。[^u136] 史実の日本は輸入超過が続き、円相場も金平価より安かった。[^u137]

# 未決の論点

- 管理通貨制への移行時期と、発券準備制度改定の具体的内容。[^u136]
- 円の信用を金で保証しない場合の裏付け（中央銀行制度、外貨準備、国際決済市場）と、日英金融協力（相互信用枠・ポンド準備・ロンドン円手形市場）の制度化の程度。[^u135][^u136]
- 1925年に英国が金本位制へ復帰した際の日英通貨関係の扱い。[^u134]
- 1920年代の日本の貿易収支が黒字か赤字か。[^u137]
