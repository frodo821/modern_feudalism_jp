# 概要

本世界線の日本は、1917年に英国などと同様に金輸出を停止した。これは戦時の非常措置であって当初から管理通貨制を意図したものではなかったが、大戦中に経済構造と対外資産構成が大きく変わり、戦前の通貨制度に戻る経済的合理性が失われていった。日本は**1922年に旧平価での金本位制復帰を正式に断念**し、新平価・金為替本位制を模索したのち、**1925年に金本位制への復帰そのものを断念して金平価と銀行券の金兌換義務を法的に廃止し、金輸出入を原則自由化した**。[^e041] 世界恐慌への対応としてではなく、日本独自の経済的事情による離脱である。[^e041]

その事情とは、第一次世界大戦で蓄積した**円建ての長期対外債権**（対英40億円）と、国内の重工業化に伴う**銀行信用の急拡大**である。国全体の対外純資産は増えても、代金を円建て債権で受け取るため中央銀行の金準備は増えず、金兌換を再開すれば国内信用の引締めを迫られる。旧平価に戻すための通貨収縮・円高誘導は、英国など債務国の円建て債務負担も重くする。[^u136][^e041][^e100]

1925年以降、金は通貨発行の法的な裏付けではなく国際決済のための準備資産となり、「金解禁」は金本位制への復帰ではなく単なる金取引規制の撤廃を意味するようになった。そのため1930年の日本には史実のような金解禁論争が起きない。[^u137][^e041] 英国が1931年、米国が1933年に金本位制を離れたとき、日本はすでに管理通貨制の運営経験を積んでおり、1937年までに三国で最長の12年となる。[^e054][^e069]

# 経過

## 通貨制度の確定年表

| 年 | 出来事 |
|---|---|
| 1917年 | 金輸出禁止。金本位制の事実上の停止（戦時非常措置） |
| 1918〜21年 | 戦時・戦後の輸出拡大と対外債権の蓄積 |
| 1922年 | 旧平価での復帰を正式に断念 |

| 1925〜29年 | 管理通貨制の下で為替・信用政策を運営 |
| 1929年 | 世界恐慌の発生 |
| 1931年 | 英国が金本位制を離脱 |

[^e041]

## 1922年：旧平価復帰の断念

1922年はジェノヴァ国際経済会議で戦後の国際通貨体制の再建が議論された年で、日本国内で金本位制への復帰条件を本格的に検討する時期にあたる。[^e041]

| 項目 | 史実の日本 | 本世界線の日本 |
|---|---|---|
| 国際金融上の立場 | 資本輸入の必要性が高い | 大規模な対外債権国 |
| 対外債務・債権 | 外貨建て債務が重要 | 円建て債権が重要 |
| 為替政策 | 国際的信用と相場安定 | 通商・債権決済の安定 |
| 通貨供給 | 金本位制復帰を意識 | 経済成長と信用拡大に対応 |
| 旧平価復帰 | 強い政治的要求 | 経済的合理性が乏しい |

[^e041]

旧平価に復帰するために国内通貨を収縮させ円高を誘導すれば、英国などの債務国が円建て債務を返済する負担が重くなり、国内の輸出産業だけでなく日本の金融機関や英国の取引先からも反対が出る。そこで政府は1922年に旧平価での復帰を正式に断念し、実勢為替相場に基づく新平価の設定を検討した。[^e041]

## 1922〜24年：新平価の模索

この段階では、政府はまだ金本位制そのものを放棄するつもりはなかった。しかし新平価の設定には、戦後の物価・為替相場の未安定、対外債権の規模に応じた円建て信用供給の必要、金準備と国内外の円需要の不一致、英国など主要貿易相手国の通貨制度の未確定、金平価の維持と国内経済の安定の両立の不確実性という障害があった。[^e041]

対外債権が大きいこと自体が金本位制を不可能にするわけではない。問題は、**対外債権の多くが金ではなく商業信用や売掛金として存在し、直ちに金へ転換できない**ことである。ドルなど金に交換可能な外国通貨を準備資産とする金為替本位制も検討されたが、最大の経済協力国である英国がまだ金本位制に復帰していなかったため、新平価による復帰も決断できなかった。[^n1][^e041]

## 1925年の通貨制度改正

1925年は、英国が史実どおり金本位制へ復帰した年である。その年に日本は逆に金本位制への復帰を断念し、国際的潮流に逆行する政策として国内外で相当な論争を呼んだ。[^e041] 日本の主張は金の価値の否定ではなく、**「金と通貨発行量の法的な結びつきを解消し、金を国際決済のための準備資産として保有する」**ことである。[^e041]

| 制度 | 改正内容 |
|---|---|
| 金平価 | 廃止 |
| 銀行券の金兌換義務 | 廃止（停止ではなく廃止） |
| 金貨 | 額面による法定通貨としての通用を終了 |
| 金地金の輸出入 | 原則自由化 |
| 中央銀行の金保有 | 国際決済準備として継続 |
| 外貨準備 | 金・外国通貨・流動性の高い外国資産 |
| 銀行券発行 | 金準備との法定連動を廃止 |
| 為替相場 | 市場相場を原則とし、必要に応じて介入 |

[^e041]

外国の中央銀行や金融機関に対しても円の金兌換を保証しない。その代わり、日本は**円建ての決済能力と金融市場の流動性**によって通貨の信用を維持する。[^e041]

## 「金解禁」の意味の変化

金本位制への復帰を諦めた後では金は単なる外貨準備となり、金解禁の議論は大きく変わった。[^e041]

| | 金本位制下 | 管理通貨制下 |
|---|---|---|
| 金価格 | 法定平価によって固定 | 市場価格で変動 |
| 金輸出 | 通貨制度と直接関係 | 資産・商品の国際移動 |
| 金流出 | 通貨供給の収縮圧力 | 必ずしも通貨供給に影響しない |
| 金輸入 | 通貨発行余力の増加 | 準備資産・商品在庫の増加 |
| 金解禁 | 金本位制への復帰 | 金取引規制の撤廃 |

[^e041]

金が通貨発行の法的な裏付けでなくなったため、国際収支黒字の使い道は「金準備を増やすか、将来必要な資源を確保するか」という経済的判断になった。必要な対外決済準備を確保したうえでの余剰は、資源輸入と海外資源開発へ向けられる（→[戦略資源備蓄制度](strategic-stockpile.md)）。[^e043]

# 管理通貨制の運営

## 中央銀行の運営原則

1925年の段階では現代的なインフレ目標政策は採られず、当時の政策思想に合わせて中央銀行の運営原則は次の三つとされた。[^n1][^e041]

1. 国内物価及び信用秩序の安定
2. 商業・産業活動に必要な通貨及び信用の供給
3. 対外決済能力と為替相場の安定

銀行券の発行高は、金準備による機械的な制限を廃止する代わりに、政府・議会による監督と適格資産を裏付けとする発券制度で律する。「制度としては管理通貨制だが、政策思想としてはかなり慎重な運営」である。[^e041] 発券の思想は商業信用を基礎とする真正手形主義的なもので、商業手形・貿易手形、担保付きの金融機関向け貸出、流動性の高い対外債権、国債など高信用の有価証券、金・外国通貨を裏付け資産とし、「正常な商業活動に伴う通貨需要を満たす発券は健全、政府の経常赤字を補う発券は不健全」と考えられた。[^n1][^e047]

## 財政規律との組み合わせ

金本位制の廃止で解消されたのは中央銀行の金兌換義務であって、政府の予算制約ではない。不換紙幣への不信を払拭するため、1925年の政府はむしろ財政規律を強調し、経常予算は経常収入で賄い、資産形成を伴う事業に限って議会の承認を得て公債を発行し、中央銀行の直接引受は非常時に限るという財政原則を制度化した。[^e047][^e048] 通貨発行の限界は物価と対外決済能力、政府支出の限界は公債消化能力と将来の債務履行能力として区別される。詳細は[1925年財政原則と恐慌期の公共投資](fiscal-principles-1925.md)を参照。

## 1920年代の物価と金融危機

1920年代の日本は戦時物価の調整を緩やかに進めることに大きく成功し[^n2]、急激なデフレで企業や債務者に過大な負担をかけずに物価を安定させた。物価指数（1929年＝100）は1920年114、1925年104、1929年100である。1920〜29年の物価下落は−12.3%（年平均−1.4%）にとどまる。1925年の金本位制廃止は、この物価政策を維持するための制度的な選択としても説明できる。[^e099]

一方、1920年代の金融不安を大規模な信用収縮なしに処理することはできなかった。[^n3] **金本位制からの離脱に成功していても、個々の銀行の経営健全性は保証されない**。1926年に一部銀行の不良債権問題が表面化し、1927年に取り付け・破綻・信用収縮が起こった。[^n4] 危機後には中央銀行の「最後の貸し手」機能の制度化などが改革案として挙がった。[^e099] 詳細は[1927年金融危機（本世界線）](../events/financial-crisis-1927.md)を参照。

## 関東大震災と柔軟性の評価

1923年の[関東大震災](../events/great-kanto-earthquake.md)に際し、京都の中央政府は金輸出停止の下で中央銀行による流動性供給や復興公債の発行を行い、信用収縮を抑えつつ建築・鉄鋼・セメント・機械への需要を維持した。この経験から、金本位制の制約を受けない通貨制度の柔軟性が有効だと認識された。[^n5]ただし通貨発行で失われた建物や設備が戻るわけではなく、インフレ・為替下落・輸入資材の価格上昇という制約は残った。[^u133][^u137]

# 離脱の論理

## 「円不足」ではなく「金と信用の不均衡」

「対外債権が100億円あれば100億円のマネタリーベースが必要になる」わけではない。円建て戦時信用は次のように形成された。[^n5][^u136]

1. 英国政府が日本から軍需品10億円分を購入する。
2. 日本の銀行団が英国政府の円建て債権10億円を保有し、輸出企業へ預金で代金を支払う。
3. 国内で企業預金が増え、雇用・設備投資・企業間決済が拡大する。

この段階で10億円の現金を新たに印刷する必要はない。問題はその後で、銀行は換金困難な英仏政府債務を大量に保有しながら、国内の短期決済や預金引出しに対応しなければならず、中央銀行にはそれを支える流動性供給能力が求められる。**金準備の増加速度よりも銀行信用の拡張速度が速いと、金本位制の制約が強く意識される**。代金を金で受け取れば金準備は増えるが、長期の円建て債権で受け取れば金は流入しない。この状況で金兌換を完全に再開すれば、資本流出の局面で中央銀行は金利引上げや信用収縮を迫られる。[^u136] 大戦期の戦時黒字65億円のうち金・外貨準備等の増加は10億円にとどまり、40億円は円建ての対英売掛債権であった。[^e100]（詳細は[円建て対外債権と円の国際化](yen-claims.md)）

## 産業政策との衝突

日本は1860年代から工業化を始め、1889年以降は全国交通網を整備し、第一次世界大戦を通じて巨大な工業国家へ成長した。企業の運転資金、設備投資、鉄道建設、造船、海外貿易の信用需要が大幅に拡大し、領主系企業と銀行が全国的な金融市場を形成している。金本位制を厳格に維持すれば海外の金利や金移動に応じて国内金融を引き締めねばならず、工業投資と金融安定を重視する[元老院](../institutions/genroin.md)には受け入れにくかった。[^n5][^u136]

## 金解禁を求める動機の弱さ

史実で金解禁が求められた理由は三つに整理される。[^u134]

1. **為替相場の安定**：円相場の変動が貿易や海外投資を妨げていた。
2. **国際金融市場での信用回復**：金本位制への復帰が健全な通貨・財政運営の証明とされた。
3. **国際金融制度への参加資格**：国際連盟財政委員会や国際決済銀行に関わる制度で、金本位制への復帰が重視された（連盟加盟に法的に必須だったわけではない）。

本世界線ではこれらの動機が変質する。

| 動機 | 本世界線での変化 |
|---|---|
| 為替安定 | 必要性は依然強い（海外資源の輸入、海運、中国投資、英国への信用供与）。ただし金本位制復帰が唯一の手段ではなく、市場相場を原則とした介入と対ポンド為替の安定策がとれる |
| 国際的信用 | 日本は英仏へ信用を供与した有力な債権国であり、信用を得るために金本位制へ復帰する圧力は弱い |
| 国際金融制度での地位 | 英国は日本の債務者。「日本を参加させるために金解禁を要求するのか、日本の参加を得るために制度側が柔軟になるのか」という交渉力の関係が史実と逆転する |

[^u134]

さらに円建て債権が大きいため、円の国際的地位は既に獲得済みであり、金解禁論は「円の地位を獲得するため」ではなく「その信用を維持するのにどの通貨制度が適切か」という議論になる。[^u135]

## 国際収支の構造

| 指標 | 史実の1920年代日本 | 本世界線の日本 |
|---|---|---|
| 主力輸出 | 生糸・繊維製品など | 機械・鉄鋼・船舶・化学製品・電機など |
| 輸入 | 原料、燃料、機械など | 鉄鉱石、原料炭、石油、綿花など |
| 対外金融 | 債権も持つが国際金融市場での地位は限定的 | 英仏への円建て債権と海外投資が大きく、利息・配当収入も期待できる |
| 為替安定 | 金本位制への復帰が有力な手段と認識された | 金兌換以外の安定策を選ぶ余地が広い |

[^u137]

国際収支の推計では、1920年代の日本は商品貿易が赤字（1923〜26年累計−11.0億円）で、それを海運収入と海外所得で補い、経常収支は小幅な黒字（同+10.0億円）であった。正式な金本位制離脱で、外貨準備を守るための輸入抑制が要らなくなり、海外からの資本財調達が進んだ。[^e100] 経常黒字の一部は対外債権の積み増しではなく資源の現物蓄積に向けられた。[^e043]

# 1930年代の展開

## 政策の選択肢と政治勢力

1925年に金本位制が廃止されていたため、1930年には金解禁を公約とする有力な政治勢力は存在しなかった。[^u137][^e041] 旧平価での金本位制復帰をめぐる主な勢力の立場は次のとおりである。[^u134][^u136][^u137]

- **元老院の領主系産業資本**（製鉄・造船・鉄道・化学・電力に投資）：旧平価復帰による輸出不振、設備投資の停滞、借入金の実質負担増を警戒し、強く抵抗する。[^u133][^u137]
- **銀行・金融・商社系資本**（英国への債権を持ち海外で事業を展開）：為替安定や国際的信用を求めるが、必ずしも旧平価での金本位制復帰を必要とはしない。[^u134][^u137]

1930〜31年の財政論では、健全財政派・開発財政派・通貨拡張派のうち、1925年改革の経緯から開発財政派が一定の影響力を持ち、通貨拡張派は少数派であった。[^n1][^e047]

## 世界恐慌と英国の離脱（1929〜1931）

国際需要の減少は避けにくいが、国内の金融収縮やデフレの程度は政府と中央銀行の政策で変わる。[^u132] 管理通貨制により、日本は恐慌に際して史実より早く金融緩和を行え、公共投資と資源備蓄で国内の工業需要を作り出せた。[^e047][^e048] 1930〜31年の実質成長率は各年−1.0%、物価指数（1929年＝100）は1930年98、1931年96にとどまり、史実の昭和恐慌は再現されない。[^e099]

1931年の[欧州通貨危機](../events/currency-crisis-1931.md)で英国が金本位制を離脱すると、日本はこれを通貨制度の破綻としてだけではなく「自国が既に経験した制度転換」として捉えた。ポンドが円に対して下落すると英国の円建て債務負担が増えるため、日英の金融協議の主題は**英国の金本位制を救済することではなく、円・ポンド間の為替相場と債務決済を安定させること**になる。[^e041][^e042] 1931年以降の日英通貨協力は、金を介した固定相場ではなく、中央銀行間の信用供与や相互決済制度を中心とする。1931年末には、日英通貨協調圏（円・ポンド）、ドル圏、欧州の金本位制諸国（金ブロック）という三通貨圏が形成され始めた。[^n1][^e041][^e042]

## 三国の金本位制離脱と物価（1933〜1937）

米国の離脱で国際的な金本位制復帰の可能性はさらに遠のいた。1933年のロンドン世界経済会議で日本は、金本位制復帰には消極的、国際為替安定・世界物価回復・関税障壁縮小・国際信用供与には積極的な「国際決済と貿易金融の安定を重視する債権国」として参加した。[^n1][^e054] 日本は三国で最長の管理通貨運営の経験を持ち、金準備以外の指標で政策を判断する慣行が定着している。[^e069]

日本は公共投資で早期にデフレを止め、1933年頃から緩やかなインフレに移った。資源輸入国として国際商品価格の下落の恩恵を受け、公共投資で供給能力も増したので、1925年以来一貫した高インフレではない。[^e069] ただし1937年の時点では日英とも遊休設備・熟練工が減り、軍拡によるインフレ圧力が大きい。[^n1][^e069]

## 1937年の通貨・金融

1937年の中央銀行のバランスシート（GDP比）は、資産が金・外貨準備4%、帝国公債5%、民間手形の再割引・銀行貸出4%、その他2%、負債が発行銀行券・貨幣9%、民間銀行の預け金4%、政府預金1%、自己資本等1%とされる。**金・外貨準備は通貨発行額を直接制約せず**、通貨の増加経路は民間信用の拡大と中央銀行の流動性供給である。経常予算の租税財源原則があるので、管理通貨制が直ちに財政赤字の貨幣化を意味するわけではない。[^e093]

円建て GDP400億円を基準とする1937年の残高は、マネタリーベース52億円（GDP比13%）、M1 124億円（31%）、M2 280億円（70%）、銀行部門総資産360億円（90%）である。[^e099] 円建て国際金融市場は発達し[^n7]、円は東アジア・日英間取引・資源開発金融の国際通貨となったが、ポンドに代わる基軸通貨ではない。[^e085] 1937年の為替相場は1ドル＝2.50円、1ポンド＝12.25円である。[^p092]

# 金に代わる円の信用

金本位制の廃止は為替の完全な自由放任を意味しない。為替相場は市場相場を原則とし、中央銀行が必要に応じて介入する。[^u133][^e041] 円の価値を支えるのは金兌換ではなく、日本の工業生産力、対外取引、金融機関の信用、債務者（英国）による円需要、そして円建て決済能力と金融市場の流動性である。ただし英国の円需要は償還が進むにつれて減る。[^u137][^e041]

海外の銀行にとっては、金に兌換できない円の価値の安定が問題であり、日本の中央銀行や外国為替銀行が円の流動性と為替市場を維持する必要がある。相互信用枠・ポンド準備・ロンドン円手形市場の構想は、1931年以降の日英金融協定案（両中銀の相互通貨信用、協調介入、既存債務の借換え、円・ポンド建て手形の割引制度、相互通貨建て流動資産の保有、金兌換の相互不要求）として具体化された。[^n1][^u136][^e042]

金本位制からの離脱は必ずしも通貨価値の不安定を意味しない。財政規律、中央銀行の信用、外国為替市場、国内の生産能力が十分なら、金兌換に依存しない通貨制度は維持できる。ただし輸入原料への依存が大きいため、円相場の急落は工業生産に深刻な打撃を与える。[^u136][^u137]

# 影響

- **昭和恐慌の不再現**：旧平価での金解禁がないため、史実の昭和恐慌をそのまま再現する必要はない。[^u133] 世界恐慌の影響は1930〜31年の各年−1.0%の成長にとどまった。[^e099]
- **ロンドン海軍軍縮会議**：金解禁のために財政を緊縮するという政策目標が存在しないため、史実の浜口内閣のような「金解禁・緊縮財政・海軍軍縮」の一体政策はない。軍縮の動機は財政均衡そのものではなく、恐慌下の資源配分と日英共同防衛に必要な艦隊編制の合理化であった。[^n5][^u136][^u137] 詳細は[ロンドン海軍軍縮会議と条約（1930）](../diplomacy/london-naval-conference-1930.md)を参照。
- **フーヴァー・モラトリアム**：日本がすでに金本位制の外にいたため、英国に金本位制の維持を求める必要は低い。日本が債権回収を猶予することと英国の金本位制維持は別問題とされた。[^n1][^e040]
