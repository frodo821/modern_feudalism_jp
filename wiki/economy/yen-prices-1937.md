# 概要

本世界線の日本は1925年に金平価と金兌換を法的に廃止して以来、金本位制に復帰していない（[金本位制離脱と管理通貨制](/economy/gold-standard.md)を参照）。[^e041][^p091] 1937年の円相場は、日本銀行と帝国政府の為替介入・金融政策によって管理される**管理相場**であり、その水準は**1ドル＝2.50円（1円＝0.400ドル）、1ポンド＝12.25円**と設定された。史実の1937年（年平均1ドル＝約3.47円）と比べ、1円当たりのドル価値が約39%高い。[^p092] 対ドル相場は1937年の確定値表に入っている。[^p097]

この相場で名目GDP400億円を換算すると160億ドルで、米国の名目GDP（930.03億ドル）の約17.2%にとどまる。一方、実質GDPは米国の27%（購買力平価換算251.1億ドル相当）を基準とし、購買力平価の換算係数は1ドル＝約1.59円、日本の対米相対物価水準は約63.7%となる。外国為替市場では1円で0.40ドルしか買えないが、国内では平均して約0.63ドル相当の財・サービスが買える、というモデルである。[^p092]

列強との比較では、本世界線の日本の実質経済規模は米国の27%、英国本国の約76%、フランスの約116%で、「国家としての工業力・経済力は列強上位に近づいているが、国民の平均生活水準は英米にまだ及ばない」段階にある。[^p092] 為替相場・購買力平価は既定の経済指標との整合を重視したモデル上の設定で、貨幣供給量・金準備・国際商品価格から一意に算出したものではない。[^p092]

経常収支の黒字は円高圧力になるが、海外への積極的な資本輸出によってある程度相殺される。1920年代の物価調整にクリティカルで成功したことから、急激なデフレや大幅な切下げを経ずに通貨価値を安定させてきたと考えられる。[^p092]

都市部の4人世帯の月間支出は次のように想定される。女性の非農業部門への就業拡大が判定で失敗しているため、主たる稼得者1人の所得に家族の副収入を組み合わせる家計が一般的である。[^p092]

|---|---:|---:|

| 光熱・燃料 | 5円 | 6.9% |

| 交通・通信 | 4円 | 5.6% |
| 教育・医療 | 4円 | 5.6% |
| 租税・社会保険等 | 3円 | 4.2% |
| その他支出 | 6円 | 8.3% |

（有力案）[^p092]

一般工場労働者1人の給与（月40〜65円）だけではこの水準の維持が難しい場合もあり、熟練工や技術者の世帯では一定の貯蓄が可能になる。これは「預貯金の普及と持家取得の不振」という既存の判定と整合する。[^p092] 就業構造と住宅事情は[1937年の就業構造と社会（労働・教育・住宅・人口）](/economy/labor-society-1937.md)を参照。

# 列強との実質経済力比較

比較基準には、Mark Harrison 編『The Economics of World War II』の史実1938年の購買力調整済みGDPを用い、日本には本世界線の対米27%を当てはめる。1938年の本世界線経済を新たに設定するものではない。[^p092]

| 国（米国＝100） | 実質経済規模 | 本世界線日本との比 |
|---|---:|---:|
| 米国 | 100 | 日本は27% |
| ソ連 | 44.875 | 日本は約60% |
| ドイツ（オーストリア除く） | 43.875 | 日本は約62% |
| 英国本国 | 35.5 | 日本は約76% |
| **本世界線の日本（1937）** | **27** | ― |
| フランス | 23.25 | 日本は約116% |
| 史実の日本 | 21.125 | 日本は約128% |
| イタリア | 17.625 | 日本は約153% |

[^p092]

日本は米国・ソ連・ドイツ・英国には及ばないが、フランスを上回る経済大国となる。英国は本国のみの比較で、英帝国全体の資源・市場・金融力とは区別する必要がある。[^p092] 植民地経済の全面的な合算は行っていない。[^p092]

# 円の国際的地位と金融政策

## 円の地位

第一次世界大戦以降に円建ての対外商業債権が蓄積し、国際金融業に成功した領主系・独立系銀行が存在するため、円は国内通貨以上の役割を持つ（[円建て対外債権と円の国際化](/economy/yen-claims.md)を参照）。[^p092]

| 通貨の機能 | 1937年の円の地位 |
|---|---|
| 国内決済通貨 | 確立 |
| 日朝貿易の決済通貨 | 有力 |
| 日中貿易の決済通貨 | 一部で普及 |
| 東アジアの貿易信用 | 有力 |
| 英国との長期債権契約 | 一部円建て |
| 国際的な外国債券発行通貨 | 限定的に発達 |
| 世界的な準備通貨 | ポンド・ドルには及ばない |

（有力案）[^p092]

円はポンドやドルと同等の世界通貨ではなく、東アジアの地域的な国際決済通貨として発展し、その信用を英米との金融関係が支える。会話ログ2の判定（出目68）で円建て国際金融・貿易決済市場の発達が成功していることと整合する。[^p092][^e085]

## 金融政策の基本構造

| 項目 | 制度 |
|---|---|
| 金兌換 | 停止 |
| 為替制度 | 管理相場 |
| 対ポンド関係 | 重視するが厳密な固定相場ではない |
| 為替介入 | 日本銀行・帝国政府が実施 |
| 外貨準備 | ポンド・ドル・金などに分散 |
| 海外投資 | 原則として可能 |
| 通貨供給 | 国内の信用・物価・景気を考慮して調整 |

[^p092]

円建て対英債権の蓄積に対応する通貨供給の拡大と、国際的な円の信用維持を両立させる構造である。[^p092] 「金兌換を停止した管理通貨制度」はP97で確定した制度・社会構造の一つに数えられる。[^p097]

# 却下・修正された案

- **実質GDP対米比 28.0% → 27%**：会話ログ2では1937年米国価格基準の共通価格評価でGDP 260.26億ドル相当（対米28.0%、範囲26〜28%）とされていた。[^e097][^e098] 会話ログ3はこの範囲の中間値27%（購買力平価換算251.1億ドル相当）を基準とし、P97の確定値表も27%を採る。旧推計（会話ログ2）28.0% → 確定値（会話ログ3）27%。[^p092][^p097]
- **対英本国比 97.1% → 約76%**：会話ログ2の共通価格評価では日本のGDPは英国本国の97.1%（英国本国は対米28.8）とされたが、会話ログ3はHarrisonの史実1938年値（英国本国＝対米35.5）を基準にし、日本は英国本国の約76%となった。比較基準の違い（1937年の1980年国際ドル推計 → 1938年の購買力調整済み推計）による。[^e097][^p092]
- **為替相場は未設定（会話ログ2）**：会話ログ2では共通価格評価と円建てGDPの比から為替相場は導けないとして、円・ポンド・ドルの相場は未決のまま残されていた。会話ログ3で1ドル＝2.50円・1ポンド＝12.25円と設定され解決した。[^e103][^p092]
- **円安案（1ドル＝2.80円）・円高案（2.20円）**：基準案と並べて比較されたが採用されなかった。[^p092]

# 未決の論点

- 列強比較は史実1938年の参考値を用いており、厳密な1937年同士の比較には修正の余地がある。[^p092]
- 為替相場・購買力平価はモデル上の設定で、史実の商品価格・為替との詳細な比較は未了。[^p092][^p096]
- 職業別所得、商品価格、家計は設定案であり、家計調査に相当する積算ではない。[^p092]
- 1938年以降の為替・物価の推移は保留。[^p097]
