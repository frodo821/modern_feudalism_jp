# 概要

1937年の本世界線日本のサービス部門は、「**企業間取引・国際取引を担う近代的部門**」と「**個人経営中心の伝統的部門**」が併存する二重構造を持つ。[^e085] 海運・総合商社・通信網・円建て国際金融といった国際的な部門はダイス判定でおおむね成功し、通信網はクリティカルとなった。一方で小売業の大規模化は失敗し、個人・家族経営の商店が売上の65%を占める。[^e085][^e092]

金額は特記のない限り1937年米国価格基準の共通価格による「億ドル相当」で、為替換算額ではない（1937年の名目GDPは約400億円、共通価格では260.26億ドル相当）。[^e097][^e099] 最終積算（E97）では、運輸18.65・通信郵便2.69・卸売9.16・小売21.46・金融4.81・保険1.82・不動産住宅14.03の計72.62億ドル相当（金融仲介サービスの追加控除−2.08億ドルを除く）で、国内純付加価値の約3分の1にあたる。[^e097]

当初の就業者・生産性方式（E86）は第三次産業を過大に見積もっており、以後の検証で輸送量・運賃、商業マージン、金融仲介サービス（FISIM）など物的・取引量ベースの積算に置き換えられた。卸売・金融・海運の付加価値は大きく下方修正され、小売は上方修正された。[^e087][^e091][^e092][^e093]

# 運輸

## 海運

商船隊900万総t（確定値）は外航600万総t・内航300万総tに分かれる。[^e091] 用途別には一般貨物船360、ばら積み・鉱石船190、タンカー150、貨客船・客船90、沿岸・特殊用途110万総t。[^e084] 推進機関は石炭焚き蒸気船45%、重油焚き蒸気船30%、ディーゼル船25%で、船舶用石油は約310万t。[^e089]

外航の航路別配分は、東アジア近海200万総t（年14航海、3,136万t）、東南アジア・豪州200万総t（7回、1,568万t）、インド洋・中東70万総t（4回、314万t）、欧州・大西洋80万総t（3回、269万t）、太平洋横断等50万総t（4回、224万t）で、計約5,500万tを運ぶ。内訳は輸入3,500万t、輸出1,000万t、第三国間1,000万t。日本の輸入貨物の約52%を日本船が、残りを英国船などの外国船が運ぶ。内航は4,800万t（平均650km、312億t-km）。[^e091]

造船の合理化には失敗したが海運の運用は成功しており、建造能力と運用能力は別物である。第三国間輸送は重量では18%だが長距離が多く、外航運賃収入の約30%を占める（豪州→英国の資源輸送、インド→東南アジア、中国↔欧州など）。これは[日英海上通商防衛協定](/diplomacy/anglo-japanese-maritime-defense-agreement.md)が世界的な適用範囲を持つことの経済的背景でもある。[^e085][^e091]

海運の総収入は7.55億ドル（外航6.05億、内航1.50億）、燃料・港湾・修繕・保険等を引いて純付加価値**3.75億ドル**、就業者25万人（外航船員7.2万、内航船員9.0万、交代・予備3.8万、陸上職員5.0万）。海運関連の国際収支は純受取約1.0億ドルである。[^e091]

[^e091] 鉄道は輸送仕事量の約70%が電化区間で行われ、純付加価値6.76億ドル・就業者62万人。[^e091] 交通網の形成史は[帝国交通整備計画](/economy/transport-plan.md)を参照。

自動車は保有250万台（自家用乗用車125万、営業用乗用車20万、貨物85万、バス8万、その他12万）で、人口1,000人当たり約32台。都市の中間所得層に自家用車が普及し始め、販売・修理・燃料販売・保険・駐車場・道路貨物輸送のサービス業が成立した。[^e084] 貨物自動車の55%が営業用運送会社の保有で、道路輸送業（営業用貨物・タクシー・バス）の純付加価値は5.39億ドル、就業者100万人（当初75万人から上方修正）。[^e091]

国内貨物輸送仕事量1,031億t-kmの分担は、鉄道43.6%、内航30.3%、自動車24.2%、河川その他1.9%で、1937年時点で自動車物流が相当普及した社会である。鉄道と自動車の連携は「ぎりぎりの成功」のため、全国的に統合された物流網ではなく地域ごとの実用的な複合輸送網にとどまり、競争も残る。[^e085][^e091]

港湾はクレーン・鉱石石炭専用設備・ベルトコンベヤー・石油桟橋・冷蔵倉庫・工業地帯への鉄道直結で機械化されたが、コンテナはなく、木箱・袋・樽・パレットの規格化と機械荷役が中心である。大規模工業港は専用荷役、地方港は人力荷役が残る。港湾・倉庫の純付加価値2.60億ドル、就業者38万人。民間航空は純付加価値0.15億ドル・就業者2万人の小産業である。[^e084][^e091]

# 通信

通信網のクリティカルは、設備の普及だけでなく、領国間の接続規格・料金精算・通信事業者間の相互接続制度の整備まで成功したことを意味する。「通信機器の技術大国ではないが、通信インフラの利用では世界有数の先進国」である。[^e085]

| 時期 | 発展 |
|---|---|
| 1900〜1914年 | 都市間電信・電話網の整備 |
| 1914〜1920年 | 国際通商拡大による需要急増 |
| 1920〜1929年 | 自動電話交換機・長距離電話網の普及 |
| 1930〜1937年 | 全国通信網の統合・家庭への普及 |

[^e085]

1937年の電話機は600万台（人口100人当たり7.7台、米国1,945万台・15.1台の約半分）、ラジオ受信契約1,000万件（家庭普及率約60%）、都市部の電話交換自動化率80%、外航船のほぼ全船に無線設備がある。[^e085][^e094] 高性能無線設備は外国依存で、海底電線は英国系通信会社と協力する。[^e084] 電話・電信・放送の純付加価値は2.34億ドル・就業者16万人で、料金収入主体の公営事業体である郵便（5万人・0.35億ドル）を加えて通信・郵便計2.69億ドル・21万人。[^e094][^e095][^e097] 通信網は物流の配車・配船、金融決済、商業の発注、帝国と領国間の行政事務にも波及した。[^e085][^e095]

# 商業

## 卸売業と総合商社

流通構造は「**大規模な卸売企業が多数の独立小売商を支える**」形である。大手商社・全国卸売業者が大量調達・輸入・在庫管理を担い、地方卸売業者・専門問屋が小口配送と信用供与で個人商店・百貨店・連鎖店・生協へつなぐ。通信網のおかげで地方の小売店も電話・電信で大手卸から仕入れられる。[^e092]

総合商社は資源輸入（石炭・鉄鉱石・原油・木材・繊維原料）、工業製品輸出（鉄鋼・重電・化学・非鉄）、海外設備調達（工作機械・精密機器・無線機器）、海外資源開発（鉱山・油田・農園への資本参加）、第三国間貿易、円建て手形による貿易金融、海運・鉄道・保険との物流手配を一体で扱う。英国系企業との共同事業や中国のコンセッションへの進出で史実以上に大規模で、日本と無関係な外国企業同士の取引でも日本の商社・銀行が使われる。[^e084][^e092]

卸売の年間取扱額136億ドル（食料・消費財の第一次卸45、二次卸42、工業原料24、輸出入15、第三国間10）に対し、商業マージン方式で総産出13.47億、純付加価値**9.16億ドル**、就業者85万人（うち総合商社・貿易商社8万人）。「総合商社の国際競争力と、卸売業全体の付加価値が米国の8割に達することは別問題」とされた。[^e092]

# 金融・保険・不動産

## 円の国際的地位

円建て国際金融市場の発達は成功し、円は東アジアを中心とする有力な国際取引通貨となった。ただしポンドに代わる基軸通貨ではない。役割分担は、ポンドが世界的な貿易金融・決済、ドルが米州、円が東アジア・日英間取引・資源開発金融である。日本国内には外国銀行・金融拠点が多数あり、円・ポンドの為替市場が発達している。[^e085] 背景となる1925年の金本位制廃止と管理通貨制は[金本位制離脱と管理通貨制](/economy/gold-standard.md)、対外債権の形成は[円建て対外債権と円の国際化](/economy/yen-claims.md)を参照。

## 金融業・保険業の付加価値

「金融資産の大きさ」と「金融サービスの付加価値」は区別される。FISIM方式で、貸出・預金仲介、為替・決済手数料、証券仲介、信託手数料などから金融業純付加価値をGDPの1.85%（最終4.81億ドル）とした。日本の金融力はGDP寄与よりも、国内外の資本蓄積、資金調達能力、海外所得の安定性に現れる。[^e093][^e097]

保険料収入はGDP比3.70%（生命・年金2.20、火災・財産0.55、海上・貨物0.45、自動車0.25、傷害その他0.25）。国内生命保険の95%、火災・財産の90%、日本船舶・貨物の元受海上保険の75%を国内会社が扱うが、日本関係以外の海上保険は限られ、巨額リスクの再保険はロンドン市場に頼る。海上保険・再保険の「ぎりぎりの成功」の具体化であり、日英間では保険サービスの輸入が続く。保険業純付加価値1.82億ドル。[^e085][^e093][^e097]

## 不動産・住宅

1,700万世帯の住宅は都市持家450万、都市借家550万、農村持家550万、農村借家100万、社宅等50万で、持家率は約59%。家賃・帰属家賃の総産出15.05億ドルから住宅サービス純付加価値10.53億ドル、商業用賃貸・仲介・管理3.50億ドルを加え不動産部門は14.03億ドル。領主家の農地貸付の地代は農業所得の分配として扱い、不動産業には重複計上しない。[^e093]

金融・保険・不動産の就業者は中央銀行1万、商業銀行24万、長期信用5万、証券4万、信託等6万、生命保険8万、損害保険6万、不動産22万の計76万人。通信網のクリティカルが事務・決済人員を抑えている。[^e093]

# 民間サービス

飲食・宿泊、修理、理美容・洗濯、家事使用人、専門職、民間医療・教育、娯楽からなる民間サービスは、当初310万人・12.82億ドルと積算され、社会構造判定（生活関連サービス市場の拡大成功、労働時間短縮クリティカル）を受けて340万人・14.02億ドルとなった。自動車修理だけで約2億ドル、外食は一人当たり年40回とされる。[^e094][^e096][^e097] 女性の非農業就業のファンブルにより、家事代行・保育サービスの大幅拡大は想定しない。[^e096] 労働時間・余暇消費については[1937年の就業構造と社会](/economy/labor-society-1937.md)を参照。

国際収支では、サービス収支が+1.50億ドル（海運・港湾+1.00、商社・取引仲介+0.40、金融・国際決済+0.30、保険・再保険−0.10、旅行・通信その他−0.10）で、一次産品の大量輸入による財の貿易赤字を海運・国際商業・海外投資所得で埋める構造をとる。[^e098] 詳細は[国際収支と対外資産（1914〜1937）](/economy/balance-of-payments.md)を参照。

# 史実との比較

* 史実1937年の日本の鉄道輸送は貨物182.5億t-km・旅客290.5億人-kmで、本世界線はその2〜2.5倍。[^e091]
* 史実米国1939年の商業センサスでは小売販売額約420億ドル・店舗177万、小売マージン加重平均29.7%。独立店と連鎖店のマージン差は小さい。[^e092]
* 史実米国1937年の商業銀行総資産は560億ドル（GDP比62%）、貸出172億ドル（19%）。本世界線日本は貸出比率が高く、公共投資・設備投資・海外資源開発の継続を反映する。[^e093]
* 史実英国1937年の海運純受取は1億3,000万ポンド。[^e091]

# 却下・修正された案

* **就業者・生産性方式による第一次積算（E86）**：海運対米85%、卸売85%、金融85%などの生産性を就業者数に掛けた結果、第三次産業が国内純付加価値の過半を占めた → 輸送量・商業マージン・FISIMによる積算に置き換え（E91〜E93）。卸売は29.52→9.16億、金融は13.80→4.81億、海運は7.30→3.75億ドルへ下方修正、小売は14.91→21.46億へ上方修正（合理化失敗で独立店舗のサービス付加価値が多い）。[^e086][^e091][^e092][^e093]
* **外航の初期案（年4航海・2,700万t）**：自国船の輸入輸送比率が25%程度にとどまり海運大国として低すぎるため、航路別の配分（5,500万t、自国船比率約52%）に修正。[^e091]
* **国内貨物分担率（E85：鉄道50・内航32・自動車15%）** → 輸送仕事量の積算で鉄道43.6・内航30.3・自動車24.2%に修正。[^e085][^e091]
* **道路輸送用石油180万t**：保有250万台の車種別走行距離・燃費と合わないため530万tに上方修正（→[エネルギー需給と電化](/economy/energy-1937.md)）。[^e089]
* **住宅賃貸サービス13.50億ドル（E86の暫定値）** → 住宅ストックからの積算で10.53億ドル。[^e086][^e093]

# 未決の論点

* 商品別小売販売額・卸売取扱額・店舗数・中間投入率は仮定で、家計消費・貿易総額の確定後に再調整を要する。[^e092]
* 航路別運賃・積載率・道路輸送の原単位、海運国際収支のFOB統一後の再計算。[^e091]
* 金融資産の残高は1920年以降の通貨供給推移からの積算ではなく、ダイス結果から数値化した仮定である。金融仲介サービスの中間投入配分にも重複の不確実性が残る。[^e093][^e097]
* 外国人旅行者からの宿泊収入の分離。[^e095]
