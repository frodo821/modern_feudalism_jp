# 概要

1937年の本世界線日本のサービス部門は、「**企業間取引・国際取引を担う近代的部門**」と「**個人経営中心の伝統的部門**」が併存する二重構造を持つ。[^e085] 海運・総合商社・通信網・円建て国際金融といった国際的な部門はダイス判定でおおむね成功し、通信網はクリティカルとなった。一方で小売業の大規模化は失敗し、個人・家族経営の商店が売上の65%を占める。[^e085][^e092]

1937年の確定値では、商船隊900万総t（外航640万総t）が貿易貨物5,400万tの約70%を運び、三国間輸送にも進出する。民間商船の年間建造量は75万総tで、建造工程の合理化には失敗した（個別受注生産が中心）ものの、独立系造船・重機械工業のクリティカルがその担い手となる（作者確定）。鉄道は帝国・領国・民間が並立する営業距離45,000km（電化13,500km）、自動車等保有は133万台で、一般家庭への普及よりも企業・商業・貨物・公共交通の利用が先行している（年産は1937年に30万台へ急増したばかりで、保有が追いついていない。作者確定）。全国の港湾取扱量は2億2,400万tに達する。[^p090][^p096][^p097]

第三次産業は1937年にGDPの34%（136億円）・就業者の27.8%（895万人）を占める。内訳は交通・通信28億円（170万人）、卸売・小売36億円（280万人）、金融・保険16億円（60万人）、不動産16億円（25万人、帰属家賃を含む）、公務・教育・医療28億円（230万人）、その他サービス12億円（130万人）である。[^p087][^p096] 会話ログ2では1937年米国価格基準の共通価格評価（億ドル相当）で積算され、商船の外航600・内航300万総t、鉄道32,000km、自動車250万台などとされていたが、会話ログ3（P90・P96・P97）の確定値に置き換えられた（→「却下・修正された案」節）。

## 造船

民間商船の年間建造量は**75万総t**で、内訳は国内商船の更新36万総t（更新率4%、平均25年周期）、純増24万総t、輸出向け15万総tである。資本別には独立系華族45万総t、領主系22.5万総t、非華族3.75万総t、公営等3.75万総t。軍艦は別の指標で、ここには含めない。[^p090] 新造船輸出15万総tは0.75億円の財貨輸出となる。[^p090][^p091] 民間造船向けの鋼材は100万tである。[^p089]

造船については二つの判定がある。造船所の建造工程合理化・船型標準化は失敗し（ダイス判定：難易度25、出目18・失敗）、日本の造船業は個別受注生産に強く同一船型の大量建造は苦手なままである。[^e083] 一方、独立系資本が造船・重機械工業で全国的な地位を確立する判定はクリティカルとなった（ダイス判定：難易度25、出目97・クリティカル）。[^p084] 前者は「どう造るか」（工程）、後者は「誰が担うか」（資本系統と市場での地位）の判定であり、両者は両立する（作者確定）。年75万総tという建造量も、会話ログ2の段階で合理化失敗を前提に想定されていた値である。[^e089][^p090]

| 帝国鉄道 | 全国幹線・領国間輸送 |
| 領国・民間鉄道 | 地域産業・都市間・近郊輸送 |
| 貨物自動車 | 短距離輸送・工場と駅や港の連絡 |
| バス・路面電車 | 都市・地方の旅客輸送 |
| 航空 | 郵便・旅客・高付加価値貨物 |

[^p090]

鉄道と自動車の連携は「ぎりぎりの成功」（出目31）のため、全国的に統合された物流網ではなく、地域ごとの実用的な複合輸送網にとどまり、競争も残る。[^e085][^e091]

# 通信

通信網のクリティカルは、設備の普及だけでなく、領国間の接続規格・料金精算・通信事業者間の相互接続制度の整備まで成功したことを意味する。「通信機器の技術大国ではないが、通信インフラの利用では世界有数の先進国」である。[^e085]

| 時期 | 発展 |
|---|---|
| 1900〜1914年 | 都市間電信・電話網の整備 |
| 1914〜1920年 | 国際通商拡大による需要急増 |
| 1920〜1929年 | 自動電話交換機・長距離電話網の普及 |
| 1930〜1937年 | 全国通信網の統合・家庭への普及 |

[^e085]

会話ログ2では、1937年の電話機600万台（人口100人当たり7.7台）、ラジオ受信契約1,000万件（家庭普及率約60%）、都市部の電話交換自動化率80%、外航船のほぼ全船に無線設備とされた。[^e085][^e094] 高性能無線設備は外国依存で、海底電線は英国系通信会社と協力する。[^e084] 通信網は物流の配車・配船、金融決済、商業の発注、帝国と領国間の行政事務にも波及した。[^e085][^e095] 会話ログ3では交通・通信を合わせて付加価値28億円・就業者170万人とされる。[^p087]

# 商業

## 卸売業と総合商社

流通構造は「**大規模な卸売企業が多数の独立小売商を支える**」形である。大手商社・全国卸売業者が大量調達・輸入・在庫管理を担い、地方卸売業者・専門問屋が小口配送と信用供与で個人商店・百貨店・連鎖店・生協へつなぐ。通信網のおかげで地方の小売店も電話・電信で大手卸から仕入れられる。[^e092]

総合商社は資源輸入（石炭・鉄鉱石・原油・木材・繊維原料）、工業製品輸出、海外設備調達（工作機械・精密機器・無線機器）、海外資源開発への資本参加、第三国間貿易、円建て手形による貿易金融、海運・鉄道・保険との物流手配を一体で扱う。英国系企業との共同事業や中国のコンセッションへの進出で史実以上に大規模で、日本と無関係な外国企業同士の取引でも日本の商社・銀行が使われる。[^e084][^e092] 会話ログ3では、領主系総合商社の担い手として、近江商人との共同出資で繊維専門商社から発展した井伊家系と、船を持たない商品取引・資源調達型の山内家系が具体化された。三井系商社は井伊系・徳川系と並ぶ商業金融の競争主体である。[^p053][^p056][^p086]

「総合商社の国際競争力と、卸売業全体の付加価値が米国の8割に達することは別問題」とされた。[^e092]

# 金融・保険・不動産

## 円の国際的地位

円建て国際金融市場の発達は成功し（出目68）、円は東アジアを中心とする有力な国際取引通貨となった。ただしポンドに代わる基軸通貨ではない。ポンドが世界的な貿易金融・決済、ドルが米州、円が東アジア・日英間取引・資源開発金融を担う。[^e085] 会話ログ3では円の地位が次のように整理された（検討案）。[^p092]

| 通貨の機能 | 1937年の円の地位 |
|---|---|
| 国内決済通貨 | 確立 |
| 日朝貿易の決済通貨 | 有力 |
| 日中貿易の決済通貨 | 一部で普及 |
| 東アジアの貿易信用 | 有力 |
| 英国との長期債権契約 | 一部円建て |
| 国際的な外国債券発行通貨 | 限定的に発達 |
| 世界的な準備通貨 | ポンド・ドルには及ばない |

円は東アジアの地域的な国際決済通貨で、その信用を英米との金融関係が支える。1937年の相場は1ドル＝2.50円・1ポンド＝12.25円の管理相場である。[^p092][^p097] 背景となる1925年の金本位制廃止と管理通貨制は[金本位制離脱と管理通貨制](/economy/gold-standard.md)、対外債権の形成は[円建て対外債権と円の国際化](/economy/yen-claims.md)を参照。

| マネタリーベース | 13% | 52億円 |

[^e093][^e099] 金利は国内企業向け平均貸出5.5%、預金平均2.5%、長期公債3.5〜4.0%、優良社債4.0〜5.0%。[^e093] 領主家の保有株式は大部分が非上場・非流通で、上場時価総額だけでは資本蓄積を測れない（検討案）。[^e093]

金融は銀行中心の間接金融で、一般国民の貯蓄は銀行預金・郵便貯金・信用組合に集中し（預貯金の普及：難易度25、出目78・成功）、金融機関を通じて大企業融資・政府公債・中小企業・農業金融へ回る。一般市民の株式・社債への直接投資は普及しなかった（難易度55、出目19・失敗）。[^p085][^p096] 会話ログ3では金融・保険の付加価値16億円・就業者60万人（就業者1人当たり2,667円）とされる。[^p087]

## 金融業・保険業の付加価値（会話ログ2）

「金融資産の大きさ」と「金融サービスの付加価値」は区別される。FISIM方式で、貸出・預金仲介、為替・決済手数料、証券仲介、信託手数料などから金融業純付加価値をGDPの1.85%とした。日本の金融力はGDP寄与よりも、国内外の資本蓄積、資金調達能力、海外所得の安定性に現れる。[^e093][^e097]

保険料収入はGDP比3.70%（生命・年金2.20、火災・財産0.55、海上・貨物0.45、自動車0.25、傷害その他0.25）。国内生命保険の95%、火災・財産の90%、日本船舶・貨物の元受海上保険の75%を国内会社が扱うが、巨額リスクの再保険はロンドン市場に頼る。[^e085][^e093] 1937年のサービス収支では、保険・金融サービスが受取0.80億円・支払0.50億円で純＋0.30億円である。[^p091]

## 不動産・住宅

不動産部門は帰属家賃を含んで付加価値16億円・就業者25万人で、就業者1人当たりGDPが6,400円と高い。[^p096] 都市住宅の所有形態は、持家22%、民間借家60%、企業・家門等の提供住宅11%、公営・共同住宅等7%で、都市中間層は所得面で成長しても不動産による資産蓄積は限られる（都市勤労者の持家取得：難易度50、出目22・失敗）。京都・大阪・江戸の都市不動産は旧公家・領主家・非華族地主・企業が保有する。[^p085] 都市4人世帯の家計では家賃が月13円（18.1%）を占める。[^p092] 領主家の農地貸付の地代は農業所得の分配として扱い、不動産業には重複計上しない。[^e093]

# 民間サービス

飲食・宿泊、修理、理美容・洗濯、家事使用人、専門職、民間医療・教育、娯楽からなる民間サービスは、会話ログ2では社会構造判定（生活関連サービス市場の拡大成功、労働時間短縮クリティカル）を受けて340万人とされた。[^e094][^e096][^e097] 女性の非農業就業のファンブルにより、家事代行・保育サービスの大幅拡大は想定しない。[^e096] 会話ログ3では「その他サービス」は付加価値12億円・就業者130万人（当初100万人から就業者総数の整合のため修正）で、公務・教育・医療が28億円・230万人である。[^p087][^p096]

国内生活関連サービス市場の拡大（ダイス判定：難易度30、出目47・成功）が「民間サービスが雇用を吸収する」というのは、都市へ流入した人口を失業なしに吸収したことを指す（失業率約2.4%）（作者確定）。[^e096] 全国の第三次産業比率27.8%が低く見えるのは、農家の女性などの家族従業者が農業就業者に数えられるためで、都市部に限ればサービス業が最大の雇用先である（作者確定）。[^p087] 華族家門が雇う使用人（家門支出に含まれる使用人の給与・給付）もサービス雇用に含める（作者確定）。[^p071][^p072] 労働時間・余暇消費については[1937年の就業構造と社会](/economy/labor-society-1937.md)を参照。

# 史実との比較

* 史実1937年の日本の鉄道輸送は貨物182.5億t-km・旅客290.5億人-kmで、本世界線（貨物540億t-km・旅客1,000億人-km）はその約3倍。[^e091][^p090]

## 会話ログ2内部で修正された案

* **就業者・生産性方式による第一次積算（E86）**：海運対米85%、卸売85%、金融85%などの生産性を就業者数に掛けた結果、第三次産業が国内純付加価値の過半を占めた → 42.2%案の保留（E87）を経て、輸送量・商業マージン・FISIMによる積算に置き換え（E91〜E93）。[^e086][^e087][^e091][^e092][^e093]
* **外航の初期案（年4航海・2,700万t）**：自国船の輸入輸送比率が25%程度にとどまり海運大国として低すぎるため、航路別の配分（5,500万t、自国船比率約52%）に修正（さらに会話ログ3で約70%）。[^e091][^p090]
* **国内貨物分担率（E85：鉄道50・内航32・自動車15%）** → 輸送仕事量の積算で鉄道43.6・内航30.3・自動車24.2%に修正。[^e085][^e091]
* **道路輸送用石油180万t**：保有250万台の車種別走行距離・燃費と合わないため530万tに上方修正 → 会話ログ3では道路用石油200万tから保有133万台を逆算。[^e089][^p089][^p090]
* **住宅賃貸サービス13.50億ドル（E86の暫定値）** → 住宅ストックからの積算で10.53億ドル。[^e086][^e093]

# 未決の論点

* 航路別距離・船速による海運能力の検証は行われていない。軍艦などの自航船舶の輸出は貨物重量に含まない。[^p090]
* 共同出資の海運会社（日本海運聯合など）と企業集団別保有量の対応。[^p086][^p090]
* 小売・卸売の内訳（店舗数・就業者）の会話ログ3の就業者280万人への組替え、商品別の販売額。[^e092][^p087]
* 金融資産残高は1920年以降の通貨供給推移からの積算ではなく、ダイス結果から数値化した仮定である。[^e093][^e097]
* 外国人旅行者からの宿泊収入の分離（旅行サービスの受取0.40億円）。[^e095][^p091]
* （作者確定で解決）造船の評価の食い違い：建造工程の合理化失敗（E83）と独立系造船・重機械工業のクリティカル（P84）は別の軸の判定として両立する。[^e083][^p084]
* （作者確定で解決）生活関連サービスによる雇用吸収（E96成功）と第三次産業比率27.8%との関係：吸収は都市流入人口の失業なき吸収を指し、比率の低さは農業に数えられる家族従業者の多さによる。[^e096][^p087]
