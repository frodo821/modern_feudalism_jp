# 概要

1937年の本世界線日本の製造業は、「**大型設備を用いた素材生産と規格化された工業製品の量産には強いが、高精度な生産設備の自給と労働集約型産業の省力化には弱い工業国**」と総括される。[^e083] 1936年までの産業発展を決める11項目のダイス判定で、臨海一貫製鉄所・帝国全体の工業規格・重電機器がクリティカル、化学・自動車・航空機・工程管理が成功となった一方、工作機械の高精度化、造船の工程合理化、無線・精密機器、軽工業の省力化は失敗した。[^e083]

会話ログ3の1937年経済の再積算（P87〜P96、P97で確定）により、製造業の規模は**付加価値132億円（GDP400億円の33.0%）、就業者760万人（就業者3,220万人の23.6%）**、就業者1人当たり付加価値1,737円とされた。鉄鋼・非鉄・機械・造船・輸送機械・化学の**重化学工業は付加価値72億円で製造業の54.5%**、就業者310万人で40.8%を占め、付加価値では過半、就業者では繊維・食品など軽工業が多数という構造である。[^p087][^p096] 会話ログ2の共通価格評価（就業者820万人、純付加価値82.11億ドル相当）は旧推計として「却下・修正された案」に残す。経済全体の数字は[1937年の日本経済（国民経済計算と基本指標）](/economy/economy-1937-overview.md)を参照。

産業間の格差は非常に大きい。重電機器（対米労働生産性95%）・非鉄金属製錬（90%）・基礎鉄鋼（80%）では米国に迫るが、工作機械（45%）・無線精密機器（40%）・繊維衣料（38%）は低い（会話ログ2の部門別評価）。[^e083] 資本の担い手では、独立系華族企業（実業家華族の企業集団）が製造業付加価値の44.7%を占めて最大勢力となり、領主系企業32.6%、非華族系16.7%、帝国・公営6.1%と続く。[^p087] 企業集団の詳細は[独立系企業集団と資本系統（1937）](/economy/business-groups-1937.md)を参照。

なお、ダイスの成功は産業の発展を確定させるが、対米労働生産性の具体的な百分率まで確定させるものではない、という原則が後に置かれた。歴史的帰結は維持し、数値（生産性・就業者数）は物的生産量に照らして修正できる。[^e087][^e088]

会話ログ3では、これとは別に**資本の担い手**についての判定が行われた。独立系資本は一貫製鉄（59＞30）、造船・重機械（97＞25、クリティカル）、基礎化学・有機化学（93＞30）、紡績・織物・化学繊維（27＞15）、自動車・航空機・精密機械（51＞35）でいずれも全国的地位を確立した。[^p084] 「造船・重機械のクリティカル」は「誰が担うか」（企業資本としての地位）についての判定であり、会話ログ2の「造船所の工程合理化・船型標準化の失敗」は「どう造るか」（生産方式）の判定であって、両者は両立する（作者確定）。会話ログ2自身も、合理化失敗を前提に年75万総tの建造を想定していた。[^e089]

## 鉄鋼業：臨海一貫製鉄所への集中

一貫製鉄所のクリティカルと国内金属鉱山のファンブル（→[資源戦略](/economy/resource-strategy.md)）が重なり、製鉄業は輸入鉱石・原料炭の荷揚げから製銑・製鋼・圧延・出荷までを一体化した臨海工業地帯へ集中する。[^e083] 1937年の物量収支は会話ログ3で次のように確定した。[^p089][^p096]

| 指標 | 1937年 |
|---|---:|
| 粗鋼能力／実生産（稼働率） | 1,350万t／1,150万t（85%） |
| 製鋼方式 | 平炉920万t（80%）、電気炉172.5万t（15%）、転炉・その他57.5万t（5%） |
| 製鋼原料 | 銑鉄850万t＋屑鉄400万t＝1,250万t（歩留92%） |
| 銑鉄需給 | 国内生産850万t＋輸入70万t＝920万t |
| 鉄鉱石（銑鉄1t当たり1.8t） | 1,530万t（国内の鉄原料220万t、輸入1,310万t＝85.6%） |
| 製鉄用原料炭 | 1,020万t（九州370・北海道240・その他国内30・輸入380万t＝37.3%） |
| 高炉用コークス | 765万t（銑鉄1t当たり0.9t、収率75%） |
| 鋼材 | 国内977.5万t（粗鋼比85%）＋輸入42.5万t＝1,020万t |

国内鉄鉱石220万tは「国内で調達できる鉄原料」で、採掘した鉄鉱石約60万t（釜石が中心で、南部家が自社用に維持）と、化学工業の副産物である硫酸滓および砂鉄など約160万tからなる（作者確定）。1930年代に国内金属鉱山は経営危機に陥り（ダイス判定：難易度55、出目1・ファンブル）、鉄鋼能力の拡大で輸入依存はむしろ強まった。[^e081]原料炭の輸入調達は南部家の海外原料調達網のクリティカル（96＞40）が支える。[^p055][^p089] 電気炉製鋼の比重が高いのは水力発電の発達による（松江松平系特殊鋼など）。[^p089]

鋼材1,020万tの用途は、建築・土木280万t、一般・電気機械170万t、商船・民間造船100万t、鉄道・車両100万t、自動車・その他輸送機械65万t、国防関連の直接需要100万t、缶・家庭用品55万t、その他国内70万t、輸出70万t、在庫増10万tで、民間の設備投資・建設・交通が中心である。[^p089]

粗鋼の企業別配分は、南部製鉄系230万t（20.0%）、帝国製鉄事業230万t（20.0%）、東洋製鉄（仮称、三井・古河・三菱・銀行資本の共同出資）220万t（19.1%）、日本臨海製鉄（仮称、住友・大倉・独立系銀行）180万t（15.7%）、その他独立系製鉄152万t（13.2%）、非華族系製鋼57.5万t（5.0%）、松江松平系特殊鋼46万t（4.0%）、その他領主系34.5万t（3.0%）である。南部系は民間単独の企業集団として最大級だが、鉄鋼業でも単一資本の独占は成立しない。[^p086]

## 工作機械と帝国工業規格

工作機械の国産化には失敗したが、工業規格の統一にはクリティカルで成功した。このため日本は高精度工作機械を十分に自製できないものの、輸入工作機械を使って互換性のある部品を大量に作れる。汎用工作機械は国産化が進む一方、高精度研削盤・歯切盤・精密測定器は米国・英国・ドイツ・スイスからの輸入に依存し、専用量産機械は国産と輸入が併存する。対外支払能力が高いため平時の問題は小さいが、長期の国際対立で設備・交換部品が入手困難になると新規投資と設備維持が問題になる。[^e083]

会話ログ3では福井松平家の「繊維機械・精密機械」判定がクリティカル（99＞35）となり、精密旋盤・研削盤・測定器・光学機器を扱う領主系企業集団が成立した。[^p052] これは国全体の高精度工作機械の自給失敗（E83）と潜在的に緊張するが、「一企業集団としては全国有数だが、国全体の高精度工作機械の自給は不十分」と整理するのが妥当である（検討案）。

帝国工業規格は1920年代までに帝国全体で制定され、1930年代に公共調達・大企業間取引に広く適用された。対象はねじ・軸受・配管・電気設備・機械部品・材料品質・測定方法など。[^e083] 制度面の経緯は[全国標準化政策](/institutions/national-standardization.md)を参照。

## 一般機械・電機：重電と弱電の格差

重電のクリティカルは、豊富な電力、安価な銅・アルミニウム、全国的な送電網、幹線鉄道の電化、工業規格の統一という条件の上に成り立つ。製品別の対米生産性は大型発電機90〜100%、水力発電用機器95〜110%、変圧器90〜100%、工業用電動機85〜95%、鉄道用電気機器90〜100%、送配電設備85〜95%で、水力関連では米国以上の優位もありうる。一方、無線・真空管・精密機器は失敗し、巨大な発電機や電動機は作れても高性能な無線機・精密測定器は外国に依存する。[^e083] 重電機の主な担い手は那珂川系・細川系の領主系資本と、共同出資の日本産業電機（仮称、那珂川系・住友系・独立系）である。[^p086]（電力側の事情は[エネルギー需給と電化](/economy/energy-1937.md)）

## 造船：高い技術と低い標準化

造船合理化の失敗は衰退を意味しない。商船隊の拡大と個別受注が長く続いた結果、各造船所が独自の設計・建造方式を発達させた。大型船建造・船舶機関の技術と品質は高く、部品の規格統一も進んだが、船型の標準化・造船所間の工程共通化は不十分で、同一船型の大量建造は苦手である。[^e083]

民間商船の年間建造量は**75万総t**で、国内商船の更新36万総t（更新率4%、平均25年周期）、純増24万総t、輸出向け15万総tからなる。資本別には独立系華族45万総t、領主系22.5万総t、非華族3.75万総t、公営等3.75万総tで、独立系造船・重機械のクリティカルを反映して三菱系などの独立系造船所が主力となる。軍艦は別指標である。[^p090] 輸出向け新造船15万総tは0.75億円の輸出となる。[^p091] 史実1937年の世界商船進水264.3万総t（英国・アイルランド92.1万総t）と比べ、日本は英国に次ぐ商船建造国となる。[^e088] 1937年以降の軍艦建造は[1937年の建艦競争と海軍財政](/military/naval-buildup-1937.md)を参照。

## 非鉄金属製錬・化学・石油精製

* **非鉄金属製錬**：水力電力を生かした製錬がクリティカルで成功し、アルミニウム16万t・精製銅35万t・亜鉛18万t・鉛10万t・その他6万tの計85万tを生産する（対米90%）。鉱石は輸入、精製金属は純輸出という「採掘は海外、精製・製錬は国内」の分業である。[^e081][^e088] 担い手は那珂川系・佐竹系の領主系資本と住友・古河などの独立系資本である。[^p086]
* **化学**：電気化学を中心に発達し、1937年の生産は硫酸250万t、窒素肥料（硫安換算）180万t、ソーダ灰50万t、苛性ソーダ35万t、人造繊維20万t、セメント1,250万t（会話ログ2の値）。対米65%。[^e082][^e083] 会話ログ3では独立系の基礎化学・有機化学がクリティカルに近い成功（93）で、日本窒素系（野口家）が細川・佐竹・鳥取池田・松江松平などの電力資本と共同出資して大規模化学工業を形成した。[^p084][^p086]
* **石油精製**：会話ログ3では国内原油60万t（秋田32・新潟20・北海道5・台湾その他3万t）と輸入原油840万tを合わせた**原油処理900万t**から、精製損失45万tを除いて国内製品855万tを生産し、製品輸入145万tと合わせて石油製品の総供給は1,000万tとなる。製品需要は民間船舶210万t、自動車・道路輸送200万t、製造業・化学180万t、国防部門170万tなど国内消費950万t。[^p089] 精製の担い手は独立系（日本石油系など）と佐竹系である。[^p084] 精製能力（会話ログ2では1,450万t）は会話ログ3で再設定されていない。

鉱工業の電力需要は390億kWh（全発電の60%）である。[^p087] 会話ログ2では製造業の電力消費を340億kWhとし、うち鉄鋼・金属加工50、アルミ製錬35、その他非鉄25、化学・電気化学65億kWhで約半分を占めるとしていた。[^e089]

## 自動車・鉄道車両・航空機

自動車は量産体制が成立し、会話ログ2では1937年の生産を乗用車9万台・貨物16万台・バス2万台・特殊その他3万台の計30万台とした。[^e083] 会話ログ3の積算（道路用石油200万tからの逆算）では、1937年の保有は乗用車・タクシー等65万台、貨物自動車40万台、バス5万台、二輪車・その他23万台の**計133万台**（人口1,000人当たり約17台）で、一般家庭への普及より企業・商業・貨物・公共交通の利用が先行する。尾張徳川系・豊田系・独立系機械企業が自動車産業を支える。[^p090]

年産30万台と保有133万台はどちらも維持される。年産は1930年の約5万台から1937年の30万台へ急増したため、保有が追いついていない。1930〜37年の累計生産約120万台に1930年以前からの保有分を加え、廃車を差し引いたものが約133万台に当たり、ほかに英国の植民地や中国への輸出が数万台ある（作者確定）。[^e083][^p090]

航空機は1936年までに量産基盤が成立し、年間生産能力3,500機・実生産2,500機、対米55%。発動機・精密部品は一部外国技術と設備に依存し、日英の航空発動機技術協力の効果は1937年以降に現れるものとして先取りしない。[^e083] 担い手は尾張徳川系（航空機・発動機の判定成功）と中島系、共同出資の東洋航空機（仮称）である。[^p086]（→[航空攻撃試験と航空主兵論](/military/naval-aviation-1935.md)）

## 軽工業：低生産性の大規模雇用部門

軽工業の省力化失敗（出目8）により、紡績45%・織布40%・衣料製造30%・食品加工40%・木材加工40%・紙パルプ50%と生産性は低く、零細経営が多数残る。農村や炭鉱から流出した労働力の受け皿となる一方、製造業の平均生産性を引き下げる。[^e083] 1937年の就業者は紡績・織物・化学繊維180万人、食品・飲料・水産加工130万人、木材・製紙70万人である。[^p087] 繊維の資本系統別シェアは領主系35%・独立系華族40%・非華族25%と非華族の比重が比較的高い（検討案）。[^p084]

# 貿易との関係

会話ログ3の1937年国際収支では、財貨輸出54.795億円（新造船0.75億円を加えて55.545億円）のうち繊維・衣料17.500億円（31.9%）、機械・金属製品12.825億円（23.4%）、化学製品・肥料5.200億円、鋼材1.260億円が製造業製品で、財貨輸入46.876億円のうち機械・その他は9.138億円である。輸出平均単価（457円/t）は輸入（112円/t）の約4.1倍で、「原材料を輸入し加工で付加価値を生む経済」として財貨貿易収支は8.669億円の黒字となる。[^p091] 高精度設備の国産化失敗は工作機械・精密機器の輸入として残る。国際収支全体は[国際収支と対外資産（1914〜1937）](/economy/balance-of-payments.md)を参照。

# 産業組織：垂直統合型の大企業と企業連合

帝国工業規格はクリティカルで成功したが、1937年の社会構造判定で「中小製造業の企業間分業が発達する」は失敗（1d100 > 25、出目21）となった。規格上は企業間で部品を融通できるのに、実際の生産組織は大企業と[領主系企業集団](/concepts/yorioya-yoriko.md)に集中している。[^e096]

| 主体 | 1937年の状況 |
|---|---|
| 大企業 | 素材から部品・完成品まで内部生産 |
| 領主系企業集団 | 集団内での専門分業が発達 |
| 独立系（実業家華族）企業集団 | 専門分野を持ち、共同出資で他集団と連合 |
| 独立中小企業 | 零細加工・修理・軽工業が中心 |
| 高精度部品 | 大企業内部の生産または輸入 |
| 外部下請網 | 発達が不十分 |
| 工業規格 | 全国的に統一 |

「技術的な標準化には成功しているが、経営組織としては垂直統合型の大企業が主流」であり、大規模な設備投資や品質管理は行いやすい一方、専門部品企業間の競争・新規参入・多品種の柔軟な生産に弱い。[^e096] 会話ログ3では、少数の総合財閥による産業横断支配は不成立（49＞50で失敗）、企業間の共同出資・企業連合は成功（55＞30）とされ、資本集約産業では東洋製鉄・日本臨海製鉄・日本精密工業（いずれも仮称）のように複数の資本系統が共同で企業を設立する。[^p084][^p086] 労働時間・職業教育など労働側の条件は[1937年の就業構造と社会](/economy/labor-society-1937.md)を参照。

# 史実との比較

* 史実1937年の日本の粗鋼生産は580万tで、本世界線（1,150万t）の約半分。[^e068]
* 史実の1935年英米製造業比較（米国＝100）では、英国は製造業全体44.6、繊維69.4、鉄鋼53.8、非鉄54.9、機械・造船・車両30.6、化学38.0。本世界線日本の設定（鉄鋼80、非鉄90、化学65など）は重工業の多くで英国を大きく上回る「強気」の設定であり、工作機械国産化失敗を考えると裏付けが必要とされた。[^e087]
* 史実1937年の米国の自動車生産は478万台、本世界線日本の30万台はその6.3%。[^e088][^e097]
* 史実の日本の製鉄は官営八幡製鉄所と財閥系企業が中心だったが、本世界線では南部系（領主系）・帝国製鉄事業・独立系共同出資企業が並立する。[^p086]

# 却下・修正された案

* **1937年の工業基盤暫定推計（E66）**：粗鋼能力1,250〜1,450万t・実生産1,050〜1,250万t、製造業対米50〜55%、造船65〜75% → E68〜E69で粗鋼1,150万tを確定値とし、能力は1,350万tとした。[^e066][^e068][^e069]
* **E72の製造業内訳**：鉄鋼・非鉄55%、造船70%、自動車40%など（製造業27%・969万人）→ ダイス判定（E83）を反映して置き換えられた。[^e072][^e083]
* **製造業就業者978万人・加重平均生産性51.8%（E86の第一次積算）** → 製造業純付加価値91.45億ドルとしたが、就業者過大として812万人（E88）→820万人（E96）、純付加価値82.11億ドル（E97）に修正された。[^e086][^e088][^e097]
* **製造業就業者820万人・純付加価値82.11億ドル相当・粗付加価値92.38億ドル（GDPの35.5%）（会話ログ2の最終値）→ 就業者760万人・付加価値132億円（GDPの33.0%）（会話ログ3、P87・P96で確定）**：会話ログ3は1937年経済を円建てで再積算し、P97で確定値とした。旧推計の内訳は次のとおり。[^e088][^e096][^e097][^p087][^p096][^p097]

  | 産業（万人） | E83案 | E88修正 |
  |---|---:|---:|

  | 食品加工 | 165 | 145 |
  | 一般機械・工作機械 | 105 | 75 |
  | 木材・紙・印刷 | 100 | 100 |
  | 鉄鋼・金属加工 | 70 | 60 |
  | 化学・石油精製 | 60 | 55 |

  | 造船・船舶機関 | 60 | 25 |
  | 自動車・鉄道車両 | 50 | 16 |
  | 非鉄金属製錬 | 15 | 10 |
  | 航空機・精密機器 | 25 | 15 |
  | その他 | 53 | 53 |
  | 計 | 978 | 812 |

  E88の812万人は、1937年米国製造業センサス（生産労働者857万・事務等122万、製造付加価値251.7億ドル）と物的生産量から必要労働力を積算し直したもので、E96で大企業内部の部品生産・交代勤務に限って8万人を加え820万人とされていた。製造付加価値（センサス方式）は繊維・衣料12.00、食品加工15.00、基礎鉄鋼3.51、鉄鋼二次加工5.77、一般機械・工作機械14.50、電機・通信機器9.00、自動車0.95、鉄道車両等0.98、木材・家具・紙・印刷11.73、化学工業14.50、ゴム製品1.50、石油精製0.50、造船・船舶機関3.70、非鉄金属製錬1.00、航空機・精密機器2.00、窯業・その他6.00、計102.64億ドル相当で、ここからサービス投入10%と固定資本減耗10%を控除して純付加価値82.11億ドルとしていた。部門別就業者（基礎鉄鋼16万・鉄鋼二次加工44万、機械・電機113万、造船25万、化学55万など）もこの旧推計に属する。[^e083][^e088][^e097]
* **鉄鋼の物量（会話ログ2）→ 会話ログ3**：銑鉄800万t → 850万t、製鋼用鉄屑約380万t → 400万t、鉄鉱石消費約1,400万t（国内60万t、純輸入約1,340万t）→ 1,530万t（国内220万t、輸入1,310万t）、製鉄用原料炭約1,100万t → 1,020万t（コークス原単位0.85t → 0.9t）。会話ログ2では鉄鉱石消費を1,750万t → 1,400万t（鉄屑利用、E83）、原料炭を1,600万t → 1,100万t（製鉄合理化、E89）と下方修正していた。[^e083][^e088][^e089][^p089][^p096]
* **鋼材約1,000万tの用途（E88）**：建築・土木280、一般機械・金属製品170、造船・船舶修理110、鉄道・車両・軌条100、電機・電力設備65、自動車35、軍需90、その他国内50、純輸出100万t → P89の用途配分（上掲）に置き換え。[^e088][^p089]
* **石油精製：原油処理1,150万t（国内原油100万t＋輸入1,050万t）→ 900万t（国内60万t＋輸入840万t）**。会話ログ2では自動車普及で石油需要を850万tから1,250万tへ上方修正し、精製能力を1,150万tから1,450万tへ引き上げていた（E88〜E89）。[^e081][^e088][^e089][^p089]
* **自動車保有250万台（うち自家用乗用車125万台、E84）→ 133万台（P90）**：会話ログ3では乗用車の家庭普及より業務利用が先行する構成とされた。[^e084][^p090]
* **国内鉄鉱石220万tの内訳と「国内鉱山の開発には成功」（P89）**：釜石・北上山地130万t、中国地方40万t、北海道30万t、その他20万tの採掘とする説明。国内金属鉱山のファンブル（E81、出目1）と逆になるため、採掘約60万t＋硫酸滓・砂鉄など約160万tの国内鉄原料に改めた（作者確定）。[^e081][^p089]
* **「農村から都市への労働移動の制約が産業間の所得格差を残す」（P87）**：E96の労働移動円滑（出目55・成功）と逆になるため外し、格差の理由を家族従業者の計上と押し出し要因の弱さに改めた（作者確定）。[^e096][^p087]
* **造船の「工程合理化失敗」と「独立系造船・重機械クリティカル」の両立（検討案）**：作者確定で両立が確定した。[^e083][^p084]
* **食品加工付加価値19.16億 → 15.00億ドル**：国内の食料消費構成に合わせて下方修正（E97、会話ログ2内の修正）。[^e097]
* **財の輸出16.20億ドル・工業製品と資本財の輸入5.80億ドル（E98）**：会話ログ2の貿易構成（財貿易は赤字）。会話ログ3の円建て国際収支（財貨貿易収支+8.669億円の黒字）に置き換えられた。[^e098][^p091]
* **「工業規格の統一で中小企業も大企業の供給網に参加しやすくなり、専門分業が進む」（E83のAI解釈）**：E96の中小製造業分業の失敗判定により、規格は統一されたが外部下請網は発達しない構造へ修正された。[^e083][^e096]

# 未決の論点

* 造船工程の標準化・高精度工作機械・無線機器・精密機器の弱点が、1937年以降の日英軍事技術協力でどこまで解消されるか。AIが提示した8項目の技術協力判定は振られておらず、1938年以降は予測シナリオにとどめられた。[^e084][^e098]
* 会話ログ2の部門別対米労働生産性（重電95%など）と会話ログ3の円建て部門別付加価値との対応。粗鋼能力・自動車生産台数・航空機生産・化学品の生産量は会話ログ3で再設定されていない。（作者確定で解決：自動車生産30万台と保有133万台の関係は、1930年年産約5万台からの急増で保有が追いついていないものとする。）
* （作者確定で解決）国内鉄鉱石220万tの採掘可能性：採掘は約60万tで、残りは硫酸滓・砂鉄などとする。[^e081][^p089]
* 各製鉄所の設備能力の個別検証。[^p089]
* 共同出資企業の企業数・持株比率。[^p086]
* 銑鉄・鉄屑比率や原料品位、製造業全品目の生産額の独立積算、国際比較価格の統一。[^e083][^e097]
