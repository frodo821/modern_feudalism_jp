# 概要

1937年の本世界線日本の製造業は、「**大型設備を用いた素材生産と規格化された工業製品の量産には強いが、高精度な生産設備の自給と労働集約型産業の省力化には弱い工業国**」と総括される。[^e083] 1936年までの産業発展を決める11項目のダイス判定で、臨海一貫製鉄所・帝国全体の工業規格・重電機器がクリティカル、化学・自動車・航空機・工程管理が成功となった一方、工作機械の高精度化、造船の工程合理化、無線・精密機器、軽工業の省力化は失敗した。[^e083]

その後の検証で、製造業就業者は当初の978万人から812万人へ、社会構造の判定を経て820万人へと修正された。製造業の純付加価値は82.11億ドル相当（1937年米国価格基準の共通価格評価、以下同じ）で、国内純付加価値212.94億ドル相当の約39%を占める。[^e088][^e096][^e097] 経済全体の数字は[1937年の日本経済（国民経済計算と基本指標）](/economy/economy-1937-overview.md)を参照。

産業間の格差は非常に大きい。重電機器（対米労働生産性95%）・非鉄金属製錬（90%）・基礎鉄鋼（80%）では米国に迫るが、工作機械（45%）・無線精密機器（40%）・繊維衣料（38%）は低い。英国経済圏に鉄鋼・精製金属・重電機器・化学製品・輸送機器を供給し、一次産品と高精度生産設備を輸入する「相互の工業的な補完関係」が成立している。[^e083]

# 部門別の構造

## 鉄鋼業：臨海一貫製鉄所への集中

一貫製鉄所のクリティカルと国内金属鉱山のファンブル（→[資源戦略](/economy/resource-strategy.md)）が重なり、製鉄業は輸入鉱石・原料炭の荷揚げから製銑・製鋼・圧延・出荷までを一体化した臨海工業地帯へ極端に集中する。[^e083]

[^e083][^e088][^e089] 鉄鉱石消費は鉄屑利用の進展で1,750万tから1,400万tへ、原料炭需要は銑鉄1t当たりコークス0.85tとコークス炉ガス・高炉ガスの所内再利用により1,600万tから1,100万tへ下方修正された。[^e083][^e089]

## 工作機械と帝国工業規格

工作機械の国産化には失敗したが、工業規格の統一にはクリティカルで成功した。このため日本は高精度工作機械を十分に自製できないものの、輸入工作機械を使って互換性のある部品を大量に作れる。汎用工作機械は国産化が進む一方、高精度研削盤・歯切盤・精密測定器は米国・英国・ドイツ・スイスからの輸入に依存し、専用量産機械は国産と輸入が併存する。対外支払能力が高いため平時の問題は小さいが、長期の国際対立で設備・交換部品が入手困難になると新規投資と設備維持が問題になる。[^e083]

帝国工業規格は1920年代までに帝国全体で制定され、1930年代に公共調達・大企業間取引に広く適用された。対象はねじ・軸受・配管・電気設備・機械部品・材料品質・測定方法など。[^e083] 制度面の経緯は[全国標準化政策](/institutions/national-standardization.md)を参照。

## 造船：高い技術と低い標準化

造船合理化の失敗は衰退を意味しない。商船隊の拡大と個別受注が長く続いた結果、各造船所が独自の設計・建造方式を発達させた。大型船建造・船舶機関の技術と品質は高く、部品の規格統一も進んだが、船型の標準化・造船所間の工程共通化は不十分で、同一船型の大量建造は苦手である。対米生産性は1930年60%から1937年65%（旧想定65〜75%を修正）。[^e083]

商船保有の650万総t（1930）→900万総t（1937）から逆算すると、年平均の国内建造量は純増36万総t＋廃船・喪失補充18万＋船舶輸出12万−中古船純輸入6万＝約60万総tで、景気回復期の1937年は約75万総t。史実1937年の世界商船進水264.3万総t（英国・アイルランド92.1万総t）と比べ、英国に次ぐ商船建造国となる。造船就業者は商船・漁船建造10万、軍艦建造・改装6万、船舶修理5万、船舶機関製造4万の計25万人。[^e088] 英国との技術協力で標準船型・工程合理化が進めば、就業者を大きく増やさずに建造能力を拡大する余地がある（検討案）。[^e088] 1937年以降の軍艦建造は[1937年の建艦競争と海軍財政](/military/naval-buildup-1937.md)を参照。

## 非鉄金属製錬・化学・石油精製

* **非鉄金属製錬**：水力電力を生かした製錬がクリティカルで成功し、アルミニウム16万t・精製銅35万t・亜鉛18万t・鉛10万t・その他6万tの計85万tを就業者10万人で生産する（対米90%）。鉱石は輸入、精製金属は純輸出という「採掘は海外、精製・製錬は国内」の分業である。[^e081][^e088]
* **化学**：電気化学を中心に発達し、1937年の生産は硫酸250万t、窒素肥料（硫安換算）180万t、ソーダ灰50万t、苛性ソーダ35万t、人造繊維20万t、セメント1,250万t。国内農業の縮小で肥料需要は抑えられ、中国・東南アジアへ輸出する。対米65%。天然ゴムを英国経済圏から安定輸入できるため合成ゴムの必要は小さい。就業者は肥料8万、基礎化学・電気化学9万、人造繊維8万、ゴム製品7万、医薬・染料・塗料10万、石油精製3万、その他10万の計55万人。[^e082][^e083][^e088]
* **石油精製**：合理化判定（93）の成功で熱分解設備を備えた大型製油所が普及し、精製能力1,450万t、原油処理1,150万t（国内原油100万t＋輸入1,050万t）。対米80%。[^e081][^e089]

製造業の電力消費340億kWhのうち、鉄鋼・金属加工50、アルミ製錬35、その他非鉄25、化学・電気化学65億kWhで約半分を占める。[^e089]

## 自動車・鉄道車両・航空機

自動車は量産体制が成立し、1937年の生産は乗用車9万台・貨物16万台・バス2万台・特殊その他3万台の計30万台。[^e083] 重工業の拡大を受けて家庭向け乗用車と自動車物流は相当程度普及しているものとされ、保有は250万台（うち自家用乗用車125万台）に置かれた。[^e084] 米国（478万台、生産労働者約48万人）と比べ一人当たり年約6台（対米60%）として、必要労働力は自動車完成車・部品7万人、鉄道車両6万人、自転車その他3万人の計16万人にとどまる。量産体制の成功から将来の増産余力は大きい。[^e088]

航空機は1936年までに量産基盤が成立し、年間生産能力3,500機・実生産2,500機、対米55%。発動機・精密部品は一部外国技術と設備に依存し、日英の航空発動機技術協力の効果は1937年以降に現れるものとして先取りしない。[^e083]（→[航空攻撃試験と航空主兵論](/military/naval-aviation-1935.md)）

## 軽工業：低生産性の大規模雇用部門

軽工業の省力化失敗（出目8）により、紡績45%・織布40%・衣料製造30%・食品加工40%・木材加工40%・紙パルプ50%と生産性は低く、零細経営が多数残る。農村や炭鉱から流出した労働力の受け皿となる一方、製造業の平均生産性を引き下げる。[^e083] 1937年の就業者は繊維・衣料220万人、食品加工145万人、木材・紙・印刷100万人、その他53万人。[^e088]

センサス方式の102.64億ドルから未控除のサービス投入10%と固定資本減耗10%を差し引き、製造業純付加価値は**82.11億ドル相当**、粗付加価値は92.38億ドル（GDPの35.5%）となる。就業者が978万人から820万人に減った一方、資本集約的産業の比重が高いため、付加価値の減少幅（91.45億→82.11億、約10%減）は就業者の減少幅より小さい。[^e097]

## 貿易との関係

1937年の財の輸出16.20億ドルのうち、繊維・衣料3.50、重電・一般機械2.80、鉄鋼・金属製品2.40、化学製品・肥料1.80、船舶・輸送機器1.20、非鉄金属0.70が製造業製品である。一方、工作機械・産業設備2.50、無線・精密機器0.80など工業製品・資本財を5.80億ドル輸入しており、高精度設備の国産化失敗が資本財輸入として現れる。[^e098] 国際収支全体は[国際収支と対外資産（1914〜1937）](/economy/balance-of-payments.md)を参照。

# 産業組織：垂直統合型の大企業

帝国工業規格はクリティカルで成功したが、1937年の社会構造判定で「中小製造業の企業間分業が発達する」は失敗（1d100 > 25、出目21）となった。規格上は企業間で部品を融通できるのに、実際の生産組織は大企業と[領主系企業集団](/concepts/yorioya-yoriko.md)に集中している。[^e096]

| 主体 | 1937年の状況 |
|---|---|
| 大企業 | 素材から部品・完成品まで内部生産 |
| 領主系企業集団 | 集団内での専門分業が発達 |
| 独立中小企業 | 零細加工・修理・軽工業が中心 |
| 高精度部品 | 大企業内部の生産または輸入 |
| 外部下請網 | 発達が不十分 |
| 工業規格 | 全国的に統一 |

「技術的な標準化には成功しているが、経営組織としては垂直統合型の大企業が主流」であり、大規模な設備投資や品質管理は行いやすい一方、専門部品企業間の競争・新規参入・多品種の柔軟な生産に弱い。1937年以降の造船・航空機・高精度工作機械の増産や軍需生産の大企業集中にも影響する（検討案）。[^e096] 労働時間短縮・職業教育など労働側の条件は[1937年の就業構造と社会](/economy/labor-society-1937.md)を参照。

# 史実との比較

* 史実1937年の日本の粗鋼生産は580万tで、本世界線（1,150万t）の約半分。[^e068]
* 史実の1935年英米製造業比較（米国＝100）では、英国は製造業全体44.6、繊維69.4、鉄鋼53.8、非鉄54.9、機械・造船・車両30.6、化学38.0。本世界線日本の設定（鉄鋼80、非鉄90、化学65など）は重工業の多くで英国を大きく上回る「強気」の設定であり、工作機械国産化失敗を考えると裏付けが必要とされた。[^e087]
* 史実1937年の米国の自動車生産は478万台、本世界線日本の30万台はその6.3%。[^e088][^e097]

# 却下・修正された案

* **1937年の工業基盤暫定推計（E66）**：粗鋼能力1,250〜1,450万t・実生産1,050〜1,250万t、製造業対米50〜55%、造船65〜75% → E68〜E69で粗鋼1,150万tを確定値とし、能力は1,350万tとした。[^e066][^e068][^e069]
* **E72の製造業内訳**：鉄鋼・非鉄55%、造船70%、自動車40%など（製造業27%・969万人）→ ダイス判定（E83）を反映して置き換えられた。[^e072][^e083]
* **製造業就業者978万人・加重平均生産性51.8%（E86の第一次積算）** → 製造業純付加価値91.45億ドルとしたが、就業者過大として812万人（E88）→820万人（E96）、純付加価値82.11億ドル（E97）に修正された。[^e086][^e088][^e097]
* **造船就業者60万人・自動車鉄道車両50万人・機械電機160万人**（E83）→ 物的生産量からそれぞれ25万・16万・113万人に下方修正（E88）。[^e088]
* **鉄鉱石消費1,750万t → 1,400万t**（鉄屑利用、E83）、**原料炭1,600万t → 1,100万t**（製鉄合理化、E89）。[^e083][^e089]
* **石油精製能力1,150万t → 1,450万t**：自動車普及で石油需要が850万tから1,250万tへ上方修正されたため（E88〜E89）。[^e088][^e089]
* **食品加工付加価値19.16億 → 15.00億ドル**：国内の食料消費構成に合わせて下方修正（E97）。[^e097]
* **「工業規格の統一で中小企業も大企業の供給網に参加しやすくなり、専門分業が進む」（E83のAI解釈）**：E96の中小製造業分業の失敗判定により、規格は統一されたが外部下請網は発達しない構造へ修正された。[^e083][^e096]

# 未決の論点

* 造船工程の標準化・高精度工作機械・無線機器・精密機器の弱点が、1937年以降の日英軍事技術協力でどこまで解消されるか。AIが提示した8項目の技術協力判定は振られておらず、1938年以降は予測シナリオにとどめられた。[^e084][^e098]
* 銑鉄・鉄屑比率や原料品位、製造業全品目の生産額の独立積算、国際比較価格の統一。[^e083][^e097]
* 航空機・精密機器、一般機械、軽工業の就業者数に残る未検証の仮定。[^e088]
