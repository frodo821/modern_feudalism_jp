# 概要

帝国交通整備計画は、1889年の[下関条約](/diplomacy/shimonoseki-treaty-1889.md)で得た賠償金の使途として成立した、全領国を対象とする横断的な交通公共事業である。賠償金の分配に悩むくらいなら、はじめからすべての領国にメリットのある横断的な公共事業をやってしまえ、という意見が自然に出てきた結果であり、需要喚起策として国道・高速国道と鉄道の整備を行うという方向は確定設定である。[^u083]

政府原則は「**戦勝の利益は帝国全土に還元する。各領国を国道・鉄道・港湾によって接続し、その建設費を帝国が負担する**」である。[^u083] 元老院にも衆議院にも説明しやすく、中央政府は全国的な物流・軍事輸送網を掌握できる。**全員に利益があるからこそ、中央政府の権限強化も受け入れられる**という構造が、この計画の政治的な核心である。[^u083]

計画は1889〜1904年の15年計画とされ、賠償金の半額6,000万両を「帝国交通整備基金」に充てる配分例、領主権との調整を定める「帝国交通例」などが構想されている（いずれも検討案）。[^u083] 長期的には、日清戦争後の論功行賞として始まった公共事業が、アメリカと競争できる工業経済の基盤になったと評価されうる。[^u083]

# 成立の経緯

## 論功行賞からの転換

日清戦争後、戦功を誰の功績とし、領主家に何を与えるかをめぐって[論功行賞](/events/reward-distribution-1889.md)の政治が生じた。特定の家への加増は元老院の力関係を変え、衆議院の反発を招く。[^u078] これに対し、賠償金を特定の領国に集中投資すれば他の領主から不満が出るため、全領国を結ぶ国家的な交通網に投資する方が[元老院](/institutions/genroin.md)で合意を形成しやすい。[^u083]

| 主体 | 交通網整備の利点 |
|---|---|
| 元老院の領主議員 | 自家の領国の交通条件と産業立地が改善する |
| 衆議院 | 軍功のある特定の家への加増ではなく、一般の商工業者や住民にも利益が及ぶ |
| 中央政府 | 全国的な物流・軍事輸送網を掌握できる |

[^u083]

## 重工業化との関係

重工業化を日清戦争の賠償金から始めるのでは遅く、賠償金は既存基盤の拡大資金にしかならない。そして重工業化の本当の制約は製鉄所の建設よりも**需要の形成**である。各領主が小規模製鉄所を乱立させれば遊休化するため、中央政府による全国鉄道網、商船・軍艦の国内建造、港湾・橋梁・都市インフラ、機械の国産化によって需要を作る必要がある。[^u082] 交通整備計画は、この需要形成策の中核に位置づけられる。（[重工業化と国力の推移](/economy/heavy-industrialization.md)参照）

# 計画の内容

## 交通の区分

1889年にはまだ自動車が一般的な輸送手段ではないため、現代的な自動車専用高速道路をすぐ建設するのは需要の面で早すぎる。そこで次の区分が設けられる（検討案）。[^u083]

| 区分 | 1889年時点での役割 |
|---|---|
| 国道 | 領国間の一般交通、馬車、物資輸送、郵便 |
| 高速国道 | 幹線の高規格馬車道。緩勾配、広い幅員、橋梁整備、通過交通を優先 |
| 鉄道 | 大量貨物、長距離旅客、兵員輸送 |
| 領道 | 国道・鉄道駅・港湾と各領国内の集落を接続（領主が管理） |

**高速国道**は当初、高速馬車や貨物馬車の運行を想定した高規格の幹線道路である。ただし自動車の普及を見越して用地を広く確保し、将来の立体交差化や車道拡幅に対応できる設計とする。これにより1900年代以降に自動車交通が普及した際の改良費を抑えられる。[^u083]

## 鉄道

本世界線では1860年代から近代化が始まり、有力領主が早期に鉄道投資を行っているため、1889年の段階ですでに東海道・山陽道・東北道などの幹線が相当程度完成していても不思議ではない。[^u083] そのため賠償金は新線建設だけでなく、既存線の改良にも投じられる。

* 単線の複線化
* 橋梁の鋼橋への架け替え
* トンネルの拡張
* 輸送力の大きい機関車への更新

[^u083]

## 15年計画

工事を数年に集中させず、1889年から1904年までの15年間を対象とした整備計画を制定する。製鉄所や車両工場が長期需要を見込んで設備投資できるようにするためで、賠償金が一時的な財政収入であっても、産業の成長を持続させる仕組みになる。[^u083]

## 帝国交通整備基金（検討案）

賠償金1億2,000万両の半額にあたる6,000万両を長期の交通整備基金へ振り向ける配分例:

| 用途 | 配分額（万庫平両） |
|---|---:|
| 幹線鉄道・複線化 | 3,000 |
| 国道・高規格道路 | 1,500 |
| 港湾・橋梁 | 900 |
| 通信・測量・技術教育 | 600 |
| 合計 | 6,000 |

[^u083]

清国の賠償金は一括で受け取れるとは限らないため、実際の建設費は賠償金を返済原資とする帝国債の発行や毎年の財政収入と組み合わせて調達する。また初期にはレールや機関車を輸入する必要があるため、公共投資がすぐにすべて国内の重工業需要になるわけではなく、国産化を進める技術導入政策が不可欠である。[^u083]（[対清賠償借款と講和の国際金融](/economy/indemnity-loan.md)参照）

# 帝国交通例（検討案）

本世界線の[領主権](/institutions/lordship-rights.md)は中央政府の委任権限ではなく憲法で保障された権利であるため、国家が領主の土地を横断して鉄道や国道を建設するには、用地取得・道路管理・収用・通行規制を定める必要があり、中央政府が一方的に用地を取り上げることは難しい。そこで元老院が全国共通の「帝国交通例」を制定する。[^u083]

| 原則 | 内容 |
|---|---|
| 公共事業の定義 | 国道と幹線鉄道を帝国の公共事業として定義する |
| 用地取得 | 必要な用地は適正な補償によって取得する |
| 通行税の禁止 | 領主は建設を妨げる恣意的な通行税を課せない |
| 損失補償 | 工事による農地・住宅の損失は補償する |
| 地方交通網 | 各領国の地方交通網は領主の管理権を残しつつ国の幹線と接続する |

[^u083]

元老院の領主議員自身が合意した法律であれば、中央政府による一方的な権利侵害ではなく、**諸領主による共同の国家事業**として正当化できる。中央政府の交通網整備権限と各領主の領主権が両立する。[^u083] これは[全国標準化政策](/institutions/national-standardization.md)で鉄道規格や全国市場の統一を早期に実現していたことの延長でもある。[^u082]

# 「路線の配分」の政治

領主たちは直接的な恩賞金よりも、「うちの領国に鉄道を通してほしい」「この港を国際港として整備してほしい」と要求するようになる。「我が家は日清戦争に大きく貢献したのだから、我が領国の鉄道建設を優先してほしい」という政治交渉は、近代的な公共事業政治であると同時に伝統的な論功行賞の延長である。[^u083]

全領主の要求を無条件に受け入れると不採算路線が大量に建設される危険があるため、全国の幹線網は国が統一的に計画し、領国への接続線は費用対効果や領主負担を考慮して決定する。**論功行賞を公共事業に変換することはできても、論功行賞の政治そのものが消えるわけではない。**[^u083]

# 経済的効果

## 重工業への波及

| 公共投資 | 波及する需要 |
|---|---|
| 鉄道建設・複線化 | レール・車両・橋梁 |
| 高規格国道整備 | 鋼橋・建設機械・セメント |
| 港湾整備 | 岸壁・荷役機械・造船 |
| 通信・送電 | 銅線・電機・発電設備 |

戦勝賠償金・帝国交通整備予算は、これらを経て製鉄・機械・化学工業への継続的需要となる。[^u083]

## 鉄道営業距離の試算（検討案）

日本本土・北海道を対象とし、台湾・朝鮮を含めない中核シナリオ:

| 年 | 粗鋼生産 | 鉄道営業距離 |
|---|---|---|
| 1889 | 10万〜20万t | 3,000〜4,500km |
| 1895 | 30万〜60万t | 5,500〜7,500km |
| 1900 | 80万〜150万t | 8,000〜11,000km（約9,000km） |
| 1905 | 150万〜250万t | 11,000〜14,000km |

[^u084]

史実の日本の鉄道営業距離は1892年約3,107km、1907年約7,808kmであり、本世界線は1900年の時点で史実の1907年を上回る。[^u084]

## 領主経済の統合

全国的な鉄道・国道が完成すれば、人・物資・資本は領国の境界を越えて移動し、領主たちは自領の経済を発展させるため積極的に全国市場へ参加するようになる。領主権は存続しても、領主経済は全国的な産業体系に組み込まれていく。**領主権を取り上げずに、領主たち自身の利益によって経済統合を進める**——これが本計画の最大の国制上の意味である。[^u083]（[近代封建制](/concepts/modern-feudalism.md)参照）

# 安全保障・財政上の意味

* **軍民両用**: 交通網整備は平時には経済成長を、有事には動員を支え、軍事費と民生投資を対立させずに済む。[^u087]
* **対露競争**: 1890年代の日本は鉄道網・重工業・海軍近代化を進めており、対露軍拡競争の必要が史実より小さいため、賠償金を交通網・製鉄・電力・工作機械に投資できる。[^u092]
* **戦費との競合**: 対露臨時軍事費の財源として賠償金・交通整備基金を転用すれば、約束済みの鉄道・道路・港湾事業を削ることになり、元老院・衆議院の反発を招く。[^u088]
* **大陸非関与の利点**: 戦間期に至っても、満洲に大規模駐屯軍を置かず植民地行政を負わないため、国内の鉄道・国道・電力・化学・機械工業へ投資を優先できる。[^u102]
* **財政慎重論**: 1920年代にも、交通整備優先の財政慎重論が平時軍事費を国民所得の4〜6%に抑える前提の一つとされる。[^u126]
* **震災復興**: 1923年の関東大震災では、全国交通網が発達しているため西日本から復興資材を送り込める。複数領国にまたがる被災には、国道・鉄道整備時と同様に元老院を通じた共同負担制度が重要となる。[^u133]（[関東大震災](/events/great-kanto-earthquake.md)参照）

# 未決の論点

* 交通整備基金の実際の規模と配分（6,000万両案は設定検討用の仮定）。[^u083]
* 賠償金の受領方式と、帝国債発行による前倒し調達の範囲。[^u083]
* 1889年時点の幹線鉄道の完成度と、レール・機関車の国産化の時期。[^u082][^u083]
* 1890/1895/1900/1905年の国力（財政規模・鉄道・粗鋼など）を揃えて設定すること。[^u084]
