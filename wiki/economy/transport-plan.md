# 概要

帝国交通整備計画は、1889年の[下関条約](/diplomacy/shimonoseki-treaty-1889.md)で得た賠償金の使途として成立した、全領国を対象とする横断的な交通公共事業である。賠償金の分配に悩むくらいなら、はじめからすべての領国にメリットのある横断的な公共事業をやってしまえ、という意見が自然に出てきた結果であり、需要喚起策として国道・高速国道と鉄道の整備を行うという方向は確定設定である。[^u083]

政府原則は「**戦勝の利益は帝国全土に還元する。各領国を国道・鉄道・港湾によって接続し、その建設費を帝国が負担する**」である。[^u083] 元老院にも衆議院にも説明しやすく、中央政府は全国的な物流・軍事輸送網を掌握できる。**全員に利益があるからこそ、中央政府の権限強化も受け入れられる**という構造が、この計画の政治的な核心である。[^u083]

計画は1889〜1904年の15年計画とされ、賠償金の半額6,000万両を「帝国交通整備基金」に充てる配分例、領主権との調整を定める「帝国交通例」などが構想されている（いずれも検討案）。[^u083] 長期的には、日清戦争後の論功行賞として始まった公共事業が、アメリカと競争できる工業経済の基盤になったと評価されうる。[^u083]

計画は政治的にも、元老院（領国の産業開発・交通整備）と衆議院（選挙区の経済発展・雇用）が鉄道・国道・港湾・電力・教育で手を組む両院横断の「開発政治」を生んだ（ダイス判定：難易度20、出目87・成功）。[^p005]

その後の交通網は、1930年代の恐慌対策の公共投資（鉄道の複線化・電化、道路、港湾の荷役機械化）を経て、1937年には**鉄道営業距離45,000km**（帝国鉄道50%・領国政府鉄道15%・民間鉄道35%、電化13,500km）、自動車等保有133万台、全国港湾取扱量2億2,400万tの段階に達した。領国政府が存続するため、鉄道は帝国鉄道への一元化ではなく帝国・領国・民間の並立となっている。[^e049][^p090][^p096][^p097]

# 成立の経緯

## 論功行賞からの転換

日清戦争後、戦功を誰の功績とし、領主家に何を与えるかをめぐって[論功行賞](/events/reward-distribution-1889.md)の政治が生じた。特定の家への加増は元老院の力関係を変え、衆議院の反発を招く。[^u078] これに対し、賠償金を特定の領国に集中投資すれば他の領主から不満が出るため、全領国を結ぶ国家的な交通網に投資する方が[元老院](/institutions/genroin.md)で合意を形成しやすい。[^u083]

| 主体 | 交通網整備の利点 |
|---|---|
| 元老院の領主議員 | 自家の領国の交通条件と産業立地が改善する |
| 衆議院 | 軍功のある特定の家への加増ではなく、一般の商工業者や住民にも利益が及ぶ |
| 中央政府 | 全国的な物流・軍事輸送網を掌握できる |

[^u083]

## 重工業化との関係

重工業化を日清戦争の賠償金から始めるのでは遅く、賠償金は既存基盤の拡大資金にしかならない。そして重工業化の本当の制約は製鉄所の建設よりも**需要の形成**である。各領主が小規模製鉄所を乱立させれば遊休化するため、中央政府による全国鉄道網、商船・軍艦の国内建造、港湾・橋梁・都市インフラ、機械の国産化によって需要を作る必要がある。[^u082] 交通整備計画は、この需要形成策の中核に位置づけられる。（[重工業化と国力の推移](/economy/heavy-industrialization.md)参照）

# 計画の内容

## 交通の区分

1889年にはまだ自動車が一般的な輸送手段ではないため、現代的な自動車専用高速道路をすぐ建設するのは需要の面で早すぎる。そこで次の区分が設けられる（検討案）。[^u083]

| 区分 | 1889年時点での役割 |
|---|---|
| 国道 | 領国間の一般交通、馬車、物資輸送、郵便 |
| 高速国道 | 幹線の高規格馬車道。緩勾配、広い幅員、橋梁整備、通過交通を優先 |
| 鉄道 | 大量貨物、長距離旅客、兵員輸送 |
| 領道 | 国道・鉄道駅・港湾と各領国内の集落を接続（領主が管理） |

**高速国道**は当初、高速馬車や貨物馬車の運行を想定した高規格の幹線道路である。ただし自動車の普及を見越して用地を広く確保し、将来の立体交差化や車道拡幅に対応できる設計とする。これにより1900年代以降に自動車交通が普及した際の改良費を抑えられる。[^u083]

## 鉄道

本世界線では1860年代から近代化が始まり、有力領主が早期に鉄道投資を行っているため、1889年の段階ですでに東海道・山陽道・東北道などの幹線が相当程度完成していても不思議ではない。[^u083] そのため賠償金は新線建設だけでなく、既存線の改良にも投じられる。

* 単線の複線化
* 橋梁の鋼橋への架け替え
* トンネルの拡張
* 輸送力の大きい機関車への更新

[^u083]

## 15年計画

工事を数年に集中させず、1889年から1904年までの15年間を対象とした整備計画を制定する。製鉄所や車両工場が長期需要を見込んで設備投資できるようにするためで、賠償金が一時的な財政収入であっても、産業の成長を持続させる仕組みになる。[^u083]

## 帝国交通整備基金（検討案）

賠償金1億2,000万両の半額にあたる6,000万両を長期の交通整備基金へ振り向ける配分例:

| 用途 | 配分額（万庫平両） |
|---|---:|
| 幹線鉄道・複線化 | 3,000 |
| 国道・高規格道路 | 1,500 |
| 港湾・橋梁 | 900 |
| 通信・測量・技術教育 | 600 |
| 合計 | 6,000 |

[^u083]

清国の賠償金は一括で受け取れるとは限らないため、実際の建設費は賠償金を返済原資とする帝国債の発行や毎年の財政収入と組み合わせて調達する。また初期にはレールや機関車を輸入する必要があるため、公共投資がすぐにすべて国内の重工業需要になるわけではなく、国産化を進める技術導入政策が不可欠である。[^u083]（[対清賠償借款と講和の国際金融](/economy/indemnity-loan.md)参照）

# 帝国交通例（検討案）

本世界線の[領主権](/institutions/lordship-rights.md)は中央政府の委任権限ではなく憲法で保障された権利であるため、国家が領主の土地を横断して鉄道や国道を建設するには、用地取得・道路管理・収用・通行規制を定める必要があり、中央政府が一方的に用地を取り上げることは難しい。そこで元老院が全国共通の「帝国交通例」を制定する。[^u083]

| 原則 | 内容 |
|---|---|
| 公共事業の定義 | 国道と幹線鉄道を帝国の公共事業として定義する |
| 用地取得 | 必要な用地は適正な補償によって取得する |
| 通行税の禁止 | 領主は建設を妨げる恣意的な通行税を課せない |
| 損失補償 | 工事による農地・住宅の損失は補償する |
| 地方交通網 | 各領国の地方交通網は領主の管理権を残しつつ国の幹線と接続する |

[^u083]

元老院の領主議員自身が合意した法律であれば、中央政府による一方的な権利侵害ではなく、**諸領主による共同の国家事業**として正当化できる。中央政府の交通網整備権限と各領主の領主権が両立する。[^u083] これは[全国標準化政策](/institutions/national-standardization.md)で鉄道規格や全国市場の統一を早期に実現していたことの延長でもある。[^u082]

# 「路線の配分」の政治

領主たちは直接的な恩賞金よりも、「うちの領国に鉄道を通してほしい」「この港を国際港として整備してほしい」と要求するようになる。「我が家は日清戦争に大きく貢献したのだから、我が領国の鉄道建設を優先してほしい」という政治交渉は、近代的な公共事業政治であると同時に伝統的な論功行賞の延長である。[^u083]

全領主の要求を無条件に受け入れると不採算路線が大量に建設される危険があるため、全国の幹線網は国が統一的に計画し、領国への接続線は費用対効果や領主負担を考慮して決定する。**論功行賞を公共事業に変換することはできても、論功行賞の政治そのものが消えるわけではない。**[^u083]

## 両院横断の開発政治（1889〜1904年）

会話ログ3の政治史では、1889〜1900年の政治がダイスで判定され、交通整備・産業振興の両院横断的な開発政治が成立した（難易度20、出目87・成功）。一方、日清戦争後の論功行賞をめぐる両院対立の円滑な調整は失敗し（難易度35、出目24）、公共事業の利益誘導・汚職が深刻な政治問題になることはなかった（難易度45、出目34・失敗＝深刻化せず）。[^p005]

| 参加主体 | 開発政治に参加する理由（検討案） |
|---|---|
| 領主 | 領国経済の発展・領主家資産の収益 |
| 地方名望家 | 販路拡大・地価上昇 |
| 都市商工業者 | 全国市場・輸送費の低下 |
| 金融業者 | 設備投資の資金需要 |
| 帝国官僚 | 全国的な行政基盤 |
| 軍部 | 兵站・動員 |

[^p005]

汚職が全国問題化しなかったことから、官僚による技術審査・費用積算が重視される制度が生まれた可能性がある（監査制度は別途検討）。交通整備・産業振興という共通政策は、元老院主導の非政党内閣に代わる政党中心内閣の余地を作り、1900年までに最初の本格的政党内閣が成立した（難易度35、出目52・成功）。[^p005]（→[内閣の系譜と政党内閣の慣行（1867〜1937）](/politics/party-cabinets.md)、[政党の系譜と衆議院の議席推移（1876〜1937）](/politics/political-parties.md)）

# 経済的効果

## 重工業への波及

| 公共投資 | 波及する需要 |
|---|---|
| 鉄道建設・複線化 | レール・車両・橋梁 |
| 高規格国道整備 | 鋼橋・建設機械・セメント |
| 港湾整備 | 岸壁・荷役機械・造船 |
| 通信・送電 | 銅線・電機・発電設備 |

戦勝賠償金・帝国交通整備予算は、これらを経て製鉄・機械・化学工業への継続的需要となる。[^u083]

## 鉄道営業距離の試算（検討案）

日本本土・北海道を対象とし、台湾・朝鮮を含めない中核シナリオ:

| 年 | 粗鋼生産 | 鉄道営業距離 |
|---|---|---|
| 1889 | 10万〜20万t | 3,000〜4,500km |
| 1895 | 30万〜60万t | 5,500〜7,500km |
| 1900 | 80万〜150万t | 8,000〜11,000km（約9,000km） |
| 1905 | 150万〜250万t | 11,000〜14,000km |

[^u084]

史実の日本の鉄道営業距離は1892年約3,107km、1907年約7,808kmであり、本世界線は1900年の時点で史実の1907年を上回る。[^u084]

## 領主経済の統合

全国的な鉄道・国道が完成すれば、人・物資・資本は領国の境界を越えて移動し、領主たちは自領の経済を発展させるため積極的に全国市場へ参加するようになる。領主権は存続しても、領主経済は全国的な産業体系に組み込まれていく。**領主権を取り上げずに、領主たち自身の利益によって経済統合を進める**——これが本計画の最大の国制上の意味である。[^u083]（[近代封建制](/concepts/modern-feudalism.md)参照）

# 安全保障・財政上の意味

* **軍民両用**: 交通網整備は平時には経済成長を、有事には動員を支え、軍事費と民生投資を対立させずに済む。[^u087]
* **対露競争**: 1890年代の日本は鉄道網・重工業・海軍近代化を進めており、対露軍拡競争の必要が史実より小さいため、賠償金を交通網・製鉄・電力・工作機械に投資できる。[^u092]
* **戦費との競合**: 対露臨時軍事費の財源として賠償金・交通整備基金を転用すれば、約束済みの鉄道・道路・港湾事業を削ることになり、元老院・衆議院の反発を招く。[^u088]
* **大陸非関与の利点**: 戦間期に至っても、満洲に大規模駐屯軍を置かず植民地行政を負わないため、国内の鉄道・国道・電力・化学・機械工業へ投資を優先できる。[^u102]
* **財政慎重論**: 1920年代にも、交通整備優先の財政慎重論が平時軍事費を国民所得の4〜6%に抑える前提の一つとされる。[^u126]
* **震災復興**: 1923年の関東大震災では、全国交通網が発達しているため西日本から復興資材を送り込める。複数領国にまたがる被災には、国道・鉄道整備時と同様に元老院を通じた共同負担制度が重要となる。[^u133]（[関東大震災](/events/great-kanto-earthquake.md)参照）

# 1930年代の展開（1930〜1937）

## 恐慌期の公共投資

15年計画が完了した後も、交通網への投資は帝国の開発財政の柱であり続けた。1925年に資本形成を伴う支出に限って公債を認める財政原則が定まり、世界恐慌に際しては失業救済よりも公共事業が優先された。恐慌対策の公共事業には、幹線鉄道の複線化・電化、全国電力網、港湾拡張と荷役機械化、道路網、河川改修・治水・灌漑、公営住宅、資源備蓄施設が挙げられる。[^e048] 公共固定資本形成のGDP比は1929年3.5%から1932〜33年の7%を頂点に、1936〜37年には5%となった。[^e098]（→[1925年財政原則と恐慌期の公共投資](/economy/fiscal-principles-1925.md)）

| 用途 | 配分（検討案） | 主な内容 |
|---|---:|---|
| 鉄道 | 25% | 複線化・電化・貨物能力 |
| 道路・橋梁 | 20% | 道路網 |
| 電力 | 15% | 発電・広域送電網 |
| 港湾・物流 | 15% | 拡張・荷役機械化・倉庫 |
| 治水・灌漑 | 10% | 河川改修 |
| 都市基盤 | 10% | 上下水道・住宅・都市交通 |
| 教育・医療施設 | 5% | ― |

[^e049] 新線建設より既存インフラの能力増強が重視され、1936年頃までに幹線鉄道の貨物輸送能力は20〜35%、主要港湾の荷役能力は30〜50%増え、改良区間の陸上輸送費は10〜20%下がったとされる（検討案）。[^e049] 1889年以来の「全領国に利益のある横断的公共事業」という考え方が、恐慌対策として再び用いられたことになる。

### 電化と輸送量

幹線鉄道の電化は1d100 > 40に対し76で成功し、主要工業地域で大規模に進んだ。[^e079] 1937年の電化区間は13,500km（30%）で、京都・大阪・神戸、江戸・横浜、名古屋の都市圏と、山岳幹線・工業地帯の貨物路線が電化されている。非電化の31,500kmは蒸気機関車が主力のため、鉄道用石炭650万tが必要となる。交通向け電力65億kWhのうち幹線・地域鉄道が48億kWh、路面電車・都市交通が12億kWhである。[^p089][^p090]

貨物は3億t（平均180km、540億t-km）、旅客は40億人回（平均25km、1,000億人-km、1人年約51回）で、史実1937年の日本の鉄道輸送（貨物182.5億t-km、旅客290.5億人-km）の約3倍の規模となる。[^e091][^p090] 鉄道三等の運賃は100kmで約1.50円、路面電車は1乗車約0.05円とされる。[^p092]

### 1937年度の交通投資

1937年度の帝国政府の資本的支出17.5億円（艦艇建造3.5億円を含む。作者確定）のうち、帝国鉄道の建設・電化に3.0億円、港湾・航路施設に1.8億円、道路・橋梁に1.5億円が充てられ、建設公債で賄われる。地方（領国）政府の資本的支出10億円のうち2.8億円が地方鉄道・道路、1.0億円が地方港湾・物流である。[^p093]（→[1937年度の帝国財政と連結政府財政](/economy/public-finance-1937.md)）領国間の行政サービス格差を示す暫定指数では、道路・交通は大都市・工業領国140に対し北海道開拓領国60・小規模領国65と大きな差がある（検討案）。[^p095]（→[領国の類型・財政と財政調整交付金（1937）](/economy/fief-finance-1937.md)）

## 自動車化と複合輸送

1937年の自動車等保有は133万台（乗用車・タクシー等65万台、貨物自動車40万台、バス5万台、二輪車・その他23万台）、人口1,000人当たり約17台で、一般家庭への普及よりも企業・商業・貨物・公共交通での利用が先行している。保有台数は道路輸送用石油200万tから逆算された。尾張徳川系・豊田系・独立系機械企業が自動車産業を支える。[^p090]

| 輸送機関 | 主な役割 |
|---|---|
| 内航海運 | 重量原材料・長距離大量輸送 |
| 帝国鉄道 | 全国幹線・領国間輸送 |
| 領国・民間鉄道 | 地域産業・都市間・近郊輸送 |
| 貨物自動車 | 短距離輸送・工場と駅や港の連絡 |
| バス・路面電車 | 都市・地方の旅客輸送 |
| 航空 | 郵便・旅客・高付加価値貨物 |

[^p090]

鉄道貨物と自動車物流の連携は1d100 > 30に対し31の「ぎりぎりの成功」で、全国的に統合された物流網ではなく、地域ごとの実用的な複合輸送網にとどまり、鉄道と自動車の競争も残る。大規模な道路貨物輸送業（52、成功）と港湾荷役・倉庫の機械化（48、成功）も成立した。[^e085] 港湾は鉱石・石炭専用荷揚げ設備、石油桟橋、冷蔵倉庫、工業地帯への鉄道直結を備え、臨海一貫製鉄所や輸入資源の荷揚げと一体化している。[^e084] 運輸業・港湾の詳細は[運輸・商業・通信・金融サービス（1937）](/economy/services-1937.md)を参照。

# 却下・修正された案

* **1937年の交通網（会話ログ2の推計）**: 鉄道営業延長32,000km（台湾を含む、電化12,800km・延長の40%、主要幹線の電化率65%）、鉄道貨物450億t-km・旅客650億人-km、自動車保有250万台（自家用乗用車125万・貨物自動車85万台、人口1,000人当たり約32台）、港湾取扱量1億9,000万t、国内貨物輸送仕事量の分担（鉄道450億t-km・43.6%、内航312億t-km・30.3%、自動車249億t-km・24.2%、河川その他20億t-km・1.9%）、鉄道用石炭約500万t、「家庭向け乗用車と自動車物流が相当程度普及」 → 会話ログ3の確定値（鉄道45,000km・電化13,500km・30%、貨物540億t-km、旅客1,000億人-km、自動車133万台で業務利用が先行、港湾2億2,400万t、鉄道用石炭650万t）に置き換え。理由：会話ログ3は後の決定で、P90の積算がP96の最終集計・P97の確定宣言（鉄道営業距離45,000kmは確定値表に明記）で確定したため。[^e079][^e084][^e089][^e091][^p089][^p090][^p096][^p097]

# 未決の論点

* 交通整備基金の実際の規模と配分（6,000万両案は設定検討用の仮定）。[^u083]
* 賠償金の受領方式と、帝国債発行による前倒し調達の範囲。[^u083]
* 1889年時点の幹線鉄道の完成度と、レール・機関車の国産化の時期。[^u082][^u083]
* 1890/1895/1900/1905年の国力（財政規模・鉄道・粗鋼など）を揃えて設定すること。[^u084]
* 1905年（11,000〜14,000km）から1937年（45,000km、台湾等2,000kmを含む）までの鉄道網の拡大経路と、帝国鉄道・領国政府鉄道・民間鉄道それぞれの形成過程。[^u084][^p090]
* 1889年計画で自動車化を見越して用地を確保した高速国道が、1930年代の自動車物流（保有133万台）でどう使われたか。会話ログ2・3とも道路網そのものの延長・規格は設定されていない。[^e084][^p090]
* 公共事業の監査制度の具体像。[^p005]
* 1930年代の公共投資の配分比率と生産性効果は設定案のまま。[^e049]
