# 概要

1925年に金本位制を法的に廃止した日本は、金という客観的な通貨発行の基準を失った。そこで制度改正の最大の論点は「何をもって健全な通貨発行と財政運営の限界とするか」になった。[^e047] 答えとして制度化されたのが、**経常予算は原則として経常収入で賄い、資産形成を伴う事業に限って議会の承認を得て公債を発行できる**という財政原則である（確定）。ユーザーの言葉では「赤字国債で公共事業投資はやっていいが、消費支出はダメという線」であり、後世の建設国債と赤字国債の区別に近い。[^e048]

この原則は、不換紙幣の濫発を防ぐための財政規律として導入された。金本位制の廃止で解消されたのは中央銀行の金兌換義務であって政府の予算制約ではなく、不換紙幣への不信を払拭するため、1925年の政府はむしろ財政規律を強調した（確定）。[^e047][^e048]

しかし同じ原則は、世界恐慌に際して「均衡財政主義を放棄することなく、大規模な財政赤字を伴う公共投資を実施できる」根拠にもなった。日本は1930年度から公債による公共投資を拡大し、公共固定資本形成はGDP比で1929年の3.5%から1932〜33年の7.0%へ倍増した。満洲事変がなくロンドン条約で海軍の純増も制限されていたため、投資は鉄道・道路・電力・港湾などの民生インフラに向かい、「**史実より浅い恐慌、史実より民生部門に偏った回復、そしてより大きな公共資本の蓄積**」が1930年代前半の日本経済の特徴となった。[^e048][^e049][^e098]

# 背景：金に代わる財政制約

## 五つの制約

1925年時点では、財政支出と総需要の関係について現代のような共通認識はまだない。金本位制に代わる財政・金融政策の制約として認識され得るのは次の五つである（有力案）。[^e047]

| 制約 | 政策担当者の認識 |
|---|---|
| 物価水準 | 過剰な通貨発行は物価騰貴を招く |
| 為替相場 | 円の信用低下は国際決済を困難にする |
| 国際収支 | 対外支払能力を維持する必要がある |
| 国債消化能力 | 民間金融市場が吸収できる公債には限度がある |
| 政府の信用 | 将来の租税収入によって債務を履行できなければならない |

[^e047]

## 財政制約と通貨発行制約の区別

| | 金本位制時代 | 1925年以降 |
|---|---|---|
| 中央銀行の発券制約 | 金準備・兌換能力 | 通貨価値・信用秩序 |
| 政府の歳出制約 | 税収・公債発行能力 | 基本的に従来通り |
| 国債発行 | 民間金融市場を中心とする | 同左 |
| 中央銀行の国債保有 | 限定的 | 金融調節のために拡大可能 |
| 政府への直接信用供与 | 例外的 | 引き続き例外的 |

[^e047]

## 商業信用を基礎とする発券思想

日本が金本位制を断念したのは財政赤字を賄うためではなく、実体経済の拡大や国際的な円建て決済の需要に金準備が対応できなくなったためであった（→[金本位制離脱と管理通貨制](/economy/gold-standard.md)）。そのため1925年の制度改革で金準備に代わって重視されたのは、商業手形・貿易手形、金融機関への担保付き貸出、流動性の高い対外債権、国債など信用力の高い有価証券、金・外国通貨である。[^e041][^e047]

当時の政策担当者は「正常な商業活動に伴う通貨需要を満たす発券は健全だが、政府の経常的な赤字を補う発券は不健全」と考えた。**金に代わる通貨の裏付けは、国家の徴税能力だけでなく、国内外の商業信用と生産活動である**という認識である。ただし商業手形を基準に金融政策を運営すると、恐慌時には商業活動の縮小とともに信用供給まで縮むという欠点がある（有力案）。[^e047]

# 1925年の財政金融制度

## 財政原則（確定）

1. 経常予算は原則として経常収入で賄う。
2. 資産形成を伴う事業については、議会の承認を得て公債を発行できる。
3. 公債は原則として民間金融市場で消化する。
4. 中央銀行による直接引受は非常時に限定する。
5. 通貨発行は金準備ではなく、物価・信用秩序・対外決済能力によって制約される。

[^e048]

## 制度の全体像（有力案）

| 制度 | 内容 |
|---|---|
| 通貨価値の維持 | 国内物価・為替・対外決済能力を総合的に判断 |
| 金準備率 | 法定の最低準備率を廃止 |
| 発券制度 | 適格資産を裏付けとして発券 |
| 経常予算 | 原則として租税その他の経常収入で賄う |
| 資本予算 | 議会の承認による公債発行を認める |
| 国債消化 | 原則として民間金融市場 |
| 中央銀行の国債購入 | 金融調節の手段として認める |
| 国債の直接引受 | 非常時に限定 |
| 外貨準備 | 対外決済上の必要性に応じて保有 |

[^e047]

これは現代的な意味での積極財政主義ではなく、「**信用本位の通貨制度と、資産形成を重視する健全財政思想の組み合わせ**」である。[^e047]

## 公債発行の可否

| 支出項目 | 公債発行 | 理由 |
|---|---|---|
| 鉄道・道路建設 | 可 | 社会資本の形成 |
| 港湾整備 | 可 | 通商能力の拡大 |
| 発電所・送電網 | 可 | 生産能力の拡大 |
| 上下水道 | 可 | 恒久的な公共資産の形成 |
| 学校・病院建設 | 可 | 長期的な公共利益 |
| 戦略資源備蓄 | 可 | 売却可能な政府資産の取得 |
| 軍艦・軍事施設建造 | 条件付きで可 | 耐久資産だが経済的収益性に乏しい |
| 官吏・軍人の給与 | 不可 | 経常的な消費支出 |
| 社会保障・生活扶助 | 原則不可 | 経常的な移転支出 |
| 既存施設の維持管理 | 原則不可 | 経常的な維持費 |

（確定）[^e048]

公共事業に直接従事する労働者の賃金は建設費の一部として公債で賄えるが、失業者に直接生活費を給付する場合は経常予算から支出しなければならない。この違いが恐慌への対応を大きく左右した。[^e048] 1億円の国債で官吏の給与を払うことと、1億円の国債で鉄道や石油備蓄施設を取得することは、当時の財政担当者にとって全く異なる意味を持つ。後者には将来の収益や国有資産が残るからである。[^e047] 戦略資源備蓄が公債の対象となったことは、[戦略資源備蓄制度](/economy/strategic-stockpile.md)の拡大を財政面から支えた。[^e043][^e048]

## 公債発行額の制約

資産形成を伴えば無制限に公債を発行できるとは考えられていない。[^e048]

| 制約 | 判断基準 |
|---|---|
| 資産価値 | 支出に見合った公共資産が形成されるか |
| 公債消化能力 | 民間金融市場で公債を消化できるか |
| 債務償還能力 | 将来の租税・事業収入で元利払いができるか |
| 物価 | 資材や労働力の不足による価格騰貴が生じないか |
| 対外決済能力 | 輸入増加によって外貨不足が生じないか |

[^e048]

恐慌下では民間の資金需要が減り物価も下がっているので、これらの制約の多くが緩む。従来の健全財政思想を維持したままでも、平時より大規模な公債発行が可能になる。[^e048]

# 恐慌期の財政論争（1930〜1931）

輸出減少と企業収益の悪化で税収が減り政府の財政余力が落ちる一方、民間投資も減って銀行に資金が滞留し、遊休設備が増える。こうして**政府の借入需要と民間の余剰資金が同時に発生**すると、国債発行が民間の資金調達を圧迫するという従来の懸念は弱まる。[^e047] 1930〜31年の日本では三つの財政思想が対立した（有力案）。[^e047]

| | 健全財政派 | 開発財政派 | 通貨拡張派 |
|---|---|---|---|
| 財政制約 | 税収・国債償還能力 | 取得資産の価値・国債消化能力 | 物価・実体経済の供給能力 |
| 恐慌への対応 | 歳出削減 | 公共投資・備蓄拡大 | 赤字財政・金融緩和 |
| 国債発行 | 抑制 | 資本支出に限定して容認 | 経常赤字にも容認 |
| 中央銀行 | 通貨信用の維持 | 民間金融の補完 | 景気回復のための信用供給 |

[^e047]

1925年の通貨制度改革の経緯から、**開発財政派**がすでに一定の政治的影響力を持ち、財政赤字そのものを景気対策に使う通貨拡張派はまだ少数派である。[^e047] 1931年の財政政策は「通貨発行の限界は通貨価値と対外決済能力にあり、政府支出の限界は公債の消化能力と将来の債務履行能力にある」と整理され、資産形成を目的とする支出は経常支出と区別されるので、公共投資や戦略備蓄は相当規模の拡張が可能と認識される。[^e047]

政策担当者は必ずしも総需要の拡大を理論的に理解している必要はない。「**民間資金が余り、工業設備も遊休化し、建設資材も安くなっているのだから、この機会に必要な国家資産を取得すべきだ**」という論理だけで積極財政を正当化できる。[^e048] そして回復の過程で初めて、「財政の限界は金融資産の量だけでなく、利用可能な労働力・設備・資源によって決まるのではないか」という認識が広まっていく。[^e047]

# 恐慌期の公共投資（1930〜1936）

## 恐慌対策は失業救済より公共事業へ

失業者への直接給付には財政上の抵抗があるが、公共事業を起こして失業者を雇うことには抵抗が少ない。そのため日本の恐慌対策は、幹線鉄道の複線化・電化、全国的な電力網の整備、港湾の拡張と荷役の機械化、道路網の整備、河川改修・治水・灌漑、公営住宅の建設、資源備蓄施設の建設と備蓄の積み増しに集中した（確定）。[^e048] 管理通貨制の日本は史実より早く金融緩和ができ、石油備蓄に伴う貯油槽・ポンプ、港湾のクレーン・浚渫船、商船・タンカー、電力網、鉄道電化、住宅・都市整備によって国内の工業需要を作り出せた。1930〜31年の段階で大規模な公共投資の条件が揃っていた。[^e046]

史実の日本でも1932〜34年に時局匡救事業が行われたが、同時に満洲事変以降の軍事費も増えていた。本世界線では満洲事変がなく、ロンドン条約で海軍の純増も制限され、1925年の段階で公債による資本形成を認める財政原則が成立しているため、**史実より早い1930年度から、軍事費ではなく民生用の社会資本に重点を置いて**公共投資を拡大できた。[^e049]

## 公共投資の規模

| 年 | 公共固定資本形成/GDP | うち平時分 | 追加分 | 政策の段階 |
|---|---:|---:|---:|---|
| 1929 | 3.5% | 3.5% | 0 | 通常の公共投資 |
| 1930 | 4.5% | 3.5% | 1.0 | 恐慌対策開始 |
| 1931 | 6.0% | 3.5% | 2.5 | 本格的な公債発行 |
| 1932 | 7.0% | 3.5% | 3.5 | 公共投資の最盛期 |
| 1933 | 7.0% | 3.5% | 3.5 | 大規模事業の継続 |
| 1934 | 6.5% | 3.5% | 3.0 | 景気回復に伴う調整 |
| 1935 | 5.5% | 3.5% | 2.0 | 通常の開発財政へ移行 |
| 1936 | 5.0% | 3.5% | 1.5 | 財政拡張の縮小 |
| 1937 | 5.0% | — | — | 1936年の率を維持 |

[^e049][^e098]

1929〜36年の比率は E49 の設定案で、E98 の支出面GDP検証で既存設定として再掲・使用されたので確定扱いとする（1937年の5%は E98 の仮定）。[^e049][^e098] この数字には資源の備蓄購入費や対外融資は含まず、国内の固定資本形成だけである。GDP比7%は大規模だが国家総動員的というほどではなく、既存の行政機構と民間建設業で実施できる範囲とされる。[^e049] 1937年の公共固定資本形成は13.01億ドル相当（1937年米国価格基準、GDP260.26億ドル相当の5%）で、軍艦など長期使用する軍事設備もこの枠に含めている。[^e098]

## 配分

| 分野 | 配分 | 主な事業 |
|---|---:|---|
| 鉄道 | 25% | 複線化・電化・貨物輸送能力の拡大 |
| 道路・橋梁 | 20% | 幹線道路・地方道路の改良 |
| 電力 | 15% | 発電・広域送電網 |
| 港湾・物流 | 15% | 港湾拡張・荷役機械化・倉庫 |
| 治水・灌漑 | 10% | 農業生産性と防災能力の向上 |
| 都市基盤 | 10% | 上下水道・住宅・都市交通 |
| 教育・医療施設 | 5% | 学校・研究施設・病院 |

（有力案）[^e049]

すでに工業化が進んだ日本では、新線の敷設より既存インフラの輸送能力の増強が重視される。失業対策としての即効性と長期的な生産性向上を両立させる配分である。[^e049] 詳細な交通網の整備は[帝国交通整備計画](/economy/transport-plan.md)を参照。

## 生産性への効果

簡易モデルとして、1929年末の公共資本ストックをGDPの70%（50〜100%で可変）、年間減耗率2.5%、1930年代の平均実質成長率4%、公共資本に対する生産弾力性0.12（0.05〜0.25で可変）を置いた（検討用、有力案）。[^e049]

| 分野 | 1936年頃までの改善幅（有力案） |
|---|---:|
| 幹線鉄道の貨物輸送能力 | 20〜35%増加 |
| 主要港湾の荷役能力 | 30〜50%増加 |
| 電力供給能力 | 30〜50%増加 |
| 改良区間の陸上輸送費 | 10〜20%低下 |
| 公共投資による経済全体の追加的な潜在生産向上 | 2〜4%程度 |

[^e049]

恐慌期の財政支出は景気回復後も公共資本として残り、電力や輸送の制約が解消されれば民間の設備投資も誘発される。ただし公共投資だけで成長率が恒久的に倍増するという設定にはしない。[^e049]

## 恐慌と回復の経路

|---|---:|---:|---:|
| 1929 | +5.0% | 100 | 229.1億円 |
| 1930 | −1.0% | 98 | 222.3億円 |
| 1931 | −1.0% | 96 | 215.6億円 |
| 1932 | +3.0% | 97 | 224.3億円 |
| 1933 | +5.0% | 99 | 240.4億円 |
| 1934 | +5.0% | 102 | 260.1億円 |
| 1935 | +5.0% | 105 | 281.1億円 |
| 1936 | +5.0% | 108 | 303.6億円 |
| 1937 | +5.5% | 112 | 332.2億円 |

[^e099]

1932〜37年の年平均実質成長率は約5.1%である（史実の日本の1932〜36年は実質GNP年平均6.1%だが、そのまま採用しない）。[^e049][^e099] 1930〜31年の収縮は史実より緩やかで、1932年以降の回復は国内投資と輸出の双方によって進み、軍需より民生用重工業・電力・交通の成長が大きい。英国経済圏との関係で原材料の調達費も抑えられた。[^e049] 公共投資でデフレを早期に止め、1933年頃から緩やかなインフレに移った。[^e069]

## 対外的な意味

国内の公共事業で工業生産力の一部を吸収できる以上、日本は余剰工業製品をすべて海外市場に押し出す必要がない。資源輸入と国内投資を拡大する日本に対して英国や自治領が市場開放を求めるという関係が成り立ち、1932年の日本は単なる輸出競争国ではなく「**世界恐慌下で比較的有力な需要創出国**」として[オタワ帝国経済会議](/diplomacy/ottawa-conference-1932.md)に関わった。[^e048] 「日本の財政拡張の限界は主として国内の信用・供給能力にあるのに対し、ドイツの限界は国際収支にある」という対比も示されている。[^e055]

# 軍事費の扱い

## 恐慌期：政治的争点として残す

軍艦は物理的には長期間使える資産だが、鉄道や発電所のように経済的収益を生むとは限らない。海軍は資本支出として公債発行を求め、財政当局は軍事資産と経済的な社会資本を区別しようとする。この問題は意図的に政治的争点として残され、ロンドン条約で海軍の増強が制限されていたこともあって、恐慌対策の公共投資は軍備拡張より民生インフラに向かった。[^e048]

## 1937年：建艦公債の条件付き承認

第二次ロンドン海軍軍縮会議の決裂後、1937年に軍艦建造への公債発行がダイスで判定され、1d100 > 40 に対し出目51で**限定的な条件付き承認**となった。軍艦の新規建造・大規模改装・基地建設・造船所や航空機工場の設備拡張は可、航空機の新規取得は条件付きで可、消耗補充・給与・訓練・燃料・通常の維持修繕は不可である。1925年に確立した経常予算と資本予算の区別は維持され、開発財政が全面的に軍事財政へ転換するのではなく民生の公共投資との両立が求められる。[^e066][^e067] 航空主兵論を採る日本では、「艦隊を建造する財源より、完成した艦隊を維持する財源の方が問題」となる。[^e066]

1937年以降の見通し（保留）では、1937〜40年の海軍資本支出の一部を建設公債（累計22.6億円）で賄いつつ、経常予算は租税と拠出金で賄う原則が守られ、増税も中央銀行の直接引受も要らないとされる。[^e101] 1936年以降は民生の公共投資を平常水準へ戻し、海軍の資本支出を広げる。[^e098] 1937年時点でも帝国政府は経常予算の租税財源原則を維持している。[^e093] 詳細は[帝国財政と諸侯の法定拠出](/economy/imperial-finance.md)と[1937年の建艦競争と海軍財政](/military/naval-buildup-1937.md)を参照。

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 金本位制離脱 | 1931年12月金輸出再禁止、1932年に事実上の管理通貨制 | 1925年に法的に廃止 |
| 財政規律 | 高橋財政で日銀の国債引受。ただし恒久財源とは想定されず、市中売却を重視 | 1925年から経常・資本予算を区別し、直接引受は非常時に限定 |
| 恐慌期の公共事業 | 1932〜34年の時局匡救事業（道路・河川・港湾） | 1930年度から開始し、1932〜33年にGDP比7% |
| 軍事費 | 満洲事変以降に増加 | 満洲事変なし。ロンドン条約で海軍の純増も制限 |
| 1930年代前半の成長 | 1932〜36年の実質GNP年平均6.1% | 1932〜37年の実質年平均約5.1% |

[^e047][^e049][^e099]

史実の高橋是清自身も、国債の市中消化が困難になれば悪性インフレにつながると考えていた。金本位制を離脱しても、財政規律についての従来の思想は相当程度残るという点で、本世界線の1925年体制は史実の延長上にある。[^e047] 後世の日本の建設国債と赤字国債の区別に近い原則が、本世界線では40年近く早く制度化されている。[^e048]

# 却下・修正された案

- **1930年代の公共投資比率の確度**：E49 では「暫定的に」置かれた設定案で、ユーザーの明示的な確定はなかったが、E98 で既存設定として再掲され、1937年GDPの支出面検証にそのまま使われたので、確定扱いとした。[^e049][^e098]
- **E47 の「公債による調達への態度」表**：E47 では通常の軍事費は「原則反対」、社会救済費は「非常時に限り容認」、海外開発投資は「収益性に応じて容認」、金融機関の救済は「担保・返済条件付きで容認」とされていたが、E48 の確定表では軍艦・軍事施設建造が「条件付きで可」、社会保障・生活扶助は「原則不可」に整理された。[^e047][^e048]

# 未決の論点

- 軍艦・軍事施設建造費の公債対象性は恐慌期には政治的争点として残され、1937年の判定（出目51）で条件付きで決着した。航空機の新規取得の「条件」の具体的な内容は未定。[^e048][^e067]
- 公共資本ストックの初期値（GDP比50/70/100%）と生産弾力性は可変のまま。[^e049]
- 1930〜36年の公債発行額・残高の年次推移（1936年の政府債務156.8億円は予測シナリオ側の値）。[^e101]
- 公共投資における帝国政府と領国の分担。領主家の拠出は経済力に連動するが、領国独自の公共投資との関係は積算されていない。[^e070][^e101]
