# 概要

1937年の日本帝国では、総人口7,800万人のうち6,000万人が領主権の下にある領国に、1,800万人が帝国直轄・特別領等に住む。領国は領主家門249家に対応する249の財政単位に集約され、経済構造によって大都市・工業、資源・電力、農業中心、北海道開拓、小規模の5類型に分けられる（家門数と行政上の領国数は必ずしも一致しない）。[^p094]

領国間の経済力の差は大きく、大都市・工業領国と小規模領国の1人当たりGDPには約2.3倍、1人当たり独自歳入には2.78倍の差がある。これを補うため、1927年以降の[公私財政分離](household-accounts.md)を土台に、法定拠出金の猶予・減免制度、帝国の財政調整交付金（1937年度4.5億円）、領国共同事業組合、共同建設公債が整えられた。財政調整後の財源格差は1.57倍に縮まる。[^p075][^p094]

1937年までに、恒常的な交付金制度、客観的な算定基準、共同事業組合、共同建設公債、帝国の過度な自治介入の抑制がいずれも実現したが、基礎的行政サービスの格差は相当程度には縮小しなかった。[^n1] 制度面では大きく成功しながら行政サービスの均質化には結びつかなかったことは、自治を重視する国家として一貫した帰結である。[^p095] 帝国・地方の全体の財政は[1937年度の帝国財政と連結政府財政](public-finance-1937.md)を参照。

# 前史：公私財政分離と拠出金の負担移行

## 公私財政分離（1925〜1937）

1925〜32年に領主家資産と領国政府財政の制度的分離が大きく進み[^n2]、1933〜37年に分離は全国的に定着した。[^n3][^p008][^p009] これにより、領主家の私会計（配当・利子・私有不動産収益・家政費）と領国政府の公会計（領国税・公有財産収益・教育・警察・公共事業・公債）が分けられ、領主家債務を領国政府が当然には承継しない、領主家企業への公的債務保証を規制する、帝国共通の会計基準で監査する、といった改革が行われた。[^n4][^p008] 家門会計の詳細は[家門会計・法定拠出金と公私財政分離](household-accounts.md)を参照。

## 法定拠出金の負担主体の移行

領国規模に連動する法定拠出金は、財政分離の前は領主家門が、分離の後は領国政府が負担する。1927年以降の公私財政分離は、単なる会計処理の変更ではなく「法定拠出金の負担主体が領主家門から領国政府へ部分的に移る制度改革」である。[^p075]

| 負担項目 | 分離前 | 分離後 |
|---|---|---|
| 領国人口連動拠出金 | 領主家門 | 領国政府 |
| 領国歳入連動拠出金 | 領主家門 | 領国政府 |
| 家門所得連動拠出金 | 領主家門 | 領主家門 |
| 家門所得税 | 領主家門 | 領主家門 |
| 家門維持費 | 領主家門 | 領主家門 |
| 領国行政費 | 公私の区分が不明確 | 領国政府 |

[^p075]

1937年の領国政府法定拠出金は次の算定式による。[^n5][^p074][^p075][^p094]

> 領国政府拠出金 ＝ 人口 × 0.5円 ＋ 独自経常歳入 × 5%

算定対象の歳入には帝国からの財政援助や借入金収入を含めない。[^p075] 人口比例分があるため、所得や歳入の少ない領国ほど相対的な負担が重く、減免制度がその逆進性を緩和する。[^p094]

## 拠出金の猶予・減免制度

支払能力のない領国には、法定拠出金の猶予や免除が認められる。[^n6][^p075]

| 措置 | 想定される状況 |
|---|---|
| 納付猶予 | 一時的な資金不足（期限を延期） |
| 分割納付 | 年度内の資金繰り難（複数年度に分割） |
| 一部減額 | 継続的な歳入不足 |
| 全額免除 | 深刻な財政難・大規模災害 |
| 滞納債務の整理 | 過年度分の累積（返済条件変更・一部免除） |

[^n4][^p075]

支払能力は F ＝ R − E − D（R＝経常歳入、E＝必要な経常行政支出、D＝その年度の債務返済・利払い）で測り、F が拠出義務額の100%以上なら全額納付、50〜100%なら一部猶予・分割、0〜50%なら減額・長期猶予、0%以下なら全額免除を含む財政再建措置とする。必要行政支出の認定は帝国側が審査する。拠出率と減免要件は帝国議会が法律で定め、帝国政府が個別に審査・決定し、紛争は帝国の司法機関が審理する。元老院議員でもある領主が自家の免除を直接決められる制度にはなっていない。[^n4][^p075]

領国政府と家門の救済は別個に扱われる。黒田家が家産の大半を失っても領国の税収が健全なら領国政府は通常どおり納付し、井伊家のような富裕な家の領国でも災害で財政難になれば領国政府は減免を申請できる。家門が私財で領国の赤字を補填することは強制されない。[^n4][^p075] 1867〜1937年に累計60家に及んだ[領主権奉還](../institutions/lordship-surrender.md)は、減免制度があっても財政を再建できなかった家が奉還に至ったものである。[^p075]

## 財政調整交付金

帝国から地方政府への交付金4.5億円は、既に成立していた拠出金の猶予・減免制度を補完するものとして1930年代に整備された。[^p093]

| 目的別内訳 | 億円 |
|---|---:|
| 一般財政調整交付金 | 2.0 |
| 教育・医療等の特定交付金 | 1.2 |
| 北海道・開拓地域支援 | 0.6 |
| 災害・財政再建支援 | 0.5 |
| その他 | 0.2 |
| **合計** | **4.5** |

[^p093]

交付金は**領主家門への援助ではなく領国政府への公的移転**である。黒田家自身が財政難でも、領国政府の財政が健全なら増額しない。逆に裕福な領主家の領国でも、行政需要に対して税収が不足すれば交付対象となる。[^p093]

算定方式は、各領国の標準財政需要と標準的な税率で得られる標準財政収入の差による。[^p093]

> 交付基準額 ＝ max(0, 標準財政需要 − 標準財政収入)

標準財政需要には人口・学齢人口・道路延長・面積・積雪・離島・開拓地などの行政条件を反映する。実際の歳入不足をすべて補填すると領国政府の財政規律が弱まるので、交付額は標準的な行政費用に基づいて決め、任意の過大支出は補填しない。[^p093] この客観算定方式は1937年に成立した。[^n7][^p095]

# 広域行政と共同金融

## 領国共同事業組合

小規模領国が95もある以上、すべての行政サービスを各領国が単独で提供するのは非効率である。そこで複数の領国政府が費用を分担して施設を共同運営する**領国共同事業組合**[^n8]が発達した。対象は高等教育・専門教育、病院・公衆衛生、道路・河川管理、上下水道、広域交通、行政職員の養成で、領主権や領国政府を統合せずに行政事業の規模を拡大できる。[^n9][^p094][^p095]

| 組織 | 構成主体 | 主な目的 |
|---|---|---|
| 諸侯共済会 | 領主家門 | 私的家産の運用・金融・共済 |
| 華族共済会 | 無領華族等 | 私的家産の保全・共同金融 |
| 領国共同事業組合 | 領国政府 | 公共施設・行政サービス |
| 帝国政府 | 帝国の公的機関 | 全国的行政・財政調整 |

[^p094]

私的家産の共同金融組織である諸侯共済会（[領主金融圏と諸侯共済会（1867〜1937）](lord-financial-spheres.md)を参照）と、公的な行政組織である共同事業組合は明確に区別される。これは1927年以降の公私財政分離を制度的に徹底したものである。[^p094]

## 共同建設公債

中小領国が共同で建設公債を発行・調達する制度は、1937年に成立した。[^n10][^p095] 単独では市場での起債条件が不利な小規模領国にとって、公共投資の資金調達手段となる。

# 領国財政の自治と帝国の監督

| 財政事項 | 権限の所在 |
|---|---|
| 領国予算の編成 | 領国政府 |
| 領国独自課税 | 法令の範囲内で領国政府 |
| 法定拠出金の算定 | 帝国政府 |
| 拠出金の減免 | 帝国政府 |
| 財政調整交付金 | 帝国政府 |
| 交付金の使途 | 原則として領国政府 |
| 特定交付金の使途 | 法定の事業目的に限定 |
| 領国建設公債 | 領国政府（法定の発行要件あり） |
| 違法な財政処分 | 司法的救済の対象 |

[^p094]

財政難を理由に帝国政府が当然に領主権を接収できる制度はとられず、従来の憲法構造との整合が保たれている。[^p094] 領国政府の財政難を理由とする帝国政府の過度な自治介入は抑制された。[^n11][^p095] 領主権の憲法上の位置づけは[領主権](../institutions/lordship-rights.md)を参照。

# 財政調整制度の成立（1937）

1937年までに、帝国による恒常的な領国財政調整交付金制度が成立し[^n12]、財政調整は政治的裁量ではなく客観的算定基準に基づくものとなった。[^n7] 領国政府間の広域行政・共同事業組合が発達し[^n9]、中小領国が共同で建設公債を発行・調達する制度も成立した。[^n10] 領国政府の財政難を理由とする帝国政府の過度な自治介入は抑制された。[^n11] 一方、領国間の基礎的行政サービスの格差は相当程度には縮小しなかった。[^n13][^p094][^p095]

こうして財政調整交付金4.5億円と共同建設公債制度が採用されたが、行政サービスの地域格差は引き続き大きかった。[^p095] 1937年の領国財政制度は、恒常的財政調整交付金の成立、客観的な交付金算定、年間交付金4.5億円、領国政府法定拠出金1.14億円、共同事業組合の発達、共同建設公債の成立、過度な自治介入の抑制、行政サービスの地域格差の残存として総括される。[^n14][^p096][^p097]

# 行政サービスの地域格差

財源格差の縮小（2.78倍→1.57倍）がそのまま行政サービスの格差縮小につながったわけではない。人口密度の低い北海道では、住民1人当たりの教育予算が多くても学校までの距離や教員の確保の問題が残る。小規模領国では行政機構の固定費が大きく、教育や医療に回せる予算が限られる。過去数十年間に蓄積された社会資本の格差は、数年間の財政調整では容易に解消できない。[^p095]

| 行政サービス（全国平均＝100） | 都市工業 | 資源電力 | 農業中心 | 北海道開拓 | 小規模 |
|---|---:|---:|---:|---:|---:|
| 初等教育 | 115 | 105 | 95 | 90 | 80 |
| 中等教育 | 155 | 110 | 70 | 80 | 55 |
| 医療へのアクセス | 160 | 105 | 65 | 60 | 55 |
| 上下水道 | 165 | 110 | 60 | 75 | 45 |
| 道路・交通 | 140 | 110 | 80 | 60 | 65 |
| 司法・行政サービス | 125 | 105 | 90 | 85 | 75 |
| 社会保障の実効性 | 135 | 110 | 80 | 85 | 65 |

[^n15][^p095]

全国に普及した初等教育よりも、多額の設備投資や専門人材を要する中等教育・医療・上下水道で格差が大きい。[^p095]

## 四重の格差

| 格差の種類 | 程度・特徴 |
|---|---|
| 資産所有格差 | 華族770家門が民間純資産の50%を保有 |
| 産業間格差 | 製造業の労働生産性は農業の約3倍 |
| 地域経済格差 | 都市工業領国と小規模領国の1人当たりGDPに約2.3倍の差 |
| 行政サービス格差 | 財政調整が成立しても大きく残存 |

[^p095]

男女普通選挙・教育の普及・社会保障制度の発達など政治的・社会的な近代化には成功したが、経済的な平等化には必ずしも成功していない。1937年の日本は「**自由主義的な憲政、世襲的な資産所有、高度な地方自治、近代的な工業経済が併存する国家**」と総括される。[^p095] 資産所有の構造は[国民資産と富の所有構造（1937）](national-wealth-1937.md)を参照。

# 政治的含意

領国の財政力の差は、元老院の政治的利害に直接影響する。大領主と小領主は必ずしも同じ財政政策を支持しない。[^n4][^p094]

| 政治的勢力 | 主な財政政策上の関心 |
|---|---|
| 大都市・工業領主 | 租税負担の抑制・産業基盤整備 |
| 資源・電力領主 | 鉄道・港湾・電力投資 |
| 農業領主 | 農業振興・財政調整 |
| 北海道領主 | 開拓補助・交通網整備 |
| 小規模領主 | 拠出金減免・財政調整・共同事業 |
| 実業家華族 | 公共投資・国債市場・企業金融 |
| 学術・専門職華族 | 教育・研究・医療への支出 |

[^n4][^p094]

中小領主を支持基盤とする元老院の倶楽部「諸侯協同会」[^n16]（[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)を参照）にとって、財政調整制度は家門の救済ではなく、領主権に伴う行政責任を果たすための制度である。[^p079][^p094] 中小領主は帝国からの財政支援を積極的に求めながら、それに伴う行政監督の強化には反対する可能性が高い。[^p095]

自治と平等をめぐる衆議院各党の政策傾向は次のとおりである（[政党の系譜と衆議院の議席推移（1876〜1937）](../politics/political-parties.md)を参照）。[^n17][^p095]

| 政党・勢力 | 想定される政策傾向 |
|---|---|
| 国民進歩党 | 全国的な社会資本整備と財政調整 |
| 立憲改進党 | 自治を維持しながら行政を近代化 |
| 国民協同党 | 教育・医療・母子保護の地域格差是正 |
| 社会民権党 | 全国共通の社会保障・労働者保護 |
| 日本労農党 | 居住地域によらない社会的権利の保障 |
| 立憲保守党 | 領国自治と財政規律の維持 |
| 元老院の中小領主勢力 | 財政支援の拡充と自治権の保全 |

[^n17][^p095]

# 史実との比較

独立性の高い連邦国家では国内の地域格差が大きくなりやすい。この点で史実の米国と制度を比較すると次のようになる。[^n18][^p095]

| 項目 | 史実の米国 | 本世界線の日本 |
|---|---|---|
| 地方自治の基礎 | 州の憲法上の権限 | 領主権・帝国憲法 |
| 地方政府の政治的正統性 | 住民による選挙 | 世襲領主権を基礎とする |
| 地域間財政格差 | 大きい | 大きい |
| 上院の地域代表 | 各州同数 | 領主家門による全国選挙 |
| 中央政府の財政支援 | 連邦補助金 | 帝国財政調整交付金 |
| 自治体の統廃合 | 州内制度に依存 | 領主権との関係で制約 |
| 地域間の政策差 | 大きい | 大きいと推定 |

[^p095]

本世界線では単なる地方分権ではなく領主権という憲法上の権利が自治の基礎にあるため、帝国政府が全国一律の行政制度を導入しようとすると、政策上の合理性だけでなく領主権との権限関係が問題になる。[^p095] 史実の日本は廃藩置県で旧藩の徴税権を中央へ集め、府県と市町村を中央の監督下に置いた。財政力の地域差を中央からの交付金で調整する制度が本格化するのは、1940年の地方分与税制度以降である。
