# 概要

1937年の本世界線日本の**国民純資産は1,800億円**で、GDP400億円の4.5倍、1人当たり2,308円にあたる。政府純資産120億円を除いた**民間純資産は1,680億円**である。[^p096] この所有構造は、明治維新で旧領主の経済基盤が解体されなかったことを前提に、1937年の資産所有構造を決める6項目のダイス判定（[^p068]）と、領主家・無領華族・独立系実業資本・一般国民の経済史判定を積み上げて確定された。P97で「一旦これで確定」と宣言された値（国民純資産1,800億円、華族の民間純資産保有率50%など）は確定値である。[^p097]

民間純資産の内訳は、領主華族249家が30%（504億円）、無領華族521家が20%（336億円）、非華族の富裕層（地主・不動産所有者・実業家）が30%（504億円）、その他の一般国民が20%（336億円）となる。**華族770家門だけで民間純資産の50%**を持ち、領主家産の90%は主要25家に集中する。[^p096] 1937年の領主階級は伝統的な大地主というより、近代企業の株主・金融資本家としての性格が強い。[^p070]

経済発展は社会の平等化や中央集権化を意味しなかった。近世以来の家門・領主制度が近代資本主義に適応し、旧支配層が経済的優位を保ったまま、男女普通選挙・教育・社会保障などの政治的・社会的近代化が進んだ、というのが1937年日本の性格である。[^p095][^p096] 所得面・生産面の全体像は[1937年の日本経済（国民経済計算と基本指標）](economy-1937-overview.md)を参照。

# 資産所有構造のマクロ判定（1937年）

国民経済全体の資産所有構造を決めるため、次の6項目が判定された。[^p067][^p068]

| 判定項目 | 難易度 | 出目 | 結果 | 帰結 |
|---|---:|---:|---|---|
| 明治維新後の資本蓄積がGDPに対して高い水準に達する | 35 | 77 | 成功 | 国民純資産のGDP倍率を4.0倍から4.5倍へ |
| 領主階級が近代化後も民間純資産の大きな割合を維持する | 40 | 95 | 成功（クリティカル） | 領主の保有割合を20%から30%へ |
| 無領華族・独立系実業家への資産所有の分散が進展する | 30 | 71 | 成功 | 無領華族・独立系実業家も有力な保有層に |
| 領主階級内部で主要25家への家産集中が著しく進展する | 30 | 49 | 成功 | 主要25家への集中を75%から90%へ |
| 一般市民・農民への土地・金融資産の分散が進展する | 45 | 15 | 失敗 | 自作農化と金融資産の普及は限定的 |
| 領主家の資産所得率が一般の資産保有者より高い水準を維持する | 45 | 61 | 成功 | 専門的家産管理により平均以上の収益率 |

（ダイス判定：いずれも1d100、出目が難易度を上回れば成功）

この結果は、旧領主が新興資本家の成長を阻んだのではなく、両者がともに資産を蓄積し、一般市民・農民への富の分散が進まなかったと解釈される（検討案）。[^p068] 資産倍率4.5倍、領主保有率30%、主要25家への集中率90%、所得率6%はロール結果を反映したモデル上の仮定値で、出目から一意に導かれたものではない。[^p068] ただしこれらの総額はP96の最終集計とP97の確定宣言で確定値となった。[^p096][^p097]

# 国民純資産の構成

国内の金融資産・負債（株式・社債・預金・公債）は国内で相殺し、実物資産と純対外資産のみを計上する。[^p067][^p096]

| 資産区分 | 1937年資産額 | 構成比 |
|---|---:|---:|
| 農地・農業用土地 | 320.0億円 | 17.8% |
| 山林・天然資源等 | 140.0億円 | 7.8% |
| 都市・宅地・工業用地 | 310.0億円 | 17.2% |
| 住宅・商業建築物 | 310.0億円 | 17.2% |
| 工場・機械・産業設備 | 270.0億円 | 15.0% |
| 交通・電力・公益等の社会資本 | 280.0億円 | 15.6% |
| 在庫・その他生産資産 | 72.9億円 | 4.1% |
| 純対外資産 | 97.1億円 | 5.4% |
| **国民純資産** | **1,800.0億円** | 100% |

（出典：[^p068][^p096]）

蓄積の要因は、大規模な内戦がなかったこと、領主が土地・山林を維持したこと、北海道開拓、第一次世界大戦期の対外債権、1920年代の設備投資と1930年代の公共投資である。1927年以降の金融危機で評価額は一時毀損した。[^p067] 判定後は工業設備・交通・電力などの生産資産が重点的に増額された。[^p068]

## 政府純資産

公的部門は帝国政府保有資産210億円、領国・その他地方政府保有資産90億円の計300億円から、帝国政府債務160億円と領国・地方政府純債務20億円を差し引いて、**政府純資産120億円**とされる。領主家が保有する公債は民間純資産に含め、領国政府の財産は領主家産に含めない。[^p067] 帝国政府債務160億円（総債務）と地方政府純債務20億円（純債務）が混在している点は未整理である。[^p096] 財政の詳細は[1937年度の帝国財政と連結政府財政](public-finance-1937.md)を参照。

## 対外資産の帰属（検討案）

純対外資産97.1億円は対外総資産135.0億円から対外総負債37.9億円を引いたもので、対外総資産は領主家42.73億円、無領華族・その他民間62.27億円、帝国政府・公的機関30.00億円に仮に配分されている。国内企業経由の海外資産は直接保有分と重ねて計上しない。[^p070][^p091] 対外資産の種類別内訳は[国際収支と対外資産（1914〜1937）](balance-of-payments.md)を参照。

| 専門職・技術者・管理職を中心とする都市中間層が発達する | 25 | 33 | 成功 |
| 1927年以降の金融危機によって一般国民の資産格差が拡大する | 30 | 75 | 成功 |
| 社会保障制度によって低所得者の資産取崩しが抑制される | 40 | 59 | 成功 |
| 世代間の資産格差が固定化する | 30 | 81 | 成功 |

一般国民の貯蓄は銀行預金・郵便貯金・信用組合に集中し、金融機関を通じて大企業融資・政府公債・中小企業・農業金融へ流れる。貯蓄は工業化の資金源となるが、議決権と企業利益の所有権は華族家門などに集中する。「職業上の上昇移動は可能だが、資産所有における世代間移動は限定的」である（検討案）。[^p085] 都市住宅・家計の詳細は[1937年の就業構造と社会（労働・教育・住宅・人口）](labor-society-1937.md)を参照。

## 農地の所有者別配分（検討案）

全国の農地評価額320億円は、領主華族57.6億円（18%）、無領華族16億円（5%）、非華族地主128億円（40%）、自作農・自小作農102.4億円（32%）、政府・法人その他16億円（5%）に配分される。評価額基準で耕作面積比とは異なる。領主華族の農地・山林等97.08億円＝農地57.6億円＋山林・その他開拓地39.48億円で、従来推計と整合する。[^p085] 地主集積のファンブルは地主制度の崩壊ではなく、大規模な土地買収を試みた新興地主・投機的土地資本の失敗を意味し、伝統的な中小地主層が残った。「農地所有は固定的だが、農業経営は近代化する」。[^p085] 農家の経営形態は[農林水産業の近代化（1900〜1937）](agriculture-1937.md)を参照。

# 所得の分配と資本所得の帰属

## 国民所得の分配（確定）

国民純所得333.00億円の分配は、雇用者報酬156.51億円（47.0%）、自営業者等の混合所得76.59億円（23.0%）、純営業余剰等76.59億円（23.0%）、生産・輸入税等（純額）23.31億円（7.0%）である。混合所得を労働70%・資本30%に再分類すると、**労働所得210.123億円（63.1%）、資本所得99.567億円（29.9%）**、生産・輸入税等23.31億円となる。[^p096]

## 資本所得99.57億円の帰属

| 帰属先 | 年間資本所得 | 純資産に対する所得率 |
|---|---:|---:|
| 領主華族の家産所得 | 30.45億円 | 6.04% |
| 実業家華族の家産所得 | 18.21億円 | 6.09% |
| 非実業家華族の家産所得 | 1.29億円 | 3.49% |
| 非華族富裕層の資本所得 | 22.00億円 | 4.37% |
| 一般国民の資本所得 | 10.00億円 | 2.98% |
| 企業内部留保 | 13.00億円 | ― |
| 政府等の純資本所得 | 4.62億円 | ― |
| **計** | **99.57億円** | |

（出典：[^p086][^p096]）

企業内部留保は家門配当と別に計上し、当年の留保を家門の現金所得に加算しない。華族770家門の家産所得は約50億円で、全国の資本所得の約半分にあたる。[^p083][^p086] 国民経済計算上の厳密な帰属表としては暫定とされ、国内公債利子などの移転的財産所得の調整が残る。[^p096]

主要25家の家産所得は合計27.89億円（平均6.15%）で、徳川宗家は年5億4,096万円に達する。所得率が一般より高いという判定（出目61）を根拠に、資産種類別の基準所得率による25.81億円ではなく27.89億円が採られた。[^p069][^p070]

## 領主家門の公的負担

領主家門の家産所得30.450億円から家門法定拠出金3.015億円と所得税10.500億円を差し引くと、税・拠出金控除後は16.935億円で、公的負担率は44.38%となる。家門維持費・使用人給与・家族扶養費・私有財産の維持費はこの16.935億円から支出する。領国政府が負担する法定拠出金1.14億円は家門所得から控除しない。[^p096] 恒常的な資産保有税は導入されておらず、課税は所得に対して行う。家門会計と拠出金の制度は[家門会計・法定拠出金と公私財政分離](household-accounts.md)を参照。所得税10.5億円は財政総額に合わせた暫定推計で、249家に累進税率を適用した積み上げではない。[^p096]

# 経済社会の性格

1937年の経済社会は次のように総括される。[^p086]

| 側面 | 1937年の姿 |
|---|---|
| 資産所有 | 華族階級への高度集中 |
| 企業経営 | 同族所有と専門経営者の併存 |
| 企業間関係 | 共同出資・長期取引による企業連合 |
| 金融 | 銀行中心の間接金融 |
| 工業 | 領主系・独立系・公営企業の並立 |
| 農業 | 地主制を維持しながら経営近代化 |
| 都市社会 | 借家居住の給与所得中間層が発達 |
| 社会保障 | 生活保障は拡充、資産再分配は限定的 |
| 社会移動 | 教育・専門職・功績叙爵による上昇移動 |
| 世代間格差 | 家門財産の継承で固定化 |

旧領主系企業集団は独立系実業資本と並ぶ規模で存在し、企業社会と華族社会は元老院・金融機関・取締役会・社交組織を通じて密接に結合している。[^p086]

## 四重の格差

| 格差 | 1937年の状況 |
|---|---|
| 資産所有格差 | 華族770家門が民間純資産の50%を保有 |
| 産業間格差 | 製造業の労働生産性は農業の約3倍 |
| 地域経済格差 | 都市工業領国と小規模領国の1人当たりGDPに約2.3倍の差 |
| 行政サービス格差 | 財政調整制度が成立しても大きく残存 |

（出典：[^p095]）

地域経済格差と行政サービス格差の詳細は[領国の類型・財政と財政調整交付金（1937）](fief-finance-1937.md)を参照。

## 階級構造と両院の政治的利益（検討案）

大領主・実業家華族は財産権・企業活動・家門自治、中小領主・非実業家華族は共同金融・家門維持・負担軽減、非華族地主は土地所有権・農業政策、自作・自小作農は農業金融・価格安定・土地改良、小作農は小作権・生活保障、都市中間層は教育・住宅・職業機会、中小企業・自営業は信用供与・商業秩序、労働者は労働保護・賃金・社会保障に利害を持つ。元老院は資産所有者・専門エリートを、男女普通選挙の衆議院は農民・労働者・都市中間層を代表し、両院間の政策対立の基礎となる。[^p085] 元老院では大小の領主が互選で平等に1票を持つため（徳川宗家90億円も純資産53万円の小領主も同じ1票）、中小領主への信用供与や共同の資産運用が政治的に重要になる。[^p069]（→[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)、[領主金融圏と諸侯共済会（1867〜1937）](lord-financial-spheres.md)）

# 史実との比較

* 史実の日本では明治維新で旧領主の経済基盤が解体され、資産所有の頂点には三井・三菱・住友などの財閥家族が立った。本世界線では領主家が近代企業の株主・金融資本家として残り、財閥に相当する独立系の実業家華族と並立する。[^p070][^p086]
* 史実の戦前日本も地主制と高い資産格差を抱えていたが、本世界線では華族という法的身分が資産保有と強く結びついている点が異なる。[^p096]

# 却下・修正された案

* **国民純資産1,600億円案（P67）**：GDPの4倍（範囲1,400〜1,800億円）、民間純資産1,480億円とする判定前の基準案。資本蓄積の判定成功（77）を受け4.5倍・1,800億円、民間1,680億円に引き上げられた。1,600億円案の構成は農地290・山林120・都市土地280・建築物280・設備220・社会資本245・在庫67.9・純対外資産97.1億円だった。[^p067][^p068]
* **領主家産296億円案（P67）**：民間純資産の20%、家産所得率4.5%で年13.32億円、主要25家75%＝222億円、その他199家13%＝38.48億円（平均約1,934万円）。199家の平均家産所得が約87万円となり「家産所得のみで維持できる領主は少数派」という判定と矛盾したため、領主保有率のクリティカル（95）と集中判定（49）を受け504億円・主要25家90%に修正された。[^p067][^p068]
* **無領華族の家産集中モデル（P82）**：巨大実業家華族20家184.80億円（平均9.24億円）、有力80家100.80億円など上位100家で85%とする「ロール前の参考モデル」。P83で金融危機後の資産集中判定が失敗（出目6）したため、上位20家117.60億円などへ修正された。[^p082][^p083]
* **労働分配率約68%（P67）**：要素所得ベースの表現で、最終集計では労働所得63.1%・資本所得29.9%・生産輸入税等7.0%の区分が採られた。[^p067][^p096]

# 未決の論点

* 徳川宗家90.16億円が過大ではないか。資本蓄積モデルの初期指数・成長倍率には独立した実証的基準がない。[^p069]
* 政府部門の総債務と純債務の統一、連結総債務の確定（政府保有金融資産の整理）。[^p096]
* 国民経済計算上の資本所得と家門の現金所得との厳密な対応、国内財産所得の調整。[^p096]
* 249家の家門別所得税の累進税率による積み上げ。[^p096]
* 非華族富裕層・一般国民・農地所有者別の資産内訳は土地法制・産業統計と未照合の暫定推計。[^p084][^p085]
* 台湾・澎湖を人口・資産統計にどこまで含めるか。[^p096]
* 1938年以降の展開は保留。[^p097]
