# 概要

1937年の本世界線日本の**国民純資産は1,800億円**で、GDP400億円の4.5倍、1人当たり2,308円にあたる。政府純資産120億円を除いた**民間純資産は1,680億円**である。[^p096] この所有構造は、明治維新で旧領主の経済基盤が解体されなかったことを前提に、資本蓄積・領主の資産維持・資産の分散などをめぐる6つの要因と、領主家・無領華族・独立系実業資本・一般国民それぞれの経済史の帰結が積み重なって形づくられた。[^n1][^p068][^p097]

民間純資産の内訳は、領主華族249家が30%（504億円）、無領華族521家が20%（336億円）、非華族の富裕層（地主・不動産所有者・実業家）が30%（504億円）、その他の一般国民が20%（336億円）となる。**華族770家門だけで民間純資産の50%**を持ち、領主家産の90%は主要25家に集中する。[^p096] 1937年の領主階級は伝統的な大地主というより、近代企業の株主・金融資本家としての性格が強い。[^p070]

経済発展は社会の平等化や中央集権化を意味しなかった。近世以来の家門・領主制度が近代資本主義に適応し、旧支配層が経済的優位を保ったまま、男女普通選挙・教育・社会保障などの政治的・社会的近代化が進んだ、というのが1937年日本の性格である。[^p095][^p096] 所得面・生産面の全体像は[1937年の日本経済（国民経済計算と基本指標）](economy-1937-overview.md)を参照。

# 資産所有構造を決めた帰結（1937年）

国民経済全体の資産所有構造は、次の6項目の成否によって決まった。[^n2][^p067][^p068]

| 事項 | 結果 | 帰結 |
|---|---|---|
| 明治維新後の資本蓄積がGDPに対して高い水準に達する | 成功[^n11] | 国民純資産のGDP倍率を4.0倍から4.5倍へ |
| 領主階級が近代化後も民間純資産の大きな割合を維持する | 際立って成功[^n12] | 領主の保有割合を20%から30%へ |
| 無領華族・独立系実業家への資産所有の分散が進展する | 成功[^n13] | 無領華族・独立系実業家も有力な保有層に |
| 領主階級内部で主要25家への家産集中が著しく進展する | 成功[^n14] | 主要25家への集中を75%から90%へ |
| 一般市民・農民への土地・金融資産の分散が進展する | 失敗[^n15] | 自作農化と金融資産の普及は限定的 |
| 領主家の資産所得率が一般の資産保有者より高い水準を維持する | 成功[^n16] | 専門的家産管理により平均以上の収益率 |

旧領主は新興資本家の成長を阻んだのではなく、両者がともに資産を蓄積し、一般市民・農民への富の分散が進まなかった。[^n3][^p068] 資産倍率4.5倍、領主保有率30%、主要25家への集中率90%、所得率6%は、これらの帰結を反映したモデル上の値である。[^n4][^p068][^p096][^p097]

# 国民純資産の構成

国内の金融資産・負債（株式・社債・預金・公債）は国内で相殺し、実物資産と純対外資産のみを計上する。[^p067][^p096]

| 資産区分 | 1937年資産額 | 構成比 |
|---|---:|---:|
| 農地・農業用土地 | 320.0億円 | 17.8% |
| 山林・天然資源等 | 140.0億円 | 7.8% |
| 都市・宅地・工業用地 | 310.0億円 | 17.2% |
| 住宅・商業建築物 | 310.0億円 | 17.2% |
| 工場・機械・産業設備 | 270.0億円 | 15.0% |
| 交通・電力・公益等の社会資本 | 280.0億円 | 15.6% |
| 在庫・その他生産資産 | 72.9億円 | 4.1% |
| 純対外資産 | 97.1億円 | 5.4% |
| **国民純資産** | **1,800.0億円** | 100% |

（出典：[^p068][^p096]）

蓄積の要因は、大規模な内戦がなかったこと、領主が土地・山林を維持したこと、北海道開拓、第一次世界大戦期の対外債権、1920年代の設備投資と1930年代の公共投資である。1927年以降の金融危機で評価額は一時毀損した。[^p067] 判定後は工業設備・交通・電力などの生産資産が重点的に増額された。[^p068]

## 政府純資産

公的部門は帝国政府保有資産210億円、領国・その他地方政府保有資産90億円の計300億円から、帝国政府債務160億円と領国・地方政府純債務20億円を差し引いて、**政府純資産120億円**とされる。領主家が保有する公債は民間純資産に含め、領国政府の財産は領主家産に含めない。[^p067] 帝国政府債務160億円（総債務）と地方政府純債務20億円（純債務）が混在している。[^n5][^p096] 財政の詳細は[1937年度の帝国財政と連結政府財政](public-finance-1937.md)を参照。

## 対外資産の帰属[^n3]

純対外資産97.1億円は対外総資産135.0億円から対外総負債37.9億円を引いたもので、対外総資産は領主家42.73億円、無領華族・その他民間62.27億円、帝国政府・公的機関30.00億円に配分される。国内企業経由の海外資産は直接保有分と重ねて計上しない。[^p070][^p091] 帝国政府・公的機関30.00億円のうち英国向け債権は約5億円（1931年日英緊急金融・通商協定の政府間信用分の借換債の残り約4億円と、割引で買い取った民間債権分約1億円）で、残り約25億円は、外貨準備・金（対外資産表の「外貨準備・金・その他」15億円の大半）と、外国政府・公的機関への融資や外国公債などからなる（→[1931年欧州通貨危機と日英金融協力](../events/currency-crisis-1931.md)）。[^n31] 対外資産の種類別内訳は[国際収支と対外資産（1914〜1937）](balance-of-payments.md)を参照。

### 領主家産の資産構成[^n3]

全249家の家産504億円の構成は、農地・山林・開拓地97.08億円、都市不動産40.77億円、金融企業株式86.18億円、鉱工業株式120.00億円、電力・鉄道株式32.24億円、商業・海運株式42.59億円、海外資産42.73億円、債券・預金等42.40億円である。比率では**国内企業株式55.8%**、土地・不動産27.4%、海外資産8.5%、債券・預金等8.4%である。[^p070]

無領華族の経済史では、旧公家系は明治初期の家産保全に失敗した一方、都市不動産・金融資産による所得源の形成には成功した。領主権を奉還した旧領主家は経済的に再起できず、学術・軍人・官僚系の功績華族も家産を蓄積できなかった。非実業家系の多くは家産所得だけでは家門を維持できない。[^n6][^p083]

| 非華族の中小企業・自営業者が安定した資産を形成する | 成功[^n26] |
| 専門職・技術者・管理職を中心とする都市中間層が発達する | 成功[^n27] |
| 1927年以降の金融危機によって一般国民の資産格差が拡大する | 成功[^n28] |
| 社会保障制度によって低所得者の資産取崩しが抑制される | 成功[^n29] |
| 世代間の資産格差が固定化する | 成功[^n30] |

一般国民の貯蓄は銀行預金・郵便貯金・信用組合に集中し、金融機関を通じて大企業融資・政府公債・中小企業・農業金融へ流れる。貯蓄は工業化の資金源となるが、議決権と企業利益の所有権は華族家門などに集中する。「職業上の上昇移動は可能だが、資産所有における世代間移動は限定的」である。[^n3][^p085] 都市住宅・家計の詳細は[1937年の就業構造と社会（労働・教育・住宅・人口）](labor-society-1937.md)を参照。

## 農地の所有者別配分[^n7]

全国の農地評価額320億円は、領主華族57.6億円（18%）、無領華族16億円（5%）、非華族地主128億円（40%）、自作農・自小作農102.4億円（32%）、政府・法人その他16億円（5%）に配分される。評価額基準で耕作面積比とは異なる。領主華族の農地・山林等97.08億円＝農地57.6億円＋山林・その他開拓地39.48億円で、従来推計と整合する。[^p085] 地主層による農地集積の大きな失敗は地主制度の崩壊ではなく、大規模な土地買収を試みた新興地主・投機的土地資本の失敗を意味し、伝統的な中小地主層が残った。「農地所有は固定的だが、農業経営は近代化する」。[^p085] 農家の経営形態は[農林水産業の近代化（1900〜1937）](agriculture-1937.md)を参照。

# 所得の分配と資本所得の帰属

## 国民所得の分配

国民純所得333.00億円の分配は、雇用者報酬156.51億円（47.0%）、自営業者等の混合所得76.59億円（23.0%）、純営業余剰等76.59億円（23.0%）、生産・輸入税等（純額）23.31億円（7.0%）である。混合所得を労働70%・資本30%に再分類すると、**労働所得210.123億円（63.1%）、資本所得99.567億円（29.9%）**、生産・輸入税等23.31億円となる。[^p096]

## 領主家門の公的負担

領主家門の家産所得30.450億円から家門法定拠出金3.015億円と所得税10.500億円を差し引くと、税・拠出金控除後は16.935億円で、公的負担率は44.38%となる。家門維持費・使用人給与・家族扶養費・私有財産の維持費はこの16.935億円から支出する。領国政府が負担する法定拠出金1.14億円は家門所得から控除しない。[^p096] 恒常的な資産保有税は導入されておらず、課税は所得に対して行う。家門会計と拠出金の制度は[家門会計・法定拠出金と公私財政分離](household-accounts.md)を参照。所得税10.5億円は財政総額に合わせて配分した推計値で、249家に累進税率を適用した積み上げではない。[^n9][^p096]

# 経済社会の性格

1937年の経済社会は次のように総括される。[^p086]

| 側面 | 1937年の姿 |
|---|---|
| 資産所有 | 華族階級への高度集中 |
| 企業経営 | 同族所有と専門経営者の併存 |
| 企業間関係 | 共同出資・長期取引による企業連合 |
| 金融 | 銀行中心の間接金融 |
| 工業 | 領主系・独立系・公営企業の並立 |
| 農業 | 地主制を維持しながら経営近代化 |
| 都市社会 | 借家居住の給与所得中間層が発達 |
| 社会保障 | 生活保障は拡充、資産再分配は限定的 |
| 社会移動 | 教育・専門職・功績叙爵による上昇移動 |
| 世代間格差 | 家門財産の継承で固定化 |

旧領主系企業集団は独立系実業資本と並ぶ規模で存在し、企業社会と華族社会は元老院・金融機関・取締役会・社交組織を通じて密接に結合している。[^p086]

## 四重の格差

| 格差 | 1937年の状況 |
|---|---|
| 資産所有格差 | 華族770家門が民間純資産の50%を保有 |
| 産業間格差 | 製造業の労働生産性は農業の約3倍 |
| 地域経済格差 | 都市工業領国と小規模領国の1人当たりGDPに約2.3倍の差 |
| 行政サービス格差 | 財政調整制度が成立しても大きく残存 |

（出典：[^p095]）

地域経済格差と行政サービス格差の詳細は[領国の類型・財政と財政調整交付金（1937）](fief-finance-1937.md)を参照。

## 階級構造と両院の政治的利益[^n3]

大領主・実業家華族は財産権・企業活動・家門自治、中小領主・非実業家華族は共同金融・家門維持・負担軽減、非華族地主は土地所有権・農業政策、自作・自小作農は農業金融・価格安定・土地改良、小作農は小作権・生活保障、都市中間層は教育・住宅・職業機会、中小企業・自営業は信用供与・商業秩序、労働者は労働保護・賃金・社会保障に利害を持つ。元老院は資産所有者・専門エリートを、男女普通選挙の衆議院は農民・労働者・都市中間層を代表し、両院間の政策対立の基礎となる。[^p085] 元老院では大小の領主が互選で平等に1票を持つため（徳川宗家90億円も純資産53万円の小領主も同じ1票）、中小領主への信用供与や共同の資産運用が政治的に重要になる。[^p069]（→[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)、[領主金融圏と諸侯共済会（1867〜1937）](lord-financial-spheres.md)）

# 史実との比較

* 史実の日本では明治維新で旧領主の経済基盤が解体され、資産所有の頂点には三井・三菱・住友などの財閥家族が立った。本世界線では領主家が近代企業の株主・金融資本家として残り、財閥に相当する独立系の実業家華族と並立する。[^p070][^p086]
* 史実の戦前日本も地主制と高い資産格差を抱えていたが、本世界線では華族という法的身分が資産保有と強く結びついている点が異なる。[^p096]
