# 概要

1937年の日本（台湾を含む）は総人口7,800万人、労働力人口3,300万人、就業者3,220万人、失業者80万人（失業率2.4%）で、総人口に対する就業率は41.3%である。就業者の産業構成は第一次産業24.5%、第二次産業33.9%、第三次産業41.5%。[^e096][^e097] これらは[1937年の日本経済](/economy/economy-1937-overview.md)の産業別積算の過程で、当初の仮定（就業者3,590万人・就業率46%）を検証し直して得られた値である。

就業構造の最終形を決めたのは、1937年の社会構造に関する8項目のダイス判定である。中等教育・職業教育の普及は成功、女性の非農業部門への就業はファンブル、労働時間短縮・休日制度の普及はクリティカルとなり、1937年の日本は「労働力を最大限動員して成長する社会ではなく、資本装備と技能水準を高めながら教育期間と余暇を拡大する社会」と性格づけられた。経済成長の成果の一部は、GDPの増加ではなく教育・余暇・労働時間短縮として国民生活に還元されている。[^e096]

# 人口構成

1937年の人口構成は次のとおり置かれている。男女比は1:1の簡易モデルで、年次別の出生・死亡の積算は済んでいない。早期の工業化と公衆衛生の改善で死亡率の低下が早く、都市化で出生率の低下も早く始まった可能性がある。[^e095]

| 年齢 | 人口 | 構成比 |
|---|---:|---:|
| 0〜14歳 | 2,500万人 | 32.1% |
| 15〜19歳 | 720万人 | 9.2% |
| 20〜24歳 | 680万人 | 8.7% |
| 25〜39歳 | 1,680万人 | 21.5% |
| 40〜54歳 | 1,280万人 | 16.4% |
| 55〜64歳 | 600万人 | 7.7% |
| 65歳以上 | 340万人 | 4.4% |
| **計** | **7,800万人** | 100% |

生産年齢人口（15〜64歳）は4,960万人（63.6%）。世帯数は約1,700万。[^e093][^e095] 史実の1935年の日本は総人口約6,930万人、14歳以下約2,550万人、15〜59歳約3,850万人、60歳以上約510万人であった。[^e095]

## 長期の産業構成

第一次産業の就業率は史実より早く下がる。貿易黒字と海外所得があれば食料を輸入でき、早期の工業化と地方への鉄道・港湾・電力の普及、海運・金融・商業部門の大きさ、領主による農業基盤整備と機械化、恐慌期の公共事業による非農業雇用がその理由である。[^e070][^e071]

| 年 | 第一次 | 第二次 | 第三次 |
|---|---:|---:|---:|
| 1900 | 60% | 18% | 22% |
| 1910 | 51% | 23% | 26% |
| 1920 | 40% | 29% | 31% |
| 1925 | 34% | 32% | 34% |
| 1930 | 29% | 34% | 37% |
| 1937（E71案） | 22% | 36% | 42% |
| **1937（最終）** | **24.5%** | **33.9%** | **41.5%** |

（出典：[^e071][^e097]。1937年最終値は就業者総数が減ったため第一次産業の比率が上がったもの）

農業近代化の成功と農業の低生産性は両立する。近代化で必要な労働力が減り、比較優位を持つ製造・建設・電力・サービスや海外投資へ労働と資本が移って、産業間の賃金格差が広がる「1930年代の構造転換」が進む。[^e090] 農村・産炭地域からの労働移動は円滑に進んだ（ダイス成功）。[^e096]（→[農林水産業の近代化（1900〜1937）](/economy/agriculture-1937.md)）

# 労働時間と休日制度

労働時間短縮・休日制度の普及はクリティカル（出目98）で、その動機は領主家による大量の資本保有と1930年代の雇用対策にある。[^e096] 発展過程は次のように描かれる。

| 時期 | 内容 |
|---|---|
| 1910年代 | 大規模工場で労働時間規制が進む |
| 1920年代前半 | 1日8時間・週48時間制が普及 |
| 1920年代後半 | 官公庁・大企業で休日制度が拡充 |
| 1930〜33年 | 恐慌対策として労働時間短縮を推進 |
| 1934〜37年 | 週40〜44時間制が主要産業に普及 |

1937年の標準的な週労働時間は、官公庁・金融・大企業事務職40時間、大規模製造業40〜44時間、中小製造業44〜48時間、建設44〜48時間、運輸・公益40〜48時間（交代勤務）、小売・飲食48〜54時間、農林水産業は季節と操業条件による。大企業・官公庁では週休二日制が相当普及し、有給休暇は勤続年数に応じて年6〜12日である。帝国政府が基本的な労働基準を定め、各領国が地域・産業の事情に応じて実施する形をとる。ただし週40時間制や有給休暇の日数は、法制度としてはまだ確定していない。[^e096]

週48時間を42時間に短縮すれば、同じ生産量に約14%多い従業者が必要になる（一律には適用しない）。日本の年間労働時間を米国の90%と仮定すると、就業者一人当たりGDPの対米40.5%は時間当たりでは45.0%となる。[^e096][^e097] 史実でも国際労働機関（ILO）は1919年に1日8時間・週48時間を国際基準とし、1930年に商業・事務職へ拡大、1935年に週40時間の原則を条約化している。[^e096]

# 女性の就業

女性の非農業部門への就業はファンブル（出目5）であった。ただし女性がまったく就業しない社会ではなく、近代的な非農業部門での継続的な就業が進まなかった、という形で反映されている。[^e096]

| 分野 | 女性就業の状況 |
|---|---|
| 農業 | 家族従業者として広く就業 |
| 繊維・衣料 | 若年女性を中心に就業 |
| 小売・飲食 | 家族経営を中心に就業 |
| 教育・医療 | 女性の専門職が一定程度存在 |
| 金融・一般事務 | 継続的な就業は限定的 |
| 重工業・機械工業 | 男性中心 |
| 結婚後 | 離職・家庭への移行が多い |
| 管理職・技術職 | 進出は限定的 |

農村から都市へ移るとき、男性は工場や建設業に就職し、女性は農業の家族従業者から専業主婦へ移ることが多い。企業・官公庁の結婚退職慣行、男性世帯主を前提とした賃金制度、職業教育の男女別進路が形成され、片働き世帯が成立している。[^e096] 教育の判定は成功しているので女性教育そのものは失敗ではなく、中等教育を受けた女性が増えてもその教育を職業に生かせない構造であり、長期的には人的資本の利用という点で日本経済の弱点となりうる。女性の家事代行・保育サービスの大幅な拡大も想定しない。[^e094][^e096] 一方、片働き世帯と余暇時間の増加は耐久消費財・住宅・旅行・娯楽の需要を支える。[^e096]

# 教育

義務教育は史実の6年制を基準とし、義務教育後の進学率が高い社会である。中等・職業教育のダイス成功（出目88）を受けて在学者数が上方修正された。[^e095][^e096]

| 教育段階 | 判定前 | 1937年（修正後） |
|---|---:|---:|
| 初等教育 | 1,050万人 | 1,050万人 |
| 普通中等教育 | 250万人 | 280万人 |
| 実業・職業教育 | 160万人 | 200万人 |
| 高等教育・大学 | 35万人 | 45万人 |
| その他 | 40万人 | 40万人 |
| **計** | **1,535万人** | **1,615万人** |

重電・電力・鉄道・化学工業が高度に発達しているため、大学卒業者だけでなく現場監督・電気技師・機械整備士・製図工・化学分析技術者の需要が大きく、職業教育が重点的に拡充された。この人材基盤は、1937年以降に英国との軍事技術協力で外国技術を吸収する際の土台となる。公教育の就業者は65万人から75万人に増え、民間教育は15万人である。教員一人当たり生徒数は初等30人、中等25人、職業20人を目安とする。[^e094][^e095][^e096] 史実の1937年の日本は中学校生徒約36万人、高等女学校生徒約45万人（別に実業学校）であった。[^e095]

# 医療・公衆衛生

公衆衛生・医療制度の整備は成功（出目48）で、労働者と兵員の健康状態が改善している。[^e096] 公的医療は公立病院・診療所15万人、保健所・感染症対策5万人、母子保健・学校衛生3万人、公的福祉施設4万人、医療行政・検査3万人の計30万人、民間医療は医師6万人、歯科医2万人、看護師・助産師等18万人、薬剤・検査・事務14万人の計40万人で、公私合わせて70万人（人口千人当たり約9人）である。領国ごとに充実度の差があり、全国一律の医療保険（皆保険）は成立していない。[^e094][^e095]

|---|---:|---:|---:|
| 都市持家 | 450万 | 26.5% | 120ドル相当 |
| 都市借家 | 550万 | 32.4% | 110ドル相当 |
| 農村持家 | 550万 | 32.4% | 50ドル相当 |
| 農村借家 | 100万 | 5.9% | 45ドル相当 |
| 社宅・官舎等 | 50万 | 2.9% | 80ドル相当 |

持家率は約59%。都市住宅供給のダイス成功（出目65）により、年間の住宅建設は40万戸から45万戸に上方修正され、新規住宅建設は6.75億ドル相当（一戸1,500ドル相当）となる。[^e094][^e096][^e098] 都市住宅と生活関連サービスの成功に労働時間短縮のクリティカルが重なり、郊外住宅地・電化住宅・借家の供給、自動車による通勤・買物・休日旅行、鉄道の通勤・観光輸送、国内旅行、映画・演劇・スポーツ観戦、家庭向けの放送・出版、外食・休日需要、家庭電機・乗用車の保守といった生活様式が広がる。[^e096] 家庭用電力は一世帯年約398kWh（照明・ラジオ・扇風機・電気アイロンが中心）で、電灯普及率は96%である。[^e086][^e089]

# 産業組織

帝国工業規格の統一はクリティカル成功だが、中小製造業の企業間分業は失敗した（出目21）。そのため「技術的な標準化には成功しているが、経営組織としては垂直統合型の大企業が主流」である。[^e096]

| 主体 | 1937年の姿 |
|---|---|
| 大企業 | 素材から部品・完成品まで内部生産 |
| 領主系企業集団 | 集団内で専門分業が発達 |
| 独立中小企業 | 零細加工・修理・軽工業が中心 |
| 高精度部品 | 大企業内部の生産または輸入 |
| 外部下請網 | 発達が不十分 |
| 工業規格 | 全国的に統一 |

大規模な設備投資や品質管理は行いやすい一方、専門部品企業間の競争、新規参入、多品種の柔軟な生産には弱く、1937年以降の造船・航空機・高精度工作機械の増産や、軍需生産の大企業への集中に影響する。[^e096]（→[製造業の構造（鉄鋼・造船・機械・化学・自動車 1937）](/economy/manufacturing-1937.md)、[全国標準化政策](/institutions/national-standardization.md)、[寄親・寄子制と大領主間の近代化競争](/concepts/yorioya-yoriko.md)）

# 政府部門の人員

政府部門は帝国政府（外交・国防・通貨・司法・全国制度）、領国政府（地域行政・警察・教育・医療・公共事業）、市町村等（消防・衛生・住民行政）、軍から成る。料金収入を主とする公共事業体（郵便・電力・鉄道など）は各産業に分類し、領主家の資産管理部門や領主系企業は民間部門とする。[^e095]

# 軍備拡張への含意

社会構造ダイスの結果は、平時の経済力と戦時の潜在生産力の差を大きくしうる。[^e096]

| 判定 | 軍備拡張への影響 |
|---|---|
| 職業教育の成功 | 熟練工・技術者・整備要員の供給 |
| 女性の非農業就業の失敗 | 平時の女性労働力の活用が限定的 |
| 労働時間の短縮 | 非常時に労働時間を延長する余地 |
| 中小企業分業の失敗 | 軍需生産が大企業に集中 |
| 都市住宅の成功 | 工業地域への労働移動が容易 |
| 公衆衛生の成功 | 労働者・兵員の健康改善 |
| 地域間労働移動の成功 | 産業間の再配置が容易 |

ただし、非常時にただちに大量の女性労働力を動員できるとは限らず、職業訓練・企業慣行・家庭内労働の代替・社会的抵抗については別途の判定が必要とされる。[^e096]

# 却下・修正された案

* **就業者3,590万人・就業率46%**：当初の仮定。物的検証と社会構造ダイスにより3,220万人・41.3%に修正。[^e085][^e096]
* **第一次産業就業率27%（E70案）**：E71で22%に引き下げ。最終的には就業者総数の減少により24.5%。[^e070][^e071][^e097]
* **製造業余剰166万人の移動先案**：建設35万・運輸物流25万・商業25万・生活関連サービス40万・教育医療専門職25万・その他16万とする案は、全産業の検証が済むまで採用されなかった。[^e088]
* **追加雇用255万人案（E95）**：就業3,412万人・失業率2.4%・就業率43.7%とする案。社会構造ダイスで労働力人口自体が約195万人減ったため、追加63万人に縮小。[^e095][^e096]
* **在学者1,535万人・公教育就業者65万人（E95）**：中等・職業教育の成功で1,615万人・75万人に上方修正。[^e095][^e096]
* **年間住宅建設40万戸・50万戸案**：E94の40万戸、E95の50万戸案を経て45万戸に確定。[^e094][^e095][^e096]

# 未決の論点

* 週40時間制・有給休暇日数を法制度とするか。[^e096]
* 女性の就業制限が法律によるものか、企業慣行・社会規範によるものか。[^e096]
* 戦時の女性労働力動員（職業訓練・企業慣行・家庭内労働の代替・社会的抵抗）の判定。[^e096]
* 男女別の産業就業者数と年間総労働時間の完全な積算。年間労働時間の対米比（90%）は仮定。[^e096][^e097]
* 義務教育の延長の有無、年次別の出生・死亡に基づく人口構成の積算。[^e095]
* 公的医療を含む国民医療支出の規模。[^e095]
* 都市化率、主要都市の人口、地域別の産業構成、所得分布、社会保障。
