# 概要

本世界線では、1889年の日清講和の頃であれば、日本がアメリカと「経済力でトントン」を目指す戦略はまだぎりぎり間に合う、という見立てが置かれている（確定した方向性）。[^u080]

ただしここでいう「並ぶ」は、経済規模（総GDP・工業生産総額）で並ぶことではない。人口・天然資源・国内市場の規模で米国に並ぶのは極めて困難であり、目標は**工業技術・生産性・国民の豊かさ**で並ぶこと、そして太平洋地域の産業力・金融力で米国の対等な交渉相手になることにある。[^u080]

戦略の核心は、1860〜80年代に第一次産業革命への追いつきを終え、1890年代に始まる工業技術の世代交代（電力・電気機械・化学工業・内燃機関・新製鋼技術）、すなわち**第二次産業革命では米国と同じ時期から競争する**ことである（検討案）。[^u080] 「この世界の日本がアメリカに追いつくための最大の武器は、領主制を廃止したことではなく、領主同士の競争を全国的な産業発展へ転換できたこと」とされる。[^u080]

1937年の到達点は、GDPが米国の27%（購買力平価換算、英国本国の約76%）、一人当たり実質GDPが米国の約45%である（会話ログ3の確定値。会話ログ2の共通価格評価では28.0%・英国本国の約97%・一人当たり46.3%）。[^p092][^p097]総量の格差は大きいが、重電機器・非鉄金属製錬・通信・海運などでは米国に迫る生産性を得ており、成長の成果の一部は労働時間短縮・教育・余暇として還元された。[^e083][^e096][^e097]

# 戦略の構成

## 出発点の格差

史実の1890年の一人当たりGDP（マディソン系列、1990年国際ドル）は米国3,396、日本1,012で、日本は米国の約30%であった。1890年の米国人口は約6,300万人で、総GDPで追いつくには生産性格差に加えて人口規模の差も克服しなければならない。一方、近年の研究では幕末・明治初期の日本の所得水準は従来より高かった可能性も示されており、出発点を過度に低く見積もる必要はない。[^u080]

## 本世界線の日本の成長要因

| 要因 | 内容 |
|---|---|
| 統一市場 | 1860年代から商法・通貨・金融・輸送規格を統一（[全国標準化政策](/institutions/national-standardization.md)） |
| 領主間の産業投資競争 | 島津・毛利・鍋島・徳川・前田などが自領の産業化へ継続投資（[寄親・寄子制と大領主間の近代化競争](/concepts/yorioya-yoriko.md)） |
| 分散的な技術導入 | 使節団的な大規模視察に加え、領主家の技術官・留学生を長期派遣 |
| 早期の資本形成 | 1889年の賠償金を鉄道・製鉄・造船・教育・金融へ投資 |

この四つが重なることで、史実より早く重工業と機械工業を育成する経路が成立する。[^u080]（→[重工業化と国力の推移（1870〜1930）](/economy/heavy-industrialization.md)）

## 目標の分解

「アメリカとトントン」を目標別に分解すると次のようになる。[^u080]

| 目標 | 本世界線での見通し |
|---|---|
| 一人当たりGDP | 20世紀前半に格差を大幅に縮小する可能性 |
| 工業技術 | 造船・機械・電機など一部分野で早期に競争力を持つ余地 |
| 工業生産総額 | 米国の人口・資源規模が大きく、高い障壁 |
| 貿易・海運 | 東アジアの有力な商業国家になる可能性 |
| 金融・資本市場 | 全国統一市場と領主系資本を利用して発展する余地 |
| 軍需産業 | 陸海軍の需要を背景に重工業を育成できる |

## 工業化そのものを安全保障とする

1889年の講和で台湾・澎湖の領有が確定し、ロシアがシベリア鉄道建設へ向かう1890年代に、日本政府が対露軍拡へすべての資源を振り向けるのではなく、**工業化そのものを長期的な安全保障の手段として位置づける**ことがこの戦略の要である（検討案）。中央政府は軍艦や兵器を直接製造するだけでなく、領主系企業に発注して民間産業を育成でき、造船所・製鉄所・機械工場・鉄道会社・銀行が相互に発展する。ただし軍需への過度な依存は財政を圧迫し、領主系企業への優遇は競争を妨げる危険がある。[^u080]

戦略の分岐点は、1889年の賠償金を中央政府がどこまで産業投資へ使い、どこまで各領主へ分配するかにある。中央政府が相当部分を全国的な鉄道・電力・製鉄・教育・研究機関へ投入し、大領主がそれに競争的に追随するなら、工業化は史実以上に加速する。[^u080] 実際には、賠償金の分配をめぐる論争は全領国に利益のある[帝国交通整備計画](/economy/transport-plan.md)へと転換された。重工業化はさらに遡って、1870年代後半〜1880年代前半の製鉄・機械工業投資の成否に依存する。[^u082]

## 資源の制約

米国は国内に豊富な資源（とりわけ石油）を持つが、日本にはない。米国と総合的な工業力で競争するには、米国の資源を国内に再現するよりも、資源を世界中から集めて高付加価値の工業製品に変える仕組みをどれだけ早く確立できるかが重要になる。その前提として国際貿易の自由と英国との通商・海軍協力が不可欠となる。[^u081]（→[資源戦略](/economy/resource-strategy.md)）

# 追いつく相手としての米国

本世界線では[南北戦争が回避されている](/events/american-civil-war-avoided.md)ため、米国自身も史実と異なる発展をたどる。戦争による人的・物的損失を避けた一方、史実で戦争を通じて進んだ連邦財政・銀行制度・鉄道・工業生産の拡張は別の経過をたどりうる。奴隷制と州権問題の解決方法によって南部の労働市場・人口移動・投資環境も変わる。米国経済が史実以上に発展するのか、制度改革の遅れで一部分野の成長が鈍るのかは決まっていない。「追いつくべき相手自体が動いている」のである。[^u080]

1888年頃の日本外交にとって、米国は通商の自由・朝鮮独立・金融協力をめぐる交渉相手と位置づけられ、その対日協調の度合いは南北戦争回避世界の独自の経緯に左右される。[^u075]

# その後の推移

## 第一次世界大戦：共同の供給国

第一次世界大戦では、日米はともに英国を支える立場に立つ。日本は太平洋・インド洋の海軍活動、軍需供給、商船建造を、米国は大西洋の海運、軍需供給、金融を担う構造が想定される。ただし日本製品が米国製品を一部代替するだけなら、連合国への供給総額は増えない。戦後の利害も異なり、日本は英国と築いた東アジアの金融・通商秩序とドイツの技術賠償を、米国は大西洋貿易の安全・債権回収・欧州安定を重視する。[^u101]（→[第一次世界大戦と日本](/events/world-war-one.md)）

大戦の結果、英国の戦時債務の一部は米国から日本へ移り、日本も英仏への大口債権国となる。[^u118] その債権の多くは軍需品・船舶輸出代金の繰延べとして円建てで形成され、円の国際的地位を押し上げた。[^u135]（→[円建て対外債権と円の国際化](/economy/yen-claims.md)）

## 戦間期：中国市場をめぐる対立

経済面での接近は、日米の利害衝突も生む。1889年に日本が対露戦略上英国へ先行的に与えた中国権益と、それへの日本の資本参加は、門戸開放を掲げて新規参入を図る米国資本と衝突する。辛亥革命は日英米の対中政策を分裂させる最初の重大事件になりうるとされる。[^u107]（→[戦間期の中国（軍閥・謀略・民族主義）](/diplomacy/interwar-china.md)、[戦間期の米独接近と米国内の宣伝戦](/diplomacy/us-germany-relations.md)）

## 到達点：1920年と1930年

| 指標 | 1920年（中核・検討案） | 1930年（中核・検討案） | 米国（史実） |
|---|---|---|---|
| 粗鋼 | 500万t | 実生産700万t（能力900万t） | 約4,230万t（1920）、5,734万t（1929） |
| 製造業労働生産性（米国＝100） | — | 45 | 100 |
| 造船業労働生産性（米国＝100） | — | 60 | 100 |

1920年の日本は「史実よりかなり豊かな工業国だが、まだアメリカとは大きな差がある国家」であり、設備稼働率・熟練労働者・燃料効率・製品品質で米国と差がある。[^u126] 1930年の中核案でも製造業全体の労働生産性は米国の45%で、造船（60%）など一部分野で接近している。[^u132] 総量での格差は残るが、一人当たり・技術での接近という戦略目標に沿った推移である。

## 1930年代の米国と日米の経済関係

世界恐慌下の米国は高関税のもとで国内・中南米・中国・ソ連に需要を求め、1933年に金本位制を停止してニューディールに転じた（史実通り）。日本（1925年に金本位制を廃止）・英国（1931年）・米国（1933年）の三国はいずれも管理通貨へ移り、安全保障上は対立しつつも恐慌脱出の利益は共有した。[^e046][^e054] 1931年の欧州通貨危機以後、米国は日英の金融・通商協力を世界規模の経済ブロックへの発展とみて警戒するが、自らも高関税のため批判には限界があり、米企業は中国・カナダ・豪州で日本企業と競争する（検討案）。[^e044]（→[1931年欧州通貨危機と日英金融協力](/events/currency-crisis-1931.md)、[オタワ帝国経済会議（1932）と日本](/diplomacy/ottawa-conference-1932.md)）

1936年末に海軍軍縮条約が失効すると、米国では「1937年海軍拡張法」（仮称）がクリティカル（1d100 > 20、出目99）で成立し、潜在工業力を海軍に振り向ける政治的・財政的障害が取り除かれた。これがニューディールに加わることで、史実の1937〜38年の景気後退が縮小する可能性があり、米国が史実より早く恐慌を脱すれば日英にとって強力な競争相手となる（検討案）。[^e067]（→[1937年の建艦競争と海軍財政](/military/naval-buildup-1937.md)）

経済面の結びつきも残る。1937年の日本の石油調達850万t（当時の需要想定）のうち米国産は150万t（18%）で、対米関係が悪化しても即座に途絶はしないが依存は小さくない。[^e081] 高精度工作機械・精密測定器は米国・英国・ドイツ・スイスから輸入している。[^e083] 石油需要はその後1,250万tへ上方修正された（→[エネルギー需給と電化](/economy/energy-1937.md)）。[^e089]

## 1937年の到達点

1937年の日本経済は産業別の積算によって、GDP 260.26億ドル相当（1937年米国価格基準）、米国（BEA推計930.03億ドル）の**28.0%**、GNIは264.27億ドル相当（28.4%）とされた。一人当たりGDPは米国の46.3%、英国本国の58.5%で、総GDPは英国本国の約97%にあたる。[^e097] 日英本国の合計は米国の56.8%（自治領・植民地を含まない）である。[^e097] その後、会話ログ3でこの幅（26〜28%）の中間値27%が確定値とされ、比較基準もHarrison編の1938年購買力調整値に改められた。この基準では本世界線日本は米国の27%、ソ連の約60%、ドイツの約62%、英国本国の約76%、フランスの約116%にあたる（→[1937年の円相場・物価・家計と列強経済力比較](/economy/yen-prices-1937.md)）。[^p092][^p097]

| 指標（米国＝100） | 日本（1937） |
|---|---:|
| 漁業生産量 | 約380 |
| 商船保有量 | 72.6 |
| 就業人口 | 69.1 |
| 総人口 | 60.5 |
| 一人当たりGDP | 46.3 |
| 総発電量 | 44.4 |
| 就業者当たりGDP | 40.5 |
| GDP | 28.0 |
| 粗鋼生産 | 21.6 |
| 自動車生産台数 | 6.3 |

[^e097] 電力・海運・特定の素材産業には比較優位がある一方、自動車の大量生産と国内資源の採掘では大きな格差がある。年間労働時間を米国の90%と仮定すると、時間当たり労働生産性は米国の約45%となる（労働時間の対米比は未確定）。[^e097]

産業別の対米労働生産性は部門によって大きく異なる。[^e083][^e085][^e088]

| 米国に接近する部門 | 対米 | 格差の大きい部門 | 対米 |
|---|---:|---|---:|
| 重電機器 | 95% | 小売 | 40% |
| 非鉄金属製錬 | 90% | 無線・精密機器 | 40% |
| 通信 | 90% | 繊維・衣料 | 38% |
| 海運・総合商社 | 85% | 工作機械 | 45% |
| 基礎鉄鋼・石油精製 | 80% | 石炭採掘 | 約26% |

ただしダイスの成功は産業の発展を確定させても対米生産性の百分率までは確定させないとされ、海運・卸売・金融などは後の積算で付加価値が下方修正された。[^e087][^e090][^e091][^e092] 部門別の詳細は[製造業の構造（1937）](/economy/manufacturing-1937.md)と[運輸・商業・通信・金融サービス（1937）](/economy/services-1937.md)を参照。

戦略目標に照らすと、総GDPでは米国の3割弱にとどまるが、一人当たりでは史実（約29%）を大きく上回る46%に達し、重電・非鉄・通信・海運などでは米国に並ぶ技術・生産性を得た。さらに1937年の社会構造判定では労働時間短縮・休日制度がクリティカル（98）で成功し、日本は「労働力を最大限動員して成長する社会ではなく、資本装備と技能水準を高めながら教育期間と余暇を拡大する社会」とされる。成長の成果の一部はGDPの増加ではなく、教育・余暇・労働時間短縮として国民生活に還元された。[^e068][^e096] 社会面は[1937年の就業構造と社会](/economy/labor-society-1937.md)、経済全体は[1937年の日本経済（国民経済計算と基本指標）](/economy/economy-1937-overview.md)を参照。

# 史実との比較

* 史実1890年の日本の一人当たりGDPは米国の約30%。[^u080]
* 深尾京司らの推計では、1935年前後の日本の工場制製造業の規模は米国の約12%、労働時間当たり生産性は約24%。本世界線1930年の中核案（45%）はその約2倍に当たる。[^u132]
* 史実1929年の粗鋼生産は米国5,734万t、日本229万t。[^u132]
* マーク・ハリソンの1937年推計（1980年国際ドル）では、史実日本のGDPは米国の約16%、一人当たりは1,333ドル（米国4,574ドルの約29%）。本世界線ではGDP28.0%・一人当たり46.3%となる。[^e068][^e097]
* 1937年の比較では、米国経済は史実通りの規模（GDP930.03億ドル、粗鋼5,324万t、自動車478万台）を維持すると仮定されている。米国側の分岐（南北戦争回避）の経済的影響はこの積算には反映されていない。[^e068][^e097]

# 却下・修正された案

* **1937年GDP対米比の変遷**：E68〜E69で人口7,800万・一人当たり対米47%・GDP対米28（英本国の99%相当）を確定 → E72で産業構造と整合しにくいとして38%（一人当たり63%、英本国の131%）を候補に → E86の就業者・生産性方式で42.2%（一人当たり約70%、英国の約1.46倍） → 就業者・卸売・金融・海運の過大推計を修正したE97の産業別積算で28.0%に戻った。支出面推計（25.8%）を加え範囲は26〜28%、28%を中核とする。[^e068][^e069][^e072][^e086][^e097][^e098]
* **1937年の米国GDP基準900億ドル** → BEAの930.03億ドルに変更（E97）。[^e086][^e097]

# 未決の論点

* 南北戦争を回避した米国の経済発展が史実以上か否か、その金融・外交・対日対清金融への関与度。[^u080][^u075]
* 1889年の賠償金のうち、中央政府の産業投資と各領主への分配の比率。[^u080]
* 1920年代以降の日米経済関係（貿易・投資・債権債務）の具体像。1937年の米国からの石油調達（18%）や工作機械輸入は示されたが、国別・地域別の貿易表は未作成。[^e081][^e103]
* 米国の「1937年海軍拡張法」が1937〜38年の米国景気と工業力拡張に与える効果（1938年以降は予測シナリオにとどめる）。[^e067][^e103]
* 年間労働時間の対米比（時間当たり生産性45%は90%の仮定に基づく）。[^e097]
