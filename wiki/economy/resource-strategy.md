# 概要

天然資源をどう確保するかは、本世界線の日本にとって実際に大きな問題である。[^u081] 工業化が史実より早い分、資源制約にぶつかる時期も早い。ただし1889年時点の日本は必ずしも資源小国ではなく（石炭・銅は国内に供給源がある）、問題は工業化の進展に伴って必要な資源の種類が変わること、とりわけ**鉄鉱石**と20世紀の**石油**である。[^u081]

この問題に対し、本世界線の日本は資源を領有するのではなく、「国際金融と商業契約によって資源供給を確保する」路線を基本とする（検討案。ただし以後の設定――中国大陸に直接・独占の利権を持たない日本、輸入鉄鉱石・原料炭に依存する1920〜30年代の鉄鋼業、海上交通保護を主任務とする海軍――はこの路線と整合して組み立てられている）。[^u081][^u102][^u126][^u127] この戦略は、「資源を世界中から集めて高付加価値の工業製品へ変える仕組み」の確立を目指すものであり、その代わりに国際貿易の自由の維持が日本の経済と安全保障の双方を左右するという弱点を抱える。[^u081]

1937年までにこの路線は具体的な数値として実現した。国内の金属鉱山は1930年代に経営危機に陥り（ダイス判定：1d100 > 55、出目1・ファンブル）、鉄鉱石の自給率は3.4%にまで下がった一方、英国経済圏・中国での鉱山投資と英国系石油事業への資本参加はいずれも成功し、水力電力を生かした非鉄金属製錬はクリティカル（出目100）で成功した。「**採掘は海外、精製・製錬・加工は国内**」という国際分業が成立し、日本は鉱石の大規模輸入国であると同時に精製金属の輸出国となった。[^e081] 資源の国際分業は農産物にまで及び、本世界線の日本は「史実の日本より資源調達能力が高い反面、平時の国際分業への依存度も高い国家」となっている。[^e071]

# 資源別の条件

| 資源 | 本世界線の日本の条件 | 長期的な問題 |
|---|---|---|
| 石炭 | 筑豊・三池・北海道などに国内供給源 | 工業化に伴う需要増と製鉄用炭の品質 |
| 銅 | 足尾・別子などの鉱山 | 鉱量と公害、将来の電化需要 |
| 鉄鉱石 | 釜石などがあるが大規模製鉄には不足 | 中国大陸などからの安定輸入 |
| 石油 | 国内産出量が小さい | 内燃機関・石油燃料艦船の普及で深刻化 |
| 水力 | 山地と河川を多数持つ | 送電技術と設備投資 |
| 綿花・羊毛 | 大量生産には輸入が必要 | 海上貿易と輸出競争力 |

最大の問題は石炭より鉄鉱石と石油である。日本の本格的重工業化は、かなり早い段階から大陸の鉄鉱石に依存する構造になる。[^u081]（→[重工業化と国力の推移（1870〜1930）](/economy/heavy-industrialization.md)）

# 基本方針

## 領有によらない資源確保

日本が必要としているのは満洲や中国大陸の広大な領土ではなく、工業生産を維持するための資源である。それは次の手段で確保できる。[^u081]

* 鉄鉱山の採掘権
* 長期購入契約
* 鉄道輸送権
* 港湾使用権
* 共同出資会社

清国が対日賠償を支払うために外国資本を必要としている時期は、日本系企業が資源事業へ進出する好機でもある。この方法なら、ロシアのような大陸国家との領土紛争を増やさずに工業化を進められる。ただし戦争や海上封鎖が起これば輸入は途絶えるので、海軍力と通商外交が条件となる。[^u081]

## 自給自足か国際貿易か

本世界線で決定的なのは、日本が資源の自給自足を国家目標にするのか、国際貿易による安定供給を目標にするのかという選択である。国内に米国のような資源の豊かさはなく、それを無理に国内（あるいは領土拡張）で補おうとすれば軍事費と領土拡張の負担が増し、産業投資を圧迫する。逆に1889年の戦勝で中国市場での地位を確立し、英米との通商関係を維持しながら鉱業・海運・金融へ投資するなら、資源の不足を輸入で補う経済構造を作れる。本世界線の議論は後者を有望とする。[^u081]

その帰結として、1889年以降の日英の海軍・通商協力は単なる対露外交ではなく、米国に匹敵する工業国家を目指すための経済政策でもある。[^u081]（→[日英協調](/diplomacy/anglo-japanese-cooperation.md)、[対米経済戦略](/economy/us-economic-strategy.md)）

# 経過

## 1889年前後：下関条約と大冶鉄鉱

[下関条約（1889年）](/diplomacy/shimonoseki-treaty-1889.md)と[対清賠償借款](/economy/indemnity-loan.md)の交渉と並行して、日本企業自身が清国の鉱山・鉄道のコンセッションを取得することが考えられる（検討案）。特に長江流域で、湖北省の大冶鉄鉱山と長江の輸送網を確保し、筑豊炭田の石炭と中国の鉄鉱石を組み合わせて北九州で製鉄する構造が想定される。これは史実の八幡製鉄所が採用した構造に近い。[^u081]

この事業の主体は中央政府だけとは限らず、島津家・鍋島家・毛利家・徳川家などの領主系企業の共同出資もありうる。ただし中国の鉱山利権には清国の地方官や商人の利害が絡み、日本が戦勝国だからといって鉱山を自由に取得できるわけではない。英仏の既得権と衝突しないよう、鉱業特許を分野・地域ごとに調整する必要がある。[^u081]

日本の地域別関心では、長江流域は英系金融・商業と協調できる地域とされ、日本の商社・銀行（領主系資本）が欧米銀行団と共同で中国の鉄道・鉱業へ投資する余地がある。ただしそれは清の従属を深めることにもなる。[^u074]（→[中国大陸の利権争奪（1888〜1900年代）](/diplomacy/china-concessions.md)）

## 領主系企業による分散投資

本世界線独自の強みは、資源調達を中央政府が一元管理するのではなく、複数の領主系企業が競争して海外資源に投資する点にある（検討案）。例えば、ある領主家は湖北省の鉄鉱石へ、別の家は豪州の石炭・鉱産資源の調査へ、さらに別の家は北米の石油企業への出資へ向かう。その結果、資源供給源が複数に分散される。[^u081]

ただし領主家の企業が自家の政治力を使って関税優遇や独占権を得る危険があり、元老院による経済政策の決定には利益相反の問題が常につきまとう。[^u081]（→[元老院](/institutions/genroin.md)）

## 20世紀の石油問題

石炭については、史実でも日本は1890年代を通じて相当量を輸出しており、1889年時点で石炭不足を理由に海外領土を拡張する必要は薄い。深刻なのはその後の技術転換で、蒸気機関から内燃機関へ、石炭燃焼から石油燃料へと移行するにつれ日本の資源条件は急速に悪化する。米国には大規模な石油資源があり、日本が米国と工業生産力で競争するなら、石油という戦略物資の安定調達が問題になる。[^u081]

新潟・秋田の油田だけでは不足するため、東南アジア・米国・ロシアなどとの石油貿易や海外油田への投資が検討課題となる。一方、水力発電と電気鉄道を早期に普及させれば、石炭・石油への依存を一定程度抑えられる。[^u081]（いずれも1937年までに実現した。→「1930年代の展開」節、[エネルギー需給と電化（1937）](/economy/energy-1937.md)）

## 第一次世界大戦期：船腹と輸入の両立

1914年の粗鋼300万〜450万tという中核案は、中国大陸などからの鉄鉱石・原料炭の輸入を成立条件とする。大戦中、日本の商船を大量に英国へ貸し出せば鉄鉱石・石炭・石油・綿花の輸入が滞り、自国の工業生産を損なう。このため既存船の無制限な徴用ではなく、造船能力を増やして英国へ新造船を供給する方針が優先される（検討案）。[^u098]

## 戦間期：英国の秩序を通じた資源調達

戦間期の日本は中国大陸に直接かつ独占の利権を持たず、その空白は英国が埋めている（確定）。日本は英国の金融・通商秩序を通じて中国経済に参加し、英系事業への投資・取引、資源輸入、工業製品輸出を行う。[^u102] 英国の対日戦時債務の代物弁済として、日本が英系の鉄道・鉱山・港湾企業へ資本参加すれば、長期収益権と資源輸送網を獲得できる（→[日英戦時債務整理と中国権益の移転](/diplomacy/war-debt-settlement.md)）。[^u103]

1920年の粗鋼500万t級の生産には輸入鉄鉱石と原料炭が必要で、英国・中国との海運・資源調達網が大戦後も機能していることが前提である。[^u126] 1930年にも、工業化には中国などからの鉄鉱石・原料炭・製鉄設備の安定供給が必要で、中国の軍閥政治や英米との金融対立がそこに響く。[^u132]

1930年前後の日本の主力輸入は鉄鉱石・原料炭・石油・綿花であり、主力輸出は機械・鉄鋼・船舶・化学製品・電機である。輸入原料に依存するため、円相場の急落は工業生産に深刻な打撃となる。[^u137]

## 海軍戦略との結びつき

資源輸入への依存は、本世界線の日本海軍の性格を規定した。日本海軍は敵艦隊の撃滅よりも、海外の鉄鉱石・石炭・石油・綿花の輸送と英国との通商を守る海上交通維持のために発展し、元老院は海軍予算の審議で「その戦艦を造ることで、どの輸送路が安全になるのか」と問う。[^u127]（→[帝国海軍の戦略思想](/military/navy-strategy.md)）

# 1930年代の展開：1937年の資源需給

## 一次産業の競争力喪失

1930年代の日本では、農作物を含む一次産品の国内生産の競争力が大幅に下がった。英国の植民地は日本の植民地ではないが、資源輸入元・投資先としてはほぼ同様に機能している。一次産業の衰退は生産性の低下ではなく、生産性が向上しても外国産品と国内非農業部門の賃金上昇に勝てないことによるもので、海運・港湾の生産性向上による輸送費の低下がそれを加速した。「国内の工業化と海運業の発展が国内一次産業の価格競争力を失わせる」。[^e071]

資源・農産物の貿易は大幅な赤字だが、工業製品貿易・海運保険収支・海外投資所得の黒字で補われる。対英経常黒字の恒常化は好ましくないため、日本政府・金融界には国内一次産業を保護するより英国経済圏からの輸入を拡大する動機が働き、領主家も事業を多角化しているため一枚岩の資源・農業保護勢力にはならない。[^e071]（→[農林水産業の近代化（1900〜1937）](/economy/agriculture-1937.md)、[国際収支と対外資産](/economy/balance-of-payments.md)）

## 国内金属鉱山の衰退

ファンブルの結果、1930年代に国内金属鉱山は経営危機に陥った。原因は、恐慌による金属価格の下落、深部化による採掘費の上昇、設備更新の失敗と経営破綻、海外鉱山への資本流出、工業との賃金競争による労働力不足である。領主系企業は1932年の[オタワ会議](/diplomacy/ottawa-conference-1932.md)後に確立した円建て投資制度を使って海外鉱山へ向かった。金銀は採算のよい鉱山が残る（金本位制を廃止済みで金山を保護する必要も低い）。[^e081]

| マグネシウム | 1.0万t | 0.8万t | 0.2万t |
| 錫 | 3.0万t | 2.0万t | 1.0万t |

[^e081]

ボーキサイトは英領・蘭領から輸入し、水力電力で製錬する。「国内資源の採掘産業は石油を例外として衰退し、輸入資源を加工する素材産業は世界有数の競争力を獲得する」。海外資源投資はGNIに、国内の精製・製錬はGDPに寄与する。[^e081]（→[製造業の構造（1937）](/economy/manufacturing-1937.md)）

| カナダ | 銅・ニッケル・亜鉛 |
| 英領マラヤ | 鉄鉱石・錫 |

| 英領アフリカ | 銅・金 |
| 蘭領東インド | 石油・ボーキサイト・錫 |
| チリ | 銅 |
| ニューカレドニア | ニッケル |

出資・採掘権・長期購入契約は区別される。中国での投資はぎりぎりの成功で、聯合の政治的不安定と加盟軍閥間の相互不信による政治リスクが残る。英国経済圏への投資は大規模な資本参加として成功した。[^e080][^e081]

1889年前後に想定された大冶鉄鉱（湖北省）など清国の鉱山コンセッションに代わり、1937年の鉄鉱石・石炭の主な供給元は中国諸省聯合・英領マラヤ・インド・豪州である。[^e072][^e080]

石油は、国内原油生産／日本企業の海外油田持分生産／長期購入契約／国際市場購入の4区分で調達する。需要850万tとしていた段階の調達構造は、国内12%、英領ボルネオ・ブルネイ18%、ビルマ6%、イラク・ペルシャ12%、蘭領東インド25%、米国18%、ソ連5%、その他6%で、米国依存は18%にとどまるが、日英の海上交通が同時に妨害されれば脆弱である。[^e080][^e081] その後の積算で石油需要は1,250万t、輸入原油は1,050万tに修正された。[^e089]

## 安全保障上の帰結

海上交通が途絶すれば、日本は軍需資源だけでなく都市人口の食料・工場の原材料・海外投資所得を同時に失う。自給自足を目的とする領土拡張は英国との経済関係を破壊するため経済合理性が極めて低く、とるべき手段は海外資源投資・[戦略資源備蓄](/economy/strategic-stockpile.md)・輸入先の分散と、[日英海上通商防衛協定](/diplomacy/anglo-japanese-maritime-defense-agreement.md)による海上交通の維持である。この協定は「経済構造そのものの維持」を意味する。[^e071] 石油の輸入依存が当初の想定より深刻となったことで、協定の経済的重要性はさらに高まった。[^e089]

# 史実との比較

* 史実の八幡製鉄所は国内鉄鉱石の不足から、1899年に中国大冶鉄鉱石の輸入契約を結んだ。[^u081]
* 明治期の日本は石炭・銅の輸出国であり、1886〜1910年の国内石炭生産は国内消費を上回っていた。資源不足が深刻な制約になった時期については、1930年代の軍備拡大の影響を重視する研究もある。[^u081]
* 史実の日本は満洲などの領土的支配によって資源を確保しようとしたが、本世界線の日本は採掘権・契約・資本参加による確保を基本とし、大陸を直接支配しない。[^u081][^u102]
* 史実では新潟・秋田の国内原油は1915年の約48万kLが頂点で、海外油田権益の取得は多くが成立しなかった。本世界線では1937年に国内原油100万tを産し、英国系・英国圏外の石油権益取得にも成功している。[^e080][^e081]

# 却下・修正された案

* **1937年の資源需給（E72の初期案）**: 石炭の国内生産5,700万t・需要7,200万t・自給率79%、石油自給率5%（国内原油45万t）、鉄鉱石の国内採掘180万t・自給率10%、銅28%などの案 → 炭鉱合理化の失敗と国内金属鉱山のファンブル（E79・E81）を反映して、石炭3,800万t、鉄鉱石60万t、銅13.3%などへ修正。さらにE89で石炭需要5,700万t・石油需要1,250万tに修正された。[^e072][^e079][^e081][^e089]
* **鉄鉱石の需要**: 1,750万t → 臨海一貫製鉄所の合理化（クリティカル）を反映して消費約1,400万tへ下方修正。[^e081][^e083]
* **鉱業就業者**: 72万人 → 64万人（E81）→ 石炭採掘就業者の過大を修正して40万人（E90）。[^e081][^e090]

# 未決の論点

* 日本企業（領主系企業）が1889年前後に取得する鉱山・鉄道コンセッションの具体的な範囲と、英仏既得権との調整方法。[^u081]
* 20世紀の石油調達先の具体像は、1937年の調達構造として設定された（E81で解決）。ただし石油需要1,250万tへの修正後の輸入先別内訳と、持分生産・長期契約・市場購入の区別は未設定。[^e081][^e089]
* 領主系企業の海外資源投資に対する関税優遇・独占権要求をどう規制するか。[^u081]
* 代物弁済で取得する中国権益の範囲（債券・株式・経営権に限るか）。[^u103]
* 鉱石の品位・製錬歩留まり・再生金属の割合の調整と、海外資源事業から得る所得の推計。[^e081]
