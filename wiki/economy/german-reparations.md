# 概要

本世界線の第一次世界大戦後、ドイツは史実以上に厳しい戦後処理を求められた。[^n5] 戦勝国の債務残高は史実より重く、日本も知的財産の接収や物的賠償によって戦争の果実を得ようとした。[^u099] 対独厳格賠償の政治的圧力は、英仏だけでなく日本からも生じた。

ただし日本が欲しがるものと英仏が必要とするものは異なる。英仏が必要とするのは自国の戦時債務を返済するための**現金**であり、日本が求めるのは自国の第二次産業革命を完成させるための**ドイツの工業技術と実物**である。このため講和条件は史実以上に複雑になり、問題は「ドイツにいくら払わせるか」だけでなく「**ドイツの産業力を誰がどれだけ利用できるようにするか**」となった。[^u099]

賠償は、日本の対英仏戦時債権（→[日英戦時債務整理と中国権益の移転](../diplomacy/war-debt-settlement.md)）と連鎖しており、日本は債権国として講和会議での発言力を強める一方、欧州の財政・銀行危機を輸入する危険も負う。[^u099]

# 背景：日本の債権国化

日本は大戦中、英仏へ砲弾・火砲・商船・機械類を大量に供給した（→[第一次世界大戦期の日本の軍需・海運・海軍協力](../military/wwi-japan-war-effort.md)）。代金の一部が借款・政府保証債務として繰り延べられると、次の連鎖が生まれる。[^u099]

1. **日本の軍需工業・造船業**が兵器・商船・機械を英仏へ供給する。
2. **英仏の対日戦時債務**として代金の一部が繰り延べられる。
3. **対独賠償との連動**：英仏は賠償収入を対日債務の返済財源として期待する。

ただし、日本の供給が米国からの購入を置き換えただけなら、変わるのは債務の総額より**債権者の構成**である。[^u099][^u119] 戦後の国際債務構造は、史実の「米国中心」から「米国に加え日本も英仏への大口信用供与国」へ変化する。[^u099]

| | 史実に近い構造 | 本世界線の構造 |
|---|---|---|
| 大口債権国 | 米国 | 米国と日本 |
| 英仏の返済財源 | ドイツからの賠償収入 | 同左 |
| 賠償配分の争点 | 現金の取り分 | 日本が現金・技術・船舶・設備のいずれを求めるか |

1918年の終戦時、英仏は日米に大きな債務を負い、革命ロシアは旧債務を否認し、ドイツには従来以上に重い戦後処理を求める圧力が生じた。[^n1][^u119]

# 日本の要求：産業賠償

## 求めるもの

日本は技術獲得を賠償の重要な目的に据えた。[^n2][^u099]

| 日本が求めるもの | 工業化への効果 |
|---|---|
| 化学・染料・医薬品の特許実施権 | 国内化学工業の高度化 |
| 合成アンモニア・肥料製造技術 | 農業生産性の向上、火薬原料の確保 |
| 電機・精密機械関連の特許 | 電力設備・工作機械産業の育成 |
| 工作機械・化学設備の現物引渡し | 生産設備の迅速な増強 |
| 技術文書・製造ノウハウ | 国内企業の技術習得の支援 |

合成アンモニアの要求は、大戦中に火薬原料（窒素化合物）の不足が日本の軍需生産の制約となったことと直結している。

## 「産業賠償」という方式

特許の接収と実際の製造技術の取得は別である。熟練技術者の経験や企業秘密は自動的には手に入らない。また、ドイツ国内の特許権を日本へ移転させることと、日本国内のドイツ特許を接収することは法的に区別される。そのため日本は、**特許の実施権、設備供与、技術文書、技術者による指導を組み合わせた産業賠償**を要求した。[^n2][^u099]

日本にとっては、数千万金マルクの現金より、ドイツとの技術格差を数年縮められる制度の方が魅力的であった。[^u099] 1919年の講和会議において、日本はドイツの工業技術を獲得して**自国の第二次産業革命を完成させようとした**。[^u099]

# 英仏日の利害対立

日本がドイツ製の工作機械や化学設備を受け取れば、将来の日本企業は英仏企業の強力な競争相手になる。英国は日本の軍需供給で戦争に勝ちながら、戦後にはその日本を産業上の競争相手として強化することになるため、日本への技術賠償をどこまで認めるかは英仏にとって簡単な問題ではない。日本側も、現金賠償の取り分を減らす代わりに特定分野の技術供与を求める交渉を行った。[^u099]

| 国 | 賠償に求めるもの |
|---|---|
| フランス | 戦災復旧と安全保障のための巨額賠償、ドイツの軍事的弱体化 |
| イギリス | 戦時債務の返済財源。同時にドイツ市場の回復と欧州経済の安定 |
| 日本 | 戦費回収と産業技術の獲得。無期限の現金取り立てには強い利益をもたない |
| アメリカ | 大西洋貿易の安全、戦後通商、債権回収、欧州の安定 |

米国の戦後利害は日本と異なり、日英と一体化するとは限らない。[^u101]

# 賠償総額への抑制

日本は1889年の日清講和で、**敗戦国の支払い能力を超える賠償金は回収できない**ことを経験している（→[対清賠償借款と講和の国際金融](indemnity-loan.md)）。しかも今回は、ドイツから取り立てるために日本自身が海軍力を行使したり欧州占領軍を維持したりする必要もない。そのため日本は、英仏による賠償総額の引き上げを支持しつつも、実際に回収できない名目上の巨額請求には慎重であったとみられる。[^u099]

結果として、名目上の賠償総額が史実の1,320億金マルクを超えた可能性も、逆に日本の実物・技術賠償優先によって現金賠償をめぐる争いに一定の抑制が働いた可能性もある。[^n3][^u099]

# 戦後国際金融への影響

## 欧州の不安定の輸入

債権国になることは現金を確実に回収できることと同義ではない。英仏がドイツ賠償に依存しているなら、日本の対英仏債権も間接的にドイツ経済の回復に左右される。史実ではこの連鎖が1920年代の欧州金融を不安定にしたため、日本が巨額の欧州債権を抱えれば戦後の財政・銀行危機を輸入しかねない。**戦勝によって欧州に対する日本の金融的影響力は拡大するが、同時に欧州経済の不安定さに巻き込まれる**。[^u099]

## 日本国内での財源としての位置づけ

1920年代の軍事財源の区分では、対独賠償は「戦後の臨時財源」に分類される（財源三区分の詳細は[帝国財政と諸侯の法定拠出](imperial-finance.md)）。[^u126]

- 実際に受領した金銭は臨時財源にできる。
- 船舶・機械・設備による現物賠償は調達費の節約につながる。
- ただし額面の賠償請求権は、そのまま自由に使える現金ではない。

1920〜1925年に対英仏債権の償還金・実受領の対独賠償・戦時準備金から計6億円を海軍へ配分する「帝国艦隊更新基金」が構想された。ただしこれは賠償・債権の回収が順調に進むことを前提とした楽観的な見通しであった。[^n4][^u126]

## ドイツの反応と米独接近

本世界線でドイツの賠償条件が史実以上に厳しければ、ドイツが米国の金融協力を求める動機はさらに強くなる。米国がドイツの経済再建を支援し、そのドイツが中国市場への再進出を目指す連鎖が生まれる（→[戦間期の米独接近と米国内の宣伝戦](../diplomacy/us-germany-relations.md)）。[^u109] ただしドイツは米資本で復興しても対英仏日賠償の履行義務を負い、米銀行も「ドイツへの融資→賠償支払い→英仏の対米（本世界線では対日も）債務返済」の循環に関与するため、ドイツは日英仏から完全に自由にはなれない。[^u109] ドイツから見れば、積極参戦して賠償を要求し、戦後に英国から中国権益を取得した日本もまた、ヴェルサイユ体制と既存権益秩序を維持する側である。[^u109]

1930年代については、米国にとってフランス優位・ヴェルサイユ体制の永久維持は必ずしも利益でなく、ドイツを一定程度再建して欧州均衡を回復させる利益がある。賠償減免・債務再編は、米国にとって対独金融と両立する要求であった。[^n2][^u111]

# 史実との比較

- 1921年、賠償委員会はドイツの賠償義務額を1,320億金マルクとした（1919年のヴェルサイユ条約締結時には未確定）。休戦時の連合国間債務は約161億米ドル。[^u099]
- ドイツは賠償を円滑に履行できず、1923年ルール占領、1924年ドーズ案による再編へ進んだ。賠償額を大きく設定しても戦勝国の債務問題は解決しなかった。[^u099] ドーズ案では外国銀行団が約2億ドルの安定化借款を供与し、1924〜30年にドイツは米民間資本の主要投資先となった。[^u109]
- 米国では敵国財産管理制度により化学・医薬・染料分野だけで約4,500件のドイツ特許が1919年に化学財団（Chemical Foundation）へ移管された。ヴェルサイユ条約第306条は戦時中の独知的財産への特別措置の効力を認め、第236条は船舶・復旧用物資・石炭・染料化学製品などの現物賠償を定めた。[^u099]
- 1932年のローザンヌ会議でドイツの賠償負担は大幅に見直され、ヒトラー政権成立前に経済面のヴェルサイユ体制は修正済みであった。[^u111]
