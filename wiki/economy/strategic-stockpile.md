# 概要

本世界線の日本は、1920年代の国際収支黒字の一部を、対外債権の積み増しや金準備ではなく、**輸入資源の現物蓄積（戦略備蓄）**に向けている（確定）。第一次世界大戦で物資供給国として大きな利益を得た日本は、同時に海上交通の途絶と資源価格の高騰がもたらす危険も知った。対外債権をさらに積み増すよりも、輸入資源を現物として蓄えるほうが、経済政策と安全保障政策の双方に適合すると考えられた。[^e043][^e044]

備蓄は政府・海軍・商社・海運会社・製鉄会社・石油会社・金融機関が分担する**官民共同備蓄制度**として運営され、平時には商業在庫として使いながら、非常時には国家的な供給余力となる。対象の中心は原油・重油とニッケルで、鉄鉱石・銅・合金原料・錫・天然ゴムがこれに次ぐ。[^e043]

1925年の管理通貨制移行で金が通貨発行の法的な裏付けでなくなったことが、この政策を後押しした。1929年以降の世界恐慌では資源価格の下落を利用して大規模に買い増し、備蓄施設の建設が国内の工業需要を支えた。英帝国の一次産品地域からの資源購入は英国の円建て債務の返済を助け、1931年の[欧州通貨危機](../events/currency-crisis-1931.md)後の日英協力や1932年の[オタワ帝国経済会議](../diplomacy/ottawa-conference-1932.md)での資源長期供給契約へとつながった。その結果、1931年の日本は「**巨大な対外純債権国ではあっても、必ずしも巨大な金準備保有国ではない**」資産構成を持つ。[^e043][^e046]

# 背景：国際収支黒字の処理

1931年の英国危機を前に、1925年以降の日本が国際収支の黒字をどう処理してきたか（対外融資で還流させたのか、金・外貨準備として蓄えたのか、輸入拡大で調整したのか）が問題になった。これによって、日本が英国に供与できる金・ドル資産の規模が大きく変わるためである。[^e042] その答えが戦略備蓄である。1920年代の日本には、経常収支の黒字に対して次の選択肢があった。

| 黒字の処理方法 | 利点 | 欠点 |
|---|---|---|
| 対外融資 | 利子収入・経済的影響力 | 債務不履行リスク |
| 外国企業への出資 | 長期的な収益 | 流動性が低い |
| 金の購入 | 国際決済能力の確保 | 利子を生まない |
| 外貨準備の蓄積 | 為替介入・国際決済 | 外国通貨の信用に依存 |
| **資源の輸入・備蓄** | **産業・軍事上の安全保障** | **保管費用・価格変動リスク** |

[^e043]

厳密には、資源の輸入は経常収支の黒字を縮小させる政策であり、既に生じた黒字を金融資産として運用することとは異なる。日本政府は国内の資源需要を超えて輸入を促進することで、対外債権の増加を抑制する。[^e043]

債権国として輸入を拡大することには、ほかにも利点がある。英国の円建て債務の返済を容易にし、国内工業の原料調達費用を抑え、対外債権の過度な累積を防ぎ、日本製品に対する報復関税を避けられる。1920年代に通商政策の重点を幼稚産業保護から輸出市場確保と原料輸入自由化へ移した日本にとって、戦略備蓄の拡充は輸入拡大政策の一部でもある。[^e045]

## 1925年の管理通貨制移行との関係

金本位制の下では、輸入増加に伴う金流出は通貨制度の維持を脅かす。しかし1925年に金平価と金兌換を廃止した日本では、金は通貨発行の法的な裏付けではない（[金本位制離脱と管理通貨制](gold-standard.md)）。そのため政策判断の基準は、

> 金準備を増やすことと、将来必要になる資源を確保することのどちらが国家の経済的安定に寄与するか。

というものに変わる。金と資源備蓄では流動性がまったく異なるので、金・外貨準備が不要になるわけではない。必要な対外決済準備を確保した後の余剰資金を、資源輸入と海外資源開発に向けるのである（確定）。[^e043]

# 制度

## 備蓄対象と優先度

| 資源 | 備蓄の優先度 | 理由 |
|---|---|---|
| 原油・重油 | 非常に高い | 海軍・商船・産業用燃料 |
| 鉄鉱石 | 高い | 製鉄業の安定操業 |
| 銅 | 高い | 電化・通信・機械工業 |
| ニッケル | 非常に高い | 特殊鋼・機械工業 |
| クロム・マンガン | 高い | 合金鋼の生産 |
| 錫 | 高い | 工業用途・保存容器 |
| 天然ゴム | 高い | 自動車・電線・工業製品 |
| ボーキサイト | 中〜高 | アルミニウム産業の発展 |
| 綿花 | 中程度 | 繊維産業の原料 |
| 穀物 | 中程度 | 食料安全保障・価格安定 |

[^e043]

金属資源は長期保存に適しているため、金融資産に代わる実物資産としても扱いやすい。石油は貯蔵施設への大規模な投資を要するが、日本の海軍戦略が通商保護を中心としているため（[海軍戦略](../military/navy-strategy.md)）、海軍だけでなく商船隊の燃料確保にも国家的な関心が向けられる。[^e043]

## 官民共同備蓄制度

すべてを政府が直接買い上げるのではなく、官民が分担する。

| 備蓄主体 | 主な対象 |
|---|---|
| 政府 | 国家緊急時に必要となる資源 |
| 海軍 | 艦船用燃料・軍需資材 |
| 商社 | 輸入原材料・金属資源 |
| 海運会社 | 船舶用燃料 |
| 製鉄会社 | 鉄鉱石・合金原料 |
| 石油会社 | 原油・石油製品 |
| 金融機関 | 在庫を担保とする融資 |

[^e043]

政府は備蓄への低利融資、倉庫・貯油施設への投資支援、税制上の優遇を行う。この方式なら平時には通常の商業在庫として利用しながら、非常時には国家的な供給余力として動員できる。[^e043]

## 財政上の位置づけ

1925年の金本位制廃止に際して制度化された財政原則では、経常予算は経常収入で賄い、資産形成を伴う事業に限って議会の承認を得て公債を発行できる。戦略資源備蓄は「売却可能な政府資産の取得」として**公債発行の対象（可）**とされる（確定）。[^e048]

| 支出項目 | 公債発行 | 理由 |
|---|---|---|
| 鉄道・道路建設、港湾整備、発電所・送電網 | 可 | 社会資本・生産能力の形成 |
| **戦略資源備蓄** | **可** | **売却可能な政府資産の取得** |
| 軍艦・軍事施設建造 | 条件付きで可 | 耐久資産だが経済的収益性に乏しい |
| 官吏・軍人の給与、社会保障・生活扶助 | 不可／原則不可 | 経常的な消費・移転支出 |

[^e048]

1億円の国債で官吏の給与を払うことと、1億円の国債で鉄道や石油備蓄施設を取得することは、当時の財政担当者にとってまったく意味が異なる。後者には国有資産が残るからである。[^e047] 1930〜31年の財政論争では、取得資産の価値と国債消化能力を制約とみる開発財政派が「公共投資・備蓄拡大」を恐慌対策として掲げ、1925年の改革以来一定の影響力を持つ（検討案）。財政原則の詳細は[1925年財政原則と恐慌期の公共投資](fiscal-principles-1925.md)を参照。[^e047]

# 経過

## 1917〜1931年の推移

| 時期 | 備蓄政策の推移 |
|---|---|
| 1917〜20年 | 戦時の供給不安を受けて備蓄の必要性を認識 |
| 1921〜24年 | 官民による備蓄制度・保管施設の整備 |
| 1925年 | 管理通貨制移行に伴い資源輸入を促進 |
| 1926〜28年 | 対外債権の蓄積と並行して備蓄を拡大 |
| 1929〜31年 | 資源価格下落を利用した大規模な買い増し |
| 1931年以降 | 日英金融協力と資源貿易政策を接続 |

（確定）[^e043][^e044]

## 世界恐慌期の買い増し

1929年以降の資源価格下落は、日本にとって備蓄を拡大する機会となった。資源購入には国内需要を下支えする効果もあり、備蓄施設の建設、海上輸送、港湾荷役に需要が生まれる。ただし輸入資源の価格が下がれば既存在庫に評価損が出るため、民間企業だけで恐慌期に備蓄を拡大するのは難しく、政府の信用供与が必要になる。[^e043]

資源そのものは輸入品だが、備蓄には大量の国内工業製品が要る。管理通貨制の下で史実より早く金融緩和に動ける日本は、備蓄とインフラ整備を組み合わせて国内の工業需要をつくり出す（検討案）。[^e046]

| 政策 | 生じる工業需要 |
|---|---|
| 石油備蓄 | 貯油槽・ポンプ・配管 |
| 金属資源備蓄 | 倉庫・荷役設備 |
| 港湾整備 | クレーン・浚渫船・建設機械 |
| 海運力の維持 | 商船・タンカー・船舶修理 |
| 電力網の整備 | 発電機・変圧器・送電設備 |
| 鉄道整備・電化 | 車両・鉄鋼・電気機器 |
| 住宅・都市整備 | セメント・鉄鋼・建材 |

[^e046]

恐慌対策は失業者への直接給付よりも公共事業に向かい、その対象には幹線鉄道の複線化・電化、電力網、港湾、道路、治水と並んで「資源備蓄施設の建設と備蓄の積み増し」が含まれる（確定）。「民間資金が余り、設備も遊休化し、建設資材も安い今こそ必要な国家資産を取得すべきだ」という論理で、総需要の理論を持ち出さずに積極財政が正当化される。[^e048] なお公共投資のGDP比（1929年3.5%から1932〜33年に7.0%へ、検討案）は国内の固定資本形成だけを数えたもので、資源そのものの備蓄購入費や対外融資は含まない。[^e049]

## 恐慌下の世界経済への作用

1929〜32年の世界貿易量は食料品で約11%、原材料で約18.5%減ったのに対し、工業製品は40%以上減った（史実）。原材料価格の下落が一次産品輸出国の購買力を奪い、それが工業国の輸出をさらに減らす悪循環が起きていた。日本の資源備蓄政策はこの悪循環を部分的に和らげる。[^e046]

1. 日本が資源輸入・戦略備蓄・信用供与を行う。
2. 英帝国の一次産品輸出地域が輸出収入と購買力を維持する。
3. 英国・日本の工業製品（機械・設備・輸送機器・消費財）への需要が生まれる。
4. 工業生産と雇用が維持され、さらに原材料需要が生じる。

この循環を支えているのが日本の資源購入である以上、帝国特恵で日本製品を排除する政策には矛盾が生じる。日本が買付先を米国・中南米・ソ連・蘭領東インドへ移せば、帝国各地域の購買力が再び落ちかねない（検討案）。[^e046]

# 英国経済圏との関係

## 輸入対象

| 地域 | 主な輸入資源 |
|---|---|
| 英領マラヤ | 錫・天然ゴム |
| 英領ボルネオ | 石油 |
| 英領インド | 綿花・マンガン |
| オーストラリア | 鉱産物・農産物 |
| カナダ | 非鉄金属 |
| 英国本国 | 機械設備 |

[^e043]

英国及び帝国経済圏から輸入すれば、日本の輸出超過が縮小し、英国側は円を獲得できる。**英国の円建て債務を新たな日本からの借款だけで処理するのではなく、貿易によって返済できる構造をつくる**ことになる（確定）。[^e043]（対英債権については[円建て対外債権と円の国際化](yen-claims.md)を参照）

## 1931年の資産構成と通貨危機

備蓄政策の結果、1931年の日本の資産構成は次のようになる（確定）。

| 資産 | 保有状況 |
|---|---|
| 円建て対外債権 | 大規模 |
| 海外企業・インフラへの出資 | 大規模 |
| 金・ドル準備 | 必要な決済能力を確保する程度 |
| ポンド建て資産 | 相当規模 |
| 国内資源備蓄 | 大規模 |
| 海外資源開発権益 | 拡大中 |

[^e043]

このため日本が英国の金本位制を金やドルで救済する能力は、対外純資産の規模ほど大きくない。日本の対英支援は円建て信用の供与、英国圏からの資源購入、既存債務の借換えのほか、**英国経済圏からの資源買付保証**という形をとりうる。1931年の日英金融協議は、中央銀行間の通貨協力にとどまらず、債務決済・為替安定・資源貿易を一体化した経済協定へ発展する（検討案）。経過は[1931年欧州通貨危機と日英金融協力](../events/currency-crisis-1931.md)を参照。[^e043]

## オタワ会議での交渉材料

日本の戦略備蓄のための大量購入は、一次産品価格の下落に苦しむ自治領にとって重要な市場となり、オーストラリアや英領マラヤの輸出需要を支える。日本は関税引下げを求めるだけでなく、オーストラリアに羊毛・鉱産物、カナダに木材・非鉄金属、マラヤにゴム・錫の長期購入を保証できる。このため対日経済協力は、自治領の一次産品輸出部門からも求められる政策になる（検討案）。[^e044]

1932年のオタワ会議で特別オブザーバーとなった日本は、関税上の特別待遇ではなく資源調達の安定を求め、日本向け資源輸出に差別的な輸出制限を設けないこと、資源の長期供給契約の奨励、供給不足時の既存長期契約の尊重などが確認された（確定）。英国や自治領には、日本の戦略備蓄政策が一次産品の安定した需要を保証するという受け入れ理由がある。ただし排他的な購入権や独占的な供給権は設定せず、日本も調達先の多様化を保つ。詳細は[オタワ帝国経済会議（1932）と日本](../diplomacy/ottawa-conference-1932.md)を参照。[^e051]

# 1930年代後半の位置づけ

1935年までに、日英関係の資源供給面は「商業契約」から「**長期供給契約・戦略備蓄**」へと制度化された（確定）。[^e060] 建艦能力の比較でも、日本の資源調達は「海外依存・戦略備蓄」と整理され、国内資源が豊富な米国、海外依存の英国と対比される（検討案）。[^e066]

1937年に向けて一次産業の国内競争力が大きく下がり、資源・農産物の貿易が大幅な赤字になると、戦略備蓄は安全保障政策の一要素として位置づけ直される（検討案）。[^e071]

| 安全保障政策 | 日本にとっての意味 |
|---|---|
| 国内一次産業の全面保護 | 工業競争力と実質所得を低下させる |
| 資源供給地域の領土化 | 外交・軍事・統治コストが大きい |
| 海外資源への投資 | 安定供給と投資収益を確保 |
| **戦略備蓄** | **短期的な供給途絶への対応** |
| 輸入先の分散 | 特定地域への依存を軽減 |
| 日英海上通商防衛同盟 | 経済構造そのものの維持 |

[^e071]

食料についても、日本は完全な自給を目指さず、国内生産能力・輸入先の分散・穀物備蓄・海上通商防衛を組み合わせて安全保障を確保する（検討案）。[^e071] 備蓄はあくまで短期的な途絶への備えであり、長期の安定供給は海外資源投資と[日英海上通商防衛協定](../diplomacy/anglo-japanese-maritime-defense-agreement.md)による海上交通の維持が担う。

## 1937年の推計上の扱い

1937年の経済推計では、備蓄は次のように扱われている。

- **国民経済計算**：1937年の総資本形成50.76億ドル相当（1937年米国価格基準、GDP比19.5%）は、民間固定資本形成34.75億、公共固定資本形成13.01億、**在庫増加・戦略備蓄等3.00億ドル相当**から成る（検討案）。[^e098]
- **推計誤差**：支出面GDP（240.11億ドル相当）が生産面を下回る差額20.15億ドルの原因候補の一つに、戦略資源備蓄や企業在庫の過小評価が挙げられている。[^e098]
- **エネルギー収支**：1937年の石油需給（製品総供給1,250万t、原油処理1,150万t等）は平時の年間需要として組まれ、備蓄の積み増しは別途加算とされる。原油処理量を国内需要より大きく置く理由の一つにも備蓄がある。詳細は[エネルギー需給と電化](energy-1937.md)を参照。[^e080][^e081][^e089]

**備蓄の具体的な量（石油・石炭・鉄鉱石・食料等）は1937年時点でも決まっておらず、今後の検討事項として残されている。**[^e103]

# 未決の論点

- 1937年時点の備蓄量（石油・石炭・鉄鉱石・食料等）。[^e103]
- 在庫増加・戦略備蓄等3.00億ドル相当のうち、戦略備蓄に当たる額と企業在庫の区別。[^e098]
- 1920年代の備蓄輸入額。会話ログ2の国際収支推計では1920年代の商品貿易は赤字で推移しており、備蓄のための輸入がその中でどれだけを占めるかは算定されていない。[^e100]
- 政府備蓄の所管機関、備蓄に関する法制、海軍備蓄と民間備蓄の分担比率、恐慌期の在庫評価損の処理方法。[^e043]
- 備蓄の放出基準（非常時の定義と、平時の価格安定目的での放出を認めるか）。
