# 概要

本世界線の日本の農業は、1900〜1929年に**領主制を利用した広域的な農地区画整理**（ダイス判定：1d100 > 45、出目100・クリティカル）と国産農業機械の普及（1d100 > 40、出目89・成功）に成功し、史実では戦後の1963年に制度化される「労働生産性向上のための圃場整備」を数十年早く事実上実現した。[^e073][^e074] しかし1930年代の農業基盤整備事業は、世界恐慌後に流入した安価な外国産農作物に押されて投資が集まらず失敗し（1d100 > 30、出目19・失敗）、農業は技術的には近代化されながら産業としては縮小していく。[^e074]

1937年の帝国の耕地は570万ha（1929年650万ha）、農業就業者は682万人（1929年900〜1,000万人）で、穀物など土地集約的な産品は輸入に依存し、国内農業は野菜・果樹・園芸・生乳・養鶏など付加価値の高い分野へ移った。[^e074][^e075] 一方で漁業は、冷蔵網・遠洋漁業の企業化・海外漁場へのアクセス（出目100・クリティカル）のすべてに成功し、生産785万t・水産物輸出180万tという「一次産品の純輸入国でありながら世界最大級の水産物供給国」となった。[^e077] 林業は採算のよい地域で機械化され、木材自給率は67.5%である。[^e077]

この構造は、「国内の工業化と海運業の発展が国内一次産業の価格競争力を失わせる」という本世界線の国際分業の帰結であり、[資源戦略](/economy/resource-strategy.md)・[日英海上通商防衛協定](/diplomacy/anglo-japanese-maritime-defense-agreement.md)と表裏一体の関係にある。[^e071]

# 背景：一次産業の競争力喪失

## 国際分業の論理

本世界線の日本は早期に工業化し、英国経済圏（英植民地・自治領）を資源輸入元・投資先としてほぼ自国の植民地と同様に利用できる。その一方で対英経常黒字が恒常化するのは好ましくなく、日本政府・金融界には国内一次産業を保護するより英国経済圏からの輸入を拡大する動機が働く。[^e071]

一次産業の衰退は、生産性が低下したためではない。生産性が向上しても、外国産品との競争と、国内の非農業部門の賃金上昇に勝てないためである。海運・港湾の生産性向上で輸送費が下がったことも外国産品の競争力を高めた。[^e071]

| 品目 | 主な輸入先 | 国内生産の方向 |
|---|---|---|
| 小麦 | カナダ・豪州（米国） | 大幅縮小 |
| 大麦・雑穀 | 豪州・北米 | 縮小 |
| 米 | 英領ビルマ・タイ・朝鮮 | 主力として残るが輸入増 |
| 大豆 | 満洲・中国北部 | 縮小 |
| 砂糖 | 台湾・東南アジア | 国内（本土）産は縮小 |
| 牛肉・乳製品 | 豪州・NZ | 縮小・停滞 |
| 羊毛 | 豪州・NZ | ほぼ輸入 |
| 綿花 | インド・米国 | ほぼ輸入依存 |
| 木材 | カナダ・ソ連 | 国内林業は一部縮小 |
| 生鮮野菜・果実 | 国内 | 都市近郊農業として発展 |
| 水産物 | 国内 | 遠洋漁業・加工業が発展 |

[^e071][^e072]

## 領主制と農業保護

領主家は大土地所有者であるが、商工業・金融・海運・海外投資に多角化しているため、一枚岩の農業保護勢力にはならない。農地の地代には下落圧力がかかるが、製造業にとっては原材料費・生活費の低下、鉄道・港湾・海運にとっては輸送需要の増加、海外農園・鉱山への投資にとっては収益増となるからである。ただし小規模農家や農業依存度の高い領国では、人口流出と税収減が深刻な政治問題になりうる。[^e071]

# 土地改良の歴史

## 本世界線の動機

史実の1899年耕地整理法は当初、区画整理・乾田化による馬耕普及を目的とし、1909年の改正以降は灌漑・排水事業が中心となった。背景には食料増産の要請、農機の未発達、水資源の制約、零細分散所有があった。[^e073]

本世界線では農村労働力が工業へ流出し、食料輸入も比較的容易であるため、農業政策の目的は「単収向上」よりも「生産費削減・農業経営の維持」にあり、土地改良は**労働投入量の削減**を目的とした。農機は国内の機械工業から調達でき、採算の悪い農地は放棄・転用・集約された（検討案として提示され、以後の判定の前提となった）。[^e073]

領主制は土地改良に有利に働いた。領主家が大規模な土地所有者であり、鉄道・電力・金融事業にも関与しているため、一体的な地域開発を進めやすい。領主は土地改良で農地収益を維持すると同時に、余剰となった農村労働力を領国内の工場や建設事業で雇用できる。ただし小作権・水利権については別途の制度調整を要した。[^e073]

## 三段階の展開

| 時期 | 土地改良の主目的 |
|---|---|
| 1870〜1900年 | 治水・灌漑・開墾・農業増産 |
| 1900〜1929年 | 農地区画整理・乾田化・農道整備・動力導入 |
| 1930〜1937年 | 農業経営の合理化・労働節約・不採算農地の整理 |

[^e073]

改良の内容は、畦畔撤去・長方形化による区画統合、緩傾斜の棚田・段々畑の段差統合（急傾斜地の全面平地化は費用過大で、林業・果樹への転換か耕作放棄）、農機と貨物車両が進入できる農道・用排水路の再整備、揚水・耕起・脱穀・精米の動力化である。[^e073]

## ダイス判定と1929年までの到達点

| 判定事項 | 閾値 | 出目 | 結果 |
|---|---|---|---|
| 1900〜1929年の農地区画整理が進展する | 1d100 > 45 | 100 | 成功（クリティカル） |
| 農地集約・換地に関する制度改革が成功する | 1d100 > 50 | 68 | 成功 |
| 1930年代の農業基盤整備事業が成功する | 1d100 > 30 | 19 | 失敗 |
| 国産農業機械の普及が進む | 1d100 > 40 | 89 | 成功 |

[^e074]

区画整理のクリティカルは、単なる耕地整理の進展ではなく、領主制を利用した**全国的・広域的な農地再編**の成功と解釈される。1929年までに、平野部の大部分で区画整理が完了し、主要農業地域では農機・車両が通行できる農道が整い、緩傾斜の棚田・段々畑の大区画化、用排水路の再整備、分散耕作地の統合、揚水・脱穀・精米の動力化、小型耕耘機・トラクターの普及が進んだ。農業金融は領主系銀行と農業組合が担った。[^e074]

## 1930年代の失速

1930年代の基盤整備事業の失敗は、技術や能力の不足ではなく、**外国産農作物に押されて思うように投資が集まらなかった**ことによる。[^e074] 世界恐慌と国際農産物価格の下落で豪州・カナダ・ビルマなどの安価な農産物が流入し、農地収益が低下して追加投資が停滞した。工業・商業が相対的に有利になり、資本と労働力は非農業部門へ移った。領主家自身も豪州の農業事業やビルマの稲作・精米・輸送事業など海外農業・資源開発へ投資し、公債による農業基盤整備は議会の承認を得にくくなった。1930年代の公共投資のうち治水・灌漑への配分も、都市防災・工業用水へ重点が移った。[^e074]

# 労働投入と付加価値の再積算

## 稲作の労働投入

1937年の経済規模の検証では、農業を労働生産性から逆算せず、物的生産量→必要労働力→生産額→付加価値の順で推計し直した。[^e087][^e090]

史実の日本の稲作（1931〜43年平均）は254人日/ha、収量2.69t/haである。本世界線では農地の状態別に次の労働投入を置く。[^e090]

| 農地の状態 | 比率 | 労働投入 |
|---|---:|---:|
| 機械利用向け整備済み | 47% | 155人日/ha |
| 部分整備 | 38% | 205人日/ha |
| 未整備 | 15% | 260人日/ha |
| 加重平均 | | 190人日/ha |

加重平均190人日/haは史実より約25%少なく、玄米収量3.2t/haを維持すると一人日当たり16.8kg（史実10.6kg）、物的労働生産性は史実の159%になる。[^e090]

国内農産物価格は安価な外国産農産物との競争で抑えられている。[^e087]

## 構造転換としての意味

「**農業近代化の成功と農業の低生産性は両立する**」。近代化によって必要な労働力が減り、比較優位を持つ製造・建設・電力・サービス業や、海外の鉱山・油田・農園・金融資産への投資へ労働と資本が移動した。これが産業間の賃金格差を伴う「1930年代の構造転換」である。[^e090] 農村・産炭地域からの労働移動は円滑に進んだ（1d100 > 35、出目55・成功）。[^e096]（→[1937年の就業構造と社会](/economy/labor-society-1937.md)）

# 畜産業

## 企業的畜産

土地を大量に必要とする畜産から、**飼料を輸入して国内で付加価値を生み出す畜産**へ移行した。[^e076] 輸入飼料を利用した企業的畜産の発達はぎりぎりで成功し（1d100 > 40、出目42・成功）、都市近郊に専業的な養豚・養鶏が成立して飼料調達・食肉加工と一体化した（史実では小規模な副業的経営が中心）。[^e076][^e077]

|---|---|---:|
| 肉牛 | 豪州の放牧と競争し縮小・停滞 | 牛計140万頭（うち乳牛45万頭） |
| 酪農 | 生乳の輸送・保存制約により拡大 | |
| 養豚 | 輸入飼料・食品加工副産物で拡大 | 250万頭 |
| 養鶏 | 大幅拡大 | 6,000万羽 |
| 養羊 | 豪州産羊毛・羊肉に押され縮小 | 10万頭 |
| 農耕用牛馬 | 農機普及で史実より早く減少 | 馬85万頭 |

[^e076]

# 漁業

## 発展の条件

本世界線の漁業は、造船・船舶機関の高度な発達、港湾と鉄道網、冷蔵・製氷の普及、英国経済圏の港湾・補給施設の利用（英国領海の漁業権を意味しない）、都市化、缶詰などの輸出市場を背景とする。沿岸では動力船が普及して経営が集約され、沖合では大型動力船による機械化、遠洋では領主系企業や商社が資本を投じる大規模企業経営、北太平洋中心の母船式漁業、海外市場向けの捕鯨、貝類・海藻の養殖、冷蔵・缶詰・魚油・魚粉の水産加工が発達した。[^e076]

## ダイス判定

| 判定事項 | 閾値 | 出目 | 結果 |
|---|---|---|---|
| 冷蔵・製氷・冷蔵輸送網が広く普及する | 1d100 > 25 | 52 | 成功（主要都市・港湾中心） |
| 遠洋漁業の企業化・大型化が成功する | 1d100 > 25 | 77 | 成功 |
| 海外漁場への安定したアクセスを確保する | 1d100 > 40 | 100 | 成功（クリティカル） |

[^e077]

海外漁場アクセスのクリティカルは、国際漁業協定の締結と海外漁業拠点の確保の成功と解釈される。海外漁業権は無制限ではなく、個別許可・共同出資・現地法人の形をとり、英国との協力が加工・保管・輸送まで支える。[^e077]

| 海域 | 海外漁業権の形態 |
|---|---|
| ソ連極東 | 有償の漁業権・水産加工事業 |
| 朝鮮沿岸 | 二国間漁業協定・共同事業 |
| 中国沿岸 | [中国諸省聯合](/diplomacy/china-federation.md)及び地方政府との漁業協定 |
| 英領東南アジア | 現地企業との共同漁業・港湾利用 |
| 豪州・NZ | 漁業事業への資本参加・許可漁業 |
| インド洋 | 遠洋漁業・補給拠点 |
| 南極海 | 捕鯨事業 |

[^e077]

| 区分 | 判定前案 | 1937年 | 就業者 | 一人当たり |
|---|---:|---:|---:|---:|
| 沿岸 | 210万t | 210万t | 42万人 | 5.0t |
| 沖合 | 230万t | 260万t | 14万人 | 18.6t |
| 遠洋 | 150万t | 280万t | 10万人 | 28.0t |
| 養殖・内水面 | 30万t | 35万t | 6万人 | 5.8t |

[^e076][^e077][^e090]

785万tは日本居住者・国内事業体の生産であり、海外現地法人の漁獲は別集計でGDPに含めない。輸入15万t、輸出（原魚換算）180万t、国内供給620万t、一人当たり約79kgで、缶詰・冷凍魚・魚油・魚粉は外貨を稼ぐ輸出産業である。[^e077] 遠洋漁業の企業化成功と沿岸の小規模経営の残存が、就業者一人当たり漁獲の大きな差として現れている。漁業就業者72万人のFTEは約58万人である。[^e090]

史実の1937年日本本土の漁業生産は約389万t（別集計で約491万t）、米国・アラスカの漁獲は約188〜220万tであり、本世界線の日本の漁業生産は米国の約4倍に達する。[^e076][^e087]

# 林業

建築用材は輸入材との競争が激化し、パルプ材は海外依存が拡大し、高級木材は国内で維持され、薪炭は電化・石炭・ガスに置き換えられて縮小した。山林経営は資産保有・治水・保全へ重点を移し、領主系資本はカナダなどへの海外林業投資を進めた。[^e076]

国内林業の機械化・林道整備は成功したが（1d100 > 55、出目57・成功）、ぎりぎりの成功であるため採算性の高い地域が中心で、全面的な機械化ではない。林道・森林鉄道、索道・動力集材、製材所との一体経営が進み、不採算森林は保全・治水へ転換された。[^e077][^e090]

| 用途 | 国内生産 | 国内需要 | 純輸入 |
|---|---:|---:|---:|
| 建築・一般用材 | 1,500万m³ | 2,100万m³ | 600万m³ |
| パルプ材 | 450万m³ | 1,000万m³ | 550万m³ |
| その他産業用材 | 350万m³ | 500万m³ | 150万m³ |
| 薪炭 | 400万m³ | 400万m³ | 0 |
| 合計 | 2,700万m³ | 4,000万m³ | 1,300万m³ |

[^e077]

木材自給率は67.5%、林業就業者は36万人（一人75m³、FTE約30万人）。素材生産段階の生産額は約1.79億ドル、純付加価値は約1.11億ドル相当である。[^e077][^e090]

# 史実との比較

* 史実の耕地整理法（1899年）は区画整理・乾田化から灌漑・排水事業へ重点を移し、労働生産性向上を目的とする圃場整備の制度化は1963年である。本世界線では1900〜1929年に事実上の圃場整備が進んだ。[^e073]
* 史実の稲作労働は254人日/ha（1931〜43年平均）、本世界線は190人日/ha。[^e090]
* 史実の日本本土の1935年前後の米は、国内生産約941万tに朝鮮から約121万t、台湾から約71万tを移入していた。本世界線では朝鮮は独立国で、米はビルマ・タイ・朝鮮などから輸入する。[^e072]
* 史実1937年の日本本土の漁業生産は約389万t、本世界線は785万t。[^e076][^e077]
* 史実の農業は単収向上が主目的で、小規模副業的な畜産が中心だったが、本世界線では省力化と企業的畜産が進んだ。[^e073][^e076]

# 却下・修正された案

* **農業の対米労働生産性**: 史実比較前の「40〜50%」（前段の設定）→ 土地改良判定前に「中進捗28〜35%」へ下方修正 → 判定後に「30〜40%・中核35%」→ 物的生産量からの再積算で**過大と判断**（就業者一人当たり耕地の差を共通価格評価では補えない）。農業純付加価値は21.16億ドルから8.90億ドルへ修正された（E86→E90）。[^e073][^e074][^e090]
* **漁業の付加価値**: 対米生産性90%から積算した4.32億ドル → 水揚げ総額すら上回っていたため、生産量×評価価格から2.02億ドルへ修正。漁業生産785万tと海外漁場アクセスのクリティカルは維持された。[^e087][^e090]
* **林業の付加価値**: 当初0.47億ドル → 米国統計の林業分類が狭かったため過小として1.11億ドルへ上方修正。[^e090]
* **E72時点の農産物需給案**: 米850万t（自給率81%）、小麦100万t（29%）、砂糖115万t、水産物480万tなどの案 → 土地改良・漁業の判定を経てE75・E77の値（米880万t・84%、小麦64万t・18%、漁業785万t）に置き換えられた。[^e072][^e075][^e077]
* **林業の判定前案**: 国内生産2,500万m³・自給率約63% → 機械化成功により2,700万m³・67.5%。[^e076][^e077]
* **漁業の判定前案**: 620万t・対米75% → 遠洋の企業化と海外漁場クリティカルで785万t。[^e076][^e077]

# 未決の論点

* 食料自給率（供給カロリー）: E71で中核55〜65%とされたが、E72の需給案ではそれより高くなる可能性があり、食用油・飼料・加工損失を含めた再積算が必要。飼料需要390万tも既存の穀物需給に十分含まれていない可能性がある。[^e071][^e072][^e077]
* 休耕地・牧草地・作付間隔を考慮した土地利用と作付面積（563万ha）の調整。[^e075]
* 稲作以外の作物の労働原単位、農産物の評価価格、畜産の労働原単位は新規の仮定値であり、付加価値の減少幅は確定していない。[^e090]
* 国内林業の設備投資（森林鉄道・林道・索道）の程度の詳細。[^e076]
* 地域ごとの土地改良の差（北海道の大区画化・大型農機、東北・北陸の水田区画整理、関東の畑作機械化、濃尾・大阪の都市農業転換、中国・四国山間部の集約、九州の平野部機械化、台湾の灌漑・製糖原料生産の大規模化）は検討案の段階にある。[^e073]
