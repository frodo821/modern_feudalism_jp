# 概要

本世界線の日本の農業は、1900〜1929年に**領主制を利用した広域的な農地区画整理**と国産農業機械の普及に成功し、史実では戦後の1963年に制度化される「労働生産性向上のための圃場整備」を数十年早く事実上実現した。[^n1][^n2][^e073][^e074] 北海道の開墾も主に1920年代までに進み、1929年の耕地は約720万ha（北海道・台湾を含む）に達した。1930年代の農業基盤整備事業は、世界恐慌後に流入した安価な外国産農作物に押されて投資が集まらず失敗し[^n4]、本州の未改良耕地およそ40万haが耕作放棄された。[^n3][^e074]

農地の所有構造は固定的である。近世以来の非華族地主層は土地を維持したが、地主による農地集積は完全に失敗し、自作農による農地取得も進まなかった。一方で小作農の権利改善、農業協同組合・信用組合の普及、中小農家への機械化の波及には成功し、「**農地所有は固定的だが、農業経営は近代化する**」という姿になった。[^n5][^p085] これは1937年の確定事項「地主制の存続と農業経営の近代化」に当たる。[^p097]

1937年には、**耕地は680万ha**（本州等545・北海道95・台湾40万ha）で、1920年代までの北海道開拓で広がった耕地から1930年代の耕作放棄分を差し引いた水準にある。[^n3] 農家550万戸・農業就業者1,100万人が**玄米1,056.25万t**を生産して米穀自給率は約93%、小麦も250万tを国内で産する。水産物の国内の港への水揚げは420万tで、これとは別に海外漁業拠点・母船式による海外での漁獲が約300万tある。[^n6] 1人1日当たり食料供給熱量は約2,435kcalである。[^p088][^p096] 「中小農家の生産性向上と北海道の耕地拡大によって食料供給を増やした農業経済」（北海道の耕地拡大は1920年代までのこと）であり、朝鮮を政治的に支配して食料を確保するのではなく、貿易と国内農業開発で供給を維持している。[^p088] 他方、農業の就業者1人当たり付加価値は582円で製造業の約3分の1にとどまり、産業間の所得格差の主因となっている。[^p087][^p095]

# 背景：国際分業と一次産業

## 国際分業の論理

本世界線の日本は早期に工業化し、英国経済圏（英植民地・自治領）を資源輸入元・投資先としてほぼ自国の植民地と同様に利用できる。その一方で対英経常黒字が恒常化するのは好ましくなく、日本政府・金融界には国内一次産業を保護するより英国経済圏からの輸入を拡大する動機が働く。[^e071] 生産性が向上しても、外国産品との競争と国内の非農業部門の賃金上昇に勝てない分野は縮小し、海運・港湾の生産性向上で輸送費が下がったことも外国産品の競争力を高めた。[^e071]

この論理のもとで、1937年には小麦（総供給の約36%を輸入）、食用油脂の原料、綿花・羊毛、飼料などが輸入に依存する一方、米・芋類・水産物は高い国内供給力を保っている。[^p088][^p096]

| 品目 | 主な輸入先 | 1937年の国内供給 |
|---|---|---|
| 米 | 英領ビルマ・タイ・朝鮮 | 国内供給が高く一部輸入（自給率約93%、輸入先は朝鮮・中国・東南アジア） |
| 小麦 | カナダ・豪州（米国） | 国内250万t＋輸入140万t |
| 大豆 | 満洲・中国北部 | 国内生産と輸入を併用 |
| 砂糖 | 台湾・東南アジア | 台湾・北海道（甘蔗・甜菜）が重要 |
| 牛肉・乳製品 | 豪州・NZ | 国内供給力が拡大 |
| 羊毛・綿花 | 豪州・NZ／インド・米国 | 輸入依存 |
| 木材 | カナダ・ソ連 | 国内林業は一部縮小 |
| 水産物 | 国内 | 国内供給力が高い |

（出典：[^e071][^e072][^p088]）[^n7]

## 領主制と農業保護

領主家は大土地所有者であるが、商工業・金融・海運・海外投資に多角化しているため、一枚岩の農業保護勢力にはならない。ただし小規模農家や農業依存度の高い領国では、人口流出と税収減が深刻な政治問題になりうる。[^e071] 1937年には、249領国のうち農業中心領国74家（人口1,900万人）の1人当たりGDPは368円で全国平均の72%にとどまる（→[領国の類型・財政と財政調整交付金（1937）](fief-finance-1937.md)）。

# 土地改良の歴史

## 本世界線の動機

史実の1899年耕地整理法は当初、区画整理・乾田化による馬耕普及を目的とし、1909年の改正以降は灌漑・排水事業が中心となった。背景には食料増産の要請、農機の未発達、水資源の制約、零細分散所有があった。[^e073]

本世界線では農村労働力が工業へ流出し、食料輸入も比較的容易であるため、農業政策の目的は「単収向上」よりも「生産費削減・農業経営の維持」にあり、土地改良は**労働投入量の削減**を目的とした。農機は国内の機械工業から調達でき、採算の悪い農地は放棄・転用・集約された。[^n8][^e073]

領主制は土地改良に有利に働いた。領主家が大規模な土地所有者であり、鉄道・電力・金融事業にも関与しているため、一体的な地域開発を進めやすい。領主は土地改良で農地収益を維持すると同時に、余剰となった農村労働力を領国内の工場や建設事業で雇用できる。ただし小作権・水利権については別途の制度調整を要した。[^e073]

## 三段階の展開

| 時期 | 土地改良の主目的 |
|---|---|
| 1870〜1900年 | 治水・灌漑・開墾・農業増産 |
| 1900〜1929年 | 農地区画整理・乾田化・農道整備・動力導入 |
| 1930〜1937年 | 農業経営の合理化・労働節約・不採算農地の整理 |

[^e073]

改良の内容は、畦畔撤去・長方形化による区画統合、緩傾斜の棚田・段々畑の段差統合（急傾斜地の全面平地化は費用過大で、林業・果樹への転換か耕作放棄）、農機と貨物車両が進入できる農道・用排水路の再整備、揚水・耕起・脱穀・精米の動力化である。[^e073]

## 1929年までの到達点

| 事項 | 結果 |
|---|---|
| 1900〜1929年の農地区画整理 | 全国的・広域的に大きく進展[^n1] |
| 農地集約・換地に関する制度改革 | 成功[^n9] |
| 1930年代の農業基盤整備事業 | 失敗[^n4] |
| 国産農業機械の普及 | 進展[^n2] |

[^e074]

区画整理の際立った成功は、単なる耕地整理の進展ではなく、領主制を利用した**全国的・広域的な農地再編**の成功である。1929年までに、平野部の大部分で区画整理が完了し、主要農業地域では農機・車両が通行できる農道が整い、緩傾斜の棚田・段々畑の大区画化、用排水路の再整備、分散耕作地の統合、揚水・脱穀・精米の動力化、小型耕耘機・トラクターの普及が進んだ。農業金融は領主系銀行と農業組合が担った。[^e074]

## 1930年代の失速

1930年代の基盤整備事業の失敗は、技術や能力の不足ではなく、**外国産農作物に押されて思うように投資が集まらなかった**ことによる。[^e074] 世界恐慌と国際農産物価格の下落で豪州・カナダ・ビルマなどの安価な農産物が流入し、農地収益が低下して追加投資が停滞した。領主家自身も豪州の農業事業やビルマの稲作・精米・輸送事業など海外農業・資源開発へ投資し、公債による農業基盤整備は議会の承認を得にくくなった。1930年代の公共投資のうち治水・灌漑への配分も、都市防災・工業用水へ重点が移った。[^e074]

基盤整備の失敗は耕地の縮小をもたらした。1929年の耕地は約720万ha（本州・四国・九州等約585、北海道約95、台湾約40万ha）で、北海道の開墾は主に1920年代までに進んでいた。1930年代には区画整理から取り残された本州の未改良耕地（傾斜地・小区画・排水不良田など）に投資が回らず、輸入農産物との価格競争に耐えられないおよそ40万haが耕作放棄され、1937年の耕地は680万haとなった。[^n3][^e074][^p088][^p096]

| 地域 | 1929年 | 1937年 | 増減 |
|---|---:|---:|---:|
| 本州・四国・九州等 | 約585万ha | 545万ha | 約−40万ha |
| 北海道 | 約95万ha | 95万ha | ほぼ横ばい |
| 台湾・澎湖 | 約40万ha | 40万ha | ほぼ横ばい |
| **合計** | **約720万ha** | **680万ha** | **約−40万ha** |

（出典：[^p088]）[^n10]

# 農地所有と小作制度（1937年）

## 農地所有をめぐる帰結

| 事項 | 結果 |
|---|---|
| 近世以来の非華族地主層の土地所有 | 維持 |
| 地主層による農地の集積 | 完全に失敗 |
| 自作農による農地取得 | 進展せず |
| 小作農の契約上の権利・生活保障 | 改善 |
| 農業協同組合・信用組合 | 広く普及 |
| 農業の機械化・生産性向上の中小農家への波及 | 実現 |

[^n5][^p085]

同じ時期には、都市勤労者の持家取得が進まず、預貯金・郵便貯金が普及し、世代間資産格差が固定化しており[^n11]、農村と都市の双方で「職業上の上昇移動は可能だが、資産の世代間移動は限定的」な社会となった（→[1937年の就業構造と社会](labor-society-1937.md)、[国民資産と富の所有構造（1937）](national-wealth-1937.md)）。[^p085]

## 地主制の構造

地主集積の失敗は地主制度の崩壊ではなく、明治期以降に大規模な土地買収を試みた新興地主・投機的土地資本が失敗し、伝統的な中小地主層が残ったことを意味する。[^n12][^p085]

| 主体 | 1937年の状態 |
|---|---|
| 領主系大地主 | 既存の私有農地を維持 |
| 旧来の非華族地主 | 地域的な所有を維持 |
| 新興大地主 | 集積に失敗 |
| 自作農 | 維持するが拡大せず |
| 自小作農 | 相当数存続 |
| 小作農 | 土地取得は進まないが契約上の地位が改善 |
| 農協・信用組合 | 金融・販売・設備利用を支援 |

[^n12][^p085]

全国農地の評価額は320億円（国民純資産の17.8%）である。[^p096] その所有者別配分は、領主華族57.6億円（18%）、無領華族16億円（5%）、非華族地主128億円（40%）、自作農・自小作農102.4億円（32%）、政府・法人その他16億円（5%）で、評価額基準のため耕作面積比とは異なる。[^n13][^p085]

## 農家の経営形態

農家550万戸の経営形態は、自作農35%（192.5万戸）、自小作農35%（192.5万戸）、小作農30%（165万戸）で、約357.5万戸（65%）が何らかの小作地を利用する。[^n13] このため1930年代の農村政策の争点は、所有権の移転よりも小作料の調整・小作契約の安定化・農業金融の改善にある。[^p085][^p088]

小作制度の近代化の内容は、書面契約の普及、長期契約・更新保障、小作料の一方的引上げの制限、凶作時の減免・猶予、恣意的な契約解除（離作）の制限、小作農の改良投資の保護、調停・司法的救済、信用組合による低利融資で、小作権は一定の経済的価値を持つ。[^n14][^p085]

農協・信用組合は、肥料・種苗・農機具の共同購買、集荷・価格交渉の共同販売、脱穀機・精米機・揚水設備の共同利用、融資・貯蓄・信用保証の共同金融を担い、農機の共同利用によって中小農家にも機械化が及んだ。庄内酒井系の農業機械企業、伊達系の食品企業、山内系の商社が農協を通じて中小農家と取引する。生産性上昇の利益は地代・流通利益として地主・商業資本にも分配される。[^n12][^p085] 機械化の担い手は、領主の主導に加えて農協を経由する経路をもつ。[^n15]

## 労働投入

本世界線の稲作の労働投入は、整備済み155・部分整備205・未整備260人日/haの加重平均で**約190人日/ha**である。史実の日本の稲作（1931〜43年平均）が254人日/ha・収量2.69t/haであるのに対し、玄米収量3.2t/haを維持すると、物的労働生産性は史実の159%になる。[^n20][^e090] 農業就業者には農繁期への労働需要の集中と兼業（農閑期の建設・サービス従事）があり、人数とフルタイム換算（FTE）は一致しない。[^e090] 1937年の就業者1,100万人は人数ベースの値である。[^n20]

## 構造転換としての意味

「**農業近代化の成功と農業の低生産性は両立する**」。近代化によって必要な労働力が減り、比較優位を持つ製造・建設・電力・サービス業や海外への投資へ労働と資本が移動した。農村・産炭地域からの労働移動は円滑に進んだ。[^n21][^e090][^e096] それでも1937年になお就業者の39.1%が第一次産業にあり、「農村人口を多く抱えながら経済の中心が工業に移行した社会」である。[^p087][^p096] 移動が円滑でも農業就業者が1,100万人と多い理由は次の3つである。[^n19]

1. 女性の非農業部門への就業がまったく進まなかったため、農家の女性が家族従業者として農業就業者に数えられている。[^n22][^e096]
2. 小作権の改善と農協・信用組合の普及で農家経営が安定し、農村から人を押し出す力が弱かった。[^n5][^p085]
3. 移動の一部は都市ではなく北海道の開拓地に向かった。

いずれも失業を生まずに進み、1937年の失業率は約2.4%にとどまる。[^n19]（→[1937年の就業構造と社会](labor-society-1937.md)）

# 漁業

## 発展の条件

本世界線の漁業は、造船・船舶機関の高度な発達、港湾と鉄道網、冷蔵・製氷の普及、英国経済圏の港湾・補給施設の利用（英国領海の漁業権を意味しない）、都市化、缶詰などの輸出市場を背景とする。沿岸では動力船が普及して経営が集約され、沖合では大型動力船による機械化、遠洋では領主系企業や商社が資本を投じる大規模企業経営、北太平洋中心の母船式漁業、海外市場向けの捕鯨、貝類・海藻の養殖、冷蔵・缶詰・魚油・魚粉の水産加工が発達した。[^e076]

420万tは「国内の港への水揚げ」を指す。これとは別に、国際漁業協定・海外漁業拠点・母船式漁業による**海外での漁獲が約300万t**あり、現地法人や海外拠点で水揚げ・加工・販売される。この漁獲は日本の領主系企業・商社・独立系漁業資本による海外直接投資の収益として扱われ、国内総生産ではなく海外からの要素所得としてGNIの側に入る。したがってGDP 400億円や林業・水産業の付加価値16億円は変わらない。[^n6][^e077][^p088]（→[国際収支と対外資産](balance-of-payments.md)）

遠洋漁業の企業化・大型化の成功[^n23][^e077]により、遠洋漁業は国内の港への水揚げ100万tと海外拠点・母船式による海外での漁獲約300万tを合わせた**約400万tの事業規模**をもつ。[^n24] 担い手は山内家の遠洋漁業・水産加工、津軽家の北海道水産事業、独立系漁業資本である。420万tは国内の港への水揚げ時の重量で、加工時の廃棄、魚油・肥料・飼料への利用、輸出などを除いた国内の可食供給は200万t前後、1人当たり年約25kgとなる。[^p088] 水産加工品・食品の輸出は120万t・5.76億円である。[^p090][^p091]

史実の1937年日本本土の漁業生産は約389万t（別集計で約491万t）、米国・アラスカの漁獲は約188〜220万tである。[^e076][^e087]

# 林業

建築用材は輸入材との競争が激化し、パルプ材は海外依存が拡大し、高級木材は国内で維持され、薪炭は電化・石炭・ガスに置き換えられて縮小した。山林経営は資産保有・治水・保全へ重点を移し、領主系資本はカナダなどへの海外林業投資を進めた。[^e076]

国内林業の機械化・林道整備は成功したが、ぎりぎりの成功であるため採算性の高い地域が中心で、全面的な機械化ではない。[^n25] 林道・森林鉄道、索道・動力集材、製材所との一体経営が進み、不採算森林は保全・治水へ転換された。[^e077][^e090]

# 史実との比較

* 史実の耕地整理法（1899年）は区画整理・乾田化から灌漑・排水事業へ重点を移し、労働生産性向上を目的とする圃場整備の制度化は1963年である。本世界線では1900〜1929年に事実上の圃場整備が進んだ。[^e073]
* 史実の稲作労働は254人日/ha（1931〜43年平均）、本世界線は約190人日/ha。[^n20][^e090]
* 史実の日本本土の1935年前後の米は、国内生産約941万tに朝鮮から約121万t、台湾から約71万tを移入していた。本世界線では朝鮮は独立国で、台湾は国内に含まれ、1937年の玄米生産は1,056.25万t（台湾80万tを含む）、米穀輸入は精米換算85万tである。[^e072][^p088]
* 史実1937年の日本本土の漁業生産は約389万t、本世界線は国内水揚げ420万tに海外での漁獲約300万tが加わる。[^e076][^p088]
* 史実の農業は単収向上が主目的で、小規模副業的な畜産が中心だったが、本世界線では省力化と企業的畜産が進んだ。[^e073][^e076]

| 米・小麦その他穀物の輸入 | 約670万t | 米・小麦225万t |

（出典：[^e074][^e075][^e076][^e077][^e090][^e097][^e098][^p087][^p088][^p090][^p091][^p096]）

理由：会話ログ3は会話ログ2より後の決定で、P88で北海道開拓の成功を考慮した基準案として耕地680万haなどが設定され、P96の最終集計とP97の確定宣言で1937年の確定値となったため。会話ログ2の「技術的に近代化された農業が、国際分業によって産業として縮小していく」という1937年像は、会話ログ3の「北海道の耕地拡大と中小農家の生産性向上によって食料供給を増やした農業」に置き換えられた。[^e074][^p088][^p097] ただし基盤整備の失敗（出目19）を生かすため、1929年約720万ha→1937年680万haという1930年代の縮小は残す（作者確定）。会話ログ2の「1929年650万ha→1937年570万ha」は旧推計である。

* **「1930年代の基盤整備の失敗は既存農地の追加整備の停滞にとどまり、耕地の縮小には結びついていない」という説明**：会話ログ3の確定値（680万ha）を北海道開拓による拡大と読んだ旧整理。1929年を約720万haとし、本州の未改良耕地約40万haの耕作放棄で680万haに減ったと改めた（作者確定）。[^e074][^p088]
* **馬190万頭（P88）**：国産農業機械の普及（出目89・成功）の帰結「農耕用牛馬が史実より早く減少」と合わないため、約110万頭に改めた（会話ログ2は85万頭）。牛280万頭は維持し、大半を乳用・肉用とした（作者確定）。[^e074][^p088]
* **漁業420万tを日本の漁業生産の全量とする読み方**：海外漁場クリティカル（出目100）の帰結が数値に表れないため、420万tを国内の港への水揚げと定義し直し、別に海外での漁獲約300万t（GNI側の要素所得）を置いた（作者確定）。[^e077][^p088]
* **「農村から都市への労働移動の制約」を農業就業者の多さと所得格差の要因とする説明**（P87）：労働移動円滑の判定（出目55・成功）と食い違うため外し、女性の家族従業者、小作権改善・農協による押し出し圧力の弱さ、北海道開拓地への移動の3点で説明する形に改めた（作者確定）。[^e096][^p087]

## 会話ログ2内部で修正された案

* **農業の対米労働生産性**: 史実比較前の「40〜50%」→ 土地改良判定前に「中進捗28〜35%」→ 判定後に「30〜40%・中核35%」→ 物的生産量からの再積算で**過大と判断**。農業純付加価値は21.16億ドルから8.90億ドルへ修正された（E86→E90）。[^e073][^e074][^e090]
* **漁業の付加価値**: 対米生産性90%から積算した4.32億ドル → 水揚げ総額すら上回っていたため、生産量×評価価格から2.02億ドルへ修正。[^e087][^e090]
* **林業の付加価値**: 当初0.47億ドル → 米国統計の林業分類が狭かったため過小として1.11億ドルへ上方修正。[^e090]
* **E72時点の農産物需給案**: 米850万t（自給率81%）、小麦100万t（29%）、砂糖115万t、水産物480万tなどの案 → E75・E77の値に置き換えられ、さらに会話ログ3の確定値に置き換えられた。[^e072][^e075][^e077][^p088]
* **林業の判定前案**: 国内生産2,500万m³・自給率約63% → 機械化成功により2,700万m³・67.5%。[^e076][^e077]
* **漁業の判定前案**: 620万t・対米75% → 遠洋の企業化と海外漁場クリティカルで785万t → 会話ログ3で420万t → 作者確定で国内水揚げ420万t＋海外での漁獲約300万t。[^e076][^e077][^p088]
