# 概要

[日清戦争（1887〜1889）](../events/sino-japanese-war.md)の講和における最大の制約は、清国の支払い能力だった。清に講和条件を履行させるには、戦後の清の信用を補完し融資する列強との交渉が不可欠であり、**日本が清国からいくら取れるかは、清国自身の財政力ではなく、列強が清国にいくら貸す意思を持つかによって決まる**。[^u072]

このため1889年の講和は、実質的に「日清二国間条約＋列強の金融協定」となった。[^u072] 日本はイギリス系銀行団を対清賠償借款の中心に据え、清国の海関収入を担保とする借款で賠償を履行させる構造を作った（「対清賠償借款協定」）。[^n1][^u076][^u077] 最大の外交的成果は、史実1895年の露仏借款に相当するものを起こさず、ロシアを対清金融の中心から外したことにある。[^u077]

# 基本構造

## 講和の金融的制約

講和の軍事面では日本が時期と条件を決められるが、金融面では列強との事前調整が講和の時期を決める。[^u073] 日本は清国に軍事的に優位でも、英仏の銀行団に融資を強制することはできず、融資には必ず担保と返済条件が要る。[^u073]

| 当事者 | 役割 |
|---|---|
| 日本帝国 | 朝鮮独立・台湾割譲・賠償金を要求 |
| 清国政府 | 海関収入などを担保に借款を調達 |
| 欧米銀行団 | 融資し、利息収入と担保権を得る |
| ↓ | 講和条約の履行：日本への賠償支払い・清国の債務返済・軍事占領の段階的解除 |

[^u072]

日本は英独などに清国への融資を妨げないことを約束し、その代わり融資の一部を日本への賠償支払いに充てる仕組みを整える。台湾では既存外国商人の権利維持と事業特許で列強に講和受諾の経済的理由を与えるが、台湾特許の相手国と融資担当国が一致する必要はない。[^u072]

## 事前の銀行団協議

日本の大蔵・外務当局は、講和交渉の前から各国の銀行団と協議する。[^u072]

| 相手 | 日本が確認したいこと |
|---|---|
| イギリス系銀行団 | 清国の海関収入を担保にどの程度融資できるか |
| フランス系銀行団 | 清仏戦争後の対清金融への参加意思 |
| ドイツ系銀行団 | 清国向け借款と軍事・鉄道事業の条件 |
| ロシア政府・金融機関 | 清国への信用供与と引き換えに求める政治的利益 |
| アメリカ系金融機関 | 南北戦争が回避された本世界線で拡大した可能性のある対日・対清金融 |

民間銀行の融資と政府の信用保証は別であり、ロシアやフランスのように政府が融資を外交手段とする場合、銀行団の融資条件は国家間の政治問題となる。[^u072]

# 支払い能力の試算

## 海関収入という上限

清国の支払い能力の上限は海関収入である。史実の1890年代の海関収入は年およそ2,200万〜2,300万両、1887年は約2,054万海関両であった。[^u072][^u077]

年利5%・30年元利均等返済の単純モデルによる年間返済額（検討用の試算）:

| 借款元本 | 年間返済額（概算） |
|---|---:|
| 5,000万両 | 約325万両 |
| 1億両 | 約651万両 |
| 1億2,000万両 | 約780万両（1887年海関収入の約38%） |
| 1億5,000万両 | 約976万両 |
| 2億両 | 約1,301万両（海関収入の半分超） |

[^u072][^u077]

海関収入はすべてを自由に担保へ回せるわけではなく、既存の支出・他の債務・徴収機構の維持費がある。融資する側から見れば、**賠償額よりも、担保として確保できる税収と、その徴収を誰が管理するか**が重要である。[^u072] 庫平両と海関両は厳密には別単位であり、38%は大まかな規模比較にすぎない。[^u077]

## 賠償額の選択

日本には二つの選択肢があった。清国から2億両を要求し列強に巨額の借款を組ませるか、1億〜1億5,000万両程度に抑えて台湾・澎湖割譲と北洋方面の安全保障を優先するかである。[^u072] [下関条約](../diplomacy/shimonoseki-treaty-1889.md)では後者に近い1億2,000万庫平両とし[^n2]、分割払いと借款調達を認め、資金調達が確認されるまで威海衛の占領を解除しない設計となった。[^u077] 講和条件のうち最も調整しやすいのは賠償金であり、台湾割譲を確保できるなら賠償額は列強の融資可能額に合わせる余地がある。[^u073]

# 賠償を取りすぎないことの論理

* **清国を破産させない**: 清朝が財政破綻して賠償を払えなくなったり、列強が清国を分割したりすれば、日本が望む安定した東アジアの通商秩序そのものが損なわれる。最も難しいのは「清国が実際に履行でき、列強も資金を提供でき、元老院も納得する講和条件」の設計である。[^u072]
* **列強影響力拡大の逆説**: 賠償が巨額になるほど清国は外国借款に依存し、財政・鉄道・港湾・海関に列強の影響力が強まる。特にロシアが融資を通じて満洲へ進出すれば、朝鮮独立のために戦った日本は戦後に満洲でロシアの影響力が強まるという結果を招く。[^u072]
* **清の統治権の削減**: 清国は日本への賠償を払うために、税収・鉄道・鉱山という統治権を削られる。日本の戦勝が列強による中国の経済的分割を加速させる皮肉が生じる。[^u074]（[中国大陸の利権争奪](../diplomacy/china-concessions.md)参照）

# ロシアの排除

日本にとって列強の中で最も怖いのはロシアであり、対露妥協の余地は狭い。[^u075] このため対清賠償借款は、ロシアを排除した金融協定（英独米中心）を目指す理由がある。ただし露を排除するには、清にとって魅力的な代替融資条件が必要である。[^u075]

対露戦略上は、1888年頃ならフランスよりイギリスを先に引き込む方が有効とされた。「妙手」は、清国に借款を提供する銀行団へ鉄道・港湾などの事業権を先に設定させることである。例えば講和交渉と並行して清国と英系銀行団の間で山東・直隷方面の鉄道建設契約を締結させ、その資金の一部を賠償支払いに充てる。後からロシアが同じ地域へ進出すれば英国の既得権と衝突し、日本はロシアへの対抗を単独で負担せずに済む。[^u076]

その三本柱は次のとおりである。[^n3][^u076]

1. イギリス系銀行団を対清賠償借款の中心に据える
2. 清国に山東・直隷方面の港湾・鉄道事業権を認めさせる
3. フランスには華南の事業特許を提供し、台湾割譲への外交的反対を和らげる

# 信用リスクの移転と英国権益

## 「他人事ではない」英国権益

英国の対清権益は、日本にとって賠償金の支払いに直結する問題である。[^u085] 1889年の英系銀行団の対清借款は単なる外国投資ではなく、日本が清国から戦争賠償金を回収するための金融制度だからである。

| 当事者 | 利害 |
|---|---|
| 日本政府 | 賠償金の確実な受領、清国財政の安定 |
| 英系銀行団 | 元利金の確実な回収、担保収入の維持 |
| イギリス政府 | 自国金融機関の保護、中国市場へのアクセス |
| 清国政府 | 債務履行と残余の財政主権の維持 |
| ロシア政府 | 満洲・北洋での軍事・鉄道・金融権益の拡大 |

[^u085]

## 受領時期の設計

日本が借款によって賠償金全額を受領した後なら、清国が銀行団に返済不能になっても日本への支払いは取り消されず、損失を被るのは銀行団である。しかし分割融資・分割送金の方式なら、ロシアの介入で清国の担保能力が損なわれ残りの融資が停止すれば、日本への支払いも滞る。したがって**賠償金をいつ受領し、借款の信用リスクをいつ銀行団へ移すか**の設計が決定的に重要となる。[^u085]

ロシアの行動ごとの日本の利害は次のように整理される。[^n3]

| ロシアの行動 | 日本の利害 |
|---|---|
| 満洲北部の鉄道利権を要求 | 賠償借款を直接危険にさらすとは限らず、即時の軍事対応の理由は弱い |
| 英系企業の北洋鉄道・港湾権益を排除 | 収益が借款の追加担保なら日本にも介入理由 |
| 清国の海関収入・徴税制度に影響力を行使 | 未払い賠償の担保なら講和条約の履行に直結し、「清国の条約履行能力を守る」理由で抗議できる |

[^u085]

## 威海衛撤兵の順序

英系銀行団による賠償金支払いの確定→日本の威海衛撤退→英国の港湾権益の発効、という順序が重要とされる。これにより英国権益を対露牽制に使いつつ、日本自身の賠償回収も守ることができる。[^u085]

## 日英協定への発展

金融協力を外交協定へ発展させる案として、次の三項目が挙げられた。[^n3][^u085][^u086]

1. 北洋鉄道・港湾の権益を第三国へ移転・譲渡する際の日英事前協議
2. 賠償借款の担保を保護する共同外交（実効性は賠償が未払いかどうか次第）
3. 朝鮮・北洋における現状変更（旅順租借・朝鮮軍港使用権など）への協議

ただし清国も関連協定の当事者として同意している必要があり、日本に外交上の拒否権まで認めることにイギリスが応じるかは別問題である。[^u085] また、英国の権益への挑戦では第一義的な当事者は英国と清国であり、日本は英国に外交的主導権を取らせる。日本が英国権益の保護に直接の金融上の利害を持つのは、賠償履行が未完了の場合か、日本自身が借款・担保契約の当事者である場合に限られる。[^u089]（[日英協調](../diplomacy/anglo-japanese-cooperation.md)参照）

# 賠償金の使途と教訓

* 賠償金は帝国財政・軍備整備に利用できるほか[^u073]、半額6,000万両を「帝国交通整備基金」とする配分例がある。[^n3]賠償は一括受領とは限らないため、賠償を返済原資とする帝国債の発行や毎年の財政収入と組み合わせる。[^u083]（[帝国交通整備計画](transport-plan.md)参照）
* 日清戦争の経験により、勝っても賠償は清国の支払い能力に制約され、回収には列強の金融協力が必要であるという認識が帝国政府と領主に共有され、「戦争は勝てば儲かる事業ではない」という学習が対露慎重論の基盤となった。[^u088]
* 第一次世界大戦後の対独賠償でも、日本は1889年の経験から「敗戦国の支払い能力を超える賠償金は回収できない」ことを知っており、名目上の巨額請求に慎重になる可能性がある。[^u099]（[対独賠償と産業賠償](german-reparations.md)参照）

# 編集注：却下・修正された案

* **日本の役割の過大評価**: 日本が英国権益の保護に前面に立ち、英国に対露妥協を強く断念させる関与をするという方向は、「直接権益を侵されるのは英国であり、日本が単独で出しゃばる正当性はない」として修正された。[^u089]
* **「英国権益を先に作ればロシアは手を出せない」**: 史実の1899年英露鉄道協定のように英国は勢力圏調整に応じうるため、この想定は危険とされた。英国権益がロシアに譲渡・交換されにくい契約構造かどうかまで考える必要がある。[^u085]
