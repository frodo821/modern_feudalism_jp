# 概要

第一次世界大戦で日本は英仏に対する大口の債権国となった。その戦時債権の大部分は、日本企業による軍需品・船舶の輸出代金を繰り延べた**売掛金の性格の強いもの**であり、そのため**円建て債権が相当な割合を占める**（確定）。[^u135]

規模は会話ログ2の国際収支の積算で定まった。1914〜18年の累積経常黒字は**65億円**で、そのうち**対英の円建て貿易信用・売掛債権が40億円**、その他の対外債権が10億円、金・外貨準備等の増加が10億円、対外負債の純返済が5億円である。対英債権40億円は1920年の国民所得200億円の20%に当たる。[^e100] 前編で検討案として置かれた「対英8億〜18億円（1918年終戦シナリオ）」は、これにより大幅に上方修正された（「却下・修正された案」節を参照）。

史実の日本は外貨建て債務を抱える立場であったが、本世界線の日本は工業製品を輸出し、その代金を円建てで外国政府に貸し付ける。為替変動の危険を負担する側が史実と逆転し、英国は返済のために円を調達しなければならなくなった。この構造が1922年の旧平価復帰断念と1925年の[金本位制の法的廃止](/economy/gold-standard.md)を促し、円は金本位制に頼らず国際的に利用される通貨となった。[^u135][^u136][^e041]

戦後、この債権は単に返済されて消えたのではなく、ダイス判定の成功（1d100 > 25、出目69）によって**回収・借換・海外投資へ円滑に転換**された。[^e099][^e100] 会話ログ3の1937年国際収支の積算では、円建ての戦時商業債権を含む英国向け債権は借換・長期債権化によって残存し、**英国向け戦時債権・借換債権等50億円**（利回り4.5%、年2.25億円）が対外総資産135億円の最大項目となっている。英国への戦時債権の蓄積は1937年にも大きな投資収益をもたらす。[^p091] 英国向け債権50億円は、大戦期の戦時債権の残存・借換分25億円（会話ログ2の E100 の値）と、1931年の欧州通貨危機の際に日本が英国へ供与した円建ての支援信用とその借換債25億円からなる（作者確定）。 1937年の円相場は**1ドル＝2.50円、1ポンド＝12.25円**の管理相場と設定され、円は東アジアの地域的な国際決済通貨と位置づけられた。[^p092][^p097]

# 形成（1914〜1918）

## 発生の仕組み

日本の軍需・造船能力は、英仏の対日戦時債務（代金の一部を借款・政府保証債務で繰り延べたもの）を生み、英仏は対独賠償収入をその返済財源として期待するという連鎖を作った。ただし日本の供給が米国からの購入を置き換えただけなら、変わるのは債務総額よりも「債権者の構成」である。[^u099][^u119]

## 戦時黒字と対英債権の規模

会話ログ2では、1913年末の純対外資産をゼロ（資産・負債とも20億円）とする中立的な初期条件から、大戦期の経常収支を年ごとに積み上げた。史実の黒字（27.14億円）に対し工業力と海運力の差から2〜3倍を想定しつつ、英国側の輸送能力・支払能力が無制限ではないため工業生産力の倍率をそのまま掛けることは避けている。[^e100]

## 円建てになる理由

売掛金の発生地が日本だからといって自動的に円建てになるわけではなく、決済通貨は売買契約と信用供与契約で決まる。英国側にはポンド建てを望む理由があるが、日本側に価格交渉力があれば円建てを要求しやすい。[^u135]

| 取引 | 想定される通貨 |
|---|---|
| 日本企業の英国向け軍需品納入 | 円建て請求が有力 |
| 英国政府の日本国内での借款発行 | 円建て |
| 日本政府・領主系銀行団の対英貸付 | 円建てが中心になり得る |
| 英国の日本への債務返済 | 円、または契約に定めた換算額 |
| 英国からの石油・原料輸入 | ポンドなど外国通貨建ても残る |

（検討案）[^u135]

## 信用形成の仕組み

円建て戦時信用は、新たな現金の印刷を必要としない。英国政府が日本から軍需品10億円分を購入すると、日本の銀行団が英国政府の円建て債権10億円を保有し、輸出企業へ預金で代金を支払う。国内では企業預金が増え、雇用・設備投資・企業間決済が拡大する（検討案）。[^u136]

しかしこの仕組みは、銀行が換金困難な長期の英仏政府債務を抱えながら国内の短期決済に応じるという構造を生み、中央銀行の金準備が増えないまま銀行信用だけが拡大する。これが金本位制を維持しにくくした主因である（検討案）。[^u136] 対外債権の多くは金ではなく商業信用・売掛金として存在し、直ちに金へ転換できないことは、1922〜24年の新平価模索が行き詰まった理由の一つにも数えられた。[^e041]

# 戦後の処理と転換（1919〜1937）

## 回収・借換・再投資の成功

1920年代経済史のダイス判定のうち「対英戦時債権の回収・借換・再投資が円滑に進む」は 1d100 > 25 に対し出目69で成功した。これにより、円建て対英債権は単に返済されて消えたのではなく、次の4つの経路で別の資産へ転換されたとされる。円建てという性格は維持される。[^e099]

| 転換経路 | 内容 |
|---|---|
| 現物・資源調達 | 英国経済圏からの物資購入 |
| 長期債権への借換 | 円建て長期債券・借款 |
| 海外直接投資 | 鉱山・油田・農園・企業出資 |
| 金融資産への転換 | 海外証券・預金等 |

[^e099]

英国側には、円を調達するために英国経済圏から日本への輸出を増やす動機が生まれ、日本も受け取った資金を英国経済圏への新規投資に回すので、日英の経済関係は長期的なものになる。[^e099] ただし債権の回収や資産構成の変更は、それ自体では純対外資産の増加を意味しない。既存の対英債権を海外鉱山の株式に転換しても、資産構成が変わるだけである。[^e099][^e100]

## 貿易による返済の構造

英国が円建て債務を返済するには、何らかの方法で円を獲得しなければならない。債権国となった日本は輸入拡大の必要を自覚し、通商政策の重点を幼稚産業保護から輸出市場確保・原料輸入自由化へ移した（確定）。輸入拡大は英国の円建て債務返済を容易にし、対外債権の過度の累積も抑える。[^e045]

1920年代の日本は国際収支黒字の一部を[戦略資源備蓄](/economy/strategic-stockpile.md)に向け、英領マラヤの錫・ゴム、英領ボルネオの石油、英領インドの綿花・マンガンなどを英国経済圏から買い付けた。これは**英国の円建て債務を、日本からの新たな借款だけで処理するのではなく、貿易によって返済できる構造を作る**ものである（確定）。[^e043] 1932年の[オタワ帝国経済会議](/diplomacy/ottawa-conference-1932.md)で円建て投資の優遇と資源輸入の安定化が制度化されると、日本の資源購入で英国経済圏に供給された円が対日輸入代金や円建て債務の返済に使われ、円建て投資で形成された資源生産能力が将来の対日輸出能力を広げる、という循環が組み込まれた。[^e051]

## 1927年金融危機との関係

対英債権が健全であっても、それが長期債権である以上、国内銀行の短期的な支払能力を直接保証するわけではない。海外債権を多く保有する一方で国内の流動資金が不足していたことは、[1927年金融危機](/events/financial-crisis-1927.md)の構造的原因の一つに数えられる。[^e099] 危機に伴う対外資産の処理は、海外証券の売却・外貨預金化5億円、対外資産による外国借入返済3億円、輸入代金等への充当2億円、外国債権の貸倒・売却損等3億円とされ、純対外資産への影響は−3億円にとどまった。長期の対英債権や海外直接投資は簡単には換金できない。[^e100]

## 1931年の通貨危機と円建ての効果

1931年の[欧州通貨危機](/events/currency-crisis-1931.md)では、日本の対英債権の性格が問題となった。フーヴァー・モラトリアムは政府間の戦債・賠償の支払いを停止するもので、日本の対英債権のうち政府間戦債は原則対象となるが、物資供給に伴う売掛金・商業信用の性格が強い**商業債権と民間投資は原則対象外**となる。そのため英国は日本と独自の債務・決済協議を行う必要があった（有力案）。[^e040] 日本の対英債権が長期・継続的な商業信用であれば、直ちにロンドンから流出する資金にもならない。[^e042]

英国が金本位制を離脱してポンドが円に対して下落すると、英国の円建て債務負担はポンド換算で増える（下落率 d% なら負担は 100/(1−d) 倍）。日本は「英国を救済する意思はあっても、英国の金本位制を救済する意思は必ずしもない」立場をとり、円建て対英債権の保全・日英貿易金融の維持・円ポンド相場の安定には積極的に動いた（有力案）。[^e042] 英国離脱後の日英緊急金融・通商協定案では、日本側が円建て債務の借換え・円建て貿易信用・資源の長期買付を、英国側が既存契約の維持・対日輸入制限の抑制を約する。[^e044]

国際収支の積算では、円建て債権を中心としていたことが日本にとって重要なリスク軽減要因になった。[^e100]

| 保有資産 | ポンド下落時の影響 |
|---|---|
| 円建て対英債権 | 為替による円換算元本の減少を回避 |
| ポンド建て預金・債券 | 円に対してポンドが下落すれば評価損 |
| 英国企業の株式 | 為替と企業価値の双方に影響される |
| 海外鉱山・油田権益 | 資源価格下落による収益・評価額の低下 |

ただし英国側の返済負担が増えるので、円建て債権でも信用リスクは残る。1930〜32年の評価損・債権償却等は純額4億円とされた。[^e100]

| **対外総負債** | **37.9億円** | **1.90億円** |

[^p091]

純対外資産は97.1億円（GDP比24.3%）、純投資所得5.20億円に純雇用者報酬等0.10億円を加えた純第一次所得は5.30億円である。経常収支黒字15.169億円のうち約35%が純第一次所得で、英国への戦時債権の蓄積は1937年にも大きな収益を生んでいる。[^p091][^p096] 英国向け債権は、円建ての戦時商業債権を含めその後の借換・長期債権化によって残存しているものとされ、円建てか外国通貨建てかは資産評価や為替リスクに影響するが、英国居住者への債権である限り日本の対外資産となる。[^p091] 戦時債権の元本は、1914〜18年の40億円から1937年の残存・借換分25億円へ縮小し、これに1931年の欧州通貨危機の際の円建て対英支援信用とその借換債25億円が加わって、英国向け債権は50億円となる（作者確定）。[^e100] 海外直接投資が会話ログ2の80億円から30億円に縮んだのは、1927年の金融危機で前田家など領主家の国際金融資本が海外資産を失ったためである（作者確定）。

対外資産135億円の保有主体は、整合性確認のための仮置きとして、領主家42.73億円・無領華族その他民間62.27億円・帝国政府等公的機関30.00億円とされている（対外負債の主体別配分は未了）。[^p070] 領主家の海外資産の内訳は[国民資産と富の所有構造（1937）](/economy/national-wealth-1937.md)を参照。

# 円の国際化

## 円の地位

円建て貿易・国際借款の拡大によって、円の国際的地位は既に獲得されている。そのため1920年代の金解禁論は「国際金融市場で円の地位を獲得するため」ではなく、「その信用を維持するためにどの通貨制度が適切か」という議論になる。[^u135] すでに国際的に利用されている円を、金本位制へ戻すことで初めて信用できる通貨にする、という発想は弱まる。[^u137]

1922年に旧平価復帰を断念した理由の一つは、旧平価復帰のための通貨収縮・円高誘導が英国など債務国の円建て債務負担を重くし、国内輸出産業だけでなく日本の金融機関や英国の取引先からも反対が出ることであった（確定）。1925年の制度改正後は、外国の中央銀行・金融機関にも円の金兌換を保証せず、**円の信用は円建て決済能力と金融市場の流動性で維持する**。[^e041]

## 1937年の円建て国際金融市場

1937年の産業別設定のダイス判定で、「円建て国際金融・貿易決済市場」の発達は 1d100 > 25 に対し出目68で成功した。円は東アジアを中心とする有力な国際取引通貨として定着しているが、**ポンドに代わる世界の基軸通貨にまではならない**。[^e085]

| 通貨 | 役割（1937年） |
|---|---|
| ポンド | 世界的な貿易金融・決済 |
| ドル | 米州 |
| 円 | 東アジア・日英間取引・資源開発金融 |

[^e085]

日本国内には外国銀行・金融拠点が多数置かれ、円・ポンドの為替市場が発達する。[^e085] 会話ログ2では、円建て決済の普及で外国企業・外国政府も円資産を持つため対外総資産・総負債の双方が大きく、非居住者の円預金32億円を居住者の通貨供給量と区別して集計するとされていたが、会話ログ3の対外負債37.9億円の内訳には円預金の項目は置かれていない。[^e093][^e100][^p091]

会話ログ3では、円の国際的な機能が次のように整理された。[^p092]

| 通貨の機能 | 1937年の円の地位 |
|---|---|
| 国内決済通貨 | 確立 |
| 日朝貿易の決済通貨 | 有力 |
| 日中貿易の決済通貨 | 一部で普及 |
| 東アジアの貿易信用 | 有力 |
| 英国との長期債権契約 | 一部円建て |
| 国際的な外国債券発行通貨 | 限定的に発達 |
| 世界的な準備通貨 | ポンド・ドルには及ばない |

（有力案）[^p092]

円はポンドやドルと同等の世界通貨ではなく、東アジアの**地域的な国際決済通貨**として発展し、その信用を英国・米国との金融関係が支える。背景には、第一次世界大戦以降に蓄積した円建て対外商業債権と、国際金融業に成功した領主系・独立系銀行の存在がある。[^p092]

## 1937年の為替相場

会話ログ2で未決だった円・ポンド・ドルの為替相場は、会話ログ3で**1ドル＝2.50円（1円＝0.400ドル）、1ポンド＝12.25円**と設定された。日本銀行・帝国政府の為替介入と金融政策で相場を管理する管理通貨制度で、対ポンド関係を重視するが厳密な固定相場ではなく、外貨準備はポンド・ドル・金などに分散する。史実の1937年（1ドル＝約3.47円）より1円当たりのドル価値が約39%高い。[^e103][^p092][^p097] この相場で純対外資産97.1億円は38.84億ドル＝7.93億ポンドに当たる。[^p092] 経常黒字の円高圧力は資本輸出で相殺され、円建て対英債権の蓄積に対応する通貨供給の拡大と国際的な円の信用維持が両立する。[^p092] 詳細は[1937年の円相場・物価・家計と列強経済力比較](/economy/yen-prices-1937.md)を参照。

## 必要な金融インフラ

英国は円を調達しなければならず、日本も英国からの返済を実際に円で受け取る仕組みを必要とする。そのため、横浜正金銀行に相当する外国為替銀行や、ロンドンにおける円決済市場の発展が欠かせない。英国政府が円建て債務を返済しても、円を受け取った銀行が国外で自由に利用できなければ円の国際化には限界があるため、外国為替取引や資金移動について一定の自由を維持する必要がある（検討案）。[^u135]

金に兌換できない円の信用を海外で支える手段として、英国との通貨スワップに相当する相互信用枠、ポンド準備の保有、ロンドンでの円建て手形市場の整備が挙げられた。[^u136] 会話ログ2では、1931年の英国離脱を契機とする日英金融協定案として、両中央銀行の相互通貨信用、急変時の協調介入、既存債務の返済延長・借換え、円・ポンド建て手形の割引制度、相互通貨建て流動資産の保有、金兌換の相互不要求、固定平価ではなく協議による為替安定化が具体化されている（有力案）。[^e042]

## 円の価値を支えるもの

円の価値を支えるのは金兌換だけではなく、日本の工業生産力、対外取引、金融機関の信用、そして債務者である英国の円需要である。ただし英国の円需要は償還が進むにつれて減っていく。[^u137] 戦時債権の残高は1937年までに25億円へ縮小したが（E100）、1931年の対英支援信用とその借換債25億円が加わって英国向け債権は50億円残り（作者確定）、英国の円需要は1937年にもなお相当の規模を保つ。これに加えて、円建て借款・円建て債券・円建て貿易信用を利用する英国経済圏の開発事業が円需要の担い手となっている。[^e051][^e100][^p091]

# 為替と債権の関係

円建て債権が多いからといって、日本が円高・円安のどちらを望むとは一概に言えない。例えば英国の債務が10億円建てなら、円安になっても返済額面は10億円のままで、ポンド換算の英国の返済負担は軽くなる。逆に円高なら英国が円を調達する負担が増す。日本の債権者にとっては、受け取る円の額は変わらないが、その円で外国製品をどれだけ買えるかが変わる。立場は貸倒れの危険、国内物価、海外資産の取得計画によって異なる。[^u135] 1931年のポンド下落局面では、円高が日本の輸出産業にも不利であり、英国の債務の不良債権化の危険もあるため、日本にも円高を抑える動機があった。[^e042]

# 外交・財政への影響

## 日英関係

英国にとって、日本は債権者・工業製品の供給国・中国事業の共同投資者・海軍協力の相手を兼ねる存在となった。対米関係のために日本との関係を損ね、「金で返せ」と迫られる方が英国には厳しい。[^u118] 日本の影響力は債務残高だけでなく、借り換えへの同意か満期返済の要求か、期限前償還条項、違約事由、満期の集中といった返済条件で決まり、日本が一方的に期限前一括返済を要求できるわけではない。日本の債権者（領主系銀行・産業資本）も、自らの資産価値を損なうため英国を金融危機に追い込みたくはない（検討案）。[^u118]

「巨額の自国債権を持つ国を仮想敵として設定する必要があるか」という問いのとおり、英国が日本を仮想敵にすれば対日戦備の支出増が対日返済能力を損なう。ただし債権関係それ自体は戦争防止の保証ではない（戦時の敵国債権の凍結・支払停止）。[^u122]

国際金融制度においても、英国が日本の債務者であるため、「日本を参加させるために金解禁を要求するのか、日本の参加を得るために制度側が柔軟になるのか」という交渉力の関係が史実と逆転する。[^u134]

債務の一部は、中国の鉄道・鉱山・港湾企業への日本資本の参加と交換する代物弁済で整理され得る。この経路については[日英戦時債務整理と中国権益の移転](/diplomacy/war-debt-settlement.md)を参照。[^u103]

## 帝国財政

対英仏債権の元本償還は新たな所得ではなく、保有資産が債権から現金へ変わるだけである。利息は経常収入だが債務者の支払能力に依存する。民間銀行や領主系企業が保有する債権の償還金は自動的に帝国歳入にはならず、政府が利用するには課税・国債発行・債権購入・金融機関との別途契約が必要となる。帝国政府保有分の償還金は、対独賠償などとともに1920〜25年の帝国艦隊更新基金（6億円）の財源とされる（検討案）。[^u126] 詳細は[帝国財政と諸侯の法定拠出](/economy/imperial-finance.md)を参照。

円建て債権の元本償還は国民総所得（GNI）にも加算されない。[^e072] 1937年以降の軍拡に際しても、海外資産を売って軍艦を造ることは通常の財源とせず、輸入資源の調達や為替・国際決済の流動性のために維持するのが原則とされる（有力案）。[^e101]

## 通貨政策の帰結

円建て債権が生んだ金と信用の不均衡は、1922年の旧平価復帰断念、1925年の金平価・金兌換義務の法的廃止と金輸出入の自由化につながった（確定）。日本は1925年以降、円建て貿易と円建て国際借款を発展させ、円相場の安定を外国為替市場への介入と日英間の金融協調によって維持する。世界恐慌に際しても旧平価で金解禁することはなく、円建て債権の信用を維持しながら国内の金融緩和と公共投資を続けた。[^u135][^e041] 詳細は[金本位制離脱と管理通貨制](/economy/gold-standard.md)を参照。

# 却下・修正された案

- **英国向け債権50億円をすべて大戦期の戦時債権の借換・長期債権化による残存分とする説明（P91）**：大戦期の債権40億円を上回り、回収・借換・再投資の成功（E99、出目69）と合わないため、戦時債権の残存・借換分25億円（E100）と1931年の対英支援信用・借換債25億円に分けた（作者確定）。海外直接投資80億円（E100）→30億円（P91）の縮小は、1927年の金融危機で前田家など領主家の国際金融資本が海外資産を失ったためとした（作者確定）。[^e099][^e100][^p091]
- **終戦シナリオ別の債権レンジ（前編 U119）→ 対英40億円（E100）**：前編では終戦年に応じて「A 1917年終戦：対連合国8億〜15億円（うち対英4億〜9億円）／B 1918年終戦：15億〜30億円（うち対英8億〜18億円）／C 1919〜20年終戦：30億〜50億円（うち対英15億〜30億円）」という検討案が置かれ、B が検討の中心であった。[^u119] 会話ログ2の国際収支の積算（1914〜18年の戦時黒字65億円）で、対英債権は40億円、その他の対外債権10億円とされ、B案の上限（対英18億円）を大きく超えた。後の決定である会話ログ2の値を採る。[^e100]
- **英国の対日債務20億ドル（前編 U118）**：1922年の英国政府対外戦時債務を「米国26・日本20・その他3（億ドル相当）」とする仮置きは、史実の日本の資金供給実績に照らして過大として撤回されていた。[^u118][^u119] 編者注：会話ログ2の40億円は、旧平価（100円≒49.85ドル）で機械的に換算すると約20億ドルに当たり、結果として撤回前の仮置きと同水準に戻っている。本世界線の1937年の相場は1ドル＝2.50円と設定されたが（P92）、大戦期・戦後期の相場は未設定であり、この換算は目安にとどまる。[^e103][^p092]
- **1937年の戦時債権残存分：GDP比10%（E93）→ 40億円（E99）→ 25億円（E100）→ 英国向け戦時債権・借換債権等50億円（P91）**：金融部門の検証では対外資産の内訳として「戦時債権の残存・借換分 GDP比10%」が置かれ、円建てGDP400億円の決定で40億円とされたが、国際収支の累積で純対外資産が120億円から97.1億円へ下方修正された際、債権処理の成功（出目69）を踏まえて残存分を25億円へ減らし、直接投資の規模は維持した。[^e093][^e099][^e100] 会話ログ3では対外資産全体の再積算により、借換・長期債権化した英国向け債権等が50億円とされた。[^p091]
- **1937年の対外資産の内訳：会話ログ2 → 会話ログ3**：会話ログ2では対外総資産177.1億円（戦時債権の残存・借換分25億円、海外鉱山・油田40億円、海外農園・林業20億円、その他直接投資20億円、海外証券24.1億円、貿易信用・その他32億円、金・外貨準備等16億円）、対外総負債80億円（うち非居住者の円預金32億円）、海外純第一次所得5.28億円とされ、直接投資が総資産の約45%を占めて「債権国から海外事業を経営する投資国へ移行」したと位置づけられていた。[^e100] 会話ログ3（P91・P96）では対外総資産135億円（英国向け戦時債権・借換債権等50億円が最大）、対外総負債37.9億円、純第一次所得5.30億円に置き換えられた。純対外資産97.1億円は一致する。後の決定である会話ログ3を採る。[^p091][^p096]
- **1937年の純対外資産120億円（GDP比30%）→ 97.1億円（24.3%）**：GDP比30%という従来の想定は、1914年以降の国際収支の累積で下方修正された。検討範囲は80〜120億円で、戦時黒字を80億円（史実の約3倍）とすれば112.1億円になる。[^e093][^e100]
- **「金輸出停止を継続」する1930年の通貨政策（前編 U135）**：1930年の通貨政策を「金輸出停止を継続しながら円建て貿易と円建て国際借款を発展させる」とした整理は、会話ログ2で1925年に金輸出入が原則自由化されたことになったため、「金本位制を廃止したうえで」と読み替える。[^u135][^e041]

# 未決の論点

- 65億円・40億円という規模は、英国側の戦時調達額・支払能力から独立に検証されていない。1913年の資産残高と為替評価損益も独立の統計的積算ではない。[^e100]
- その他の対外債権10億円の内訳（フランス向け、革命で回収不能になるロシア向けの規模。[ソ連承認問題と旧ロシア債務](/diplomacy/soviet-recognition.md)を参照）。[^u119][^e100]
- 日本の対英債権のうち政府間戦債と商業債権の比率、政府管理か民間保有か、満期構成、借り換え拒否の可否。[^u118][^e040]
- 対英債権40億円のうち、代物弁済（中国権益の移転）で整理された額。（会話ログ2は4つの転換経路を示すのみで、代物弁済の金額には触れていない）[^e099]
- 為替相場は1937年について1ドル＝2.50円・1ポンド＝12.25円で解決した（P92）。大戦期から1936年までの相場の推移と、決済制度の詳細は未設定。[^e103][^p092]
- 英国向け債権50億円のうち円建て分・ポンド建て分の比率、および対外負債の保有主体別配分。[^p070][^p091]
- 日英金融協力（相互信用枠・ポンド準備・ロンドン円手形市場）の制度化の程度と、外国人の円資産の保護制度。[^u136][^u137][^e042]
