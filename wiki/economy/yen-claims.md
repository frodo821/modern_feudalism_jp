# 概要

第一次世界大戦で日本は英仏に対する大口の債権国となった。その戦時債権の大部分は、日本企業による軍需品・船舶の輸出代金を繰り延べた**売掛金の性格の強いもの**であり、そのため**円建て債権が相当な割合を占める**（確定）。[^u135]

史実の日本は外貨建て債務を抱える立場であったが、本世界線の日本は工業製品を輸出し、その代金を円建てで外国政府に貸し付ける。為替変動の危険を負担する側が史実と逆転し、英国は返済のために円を調達しなければならなくなった。円は金本位制への復帰を待たずに国際的に利用される通貨となり、この構造が1920年代の[金本位制離脱](/economy/gold-standard.md)と1930年の通貨政策を規定した。[^u135][^u136]

# 形成

## 戦時債権の規模（検討案）

日本の軍需・造船能力は、英仏の対日戦時債務（代金の一部を借款・政府保証債務で繰り延べたもの）を生み、英仏は対独賠償収入をその返済財源として期待するという連鎖を作った。ただし日本の供給が米国からの購入を置き換えただけなら、変わるのは債務総額よりも「債権者の構成」である。[^u099][^u119]

終戦時の日本の対連合国債権は、大戦の終結時期に応じて次のレンジが置かれている（当時の円。日本の金融市場が十分発達し、輸出代金の相当部分を政府・銀行団の信用供与で賄った場合）。[^u119]

| シナリオ | 終戦 | 対連合国債権 | うち対英 |
|---|---|---:|---:|
| A 早期終結型 | 1917年 | 8億〜15億円 | 4億〜9億円 |
| **B 長期消耗型（検討の中心）** | 1918年 | 15億〜30億円 | 8億〜18億円 |
| C 戦争激化型 | 1919〜20年 | 30億〜50億円 | 15億〜30億円 |

「工業品を供給できることと、英仏政府に何十億ドルも貸せることは別」であり、英国の対日債務を20億ドル相当とした当初の仮置きは過大として撤回されている。[^u119]

## 円建てになる理由

売掛金の発生地が日本だからといって自動的に円建てになるわけではなく、決済通貨は売買契約と信用供与契約で決まる。英国側にはポンド建てを望む理由があるが、日本側に価格交渉力があれば円建てを要求しやすい。[^u135]

| 取引 | 想定される通貨 |
|---|---|
| 日本企業の英国向け軍需品納入 | 円建て請求が有力 |
| 英国政府の日本国内での借款発行 | 円建て |
| 日本政府・領主系銀行団の対英貸付 | 円建てが中心になり得る |
| 英国の日本への債務返済 | 円、または契約に定めた換算額 |
| 英国からの石油・原料輸入 | ポンドなど外国通貨建ても残る |

（検討案）[^u135]

## 信用形成の仕組み

円建て戦時信用は、新たな現金の印刷を必要としない。英国政府が日本から軍需品10億円分を購入すると、日本の銀行団が英国政府の円建て債権10億円を保有し、輸出企業へ預金で代金を支払う。国内では企業預金が増え、雇用・設備投資・企業間決済が拡大する（検討案）。[^u136]

しかしこの仕組みは、銀行が換金困難な長期の英仏政府債務を抱えながら国内の短期決済に応じるという構造を生み、中央銀行の金準備が増えないまま銀行信用だけが拡大する。これが金本位制を維持しにくくした主因である（検討案）。[^u136]

# 円の国際化

## 円の地位

円建て貿易・国際借款の拡大によって、円の国際的地位は既に獲得されている。そのため1920年代の金解禁論は「国際金融市場で円の地位を獲得するため」ではなく、「その信用を維持するためにどの通貨制度が適切か」という議論になる。[^u135] すでに国際的に利用されている円を、金本位制へ戻すことで初めて信用できる通貨にする、という発想は弱まる。[^u137]

## 必要な金融インフラ

英国は円を調達しなければならず、日本も英国からの返済を実際に円で受け取る仕組みを必要とする。そのため、横浜正金銀行に相当する外国為替銀行や、ロンドンにおける円決済市場の発展が欠かせない。英国政府が円建て債務を返済しても、円を受け取った銀行が国外で自由に利用できなければ円の国際化には限界があるため、金兌換を停止したままでも外国為替取引や資金移動について一定の自由を維持する必要がある（検討案）。[^u135]

金に兌換できない円の信用を海外で支える手段として、英国との通貨スワップに相当する相互信用枠、ポンド準備の保有、ロンドンでの円建て手形市場の整備が挙げられる。ただし、そうした日英金融協力の制度が1920年代に成立していることは既存の設定から自動的には導かれない（検討案）。[^u136]

## 円の価値を支えるもの

円の価値を支えるのは金兌換だけではなく、日本の工業生産力、対外取引、金融機関の信用、そして債務者である英国の円需要である。ただし英国の円需要は償還が進むにつれて減っていく。[^u137]

# 為替と債権の関係

円建て債権が多いからといって、日本が円高・円安のどちらを望むとは一概に言えない。例えば英国の債務が10億円建てなら、円安になっても返済額面は10億円のままで、ポンド換算の英国の返済負担は軽くなる。逆に円高なら英国が円を調達する負担が増す。日本の債権者にとっては、受け取る円の額は変わらないが、その円で外国製品をどれだけ買えるかが変わる。立場は貸倒れの危険、国内物価、海外資産の取得計画によって異なる。[^u135]

# 外交・財政への影響

## 日英関係

英国にとって、日本は債権者・工業製品の供給国・中国事業の共同投資者・海軍協力の相手を兼ねる存在となった。対米関係のために日本との関係を損ね、「金で返せ」と迫られる方が英国には厳しい。[^u118] 日本の影響力は債務残高だけでなく、借り換えへの同意か満期返済の要求か、期限前償還条項、違約事由、満期の集中といった返済条件で決まり、日本が一方的に期限前一括返済を要求できるわけではない。日本の債権者（領主系銀行・産業資本）も、自らの資産価値を損なうため英国を金融危機に追い込みたくはない（検討案）。[^u118]

「巨額の自国債権を持つ国を仮想敵として設定する必要があるか」という問いのとおり、英国が日本を仮想敵にすれば対日戦備の支出増が対日返済能力を損なう。ただし債権関係それ自体は戦争防止の保証ではない（戦時の敵国債権の凍結・支払停止）。[^u122]

国際金融制度においても、英国が日本の債務者であるため、「日本を参加させるために金解禁を要求するのか、日本の参加を得るために制度側が柔軟になるのか」という交渉力の関係が史実と逆転する。[^u134]

債務の一部は、中国の鉄道・鉱山・港湾企業への日本資本の参加と交換する代物弁済で整理され得る。この経路については[日英戦時債務整理と中国権益の移転](/diplomacy/war-debt-settlement.md)を参照。[^u103]

## 帝国財政

対英仏債権の元本償還は新たな所得ではなく、保有資産が債権から現金へ変わるだけである。利息は経常収入だが債務者の支払能力に依存する。民間銀行や領主系企業が保有する債権の償還金は自動的に帝国歳入にはならず、政府が利用するには課税・国債発行・債権購入・金融機関との別途契約が必要となる。帝国政府保有分の償還金は、対独賠償などとともに1920〜25年の帝国艦隊更新基金（6億円）の財源とされる（検討案）。[^u126] 詳細は[帝国財政と諸侯の法定拠出](/economy/imperial-finance.md)を参照。

## 1930年の通貨政策

1930年の通貨政策は、「金輸出停止を継続しながら、円建て貿易と円建て国際借款を発展させ、円相場の安定を外国為替市場への介入や日英間の金融協調によって維持する」ものと整理される（検討案）。世界恐慌に際しても、旧平価で金解禁することなく、円建て債権の信用を維持しながら国内の金融緩和と産業投資を続ける選択肢がある。[^u135]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 対連合国貸付 | 1915〜18年に英仏露へ約6億4,063万円、うち約2億2,000万円がロシア革命で回収不能 | 終戦時15億〜30億円（B案、検討案） |
| 円建て借款 | 1916年12月に英国向け1億円借款、以後政府支援の戦時借款は円建て。1918年に英国政府が8,000万円の円建て大蔵省証券を日本で発行 | 同じ手法をはるかに大規模に展開 |
| 円の国際化 | 円建て貿易拡大が政策目標で、金の自由な移動が円の信用を支えると考えられた | 円の国際的地位は既に獲得済み。金兌換に依存しない |
| 国際収支 | 生糸・繊維中心の輸出、輸入超過 | 機械・鉄鋼・船舶・化学製品の輸出、英仏への円建て債権と海外投資からの利息・配当 |

[^u119][^u135][^u137]

史実で日本は1916〜18年に英仏露への戦時信用供与を拡大しており、円建ての国際信用供与は本世界線独自の金融技術ではない。本世界線ではそれが「はるかに大規模に」発展した。[^u135] 史実の英国は1923年に対米戦時債務約46億ドルについて62年返済の協定（金利当初3%、後3.5%）を結んだ。[^u118]

# 未決の論点

- 終戦年（A/B/C）と、それに応じた英国の対日債務の規模（10億円か30億円か）。[^u119]
- 日本の対英債権が政府管理か民間保有か、満期構成、借り換え拒否の可否。[^u118]
- ロシア革命による旧ロシア向け債権の損失規模（[ソ連承認問題と旧ロシア債務](/diplomacy/soviet-recognition.md)を参照）。
- 日英金融協力（相互信用枠・ポンド準備・ロンドン円手形市場）の制度化の程度と、外国人の円資産の保護制度。[^u136][^u137]
