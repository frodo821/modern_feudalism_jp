# 概要

本世界線の領主は、領国を治める公的統治者であると同時に、企業株式・土地・海外資産を持つ大資産家でもある。この二つの立場の会計は、明治以来はっきり分かれていなかったが、1927年の金融危機（→[1927年金融危機（本世界線）](../events/financial-crisis-1927.md)）を機に**領主家資産と領国政府財政の制度的分離**が進み（ダイス判定：難易度35、出目95・クリティカル）、1937年までに全国的に定着した（ダイス判定：難易度15、出目60・成功）。一般的な銀行監督の強化には失敗したので、金融危機への政治的対応は「金融業全体の規制」ではなく「**領主家の企業活動から公的財政を保護する方向**」へ進んだ。[^p008][^p009]

この改革で、領主が統治者であることと大資産家であることが法的に切り離された。領主家の企業が破綻しても領国政府は当然には財政破綻せず、領主権も失われない。逆に、領国の財政赤字を領主家の私財で埋める義務もない。[^p008]

1937年の制度では、**法定拠出金**は、領国の人口と歳入に連動する分を領国政府が、家門の所得に連動する分を領主家門が負担する二本立てとなり、恒常的な資産保有税は導入されず、領主家門は累進所得税の大口納税者となった。家門の私的支出（構成員への給付、使用人の給与・給付、家門用不動産の維持費など）は**家門会計**として、領国政府の予算とは完全に別の勘定で扱われる。[^p071][^p073][^p075]

# 公私財政分離（1927年〜）

## 判定

| 判定項目 | 難易度 | 出目 | 結果 |
|---|---:|---:|---|
| 金融危機を契機に銀行監督制度が大幅に強化される（1932年まで） | 25 | 15 | 失敗 |
| 領主家資産と領国政府財政の制度的分離が進展する（1932年まで） | 35 | 95 | クリティカル |
| 金融危機が領主制そのものに対する大規模な批判運動を引き起こす | 55 | 19 | 失敗 |
| 領主家資産と領国財政の分離が全国的に定着する（1937年まで） | 15 | 60 | 成功 |
| 銀行監督制度の抜本的改革が実現する（1937年まで） | 35 | 20 | 失敗 |

[^p008][^p009]

## 改革の内容

クリティカルの結果、単なる帳簿の分離ではなく次の制度まで成立したとされる（AI の提示を受けてユーザーが異議なく次へ進んだ内容）。[^p008]

| 制度 | 内容 |
|---|---|
| 公私財産の区分 | 領国公有財産と領主家私有財産を法的に区別 |
| 会計分離 | 公会計と家産会計の完全分離 |
| 債務分離 | 領主家の債務を領国政府が当然には承継しない |
| 保証制限 | 領主家企業への公的債務保証を規制 |
| 公的契約 | 領主家企業との取引を公会計上明示 |
| 領主家拠出金 | 私的所得から公的財政への拠出として明確化 |
| 領国財政監査 | 帝国共通の会計基準による監査 |
| 財産承継 | 領主権の継承と私有財産の継承を区別 |

改革後の勘定は次のように整理される。[^p008]

| 領主家私会計 | 領国政府公会計 |
|---|---|
| 配当・利子 | 領国税・手数料 |
| 私有不動産収益 | 公有財産収益 |
| 家産企業への投資 | 教育・警察・公共事業 |
| 家政費・私的債務 | 公債・公的債務 |

公私間の資金移動は、法定拠出・契約・予算に基づくものに限られる。これにより、1937年の財政制度では「領主家の私的資産所得」「領国政府の公的歳入」「帝国政府への拠出金」の三つの勘定を区別できるようになった。[^p008]

## 背景と意義

1927年の危機では「領主系銀行を政府が救済するのか」が全国政治の争点となり、衆議院は「税金で領主系金融資本を救済するのか」と批判し、元老院は金融システム全体の保護を主張した（有力案）。[^p001] 島津家（危機対応ファンブル）や黒田家（同ファンブル）の経営危機は改革を促した主要な事件とされ、改革の結果、薩摩・熊本・福岡の各領国政府は家産危機から守られ、領主権も維持された（有力案）。前田家も巨額の損失を受けて改革を支持する動機を持った。[^p038][^p039][^p042][^p043]

反領主制運動が広がらなかった（出目19）こととあわせ、領主制への批判は制度廃止ではなく制度改革として吸収された。領主制の性格は次のように変化したと整理される。[^p008]

| 時期 | 領主制の発展 |
|---|---|
| 1860〜1870年代 | 領主権の憲法的確立 |
| 1890年代 | 領主権と臣民の権利の調整 |
| 1920年代後半 | 領主家産と公的統治権の制度的分離 |
| 1930年代 | 世襲的な公的統治職としての領主制 |

公私分離は、華族全体の家門制度にも波及した。領主家の私有財産だけを特別扱いする根拠が弱まり、「領主家産制度」が無領華族を含む「華族家産制度」へ発展したとされる（→[家門自治権と家門司法権](../institutions/family-autonomy.md)）。[^p026][^p027] また、大領主が債務を通じて中小領主の領国を事実上支配する関係（→[領主金融圏と諸侯共済会](lord-financial-spheres.md)）も、私的債務を根拠に領国の公的資産を処分したり領国財政を担保にしたりすることが難しくなって、部分的に制約された。[^p023]

# 家門会計

## 家門支出の範囲

使用人の給与その他の給付と不動産の維持費は、家門支出に含めることがユーザーにより決定された。[^p071] これを受けて家門支出は次の10分類に整理された。[^p071]

|---|---|

| 使用人現物給付費 | 食事・衣服・宿舎・医療その他の福利厚生 |
| 不動産維持費 | 邸宅・庭園・別邸・家門施設の修繕・清掃・光熱水費 |
| 家門管理費 | 会計・財産管理・登記・文書管理・法律事務 |
| 家門司法費 | 家門司法機関の運営・調査・審理 |
| 儀礼・交際費 | 儀礼・社交 |
| 政治活動費 | 元老院活動・選挙活動・首都滞在 |
| 公益事業費 | 寄付・奨学金・文化事業 |
| 法定負担 | 法定拠出金・租税 |

使用人の職種は、家令・事務職員、法務・司法職員、秘書、家事使用人、庭師・営繕職員、運転手、警備員、医療・教育職員である。使用人は原則として爵位別の家門構成員数の上限（公爵500・侯爵250・伯爵100・子爵50・男爵25人）に数えない。正式に家門へ加入した者は例外である。[^p028][^p071]

> 総家産収入（配当・利子・地代・賃貸収入など）− 資産運用経費 ＝ 純家産所得
> 純家産所得 ＋ その他の家門収入 ＝ 家門経常収入

黒字なら積立・再投資に回し、赤字なら資産の取崩しなどで埋める。歴史の長い家ほど、家産に比べて維持すべき施設や使用人が多い。[^p071] 家門構成員の就業所得は原則として本人に帰属し、家門に納めた部分だけが家門収入になる。家門維持費は所得税の必要経費として控除せず、税引後の所得から支出する（有力案）。[^p072][^p076]

# 法定拠出金と租税

## 制度方針（P73）

ユーザーは、法定拠出金と租税負担を**領国の規模と所得に連動させ**、**資産課税は実施が困難で憲法との整合性も怪しいので行わない**と決定した。[^p073] 確定した方針は次のとおりである。[^p073]

| 負担 | 算定基準 | 負担主体（1937年） |
|---|---|---|
| 領国規模連動拠出金 | 領国の人口・経常歳入 | 領国政府（公私分離前は領主家門） |
| 所得連動拠出金 | 家門の年間純所得 | 領主家門 |
| 所得税 | 課税所得 | 家門・個人 |
| 法人税 | 企業所得 | 各企業 |
| 資産保有税 | ― | 導入しない |

法定拠出金は**領主の地位に伴う特別な負担**であり、所得税は一般国民にも適用される租税として区別される。[^p073] 所得連動の拠出金は無領華族には適用しないと仮定されている。[^p082]

資産課税を導入しない理由として、家門自治権（帝国政府が家門財産を調べる権限が問題になる）、財産権の保障（合憲性が争われうる）、非上場株式の時価評価の困難、山林・開拓地の収益と評価額の乖離、海外資産の把握・徴税の困難、所得を生まない歴史的建造物、所得の少ない家門に資産売却を強いるおそれが挙げられた。ただし「憲法上当然に禁止」とまでは確定せず、「1937年までは導入されなかった」という設定にとどめる。[^p073] 領国も資産保有額への恒常的課税は行わず、土地には実際の地代・農業所得に課税する。[^p093]

## 拠出金の歴史的な位置

諸侯の法定拠出は、1861年の海防勅命の「諸侯は国力に応じて軍費と兵員を供出する」原則に由来し、軍役の金納化を経て、元老院が承認する算定基準による帝国への拠出として制度化された。1920年の中核案で2.5億円である（→[帝国財政と諸侯の法定拠出](imperial-finance.md)）。[^u126][^p074]

## 試算の経過（P74）

拠出金の算定式は C = aP + bR + cY（P＝領国人口、R＝領国政府の算定対象経常歳入、Y＝家門の年間純所得）とされた。経常歳入は算定基準としてだけ使い、拠出は家門の私的財産から行う形であれば公私分離と両立する。[^p073]

* **当初案**（C = 0.2P + 0.01R + 0.05Y）では、領主249家の拠出金は1.82億円、所得税11.05億円となった。これは1920年に既に2.5億円であった拠出金が1937年に減ることになり、「経済力に連動して定期改定」という設定と矛盾するため、AI 自身が退けた。[^p074]
* **修正案**（人口1人あたり0.50円、歳入の5%、家門所得の10%）では総額4.25億円で、国民純所得の1.27%となり、1920年の比率（200億円に対し2.5億円＝1.25%）とほぼ一致する。以後この係数が事実上採用された。[^p074][^p075]

当初案の段階では、人口・歳入連動分まで家門が負担するため、所得税が累進でも低所得の領主ほど負担率が高く、経営困難な中小領主は所得税を払わなくても拠出金を賄えない（負担率122%）という逆進性が明らかになった。[^p074]

## 負担主体の移行（P75）

ユーザーは「領国規模連動分は当初は家門、財政分離後は政府負担」とし、「支払能力のない領国に対する猶予や免除があってもよい」と決定した。[^p075]

| 負担項目 | 公私財政分離の前 | 分離の後 |
|---|---|---|
| 領国人口連動拠出金 | 領主家門 | 領国政府 |
| 領国歳入連動拠出金 | 領主家門 | 領国政府 |
| 家門所得連動拠出金 | 家門 | 家門 |
| 家門所得税 | 家門 | 家門 |
| 家門維持費 | 家門 | 家門 |
| 領国行政費 | 公私の区分が不明確 | 領国政府 |

[^p075]

1927年以降の公私財政分離は単なる会計処理の変更ではなく、「**法定拠出金の負担主体が領主家門から領国政府へ部分的に移る制度改革**」である。1927年以前は領主が統治の主体として拠出義務を負い、以後は領国政府が独立した財政主体として領国規模由来の公的負担を引き継ぐ。領主の身分に由来する所得連動の拠出義務は家門に残る。これで領主家の財政難と領国政府の財政難を制度上区別できるようになった。[^p075]

1937年の算定式は次のとおりである。[^p075][^p094]

* 領国政府拠出金 C_G = 0.5P + 0.05R（R は帝国からの財政援助・借入金収入を除く独自経常歳入）
* 家門拠出金 C_H = 0.10Y（所得が減れば自動的に減る）

## 猶予・減額・免除の制度

| 措置 | 想定する状況 | 内容 |
|---|---|---|
| 納付猶予 | 一時的な資金不足 | 期限を延期 |
| 分割納付 | 年度内の資金繰り難 | 複数年度にわたって納付 |
| 一部減額 | 継続的な歳入不足 | その年度の額を減らす |
| 全額免除 | 深刻な財政難・大規模災害 | その年度の義務を免除 |
| 滞納債務の整理 | 過年度分の累積 | 返済条件の変更・一部免除 |

（措置の段階は有力案。制度の存在は確定）[^p075]

適用理由の例は、金融恐慌、自然災害、凶作、主要産業の衰退、開拓初期の財政負担である。支払能力は F = R − E − D（R＝経常歳入、E＝必要な経常行政支出、D＝その年度の債務返済・利払い）で判定し、F が拠出義務額の100%以上なら全額納付、50〜100%なら一部猶予・分割、0〜50%なら減額・長期猶予、0%以下なら全額免除を含む財政再建措置とする。必要行政支出の認定は、支出の水増しによる義務逃れを防ぐため帝国側が審査する（有力案）。[^p075]

領国政府と家門は別々に審査される。黒田家が家産の大半を失っても領国の税収が健全なら領国政府は通常どおり納付し、井伊家のように富裕な家でも領国が災害で財政難になれば領国政府は減免を申請できる。家門から領国政府への任意の援助はできるが、私財による赤字補填は強制しない。[^p075]

決定権は、帝国議会が拠出率と減免要件を法律で定め、帝国政府が個別の財政状況を審査して減免を決め、領国政府・領主家門がそれぞれ申請し、帝国司法機関が紛争を審理する、という形に置かれた。元老院議員でもある領主が自家の免除を直接決められる制度にはしない（有力案）。[^p075] 拠出金の算定と減免は帝国政府、領国予算の編成は領国政府の権限である。[^p094] AI は「負担主体の移行と猶予・減免制度の存在は確定、減免率・財政審査基準・審査機関は暫定」と整理した。[^p075]

確定済みの累計60家の領主権奉還は変わらない。減免制度があっても財政再建できなかった家が奉還に至った、と解釈される。[^p075] この制度は1930年代に、財政力の弱い領国への恒常的な財政調整交付金制度（1937年度4.5億円）へ発展した（→[領国の類型・財政と財政調整交付金（1937）](fief-finance-1937.md)）。[^p075][^p095]

## 累進所得税（家門を一つの納税主体とする暫定モデル）

| 年間課税所得 | 限界税率 |
|---|---:|
| 500円以下 | 非課税 |
| 500〜2,000円 | 3% |
| 2,000〜1万円 | 5% |
| 1万〜5万円 | 10% |
| 5万〜20万円 | 15% |
| 20万〜100万円 | 20% |
| 100万〜500万円 | 30% |
| 500万円超 | 40% |

法定拠出金は義務的支出として課税所得から控除できると仮定する。家門構成員個人の就業所得は別に課税する。課税対象は配当、利子、経費控除後の地代・賃貸所得、海外資産所得（外国税額控除を考慮）、家門の直接事業所得で、未実現の評価益、家産の保有額、領国政府の税収は課税しない（有力案）。[^p073][^p074]

## 帝国財政に占める位置

拠出金の総額は、減免前で人口連動0.300億円＋歳入連動0.900億円（領国政府）＋家門所得連動3.045億円＝4.245億円。減免率は領国政府5%、家門1%と置かれ、**減免後は領国政府1.140億円＋家門3.015億円＝4.155億円**（国民純所得の1.25%、帝国経常歳入の7.34%）である。納付猶予は債務を消さないので別に管理する。[^p075]

1937年度の帝国経常歳入56.6億円のうち、領主家門所得税10.500億円（18.6%）、家門法定拠出金3.015億円（5.3%）、領国政府法定拠出金1.140億円（2.0%）で、領主・領国関係の歳入は合わせて約14.66億円（25.9%）を占める（税目内訳は暫定）。「領主階級は帝国財政にとって非常に重要な納税主体」である。帝国と領国の連結財政では、領国からの拠出金1.14億円は政府間移転として相殺される（→[1937年度の帝国財政と連結政府財政](public-finance-1937.md)）。[^p076][^p093]

# 史実との比較

* 史実の日本では廃藩置県（1871年）で藩の財政は政府に吸収され、旧大名の家計（華族の家政）は完全に私的な領域となった。統治と家産の分離は、統治権そのものの消滅によって一挙に起きた。
* 本世界線では統治権を残したまま、1920年代後半に会計・債務・承継を分ける形で分離が行われた。この点はドイツ諸邦で19世紀に進んだ君主の私的財産（家産・王室財産）と国家財産の分離に近い（編者による比較）。
* 史実の日本で富裕層への資産課税として実施されたのは、戦後1946年の財産税（一回限り）である。本世界線では1937年まで恒常的な資産保有税はない。

# 却下・修正された案

* **拠出金の当初案**（C = 0.2P + 0.01R + 0.05Y、総額1.82億円）: 1920年の2.5億円から減ってしまうため退けられ、修正案（0.5円・5%・10%）に置き換えられた。[^p074]
* **P76の所得税10.561億円**: P96の最終集計では財政総額に合わせて10.500億円とされた。P93の帝国歳入表も10.500億円を用いる。[^p076][^p093][^p096]
* **拠出の承認主体**: 前編では法定拠出の算定基準を「元老院が承認する」とされていた。[^u126] 会話ログ3では拠出率と減免要件を「帝国議会が法律で定め、帝国政府が審査・決定する」と置いた（有力案）。両者の関係（元老院の承認が両院の立法に置き換わったのか、元老院の承認と並存するのか）は整理されていない。[^p075]

# 未決の論点

* 249家それぞれに累進税率を適用した所得税の積上げ。配当所得税と法人税の二重課税の調整、外国税額控除。[^p073][^p096]
* 減免率（領国政府5%・家門1%）、財政審査の基準、審査機関の具体的な形。[^p075]
* 家門構成員・使用人の実人数、給与水準、維持費率（いずれも暫定）。[^p072]
* 資産課税の合憲性（憲法条文との厳密な照合は未了）。[^p073]
