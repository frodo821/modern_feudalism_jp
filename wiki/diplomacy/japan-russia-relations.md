# 概要

本世界線の日本にとって、列強のなかで最も怖いのはロシアであり、ロシアとの妥協の余地は他列強との関係を考えても広くない。[^u075] しかし同時に、ロシアと戦争しても日本が得られるものは何もない。[^u087] 日清戦争で「戦争は財布が痛いだけ」と学習した日本では、衆議院が沸騰することはあっても、元老院は「金がない」という現実を重く見て、先制的な対露戦争に踏み切らない。[^u088]

1889年の[下関条約](shimonoseki-treaty-1889.md)で遼東半島の割譲を求めなかったため三国干渉は起きず、日露関係を直ちに敵対に固定する事件も雪辱の動機も存在しない。[^u079] ロシアの南下は、まず清国に設定された英国の鉄道権益とぶつかり、朝鮮へ到達する前に英国の戦争許容度の方が先に上がる。[^u091] こうして本世界線の日露問題は、英露「グレート・ゲーム」の極東版として展開し、日本は有力な利害関係者でありながら軍事衝突の直接当事者にならずに済む。[^u090] **日露戦争（史実1904〜05年）は起きない。**[^u093][^u100]

1914年に欧州大戦が始まると、ロシアは連合国の一員として日本の軍需供給を受ける相手になるが、その供給はかえってロシア軍の消耗を長引かせ、帝国の崩壊を早める。革命後のロシアが戦時債務を否認すると、日本は債権者として損失を被る。[^u098][^u115][^u114]

# 対露認識と妥協の限界（1888〜1890年代前半）

## 地理的な脅威

ロシアは沿海州・ウラジオストクを拠点に朝鮮北部と接壌しており、清が北洋海軍を失えばロシアの南下に対する清の抑止力は下がる。日本が保障する朝鮮の独立はロシアの進出によっても脅かされる。日本が清に勝つほど強大なロシアが朝鮮北方に進出しやすくなるという矛盾がある。ただし1888年のロシアは極東での兵站が限られ（シベリア鉄道着工は1891年）、日本はロシアを最重要の長期的脅威と見ながら、当面はその兵站上の弱さを利用できる。[^u075]

## 交渉可能な事項と譲れない事項

1888年頃の対露交渉で、日本は商業的利益の容認と軍事力の招き入れを明確に区別した。[^n1][^u075]

| 事項 | 日本の態度 |
|---|---|
| 通商・金融協力（露系金融機関の対清借款参加・通常の商業） | 交渉可能 |
| 清国内の一般鉄道投資 | 条件次第 |
| 満洲横断鉄道 | 強い警戒 |
| 旅順・大連の租借 | 非常に受け入れにくい |
| 朝鮮の港湾・軍事顧問・駐兵権 | 朝鮮独立保障と正面衝突 |

対露妥協の限界は満洲より先に朝鮮で現れる。対露外交原則の案は「朝鮮王国の領土保全と政治的独立を尊重する。朝鮮国内に外国軍の恒久的な基地を設けない。日本の一時的な駐兵についても朝鮮政府との合意に基づく」というもので、日本自身の対朝鮮軍事政策にも制限を課さなければ国際的な説得力がない。清に勝った直後に戦果をロシアへ譲り渡すような妥協は元老院でも大反発を招く。日露対立は三国干渉を待たず、1880年代末の講和・賠償借款交渉から表面化しうる。[^u075]（→[日本の対朝鮮戦略目標](korea-strategy.md)、[朝鮮国独立保障（1884年）](korea-independence-guarantee-1884.md)）

対清賠償借款はロシアを排除した金融協定（英独米中心）を目指し、史実1895年の露仏借款に相当するものを起こさないことが講和外交の最大の成果とされる。[^u075]（→[対清賠償借款と講和の国際金融](../economy/indemnity-loan.md)）

# 三国干渉のない日露関係

| 論点 | 史実 | 本世界線 |
|---|---|---|
| 日清戦争の終結 | 1895年 | 1889年 |
| 三国干渉 | 遼東半島返還を要求 | 発生しない |
| 日本国内の反露感情 | 屈辱への反発 | 安全保障上の警戒が中心 |
| 朝鮮 | 戦後も列強の干渉にさらされる | 高宗の独立を日本が正式に保障 |
| 満洲 | ロシアの鉄道・軍港権益が拡大 | 英仏利権の先行で進出条件が変化 |
| 日露関係 | 1895年以降先鋭化 | 警戒と外交的妥協が併存 |

ロシアの南下政策そのものは変わらないが、三国干渉を通じた対清影響力の上昇という過程は存在しない。ロシアが旅順・大連を要求する際も、清との二国間交渉では済まず英国の利益と衝突しうる。[^u079]

日露間で最初に争われるのは朝鮮である。相互不占領原則の取決め案「朝鮮国の独立と領土保全を相互に承認し、朝鮮に外国軍の恒久的な軍港を設けない」があり[^n1]、これを結べば日本の駐兵にも期限・条件が必要になる。「満洲はロシア、朝鮮は日本」という勢力圏分割の妥協は、朝鮮を独立した通商相手として維持したい日本の方針に合わない。朝鮮の独立・中立を列強が共同保障する構想もある。[^n1][^u079]

## 元老院の対露三勢力

| 勢力 | 主張 |
|---|---|
| 対露牽制重視派 | 朝鮮独立保障・日本海と黄海の安全・陸海軍整備・日英協調 |
| 対露外交調整派 | 満洲の通商・鉄道で利益を調整し衝突を回避 |
| 財政・産業重視派 | 戦後財政と台湾開発を優先、軍拡競争に慎重 |

大領主は自領の産業発展を優先するため、長期の軍拡に反対する理由を持つ。[^n1][^u079]（→[元老院](../institutions/genroin.md)）

## 二段階の推移

1890年代前半はロシアへの警戒と外交的調整、1890年代後半はシベリア鉄道の進展を受けた安全保障上の対立、という二段階をたどる。[^n1] 史実の東清鉄道契約（1896）・旅順租借（1898）は三国干渉後の外交関係と結びついていたため、本世界線で同じ年に起きるとは限らない。[^u079]

# 日露の国力競争と東清鉄道

## 非対称な競争

日露の競争は最初から軍艦の建造競争にはならず、重点が非対称である。[^u084]

| 日本の重点 | ロシアの重点 |
|---|---|
| 日本海・黄海の制海権 | 極東艦隊の拡充 |
| 朝鮮の独立と親日的な関係 | 朝鮮への外交的影響力 |
| 鉄鋼・造船・機械工業の育成 | シベリア鉄道の建設と輸送能力 |
| 英仏の中国利権を利用した対露牽制 | 満洲の鉄道・港湾権益 |
| 国内の軍事輸送網 | 欧露から極東への兵員・物資輸送 |

日本はロシアが鉄道輸送能力を拡充するまでに外交上の現状を固定したく、ロシアは鉄道完成前の対日戦争に慎重になる。日本はロシア全体の経済力に匹敵する必要はなく、ロシアが極東へ投入できる戦力に対して十分な海軍力と継戦能力を持てばよい。ただし輸入資源と海上交通に依存するため長期戦は危険である。[^u084] 1900年に日本の粗鋼生産は100万t規模に達しうる（ロシアは約263万t）。[^u084]（→[重工業化と国力の推移（1870〜1930）](../economy/heavy-industrialization.md)）

## 最大の分岐：東清鉄道

日露関係の最大の分岐は、ロシアが満洲横断鉄道（東清鉄道）の権益を獲得できるかである。英系銀行団が1889年から賠償金融を主導し、山東・直隷の鉄道・港湾に英国権益が先行していれば、ロシアは史実と同じ条件では取得できない。ロシアの選択肢は次の三つとされる。[^u084][^u092]

* **A** 外交で満洲横断鉄道権益を獲得（日英が反対）
* **B** ロシア領内のアムール線を優先（費用・工期が大きく、日本に猶予）
* **C** 極東での軍事進出を抑え、海軍・商業で影響力を拡大（不凍港問題は残る）

ロシアには自国領内で極東まで鉄道を敷く能力はあったが、1890年代に短期間・低費用で実現する能力は乏しかった。本世界線のロシアは1889年時点で日本と戦っておらず、北回りを急ぐ財政的理由も弱い。ロシア政府内では「極東軍事重視派」と「財政重視派」の対立が起こりうる。東清鉄道は「ロシアの極東戦略全体の費用を大幅に下げる装置」であるためロシアは諦めきれず、英国権益を避ける独自の満洲横断ルートを交渉する可能性もある。失敗すればロシアの極東での軍事的発言力は長期間制約され、日本は戦争なしに朝鮮独立と北洋秩序を維持できる。[^n1][^u092]

ハルビン（哈爾浜）はロシアの勢力圏として史実どおりには成立しなかったとみられ、経路A（外交による満洲横断鉄道権益の獲得）は史実の形では実現しなかった公算が大きい。[^n2][^e021][^e024][^e025]

1890〜1905年の日露関係は、外交・金融中心の競争（経路A）、旅順・朝鮮をめぐる軍事危機（経路B、必ず開戦するわけではない）、満洲鉄道と清の政治危機の連動（経路C）が排他的でなく重なりうる。1904年を日露決戦の年とする必然性はない。[^u084]

# 対露抑止の体系

## 目的：ロシアに「得をさせない」

ロシアには賠償を確実に払わせる手段も、経済的に魅力ある割譲対象もない。極東のロシア領を占領してもロシア帝国は屈服せず、国境防衛の負担が増すだけである。そこで対露政策の目的は「ロシアを倒すことではなく、ロシアが現状を武力で変更しても得をしない状況を維持すること」に置かれる。[^u087]

抑止の手段は、日本海・黄海の有力な帝国海軍、朝鮮の独立保障と現地防衛能力、英国資本の北洋鉄道・港湾利権、日英の事前協議と共同外交、清の財政・行政の一定の安定、そしてロシア自身に平和の経済的利益を与える対露通商関係の維持である。原則は「ロシアの軍事的南下は阻止するが、通常の貿易や投資には門戸を閉ざさない」、すなわち**ロシアの経済的進出と軍事的南下を切り離す**ことにある。[^u087]

## 三層の対露抑止

対露抑止は次の三層で構成される。[^n1]

| 層 | 内容 |
|---|---|
| 第一層 | 朝鮮・清を自立した緩衝国家として維持する（清を弱く保つ政策から、清をロシアに依存させない政策へ） |
| 第二層 | 英国が単独で対露譲歩しにくい利害関係を作る（賠償借款・北洋鉄道・港湾特許を相互に関連させる） |
| 第三層 | 日本軍に「撃退できるが占領を目指さない」能力を持たせる（海軍・沿岸防衛・輸送力・通信・予備役重視） |

議会での論点は「ロシアに勝つための軍備が必要なのか、ロシアに戦争を選ばせないための軍備が必要なのか」となる。日露戦争を回避すれば戦費と人的資源を重工業・教育・交通網に回せ、戦争回避そのものが極めて大きな経済的成果になる。[^u087]（→[帝国軍](../military/imperial-army.md)）

## 英国権益への挑戦と日本の関与

「英国の権益を先に作ればロシアは手を出せない」という想定は危険で、ロシアは「満洲では我々の活動を認める代わりに長江流域では英国権益を尊重する」と英国に持ちかけうる（史実1899年英露鉄道協定）。[^u085] ただし、ロシアが英国権益を侵す場合に直接の当事者となるのは英国と清国であり、日本が単独で出しゃばる正当性はない。日本は英国に対露問題の主導権を取らせ、どこまで支援するかを交渉する。[^u089] 詳細は[日英協調](anglo-japanese-cooperation.md)を参照。

ロシアの行動段階と英日の立場は次のように整理される。[^n1][^u091]

| ロシアの行動 | 英国 | 日本 |
|---|---|---|
| 北満洲に独自鉄道 | 既存権益を侵さなければ交渉可 | 警戒するが介入理由は弱い |
| 英系鉄道・港湾を妨害 | 契約履行・投資保護を要求 | 英国の外交対応を支持 |
| 英国鉄道利権を強制接収 | 武力示威を含む強硬措置の理由が増す | 日英協議を重視 |
| 朝鮮への軍事介入 | 極東の勢力均衡問題として対応 | 独立保障という直接利害 |

この順序関係が成り立つ条件は、英国の鉄道権益が営口方面など南満洲まで実際に延びていることである。[^u091] 英露が正式に戦争すれば列強戦争の入口になりうるが、英国にも開戦回避の強い動機があり、日英協調は「共同でロシアと戦う」ためではなく「共同で対露戦争を回避しつつ既得権を守る」ための仕組みとして機能する。[^u090] ロシアが朝鮮独立に軍事介入しても、日本が戦って得る実利は「絶無」である。[^u091]

## 議会と戦争の財布

[元老院](../institutions/genroin.md)の領主議員は、自領の鉄道・製鉄所・港湾・学校・電力事業への投資を背景に、戦争の機会費用（鉄道建設の遅れ、資金調達難、労働力の軍への吸収）を具体的に計算できる。対露臨時軍事費の財源はどれも政治問題を抱える。[^u088]

| 財源案 | 問題 |
|---|---|
| 国税増税 | 衆議院が有権者に説明を迫られる |
| 帝国公債 | 将来の税収を拘束し公共投資の余力を減らす |
| 外国借款 | 対外債務と外交的依存 |
| 領国への追加負担 | 領主議員の反発 |
| 賠償金・交通整備基金の転用 | 約束済みの鉄道・道路・港湾事業の削減 |

「領主の財布と帝国の財布が別でも、資本市場は同じ」であり、帝国の借金増は国債金利を通じて領主系企業の資金調達にも響く。主戦派は「勝った後、戦費を何によって回収するのか」に答えねばならず、満洲・朝鮮を併合する意図のない日本ではそれが一層難しい。元老院の合意点は「軍備の維持・増強には賛成するが、先制的な対露戦争には反対する」となる。議会は「新たな利益の獲得には消極的でも、既存の利益が失われることには強く反応する」ため、ロシアが満洲鉄道権益を得ただけなら抗議・外交的対抗は支持しても開戦は承認せず、ロシア軍が朝鮮国境を越えるなどの事態で初めて状況が変わる。[^u088]

帰結として、「この世界の日本は、ロシアと戦えるだけの国力を育てることには積極的でも、実際に戦争することには非常に慎重な国家になる」。その理由は平和主義ではなく、世襲領主の経済的利害、議会の戦費審議、日清戦争での収益性の低さの学習にある。[^u088]

# 第一次世界大戦と革命期

## 連合国としてのロシア

1914年の日本は、対露関係よりも対英関係で参戦を判断する国家であり、ロシアは「まだ敵ではない」。[^u095] ロシアと戦っていない日本は、ロシアへの軍需輸出によっても英仏を支えられる。一方で日本は大戦中も北洋・日本海の防備に主力艦隊の大部分を保持し、ロシア極東艦隊への抑止を続けた。[^n1][^u098] 東清鉄道の取得が困難であったためロシアの極東鉄道輸送力は弱く、ウラジオストクから東部戦線への輸送がボトルネックになる。[^u100]

## 軍需供給の皮肉

日米の軍需供給はロシア軍の武器不足を改善するが、それは攻勢の継続と人的損耗の増大を招き、鉄道と農村労働力への圧迫を強めた。[^u114] 日本はロシアとの戦争を避け、1914年以降は連合国としてロシアに軍需品を供給したが、それが消耗戦を長引かせ帝国の崩壊を早めるという、日本政府が望まなかった結果を生んだ。[^u115] 詳細は[ロシア帝国の動揺と革命（1905〜1917）](../events/russian-revolution.md)を参照。

## 清朝崩壊と亡命皇帝の保護（1912〜1917）

1911年の革命で清朝が崩れると、退位しなかった清帝[溥儀](../people/puyi.md)はロシア帝国の保護下に入り[^e024]、1912年にウラジオストクへ亡命した。[^e025] 日露戦争のない本世界線では、ロシアは清朝皇室の受け入れ先として史実以上に重要な候補であった。ハルビンも候補に挙がったが、ロシアの勢力圏として成立していないとみられることから外された。[^e024][^e025]

ロシアにとって退位していない溥儀は、中国の正統な統治者としての権利を主張できる外交資産であり、復辟をすぐに支援しなくても、保護しておくだけで日英が支える北京政府への牽制になる。[^e024] ロシア帝国の対中政策は、北京とは別の中国政府を北方に確保することを狙い、主に満洲の清朝残存勢力、副次的に新疆・モンゴルを支援する。[^e023]

| 方式 | ロシアの関与 |
|---|---|
| 満洲に清朝残存政権が成立 | 外交・金融支援 |
| 満洲でも清朝が崩壊 | ロシア領内で皇室を保護（実現） |

[^e023]

日英も奉天の地方軍事政権との経済関係を維持しようとするため、満洲全体が親露政権になるとは限らない。満洲内部では、南満洲の親英的な地方軍事勢力、北満洲の親露勢力、清朝皇室を奉じる王党派が競合しうる。[^e023] 日本の対中支援は英国とほぼ共通（北京・両江・湖北）で、副次的に奉天と山東に置かれ、その目的には投資保護と並んで朝鮮の安全保障（対露牽制）が含まれる。[^e023] 詳細は[中国の軍閥と列強の支援配置（1912〜1930）](chinese-warlords.md)を参照。

1917年のロシア革命で、ロシアによる皇室支援は根本から崩れた。[^e023] ソ連は帝政の王朝支援を引き継がず、日英の既存秩序に対抗して南方の中華民国に接近し、新疆・モンゴル・中国共産主義勢力にも関与する。[^e023] 革命後の溥儀は、ロシア内戦を経て日本に再亡命したとみられる。[^n3] 日本は溥儀を皇族として待遇するが、皇帝としては承認せず、復辟運動も認めない。[^e024][^e025]

## 債権者としての日本

革命後のロシアが戦時債務を否認すれば、日本は損失を被る。本世界線の日本にとってソ連は地政学的な警戒対象であると同時に、「戦時債権の不履行という具体的経済問題を抱えた相手」である。[^u114][^u116] 日露戦争がないため日本は南樺太を取得しておらず、シベリア出兵も史実どおりとは限らない。そのため史実1925年の日ソ基本条約における北樺太撤兵と石油・石炭コンセッションの交換という問題は存在しない。日本は承認問題を、旧債務処理と通商再開（樺太・沿海州との通商）の交渉材料として利用した。[^n1][^u116] ロシアの安定は日本にとって必ずしも悪くなく、内戦で極東の統治が崩れれば沿海州・満洲の安全保障問題に日本が巻き込まれる。[^u093] 承認問題の詳細は[ソ連承認問題と旧ロシア債務](soviet-recognition.md)を参照。

# 史実との比較

| 事項 | 史実 | 本世界線 |
|---|---|---|
| 三国干渉 | 1895年、遼東半島返還 | 起きない |
| 対露感情 | 「臥薪嘗胆」型の雪辱と軍拡 | 安全保障上の警戒、軍拡には財政的歯止め |
| 東清鉄道 | 1896年敷設権獲得 | 英国権益の先行で取得条件が悪化。ハルビンはロシア勢力圏として史実どおりには成立しない可能性が高い[^n2] |
| 旅順・大連 | 1898年ロシアが租借 | 英国利益との衝突で同様に進むとは限らない |
| 日英同盟 | 1902年 | 1930年の日英海上通商防衛協定まで正式な防衛協定はない |
| 日露戦争 | 1904〜05年、戦費約17億円 | 起きない |
| 南樺太 | 1905年獲得 | 獲得していない |
| シベリア出兵 | 1918年〜 | 史実どおりとは限らない |
| 清朝皇帝の処遇 | 1912年退位、1924年に紫禁城を追われ日本公使館へ | 退位せず1912年ウラジオストクへ亡命、ロシア帝国が保護 |

史実の日露戦争の戦費は約17億円（開戦前5年間の中央政府平均年間一般支出の約6倍以上）で、約8割を国債等で調達し外国借款に大きく依存した。[^u088] 史実のシベリア鉄道はバイカル以東の区間を1895年に事実上棚上げし、1896年に東清鉄道を選択、日露戦争後の1908年にアムール鉄道建設を再開して1916年に全線ロシア領内経路を完成させた（1908〜16年の建設費約4億ルーブル）。[^u092]

# 編集注：未決の論点

* ロシアが東清鉄道の権益を獲得するか（A/B/C）、旅順など不凍港を獲得するか、アムール鉄道をいつ建設するか。[^u084][^u092] 会話ログ2で作者はハルビンが史実どおりには成立しない可能性が高いと判断し、Aの否定に傾いたが、正式な確定はない。[^e025]
* ロシア革命後の溥儀の処遇と再亡命先（日本が有力案だが保留）。[^e024][^e025]
* 英国の鉄道権益が北洋のどの路線（山東・直隷、山海関付近、営口など南満洲）まで延びているか。[^u091]
* 1890〜1905年の日露関係の三経路のいずれが主となるか、朝鮮の相互不占領取決めが成立するか。[^u079][^u084]
* 1869年憲法における開戦権限と戦費支出権限（緊急勅令による戦費支出の可否、戦時公債の議会同意要件）。[^u088]
* シベリア出兵の有無、日本の対露戦時債権の規模と処理。[^u116]

# 編集注：却下・修正された案

* **日本が英国権益保護の前面に立つ案**：英国に対露妥協を断念させるよう日本が強く関与し、権益保護の前面に立つという見方は、「直接権益を侵されるのは英国であり、日本が単独で出しゃばる正当性はない」との判断により修正された。日本が単独で軍艦派遣や最後通牒に踏み切れば、英国の商業問題が日露の軍事対立に変わり、ロシアに「日本が満洲に勢力圏を築こうとしている」と主張する材料を与えてしまう。[^u089]
* **1905年革命が起きないかもしれないという見通し**：日露戦争がなければ1905年のロシアの危機自体が起きないかもしれないという当初の見通しは、血の日曜日事件はほぼ確実に起きるという判断で修正された（→[ロシア帝国の動揺と革命（1905〜1917）](../events/russian-revolution.md)）。[^u093][^u112]
* **日英同盟を「存在するとは限らない」とする比較**：旧記述は史実との比較で日英の正式同盟の有無を不確定としていたが、会話ログ2で1930年4月21日の日英海上通商防衛協定と1932年の第一追加議定書が確定したため、1930年まで正式な防衛協定はない形に改めた（→[日英海上通商防衛協定と追加議定書（1930〜1937）](anglo-japanese-maritime-defense-agreement.md)）。
