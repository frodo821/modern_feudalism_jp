# 概要

本世界線の中華民国は、清朝崩壊後の1912年に孫文らが**広州で建国を宣言**し、以後広州を拠点として存続する共和政権である。[^e021][^e025][^e028] 史実の国民党のように一度全国政権を得てから南へ追われたのではなく、最初から華南の地方軍事勢力に依存する政権として出発した。[^e021][^e028] 日英が中国の対外代表として承認するのは北方の[中国諸省聯合](china-federation.md)であり、中華民国は「**成立しているが、中国全体を代表する国家としては成立していない**」。[^e025]

中華民国の正統性の根拠は革命と国民主権であり、統一を求める知識人・学生・青年軍人の支持を集める。[^e025][^e026] 米国・ドイツ・ソ連が支援し、1923〜24年のソ連援助による国民党改組を経て、1926年に蒋介石が[北伐](../events/northern-expedition.md)を開始した。北伐は湖南の大部分を得る部分的成功に終わり、中華民国は広東の地方政権から中国南部の有力政権へ成長したが、長江流域の主要な工業・金融都市を掌握できず統一は達成できなかった。[^e032][^e039]

1930年の中華民国は、聯合を「軍閥の寄せ集め」と批判しながら、自らも**国民党と地方軍閥の連合政権**へ変質していた。蒋介石の地位は動揺し、国共合作は正式に解消されないまま共産党の活動を制限する「制限付き合作」として続き、世界恐慌が脆弱な財政を直撃した。[^e036][^e039]

# 建国と初期（1912〜1925）

## 広州での建国

史実では1911年12月29日に南京の各省代表が孫文を臨時大総統に選び、1912年1月1日に中華民国臨時政府が成立した。建国宣言に清朝からの政権移譲は必要なかったため、本世界線でも孫文らは先に中華民国の建国を宣言した。[^n1][^e025] ただし南京の両江勢力が独自性を保ったため、建国の地は広州となった。孫文は臨時大総統を袁世凱に譲ることがなかった代わりに、自前の大軍も持たず、広東・広西・雲南の軍事勢力との協力を必要とした。[^e021] 南京は孫文の中華民国政府の所在地とはならなかったのである。[^e021]

## 孫文系と陳炯明系

広東の政治勢力は、陳炯明らの地方自治派（連省自治・連邦制、自治の相互承認）と、孫文系の統一派（統一共和国、主権回復の強い要求、他軍閥の統合・従属）に分かれる。[^e022] 孫文系は最初から債務の全面否認派ではなく、資本・技術の導入は必要としつつ、国家統一や財政自主権を妨げる外国権益の見直しを求める。ここに米国が関与する余地がある。[^e022]

1922年頃、孫文と陳炯明は史実どおり決裂した。決裂は史実以上に起きやすい状況にあった。陳炯明は連邦的共和国、聯合との交渉・協力、地方軍権の維持、北伐への消極を志向し、聯合への参加を検討することすらあり得る（加盟は別問題）。[^e028]

## 国民党改組と黄埔

1923〜24年、ソ連の援助で国民党が改組され、党直属の軍事教育機関（黄埔軍官学校に相当）が設立されて蒋介石が校長となる（史実に準じる）。[^e028] 蒋介石は日本で軍事教育を受けて孫文に参加する経路を維持するが、青年期の日本の政治環境は史実と異なる。[^e028] 1925年に孫文は史実どおり死去した。[^e027][^e028]

| 後継候補（1925年） | 年齢 | 基盤 |
|---|---:|---|
| 蒋介石 | 37 | 黄埔・党軍 |
| 汪兆銘 | 41 | 党組織 |
| 胡漢民 | 45 | 右派・広東政界 |
| 廖仲愷 | 47 | 財政・左派 |
| 陳炯明 | 47 | 広東地方軍・自治派 |
| 李宗仁 | 33 | 広西 |

後継争いでは軍権を持つ者が優位に立った。[^n1][^e028]

# 外国の支援

列強の支援先は政体ではなく、どの地域に既存権益を持ち、どの政権を通じて将来の権益を広げられるかで決まる。日英が既存の契約・債権・投資を守る側、米独が英国中心の秩序を再編して新市場を得る側である。[^e023][^e024]

| 支援国 | 内容 | 目的 |
|---|---|---|
| 米国 | 民間融資・通商・外交支援（政府の積極的軍事援助までは不要） | 門戸開放、既存権益の再編 |
| ドイツ | 工業技術・軍事顧問・装備輸出（1919〜33年に接近） | 市場への再進出 |
| ソ連 | 軍事顧問・政党組織・軍事教育 | 革命運動の拡大、日英秩序への対抗 |

[^e023][^e028]

米国は孫文系を政治的に支援するが債務の全面否認は支持せず、政治的統一・通商機会均等・外国企業の差別的特権の撤廃・既存債務の合理的整理・米国企業の新規投資の保障を条件とする。[^e023] 米独とソ連が同じ南方政府を支援するという一見奇妙な構図であり、三者の最終目標の違いから政権内部に外交路線の対立が生じる。[^e023] 米独の支援があるため、国民党は史実よりソ連への依存度が低くなる可能性があった。[^n1][^e028] なおフランスは、南方共和政府による雲南・広西の統合を望まず、既存契約を守る滇系・桂系を支援するため、華南の軍閥がすべて中華民国陣営に入るとは限らない。[^e023]

# 地方軍閥との関係

| 地方 | 立場（1925年頃） |
|---|---|
| 広西・新桂系（李宗仁・白崇禧・黄紹竑） | 中華民国に参加するが独自の軍隊・財政を維持する「準加盟勢力」 |
| 湖南 | 聯合寄り中立。帰属は北伐そのものによって決まる |
| 雲南（唐継堯、のち龍雲ら） | どちらにも従属しない独立した連邦主義勢力。フランスとの経済関係 |
| 福建 | 中立〜中華民国寄り（華僑・沿岸貿易）、日英通商も重要で内部分裂 |

[^e030][^e032]

広西は財政が弱く広東と結びつき、全国政治への進出が魅力となる。[^e030] 1926年の湖南政変で唐生智が中華民国に参加し、湖南の大部分が北伐で中華民国に帰属した。[^e031][^e032] 詳細は[北伐と湖南内戦](../events/northern-expedition.md)および[中国の軍閥と列強の支援配置](chinese-warlords.md)を参照。

# 蒋介石と北伐後の政権

## 不安定な軍事指導者

蒋介石は1926年に軍事的主導権を得て北伐を開始し、中華民国の実質的な軍事指導者となった。[^e028][^e032] しかし北伐で南京・上海の財政基盤を獲得できず、広西軍・湖南軍への依存度が高く、ソ連の援助も必要である。**軍事的主導権はあっても他勢力を排除できるほどの権力はない**。[^e036] 1930年時点で蒋介石の地位は動揺している。[^e039]

## 派閥構造（1928年頃）[^n1]

| 派閥 | 指導者 | 基盤 | 志向 |
|---|---|---|---|
| 黄埔系 | 蒋介石 | 党直属軍 | 軍権の中央集権化 |
| 新桂系 | 李宗仁・白崇禧 | 広西軍 | 軍事・政治的自主権 |
| 湘軍系 | 唐生智 | 湖南軍 | 湖南支配権の維持 |
| 国民党左派 | 汪兆銘 | 党組織 | 党による軍事指導 |
| 国民党右派 | 胡漢民 | 広東政界 | 反共・党統治 |
| 広東地方勢力 | 陳済棠ら | 広東 | 広東の利益 |
| 共産党 | 陳独秀・周恩来ら | 都市労働運動 | 社会革命・合作維持 |

[^e036]

蒋介石と新桂系の対立は、北伐が未完であるため、史実（1929年蒋桂戦争、1930年中原大戦）のような軍縮・編遣を名目とするものではなく、**限られた軍事予算の配分**が争点となった。[^n1][^e036] 1929年頃には蒋介石が一時的に軍事最高指導者の地位を辞任し、湖南の軍権問題も絡んだ蒋桂戦争相当の限定的内戦でも、蒋介石は決定的な勝利を得られなかったとされる。[^n2][^e036]

## 恐慌と財政

中華民国の財政は、広東の貿易収入、海外華僑の送金、湖南・広西の地方税収、外国融資に依存し、聯合以上に脆弱である。世界恐慌は税収減少、軍人給与の支払い困難、北伐継続能力の低下をもたらした。[^e036][^e039]

# 中国共産党

## 成立と支持基盤

中国共産党は1921年頃、史実に近い形で成立する。ロシア革命は起きており、陳独秀・李大釗らがマルクス主義に接近する経路は残るからである。[^e029] しかし1920年代後半の勢力分布と国民党との関係は大きく変わる。

| 地域 | 支持基盤 | 帰属 |
|---|---|---|
| 上海 | 紡績・港湾・外国企業の労働者 | 聯合 |
| 武漢 | 製鉄・兵器工業・鉄道 | 聯合 |
| 天津 | 港湾・工業・鉄道 | 聯合 |
| 北京 | 大学・知識人 | 聯合 |
| 広州 | 港湾・労働運動 | 中華民国 |
| 湖南 | 農民運動 | 非加盟→中華民国 |
| 江西 | 農民運動 | 帰属未確定 |

[^e029]

共産党は**中華民国と協力しながら、その支持基盤の多くは敵対する聯合の領内にある**。日英資本による工業化が史実以上なので五・三〇事件型の事件はむしろ起こりやすいが、聯合が外国企業との契約履行のため労働運動を厳しく取り締まるため、支持基盤の拡大と組織拡大の阻害が同時に起きる。[^e029] 1919年前後の学生運動（五四運動相当）は、反日よりも列強の既存権益の処理（特に英国・日本）と「聯合体制」への反対の性格が強い。[^e029][^e038]

## 制限付き国共合作

北伐で中華民国が上海を掌握しないため、史実の上海クーデター（1927年）は起きない。しかし湖南を占領した時点で、唐生智・李宗仁ら地方軍事指導者は急進的な土地改革を認められず、国共対立は発生する。[^e032] そこで1927年頃、国民党が共産党の活動を大幅に制限しつつ正式な合作解消には至らない「**制限付き合作**」が成立した。[^e032][^e036]

| 項目 | 1927年以降の取り決め |
|---|---|
| 共産党員の国民党参加 | 継続 |
| 国民革命軍内での政治活動 | 制限 |
| 独立した共産党軍 | 原則禁止 |
| 労働組合 | 条件付きで容認 |
| 農民組合 | 容認するが武装化を制限 |
| 土地改革 | 地代軽減などに限定 |
| 聯合領内での政治運動 | 国共双方が継続 |
| ソ連の軍事援助 | 継続 |

[^e032]

合作は政権内部の権力闘争に巻き込まれる。蒋介石は軍事的必要から限定的に維持、李宗仁・白崇禧は地方での活動を警戒、唐生智は湖南の農民運動への対応を優先、汪兆銘は合作維持で党内発言力を確保、胡漢民は合作解消を要求、共産党内では穏健派が維持、急進派が独自革命路線を唱える。制限付き合作は**繰り返し破綻の危機を迎える政治的妥協**である。[^e036]

## 1930年の共産党

| 項目 | 状態 |
|---|---|
| 党員数 | 5〜10万人 |
| 政治活動の拠点 | 広州・湖南 |
| 都市地下組織の中心 | 上海・武漢・北京 |
| 独立した大規模な紅軍 | 未成立 |
| 国民党左派 | 協力関係を維持 |
| 党内 | 農村革命派と都市革命派の路線対立 |
| 毛沢東 | 有力な農民運動指導者だが党全体の最高指導者ではない |

[^e029][^e032]

「**史実より工業労働者の潜在的支持基盤が大きく、史実より独立した軍事力が小さい中国共産党**」である。[^e029] 共産党は独立した領域支配勢力というより、各陣営を横断する革命運動として存在する。1929年以降の恐慌で日英系企業の操業縮小・人員整理が進めば支持が急拡大し得るし、聯合領内の労働争議が増えれば国民党にとっての共産党の政治的価値は再び高まる。[^e032][^e039]

# 1930年の中華民国

| 項目 | 状態 |
|---|---|
| 政治的中心 | 広州 |
| 支配領域 | 広東・広西・湖南の大部分 |
| 統治理念 | 共和革命・国家統一 |
| 体制 | 国民党と地方軍閥の連合政権 |
| 最高指導者 | 蒋介石（地位が動揺） |
| 財政基盤 | 脆弱かつ戦費負担が重い |
| 軍事力 | 党軍と地方軍の対立 |
| 外国支援 | 米国・ドイツ・ソ連 |
| 共産党 | 制限付き国共合作 |
| 最大の問題 | 財政難と政治的分裂 |

[^e039]

内部対立は、蒋介石と新桂系・湘軍系の軍権争い、国民党の左右対立、国共合作をめぐる対立、北伐継続派と国内整備優先派の対立、恐慌による歳入・外資の減少である。[^e036][^e039] 聯合と同じく、中華民国が統一を実現できない理由は相手の強さだけでなく**自陣営の政治構造そのもの**にある（中華民国は国共合作と地方軍閥の独立性を解消できない）。[^e032]

# 1930年代の展開

* 1930年代初頭、中華民国は軍需・交通・工業設備の市場として米独・ソ連と結びついた。[^n1][^e046]
* 1933年のナチス政権成立後、ドイツにとって中華民国は「史実以上に重要な」接近可能国の一つとなる。中独には民国の工業化、外国権益の再編、ドイツ製品の市場、中国産資源の貿易、日英秩序への対抗という共通利益がある。ただし民国はソ連援助と共産党の組織力を必要とし、蒋介石も史実ほど強固でないため、ドイツが反共を求めれば内部対立が激化し、**ナチス政権の成立が国共合作を再び破綻の危機に追い込む外的要因になる**可能性があった。[^n1][^e055]（→[1933年の国際秩序再編とナチス・ドイツ](../events/nazi-germany-1933.md)）
* 1932年末時点でも、聯合と中華民国の軍事的膠着と制限付き国共合作は続いていた。[^e054]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 建国 | 1912年1月1日、南京で臨時政府 | 広州で建国宣言、以後広州が拠点 |
| 孫文 | 臨時大総統を袁世凱に譲る | 譲る相手がおらず、華南軍閥に依存 |
| 北伐 | 1926〜28年、武漢・南京・北京を掌握し形式的統一 | 湖南の大部分を得るが湖北・江西方面で膠着 |

| 共産党員 | 1930年122,318人（集計法により差） | 5〜10万人 |

* 1929年に蒋桂戦争相当の武力衝突が実際に起きるか、蒋介石が一時辞任するか（いずれも検討案）。[^e036]
* 国共合作が1930年代に完全に決裂するか、共産党の路線対立の行方。[^e032][^e055]
* 江西・福建の最終的な帰属。[^e032]
* 1937年時点の中華民国の政治・経済・軍事。[^e103]

# 編集注：却下・修正された案

* **共産党員数の他案**：早期の国共分裂（3〜8万人・地下組織・農村革命）、合作継続・労働運動拡大（10〜20万人・大衆政党）の二案は採られず、「合作継続・聯合による弾圧」の5〜10万人案が採用された。[^e029][^e032]
* **国共合作の全面決裂**：史実型の決裂ではなく、正式解消なしの制限付き合作とされた。[^e032]
