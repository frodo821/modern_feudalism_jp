# 概要

対馬宗家は室町時代以来、日朝外交・貿易の窓口を世襲してきた家であり、本世界線では1866年の所領安堵によって対馬の世襲領主権を憲法上保障されたまま明治の新体制に入った。このため、宗家が朝鮮に対して事実上「日本国の代表」を僭称し続けていることが、帝国の対朝鮮戦略における最大の問題となった。[^u038]

史実では1871年の廃藩置県で対馬藩が消滅し、宗家の家役も自然に解かれたが、[廃藩置国](../institutions/kokugun-system.md)によって[領主権](../institutions/lordship-rights.md)が存続する本世界線ではこの解決策が使えない。帝国政府は「宗家から奪うのは領主権ではなく外交権である」という整理を採り、[元老院](../institutions/genroin.md)の政治的圧力と経済的補償を組み合わせて、1867〜1869年のうちに宗家の朝鮮通交家役を接収した。[^u038][^u039]

この結果、国内の外交権一元化は史実より早く完了したが、それは同時に朝鮮側から見て長年機能してきた外交経路の一方的な変更でもあり、[日朝国書問題](japan-korea-relations-1870s.md)を史実より早く表面化させる要因となった。[^u039][^u040]

近代外交制度の成立後、宗家は対朝鮮外交で特別な役割を保つことができず、外交機能は完全に帝国政府へ移った。[^n2] 一方、朝鮮が併合されず独立国として存続する本世界線では、宗家の対朝鮮商業網・朝鮮語人材・現地の信用関係が近代以降も経済的な価値を持ち続けた。宗家は対朝鮮貿易商社と朝鮮での銀行・為替・貿易金融に成功し、1937年には「領国の経済規模に比べて海外資産の比重が極めて大きい、対朝鮮特化型の国際商業金融資本」となっている（後述の「近代の宗家（1870〜1937年）」節）。[^p063]

# 問題の所在

## 「誰が日本国を代表するのか」

1866年に将軍の軍事権が朝廷へ移り、1867年に天皇を中心とする政府が成立したにもかかわらず、朝鮮外交だけは宗家の世襲的な家役として残っていた。これは国家制度上の大きな矛盾であり、本世界線の日清戦争前史で最初に解決すべき問題は、朝鮮の開国ではなく「日本国内で誰が日本国を代表するのか」という問題だったとされる。[^u038]

宗家は単なる窓口ではなく、長年にわたり日朝間の国書を操作し、中央政権の意思が朝鮮側へ伝わる過程を事実上支配してきた家である。他方、近世後期の宗家は幕府から家役として正式に委任された窓口でもあり、問題の核心は「外交特権が世襲化し、宗家の領主としての利害や朝鮮貿易と一体化していたこと」にある。[^u038]

## 宗家の権限の切り分け

帝国政府は宗家が保持してきた権限を次のように区分した。[^u038]

| 宗家の権限 | 新政府による扱い |
|---|---|
| 対馬の世襲領主権 | 憲法によって保障 |
| 朝鮮との通商に関する既得権 | 補償・再交渉の対象 |
| 朝鮮語通訳・外交官僚の組織 | 外務官庁へ移管可能 |
| 朝鮮への日本国代表の派遣権 | 中央政府が接収 |
| 国書の作成・修正・発給 | 中央政府の専権 |

これにより1866年の所領安堵を破棄する必要はなく、宗家は対馬の領主として残り、元老院へ領主議員を送ることもできる。ただし朝鮮への使者は宗家の私的な使者ではなく、帝国政府が正式に任命した外交官でなければならない。[^u038]

## 「人材登用」と「家への外交特権」の区別

宗家当主を「朝鮮国外交総督」のような官職に任命するだけでは、国書の内容・使節の人事・通商利益を宗家が引き続き掌握し、独占構造が温存される。そのため、宗家出身者を外交官に登用する場合でも任期を設け、外務官庁の訓令に服させ、中央政府が罷免できるようにする。こうして「宗家の人材を登用すること」と「宗家という家に外交特権を認めること」を明確に区別した。[^u038]

# 経過

## 元老院における宗家の孤立

この問題では中央政府と他の領主たちの利害が一致した。宗家だけが朝鮮外交を世襲的に独占し、日本国を代表するかのように振る舞うことは、他の領主から見て面白くない話であり、宗家に政治的圧力をかけて受け入れさせることは十分に可能だった。[^u039]

- **島津家・毛利家**：宗家の朝鮮外交独占に特別な利益はなく、むしろ自らの通商・外交政策を妨げうる。
- **徳川宗家**：将軍家として外交権を失っている以上、旧幕府の委任先にすぎない対馬宗家だけがそれを維持するのは説明しにくい。
- **領主権の擁護者一般**：「宗家の対馬領主権」と「宗家の朝鮮外交特権」は別物であるという論理は、むしろ領主権を守りたい側こそ支持しやすい。領主権とは別の特権を整理することに賛成できるからである。

こうして元老院では「**諸侯の領主権は保障する。しかし、外国との交渉は帝国政府の専権である**」という原則が支持を集め、これを覆そうとする宗家の方が例外的特権を要求する立場に追い込まれた。[^u039]

## 外交事務統一例

1868年（本世界線の明治2年）、元老院は宗家を名指しせず、一般原則として外交権の一元化を定める「例」を制定した。[^n1][^u039]

> **外交事務統一例**
> 第一条　帝国ノ外国交際及条約締結ノ権ハ中央政府ニ属ス。
> 第二条　諸侯ハ帝国政府ノ委任ナクシテ外国政府ト国交ヲ結ビ、又ハ帝国ヲ代表スルコトヲ得ス。
> 第三条　従前ノ家役ニ依リ外国交際ヲ担当セル諸家ノ権限ハ、帝国政府之ヲ承継ス。
> 第四条　前条ニ依リ家役ヲ廃止セラレタル諸家ノ既得ノ財産及通商上ノ利益ニ付テハ、別ニ例ヲ以テ補償ヲ定ム。

一般原則の適用として宗家の家役を整理するため、宗家を処罰する必要がなく、他の領主も自らの領主権が直接脅かされない限り反対する理由が乏しい。[^u039]

## 補償付きの家役返上

宗家との取引は「**宗家は外交上の世襲特権を返上する。新政府は対馬の領主権を再確認し、従来の通商収益の一部に相当する補償を与える**」という形で整理された。[^n1] 宗家が育成した朝鮮語通詞や外交実務官僚は中央政府が採用し、宗家の人物を正式な外交官や対朝鮮政策顧問として任用することも構想された。宗家は制度上の独占権を失っても、経験と人脈による影響力は残るとみられていた。[^n1][^u038][^u039] しかし実際には、帝国政府の外交権の下で宗家が仲介・通訳・外交実務に継続的に関与することはできなかった。[^n2] 外交実務を担った人材の多くは、宗家系の貿易商社・金融機関へ移った。[^p062][^p063]

宗家は1868年頃に自ら家役返上を申し出、新政府は領主権の保障と対馬の財政支援を約束した。[^n1] 元老院に味方がほとんどいない以上、宗家にとっては特権に固執するより、返上によって有利な条件を確保する方が合理的だったからである。[^u039]

## 最初の政治危機としての経過

1867〜1869年の宗家問題は、本世界線の対朝鮮政策における「最初の政治危機」として次のように推移した。[^n1][^u038]

1. 新政府が宗家に朝鮮外交の家役返上を求める。
2. 宗家は領主権の保障を根拠に、従来の外交・通商上の権利を主張する。
3. 元老院で「外交権は中央政府の専管」とする勢力と「宗家の世襲的権利を保護すべき」とする勢力が対立する。
4. 最終的に外交権を中央政府が接収し、宗家に一定の経済的補償を与える。
5. 新たな朝鮮使節を派遣するが、今度は外交文書の形式をめぐって朝鮮側と対立する。

# 帰結

- **国内の外交権一元化の早期完了**：史実より早く一元化が完了し、1870年代には朝鮮王朝が新しい帝国政府と直接向き合うことになった。[^u039]
- **日朝関係の早期悪化**：朝鮮側にとっては宗家こそが正規の窓口であり、宗家が領主として存続している以上、従来どおり宗家を通じて交渉したい理由がある。外交権の接収と「皇」「勅」を含む新しい国書形式の採用が重なり、国書問題は1867〜1869年に表面化した。「国内では外交一元化に成功したのに、朝鮮との関係では従来の外交秩序が崩れる」という逆説である。詳細は[日朝国書問題と1870年代前半の日朝関係](japan-korea-relations-1870s.md)を参照。[^u038][^u040]
- **中央政府の直接責任**：宗家の家役が失われたことで、交渉停滞の責任を中央政府が直接負うことになった。諸領主からは「外交権を中央へ集中させたのに、朝鮮との関係すら正常化できないのか」と批判されうる立場となり、これが[征韓論争](../events/seikanron-debate.md)や[江華島事件](../events/ganghwa-island-incident.md)へ向かう軍事的圧力の誘因となった。[^u041][^u046]
- **原則の継承**：「民間の商業・技術交流は奨励しつつ、外国政府との政治交渉は中央政府の専権」という区別は、のちに[岩倉使節団](../events/iwakura-mission.md)以後、各領主家が海外に独自の人脈を持つようになった際にも境界線として用いられる。[^u043]

# 近代の宗家（1870〜1937年）

## 爵位と位置づけ

対馬宗家は表高が小さい一方、10万石以上の格式を持ち、対朝鮮外交・貿易を含む領国の特殊性があるため、1867年華族令では石高基準で処理できない個別審査の家とされ、伯爵に叙せられた。[^n3][^p017] 詳細は[1867年華族令と初叙爵](../institutions/kazoku-ordinance-1867.md)を参照。宗家は、1937年の経済力と元老院勢力を見るうえで個別に経済史が詳述される主要25家の最後の家である。[^p062]

## 経済史の成否

宗家は石高や国内産業の基盤より、朝鮮との歴史的な外交・商業関係が重要な家である。その近代の経済史は、次の各項目の成否によって形づくられた。「外交上の特別な役割」は独自の外交権の保有ではなく、帝国政府の外交権の下で仲介・通訳・外交実務に継続的に関与できるかを問う項目である。[^n4][^p062]

| 事項 | 結果 |
|---|---|
| 幕末の累積債務を1870年代までに整理する | 失敗[^n14] |
| 既存の商業・専売事業を近代企業へ転換する | 成功[^n15] |
| 1889年までに有力な近代工業資本を形成する | 失敗[^n16] |
| 独自の銀行・金融機関を発展させる | 失敗[^n17] |
| 北海道開拓から大きな経済的利益を得る | 失敗[^n18] |
| 第一次世界大戦の経済成長を長期資産形成につなげる | 失敗[^n19] |
| 海外投資・国際金融への進出に成功する | 成功[^n20] |
| 1927年以降の金融危機で大規模な資産毀損を回避する | 失敗[^n21] |
| 旧来の対朝鮮商業網を近代的な貿易商社へ転換する | 成功[^n22] |

| 朝鮮の鉱業・農業・工業への直接投資に成功する | 成功[^n25] |
| 対馬の水産業・水産加工・林業を大規模に資本化する | 失敗[^n26] |
| 中国・ロシア極東まで商業網を拡大する | 失敗[^n27] |
| 近代外交制度の成立後も対朝鮮外交における特別な役割を維持する | 失敗[^n28] |
| 九州北部・朝鮮海峡周辺の中小領主を包含する金融圏を形成する | 失敗[^n29] |
| 黒田家などの九州大領主から経済的・政治的に独立した勢力を形成する | 失敗[^n30] |

## 外交主体から国際商業資本へ

宗家の外交機能は帝国政府へ移管されて特別な役割は消え、商業機能は民間企業へ転換されて対朝鮮商業網を引き継いだ。こうして生まれた宗家系の貿易商社・金融機関は、日本と朝鮮の二国間経済関係に特化している。[^n5][^p063]

- **国内銀行の失敗と朝鮮金融の成功**：国内の預金銀行の形成には失敗した[^n6]が、朝鮮での銀行・為替・貿易金融には成功した[^n7]。宗家は朝鮮の有力金融機関への出資・経営参加、朝鮮の商人・実業家との共同出資による金融機関、日朝間の貿易金融を専門とする会社を発展させた。日朝間の為替取引と貿易手形・信用状が主力で、朝鮮企業への融資も有力、朝鮮の企業・土地への投資も一定規模に達するが、中国・ロシア向けの金融は限られる。[^p063]
- **朝鮮の主権**：朝鮮は独立国であるため、宗家の朝鮮事業は朝鮮政府の法令・金融制度に従う。日本の領主権は朝鮮国内には及ばない。[^p063]
- **領国経済と家産の乖離**：宗家は対馬の水産業・林業の資本化にも失敗しており、主要25家の中で領国経済と家の経済力が最も乖離した家の一つである。対馬の領国は農林水産業・港湾の地域商業・地方金融と領国税収に依拠し、宗家の私的な経済基盤は国際貿易商社と朝鮮での金融事業、その主な所得は国際商業利益と海外資産所得である。当主の居所は対馬の厳原に残しつつ、主要企業の経営拠点は釜山などに置く。福井松平家の北海道移転とは異なり、外国に経済的な本拠を持つ特殊な領主家である。[^p063]
- **金融危機**：1927年以降の金融危機では資産毀損を回避できなかった。[^n8] 損失の中心は、朝鮮向け融資の不良債権化、海外企業持分の評価損、貿易の縮小、為替変動である。国内銀行への依存度が低いため、最大実質純資産毀損率は15〜25%程度とされる。[^n9][^p063]

家産所得構成は、朝鮮での銀行・為替・貿易金融36%、日朝貿易・商社25%、朝鮮の鉱工業・農業への直接投資18%、日朝間の海運・港湾物流10%、その他の海外証券・金融資産6%、国内の不動産・農林水産業3%、公債・その他2%で、日朝関連が89%を占める。[^n9][^p063] 1937年の米穀輸入（85万t、輸入先は朝鮮・中国・東南アジア）には、宗家の商業金融網が関与する可能性がある。[^p088]

## 金融圏と政治的位置

- 宗家は独自の領主金融圏の形成にも、九州大領主からの独立にも失敗した。[^n10] そのため黒田家との関係が重要になる。黒田家は宗家の朝鮮での商業・金融網を利用し、宗家は黒田系金融機関から国内での資金調達や信用保証を受ける。宗家の所属先としては黒田系（北部九州系）金融圏が第一候補であるが、黒田家自身が金融危機で大打撃を受けたため、1937年の所属は確定していない。[^n11][^p063][^p077]
- 北部九州系金融圏は黒田家・宗家を中核とし、所属家数は1927年17家→1937年6家に減った。[^n11] 1936年の元老院改選では7家で3議席を得た。[^n12][^p077][^p078]
- 元老院の倶楽部では、徳川系・旧来大領主の宗交会に属する。[^n13][^p079] 黒田家については[九州の領主家](../people/houses-kyushu.md)を参照。

# 編集注：却下・修正された案

- **宗家の外交ネットワークをそのまま利用する案**：当初は、旧幕府外交官僚と宗家が残っている以上、宗家を通じた漸進的な外交正常化が可能と考えられていた。しかし宗家が日本国の代表を僭称してきたこと自体が問題であるとの指摘を受けて撤回され、外交権の接収が前提となった。[^u037][^u038]
- **宗家当主を「朝鮮国外交総督」に任命する案**：宗家の経験を活かしつつ外交権を中央へ移す形に見えるが、国書・人事・通商利益を宗家が引き続き握れば独占構造が変わらないため、不十分とされた。[^u038]
- **宗家人物の外交官・顧問への任用による影響力の維持**：家役返上後も宗家の人物が外交官や対朝鮮政策顧問として影響力を保つ筋が想定されていた（検討案）。会話ログ3では「近代外交制度の成立後も対朝鮮外交における特別な役割を維持する」がダイスで失敗し（難易度50、出目36）、宗家の外交上の特別な役割は消滅したとされた。宗家の対朝鮮関係は外交ではなく商業・金融の面で存続する。[^u039][^p063]
