# 概要

本世界線では、1889年の[下関条約](/diplomacy/shimonoseki-treaty-1889.md)と[対清賠償借款](/economy/indemnity-loan.md)を契機に、史実で1897〜1899年に起きた列強による中国利権の争奪が、1888〜1890年代前半へ約7年前倒しされる。[^u074] 日本の戦勝が、列強による中国大陸の経済的分割を加速させるという皮肉な展開である。[^u074]

日本はこの過程で、ロシアに取られたくない地域へ先に別の列強の権益を設定する「既成事実化」を外交方針とした。イギリスを北洋（山東・直隷）へ、フランスを華南（雲南・広西）へ誘導し、ロシアの南下を英国の既得権と衝突させる構造を作ったのである。[^u076][^u077] 一方で日本自身は中国大陸に直接かつ独占の利権を持たず、その空白はイギリスが埋める。日本は英国の金融・通商秩序を通じて中国経済に参加する立場をとった。[^u102]

# 利権拡大の構造

## 二種類のコンセッション

| 種類 | 内容 | 史実の例 |
|---|---|---|
| 領域的コンセッション | 租界・租借地・港湾区域など、外国が一定地域の行政・警察・司法、場合により軍事施設を管理 | 上海租界、膠州湾、旅順、大連 |
| 経済的コンセッション | 鉄道建設・運営権、鉱山採掘権、港湾経営権、税収担保権など。清国の名目上の領土主権は維持 | 各国の鉄道・鉱山権益 |

[^u074]

本世界線では、最初に膨張するのは経済的コンセッションである。銀行団が清国に巨額の融資をする際に必要なのは、まず確実な返済財源だからである。[^u074]

## 段階的展開（検討案）

| 時期 | 展開 |
|---|---|
| 1888〜1889年 | 海関収入の担保化。賠償借款の返済に海関収入の一部が長期に充当される |
| 1889〜1891年 | 海関だけでは担保が足りず、塩税・厘金などへの担保設定や外国金融機関による徴収監督が問題化 |
| 1890年代前半 | 列強の銀行・企業による鉄道・鉱山・港湾の事業権獲得競争 |
| 1890年代中盤以降 | 港湾防衛や商業保護を理由とする租借地要求の可能性 |

[^u074]

この結果、1895年の時点で清国の鉄道・鉱山・海関には史実の同年よりはるかに広範な外国権益が形成され、1890年代半ばには史実の1890年代末に近い利権構造がすでに存在しうる。ただし、利権が「早く」拡大しても、最終的な「総量」が史実より大きくなるとは限らない。列強は互いの進出を警戒し、相互に認め合った勢力圏の内部で利権を拡大する形をとるからである。[^u074]

## 最大の逆説

清国は日本への賠償を支払うために、税収・鉄道・鉱山という統治権を削られる。賠償借款の返済のため将来の税収まで拘束され、史実より早く清朝への政治的不満が高まり、改革運動や反外国勢力運動が異なる時期に拡大しうる。本世界線の日清戦争は、清朝末期の財政危機と利権争奪を丸ごと数年から十年程度前倒しする事件となる。[^u074]

# 日本の対列強配置政策

## 既成事実化の論理

日本にとって最も怖いのはロシアである。[^u075] そこで、日本がロシアと直接対決するのではなく、ロシアに取られたくない地域に先に英仏の権益を設定する。[^u076] 1888年頃なら、対露牽制の協力相手としてはフランスよりイギリスの方が使いやすい。露仏同盟（史実1891〜94年）はまだ固定されていないが、フランスが1890年代にロシア側へ接近しない保証はないためである。[^u076]

| 列強 | 優先的に認める経済的利益 | 日本の狙い |
|---|---|---|
| イギリス | 山東・直隷の港湾、鉄道、金融 | ロシアの北洋進出を牽制 |
| フランス | 雲南・広西・華南の鉄道、鉱山、通商 | 台湾領有への反対を抑える |
| ドイツ | 清国の産業・軍需・鉄道契約 | 借款参加を促す |
| アメリカ | 通商・投資の平等、金融参加 | 対日外交協力を得る |

[^u076]

これらの権益は日本が一方的に授与できるものではなく、清国に講和と賠償借款の条件として承認させる必要がある。[^u076] 下関条約本体には書かれず、「対列強通商協定」として別に成立する（検討案）。フランスには1885年清仏天津条約（第7条に仏の鉄道技術・産業利用の規定）を発展させるトンキン―華南の交通・通商の余地が与えられる。[^u077]

## 日本の地域別関心

| 地域 | 日本の関心 |
|---|---|
| 満洲・遼東 | ロシアの軍事進出による朝鮮への脅威を警戒 |
| 山東 | 北洋海軍の再建を制限しながら、外国軍港化にも警戒 |
| 長江流域 | イギリス系の金融・商業活動との協調余地 |
| 福建・華南 | 日本領台湾の安全保障と、フランスなどの活動の調整 |
| 台湾海峡 | 航行自由と帝国海軍の防衛上の優位 |

[^u074]

## 対露妥協の限界線

| 対露交渉の項目 | 日本の態度 |
|---|---|
| 通商・金融協力（露系金融機関の対清借款参加、通常の商業） | 交渉可能 |
| 清国内の一般的な鉄道投資 | 条件次第 |
| 満洲横断鉄道 | 強い警戒 |
| 旅順・大連の租借 | 非常に受け入れにくい |
| 朝鮮の港湾・軍事顧問・駐兵権 | 朝鮮独立保障と正面衝突 |

[^u075]

商業的利益の容認と軍事力の招き入れを明確に区別するのが基本線である。[^u075]

# 主要な利権

## 北洋の英国権益

* **威海衛**: 賠償担保として日本が一時占領し、講和後に清国がイギリスへ長期的な港湾使用権・商業特許を与える構想（検討案）。最初は軍港の完全租借ではなく、港湾施設使用権・商業施設経営権・石炭補給施設から始める。英国海軍の拠点が近くなること自体は日本に無条件に好都合ではないためである。[^u076] 英系銀行団の賠償支払い確定→日本の撤退→英国権益の発効という順序が重要とされる。[^u085]
* **山東・直隷の鉄道**: 講和交渉と並行して清国と英系銀行団の間で鉄道建設契約を結ばせ、資金の一部を賠償支払いに充てる。[^u076]
* **山海関―営口鉄道**: 英国権益をロシアとの境界に置くため英国資本を導入する（検討案）。ただし特許だけでなく、実際に資金が払い込まれ線路が建設され英国債権が成立して初めて守るべき利益になる。[^u086]

## 英国権益が先に来る順序関係

ロシアが朝鮮へ到達する前に英国権益と衝突せざるを得ない、という順序関係が成立する。英国資本が北洋の鉄道・港湾へ先行進出している以上、ロシアが南満洲へ勢力を伸ばすには英系事業との調整が必要となり、対露危機が深刻化した際はむしろ英国が先に強硬になる。[^u091] ただしこれは、英国の鉄道権益が営口方面など南満洲まで実際に延びロシアと競合していることが条件で、山東・直隷の港湾や山海関付近だけなら、ロシアは北満洲から朝鮮国境へ接近する経路を遮断されない。[^u091]

| ロシアの行動 | 英国の立場 | 日本の立場 |
|---|---|---|
| 満洲北部に独自の鉄道を建設 | 既存権益を侵害しなければ交渉可能 | 警戒するが直接介入する理由は弱い |
| 英国系の鉄道・港湾事業を妨害 | 契約履行と投資保護を要求 | 英国の外交対応を支持 |
| 英国の鉄道利権を強制接収 | 武力示威を含む強硬措置の理由が増す | 日英協議を重視 |
| 朝鮮への軍事介入 | 極東の勢力均衡問題として対応 | 独立保障という直接の利害 |

[^u091]

英国が直接の権利者である問題では英国に交渉を主導させ、日本は日英協調と朝鮮独立保障を通じてロシアの軍事的進出を抑える。[^u089][^u091]

## ロシアの鉄道問題

本世界線では、清国の賠償借款を英系金融機関が主導し北洋の鉄道・港湾に英国権益が既存であるため、ロシアが東清鉄道（満洲横断鉄道）の敷設権を得る外交的条件は史実より悪い。1890年代の日露関係の最大の分岐は、ロシアが満洲横断鉄道の権益を獲得できるかどうかである。[^u092]（[日露関係と対露抑止](/diplomacy/japan-russia-relations.md)参照）

## ドイツと山東：膠州湾租借の不成立

英国系資本が山東・直隷に先行しているため、ドイツは膠州湾・青島を史実と同じ条件では取得できない。前編では「取得できるとは限らない」とされていたが、会話ログ2で**ドイツの膠州湾租借は成立しない**と確定した。[^u095][^e038][^e039]

1897年の山東での宣教師殺害事件に相当する事件は本世界線でも起こり得るが、1889年以来日本と共同で北洋に進出してきた英国は、膠州湾租借と山東の排他的鉄道利権が英国系資本の利益を直接侵害するとして清朝に外交支援を与え、ドイツの要求を限定する。[^e038]

| ドイツの要求 | 帰結 |
|---|---|
| 宣教師殺害に対する賠償・宣教師の保護 | 清朝が受諾 |
| 通商上の権利拡大 | 一部受諾 |
| 膠州湾の99年間租借 | 英国の反対によって不成立 |
| 山東省の排他的鉄道利権 | 不成立 |
| 青島へのドイツ海軍基地設置 | 不成立 |

[^e038]

ドイツには代償として青島での商業上の権利や外国船舶への補給施設の開放が認められる。一方、1898〜1900年頃に清朝と英国系企業の間で青島の開港場指定、港湾施設の建設・運営権、青島・済南間の鉄道敷設権、沿線の鉱山開発権、外国人居留区の設置が契約され、日本資本は英国系事業への出資で参加する。青島はドイツの軍港ではなく、日英資本による北洋経済圏の主要貿易港として発展した（→[青島](/regions/qingdao.md)）。[^e038] このため1914年に日本が攻撃すべき青島要塞は存在しない。[^e038]

本世界線の利権拡大は、軍事占領を伴わない経済的コンセッションが中心であるという本記事の基本構図を、山東でも貫いたことになる。[^u074][^e038]

## 日本資本の参加

日本の商社・銀行（領主系資本）が欧米銀行団と共同で中国の鉄道・鉱業へ投資する余地がある。ただしその参加は清国の財政・経済的従属を深めることにもなる。[^u074] 資源面では、日本企業自身が清の鉱山・鉄道コンセッションを取得する。特に湖北省の大冶鉄鉱山と長江輸送網を、筑豊炭と組み合わせて北九州で製鉄に用いる構想があり、島津・鍋島・毛利・徳川家などの領主系企業の共同出資も想定される。「領土を獲得する代わりに国際金融と商業契約によって資源供給を確保する」方針である。[^u081]（[資源戦略](/economy/resource-strategy.md)参照）

# 20世紀への展開

1900年代以降の展開は他記事で扱うため、ここでは要点のみ記す。

* **戦間期の構図**: 戦間期の中国は日本の勢力圏ではなく英国の金融・商業圏であり、民族主義運動の標的は英国へ移る。日本は大陸に大規模な駐屯軍や植民地行政を負わず、国内投資を優先できる。[^u102]（[戦間期の中国](/diplomacy/interwar-china.md)参照）
* **代物弁済**: 第一次世界大戦後、英国の対日戦時債務を中国の英国系資産で代物弁済し、日本が中国の鉄道債券・株式・経営権を取得する可能性が高い。領域的租借地（威海衛など）の取得には元老院が慎重である。[^u103]（[日英戦時債務整理と中国権益の移転](/diplomacy/war-debt-settlement.md)参照）
* **米国との衝突**: 1889年に英国へ与えた中国権益は、新規参入を狙う米国資本と衝突し、1920年代の日米関係悪化の原因となりうる。[^u107] 英国は中国権益と対日債務のため日本を切りにくく、フランスも華南権益で日英に近い。[^u108]
* **清朝崩壊後の承継**: 清朝崩壊後、清の対外権利義務（条約・公的債務・海関・鉄道鉱山契約）は北京・両江・湖北の[中国諸省聯合](/diplomacy/china-federation.md)が共同で承継し、日英はこれを中国の対外代表として承認する。列強の支援先は政体ではなく、どの地域に既存権益を持つかで決まった。[^e023][^e025]
* **青島の特別行政区域化**: 青島は清朝崩壊後、山東政府・聯合・英国領事当局の協定により、青島行政委員会が市街地を施政する特別行政区域となった。港湾は英国系港湾会社、鉄道は日英系鉄道会社が運営し、領土主権は名目上中国に残る。[^e038]
* **租界の準国家化（1930年頃）**: 全中国を実効支配する政府が一度も成立しなかったため、租界・租借地は主権回復で縮小せず、警察・徴税・司法・公債発行まで担う行政的自立性を強めた。正式租界・租借地のほか、租界外委託行政区・鉄道附属地・港湾管理区・外国企業の鉱工業地区といった外国施政地域が広がり、経済的コンセッションが政治的混乱によって事実上の施政権へ転化した。[^e037][^e039]（[戦間期の中国](/diplomacy/interwar-china.md)参照）
* **ワシントン会議**: 日英の中国権益の法的基盤は「1889年下関条約以来の債権・鉄道・港湾」であり、中華民国が統一国家として成立していない状況で、従前の契約を尊重する軍閥への支援を日英はやめられない。[^u123]（[ワシントン会議](/diplomacy/washington-conference.md)参照）

# 史実との比較

| 列強 | 史実の代表的利権（主に1897〜1899年） | 本世界線 |
|---|---|---|
| ドイツ | 膠州湾租借、山東の鉄道・鉱山 | 英国の反対で租借不成立。青島での商業上の権利のみ。青島・山東鉄道は英国主導・日英資本が開発 [^e038] |
| ロシア | 旅順・大連租借、満洲の鉄道（東清鉄道1896年） | 東清鉄道取得の条件が悪化、旅順大連租借は英国利益とも衝突 |
| イギリス | 威海衛租借（1898年）、香港新界租借、鉄道 | 1889年から北洋の鉄道・港湾・賠償金融を主導 |
| フランス | 広州湾租借、華南・西南の鉄道 | 1889年に華南の事業機会を得る |
| ベルギー系 | 北京―漢口鉄道 | 言及なし |
| 日本 | 福建不割譲宣言など、のち満洲権益 | 直接・独占の利権を持たず、英国秩序経由で参加 |

[^u074][^u095]

史実では1898年、英系資本が関与する京奉鉄道の山海関以北延長と借款担保にロシアが異議を唱え、1899年4月28日の英露鉄道協定で、英国は長城以北でロシアの鉄道敷設権獲得を妨げず、ロシアは長江流域で英国の鉄道敷設権獲得を妨げないことを約した。ただし山海関―営口線の英系銀行の既存借款契約は保全され、鉄道自体は清国管理下に残された。英国には「新規利権を譲ってでも既存の債権を守る」優先順位があった。[^u085][^u086][^u091]

# 却下・修正された案

* **ドイツの膠州湾取得を不確実とする整理**: 「ドイツが膠州湾・青島を史実と同じ条件で取得できるとは限らない」「青島要塞が存在しない可能性がある」という前編の見通し（U95）は、会話ログ2で租借不成立として確定した。[^u095][^e038]
* **「英国権益を先に作ればロシアは手を出せない」**: 1899年英露鉄道協定のように英国は勢力圏調整に応じうるため、危険な想定とされた。英国にとって妥協可能でも日本には妥協できない場合があり、英国権益がロシアに譲渡・交換されにくい契約構造まで考える必要がある。[^u085]
* **日本の前面関与**: 日本が英国権益保護に前面に立つ方向は、直接権益を侵されるのは英国であり日本が単独で出しゃばる正当性はないとして修正された。日本が単独で軍艦派遣や最後通牒に出れば、英国の商業問題が日露軍事対立に変わり、ロシアに「日本が満洲に勢力圏を築こうとしている」と主張する材料を与える。[^u089]

# 未決の論点

* 英国の鉄道権益が南満洲（営口方面）まで実際に延びているか。[^u091]
* ロシアが東清鉄道を獲得できるか、旅順など不凍港を得られるか。[^u092]
* 1890年代中盤以降に領域的コンセッション（租借地）がどの程度発生するか。[^u074]（膠州湾租借は不成立と確定。[^e038] 旅順・大連、威海衛などの扱いは未確定）
* 日本の領主系企業が取得する大陸の鉱山・鉄道コンセッションの具体的範囲。[^u081]
