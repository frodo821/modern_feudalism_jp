# 概要

1930年のロンドン海軍軍縮会議は、本世界線の戦間期を検討するうえでの「本題」と位置づけられた会議である。[^u132] 1922年の[ワシントン主力艦建造停止条約](/diplomacy/washington-conference.md)が巡洋艦・駆逐艦・潜水艦・空母の総量を一切制限しなかったため、1920年代後半には米国が日本の補助艦・空母の増強を問題視し、補助艦の制限が新たな対立点となる（検討案）。[^u129][^u131]

本世界線の日本は、1930年時点で金本位制を停止しており（金輸出停止の継続）、金解禁を公約とする有力な政治勢力も存在しない。また天皇に固有の統帥権がないため、史実のような統帥権干犯問題は起こらない。そのため、史実の浜口内閣のような「金解禁・緊縮財政・海軍軍縮」の一体政策は存在せず、会議の争点は**高度な工業国家となった日本が、英国と共同で必要とする巡洋艦・駆逐艦・潜水艦戦力を、米国がどこまで認めるか**という、かなり純粋な海軍戦略・外交問題になる（争点の整理は検討案）。[^u124][^u137]

会話ログは会議の前提条件（1930年の工業力、通貨制度、軍と政府の関係）を整えた段階で終わっており、交渉の具体的内容と結果は未決である。

# 会議の前提条件

## 1930年の日本の国力（検討案）

| 指標 | 慎重 | 中核 | 高成長 |
|---|---:|---:|---:|
| 粗鋼年産能力 | 650万t | **900万t** | 1,200万t |
| 粗鋼実生産（1930年） | 450万t | **700万t** | 950万t |
| 石炭年産 | 3,800万t | **4,800万t** | 5,800万t |
| 商船保有量 | 500万総t | **650万総t** | 800万総t |

労働生産性（米国＝100）は中核案で製造業全体45、鉄鋼50、造船60、機械・電機45、化学50とされる。粗鋼実生産700万tは英国にかなり接近する水準である（いずれも検討案）。[^u132] 工業力の推移全般は[重工業化と国力の推移](/economy/heavy-industrialization.md)を参照。

ただし海軍建造能力では、粗鋼量だけでなく造船・特殊鋼・機関製造・電機・精密加工・光学機器が重要であり、主機・減速歯車・測距儀・射撃指揮装置が輸入依存なら高性能艦の多数建造には制約がある。また1920年の国民所得200億円・帝国恒常歳入26億円をそのまま名目成長率で1930年へ延長してはならず、製鋼能力という物的上限と恐慌下の帝国予算という金融的上限を別々に積算する必要がある。[^u132]

## 交渉条件と影響

| 1930年の条件 | 軍縮交渉への影響 |
|---|---|
| 粗鋼年産能力約900万トン | 建艦計画を継続する物的基盤がある |
| 造船・機械工業の高度化 | 巡洋艦・駆逐艦・航空艦の国産化能力が高い |
| 英国との海軍協力 | 単独の対米艦隊比率だけで必要兵力を説明できない |
| 世界恐慌 | 建艦費節約への圧力と、造船業への発注維持要求が併存 |
| 統帥権独立の不在 | 軍部が憲法上の独立権限によって政府の妥協を拒否できない |

（検討案）[^u132]

日本は史実以上に建艦能力を持っているからこそ、必ずしも軍縮に反対する必要がない。景気後退で造船所に遊休設備が生じても、それを軍艦建造で稼働させれば財政負担が伴う。[元老院](/institutions/genroin.md)の領主系産業資本は建艦需要を歓迎する一方、国債増発や増税を嫌うという複雑な立場に置かれる（検討案）。[^u132]

## 金解禁不在の経済環境

日本は1917年以来の金輸出停止を1930年まで継続しており（確定）、史実のような「金解禁しなければ日本経済を正常化できない」という議論は政治的主流にならない（確定）。[^u133][^u137] 詳細は[金本位制離脱と管理通貨制](/economy/gold-standard.md)を参照。

その結果、海軍軍縮の財政的な必要性は残るものの、史実の浜口内閣ほど金解禁デフレに追い詰められてはいない。日本政府が軍縮を求める理由は、財政均衡そのものではなく、世界恐慌下での資源配分と、英国との共同防衛に必要な艦隊編制の合理化となる。日本は「財政破綻を避けるために譲歩する」立場ではなく、「国内産業や日英共同防衛にとって必要な艦艇を見極め、無駄な建艦競争だけを停止する」立場を取りやすい（検討案）。[^u136][^u137]

円建て対外債権と管理通貨制に近い制度の下で、日本には旧平価で金解禁することなく、円建て債権の信用を維持しながら国内の金融緩和と産業投資を続けるという選択肢がある。円の信用を何で保証するか（中央銀行制度、外貨準備、国際決済市場）は、ロンドン会議における財政余力にも関わる（検討案）。[^u135]（[円建て対外債権と円の国際化](/economy/yen-claims.md)を参照）

## 統帥権干犯問題の不在

本世界線では、天皇に固有の統帥権がないため、統帥権干犯事件は起きない。シビリアンコントロールが成立しているとはいえないが、軍が天皇の権威のみに基づいて政府の指令を拒否することはできない（確定）。[^u124]

軍縮条約が適法に批准され、政府が編制変更を決めれば、軍令部は専門的な反対意見を述べることはできても、それを天皇大権によって無効にすることはできない。条約を阻止するには議会と国民を説得するしかなく、軍の影響力は元老院・衆議院の政治勢力との結合を通じて合法的な制度の中で行使される。元老院には領主系産業資本や財政利益を代表する議員がおり、海軍軍縮を支持する経済的動機も十分にある（検討案）。[^u124] 詳細は[統帥権（本世界線）](/institutions/supreme-command.md)を参照。

# 想定される争点

## 日英の広域海上交通保護体制

日本海軍は主力艦決戦主義よりも通商保護・艦隊護衛・対潜能力を重視しており（[帝国海軍の戦略思想](/military/navy-strategy.md)）、ロンドン会議では史実のような重巡洋艦比率の争いだけでなく、**どの艦艇を制限すると日英の広域海上交通保護体制が維持できなくなるか**が中心的な論点になる（検討案）。[^u132]

日本は第一次世界大戦で英帝国の海上交通を守った実績を持つため、巡洋艦と護衛艦の需要を、単に米国に対抗するためではなく、英国との共同防衛任務を根拠に説明できる（検討案）。[^u129]

## 空母

1922年条約は空母の総量・個艦排水量を制限しなかった。1930年代に航空機の性能が向上すれば、1922年には危険視されなかった空母が戦艦と同等以上の戦略的重要性を持ち、新たな軍縮問題となる可能性がある（検討案）。ロンドン会議の時点でそれがどの程度争点化しているかは未決である。[^u131]

# 史実との比較

| 項目 | 史実（1930年） | 本世界線 |
|---|---|---|
| 通貨制度 | 1930年1月に旧平価で金解禁、1931年12月に再停止 | 1917年以来の金輸出停止を継続、管理通貨制に近い制度 |
| 国内政策 | 浜口内閣の「金解禁・緊縮財政・海軍軍縮」の一体政策 | 金解禁のための緊縮という政策目標が存在しない |
| 景気 | 金解禁と世界恐慌が重なり強いデフレ（1929〜31年に卸売物価30%以上下落） | 国際需要の減少は避けにくいが、国内金融収縮の程度は政策次第 |
| 軍と政府 | 軍令部が反対する兵力量を政府が決定できるかをめぐる統帥権干犯問題 | 統帥権干犯問題は起こらない |
| 条約内容 | 巡洋艦・駆逐艦・潜水艦に数量制限。重巡洋艦は米18・英15・日12隻 | 未決 |
| 日本の工業力 | 粗鋼約190万t、石炭約3,138万t | 粗鋼実生産700万t、石炭4,800万t（検討案） |

# 未決の論点

- 補助艦の制限方式、日本の要求、米国の譲歩範囲など、交渉の具体的内容と会議の結果。[^u132][^u137]
- 1930年の帝国財政（国民所得・帝国歳入・軍事費）と艦隊保有量の積算。[^u132]
- 1930年の工業力の数値（中核案）は暫定値で、明示的な承認はない。[^u132]
- 1869年憲法における内閣・元老院・軍司令部の軍事権限の具体的分配、軍部大臣現役武官制に相当する制度の有無。[^u124]
