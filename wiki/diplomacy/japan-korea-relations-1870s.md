# 概要

[対馬宗家の朝鮮通交家役](tsushima-so-clan.md)を接収した帝国政府は、天皇の政府として新しい形式の国書を朝鮮へ送ったが、朝鮮はこれを受理しなかった。朝鮮にとって新しい外交秩序を受け入れる意味はなく、しかもこの時期の朝鮮は清国の後ろ盾があると考えていたからである。[^u040]

本世界線では宗家特権の接収が史実より早いため、国書をめぐる衝突は1867〜1869年に表面化し、仮に1868年の国書受理拒否を起点とすれば、1870〜1873年の交渉停滞を経て1874年以降の軍事的圧力強化、1875年前後の[江華島事件](../events/ganghwa-island-incident.md)へと至る。[^u040][^u041]

# 背景

## 朝鮮側の論理

当時の朝鮮では高宗の父・興宣大院君が実権を握り、外国との通商・外交の拡大に強く抵抗していた。朝鮮は1866年にフランス軍、1871年にアメリカ軍と交戦しても開国に転じておらず、日本に対しても同じ姿勢をとった。朝鮮は清朝中心の伝統的な国際秩序の中に位置づけられており、日本が突然「天皇の詔勅によって外交を行う」と主張しても、それを認める必要はなかった。[^u040]

さらに、本世界線では宗家が対馬の領主として存続している。朝鮮側にとって宗家は長年の正規の窓口であり、従来どおり宗家を通じて交渉したい理由があった。日本が国内的に外交を一元化したことは、朝鮮側から見れば長年機能してきた外交経路の一方的な変更にすぎない。[^u038][^u040]

## 日本側の論理

帝国政府は「外交権は天皇の政府に帰属する」と主張し、宗家による朝鮮外交の独占を認めるわけにはいかなかった。新政府は「皇」「勅」という表現を法制度上も重視しており、朝鮮側が従来の秩序を守ろうとすれば衝突は避けがたかった。[^u038]

ただし、外交権の接収と外交文書の形式変更は本来別の問題である。宗家の実務官僚を利用して従来の文書形式を暫定的に維持すれば国交断絶を回避する余地はあったが、天皇の権威を明示した新形式にこだわれば対立は深まる。本世界線の帝国政府は後者の道をとった。[^u038][^u041]

# 経過

## 国書の受理拒否（1867〜1869年）

宗家の家役接収と同時期に新しい国書が送られ、朝鮮はこれを受理しなかった（1867年接収・1868年受理拒否という時系列が仮置きされている）。国内では外交一元化に成功したのに、朝鮮との関係では従来の外交秩序が崩れるという事態が生じた。宗家から外交権を取り上げる国内法上の問題は元老院の政治的圧力で比較的早く解決できたが、朝鮮王朝に新しい外交代表と文書形式を承認させる国際関係上の問題は、宗家の協力を得ても簡単には解決しなかった。[^u038][^u039][^u040]

## 日本側の選択肢

国書を拒否された帝国政府には、次の選択肢があった。[^u040]

| 方針 | 予想される展開 |
|---|---|
| 従来の文書形式を暫定的に使用 | 国交維持の余地はあるが、政府内で反発が生じうる |
| 清国を通じて朝鮮に交渉を求める | 朝鮮と清朝の宗属関係を外交上認めることになる |
| 交渉を中断して通商関係を制限 | 対馬などの日朝交易に影響 |
| 軍艦による示威と開国要求 | 朝鮮の反発を強め、軍事衝突に発展する危険 |

軍事行動に先立ち、まず清朝との外交関係を整える展開が考えられた（検討案）。[^u040]

## 日清修好条規（1871年）

本世界線でも史実の1871年日清修好条規に相当する条約が成立し、日本と清国は近代的な条約関係を形成する（検討案）。しかし清国は、朝鮮を自国の属邦と主張しながら、朝鮮自身が外交上の判断を行うという立場をとった。[^u037][^u040]

このため日本政府は「清国が宗主国なら朝鮮の外交政策に責任を負うのか、それとも朝鮮が独自に外交を行うなら日本は直接朝鮮政府と交渉してよいのか」という問題を整理できないまま、日朝関係の悪化に直面した。日本が清国に仲介を求めても、清国がそれを引き受ける保証はなかった。[^u040]

## 「清国が守ってくれる」という認識のずれ

朝鮮側にとって清国が外交的な支えであったことは確かだが、清朝の宗主権と朝鮮に対する無条件の軍事防衛義務は同じではない。1870年代の清朝は朝鮮の内政・外交に原則として干渉しない立場をとっており、朝鮮をめぐって日本との戦争に踏み込む姿勢は見せていなかった。清の朝鮮政策が軍事介入を伴って変化するのは1882年以降である。[^u040]

朝鮮が清朝の権威を頼りに日本の要求を拒否することと、実際の紛争で清軍が援軍を送ることは別問題であり、この認識のずれが外交危機の原因となった。日本が軍事的威圧を選べば、朝鮮は清国の外交的権威を背景に抵抗し、清国は即座には介入しないという危険な状況が生まれる。[^u040]

## 交渉の停滞と軍事的圧力（1870〜1875年）

江華島事件に至る経過は次のように整理される。[^u041]

| 年 | 出来事 |
|---|---|
| 1867〜1869年 | 帝国政府が宗家の朝鮮外交家役を接収。朝鮮が新しい国書の受理を拒否 |
| 1870〜1873年 | 日朝交渉が停滞。国内では外交的威信と通商上の利益をめぐる議論が続く |
| 1871年 | 日清修好条規相当の条約が成立 |
| 1872〜1873年頃 | 元老院で対朝鮮強硬論が高まる（[征韓論争](../events/seikanron-debate.md)） |
| 1874年 | 日本政府が外交圧力を強化。海軍の航路調査・測量活動が拡大 |
| 1875年前後 | 日本艦が江華島近海に進出し、朝鮮側砲台と衝突 |
| 1876年 | 軍事的圧力を背景とする日朝条約交渉、朝鮮開国 |

停滞が長引いた背景には、宗家の家役喪失によって交渉停滞の責任を中央政府が直接負うことになった事情がある。さらに、武家出身の領主が元老院で朝鮮の国書拒絶を「天皇の権威と帝国の威信に対する侮辱」と捉える政治文化が、強硬論を後押しした。[^u041][^u042]

# 意義

本世界線では、日本が史実より早く強力な国軍を整備している可能性がある一方、朝鮮政府はその能力を十分に把握していなかったかもしれない。この非対称が江華島事件型の衝突を起こりやすくした。[^u040]

また、宗家の外交特権の廃止・朝鮮による国書拒否・清国との国交樹立という三つの出来事が、1870年代の日朝間の外交・軍事的事件の性格を決め、その後の朝鮮問題全体の出発点となった。後年「日本の日清戦争前史で本当に重要なのは、清朝がいつ朝鮮に対する不干渉姿勢を改めるか」と整理される論点も、この時期の清朝の曖昧な立場に由来する。[^u040]

朝鮮問題はやがて、[元老院](../institutions/genroin.md)政治において政権の能力を測る問題ともなった（[不平等条約改正](treaty-revision.md)参照）。[^u046]

# 史実との比較

- 史実では1868年12月、明治政府が宗家を通じて王政復古を通告したが、「皇」「勅」などの表現や印章の変更を理由に朝鮮側が受理を拒否した（書契問題）。本世界線では宗家家役の接収が早く、同種の衝突が1867〜1869年に起こる。[^u038][^u040]
- 史実では1871年の廃藩置県で宗家の家役が消滅したが、本世界線では宗家が対馬の領主として存続している点が異なる。[^u038]
- 史実の日清修好条規（1871年）は本世界線でも相当の条約が結ばれる。[^u040]

# 未決の論点

- 国書受理拒否の正確な年（1867年接収・1868年拒否は仮置き）。
- 日清修好条規相当の条約の具体的内容、清国に朝鮮問題の仲介を求めたかどうか。
- 旧形式の文書を暫定的に使う妥協案が政府内でどの程度検討されたか。
