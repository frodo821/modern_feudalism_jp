# 概要

第一次世界大戦中、日本は英国へ大量の軍需品と商船を供給し、その代金の一部を政府間借款・信用供与として繰り延べた。その結果、戦後の英国には相当規模の対日戦時債務が残る。[^u099][^u103] 対米債務の一部が対日債務に移っている以上、英国にとって米国がどこまで代替不可能かは自明ではなく、むしろ対日関係を損ねて「金で返せ」と言われる方が英国には厳しい（確定）。[^u118]

この債務の整理手段として、日本が現金返済にこだわらず、**中国大陸の英国系資産・事業権を代物弁済として受け入れる**経路がある（確定）。[^u103] これは「日本は中国大陸に直接かつ独占の利権を持たず、その空白を英国が埋めている」という戦間期の前提（確定）[^u102]を変える重要な経路であり、**日本は中国大陸へ軍事進出することなく、戦時債権を通じて中国における有力な投資国家へ変わる**。[^u103]

もっとも有力な形は、英国が外交上の権利者として残り、日本が資本参加によって収益と経営上の影響力を確保する**日英共同保有**である。債務を減らすために中国権益を日本へ渡すほど、日英はその権益を共同で守る必要が増し、債務整理がかえって日英関係を深める。[^u103][^u118]

# 債権の形成と規模

## 発生の仕組み

日本の軍需工業・造船業が英仏へ兵器・商船・機械を供給し、その代金の一部が借款や政府保証債務として繰り延べられる。英仏は対独賠償収入を返済財源として期待する（→[対独賠償と産業賠償](/economy/german-reparations.md)）。[^u099] 債権の大半は日本企業の軍需品・船舶輸出代金の繰延べ、つまり売掛金に近い性格をもつため、**円建て**が相当な割合を占める。為替リスクを負うのは史実と逆に英国側となる。[^u135] 通貨面の詳細は[円建て対外債権と円の国際化](/economy/yen-claims.md)を参照。

| 金融関係 | 想定される通貨 |
|---|---|
| 日本企業の英国向け軍需品納入 | 円建て請求が有力 |
| 英国政府の日本国内での借款発行 | 円建て |
| 日本政府・領主系銀行団の対英貸付 | 円建てが中心 |
| 英国の対日債務返済 | 円、または契約上の換算額 |

## 規模の推計（検討案）

「工業品を供給できること」と「英仏政府に何十億ドルも貸せること」は別問題である。[^u119] 終戦時の日本の対連合国債権は、戦争の長さによって次のように仮置きされている（当時の円。日本の金融市場が十分発達し、英仏向け輸出代金の相当部分を政府・銀行団の信用供与で賄った場合）。[^u119]

| シナリオ | 対連合国債権 | うち対英国債権 |
|---|---:|---:|
| A：1917年終戦 | 8億〜15億円 | 4億〜9億円 |
| **B：1918年終戦（中心）** | **15億〜30億円** | **8億〜18億円** |
| C：1919〜20年終戦 | 30億〜50億円 | 15億〜30億円 |

債権のすべてが英国向けではなく、フランス向けや、革命で回収不能になるロシア向けも含まれる。英国向け輸出が増えても現金で決済されれば債権は増えない。重要なのは**英国の総債務の増加と、債権者が米国から日本へ移ることを別々に評価すること**であり、日本が米国の供給を代替したなら総債務が変わらなくても対日債務の比率は大きくなる。[^u119] 次に決めるべきは1918年末の英仏露の対外債務の債権者別内訳であり、英国の対日債務が10億円か30億円かで、英国が1921年の軍縮会議で日本との関係をどこまで重視するかが変わる。[^u119]

# 代物弁済の対象

## 英国側資産の譲渡難易

所有権と租借権は区別される。[^u103]

| 英国側の資産・権利 | 対日債務との相殺 | 必要な手続き |
|---|---|---|
| 英国政府保有の鉄道債券 | 比較的容易 | 債権譲渡・評価額の合意 |
| 英国系企業の鉄道・鉱山株式 | 可能 | 企業買収・株式移転 |
| 港湾経営権・鉱業特許 | 条件付きで可能 | 中国側の許可や契約変更 |
| 租界内の不動産・施設 | 個別に可能 | 土地権利・行政規則の確認 |
| **中国から得た領域的租借権** | **外交交渉が必要** | **日英中三者の合意** |

英国系企業の資産は英国政府の所有物とは限らず、政府が直接譲渡できない場合は企業からの買い取りや政府保証付きの債務相殺が必要になる。[^u103] 実際には資産購入・債権交換・企業再編・中国側承認が伴う。[^u118]

## 仮想「1922年日英戦時債務整理協定」（検討案）

作中で想定された架空の債務整理協定の骨子は次のとおり。[^u103]

1. 英国政府は対日戦時債務の一部を資産移転によって整理する。
2. 日本の政府系金融機関・領主系銀行団が、英国保有の中国鉄道債券を取得する。
3. 日本資本が英国系の港湾・鉄道会社へ出資し、共同経営体制を組む。
4. 中国政府の承認が必要な事業権については、日英中三者で契約を改定する。
5. 英国は残存する投資利益を確保し、日本は長期的な収益権と資源輸送網を獲得する。

最もありそうな形は、英国の対日債務の一部を中国大陸の鉄道・鉱山・港湾企業への日本資本参加と交換し、**現金・公債による返済も併用する**ものである。債権の額面と英国資産の実際の収益価値は混同できず、英国が優良資産を割安に手放す理由もない。[^u103]

# 双方の利益と元老院の論争

## 英日双方の動機

- **英国**：現金流出を抑えられるうえ、民族主義運動の高まりで維持が難しくなる中国権益の追加投資・経営負担を日本に分担させられる。[^u103]
- **日本**：成長した領主系企業が長期投資先を必要としており、配当・利息収入と工業原料の輸送経路を、独自の戦争なしに得られる。[^u103]

ただし日本は、それまで中国の外国権益問題で「一歩引いた立場」にいられたのに、**権利者本人**になって英国の政治的リスクも引き受けることになる。[^u103]

## 「金で権益を買うこと」と「軍で守ること」

[元老院](/institutions/genroin.md)は両者を区別する。1889年以来、海外権益の獲得に伴う費用を警戒してきた元老院は、**鉄道債券・鉱山株式・港湾経営権などの収益資産を優先し、領域的租借地の取得には慎重**となる。租借地には警察・行政・軍事・住民関係の継続的な統治負担が伴うためである。一方、海軍は北洋の補給港・修理施設として租借地の安全保障上の価値を主張する。この対立は領土拡張論としてではなく、債務整理の方法をめぐる議論として始まる。[^u103]

もし日本が威海衛の租借権そのものを取得しようとすれば、それは金融取引を超えた重大な外交事件となり、国内でも「代物弁済のために新たな海外統治責任を負うべきか」という論争が起こる。**戦時債権を資産へ変えること自体は経済政策だが、租借地まで受け取ると経済政策が領土・安全保障政策へ変わる**。この境界が、戦間期の日本が中国大陸へどこまで関与するかを決める分岐点である。[^u103]

## 共同保有という解

日本が英国の権益をすべて取得すれば、ロシアや中国民族主義勢力と直接対峙し、それまで英国に担わせていた外交負担を自ら引き受けることになる。そのため、英国が外交的な権利者として残り、日本が資本参加で収益と経営上の影響力を確保する構造が日英双方にとって都合がよい。共同投資が長く続けば、英国の中国利権は形式上英国のものでも、資本構成は日英共同になっていく。[^u103]

# 日英関係への帰結

## 「金で返せ」の重み

日本が借り換えに応じれば英国は長期で少しずつ返済できるが、関係が悪化して日本が借り換えを拒み満期返済を求めれば、戦後の復興・輸入代金・為替安定・国債償還を抱える英国には大きな外貨調達圧力となる。ただし日本が長期債務の期限前一括返済を一方的に要求できるわけではなく、期限前償還条項・違約事由・借り換え時期、つまり**満期の集中**が日本の影響力を決める。[^u118]

また、日本の債権者である領主系銀行・産業資本も、英国を金融危機に追い込みたいわけではない。英国が支払不能になれば自らの資産価値も損なわれるからである。対日債務が英国外交をどこまで拘束できるかは、債権がどの程度政府管理下にあるか、満期、借り換え拒否の可否によって決まる。[^u118]

## 英国にとっての日本の代替可能性

| 分野 | 日本による代替可能性 | 英国にとっての意味 |
|---|---|---|
| 東アジアの海軍協力 | 高い | 中国権益と海上交通の保護 |
| 工業製品・商船供給 | 相当程度ある | 対米依存の抑制 |
| 戦時債務の借り換え | 日本の金融市場次第 | 日本が有力な債権者となる |
| 大西洋の安全保障と米国金融市場 | 限定的 | 英米関係の重要性は残る |

米国は完全には代替できないが、**代替不可能だからといって英国が中国問題で米国に譲歩しなければならないわけではない**。[^u118] 日本は英国にとって単なる同盟国ではなく、債権者・工業製品供給国・中国事業の共同投資者・海軍上の協力相手を兼ねる存在である（ただし米国より重要になったという意味ではない）。[^u118][^u120]

## 債権国を仮想敵にできない英国

「巨額の自国債権を持つ国を仮想敵として設定する必要があるか」が問題となる（確定）。[^u122] 英国が日本を仮想敵とすれば、対日戦備のための支出増が対日返済能力を下げる矛盾が生じる。英国にとって合理的なのは、日本との協力を前提に海軍予算を削減し、その余力で対日債務を返済することである（検討案）。[^u122] ただし債権関係それ自体は戦争防止の保証ではない（戦時には敵国債権の凍結・支払停止が起こる）。日本側も英国を敵にする理由はないが、日本が英国の中国権益回収運動を支持したり不利な債務整理を求めたりすれば対立の余地は残る。[^u122]

この構造は1921〜22年の軍縮会議に反映され、会議は軍艦建造制限についてのみ成立し、日英関係の制限を含む他の論点は決裂した（確定）。日英は米国と敵対しないが、米国の無条件の味方にもならなかった。[^u125] 詳細は[ワシントン会議と主力艦建造停止条約](/diplomacy/washington-conference.md)を参照。

## 米国と中国からの見え方

米国から見れば、日本の代物弁済による中国資産の取得は「**日英が戦争債務の整理を利用して中国の独占権益をさらに強化している**」と映る。中国の革命政府や民族主義勢力もこれを批判材料にできる。[^u107] 英国が北方軍閥へ融資し、日本も代物弁済で取得した鉄道株式・債券を通じて関与し、日英がその軍閥を正統政府と認める構図は、買弁資本批判の格好の対象となる（→[戦間期の中国](/diplomacy/interwar-china.md)）。[^u106] 一方、日本は排他的領域支配をもたず後から資本参加したため、債権・株式価値が保全されれば行政特権の縮小を許容でき、英仏より権益改定に柔軟になり得る（例：鉄道を中国との合弁会社へ改組し、日本に長期配当と経営参加権を保障する）。[^u108]

# 財政上の扱い

対英仏債権の元本償還は新たな所得ではなく資産形態の変化（対外金融資産から実物資本へ）であり、利息は経常収入だが債務者の支払能力に依存する。民間銀行・領主系企業が保有する債権の償還金は自動的には帝国歳入にならず、課税・国債・債権購入・金融機関との契約が必要である。[^u126] 財源区分の詳細は[帝国財政と諸侯の法定拠出](/economy/imperial-finance.md)を参照。

# 史実との比較

- 第一次世界大戦後の英国は巨額の対外債務を抱え、海外投資の整理や資産売却で資金を調達した。[^u103]
- 1923年、英国は対米戦時債務約46億ドルについて62年返済の協定を結んだ（金利当初3%、のち3.5%）。[^u118]
- 史実の日本は1915〜1918年に英仏露へ約6億4,063万円を貸し付け、うち約2億2,000万円がロシア革命で回収不能となった。[^u119]
- 史実でも1916年12月に英国向け1億円借款が組成され、以後の政府支援の戦時借款は円建てで発行された。英国政府は1918年に8,000万円の円建て大蔵省証券を日本で発行している。[^u135]
- 史実の威海衛租借条約は、清国が英国政府へ特定地域を租借し管轄権を認めたものである。[^u103]

# 却下・修正された案

- **英国の対日債務20億ドル**：1922年の英国政府対外戦時債務を「米国26・日本20・その他3（億ドル相当、計49）」とする仮置き（U118）は、史実の日本の資金供給実績（約6.4億円）に照らして過大として撤回され、シナリオ別の円建てレンジ表（U119）に置き換えられた。[^u118][^u119]
- **英国は米国のために日本を切り捨てる**：史実の英米関係に引きずられた当初の見立ては、対日債務と東方防衛協力の重みから修正された。[^u118]

# 未決の論点

- 日本が代物弁済で取得した中国権益の具体的範囲（債券・株式・経営権に限るか、威海衛など租借地まで含むか）。[^u103]
- 1918年末の英仏露の対外債務の債権者別内訳と、英国の対日債務の額（10億円か30億円か）。[^u119]
- 日本の対英債権が政府管理か民間か、満期構成、借り換え拒否の可否。[^u118]
- 1920年代に対清賠償支払いが完了しているか。[^u102]
