# 概要

日英協調は、本世界線の日本外交の基軸である。その出発点は、1889年の日清講和に際して英系銀行団が清国の対日賠償借款を主導し、英国が山東・直隷（北洋）の鉄道・港湾に先行して権益を得たこと――日本が対露戦略上「英国の利権を先に既成事実として中国に突っ込む」選択をしたこと――にある（確定した前提）。[^u076][^u077]

この関係の性格は、史実の日英同盟とは異なる。本世界線の日英協調は「共同でロシアと戦う」ためではなく、「共同でロシアとの戦争を回避しながら既得権を守る」仕組みであり、正式な軍事同盟が存在するとは限らない。[^u090][^u095] ロシアが権益を侵す場合も、直接の当事者は英国であって、日本が単独で出しゃばる正当性はない（確定）。[^u089]

第一次世界大戦では、ドイツが勝てばすべてがご破算になるとの判断から日本は英国側で参戦し（確定）、日本海軍がインド洋・太平洋を守って英海軍を欧州に集中させた。[^u095][^u096][^u120] 大戦後の日本は英国にとって債権者・工業製品供給国・中国事業の共同投資者・海軍協力相手を兼ね、英国が日本を仮想敵とすることは財政的に不合理となる。[^u118][^u122] 1921〜22年のワシントン会議を経て、日英は米国と敵対しないが米国の無条件の味方でもない立場をとる（確定）。[^u125]

# 起源（1885〜1889）

日英の対露利害は、1885〜87年の巨文島事件（英国がロシアの朝鮮進出を警戒して巨文島を占領し、撤退時にロシアの朝鮮不占領を条件とした）以来重なっており、日英接近は史実より早まる。[^u075]

1888年頃、対露戦略上はフランスより英国を先に引き込む方が有効とされた。ロシアに取られたくない地域に先に別の列強の権益を設定する外交であり、英国を北洋（山東・直隷の港湾・鉄道・金融）、フランスを華南（雲南・広西）へ誘導する。その「妙手」は、清に借款を提供する銀行団へ鉄道・港湾などの事業権を先に設定させることで、後からロシアが進出すれば英国の既得権と衝突し、日本が単独で対露負担を負わずに済む。講和条約より先に英仏との非公式な金融・通商協定が成立していても不思議ではなく、1889年の講和は「日本が列強と事前調整した構想を敗戦国清に受諾させる場」となった（検討案）。[^u076]

[下関条約（1889年）](/diplomacy/shimonoseki-treaty-1889.md)では、英国の具体的な事業特許は条約本体ではなく、並行する「対清賠償借款協定」（英系中心の銀行団による海関担保融資）と「対列強通商協定」（英国への北洋方面の経済権益）に置かれた（検討案）。[^u077]（→[対清賠償借款と講和の国際金融](/economy/indemnity-loan.md)、[中国大陸の利権争奪（1888〜1900年代）](/diplomacy/china-concessions.md)）

威海衛については、英系銀行団による賠償金支払いの確定 → 日本の威海衛撤兵 → 英国の港湾権益の発効、という順序が重要とされた（英国権益で対露牽制をしつつ、賠償回収も守る）。[^u085]

ただし、英国の権益が山東・直隷にあっても満洲全域をロシアから守る保証にはならない。この政策の成功はロシアの野心を消すことではなく、英露の対立を日本の近くに引き寄せることである。[^u076]

# 1890年代：対露抑止の協力

## 英国権益と日本の賠償

英国権益は日本にとって他人事ではなく、賠償金の支払いに直結する問題であった（確定）。[^u085] 日本が借款で賠償全額を受領済みであれば、清が返済不能になっても損失を負うのは銀行団だが、分割送金方式ならロシアの介入で清の担保能力が損なわれたとき日本への支払いも滞る。「賠償金をいつ受領し、借款の信用リスクをいつ銀行団へ移すか」の設計が日英関係の性格を左右する。[^u085]

## 英国の対露妥協を防ぐ工作

日本は、英国に対露妥協を断念させるような工作を必要とする（確定した方針）。[^u086] ただしその要点は、英国にあらゆる対露妥協を拒ませることではなく、日英が利害を共有する北洋で英国が日本を置き去りにしてロシアと取引するのを防ぐことにある。日本が提示できる利益は次のとおりである。[^u086]

| 分野 | 日本が提供できるもの |
|---|---|
| 対清金融 | 賠償借款の組成・返済条件での協力 |
| 北洋鉄道 | 英系既存利権への外交支援 |
| 帝国交通網 | 鉄道設備・機械の発注機会（→[帝国交通整備計画](/economy/transport-plan.md)） |
| 海軍 | 艦艇建造・技術協力 |
| 台湾・朝鮮 | 通商・港湾利用の保障 |

1889年以降の日本は「資金や軍艦の援助を求めるだけの国ではなく、購買力と軍事力を持つ協力相手」である。特に山海関から営口に至る鉄道に英国資本を導入し、英国権益をロシアとの境界に置くことが有効とされるが、特許だけでなく実際に資金が払い込まれ線路が建設されて初めて守るべき利益になる。[^u086]

1889〜1890年代初頭の日英協定案（検討案）[^u086]

1. 北洋の鉄道・港湾権益を第三国へ移転・譲渡する際の日英事前協議
2. 賠償借款の担保を保護する共同外交
3. 朝鮮・北洋における現状変更（旅順租借、朝鮮の軍港使用権など）についての協議

関係は金融・通商協定 → 外交協議 → 海軍協力と段階的に発展する。正式な軍事同盟には、日本側では元老院・衆議院による継続的な軍事負担の承認、英国側では自動参戦義務への慎重さという制約がある。英国の対露妥協を防ごうとして日本自身が対露戦争に引きずり込まれる危険もあり、日英関係は「対清講和を共同で支えた二国がその戦後秩序をロシアから守ろうとする関係」と位置づけられる。[^u086] 1890年代前半は情報交換・海軍協力・清の借款政策協議から深化し、ロシアが旅順・大連を軍港化する段階で正式な安保協定が検討される。[^u079]

## 英国主導の原則

ロシアが権益を侵す場合でも直接侵されるのは英国であり、日本が単独で出しゃばる正当性はない（確定）。[^u089] 日本は重要な利害関係者だが英国の権利を代行できず、英国に外交的主導権を取らせたうえで支援の範囲を交渉する。日本の問い方は「満洲からロシアを排除してほしい」ではなく、「1889年の戦後金融協定によって成立した債権と事業権を守るため、どのような措置を考えているか」となる。[^u089]

| 英国の対応 | 日本の対応 |
|---|---|
| ロシアへ抗議 | 外交的支持と清への働きかけ |
| 清との契約保全を要求 | 賠償金融上の利益があれば共同協議 |
| 海軍示威 | 日本の港湾・補給施設の利用を協議 |
| 英露妥協を探る | 日本への影響を確認し懸念を伝える |
| 既存権益を放棄 | 日本は別途自国の安保政策を再検討 |

英国が海軍を動かしても日本は自動的に動員せず、参戦義務もない。武力行使への協力には元老院・衆議院の判断が必要である。対露危機のたびに「日英外交会議」が開かれ、協議が定例化する可能性がある（軍事同盟ではなく、利益衝突を防ぎ英国の対露交渉に日本の利害を反映させる協議機構、検討案）。1890年代の中心的な外交問題は日露の軍拡競争ではなく、「英国がロシアとどの範囲で妥協し、その交渉に日本がどの程度関与できるか」となる。[^u089]

ロシアの南下は鉄道（英国権益の侵犯）が先に来るため、英国の戦争許容度の方が先に上がる（確定）。[^u091] 英国資本が1889年の戦後処理で史実より早く大きく投資しているため守るべき既得権の総額も大きい。ただし英国は日本が対露戦争を肩代わりするとは期待できない。[^u091] 英露が正式に戦争すれば世界大戦の入口になりうるが、露仏同盟に自動参戦義務はなく、英国にも開戦回避の強い動機がある。日本にとって望ましいのは、英国が権益を簡単に手放さず、かつ開戦前に必ず外交解決を試みることである。[^u090]（→[日露関係と対露抑止](/diplomacy/japan-russia-relations.md)）

# 第一次世界大戦

## 参戦の論理

1914年の日本は、中立かイギリス寄りであり、英国は直接のステークホルダー、ロシアはまだ敵ではない。ドイツが勝つと困るので英国側で参戦はありうる（確定）。ドイツが勝てばすべてがご破算になるので、ドイツが勝ちそうならなりふり構っていられない（確定）。[^u095][^u096]

日本は対露関係より対英関係で参戦を判断する国家であり、その論理は「日露戦争には勝っても得るものが乏しい。しかし第一次世界大戦では、イギリスが負けると失うものが大きい」と要約される。英国が講和へ追い込まれれば、1889年以来の北洋の金融・通商秩序も再交渉を迫られかねない。[^u095] 「勝っても儲からないから戦わない」と判断した元老院が、ここでは「負けたら損失が大きすぎるから戦う」と判断を逆転させ、財政慎重派こそ参戦支持の理由を持つ。[^u096] 参戦目的は領土獲得ではなく長期的な対英協力の維持であり、正式な日英同盟がなくとも、英国の正式要請 → 元老院・衆議院による海軍の限定参戦と臨時軍事費の承認 → 対独宣戦、という過程が想定される（検討案）。[^u095] 参戦の経過は[第一次世界大戦と日本](/events/world-war-one.md)を参照。

## 英帝国の東方防衛

日本の重要性を測る第一のファクターは、英国の植民地防衛にどれだけ協力し、どれだけ重要な役割を演じたかである（確定）。[^u120] 中核となる構図は、日本海軍がインド洋・太平洋を守ることで英国海軍が北海・大西洋・地中海に集中できることにある。[^u120]

| 海域 | 日本の任務（検討案） |
|---|---|
| 香港・南シナ海 | 商船護衛、港湾防衛、通商破壊艦対策（巡洋艦3〜5） |
| シンガポール・東インド洋 | 海峡警備、輸送船護衛、巡洋艦哨戒（巡洋艦3〜4） |
| 豪州・NZ | ANZAC船団護衛（大型巡洋艦1〜2＋軽巡など） |
| 英領太平洋諸島 | 海上警備・部隊輸送（巡洋艦・補助艦2〜4） |
| 地中海 | 駆逐艦による対潜・船団護衛（1917年以降） |
| 中国内河・租界警備 | 英国が主に継続（日本の代替は限定的） |

同時配備の仮想投入規模は巡洋艦12〜18隻、駆逐艦20〜30隻、補助艦・給炭船など。[^u120] 協力は三段階で進む：1914〜15年は東方海域の防衛代行（通商破壊艦対策、ANZAC船団護衛）、1916年は英海軍の欧州集中の支援、1917〜18年は地中海への駆逐艦派遣と護衛艦艇の追加建造・提供。[^u120]

ただし「史実より英国艦隊を何十隻も欧州へ移した」とするのは過大評価である。1914年末までに英国が追加で転用できる余裕は、大型・装甲巡洋艦1〜2、軽巡洋艦など2〜4、旧式戦艦・駆逐艦若干、条件次第で豪巡洋戦艦 Australia 1隻程度にとどまる。日本の協力の価値は艦艇数より、東方航路の海上輸送の信頼性と、英国が世界規模の戦争を遂行するための海軍配置の安定にある。ANZAC船団などの護衛は臨時協力ではなく、日英間で事前に計画された常設任務になる（検討案）。[^u121] 詳細は[第一次世界大戦期の日本の軍需・海運・海軍協力](/military/wwi-japan-war-effort.md)を参照。

豪州・NZなど自治領にとって、日本は「頼りになる防衛協力国」であると同時に「自国周辺で圧倒的な海軍力を持つ外国」という両面を持つ。[^u120]

# 戦間期：債権と中国権益で結ばれた関係

## 債権者としての日本

大戦中の日本の軍需・船舶供給は英国の対日戦時債務を生み、対米債務の一部が対日債務に移った。米国が英国にとってどれだけ代替不可能かは不明であり、むしろ対日関係を損ねて「金で返せ」と言われる方が英国には厳しい（確定した論点）。[^u118] 日本の影響力は債務残高だけでなく、返済条件（借り換えに応じるか満期返済を求めるか）、期限前償還条項、違約事由、満期の集中によって決まる。日本の債権者（領主系銀行・産業資本）も英国を金融危機に追い込みたくはない。[^u118] 規模の推計と債務整理の詳細は[日英戦時債務整理と中国権益の移転](/diplomacy/war-debt-settlement.md)を参照。

英国にとっての日本の代替可能性は、東アジアの海軍協力（高い）、工業製品・商船供給（相当程度）、戦時債務の借り換え（日本の金融市場次第）、大西洋の安全保障と米国金融市場（限定的）と整理され、「代替不可能だからといって中国問題で米国に譲歩しなければならないわけではない」。[^u118]

## 中国権益の共同保有

戦間期の日本は中国大陸に直接かつ独占の利権を持たず、その空白は英国が埋めている（確定）。中国は日本の勢力圏ではなく英国の金融・商業圏であり、日本は英国の秩序を通じて中国経済に参加する。日英協調は「租界を守る同盟」から「中国市場の安定と投資安全を共同で確保する協調」へ変わり、日本にとって合理的なのは英国の政治的特権を縮小しつつ双方の商業契約を保護する方向である。[^u102]

日本が債権の代物弁済を認め、英国から中国権益をさらに譲り受けている可能性もある（ユーザー提起、採用方向）。最も好都合な構造は「英国が外交的な権利者として残り、日本が資本参加によって収益と経営上の影響力を確保する」ものである。元老院は鉄道債券・鉱山株式・港湾経営権などの収益資産を優先し、領域的租借地の取得には慎重である（「戦時債権を資産へ変えるのは経済政策だが、租借地まで受け取ると領土・安全保障政策に変わる」）。[^u103] 代物弁済は日英の中国事業を一体化させ、債務整理がかえって関係を深める。[^u118]

## 仮想敵にできない日本

「巨額の自国債権を持つ国を仮想敵として設定する必要があるか」が戦間期日英関係の核心である（確定した論点）。[^u122] 英国が日本を仮想敵とすれば、対日戦備のための支出増が対日返済能力を低下させる矛盾が生じる。[^u122]

| 項目 | 日本を協力国とする場合 | 日本を仮想敵とする場合 |
|---|---|---|
| 香港・シンガポール | 日英協力による航路防衛 | 日本艦隊に対抗する基地防衛 |
| インド洋・太平洋 | 任務分担 | 英艦隊の独自配備 |
| 中国利権 | 共同投資・契約保護 | 日系資本との関係悪化 |
| 戦時債務 | 借り換え・資産交換 | 返済条件の硬化 |
| 主力艦隊 | 欧州重点 | 極東増援能力も必要 |

英国にとっての問題は「日本との協力を解消すべきか」ではなく、「日本との協力を維持したまま米国を仮想敵としない海軍政策を組めるか」へ逆転する。日本側にも英国を敵にする理由はない（巨額債権、英国秩序経由の中国資源調達、海軍協力による交通の安定、戦費を厳しく監督する元老院）。ただし債権関係それ自体は戦争防止の保証ではなく、将来日本が英国の中国権益回収運動を支持したり、不利な債務整理を求めれば対立の余地はある。[^u122]

## 米国との三角関係

日米関係が悪化しても、少なくとも英国は米国側に立てない（確定）。英国の中国権益は日本との協調で形成・維持され、対日債務も残るためである。英国は「中国の既存権益では日本・フランスと協調し、海軍軍縮や大西洋の安全保障では米国と協調する」という使い分けを図る。[^u108]

1921〜22年の[ワシントン会議](/diplomacy/washington-conference.md)は、軍艦建造制限についてのみ成立し、中国問題・日英関係・太平洋の基地制限などそれ以外の論点はすべて決裂した。日英は米国と敵対こそしないが、米国の無条件の味方とすることはできなくなった（確定）。[^u125] 英国は、日本に必要な海軍力を保持させることが自国の軍縮を可能にするという論理で日本の高比率を支持しうる（ただし英海軍省・財務省・自治領政府の判断は一致しない可能性がある）。[^u125]

海軍面では、日英の共同艦隊で主力艦戦力を確保し、日本単独では通商保護と地域防衛を重視する「日英分業」が構想される。その弱点は、英国の協力を失ったとき日本が独力で制海権を維持できるかにある（検討案）。[^u127]（→[帝国海軍の戦略思想](/military/navy-strategy.md)）

## 金融協調

金本位制を離脱した後の円の信用を支える手段として、英国との通貨スワップ相当の相互信用枠、ポンド準備の保有、ロンドンでの円建て手形市場の整備が挙げられるが、日英金融協力の制度化の程度は未検討である。[^u136]（→[金本位制離脱と管理通貨制](/economy/gold-standard.md)）

## 経済政策としての日英協調

資源を世界中から集めて工業製品に変える日本にとって、国際貿易の自由の維持は経済と安全保障の双方を左右する。その意味で1889年以降の日英の海軍・通商協力は、単なる対露外交ではなく、米国に匹敵する工業国家を目指すための経済政策でもある。[^u081]（→[資源戦略](/economy/resource-strategy.md)）

# 史実との比較

| 事項 | 史実 | 本世界線 |
|---|---|---|
| 協力の起点 | 1902年日英同盟 | 1889年の対清講和金融（巨文島事件以来の利害一致） |
| 性格 | 対露軍事同盟（自動参戦条項） | 金融・通商協定から段階的に発展、正式同盟とは限らない |
| WWI参戦 | 1914年8月23日対独宣戦、青島攻略 | 英国の敗北阻止のための限定参戦（青島要塞が存在しない可能性） |
| 東方防衛 | ANZAC第一船団護衛（伊吹）、1917年地中海派遣（護衛348回・788隻） | 事前計画された常設任務、より早く大規模 |
| 戦間期 | 1921年四カ国条約で同盟解消 | 協力は維持、ワシントン会議は建造制限のみ成立 |
| 対英債権 | 戦時借款はあるが規模は限定的 | 大口債権国、代物弁済で中国権益を共同保有 |

史実の1899年英露鉄道協定では、英国は長城以北でのロシアの鉄道敷設権獲得を妨げず、ロシアは長江流域での英国の鉄道権獲得を妨げないとしたが、山海関―営口間の英系銀行の既存借款契約は追加の交換公文で保護された。[^u085][^u089]

# 却下・修正された案

* **日本が英国権益保護の前面に立つ案**：日本が英国に対露妥協を断念させるよう強く関与し、権益保護の前面に立つという見方は、「直接権益を侵されるのは英国であり、日本が単独で出しゃばる正当性はない」との判断により、日本の役割を大きく見積もりすぎていたとして修正された。[^u089]
* **戦間期の英国が米国のために日本を切り捨てる見通し**：英国にとって米国が代替不可能であるという前提は、対米債務の一部が対日債務に移っていることを踏まえて修正された。[^u118]
* **ワシントン会議の全面決裂予想**：英国が日本を仮想敵にできない構造を踏まえ、日英協調を維持したまま海軍軍縮だけが成立する方向へ見直された（最終的に建造制限のみ成立で確定）。[^u122][^u125]

# 未決の論点

* 日英関係をどこまで制度化するか（事前協議協定・共同外交・正式同盟の有無と時期）。[^u086][^u095]
* 英国の鉄道権益が南満洲（営口方面）まで実際に延びているか。[^u091]
* 英国の対日債務の規模・満期構成、債権が政府管理か民間か、借り換え拒否の可否。[^u118]
* 代物弁済で日本が取得する中国権益の範囲（威海衛など租借地を含むか）。[^u103]
* 日英金融協調（相互信用枠・ポンド準備）の制度化の程度。[^u136]
