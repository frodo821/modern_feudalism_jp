# 概要

本世界線の戦間期の中国は、史実同様に軍閥支配の時代となった。[^u104] ただし[清朝の終わり方](../events/xinhai-revolution.md)が史実と異なり、中華民国は統一国家として成立していない。北方には旧清朝の債務と官僚機構を承継する政権が、南方には共和派の政府があり、日英は旧清朝の契約を尊重する北方の軍閥への支援をやめられない。[^u123] 具体的には、溥儀は退位せずロシアへ亡命し、北方では北京・両江（南京）・湖北（武昌）の地方政権が清朝以来の対外権利義務を共同管理する[中国諸省聯合](china-federation.md)を1912年に結成し、日英はこれを中国の対外代表として承認した。南方では広州を拠点とする[中華民国](republic-of-china-canton.md)が米独ソの支援を受けた。[^e020][^e023][^e025][^e026]

日本の立場は史実と大きく異なる。日本は中国大陸に直接かつ独占の利権をもたず、その空白は英国が埋めている。[^u102] 中国は日本の勢力圏ではなく**英国の金融・商業圏**であり、日本は英国の秩序を通じて中国経済に参加する。そのため民族主義運動の主たる標的は英国となる。[^u102]

しかし日本も軍閥政治から距離を置くことは難しい。関東軍のような日本軍組織がなくても、張作霖爆殺事件や柳条湖事件に相当する事件は起こり得るし、日英が支援する軍閥指導者が謀殺される危険も相当にあった。[^u106] 中心となる構図は、**史実では関東軍が中央政府を既成事実へ引きずり込んだのに対し、この世界では外国資本と中国軍閥の結合が日英両政府を既成事実へ引きずり込む**というものである。[^u106] この「相当事件」は、1928年に聯合の実質的指導者黎元洪が怪死した[武昌公邸火災事件](../events/wuchang-residence-fire-1928.md)として現れた。[^e034]

1926年に始まった中華民国の[北伐](../events/northern-expedition.md)は湖南の大部分を得たが湖北で膠着し、1930年頃に事実上の休戦となる。1930年の中国は、聯合・中華民国・非加盟の独立軍閥・列強及び外国人自治機関による施政地域という四種の統治主体に分かれ、「**経済的には外国資本を介して結合し、政治的には分裂し、軍事的には膠着している**」。[^e032][^e037][^e039] 1931年に満洲事変に相当する日本の軍事行動は起きない。[^e039][^e040]

# 列強の配置

## 各国の立場

| 主体 | 中国での立場 |
|---|---|
| 英国 | 海関金融・鉄道・港湾・海運・銀行の有力権益保有国 |
| 日本 | 英系事業への投資・取引、資源輸入、工業製品輸出の参加者。のち代物弁済で権利者の一角に |
| フランス | 華南・西南を中心とする経済権益（インドシナと結びつく） |
| ロシア／ソ連 | 北満洲・沿海州への進出を模索[^n1] |
| 米国 | 通商機会と対中投資、門戸開放 |
| ドイツ | 敗戦で旧権益を喪失した「後発国」 |
| 中国側政府 | 条約改正・財政自主権・権益回収 |

[^u102][^u109]

1912〜30年の列強の中国国内での支援先（基本方針）は次のとおりである。基準は政体ではなく、どの地域に既存権益を持ち、どの政権を通じて将来の権益を広げられるかである。[^e023][^e024]

| 列強 | 主な支援先 | 副次的支援先 | 目的 |
|---|---|---|---|
| 英国 | 北京・両江・湖北（聯合） | 奉天・湖南 | 既存債権と商業秩序の維持 |
| 日本 | 英国とほぼ共通 | 奉天・山東 | 投資保護と朝鮮の安全保障 |
| 米国 | 南方共和政府（中華民国） | 広東自治派・四川 | 門戸開放と既存権益の再編 |
| ドイツ | 南方共和政府（1919〜33年に接近） | 山東・湖北 | 市場確保と工業製品輸出 |
| ロシア帝国 | 満洲の清朝残存勢力（溥儀を保護） | 新疆・モンゴル | 南下政策と国境地帯 |
| ソ連 | 南方革命派 | 新疆・モンゴル・中国共産主義勢力 | 革命外交と国境の安全保障 |
| フランス | 雲南・広西 | 北京・貴州 | インドシナ防衛と鉄道権益 |
| イタリア | 北京 | ― | 既存権益と武器輸出 |

[^e023]

ここでの「支援」は外交承認・借款・民間投資・軍事顧問・装備購入などであり、軍事同盟や直接派兵を意味しない。米独とソ連が同じ南方政府を支援する一見奇妙な構図となる一方、フランスは南方共和政府による雲南・広西の統合を望まないため、華南も一枚岩ではない。[^e023] 詳細は[中国の軍閥と列強の支援配置（1912〜1930）](chinese-warlords.md)を参照。

## 日本の位置

日本は中国の土地・鉄道を独占せず、安全保障と経済権益を切り離すことができる。**中国における日本の経済的利益が大きくなっても、それを守る第一義的な外交責任は必ずしも日本にない**。[^u102] 満洲に大規模な駐屯軍を置かず植民地行政も負わないため、国内の鉄道・国道・電力・化学・機械工業へ投資を優先できる（台湾の維持費と朝鮮との安全保障支出は残る）。[^u102]

1920年代には対清賠償の支払いが完了しているかもしれず、日本企業は英国の競争相手にもなる。日本にとって英国特権を永久に維持する必要はなく、「**英国の政治的特権を縮小し、中国の関税・司法主権を回復させながら、日英双方の商業契約を保護する**」方向が合理的となる。日英協調は「租界を守る同盟」から「中国市場の安定と投資安全を共同確保する協調」へ変化し得る性格を持っていた。[^n2][^u102] 日本は英国より条約改正に寛容で、北京の保守的な官僚・軍人よりも両江・湖北の穏健な条約改正派を評価するという日英の温度差があった。[^e023] ただし実際の1920年代の展開では、全中国を代表する政府が成立しなかったため英国の政治的特権（租界）は縮小せず、むしろ行政的自立性を強めた（後述「外国施政地域の準国家化」）。[^e037] 英国が大戦で巨額の対外債務を負えば、日系資本が英国の中国権益を補完し、さらに[代物弁済](war-debt-settlement.md)によって日本が権利者本人の一角となる。[^u102][^u103]

戦間期の東アジアは史実の日中対立中心ではなく、「中国の政治的・経済的自主権の回復と、英国がどこまで譲歩するか」を軸に動く。[^u102]

# 1930年の中国：四つの統治主体

## 聯合と中華民国

| 項目 | 中国諸省聯合 | 中華民国 |
|---|---|---|
| 政治的中心 | 北京・南京・武漢 | 広州 |
| 支配領域 | 華北・長江中下流域 | 広東・広西・湖南の大部分 |
| 統治理念 | 地方自治・権利義務の承継 | 共和革命・国家統一 |
| 政治体制 | 暫定的な集団指導体制 | 国民党と地方軍閥の連合政権 |
| 最高指導者 | 黎元洪の死後不在 | 蒋介石の地位が動揺 |
| 財政基盤 | 比較的強固だが分散 | 脆弱かつ戦費負担が重い |
| 軍事力 | 総兵力で優勢だが指揮権分散 | 党軍と地方軍の対立 |
| 外国支援 | 日本・英国 | 米国・ドイツ・ソ連 |
| 共産党 | 地下活動・労働運動を取り締まる | 制限付き国共合作 |
| 最大の問題 | 加盟勢力間の相互不信 | 財政難と政治的分裂 |

[^e039]

その他の勢力は、奉天系（満洲で独自政権を維持）、晋系（山西の自治と独立性）、滇系（雲南、フランスとの経済関係を背景に独立）、四川諸軍閥（省内分裂・抗争継続）、西北諸軍閥、そして実効的な政治権力を失った亡命清朝皇室である。[^e039] 中国共産党は1930年に党員5〜10万人、独立した大規模な紅軍を持たず、支持基盤の多くは聯合領内の工業都市にある。[^e029][^e032]

世界恐慌は、聯合には輸出減少・企業収益悪化・失業増加・労働運動激化を、中華民国には税収減少・軍人給与の支払い困難・北伐継続能力の低下を、独立軍閥には外国資本への依存拡大を、共産党には支持拡大の余地を、外国施政地域には行政委託の拡大と民族主義的反発をもたらした。[^e039] 聯合にも中華民国にも現状打破の能力がなく、現状を恒久的に受け入れる意思もない。[^e039]

## 外国施政地域の準国家化

1930年頃の中国大陸のコンセッションは、事実上列強が直接施政権を行使する状態になっている。[^e037] 清朝崩壊後に全中国を実効支配する政府が一度も成立せず、租界返還や条約改正を実行できる中国政府も存在しないため、租界・租借地は主権回復によって縮小するのではなく、**行政的自立性を強めた**。領土併合ではなく、中国側の施政能力不足を列強が補完するうちに事実上の直接統治へ移行したのである。[^e037][^e039]

| 権限（1930年頃）[^n2] | 内容 |
|---|---|
| 警察権 | 租界当局が排他的に行使 |
| 徴税権 | 独自の地方税・事業税 |
| 司法権 | 領事裁判及び租界内裁判制度 |
| 公共事業 | 独自予算 |
| 金融行政 | 独自の公債発行・金融機関監督 |
| 出入域管理 | 治安上の理由で強化 |
| 防衛 | 列強の軍隊・海軍 |
| 外交権 | 列強領事団 |
| 領土主権 | 名目上中国に残存 |

[^e037]

外国施政地域は、正式租界、租借地、租界外委託行政区（中国側との協定による行政権委託）、鉄道附属地、港湾管理区、外国企業の鉱工業地区の六形態をとる。財政難の聯合加盟省は、租界当局に周辺の治安維持や公共事業を委託する誘因を持った。[^n2][^e037]

| 租界・地域 | 主な列強 | 1930年の状況[^n3] |
|---|---|---|
| 上海 | 英米日仏など | 共同租界・仏租界の行政的自立が進み、事実上の国際管理都市に |
| 天津 | 英仏日伊など | 華北の不安定化で重要性が増大 |
| 漢口 | 英仏日など | 黎元洪怪死事件後に租界の治安権限を強化 |
| 九江 | 英国 | 北伐の影響を受け、聯合との保護協定を強化 |
| 広州・沙面 | 英仏 | 中華民国との政治的対立が深刻化 |
| 廈門・鼓浪嶼 | 多国間 | 福建の帰属問題に伴い行政的自立 |
| 青島 | 英日 | 英国主導の青島行政委員会が事実上の施政権を行使 |

[^e037][^e038]

戦乱を避ける中国人の流入で漢口・上海の人口は増え、外国施政地域は巨大な都市経済圏となる。[^e037] 上海は1930年代には事実上の国際管理都市として扱われる。[^e037][^e039] 青島はドイツの租借が成立せず、英国主導・日英資本の商業港から特別行政区域へ移行した「軍事占領を伴わない経済的コンセッションが、政治的混乱によって事実上の外国施政地域へ変化した代表例」である（→[青島](../regions/qingdao.md)）。[^e038]

列強の立場は一様ではない。英国は既存租界の行政権維持に直接の利益を持つ。日本は領土拡張より対外投資と通商の保護を重視し、英国や国際行政機関が法的安定性を保障すれば自ら行政を担う必要はないため、日英共同出資の企業・金融機関が増える一方、行政機構は英国系または多国間が維持する。米国は中華民国を支持して門戸開放を求めながら、米国人も租界の自治・治外法権の利益を享受しており、要求は全面撤廃ではなく租界・港湾管理機関の国際化と機会均等となる。[^n2][^e037]

聯合にとって租界は主権を制限する一方、外国資本の流入・輸出入・対外信用を支える財政的支柱でもある。ただし海関税（国家財源）と租界の地方税は別であり、租界の発展が聯合財政の改善に直結しない。この矛盾は中華民国・共産党の宣伝材料となる。[^e037] こうして1930年の中国の分裂は、軍閥間の**水平的分裂**と、主権と施政権が異なる主体に帰属する**垂直的分裂**の両方を含む。[^e037]

# 軍閥と外国資本

## 日本が巻き込まれる経路

日本が中国大陸で領土をもたなくても、中国の地方政治に関与する経済的理由は生じる。たとえば英国が北京政府と結んだ鉄道契約を奉天の軍閥が認めなければ、その鉄道会社へ出資している日本の領主系銀行団も無関係ではいられない。[^u104] 経路は次のように進む。[^u106]

1. 日本の銀行が軍閥の債券を大量に保有する。
2. [元老院](../institutions/genroin.md)の領主系銀行・企業を代表する議員が債権保護を要求する。
3. 政府が外交的に介入する。
4. 介入を正当化するため、現地の軍閥を支援する。

**軍閥と距離を置くつもりだった日本が、金融上の損失を避けようとするうちに、軍閥政治へ深く関与してしまう**。戦間期の日本最大の外交的難題は、軍事的関与を回避してきたにもかかわらず、金融資本を通じて中国の内戦に巻き込まれることである。[^u106] 日本政府が撤退したくても銀行団が認めず、英国政府が撤退を決めても日本の領主系資本が損失を嫌って抵抗する、という可能性もある。[^u106]

一方で、元老院の領主は戦費負担を嫌い、大陸派兵で軍事費を回収できる見込みも乏しい。そのため**日本は中国の軍閥政治から完全に距離を置くことはできないが、それを軍事的に解決しようとする動機も弱い**。[^u104]

## 外国系警備の軍閥化

関東軍は日本の国家予算・正規軍組織・帝国の威信を利用できた点で一般の軍閥と異なっていた。本世界線では、軍閥と外国資本と外国政府の権益保護機構が結びつくことで、別種の軍事的な自立勢力が形成される。[^u106] たとえば奉天の軍閥が英系鉄道の警備を引き受け、見返りに融資や武器購入資金を得れば、軍閥にとって鉄道は自軍の財源、外国資本にとって軍閥の政権維持は投資保護となり、両者は切れない関係になる。[^n2][^u106]

## 「奉天鉄道紛争」型の危機

1920年代に想定される危機の典型は、次のような経過をたどる。[^n4][^u104]

1. 英国系鉄道会社が日系資本を受け入れ、奉天方面の鉄道を経営する。
2. 奉天の軍閥が自主財源確保のため並行鉄道の建設や運賃規制を進める。
3. 英国の銀行団と日本の出資者が契約違反を主張する。
4. 英国は北京政府と奉天当局の双方に交渉を求め、日本は出資者保護を外交的に要請する。
5. 鉄道警備権や債務不履行をめぐって国際的な外交危機に発展する。

史実の満洲事変とはまったく異なるが、中国の地方政権と外国資本の利益対立という点で共通する構造をもつ。

# 謀略と政治的暴力

## 関東軍不在下の相当事件

史実の関東軍は事実上軍閥の一つにすぎず、軍閥として見ればそれほど奇妙な行動はしていない（「なぜ国軍が軍閥になっているのか」という問題は別として）。したがって関東軍が存在しなくても、張作霖爆殺・柳条湖に相当する事件が起きないわけではない。[^u106] **関東軍の不在は事件の不在を意味しない。実行主体が変わる**。

## 謀殺の実行主体

謀殺の実行主体と動機は次のように整理される。[^n2]

| 実行主体 | 動機 |
|---|---|
| 敵対軍閥 | 相手の基盤破壊 |
| 支援先軍閥の内部派閥 | 指導者の排除と外国支援の引継ぎ |
| 中国民族主義系の武装勢力 | 外国権益と結んだ体制への攻撃 |
| 外国系警備組織の一部 | 別政権の擁立 |
| 第三国の情報・軍事関係者 | 英日系資本の影響力の弱体化 |

英国政府が命じるのではなく、現地関係者が政府の意向に反して行動する形が想定される。とくに**支援先の軍閥指導者が外国資本から自立しようとした瞬間に、支援関係の内部で対立が起こる**。[^u106]

## 武昌公邸火災事件（1928年）

日英が支援する軍閥指導者の謀殺という危険は、具体的な事件として現実となった。1928年6月3日、聯合の実質的指導者[黎元洪](../people/li-yuanhong.md)が湖北省武昌の公邸の火災で死亡し、出火原因も直接の死因も不明のまま、湖北軍将校の排除協議文書や中華民国情報機関との接触を示す書簡など、複数の陰謀説を支える真偽不明の「証拠」が現れた。外国勢力の関与は確認されていない。[^e027][^e034] 正式名称は「武昌公邸火災事件」、通称は「黎元洪怪死事件」で、真相は明らかでない。[^n5][^e034]

この事件は、史実の張作霖爆殺事件が日本の対満洲政策の矛盾から生じたのに対し、**聯合自身が抱える地方自治と軍事的中央集権化の矛盾**から生じたものと位置づけられる。日英は黎元洪政権の存続で利益を得ており、事件を起こす必然性はない。[^e027][^e033] 日本は謀殺の可能性を排除せず公式な犯人認定を避け、英国は政治的安定と既存契約の履行を優先した。事件後、日英は特定の人物を擁立すれば謀殺関与の疑惑を強めるため擁立できず、聯合の既存機関（財政委員会）を支援し、加盟諸省間を調停した。[^e033][^e034][^e035] 外国資本と軍閥の結合が日英両政府を既成事実へ引きずり込むという構図は、ここでは「日英が特定人物を擁立できない」という形で表れた。詳細は[武昌公邸火災事件（1928年）](../events/wuchang-residence-fire-1928.md)を参照。

## 柳条湖型の謀略

日英資本が参加する奉天の鉄道が爆破され、軍閥が敵対勢力の犯行と発表して鉄道警備の名目で占領を進め、外国人顧問や警備部隊が関与する、という事件は起こり得る。しかし実行者が中国の軍閥ならまず軍閥間戦争になり、英系警備組織なら英国政府の承認問題となり、日本には大陸駐屯軍がないため満洲全域の占領は困難である。つまり「**謀略事件は起こる。しかし満洲事変と同じ規模の領土占領へ発展するには追加条件が必要**」である。[^n2][^u106] 結末が満洲国型の国家建設か、統一政権による外国権益の回収かは史実より不確実である。[^u106]

1931年に史実の満洲事変に相当する日本の軍事行動は起きなかった。[^e039][^e040] 日本は中国の経済権益を英国との協調で維持しており、満洲は聯合に加盟しない奉天系軍閥が独自政権を維持する。[^e012][^e039] 満洲事変がないため、日本は1933年の国際連盟脱退通告もせず、連盟に残留する。[^e049][^e054]

# 民族主義と買弁資本批判

## 激化する非難

中華民国が素直に成立せず、どこかの軍閥を公然と支援するなら、買弁資本に対する非難は史実より激しくなる。[^u106] 英国が北方軍閥へ融資し、軍閥が英系鉄道権益を保障し、日本も代物弁済で取得した鉄道株式・債券で関与し、日英がその軍閥を正統政府として承認する、という構図に対し、反対勢力は「**外国資本が中国の鉄道と海関を掌握し、その利益を守る軍閥に資金を提供し、最後にはその軍閥を中国の合法政府と認めている**」と批判できる。[^u106]

英国の中国権益が史実より大きいため、反英運動は中国政治の中心争点になる。日本も「英国とともに中国の軍閥支配から利益を得ている国」として批判される。[^u102][^u106] ただし「買弁」は民族主義的非難の概念であり、外国資本と提携しつつ中国国内の産業育成を目指す勢力もあり得る。[^u106]

## 五四運動と労働運動

史実の山東問題（ドイツ権益の日本への移転）は本世界線に存在しない。1919年前後の学生運動（五四運動相当）は、反日よりも、パリ講和会議で清朝以来の外国権益（特に英国・日本の権益）が維持されたことへの反発と、「中国諸省聯合」「聯合体制」への反対の性格が強い。[^e029][^e038] 日英資本による工業化が史実以上であるため、1925年の五・三〇事件型の事件はむしろ起こりやすいが、外国企業との契約履行を存立基盤とする聯合は労働運動を厳しく取り締まる。中国共産党は中華民国と協力しながら、その支持基盤（上海・武漢・天津・北京の労働者・知識人）の多くは聯合領内にある、という構図になる。[^e029] 聯合の最大の弱点は政治的正統性であり、配下の青年将校・学生・知識人には中華民国の方が魅力的であった。[^e030]

## 日本の選択肢

| 選択肢 | 性格 |
|---|---|
| 英国の金融秩序のため軍閥支援を継続 | 既存債権は守れるが批判の的となる |
| 中国統一を優先し外国特権の見直しを容認 | 長期的な市場安定を狙う |
| 投資関係は維持しつつ軍閥への政治的支援から距離を置く | 魅力的だが実現は困難 |

戦間期最大の政治的危機は、「**中国の統一を妨げてまで既存の軍閥と契約を維持するのか、それとも統一政府と交渉して外国権益を再編するのか**」という問いである。[^u106]

# 日英仏対米独の対立軸

## 既得権の保全と再編

日米関係が悪化しても、英国は少なくとも米国側には立てない。フランスも中国に利権をもつため米国側に立つかは微妙である。[^u108] 英国の中国権益は日本との協調で形成・維持され、大戦中の日本の軍需供給による対日債務も残るからである。フランスは華南・西南権益とインドシナで日英と利害が近いが、対米戦時債務があり米国との全面対立は避ける。[^u108]

| 論点 | 英国 | フランス | 日本 |
|---|---|---|---|
| 清朝以来の借款継承 | 非常に重要 | 重要 | 共同投資の範囲で重要 |
| 鉄道・鉱業特権 | 広範 | 華南・西南 | 英系権益への出資 |
| 民族主義的権益回収 | 直接影響 | 直接影響 | 間接・直接 |
| 米国の門戸開放要求 | 既得権との調整が必要 | 既得権との調整が必要 | 通商平等そのものには利益もある |
| 対米戦時債務 | 重要 | 非常に重要 | 本世界線の債権債務次第 |

[^u108]

利害は「既存契約の保全（英・日・仏）」対「市場開放・契約再編（米・中国の改革／革命勢力の一部）」に分かれるが、固定的な同盟陣営ではない。英国は「中国の既存権益では日本・フランスと協調し、海軍軍縮や大西洋の安全保障では米国との協調を維持する」。[^u108] さらにドイツが米国の側に加わり、日英仏（既得権保全）対米独（再編）という経済的対立軸が生まれる。米独は「日英仏の既得権改定では協力し、具体的な商業契約では競争する」関係にある（→[戦間期の米独接近と米国内の宣伝戦](us-germany-relations.md)）。[^u109]

## 日本の柔軟性

日本は排他的領域支配をもたず後から資本参加したため、債権・株式価値が保全されれば行政特権の縮小を許容でき、英仏より権益改定に柔軟になり得る。たとえば鉄道を中国との合弁会社へ改組し、日本に長期配当と経営参加権を保障する方式がある。また**英仏の中国利権が大きいほど、米国は日本だけを孤立させることが難しくなる**。[^u108] 最大の問題は、中国の民族主義政府が「外国企業の参入は認めるが、軍閥と結んだ排他的利権契約は認めない」と宣言した場合である。[^u108]

## 中国国内の分裂

中国の統一派・共和派は米国から資金、ドイツから工業設備・軍事技術を導入し、英日仏資本に支えられた北方軍閥政権に対抗する。ただし統一派は米独の代理人ではない。[^u109] 中国資本そのものも、英系事業から利益を得る「親英日派」と「親米独派」に分裂し得る。[^u110] この分裂は、日英が支える中国諸省聯合（契約承継型の連合国家）、米独・ソ連が支える中華民国（中央集権型の統一共和国）、雲南・広西・山西・四川などの地方自治・独立維持派という三つの政治構想として具体化した。[^e023] ソ連が中国の革命勢力へ資金や軍事顧問を提供し英国系鉄道・港湾の権益回収を支援すれば、英国の対ソ姿勢は硬化する（→[ソ連承認問題と旧ロシア債務](soviet-recognition.md)）。[^u116]

# 「誰が契約を履行するか」と軍縮会議

## 米国の妥協可能範囲

米国が中国権益への口出しをやめない限り、日英米の合意は難しい。[^u123] 米国が妥協できる範囲は次のように整理される。[^n2][^u123]

| 事項 | 米国の姿勢 |
|---|---|
| 1889年以来の正当な既存債権 | 尊重し得る |
| 既存の鉄道・港湾事業権 | 排他性を制限する条件で尊重 |
| 新規投資 | 機会均等を要求 |
| 特定軍閥の政治的承認 | 事実上の交渉相手としては容認の余地 |
| 特定軍閥への排他的軍事・財政支援 | 深刻な対立要因 |
| 日英海軍協力 | 対米戦を想定しているかが問題 |

米国の妥協案は「既存の英仏日系債権・鉄道契約は尊重し、新たな排他的特権は設定せず、既存契約も内容を公開する」というものになり得る。最大の障害は既存契約そのものではなく、**誰が契約を履行するか**、すなわち中国全体を代表する政府の不在である。[^u123] 北方政権が統一に反対せず債務承継を条件とする全国的妥協を模索しているなら米国にも協調の余地があるが、外国融資で軍事的に自立し統一交渉を拒むなら米国が問題視する理由が強まる。[^u123]

## 会議での決裂

1921〜22年の軍縮会議は軍艦建造制限についてのみ成立し、中国問題（条約・債務・軍閥支援）は決裂した。[^u125] 史実の九カ国条約に相当する協定は成立しない。詳細は[ワシントン会議と主力艦建造停止条約](washington-conference.md)を参照。

# 1930年代の展開

* **1931年の金融危機**：欧州金融危機は本世界線でも起き、日本の対英債権の扱いが論点となる。中国では恐慌による各政権の財政危機が東アジアの次の重要問題となった（→[1931年欧州通貨危機と日英金融協力](../events/currency-crisis-1931.md)）。[^e040]
* **通貨**：1931年以降、聯合や外国施政地域では円・ポンドの貿易金融が重要化し、中国の銀本位制との為替関係も問題となった。[^n2][^e042]
* **市場**：恐慌下の各工業国の余剰生産力の受け皿として、聯合は日英の鉄道・発電・工場設備・消費財、中華民国は米独ソの軍需・交通・工業設備、満洲は日米独などの農業・鉱山・鉄道設備、西南軍閥はフランスなど、外国施政地域は各国の港湾・都市インフラの市場となる。購買力不足のため、借款・直接投資を伴う「金融支援と工業製品輸出の一体化」が進んだ。[^n2][^e046]
* **日独の対中競争**：1933年のナチス政権成立後、日本は聯合と既存契約の保護、ドイツは中華民国への経済進出を進め、日独は中国で異なる勢力を支援して経済的に競争する。ドイツが反共を求めれば国共合作が再び破綻の危機に追い込まれる可能性がある。[^n2][^e054][^e055]
* **資源**：1937年時点で、聯合は日本の鉄鉱石・原料炭・銅の輸入元となる。中国における鉱山投資・長期供給契約はかろうじて成立したが[^n6]、聯合の政治的不安定による政治リスクは残る（→[資源戦略](../economy/resource-strategy.md)）。[^e072][^e081]

# 史実との比較

- 史実の張作霖爆殺事件（1928年）は関東軍の河本大作らが起こし、柳条湖事件（1931年）は関東軍が南満洲鉄道を爆破して軍事行動の口実とした。東京政府の不拡大方針は関東軍に無視された。[^u104][^u106] 本世界線では日露戦争がなく、旅順・大連の租借地も満鉄もないため、関東軍が存在する理由は乏しい。[^u104]
- 史実では1925年の五・三〇事件以降、対英反帝国主義運動が拡大し、1927年に国民政府系勢力が漢口・九江の英国租界を回収した。英国は1926年以降条約改正へ転じ、1927年に漢口租界の行政権を返還、1928年に中国の関税自主権を承認した。[^u102][^u106] 本世界線では北伐が武漢に達しないため漢口・九江の租界は回収されず、漢口は黎元洪怪死事件後に治安権限を強化し、九江は聯合との保護協定を強化する。[^n3][^e037]
- 史実の上海共同租界の工部局は徴税・警察・道路・病院・学校・行政規則制定を担い、1928年まで中国人は董事になれなかった。工部局は英国政府直属ではなく外国人納税者を基盤とする自治行政機関で、領事団とも権限争いがあった。[^e037]
- 史実では日本が1914年に青島を攻略して山東権益を得、1919年の山東問題が五四運動を引き起こした。本世界線ではドイツの膠州湾租借が成立せず、山東問題・済南事件は史実の形では起きない。[^e038]
- 史実の満洲事変（1931年）と国際連盟脱退（1933年）は、本世界線では起きない。[^e039][^e054]
- 史実の九カ国条約は既存の外国権益をすべて無効にするものではなく、第3条も特定事業に必要な権利の取得を一律には禁じなかった。[^u123]
- 史実のワシントン会議では四カ国条約で日英同盟が解消され、九カ国条約で中国の主権・領土保全・機会均等が確認された。[^u108]

# 編集注：却下・修正された案

- **北方軍閥政権という抽象的な整理**：「北方の軍事政権 対 南方の共和政権」の二極構造は、会話ログ2で華北・長江・華南の三極構造と、北京・両江・湖北による中国諸省聯合として具体化された。北方＝親英、南方＝反英という単純な図式も修正された。[^e021][^e022][^e025]
- **租界の縮小・主権回復の方向（検討案）**：日英協調が英国の政治的特権を縮小し中国の関税・司法主権を回復させる方向へ変化し得るという前編の見通し（U102）は、実際には全中国を代表する政府が成立しなかったため租界が逆に行政的自立性を強めたとする会話ログ2の設定（E37）と方向が異なる。日本が行政特権より投資・通商保護を重視する点は維持された。[^u102][^e037]
- **謀殺の実行主体の検討案**：張作霖爆殺相当の事件は、実行主体の特定されない武昌公邸火災事件として確定した。湖北軍強硬派による明白な暗殺とする案（E33）も採られなかった。[^u106][^e033][^e034]
- **関東軍不在ゆえ満洲事変型事件は起きにくい**：日露戦争・旅順大連租借・満鉄がないので史実型の事件は成立しにくい、という当初の整理（U104）は、関東軍は事実上一軍閥にすぎず事件の構造は残るという作者の指摘（U106）を受けて修正された。[^u104][^u106]
