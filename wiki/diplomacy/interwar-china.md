# 概要

本世界線の戦間期の中国は、史実同様に軍閥支配の時代となる（確定）。[^u104] ただし[清朝の終わり方](/events/xinhai-revolution.md)が史実と異なり、中華民国は統一国家として成立していない。北方には旧清朝の債務と官僚機構を承継する軍事政権が、南方には共和派の政府があり、日英は旧清朝の契約を尊重する北方の軍閥への支援をやめられない（確定）。[^u123]

日本の立場は史実と大きく異なる。日本は中国大陸に直接かつ独占の利権をもたず、その空白は英国が埋めている（確定）。[^u102] 中国は日本の勢力圏ではなく**英国の金融・商業圏**であり、日本は英国の秩序を通じて中国経済に参加する。そのため民族主義運動の主たる標的は英国となる。[^u102]

しかし日本も軍閥政治から距離を置くことは難しい。関東軍のような日本軍組織がなくても、張作霖爆殺事件や柳条湖事件に相当する事件は起こり得るし、日英が支援する軍閥指導者が謀殺される可能性も相当ある（確定）。[^u106] 中心となる構図は、**史実では関東軍が中央政府を既成事実へ引きずり込んだのに対し、この世界では外国資本と中国軍閥の結合が日英両政府を既成事実へ引きずり込む**というものである。[^u106]

| 主体 | 中国での立場 |

| 英国 | 海関金融・鉄道・港湾・海運・銀行の有力権益保有国 |
| 日本 | 英系事業への投資・取引、資源輸入、工業製品輸出の参加者。のち代物弁済で権利者の一角に |

| 米国 | 通商機会と対中投資、門戸開放 |
| ドイツ | 敗戦で旧権益を喪失した「後発国」 |
| 中国側政府 | 条約改正・財政自主権・権益回収 |

[^u102][^u109]

## 日本の位置

日本は中国の土地・鉄道を独占せず、安全保障と経済権益を切り離すことができる。**中国における日本の経済的利益が大きくなっても、それを守る第一義的な外交責任は必ずしも日本にない**。[^u102] 満洲に大規模な駐屯軍を置かず植民地行政も負わないため、国内の鉄道・国道・電力・化学・機械工業へ投資を優先できる（台湾の維持費と朝鮮との安全保障支出は残る）。[^u102]

1920年代には対清賠償の支払いが完了しているかもしれず、日本企業は英国の競争相手にもなる。日本にとって英国特権を永久に維持する必要はなく、「**英国の政治的特権を縮小し、中国の関税・司法主権を回復させながら、日英双方の商業契約を保護する**」方向が合理的となる。日英協調は「租界を守る同盟」から「中国市場の安定と投資安全を共同確保する協調」へ変化し得る（検討案）。[^u102] 英国が大戦で巨額の対外債務を負えば、日系資本が英国の中国権益を補完し、さらに[代物弁済](/diplomacy/war-debt-settlement.md)によって日本が権利者本人の一角となる。[^u102][^u103]

戦間期の東アジアは史実の日中対立中心ではなく、「中国の政治的・経済的自主権の回復と、英国がどこまで譲歩するか」を軸に動く。[^u102]

# 軍閥と外国資本

## 日本が巻き込まれる経路

日本が中国大陸で領土をもたなくても、中国の地方政治に関与する経済的理由は生じる。たとえば英国が北京政府と結んだ鉄道契約を奉天の軍閥が認めなければ、その鉄道会社へ出資している日本の領主系銀行団も無関係ではいられない。[^u104] 経路は次のように進む。[^u106]

1. 日本の銀行が軍閥の債券を大量に保有する。
2. [元老院](/institutions/genroin.md)の領主系銀行・企業を代表する議員が債権保護を要求する。
3. 政府が外交的に介入する。
4. 介入を正当化するため、現地の軍閥を支援する。

**軍閥と距離を置くつもりだった日本が、金融上の損失を避けようとするうちに、軍閥政治へ深く関与してしまう**。戦間期の日本最大の外交的難題は、軍事的関与を回避してきたにもかかわらず、金融資本を通じて中国の内戦に巻き込まれることである。[^u106] 日本政府が撤退したくても銀行団が認めず、英国政府が撤退を決めても日本の領主系資本が損失を嫌って抵抗する、という可能性もある。[^u106]

一方で、元老院の領主は戦費負担を嫌い、大陸派兵で軍事費を回収できる見込みも乏しい。そのため**日本は中国の軍閥政治から完全に距離を置くことはできないが、それを軍事的に解決しようとする動機も弱い**。[^u104]

## 外国系警備の軍閥化

関東軍は日本の国家予算・正規軍組織・帝国の威信を利用できた点で一般の軍閥と異なっていた。本世界線では、軍閥と外国資本と外国政府の権益保護機構が結びつくことで、別種の軍事的な自立勢力が形成される。[^u106] たとえば奉天の軍閥が英系鉄道の警備を引き受け、見返りに融資や武器購入資金を得れば、軍閥にとって鉄道は自軍の財源、外国資本にとって軍閥の政権維持は投資保護となり、両者は切れない関係になる（検討案）。[^u106]

## 仮想「奉天鉄道紛争」（検討案）

作中で想定された1920年代の架空事例である。[^u104]

1. 英国系鉄道会社が日系資本を受け入れ、奉天方面の鉄道を経営する。
2. 奉天の軍閥が自主財源確保のため並行鉄道の建設や運賃規制を進める。
3. 英国の銀行団と日本の出資者が契約違反を主張する。
4. 英国は北京政府と奉天当局の双方に交渉を求め、日本は出資者保護を外交的に要請する。
5. 鉄道警備権や債務不履行をめぐって国際的な外交危機に発展する。

史実の満洲事変とはまったく異なるが、中国の地方政権と外国資本の利益対立という点で共通する構造をもつ。

# 謀略と政治的暴力

## 関東軍不在下の相当事件

ユーザーの評価では、史実の関東軍は事実上軍閥の一つにすぎず、軍閥として見ればそれほど奇妙な行動はしていない（「なぜ国軍が軍閥になっているのか」という問題は別として）。したがって関東軍が存在しなくても、張作霖爆殺・柳条湖に相当する事件が起きないわけではない（確定）。[^u106] **関東軍の不在は事件の不在を意味しない。実行主体が変わる**。

## 謀殺の実行主体（検討案）

| 実行主体 | 動機 |
|---|---|
| 敵対軍閥 | 相手の基盤破壊 |
| 支援先軍閥の内部派閥 | 指導者の排除と外国支援の引継ぎ |
| 中国民族主義系の武装勢力 | 外国権益と結んだ体制への攻撃 |
| 外国系警備組織の一部 | 別政権の擁立 |
| 第三国の情報・軍事関係者 | 英日系資本の影響力の弱体化 |

英国政府が命じるのではなく、現地関係者が政府の意向に反して行動する形が想定される。とくに**支援先の軍閥指導者が外国資本から自立しようとした瞬間に、支援関係の内部で対立が起こる**。[^u106]

## 柳条湖型の謀略

日英資本が参加する奉天の鉄道が爆破され、軍閥が敵対勢力の犯行と発表して鉄道警備の名目で占領を進め、外国人顧問や警備部隊が関与する、という事件は起こり得る。しかし実行者が中国の軍閥ならまず軍閥間戦争になり、英系警備組織なら英国政府の承認問題となり、日本には大陸駐屯軍がないため満洲全域の占領は困難である。つまり「**謀略事件は起こる。しかし満洲事変と同じ規模の領土占領へ発展するには追加条件が必要**」である（検討案）。[^u106] 結末が満洲国型の国家建設か、統一政権による外国権益の回収かは史実より不確実である。[^u106]

# 民族主義と買弁資本批判

## 激化する非難

中華民国が素直に成立せず、どこかの軍閥を公然と支援するなら、買弁資本に対する非難は史実より激しくなるかもしれない（確定）。[^u106] 英国が北方軍閥へ融資し、軍閥が英系鉄道権益を保障し、日本も代物弁済で取得した鉄道株式・債券で関与し、日英がその軍閥を正統政府として承認する、という構図に対し、反対勢力は「**外国資本が中国の鉄道と海関を掌握し、その利益を守る軍閥に資金を提供し、最後にはその軍閥を中国の合法政府と認めている**」と批判できる。[^u106]

英国の中国権益が史実より大きいため、反英運動は中国政治の中心争点になる。日本も「英国とともに中国の軍閥支配から利益を得ている国」として批判される。[^u102][^u106] ただし「買弁」は民族主義的非難の概念であり、外国資本と提携しつつ中国国内の産業育成を目指す勢力もあり得る。[^u106]

## 日本の選択肢

| 選択肢 | 性格 |
|---|---|
| 英国の金融秩序のため軍閥支援を継続 | 既存債権は守れるが批判の的となる |
| 中国統一を優先し外国特権の見直しを容認 | 長期的な市場安定を狙う |
| 投資関係は維持しつつ軍閥への政治的支援から距離を置く | 魅力的だが実現は困難 |

戦間期最大の政治的危機は、「**中国の統一を妨げてまで既存の軍閥と契約を維持するのか、それとも統一政府と交渉して外国権益を再編するのか**」という問いである。[^u106]

# 日英仏対米独の対立軸

## 既得権の保全と再編

日米関係が悪化しても、英国は少なくとも米国側には立てない。フランスも中国に利権をもつため米国側に立つかは微妙である（確定）。[^u108] 英国の中国権益は日本との協調で形成・維持され、大戦中の日本の軍需供給による対日債務も残るからである。フランスは華南・西南権益とインドシナで日英と利害が近いが、対米戦時債務があり米国との全面対立は避ける。[^u108]

| 論点 | 英国 | フランス | 日本 |
|---|---|---|---|
| 清朝以来の借款継承 | 非常に重要 | 重要 | 共同投資の範囲で重要 |
| 鉄道・鉱業特権 | 広範 | 華南・西南 | 英系権益への出資 |
| 民族主義的権益回収 | 直接影響 | 直接影響 | 間接・直接 |
| 米国の門戸開放要求 | 既得権との調整が必要 | 既得権との調整が必要 | 通商平等そのものには利益もある |
| 対米戦時債務 | 重要 | 非常に重要 | 本世界線の債権債務次第 |

[^u108]

利害は「既存契約の保全（英・日・仏）」対「市場開放・契約再編（米・中国の改革／革命勢力の一部）」に分かれるが、固定的な同盟陣営ではない。英国は「中国の既存権益では日本・フランスと協調し、海軍軍縮や大西洋の安全保障では米国との協調を維持する」。[^u108] さらにドイツが米国の側に加わり、日英仏（既得権保全）対米独（再編）という経済的対立軸が生まれる。米独は「日英仏の既得権改定では協力し、具体的な商業契約では競争する」関係にある（→[戦間期の米独接近と米国内の宣伝戦](/diplomacy/us-germany-relations.md)）。[^u109]

## 日本の柔軟性

日本は排他的領域支配をもたず後から資本参加したため、債権・株式価値が保全されれば行政特権の縮小を許容でき、英仏より権益改定に柔軟になり得る。たとえば鉄道を中国との合弁会社へ改組し、日本に長期配当と経営参加権を保障する方式がある。また**英仏の中国利権が大きいほど、米国は日本だけを孤立させることが難しくなる**。[^u108] 最大の問題は、中国の民族主義政府が「外国企業の参入は認めるが、軍閥と結んだ排他的利権契約は認めない」と宣言した場合である。[^u108]

## 中国国内の分裂

中国の統一派・共和派は米国から資金、ドイツから工業設備・軍事技術を導入し、英日仏資本に支えられた北方軍閥政権に対抗する。ただし統一派は米独の代理人ではない。[^u109] 中国資本そのものも、英系事業から利益を得る「親英日派」と「親米独派」に分裂し得る。[^u110] ソ連が中国の革命勢力へ資金や軍事顧問を提供し英国系鉄道・港湾の権益回収を支援すれば、英国の対ソ姿勢は硬化する（→[ソ連承認問題と旧ロシア債務](/diplomacy/soviet-recognition.md)）。[^u116]

# 「誰が契約を履行するか」と軍縮会議

## 米国の妥協可能範囲

米国が中国権益への口出しをやめない限り、日英米の合意は難しい（確定）。[^u123] 米国が妥協できる範囲は次のように整理される（検討案）。[^u123]

| 事項 | 米国の姿勢 |
|---|---|
| 1889年以来の正当な既存債権 | 尊重し得る |
| 既存の鉄道・港湾事業権 | 排他性を制限する条件で尊重 |
| 新規投資 | 機会均等を要求 |
| 特定軍閥の政治的承認 | 事実上の交渉相手としては容認の余地 |
| 特定軍閥への排他的軍事・財政支援 | 深刻な対立要因 |
| 日英海軍協力 | 対米戦を想定しているかが問題 |

米国の妥協案は「既存の英仏日系債権・鉄道契約は尊重し、新たな排他的特権は設定せず、既存契約も内容を公開する」というものになり得る。最大の障害は既存契約そのものではなく、**誰が契約を履行するか**、すなわち中国全体を代表する政府の不在である。[^u123] 北方政権が統一に反対せず債務承継を条件とする全国的妥協を模索しているなら米国にも協調の余地があるが、外国融資で軍事的に自立し統一交渉を拒むなら米国が問題視する理由が強まる。[^u123]

## 会議での決裂

1921〜22年の軍縮会議は軍艦建造制限についてのみ成立し、中国問題（条約・債務・軍閥支援）は決裂した（確定）。[^u125] 史実の九カ国条約に相当する協定は成立しない。詳細は[ワシントン会議と主力艦建造停止条約](/diplomacy/washington-conference.md)を参照。

# 史実との比較

- 史実の張作霖爆殺事件（1928年）は関東軍の河本大作らが起こし、柳条湖事件（1931年）は関東軍が南満洲鉄道を爆破して軍事行動の口実とした。東京政府の不拡大方針は関東軍に無視された。[^u104][^u106] 本世界線では日露戦争がなく、旅順・大連の租借地も満鉄もないため、関東軍が存在する理由は乏しい。[^u104]
- 史実では1925年の五・三〇事件以降、対英反帝国主義運動が拡大し、1927年に国民政府系勢力が漢口・九江の英国租界を回収した。英国は1926年以降条約改正へ転じ、1927年に漢口租界の行政権を返還、1928年に中国の関税自主権を承認した。[^u102][^u106]
- 史実の九カ国条約は既存の外国権益をすべて無効にするものではなく、第3条も特定事業に必要な権利の取得を一律には禁じなかった。[^u123]
- 史実のワシントン会議では四カ国条約で日英同盟が解消され、九カ国条約で中国の主権・領土保全・機会均等が確認された。[^u108]

# 却下・修正された案

- **関東軍不在ゆえ満洲事変型事件は起きにくい**：日露戦争・旅順大連租借・満鉄がないので史実型の事件は成立しにくい、という当初の整理（U104）は、関東軍は事実上一軍閥にすぎず事件の構造は残るというユーザーの指摘（U106）を受けて修正された。[^u104][^u106]

# 未決の論点

- 張作霖に相当する軍閥指導者が誰か、日英が支援する軍閥と謀殺事件の具体像。[^u106]
- 結末が満洲国型の国家建設か、統一政権による外国権益の回収か。[^u106]
- 北方政権の姿勢（統一への妥協を模索するか、統一交渉を拒むか）。[^u123]
- 中国統一派の具体的な勢力と、統一戦争の帰結。[^u109]
- フランスが最終的にどちら側に立つか。[^u108]
