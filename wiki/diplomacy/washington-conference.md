# 概要

1921年から1922年にかけて開かれたワシントン会議は、本世界線では**軍艦建造制限についてのみ成立し、それ以外の論点はすべて決裂した**会議である。中国問題（旧清朝以来の条約・債務・軍閥支援）、日英の外交・軍事協力の制限、太平洋の基地制限はいずれも合意に至らなかった。その結果、日英は米国と敵対こそしないものの、米国を無条件の味方とすることはできなくなった。[^u125]

成立したのは1922年の「ワシントン主力艦建造停止条約」である。条約は、建造中の主力艦の廃棄、主力艦新規起工の原則10年間の停止、航空母艦の定義と砲装制限の三本柱からなり、史実の5：5：3のような主力艦の保有比率は設定しなかった。巡洋艦・駆逐艦・潜水艦・空母の総保有量にも制限はない。[^u131][^u132]

この条約は外交的な和解ではなく、**政治的な対立を残したまま財政負担だけを軽減する技術的な軍備管理協定**と位置づけられる。中国権益、日英協調、太平洋の基地、主力艦の保有比率は何も決着しておらず、補助艦をめぐる対立は1930年の[ロンドン海軍軍縮会議](/diplomacy/london-naval-conference-1930.md)へ持ち越された。[^u131]

# 背景

## 史実型の包括合意が成立しない理由

史実のワシントン会議は、五カ国条約（米英日5：5：3、仏伊1.75）、四カ国条約（日英同盟に代わる協議体制）、九カ国条約（中国の領土保全と機会均等）という三つの取引を一括で成立させた。本世界線では、これらの一括成立は不自然とされる。[^u117]

| 障害 | 内容 |
|---|---|
| 日本の艦隊規模と日英協調 | 日本の重工業化と海軍整備が早く、1914年以来英国へ海軍協力を提供しているため、史実の比率をそのまま受け入れる理由が弱い |
| 英国と日本の特別な関係 | 英国は中国権益の形成・維持と戦時債務の両面で日本と結びついており、日本との協力を解消しにくい |
| 中国の既存権益 | 英仏日の巨大な既存権益と、米国の市場開放要求が正面から衝突する |
| 米国の脅威評価 | 米国から見れば、5：5：3でも日英が協調すれば日英合算で「8」に向き合うことになる |

[^u117]

## 日英仏 対 米の利害配置

戦間期の中国では、日本は独占的な直接権益を持たず、英国の金融・商業秩序を通じて中国経済に参加している（詳細は[戦間期の中国](/diplomacy/interwar-china.md)）。日米関係が悪化する場合、少なくとも英国は米国の側に立てず、中国利権を持つフランスが米国側に立つかも微妙である。[^u108]

英国は「中国の既存権益では日本・フランスと協調し、海軍軍縮や大西洋の安全保障では米国との協調を維持する」という使い分けを望む。米国が中国問題を日英協調の解消と結びつければ、英国は難しい選択を迫られる。会議の争点は、既存の借款・租界・鉄道契約の維持範囲、中国新政府の契約改定権、米企業の新規参入機会、日英の金融・海軍協力の維持範囲となる。[^u108]

## 英国が日本を切り捨てられない理由

英国の戦時債務の一部は、米国ではなく日本に対するものになっている。英国にとっては、米国の歓心を買うために日本との関係を損ね、日本から「金で返せ」と迫られる方がはるかに厳しい。[^u118] 日本は英国にとって、債権者・工業製品の供給国・中国事業の共同投資者・海軍協力の相手を兼ねる存在であり（[日英戦時債務整理](/diplomacy/war-debt-settlement.md)を参照）、第一次世界大戦では英帝国の東方防衛を相当程度肩代わりした（[第一次世界大戦と日本](/events/world-war-one.md)）。[^u118][^u120]

「巨額の自国債権を持つ国を仮想敵として設定する必要があるか」という問いに対し、英国が日本を仮想敵にすれば、対日戦備の支出増が対日返済能力を損なうという矛盾が生じる。英国の課題は「日本との協力を解消すべきか」ではなく、「日本との協力を維持したまま、米国を仮想敵としない海軍政策を組めるか」へと逆転する。日本側にも英国を敵とする理由はない。[^u122]

## 中国問題での決裂

米国が中国権益への口出しをやめない限り合意は難しい。中華民国が統一国家として成立していない以上、日英は従前の契約（旧清朝の条約・債務）を尊重する軍閥への支援をやめられない。[^u123]

米国が受け入れ得る妥協（既存債権の尊重、新たな排他的特権の禁止、既存契約の公開）はあり得たが、最大の障害は既存契約そのものではなく「誰が契約を履行するか」であった。日英は「清国政府と合法に契約し、それを承継・返済しているのが北方政府である」と主張し、米国と中国の共和派は「外国金融機関が債権保全のために特定軍閥の軍事支配を支援し、統一を妨げている」と主張する。中国全体を代表する政府が存在しないため、九カ国条約に相当する協定は当事者の段階で成立しなかった。[^u123]

一方で米国議会にも「中国の鉄道利権のために、なぜ巨額の戦艦建造費を払うのか」という疑問があり、米国は中国問題と建艦制限を切り離す方針（B案）に傾いた。これが「軍縮だけ成立、中国問題では決裂」という結果につながった。[^u123]

# 交渉の構図

## 三国の利害

| 国 | 建造停止に対する利害 |
|---|---|
| 米国 | 多数の大型主力艦が建造中で、継続には議会の支出承認が必要。日英同時の建艦競争は高価で、議会も無制限の軍拡を望まない。建造停止が決裂した場合の政治コストが高いため、日英の離間工作に失敗した時点で交渉力が低下する |
| 英国 | 戦時債務が重く、老朽戦艦の整理を急ぐ。日本に必要な海軍力を保持させることが英国自身の軍縮を可能にする（ただし海軍省・財務省・自治領政府の判断は一致しない可能性） |
| 日本 | 艦隊決戦主義を持たず、戦艦の大量保有を求めていない。主力艦建造競争を止め、浮いた予算を巡洋艦・駆逐艦・航空機・商船護衛へ回したい |

[^u125][^u127][^u130]

日本の元老院は、建艦競争の決裂にも冷淡であった。会議が決裂すれば、元老院は「中国の債権を守るために、なぜ米国と戦艦建造競争をしなければならないのか」と政府を問い詰めることになる。日露戦争を避けるほど戦費に慎重だった国家が、中国の金融権益をめぐって対米軍拡競争に引き込まれる、という皮肉は避けられた。[^u117]

## 会議前の三国海軍（検討案）

会議直前（1921年11月）の第一線に配備可能な完成艦について、次のレンジが仮置きされている（検討案）。[^u130]

| 艦種 | 英国 | 米国 | 日本 |
|---|---|---|---|
| 戦艦 | 18〜24 | 16〜20 | 5〜7 |
| 巡洋戦艦 | 4〜6 | 0〜2 | 2〜4 |
| 巡洋艦 | 55〜80 | 15〜30 | 20〜30 |
| 駆逐艦 | 150〜230 | 140〜220 | 70〜110 |
| 潜水艦 | 70〜110 | 60〜90 | 25〜45 |
| 航空母艦・航空母船 | 3〜6 | 0〜2 | 1〜3 |

第一線主力艦（戦艦＋巡洋戦艦）の排水量の中央値は、英国76万英トン、米国53万英トン、日本29万英トンと置かれる（検討案）。日本の主力艦排水量は米国の約55%だが、これは日本海軍の総合能力が55%という意味ではない。日本の中核案は、戦艦・巡洋戦艦8隻前後（約29万英トン）、巡洋艦25隻前後、駆逐艦90隻前後、潜水艦35隻前後、航空母艦・航空母船2隻前後である（検討案）。[^u130] 日本海軍の編制思想については[帝国海軍の戦略思想](/military/navy-strategy.md)を参照。

日本の交渉上の立場を支えたのは、1920年の国力である（検討案：粗鋼500万t、国民所得200億円、国防費10億円、うち海軍6.2億円、1920〜25年の臨時建艦基金6億円）。「アメリカとの無制限の建艦競争を望まないが、建造中止を条件に低い保有比率を押しつけられるほど財政的に追い詰められてもいない」国家として会議に臨んだ。[^u126] 財政の詳細は[帝国財政と諸侯の法定拠出](/economy/imperial-finance.md)を参照。

## 比率交渉から建造停止協定へ

当初は史実同様に主力艦の保有比率が交渉の中心と想定されたが、検討の過程で「日本は戦艦を大量に持つことを目的としていない」ことが明らかになり、比率を先に決めるより、三国が既に持つ戦艦を原則として維持し、建造中艦の処理と新造停止期間を協定する方が「建造制限だけが成立する」会議に合うとされた。[^u127][^u130]

日本の交渉上の強みは、戦艦を大量に持つことではなく、**戦艦の建造競争から降りても自国の海軍戦略を維持できること**にあった。「軍縮条約で42万トン持つことを認められても、日本に42万トン建造する理由があるわけではない」。[^u127] この戦略は会議によってむしろ一層強化された。[^u130]

なお建造停止には「既存艦隊が大きい国ほど有利で、将来の建艦計画に依存していた国ほど不利」という構造的問題がある。比率を実効化するには廃艦規定か保有上限への経過規定が必要になるが、比率を設定しない本条約ではこの問題は既存艦の保有容認という形で処理された。[^u125][^u131]

# 1922年ワシントン主力艦建造停止条約

## 条項

| 項目 | 条約の内容 |
|---|---|
| 主力艦の新規起工 | 原則10年間禁止 |
| 建造中の主力艦 | 原則廃棄。具体的な対象艦は附属表に列挙 |
| 既存主力艦 | 原則保有を認め、国別総排水量の比率は設定しない |
| 主力艦の定義 | 10,000英トン超、または8インチ超の主砲を持つ、航空母艦以外の軍艦 |
| 空母の定義 | 航空機の発着艦を主要目的とする軍艦 |
| 空母の最大砲口径 | 8インチ（203mm） |
| 空母の砲門数 | 6インチ超の砲は原則10門以下 |
| 空母の保有総量 | 制限なし |
| 空母の個艦排水量 | 制限なし |
| 巡洋艦・駆逐艦・潜水艦 | 総保有量の制限なし |

[^u131][^u132]

中国の条約・債務・軍閥支援、日英の外交・軍事協力、太平洋の基地制限については何も規定していない。[^u125][^u131]

## 空母規定の考え方

空母制限の争点は排水量より砲門・口径であり、条約の関心は「飛行甲板があるだけの戦艦」、すなわち空母の名目で戦艦を建造する抜け道を防ぐことに向けられた。1922年の時点では航空母艦で制海権が取れることは立証されておらず、火砲が巡洋艦未満に抑えられるなら、空母の建造競争を規制する必要はないと判断された。[^u131]

三国とも空母を戦艦と同じ総排水量枠に入れることには消極的であった。日本は第一次世界大戦の通商保護経験から偵察・索敵用航空機に強い関心を持ち、英国は航空艦の実験を続けたく、米国も新技術への投資機会を失いたくなかった。[^u131]

## 各国の得失

- **米国**：大量の建造中艦を放棄する代わりに、将来の戦艦競争を停止できた。
- **英国**：戦後の財政負担を軽減できた。
- **日本**：自国が重視する巡洋艦・駆逐艦・航空戦力への投資を継続できた。

[^u131]

## 補強条項（検討案）

砲装制限だけでは、例えば排水量35,000英トン・8インチ砲10門・飛行甲板付きの高速艦（大型巡洋艦と空母を兼ねる艦）が可能になるという懸念がある。そのため、次のような補強が検討案として挙げられている。[^u131]

- 空母の定義に、単なる飛行甲板の存在ではなく「航空機運用を主たる任務とする艦艇」であることを明記する。
- 廃棄対象に指定された建造中主力艦は、空母への改造も原則認めない。
- 既存の主力艦に飛行甲板を取り付けても、主力艦としての扱いを解除しない。
- 空母への分類変更には、戦艦用の大口径砲と関連設備の撤去を必要とする。

ただし、既に多額の費用を投じた船体の空母転用を認めた方が政治的に妥協しやすい場合もあり、これは各国の建造中艦の内訳次第である。また、空母の個艦排水量について将来の改定会議で再検討する留保（個艦上限30,000〜35,000英トン案など）を設ける余地もある（検討案。この上限に強い理論的根拠はない）。[^u131]

# 帰結

- **補助艦問題の顕在化（検討案）**：1920年代後半には米国が日本の巡洋艦・駆逐艦・空母の増強を問題視し、補助艦の軍縮交渉が新たな対立点になる。日本は英国との共同防衛任務を根拠に補助艦需要を説明できる。[^u129][^u131]
- **空母の早期台頭（検討案）**：主力艦の建造停止で浮いた予算が航空・対潜・護衛戦力へ向かうため、1930年代に航空機の航続距離・搭載量・雷撃・急降下爆撃能力が向上すると、1922年には危険視されなかった空母が戦艦と同等以上の戦略的重要性を持ち、新たな軍縮問題となる。史実より早く空母の重要性が認識される可能性があるが、航空技術・飛行甲板運用・航空燃料補給・訓練制度が必要なため、直ちに巨大空母の量産にはならない。[^u131]
- **日英米関係**：日英は米国と敵対しないが、米国の無条件の味方でもない状態が固定された。[^u125]

史実の1921年11月の米国初期提案（削減後の保有案）は、米国18隻・500,650英トン、英国22隻・604,450英トン、日本10隻・299,700英トンであった。[^u125][^u130] 1921年1月1日現在の第一線艦（米議会記録）は、戦艦が英26・米16・日6、巡洋戦艦が英6・米0・日4、軽巡洋艦が英44・米0・日6、駆逐艦が英334・米260・日27、通常潜水艦が英71・米52・日0であった。米国は当時サウスダコタ級戦艦・レキシントン級巡洋戦艦を建造中であった。[^u130] 史実では1927年のジュネーヴ海軍軍縮会議が英米の巡洋艦問題で決裂している。[^u123]

# 却下・修正された案

- **全面決裂案**：当初は会議全体の決裂も有力視されたが、英国にとって巨額の債権を持つ日本を仮想敵にする不合理（[^u122]）と、米国の建艦競争回避の利益（[^u118]、[^u123]）から見直され、「日英協調を維持したまま海軍軍縮のみ成立」へ移行した。[^u117][^u122]
- **10：10：8案**：日本は基地制限という代償を得られないため7割以上を要求できるとして、米英日10：10：8（米英各52.5万英トン、日本42万英トン。史実より10.5万英トン多く、35,000トン級戦艦約3隻分）が作業仮説とされた。米国は8割の承認は検討可能だが、9割以上は米海軍と議会の説得負担が大きいと分析された。しかし「日本が戦艦の大量保有を求めていなければ高比率の獲得は主要目標にならない」として保留され、最終的に比率を設けない条約となった。[^u125][^u127][^u130][^u131]
- **比率候補表**：A 10：10：7（70%）、B 10：10：7.5（75%）、C 10：10：8（80%）、D 10：10：9（90%）、E 10：10：10（100%）の各案が検討されたが、いずれも採用されていない。[^u125]
- **主力艦の排水量上限案**：一時は「主力艦の建造停止と排水量上限に合意し、補助艦の総量は制限しない」形が推奨されたが、確定条約では排水量上限・比率も設けないこととなった。[^u129][^u131]

# 未決の論点

- 1921年時点の日本の戦艦・巡洋戦艦の実際の隻数・艦型・総排水量（約29万英トン・8隻前後は暫定）。1910〜1920年の建艦の積上げは未了で、史実の薩摩型・河内型・金剛型以降の建艦計画が存在するかも未定。[^u125][^u126][^u130]
- 本世界線の米国の建造中主力艦の内訳（史実の1916年計画をそのまま使えない）と、附属表に列挙される廃棄対象艦。[^u130]
- 空母の個艦排水量制限の留保を設けるか、廃棄対象艦の空母転用を認めるか。[^u131]
- 英国内（海軍省・財務省・自治領政府）の対日評価の一致の程度。[^u125]
