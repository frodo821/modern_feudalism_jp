# 概要

清は朝鮮を属邦（宗属関係・冊封関係の下にある国）としつつ、もともと内政・外交には原則として干渉しない立場をとっていた。[^u040] 本世界線でも、清の朝鮮政策が軍事介入を伴うものへ変わるのは1882年以降である。1885年の清仏戦争終結で二正面戦争の恐れから解放された清は、日本の[朝鮮国独立保障（1884年）](korea-independence-guarantee-1884.md)に対抗して対朝鮮政策を強硬化し、宮廷人事への介入や高宗廃位論へ進んだ。[^u056][^u057]

1886年に朝鮮国王[高宗](../people/gojong.md)が清国代表[袁世凱](../people/yuan-shikai.md)を捕縛すると、清に譲歩の余地はなくなり、清朝中央は北洋大臣[李鴻章](../people/li-hongzhang.md)の慎重論を退けて朝鮮征討に踏み切った（ユーザーの判断）。[^u063] 政策の主導権は清朝中央に移ったが、戦争を実際に遂行する北洋軍事体系は李に依存しており、この「政治と軍事の不一致」が[日清戦争（1887〜1889）](../events/sino-japanese-war.md)における清の構造的弱点となった。[^u063]

# 政策の変遷

## 1. 宗属関係と不干渉（1860〜1870年代）

清は朝鮮を属邦と主張しつつ、朝鮮の外交は「自主」とする立場をとった。そのため1870年代の日本は、朝鮮と清のどちらと交渉すべきかが曖昧なまま日朝関係の悪化に直面した。[^u040] 朝鮮側は「清が守ってくれる」と認識していたが、清の宗主権は朝鮮への無条件の軍事防衛義務を意味せず、この認識と清の実際の行動とのずれが外交危機の原因となりうるとされた。[^u040]

## 2. 1882年の介入と「手打ち」

1882年の[漢城危機（壬午軍乱）](../events/imo-incident-1882.md)で清軍と日本軍は漢城周辺で対峙した。清には日本と全面衝突する理由がなく、日本にもエスカレートの利点がなかったため、両国は手打ちとした。ただしその事実は火種として燻った（ユーザーの設定）。[^u048] 清では「属邦について日本に派兵通告権を認めた」ことへの不満が残った。[^u048]

## 3. 軍拡と清仏戦争の二正面問題（1882〜1885）

1882年以降の数年間は日清双方の軍拡が重要となるが、清は対日軍拡の最中に対仏戦争で「背中から殴られる」構図となり、史実より軍事力を用意できるかは不透明であった（ユーザーの設定）。[^u049] 清の軍事力は北洋（李鴻章）と福建・南洋で利害と指揮系統が異なり一枚岩ではなかった。1882年の危機を経て李鴻章が北洋艦隊を温存する理由は史実より強くなった。[^u049]

| 時期 | 清の軍備（検討案の経過） |
|---|---|
| 1882 | 漢城危機を受け、李鴻章が北洋海防の追加予算を要求 |
| 1883 | 北洋の軍拡開始（兵器購入・朝鮮周辺の警備・沿岸要塞）。仏との緊張で南方も増援を要求 |
| 1884 | 清仏戦争が激化。李鴻章は北洋の南下をためらい、福建の損害が拡大。軍備配分で内部対立 |
| 1885 | 講和。北洋の軍拡と南方の再建を同時に迫られ、朝鮮での対日対立は未解決 |

[^u049]

1885年時点の清の軍事力の方向は、北洋のみ強化（分岐A）、両面対応で軍拡停滞（分岐B）、危機感から改革加速（分岐C）のいずれにも決めず並置されている。[^u049]

## 4. 清仏戦争後の強硬化（1885〜1886）

1885年に清仏戦争が終結すると、清はもはや二正面戦争を恐れる必要がなくなり、対日強硬化や宗主権強化のための軍事動員に進みうる。その程度は清が日本をどれほど恐れるかによる（ユーザーの判断）。[^u057] ここでは「対日強硬の意思」（清仏戦争の終結で強まる）と「日本と全面戦争を遂行する能力」（財政・艦隊・輸送・陸軍に制約される）を区別する必要がある。[^u057]

| 清の日本に対する認識 | 朝鮮への政策 |
|---|---|
| 日本軍は清軍を上回ると判断 | 直接戦闘を避け、袁世凱らによる政治・外交干渉を強める |
| 両国軍は拮抗すると判断 | 朝鮮へ追加兵力を送り、日本の介入に対抗する構えを示す |
| 北洋の増強で日本を抑えられると判断 | 王宮への圧力や王位問題への介入を強化する |

[^u057]

清は宗主権の空洞化を恐れて朝鮮の政情不安に積極的に干渉し、李氏王朝内部の事情にも口を出し始めた（ユーザーの設定）。[^u056] ただし自ら冊封した国王を廃位すれば宗属秩序の正統性を損なうため、まずは王宮警備・軍制・閣僚人事・外交官の任免に介入して高宗の実権を制限する方法がとられた。[^u056]

| 時期 | 仮想・清仏戦争後の朝鮮危機 |
|---|---|
| 1885年後半 | 日本の独立保障宣言に対抗し、清の対朝鮮政策が強硬化 |
| 1886年 | 袁世凱らが宮廷に圧力をかけ、閣僚人事で対立、廃位論が浮上 |
| 1886〜1887年 | 高宗が日本公使に保護を要請（のちの整理では避難は1886年） |
| 1887年 | 日清間の重大外交危機 |

[^u057]

外的要因として、1885年の英国による巨文島占領とロシアの朝鮮進出への懸念があり、清は「対日強硬だが全面戦争は回避」という難しい外交を迫られた。[^u057] 日清戦争の引き金は、清が「朝鮮王室への政治介入なら日本は全面戦争に踏み切らない」と判断したことかもしれず、その誤算が史実より早い開戦を招いた。[^u057] 最大の変数は清の軍事的自己評価、つまり李鴻章や清朝中央が日本に勝てると考えるかであった。

## 5. 公使館危機への対応

高宗が日本公使館に避難すると、清は身柄の引き渡しを求めたが、日本は国王本人の意思に反する引き渡しを拒んだ。[^u056] 清にとって日本公使館をどうにかすることが第一目標となったが、清が直接手を下す必要はなく、第三者に襲撃させればよかった（ユーザーの設定）。[^u058] 清の狙いは高宗の殺害ではなく、高宗を日本の保護から引き離すことにあった。しかし公使館襲撃はかえって日本に介入理由を与え、高宗の許可による日本帝国軍の漢城駐留を招いた（[高宗の日本公使館避難と1886年漢城公使館危機](../events/gojong-legation-refuge.md)）。[^u058]

## 6. 袁世凱逮捕と朝鮮征討の決定（1886〜1887）

袁世凱の逮捕は、清から見れば朝貢国の君主が宗主国の官員を自国の司法権で裁こうとする重大な秩序違反であり、清は朝鮮征伐までエスカレートしうる（ユーザーの判断）。[^u061] 清は最後通牒で袁の釈放・処罰撤回・関係者の処分を求め、日本には軍事支援の停止を求めたが、高宗は拒絶し、日本も釈放を勧告しなかった（[袁世凱逮捕事件（1886年）](../events/yuan-shikai-arrest.md)）。[^u061][^u062]

こうなった時点で清に譲歩の余地はなく、李鴻章を飛ばしてでも軍事強硬路線をとることはほぼ既定路線となった（ユーザーの判断）。[^u063] 清朝中央では次のような議論が成立した。

> 李鴻章は日本との戦争を避けるために譲歩を重ねた。その結果、朝鮮王は清国の官員を捕縛し、日本軍がこれを守っている。これ以上の譲歩は宗属秩序を崩壊させる。[^u063]

ベトナムの宗主権を失った直後に朝鮮でも日本に譲歩するのかという圧力も加わった。

### 李鴻章の扱い

| 清朝中央の措置 | 政治的な意味 |
|---|---|
| 李鴻章に対日強硬政策を命令 | 李の軍事・外交機構を維持したまま政策を変更 |
| 朝廷から欽差大臣を派遣 | 李の権限を制限し、強硬派に政治的主導権を与える |
| 李鴻章を罷免・更迭 | それまでの対朝鮮政策を全面的に否定 |

[^u063]

最もありそうなのは二番目、すなわち**李に北洋軍の準備を続けさせながら、朝鮮征討の政治的決定権を清朝中央が直接握る**形である（検討案）。[^u063]

### 朝鮮征討の目的の拡大

征討の目的は袁の救出にとどまらず、次のように拡大した。[^u063]

- 袁世凱の釈放と清国官員の保護
- 高宗への制裁、あるいは王位からの排除
- 清が承認する別の李氏王族の擁立
- 朝鮮における清の軍事的・政治的権限の再確認

日本にとってこれは「清朝が朝鮮王国の統治権を武力で奪おうとしている」問題であった。軍事制裁の決定と全面戦争の決定は別だが、日本軍が高宗の要請で漢城を警備している以上、清軍が高宗の身柄確保や政権交代を強行すれば衝突は避けられず、相互の増援で全面戦争へ拡大した。[^u063]

## 7. 戦争中の清

局地戦で清軍が退けられると、撤兵すれば「国王による清国官員の逮捕を認めたまま宗主権回復に失敗した」ことになるため、清は引き下がれず、全力投射以外の選択肢が乏しくなった（ユーザーの判断）。[^u064] 李鴻章らが講和を求める余地は残ったが、朝廷が宗主権の回復を国家的威信の問題とすれば慎重論は抑えられた。[^u064]

清の敗因は兵力ではなく戦争遂行体制にあった。陸海軍の協同不全、統一戦略の欠如、参謀・兵站の弱さ、臨時的な海防財政に加え、清仏戦争の財政負担も重かった。[^u070] 1889年の[下関条約](shimonoseki-treaty-1889.md)で清は朝鮮の完全独立と李氏王統を承認し、宗主権を放棄した。[^u077]

# 構造的問題: 清朝中央と北洋の不一致

> 清朝が威信を守るために戦争を始めようとする一方、実際にその戦争を遂行する北洋軍事体系の責任者は、勝算に疑問を持っている。[^u063]

李鴻章が朝廷の強硬方針に反対していても、軍の指揮・補給・調達には李の協力が必要であり、中央が李を政治的に押し切っても北洋軍が直ちに効果的に動けるとは限らない。開戦直前の重要な分岐は「李鴻章が罷免されるか」ではなく、「**李の慎重論が退けられた後、清朝中央がどれほど北洋軍の軍事行動を直接統制しようとするか**」であった。[^u063]

敗戦後、清朝中央は「朝鮮における現地官僚の越権行為が危機を招いた」として袁世凱に責任を負わせることができ、それは李鴻章や中央の責任を軽くする意味も持った。ただし袁を切り捨てれば、朝鮮への介入が正当だったという開戦時の主張と矛盾する。[^u105]

# 日本側の要求との関係

日本は朝貢儀礼と実質的な宗主権を区別した。朝貢儀礼の存続は、通商・外交権を妨げなければ容認の余地があったが、清の外交政策への介入、清軍の常駐、清による人事・改革への関与は受け入れられなかった。問題は朝貢そのものではなく「清が朝鮮の主権的意思決定を制約できること」であった。[^u052] 本世界線の清の政策は、まさにこの実質的宗主権を宮廷人事と王位にまで及ぼそうとしたため、日本の独立保障と正面衝突した。

# 史実との比較

- 史実の清は朝鮮を属邦としつつ内政外交に原則不干渉の立場をとったが、1882年の壬午軍乱で大院君を拘束して天津へ連行し、政治介入を強めた。[^u040][^u061]
- 史実の李鴻章は日露との衝突を警戒して外交的均衡を模索し、1885年の天津条約で日清両軍の撤兵と再派兵時の通告制度によって危機を収拾した。甲申政変後は強硬派の要求もあり、袁世凱を派遣して朝鮮政府への統制を強めた。[^u063]
- 1885年以降、袁世凱は朝鮮駐在の清国代表として外交・税関・電信への関与を深めたが、法的には総督ではなかった。1886年8月には高宗廃位を李鴻章に提案したが、李は認めなかった。1885年には清の官僚が、朝鮮に強力な軍隊を送り閔妃周辺を排除する構想も提案していた。[^u057][^u061]
- 史実の1884年8月23日の馬江海戦で福建水師は壊滅し、李鴻章は朝鮮方面の日本の脅威を理由に北洋艦艇の派遣を取りやめた。定遠・鎮遠はドイツ建造で清仏戦争の影響により引き渡しが遅れ、1885年秋に到着した。1885年に海軍衙門が設置されたが艦隊間の分立は解消されなかった。[^u049][^u057]

# 却下・修正された案

- **清の高宗帰宮と引き換えの妥協**: 清仏戦争中なら、清が高宗の帰宮と引き換えに朝鮮内政への軍事介入を控える妥協もありうるとされたが、清仏戦争は1885年に終結するため、清がその後も同じ程度の譲歩に応じるかは別問題とされた。[^u056]
- **袁の身柄をめぐる外交取引**: 清が袁を召還し、日朝側が身柄を引き渡す代わりに清が王位継承・宮廷人事への介入を控える収拾案は、日本が高宗に釈放を迫れないという判断（独立保障の下での背信）により成立しない方向となった。[^u062]

# 未決の論点

- 李鴻章を罷免するか、欽差大臣の派遣で権限を制限するか。ユーザーは「飛ばしてでも」とのみ述べ、欽差大臣派遣は検討案にとどまる。[^u063]
- 1885年時点の清の軍備の方向（分岐A・B・C）。[^u049]
- 公使館襲撃への清の関与が中央の命令か、現地官僚の非公式関与か。[^u058]
