# 概要

1889年の下関条約は、高宗による袁世凱捕縛（1886年）を発端とする[日清戦争（1887〜1889）](/events/sino-japanese-war.md)を終結させた講和条約である。締結は1889年（本世界線の明治23年）と確定しており、時期は春〜夏とされる。[^u077]

条約の特徴は三点に集約される。第一に、清国が[朝鮮の独立](/diplomacy/korea-independence-guarantee-1884.md)と李氏王統を承認し宗主権を放棄する「朝鮮問題の徹底的な解決」。第二に、台湾・澎湖諸島の割譲と北洋海軍の時限的な再建制限による日本の安全保障（遼東半島の永久割譲は要求しない）。第三に、イギリスを中心とする銀行団の対清借款を前提とした賠償である。[^u077] 列強への事業特許は条約本体に書かれず、並行する「対清賠償借款協定」「対列強通商協定」によって定められた（検討案）。[^u077]

遼東割譲がないため三国干渉は発生せず[^u079]、この条約は以後の日英協調、[中国大陸の利権争奪](/diplomacy/china-concessions.md)、日露関係の出発点となる。[^u091] 1920年代に至っても、日英の中国権益の法的基盤は「1889年下関条約以来の債権・鉄道・港湾」とされる。[^u123]

# 講和に至る経緯

## 戦争目的の拡大と早期講和の拒否

戦争は高宗の保護から始まったが、清が局地戦敗北後に追加派兵し全面戦争へ移行したことで、日本の講和条件は不可逆に拡大した。立憲帝国として両院に戦費を説明し国民・領主に負担を求めている以上、撤兵だけで講和すれば成果を説明できないうえ、「今終戦すれば清国は艦隊を再建して数年後に戻ってくるのではないか」という疑念があったためである。[^u071]

| 戦争段階 | 講和に必要な条件 |
|---|---|
| 清軍の朝鮮派兵 | 撤退と干渉停止 |
| 朝鮮での局地戦 | 独立の明文承認・賠償 |
| 清の全面戦争決断 | 北洋の脅威除去・再侵攻防止・戦費補償 |
| 清海軍敗北・沿岸進攻 | 台湾澎湖割譲・賠償・北洋軍備制限 |

[^u071]

日本近海での清の海軍力の解体に必要な程度が、日本が受け入れられる最低限の講和条件とされた。[^u064] 求めたのは清海軍の全面廃止ではなく、黄海・渤海方面から朝鮮へ派兵する能力、すなわち北洋の海上戦力の無力化である。[^u064] 南洋海軍の侵入を防ぐため台湾も要求された。[^u065]

## 順天府への圧力

厳しい講和条件を呑ませるには、順天府（北京）へ進軍する意思と能力を清朝中央に信じさせる必要があった。北京の占領は不要かつ有害とされ、朝鮮での清軍撃退→北洋艦隊撃破と旅順・威海衛への脅威→天津・山海関方面への進出能力の誇示、という三段階が講和の軍事的条件となる。[^u068] 締結時点で日本は旅順・威海衛方面で軍事的優位を確保し順天府への進軍能力を示しているが、北京そのものは攻撃していない。[^u077]

## 講和の三条件と時期

清に交渉力はなく、講和の終わり方は日本が決められる。[^u073] ただし金融面では列強との事前調整が講和時期を決める。日本が講和に踏み切る三条件は次のとおりである。[^u073]

1. 北洋の海上脅威が実質的に除去されている（黄海の優位、朝鮮への海上増援が困難）
2. 順天府への軍事的脅威が十分に信用されている
3. 列強の銀行団との融資調整ができている（海関担保借款の見通し）

講和をあえて遅らせる理由は、領土・賠償の追加要求ではなく列強との交渉を完成させるためである。[^u073]

## 列強との事前調整

講和の前提として、ロシアに取られたくない地域へ先にイギリス・フランスの権益を設定する「既成事実化」が採用された。[^u076][^u077] 1888年頃ならフランスよりイギリスを先に引き込む方が対露戦略上有効であり、イギリスは北洋（山東・直隷の港湾・鉄道・金融）、フランスは華南（雲南・広西）へ誘導される。清との講和条約より先に英仏との非公式な金融・通商協定が成立していても不思議ではなく、1889年の講和は「日本が列強と事前調整した構想を敗戦国清に受諾させる場」となる。[^u076] 台湾については、割譲後も既存の外国通商権を尊重しコンセッションを設ける約束で列強の反対を抑えた。[^u069]

# 条約の内容

## 仮想十条案（検討案）

| 条 | 内容 |
|---|---|
| 第一条 | 清国は朝鮮国の完全な独立と李氏王統を承認し、宗主権を放棄する |
| 第二条 | 清国は台湾・澎湖諸島を日本帝国に割譲する |
| 第三条 | 清国は戦争賠償金1億2,000万庫平両を支払う |
| 第四条 | 北洋方面の軍備・軍港について時限的な制限を設ける |
| 第五条 | 清国は朝鮮から軍隊を撤収し、高宗の統治に干渉しない |
| 第六条 | 日清間の通商、航行、居留民の保護を再規定する |
| 第七条 | 賠償履行を担保するため、日本は威海衛の一時占領を継続できる |
| 第八条 | 賠償金支払いのため、海関収入を担保とする借款を認める |
| 第九条 | 清国は既存の外国人の通商権益を尊重し、新たな経済協定の締結を認める |
| 第十条 | 捕虜交換、占領地返還、停戦、批准手続きを定める |

[^u077]

条約の締結（1889年）、朝鮮独立承認、台湾・澎湖割譲、遼東割譲なし、三国干渉なしは確定設定である。[^u077][^u079][^u105] 条文構成と金額は検討案である。

## 賠償金

賠償額1億2,000万庫平両は、1889年という早い時期の外国借款市場と清国の返済能力を考慮した**暫定値**である。[^u077] 年利5%・30年元利均等で調達すると年間元利返済は約780万両となり、1887年の清国海関収入（約2,054万海関両）の約38%に相当する（庫平両と海関両は別単位のため大まかな比較）。全額即時の現金払いではなく、分割払いと借款による調達を認め、資金調達が確認されるまで威海衛の占領を解除しない。[^u077] 詳細は[対清賠償借款と講和の国際金融](/economy/indemnity-loan.md)を参照。

## 北洋軍備制限

日本は清国の海軍を永久に禁止したいわけではなく、対露上は清に一定の軍事力を残すことにも意味がある。そのため制限は時限的なものとされる（検討案）。[^u077]

* 旅順・威海衛の攻撃的な海軍基地機能について一定期間制限する
* 北洋艦隊の大型軍艦の再建・増強について期限付きの制約を設ける
* 清国の朝鮮への派兵を禁止し、違反時の外交的対応を定める

例えば五年間の制限とし、その間に日本軍の一時占領を解除しつつ、違反時には国際仲裁や条約上の制裁を求める。[^u077] 旅順・威海衛は戦中に占領・無力化しても講和後は返還する。[^u069]

## 朝鮮条項

清国の宗主権が消滅することと、日本が朝鮮の宗主国になることは同じではない。条約は高宗の王位、朝鮮の独立、清軍の撤退の確認にとどめ、日本の特別な宗主権は規定しない。日本にとって重要なのは朝鮮市場の確保であり、直接統治は不要である。[^u077]

## 威海衛の扱い

威海衛は賠償履行の担保として日本が一時占領を続ける（第七条）。講和後には清国がイギリスに長期的な港湾使用権・商業特許を与え、ロシアが後から威海衛を取得する余地を狭める構想がある（検討案）。最初は軍港の完全な租借ではなく、港湾施設使用権・商業施設経営権・石炭補給施設から始める。[^u076] 順序としては、**英系銀行団による賠償金支払いの確定→日本の威海衛撤退→英国の港湾権益の発効**が重要とされる。これにより英国権益を対露牽制に使いつつ、日本自身の賠償回収も守ることができる。[^u085]

# 付随協定（検討案）

| 協定 | 内容 |
|---|---|
| 日清下関条約 | 領土・朝鮮独立・賠償・軍備制限 |
| 対清賠償借款協定 | 英系を中心とする銀行団の融資、海関担保、返済期限 |
| 対列強通商協定 | 英国への北洋方面の経済権益、仏国への華南方面の事業機会など |

[^u077]

イギリスには山東・直隷における鉄道・港湾事業と対清借款の主導権が与えられ、将来のロシアの南下を抑える既成事実となる。フランスには1885年の清仏天津条約（第7条にフランスの鉄道技術・産業利用の規定がある）で認められたトンキンと中国南部との交通・通商関係を発展させる余地が与えられる。ただし英仏は日本の命令で清国の利権を受け取れるわけではなく、最終的には清国が契約当事者となる。[^u077]

# 意義と影響

* **ロシアを融資の中心から外す**: 史実1895年の露仏借款に相当するものが起きず、戦後金融の最初の枠組みがイギリス中心になる。ただし清が戦後ロシアから追加借款を受ける可能性は残る。[^u077]
* **三国干渉の不在**: 遼東を割譲しないため三国干渉は起きず、対露政策は雪辱の動機を欠き、史実より冷静だが長期的には厳しいものとなる。[^u079]（[日露関係と対露抑止](/diplomacy/japan-russia-relations.md)参照）
* **英国権益の北洋先行**: 英国資本が北洋の鉄道・港湾へ先行進出しているため、ロシアが南満洲へ伸びるには英系事業との調整が必要となり、対露危機ではむしろ英国が先に強硬になる構造が生まれる。[^u091]（[日英協調](/diplomacy/anglo-japanese-cooperation.md)参照）
* **国内制度**: 締結と同時期に「台湾統治例」の制定と、戦勝賠償金の配分をめぐる元老院・衆議院の審議が始まる。[^u077] これが[論功行賞](/events/reward-distribution-1889.md)と[帝国交通整備計画](/economy/transport-plan.md)につながる。
* **袁世凱**: 講和後、清国へ引き渡された袁世凱は敗戦責任を問われて処刑される経路が成立する。[^u105]（[袁世凱](/people/yuan-shikai.md)参照）

# 却下・修正された案

* **早期講和**: 戦争が思ったより短くなり清が早期講和を選ぶという見立ては、全面戦争に進展した場合の早期講和は日本側が受け入れられないとして修正された。[^u070][^u071]
* **1888年後半の講和**: 講和時期の候補として1888年後半が挙げられたが、1889年の締結に決定された。[^u073][^u077]
* **2億両の賠償**: 2億両を要求し列強に巨額借款を組ませる案と、1億〜1億5,000万両に抑えて台湾・澎湖と北洋の安全保障を優先する案が比較され、後者寄りの1億2,000万両（暫定）が採られた。[^u072][^u077]
* **遼東半島の割譲**: 旅順はロシアにとって極東の軍事均衡に直結し危険なため、永久割譲には固執しないとされた。[^u069]

# 未決の論点

* 賠償額1億2,000万庫平両は暫定値で、確定額ではない。[^u077]
* 北洋軍備制限の期間（五年案）と監督・違反時の制裁の方法。[^u077]
* 賠償金の受領方式（借款による一括受領か分割送金か）と、信用リスクを銀行団へ移す時期。[^u085]
* 列強と事前に結ばれた非公式協定の具体的な範囲。[^u076]
