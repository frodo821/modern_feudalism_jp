# 概要

本世界線の日本帝国にとって、朝鮮を従属化させる必要はなかった。目指したのは、そこに親日的な市場ができることであり、どうせなら清は排したい――この欲が対朝鮮政策の「助平心」そのものだった。[^u051]

国内には強い[領主権](/institutions/lordship-rights.md)が残り、大領主同士が産業・通商で競争している。彼らにとって朝鮮の直接統治は大きな軍事費・行政費を伴うが、朝鮮が独立を保ちながら日本との通商を拡大すれば、領主系の銀行・鉄道・海運・商社に利益が生まれる。つまり日本の立場は「**朝鮮を統治する必要はないが、清国に朝鮮の外交・通商政策を左右されるのは困る**」というものだった。[^u051]

この基本目標は、1870年代の国交正常化から、1880年代前半の市場確保、反日暴力の抑止と清の宗主権の解消、そして1884年の李氏王統と朝鮮独立の一方的保障へと段階的に深化した。保障は清への牽制として発せられたが、やがて日本自身を朝鮮問題に縛りつける約束となり、1887年の[日清戦争](/events/sino-japanese-war.md)へとつながった。[^u055][^u062]

## 国交正常化と国内向けパフォーマンス（1870年代）

1870年代の朝鮮政策の第一の課題は、宗家の家役を接収した帝国政府として朝鮮と直接の国交を確立することだった。朝鮮に開国を迫る理由には国内向けパフォーマンスが確実に含まれ、朝鮮問題は[元老院](/institutions/genroin.md)政治において政権の能力を測る問題となった。政府は「不平等条約を改正した、次は朝鮮との国交正常化」と訴え、強硬派領主は「西洋に認められる近代国家が隣国との国交も確立できないのか」と批判した（[不平等条約改正](/diplomacy/treaty-revision.md)）。[^u046]

1880年代に清が介入を強めると、朝鮮問題は勢力均衡の問題へ変化し、朝鮮への影響力の維持そのものが過去の外交的成果を守ることになった。影響力の喪失は長年の外交政策の失敗として両院で追及されうるため、政府は清軍の派遣を単なる朝鮮の国内問題として扱いにくくなった。[^u046]

## 親日的市場と「朝鮮の清国離れ」（1884年）

1884年の目標は次のように整理される。[^u051]

| 区分 | 内容 |
|---|---|
| 戦略目標 | 朝鮮を清国の政治的影響力から切り離し、独立した通商相手として確保する |
| 戦術的機会 | 清仏戦争によって清国の軍事的対応余力が制約されている1884年 |
| 手段 | 開化派支援、外交承認、必要に応じた軍事的圧力 |
| 回避したい事態 | 清国との長期全面戦争、朝鮮の直接統治、列強の大規模介入 |

求める具体的成果は、清軍の朝鮮撤退、朝鮮の独立外交の確認、追加開港と通商の自由化、港湾・鉄道・電信への投資機会、日本人・日本企業の法的保護である。この整理により、日本の強硬姿勢と全面戦争回避の判断は矛盾しない。[^u051]

工業化した日本は、清の政治的干渉さえ排除すれば、日本製の綿布・金属製品・日用品と海運・金融・保険の力によって、清商人と自由に競争しても優位に立てると考える政治家を生んだ。ただしこれは価格競争力と輸送費次第で、確実な結果ではない。また、清国を排除することと朝鮮の実質的な自主性を尊重することは同じではなく、朝鮮側が外国資本の進出条件を独自に決定できなければ独立は名目的なものにとどまる。[^u051]

## 反日暴力の抑止と宗主権の解消（1884〜1885年）

日本政府が朝鮮政府に反日活動への対処を申し入れるのは自然な流れであり、また朝鮮が清の属国である状態は日本にとって受け入れ可能なものではなかった。これにより目標は市場開放より踏み込んだものとなった。[^u052]

- **反日暴力の抑止**：日本人への暴力事件の捜査と処罰、公使館・商館・居留民の安全保障、組織的襲撃の予防、賠償と再発防止。ただし反日的な言論や政治運動の一律の取締りまで求めれば内政干渉となるため、具体的な暴力の抑止と反日感情の抑圧は区別された。
- **宗主権の解消**：「朝鮮政府が日本と自由に条約を結べるだけでなく、清国の許可や干渉なしに履行できなければならない」。問題は朝貢儀礼そのものより、清国が朝鮮の主権的な意思決定を制約できることにあった。強硬派は宗属関係の廃止を、通商優先派は朝貢儀礼を残した実質的自主権の確保を求めた。

二つの要求は「**朝鮮政府には日本人の安全を保障する責任がある。そして、その責任を果たせる独立した政府でなければ、日本との正常な外交関係は成立しない**」という論理で結びつけられた。ただし、そこから日本軍による朝鮮政府の保護や政権転覆支援が正当化されるわけではない。[^u052]

## 李氏王統の保障（1884年〜）

日本は1884年、李氏王朝による統治と朝鮮の独立を一方的に保障した。日本が独立を「与える」のではなく、既存の朝鮮王国の独立と李氏王統を承認・保障する構成であり、その論理は「**日本は朝鮮を支配するためではなく、清国に朝鮮を支配させないために王朝の独立を支持する**」というものである。天皇の下で世襲領主権を憲法で保障し、1866年の幕府解体も徳川家の領地と家格の保障で実現した日本の国制とも相性がよかった。詳細は[朝鮮国独立保障（1884年）](/diplomacy/korea-independence-guarantee-1884.md)を参照。[^u055]

日本が望むのは親日的な市場であり、王朝の廃止は必要ない。むしろ王室を存続させたまま開化派の内閣を設け、通商・財政・軍制を改革する方が既存の政治秩序を利用できる。一方、王朝の不安定化は、条約を履行できる政府を必要とする日本の通商政策にも反した。日本が治安維持のため軍事介入すれば反日感情が高まるというジレンマも残った。[^u053]

## 保障の履行（1886〜1887年）

高宗が日本公使館に避難し、高宗の許可のもと邦人保護を名目に日本軍が派遣されると、日本の立場は「自らが承認した独立国の正統な君主を保護する」ものとなった。派兵の根拠は既存の公使館警備権、居留民の生命・財産の保護、朝鮮国王の正式な要請の三つで、独立保障政策との整合上は第三が特に重要とされた。史実1894年7月の日本軍による王宮占領とは、政治的な出発点が逆である。[^u059]

高宗が清の派遣官・袁世凱を逮捕すると、日本は独立を保障している以上、逮捕を咎める理由に乏しく、清の要求を呑むよう朝鮮に勧告することさえ背信行為となった。日本政府の立場は次のように整理される。[^u062]

> 袁世凱の法的地位と訴追の適法性は、朝鮮政府と清国政府の間で解決すべき問題である。ただし、その解決を強制するために清国が朝鮮へ軍隊を派遣することは認めない。

世襲領主権と司法権を憲法上保障する日本にとって、独立を保障した外国君主に司法権の行使を断念させることは説明困難であり、元老院の領主議員からも「朝鮮国王の統治権を尊重せよ」という主張が出た。国内対立の軸は「高宗を見捨てるか否か」ではなく「保障の維持にどれだけの軍事的危険を負うか」に移った。戦争の争点も「清朝の宗主権に朝鮮国王の司法権・統治権を武力で覆す権限があるか」となり、日清戦争は日本が朝鮮市場を欲して始める戦争ではなく、**日本が保障した朝鮮の独立と清の宗主権が正面衝突する戦争**となった。[^u062]

## 戦争目的の拡大（1887〜1889年）

清が全面戦争を決断すると、日本も清から得るべきものを計算しなければならなくなった。戦争目的は高宗保護から段階的に拡大し、日本近海での清の海軍力の解体に必要な程度、すなわち北洋方面の海上戦力の無力化が最低限の講和条件となり、さらに台湾・澎湖の割譲が加わった。領主議員は「自分たちが憲法で保障された権限を持っているからこそ、外国の世襲君主が持つ統治権への武力干渉にも反対する」という論理で戦争を支持した。全面戦争に進んだ以上、早期講和は日本の側が受け入れられないものとなった。詳細は[日清戦争（1887〜1889）](/events/sino-japanese-war.md)と[下関条約（1889年）](/diplomacy/shimonoseki-treaty-1889.md)を参照。[^u064][^u067][^u071]

# 国内の利害構造

対朝鮮政策は単純な開戦派・反戦派に分かれず、領主ごとの地理的・経済的利害が交錯した（例示）。[^u037]

| 領主・政治勢力 | 関心 |
|---|---|
| 宗家・西日本の通商関係者 | 朝鮮との交易、港湾開放、航路の安定 |
| 毛利家・中国地方の領主連合 | 日本海の安全保障、対馬海峡、半島への交通 |
| 島津・鍋島などの領主連合 | 海軍整備、海外貿易、軍需産業 |
| 徳川・前田などの大領主 | 国家財政、産業振興、海外市場、戦費負担 |

武家領主が主導する元老院が威信を重んじて強硬論に傾きやすい一方、戦費を負担する納税者を代表する[衆議院](/institutions/house-of-representatives.md)は財政面から抑制に働きうる。[^u037][^u046] ただし公使館襲撃のような事件では、元老院の領主層と衆議院の商工・都市勢力が同じ強硬要求で一致することもあった。[^u058]

# 構造的なジレンマ

- **市場と反発**：日本の経済進出が成功するほど、朝鮮で反日的・反外国的な政治運動が強まる。介入を強めれば反発を招き、干渉しなければ親日的な政権が倒れうる。[^u051]
- **独立と王朝**：「朝鮮国の独立」と「李氏王朝の正統性」は同一ではない。朝鮮国内で王制廃止運動が起きた場合に王朝を守れば、内政干渉となる。[^u055]
- **牽制と拘束**：清への牽制として発した独立保障が、日本自身を朝鮮問題へ継続的に関与させる外交上の約束になる。[^u055]
- **前例の二面性**：1882年の妥協は、後の危機で和平論と強硬論の双方の根拠として引用された。[^u048]
- **戦後の配分**：戦争目的が拡大するほど、戦時に影響力を得た中央政府と、戦争を支持し戦費を負担した元老院の間で、戦勝成果の配分が国内政治問題となる。[^u071]

# 史実との比較

- 史実の明治政府も朝鮮の「自主」を掲げて清の宗主権を否定しようとしたが、1876年の日朝修好条規の「自主」の解釈は日朝清で一致せず、日本は1894年に王宮を占領して開戦した。本世界線では日本が李氏王統を明示的に保障し、高宗自身が日本の保護と派兵を求める点で出発点が逆である。[^u055][^u059]
- 史実の日清戦争の契機は東学農民革命だったが、本世界線では袁世凱逮捕をめぐる外交危機が直接の契機となる。[^u062]

# 却下・修正された案

- **市場へのアクセスに目標を限定する整理**：当初は親日的な市場の確保が目標とされたが、反日暴力の抑止と、清の属国状態を受け入れないという要素を加えて修正された。[^u051][^u052]
- **亡命王室の保護という解釈**：李氏王朝の日本亡命を受け入れる構想は、日本が李氏王朝の統治する朝鮮の独立を一方的に保障するという方向に読み替えられた。[^u055]
- **高宗に袁世凱の釈放を勧告する選択肢**：独立保障の下では背信行為にあたるとして退けられ、日本は釈放を勧告しないことが確定した。[^u062]

# 未決の論点

- 独立保障が軍事介入義務まで含むか、その適用条件。
- 「朝鮮国の独立」と「李氏王朝の正統性」をどこまで一体として保障するか。
- 反日活動取締り要求の範囲と、日朝間での取り決めの形式。
- 独立後の高宗が開化派と協調するか、王権強化をめざすか。
