# 概要

本世界線の中国の軍閥は、史実の軍閥と成立経路が大きく異なる。史実の軍閥は、[袁世凱](../people/yuan-shikai.md)の北洋軍が分裂して生まれたもの（直隷派・安徽派など）と、清末の地方新軍・地方警備組織から独自に発展したもの（晋系・滇系・桂系など）に分かれるが、袁世凱が1880年代に退場した本世界線では前者が史実の形では成立しない。一方、後者は史実に近い形で成立し、さらに史実では北洋軍や国民革命軍に吸収された**湖北・江蘇・湖南・江西の地方軍が有力な独立勢力として残る**。[^e021]

その結果、中国の政治構造は単純な南北二極ではなく、**華北の旧清朝官僚・軍事政権、長江流域の地方立憲・軍事政権、華南の共和革命政権**の三極構造に近いものとなり、そこに満洲・山西・西南・西北の自立勢力が加わる。史実との最大の違いは、北方の軍閥が弱くなることより、長江流域の軍閥が強くなることにある。[^e021]

列強の支援先は、政体ではなく「どの地域に既存権益を持ち、どの政権を通じて将来の権益を広げられるか」で決まる（確定）。[^e023][^e024] 日英は北京・両江・湖北の契約承継型の連合（のちの[中国諸省聯合](china-federation.md)）を、米独とソ連は広州の[中華民国](republic-of-china-canton.md)を、フランスは雲南・広西を支える。この配置が、1926年以降の[北伐](../events/northern-expedition.md)と1930年の膠着の前提となった。[^e023][^e039]

## 華北：旧淮軍系の共同政権

直隷派・安徽派は北洋軍の分裂から生まれた軍閥なので、同じ形では成立しない。ただし軍人自身が消えるわけではない。[^e021]

| 人物 | 1911年の年齢 | 本世界線での位置 |
|---|---:|---|
| 段祺瑞 | 46歳 | 軍事教育・砲兵出身の高級軍人 |
| 馮国璋 | 52歳 | 淮軍系の軍事指導者 |
| 曹錕 | 49歳 | 天津方面の軍事指導者 |
| 呉佩孚 | 37歳 | 華北の新軍将校 |
| 馮玉祥 | 29歳 | 地方軍の中堅将校 |
| 張勲 | 57歳 | 旧式軍を基盤とする清朝忠誠派 |

[^e021]

段祺瑞や馮国璋は袁世凱の下で出世する以前から軍歴があるので、李鴻章系の軍事組織や陸軍部で地位を得る可能性は残るが、安徽派・直隷派の構図を再現する必要はない。北京・天津を中心とする華北軍事政権は、旧淮軍系の軍人・陸軍部官僚・清朝の財政官僚の共同政権となり、兵力よりも**北京の中央官庁・外交機構・外国借款の窓口を握っていること**が強みとなる。推定兵力は12〜20万人。[^e021]

## 山西：晋系

閻錫山（1883〜1960）は山西の軍事教育機関を経て日本に留学し、1911年の革命で山西都督となった。袁世凱の人脈への依存度は低い。山西は山地に囲まれて独立しやすく、石炭・鉄鉱石もあり、華北に強い北洋軍がないぶん史実より早く自立しうる。支配領域は山西省、1920年代の推定兵力は5〜10万人、性格は地方自治・産業振興・独立性の維持。史実の閻錫山軍は1916年以前の約7,000人から1923年頃に約10万人に拡大した。[^e021]

## 満洲：奉天系

張作霖（1875〜1928）は1889年の日清戦争時に14歳程度で従軍経歴を再現しにくく、日露戦争もないため日露双方との接触で勢力を広げる機会もない。本人の出世は不確実だが、治安悪化・地方自衛組織の成立・清朝による武装集団の取り込みという構造は残るので、**奉天を基盤とする地方軍事政権そのものは成立しやすい**。[^e021]

| 支配領域 | 1920年代の推定兵力 |
|---|---:|
| 奉天省のみ | 5〜10万人 |
| 奉天・吉林 | 8〜15万人 |
| 東三省全域 | 15〜25万人 |
| 東三省と華北の一部 | 25万人以上 |

[^e021]

史実の奉天派は最盛期に30万人を超えたが、それは東三省統合と華北進出の後の数字である。[^e021] 清帝を奉じて東三省を統合する経路も検討されたが、[溥儀](../people/puyi.md)がロシアへ亡命したため実現しない。[^e025] 満洲内部では、南満洲の親英的な地方軍事勢力、北満洲の親露勢力、王党派が競合しうる。[^e023] 1930年の奉天系は満洲で独自政権を維持している。[^e039]

## 長江流域：史実以上に重要な地域

史実の1910〜11年の地方新軍（旧式軍・巡防営を含まない）は、江蘇25,682、湖北16,102、四川16,096、雲南10,977、湖南4,443であった（McCord, *The Power of the Gun*）。史実では袁世凱による地方軍の削減と北洋軍への置き換えが進んだが、本世界線ではそれが起きない。[^e021]

| 勢力 | 拠点・領域 | 推定兵力 | 性格 |
|---|---|---|---|
| 湖北系 | 湖北省（場合により河南南部） | 8〜15万人 | 地方立憲派と新軍の連合政権。経済基盤は武漢の商工業・漢陽兵工廠・長江水運 |
| 両江系 | 南京、中核は江蘇省、連携地域は安徽・浙江・江西 | 10〜20万人 | 地方立憲派・官僚・軍人の連合。英国系金融・商業資本と結びつき、商人・銀行家の影響が強い |
| 湖南系 | 湖南省 | 4〜8万人 | 湖北・広東・四川の間の緩衝的な地方政権 |

[^e021]

湖北の[黎元洪](../people/li-yuanhong.md)（1864〜1928）は、史実のように全国政治へ進出するのではなく湖北の地方政権を維持する道をたどる。史実の湖北軍は革命による動員で1912年初頭に10〜12万人へ膨張した。[^e021] 江蘇は経済力で華北の軍閥を上回りうる。**南京が孫文の中華民国政府の所在地になるとは限らない**。[^e021] 史実の湖南では革命後の湖南軍が約5万人に達し、譚延闓の地方政権が成立した。[^e021]

華南・西南の軍閥は北洋軍への依存度が低く、史実との連続性が高い。四川は人口と経済規模が大きい一方で複数の軍人が並立し、単一の軍閥として集計しにくい。雲南・広西は仏領インドシナとの経済関係からフランスの影響を受ける。馬家軍は清朝時代からの地方軍事組織と宗教・地域的人脈に基づくため袁世凱不在の影響を受けにくく、新疆は1917年以降ロシア革命の影響を直接受ける。[^e021] 孫文は臨時大総統を譲る展開がなくなる一方、自前の大軍を持たないため、広東・広西・雲南の軍事勢力との協力を必要とし、陳炯明ら連省自治派との対立も残る。南方の中華民国政府は当初から広州を所在地とし、華南軍閥の連合で維持される。[^e021]

# 清朝観と対外権利義務観

## 二つの軸

各勢力の立場は、**清朝への態度**（皇室への忠誠／立憲君主制／地方自治優先／共和革命）と、**清の対外関係への態度**（条約・債務・租界・鉄道利権・投資契約をどこまで承継するか）という独立した二軸で考える。反清派が外国との契約を否定するとは限らず、清朝忠誠派が列強権益を尊重するとも限らない。[義和団事件と東南互保](../events/boxer-rebellion.md)はこの二つが別問題であることを示していた。本世界線では、清朝への忠誠よりも**既存の経済秩序を維持する意思があるか**が、日英の支援先を決める基準になる。[^e022]

| 分類 | 国家間の条約・特権 | 公的債務 | 民間商業契約 |
|---|---|---|---|
| 承継派 | 原則維持 | 承継 | 尊重 |
| 改正派 | 交渉による改正 | 承継・条件変更 | 原則尊重 |
| 革新派 | 不平等条約の撤廃 | 選別・再交渉 | 特権的契約の見直し |

[^e022]

鉄道敷設権のように商業契約と政治特権の両方の性格を持つ権利は、承継派と改正派の間でも争点になる。[^e022]

## 勢力別の配置（1911〜15年頃）

| 勢力 | 清朝への態度 | 対外関係への態度 |
|---|---|---|
| 皇室・禁衛軍 | 王朝存続 | 全面的承継 |
| 華北・旧淮軍系 | 王朝への忠誠から秩序維持へ | 承継 |
| 奉天系 | 王朝存続または地方自治 | 承継・改正 |
| 晋系 | 共和制・地方自治 | 改正 |
| 両江系 | 立憲派から共和派へ | 承継・改正 |
| 湖北系 | 共和制・地方自治 | 承継・改正 |
| 湖南系 | 共和制・地方自治 | 改正 |
| 粤系 | 共和革命・連省自治 | 改正〜革新 |
| 孫文系共和派 | 王朝打倒・国家統一 | 改正〜革新 |
| 桂系 | 政体より地方権力 | 承継・改正 |
| 滇系 | 共和制 | 改正 |
| 川系 | 反中央集権・共和制 | 改正〜革新 |
| 黔系 | 地方自治・共和制 | 改正 |
| 馬家軍諸派 | 清朝忠誠派と地方自治派が混在 | 承継・改正 |
| 新疆 | 政体より地方秩序 | 承継 |

[^e022]

主な勢力の性格は次のとおりである。[^e022]

- **華北**：北京の外務部・度支部を押さえる官僚と軍人は、共和制を採っても、対外債務の承継・外交関係と海関制度の維持・鉄道鉱山契約の尊重・交渉による条約改正を選ぶ。日英には溥儀の身柄よりこの官僚機構を握る政権の方が重要である。
- **両江（反清だが親契約的）**：江蘇・上海の商人・銀行家・立憲派は皇族の集権化に強く反対するが、外国資本との関係を壊す動機は乏しい。日英にとって最も信用できる地方政権になりうるが、他省の分まで清朝の国家債務を背負うことには反対する。
- **湖北**：新軍の政治的影響力が江蘇より強く、関税自主権や鉄道経営権の回復に積極的。「中国側の管理権を回復したうえで外国資本を利用する」立場。両江・湖北は清朝打倒では孫文と協力できても、革命後の集権化では対立する。
- **広東**：陳炯明らの地方自治派（連省自治・自治の相互承認）と孫文系統一派（統一共和国・主権回復・他軍閥の統合）を分ける。孫文系は最初から債務の全面否認派ではなく、資本・技術の導入を必要としつつ、統一や財政自主権を妨げる外国権益の見直しを求める。ここに米国が関与する余地がある。
- **四川**：鉄道国有化を機に離反するため、清朝の鉄道借款に強く反発する。外国資本一般ではなく、地方出資の資産を中央が接収して外債の担保にすることへの反発で、北京政府が承継した債務を自省は負わないと主張しうる。
- **西北**：馬家軍は年長世代が皇室に忠誠、若い世代は地方政権の存続を優先。新疆は自治が尊重されれば北京の名目的支配を認めうる。

## 国家承認と債務承継

清朝崩壊直後の最大の国際問題は、共和制か君主制かではなく、**どの政権が中国という国家の国際法上の代表者になるか**であった。[^e022]

| 政権候補 | 強み | 弱み |
|---|---|---|
| 満洲の残存清朝 | 王朝としての法的連続性 | 税収・実効支配の不足 |
| 北京政府 | 中央官僚機構・外交機構 | 財政基盤の不足 |
| 両江政府 | 商業・金融・税収 | 全国政府としての正統性 |
| 湖北政府 | 工業・軍事・交通 | 全国政府としての正統性 |
| 南方共和政府 | 革命による政治的正統性 | 地方軍閥への依存 |

[^e022]

北京だけでは返済能力が足りず、江蘇・湖北には返済能力があっても国家債務を負う意思があるとは限らない。そこで日英は北京・南京・武漢の間で債務と税収の協定をまとめようとし、**清朝の権利義務を共同で承継する地方政権の連合体と、国家統一を目指す南方共和政府が対立する**構図が生まれる。これは「北方＝親英、南方＝反英」とするより、本世界線の経済構造と軍閥の成立過程に整合的である。[^e022]

# 列強の支援配置

## 列強別の支援先（1912〜1930年の基本方針、確定）

| 列強 | 主要支援先 | 副次的支援先 | 目的 |
|---|---|---|---|
| 英国 | 北京・両江・湖北 | 奉天・湖南 | 既存債権と商業秩序の維持 |
| 日本 | 英国とほぼ共通 | 奉天・山東 | 投資保護・朝鮮の安全保障 |
| 米国 | 南方共和政府 | 広東自治派・四川 | 門戸開放・既存権益の再編 |
| ドイツ | 南方共和政府 | 山東・湖北 | 市場確保・工業製品輸出 |
| ロシア帝国 | 満洲の清朝残存勢力 | 新疆・モンゴル | 南下政策・国境地帯への影響力 |
| ソ連 | 南方革命派 | 新疆・モンゴル・中国共産主義勢力 | 革命外交・国境の安全保障 |
| フランス | 雲南・広西 | 北京・貴州 | インドシナ防衛・鉄道権益 |
| イタリア | 北京 | 特定の地方政権に限らない | 既存権益・武器輸出 |

[^e023][^e024]

支援関係は1912〜30年を通じて固定されるわけではない。ここでいう「支援」は外交承認・借款・民間投資・軍事顧問・装備購入などで、軍事同盟や直接派兵を意味しない。満洲・山西・四川・西北の諸勢力は独自性を保ちながら複数の列強と交渉する。[^e023]

## 日英：契約承継型の連合国家

| 地方政権 | 日英にとっての重要性 |
|---|---|
| 北京 | 清朝の外交・債務・行政機構の承継 |
| 両江 | 上海金融市場・貿易・銀行・鉄道 |
| 湖北 | 長江水運・漢陽の工業・内陸交通 |
| 山東 | 北洋方面の鉄道・港湾権益 |
| 奉天 | 南満洲の鉄道・資源・対露牽制 |
| 湖南 | 長江中流域の安定 |

[^e023]

日英にとって最も都合がよいのは、軍閥が個別に独立することではなく、**北京を対外的な代表政府とし、両江・湖北などが高度な地方自治を保ちながら国家債務を共同で承継する体制**である。全国的な中央集権国家を再建する必要がなく、地方軍閥も権力を手放さずに済む。日英は清朝の復辟ではなく、この緩やかな国家連合の成立を促す（確定）。[^e023][^e024] これはのちに[中国諸省聯合](china-federation.md)として具体化した。[^e025][^e026] 前編で確定していた「日英は旧清朝の契約を尊重する軍閥への支援をやめられない」という構図は、この形で具体化される。[^u123]

日英の間には温度差がある。英国は租界・治外法権・海関制度などの政治特権も守る必要があるが、日本は英国系企業への出資者という性格が強いため、商業契約が守られるなら関税自主権・司法主権の回復を認める余地があり、北京の保守的な官僚・軍人よりも両江・湖北の穏健な条約改正派を評価しうる。この差は1920年代後半ほど重要になる。[^e023]

## 米国：南方共和政府と門戸開放

米国は孫文系の南方共和政府を政治的に支援するが、自国の投資も危うくなるので債務の全面否認は支持しない。求める条件は、中国の政治的統一、通商機会の均等、外国企業への差別的特権の撤廃、既存債務の合理的整理、米国企業の新規投資の保障である。孫文の集権思想そのものを支持する必要はなく、広東の自治派や、英国系鉄道借款への反発が強い四川にも投資しうる。[^e023]

## ドイツ：時期による変化

| 時期 | 方針 |
|---|---|
| 1911〜14年 | 既存権益を守る北京政府・地方軍閥と関係を維持 |
| 1914〜18年 | 英国の中国権益を牽制するが、直接支援能力は低下 |
| 1919〜33年 | 南方共和政府と経済・軍事技術面で接近 |
| 1933年以降 | 対ソ政策と欧州外交を踏まえて再調整 |

[^e023]

史実の日独関係と異なり、本世界線では**日英が支援する中国の既存秩序に対して、米独が新規参入を求める**構図となる。ただし米独に正式な共同対中政策は必要なく、それぞれが同じ政権を支援するだけでよい。[^e023]（→[戦間期の米独接近と米国内の宣伝戦](us-germany-relations.md)）

## ロシア帝国とソ連

ロシア帝国は、日英が支える北京とは別の中国政府を北方に確保したい。不退位の溥儀を保護すれば北京の正統性を牽制できる。満洲に清朝残存政権ができれば外交・金融支援、満洲でも崩壊すればロシア領内で皇室を保護する、という二方式のうち、後者が実現した（溥儀のウラジオストク亡命）。1917年の革命で皇室支援は根本から崩れる。[^e023][^e025]

ソ連は帝政の王朝支援を引き継がず、日英の既存秩序に対抗して南方共和政府に接近する。米独とソ連が同じ南方政府を支援する一見奇妙な構図となり、三者の最終目標が異なるため、南方政府の内部で外交路線の対立が生じる。[^e023]

| 支援国 | 南方政府を支援する理由 |
|---|---|
| 米国 | 通商機会・門戸開放 |
| ドイツ | 工業製品輸出・経済的再進出 |
| ソ連 | 反帝国主義運動・革命勢力の拡大 |

[^e023]

## フランス：西南の独自勢力圏

フランスは日英と同じ既得権益国だが、関心は雲南（鉄道・鉱山・対インドシナ貿易）、広西（国境治安・通商）、貴州（交通・鉱業）、北京（清朝以来の条約・債務）にある。南方共和政府による雲南・広西の統合は必ずしも望まず、既存契約を守る滇系・桂系の存続を支援するため、華南の軍閥がすべて南方共和政府の陣営に入るとは限らない。[^e023]

## 1920年代の三つの政治構想

| 政治構想 | 中心勢力 | 主な外国支援 |
|---|---|---|
| 契約承継型の連合国家 | 北京・両江・湖北 | 日英 |
| 中央集権型の統一共和国 | 孫文系共和派 | 米独・ソ連 |
| 地方自治・独立維持 | 雲南・広西・山西・四川など | 仏その他と個別に交渉 |

[^e023]

最も重要なのは北京と南京・武漢の関係である。北京だけでは財政が足りず、南京・武漢だけでは対外代表権を確立しにくいので、日英には三者を結びつける強い動機がある。1910年代に日英の仲介で「清朝の対外権利義務を共同で承継する南北横断的な連省協定」が成立し、孫文らはこれを外国資本による割拠の固定化と批判する。この対立を1920年代中国政治の中心に置くと、1930年代の反英民族主義、米独の対中進出、日本の軍閥政治への関与まで一貫して説明できる（検討案）。[^e023]

# 1920年代の帰属と1930年の配置

## 地方軍閥の帰属

聯合への加盟、中華民国への参加、軍事協力、外交的中立は別々の選択肢であり、共和主義者が聯合と協力することも、地方自治派が北伐に参加することもありうる。[^e030]

| 勢力 | 1925年頃の帰属 |
|---|---|
| 広西・新桂系（李宗仁・白崇禧・黄紹竑） | 中華民国に参加するが独自の軍と財政を保つ「準加盟勢力」 |
| 広西・旧桂系（陸栄廷） | 中立〜聯合寄り |
| 湖南（趙恒惕政権） | 聯合寄りの中立。帰属は北伐そのもので決まる |
| 雲南（唐継堯） | 聯合にも中華民国にも従属しない独立した連邦主義勢力。清朝債務は負担しない |
| 貴州 | 独立〜雲南寄り |
| 四川 | 分裂したまま各国と個別に交渉 |

[^e030]

東南では、浙江・安徽が聯合、江西が聯合寄りの独立軍閥、福建が中立〜中華民国寄りとされ、孫伝芳の五省聯軍が成立する経路はない（検討案）。[^e032]

## 1926年の兵力

| 陣営 | 構成（万人） | 合計 |
|---|---|---|
| 中華民国側 | 広東・国民革命軍8〜15、新桂系5〜8、唐生智派湖南軍2〜4 | 15〜27万人 |
| 聯合側 | 湖北軍8〜15、両江軍10〜20、華北軍12〜20、葉開鑫派湖南軍2〜4 | 32〜59万人 |

[^e032]

聯合側の兵力は加盟軍の合計で、統一指揮下にはない。[^e028] その後の湖南政変と北伐の経過は[北伐と湖南内戦（1926〜1930）](../events/northern-expedition.md)を参照。

## 1930年の配置

1930年の中国大陸は、中国諸省聯合（北京・南京・武漢）、中華民国（広州。広東・広西・湖南の大部分）、非加盟の独立軍閥、列強と外国人自治機関の施政地域という四種の統治主体に分かれている。[^e039]

| 非加盟勢力 | 1930年の状況 |
|---|---|
| 奉天系 | 満洲で独自政権を維持 |
| 晋系 | 山西の自治と独立性を維持 |
| 滇系 | フランスとの経済関係を背景に独立 |
| 四川諸軍閥 | 省内で分裂・抗争を継続 |
| 西北諸軍閥 | 地方支配を維持 |
| 亡命清朝皇室 | 実効的な政治権力を喪失 |

[^e039]

世界恐慌で独立軍閥は財政難に陥り、外国資本への依存を強める。中国は「経済的には外国資本を介して結合し、政治的には分裂し、軍事的には膠着している」。[^e039]

# 史実との比較

- 史実の軍閥政治は、袁世凱死後（1916年）の北洋軍の分裂（直隷派・安徽派・奉天派）を軸に展開し、北京政府の支配権をめぐって争われた。本世界線では北洋軍そのものが成立せず、長江流域の地方政権が独立した有力勢力となる。[^e021]
- 史実の北伐（1926〜28年）は、分裂した北洋軍閥を個別に打倒・吸収して成功した。本世界線では聯合という協議機構があるため北伐は史実より困難になる。[^e028]
- 史実のドイツは膠州湾を租借して山東に権益を持ったが、本世界線ではドイツの膠州湾租借が成立せず、青島は英国主導・日英資本の商業港となる（→[青島](../regions/qingdao.md)）。[^e038]
