# 概要

1932年7月21日から8月20日まで、カナダのオタワで英帝国経済会議が開かれた。本世界線でも会議そのものは史実どおり開催され、英国と各自治領のあいだの相互特恵協定の束として**帝国特恵関税制度が成立する**。[^e044][^e051] 本世界線でこの会議が史実以上に重い意味をもったのは、帝国の外に、英国の巨大な経済協力国である日本がいたからである。[^e012][^e044]

日本は帝国特恵圏にもスターリング圏にも加わらず、日本製品には一般外国と同じ関税がかかる。そのうえで日本は、**従来の日英経済協力関係を根拠とする「特別オブザーバー」**として会議に参加した（ユーザー決定）。日本が求めて得たのは関税上の特恵ではなく、**英国経済圏からの資源輸入の安定と、円建て開発投資に対する金融・行政上の優遇**の二つである。[^e049][^e051]

1930年のロンドン会議で海上通商防衛が制度化され（→[ロンドン海軍軍縮会議と条約（1930）](london-naval-conference-1930.md)）、1931年の通貨危機で金融協力が進み（→[1931年欧州通貨危機と日英金融協力](../events/currency-crisis-1931.md)）、1932年のオタワ会議で資源貿易と開発投資が制度化された。ただし軍事・通貨・関税のどれも単一の体制にはまとめられていない。この**「緩やかな結合」**が本世界線の日英関係の特徴になる。[^e051] 会議の後、日本は英国経済圏への資源開発投資を広げ、領主系企業を中心に海外鉱山へ資本を振り向けていく。[^e081][^e100]

# 背景

## 史実の会議と本世界線の前提

史実では、1930年の帝国会議で帝国内市場の拡大が合意され、カナダ政府が経済会議の準備を進めた。世界恐慌と英国の金本位制離脱（1931年9月）を経て、1932年2月に輸入関税法が成立し、7〜8月にオタワ会議が開かれる。議題は帝国内の相互特恵関税、原産地規則、帝国外諸国との通商関係、通貨・金融政策などであった。協定は帝国全体の単一関税ではなく、**英国と各自治領などとの二国間の相互特恵協定**が中心であった。そのため英国政府だけでは日本に帝国並みの待遇を約束できず、各自治領との交渉が必要になる。[^e044]

本世界線の1932年時点の日本は、次のような立場にある。

- 1925年に金平価・金兌換を法的に廃止して管理通貨制へ移行し、すでに7年ほど運営している（→[金本位制離脱と管理通貨制](../economy/gold-standard.md)）。[^e044]
- 第一次世界大戦期に生じた円建ての対英貿易信用・売掛債権を持つ対外純債権国である（→[円建て対外債権と円の国際化](../economy/yen-claims.md)、[日英戦時債務整理と中国権益の移転](war-debt-settlement.md)）。[^e100]
- 国際収支の黒字を資源現物の備蓄に向けており、恐慌下の一次産品の大口の買い手になっている（→[戦略資源備蓄制度](../economy/strategic-stockpile.md)）。[^e044]
- 1925年の財政原則により、公債で恐慌期の公共投資をまかない、国内で工業需要をつくり出せる（→[1925年財政原則と恐慌期の公共投資](../economy/fiscal-principles-1925.md)）。[^e046][^e048]

## 英国にとっての日本

英国から見た日本は、単なる輸出市場ではない。次の性格をあわせ持っている。[^e044]

| 日本の性格 | 内容 |
|---|---|
| 債権国 | 大規模な円建て対英債権を保有する |
| 資源の買い手 | 英帝国産の資源を大量に購入する工業国 |
| 共同投資国 | 中国における日英共同事業の相手（→[中国諸省聯合](china-federation.md)） |
| 同盟相手 | [日英海上通商防衛協定](anglo-japanese-maritime-defense-agreement.md)の締約国 |
| 通貨協力相手 | 英国の金本位制離脱後の円・ポンド協調の相手 |

日本を締め出した帝国経済圏をつくれば、英国の債務返済能力と海上通商防衛体制が傷つく。反対に日本を帝国特恵に組み込めば、自治領の産業保護と衝突する。これが本世界線のオタワ会議の根本的な難しさであった。[^e044]

## 1931年秋の日英緊急協定（検討案）

英国の金本位制離脱の後、オタワ会議に先立って日英は緊急の金融・通商協定を結ぶと想定されている（検討案）。日本は円建て債務の借換えや返済延期を認め、資源の買付を広げる。英国は日本製品に対する急激な関税引上げを避ける。[^e044]

| 日本側の措置 | 英国側の措置 |
|---|---|
| 円建て債務の借換え | 日本企業との既存契約の維持 |
| 円建て貿易信用の供与 | 対日輸入制限の抑制 |
| 資源の長期買付契約 | 資源供給の安定化 |
| ポンド買入れ・為替介入 | 円・ポンド相場の安定化協力 |
| 英国系企業への投資継続 | 日本資本に対する差別の回避 |

この協定は双方の恐慌対策を助ける一方で、英国が帝国特恵を導入するときの制約にもなる。通貨危機そのものの経過は[1931年欧州通貨危機と日英金融協力](../events/currency-crisis-1931.md)を参照。

## 自治領から見た日本（検討案）

自治領にとって、日本はかならずしも脅威ではなかった。一次産品価格の暴落に苦しむ地域にとって、備蓄のために資源を買い続ける日本は大事な市場である。一方で日本は工業製品の輸出国でもあるので、自治領の中でも一次産品輸出部門と工業部門とで利害が分かれる。[^e044]

| 地域 | 日本との主な経済関係 | 対日協力への態度（検討案） |
|---|---|---|
| オーストラリア | 羊毛・小麦・鉱産物 | 条件付きで積極的 |
| カナダ | 木材・小麦・非鉄金属 | 農業・資源部門は積極的、工業部門は慎重 |
| ニュージーランド | 羊毛・畜産物 | 市場拡大を期待 |
| 南アフリカ | 鉱産物・羊毛 | 比較的積極的 |
| インド | 綿花・マンガン・ジュート | 原料輸出には積極的、繊維産業は反対 |
| 英領マラヤ | 天然ゴム・錫 | 積極的 |
| 英領ボルネオ | 石油 | 積極的 |
| 英国本国 | 金融・機械・海運・共同投資 | 経済関係の維持を強く要求 |

このため対日協力は、英国本国が自治領に押しつける政策ではなく、**自治領の一次産品輸出部門からも求められる政策**になりうる。オタワでの対日論争は「帝国の内と外」の対立というより、**資源輸出部門と工業部門の対立**として現れる。[^e044]

# 日本の通商政策と交渉方針

## 保護関税から輸出市場の確保へ

工業生産性が十分に上がったのだから保護主義を続ける必要はない、というユーザーの提起を受けて、日本は1920年代に通商政策の重点を**幼稚産業保護から輸出市場の確保へ**移したと設定された（確定）。日本は工業製品輸出国・海運国・対外債権国という三つの性格を持ち、高関税で国内市場を守る利益より、世界貿易の拡大から得る利益のほうが大きくなっていく。[^e045]

| 時期 | 通商政策（検討案） |
|---|---|
| 19世紀後半 | 国内産業育成のための保護関税 |
| 1900〜1914年 | 工業化に伴う選択的な産業保護 |
| 1914〜1920年 | 輸出産業の急成長 |
| 1920〜1925年 | 工業製品の保護関税を段階的に引下げ |
| 1925〜1929年 | 輸出促進・原料輸入自由化を重視 |
| 1929〜1932年 | 世界恐慌下でも相互的な市場開放を追求 |

全面的な自由貿易ではなく、農業と新興産業には選択的な保護が残る。1925年の金本位制離脱と関税引下げは矛盾しない。管理通貨制で国内の信用供給を保ちつつ、関税引下げで原材料と設備の調達費を下げられるからである。[^e045]

債権国である日本には、輸入を増やす理由もある。英国が円建て債務を返すには円を手に入れなければならないので、日本が輸入を絞れば英国は借入れか資産売却に頼るしかない。輸入の拡大は、英国の返済を容易にし、原料費を抑え、備蓄を積み増し、対外債権の過度な累積を抑え、報復関税を防ぐ。[^e045]

## 「加入せず、排除されない」

日本が比較的自由貿易的な工業国になっていれば、日本はそもそも帝国特恵の導入に乗り気ではない。日本が英国に求めるのは、自国への特恵というより、従来の市場アクセスの維持、帝国特恵による新たな対日差別の回避、資源輸出制限の回避、円・ポンド間の決済の自由である。英国が経済圏を閉じようとするのに対し、日本はそれを外に開かれたものにしようとする。[^e045]

> **日本は帝国特恵圏への加入を求めるのではなく、帝国特恵圏によって排除されないことを求める。**[^e045]

この方針は E49・E51 のユーザー決定（部外者としての地位、オブザーバー参加）と整合する。これにより、日本が米国・欧州・ソ連・蘭領東インドなどとの通商を続けることとも矛盾しない。[^e045][^e049]

E45 では、日本側が提示しうる条件として次の表が示された（検討案）。[^e045]

| 日本側の提示条件 | 英国・自治領への要求 |
|---|---|
| 工業製品の関税引下げ | 日本製工業製品への差別回避 |
| 鉱産資源の輸入自由化 | 資源供給の保障 |
| 羊毛・綿花などの関税撤廃 | 長期供給契約 |
| 一部農産物の市場開放 | 日本製品の輸入割当確保 |
| 円建て債務の借換え | 通商・資本取引の継続 |
| 貿易金融の拡充 | 日本企業への差別的規制の回避 |

## 国内対立：工業・海運・金融 対 農業

部門別の利害は次のように整理される（検討案）。海運業と金融業の政治的影響力が史実より大きいため、自由貿易を支持する勢力はかなり強い。[^e045]

| 経済部門 | 通商政策に対する利害 |
|---|---|
| 鉄鋼・造船 | 原料輸入の自由化と海外市場の拡大 |
| 機械工業 | 輸出市場の確保、一部の新興分野は保護 |
| 繊維工業 | 原料輸入の自由化と外国関税の引下げ |
| 化学工業 | 分野によっては引き続き保護 |
| 海運業・商社 | 世界貿易の拡大、関税障壁の縮小 |
| 金融業 | 国際的な資本移動と債務決済の円滑化 |
| 農業 | 外国産農産物との競争回避 |
| 国内資源産業 | 安価な輸入資源に対する保護 |

問題になるのは工業製品より農産物である。日本の工業は英国製品との競争に耐えられるが、カナダやオーストラリアの大規模農業との競争は国内の農業者にとって深刻である。オタワ会議をめぐる日本国内の対立は「財界対外国」ではなく、**工業・海運・金融部門と農業部門の対立**になる可能性が高い。[^e045]

# 恐慌下の余剰生産力と需要の循環

オタワで各国がどこまで保護を求めるかは、恐慌で余った工業生産力の行き先と結びついている。史実の世界工業生産（ソ連を除く、1929年＝100）は1930年87、1931年75、1932年64まで落ちた。1929〜32年の世界貿易量は、食料品が約11%、原材料が約18.5%減ったのに対し、工業製品は40%以上減った。原材料価格の下落で一次産品国の購買力が落ち、それが工業国の輸出をさらに減らす悪循環である。[^e046]

本世界線では、日本の資源購入がこの悪循環を部分的にやわらげる（検討案）。[^e046]

1. 日本：資源輸入・戦略備蓄・信用供与
2. 英帝国の一次産品輸出地域：輸出収入と購買力を維持
3. 英国・日本の工業製品への需要：機械・設備・輸送機器・消費財
4. 工業生産と雇用の維持：さらなる原材料需要が生まれる

英国が帝国特恵を導入する目的の一つは、この循環で生まれる工業製品需要を英国本国へ誘導することにある。しかし、その需要を支えているのが日本の資源購入である以上、日本製品を締め出すのは自己矛盾になる。日本が買付先を米国・中南米・ソ連・蘭領東インドへ移せば、帝国各地の購買力はふたたび落ちかねない。[^e046]

> **英国は市場を持ち、日本は信用供給能力と資源購入需要を持っている。**[^e046]

このため E46 では、オタワでの対日協議が、特恵関税の例外措置にとどまらず日英共同の恐慌対策に発展しうるとされた。日本はここで、国内の公共投資と資源購入によって世界恐慌下に需要を生む「需要創出国」として会議に関わる。[^e046][^e048] 一方、英国のような植民地経済圏も日本のような信用供与能力も持たないドイツには、1933年のナチス政権成立につながる経済条件が残る（→[1933年の国際秩序再編とナチス・ドイツ](../events/nazi-germany-1933.md)）。[^e046]

# ポンド経済圏における日本の位置

## 部外者だが優位に保たれる（E49 決定）

ユーザーは E49 で次のように方針を示した。

> ポンド経済圏において日本は部外者で、関税は諸外国と同等にかかるだろうが、その上で日本を一定優位に保つ政策が取られる可能性は高いと思う[^e049]

これにより日本の制度上の位置が決まった（確定）。史実でもスターリング圏（ポンド準備と為替関係を中心とする緩やかな通貨圏）と帝国特恵関税制度は完全には重ならなかったが、日本はそのどちらにも正式には加わらない。[^e049]

| 制度 | 日本の立場 |
|---|---|
| 帝国特恵関税 | 対象外 |
| スターリング圏 | 非加盟 |
| 一般外国向け関税 | 適用される |
| 円・ポンド間の通貨協力 | 二国間協定によって実施 |
| 海上通商防衛 | 日英防衛協定の対象 |
| 資源供給・開発 | 個別契約によって優遇 |
| 対外投資 | 日英共同事業を促進 |

制度の上では部外者だが、経済的にはきわめて深く組み込まれている、という位置である。[^e049]

## 関税以外の優遇手段（検討案）

英国と自治領には、関税上の特恵を与えずに日本の優位を確保する手段がいくつもある。[^e049]

| 政策 | 日本側が得る利益 |
|---|---|
| 資源の長期供給契約 | 原料価格と調達量の安定 |
| 円建て貿易信用 | 為替リスクと決済費用の縮小 |
| 共同開発融資 | 鉄道・鉱山・港湾事業への参入 |
| 政府調達での契約 | 工業製品・資本財の需要確保 |
| 港湾・倉庫の利用契約 | 物流費の削減 |
| 共同海運事業 | 安定した貨物輸送需要 |
| 投資保護協定 | 政治的・法的リスクの低下 |
| 日英の金融機関による協調融資 | 他国企業より有利な資金調達 |

たとえば日英の企業が同じ鉱山開発に出資し、日本企業がその鉱石を長期購入し、必要な設備も日本企業から調達するなら、日本製品に一般外国並みの関税がかかっていても日本企業には商業上の優位が残る。英国側の設備購入に日本の金融機関が円建てで融資すれば、日本製品の販売条件を有利にすることもできる。これは**特恵関税ではなく、金融・所有・契約関係による優位**である。[^e049]

この構造なら、英国は帝国特恵を保って自治領との政治的結合を強められ、日本は英国経済圏から実質的に締め出されずにすむ。オタワ会議は「日本への特恵関税を認めた会議」ではなく、帝国特恵の成立と並行して、日英の既存の経済関係を金融・投資・資源供給の協定で維持する方針を確かめた会議となる。[^e049]

# 日本は何を売りたいのか

## 「開発事業そのもの」を売る（検討案）

ユーザーが E50 で「日本はスターリング経済圏に何を売りたいのか」と問い、AI は次のように整理した。本世界線の日本は、綿織物中心の輸出国ではなく、重工業・海運・金融・海外投資の発達した経済大国である（1930年の中核案：粗鋼生産能力900万t・実生産700万t、石炭4,800万t（作者確定で約6,000万tに修正）、商船650万総t、製造業労働生産性は米国の45%、造船は60%。→[重工業化と国力の推移（1870〜1930）](../economy/heavy-industrialization.md)）。日本が英国経済圏に求めるのは、製品の販売市場というより**資源の調達先と資本の運用先**である。[^e050]

日本が売るのは個々の製品ではなく、**経済開発に必要な資本財と付随サービスをひとまとめにした開発事業**である。英領マラヤで新しい鉱山を開く場合を例にとると、次のようになる。[^e050]

| 事業段階 | 日本側の経済活動 |
|---|---|
| 資金調達 | 円建て融資・共同出資 |
| 鉱山開発 | 採掘設備・建設機械の供給 |
| インフラ整備 | 鉄道・発電設備・港湾設備の供給 |
| 操業 | 技術者派遣・保守部品の供給 |
| 生産物購入 | 鉱石の長期買付 |
| 輸送 | 日本商船による海上輸送 |
| 利益回収 | 利息・配当・運賃収入 |

これは中国で行ってきた日英共同事業の延長線上にある。恐慌で英国の資本供給能力が落ちているので、「日本が資金を出し、英国企業が経営し、日英双方が設備を供給し、日本が資源を長期購入する」型の共同事業が成り立つ。日本の融資が英国製品への需要まで生むなら、英国政府が日本企業を排除する理由は弱まる。[^e050]

## 地域別の売りたいもの・得たいもの（検討案）

| 地域 | 日本が売りたいもの | 日本が得たいもの |
|---|---|---|
| 英国本国 | 船舶・部品・半製品・金融サービス | 高度な機械・技術・投資収益 |
| オーストラリア | 鉱山設備・農業機械・鉄道車両 | 羊毛・小麦・鉱石 |
| カナダ | 工業設備・船舶・電機 | 木材・鉱産物・農産物 |
| インド | 鉄道設備・発電設備・機械 | 綿花・マンガン・その他原料 |
| 英領マラヤ | 採掘設備・港湾設備 | ゴム・錫 |
| 英領ボルネオ | 石油関連設備・タンカー | 石油 |
| 英領アフリカ | 鉄道・鉱山・電力設備 | 鉱産資源・投資収益 |
| 香港・シンガポール | 船舶・修理・金融サービス | 物流・金融拠点へのアクセス |

大規模な対外純債権国である日本には、商品貿易の黒字を保つ必要もない。海外投資の利子・配当、海運収入、保険・金融収入、技術提供・事業経営の収入が十分にあれば、商品貿易が均衡か赤字でも国際収支上の問題は生じない。かつての英国経済に近い構造であり、日本は**工業・海運・金融を一体として海外市場に展開する資本輸出国**と捉えられる。[^e050]

## オタワでの要求の重要度（検討案）

| 政策 | 日本にとっての重要性 |
|---|---|
| 工業製品への特恵関税 | 中程度 |
| 資源の安定供給 | 非常に高い |
| 投資事業への参入権 | 非常に高い |
| 円建て金融取引の自由 | 非常に高い |
| 政府・公共事業の調達機会 | 高い |
| 海運上の差別回避 | 非常に高い |
| 投資資産・契約の保護 | 非常に高い |
| 利子・配当の国外送金の自由 | 高い |

日本が警戒するのは関税そのものより、帝国特恵をきっかけに英国が投資・金融・海運まで排他的な制度にしてしまうことである。関税上は一般外国として扱われても、資本参加・資源供給・金融・海運での既存の優位を保てるなら、日本は十分に妥協できる。[^e050]

# 会議での日本の地位と成果（E51 確定）

## 特別オブザーバー

ユーザーは E51 で次のように決めた。

> オタワ会議での立場は従前の経済協力関係に基礎づけられたオブザーバー参加とするのがいいかな。スターリング経済圏からの輸入と、円建て投資に関する優遇だけ入れてもらえればよさそう[^e051]

英国は日本との債権債務関係や資源貿易を協議せずに帝国経済政策を決められず、自治領は日本に議決権を与える必要がない。両方の事情に合うのが特別オブザーバーという地位である。[^e051]

| 項目 | 取り扱い |
|---|---|
| 参加資格 | 特別オブザーバー |
| 帝国内部の政治協議 | 参加しない |
| 帝国特恵関税の決定 | 議決権なし |
| 通貨・金融協議 | 参加可能 |
| 資源貿易・開発投資協議 | 参加可能 |
| 英国・自治領との個別交渉 | 自由 |
| 帝国特恵関税の適用 | 対象外 |
| スターリング圏への加盟 | なし |

日本代表団は、外務・財政・通商当局に加え、中央銀行・商社・金融機関の実務家を含む構成になる（検討案）。[^e051]

## スターリング経済圏からの輸入に関する優遇

日本が求めたのは輸入関税の特別待遇ではなく、資源調達の安定性と優先的な取引機会である。確認された内容は次の5項目である。[^e051]

1. 日本向け資源輸出に対する差別的な輸出制限を設けない。
2. 資源の長期供給契約の締結を奨励する。
3. 日本企業による資源開発事業への参加を促進する。
4. 供給不足時には既存の長期契約を可能な限り尊重する。
5. 円建てによる輸出代金の受領及び決済を認める。

日本の戦略備蓄政策が一次産品の安定した需要をもたらすので、英国と自治領にも受け入れる理由がある。ただし資源の排他的購入権や独占的供給権は設定しない。日本自身も調達先を多様化しておきたいからである。[^e051]

## 円建て投資に関する優遇

長期的にはこちらのほうが重要である。[^e051]

| 項目 | 優遇内容 |
|---|---|
| 円建て借款 | 公共事業・産業開発への利用を奨励 |
| 円建て債券 | 英国・自治領の政府や企業による発行を認める |
| 為替取引 | 円建て投資に伴う決済の円滑化 |
| 投資認可 | 円建て共同開発事業の優先的な審査 |
| 政府保証 | 公共性の高い開発事業について個別に付与 |
| 利子・配当 | 円による送金を保障するための金融協力 |
| 設備調達 | 融資契約に基づく日本製設備の調達を容認 |

この制度の要点は、**日本国籍の企業を一律に優遇するのではなく、円建て資金を利用した開発事業を優遇する**ことにある。英国企業が日本の金融市場で資金を調達する場合にも適用されるので、英国の産業界から見ても日本企業への特権付与にはならない。英国政府はオタワ会議だけで全自治領に義務を課せないため、会議では共通方針を確認するにとどめ、具体的な保証や投資条件は各政府との個別協定で定める。[^e051]

この制度には英国の既存の対日円建て債務を処理する意味もある（検討案）。日本が英国経済圏から資源を買えばそこに円が供給され、その円は日本からの輸入や円建て債務の返済に使える。円建て投資で新しい資源生産能力ができれば、将来の対日輸出能力も広がる。新規融資で既存債務を借り換え続けるのではなく、実物経済の発展で返済能力を高める構造である。[^e051]

## 確定事項

| 項目 | 帰結 |
|---|---|
| 帝国特恵関税制度 | 史実に準じて成立 |
| 日本の参加 | 特別オブザーバー |
| 日本製品への関税 | 一般外国と同等 |
| 日本のスターリング圏加盟 | なし |
| 日本向け資源輸出 | 長期供給契約・安定供給を促進 |
| 円建て投資 | 金融・行政上の優遇 |
| 円・ポンド間の為替 | 二国間の通貨協力によって安定化 |
| 具体的な通商・投資条件 | 各政府との個別協定で決定 |
| 第三国との通商 | 日英双方とも自由 |

日本はスターリング経済圏の構成国ではなく、**外部から資本と需要を供給する特別な経済協力国**になった。[^e051]

## 円・ポンドの二圏接続

通貨面でも日本はスターリング圏に加わらず、二つの通貨圏が互いに接続される形をとる。円をポンドに従属させる制度ではない。[^e044][^e051]

| 項目 | 英帝国通貨圏 | 日本 |
|---|---|---|
| 中心通貨 | ポンド | 円 |
| 金兌換 | 停止 | 廃止済み（1925年） |
| 為替政策 | ポンドを中心とした協調 | 独立した管理通貨政策 |
| 準備資産 | ポンド建て資産など | 円・ポンド・ドル・金など |
| 相互関係 | 日英間の信用供与・為替安定協定 | 同左 |

# 「緩やかな結合」としての日英関係

オタワ会議までの3年間で、日英関係は分野ごとに別々の枠組みで制度化された。[^e051]

| 年 | 契機 | 制度化された分野 |
|---|---|---|
| 1930年 | ロンドン会議・日英海上通商防衛協定 | 海上通商の防衛 |
| 1931年 | 欧州通貨危機 | 金融・通貨協力 |
| 1932年 | オタワ会議 | 資源貿易と開発投資 |

関係は強まっていくが、軍事・通貨・関税のどれも単一の体制にはまとまっていない。日英は軍事・金融で強く結びつきながら、通商政策では日本が比較的自由貿易的、英国が帝国特恵・保護貿易的で、完全には一致しない。だからこそ日本は英国と自治領のあいだに入り、個別の相互協定を積み重ねていく。[^e045][^e051] 同じ年の秋から冬には、海上通商防衛協定の第一追加議定書が結ばれる（→[日英海上通商防衛協定と追加議定書（1930〜1937）](anglo-japanese-maritime-defense-agreement.md)）。日英協調の全体像は[日英協調](anglo-japanese-cooperation.md)を参照。

# 米国の反応（検討案）

米国にとってオタワ会議は、1930年のロンドン会議に続く外交問題になる。海上交通の保護に続いて、通貨・金融・通商でも日英の結合が制度化されたからである。米国企業は中国市場だけでなく、カナダやオーストラリアでも日本企業と競争することになる。米国から見れば、日英協調は二国間の友好関係から**世界規模の経済ブロック**へ発展しつつある。ただし米国自身も高関税政策をとっているので、自由貿易を根拠に日英だけを批判するには限界がある。[^e044] 日本の対米経済戦略は[対米経済戦略](../economy/us-economic-strategy.md)を参照。

# その後の展開

## 1933年ロンドン世界経済会議（検討案）

1933年6〜7月のロンドン世界経済会議で、日本は「国際決済と貿易金融の安定を重視する債権国」として振る舞うとされる。金本位制への復帰には消極的、国際為替相場の安定・世界物価の回復・関税障壁の縮小・国際的な信用供与には積極的、通貨政策の統一には慎重、各国の公共投資には資本形成を伴うものなら肯定的、という立場である。会議での日英米仏の対立の中身は未検討である。[^e054]

## 英国経済圏への資源開発投資の拡大（1933〜1937）

オタワ会議の後、日本は英国経済圏への資源開発投資を広げる。輸出を増やすことより、安価な海外資源の調達と既存の海外所得の活用を重視したため、経常黒字は第一次世界大戦期ほど大きくならない。[^e100]

| 年 | 商品貿易 | サービス | 純所得・移転 | 経常収支 |
|---|---:|---:|---:|---:|
| 1933 | −2.0 | 2.0 | 3.0 | 3.0 |
| 1934 | −2.5 | 2.2 | 3.3 | 3.0 |
| 1935 | −3.0 | 2.5 | 4.0 | 3.5 |
| 1936 | −3.8 | 2.5 | 4.6 | 3.3 |
| 1937 | −5.0 | 2.3 | 5.0 | 2.3 |
| **合計** | **−16.3** | **11.5** | **19.9** | **15.1** |

（単位：億円。E100 の推計）[^e100]

商品貿易は赤字のまま、海外投資の所得とサービス収入で経常収支を黒字に保つ構造で、E50 で描かれた「英国型」の姿がそのまま数字に現れている。1933〜37年の経常収支累計+15.1億円に評価益+3億円を加え、1932年末79億円だった純対外資産は**1937年末に97.1億円**となる。1937年の対外資産のうち海外直接投資は80億円（うち海外鉱山・油田40億円）で、総資産の約45%を占める。大戦期の円建て対英債権（1914〜18年に生じた貿易信用・売掛債権40億円）は、1937年には残存・借換分25億円まで減っている。日本が「債権国」から「海外事業を経営する投資国」へ移ったことを示す数字である。[^e100] ただし以上は会話ログ2の推計で、会話ログ3の確定値では1937年単年の経常収支が+15.169億円（財貨貿易も+8.669億円の黒字）、対外総資産135億円・総負債37.9億円、英国向け戦時債権・借換債権等50億円が最大項目と改められた。1937年末の純対外資産97.1億円は両者で一致するが、1936年末以前の経路との整合は未決である。[^p091][^p097] 詳しくは[国際収支と対外資産（1914〜1937）](../economy/balance-of-payments.md)、[円建て対外債権と円の国際化](../economy/yen-claims.md)を参照。

## 海外鉱山投資への流れ

オタワ会議で円建て開発投資の優遇が確立したことは、その後の設定で前提として繰り返し参照されている。[^e080][^e081][^e084]

- **鉱業**：日本の鉱業資本には大きな海外展開の余地がある。投資先の想定は、中国諸省聯合（鉄鉱石・石炭・銅）、オーストラリア（石炭・鉛・亜鉛・金）、カナダ（銅・ニッケル・亜鉛）、英領マラヤ（鉄鉱石・錫）、インド（鉄鉱石・マンガン）、英領アフリカ（銅・金など）、蘭領東インド（石油・ボーキサイト・錫）、チリ（銅）、ニューカレドニア（ニッケル）。出資・採掘権・長期購入契約は区別される。[^e080]
- **国内鉱山の衰退との連動**：国内金属鉱山の機械化・集約化はダイスで失敗した（ダイス判定：1d100 > 55、出目1・ファンブル）。1930年代に国内鉱山は経営危機に陥り、特に領主系企業は国内鉱山に追加投資するより、**オタワ会議後の円建て投資制度を使って海外鉱山へ資本を振り向ける**。海外鉱山への出資が成功すれば、国内鉱業の生産性が低くても、製錬・加工産業は国際競争力を保てる。[^e080][^e081] 資源政策全体は[資源戦略](../economy/resource-strategy.md)、判定の一覧は[ダイス判定一覧（1935〜1937年設定）](../economy/dice-rolls-1937.md)を参照。
- **金融業**：管理通貨制の運営経験、大量の円建て対外債権・海外投資に、オタワでの円建て投資優遇が加わり、円建て借款・国際決済などの海外金融業務が史実より大きく発達する。[^e084]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 帝国特恵関税 | 1932年オタワ協定で成立 | 史実に準じて成立 |
| 日本の関与 | 会議の外にあり、ブロック化の影響を一方的に受ける | 特別オブザーバーとして通貨・金融・資源・投資協議に参加 |
| 日本製品への関税 | 一般外国並み。帝国各地で日本製品（特に綿製品）への関税・輸入制限が強まる | 一般外国並み。ただし資源契約・円建て金融・共同事業で商業上の優位を保つ |
| 日本の主力輸出 | 綿織物など軽工業品 | 資本財と開発事業（融資・設備・海運の一体パッケージ） |
| 日本の通貨 | 1931年12月に金輸出再禁止 | 1925年から管理通貨制。円・ポンドは二国間協力で接続 |
| 日英関係 | 通商摩擦が深まる | 「緩やかな結合」として資源貿易・開発投資が制度化 |

史実では、オタワ会議は日本にとって英帝国市場からの締め出しの始まりであった。インドとの綿業をめぐる摩擦（日印会商）など、1930年代の日英間の通商摩擦はここから深まる。本世界線では、日本が軽工業品の輸出国ではなく資源の大口の買い手・資本の供給者であるため、同じ帝国特恵の成立がむしろ日英の経済的相互依存を制度化する契機になる。[^e044][^e050] また史実の満洲事変は本世界線では起きず、日本が独自の円ブロックへ向かう動機も生じない。[^e049]

# 却下・修正された案

- **1930年の国内石炭生産4,800万t（前編の中核案）**：作者確定で1930年の国内石炭生産は約6,000万tに改められ、1930年代は坑内掘りの機械化の失敗（E79、出目27）によって1937年の5,400万tへ減少したとされた。4,800万tは旧推計として残す。
- **三段階関税案（E44 → E49 で却下）**：AI は E44 で、帝国特恵とは別に日本への「協定特恵」を設け、関税率を帝国内0〜5%／日本5〜10%／その他の外国15〜25%（仮例）とする三段階の構造を提案した。独立国である日本だけへの特恵は最恵国待遇条項に抵触するおそれがあるため、長期購入契約・品目別譲許・輸入割当・通商条約改定を組み合わせるとされていた。E49 でユーザーが「日本は部外者で、関税は諸外国と同等にかかる」と決めたため不採用となり、優遇は関税以外の手段で行うことになった。[^e044][^e049]
- **日英双方の経済ブロック化（E44 → E45 で修正）**：当初は日英がそろって経済ブロックをつくる方向が想定されていた。E45 で日本が比較的自由貿易的な工業国とされたことで、日本は帝国特恵の導入に積極的でなく、「加入せず、排除されない」ことを求める立場に修正された。[^e045]
- **「正式参加国にならず、会議の外で非公式に協議」案（E44 → E51 で修正）**：E44 では、日本は正式な参加国にならず、代表団が会期中に非公式に各国と協議し、会議後に個別協定を結ぶ手順が示された。E51 でユーザーが「オブザーバー参加」と決めたため、日本は特別オブザーバーとして通貨・金融・資源・投資協議に正式に参加できる形になった。会議後に個別協定で具体条件を詰める点は引き継がれている。[^e044][^e051]

# 未決の論点

- 日本の関税政策の個別税率（方向は E45 で決まったが、品目別の税率は未定）。[^e045]
- オタワ会議後に日本と英国・各自治領が結んだ個別協定の締結時期と内容（1932年秋以降とされるが具体化されていない）。[^e044][^e051]
- 自治領ごとの対日態度、特にインドの繊維産業やオーストラリア・カナダの工業部門の反発がどう処理されたか。
- 日本国内の農業部門の反発（カナダ・オーストラリアの農産物との競争）に対する補償や調整の手段。[^e045]
- 1933年ロンドン世界経済会議での日英米仏の対立の中身。[^e054]
