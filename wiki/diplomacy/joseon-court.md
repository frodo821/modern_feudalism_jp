# 概要

1880年代の朝鮮王朝（李氏朝鮮）は、1392年以来の王統、儒教的な君臣秩序、両班層、地方行政機構という独自の統治基盤を持つ一方、政権の存続を清の軍事力に左右されていた。[^u053] 本世界線では、清仏戦争（1884〜1885年）と日本の介入によって清の威信が早く揺らぎ、それが李氏王朝の立場を史実より早く不安定にした（ユーザーの指摘）。[^u053]

ただし清の権威低下は王朝の正統性を直ちに消し去るものではなかった。問題は、**清の後ろ盾によって維持されていた宮廷内の勢力均衡が崩れ、清の軍事力で抑えられていた国内対立が表面化すること**であった。[^u053] その中で国王[高宗](/people/gojong.md)は、清の干渉に対抗するため日本公使館に避難し、日本の保護を利用して清国代表を捕縛するまでに至り、宮廷政治は[日清戦争（1887〜1889）](/events/sino-japanese-war.md)の引き金となった。[^u056][^u061]

# 政治勢力

清の影響力が低下した場合の各勢力の変化は次のように整理される（検討案）。[^u053]

| 政治勢力 | 清の影響力低下による変化 |
|---|---|
| 高宗と王室 | 清への依存を減らせるが、国内の政治対立を自力で調整する必要がある |
| 閔氏系の政権勢力 | 清の軍事・外交的後ろ盾が弱まる |
| 急進開化派 | 清による政変鎮圧の危険が減り、政権参加の余地が広がる |
| 大院君系の勢力 | 清との関係とは別に、王室内部の権力争いを続ける |
| 地方両班・農民勢力 | 中央政権の統治能力や改革政策への不満が政治運動につながる |

- **高宗**: 王権の維持と清からの自立を図る。清の干渉と廃位の危険に直面し、のちに日本公使館を政治拠点とする。
- **閔氏（閔妃）系**: 王妃一族を中心とし、清を後ろ盾とする政権勢力。
- **大院君系**: 高宗の父・興宣大院君の勢力。史実では1882年に清に拘束・連行された。
- **開化派**: 清からの自立と改革を目指す勢力。日本の商業的利益と一時的に利害が一致するが、日本に従属するとは限らない。[^u051]
- **王世子**: 王位継承者。亡命・避難の対象候補とされた。[^u054]

# 統治能力の危機

王朝にとって最も危険なのは正統性よりも統治能力の問題であった。[^u053] 本世界線では日本の工業化が早く朝鮮との貿易も拡大しているため、朝鮮には史実より早く商品経済が浸透する一方、行政・租税制度がそれに追いつかない。日本が支援する開化派政権が旧来の両班層を敵に回す改革を進めれば、高宗は二重の困難に直面する。

> 改革しなければ農民や開化派が反発し、改革すれば既存の支配層が反発する。[^u053]

清の軍事的後ろ盾が失われていれば、この対立を外部の力で抑えることもできない。日本の早い近代化は、朝鮮の農民の不満や排外運動を早める要因にもなりうる。[^u047]

# 王朝の三つの道

1884年以降の王朝には、次の三つの道があるとされた（検討案）。三つは排他的ではなく、A→B→Cと推移しうる。[^u053]

| 道 | 内容 | 日本にとっての意味 |
|---|---|---|
| A: 高宗が改革君主として生き残る | 清の影響力を排除し開化派を政権に迎える。王朝は存続するが内閣や新官僚制で王権が制約される | 政治的に自立しつつ通商関係を維持する朝鮮が成立 |
| B: 宮廷政変の反復 | 閔氏系・大院君系・開化派の対立が続き、軍事力や外国の支援を利用した政権交代が頻発 | 条約を履行できる政府が不安定になる |
| C: 王制そのものが争点に | 財政・土地・身分制度の改革が進まず農民運動が大規模化し、統治体制の再編要求が強まる | 王朝保障と内政不干渉の矛盾が露呈する |

王朝が直ちに倒れるより、まず高宗の実権が制約される展開が考えやすい。日本が望むのは親日的な市場であり、王朝廃止は不要で、王室を存続させたまま開化派内閣で通商・財政・軍制を改革する方が既存秩序を利用できる。[^u053] ただし改革政権が日本軍の支援に依存すれば、国内で外国への従属と見なされる。

# 「正統性と実力の分離」

清の権威が失われた後、決定的になるのは「**朝鮮の軍隊が誰の命令に従うのか**」である。[^u053] 君主としての正統性は残っていても、軍隊と官僚を実際に統制できなければ政権は維持できない。これは1866年に徳川幕府が直面した問題と同じであり（[1866年の無血の幕府解体](/events/bloodless-dissolution-1866.md)）、本世界線では幕府が経験した「正統性と実力の分離」が1880年代後半の朝鮮王朝で表面化する。[^u053] 実際、高宗が日本側に立った後も、朝鮮の軍隊・官僚・地方勢力がすべて同じ立場をとるとは限らず、国内の分裂は残った。[^u061]

## 日本の独立保障と宮廷政治

日本が高宗と李氏王朝の正統性を保障したことで、開化派の行動は王朝廃止ではなく高宗の下での改革として位置づけられる必要が生じた。[^u055] 一方で、高宗が日本公使館へ自発的に避難すれば、開化派の政変を成功させる必要すらなくなる。高宗は日清間の勢力争いの受け身の対象ではなく、**清から自立するために日本の外交的・軍事的影響力を利用する政治主体**となった。[^u056]

## 亡命という選択肢

弱体化した李氏王朝が清を切って日本に亡命する可能性は「まあまあある」とされた（ユーザーの判断）。[^u054] 日本への亡命が現実味を帯びるのは、清の保護を期待できず、かつ日本による王朝廃止や直接支配を恐れる理由が小さい場合である。高宗が亡命の前から「清の介入が強まれば日本の保護を求める」と秘密裏に伝え、亡命カードを交渉材料にする展開も考えられた。日本は皇族出身の[那珂川公爵家](/people/nakagawa-ducal-house.md)をはじめ多くの世襲領主を抱える立憲君主国であり、外国王室を保護する儀礼と制度を整える能力があった。[^u054] 最終的には、日本本土への亡命ではなく漢城の日本公使館への避難が採られた（[高宗の日本公使館避難と1886年漢城公使館危機](/events/gojong-legation-refuge.md)）。

## 日本にとってのジレンマ

清の権威を弱めることには日本の利益があったが、王朝が不安定になりすぎることは日本の通商政策にも反した。条約を履行できる朝鮮政府がなければ、日本の商人や企業は財産と人員の安全を確保できない。そして日本が治安維持に軍事介入すれば、反日感情が高まる。[^u053] 日本の経済進出が成功するほど朝鮮で反日・反外国運動が強まるというジレンマもあった。[^u051]

# 戦後の展望

戦後の朝鮮は単なる緩衝地帯ではなく独立国家であり、高宗政府の安定、朝鮮軍備の近代化、港湾・鉄道をめぐる日露の権利関係が、日本の安全保障の積算項目となった。日本の影響力が強くなりすぎれば、高宗政府がロシアへ接近する誘因も生まれる。[^u084]

# 史実との比較

- 史実の1882年壬午軍乱では大院君が一時復権し、清軍の介入でその政権は覆された。1884年甲申政変の開化派政権は清軍によってわずか3日で倒れた。清は名目的な宗主国ではなく、朝鮮の政権存続を軍事力で左右していた。[^u053]
- 史実では開港後の米穀輸出・物価変動・地方官の収奪・身分秩序への反発が農民運動の背景となり、東学がそれを取り込んで1894年の大規模農民蜂起につながった。[^u053]
- 史実の高宗も近代化に無関心ではなく、1887年には清の反対を押して外交使節をアメリカへ派遣し、電気設備や外国人顧問を導入した。[^u053]
- 史実の1884年、清仏戦争で清が朝鮮駐屯軍の一部を引き揚げたことを、金玉均ら急進開化派は好機と判断した。[^u050]

# 未決の論点

- 1880年代後半に高宗が立憲君主制への移行を受け入れるか、宮廷政治の維持を図って改革勢力と対立するか。[^u053] 清から自立した後、高宗が開化派と協調するか王権強化を目指すか。[^u056]
- 閔氏系・大院君系が袁世凱逮捕事件と日清戦争でどう動いたか、朝鮮国内の親清派の処遇。
- 1890年代に農民蜂起が起きるか、起きる場合の性格（日本の支援を受ける改革政権への抵抗となる可能性）。[^u050]
