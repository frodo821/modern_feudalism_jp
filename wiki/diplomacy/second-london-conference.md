# 概要

**第二次ロンドン海軍軍縮会議**は、1930年の[ロンドン海軍軍縮条約](london-naval-conference-1930.md)の期限（1936年末）を前に、1935年12月に開幕した米英日などの海軍軍縮会議である。1930年の会議で米国は「潜在的な日英連合」を相手に交渉したが、1935年の米国が相手にしたのは、1932年の第一追加議定書で共同防衛義務を明文化した「日英防衛同盟」であった。[^e060] 米国は1930年に受け入れた総排水量比 **100:85:65（米140万・英119万・日91万英トン）** に納得せず、日英合算兵力との均等（二国標準主義）を要求した。[^e060][^e061]

ロンドン条約は自動延長ではなく、決裂した時点で各国の海軍は膨張し始める。本世界線の第二次ロンドン会議は、妥協点を探す会議ではなく、**軍縮体制の終了について誰が外交的責任を負うかを争う会議**であり、決裂は既定路線だった。[^e061] 会議は1936年春に**全面決裂**し、1936年12月31日をもって総排水量・艦種別保有量・個艦排水量・主砲口径を含む既存の海軍軍備制限がすべて失効した。[^e062] 1922年以来14年間続いた主力艦の新規起工停止もここで終わり、1937年から日英と米国は異なる海軍思想に基づく建艦競争に入った（→[1937年の建艦競争と海軍財政](../military/naval-buildup-1937.md)）。[^e061][^e065]

# 背景

## 1930年条約の枠組み

1930年4月22日に署名されたロンドン条約は、米英日の海軍全体の基準排水量に総量上限を課し、日英の現有艦隊を削減しない「海軍軍備増強制限条約」であった。主力艦の建造停止は1936年末まで延長され、条約の有効期間も1936年末までとされた（第20条）。[^e008] 第16条は、国際関係の変化を理由に締約国が再協議を要求できる規定であり、その対象は「本条約署名の日以後」の事態に限定された。日英は前日の4月21日に[日英海上通商防衛協定](anglo-japanese-maritime-defense-agreement.md)へ調印し、協定は第16条と無関係という立場をとった。[^e010]

## 1930年から1935年までの変化

1935年の米国から見ると、艦艇の合計排水量が変わっていなくても、日英海軍を支える経済的・制度的基盤は大幅に強化されていた。[^e060]

| 争点 | 1930年 | 1935年 |
|---|---|---|
| 日英共同交戦 | 潜在的な可能性 | 条約上の共同防衛義務 |
| 海軍基地 | 従来の協力関係 | 相互利用の制度化 |
| 海軍当局 | 非公式な協議 | 常設の日英海軍協議会 |
| 通貨・金融 | 経済的相互依存 | 円・ポンド間の金融協力 |
| 資源供給 | 商業契約 | 長期供給契約・[戦略備蓄](../economy/strategic-stockpile.md) |
| 欧州情勢 | 比較的安定 | 独伊の現状変更政策 |
| 米国経済 | 恐慌の初期 | ニューディールによる回復途上 |

[^e060]

1932年の第一追加議定書は、一方の商船だけが攻撃された場合や、適法な海上封鎖に対しても共同防衛義務が生じることを定め、例外は締約国自身が始めた侵略戦争に起因する場合だけであった。[^e053] 恒久的な統合司令部はないものの、米国との海上戦争で日英が共同交戦する可能性は、もはや仮想上の想定ではなくなった。[^e060]

米国の側でも、レッド・オレンジ計画（英＝レッド、日＝オレンジの二正面戦争計画）が史実より具体的かつ緊迫しており、日英の離間はすでに遅きに失していた。[^e005] 史実の1934年ヴィンソン＝トランメル法（102隻の取得承認）に相当する建艦法が本世界線でも成立し、1930年条約で米国が得た約29万トンの純増枠の相当部分はすでに建造計画に組み込まれていたと考えられる（検討案）。[^e060]

## 欧州情勢との矛盾

米国は欧州の勢力均衡を理由に[ドイツの対仏軍備均等を容認し](../events/nazi-germany-1933.md)、[第二次エチオピア戦争](../events/second-italo-ethiopian-war.md)でも対伊制裁に協力しなかった。[^e056][^e059] その結果、英国は独伊の海軍力に対応する必要を強く認識するようになり、第二次会議で次のように反論できた（検討案）。[^e060]

> 米国は欧州における軍備の増加を容認する一方、その増加に対応するための英国の軍備整備を制限しようとしている。

日本もこれを支持し、米国の二国標準主義に対して日英は**世界全体の海軍力を考慮した兵力配分**（独伊など非参加国の海軍力も考慮せよ）を主張した（検討案）。[^e060]

# 各国の立場

## 米国：二国標準主義

米国の要求は、単純な自国保有枠の拡大にとどまらなかった。米国から見れば、日英の海軍力は軍艦の排水量だけでは測れないからである。交渉の出発点として米国が示した要求は次のとおりで、これだけで日英が承諾できる範囲を大きく超えていた。[^e061]

| 争点 | 米国の要求 |
|---|---|
| 総排水量 | 米国と日英合算の均等 |
| 主力艦 | 米国と日英合算の均等 |
| 航空母艦 | 米国と日英合算の均等 |
| 海軍基地 | 日英間の相互利用に制限 |
| 補助艦艇 | 従来の規制対象外艦艇にも制限を拡大 |
| 商船 | 軍事転用を前提とした建造への規制 |
| 軍事協定 | 日英共同防衛義務の縮小または再検討 |
| 軍事協力 | 常設海軍協議会の権限制限 |

[^e061]

米国の認識は1930年から大きく変わっていた。[^e061]

| 項目 | 1930年 | 1935年 |
|---|---|---|
| 国内経済 | 恐慌の初期 | 恐慌からの回復途上 |
| 財政思想 | 財政均衡を重視 | 政府支出の拡大を容認 |
| 建艦能力 | 大きいが財政的制約 | 遊休工業生産力の活用が可能 |
| 日英関係 | 潜在的な軍事協力 | 明文化された防衛同盟 |
| 軍縮による安全保障 | 一定の改善を期待 | 不利な均衡の固定化を懸念 |
| 条約失効の評価 | 回避したい | 受容可能 |

ニューディール政策の下で政府支出による雇用創出が政治的に受け入れられ、海軍建造も雇用政策として正当化できるようになった。**1930年には財政制約が米国を妥協させたが、1935年の米国は財政支出の拡大によって海軍力の不均衡を解消できると考え始めていた**（検討案）。[^e060] ただし、米国が実際に日英合算を上回れるかどうかと、1935年の米国政府・海軍がそれを可能と認識しているかどうかは区別される。[^e061]

## 日英：条約失効も受け入れる

日英は軍縮体制の維持を望んだが、そのために安全保障上必要な兵力を放棄することはできなかった。英国は独伊の再軍備に、日本は1930年代の公共投資と資源貿易の拡大で増えた保護すべき海上交通に対応する必要があり、1930年に設定した日本の91万トン枠が1935年にも十分である保証はなかった（検討案）。[^e060] 条約が失効すれば、英国は対独伊海軍力を整備でき、日本は拡大した商船隊と資源貿易に見合う海軍を整備でき、1922年以来延期されてきた主力艦の更新も可能になる。**三国とも軍縮を望むという建前を維持しながら、相手の条件を受け入れるより建艦競争を選んだ**。[^e061]

| 国家 | 1935年の追加的な海軍需要（検討案） |
|---|---|
| 米国 | 日英共同交戦への備え |
| 英国 | ドイツ・イタリアへの対応 |
| 日本 | 商船隊の成長と世界的な通商保護 |
| フランス | ドイツ・イタリアへの対応 |
| イタリア | 地中海・東アフリカ方面の権益維持 |

[^e060]

## 英独海軍協定の不成立（検討案）

史実では会議に先立つ1935年6月18日に英独海軍協定が結ばれ、ドイツの海軍総排水量を英国の35%まで認めた。本世界線の英国はドイツの再軍備自体に反対しており、しかもドイツ海軍が英国商船を攻撃すれば日本の共同防衛義務が発生するため、この協定を史実どおり締結する理由に乏しい。英国はむしろ第二次ロンドン会議を通じた多国間の制限を求めるが、ドイツが応じる保証はない。[^e060]

# 配分案

交渉構造を検討するための仮の数値として、次の配分案が想定された（単位：万英トン、いずれも検討案）。[^e060][^e061]

| 配分案 | 米国 | 英国 | 日本 | 日英合算 | 日英合算の対米比 |
|---|---:|---:|---:|---:|---:|
| 1930年条約（現行） | 140 | 119 | 91 | 210 | 150% |
| 米政府の妥協案 | 180 | 119 | 91 | 210 | 117% |
| 日英側の増枠要求例 | 180 | 135 | 105 | 240 | 133% |
| 米国の増枠による均等（米海軍の理想） | 210 | 119 | 91 | 210 | 100% |
| 日英の削減による均等 | 140 | 79.3 | 60.7 | 140 | 100% |
| 三国の調整による均等 | 180 | 102 | 78 | 180 | 100% |

均等案はいずれも日英に受け入れにくい。米国だけの増枠を認めれば日英は独伊の再軍備や通商需要の増加に対応できず、日英の削減を伴う案は1930年にも拒否した現有艦隊の廃棄を要求することになる。[^e061]

# 経過

会議の経緯は次のとおりである。[^e061][^e062]

| 時期 | 出来事 |
|---|---|
| 1935年前半 | 米国がロンドン条約第16条に基づく再協議を要求 |
| 1935年夏 | 日英が現行比率の維持または三国の増枠を提案 |
| 1935年12月 | 第二次ロンドン海軍軍縮会議開幕 |
| 1936年初頭 | 米国が日英合算との兵力量均等を要求 |
| 1936年春 | 日英が米国案を拒否。総量規制交渉が決裂（全面決裂） |
| 1936年中 | 各国が条約失効後の建艦計画を策定・予算化 |
| **1936年12月31日** | **第一次ロンドン条約失効。すべての海軍軍備制限が消滅** |
| 1937年1月以降 | 海軍軍備拡張競争が本格化 |

会議決裂と条約失効には時間差がある。現行条約は1936年末まで有効なので、決裂直後から設計・予算化・造船施設の拡張が始まり、条約の制限を超える建造は失効後になった。[^e061]

## 全面決裂の内容

会議は質的制限だけを残す部分合意にも至らず、全面決裂した。[^e062]

| 規制 | 1937年以降 |
|---|---|
| 総排水量 | 廃止 |
| 艦種別保有量 | 廃止 |
| 個艦排水量 | 廃止 |
| 主砲口径 | 廃止 |
| 建艦計画の通報 | 任意 |
| 主力艦建造停止 | 終了 |

航空機と航空母艦は1930年まで総量規制すら存在せず、1930年条約の空母枠も失効で消滅した。このことが、日英の航空主兵論への転換を妨げる制度的・予算的な既得権を小さくした。[^e062]（→[航空攻撃試験と航空主兵論](../military/naval-aviation-1935.md)）

# 帰結

## 建艦競争の性格

1937年以降の海軍軍拡は、史実のような日本による対米英海軍力への挑戦とは異なる性格を持つ。[^e061]

| 国家 | 軍拡の主目的 |
|---|---|
| 米国 | 日英合算兵力との均衡達成 |
| 英国 | 対米均衡及び独伊への対応 |
| 日本 | 日英共同防衛義務の履行と通商保護 |
| ドイツ | 海軍力の再建 |
| イタリア | 地中海における海軍力の拡大 |
| フランス | 独伊海軍力への対応 |

日英は軍拡でも相互の任務分担を考慮するため、米国は二国分の海軍を個別に相手にするのではなく、**相互補完的に発達する二つの海軍**を相手にすることになる。決裂によって米国は建艦の自由を得たが、日英も海軍整備方針をさらに協調させる必要に迫られた。[^e061]

## 三国の建艦方針

1935年の日英共同航空攻撃試験の結果、日英は航空主兵論を採り、米国は戦艦・航空併用論を維持した。1937年の三国の総括は、日本が「防空戦艦を伴う空母中心海軍」、英国が「既存戦艦を活用しつつ空母中心へ移行する海軍」、米国が「戦艦と空母を併用する従来型海軍」である。[^e065] 米国では1937年に仮称「1937年海軍拡張法（Naval Expansion Act of 1937）」が成立し（ダイス判定：1d100 > 20、出目99・クリティカル）、日本では軍艦建造への公債発行が条件付きで承認された（ダイス判定：1d100 > 40、出目51）。[^e067] 詳細は[1937年の建艦競争と海軍財政](../military/naval-buildup-1937.md)を参照。

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 会議の開幕 | 1935年12月 | 1935年12月 |
| 決裂の原因 | 日本の対米英均等要求 | 米国の日英合算均等（二国標準）要求 |
| 総量規制を破綻させた側 | 日本（1936年1月に会議脱退） | 米国 |
| 成立した条約 | 1936年第二次ロンドン条約（質的制限中心、日伊不参加） | なし（全面決裂） |
| 1936年末以降 | 日本はワシントン・ロンドン両条約から離脱、英米仏は質的制限を維持 | 米英日のすべての制限が失効 |
| 英独海軍協定 | 1935年6月成立（独海軍を英の35%まで容認） | 成立しない可能性が高い（検討案） |
| 英国の巡洋艦所要 | 約50隻から70隻へ増やそうとした | 独伊対応から増枠要求に根拠あり |

史実の第二次ロンドン会議では、日本の均等要求をめぐって総量規制が成立せず、1936年の条約は個艦規格など質的制限を中心とするものになった。本世界線では総量規制を破綻させる側が米国になる。[^e060]

# 却下・修正された案

* **部分合意案**: 総量・艦種別保有量は廃止しつつ、個艦排水量・主砲口径の質的制限と建艦計画の通報を維持する案（非締約国の規格超過を理由とする解除条項付き）。ドイツが軍備制限を破棄した状況では日英に非参加国を拘束できない質的制限への抵抗があり、「全面決裂でよさそう」との決定で不採用となった。[^e061][^e062]
* **新比率での合意・暫定延長案**: 1935年時点では「米国の大幅増枠と日英の限定的増枠による新比率」「主力艦の更新を認めつつ総量交渉を継続する暫定延長」も帰結の候補とされたが、決裂が既定路線であるとの判断で退けられた。[^e060][^e061]

# 未決の論点

* 英独海軍協定が成立しないことは「可能性が高い」とされたのみで、ドイツの海軍再建規模も未決。[^e060]
* 1932年の第一追加議定書が第16条の対象となるか（日英は既存協定の実施細則、米国は新たな軍事的義務と主張）という1930年以来の争点が、会議でどう扱われたかの具体像。[^e010]
* 仏伊など他の参加国の態度と、会議における具体的な外交過程。
