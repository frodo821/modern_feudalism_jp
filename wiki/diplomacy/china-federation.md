# 概要

中国諸省聯合（略称「聯合」）は、[辛亥革命](../events/xinhai-revolution.md)で清朝が崩壊した後の1912年、北京・両江（南京）・湖北（武昌）を中核とする地方政権が、**清朝以来の対外権利義務（条約・公的債務・海関・鉄道鉱山契約）を共同で管理するために**結成した連合体である。[^e025][^e026] 強力な軍事指導者が他の軍閥を従属させて成立した組織ではなく、各省は独自の政府・軍隊・財政を保ったまま、外交・国家債務・海関・省境を越える交通だけを共通機関に委ねる。[^e025][^e026] 恒久的な国号と国体は将来の全国協議に委ねられ、聯合は「新国家の独立宣言」ではなく「従来の中国国家が存続しており、その対外権利義務を共同管理する暫定機構」であると主張した。[^n1][^e025]

日本と英国は、広州で建国を宣言した[中華民国](republic-of-china-canton.md)ではなく、この聯合を中国の対外代表機関として承認し、支援する。[^e023][^e024][^e025] 本世界線の中国を象徴する標語は「**中華民国は成立しているが、中国全体を代表する国家としては成立していない。そして日英が承認する中国の代表機関は中華民国ではなく、中国諸省聯合である**」である。[^e025]

聯合は1912〜26年を創設者[張謇](../people/zhang-jian.md)による形成・安定期とし、1926年以降は後継者問題と中華民国による統一戦争（[北伐](../events/northern-expedition.md)）の時代に入る。[^e026][^e027] 実質的指導者[黎元洪](../people/li-yuanhong.md)が1928年の[武昌公邸火災事件](../events/wuchang-residence-fire-1928.md)で怪死すると、聯合は特定の指導者を持たない暫定集団指導体制に移行し、1930年には「**共通の敵と共通の債務によって結びついているが、共通の指導者を持たない政治共同体**」となった。[^e034][^e035]

# 成立の背景

## 清末の軍権分散

本世界線の清朝は1889年の[日清戦争](../events/sino-japanese-war.md)敗北後、袁世凱を失ったまま軍制改革を進めたため、北洋・湖北・両江・広東・京師直属の各新軍が並立し、「史実より早く軍隊の近代化が進む一方、史実以上に軍事権力が分散する清朝」となった。[^e016] 摂政載灃は皇族中心の集権化を史実より強く断行し、維持費を地方に負担させたまま人事権・指揮権だけを中央へ移そうとして立憲派まで離反させた。[^e018] 皇室直属の禁衛軍は1.2〜1.5万人程度にすぎず、複数の省が同時に独立すれば止められない。結果として「**清朝の滅亡そのものは史実より容易だが、清朝に代わる統一国家の成立は史実より困難**」となる。[^e019] 清末の経過は[清末の軍制改革と新政（1889〜1911）](../events/late-qing-reforms.md)を参照。

1911年の革命後、溥儀は退位せずに1912年ウラジオストクへ亡命し、ロシア帝国の保護を受けた。[^e020][^e024][^e025] 袁世凱による南北和平交渉も清帝退位もないため、共和政への一括した政権移譲は起こらない（→[溥儀](../people/puyi.md)）。

## 三極構造と「承継派」

革命後の中国は単純な南北二極ではなく、華北の旧清朝官僚・軍事政権、長江流域の地方立憲・軍事政権、華南の共和革命政権の三極構造に、満洲・西南の自立勢力が加わる形となった。[^n1][^e021] 各勢力は「清朝への態度」と「清の対外権利義務への態度（承継派・改正派・革新派）」の二軸で整理され、日英の支援先を決める基準は清朝への忠誠ではなく、**既存の経済秩序を維持する意思があるか**であった。[^e022]

| 勢力 | 清朝への態度 | 対外権利義務 |
|---|---|---|
| 華北・旧淮軍系 | 忠誠から秩序維持へ | 承継 |
| 両江系 | 立憲派から共和派へ | 承継・改正 |
| 湖北系 | 共和制・地方自治 | 承継・改正 |
| 湖南系 | 共和制・地方自治 | 改正 |
| 孫文系 | 王朝打倒・国家統一 | 改正〜革新 |

[^e022]

両江・湖北は「反清だが親契約的」な勢力であり、清朝打倒では孫文と協力できても、革命後の集権化では対立する。[^e022] 北京は官僚機構・外交機構を持つが財政基盤がなく、南京・武漢は税収・工業を持つが対外代表権を確立しにくい。三者を結びつける強い動機を持ったのが日英であった。[^e022][^e023]

# 成立と国号問題

## 国号の三案

清の権利義務を承継する共同体が国を名乗るのか、それが中華民国なのかは、成立時の大きな論点であった。[^e025] 共同体は「対外的には一つの国家を名乗る必要性が高いが、国内的には統一政府を作る必要性が低い」ため、次の三案が比較された。[^e025]

| 案 | 共同体の名称 | 南方の名称 | 評価 |
|---|---|---|---|
| A案 | 中華民国 | 中華民国 | 二つの中華民国。共同体が強い中央政府を望まないなら実態に合わない |
| B案 | 中華聯邦共和国 | 中華民国 | 国家構想の対立になるが、1912年に連邦憲法を作れるか疑問 |
| **C案** | **中国諸省聯合（国号留保）** | 中華民国 | 採用 |

C案が採られ、共同体は「中国諸省聯合」（略称「聯合」）と称した。[^e025][^e026]

## 制度の骨格

成立時の制度は次のとおりである。[^n1][^e025]

| 項目 | 内容 |
|---|---|
| 名称 | 中国諸省聯合（対外呼称は「中国（China）」） |
| 中央機関 | 北京 |
| 意思決定機関 | 諸省代表会議 |
| 外交機関 | 旧清朝外務部を承継 |
| 財政機関 | 共同債務・海関管理機関 |
| 国家元首 | 当面置かない |
| 統一軍 | 置かない |
| 加盟省 | 独自の政府・軍隊・財政を保持 |
| 国体 | 恒久憲法の制定まで留保 |

共通機関の所管は、外交関係、清朝の公的債務の承継と償還、海関税収の管理、既存条約・契約の履行、省境を越える鉄道・水運・郵便に限られる。[^e025] 正統性の根拠は、亡命清朝皇室が「皇帝の地位と王朝の継続」、中華民国が「革命と国民主権」であるのに対し、聯合は「**国家機構・実効支配・権利義務の承継**」である。聯合は皇室の帰還を認める必要がなく、共和国を宣言しなくても清朝の国家機構を運営できる。[^e025]

成立は1912〜13年、北京・両江・湖北の連携による。1912年の結成時に日英が対外代表権を承認した。日英の仲介で、清朝の対外権利義務を共同承継する「南北横断的な連省協定」が結ばれた可能性もある。[^n2][^e023][^e025]

# 機構と指導体制

## 集団指導の機構

聯合の機構は、特定の人物に元首の権限を与えない集団指導体制である。[^e026][^e027]

| 機関 | 構成・役割 |
|---|---|
| 中国諸省聯合代表会議 | 加盟省政府の代表で構成する最高合議体 |
| 聯合主席 | 代表会議の議事・地方間調整・対外代表。各省軍の統帥権は持たない。初代は張謇 |
| 外交委員会 | 唐紹儀ら外交官 |
| 財政委員会 | 旧清朝官僚・金融実務家。1928年以降は日英の債務・借款交渉の相手方 |
| 軍事協議会 | 黎元洪ら各省軍代表。黎元洪期に事実上の最高意思決定機関化 |
| 交通委員会 | 鉄道・水運・郵便の管理 |

政治的中心は北京にあるが、**経済的・政治的な実際の主導権は江蘇にある**という構造をとる。[^e026]

## 人的配置

1912年時点の主要人物と役割は次のとおりである。[^n3][^e026][^e027]

| 人物 | 1912年の年齢 | 役割 |
|---|---:|---|
| 張謇 | 58 | 創設・地方間調整（初代主席） |
| 黎元洪 | 47 | 湖北代表・軍事調整 |
| 唐紹儀 | 50 | 外交・行政（袁世凱失脚で経歴は不確実） |
| 盛宣懐 | 67 | 財政・鉄道・対外債務の実務（政治的代表にはなりにくい） |
| 馮国璋 | 53 | 華北の軍事的安定 |
| 段祺瑞 | 47 | 軍事行政 |
| 梁啓超 | 39 | 政治制度・立憲理論 |
| 顧維鈞 | 24 | 次世代の外交実務 |

張謇が主席に選ばれた最大の理由は、**独自の軍事力を持たず、他の軍閥にとって脅威にならない**ことである。[^e026]

## 権力分担

| 権力基盤 | 主導者・勢力 |
|---|---|
| 政治的調整・制度設計 | 張謇 |
| 軍事力・安全保障 | 黎元洪 |
| 金融・経済 | 江蘇・上海の実業家 |
| 外交・国家債務 | 北京の旧清朝官僚 |
| 地方行政 | 各加盟省政府 |

権力の分担は上表のとおりである。[^n1][^e027]

聯合は内部が不安定である以上、軍権が支配力の実態となり、黎元洪が主導権を握った。[^e027] こうして**張謇＝制度的創設者、黎元洪＝軍事的存立を支える実質的指導者**の二重構造が生まれた。[^e027] 黎元洪政権は個人独裁ではなく、軍事力を背景とする連合政権である。[^e027]

# 加盟勢力と兵力

聯合の中核は華北・江蘇（両江）・湖北であり、浙江・安徽も上海金融市場や長江下流との結びつきから聯合に属する。[^e032] 江西は聯合寄りの独立軍閥、湖南は1920年代前半には「聯合寄り中立」（通商・交通・金融で協力しつつ清朝国家債務の共同負担には慎重）であった。[^e030][^e032]

| 勢力（1926年夏） | 兵力（万人） |
|---|---:|
| 湖北軍 | 8〜15 |
| 両江軍 | 10〜20 |
| 華北軍 | 12〜20 |
| 葉開鑫派湖南軍 | 2〜4 |
| **聯合側合計** | **32〜59** |

兵力はいずれも本世界線の推計である。[^n4][^e032]

総兵力は中華民国側（15〜27万）を大きく上回るが、加盟軍の合計にすぎず統一指揮下にない。聯合は軍事同盟として成立した組織ではないため、湖北軍が危機に陥ったとき江蘇軍や華北軍がどこまで協力するかは未知数である。[^e028][^e032] 山西（晋系）・満洲（奉天系）・雲南（滇系）・四川・西北の諸勢力は非加盟の独立軍閥として残る（→[中国の軍閥と列強の支援配置](chinese-warlords.md)）。[^e030][^e039]

軍閥にとって聯合加盟は自らの支配権の放棄を意味しないため、独立軍閥が段階的に参加する余地があった。一方で「聯合加盟・中華民国参加・軍事協力・外交中立」は別々の選択肢であり、地方自治重視者が北伐に加わることも、共和主義者が聯合と協力することもあり得る。[^e026][^e030]

# 中華民国との比較

| 項目 | 中国諸省聯合 | 中華民国 |
|---|---|---|
| 加盟・参加の条件 | 対外権利義務の共同管理 | 共和国への政治的統合 |
| 地方軍 | 独立性を維持 | 将来的な国軍への統合 |
| 地方財政 | 原則として維持 | 中央財政への統合を志向 |
| 地方政府 | 自治を承認 | 全国的な行政制度への統合 |
| 外国との関係 | 既存契約の承継 | 条約・権益の再編 |
| 政治的正統性 | 行政・制度の継続 | 革命・国民主権 |
| 支持層 | 軍閥・地方有力者 | 統一を求める知識人・学生・青年軍人 |

[^e026]

聯合の最大の弱点は**政治的正統性**である。清朝以来の不平等条約を承継し、日英の経済支援に依存し、全国統一を実現できず、軍閥の地方支配を制度的に保障し、恒久的な憲法・国体を持たない。軍閥指導者には魅力的でも、配下の青年将校・学生・知識人には中華民国の方が魅力的であり、聯合は「地方自治の保障」か「分裂の固定化」かという論争の的になる。[^e030]

# 1912〜1930年の歩み

## 張謇期（1912〜1926）

張謇は聯合を恒久的な分裂体制ではなく、将来の中国再統合のための暫定制度と考えていたとされる。[^e026] 1910年代後半には軍閥間の紛争を背景に黎元洪の発言力が増し[^n1]、軍事協議会が次第に実質的な最高意思決定機関となっていく。[^e027]

1919年前後の学生運動（五四運動相当）は、本世界線では反日よりも、パリ講和会議で清朝以来の外国権益（特に英国・日本の権益）が維持されたことへの反発と、「聯合体制」そのものへの反対の性格が強い。[^e029][^e038] 1925年の五・三〇事件型の労働争議は、日英資本による工業化が史実以上であるため起こりやすいが、外国企業との契約履行と経済秩序の維持を存立基盤とする聯合はこれを厳しく取り締まる。[^e029]

## 黎元洪期と北伐（1926〜1928）

1926年に張謇が史実どおり死去すると、聯合は文民的な調整能力を失う。[^e027] 同年の湖南政変で、黎元洪は失脚した趙恒惕・葉開鑫側を支援し、これが中華民国の北伐を招く。[^e031] この過程で聯合は、**外交・経済共同体から加盟省の共同防衛を担う軍事的共同体へと変質**し、黎元洪の権力は急拡大した。[^e031][^e032] 北伐の経過は[北伐と湖南内戦（1926〜1930）](../events/northern-expedition.md)を参照。聯合は湖南の大部分を失ったが、湖北・江蘇を維持した。[^e032]

## 武昌公邸火災事件と暫定集団指導（1928〜1930）

1928年6月3日、黎元洪は武昌の公邸の火災で死亡し、原因は不明のまま陰謀の「証拠」が現れた（→[武昌公邸火災事件](../events/wuchang-residence-fire-1928.md)）。[^e034] 後継者になれるだけの権力基盤を持つ者は全員が疑惑の対象となり、「無垢の後継者」は存在しなかった。[^e035] 黎元洪の権力は四つに分解され、分散した。[^e035]

| 黎元洪の権力 | 1928年以降の帰属 |
|---|---|
| 湖北軍最高指揮権 | 湖北軍高級将校による暫定軍事委員会 |
| 湖北省支配権 | 湖北省政府 |
| 聯合軍事協議会の主導権 | 各加盟軍代表による軍事協議会 |
| 加盟省間の政治調整権 | 対外代表権は北京の聯合中央機関、軍事費・対外借款は財政委員会と両江の金融勢力 |

[^e035]

これは誰にも権力を独占させたくないという**消極的合意による暫定体制**である。1928年夏に湖北軍内部の指揮権争いと相互告発、秋に軍事協議会による暫定集団指導体制が成立し、1929年には軍事費負担と指揮権をめぐる加盟省間の対立、年末には世界恐慌による財政悪化が続いた。[^e035] 日英も特定の人物を擁立すれば謀殺関与の疑惑を強めるため、人物ではなく聯合の既存機関を支援し、対外債務の履行や借款契約は財政委員会を相手とした。[^e035] 怪死事件は聯合の国家化を促すどころか、中央権力の形成を阻害した。[^e035]

北伐の継続は聯合の弱点であると同時に、解体を防ぐ要因でもあった。加盟軍閥は単独で中華民国と対峙したくないからである。[^e035] 1930年の聯合には相互不信が蓄積しており、「**互いを信用していないが、互いを必要としている**」状態であった。日英からの資金援助の配分自体が政治争点となるが、離脱すれば対外信用も失う。[^e039]

# 1930年の聯合

| 項目 | 中国諸省聯合（1930年） |
|---|---|
| 政治的中心 | 北京・南京・武漢 |
| 支配領域 | 華北・長江中下流域 |
| 統治理念 | 地方自治・権利義務の承継 |
| 政治体制 | 暫定的な集団指導体制 |
| 最高指導者 | 黎元洪の死後不在 |
| 財政基盤 | 比較的強固だが分散 |
| 軍事力 | 総兵力で優勢だが指揮権分散 |
| 外国支援 | 日本・英国 |
| 共産党への姿勢 | 地下活動・労働運動を取り締まる |
| 最大の問題 | 加盟勢力間の相互不信 |

[^e039]

世界恐慌は聯合領内の輸出減少・企業収益悪化・失業増加・労働運動激化をもたらし、中国共産党が都市労働者への支持を広げる余地を生む。[^e029][^e039] 1930年の中国は、聯合・中華民国・非加盟の独立軍閥・列強及び外国人自治機関による施政地域という四種の統治主体に分かれ、軍閥間の「水平的分裂」と、主権と施政権が異なる主体に帰属する「垂直的分裂」が重なっている。[^e037] 聯合にとって租界は主権を制限する一方、外国資本の流入・輸出入・対外信用を支える財政的支柱でもあり、恐慌で財政が悪化した加盟省は租界当局へ周辺の治安維持・公共事業を委託する誘因を強めた（→[戦間期の中国](interwar-china.md)）。[^e037]

まとめれば、1930年の中国は「**経済的には外国資本を介して結合し、政治的には分裂し、軍事的には膠着している**」。聯合にも中華民国にも現状打破の能力がなく、現状を恒久的に受け入れる意思もない。[^e039]

# 1930年代の展開

* **満洲事変の不在**：1931年に史実の満州事変に相当する日本の軍事行動は起きない。満洲は聯合に加盟しない奉天系が独自政権を維持する。[^e039][^e040]
* **恐慌下の市場**：1930年代初頭、聯合は鉄道・発電・工場設備・消費財の市場として日英製品と融資の受け皿となる。北伐による財政疲弊と恐慌で購買力は乏しく、借款・直接投資を伴う「金融支援と工業製品輸出の一体化」が進む。日英の聯合支援には、余剰生産力の吸収という経済的理由も加わった。[^n1][^e046]
* **通貨**：1931年以降、聯合や外国施政地域では円・ポンドの貿易金融が重要化し、中国の銀本位制との為替関係も問題となった。[^n1][^e042]
* **ナチス・ドイツとの関係**：1933年以降、日本は聯合と既存契約の保護、ドイツは中華民国への経済進出という形で、日独は中国で異なる勢力を支援し経済的に競争する。[^e054][^e055]
* **資源供給元**：1937年時点で、聯合は日本の鉄鉱石・石炭（原料炭）・銅の輸入元となる。[^e072][^e079] 中国における鉱山投資・長期供給契約はかろうじて成立したが[^n5]、聯合の政治的不安定と加盟軍閥間の相互不信による政治リスクは残る。[^e081] 詳細は[資源戦略](../economy/resource-strategy.md)。

# 編集注：却下・修正された案

* **熱河・奉天への宮廷移転と満洲での清朝存続**：清朝が満洲へ遷都し北方に清朝残存政権が残る経路は、溥儀のロシア亡命確定（E24・E25）により採られなかった。[^e020][^e024][^e025]
* **北方政権の政体3案**：清朝残存政権・立憲君主政・北方共和政の3案（E13）は、国号を留保した「聯合」案に収斂した。[^e013][^e025]
* **国号A案・B案**：「二つの中華民国」案、「中華聯邦共和国」案は採られず、C案（国号留保の中国諸省聯合）が前提となった。[^e025]
* **黎元洪死後の国家化**：黎元洪の後継者危機を契機に聯合が制度化された国家へ改組されるという見通し（E27）は、怪死事件がかえって中央権力の形成を阻害したとする整理（E35）に置き換えられた。[^e027][^e035]
* **単独の後継者**：蔣作賓・李書城・何成濬・孫武・呉佩孚・段祺瑞らを後継候補とする案（E27）は、「無垢の後継者になれる人間はいない」との指摘により、単独の後継者は現れない方向へ修正された。[^e027][^e035]
