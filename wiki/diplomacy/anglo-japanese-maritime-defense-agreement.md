# 概要

日英海上通商防衛協定は、1930年4月21日に大日本帝国と大英帝国が署名し、即日発効した防衛協定である。翌4月22日に署名された[ロンドン海軍軍縮条約](/diplomacy/london-naval-conference-1930.md)は米英日の海軍総排水量を100：85：65で凍結し、日英が相手国の中立化による戦力不足を独自の建艦で補う道を閉ざした。協定はその安全保障上の不足を補うために、条約署名の直前に公然と結ばれた。[^e010][^e011] 史実では1922年のワシントン会議によって日英同盟が解消されたのに対し、本世界線では1930年のロンドン会議によって日英間に初めて正式な防衛協定が成立する。[^e010]

協定本体は前文と全6条の簡潔な**枠組み協定**であり、保護の対象を海域ではなく商船の国籍で定める（地理的適用範囲なし・船籍基準）。相互援助の原則は定めたが、その条件・範囲・方法は後日の追加議定書に委ねられた。[^e011] 1932年秋〜冬に締結された第一追加議定書は、一方の締約国の商船だけが攻撃された場合や、国際法上適法な海上封鎖を受けた場合にも共同防衛義務を発生させ、締約国自身が始めた侵略戦争に起因する場合だけを免責とした。これにより協定は「**一般的な相互防衛同盟より対象は狭いが、海上通商についての防衛義務は極めて強い**」限定的な海上通商防衛同盟となった。[^e052][^e053]

1935〜36年の[第二次エチオピア戦争](/events/second-italo-ethiopian-war.md)では、英国が対伊軍事制裁に踏み込めば日本も自動的に巻き込まれる構造が明らかになり、「共同防衛義務は存在するが、共同の外交政策決定機構は存在しない」という制度的欠陥が露呈した。[^e058] また米国は協定を日英の軍事同盟とみなし、[第二次ロンドン海軍軍縮会議](/diplomacy/second-london-conference.md)では日英合算との兵力均等を要求して、軍縮体制は1936年末に終わる。[^e060][^e061]

# 成立の背景

## 中立化コストと軍縮条約

ロンドン会議で米国は日英を「事実上一体の艦隊」とみなす合算兵力論を掲げた。日英は互いに参戦義務を負っていないが、相手の友好的行動を前提に国防を最適化しており、相手が中立化した場合のコストは双方にとって高すぎる。米国が日英の合算兵力を基準に軍縮を迫ることで、「軍縮条約が、従来は存在しなかった相互の安全保障上の保証を必要とさせる」ことになった。[^e003]

| 争点 | 日本の要求 | 英国の要求 |
|---|---|---|
| 海上交通 | インド洋以西の通商保護 | 東アジア方面の通商保護 |
| 海軍基地 | 英国の海外基地の利用保証 | 日本の港湾・修理施設の利用保証 |
| 戦時補給 | 燃料・物資供給の継続 | 日本の工業生産力・海運力へのアクセス |
| 中立問題 | 英国の中立による通商途絶の回避 | 日本の中立による極東防衛の空白の回避 |
| 海軍整備 | 互いの兵力配分の予見可能性 | 同左 |

（検討案）[^e009]

協議の中心は中立問題である。協定は一般的な相互防衛同盟ではなく、対象を海上通商の防衛に限定し、「**戦争の原因ではなく、海上通商に対する侵害を発動条件とする**」構想をとった。日本にはソ連・中国情勢、英国には欧州・地中海の危機があり、協定は対米戦争だけを想定したものではなく、特定国を仮想敵国として明記しない。ただし米国はこれをレッド・オレンジ連合の制度化と受け取る（検討案）。[^e009]

## 署名直前調印と第16条

日英間の海上通商防衛についての協議は、会議中の非公式協議がそのまま協定交渉に移行する形で始まった（確定）。[^e009] 日英はロンドン条約署名の直前に協定に調印し、条約第16条（国際関係の変更に伴う再協議）は本協定と無関係という立場をとった（確定）。[^e010]

秘密締結ではなく、交渉の最終段階で協定締結が公然と通告された。日英の論理は次のとおりである。[^e010]

1. 米国は日英の潜在的な共同交戦能力を考慮して100：85：65という比率を要求した。
2. 日英はその要求を受け入れることで、独立した軍備増強の自由を放棄する。
3. その結果生じる安全保障上の不足を補うため、日英間の防衛協定が必要になった。
4. 協定締結後にロンドン条約へ署名する以上、協定の存在は軍縮条約締結時の前提条件である。

日英は合算兵力論を否定する段階から、「合算兵力を前提とした軍縮を受け入れる以上、それに対応する安全保障体制を構築する権利がある」という立場へ移った。日英の離間が不可能であると既に認識していた米国は、協定の存在を承知のうえで条約に署名した。こうして協定は、ロンドン条約を成立させるための**事実上の前提条件**となった。[^e010] 第16条の最終文言も「本条約署名の日以後」に成立した軍事同盟等に限定され、協定は規制対象外となる一方、将来全面的な軍事同盟へ発展する場合には米国が再協議を要求できる余地が残された。[^e010]

| 日付 | 出来事 |
|---|---|
| 1930年4月中旬 | 海軍総排水量比率100：85：65で合意 |
| 1930年4月21日 | 日英海上通商防衛協定署名・即日発効 |
| 1930年4月22日 | ロンドン海軍軍縮条約署名 |
| 1930年夏以降 | 日英間の追加議定書交渉開始 |

[^e011]

# 協定本文（1930年）

地理的適用範囲は定めず船籍だけで保護対象を決め、相互援助義務については追加議定書で定めると規定する（確定）。会議の最終段階で急遽締結したため、具体的な交渉を行う時間的猶予はなかった。[^e011]

**前文**

大日本帝国及び大英帝国は、両国の経済的繁栄及び安全が海上交通の自由と安全に依存することを認め、海上軍備の制限の下において両国の海上通商を保護するため、以下のとおり協定する。

**第1条　共同利益**

両締約国は、各締約国の海上通商の自由及び安全の維持を、両国共通の利益と認める。

**第2条　保護の対象**

本協定による保護の対象は、両締約国の法令に基づきその国籍を有する商船及びこれらの船舶による海上交通とする。

本協定の適用は、当該船舶の航行する海域によって制限されない。

**第3条　相互援助**

一方の締約国の海上通商が第三国の行為によって重大な脅威にさらされた場合、両締約国は速やかに協議し、その保護のため相互に援助するものとする。

相互援助の条件、範囲及び方法については、別途締結する追加議定書によって定める。

**第4条　海軍当局間の協議**

両締約国は、本協定の目的を達成するため、外交当局及び海軍当局間の定期的な協議を行うものとする。

**第5条　追加議定書**

両締約国は、本協定の実施に必要な事項について、速やかに交渉を開始する。

追加議定書は両締約国の合意によって随時締結することができる。

**第6条　発効及び有効期間**

本協定は署名の日より効力を生ずる。

本協定は一方の締約国が廃棄の意思を通告した日より一年を経過するまで、その効力を有する。

[^e011]

## 1930年4月時点の性格

| 項目 | 1930年4月時点 |
|---|---|
| 海上通商の共同防衛 | 合意済み |
| 地理的適用範囲 | 制限なし |
| 保護対象 | 日英両国籍の商船 |
| 相互援助義務 | 原則のみ確立 |
| 共同参戦義務 | 未確定 |
| 基地・港湾の相互利用 | 今後交渉 |
| 戦時の指揮権 | 今後交渉 |
| 軍事的援助の発動条件 | 今後交渉 |
| 有効期間 | 無期限・1年前の廃棄通告 |

[^e011]

地理的範囲を定めないことには合理性がある。日英双方の商船は世界規模で活動しているので、太平洋やインド洋といった海域区分は両国の経済的実態に合わない。また英国の欧州方面での戦争と日本の東アジア方面での戦争を形式的に区別する必要もなくなる。ただし、船籍を基準とすることと、商船への攻撃が直ちに共同参戦を意味することは別の問題として扱われた。[^e011]

「**日英間の軍事協力は制度化されたが、その具体的な形態はまだ決まっていない**」。追加議定書の内容は、世界恐慌の進展、中国情勢、欧州の政治情勢、米国の建艦政策に応じて後に決まることとされた。[^e011]

# 第一追加議定書（1932年）

## 交渉経緯

| 時期 | 経緯 |
|---|---|
| 1930年4月 | 原協定締結 |
| 1930年夏〜1931年春 | 相互援助義務・施設利用について交渉 |
| 1931年秋 | 欧州通貨危機により経済・金融協力を優先 |
| 1932年夏 | オタワ会議において自治領との調整 |
| 1932年秋〜冬 | 第一追加議定書締結 |
| 1933年 | 日英海軍協議会が本格的に活動開始 |
| 1935年 | 第二次ロンドン会議で米国との争点となる |

[^e040][^e052]

1931年の[欧州通貨危機](/events/currency-crisis-1931.md)と1932年の[オタワ会議](/diplomacy/ottawa-conference-1932.md)を経て、日英の経済的相互依存は協定締結時よりさらに強まった。一方でロンドン条約の総量規制は既に発効しており、相手国の中立化による戦力不足を独自の建艦で補うことは難しい。そのため追加議定書は平時の海軍協力にとどまらず、有事における相互援助を具体的な義務として定めるものとなった。ただし領土防衛や一般的な相互参戦義務は含めず、船籍を基準とした地理的制限のない海上通商防衛協定という原則は維持された。[^e052] 日英関係は、1930年の海上通商防衛、1931年の金融協力、1932年のオタワでの資源貿易・開発投資と段階的に制度化されたが、軍事・通貨・関税のいずれも単一の体制には統合されない「緩やかな結合」にとどまった。[^e051] 1932年末に締結されたため、議定書はナチス政権成立以前に成立しており、ドイツの再軍備に対抗するためではなく、ロンドン軍縮条約と日英の経済的相互依存から生まれたものである。[^e052][^e054]

## 発動条件の決定

当初の案は「不法な武力行使」による重大な侵害を発動条件とし、事態を四類型（海賊・武装集団による侵害＝相互協力／第三国による平時の不法な拿捕・攻撃＝外交的・軍事的援助／一方の締約国の交戦＝協議と国際法上許容される援助／両国の海上通商に対する重大かつ継続的な攻撃＝共同防衛措置）に分けるものであった。[^e052]

しかしこの方式では、第三国が片方の船籍だけを選別して攻撃したり、正式に宣戦布告して国際法に従った封鎖を実施したりするだけで、日英の共同防衛を回避できてしまう。そこで次の原則が確定した。[^e053]

* 片方の締約国の商船だけが攻撃された場合でも共同防衛義務が発生する。
* 艦隊護衛（護衛艦艇への攻撃）と適法な海上封鎖も共同防衛義務の対象とする。
* 一方の締約国が始めた侵略戦争に起因するものは「当面」免責とする。
* 第三国の行為の国際法上の適法性と、日英の共同防衛義務の発生を切り離す。発動条件は「海上通商に対する重大な軍事的妨害」とする。

| 事態 | 共同防衛義務 |
|---|---|
| 日本商船のみへの組織的攻撃 | 発生 |
| 英国商船のみへの組織的攻撃 | 発生 |
| 両国商船への攻撃 | 発生 |
| 商船を護衛する海軍艦艇への攻撃 | 発生 |
| 一方の締約国に対する適法な海上封鎖 | 発生 |
| 一方の締約国に対する違法な海上封鎖 | 発生 |
| 通常の関税・経済制裁 | 原則として発生しない |
| 海上通商と無関係な陸上戦争 | 発生しない |
| 締約国自身が開始した侵略戦争に起因する封鎖・攻撃 | 他方は免責 |

[^e053]

海上封鎖については、個々の商船が実際に攻撃されるまで待つ必要はなく、封鎖の実施段階で義務が発生する。適法な封鎖に対する軍事的な共同防衛は単なる中立国の通商保護では済まず、援助国は中立国としての地位を失う可能性がある。つまり第一追加議定書は実質的に、「**海上通商の防衛に必要な場合、相手国のために交戦国となることも受け入れる協定**」であり、日英双方の中立化コストを解消するという1930年協定の目的に合致する。[^e053]

## 議定書本文

修正条文では、当初案の第2〜4条を改めて第2〜5条とし、侵略戦争に関する免責条項を第6条として新設した。基地利用・物資供給・海軍協議会などの条項は当初案の内容を維持して繰り下げられた。[^e053]（第7条以下の条番号は、繰り下げの指示に従って本 wiki で整理したものである。）

**第1条　保護の対象**

本議定書による保護の対象は、原協定第二条に定める両締約国の国籍を有する商船及びその海上交通とする。

船舶の航行海域、出発港、目的港及び積荷の所有者によって、本議定書の適用は制限されない。[^e052]

**第2条　共同防衛義務**

一方又は双方の締約国の海上通商が、第三国その他の勢力による武力行使、海上封鎖その他の軍事的措置によって重大な侵害を受けた場合、両締約国は共同してその防衛に当たるものとする。

前項の義務は、当該侵害が一方の締約国の国籍を有する船舶のみに対して行われた場合にも生ずる。

当該措置の国際法上の適法性は、それ自体として本条に定める義務を免除する理由とはならない。

**第3条　海軍による防衛及び護衛**

両締約国は、前条に定める義務を履行するため、必要な海軍兵力を提供し、両国の商船及び海上交通の防衛に協力するものとする。

本協定に基づき商船又は船団の護衛その他の通商防衛に従事する軍艦に対する攻撃は、保護対象たる海上通商に対する攻撃と同様に取り扱う。

共同防衛措置の実施に関する事項は、両締約国政府及び海軍当局間の協議によって定める。

**第4条　海上封鎖**

一方の締約国の港湾若しくは沿岸に対する海上封鎖、又は当該締約国の海上交通を重大に妨害する軍事的措置については、個々の商船に対する武力行使の有無を問わず、第二条及び第三条を適用する。

両締約国は、海上交通の回復に必要な外交的、経済的及び軍事的措置について速やかに協議し、これを共同して実施するものとする。

**第5条　交戦及び中立**

一方の締約国と第三国との間に戦争状態が生じたことのみをもって、他方の締約国に参戦義務が生じるものではない。

ただし、第二条乃至第四条に定める事態が発生した場合、他方の締約国は、中立の維持のみを理由として共同防衛義務の履行を拒むことはできない。

**第6条　侵略戦争に関する免責**

一方の締約国が自ら開始した侵略戦争に直接起因して海上通商に対する攻撃、封鎖その他の軍事的措置を受けた場合、他方の締約国は、本議定書に定める共同防衛義務を負わない。

侵略戦争への該当性について両締約国間に意見の相違がある場合、両国政府は速やかに協議するものとする。

本条は、他方の締約国が自国の判断により援助を行うことを妨げない。

[^e053]

**第7条　港湾及び海軍施設**

両締約国は、海上通商の防衛に必要な範囲において、相互に港湾、補給、修理及び通信施設の利用を認める。

施設の利用条件及び費用負担は別途定める。

本条は恒久的な基地の設置権、駐兵権又は施設の排他的使用権を付与するものではない。

**第8条　物資及び輸送能力の確保**

両締約国は、海上通商の防衛に必要な燃料、船舶、修理資材その他の物資について、相互の供給能力を維持するため協力する。

非常時における供給及び輸送については、国内の必要を考慮した上で、既存の契約及び両締約国間の取り決めを尊重する。

**第9条　日英海軍協議会**

両締約国は、原協定及び本議定書の実施について協議するため、常設の日英海軍協議会を設置する。

協議会は以下の事項を担当する。

- 海上交通及び国際情勢に関する情報交換
- 通商防衛に関する共同研究
- 海軍施設及び補給能力に関する協議
- 海軍兵力の整備方針に関する意見交換
- 有事における協力及び費用負担の調整

協議会は両国海軍に対する直接の指揮権を有しない。

**第10条　軍事指揮権**

各締約国の海軍は、引き続き当該締約国の政府及び軍事当局の指揮下に置かれる。

共同防衛措置に伴う指揮関係については、当該事態に応じて両締約国が合意する。

恒久的な統合海軍司令部は設置しない。

**第11条　軍備制限条約との関係**

本議定書は、両締約国が締結している海軍軍備制限条約上の義務を変更するものではない。

両締約国は軍備制限条約上の保有枠を相互に譲渡せず、それぞれ独立してその義務を履行する。

**第12条　英国自治領及び属領**

英国の自治領政府が管轄する船舶及び施設については、当該自治領政府の同意を得て本議定書を適用する。

英国政府が直接管轄する植民地及び属領については、英国政府の権限の範囲内で適用する。

**第13条　適用の限界**

本議定書は領土の保全、陸上における軍事行動、植民地の統治及び第三国の内政への介入について、一般的な相互援助義務を生じさせるものではない。

**第14条　発効及び有効期間**

本議定書は両締約国による批准を経て効力を生じ、原協定とともに効力を有する。

[^e052]

英国も日本も海上通商に強く依存しているため、両国のいずれかが大国との防衛戦争に入れば、共同交戦に至る可能性は非常に高い。第一追加議定書はその現実を条約上明文化したものと位置づけられる。[^e053]

## 侵略戦争の認定問題

議定書が意図的に残した曖昧さは、何を侵略戦争と認定するかである（検討案）。[^e053]

| 想定事態 | 協定上の扱い |
|---|---|
| 第三国が英国本土を攻撃し、英国を封鎖 | 日本の共同防衛義務が発生 |
| 第三国が日本との戦争を開始し、日本を封鎖 | 英国の共同防衛義務が発生 |
| 英国が植民地拡張戦争を開始し、反撃として封鎖される | 日本は免責 |
| 日本が中国への侵略戦争を開始し、第三国から封鎖される | 英国は免責 |
| 外国政府による資産接収を契機に軍事衝突が発生 | 侵略戦争に該当するか協議 |
| 第三国による同盟国への攻撃を理由として参戦 | 戦争の性格について協議 |

特に中国のコンセッションをめぐる紛争では、権益保護と侵略の境界が問題になる。侵略戦争の厳密な定義や第三者による認定制度を設けることは1932年時点では難しく、最終的には各政府の判断に委ねられるが、その判断が協定の信頼性にも影響する。[^e053]

## 自治領の参加問題

カナダやオーストラリアなどの自治領が、英国政府の判断によって対日防衛義務を負うとは限らない。そこで第12条は自治領について当該政府の同意を要件とし、商船の保護対象となることと軍事的な相互援助義務を負うことを区別できるようにした。[^e052]

| 自治領 | 追加議定書に対する態度（検討案） |
|---|---|
| オーストラリア | 資源輸出と海上交通の保護から参加に積極的 |
| ニュージーランド | 英国との関係を重視し、参加に比較的積極的 |
| カナダ | 対米関係を考慮して慎重 |
| 南アフリカ | 経済協力には積極的だが軍事義務には慎重 |
| アイルランド自由国 | 軍事的な義務の引受けには消極的 |

特にカナダが米国との戦争に巻き込まれる危険を考えれば、全自治領が一律に参加する形は難しい（検討案）。[^e052]

## 米国の反発とロンドン条約第16条

米国は第一追加議定書をロンドン条約第16条の「既存の軍事協定に重大な変更が加えられた場合」に当たるとして再協議を要求する立場をとる。日英は「1930年4月21日に発効した原協定第3条で既に予定されていた相互援助義務の実施規定・具体化にすぎない」と反論し、米国は「原協定に存在しなかった具体的な軍事援助義務と常設協議機構が成立した」と主張する。法的には米国側にも十分な根拠がある。ただし再協議の要求は直ちに保有枠を変更するものではなく、恐慌下で建艦競争を再開する余裕に乏しい米国は、当面は抗議と再協議権の留保にとどめ、問題を1935年の次回軍縮会議に持ち越した（検討案）。[^e052][^e053]

議定書によって米国は日英関係を明確に軍事同盟として扱うようになり、レッド・オレンジ計画の「英国と日本の一方に対する海上封鎖によって戦争を有利に進める」という前提が成立しにくくなった。[^e053]

# 1933〜1937年の運用

## 軍事義務の共有と外交の独立

1933年のナチス政権成立後、英国が対独防衛戦争に入り英国商船が攻撃されれば日本にも義務が生じ、英国の侵略戦争なら日本は免責される。日本は英国の欧州外交に無関心でいられないが、協定には外交の共同決定権がない。「**軍事的義務を共有しているが、外交的意思決定は独立している**」という問題が生まれた（検討案）。[^e054] 1932年の議定書により、英国の対独戦争は日本の軍事義務になりうるため、日本は[ドイツ再軍備](/events/nazi-germany-1933.md)に反対する英国の立場を支持した。英国にとって対日協定は極東の負担を軽くし、欧州への戦力集中を可能にする制度であった（検討案）。[^e012][^e056]

## 日英海軍協議会

第一追加議定書で設置された常設の日英海軍協議会は1933年から本格的に活動した。[^e052] その「通商防衛に関する共同研究」の枠組みで、日英は1933年に航空研究成果の交換を始め、1934年に無線操縦式標的艦による試験、1935年に退役主力艦への実弾試験を行った（推移は検討案、1935年の試験結果はダイス判定で確定）。[^e062] 1935年の[日英共同航空攻撃試験](/military/naval-aviation-1935.md)の大成功を受けて、日英は艦載機の要求規格・発着艦設備・航空燃料・通信機器・整備機材の共通化と相互運用（ダイス判定：1d100 > 40、出目65・成功）、通商護衛用小型空母の開発開始（1d100 > 25、出目76・成功）、航空発動機の技術協力（1d100 > 35、出目63・成功）に合意した。いずれも同一機種への統一ではなく、相手国の空母・整備施設で運用できるようにすることが要点であり、両国の航空機産業の独立性は維持される。[^e065][^e067]

1935年時点の日英関係の制度化は次のように整理される。[^e060]

| 争点 | 1930年 | 1935年 |
|---|---|---|
| 日英共同交戦 | 潜在的な可能性 | 条約上の共同防衛義務 |
| 海軍基地 | 従来の協力関係 | 相互利用の制度化 |
| 海軍当局 | 非公式な協議 | 常設海軍協議会 |
| 通貨・金融 | 経済的相互依存 | 円・ポンド間の金融協力 |
| 資源供給 | 商業契約 | 長期供給契約・戦略備蓄 |

## エチオピア危機での試練

[第二次エチオピア戦争](/events/second-italo-ethiopian-war.md)は協定成立以来はじめて、その制度的欠陥を顕在化させた。[^e058]

| 事態 | 日英協定の扱い |
|---|---|
| イタリアによるエチオピア侵攻 | 発動しない（エチオピアは締約国でない） |
| 日英による経済制裁 | 発動しない |
| イタリアによる英国商船への重大な攻撃 | 発動対象 |
| イタリアによる日本商船への重大な攻撃 | 発動対象 |
| 英国による対伊軍事行動 | 戦争の性格によって判断 |

[^e057]

第一追加議定書の免責は締約国自身が開始した侵略戦争に限られ、国際連盟の決議に基づく軍事制裁はそれに当たらない。英国が海上封鎖や軍事制裁に踏み切り、イタリアが英国商船を報復攻撃すれば、日本が地中海への艦隊派遣を当初拒否しても共同防衛義務を免れない。日本の立場では海上封鎖や軍事制裁は避けたく、英国が艦隊を出しただけで日本はほぼ確実に戦力を出さざるを得なくなる（確定）。[^e058]

| 英国の行動 | イタリアの対応 | 日本への影響 |
|---|---|---|
| 経済制裁 | 報復関税 | 共同防衛義務なし |
| 石油禁輸 | 経済的報復 | 共同防衛義務なし |
| 海軍による示威行動 | 外交的抗議 | 軍事的緊張の上昇 |
| 海上封鎖 | 英国商船への報復攻撃 | 共同防衛義務が発生 |
| 軍事制裁 | 地中海における海上戦争 | 共同交戦に至る可能性が高い |

[^e058]

日本は国際連盟内で軍事制裁に対する抑制派となり、英国に海上封鎖を断念させた。さらに、米国がイタリアへの石油輸出を通常の商取引として続けたとき、英国がそれを海上で阻止すれば対米戦争の危険を招くため、日本は英国に封鎖を思いとどまらせた。「**日英の海軍力は強大だが、それを経済制裁の強制手段として利用する政治的自由は小さい**」ことは、米国にとって重要な外交的発見となった。[^e059]

この経験から、日本は将来の第二追加議定書として、国際連盟の軍事制裁への参加に関する事前協議、第三国への海上封鎖実施に関する事前協議、共同防衛義務を生じさせるおそれのある軍事行動の事前通告を求める可能性がある。共同防衛義務そのものは弱めず、日本が求めるのは「参戦義務から逃れることではなく、参戦義務が生じる決定に事前に関与すること」である（検討案）。協定は「1930年に軍事協力、1932年に共同防衛義務、1935年のエチオピア危機を契機に外交政策の協調が必要に」という段階で発展する。[^e058]

## 第二次ロンドン会議と軍縮体制の終わり

1930年に「潜在的な日英連合」を相手に交渉した米国は、1935年には「明文化された日英防衛同盟」を相手に交渉することになった。日英が正式な軍事同盟は存在しないと反論できた1930年と異なり、その反論はもはや成立しない。[^e060] 米国は第16条に基づく再協議を要求し、[第二次ロンドン海軍軍縮会議](/diplomacy/second-london-conference.md)では日英合算との兵力均等に加えて、日英の海軍基地相互利用の制限、日英共同防衛義務の縮小・再検討、常設海軍協議会の権限制限まで要求案に含めた。会議は1936年春に全面決裂し、1936年12月31日にロンドン条約は失効した。[^e061][^e062]

条約失効後、日英は軍拡に際しても相互の任務分担を考慮する。米国は二国分の海軍を個別に相手にするのではなく、「相互補完的に発達する二つの海軍」を相手にすることになり、日英は海軍整備方針をさらに協調させる必要に迫られた。[^e061] 1937年以降の米国の大規模な海軍拡張は、米国が協定によって日英の海軍を一体の脅威とみなしていることに対応している。[^e102]

## 経済構造の防衛

1937年の日本は、外航運賃収入の約30%を第三国間輸送（豪州→英国の資源輸送、インド→東南アジア、中国↔欧州など）から得ており、これが協定が世界的な適用範囲を持つ経済的背景となっている。[^e085] また自動車・商船・航空機の燃料を石油に依存する用途別分業が進み、石油自給率が7.5%に低下したことで、協定の経済的重要性はさらに高まった。[^e089] 1937年の海軍現役20万人という史実より大きな海軍人員規模も、協定と航空主兵論・海軍拡張を前提としている（暫定）。[^e095] 詳細は[エネルギー需給と電化](/economy/energy-1937.md)、[運輸・商業・通信・金融サービス](/economy/services-1937.md)を参照。

# 却下・修正された案

* **協定の交渉スケジュール案**：1930年夏に正式協議を始め、秋に基本原則を合意し、1930年末〜31年に締結・批准する案は、ロンドン条約署名直前に調印する方式に置き換えられた。[^e009][^e010]
* **当初の基本構想（協議義務中心）**：一方が交戦国となれば他方は通商援助について協議義務を負うという構想は、原協定では相互援助の原則と追加議定書への委任に整理された。[^e009][^e011]
* **「不法な武力行使」を発動条件とする案**：第一追加議定書の当初案（全12条）の第2条（不法な武力行使に対する相互援助義務）・第3条（両国の海上通商への重大かつ継続的な攻撃に対する共同防衛）・第4条（第三国との戦争）は、第三国が片方の船籍だけを選別攻撃したり適法な封鎖を行えば共同防衛を回避できるため退けられ、適法性を問わない共同防衛義務・護衛・封鎖・中立・侵略戦争免責の5か条に改められた。[^e052][^e053]
* **両国商船が攻撃された場合のみ軍事援助義務とする案**：中立化コストの解消という協定の目的に反するとして採用されなかった。[^e052][^e053]

# 未決の論点

* 第二追加議定書（事前協議・事前通告）を実際に締結するか、その時期。[^e058]
* 侵略戦争の認定基準と認定主体（意図的な曖昧さとして残されている）。[^e053]
* 各自治領が第一追加議定書にどこまで参加したか（同意の有無）。[^e052]
* 共同防衛措置の指揮関係、港湾・施設の利用条件と費用負担の具体的内容。[^e052]
