# 概要

本世界線の幕末は、1860年3月の桜田門外の変が失敗し、井伊直弼が生き延びたまま押込によって失脚するところから史実と分かれる。同時期、太平洋の向こうではアメリカ南北戦争が早期に終わるか回避され、米国の対日関与が維持される。[^u001][^u002]

暗殺による権威失墜を免れた幕府は、襲撃の責任を問うて[水戸藩を処分](/events/mito-domain-disposal-1860.md)し、旧水戸領35万石を皇室へ献上する見返りに「全国海防の勅命」を得る[1861年公武協定](/diplomacy/kobu-agreement-1861.md)を結んで[全国常備軍](/military/standing-army-1861.md)を創設する。しかしこの協定は将軍の軍権を「朝廷からの委任」に変えた。若い将軍家茂の強硬路線が勅許なき[第二次長州征討](/events/second-choshu-expedition.md)の敗北で破綻すると、1866年の家茂の死を機に朝廷は軍事委任を更新せず、諸侯の所領を安堵して[幕府を無血で解体](/events/bloodless-dissolution-1866.md)する。[^u009][^u010][^u014][^u015]

この時代を貫く主題は、「幕府の存続」と「中央集権化」の両立不可能性である。幕府が中央集権化のために朝廷の権威を借りるほど、その権威が最終的に幕府自身を不要にしていく。[^u003][^u010]

# 前史：1858年の日本と世界

1853年のペリー来航、1858年の日米修好通商条約（安政五カ国条約）、将軍継嗣問題と戊午の密勅、安政の大獄までは史実通りである。家茂は1858年に第14代将軍となり、1860年時点で数え15歳だった。[^u004][^u013] 清国は1840〜42年と1856〜60年のアヘン戦争に敗れ、1860年には英仏軍が北京を占領する。この「清国がボコボコにされる」光景が、幕府に時間の猶予がないことを意識させる。[^u008]

史実では1861年の南北戦争勃発で米国の対日関与が縮小し、英国が日本貿易で圧倒的地位を占めた。本世界線では戦争が早期終結または回避されるため、米国からの艦船購入・造船技術導入・軍事顧問招聘といった選択肢が幕府に残る一方、戦後余剰銃の流入など史実で戊辰戦争を支えた条件は失われる（詳細は[南北戦争の早期終結と幕末日本](/events/american-civil-war-avoided.md)）。[^u001] 米国が東アジアへ史実より多くの海軍力を向けられることは、幕府にとって技術導入の好機であると同時に、外国人殺傷事件に対して列強がより強く反応する危険でもある。[^u008]

# 1860年：桜田門外の変の失敗

1860年3月24日（旧暦3月3日）、水戸浪士らの行列襲撃は護衛に撃退され、直弼は負傷しながら生還する（日付・負傷は検討案）。直弼はさらなる弾圧を命じようとするが、彦根藩重臣は藩の存続を危ぶんで彼を「病気療養」の名目で押込め、幕府には病気による大老辞任を届け出る。老中はこれを黙認する。[^u002] 詳細は[桜田門外の変の失敗と井伊直弼の押込](/events/sakuradamon-incident-failed.md)、人物は[井伊直弼](/people/ii-naosuke.md)を参照。

幕府は「井伊大老の政策には行き過ぎがあったので幕府自身が政治を改める。しかし武力による幕政への干渉は認めない」と説明でき、暗殺された史実と比べて権威の打撃は小さい（検討案）。[^u002] 安藤信正・久世広周らの老中が政権を引き継ぎ、公武合体による朝廷関係修復を進める。[^u002]

# 1860年：水戸藩処分

襲撃の主体が水戸浪士である以上、水戸徳川家が従来の地位を保つことはありえない。反井伊派の政権でも罰が軽ければ幕府の権威が弱まり、大老襲撃という前例のない事件を放置できないからである。藩主は切腹までは至らないが、改易か、少なくとも蟄居となり、転封は避けられない。[^u004][^u005]

処分理由は「戊午の密勅を受けた罪」ではなく「家臣統制に失敗し幕府要人への武力襲撃を防げなかった統治責任」に限定される（検討案。孝明天皇の権威否定に見えるのを避けるため）。[^u004][^u005] 処分案は、斉昭の永蟄居継続、慶篤の隠居・蟄居、35万石の大幅減封と他国への転封、重臣人事への幕府介入、襲撃関係者の厳罰からなる。[^u005] 転封先として甲斐国の陣屋領8万石が推された（検討案、ユーザーは採否を明示していない）。[^u006] 詳細は[水戸藩処分（1860年）](/events/mito-domain-disposal-1860.md)、[水戸徳川家（慶篤・斉昭）](/people/mito-tokugawa.md)。

この処分は「御三家でさえ幕府に背けば領国を失う」「大名家の存続と、その家が特定の領国を世襲統治する権利は別問題」という論理を生み、本世界線の中央集権化は水戸藩の政治的解体から始まる。[^u005][^u006] 一方、厳罰化によって斉昭の子である一橋慶喜の政治的信用は損なわれ、改革の中心は家茂を軸とする幕政へ移る。[^u004][^u005]

残る問題は旧水戸領35万石の処分だった。天領化は治安上の負担が大きく、紀伊・尾張から藩主を迎えれば水戸藩が独立勢力として復活する危険がある。そこで採られたのが「無力な皇子・親王を名目上の領主とし、本人は江戸に置き、幕府の名代が統治する」という案である。[^u007] 中間段階として、旧水戸領を朝廷の御料とし統治を幕府に委任する「禁裏御料預地」案も示された。[^u007] → [旧水戸領と禁裏御料預地](/regions/former-mito-domain.md)

# 1861年：公武協定と全国常備軍

## 水戸領献上と海防勅命の取引

「黒船は来ており、清国がボコボコにされるのも見ている」以上、幕府には時間がない。最初の期限は1863年頃であり、それまでに外交と軍事の指揮系統を統一し、外国から見て日本政府が国内の軍事行動を統制できる状態を作らなければ、諸藩が独断で外国と戦争を始めかねない。[^u008]

幕府の権威だけで諸藩に常備軍の負担を求めるのは難しい。そこで、旧水戸領を皇族の領地とする代わりに天皇に号令を出してもらう取引が成立する。[^u009] 幕府は旧水戸領35万石を皇室へ献上し、朝廷は「全国海防の勅命」を発して将軍に軍事統率を委任し、諸藩に協力を命じる。勅命の文言は「攘夷のための開戦」ではなく「皇国防衛のための武備充実」とされ、軍役は「将軍への封建的奉仕」から「諸侯が皇国防衛のために軍費と兵員を負担し、その実務を将軍が統括する国家的義務」へ再定義される（文言・条件は検討案）。[^u009] 詳細は[1861年公武協定](/diplomacy/kobu-agreement-1861.md)。

## 幕府を終わらせうる協定

この協定は幕府を延命させると同時に終わらせうるものだった。将軍は朝廷の裁可のない軍権を失いうる。[^u010] 編成・訓練・人事と平時の警備は将軍に、全国動員・対外開戦・諸侯討伐は勅裁に、という配分が考えられ、将軍が勅裁なしに諸侯を討伐できなくなれば、幕府と諸藩の争いは「京都における朝廷の裁可をめぐる政治闘争」へ転換する（検討案）。[^u010] 後世の歴史家はこれを「幕府延命のための協定であると同時に、徳川将軍による独占的統治の終わりを制度化した協定」と評価するだろうとされる。[^u010]

## 那珂川公爵家の創設

旧水戸領の名目上の領主には、伏見宮家出身の若い法親王・公現（後の北白川宮能久親王、1847年生）が選ばれ、還俗・臣籍降下して「那珂川」の家名を賜る。家名は水戸徳川家の継承や常陸一国への権威主張を連想させない地名から採られた。[^u018] 1861年頃の創設から1863〜65年は名目的領主の時代で、徴税・軍事・人事は幕府が管理する（年次は検討案）。[^u018] 那珂川家は「徳川家に由来しない領主権でありながら、朝廷の権威によって保証された領主権」を持つ家であり、後に朝廷政府自身の中央集権化を制約する有力領主となる。[^u018] → [那珂川公爵家と公現法親王](/people/nakagawa-ducal-house.md)

水戸学については、尊王論が朝廷にとってむしろ親和的であり、朝廷が警戒すべきは思想ではなく激派・鎮派の党派対立である。那珂川家は弘道館・彰考館・『大日本史』編纂を保護して旧藩士知識層を取り込み、「最も強い尊王思想を持つ大領主家」となる。[^u019] → [水戸学（本世界線）](/concepts/mitogaku.md)

## 常備軍の忠誠構造

最初にできた常備軍は「国軍」ではなく「諸侯連合軍」だった。天皇の権威で作られ、将軍の軍事官僚が指揮するが、藩籍のまま出向した兵の俸禄・家族生活は藩主に依存し、兵士の忠誠は直接には藩主に向かう。[^u011] 真の常備軍となるには、①俸給・家族扶助を中央が払う、②軍籍を藩籍から分離する、③将校任命権を中央に置く、④藩別編成を解体する、の四条件が必要とされた（検討案）。[^u011] 最初の10年間には、藩兵・諸藩供出の中央軍・幕府直雇の中央軍・朝廷直属の近衛部隊という四種の軍隊が並存しうる。[^u011] 詳細は[全国常備軍（公武合体軍）](/military/standing-army-1861.md)。

この構造の矛盾は勝っている間は隠れ、幕府が負けたときに表出する。「幕府軍は敗北によって軍隊を失うのではなく、敗北によって、それまで軍隊を保有できていた政治的な前提を失う」。[^u012]

# 1862〜1865年：家茂の強硬路線

1862年には全国軍役改革と中央常備軍の創設、1863年には江戸湾・大坂湾・下関海峡への海防軍配備が進む（年表は検討案）。[^u009] 生麦事件（1862）と薩英戦争（1863）は史実通り起きる前提で、「一藩の軍備では列強に対抗できず、一藩の紛争で日本全体が責任を問われる」ことを示し、軍事統一論を補強する。[^u016]

水戸を処理しても火種は残る。成長した家茂が火種を片端から叩き潰そうとしても不思議ではない。[^u013] 初期の水戸処分は老中主導だったが、その成功体験と1863〜64年の京都政局への中央軍の介入（尊攘派鎮圧）が将軍に過信を生む（経過は検討案）。危険な転換点は、「最初は幕府の秩序を守るために軍事力を使い、次第に幕府の政策に反対すること自体を秩序への挑戦とみなす」ことにあった。[^u013] 人物は[徳川家茂](/people/tokugawa-iemochi.md)を参照。

# 1865〜1866年：第二次長州征討と最初の憲政危機

第二次長州征討は史実通り行われるが、本世界線の朝廷はこれに同意しない。1861年以降、水戸処分・全国常備軍・諸藩からの徴収・京都での軍の使用によって幕府が強くなりすぎ、朝廷が監督権を維持するため慎重になったからである。[^u014]

1865年に朝廷が勅許を保留し、1866年初頭に家茂が勅許なしで出兵を強行、長州軍が幕府軍の一部を撃破すると、諸藩部隊では勅許なき作戦に従う義務が問題となり、藩主への照会と撤収が始まる（三段階の経過は検討案）。[^u014] 朝廷は家茂を朝敵とする必要はなく、「出兵を停止せよ」と命じるだけで足りた。「軍が負けたから朝廷に逆らえなくなるのではなく、朝廷の命令に逆らっている軍が負けたことで、諸藩が将軍に従う理由を失い始める」。[^u014] 「1861年の協定は朝廷権威で幕府の軍事的中央集権化を始めさせ、1866年、同じ朝廷権威がそれを止める」。この事件は本世界線における最初の本格的な憲政危機とされる。[^u014] 詳細は[第二次長州征討と最初の憲政危機](/events/second-choshu-expedition.md)。

# 1866年：家茂の死と無血の幕府解体

1866年7月20日（旧暦）、家茂が死去する。この時点で朝廷には幕府を解体する力がある。軍権を一時朝廷預かりとすれば覆せる存在はなく、諸大名も朝廷の名のもとで所領を安堵されるなら幕府にこだわる理由がない。[^u015]

法理は「徳川宗家の相続」と「将軍への軍事委任」を別の行為とみなすことにある。朝廷は家督相続を認めつつ、軍事委任の更新を保留できる（1861年協定の委任が将軍個人へのものであることが前提）。[^u015] 架空の勅命「征夷大将軍家茂薨去につき、天下兵馬の統轄は、新たな沙汰あるまで朝廷においてこれを預かる。諸侯は従前の封土を安堵され、軍兵は各々部署を守り、私に軍を動かすべからず」が示されている（検討案）。[^u015]

| 時期 | 経過（検討案） |
|---|---|
| 1866年7月 | 家茂死去。朝廷は軍事委任の終了と解釈し、再委任を保留 |
| 8月 | 軍権の朝廷預かり。全国軍に現状維持命令、諸藩に所領安堵通達、私的動員禁止 |
| 9月 | 徳川宗家を含む有力諸侯を京都に招集して諸侯会議 |
| 10〜11月 | 将軍職の軍政権停止。宗家相続と所領保有は承認、全国統治権の世襲継承は不承認 |
| 12月 | 朝廷の下に諸侯合議制の新政体発足、旧幕府官僚組織を朝廷直属官庁として継承 |

（典拠 [^u015]）

孝明天皇の崩御（史実1866年12月25日）までの約5か月が朝廷の猶予だったが、勅命は崩御で失効しないため、新天皇のもとで既成事実化される。[^u015] 主導者は薩長ではなく朝廷であり、徳川家は最大の敗者とは限らず、経済力・人脈・旧幕府官僚の経験によって新政府でも影響力を保つ。[^u015] 那珂川家はこのとき名実ともに大領主となる。[^u018]

「この世界線では、幕府を終わらせる決定的な行為が『徳川家を倒すこと』ではなく、『次の将軍に軍事権を再委任しないこと』になる」。[^u015] 詳細は[1866年の無血の幕府解体](/events/bloodless-dissolution-1866.md)。

# 次の時代へ：なし崩しの維新

幕府解体からなし崩しに明治維新のような改革が始まる。1863年に家茂が「皇国防衛は朝廷の命を受けた将軍が一元的に担う」と用いた論理を、1866年には朝廷が「将軍の死で軍事行政を停止させられない。今後は朝廷の下に恒久的な軍務機関を設ける」と転用する。[^u016] → [なし崩しの維新](/concepts/gradual-restoration.md)

しかし所領安堵によって幕府解体に成功した代償として、諸侯の世襲領国支配はむしろ強く保障され、廃藩置県に当たる改革はいっそう難しくなった。[^u015][^u017] 公武合体を進めた先には華族令がほぼ史実通りの形で出る一方、藩主権はほぼそのまま領主権として認められる。[^u017] こうして[近代封建制](/concepts/modern-feudalism.md)の原型が生まれ、1867年の[明治改元](/events/meiji-era-proclamation-1867.md)以降の国制建設へと引き継がれる。→ [通史：明治国制の建設（1867〜1881）](/history/1867-1881-state-building.md)

# 史実との比較

# 未決の論点

* 南北戦争が「早期終結」か「回避」か、米国が幕府の協力者となるか新たな圧力となるか。[^u001][^u008]
* 生存した井伊直弼のその後（彦根藩内の対立、隠居・家督相続の時期）。[^u002]
* 水戸徳川家の最終的な処遇と転封先、旧藩士の反乱が起きるか。[^u005][^u006]
* 1861年の那珂川家への授封が収益受給権のみか、行政・人事を含む領主権か。[^u018]
* 1861年協定の条文、とりわけ朝廷が委任を変更・撤回できるか、委任が将軍個人へのものか徳川家への世襲保障か。[^u010]
* 常備軍の四条件の実施程度、朝廷直属近衛部隊の創設の有無。[^u011]
* 第一次長州征討・禁門の変相当事件の経過、慶喜の処遇、1866年新政体の具体的機構と長州の参加資格。[^u013][^u015]
