# 概要

本世界線の[日清戦争](../events/sino-japanese-war.md)は、1886年の[袁世凱逮捕事件](../events/yuan-shikai-arrest.md)を受けた清の朝鮮征討によって1887年に始まった。史実より約7年早い。[^u063][^u064] 戦争は「高宗の保護をめぐって始まり、北洋艦隊の存廃と黄海の勢力均衡をめぐる戦争へ変化」した。[^u064] 清の追加派兵で元老院は主戦論一色となり、講和条件は北洋の海上戦力の無力化、さらに台湾・澎湖割譲へと拡大した。[^u064][^u065][^u067]

講和の真の制約は戦場ではなく、清国の支払い能力にあった。清の戦後信用を補完し融資するのは列強であり、日本は英国中心の銀行団と賠償借款を調整し、英仏の利権を先に既成事実化したうえで、1889年に[下関条約](../diplomacy/shimonoseki-treaty-1889.md)を結んだ。[^u072][^u076][^u077] 遼東半島を求めなかったため、三国干渉は起きなかった。[^u079]

戦後、日本は近代国家でありながら論功行賞に悩み、賠償金の分配をめぐる争いを全領国に益する交通網整備へと転換した。「戦争は勝てば儲かる事業ではない」という教訓は、その後の対露政策を規定することになる。[^u078][^u083][^u088]

# 開戦への政治過程

1886年の袁世凱逮捕の後、清朝中央では強硬論が優勢となり、李鴻章の慎重論を退けて朝鮮征討が準備された。[^u063] 日本は高宗への保障を再確認し、元老院・衆議院で軍事費を審議して駐留を続けた。清は1887年に朝鮮へ進出し、交渉が決裂して開戦に至った。[^n1][^u063]

構造的な問題は、清朝中央が威信のために戦争を始める一方、実際に戦う北洋軍事体系の責任者である李鴻章が勝算に疑問を持っていたことにある。[^u063] 清にとっては、局地戦に敗れて撤兵すれば、国王による清国官員の逮捕を認めたまま宗主権回復に失敗することになるため、引き下がることは難しかった。[^u064]

# 戦争の経過

## 局地戦から全面戦争へ

局地戦で清軍が退けられると、清には全力投射以外の選択肢が乏しくなった。清が全面戦争を決断した時点で、日本も清から何を得るかを計算しなければならなくなった。[^u064] 最初の衝突の後、清が追加派兵すると、元老院は主戦派一色となった。[^u067] ただし元老院は「戦うか」ではなく「どこまで勝つか」で割れた。

| 元老院の勢力[^n1] | 講和条件の主張 |
|---|---|
| 限定講和派 | 朝鮮独立承認・清軍撤退・賠償 |
| 安全保障重視派 | 上記＋北洋艦隊の壊滅・軍備制限 |
| 強硬講和派 | 上記＋台湾・澎湖などの割譲 |

（典拠 [^u067]）

領主議員の論理は「自分たちが憲法で保障された権限を持っているからこそ、外国の世襲君主が持つ統治権への武力干渉にも反対する」というものであった。[^u067] 一度安全保障目的を戦争目的に組み込むと、それを実現せずに講和することは政治的に困難となった。[^u067]

## 時間は清の敵

清を史実通り屈服させることは可能であった。時間は清の敵であり、最初の一撃で戦局を覆せなかった時点で、清に挽回の道はなかった。[^u070] 条件は日本が黄海の制海権を確保して清の増援を阻止することであり、清の不利は兵力差ではなく、陸海の協同不全・統一戦略の欠如・参謀と兵站の弱さ・臨時的な海防財政という戦争遂行体制の差にあった。[^u070] 日本側には1860年代以来の統一軍、全国標準化された鉄道・通信・金融、領主間競争で育った軍需産業、高宗の駐留承認、清の拡大を受けた両院の予算支持という強みがあった。[^u070] 最大の分岐は1887年の最初の本格的な日清海戦であり、定遠・鎮遠を擁する北洋艦隊を撃破できるかにかかっていた。[^n1][^u067][^u070]

## 戦争目的の拡大と早期講和の拒否

全面戦争に進んだ以上、早期講和はむしろ日本の側が受け入れられなかった。[^u071] 立憲帝国として両院に戦費を説明し、国民と領主に負担を求めている以上、撤兵だけで講和すれば成果を説明できず、「今ここで終戦したら、清国は艦隊を再建して数年後に戻ってくるのではないか」という疑念が残るからである。[^u071]

| 時期 | 経過[^n1] |
|---|---|
| 1887年前半 | 朝鮮で清軍が敗北、清中央が追加動員 |
| 1887年夏〜秋 | 本格的な陸海戦、日本が黄海の優位確保を図る |
| 1887年末〜1888年前半 | 日本が北洋軍港と直隷沿岸へ圧力、清から早期講和の打診 |
| 1888年中盤 | 日本が北洋戦力無力化と台湾・澎湖割譲を要求、講和申し入れは決裂 |
| 1888年後半〜1889年前半 | 順天府への脅威を背景に本格講和交渉 |

（典拠 [^u071][^u077]）

これは「戦争目的を拡大するほど『勝利した』と認める条件が遠ざかる」構造であり、日本政府の早期講和拒否そのものが戦争長期化の独立した要因となった。[^u071]

## 順天府への圧力

厳しい講和条件を呑ませるには、順天府（北京）へ行く意志と、行ける可能性を示さなければならなかった。[^u068] 核心は北京への進軍を実行することではなく、その意思と能力を清朝中央に信じさせることであった。朝鮮での清軍撃退、北洋艦隊の撃破と旅順・威海衛への圧力、天津・山海関方面への進出能力の誇示という三段階を経て、「朝鮮に対する宗主権を守ろうとした戦争が、最後には清朝の首都の安全そのものを脅かす戦争」となった。[^n1][^u068] 元老院では、清が割譲と賠償を受け入れるまで進軍準備で圧力をかけるべきとする強硬派と、北京へ進む必要はないとする慎重派が対立した。[^u068]

# 講和条件の形成

## 北洋の無力化と台湾・澎湖

日本が受け入れられる最低限の講和条件は、少なくとも日本近海での清の海軍力を解体するのに必要な程度であった。[^u064] 日本が求めたのは清海軍の全廃ではなく、黄海・渤海方面から朝鮮へ派兵する能力、すなわち北洋の海上戦力の無力化である。旅順・威海衛は戦中に占領しても講和後に返還し、北洋に軍備制限を課すこととされた。[^n1][^u064][^u069]

南洋海軍の侵入を防ぐためには、台湾の要求も避けられなかった。[^u065] 台湾を得ても南洋艦隊は東側を通れるため完全な封鎖にはならず、目的は南西方面の前進基地の確保である。1887年の台湾攻略は、劉銘伝の海防近代化などにより、1895年より困難であったとみられる。[^n1][^u065] → [台湾（帝国特別領）](../regions/taiwan.md)

## 新領土の統治

割譲された領土の扱いは難題であった。北海道や樺太の扱いもすでに課題となっており、分割して領国を設定するのかが問われた。[^u066] 根本問題は、「日本帝国は国内の世襲領主権を保障しているのに、新しく獲得した土地には領主が存在しない」ことにある。[^u066] 史実で短命だった北海道の分領支配は、廃藩置県のない本世界線では恒久的な制度へと発展した。樺太は対露交渉を考慮して帝国直轄の国境地帯とし、台湾は既存の清朝行政機構や先住民族社会があるため帝国特別領とした。統治は世襲領主領・帝国直轄国・帝国特別領の三類型で整理され、「新領土はまず帝国直轄、必要に応じて授封」が基本方針となった。[^n1][^u066] 統治制度が未確定であることは、割譲要求の障害とはならなかった。[^u067] → [新領土の統治制度](../institutions/new-territory-governance.md)、[北海道（分領支配）](../regions/hokkaido.md)、[樺太](../regions/karafuto.md)

## 列強との交渉と台湾コンセッション

列強との事前交渉の程度は講和条件を左右し、台湾についても割譲後にコンセッションを設ける約束で列強の了解を得られる部分があった。[^u069] 日本は清統治下の外国商人の通商権を尊重し、鉄道・港湾・鉱山・製糖業への投資機会を示す一方、領事裁判権や外国警察権は与えなかった。遼東半島の永久割譲には固執せず台湾・澎湖を取る方針のもと、英国が中立、米国が既存の対日関係を重視し、仏国が商業譲歩と引き換えに反対を控えたため、ロシアが警戒しても三国干渉に当たる共同圧力は形成されなかった。[^n1][^u069]

## 支払い能力という制約

講和の真の問題は、清の支払い能力の見積もりであった。清に講和条件を履行させるには、戦後の清の信用を補完し融資する列強との交渉が不可欠である。[^u072] 賠償額は清の財政力ではなく「列強がいくら貸すか」で決まり、日清講和は実質的に「日清二国間条約＋列強の金融協定」となった。[^u072] 年利5％・30年の単純モデルでは、2億両の賠償は年約1,301万両の返済となり海関収入の半分を超えるため、日本は賠償を1億〜1億5,000万両に抑え、台湾・澎湖と北洋の安全保障を優先した。[^n1][^u072] 賠償を取りすぎれば清は外国借款に依存し、特にロシアの影響力が強まるという逆説もあった。[^u072] → [対清賠償借款と講和の国際金融](../economy/indemnity-loan.md)

清に交渉力はなく、戦争の終わり方は日本が決められた。[^u073] ただし軍事的には日本が講和の時期を決められても、金融的には列強との事前調整が時期を決めた。講和をあえて遅らせた理由は要求の拡大ではなく、列強との交渉を完成させるためであった。[^u073]

## 英仏利権の既成事実化

日本は、フランスやイギリスの利権を先に既成事実として中国に入れさせる道を選んだ。[^u076] 対露戦略上は英国を先に引き込む方が有効であり、英国を山東・直隷の港湾・鉄道・金融へ、フランスを雲南・広西など華南へ誘導した。要点は、清に借款を供与する銀行団へ鉄道・港湾の事業権を先に設定させることであり、後からロシアが進出すれば英国の既得権と衝突する構図となった。[^n1][^u076] 清との講和より先に英仏との非公式な金融・通商協定が成立しており、1889年の講和は「日本が列強と事前調整した構想を敗戦国清に受諾させる場」となった。[^u076] → [中国大陸の利権争奪（1888〜1900年代）](../diplomacy/china-concessions.md)

# 1889年：下関条約

1889年（明治23年）、下関条約が締結された。[^u077] 締結時期は春〜夏で、日本は旅順・威海衛方面で優位を確保し北京への進軍能力を示していたが、北京は攻撃していない。[^n1][^u077] 条約は次の10条からなる。[^n1]

| 条 | 内容 |
|---|---|
| 第一条 | 清は朝鮮の完全独立と李氏王統を承認し、宗主権を放棄する |
| 第二条 | 台湾・澎湖諸島を日本帝国に割譲する |
| 第三条 | 戦争賠償金1億2,000万庫平両[^n2] |
| 第四条 | 北洋方面の軍備・軍港の時限的制限 |
| 第五条 | 清は朝鮮から撤兵し、高宗の統治に干渉しない |
| 第六条 | 日清間の通商・航行・居留民保護の再規定 |
| 第七条 | 賠償履行の担保として日本は威海衛の一時占領を継続できる |
| 第八条 | 賠償支払いのための海関収入担保借款を認める |
| 第九条 | 既存外国人通商権益の尊重と新たな経済協定締結の容認 |
| 第十条 | 捕虜交換・占領地返還・停戦・批准手続 |

（典拠 [^u077]）

列強の具体的な事業特許は条約本体に書かれず、英系中心の銀行団による「対清賠償借款協定」と、英国の北洋方面経済権益・仏国の華南事業機会を定める「対列強通商協定」が並行して成立した。[^n1][^u077] 1億2,000万両を年利5％・30年で調達すると年間返済は約780万両で、1887年の海関収入約2,054万海関両の約38％に当たる。[^u077] 最大の外交成果はロシアを融資の中心から外したことであり、史実1895年の露仏借款に当たるものは起きなかった。[^u077] 英系銀行団の賠償支払い確定、日本の威海衛撤退、英国の港湾権益発効という順序が重要であった。[^u085] 詳細は[下関条約（1889年）](../diplomacy/shimonoseki-treaty-1889.md)を参照。

この条件では三国干渉は起きなかった。[^u079] 雪辱の動機がないため、日本の対露政策は史実より冷静であったが、長期的にはより厳しいものとなる。[^u079]

# 戦後処理

## 論功行賞

日清戦争の後、日本は近代国家でありながら論功行賞を行わなければならなかった。これは本世界線に特有の現象である。[^u078] 軍がすでに国家軍として統一されているため、将兵個人・領主家・領主系企業の誰の功績とするかが問題となった。領主は自領出身将兵の戦功を自家の功績と主張し、中央は「将兵は帝国に仕えたのであって家臣として戦ったのではない」と反論した。[^u078] 台湾・澎湖は帝国直轄とし、領主家には陞爵・金銭・国家事業の機会を与えることで落着したが、北海道の未授封地での加増論も起こった。加増は元老院の議席と力関係を変えるため、その決定権が争点となった。[^n1][^u078] 「1867年以来領主権を整理してきた国家が、戦勝で再び『誰に何万石を与えるか』で揉める」という皮肉な事態であった。[^u078] → [日清戦争後の論功行賞](../events/reward-distribution-1889.md)

## 賠償金を公共事業へ

賠償金の分配をめぐる争いを避けるため、すべての領国に利益のある横断的な公共事業に充てるべきだという意見が自然に生じ、需要喚起策として国道・高速国道と鉄道が整備された。[^u083] 「戦勝の利益は帝国全土に還元する」という原則は元老院にも衆議院にも説明しやすく、中央は全国の物流・軍事輸送網を掌握できた。[^u083] 1889〜1904年の15年計画が立てられ、「帝国交通例」によって用地取得と恣意的通行税の禁止が定められ、賠償金の半額6,000万両が帝国交通整備基金に充てられた。[^n1][^u083] もっとも、論功行賞を公共事業に変換しても、論功行賞の政治そのものは消えなかった。恩賞の配分は路線の配分へと形を変えたのである。[^u083] → [帝国交通整備計画](../economy/transport-plan.md)

同じ時期、台湾・澎湖を帝国直轄の特別領とする「台湾統治例」が制定され、賠償金配分をめぐる元老院・衆議院の審議が始まった。[^n1][^u077]

## 清への帰結

清国は日本への賠償を払うために、税収・鉄道・鉱山という統治権の一部を削られた。日清戦争は清朝末期の財政危機と利権争奪を数年〜十年程度前倒しする事件となった。[^u074] 1886年に逮捕された袁世凱は、1889年の講和後に清へ引き渡され、敗戦責任を問われて処刑されたとみられる。[^u105] → [袁世凱](../people/yuan-shikai.md)

# 編集注：未決の論点

* 賠償額1億2,000万両は暫定設定で確定額ではない。[^u077]
* 開戦経緯・戦争経過・講和の時期と条文・新領土統治・論功行賞の落着・交通整備計画の細目は、いずれも検討案の段階にとどまる。[^u063][^u066][^u077][^u078][^u083]
* 1887年時点の日本海軍が定遠・鎮遠を中心とする北洋艦隊をどう撃破したか、海戦の具体的経過。[^u067][^u070]
* 北洋軍備制限の期間と履行監督の方法。[^u064][^u077]
* 論功行賞の決定権（天皇大権か元老院の同意か）、加増の範囲。[^u078]

# 編集注：却下・修正された案

* **短期終結の見立て**：戦争は思ったより短くなり清が早期講和を選ぶという見立ては、全面戦争化した以上早期講和は日本が受け入れられないとして修正された。[^u070][^u071]
* **1888年後半講和案**：講和時期の候補とされたが、1889年締結に改められた。[^u073][^u077]
