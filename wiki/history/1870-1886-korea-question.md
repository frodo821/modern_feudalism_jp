# 概要

本世界線の朝鮮問題は、日本国内の外交一元化から始まる。廃藩置県による外交権接収という史実の手段が使えないため、新政府は対馬宗家から領主権ではなく外交権だけを取り上げ、その結果、朝鮮との国書をめぐる衝突が史実より早く表面化する。[^u038][^u039]

朝鮮・清の内部条件は史実通りであり、変化は日本の早い近代化と特異な国制が第三国に及ぼす影響として現れる。[^u047] 武家領主が主導する元老院は対外的に武断的に傾き、江華島事件と朝鮮開国、1882年の壬午軍乱に端を発する漢城危機、清仏戦争を好機とした1884年の介入と朝鮮国独立保障へと進む。[^u042][^u048][^u050][^u055]

独立保障は清を牽制するはずの約束だったが、日本自身を朝鮮問題に縛りつけた。清仏戦争を終えた清が干渉を強めると、廃位を恐れた高宗は日本公使館に避難し、日本軍の保護を後ろ盾に袁世凱を逮捕させる。日清戦争は東学農民の蜂起ではなく、この袁世凱逮捕をめぐる危機から、史実より約7年早く始まる。[^u056][^u060][^u061]

# 1867〜1873年：外交一元化と国書問題

## 対馬宗家の家役返上

対朝鮮戦略上の最大の問題は、対馬宗家が日本国の代表を僭称していることだった。[^u038] 宗家の対馬領主権は1866年の所領安堵以来保障されているため、新政府は「宗家から奪うのは領主権ではなく外交権」という整理をとる。[^u038] 宗家の外交独占は他の領主にとって面白くない話であり、元老院で宗家は孤立する。島津・毛利には独占の利益がなく、徳川宗家にとっても、将軍家が外交権を失ったのに旧幕府の委任先だけが残るのは説明しにくい。[^u039]

元老院は「諸侯の領主権は保障する。しかし、外国との交渉は帝国政府の専権である」との原則に立ち、1868年に「外交事務統一例」を制定する。宗家を名指しせず、従前の家役により外国交際を担当していた諸家の権限を帝国政府が承継し、既得の財産・通商利益は別に例で補償するという一般原則で処理する（条文は検討案）。[^u039] 宗家は1868年頃に自発的に家役返上を申し出、対馬領主権の再確認と財政支援を得る。[^u039] 結果、国内の外交一元化は史実より早く完了する。→ [対馬宗家と外交権の一元化](../diplomacy/tsushima-so-clan.md)

## 朝鮮の国書拒否

しかし朝鮮は新しい外交秩序を受け入れる意味がないため受け入れない。清国の後ろ盾があると考えているからである。[^u040] 宗家特権の接収が早いため、国書衝突は1867〜69年に表面化する（仮に1868年の受理拒否）。[^u040] 清の宗主権は朝鮮への無条件の軍事防衛義務を意味せず、朝鮮の「清が守ってくれる」という認識と清の実際の行動のずれが後の危機の原因となる。[^u040] 1871年には日清修好条規に相当する条約が結ばれるが、清は朝鮮を属邦と主張しつつその外交は自主とする立場をとり、日本は誰と交渉すべきか曖昧なまま日朝関係が悪化する（検討案）。[^u040] → [日朝国書問題と1870年代前半の日朝関係](../diplomacy/japan-korea-relations-1870s.md)

宗家の家役がなくなったことで、交渉停滞の責任は中央政府が直接負う。「外交権を集中させたのに朝鮮との関係すら正常化できないのか」という批判が強硬策の誘因となる。[^u041]

## 征韓論争相当

領主の出自は武家であり、対外政策はより武断的になる可能性が高い。[^u042] 元老院は武家の名誉観を国家外交に持ち込み、国書拒絶を天皇と帝国の威信への侮辱と捉える議論が強まる。史実と違い、戊辰戦争の負担も廃藩置県による旧支配層の再編もないため、大久保らの内治優先論に当たる議論の説得力は弱い。[^u042] 征韓論を唱えるのは旧士族の不満代弁者ではなく、領主権を保障された現役の世襲統治者たちであり、自らは軍を編成する負担がないまま国家軍への発言権を持つ「国軍を持たない武家領主」が強硬論を領主連合間の主導権争いの手段とする。[^u042] 1872〜73年頃に元老院で強硬な使節派遣・海軍示威を求める論争が起き、「武家領主が主導する元老院」と「戦費を負担する納税者を代表する衆議院」が対立する構図が生まれる（時期は検討案）。[^u042] → [征韓論争（本世界線）](../events/seikanron-debate.md)

# 1875〜1876年：江華島事件と朝鮮開国

江華島事件は、起きない理由の方が必要なくらいである。[^u041] 元老院は穏健外交を保証せず、宣戦には元老院の同意が要っても、平時の測量航海・艦隊派遣には同意が要らない可能性があり、「戦争ではなく航路調査」と説明すれば派遣は容易だった。[^u041] 1874年に海軍の航路調査・測量が拡大し、1875年前後に日本艦が江華島近海で朝鮮砲台と衝突、1876年に軍事的圧力を背景とする条約交渉で朝鮮が開国する、というのが基本線である。[^u041]

事件後の論点は、帝国政府が元老院の事前承認なしにどこまで軍事行動を拡大できるかという憲法問題だった。将軍の独断的な軍権を制限して成立した国制の経緯がここに影を落とす。[^u041] 日朝修好条規第1款に当たる「朝鮮は自主の国」との規定は、日本が朝鮮の外交的自立を主張する明文上の根拠となる。[^u052] → [江華島事件と朝鮮開国](../events/ganghwa-island-incident.md)

## 条約改正と国内向けの外交

朝鮮の開国を迫る理由には、国内向けのパフォーマンスが確実にある。[^u046] 1880年代に欧米との不平等条約改正に成功すれば、政府は「不平等条約を改正した、次は朝鮮との国交正常化」と訴え、強硬派は「西洋に認められる近代国家が隣国との国交も確立できないのか」と批判する。[^u046] 対欧米では対等を、対朝鮮では不平等を求める二重基準がそこにある。条約改正の早期成功は対朝鮮強硬化を抑えず、むしろ促し、日清戦争は「対欧米で自信を深めた立憲帝国が朝鮮半島での地位をめぐり清と衝突する戦争」となる。[^u046] → [不平等条約改正](../diplomacy/treaty-revision.md)

# 1882年：漢城危機

1882年の壬午軍乱は本世界線でも起き、日本の早い近代化のもとでそのままエスカレートする可能性が高い。[^u047] 帝国軍は約20年の整備を経ており、日本側は清軍との直接衝突を避ける必要を史実ほど感じない。[^u047] ただし清に日本と全面衝突する理由はあまりなく、日本にもエスカレートの利点が乏しいため、どこかで手打ちとなる。その事実は火種として燻る。[^u048]

| 時期 | 経過（検討案） |
|---|---|
| 7月 | 壬午軍乱、日本公使館襲撃。日本は艦隊と陸兵を派遣 |
| 8月 | 漢城周辺で清軍と日本軍が対峙 |
| 8〜9月 | 偶発的な局地衝突 |
| 秋 | 撤兵・賠償・公使館警備で合意し全面戦争を回避 |

（典拠 [^u048]）

収拾の取り決めとして、両国の期限内撤兵・派兵の事前通告・合意なき軍事顧問派遣の禁止・朝鮮政府の秩序維持責任の確認を定める「1882年日清漢城協定」が想定されている（史実1885年天津条約の前倒し、検討案）。[^u048] 日本では元老院の武家領主層が「帝国軍を動員しながら清の介入を阻止できなかった」と政府を批判し、清では「属邦について日本に派兵通告権を認めた」ことへの不満が残る。この妥協は後年、和平論と強硬論の双方の根拠として引用されることになる。[^u048] → [1882年漢城危機（壬午軍乱）](../events/imo-incident-1882.md)

# 1882〜1885年：清の軍拡と清仏戦争

1882年以降数年の双方の軍拡が重要となる。清は対日軍拡の最中にフランスとの戦争で背中から殴られる構図になり、史実より軍事力を用意できるかは不透明である。[^u049] 清の軍事力は北洋（李鴻章）と福建・南洋で指揮系統も利害も異なり、1882年の危機を経た李鴻章が北洋艦隊を温存する理由は史実より強くなる。1885年の清がどうなるかは、北洋だけが強化される、両面対応で軍拡が停滞する、危機感から改革が加速する、の三方向を並置して一方向に決めない（検討案）。[^u049] 定遠・鎮遠の到着は史実通り1885年秋である。[^u049] → [清の対朝鮮政策と李鴻章](../diplomacy/qing-korea-policy.md)、[李鴻章](../people/li-hongzhang.md)

# 1884年：甲申政変と朝鮮国独立保障

清がフランスと戦っている以上、日本は史実以上に「助平心」を出す。[^u050] 元老院では「1882年は譲歩した。今は清が南方でフランスと戦っている」という議論が起こり、1882年協定を日本自身が破る可能性すらある。[^u050] ただし日本の目標は朝鮮の従属化ではなく、清の政治的優越を排した親日的な市場であり、清を排したいという点こそが助平心そのものだった。[^u051] さらに、日本政府が朝鮮政府に反日活動の取締りを申し入れるのは自然な流れであり、朝鮮が清の属国である状態は日本にとって受け入れ可能ではない。[^u052] → [甲申政変（本世界線）](../events/gapsin-coup-1884.md)、[日本の対朝鮮戦略目標](../diplomacy/korea-strategy.md)

清の宗主権を意識するなら、日本は「李氏王朝に支配された朝鮮」の独立を一方的に保障しうる。保障の対象は、李氏王朝の存続と、その王朝が統治する朝鮮の独立である。[^u055] 1884年に発せられる「朝鮮国独立保障ノ詔」（架空文案）は、朝鮮国王とその正統な嗣位者の統治権を認め、外国の兵威で王統を廃し政務を制することを東洋の和平に害あるものとする。[^u055] この論理は、天皇のもとで世襲領主権を保障し、徳川家の領地と家格を保障して幕府を解体した日本の国制と相性がよく、元老院の武家領主にも理解しやすい。[^u055] だが「清への牽制として発した独立保障が、日本自身を朝鮮問題へ継続的に関与させる外交上の約束になる」。[^u055] → [朝鮮国独立保障（1884年）](../diplomacy/korea-independence-guarantee-1884.md)

1884年の軍事危機の後、1885年には清が朝鮮の外交自主権について一定の譲歩をする。日本側は、朝鮮の外交自主権の明示的確認、清軍の撤収と軍事介入の制限、日本人・公使館の安全保障の三点を求めた（検討案）。[^u052] 争点は朝貢儀礼そのものではなく「清が朝鮮の主権的意思決定を制約できること」だった。[^u052] → [1885年の日清妥協](../diplomacy/sino-japanese-compromise-1885.md)

# 1885〜1886年：清の干渉と高宗の避難

清の威信が落ちると、李氏王朝の安定も揺らぐ。清の軍事力で抑えられていた高宗・閔氏系・大院君系・急進開化派・地方両班と農民の対立が表面化し、「清の後ろ盾を失った朝鮮軍が誰の命令に従うか」という、1866年の幕府が直面したのと同じ「正統性と実力の分離」が朝鮮に現れる。[^u053] → [李氏朝鮮の宮廷政治（1880年代）](../diplomacy/joseon-court.md)

1885年に清仏戦争が終わると、清は二正面を恐れる必要がなくなり、宗主権の空洞化を恐れて朝鮮の政情に積極的に干渉し、王朝内部の事情にも口を出し始める。[^u056][^u057] 清は自ら冊封した国王の廃位を避け、まず王宮警備・軍制・人事への介入で高宗の実権を制限する（検討案）。[^u056] 弱体化した王朝が清を切って日本に亡命する可能性もあったが、より可能性が高いのは、廃位されそうになった高宗が日本公使に保護を求め、それが認められることだった。[^u054][^u056] 高宗は漢城の日本公使館にとどまって政務を執り、公使館が朝鮮の政権中枢となる。[^u056][^u058] → [高宗](../people/gojong.md)

高宗が日本公使館から政権を執るなら、清の第一目標は公使館をどうにかすることである。清が直接手を下す必要はなく、適当な人間に襲撃させればよい。[^u058] 1882年・1884年に続く三度目の公使館襲撃は国王まで危険にさらし、元老院の武家領主と衆議院の商工・都市勢力が同じ強硬要求で一致する。[^u058] 日本は既存の公使館警備権・居留民保護、そして朝鮮国王の正式要請を根拠に、高宗の許可のもと邦人保護名目で派兵する。[^u059] 史実1894年の王宮占領とは逆に、本世界線では高宗自身が日本に軍事的保護を求めている。[^u059] → [高宗の日本公使館避難と1886年漢城公使館危機](../events/gojong-legation-refuge.md)

# 1886年：袁世凱逮捕事件

帝国軍の駐留は高宗にとって奇貨だったが、清の介入の「証拠」が出てくる危険も高めた。[^u060] 公使館襲撃の捜査で反高宗派と袁世凱周辺の連絡文書が見つかり、高宗は袁の召還を求め、拒否されると拘束を命じる。逮捕を命じるのは日本ではなく高宗自身である（経過は検討案）。[^u060] 日本が実際に動くと確信した高宗が先走って捕縛まで進めた可能性が高い。1882年に日本は清と対峙し、1884年に独立を保障し、1886年に軍を送ってきた以上、高宗は日本が王位を守るためなら清と戦うと読んだのである。[^u061]

朝貢国が清の権威に挑戦するなどありえない以上、清は朝鮮征伐までエスカレートしうる。[^u061] 他方、日本が独立を保障している以上、逮捕を咎める理由は乏しく、清の要求を呑めと朝鮮に勧告することさえ背信となる。[^u062] 日本の立場は「袁世凱の法的地位と訴追の適法性は朝鮮政府と清国政府の間の問題だが、その解決を強制するために清国が朝鮮へ軍隊を派遣することは認めない」というものになる（文案は検討案）。[^u062] 国内の対立軸は「高宗を見捨てるか」ではなく、「保障の維持にどれだけの軍事的危険を負うか」へ移る。[^u062] → [袁世凱逮捕事件（1886年）](../events/yuan-shikai-arrest.md)、[袁世凱](../people/yuan-shikai.md)

清には譲歩の余地がなく、李鴻章を飛ばしてでも軍事強硬路線をとることはほぼ既定路線となる。[^u063] 朝廷が欽差大臣を送り李の権限を制限しつつ北洋の実務を続けさせる形が最もありそうで、朝鮮征討の目的は袁の釈放から高宗の排除・別王族の擁立へと拡大する（検討案）。[^u063] こうして1886年末〜1887年に清は朝鮮征討を準備し、日本は高宗への保障を再確認して、戦争は1887年に始まる。→ [通史：日清戦争と下関条約（1887〜1889）](1887-1889-sino-japanese-war.md)

# 却下・修正された案

* **亡命王室の保護**：独立保障の対象を「亡命した王室の保護」とする理解は取り違えとして修正され、李氏王統の存続とその朝鮮の独立の保障とされた。[^u055]
* **日本による袁世凱釈放勧告**：日本が高宗に袁の釈放を勧告する選択肢は、独立保障のもとでは背信として退けられた。[^u061][^u062]
* **1894年戦争の維持**：当初は1894年に日清戦争を起こす前提で前史を組み直す案だったが、1882年以降の分岐を重視して1894年を当然視しない方向へ修正された。[^u037][^u047]

# 未決の論点

* 1882年の具体的な事件経過と協定の正式内容、清の軍拡の方向（北洋偏重・停滞・改革加速）。[^u048][^u049]
* 1884年の介入規模と開化派政権の帰趨、1882年協定を日本自身が破ったか。[^u050]
* 独立保障において「朝鮮国の独立」と「李氏王朝の正統性」をどこまで一体として扱うか。[^u055]
* 樺太・千島交換条約を本世界線で結ぶか。
