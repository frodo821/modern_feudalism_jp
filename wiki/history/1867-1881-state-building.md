# 概要

1866年の[無血の幕府解体](../events/bloodless-dissolution-1866.md)によって生まれた新政府は、全大名が朝廷から直接所領を安堵された諸侯連合政権だった。その課題は徳川家との戦争ではなく、諸侯連合体制を近代的な中央政府へ変えることであり、軍事・財政・司法・地方行政をどこまで中央へ移せるかが最大の政治課題となる。[^u020]

1867年の[明治改元](../events/meiji-era-proclamation-1867.md)以後、新政府は皇室典範・華族令・領主権令・官制令を相次いで整え、[元老院](../institutions/genroin.md)を設置し、1868年には藩を廃して律令国を行政区画とする[廃藩置国](../institutions/kokugun-system.md)を行う。1869年頃には天皇と諸領主の協約的性格を持つ[大日本帝国憲法](../institutions/imperial-constitution.md)が詔で公布され、1874年の民撰議院設立建白を経て[衆議院](../institutions/house-of-representatives.md)が加わる。[^u020][^u021][^u024][^u026][^u034][^u035]

この時代の改革は「廃藩置県」ではなく、律令格式の再編纂と領主権の登録・裁定を通じて諸侯の自治と中央の権限を整理する形で進む。そして中央集権化の不徹底にもかかわらず、大領主間の主導権争いと元老院による全国標準化が、近代化を史実より「巻きで」進める。[^u031][^u028][^u044]

国内政治の面では、1867年の第一回帝国議会は元老院だけで開かれ（定数240＝領主互選140・無領華族互選70・勅選30）、1870年に憲法施行後最初の元老院改選、1876年に第一回衆議院総選挙が行われた。衆議院では民権派が全国組織化に失敗し、都市商工業者の立憲改進党と地方名望家の立憲保守党（いずれも仮称）による名望家政党政治が始まる。[^p002][^p004][^p032]

# 1867年：明治改元と新政府

1867年、幕府失権の直後、新天皇睦仁親王の践祚と同時に改元の詔が出され、正式に明治元年となる。改元日は践祚日の明治元年正月九日（西暦1867年2月13日）である。[^u020] 同日に一世一元の制を定め、別に家茂死後朝廷に預けられていた全国の軍事統轄権を新天皇のもとで改めて確認し、諸侯の所領安堵を宣言する勅命が出される（検討案）。[^u020] 新政府は徳川幕府を逆賊の政権として否定せず、「幕府の役割は終わったが徳川家と諸侯の所領・家格は存続する」という論理に立つ。[^u020] 史実の王政復古の大号令に相当する出来事は1866年の軍権朝廷預かりであり、明治の開始と封建領主制の廃止は切り離される。[^u020]

新政府の構造は、明治天皇・朝廷のもとに、旧幕臣・公家・有力諸侯による中央政務機関と諸侯議政院、旧幕府の軍政機構を継承した中央軍・海軍、そして領主権と地方行政権を保つ世襲領主諸侯が並ぶものだった（検討案）。天皇は若年のため、改革は政府首脳の協議で進む。[^u020][^u024] 首都は京都のままであり、江戸城接収の必然性もないため東京奠都は起きず、「江戸」の名が存続する。[^u133] → [首都京都と江戸](../regions/kyoto-edo.md)

# 1867年の立法：典範・華族令・官制

新政府は早々に華族令を出し、皇室典範を整備する。[^u024] 立法の順序は次のように想定されている（時期は検討案）。

| 時期 | 内容 |
|---|---|
| 正月 | 明治改元・[皇室典範](../institutions/imperial-house-law.md)制定（皇位継承・宮家・皇族の範囲・臣籍降下） |
| 春 | [華族令](../institutions/kazoku-ordinance-1867.md)（五爵制）と領主権令（世襲領主権の別途保障）公布 |
| 夏 | 太政官官制改革、弾正台設置。領主権裁定院・刑部省との管轄整理 |
| 秋 | 臣籍降下した親王を初代弾正尹に任命 |

（典拠 [^u024]）

華族令では爵位と領主権が分離され、無領の公爵家もあれば大所領を持つ伯爵家もありうる。[^u021][^u024] 領主間の紛争を調停する機関として、旧幕府の評定所を改組した[領主権裁定院](../institutions/lordship-tribunal.md)が太政官の下に置かれ、領地境界の裁定・領地交換の仲裁・家督相続の審査・国司と領主の紛争処理を担う。「明治元年の朝廷政府は、諸侯の領主権を保障する代わりに、その領主権を裁定する唯一の上位機関になる」（名称・時期は検討案）。[^u022]

あわせて[弾正台](../institutions/danjodai.md)が監察・弾劾機関として置かれ、適当な親王を臣籍降下させて弾正尹に就ける。初代弾正尹には山階宮晃親王が推され、無領の公爵家として国家俸給を受け、利益相反を避ける（人物は検討案）。[^u023][^u024]

# 法体系の再編

明治維新後最初の大仕事は律令と格式の整理だった。[^u031] 1867年時点では朝廷の律令格式と先例、幕府法令・御定書、藩法、寺社の規則、条約上の義務が併存しており、まず「従来の法令・慣行は新たな全国法に抵触しない限り暫定的に効力を維持する」原則が公布される（検討案）。[^u031]

最終的に格は廃止され、法形式は**詔・勅（命令）／例（制定法）／式（施行規則）**に整理される。例は元老院（後に帝国議会）の議決で制定され、「式ハ例ノ委任ニ依リ之ヲ定メ、例ニ反スルコトヲ得ス」とされる。[^u032] 刑例・民例・商例・封土例・国郡例などの名称や「明治五年第二十号例『国郡行政例』」のような法令番号が想定されている（検討案）。[^u032] 「この世界の明治維新は、廃藩置県ではなく律令格式の再編纂を通じて諸侯の自治と中央の権限を整理する改革として記憶される」。[^u031] → [法体系（詔・勅・例・式）と司法制度](../institutions/legal-system.md)

# 元老院と暫定国制

議会は史実の貴族院ではなく、領主権の代表機関としての元老院的性格を持つ。[^u025] 元老院の議席を領主議員・華族互選議員・勅選議員に分けることで一院で足り、1867年に設置される。[^u026] この元老院だけで開かれた1867年の議会が**第一回帝国議会**であり、帝国議会は衆議院の開設を待たずに発足した。[^p002] 創設時の定数は240（領主互選140・無領華族互選70・勅選30）で確定している（旧仮案の定数300〔180/75/45〕は「# 却下・修正された案」を参照）。[^p017][^p032] 構成と互選制度の詳細は本記事の「# 国内政治」と[元老院の構成と互選制度](../institutions/genroin-composition.md)、議案別の議決要件などは[元老院](../institutions/genroin.md)を参照。[^u026]

元老院が憲法より先に成立するのは確実である。同時に、天皇の権限・領主権の保障・軍事外交権・元老院同意事項を定める暫定国制協約が1867年に結ばれたと想定される（検討案）。[^u034]

# 1868年：廃藩置国と外交の一元化

1868年（明治2年）、藩を廃して律令国を正式な地方行政区画として復活させ、諸侯の世襲領主権は安堵したうえでその支配区域を国・郡・村の単位で登録する（「廃藩置国」の名称・年次は検討案）。[^u021] 複数国にまたがる藩主には従前通り複数国の領主権を認め、複数藩にまたがる国や一国に満たない小藩は分割か協議で決める。[^u021] 最初から一国一領主へ整理せず、飛地も当面許容し、境界争いがあったときだけ裁定院が調整する。[^u022] これにより領主権の根拠は徳川幕府から朝廷へ移り、日本は「幕府が認めた藩の集合体」から「朝廷が領主権を配分する律令国の集合体」へ変わる。[^u021] → [廃藩置国と国郡制](../institutions/kokugun-system.md)

同じころ、外交権の一元化も進む。対馬宗家が朝鮮に対して日本国の代表を名乗る状態は、他の領主にとっても面白くない話であり、元老院で宗家は孤立する。「諸侯の領主権は保障する。しかし、外国との交渉は帝国政府の専権である」という原則のもと、宗家は1868年頃に家役返上を申し出、対馬の領主権再確認と財政支援を得る（経過は検討案）。[^u038][^u039] 詳細は[対馬宗家と外交権の一元化](../diplomacy/tsushima-so-clan.md)、その後の日朝関係は[通史：朝鮮問題（1870〜1886）](1870-1886-korea-question.md)へ。

# 1869年頃：大日本帝国憲法

帝国憲法は史実とはかなり性格が変わり、天皇を君として全領主の総意に基づくものとなる。[^u025] 名称はそのまま「大日本帝国憲法」とし、天皇の詔で公布される。[^u033] 諸侯は天皇に無限の権限を認めないため、憲法が史実通り1880年代末まで制定されないのは不自然であり、1869年（明治3年）頃に公布される。[^u034][^u035]

この時点の領主権はかなり強く、行政権だけでなく治安権・司法権を含む。[^u036] 仮想の領主権条項（第十一〜十五条）は、世襲領主権の保障、領内での行政・徴税・警察・司法権の行使、外交・国防・全国軍統轄の中央専管、領主権紛争の法定裁定機関による審理、法定手続によらない領主権の停止・剥奪の禁止を定める（検討案）。[^u036] 司法は領主裁判所・帝国裁判所・弾正台の三分となる。[^u036]

憲法制定の推進主体は自由民権運動ではなく、自らの統治権を守ろうとする諸領主だった。諸侯が最も警戒したのは「天皇の名を借りた太政官が勅命一つで領主を討伐できる制度」である。[^u034] 天皇の軍事権も史実の独立大権より議会手続で制約される。[^u025]

# 帝国軍の統合

1861年以来の全国常備軍は、1867〜70年に朝廷政府が旧幕府軍を継承する形で中央の軍事行政に統合される。1870年代には各領主が軍事費負担を金納化して独自軍を縮小し、1880年代には国軍が対外防衛をほぼ独占し、領主には警察・限定的な警備組織だけが残る（変遷は検討案）。[^u030] 帝国軍は諸侯の連合軍ではない。常備軍を飼える体力のある領主は多くなく、大領主も国軍の一翼として自軍を維持するとは限らないからである。[^u030] 大領主の競争は将官輩出・兵器発注・軍事予算への影響力をめぐるものとなる。[^u030] → [帝国軍](../military/imperial-army.md)

# 1870年代前半：全国共通法と標準化

1870〜72年、元老院は軍制・租税・鉄道・商業などの全国共通法を制定する（検討案）。[^u035] 標準化の圧力は高い。標準化が弱いと領国間通商が困難になるからであり、欧米を見れば確実に元老院で議論となる。[^u044] 度量衡・貨幣と銀行制度・関所と通行税の廃止・鉄道軌間・郵便電信・商事法・特許の統一が優先課題となり、1873年頃には元老院に「度量衡・工業規格調査委員会」が置かれる（検討案）。[^u044] 「経営主体は分散していても、制度と規格は全国共通」であり、標準化は大領主が自家規格を帝国標準にする競争でもあった。[^u044] → [全国標準化政策](../institutions/national-standardization.md)

## 岩倉使節団と欧米視察

欧米視察は誰もがしたがる。視察の主体は帝国中央政府・元老院と諸領主・各領主家の政府企業の三つに分かれ、岩倉を正使とする欧米回覧（1871〜73年）の正式使節は100人前後にとどまるものの、同時期の領主家の視察員・留学生を合わせると数百人規模（試算190〜330人）になる（検討案）。[^u043] 岩倉具視は倒幕政府の中心人物ではなく、朝廷と元老院の利害調整者として振る舞う。[^u043] 帰国者は全国の領主家へ知識を持ち帰り、鉄道・銀行・学校・裁判制度の改革を競う。[^u043] → [岩倉使節団と欧米視察](../events/iwakura-mission.md)

## アメリカ連邦制の受容

ここでは史実以上にアメリカ連邦制が参考にされる。[^u045] 南北戦争を回避した米国は州権が強く残っており、日本の領主たちは「広い自治権を各州に認めても全国共通の通貨・郵便・商取引制度を運営できる」と見て領主権存続の論拠にする。[^u045] 米国視察後の領主議員から、帝国通商条項・領主権留保条項・帝国法優越条項を加える憲法改正が提案されるという構想があり（検討案）、領主権は「朝廷から安堵された世襲的権利」から「憲法によって保障される統治権」へと性格を変えていく。[^u045] → [アメリカ連邦制の受容と領主権の再定義](../institutions/federalism-reception.md)

# 1874〜1876年：民撰議院設立建白と衆議院

史実通り民撰議院設立建白書が出てから衆議院がつくられる。[^u026] 時期的に、建白書は1869年頃の憲法公布への直接の応答として位置づけられる。[^u035] 元老院が全国共通法を制定しても人民は議員を選べず、商人・豪農・知識人が「代表なき負担」を問題視する。[^u035] 1874年（明治8年）の建白は、「帝国憲法既ニ制定セラレ、天皇ノ大権及諸侯ノ領主権ハ明文ヲ以テ保障セラル。然ルニ、天下ノ租税ヲ負担シ、国防ノ軍役ニ服スル人民ハ、未ダ国政ニ参与スルノ権ヲ得ズ」と、憲法を否定せずその理念を人民へ拡張するよう求める（文案は検討案）。[^u035] 欧米帰りの領主家官僚・留学生の関与や、元老院で劣勢な大領主連合による運動支援も考えられる。[^u035][^u043]

元老院の廃止ではなく、元老院は諸侯の権利代表として存続し、別に人民代表の衆議院を置く二院制が自然な妥協となる。第一回衆議院総選挙は1876年に行われた（確定）。[^p002] 1875年の衆議院選挙法の制定、律令国・郡を基準とする人口比例の選挙区は検討案である。[^u026][^u035] 長期的な争点は予算であり、元老院は領内課税権の尊重を、衆議院は税負担の公平と全国統一税制を求める。[^u026] 「諸侯が自らの権利を保障するために作った憲法が、領民が政治的権利を要求する根拠になる」。[^u035] → [衆議院と民撰議院設立建白書](../institutions/house-of-representatives.md)

# 近代化の加速：奉還と寄親・寄子

明治維新が早まると、近代化も史実より20年程度早いペースで進む可能性が高い。理由は大領主の間で必ず主導権争いが起きるからである。[^u027][^u028] 中小領主は大領主を寄親として改革を進め、軍費・出資・用地・元老院での協力と引き換えに技術・販路・鉄道接続・留学機会を得る。[^u028] 島津・毛利・鍋島・徳川宗家・前田・那珂川などの領主圏が投資を競い、成功した制度は模倣され、元老院で全国標準化される。[^u028] → [寄親・寄子制と大領主間の近代化競争](../concepts/yorioya-yoriko.md)

一方、小藩主の中には財政難から領主権を返上する者が出る。爵位を保ったまま年金・公債で補償する領主権奉還の制度が整えられる（「領主権奉還令」は検討案）。[^u027] 奉還した家は領主互選の選挙権を失って無領華族互選の選挙人となるが、元老院の定数は固定されており、奉還によって議席は減らない。[^p012][^p021] 奉還の規模は前編の想定より小さく、1867〜76年の最初の波で20家、1877〜89年に9家、1937年までの累計で60家にとどまる（家数は作者確定）。[^p022][^p023] → [領主権奉還](../institutions/lordship-surrender.md)

# 1870年代後半〜1881年：条約改正への道

欧米とは法体系が違っても、翻訳可能な程度には整理されつつあり、不平等条約の改正に成功している可能性は十分にある。[^u046] 欧米が求めたのは名称や構成の一致ではなく、外国人がどの法律・手続で裁かれるか予測できることであり、鍵は「外国人にも適用される帝国共通法と、領主の判決を帝国裁判所が審査できる仕組み」だった。[^u046] 1870年代後半に米国などと個別に交渉し、1880年代前半に領事裁判権撤廃を含む改正条約の締結を目指すという年表が想定されている（検討案）。[^u046] → [不平等条約改正](../diplomacy/treaty-revision.md)

この間、朝鮮との関係では国書問題・征韓論争相当・江華島事件と朝鮮開国が進み、対外問題が元老院政治の争点となる（[通史：朝鮮問題（1870〜1886）](1870-1886-korea-question.md)）。1880年代初頭の日本は、帝国軍が約20年整備され、成文憲法と両院を備え、経済は領主間競争と標準化で統合されつつある状態で、1882年の朝鮮危機を迎える。[^u047]

# 国内政治

## 第一回帝国議会と元老院の構成

帝国議会は1867年、元老院だけで第一回を開いた。1869年頃に公布された[大日本帝国憲法](../institutions/imperial-constitution.md)の施行後、1870年に第一回の元老院改選が行われ、以後6年ごとに改選が続く（1876年第2回、1882年第3回、1888年第4回）。[^p002][^p032] 元老院の任期は6年、勅選議員は天皇の信任が続く限り終身であり、元老院議長は慣例として勅選議員から選ばれる。[^p002]

定数の根拠は、創設時の領主華族およそ270〜276家の「2家に1人」を互選で選ぶという考え方にある。[^p011] ただし定数は領主家数に自動連動させず、創設時に固定し、変更には帝国議会の立法を要する。既得権化して政治問題になりうることは承知のうえでの設計である。[^p012] 1867年の確定定数は次のとおり。[^p017][^p032]

| 議員種別 | 定数 | 選挙権者・被選挙権者 | 選任方法 |
|---|---:|---|---|
| 領主互選議員 | 140 | 領主華族の当主 | 互選、任期6年 |
| 華族互選議員 | 70 | 無領華族の当主に限る | 互選、任期6年 |
| 勅選議員 | 30 | ― | 天皇が選任、終身 |
| 計 | 240 | | |

華族互選の選挙権・被選挙権を無領華族に限ったのは、領主華族に対する朝廷側の抵抗権として設計されたためである。[^p018] 領主側の140議席は過半数だが、首班指名の過半数120票に対して、無領華族互選と勅選の100人が一致すれば領主20人の協力で別の候補を指名できる。朝廷が諸侯に過半数を認めつつ、諸侯が一枚岩でない限り影響力を持つ構造であり、幕府解体時の朝廷と諸侯の妥協を反映する（解釈は検討案）。[^p018]

互選は全国一括の選挙区で、爵位や石高にかかわらず一人一票の**顕名単記投票**で行う。自己投票は禁止され（最低1人の同輩の信任が必要）、当落線上の同数得票者は決選投票、1票以上の得票者が定数に満たない場合は補充投票で埋める。[^p019][^p020] 顕名投票は家同士の関係を公に表明する行為となり、元老院の会派は当初、政策綱領を持つ政党ではなく「互選における相互推薦と票の調整を行う領主連合」として形づくられた（検討案）。[^p019][^p020] 衆議院が置かれる1876年より前に、元老院の内部ではすでに選挙運動・推薦組織・会派政治が発達していたことになる（検討案）。[^p011] → [元老院の構成と互選制度](../institutions/genroin-composition.md)

## 1867年華族令と初叙爵

明治維新が内戦を伴わなかったため、1867年の時点で維新の功績によって華族に叙された者はいない。1867年の[華族令](../institutions/kazoku-ordinance-1867.md)は功労者への授爵制度ではなく、既存の公家・武家の身分秩序を新帝国の法制度のもとで再編する制度だった。[^p013] 旧公家は家格をそのまま五爵に対応させ（摂関家→公爵、清華家→侯爵、大臣家→伯爵、羽林家→子爵、名家・半家→男爵）、堂上137家に爵位が配分された。[^p014] 武家については、朝廷は徳川家への親疎で決まっていた武家の家格を解体し、天皇を頂点とする新たな貴族秩序へ再編しようとした。親藩・譜代・外様の区分や殿席は叙爵に影響させず、石高を基準として侯爵30万石以上、伯爵10万〜30万石、子爵3万〜10万石、男爵3万石未満とした。徳川宗家と[那珂川家](../people/nakagawa-ducal-house.md)は公爵とされた。[^p015][^p016][^p017]

この結果、華族は414家（領主華族276家、無領華族138家）となった。[^p017] 爵位別の内訳は次のとおりである（内訳も作者確定。井伊家・水戸徳川家など個別の家の爵位には検討案を含む）。[^p017]

| 爵位 | 領主華族 | 無領華族 | 計 |
|---|---:|---:|---:|
| 公爵 | 2 | 6 | 8 |
| 侯爵 | 15 | 9 | 24 |
| 伯爵 | 40 | 3 | 43 |
| 子爵 | 87 | 66 | 153 |
| 男爵 | 132 | 54 | 186 |
| 計 | 276 | 138 | 414 |

爵位と領主権は互いに独立しており、領国を統治する男爵家も、領地を持たない公爵家もありうる。華族身分は歴史的家格に、領主権は世襲的地方統治権に、勅選議員の地位は個人の能力と天皇の信任に由来する、という三原理の区別が置かれた（検討案）。[^p013][^p016] 創設時に爵位を持たない有能な人物は勅選議員として国政に参加できるため、功績華族を急いで作る理由は乏しく、最初の功績叙爵が政治問題になるのは1889年の日清戦争後である。[^p013] → [華族制度](../institutions/kazoku-system.md)

## 奉還と新規授封（1867〜1881）

旧幕藩財政の清算期にあたる1867〜76年は、小領主にとって最も危険な時期だった。家臣団の俸禄整理（ダイス判定：難易度45、出目22・失敗）と幕末以来の債務整理（難易度45、出目43・失敗）はいずれも円滑に進まず、奉還補償は小領主にとって魅力的で（難易度30、出目75・成功）、帝国政府も奉還領の債務・行政を引き継ぐ財政能力を確保した（難易度35、出目76・成功）。一方で、国司への行政委託は広く普及し（難易度30、出目77・成功）、大領主による中小領主への金融支援はきわめて効果的に機能した（難易度30、出目99・クリティカル）。[^p022] このため奉還の波は大領主の信用圏に入らなかった独立系小領主に集中し、1867〜76年に20家、1877〜89年に9家が奉還した（件数は作者確定）。[^p022][^p023] 大領主にとって中小領主への支援は、元老院互選での政治的協力を確保する手段でもあった。1870年代には中小領主の相互扶助・債務保証組織が生まれ、のちの諸侯共済会（仮称）の前身となる（検討案）。[^p023] → [領主金融圏と諸侯共済会](../economy/lord-financial-spheres.md)

他方、北海道では領主家の分家や開拓功労者への独立授封が行われ、1867〜76年に12家、1877〜89年に12家の新領主家が生まれた（件数は作者確定）。[^p034] 本州・四国・九州の奉還地は再授封されず帝国直轄地として残るため、領主制は本土で縮小し北海道で拡大する。[^p034] → [新規授封と加増](../institutions/new-enfeoffment.md)、[北海道](../regions/hokkaido.md)

## 衆議院の開設と名望家政党（1876〜1881）

1876年の第一回総選挙で開かれた[衆議院](../institutions/house-of-representatives.md)は任期4年で、解散の制度を持たない。[^p002] 初期の選挙制度は、定数300、選挙権満25歳・被選挙権満30歳、男子のみ、一定額以上の直接税納税者、記名投票、選挙管理は帝国政府、という案である（検討案）。[^p003] 有権者は約65万人（総人口の約1.8%）と見積もられている（検討案）。[^p007]

記名投票は、元老院互選の考え方がそのまま衆議院選挙に持ち込まれたものと理解されている。選挙権は私的権利であると同時に公的職責であり、誰に投票したかを明らかにすることは政治的誠実性の証明だ、という思想である。[^p006] → [衆議院選挙制度の変遷](../politics/election-system.md)

初期の衆議院をめぐる判定は次のとおりである。[^p004]

| 判定 | 難易度 | 出目 | 結果 |
|---|---:|---:|---|
| 初期衆議院選挙の独立性が確保され、領主の恒常的な選挙支配を防ぐ | 45 | 58 | 成功 |
| 民権派が全国的な政党組織を形成する | 30 | 7 | 失敗 |
| 都市商工業者を基盤とする改進派が独立した政党を形成する | 35 | 77 | 成功 |
| 保守派が地方名望家を基盤とする全国政党を形成する | 40 | 73 | 成功 |
| 政党と元老院の改革派・保守派会派の恒常的な連携が成立する | 40 | 70 | 成功 |

選挙の独立性が確保されたため、領主による組織的な選挙支配は定着しない。民権派は全国組織を作れず、立憲自由主義者は改進派へ、地方自治・農村民権派は保守派や地方組織へ、急進民権派は独立の政治結社・院外運動へと三方向に分裂した。[^p004] こうして1880年代に、都市商工業者・銀行家・海運業者・知識人を基盤に商法・民法の全国整備や領国間経済障壁の撤廃を掲げる**立憲改進党**と、地方名望家・大地主・旧上級武士層を基盤に領国自治と漸進改革を掲げる**立憲保守党**（いずれも仮称）が成立する。保守党は選挙独立性の成功により領主家の御用政党ではなく、地方住民の利益のために領主政府と対立することもある。改進党は元老院の改革派（産業育成に積極的な領主や勅選議員）と、保守党は元老院の保守派（領国自治派）と連携した。[^p004] → [政党の系譜と衆議院の議席推移](../politics/political-parties.md)

1876年の第一回総選挙はまだ政党単位で戦われたものではなく、個人の名望や地域の人脈が重視された。勢力の推移は次のように想定されている（定数300、検討案）。[^p003][^p004]

| 勢力 | 1876 | 1880 | 1884 | 1888 |
|---|---:|---:|---:|---:|
| 保守系 | 70 | 98 | 120 | 133 |
| 改進系 | 60 | 92 | 109 | 118 |
| 民権系 | 65 | 42 | 28 | 19 |
| 無所属・その他 | 105 | 68 | 43 | 30 |

内閣は憲法上、元老院が首班を指名し（出席議員の半数以上）、衆議院が組閣拒否・不信任を決議できる（出席議員の半数以上）という仕組みで成り立ち、内閣は議会を解散できない。議員は領主を除き他の公職と兼任できず、閣僚にもなれない。[^p002] → [内閣制度と両院関係](../institutions/cabinet-system.md)

## 前史：1882〜1888年の政治

1880年代の内閣は元老院主導の官僚・元議員中心の非政党内閣だったが、政党の閣外支持を受けた。1888年までに政党を基盤とする内閣は成立せず（ダイス判定：難易度50、出目20・失敗）、選挙資格の緩和も実現しなかった（難易度60、出目30・失敗）。他方、重大な両院対立による長期の内閣不在は回避された（難易度35、出目44・成功）。[^p004] この過程で、元老院が首班を指名する前に衆議院主要政党の意向を確認する慣行が生まれる（検討案）。1880年代の内閣は「非政党的だが反政党的ではない」ものであり、1888年の日本は「議会の政党化が政府の政党化に先行」した状態にあった（検討案）。[^p004] 1880年・1884年の総選挙を経て保守・改進の二大政党が衆議院の8割強を占め、日清戦争中の1888年には両院同時改選（衆議院第4回・元老院第4回）を迎える。[^p002][^p004] その後の政党内閣の成立は[通史：列強競争と日英協調（1889〜1914）](1889-1914-great-power-rivalry.md)の「# 国内政治」へ続く。→ [内閣の系譜と政党内閣の慣行](../politics/party-cabinets.md)

# 却下・修正された案

* **憲法1880年代制定案**：史実同様1889年公布でも成立するという案は、諸侯が無限の権限を認めないとして退けられ、1869年頃へ前倒しされた。[^u033][^u034]
* **律令格式の四分類**：律・令・格・式を近代法に対応させる案は、格を廃し律も消える方向で撤回された。[^u031][^u032]
* **近代化は20年早まらないという留保**：大領主間競争を過小評価していたとして撤回された。[^u027][^u028]
* **領主系予備軍を含む三層軍制**：統一国軍案に修正された。[^u029][^u030]
* **元老院定数300（領主180・華族互選75・勅選45）**：前編の仮案。会話ログ3で、創設時の領主華族276家に対して領主議員180は少なすぎるとされ、1867年の定数は240（領主互選140・無領華族互選70・勅選30）に置き換えられた（その後1924年275、1936年310）。[^u026][^p017][^p032]
* **奉還で領主議席が消滅する案**：前編では奉還した家の元老院領主議席は消滅するとしていたが、会話ログ3で定数固定の互選制に置き換えられた。奉還した家は領主互選の選挙権を失い無領華族互選の選挙人となるが、定数は変わらない。[^u027][^p012][^p021]
* **1870〜90年代に奉還が進み強い領主権が一部の大領主に集中する見通し**：会話ログ3のダイス判定（大領主の金融支援がクリティカル、行政委託の普及など）により、奉還は1937年までの累計で60家（276家中）にとどまると下方修正された。[^u027][^p022][^p023]
* **帝国議会の成立を1876年の衆議院開設とみる記述**：会話ログ3で第一回帝国議会は1867年に元老院のみで開かれたと確定し、1876年は帝国議会の二院制化と位置づけ直された。[^u026][^p002]
* **華族互選を爵位別に行い領主家も参加する案**：会話ログ3で、華族互選の選挙権・被選挙権は無領華族に限定し、全国一括・一人一票の顕名単記投票とすることが確定した。[^p018][^p019]

# 未決の論点

* 廃藩置国の名称・実施年、国司を置くか、国司の任命方式と領主命令の取消権。[^u021]
* 弾正尹の人物（山階宮晃親王か華頂宮博経親王か別人か）と新公爵家の家名。弾正尹公爵家の創設が第一回帝国議会（1867年）の前か後か。[^u024][^p013]
* 憲法公布の正確な年、暫定国制協約の正式名称と内容。[^u034]
* 衆議院の選挙権の納税要件（帝国税のみか領国税も算入するか）、定数300と選挙区制はAIの暫定案。（設置年は会話ログ3 P2 で解決：1876年第一回総選挙。元老院との権限関係も P2 で首班指名・組閣拒否・不信任・勅令の運用として確定。）[^u026][^u035][^p002][^p003]
* 領主権奉還令の補償条件。（奉還の進度は会話ログ3 P22・P23 で解決：1867〜76年に20家、1937年まで累計60家。家数は作者確定。）[^u027][^p023]
* 御三卿・交代寄合・内分分家に独立領主権を認めるか、水戸徳川家・彦根井伊家などの石高補正。1867年の爵位別内訳はAIの集計による暫定値。[^p016][^p017]
* 元老院の非勅選議席が一斉改選か、領主議員に6年任期をどう適用するか。[^p002]
* 衆議院の議席推移はAIの暫定配分であり、立憲改進党・立憲保守党の党名は仮称。初期の首相・党首の人名は未定。[^p004]
