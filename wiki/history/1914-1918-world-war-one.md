# 概要

1914年6月のサラエボ事件はロシアと関係なく起き、本世界線でも欧州大戦が始まった。[^u094] 日露戦争を経験していない日本は、ロシアとの関係ではなく英国との関係で参戦を判断した。「日露戦争には勝っても得るものが乏しい。しかし第一次世界大戦では、イギリスが負けると失うものが大きい」。[^u095] ドイツが勝てば1889年以来の秩序はすべて覆るため、日本は英国側で参戦した。[^u096] → [第一次世界大戦と日本](../events/world-war-one.md)

ただし日本陸軍の実戦経験は1887〜89年の日清戦争だけであり、西部戦線への大規模派兵は見送られた。日本の最大の貢献は派遣した師団の数ではなく、海軍による太平洋・インド洋の防衛代行と、連合国へ供給した軍需品と船腹の総量であった。[^u097][^u098][^u120] 日米の物資供給はかえってロシアの人的損耗を増やし、帝政の崩壊を早めた。[^u114][^u115] 戦争の終わりには、日本は英仏への大口の、しかも多くが円建ての債権を持つ国となっていた。[^u099][^u135]

国内では、参戦とともに元老院の主要会派・衆議院の主要政党・帝国政府が共同で戦時政策を担う超党派の戦時協力内閣が成立し、戦時経済の成功は立憲体制全体の成功と受けとめられた。戦時利得と物価は大きな争点になったが全国的な騒擾には至らず、選挙は記名投票の制限選挙のまま、1918年の元老院第9回改選を経て戦後の競争的な政党政治へ移った。[^p006][^p007]

# 1914年：開戦と日本の参戦

## 七月危機

墺洪のボスニア支配、セルビア民族主義、南スラヴ統一運動は本世界線でも存在し、大公暗殺に当たる事件は起きた。ただし「サラエボ事件が起きること」と「欧州全体の戦争に拡大すること」は別の問題である。[^u094] 日露戦争と1905年革命の衝撃を経ていないロシアは、1908年のボスニア併合危機で譲歩せず、バルカンで史実より強硬になった可能性もある。[^n1][^u094] 本世界線でも大戦は起きたが、東部戦線をはじめ、その結果は史実どおりにはならなかった。[^u094]

## 参戦の論理

日本の立場は中立か英国寄りであり、英国が直接の利害当事者である一方、ロシアはまだ敵ではなかった。むしろドイツの勝利を防ぐために英国側で参戦することには十分な理由があった。史実でもパリは陥落寸前に至っている。[^u095] 英国が講和に追い込まれれば、北洋の金融・通商秩序も再交渉を迫られかねず、ドイツの勝利阻止そのものが具体的な外交利益であった。[^u095]

参戦は、1914年8月に英国政府から海軍支援の正式要請があり、日英で作戦範囲と戦後処理を協議したうえで、元老院・衆議院が海軍の限定参戦と臨時軍事費を承認し、対独宣戦するという経過をたどった。[^n1][^u095] 参戦に際しては超党派の戦時協力体制が成立した（後述「# 国内政治」）。[^p006] 目的は領土獲得ではなく長期的な対英協力の維持であり、政府の説明は「英国の戦争を支援する必要はあるが、日本が欧州の陸戦を肩代わりする必要はない」というものであった。[^u095] 英国系資本が山東・直隷に先行していたため、ドイツの膠州湾租借は英国の反対で成立しておらず、青島は英国主導・日英資本の商業港、清朝崩壊後は青島行政委員会の特別行政区域となっていた。攻撃すべき青島要塞は存在せず、1914年の青島攻略戦・日本の山東占領、1915年の二十一カ条の山東条項、1919年の山東問題は、いずれも史実の形では起きなかった（→[青島](../regions/qingdao.md)）。[^e038]

## 逆転する元老院

ドイツの勝利が現実味を帯びると、日本に選択の余地はなくなった。[^u096] ここで、元老院の財政慎重派こそが参戦を支持する理由を持った。問いは「今戦費を惜しんだ結果英国が敗北したら、日本はその損失をいくらで埋め合わせられるのか」であった。[^u096] 「日露戦争には『勝っても儲からないから戦わない』と判断した元老院が、第一次世界大戦には『負けたら損失が大きすぎるから戦う』と判断する」。前者は既存利益を拡大する戦争、後者は既存秩序を維持する戦争である。[^u096] 1914年9月、パリ危機を受けて両院は軍需生産の拡張と追加戦費を審議した。[^n1][^u096]

# 日本の戦争協力

## 陸軍派兵の問題

日本陸軍は史実ほど陸戦の経験を持たなかった。観戦武官を当初から送っていても、実際に軍事行動できるかは別問題であり、資源の充足も課題であった。[^u097] 旅順攻囲・遼陽・奉天のような大規模火力戦の経験を欠き、「戦場で何が起きているかは知っているが、それを自軍で実行する能力が確認されていない」状態であった。[^u097] 戦術・指揮、装備・補給、遠征能力、制度・政治の四つが障害となり、1914年は海軍と軍需、1915年は兵站・技術要員、1916年以降は必要なら限定的な師団派遣、という段階的協力がとられた。[^n1][^u097] 派遣決定から西部戦線到着までは数か月かかり、「パリが危ないから今すぐ日本軍を送ってマルヌに参加させる」ことは非現実的であった。[^u098]

逆説的に、「史実より強い工業国家だからこそ、陸軍を送るより英仏の軍需生産を肩代わりする方が戦局に貢献できる」のであった。[^u097] → [帝国軍](../military/imperial-army.md)

## 工業力と軍需供給

1914年の日本の工業力は、次のように推計される。[^n2][^u098]

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 粗鋼年産 | 約25万t（1913） | 300万〜450万t |
| 汽船保有 | 約158万総t | 350万〜500万総t |
| 汽船年間建造 | 約5万〜8万総t | 20万〜35万総t |
| 小銃 | ― | 年30万〜60万丁 |
| 野砲・山砲 | ― | 年200〜500門 |
| 野砲弾 | ― | 1915年中に年100万〜300万発 |

1915年上半期から月10万〜20万発の英仏向け砲弾を供給できれば、英国の「砲弾危機」を局所的に緩和しうる規模であった。[^u098] 商船を大量に英国へ貸せば鉄鉱石・石炭・石油・綿花の輸入が滞るため、既存船の徴用より新造船の供給が優先された。[^u098] ロシアと戦っていない日本は、ロシアへの軍需輸出でも連合国を支えた。[^u098] 元老院は軍需供給と海軍協力を支持しつつ、陸軍の大規模派遣には慎重であった。[^u098] → [第一次世界大戦期の日本の軍需・海運・海軍協力](../military/wwi-japan-war-effort.md)

## 海軍：英帝国東方防衛の代行

日本の重要性を測る第一の尺度は、英国の植民地防衛にどれだけ協力し、どれだけ重要な役割を演じたかである。[^u120] 中核の構図は、日本海軍がインド洋・太平洋を守ることで、英国海軍が北海・大西洋・地中海へ集中できたことにあった。[^u120]

| 時期 | 日本海軍の役割[^n1] |
|---|---|
| 1914〜15年 | 東方海域の防衛代行。通商破壊艦対策、ANZAC船団護衛、英アジア艦隊の負担軽減 |
| 1916年 | 英海軍の欧州集中支援。常続警備と補助艦艇・商船の供給 |
| 1917〜18年 | 地中海への駆逐艦派遣、兵員・物資輸送の護衛 |

（典拠 [^u120]）

同時配備の規模は巡洋艦12〜18隻・駆逐艦20〜30隻とされる。[^n3][^u120] ただし、日本の協力によって英国が「何十隻も」艦艇を欧州へ移せたとするのは過大評価であり、1914年末までに英国側で新たに転用できた余裕は大型巡洋艦1〜2隻、軽巡洋艦2〜4隻程度にとどまる。[^u121] 価値は艦艇数より、東方航路の海上輸送の信頼性と、ANZAC船団護衛が臨時協力ではなく事前計画された常設任務となる防衛構造の安定にあった。[^u121] 豪州・ニュージーランドにとって日本は頼れる防衛協力国であると同時に、自国の周辺で圧倒的な海軍力を持つ外国でもあった。[^u120]

この経験は日本海軍の性格を決めた。インド洋・地中海での護衛任務、通商破壊艦の捜索、潜水艦対策を経て巡洋艦・駆逐艦派が強まり、「戦艦は敵の戦艦を抑えるために必要だが、海上交通を維持する仕事の大部分は戦艦ではできない」という教訓が残った。[^u127][^u128] → [帝国海軍の戦略思想](../military/navy-strategy.md)

# アメリカの参戦

アメリカの参戦動機は日本とほぼ同じであり、フランスが危機に陥れば参戦するものであった。[^u101] 南北戦争がないため1914年の大統領がウィルソンである保証はなく、連邦軍制や徴兵制度も史実と異なりうる。[^u101][^u119] 米国は1914年に中立を宣言し、参戦までは中立国として英仏への軍需供給と金融を担った。1915年のルシタニア号撃沈で世論は反独に傾いたが参戦には至らず、1917年、ドイツの無制限潜水艦作戦とフランスの危機が重なった時点で参戦した。[^n15][^u101] 参戦後は日米が英国を共同で支える構造となり、日本は太平洋・インド洋と軍需・商船、米国は大西洋の海運・軍需・金融と陸軍派遣を担った。[^u101] 史実の米国は1917年4月の参戦時に常備陸軍約13万で、200万人の欧州輸送は1918年までかかった。[^u119] 参戦が史実どおりの時期であるため、1915〜17年に英国の軍需・資金を支える役割は日本に大きくかかった。

# ロシアの崩壊

戦争物資が潤沢になっても、東部戦線は好転しなかった。人的損耗はむしろ増えた。[^u114] 兵器があるから攻勢を続け、補充兵を求め、農村の労働力が減り、鉄道は軍事輸送に逼迫して首都への食料輸送が悪化した。本世界線のロシア革命は「物資不足ではなく、物資があっても戦争を止められない帝政と臨時政府の政治的行き詰まり」によるものである。[^u114]

最悪の経路は、19世紀の軍隊がそのまま大戦に参加して壊滅するというものであり、ロシアはこれに近い道をたどった。[^u115] 日露戦争の教訓を欠いたロシア軍は「新式の小銃や火砲を持ちながら指揮・訓練・作戦思想が旧態依然」の軍隊となり、「補充できるからこそ損耗を続けてしまう」。砲弾は半年で増産できても、中隊長・砲兵将校・参謀・下士官は育成できない。[^u115] 1914年の東プロイセン・ガリツィア攻勢の失敗から、1915年の日米からの大量供給と新兵投入、1916年の消耗戦拡大を経て、1917年に将校と皇帝への忠誠が失われた。[^n1][^u115]

皮肉なことに、ロシアとの戦争を避けた日本が、連合国として送った軍需品によってロシア帝国の崩壊を早めた。[^u115] 本世界線でも1917年の二月革命・十月革命と1918年の単独講和が起きたが、指導者・日付・戦線状況が史実と同じとは限らない。[^n5][^u114] ロシアの戦時債務否認によって、日本も損失を被った。[^u114] → [ロシア帝国の動揺と革命（1905〜1917）](../events/russian-revolution.md)

# 戦争の規模と終結

本世界線の大戦の規模については三つのシナリオがあり、1918年終戦の長期消耗型（シナリオB）が基本線である。[^n4][^u119]

| シナリオ | 終戦 | 想定 |
|---|---|---|
| A 早期終結型[^n15] | 1917年 | 米国1915年頃参戦、ロシア全面崩壊前に講和（米国の参戦が1917年と確定したため成立しない） |
| B 長期消耗型 | 1918年 | 1917年ロシア革命、1918年離脱、日米の追加戦力でドイツ敗北 |
| C 戦争激化型 | 1919〜20年 | ロシア早期崩壊、米陸軍動員遅延 |

（典拠 [^u119]）

大戦終結時の日本の対外債権は、1918年終戦を前提とした積算で、1914〜18年の戦時経常黒字65億円のうち対英の貿易信用・売掛債権が40億円、その他の対外債権が10億円である（[国際収支と対外資産](../economy/balance-of-payments.md)）。[^n6][^e100]

| 年 | 主な経過（シナリオB）[^n4] |
|---|---|
| 1914 | 欧州大戦、日本が英国側で参戦し海軍・軍需工業を動員 |
| 1915 | 日本と中立国米国の英仏への軍需供給拡大 |
| 1916 | ロシア軍大損害、国内危機の深刻化 |
| 1917 | 米国参戦。ニコライ2世退位と急進革命、ロシア軍崩壊 |
| 1918 | ロシア単独講和、日米に支えられた連合国がドイツを破る |
| 1919 | 講和会議（対独賠償、英仏の対外債務、日本への現物・技術賠償が争点） |

（典拠 [^u119]）

「英国の総債務の増加」と「債権者が米国から日本へ移ること」は、別に評価する必要がある。日本が米国の供給を代替すれば、総債務が変わらなくても対日債務の比率は大きくなる。[^u119]

# 債権国となる日本

戦後賠償では、史実以上にドイツが痛めつけられた。[^n1] 日本は知的財産の接収や物的賠償で一定の満足を得たが、主要国の債務残高は史実より厳しくなった。[^u099] 日本の軍需・造船の代金の一部は借款や政府保証債務として繰り延べられ、英仏は対独賠償収入を対日債務の返済財源として期待した。[^u099] 日本が求めたのは現金より、特許実施権・設備・技術文書・技術者の指導を組み合わせた「産業賠償」であった。[^u099] 日清講和で「敗戦国の支払い能力を超える賠償金は回収できない」ことを経験した日本は、名目上の巨額請求には慎重であった。[^n1][^u099] → [対独賠償と産業賠償](../economy/german-reparations.md)

戦時債権は売掛金の性格が強く、軍需品・船舶の輸出代金を繰り延べたものであるため、円建てが相当な割合を占めた。為替リスクの負担は史実と逆転した。[^u135] 1917年、日本は英国などと同様に金輸出を停止し、戦時信用を拡大した。この停止は戦後も続き、1922年頃に旧平価での復帰が断念され、1925年に金平価・金兌換が法的に廃止されて管理通貨制へ移行した。[^u136] → [円建て対外債権と円の国際化](../economy/yen-claims.md)、[金本位制離脱と管理通貨制](../economy/gold-standard.md)

# 国内政治

## 開戦時の政治体制

開戦時の日本は、政党内閣が恒常的な憲政慣行となり、元老院と衆議院の協調が保たれた立憲体制であった。衆議院は立憲保守党・立憲改進党・国民進歩党・社会民権党の四党体制で、選挙は記名投票による納税資格の制限選挙である。[^n7][^p006] 内閣の首班は元老院が指名し、1917年の時点では「首班は議員経験者から選ぶ」ことがすでに慣習となっていた。閣僚の指名は首班の専権だが、天皇が閣僚を認証する際に元老院へ諮問することも慣例として定着していた。[^p002] → [内閣制度と両院関係](../institutions/cabinet-system.md)

## 超党派の戦時協力内閣

参戦時には、単なる与野党の休戦協定を超えて、元老院の主要会派・衆議院の主要政党・帝国政府が共同で戦時政策を策定する体制がつくられた。[^n8][^p006] その形態は、超党派の**戦時協力内閣**と、両院合同の**戦時政策協議会**である。[^n1] 戦時政策協議会は憲法上の議決機関ではなく、予算・軍需生産・対外金融・海上輸送について事前に調整する機関とされた。[^p006] 社会民権党と労働組合にも、戦時生産への協力と引き換えに労働条件・賃金・食料供給を政府と協議する機会が与えられ、これが戦後の労使政協議の基盤となった。[^n1][^p006] 戦時経済の成功は特定政党や軍部の功績ではなく、立憲体制全体の成功と受けとめられた。[^p006] → [内閣の系譜と政党内閣の慣行](../politics/party-cabinets.md)、[労働保護法制・社会保険と労使政協議](../politics/labor-social-policy.md)

## 1916年総選挙と戦時の社会

衆議院には解散がないため、1916年に第11回総選挙が予定どおり行われた。[^p002] 議席（定数300）は保守党121・改進党76・国民進歩党78・社会民権党10・その他15であった。[^n9][^p006] 1912年に改進党から分かれた国民進歩党が改進党を上回り、保守党と進歩党は公共事業で、改進党と民権党は政治制度改革で協力しやすい「政策ごとに連合が変わる議会」となった。[^n1] ただし両院協調と戦時協力体制が強固であったため、政党の分裂は政治的不安定に直結しなかった。[^p006] → [政党の系譜と衆議院の議席推移](../politics/political-parties.md)

戦時経済の急拡大で、戦時利得と物価は重大な政治争点となったが、体制危機には至らなかった。[^n10][^p006] 1918年前後には局地的な食料価格への抗議や労働争議、商店への集団的抗議が起きたが、戦時物価・食料問題による大規模な社会騒擾は際どく回避された。[^n10] 史実の米騒動に相当する全国的騒擾はなく、内閣が強制的に退陣させられることもなかった。[^p007] 争点は農村の米価だけでなく、都市労働者の賃金と物価、戦時利得課税、労働時間、住宅不足に及び、「戦争を決めるのは元老院と政府なのに、費用を払い工場で働く国民の政治参加は十分か」という問いが、民撰議院運動の第二波として浮上した。[^n1][^p001] 戦時利得への追加課税・累進課税は1924年までに実現した。[^n10][^p007] 一方、1916年までに男子普通選挙運動は全国的な社会運動とならず、選挙資格は戦争中も緩和されなかった。[^n10][^p006] → [衆議院選挙制度の変遷](../politics/election-system.md)

## 1918年の元老院改選と戦時体制の終わり

1918年、元老院は第9回改選を迎えた。定数は創設以来の240（領主互選140・無領華族互選70・勅選30）のままである。[^p032] 大戦の経済成長は中小領主にも広く波及し、1914〜26年は領主制の安定期として奉還はほぼ止まった（1914〜26年に1家）。[^n11][^n12][^p022][^p023] 戦時協力内閣は終戦後の1919年頃に首相の判断で解散し、元老院の首班指名を経て通常の政党内閣に移行した。[^n13] 戦後は主要政党間の協調が保たれず、競争的な連立政治の時代が始まった。[^n11][^p007] → [通史：戦間期（1919〜1930）](1919-1930-interwar.md)

## 戦後の論功行賞

大戦後には大規模な功績叙爵が行われた。[^n11] 1914〜1920年の新規叙爵は95家（軍人26・官僚9・実業家38・学術17・その他5）で、日清戦争後と違い軍人の比重が一時的に高まった。[^n12][^p025] また大戦後の論功行賞として新規授封も行われた。[^n11] 対象は軍人だけでなく、戦時輸送・軍需生産・対外金融の功労者を含み、1914〜1920年期に4家が授封された。[^n12][^n14][^p034] → [功績叙爵と新華族](../institutions/merit-peerage.md)、[新規授封と加増](../institutions/new-enfeoffment.md)
