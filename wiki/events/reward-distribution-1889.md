# 概要

憲法も議会も近代的な国軍もあるのに、戦争が終われば諸侯への論功行賞を考えなければならない——これが本世界線の近代日本である。1889年の[下関条約](../diplomacy/shimonoseki-treaty-1889.md)で[日清戦争](sino-japanese-war.md)が終結すると、帝国はちゃんと論功行賞をやらなければならない近代国家として、戦勝成果の配分という国内政治問題に直面した。[^u078]

問題の核心は二つある。第一に、軍隊がすでに国家軍として統一されているため、戦功を誰の功績として評価するかが曖昧であること。第二に、この国には実際に[領主権](../institutions/lordship-rights.md)が存在するため、恩賞として「新領地」を与えるかどうかが現実の選択肢になることである。[^u078] 1867年以来領主権を整理し、全国市場を統一し、軍隊を中央集権化してきた国家が、戦勝によって再び「誰に何万石を与えるか」で揉めるという皮肉な構図が生じた。[^u078]

議論は最終的に、爵位・勲章・年金を中心とする近代的な論功行賞を主流とする方向へ収束した。[^u078] ただし、その過程は円滑ではなかった。論功行賞をめぐる両院の対立は円滑に調整されず（ダイス判定：難易度35、出目24・失敗）、戦後の憲政危機となった。[^p005] 決着の形は、台湾などの新領土は帝国のものとして授封せず、代わりに国内の未開拓地である[北海道](../regions/hokkaido.md)の開拓領を戦功領主に加増する（難易度40、出目63・成功）という妥協であり、「**海外領土は帝国のものとするが、国内の未開拓地については領主への報償として利用できる**」という原則が成立した（原則の定式化は検討案）。[^p034] 同時に、非華族の軍人・官僚への**功績叙爵**が制度化された（難易度25、出目30・成功）が、大規模な一斉叙爵は行われなかった（難易度45、出目9・失敗）。[^p025] あわせて、賠償金を個々の領主に配るより全領国に利益のある交通網整備に投じるべきだという意見が自然に出て、恩賞の配分は[帝国交通整備計画](../economy/transport-plan.md)における「路線の配分」へ変換された。[^u083]

# 背景

## 戦勝成果の配分問題

講和が成立すると、台湾という新たな帝国特別領の統治問題に加え、戦時に大きな軍事的影響力を獲得した中央政府と、戦争を支持し戦費を負担した[元老院](../institutions/genroin.md)が、戦勝の成果をどう配分するかという国内政治問題が生まれる。[^u071] 下関条約の締結と同時期に、台湾統治例の制定と戦勝賠償金の配分をめぐる元老院・衆議院の審議が始まる（検討案）。新領土の恒久的な統治制度や賠償金の使途は、中央政府の権限だけでは処理できないからである。[^u077]

## 統一国軍における功績の帰属

昔なら「島津家が何千人出した」「毛利家がどこの城を落とした」という軍功を基準に加増できた。しかし1889年の[帝国軍](../military/imperial-army.md)では、領主自身が兵を率いているとは限らない。[^u078]

| 功績 | 恩賞を求める主体 |
|---|---|
| 帝国軍の戦勝 | 将官・将兵個人 |
| 戦時の軍需品供給 | 領主系企業、商工業者 |
| 軍費負担への協力 | 元老院の領主家 |
| 港湾・鉄道・輸送の提供 | 領主家、地方政府、民間企業 |
| 外交交渉と講和の成立 | 外交官、中央官僚 |
| 国内の治安・財政維持 | 各領主の行政機構 |

[^u078]

# 争点

## 封建的論功行賞と近代的軍功評価の衝突

領主は自家の領地から出た将兵の戦功を、自家の功績として主張しうる。「当家の領民が帝国軍に多数従軍し、多大な犠牲を払った」という主張である。これに対し中央政府は「将兵は帝国に仕えたのであって、領主の家臣として戦ったのではない」と反論できる。ここで封建的な論功行賞と、近代国家の軍功評価が衝突する。[^u078]

## 何を与えるか

勲章、叙位、爵位の陞爵、年金、褒賞金で済めば比較的簡単である。しかし領主権が実在する以上、元老院では「国家に大功のあった家に新領地を与えるべきだ」という議論が出る可能性がある。[^u078]

| 恩賞の種類 | 評価 |
|---|---|
| 勲章・叙位・年金・褒賞金 | 近代的で扱いやすい |
| 爵位の陞叙（陞爵） | 領主家への主要な恩賞手段（[華族制度](../institutions/kazoku-system.md)参照） |
| 金銭的恩賞 | 賠償金の配分問題と直結 |
| 国家事業の受注機会 | 有効だが、軍需契約を恩賞として配分すると利益誘導・腐敗の危険 |
| 新領地の加増・新規授封 | 元老院の力関係を変えるため最も争点化 |

[^u078]

## 台湾は授封しない

台湾を大領主に分け与えると、海軍基地と外交上の要地を特定の領主家に依存することになる。そこで想定される落としどころは、**台湾・澎湖は帝国直轄領とし、領主家には新領地ではなく、爵位の陞叙、金銭的恩賞、国家事業の受注機会などを与える**ことである（検討案）。[^u078] これは[新領土の統治制度](../institutions/new-territory-governance.md)の「まず帝国直轄、必要に応じて授封」の原則と、1866年に保障されたのは既存諸侯の世襲領主権であって新領土の分配請求権ではないという整理に沿う。[^u066]

## 北海道加増論

北海道にはすでに分領支配や新領主権設定の先例がある。そのため元老院では「台湾は駄目でも、北海道の未授封地域なら加増できるのではないか」という議論が起こりうる。[^u078]（[北海道](../regions/hokkaido.md)参照）

## 決定権の所在

本世界線では天皇が国家元首であり、憲法によって元老院の権限も保障されている。では、領主家への加増や爵位陞叙は誰が決めるのか。天皇の大権として勅によって実施できるのか、それとも領主間の勢力均衡を変える以上、元老院の同意が必要なのか。[^u078]

特に領主議員の議席数が領主権の規模に関係する場合、加増は単なる恩賞ではなく、**特定の家に加増することが元老院における政治的な力関係を変更する行為**になる。戦争に勝った政府が味方の領主を加増して議会での支持を増やすことまでできてしまうため、元老院がこの危険を放置するとは考えにくい。[^u078] 新領土についてはすでに、天皇と元老院が共同で新領主権の設定を承認する制度が検討されていた。[^u066]

会話ログ3では、元老院の領主議員が全国一区の領主互選で各当主1票によって選ばれ、定数も固定されていることが確定したため、加増しても当主の票は増えず、元老院の議席構成は直接には変わらない。元老院が警戒したのは、加増よりもむしろ新たな領主家の創設（互選の有権者が増える）であった。[^p033] 決定手続については、新規叙爵・陞爵は天皇による授爵、新規授封と既存領主への加増は元老院の議決と天皇の承認、授封に伴う国費支出は通常の予算手続、という分担が示されている（検討案）。[^p033] 「新規授封に元老院の承認を必要とする制度が確立する」はダイス判定で成功した（難易度15、出目45）。[^p034] 衆議院は元老院の決議に対する拒否権を持つため、授封には事実上両院の同意が必要になる。[^p002][^p033]

## 衆議院の反発

戦費を負担した衆議院からすれば、「国民の税金と帝国軍の犠牲による勝利を、なぜ特定の領主家への加増で報いるのか」という疑問が生まれる。加増をめぐって元老院の領主議員と衆議院が対立する。[^u078]（[衆議院](../institutions/house-of-representatives.md)参照）

# 戦後論功行賞をめぐる憲政危機

## 両院の対立

日清戦争の勝利後、元老院と衆議院の間で論功行賞をめぐる対立が起こった。これは単純な領主対平民の対立ではなく、国家の性質そのものをめぐる論争であった（検討案）。[^p005]

| 争点 | 元老院内の授封支持派 | 衆議院内の反対派 |
|---|---|---|
| 戦勝の主体 | 天皇および帝国を構成する諸領主 | 帝国国家および国民 |
| 領主への加増 | 功績に対する伝統的報償 | 公的な戦果の私的帰属 |
| 賠償金 | 功績に応じた報償も認める | 原則として帝国財政に帰属 |
| 新規授封 | 天皇の権限として重視 | 国民の権利・財政への影響を重視 |
| 軍人への報償 | 爵位・領地・金銭 | 爵位・勲章・年金・金銭 |

[^p005]

憲法の運用上、元老院は天皇の承認の下で勅を発出でき、衆議院は元老院勅令の発出後90日以内に限りその無効を決議できる（確定）。[^p002] そのため、元老院が論功行賞に関する勅令を発出し、衆議院がそれに無効決議で対抗する、あるいは内閣不信任に至る、といった展開が想定される（検討案）。[^p005]

| 段階 | 想定される経過（検討案） |
|---|---|
| 1889年 | 日清戦争終結 |
| ↓ | 元老院で加増・授封案が浮上 |
| ↓ | 衆議院が反対（国費による戦争の成果の帰属が問題化） |
| ↓ | 戦後論功行賞をめぐる憲政危機（勅令の無効決議・内閣不信任などの可能性） |
| ↓ | 両院間の権限と報償制度の再検討 |

[^p005]

## 判定結果

日清戦争後の恩賞に関わるダイス判定は次のとおりである。[^p005][^p025][^p034]

| 判定項目 | 難易度 | 出目 | 結果 |
|---|---:|---:|---|
| 日清戦争後の論功行賞をめぐる両院間の対立が円滑に調整される | 35 | 24 | 失敗 |
| 日清戦争後に非華族の軍人・官僚への功績叙爵が制度化される | 25 | 30 | 成功 |
| 日清戦争後に大規模な一斉叙爵が行われる | 45 | 9 | 失敗 |
| 高級官僚・外交官への功績叙爵が恒常化する | 40 | 27 | 失敗 |
| 朝廷が領主勢力への対抗手段として新規叙爵を活用する | 30 | 21 | 失敗 |
| 日清戦争後の論功行賞として北海道に加増が行われる | 40 | 63 | 成功 |
| 新規授封に元老院の承認を必要とする制度が確立する | 15 | 45 | 成功 |

領主への加増・新規授封・非華族への叙爵はまとめて議論されたが、規模と基準で合意できず、制度は認められたものの叙爵者は少数に限られた。史実の日清戦争後に約36家が新たに授爵されたのに対し、本世界線では8〜15家程度で、これが最初の功績華族となる（検討案）。[^p025] 1889〜1893年の新規叙爵は20家である（家数は作者確定）。[^p025] 詳細は[功績叙爵と新華族](../institutions/merit-peerage.md)を参照。

# 帰結

## 恩賞の形態

最終的には、新たな領主権を大量に設定するより、**爵位・勲章・年金を通じた近代的な論功行賞が主流になった**。[^u078] 戦後報償の扱いは次のように整理される（検討案）。[^p025]

| 恩賞の種類 | 扱い |
|---|---|
| 既存領主への加増 | 強い政治的反対があったが、北海道に限って実施 |
| 既存華族への陞爵 | 個別に実施 |
| 非華族への新規授爵 | 顕著な功績者に限定 |
| 新規授封 | 例外的 |
| 勲章・位階 | 広く授与 |
| 金銭・年金 | 一般的な報償手段 |

日清戦争の勝利は、封建的な論功行賞制度を最後にもう一度大きく動かし、同時にその制度の限界を露呈させた。[^u078]

## 北海道加増と「国内未開拓地」の原則

台湾などの新領土を領主に分配する案は否定されたが、北海道の開拓領を加増する妥協が成立した。これによって台湾を[帝国特別領](../regions/taiwan.md)として統治することと、北海道で領主領を拡大することが両立した。[^p034] 加増は既存領主家の領国拡大なので、元老院互選の有権者数には影響しない。[^p034] どの家がどれだけ加増されたかは決まっていない。北海道ではこの時期、既存領主家の分家への独立授封や開拓功労者への授封も進んでいた（→[新規授封と加増](../institutions/new-enfeoffment.md)）。[^p034]

## 政党政治への影響

論功行賞問題で両院が対立したことで、元老院主導の非政党内閣だけでは安定した政策遂行が難しいという認識が広がり、1892年総選挙後から1896年総選挙後までの間に初の本格的な政党内閣が成立した（ダイス判定：難易度35、出目52・成功。年代は検討案）。[^p005] 危機は、領主権と臣民の権利の立法的調整（難易度40、出目72・成功）にもつながったとされる（検討案）。[^p005] 一方、領主側も封建的な論功行賞より企業投資・爵位・年金を選びうるため、日清戦争後の政治的妥協は近代的な領主制を完成させる契機ともなった（検討案）。[^p003] 政治史の流れは[内閣の系譜と政党内閣の慣行](../politics/party-cabinets.md)を参照。

## 「路線の配分」への変換

賠償金の分配に悩むくらいなら、はじめからすべての領国にメリットのある横断的な公共事業をやってしまえ、という意見が自然に出てくる。[^u083] 政府は「戦勝の利益は帝国全土に還元する。各領国を国道・鉄道・港湾によって接続し、その建設費を帝国が負担する」という原則を掲げ、元老院（自領の交通条件と産業立地の改善）にも衆議院（特定の家への加増ではなく一般の商工業者・住民への利益）にも説明しやすい解決を得る。[^u083]

交通整備・産業振興をめぐる両院横断の「開発政治」の成立はダイス判定で成功しており（難易度20、出目87）、公共事業をめぐる利益誘導・汚職は全国的な政治問題にならなかった（難易度45、出目34・失敗）。[^p005]

その結果、領主たちは直接的な恩賞金より「うちの領国に鉄道を通してほしい」「この港を国際港として整備してほしい」と要求するようになる。「我が家は日清戦争に大きく貢献したのだから、我が領国の鉄道建設を優先してほしい」という政治交渉は、近代的な公共事業政治であると同時に伝統的な論功行賞の延長でもある。**論功行賞を公共事業に変換することはできても、論功行賞の政治そのものが消えるわけではない。**[^u083] 詳細は[帝国交通整備計画](../economy/transport-plan.md)を参照。

## 長期的な教訓

日清戦争で日本は台湾・澎湖と朝鮮独立承認を得たが、賠償金は清の支払い能力に制約され、占領・戦後処理・台湾統治・海軍補充にも費用がかかった。「戦争は勝てば儲かる事業ではない」という認識が帝国政府と領主に共有され、以後の対露慎重論の基盤となる。[^u088]

# 史実との比較

史実の日清戦争後の論功行賞は、華族への陞爵（伊藤博文・山県有朋らの侯爵への陞爵など）、軍人・官僚への授爵・叙勲、金鵄勲章の授与などの形で行われ、領地の加増という選択肢は廃藩置県（1871年）以後存在しなかった。本世界線では領主権が存続しているため、加増・新規授封が現実の政治問題となり、それが元老院の議席構成と結びつく点が決定的に異なる。

| 項目 | 史実 | 本世界線 |
|---|---|---|

# 未決の論点

* 加増の決定手続（元老院の議決と天皇の承認とする案は検討案。新規授封の元老院承認制は確定）。[^u078][^p033][^p034]
* （解決）領主議員の議席数が領主権の規模に連動するか → 連動しない。領主互選の定数は固定で、各当主が1票。[^u078][^p033]
* （解決）北海道の未授封地域を加増に用いるか否か → 用いた（出目63・成功）。[^u078][^p034]
* 北海道で加増を受けた家と規模、および「特別な功績」の基準。[^u078][^p034]
* 憲政危機の具体的な経緯（元老院勅令・無効決議・不信任が実際に行われたか）。[^p005]
