# 概要

本世界線でも1900年に義和団事件が起きた。外国資本の浸透、キリスト教の布教、農村経済の疲弊、排外主義、宮廷内の保守派といった発生要因は日清戦争の前倒しでは解消されておらず、「起きない理由がない」からである。西太后は史実どおり義和団を支持して列強に宣戦し、列強の連合軍に鎮圧された。[^e015] 構造的な原因が日米の分岐と無関係な史実の事件は本世界線でも起きる、という[世界線の前提原則](../overview/worldline.md)の適用例である。[^u094]

この事件の意味は、鎮圧そのものより、その過程で生じた**北京中央と東南地方の格差**にある。中央が宣戦して敗れ、巨額の賠償を負う一方、長江流域・華南の督撫は中央の命令に従わず列強と独自に秩序維持の協定を結び（東南互保）、軍と経済基盤を温存した。[^e015] 英国はこの経験から「清朝中央は自国の権益を守れない」と学び、地方政府との関係を重視するようになる。これが後の[軍閥](../diplomacy/chinese-warlords.md)支援と、北京・両江・湖北の連合（[中国諸省聯合](../diplomacy/china-federation.md)）への道を開いた。[^e015]

# 背景

1889年の[日清戦争](sino-japanese-war.md)敗北後、清朝では[第一次軍制改革](late-qing-reforms.md)が進んでいたが、統括者を欠き、北洋・湖北・両江・広東・京師直属の各新軍が並び立っていた。[^e016] また本世界線では1889年以降、英国資本による鉄道・鉱山開発が史実以上に進んでいたため、外国勢力への反発はむしろ強まりうる状況にあった。[^e015]

# 経過

## 宣戦と鎮圧

1900年、西太后は義和団を支持して列強に宣戦布告し、列強の連合軍がこれを鎮圧した。[^e015] 北京の中央直属軍や華北の軍事組織は列強との戦闘で損耗した。[^e016]

## 東南互保

宣戦に対し、東南の有力督撫は中央の命令に従わず、列強との独自の協定で管轄地域の秩序を維持した。本世界線でも東南互保は成立した。[^e015]

| 人物 | 当時の地位 | 本世界線での位置 |
|---|---|---|
| [李鴻章](../people/li-hongzhang.md) | 両広総督 | 発言権は低下しているが、互保を成立させる影響力と外交人脈は残る[^e016] |
| 劉坤一 | 両江総督 | 湘軍系、長江下流の防衛を担う |
| 張之洞 | 湖広総督 | 湖北新軍と軍需産業を握り、相対的に台頭 |
| 盛宣懐 | 鉄道・電信・洋務事業の実務担当者 | 互保の実務 |
| 袁世凱 | 史実では山東巡撫 | 本世界線では不在。山東の対応は不明[^n1] |

[^e015]

長江流域と華南は英国資本との結びつきが史実より強いため、互保の動機も強い。英国にとっても、清朝全土を戦争状態にするより長江流域の経済活動を維持する方が望ましかった。[^e015]

## 北京議定書（1901年9月7日）

北京議定書の基本的な内容は史実に準じる。[^e015]

| 項目 | 内容 |
|---|---|
| 賠償金 | 4億5,000万海関両 |
| 利率 | 年4% |
| 償還期間 | 39年 |
| 財源 | 海関税・塩税など |
| 武器輸入 | 原則2年間禁止、延長可能 |
| 外国軍駐留 | 北京の公使館区域と、北京から海岸に至る交通路の要地 |
| 外交機構 | 総理衙門を外務部に改組 |

ただし列強間の賠償金の配分は、本世界線での各国の出兵規模や被害に応じて史実と異なりうる。[^n2][^e015]

# 帰結

## 中央と東南の格差

| | 北京中央政府 | 東南地方政府 |
|---|---|---|
| 軍事 | 敗戦による損失 | 主力の温存 |
| 財政 | 巨額の賠償債務 | 経済基盤を比較的維持 |
| 外交 | 列強からの制裁 | 列強との直接交渉の実績 |
| 政治的権威 | 大幅に低下 | 相対的に上昇 |
| 軍制改革 | 財源不足 | 地方財源で継続可能 |

[^e015]

この結果、**清朝全体として軍制改革の財源が存在しないのではなく、中央政府が自由に使える財源が不足している**状態になる。[^e015] 軍制改革も1900年を境に性格を変え、1901年以降の第二次軍制改革では、中央が新政による軍制の統一を目指す一方、実際の軍隊整備は地方督撫への依存を強めた。史実ではこの過程で袁世凱が北洋軍を拡大したが、本世界線にはその役割を担う人物がいない。[^e015] 「中央集権化の必要性が高まった時点で、それを実現する財政能力が下がっている」という矛盾が、清末新政の全体を規定した。[^e017]

義和団事件で華北の軍事組織が損耗したことは、1911年の清朝が北洋六鎮に相当する兵力を首都周辺に持てない一因となった。[^e019]

## 英国の対清政策の転換

義和団事件は、清朝中央が必ずしも英国の経済権益を守れる存在ではないことを示した。一方、東南互保に加わった督撫は、中央の命令に反してでも外国との契約と経済秩序を守る意思を示した。英国はこれ以後、清朝の領土的一体性を支持しつつ、実際の投融資と権益保護では地方政府との関係を重視するようになる。[^e015]

## 「親契約的な地方」の原型

義和団事件と東南互保は、清朝への忠誠と列強権益の尊重が一致しないことを示した事件でもあった。宣戦した宮廷は列強権益を踏みにじり、命令に背いた督撫が既存契約を守った。辛亥革命後の各勢力を「清朝への態度」と「清の対外権利義務への態度」の二軸で分けて考える必要があるのはこのためで、両江・湖北のような「反清だが親契約的」な勢力の原型がここにある。[^e022]

# 史実との比較

- 史実の義和団事件・東南互保・北京議定書の経過と条件は、本世界線でもほぼそのまま起きる。[^e015]
- 史実では山東巡撫の袁世凱が山東で義和団を弾圧し、東南互保に同調した。本世界線では袁世凱が不在のため、山東の対応は異なりうる。[^e015]
- 史実では1901年以降の新政のなかで袁世凱の北洋軍が突出したが、本世界線では東南の新軍が温存され、軍事力の分散がいっそう進む。[^e015][^e016]
