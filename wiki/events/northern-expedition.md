# 概要

本世界線の北伐は、広州の[中華民国](../diplomacy/republic-of-china-canton.md)が、日英の支援を受ける北方の[中国諸省聯合](../diplomacy/china-federation.md)の体制を解体し、中国を統一共和国に再編するために起こした戦争である。聯合側はこれを地方自治と既存の経済秩序への侵害とみなした。[^e025]

戦争の直接の契機は1926年の**湖南政変**である。唐生智が省自治派の趙恒惕政権を倒すと、聯合の[黎元洪](../people/li-yuanhong.md)が反唐生智派を支援し、唐生智は中華民国に参加、7月に蒋介石が北伐を開始した。[^e031] 北伐は湖南の大部分を獲得する程度には成功したが、黎元洪の本拠地である湖北と江西方面で膠着し、1928年の黎元洪怪死、双方の財政疲弊、世界恐慌を経て、1929〜30年に大規模な戦闘は止んだ。[^e032][^e035] この停止は政治的和解ではなく、**双方の戦争継続能力の低下による事実上の休戦**にすぎない（確定）。[^e039]

# 背景

## 史実より困難な北伐

史実の北伐は、分裂した北洋軍閥を個別に打倒・吸収して成功した。国民革命軍の当初兵力は約10万人、呉佩孚・孫伝芳・張作霖の三大軍閥は計約70〜80万人だったが、1926年中に武漢を掌握し、翌年3月には南京を占領した。[^e028][^e032]

本世界線の北伐は史実より困難である（確定）。聯合という既存の協議機構があり、湖北は黎元洪の本拠地、江蘇は聯合の経済的中核であり、日英が継続的に支援し、聯合加盟による自治の保障が地方軍の取り込みと競合する。武漢・南京は聯合の中核都市である。[^e028]

| 要因 | 史実との比較 | 北伐への影響 |
|---|---|---|
| 北方軍閥間の対立 | 聯合によって一定程度抑制 | 不利 |
| 北方軍の総兵力 | 史実より少ない可能性 | 有利 |
| 湖北軍の結束 | 黎元洪の長期政権によって強い | 不利 |
| 国民革命軍の組織力 | 史実に近い | 同程度 |
| ソ連の援助 | 継続 | 同程度 |
| 米独の経済支援 | 史実より充実 | 有利 |
| 日英の聯合支援 | 史実より強い | 不利 |
| 都市労働運動 | 潜在的には史実以上 | 有利 |
| 地方自治派の離反 | 聯合という受け皿が存在 | 不利 |

[^e032]

一方で聯合は軍事同盟として成立した組織ではないため、湖北軍が危機に陥ったとき、江蘇軍や華北軍がどこまで協力するかは未知数だった。史実の呉佩孚は湖南への介入と北方の軍事的対立を同時に抱えていたが、黎元洪にその制約があるとは限らない。[^e031][^e032]

## 湖南という争奪対象

1920年代前半の湖南は「聯合寄り中立」であり、聯合と通商・交通・金融で協力しつつ清朝国家債務の共同負担には慎重で、軍事的には中立、中華民国との政治関係も断たなかった。湖南の帰属は北伐以前ではなく、**北伐そのものによって決まる**（確定）。[^e030] 湖南は湖北南方の緩衝地帯であり、長江中流経済圏の一部でもあった。[^e031]

| 人物・勢力 | 立場 | 傾向 |
|---|---|---|
| 譚延闓 | 立憲・共和・地方自治 | 聯合協調 |
| 趙恒惕 | 省自治・軍権維持 | 聯合寄り |
| 唐生智 | 全国政治への進出 | 中華民国寄り |
| 程潜 | 共和革命・統一 | 中華民国寄り |
| 毛沢東ら | 農民運動・社会革命 | 共産党系 |
| 地主・商工業者 | 秩序維持 | 聯合寄り |

（検討案。[^e030]）

# 湖南政変と湖南内戦（1925〜1926）

聯合が湖南の自治を尊重しても、それは対外的な安定にすぎず、軍権争い・財政・青年将校の野心・農民運動は解決されない。二大勢力が存在することで、内部闘争の当事者が外部の支援を取り付ける経路も生まれる。そのため湖南内部の政変は起きる（確定）。[^e031] 1926年の趙恒惕の失脚と唐生智の台頭は史実に準じて発生し、史実で呉佩孚が担った役割を黎元洪と聯合が担う。[^e031]

| 年月 | 出来事 |
|---|---|
| 1925年 | 孫文死去。湖南軍内部の対立が激化 |
| 1926年3月 | 唐生智が趙恒惕政権を打倒 |
| 1926年春 | 葉開鑫らが聯合の支援を受けて反抗 |
| 1926年5月 | 湖南内戦が本格化 |
| 1926年6月 | 唐生智が中華民国に参加 |
| 1926年7月 | 中華民国が北伐を開始 |
| 1926年後半 | 湖南の帰属をめぐり聯合と中華民国が交戦 |

[^e031]

| 項目 | 趙恒惕・葉開鑫側 | 唐生智側 |
|---|---|---|
| 目標 | 既存の省内秩序の維持 | 軍事指導部の刷新 |
| 対外関係 | 聯合との協調 | 中華民国との協力 |
| 社会政策 | 地主・地方有力者と協調 | 農民・労働運動を一定容認 |
| 政治的立場 | 省自治の維持 | 国民革命への参加 |
| 外部支援 | 黎元洪・聯合 | 蒋介石・国民党 |

[^e031]

黎元洪は当初、湖南の自治を尊重する立場をとっていても、政変後は趙恒惕・葉開鑫側を支援する。聯合の介入は中華民国に「革命運動の妨害」という宣伝材料を与え、聯合自身も自治尊重の建前と安全保障の矛盾を抱えることになった。[^e031] この湖南内戦を契機に、聯合は外交・経済共同体から加盟省の共同防衛を担う軍事的共同体へと変質し、黎元洪の権力が急拡大する（確定）。[^e031][^e032]

史実でも1925年秋に湖南軍の内部対立が激化し、1926年3月に唐生智が趙恒惕を失脚させ、春に葉開鑫らが反抗、5月に唐生智が長沙を失い、6月に広州国民政府と提携、7月に国民革命軍の北伐で長沙を奪還した。趙恒惕側は呉佩孚、唐生智側は広州政府の支援を求めた。[^e031]

# 兵力

## 1926年夏の兵力

単位は万人、いずれも本世界線の設定値である。[^e032]

| 陣営 | 勢力 | 兵力 |
|---|---|---:|
| 中華民国側 | 広東・国民革命軍 | 8〜15 |
| | 新桂系 | 5〜8 |
| | 唐生智派湖南軍 | 2〜4 |
| | **合計** | **15〜27** |
| 聯合側 | 湖北軍 | 8〜15 |
| | 両江軍 | 10〜20 |
| | 華北軍 | 12〜20 |
| | 葉開鑫派湖南軍 | 2〜4 |
| | **合計** | **32〜59** |

これらは総兵力であり、湖南・湖北方面に実際に投入できる兵力とは異なる。中華民国は聯合全体には劣勢だが、湖北軍単独に対しては数的優位を得る余地があり、湖南で一定の成功を収めることに無理はない。[^e032]

## 周辺勢力

1926年頃の他勢力の推計は、雲南軍閥6〜12万、四川諸軍閥15〜30万、奉天系（満洲）10〜25万などで、聯合兵力は加盟軍の合計であって統一指揮下にない（検討案）。[^e028][^e030]

## 東南の帰属

孫伝芳の五省聯軍が成立する経路は本世界線に存在しないため、江西・福建は江蘇軍の強固な支配下にあるとは限らず、中華民国はこれらの地域でも勢力を拡大できた。[^e032]

| 地域 | 経済的・政治的条件 | 1926年時点の帰属案 |
|---|---|---|
| 江西 | 長江水運・農業・地方新軍 | 聯合寄りの独立軍閥 |
| 福建 | 海外華僑・沿岸貿易・広東との関係 | 中立〜中華民国寄り（日英通商も重要で内部分裂） |
| 浙江 | 上海金融市場との結びつき | 聯合 |
| 安徽 | 長江下流域・江蘇との結びつき | 聯合 |

[^e032]

## 国共関係への影響

北伐で上海を掌握しないため、史実の上海クーデターは起きない。しかし湖南を占領した時点で、地方軍事指導者（唐生智・李宗仁ら）が共産党の急進的土地改革を認められず、国共対立は発生した。1927年頃、国民党は共産党の活動を大幅に制限しつつ、正式な合作解消には至らない「制限付き合作」とした（確定）。[^e032] 詳細は[中華民国（広州）と国民党・共産党](../diplomacy/republic-of-china-canton.md)を参照。

## 黎元洪の死と膠着の固定化

1928年6月3日の[武昌公邸火災事件](wuchang-residence-fire-1928.md)で黎元洪が死亡すると、湖南は中華民国側の軍事圧力が強まる地域となった（検討案）。[^e033] しかし聯合も崩壊せず、軍事協議会による暫定集団指導体制へ移行した。北伐の継続は聯合の弱点であると同時に、加盟軍閥が単独で中華民国と対峙したくないため、聯合の解体を防ぐ要因にもなった。[^e035]

## 中華民国側の動揺

北伐が思うように進まなければ中華民国側もごたつく（ユーザーの指摘）。[^e036] 蒋介石は南京・上海の財政基盤を得られず、広西軍・湖南軍への依存とソ連援助の必要から他勢力を排除できない。新桂系との対立は軍事予算の配分が争点となり、1929年頃に蒋介石が一時辞任する展開や、蒋桂戦争相当の限定的内戦で蒋介石が決定的勝利を得られない展開が検討された（検討案）。[^e036] 世界恐慌は広東の貿易収入・華僑送金・地方税収・外国融資を直撃し、軍人給与の支払いと北伐の継続を困難にした。[^e036][^e039]

# 結果

| 項目 | 帰結（1930年） |
|---|---|
| 北伐 | 部分的成功 |
| 湖南 | 大部分が中華民国に帰属 |
| 湖北・江蘇 | 聯合が維持 |
| 江西・福建 | 帰属係争・中華民国の影響力拡大 |
| 蒋介石 | 中華民国の実質的な軍事指導者（地位は動揺） |
| 黎元洪 | 1928年に死去 |
| 国共合作 | 制限付きで存続 |
| 中国共産党 | 党員5〜10万人、独立軍事力は限定的 |
| 中国統一 | 未達成 |

[^e032][^e039]

中華民国にとって北伐は失敗ではない。支配人口・領域・財政基盤を大幅に拡大し、広東の地方政権から中国南部の有力政権へ成長した。しかし長江流域の主要な工業・金融都市を掌握できず、全国統一には至らなかった。[^e032] 1930年の中国は「**経済的には外国資本を介して結合し、政治的には分裂し、軍事的には膠着している**」。聯合にも中華民国にも現状打破の能力がなく、現状を恒久的に受け入れる意思もない。[^e039]

この戦争の特徴は、**双方とも国家統一を実現できない理由が、相手の強さだけでなく自陣営の政治構造そのものにある**ことである。聯合は地方軍閥の軍権を統合できず、中華民国は国共合作と地方軍閥の独立性を解消できない。[^e032]

# 却下・修正された案

* **湖南政変を北伐の分岐点として改変する案**：1926年の湖南政変を「北伐の最初の分岐点」として起き方を変える整理（E30）は、ガス抜きの経路がない以上政変自体は起きるとの指摘を受け、政変と北伐開始までは史実準拠とされた。[^e030][^e031]
* **湖北進出の成否を未確定とする整理**：E31時点で未確定だった湖南全域掌握と湖北進出は、E32で「湖南大部分獲得・湖北で膠着」と定まった。[^e031][^e032]
