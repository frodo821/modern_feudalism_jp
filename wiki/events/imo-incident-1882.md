# 概要

1882年（本世界線の明治16年）7月、朝鮮で壬午軍乱が勃発し、日本公使館が襲撃された。日本とアメリカ以外の環境は史実どおりという本世界線の原則により、朝鮮の反乱そのものは史実と同様に起こる。しかし日本の早い近代化によって、軍乱は史実以上にエスカレートし、日本軍と清軍が漢城周辺で対峙する「漢城危機」となった。[^u047]

この段階の清には日本と全面衝突する理由が乏しく、日本にもエスカレートさせる利点が乏しかったため、危機は外交交渉による「手打ち」で収拾された。ただしその事実は火種として燻り続け、後年「一歩間違えば日清戦争だった」と語られる事件となった。[^u048]

1882年の妥協は、戦争を回避した成功体験であると同時に、朝鮮問題を日清両国間の勢力争いとして固定化する契機ともなった。以後の危機で政治家たちは、同じ1882年の前例を和平論と強硬論の双方の根拠として引用することになる。[^u048]

# 背景

## 1882年の日本

| 分野 | 本世界線での条件 |
|---|---|
| 帝国軍 | 1860年代から約20年間整備を継続 |
| 海軍 | 海防政策と領主系造船業の発展によって拡充 |
| 国内経済 | 領主間競争と[全国標準化](/institutions/national-standardization.md)による市場統合 |
| 政治 | 成文憲法と[元老院](/institutions/genroin.md)・[衆議院](/institutions/house-of-representatives.md)が存在 |
| 対外外交 | 欧米との[条約改正](/diplomacy/treaty-revision.md)が史実より進展している可能性 |
| 対朝鮮政策 | [江華島事件](/events/ganghwa-island-incident.md)を経て開国させ、外交関係を確立済み |

[^u047]

日本側にとって壬午軍乱は、在外公館の襲撃と自国民の殺害を伴う事件であり、責任追及・外交官保護・賠償請求の理由があった。武家出身の領主が元老院で強い地位を占め外交的威信を重視するため、軍事的対抗措置を求める政治的圧力も生じた。史実との最大の違いは、**日本側が清国軍との直接衝突を避ける必要を、史実ほど強く感じなかった可能性**である。ただし軍備が強いことと清国との戦争を望むことは別であり、両院が戦争の費用と危険をどう評価するかも条件となった。[^u047]

## 軍乱の性格

壬午軍乱は旧式軍人の待遇問題を発端とする軍事反乱であり、農村社会の不満や東学の組織的活動を背景とする1894年の東学農民革命とは社会的基盤が異なる。日本の経済進出は農民の不満や排外運動を早める要因にはなりうるが、軍乱の拡大と東学農民革命の12年前倒しとは区別される。[^u047]

# 経過

## 漢城危機（想定経過）

| 時期 | 出来事 |
|---|---|
| 7月 | 壬午軍乱。日本公使館が襲撃され、日本政府は朝鮮へ艦隊と陸兵を派遣 |
| 8月 | 清軍と日本軍が漢城周辺で対峙。清国は朝鮮王朝の秩序回復を主張し、日本は外交官保護と事件の責任追及を要求 |
| 8〜9月 | 局地的な衝突。部隊間の偶発的交戦、あるいは治安維持権をめぐる武力衝突（検討案） |
| 秋 | 撤兵・賠償・公使館警備で日清が合意し、全面戦争を回避 |

[^u048]

## 対峙の構図

最大の分岐は清国軍が到着した時点にあった。日本軍は公使館の保護を名目に漢城へ進出し、反乱の鎮圧に加えて朝鮮政府の責任者の処罰まで要求しうる。一方、清軍は朝鮮王朝の秩序回復と宗主権を根拠に介入する。両軍の指揮官は誰に治安維持と政治的処分の権限があるかを争い、**双方とも「朝鮮政府を保護している」と主張できてしまう**。しかも先に実力を行使した側が朝鮮政府への影響力を確保できる状況であり、日本が清軍の撤兵まで要求すれば局地的対立が戦争へ発展する経路があった。[^u047]

## 三つの展開と「手打ち」

| 展開 | 内容 |
|---|---|
| A：史実に近い外交的妥協 | 両軍派遣、直接戦闘は回避。日本は賠償と公使館警備権、清は政治的影響力を強化 |
| B：限定的な日清武力衝突 | 交戦と増援の後、列強の調停で全面戦争回避。両国軍が朝鮮に残る |
| C：1882年日清戦争 | 日本が大規模軍事行動を承認。ただし清の北洋海軍等の構成は1894年と異なり、別の戦争になる |

[^u047]

本世界線では、清と日本の双方に全面衝突の利点が乏しいことから、A〜Bの範囲で手打ちとなった。局地戦を起こすかどうかは一つの選択として残されているが、仮に直接交戦が起きても双方に撤兵する理由がある。[^u048]

清国と日本の利害は完全には対立していなかった。清は朝鮮王朝の秩序を回復して影響力を維持したく、日本は公使館の安全を確保して外交上の要求を実現したかった。朝鮮の政治体制そのものをめぐって対立していても、直ちに全面戦争を行わなければならないわけではなかった。日本軍が史実以上に強いことは清国に慎重な交渉の理由を与えたが、日本の側も戦争を拡大すれば他の列強が介入する危険を抱えていた。[^u048]

## 日清漢城協定（検討案）

収拾策として、史実の1885年天津条約に近い取り決めが1882年の段階で前倒しで成立する余地がある。[^u048]

> **1882年日清漢城協定**（架空の協定）
> 第一条　日本国及清国ハ、朝鮮国ニ派遣セル軍隊ヲ、定メタル期限内ニ撤収ス。
> 第二条　朝鮮国ノ内乱其ノ他重大ナル事変ニ際シ、両国ノ一方ガ派兵ヲ必要トスルトキハ、他方ニ事前通告ヲ為ス。
> 第三条　両国ハ朝鮮国ノ軍制整備ニ関シ、相互ノ合意ナク軍事顧問ヲ派遣セズ。
> 第四条　朝鮮国政府ノ国内秩序維持及外交官保護ノ責任ヲ確認ス。

影響力を強めようとしている1882年の清に対等な撤兵・通告義務を認めさせるには、日本側の相応の交渉力が必要である。また朝鮮政府の意思が十分に反映されない日清間の協定は、朝鮮の主権を制約するものでもある。[^u048]

これとは別に、史実の済物浦条約に相当する日朝間の取り決め（謝罪・賠償・日本公使館警備兵の漢城駐留）も成立したとみなされ、この公使館警備権は1886年の日本軍派遣の根拠の一つとなった。[^u059]

# 影響

## 双方の強硬派の不満

- **日本**：元老院の武家領主層を中心に「帝国軍を動員しておきながら、なぜ清国軍の朝鮮介入を阻止できなかったのか」という政府批判が起こる。慎重派は全面戦争を避けつつ外交官の安全と賠償を確保した成果を主張する。
- **清**：伝統的な属邦である朝鮮について、日本に派兵通告などの権利を認めたことへの不満が生じる。

協定で当面の危機は収まっても、日清両国が朝鮮にどの程度の権限を持つかという根本問題は未解決のまま残った。[^u048]

## 火種としての前例

1882年の危機によって、日清両国は互いの軍事力を現地で確かめ合った。双方の政府は全面戦争の危険を強く認識したが、同時に日本では「清国の介入を許した」、清国では「日本に譲歩した」という不満が蓄積した。後の危機では、一方が「前回は戦争を避けられたのだから今回も交渉すべきだ」と主張し、他方が「前回の譲歩によって相手がさらに介入するようになった」と主張する。**同じ1882年の妥協が、和平論と強硬論の両方の根拠になった**のである。[^u048]

## 軍拡競争の起点

危機を経て、清では李鴻章が日本への警戒を強めて北洋海防の追加予算を要求し、日本でも清軍の行動を直接観察した元老院で具体的な軍備拡張要求が出た。これが1882〜1885年の日清軍拡競争と、清仏戦争下での清の二正面問題の出発点となった（[甲申政変（本世界線）](/events/gapsin-coup-1884.md)参照）。[^u049]

## 1884年の「助平心」

1882年の妥協に対する日本側の不満は、清仏戦争が始まると「1882年には清国との全面戦争を避けるために譲歩した。しかし今は清国が南方でフランスと戦っている」という議論となり、1884年の積極介入を後押しした。1882年に戦争回避のため結んだ協定を、1884年に日本自身が破る可能性も生じた。[^u050]

## 後年の参照

- 清朝中央と李鴻章は、1882年の漢城危機で日本の軍事力を目撃していたことが、1885年以降の対日判断の材料となった。[^u057]
- 1882年の公使館襲撃は、1884年・1886年に続く公使館襲撃の最初の例として、日本が朝鮮政府の治安能力に疑問を抱く根拠となった。[^u058]
- 高宗は「1882年に日本が清と対峙した」ことを、日本が清と武力衝突してでも王位を守るという判断材料の一つとした（[袁世凱逮捕事件](/events/yuan-shikai-arrest.md)参照）。[^u061]

| 項目 | 史実 | 本世界線 |

| 発端 | 1882年7月、旧式軍隊の待遇不満・給与遅配。新式軍隊の日本人軍事教官殺害、日本公使館襲撃 | 同じ |
| 日清両軍 | 両軍とも朝鮮へ派遣、直接交戦なし | 漢城周辺で対峙、局地衝突の可能性（検討案） |
| 清の行動 | 大院君を拘束し天津へ連行、朝鮮への政治介入を強化 | 同様の介入が想定される（確定せず） |
| 日朝間の決着 | 済物浦条約（謝罪・賠償・公使館警備兵駐留） | 相当の取り決めが成立 |
| 日清間の決着 | なし（天津条約は1885年） | 天津条約相当の「日清漢城協定」が前倒しで成立（検討案） |

同年5月には米朝修好通商条約が結ばれている。本世界線の米国は南北戦争を経ておらず日本との関係が史実と異なる可能性があり、日清対立に際して日本への外交支援・仲介、あるいは戦争抑制のいずれをとるかは定まっていない。[^u047]

# 却下・修正された案

- **1882年は日本が介入を限定し外交決着とする案**：当初は1894年の日清戦争への道筋を維持するため、1882年には日本が軍事介入を限定する設定が提示された。しかし「壬午軍乱がそのままエスカレートする可能性が高い」という前提の採用により、史実以上の日清軍事危機を経て手打ちに至る形に修正された。[^u037][^u047]
- **1894年の日清戦争を当然視する前提**：漢城危機の検討を機に、1894年開戦を所与とする前提は外された。最終的に本世界線の日清戦争は1887年に始まる（[日清戦争（1887〜1889）](/events/sino-japanese-war.md)）。[^u047]
