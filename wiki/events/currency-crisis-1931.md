# 概要

1931年、オーストリアのクレディタンシュタルト危機に始まる中欧の金融危機は、本世界線でも史実に準じて発生し、ドイツの銀行危機を経てロンドン金融市場へ波及した。英国は9月21日頃に金本位制を離脱する。米国から中欧への資本供給の停止やドイツの賠償問題には大きな歴史改変がないため、危機の発生までは史実と変わらない。[^e040][^e042]

史実と異なるのは、危機が英国に波及した後の展開である。本世界線の日本は、第一次世界大戦で英国に対する巨額の**円建て**貿易信用・売掛債権を得た債権国であり、しかも1925年に金平価と金兌換を法的に廃止して管理通貨制へ移行している（[金本位制離脱と管理通貨制](/economy/gold-standard.md)）。そのため日本は、英国の信用秩序と日英間の貿易金融は支援するが、英国の金本位制の維持そのものには関心が薄い。1931年の日英金融協議の主題は「**英国の金本位制を救済するのではなく、円・ポンド間の為替相場と債務決済を安定させること**」となる。[^e041][^e042]

日本は「巨大な対外純債権国ではあっても、必ずしも巨大な金準備保有国ではない」。1920年代の黒字の一部を金ではなく資源の現物備蓄（[戦略資源備蓄制度](/economy/strategic-stockpile.md)）に向けてきたためで、英国を金・ドルで救う能力は対外純資産の規模ほど大きくない。日本の支援は円建て信用・既存債務の借換え・英国経済圏からの資源買付という形をとり、英国離脱後の日英協議は債務決済・為替安定・資源貿易を一体化した経済協定へ発展していく。これが1932年の[オタワ帝国経済会議](/diplomacy/ottawa-conference-1932.md)へつながる。[^e043][^e044]

# 背景

## 1925年以降の日本の通貨制度

日本は1917年に金輸出を停止したのち、1922年に旧平価での復帰を断念し、1925年に金平価と銀行券の金兌換義務を「停止」ではなく「廃止」して、金輸出入を原則自由化した（確定）。金は通貨発行の法的な裏付けではなく、国際決済のための準備資産である。詳しくは[金本位制離脱と管理通貨制](/economy/gold-standard.md)を参照。[^e041]

この結果、1931年は「日英が揃って金本位制の外に出る年」となる。日本は英国の金本位制離脱を、通貨制度の破綻としてだけでなく、自国が既に経験した制度転換として受け止める。[^e040][^e041]

## 日本の対英債権

日本の対英債権の中心は政府間の戦債ではなく、大戦中の物資供給に伴う円建ての貿易信用・売掛債権である。1914〜18年の累積経常黒字65億円のうち40億円がこの対英債権となり、[日英戦時債務整理](/diplomacy/war-debt-settlement.md)による代物弁済などを経ても、その相当部分が1930年代まで残る（1937年の残存・借換分は25億円）。純対外資産は1929年末に78億円であった。詳細は[円建て対外債権と円の国際化](/economy/yen-claims.md)を参照。[^e100]

長期の債権や継続的な商業信用は、危機の際にも直ちにロンドン市場から流出する資金にはならない。英国にとって日本の債権は、危機の原因にも救済手段にもなりうる。[^e042]

## フーヴァー・モラトリアムと日本の対英債権

フーヴァー・モラトリアムは政府間の戦債・賠償金の支払いを一年間停止する構想で、民間の商業債権までは止めない。日本の対英債権は物資供給の売掛金・商業信用の性格が強いため、その大部分はモラトリアムの直接の対象にならない（検討案）。[^e040]

| 債権の種類 | モラトリアムとの関係 |
|---|---|
| 米国の対英政府間戦債 | 対象 |
| 英国の対独賠償請求権 | 対象 |
| 日本の対英政府間戦債 | 原則対象 |
| 日本の対英商業債権 | 原則対象外 |
| 日本の対英民間投資 | 対象外 |

[^e040]

このため英国は、米国との戦債問題とは別に、日本と独自の債務・決済協議を行う必要に迫られる。[^e040]

## 英国の対外資産・負債の構造（検討案）

史実の英国も対外純債権国だったが、流動性の高い短期対外債務を抱える一方、保有する対外資産には容易に回収できないものが多かった。本世界線ではこれに日本との大規模な信用関係が加わる。

| 英国の対外資産・負債 | 特徴 |
|---|---|
| 対ドイツ・中欧債権 | 金融危機によって回収困難 |
| 対米政府債務 | ドル建て・政府間戦債 |
| 対日債務 | 円建て商業債権を起源とする債務が中心 |
| 海外からのポンド預金 | 短期間で流出する可能性 |
| 中国等への投資 | 長期的な収益資産だが流動性が低い |
| 金・外貨準備 | 国際決済に利用可能 |

[^e042]

ドイツが対外短期債務の支払いを停止すると、ドイツに融資していた英国の金融機関が流動性不足に陥り、ポンドへの信用不安が広がる。この経路は史実と同じである。[^e042]

## 日本は英国の金本位制を救済しない

史実では1931年8月初頭に米仏中央銀行が合計約5,000万ポンド、8月末にも約8,000万ポンドの追加信用を英国に供与したが、資金流出は止まらなかった。本世界線では日本も信用供与を求められる。しかし日本は既に金本位制を制度的に廃止しており、その維持を国際金融秩序の前提とは考えていない。[^e042]

| 支援の目的 | 日本の対応（検討案） |
|---|---|
| 英国の金準備維持 | 消極的 |
| ポンドの対金平価維持 | 消極的 |
| 英国金融機関の破綻防止 | 積極的 |
| 円建て対英債権の保全 | 積極的 |
| 日英間の貿易金融維持 | 積極的 |
| 円・ポンド相場の安定 | 積極的 |

[^e042]

日本は**英国を救済する意思はあっても、英国の金本位制を救済する意思は必ずしもない**。日本の金融当局は、金本位制維持のために金やドルを消費し続けることにむしろ反対する。日本が債権回収を猶予することと英国の金本位制を維持することは別の問題であり、英国が金本位制のために金融引締めを続けて日英貿易が縮小するほうが日本には望ましくない。[^e040][^e042]

## 円建て信用供与とその限界（検討案）

日本は自国通貨建てでなら英国へ信用を供与しやすい。英国の銀行が日本企業に円建ての支払いを行う必要があるとき、日本の中央銀行や金融機関が円建て信用を供与すれば、決済を続けられる。

1. 日本の中央銀行・金融機関が英国の銀行・企業へ円建て信用を供与する。
2. 英国側はそれで円建て債務や輸入代金を決済する。
3. 日本の債権者・輸出企業は債権を回収し、通商が継続する。

ただしこれは円建て債務の決済には有効でも、ポンドの金兌換を維持する資金には直接ならない。英国が円を売ってドルや金を買えば円相場に下落圧力がかかるため、日本は信用の用途を日英間の決済と既存債務の借換えに限定する。[^e042]

前述のとおり日本の金・ドル準備は決済に必要な程度にとどまるので、日本が米仏と並ぶ「金本位制の救済国」になることはない。英国への支援は、円建て信用・英国圏からの資源購入・既存債務の借換え、さらに英国経済圏からの資源買付保証という形をとりうる。[^e043]

## 英国の離脱時期

英国の離脱時期には三つの経路が考えられた。

| 経路 | 成立条件 |
|---|---|
| 1931年7〜8月に離脱 | 日本が早期離脱を条件に金融支援を提案 |
| 史実通り9月に離脱 | 英国政府・イングランド銀行が金本位制維持を優先 |
| 1931年末以降まで維持 | 日本が金・ドルによる大規模な支援を実施 |

[^e042]

日本が早期離脱を求めても、金本位制をポンドの国際通貨としての地位の支えとみるイングランド銀行やシティが容易に受け入れるとは考えにくい。一方で日本の存在は、金本位制を離脱しても主要な貿易・金融関係を維持できるという見通しを英国に与える。結論として、**英国の離脱は史実と同程度の時期（9月）に起きるが、離脱後の金融政策には日本との事前協議が反映される**（検討案）。[^e042]

# ポンド下落と円建て債務負担

英国が金本位制を離脱してポンドが円に対して下落すると、円建て元本が変わらなくても、ポンドで測った英国の返済負担は増える。対円下落率を d% とすると、離脱前を100とした負担は 100 ÷ (1 − d/100) となる。[^e042]

| 対円ポンド下落率 | ポンド換算の債務負担（離脱前＝100） |
|---|---:|
| 10% | 111.1 |
| 20% | 125.0 |
| 30% | 142.9 |
| 50% | 200.0 |

（試算値）[^e042]

日本は円建てで債権を持つため、形式上は債権価値を維持できる。円建て対英債権は為替による円換算元本の減少を免れ、これは日本にとって重要なリスク軽減要因である。しかし英国の返済能力が落ちれば不良債権化の危険が増し、信用リスクは残る。またポンドに対する円高は日本の輸出産業にも不利であり、日本にも円高を抑える動機がある。英国はポンドの無秩序な下落を防ぎたく、日本は円の対ポンド相場の急騰を望まない。ここで日英の利害が一致する。[^e041][^e042][^e100]

保有資産の種類によって影響は異なる。

| 保有資産 | ポンド下落時の影響 |
|---|---|
| 円建て対英債権 | 為替による円換算元本の減少を回避 |
| ポンド建て預金・債券 | 円に対してポンドが下落すれば評価損 |
| 英国企業の株式 | 為替と企業価値の双方に影響される |
| 海外鉱山・油田権益 | 資源価格下落による収益・評価額の低下 |

[^e100]

1930〜32年の日本の経常収支は計＋5億円（1930年＋3.0、1931年＋1.0、1932年＋1.0億円）で、英国の金本位制離脱と世界的な資産価格下落による評価損・債権償却等を純額−4億円とすると、純対外資産は1929年末78億円から1932年末79億円となる。危機を経ても日本の対外純資産はほぼ横ばいで済む。[^e100]

# 日英の金融協力

## 日英金融協定案（検討案）

1931年の危機を契機に、次のような金融協定が検討される。

| 項目 | 内容案 |
|---|---|
| 相互信用供与 | 両国の中央銀行による相互通貨信用 |
| 為替介入 | 円・ポンド相場の急変時に協調介入 |
| 既存債務 | 返済期限の延長・借換え |
| 貿易金融 | 円及びポンド建て手形の割引制度 |
| 外貨準備 | 相互通貨建ての流動性の高い資産を保有 |
| 金兌換 | 相互に要求しない |
| 為替相場 | 固定平価ではなく協議による安定化 |

[^e042]

日本は円をポンドに完全に連動させない。対米貿易や中国での経済活動も考慮する必要があるため、当面は管理変動相場の下で協調する程度にとどまる。日英通貨協力は、金を介した固定相場制ではなく、中央銀行間の信用供与と相互決済制度を中心に発達する。[^e041][^e042]

## 1931年秋の日英緊急金融・通商協定（検討案）

英国の金本位制離脱後、日英はまず緊急の金融・通商協定を結ぶ。日本は英国の円建て債務について返済期限の延長や借換えを認め、英国及び帝国各地域からの資源購入を拡大する。英国は日本からの工業製品輸入について急激な関税引上げを避けることを約束する。[^e044]

| 日本側の措置 | 英国側の措置 |
|---|---|
| 円建て債務の借換え | 日本企業との既存契約の維持 |
| 円建て貿易信用の供与 | 対日輸入制限の抑制 |
| 資源の長期買付契約 | 資源供給の安定化 |
| ポンド買入れ・為替介入 | 円・ポンド相場の安定化協力 |
| 英国系企業への投資継続 | 日本資本に対する差別の回避 |

[^e044]

この協定で日英双方は恐慌への対応を進められるが、英国が帝国特恵制度を導入する際の制約にもなる。日本の資源買付は英国経済圏に円を供給し、英国が円建て債務を新規借款ではなく貿易によって返済できる構造をつくる。[^e043][^e044]

この時期、1930年夏から交渉されていた日英海上通商防衛協定の追加議定書は、欧州通貨危機を受けて経済・金融協力が優先されたため、締結が1932年秋〜冬にずれ込む（検討案）。[^e052]

## 1931年末の国際通貨秩序（検討案）

1931年末には三つの通貨圏が形成され始める。

| 通貨圏 | 中心通貨 | 特徴 |
|---|---|---|
| 日英通貨協調圏 | 円・ポンド | 管理通貨・貿易金融・相互信用 |
| 米国通貨圏 | ドル | 金本位制維持 |
| 欧州金本位制諸国 | フランなど | 金平価維持・通貨防衛 |

[^e042]

このほかドイツなど、為替管理によって国際決済を統制する諸国が存在する。[中国諸省聯合](/diplomacy/china-federation.md)や外国施政地域では円・ポンドによる貿易金融の重要性が増す一方、中国の銀本位制との為替関係も問題になる。[^e042] 米国は1933年に金本位制を停止し、日本（1925年）・英国（1931年）・米国（1933年）の順に金本位制を離れることになる。[^e054]

なお、日本はスターリング圏に加盟しない。英帝国通貨圏と日本の円は、日英間の信用供与と為替安定協定によって相互に接続される二つの通貨圏であり、円をポンドに従属させる制度ではない。[^e044]

| 項目 | 英帝国通貨圏 | 日本 |
|---|---|---|

# 影響

- **日英関係の段階的制度化**：1930年のロンドン会議で海上通商の防衛関係が、1931年の通貨危機で金融協力が、1932年のオタワ会議で資源貿易と開発投資の関係が制度化される。軍事・通貨・関税のいずれも単一の体制に統合されない「緩やかな結合」が日英関係の特徴となる。[^e051] オタワ会議での日本の扱いは[オタワ帝国経済会議（1932）と日本](/diplomacy/ottawa-conference-1932.md)を参照。
- **一次産品地域の購買力**：日本の資源輸入・備蓄・信用供与は、恐慌で一次産品価格の下落に苦しむ英帝国の資源輸出地域の購買力を支え、それが英日の工業製品需要に戻る循環をつくる。日本製品を排除する帝国特恵政策には自己矛盾が生じる。[^e046]
- **国内の恐慌対策**：日本は管理通貨制の下で史実より早く金融緩和に動け、公債による公共投資と備蓄拡大で国内需要を創出する。詳しくは[1925年財政原則と恐慌期の公共投資](/economy/fiscal-principles-1925.md)を参照。[^e046]

# 却下・修正された案

- **日本が米仏と並んで英国の金本位制を救済する案**：E42 で論点として示されたが、E43 で日本の黒字が金準備ではなく資源備蓄と対外資産に向けられてきたと整理され（E44 で確定）、日本の金・ドル準備は決済に必要な程度にとどまることになった。このため日本は円建て信用の供与と資源買付に特化し、金・ドルによる大規模支援で英国の金本位制を1931年末以降まで延命させる経路は採られない。[^e042][^e043][^e044]
- **英国の金本位制離脱そのものを回避する可能性**：E40 で最大の検討事項とされたが、日本自身が金本位制の外にあり英国に維持を求める理由が乏しいことから、離脱は史実と同程度の時期に起きるとされた。[^e040][^e042]
- **日本の1917年以降の通貨制度が「正式には未確定」とされていた点**：E40 での指摘を受け、E41 で1925年の金本位制復帰断念・金兌換義務と金平価の廃止が確定した。[^e040][^e041]

# 未決の論点

- 1931年に日本が英国へ供与できる金・ドル資産の具体的な規模（「必要な決済能力を確保する程度」とされるにとどまる）。[^e042][^e043]
- 英国離脱後のポンドの対円下落率と、1930年代の円・ポンド・ドルの為替相場の水準・決済制度。1937年時点でも検討事項として残る。[^e042][^e103]
- 日英金融協定・緊急金融・通商協定の正式名称、締結時期、条文の具体的内容。[^e042][^e044]
- 日本の対英債権のうち、政府間戦債としてモラトリアムの対象となる部分の有無と規模。[^e040]
- 中国の銀本位制と円・ポンドの為替関係。[^e042]
