# 概要

1931年、オーストリアのクレディタンシュタルト危機に始まる中欧の金融危機は、本世界線でも史実に準じて発生し、ドイツの銀行危機を経てロンドン金融市場へ波及した。英国は9月21日頃に金本位制を離脱する。米国から中欧への資本供給の停止やドイツの賠償問題には大きな歴史改変がないため、危機の発生までは史実と変わらない。[^e040][^e042]

史実と異なるのは、危機が英国に波及した後の展開である。本世界線の日本は、第一次世界大戦で英国に対する巨額の**円建て**貿易信用・売掛債権を得た債権国であり、しかも1925年に金平価と金兌換を法的に廃止して管理通貨制へ移行している（[金本位制離脱と管理通貨制](../economy/gold-standard.md)）。そのため日本は、英国の信用秩序と日英間の貿易金融は支援するが、英国の金本位制の維持そのものには関心が薄い。1931年の日英金融協議の主題は「**英国の金本位制を救済するのではなく、円・ポンド間の為替相場と債務決済を安定させること**」となる。[^e041][^e042]

日本は「巨大な対外純債権国ではあっても、必ずしも巨大な金準備保有国ではない」。1920年代の黒字の一部を金ではなく資源の現物備蓄（[戦略資源備蓄制度](../economy/strategic-stockpile.md)）に向けてきたためで、英国を金・ドルで救う能力は対外純資産の規模ほど大きくない。日本の支援は円建て信用・既存債務の返済繰り延べと借換え・英国経済圏からの資源輸入という形をとり、英国離脱後の日英協議は、1931年秋に日英両政府のあいだで結ばれた**日英緊急金融・通商協定**に結実する。協定は約25億円規模の円建ての対英支援信用、ポンド下落への対応（返済繰り延べ・信用補完・協調介入）、通商条項（英連邦からの固定輸入枠・最恵国待遇の確認・非関税優遇措置）を一体として定め、協調介入の取決めによって通貨スワップ協定に近い性格も帯びた。これが1932年の[オタワ帝国経済会議](../diplomacy/ottawa-conference-1932.md)へつながる。[^n4][^e043][^e044]

# 背景

## 1925年以降の日本の通貨制度

日本は1917年に金輸出を停止したのち、1922年に旧平価での復帰を断念し、1925年に金平価と銀行券の金兌換義務を「停止」ではなく「廃止」して、金輸出入を原則自由化した。金は通貨発行の法的な裏付けではなく、国際決済のための準備資産である。詳しくは[金本位制離脱と管理通貨制](../economy/gold-standard.md)を参照。[^e041]

この結果、1931年は「日英が揃って金本位制の外に出る年」となる。日本は英国の金本位制離脱を、通貨制度の破綻としてだけでなく、自国が既に経験した制度転換として受け止める。[^e040][^e041]

## 日本の対英債権

日本の対英債権の中心は政府間の戦債ではなく、大戦中の物資供給に伴う円建ての貿易信用・売掛債権である。1914〜18年の累積経常黒字65億円のうち40億円がこの対英債権となり、[日英戦時債務整理](../diplomacy/war-debt-settlement.md)による代物弁済などを経ても、その相当部分が1930年代まで残る（1937年の英国向け債権50億円のうち、大戦期の戦時債権の残存・借換分は25億円で、残る25億円は1931年の危機の際に日本が供与した円建ての対英支援信用とその借換債である）。[^n1][^e100][^p091] 純対外資産は1929年末に78億円であった。詳細は[円建て対外債権と円の国際化](../economy/yen-claims.md)を参照。[^e100]

長期の債権や継続的な商業信用は、危機の際にも直ちにロンドン市場から流出する資金にはならない。英国にとって日本の債権は、危機の原因にも救済手段にもなりうる。[^e042]

[^e043][^e044]

## フーヴァー・モラトリアムと日本の対英債権

フーヴァー・モラトリアムは政府間の戦債・賠償金の支払いを一年間停止する構想で、民間の商業債権までは止めない。日本の対英債権は物資供給の売掛金・商業信用の性格が強いため、その大部分はモラトリアムの直接の対象にならなかった。[^n2][^e040]

| 債権の種類 | モラトリアムとの関係 |
|---|---|
| 米国の対英政府間戦債 | 対象 |
| 英国の対独賠償請求権 | 対象 |
| 日本の対英政府間戦債 | 原則対象 |
| 日本の対英商業債権 | 原則対象外 |
| 日本の対英民間投資 | 対象外 |

[^e040]

このため英国は、米国との戦債問題とは別に、日本と独自の債務・決済協議を行う必要に迫られた。[^e040]

## 英国の対外資産・負債の構造

史実の英国も対外純債権国だったが、流動性の高い短期対外債務を抱える一方、保有する対外資産には容易に回収できないものが多かった。本世界線ではこれに日本との大規模な信用関係が加わる。[^n2]

| 英国の対外資産・負債 | 特徴 |
|---|---|
| 対ドイツ・中欧債権 | 金融危機によって回収困難 |
| 対米政府債務 | ドル建て・政府間戦債 |
| 対日債務 | 円建て商業債権を起源とする債務が中心 |
| 海外からのポンド預金 | 短期間で流出する可能性 |
| 中国等への投資 | 長期的な収益資産だが流動性が低い |
| 金・外貨準備 | 国際決済に利用可能 |

[^e042]

ドイツが対外短期債務の支払いを停止すると、ドイツに融資していた英国の金融機関が流動性不足に陥り、ポンドへの信用不安が広がる。この経路は史実と同じである。[^e042]

## 日本は英国の金本位制を救済しない

史実では1931年8月初頭に米仏中央銀行が合計約5,000万ポンド、8月末にも約8,000万ポンドの追加信用を英国に供与したが、資金流出は止まらなかった。本世界線では日本も信用供与を求められた。しかし日本は既に金本位制を制度的に廃止しており、その維持を国際金融秩序の前提とは考えていない。[^e042]

| 支援の目的 | 日本の対応[^n2] |
|---|---|
| 英国の金準備維持 | 消極的 |
| ポンドの対金平価維持 | 消極的 |
| 英国金融機関の破綻防止 | 積極的 |
| 円建て対英債権の保全 | 積極的 |
| 日英間の貿易金融維持 | 積極的 |
| 円・ポンド相場の安定 | 積極的 |

[^e042]

日本は**英国を救済する意思はあっても、英国の金本位制を救済する意思は必ずしもない**。日本の金融当局は、金本位制維持のために金やドルを消費し続けることにむしろ反対する。日本が債権回収を猶予することと英国の金本位制を維持することは別の問題であり、英国が金本位制のために金融引締めを続けて日英貿易が縮小するほうが日本には望ましくない。[^e040][^e042]

## 円建て信用供与とその限界

日本は自国通貨建てでなら英国へ信用を供与しやすかった。[^n2] 英国の銀行や企業が日本の債権者・輸出企業に円建ての支払いを行う必要があるとき、円建ての信用があれば決済を続けられる。

1. 日本が英国へ円建て信用を供与する。
2. 英国側はそれで円建て債務や輸入代金を決済する。
3. 日本の債権者・輸出企業は債権を回収し、通商が継続する。

ただしこれは円建て債務の決済には有効でも、ポンドの金兌換を維持する資金には直接ならない。英国が円を売ってドルや金を買えば円相場に下落圧力がかかるため、円建て信用は性格上、日英間の決済と既存債務の借換えに充てられるものであった。[^e042] 1931年秋の協定では、この信用は日本政府から英国政府への政府間の信用として供与され、英国内のどの金融機関・企業に資金を回すかは英国政府の判断に委ねられた（後述）。[^n4]

前述のとおり日本の金・ドル準備は決済に必要な程度にとどまるので、日本が米仏と並ぶ「金本位制の救済国」になることはなかった。英国への支援は、円建て信用・既存債務の返済繰り延べと借換えの支援・英国経済圏からの資源輸入という形をとり、資源輸入は協定で英連邦全体からの固定輸入枠として約束された。[^n4][^e043]

## 英国の離脱時期

英国の離脱時期には、理論上三つの経路がありえた。

| 経路 | 成立条件 |
|---|---|
| 1931年7〜8月に離脱 | 日本が早期離脱を条件に金融支援を提案 |
| 史実通り9月に離脱 | 英国政府・イングランド銀行が金本位制維持を優先 |
| 1931年末以降まで維持 | 日本が金・ドルによる大規模な支援を実施 |

[^e042]

日本が早期離脱を求めても、金本位制をポンドの国際通貨としての地位の支えとみるイングランド銀行やシティが容易に受け入れるとは考えにくい。一方で日本の存在は、金本位制を離脱しても主要な貿易・金融関係を維持できるという見通しを英国に与える。結局、**英国の離脱は史実と同程度の時期（9月）に起きたが、離脱後の金融政策には日本との事前協議が反映された**。[^n2][^e042]

# ポンド下落と円建て債務負担

英国が金本位制を離脱してポンドが円に対して下落すると、円建て元本が変わらなくても、ポンドで測った英国の返済負担は増える。対円下落率を d% とすると、離脱前を100とした負担は 100 ÷ (1 − d/100) となる。[^e042]

| 対円ポンド下落率 | ポンド換算の債務負担（離脱前＝100） |
|---|---:|
| 10% | 111.1 |
| 20% | 125.0 |
| 30% | 142.9 |
| 50% | 200.0 |

（試算値）[^e042]

日本は円建てで債権を持つため、形式上は債権価値を維持できる。円建て対英債権は為替による円換算元本の減少を免れ、これは日本にとって重要なリスク軽減要因である。しかし英国の返済能力が落ちれば不良債権化の危険が増し、信用リスクは残る。またポンドに対する円高は日本の輸出産業にも不利であり、日本にも円高を抑える動機がある。英国はポンドの無秩序な下落を防ぎたく、日本は円の対ポンド相場の急騰を望まない。ここで日英の利害が一致する。[^e041][^e042][^e100]

保有資産の種類によって影響は異なる。

| 保有資産 | ポンド下落時の影響 |
|---|---|
| 円建て対英債権 | 為替による円換算元本の減少を回避 |
| ポンド建て預金・債券 | 円に対してポンドが下落すれば評価損 |
| 英国企業の株式 | 為替と企業価値の双方に影響される |
| 海外鉱山・油田権益 | 資源価格下落による収益・評価額の低下 |

[^e100]

1930〜32年の日本の経常収支は計＋5億円（1930年＋3.0、1931年＋1.0、1932年＋1.0億円）で、英国の金本位制離脱と世界的な資産価格下落による評価損・債権償却等を純額−4億円とすると、純対外資産は1929年末78億円から1932年末79億円となる。危機を経ても日本の対外純資産はほぼ横ばいで済む。[^e100]

# 日英の金融協力

## 日英金融協定案

1931年の危機を契機に、次のような金融協定が日英間で検討された。[^n3]

| 項目 | 内容案 |
|---|---|
| 相互信用供与 | 両国の中央銀行による相互通貨信用 |
| 為替介入 | 円・ポンド相場の急変時に協調介入 |
| 既存債務 | 返済期限の延長・借換え |
| 貿易金融 | 円及びポンド建て手形の割引制度 |
| 外貨準備 | 相互通貨建ての流動性の高い資産を保有 |
| 金兌換 | 相互に要求しない |
| 為替相場 | 固定平価ではなく協議による安定化 |

[^e042]

日本は円をポンドに完全に連動させない。対米貿易や中国での経済活動も考慮する必要があるため、当面は管理変動相場の下で協調する程度にとどまる。日英通貨協力は、金を介した固定相場制ではなく、政府・中央銀行間の信用供与と相互決済制度を中心に発達する。[^e041][^e042]

これらの構想のうち、1931年秋の緊急金融・通商協定に取り込まれたのは、既存債務の返済繰り延べと借換え、円・ポンド相場の急変時の協調介入である。協定は政府間の取決めとして結ばれ、相互信用供与は日本政府から英国政府への円建て信用の供与という形をとった。中央銀行間の相互通貨信用、手形の割引制度、相互通貨建ての外貨準備の保有は、協定の外に置かれた。このうち中央銀行間の相互通貨信用は、1932年に日本銀行とイングランド銀行のあいだで協定とは別の取決めとして制度化された（後述）。[^n4][^n7]

## 1931年秋の日英緊急金融・通商協定

英国の金本位制離脱後の1931年秋、日本政府と英国政府は緊急金融・通商協定を結んだ。[^n1] 協定は**政府間協定**であり、両国政府のあいだの信用・保証・為替・通商の取決めを定める。日本側の資金を国内のどの機関・企業から出すか、英国側が受けた信用を国内のどの金融機関・企業に回すかといった各国内での資金の分配は、それぞれの国の内政問題として協定では定められていない。協定の有効期限は1941年までで、借換債の割引の受付期間（1932〜1941年）と一致する。[^n4][^n12]

### 対英支援信用

協定の中心は、日本の約25億円規模の円建て信用である。その内訳は、日本政府から英国政府への新規の政府間信用約21億円と、1931年の危機で凍結された日本の商業債権の借換え約4億円である。凍結された商業債権は、英連邦向け輸出の後払い代金や船舶などの延払い代金のおよそ3か月分にあたる。[^n4][^n5][^e044] 新規の政府間信用と凍結債権は1932年中に借換債に切り替えられた（後述）。この25億円は1937年にも残り、大戦期の戦時債権の残存分25億円と合わせて、英国向け債権50億円（利回り4.5%、年2.25億円）を構成する。[^n1][^n5][^n8][^e100][^p091]

### 借換債と日本政府による割引

借換えは、英国政府が発行する**円建ての100年債**（利率4.5%）への切り替えによって行われた。切り替えは1932年中に実施され、借換債は次の2種類からなる。[^n8]

| 種類 | 内容 | 額面（1937年） | 保有者 | 割引 |
|---|---|---:|---|---|
| 政府間信用分 | 1931年協定による英国政府への新規の政府間信用の借換債 | 約21億円 | 当初は日本政府。約17億円を国内の民間銀行に売却し、約4億円を政府が保有 | 対象外（売却分を含む） |
| 民間債権分 | 英国の民間部門が負っていた円建て債務を英国政府の借換債に置き換えたもの。大戦期の戦時債権の残存分（1931年に約25億円、民間保有）と、1931年に凍結された商業債権約4億円からなる | 約29億円 | 日本の居住者など | 日本の居住者の保有分が対象 |
| **計** | | **50億円** | | |

[^n5][^n8]

大戦期の戦時債権は、1918年の40億円から1920年代の回収・借換・再投資を経て、1931年には約25億円が民間保有のまま残っていた。これが1932年に民間債権分の借換債へ切り替えられ、1937年の残高も25億円である。借換債の利率4.5%は、1937年の英国向け債権の利回り4.5%と一致する。[^n5][^n8][^e100][^p091]

日本政府は、民間債権分の借換債の一部または全部を**割り引く**。ここでいう割引は手形割引と同じ意味で、日本政府が借換債を保有者から額面より安い価格で買い取り、流動性を供給することを指す。100年債は事実上換金できないため、円建て債権を持つ日本の民間保有者は、割引によって債権を現金化する道を得た。これは、協定が定めた「英国民間部門の円建て負債に対する日本政府の信用補完」を具体化する仕組みでもある。[^n8]

割引の対象は、民間債権分のうち日本の居住者（銀行・商社・製造業者のほか、領主家の金融機関を含む）が保有するものである。日本政府は保有者の申し出に応じて割り引くため、割り引かれる額は結果として一部にも全部にもなりうる。割引率は罰則的な水準に置かれ、当時の英国コンソル債の利回り（4.5〜5%程度）より高い。[^n8]

| 時期 | 割引利回り | 買取価格（額面比） |
|---|---:|---:|
| 1932〜1933年（恐慌期） | 5.5% | 約82% |
| 1934年以降 | 5.0% | 約90% |

割引は借換債への切り替えと同時に始まり、受付期間は1932〜1941年の10年間である。実際の利用は資金繰りの苦しい恐慌期（1932〜33年）が中心で、景気の回復とともにほとんど使われなくなった。1937年までの割引の累計は額面約1億円で、その大半が1932〜33年に集中した。[^n5][^n8][^n9]

政府間信用分の借換債は当初日本政府が保有したが、日本政府は1932〜34年にその約17億円を国内の民間銀行に額面前後で売却して早期に現金化し、手元には約4億円が残った。売却分は民間銀行の保有となるが、売却の条件として割引の対象外とされ、政府が売った債券を政府が割引で買い戻す循環は避けられた。[^n5][^n11] このため1937年に日本政府が保有する英国向け債権は約5億円（政府間信用分の残り約4億円と割引で買い取った民間債権分約1億円）にとどまり、帝国政府・公的機関の対外資産30億円の残り約25億円は、外貨準備・金（対外資産表の「外貨準備・金・その他」15億円の大半）と、外国政府・公的機関への融資や外国公債などからなる。[^n5][^n10]

### ポンド下落への対応

英国の金本位制離脱でポンドが円に対して下落すると、英国の円建て債務の負担はポンド換算で重くなる（→[ポンド下落と円建て債務負担](#ポンド下落と円建て債務負担)）。協定はこれに三つの措置で対応した。[^n4]

1. **返済の繰り延べ**：日本は英国の円建て債務の返済を繰り延べる。
2. **信用補完**：英国の民間部門が負う円建て負債について、日本政府が保証を与えて信用を補完する。この信用補完は、のちに借換債の割引という形で具体化された（前述）。
3. **協調介入**：日英両国は円・ポンド相場の急変に際して協調して為替市場に介入する。

三つ目の取決めにより、協定は債務・通商の協定であると同時に、**通貨スワップ協定に近い協調介入協定**としての性格も持つ。日本は英国の金本位制を救済しなかったが、離脱後のポンドの無秩序な下落を防ぐことには協力した。ポンドに対する円の急騰を望まない日本の利害とも一致する措置である。[^n4][^e042]

### 通商条項

通商条項の骨子は次の三点である。[^n4]

1. **固定輸入枠**：日本は英連邦全体からの輸入額の最低を年10億円とする固定輸入枠を設けた。この額は1931年の英連邦からの輸入額と同程度である。枠は英国本国だけでなく自治領・植民地を含む英連邦全体を単位とし、日本がそれまで進めてきた英国及び帝国各地域からの資源購入、とくに資源の長期買付はこの枠の中に組み込まれた。[^n13]
2. **最恵国待遇の確認**：英国は、英国における日本の最恵国待遇を確認した。
3. **非関税優遇措置**：英国は、英国本国と英国が施政する植民地において、日本に関税以外の手段による優遇措置を設けた。自治領は対象に含まれない。[^n6]

非関税優遇措置の内容は次の4項目である。[^n6]

| 措置 | 内容 |
|---|---|
| 政府調達 | 帝国内の政府調達（船舶・鉄道車両・電機など）で、日本企業に帝国内企業と同等の入札資格を認める |
| 輸入数量制限 | 英国の輸入数量制限から日本製品を除外するか、優先的な割当を与える |
| 金融市場 | ロンドン市場での円建て起債・手形引受の適格性を認める |
| 港湾 | 帝国内の港湾で日本船の入港・荷役を内国船並みに扱う |

固定輸入枠は1932年のオタワ会議にあわせて見直され、自治領・地域別の割当が設けられたうえで、総額は1935年までに年13億円へ段階的に引き上げられた（→[オタワ帝国経済会議（1932）と日本](../diplomacy/ottawa-conference-1932.md)）。1937年の英連邦からの輸入は16.3億円で、枠を上回っている（→[国際収支と対外資産（1914〜1937）](../economy/balance-of-payments.md)）。枠は輸入額の最低を定めるもので、英連邦に対する排他的な購入義務ではない。[^n13][^p091]

固定輸入枠に基づく日本の資源輸入は英国経済圏に円を供給し、英国が円建て債務を新規借款ではなく貿易によって返済できる構造をつくる。最恵国待遇の確認と非関税優遇措置は、翌1932年に英国が帝国特恵制度を導入する際の前提となり、日本は帝国特恵の外に置かれながら、ほかの外国より不利に扱われず、関税以外の面で優位を保つ地位を得た（→[オタワ帝国経済会議（1932）と日本](../diplomacy/ottawa-conference-1932.md)）。[^n4][^e043][^e044]

### フーヴァー・モラトリアムとの関係

協定は、日本の対英商業債権がフーヴァー・モラトリアムの対象外であることを改めて確認した。そのうえで日本は、英国の円建て債務の借換えを支援することを約束した。モラトリアムで支払いを止められない商業債務について、英国は借換えによって返済を平準化する道を得た。[^n4][^e040]

## 1932年の中央銀行間の相互信用

1932年、日本銀行とイングランド銀行は、1931年協定とは別の取決めとして、円・ポンドの相互融通枠を制度化した。枠は5億円相当（約4,000万ポンド）で、1年ごとに更新される。この枠は協定で定めた協調介入の資金となり、1937年の1ポンド＝12.25円の管理相場を支えた。[^n7]

この時期、1930年夏から交渉されていた日英海上通商防衛協定の追加議定書は、欧州通貨危機を受けて経済・金融協力が優先されたため、締結が1932年秋〜冬にずれ込んだ。[^n2][^e052]

## 1931年末の国際通貨秩序

1931年末には三つの通貨圏が形成され始めた。[^n2]

| 通貨圏 | 中心通貨 | 特徴 |
|---|---|---|
| 日英通貨協調圏 | 円・ポンド | 管理通貨・貿易金融・相互信用 |
| 米国通貨圏 | ドル | 金本位制維持 |
| 欧州金本位制諸国 | フランなど | 金平価維持・通貨防衛 |

[^e042]

このほかドイツなど、為替管理によって国際決済を統制する諸国が存在する。[中国諸省聯合](../diplomacy/china-federation.md)や外国施政地域では円・ポンドによる貿易金融の重要性が増す一方、中国の銀本位制との為替関係も問題になる。[^e042] 米国は1933年に金本位制を停止し、日本（1925年）・英国（1931年）・米国（1933年）の順に金本位制を離れることになる。[^e054]

なお、日本はスターリング圏に加盟しない。英帝国通貨圏と日本の円は、日英間の信用供与と為替安定協定によって相互に接続される二つの通貨圏であり、円をポンドに従属させる制度ではない。[^e044]

| 項目 | 英帝国通貨圏 | 日本 |
|---|---|---|
| 中心通貨 | ポンド | 円 |
| 金兌換 | 停止 | 廃止済み |
| 為替政策 | ポンドを中心とした協調 | 独立した管理通貨政策 |
| 準備資産 | ポンド建て資産など | 円・ポンド・ドル・金など |
| 相互関係 | 日英間の信用供与・為替安定協定 | 同左 |

[^e044]

# 影響

- **日英関係の段階的制度化**：1930年のロンドン会議で海上通商の防衛関係が、1931年の通貨危機で金融協力が、1932年のオタワ会議で資源貿易と開発投資の関係が制度化される。軍事・通貨・関税のいずれも単一の体制に統合されない「緩やかな結合」が日英関係の特徴となる。[^e051] オタワ会議での日本の扱いは[オタワ帝国経済会議（1932）と日本](../diplomacy/ottawa-conference-1932.md)を参照。
- **一次産品地域の購買力**：日本の資源輸入・備蓄・信用供与は、恐慌で一次産品価格の下落に苦しむ英帝国の資源輸出地域の購買力を支え、それが英日の工業製品需要に戻る循環をつくる。日本製品を排除する帝国特恵政策には自己矛盾が生じる。[^e046]
- **国内の恐慌対策**：日本は管理通貨制の下で史実より早く金融緩和に動け、公債による公共投資と備蓄拡大で国内需要を創出する。詳しくは[1925年財政原則と恐慌期の公共投資](../economy/fiscal-principles-1925.md)を参照。[^e046]

# 編集注：却下・修正された案

- **1931年秋の日英緊急金融・通商協定を検討案とする扱い**：会話ログ2（E44）では検討案として示されていた。英国向け債権50億円（P91）の内訳を説明するため、協定は締結され、日本が約25億円規模の円建て対英支援信用（新規信用と借換債）を供与したものと改めた（作者確定）。[^e044][^p091]
- **1931年秋の協定の措置表（E44）**：旧記述は日本側の措置を「円建て債務の借換え・円建て貿易信用の供与・資源の長期買付契約・ポンド買入れ・為替介入・英国系企業への投資継続」、英国側の措置を「日本企業との既存契約の維持・対日輸入制限の抑制・資源供給の安定化・円・ポンド相場の安定化協力・日本資本に対する差別の回避」としていた → 現行は、政府間の約25億円の円建て支援信用、返済繰り延べ・信用補完・協調介入、固定輸入枠・最恵国待遇の確認・非関税優遇措置、モラトリアム対象外の再確認と借換え支援とする（作者確定）。借換え・為替介入・相場の安定化協力は返済繰り延べ・借換え支援・協調介入として引き継ぎ、資源の長期買付契約は趣旨の近い固定輸入枠に統合した。英国系企業への投資継続は、協定が国内での資金の分配を定めない政府間協定とされたため協定事項から外した。日本企業との既存契約の維持・資源供給の安定化・日本資本に対する差別の回避・対日輸入制限の抑制は通商条項の骨子に含まれず、対日輸入制限の抑制と差別の回避の趣旨は最恵国待遇の確認と非関税優遇措置に置き換えた。[^e044]
- **英国が日本からの工業製品輸入について急激な関税引上げを避けることを約束したとする記述（E44）** → 現行は英国における日本の最恵国待遇の確認とする（作者確定）。協定は関税水準そのものではなく、日本がほかの外国より不利に扱われないことを約したもので、1932年の輸入関税法・オタワ協定の下で日本製品に一般外国並みの関税がかかることと両立する。[^e044][^e049]
- **日本の中央銀行・金融機関が英国の銀行・企業へ円建て信用を供与し、日本が信用の用途を日英間の決済と既存債務の借換えに限定したとする記述（E42）** → 現行は日本政府から英国政府への政府間の信用供与とし、英国内での資金の分配は英国の内政問題として協定では定めないとする（作者確定）。円建て信用が性格上、円建て債務の決済と借換えに充てられるという説明は残した。[^e042]
- **政府間信用分の借換債25億円を日本政府が1937年まで保有し続けるとした整理と、帝国政府・公的機関の対外資産枠を広げて民間分を同額減らす案** → 現行は、日本政府が政府間信用分の大半を国内の民間銀行に売却して早期に現金化したとする（作者確定）。政府保有分は約5億円にとどまり、保有者別配分（30億円・42.73億円・62.27億円）は数値を変えずに整合するため、公的機関枠を広げる案は不要となった。[^p070][^p091]
- **政府間信用分の売却額を約20億円、政府保有の残りを約5億円とした検討案** → 現行は、政府間信用分を約21億円とし、1932〜34年に約17億円を売却して政府に約4億円が残るとする（作者確定の推計値。1937年の政府保有の英国向け債権約5億円は、この残り約4億円と割引分約1億円の合計）。[^p091]
- **25億円の支援信用をすべて政府間信用分とし、民間債権分を大戦期の商業債権の残存分と1931年の商業債権とした記述** → 現行は、1931年協定の25億円を新規の政府間信用約21億円と凍結された商業債権の借換え約4億円に分け、後者を民間債権分に含める（作者確定）。[^p091]
- **日本が米仏と並んで英国の金本位制を救済する案**：E42 で論点として示されたが、E43 で日本の黒字が金準備ではなく資源備蓄と対外資産に向けられてきたと整理され（E44 で確定）、日本の金・ドル準備は決済に必要な程度にとどまることになった。このため日本は円建て信用の供与と資源買付に特化し、金・ドルによる大規模支援で英国の金本位制を1931年末以降まで延命させる経路は採られない。[^e042][^e043][^e044]
- **英国の金本位制離脱そのものを回避する可能性**：E40 で最大の検討事項とされたが、日本自身が金本位制の外にあり英国に維持を求める理由が乏しいことから、離脱は史実と同程度の時期に起きるとされた。[^e040][^e042]
- **日本の1917年以降の通貨制度が「正式には未確定」とされていた点**：E40 での指摘を受け、E41 で1925年の金本位制復帰断念・金兌換義務と金平価の廃止が確定した。[^e040][^e041]
