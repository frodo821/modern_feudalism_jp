# 概要

本世界線の清朝は、史実より6年早い1889年に[日清戦争](sino-japanese-war.md)で敗れ、しかも史実で北洋新軍を一手に束ねた[袁世凱](../people/yuan-shikai.md)をすでに失っている。そのうえ英国資本が清朝の財政と鉄道開発に深く関わっている。この条件で「清末の軍制改革を誰が主導し、何を財源とするか」が、清朝の終わり方と軍閥体制の形を決めた。[^e013][^e014]

敗戦後、[李鴻章](../people/li-hongzhang.md)は袁世凱を生贄にして失脚を免れるが発言権を失い[^e016]、改革は統括者を欠いたまま各省督撫と皇族がばらばらに進める多極的なものとなった。軍の近代化そのものは史実より早く始まるが、指揮系統・人事・財政・教育は統一されず、「史実より早く軍隊の近代化が進む一方、史実以上に軍事権力が分散する清朝」が生まれる。[^e016]

1900年の[義和団事件と東南互保](boxer-rebellion.md)で中央は大きく傷つき、東南の督撫は力を温存した。1901年以降の清末新政のもとで中央は地方新軍の軍権回収を試みるが[^e017]、成功したのは制度面だけだった。1908年に摂政となった載灃は、抵抗する有力者がいないぶん皇族中心の中央集権化を史実より強く断行し[^e018]、その結果、革命派だけでなく王朝を支えていた立憲派と地方勢力まで敵に回して1911年を迎えた。[^e018][^e019]

# 改革の論点：誰が主導し、何を財源とするか

## 三つの論点

清の軍制改革の成否は、まず「誰が主導するか」と「財源はあるか」の二点で考えることができる。[^e014] これに「財源と軍の管理権が中央政府にあるか、地方督撫にあるか」という第三の論点が加わる。改革が成功しても、近代軍が地方官僚の私的な権力基盤になれば清朝の延命にはつながらず、かえって軍閥の形成を促す。[^e014]

## 主導者の候補

| 人物 | 1889年の年齢 | 政治・軍事的基盤 |
|---|---:|---|
| 李鴻章 | 66歳 | 淮軍・北洋・外交・洋務事業 |
| 張之洞 | 52歳 | 地方行政・洋務事業・教育 |
| 劉坤一 | 59歳 | 湘軍系・両江 |
| 栄禄 | 53歳 | 満洲貴族・宮廷・軍事行政 |
| 醇親王奕譞 | 49歳 | 皇族・海軍衙門 |
| 光緒帝 | 18歳 | 皇帝の権威・中央集権改革 |

[^e014]

李鴻章は高齢で、1900年代まで一貫して改革を主導するのは難しい。最有力は張之洞で、史実でも1889年に湖広総督となり、製鉄所・兵器工場・教育機関・新軍を一体で整備でき、山西巡撫時代には地方財政改革の実績もある。袁世凱がいないため主導権争いもない。ただし改革は湖北中心の地方主導になりやすかった。[^n1][^e014] 西太后と皇族は漢人官僚に近代軍が集中するのを嫌い、実務は張之洞・李鴻章に任せつつ首都防衛軍は満洲貴族の指揮下に置こうとするため、中央軍と地方軍の二重構造ができる。[^e014]

## 財源

| 財源 | 性格 |
|---|---|
| 地丁銀 | 安定しているが増収が難しい |
| 海関税 | 外債の担保に充てられている |
| 塩税 | 恒常的な軍事費に向く |
| 釐金 | 国内流通税。地方軍の財源になりやすい |
| 外国借款 | 初期投資向きだが債務が残る |
| 官営・官督商弁事業 | 鉄道・鉱山・製鉄。長期の収益源 |

[^e014]

太平天国以降、釐金などの地方財源が発達し、中央の財政統制はすでに弱まっていた。英国は清の政治的安定と債務履行を重視するため軍制改革用の借款を出しうるが、「初期投資は外国借款で賄えても、軍隊の維持には恒常的な税収が必要」である。[^e014] 最も重要なのは**英国が誰に貸すか**で、中央に貸せば集権化、地方督撫や個別事業に貸せば地方の自立を促す。英国は本来中央を強化したいが、徴税・行政能力が地方に偏っているため、「集権化を望みながら分権化を促す」という矛盾が生じ、これが軍閥体制の形成につながる。[^e014]

# 第一次軍制改革（1889〜1900）

## 李鴻章の後退と多極化

李鴻章は袁世凱に敗戦責任を負わせて生き延びたが、発言権は低下した。[^e016] 軍事・外交を事実上主導する立場から「経験豊富な有力督撫の一人」に後退し、相対的に張之洞の地位が上がる。ただし宮廷は別の漢人官僚への権力集中も嫌うため、張之洞が全国の軍政を握るとは限らない。[^e016]

清朝中央は各省督撫に近代軍の整備を命じ、中央直属軍は皇族・満洲系の軍事官僚に担当させる。改革は1895年ではなく1889年から本格化するが、統括者がいないため統一性は低い。[^e016] 1889〜1900年を第一次軍制改革、1901年以降を第二次軍制改革と区分する。[^e015]

| 改革勢力 | 主な内容 |
|---|---|
| 李鴻章・淮軍系 | 既存軍の再建 |
| 張之洞 | 湖北の新軍と軍需産業 |
| 劉坤一・湘軍系 | 長江下流の防衛 |
| 西太后・満洲貴族 | 皇室直属の近代軍（財源・人材不足） |
| 光緒帝 | 全国的な改革を志すが実権がない |

[^e016]

## 1900年頃に並び立つ新軍

| 軍事勢力[^n2] | 拠点 | 主な財源 |
|---|---|---|
| 北洋新軍 | 直隷・天津 | 北洋系の財源・中央交付金 |
| 湖北新軍 | 武昌・漢陽 | 湖北省財政・軍需産業 |
| 両江新軍 | 南京・長江下流 | 釐金・地方税 |
| 広東新軍 | 広州 | 貿易関連収入・地方税 |
| 京師直属軍 | 北京周辺 | 中央財政 |

[^e016]

装備と訓練は近代化するが、指揮系統・人事・財政・教育は統一されない。[^e016] のちに湖北軍を率いる黎元洪も、1889年の日清戦争後の海軍再編で張之洞の下へ移り、湖北新軍の育成に関わる経歴をたどった。[^n1][^e027] 日清戦争の敗戦で朝鮮への軍事的関与を断念すれば軍事費の配分も変わり、北洋海軍を再建すれば陸軍改革と財源を奪い合う。[^e014]

## 第一世代の退場

李鴻章（1901年）、劉坤一（1902年）、光緒帝・西太后（1908年）、張之洞（1909年）の没年は史実どおりである。[^e016] 彼らが世を去っても、袁世凱のように遺産をまとめる人物はおらず、各地方新軍は職業軍人の指揮下で独自の勢力になっていく。[^e016]

# 義和団事件後の格差

1900年の義和団事件は史実どおり起き、西太后が義和団を支持して列強に宣戦し、連合軍に鎮圧された。[^e015] 北京の中央直属軍や華北の軍事組織は列強との戦闘で損耗し、長江流域の新軍は東南互保によって温存される。[^e016] 北京議定書の巨額賠償で中央の財政はさらに縛られ、「清朝全体として軍制改革の財源が存在しないのではなく、中央政府が自由に使える財源が不足している」状態になる。[^e015] 詳細は[義和団事件と東南互保](boxer-rebellion.md)を参照。

# 清末新政と軍権回収（1901〜1908）

## 新政の年表

清朝中央は地方新軍の軍権回収を試みた。新政は史実に準じて進んだ。[^e017]

| 年 | 出来事 |
|---|---|
| 1901 | 新政開始 |
| 1903 | 練兵処設置（新軍の編制・訓練を統一） |
| 1905 | 科挙廃止 |
| 1906 | 陸軍部・度支部設置 |
| 1908 | 欽定憲法大綱 |
| 1909 | 諮議局設置 |

ここには「中央集権化の必要性が高まった時点で、それを実現する財政能力が下がっている」という根本矛盾がある。中央と地方の対立に加え、中央官庁どうしの権限争いも起きる。[^e017]

## 袁世凱不在の意味

宮廷から見ると、袁世凱がいないことはむしろ有利である。強力な軍事的対抗者がおらず、北洋系の抵抗も弱く、並立する新軍を個別に牽制できる。不利な点は、専門人材が分散していること、中央直属軍が弱いこと、賠償負担が重いことである。[^e017]

## 権限別の回収見通し

| 権限 | 回収の見通し |
|---|---|
| 編制規格 | 成功しやすい |
| 軍事教育・階級制度 | 成功しやすい |
| 高級軍人の任命権 | 部分的に成功 |
| 兵器調達 | 部分的に成功 |
| 作戦指揮権 | 地方次第 |
| 給与支払い | 財政難で困難 |
| 地方軍の財源 | 強い抵抗を受ける |
| 省外への転属 | 困難 |

[^e017]

1908年頃には、制度上は全国の新軍が陸軍部に属するが、実態は各省の財源と軍人の人脈に依存する。完全な軍閥体制でも中央集権的な国軍でもない中間状態である。[^e017]

## 立憲化との結びつき

軍権問題は立憲化と結びつく。地方は財源と軍権を手放す代わりに、国家予算の決定や中央政治への参加を求める。皇族が軍権・財政権を回収しながら議会政治を遅らせれば、地方はそれを皇室による権力の独占とみなす。[^e017]

# 載灃の皇族中心集権化（1908〜1911）

## 断行の論理

1908年に光緒帝と西太后が相次いで死去し、[溥儀](../people/puyi.md)が即位して父の載灃が摂政となった。抵抗がなくなったぶん、載灃は皇族中心の中央集権化をより強く断行した。[^e018] 袁世凱の不在は集権化を実現する能力を高めたのではなく、強行する際の政治的な障害を取り除いたにすぎない。[^e018]

| 政策 | 内容 |
|---|---|
| 軍政 | 陸軍部への権限集中、高級軍人は皇族・満洲系を優先 |
| 皇室直属軍 | 禁衛軍を優先整備 |
| 地方軍 | 地方新軍の指揮権を督撫から回収 |
| 財政 | 度支部による地方財政の直接管理を拡大 |
| 政体 | 皇族中心の責任内閣、皇帝大権を残した限定的立憲制 |

[^e018]

史実の載灃もドイツ帝国の皇室と軍の関係を参考にしていた。[^e018] しかし中央に財源がないため、政策は「軍隊の維持費は地方に負担させながら、人事権と指揮権だけを中央に移す」ものになる。地方から見れば、負担はそのままで権限だけを奪われることになる。[^e018]

## 鉄道国有化問題

軍権回収の財源として、鉄道・鉱山の中央管理が進められる。英国資本が深く関わるため、鉄道の集権化は国内問題にとどまらない。英国は集権化そのものには反対しないが、既存契約の一方的な変更には反対する。利害関係者は清朝中央・地方督撫・地方の商人地主（出資金と経営権）・英国資本・革命派で、鉄道国有化問題は史実より深刻になる。[^e018] 特に四川は、地方の出資でつくった資産を中央が接収して外債の担保にすることに強く反発する。[^e022]

## 1911年までの年表

| 年 | 出来事 |
|---|---|
| 1908 | 光緒帝・西太后死去。溥儀即位、載灃摂政 |
| 1909 | 皇族による軍権掌握が本格化。張之洞死去 |
| 1909〜10 | 立憲派との対立が表面化（史実では1911年の皇族内閣で顕在化） |
| 1910 | 地方新軍の指揮権・人事権の回収を強行 |
| 1910〜11 | 地方財政・鉄道事業の中央管理を推進 |
| 1911 | 皇族内閣成立。立憲派と地方勢力が離反 |
| 1911年秋 | 革命運動と地方新軍の反乱 |

[^e018]

# 禁衛軍と1911年の清朝軍事力

史実の禁衛軍は、1911年の経費清冊で12,054人、近代陸軍の1個師団相当にすぎず、皇室護衛と首都防衛を目的としていた。[^e019] 史実の清朝が首都周辺に持っていた近代軍は次のとおりで、そこには袁世凱の人脈が強く残っていた。

| 部隊（史実、1911年前後） | 兵員数 |
|---|---:|
| 禁衛軍 | 12,054 |
| 北洋第一鎮 | 12,514 |
| 北洋第二鎮 | 9,684 |
| 北洋第四鎮 | 9,789 |
| 北洋第六鎮 | 10,039 |
| 予備兵・その他 | 12,957 |
| 合計 | 67,037 |

[^e019]

本世界線では北洋六鎮に相当する組織が成立するとは限らず、義和団事件で華北の軍事組織も損耗している。1911年時点の兵力は次のように推定される。[^n3][^e019]

| 軍事組織 | 推定兵力 | 特徴 |
|---|---:|---|
| 禁衛軍 | 1.2〜1.5万人 | 皇室直属 |
| 華北の新軍 | 2〜3万人 | 陸軍部管轄、忠誠は不確実 |
| 旧式の八旗・緑営など | 数万人 | 近代的戦闘能力に乏しい |
| 地方新軍 | 15〜20万人 | 各省に分散 |

載灃が皇室直属軍の拡大を優先しても、財政と人材の制約から禁衛軍が2個師団を超えるのは難しい。単独の反乱なら鎮圧できても、複数の省が同時に独立すれば対応できず、禁衛軍を遠方に出せば北京が手薄になる。忠誠の疑わしい地方新軍に頼るほかない。[^e019] その結果、宮廷は地方の独立を止められず、革命派も全国の新軍を掌握できず、地方立憲派は共和派に必ずしも従わず、各省が独自の軍事・行政組織を保つ。**清朝の滅亡そのものは史実より容易だが、清朝に代わる統一国家の成立は史実より困難**になる。[^e019] その帰結は[清朝の終焉と中華民国承認問題](xinhai-revolution.md)を参照。

# 編集注：未決の論点

- 革命後の各省で、諮議局と新軍のどちらが主導権を握るか（軍人が直接政権を握るか、立憲派の省政府が新軍を指揮下に置くか）。[^e019]
- 英国の借款が中央と地方のどちらに向かったかの具体的な配分（議論の流れは地方重視に傾く）。[^e014]
- 北洋海軍を再建したか否か、それが陸軍改革の財源をどの程度奪ったか。[^e014]
