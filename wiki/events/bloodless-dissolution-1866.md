# 概要

1866年の無血の幕府解体は、本世界線で徳川幕府が終わった政変である。[第二次長州征討](second-choshu-expedition.md)の敗北で将軍の正統性が揺らぐなか、1866年7月に[徳川家茂](../people/tokugawa-iemochi.md)が死去した。朝廷はこれを機に将軍への軍事委任を更新せず、全国の軍事権を「朝廷預かり」とした。さらに徳川家を含む全諸侯の所領を朝廷の名で安堵した。これに逆らえる勢力はなく、幕府に固執する必要があるのは少数派にとどまった。[^u015]

この世界線では、幕府を終わらせた決定的な行為は「徳川家を倒すこと」ではなかった。「次の将軍に軍事権を再委任しないこと」である。[^u015]

ただし所領安堵と引き換えに成立したため、諸侯の世襲的な領国支配はかえって強く保障された。徳川幕府の廃止には成功したが、廃藩置県に相当する改革は一層難しくなった。この逆説が、のちの[近代封建制](../concepts/modern-feudalism.md)の出発点となる。[^u015][^u017]

# 背景

## 軍事委任の制度

[1861年公武協定](../diplomacy/kobu-agreement-1861.md)により、「天下の兵馬は朝廷の御委任により征夷大将軍これを総督」するとされ、将軍の軍権は朝廷からの委任として明文化されていた。協定は、朝廷が委任を変更・撤回できるかを曖昧にしたまま成立していた。[^u015]

## 家茂政権の動揺

1866年、家茂は勅許のないまま長州再征を強行して敗れた。諸藩の部隊には、勅許のない作戦に従う義務があるのかという疑義が広がっていた。朝廷の命令に背いた軍が負けたことで、諸藩は将軍に従う理由を失いつつあった。[^u012]

# 法理

## 宗家相続と軍事委任の分離

政変の鍵は、「徳川宗家の相続」と「将軍への軍事権の委任」を別の行為とする解釈にあった。家茂が死んでも、徳川宗家には相続人を立てられる。しかし、次の将軍を任命して軍事権を再び委任するかどうかは朝廷の判断である。朝廷は家督相続を認めながら、軍事委任の更新を保留できた。[^u015]

この解釈は、1861年の協定が個々の将軍に軍事権を委任する仕組みである場合に成り立つ。委任を徳川家の世襲権として保障していたなら、争いになったはずである。[^u015]

## 軍権朝廷預かりの勅命（文案は検討案）

> 征夷大将軍家茂薨去につき、天下兵馬の統轄は、新たな沙汰あるまで朝廷においてこれを預かる。
> 諸侯は従前の封土を安堵され、軍兵は各々部署を守り、私に軍を動かすべからず。

[^u015]

この勅命には三つの効果があった。[^u015]

1. 将軍の後継者による中央軍の指揮権継承を止める。
2. 朝廷への恭順と引き換えに、諸侯に領地の保障を与える。
3. 現状の軍事配置を凍結し、徳川家による反撃や軍事的圧力を封じる。

特に三つ目が重要だった。軍隊に朝廷へ進軍せよと命じる必要はない。「将軍の後継者から新たな命令が出ても、朝廷の裁可があるまでは動くな」と命じるだけでよかった。諸藩出身の部隊が多いなら、藩主たちが命令に背いてまで徳川家のために戦う理由は乏しくなる。[^u015]

# 所領安堵の効果

朝廷が所領を保証したことで、朝廷に従うことは必ずしも徳川家を裏切ることを意味しなくなった。[^u015]

| 諸侯の立場 | 朝廷による所領安堵の意味 |
|---|---|
| 薩摩・土佐・越前などの雄藩 | 徳川家を介さず中央政治へ参加できる |
| 一般の外様大名 | 従来の領国支配を維持できる |
| 親藩・譜代大名 | 徳川家への忠誠と家の存続を切り離せる |
| 幕府に強く依存する小藩 | 新政府での待遇保障があれば協力する余地がある |
| 徳川宗家・御三卿 | 将軍職を失っても家名と所領を保持できる |

朝廷は次のように説明できた（文案は検討案）。

> 徳川家は長年にわたり天下の政務を担ってきた。しかし将軍家茂の死によって軍事委任は一旦終了した。徳川家の功績と所領は尊重し、新しい統治機構を諸侯と協議して定める。

[^u015]

# 経過

## 年表（月次は検討案）

| 時期 | 出来事 |
|---|---|
| 1866年7月 | 家茂死去（史実では7月20日・旧暦）。朝廷は将軍への軍事委任が終了したと解釈し、新将軍への再委任を保留 |
| 1866年8月 | 軍権の朝廷預かり。全国軍に現状維持を命じ、諸藩へ所領安堵を通達し、兵の私的動員を禁止 |
| 1866年9月 | 諸侯会議の招集。徳川宗家を含む有力諸侯が京都に集まり、新たな軍事・行政体制を協議 |
| 1866年10〜11月 | 将軍職の軍政権を停止。徳川家の宗家相続と所領保有は承認し、全国統治権の世襲継承は認めない |
| 1866年12月 | 新政体の発足。朝廷のもとに諸侯合議制の政府を置き、孝明天皇の崩御後も継続 |
| 1867年2月13日 | 新天皇の践祚と同日に[明治改元](meiji-era-proclamation-1867.md)。軍権の朝廷帰属を改めて確認 |

[^u015][^u020]

## 軍の掌握

軍権の法的な帰属と、軍隊の実際の支配は区別しなければならない。幕臣部隊の将校、江戸城の守備隊、幕府海軍などが徳川宗家への忠誠を優先すれば、朝廷の宣言だけでは実権を奪えない。そこで朝廷は既存の指揮官をできる限り留任させ、俸給と身分を保障したうえで、指揮権の名義だけを変更した。[^u015]

## 慶喜の立場

慶喜は一橋家の当主で水戸家とは別家であるが、父は徳川斉昭である。水戸徳川家が厳罰を受けた本世界線では、宗家相続そのものにも政治的な抵抗が生じうる。相続したとしても、朝廷は将軍宣下を見送れた。慶喜に残された選択肢は、委任の再開を交渉する、宗家当主として新政権に参加する、軍事力で将軍職の承認を迫る、の三つであった。三つ目は、軍隊自体が朝廷の承認に基づいて編成されている以上、指揮官が命令を拒む公算が大きく危険だった。[^u015]

## 時間制限: 孝明天皇の崩御

史実どおり孝明天皇が1866年12月25日（旧暦）に崩御するなら、朝廷に残された時間は約5か月であった。ただし、発せられた勅命は崩御によって効力を失うわけではない。朝廷の政治勢力は新天皇の即位後も軍事委任の停止を維持し、政権移行を既成事実とした。[^u015][^u020]

# 新政体

## 主導者と参加者

この政変を主導したのは朝廷であり、薩摩・長州とは限らない。諸侯の所領を安堵するのだから譜代・親藩も新政権に加わることができ、徳川家、尾張・紀伊、越前、土佐、薩摩などが参加する諸侯連合政府が成立した。長州は、それまでの朝廷との対立や征討の経緯から、同列で参加できるとは限らなかった。[^u015]

徳川家は必ずしも最大の敗者ではない。領地と家格を保ち、新政府の有力諸侯の一つとしての地位を確保したことで、全面的な内戦を避けることができた。経済力、人脈、旧幕府官僚としての経験によって、その影響力はしばらく保たれた。[^u015]

## 旧幕府機構の継承

軍事委任を停止しただけでは、行政・財政・軍事を運営できる政府はできない。新政府は将軍職を空位としたまま、旧幕府の行政官僚組織を朝廷直属の官庁として引き継いだ。徳川幕府は武力で滅ぼされたのではなく、将軍の死を契機に朝廷直属の中央政府へと組織を移し替えられたのである。[^u015]

## 那珂川家の実権取得

幕府による旧水戸領の統治機構も新中央政府の監督下に移った。その際、[那珂川家](../people/nakagawa-ducal-house.md)が自らの領主権を行使することが認められ、同家は名実ともに大領主となった。[^u018]

# 帰結

## 廃藩置県の困難化

朝廷が所領安堵を約束して幕府を解体した結果、諸侯は徳川家に従属する必要がなくなり、朝廷から直接に領国支配を認められた。新政府は諸侯の合議で運営される体制になりやすく、諸侯の領地を一方的に没収する権限を持たなかった。[^u015]

新政府の成立自体が諸侯の[領主権](../institutions/lordship-rights.md)の保障を前提としているため、藩主を中央任命の官僚にすることは難しく、版籍奉還は成立時の約束を破ることになる。「明治維新に相当する政権交代は史実より穏やかに進む一方、封建制度の解体ははるかに長期化する」ことになった。[^u017]

## 交換条件と次の争点

1866年の段階で朝廷が保障したものと、諸侯に求めたものは次のとおりである（検討案）。[^u016]

| 朝廷が保障するもの | 諸侯に求めるもの |
|---|---|
| 現在の所領と家格 | 新政府への服属 |
| 藩主家の存続 | 外交権の中央政府への一元化 |
| 家臣の身分・俸禄の当面の保障 | 全国軍費の負担 |
| 中央政務への参加 | 藩兵の一部を国家軍へ移管 |

ここから[なし崩しの維新](../concepts/gradual-restoration.md)が始まる。諸侯の合意で成立した朝廷政府が、いつ諸侯から独立した統治権力を得られるかが次の争点となった。[^u016]

## 統帥権への影響

1866年に朝廷が軍事権を回収したことは、天皇が無制約の軍事大権を得たことを意味しなかった。その後、諸領主との合意によって統一軍を維持する立憲体制が成立し（1869年の憲法）、帝国軍の権限は憲法が構成した国家機関の権限となった。このため本世界線では、天皇固有の統帥大権を根拠とする史実の統帥権干犯問題は法理として成り立たない（[統帥権（本世界線）](../institutions/supreme-command.md)）。[^u124]

## 後世の呼称

史実の「王政復古の大号令」に相当する出来事は、本世界線では1866年の軍権朝廷預かりである。後世の歴史家は「慶応の政体改革」「明治改元」「公武合体体制の解消」などの段階に分けて研究する。[^u020]
