# 概要

本世界線では欧米視察は誰もがしたがるものであり、その規模は史実の岩倉使節団をはるかに超えうる。日本には欧米を視察したい主体が少なくとも三つ――帝国中央政府、[元老院](../institutions/genroin.md)と諸領主、各領主家の政府・企業――存在し、どこかの家が大規模な視察団を出せば他家も黙っていないからである。[^u043]

その結果、岩倉使節団は「中央政府が組織した一大視察団」ではなく、**中央政府の正式使節団を核として、全国の領主家が競うように欧米へ人材を送り出す現象**となった。岩倉を全権大使とする正式な外交使節は1871年に派遣され100人前後にとどまったが、同時期に欧米を訪問した日本人の視察員・留学生の総数は数百人規模に達した。[^n1][^u043]

帰国者は中央政府だけでなく全国の領主家へ戻り、鉄道・銀行・学校・裁判制度の改革を競った。知識が複数の政治経済圏へ同時に流入したことで、使節団は[大領主間の近代化競争](../concepts/yorioya-yoriko.md)の起爆剤となり、[全国標準化政策](../institutions/national-standardization.md)と議会政治の双方を加速させた。[^u043][^u044]

# 背景

## 前倒しされた視察の必要

史実でも幕府は1862年に竹内保徳ら36人を中心とする遣欧使節を派遣して開港延期交渉を行っており、本世界線の幕府も1860年代から海外視察の経験を蓄積していた。さらに1867年に朝廷政府が発足し、1869年頃に[大日本帝国憲法](../institutions/imperial-constitution.md)が制定されたため、欧米の制度を調べる必要は史実より早く生じた。[^u043]

時期によって派遣の目的は変化した。[^n2][^u043]

| 年代 | 主な派遣 |
|---|---|
| 1867〜1869年 | 憲法・議会・領邦制度の調査使節 |
| 1870〜1871年 | 中央政府による外交使節と条約改正の準備 |
| 1871〜1873年 | 岩倉を正使とする大規模な欧米回覧 |
| 1870年代を通じて | 各領主家による専門視察団・留学生の継続的派遣 |

## 1871年派遣を維持する理由

安政五カ国条約が基本的に維持されている以上、1872年に訪れる条約改正期日への対応という外交日程は史実と同じである。外交権を中央政府に集中した以上、帝国政府による正式な使節派遣にはむしろ強い理由があった。したがって岩倉使節団そのものは1871年に派遣され、これに先立つ視察や同時期の領主家の海外派遣が史実より大幅に増える、という構図となった。[^u043]

# 構成

## 三つの視察主体

| 主体 | 主な関心 |
|---|---|
| 帝国中央政府 | 外交制度、条約改正、軍制、財政、憲法制度 |
| 元老院と諸領主 | 自らの領主権に適した立憲制度、地方自治、産業政策 |
| 各領主家の政府・企業 | 鉄道、製鉄、造船、金融、鉱業、教育などの技術 |

[^u043]

## 領主家ごとの関心（例示）

- **島津家・鍋島家など**：イギリスの造船所、機械工業、製鉄所、工業教育、金融制度。
- **徳川家・前田家など**：ドイツの連邦制度、領邦行政、鉄道、軍制、大学制度。
- **中小領主・商工業関係者**：アメリカの鉄道会社、銀行、地方自治、土地制度、企業経営。

[南北戦争が回避された](american-civil-war-avoided.md)本世界線では、アメリカへの関心が強まった。[^n3][^u043]

領主本人の長期外遊は、自領を改革するために外国の工場・役所・学校・裁判所を直接見る「現役統治者の視察」として特別な意味を持ち、領主間の主導権争いとも相性がよい。ただし留守中の領内行政の問題があるため、実際には家令・重臣・技術官を派遣する例が多かった。[^n2][^u043]

## 規模の試算

中央政府と諸領主の派遣を一体的に調整した場合の「1871年欧米回覧事業」の規模は、次のように試算される。[^n1][^u043]

| 区分 | 人数 |
|---|---|
| 帝国政府の正式使節・随行 | 50〜70人 |
| 元老院・諸領主の代表 | 30〜60人 |
| 産業・軍事・行政の専門視察員 | 60〜100人 |
| 留学生 | 50〜100人 |
| **合計** | **190〜330人** |

ただし、これだけの人数が一隻の船で出発し約2年間同じ行程をたどるのは非効率であり、史実の使節団でも各省の専門官は途中で別行動をとっていた。そのため本世界線でも、「岩倉使節団」という外交上の正式使節（100人前後）と、元老院・各領主の視察団とは区別された。**全員が岩倉の指揮下に入ったわけではない**。[^u043]

## 岩倉具視の役割と人選

本世界線の岩倉具視は、倒幕政府の中心人物というより、朝廷と元老院の利害を調整する政治家として活動している。1867年の政体変更では旧幕府官僚の多くが行政機構に残っており、人選も史実と異なる。[^n4][^u043]

- 全権大使：岩倉具視
- 副使：旧幕臣、朝廷官僚、諸領主を代表する政治家
- 随行：元老院の各会派の代表者

諸領主の代表を全員副使にすれば外交上の意思決定が複雑になるため、正式な外交権限は岩倉ら少数に集中させ、その他は視察官・随員として参加させた。[^u043]

# 費用負担原則

元老院で人数以上に激しく争われたのは費用負担である。島津家の技術者がイギリスの造船所を視察する費用を国庫が負担すれば、島津家の領内事業だけが利益を受け、他の領主が不公平だと批判する。そこで次の原則がとられた。[^n5][^u043]

- 外交使節、条約交渉、全国法制の調査は**国庫負担**。
- 各領主の産業・行政視察は原則として**領主家の負担**。
- 全国的な技術者育成に役立つ留学には**国庫補助**を認める。
- 視察成果は元老院または中央官庁へ**報告し、一定範囲で公開**する。

最後の原則は、国庫補助を受けた領主が視察成果を自家の工場や企業だけに独占することを防ぐためのものである。一方、完全な私費視察であれば、成果を自家の事業に利用する自由が一定程度保障される。[^u043]

# 帰結

## 近代化競争の起爆剤

史実の使節団では知識が日本政府へ持ち帰られたが、本世界線では視察者が全国の領主家へ戻っていく。ある領主は鉄道を建設し、別の領主は銀行を創設し、また別の領主は学校制度や裁判制度を改革し、その成果が元老院で競われる。近隣の中小領主は成功した大領主の事業に参加する。**欧米視察で得た知識が中央政府だけに蓄積されず、全国の複数の政治経済圏へ同時に流入する**ことが、本世界線の使節団の最大の特徴である。[^u043]

## 標準化と連邦制の受容

複数の領主家が別々の規格や制度を導入すれば、全国的な標準化の費用が増える。欧米を見た以上、標準化は確実に元老院で議論の俎上に載り、1873年頃の「度量衡・工業規格調査委員会」設置などの[全国標準化政策](../institutions/national-standardization.md)へつながった。ドイツ関税同盟の先例は使節団がドイツ帝国成立直後に欧州を訪れたことで強く意識された。[^u044]

また、米国を視察した領主議員たちは、州に広範な自治を残しながら全国市場を運営する合衆国の連邦制を、領主権存続の論拠として持ち帰った。この経験は帝国通商条項・領主権留保条項・帝国法優越条項などの憲法改正構想につながる（[アメリカ連邦制の受容と領主権の再定義](../institutions/federalism-reception.md)）。[^u045]

## 条約改正の準備

使節団と並行して進められた法体系の翻訳は、1870年代後半以降の[不平等条約改正](../diplomacy/treaty-revision.md)交渉の基礎となった。旧幕府の外交人材と欧米視察の経験は、交渉能力の面で史実より有利な条件をもたらした。[^u046]

## 民撰議院運動への影響

欧米の議会制度や地方自治を学んで帰国した領主家の官僚や留学生は、日本では元老院の議席が領主・華族・勅選議員に限られていることを知っている。そのため1874年頃の[民撰議院設立建白](../institutions/house-of-representatives.md)に彼らが関与し、史実より早く、あるいは強く民選議会の必要性を主張する素地となった。[^n2][^u043]

## 外交権一元化との境界

各領主家が海外に独自の人脈を持つようになると、[外交権の一元化](../diplomacy/tsushima-so-clan.md)との境界が問題となった。政府は民間の商業・技術交流を奨励しつつ、外国政府との政治交渉だけは中央政府の専権として明確に区別する必要に迫られた。[^u043]
