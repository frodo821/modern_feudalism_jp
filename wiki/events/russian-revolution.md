# 概要

本世界線のロシア帝国は、日露戦争（史実1904〜05年）を経験しない。それでも**血の日曜日事件はほぼ確実に起き、起きればロシア帝国の延命は難しい**（確定）。[^u112] その原因は対外戦争ではなく、工業化による労働問題、農民の土地要求、ゼムストヴォの立憲改革要求、民族問題、ニコライ2世の専制への固執といった国内の政治・社会構造にある。[^u112]

人民を撃った時点でニコライ2世には譲歩の余地がほぼ残っておらず、**立憲君主制への移行はほぼ不可能**である（確定）。[^u113] 帝国は軍の忠誠によって1905年には崩壊せずに延命するが、正統性を回復できないまま1914年の大戦に突入する。

大戦では、日本と米国の軍需供給によってロシア軍の武器不足は改善するが、**物資が潤沢になることは東部戦線がましになることを意味せず、人的損耗はむしろ増えうる**（確定）。[^u114] 最悪の場合は「19世紀の軍隊が第一次世界大戦に参戦して、そのままミンチになる」シナリオである（ユーザー提示のワーストケース）。[^u115] この世界のロシア革命は、物資不足よりも「物資があっても戦争を止められない帝政と臨時政府の政治的行き詰まり」によって起こり、1917年の二月革命・十月革命と1918年の単独講和という史実の流れを採ることに十分な合理性がある（検討案）。[^u114]

# 背景：日露戦争のないロシア

本世界線では1889年の日清講和で三国干渉が起きず、英国権益の先行によりロシアは史実と同じ条件で東清鉄道を取得できない可能性がある。極東での日本との戦争もない（→[日露関係と対露抑止](../diplomacy/japan-russia-relations.md)）。[^u092]

日露戦争がないことの影響は両面的である。[^u100]

| 側面 | 内容 |
|---|---|
| 有利な点 | 戦争の財政負担・極東での損耗がない。旅順陥落・対馬沖の敗北・軍の動揺もない |
| 不利な点 | 敗戦の教訓による陸軍改革（参謀組織・将校教育・予備役制度・兵站・戦術）がない |
| 政治 | 1905年の危機の形が変わり、ドゥーマが成立しないか別の形になる可能性 |

ここから「軍備・財政に余裕がある一方、政治改革が遅れて1917年の危機を吸収できない」という逆説が生じる。日露戦争の回避はロマノフ朝の安定を保証しない。[^u100] またバルカンでは、日露戦争と1905年の敗北を経験していないロシアが史実より強硬になり、1908年のボスニア併合危機で譲歩しない可能性もある（逆に立憲化していなければ意思決定も異なり、強硬化とは決めつけられない）。[^u094]

# 経過

## 1905年：血の日曜日事件

血の日曜日型の事件（労働争議を発端とする請願行進への発砲）は、日露戦争がなくても本世界線でほぼ確実に起きる。ただし戦争がないため、日付や内容まで史実と同じとはいえない。[^u112] 事件は皇帝を人民の保護者とする正統性そのものを傷つける。[^u112]

日露戦争がないため極東への大規模派兵はなく、ニコライ2世は史実以上に軍を国内の鎮圧に集中できる。しかし軍によって秩序を回復しても、正統性の問題は解決しない。[^u112]

## 1905〜1913年：立憲化できない延命

問題は譲歩の「信用性」にある。人民を撃った皇帝が改革を約束しても信じられず、十月宣言のような立憲化の宣言と、憲法による拘束を実際に受け入れることは別である。[^u113] 皇帝退位による王朝存続の道も困難である。皇太子アレクセイは1904年生まれでまだ乳児であり、摂政の問題が生じ、血の日曜日の責任者が摂政政府を運営すれば信用は回復しない。[^u113]

その結果、「1905年には崩壊しないが、1917年までに行き詰まる」経路が描かれる（検討案）。[^u113]

| 時期 | 仮想ロシアの政治状況 |
|---|---|
| 1905年 | 血の日曜日事件。ストライキと革命運動が拡大 |
| 1905〜1906年 | 皇帝が限定的改革を約束する一方、軍隊で反乱を鎮圧 |
| 1907〜1913年 | 形式的な議会制度を認めても、皇帝専制の中核は残存 |
| 1914年 | 政治的不満を抱えたまま世界大戦へ参戦 |
| 1915〜1917年 | 戦争負担が拡大し、再び革命的危機に直面 |

## 1914〜1916年：物資があるゆえの消耗

1914年6月28日のサラエボ事件はロシアと関係なく起きるため、本世界線でも欧州大戦は始まる（確定）。[^u094] 日本はロシアと戦っておらず、連合国としてロシアへ軍需品を輸出できる。[^u098] ただし東清鉄道の取得が困難な設定のためロシアの極東鉄道輸送力は弱く、ウラジオストクから東部戦線への輸送がボトルネックになる。[^u100]

日米からの軍需供給は、次のような機序で人的損耗を増やす（検討案）。[^u114]

| 物資供給の効果 | 戦場での帰結 |
|---|---|
| 防御火力と兵員装備の改善 | 戦線の保持が容易になり、損害を減らせる可能性 |
| 攻勢の持続能力の向上 | 戦闘期間・投入兵力が増え、累積死傷者が増える可能性 |
| 砲弾供給の増加 | 火力優位を攻勢の拡大に使う可能性 |
| 補充兵への小銃供給 | 新たな兵員を戦線へ投入しやすくなり、動員負担が増える |

兵器がある → 攻勢を続ける → 補充兵が必要になる → 農村の労働力が減る、そして鉄道が軍事輸送に逼迫して首都への食料輸送が悪化する。「ロシア軍の武器不足は改善するが、ロシア社会の戦争負担は史実以上になる」。物資不足のために攻撃できない軍隊より、物資があるために攻撃を繰り返す軍隊の方が人的損害を大きくすることもある。[^u114]

## 「19世紀軍隊のミンチ」シナリオ

日露戦争の教訓を欠いたロシア軍は、「新式の小銃や火砲を持ちながら、指揮・訓練・作戦思想が旧態依然」の軍隊になりうる。文字どおり19世紀の装備というわけではなく、普仏戦争・ボーア戦争・バルカン戦争から学ぶ機会はあった。[^u115]

仮想的な経過（確定ではない）[^u115]

| 年 | 経過 |
|---|---|
| 1914 | 東プロイセン・ガリツィアへ大規模攻勢、各個撃破される |
| 1915 | 日米から大量の小銃・砲弾が届き新部隊を編成するが、指揮官・下士官の養成が追いつかず新兵を前線へ投入 |
| 1916 | 歩兵・砲兵・工兵の協同が不十分なまま消耗戦が拡大 |
| 1917 | 将校・皇帝への忠誠が失われ、軍が革命鎮圧の組織として機能しなくなる |

「補充できるからこそ損耗を続けてしまう」。砲弾は半年で増産できても、中隊長・砲兵将校・参謀・下士官は育成できない。1915年以降のロシア軍は「兵器だけ近代的で、兵員と指揮組織が継続的に劣化する軍隊」となる。[^u115]

ここには皮肉がある。日本はロシアとの戦争を避け、1914年以降は連合国としてロシアに軍需品を供給したが、それが消耗戦を長引かせ、ロシア帝国の崩壊を早めてしまう。これは日本政府が望んだ結果ではない。[^u115]

## 1917年：帝政の崩壊と革命

臨時政府にとっても「戦争を続けられること自体が政治的に危険」である。軍需が潤沢なら、史実以上の大攻勢を企図する可能性すらある。[^u114] 史実以上に深刻な軍の崩壊はボリシェヴィキの政権掌握を促し、場合によっては史実以上に急激な崩壊となる。[^u115]

大戦全体の作業仮説（シナリオB：1918年終戦）では、1916年にロシア軍が大損害を受けて国内危機が深刻化し、1917年にニコライ2世の退位と急進的な革命でロシア軍が崩壊、1918年にロシアが単独講和し、日米に支えられた連合国がドイツを破る（検討案）。ロシアが早く崩壊するほど連合国の負担は大きく、それを日米が肩代わりできるかが終戦時期を決める。ロシアが1916年末頃に攻勢能力を失えば、1917年の西部戦線は史実より厳しくなる。[^u119]（→[第一次世界大戦と日本](world-war-one.md)）

# 影響

## 日本への影響

日本はロシアの戦時債務否認によって損失を被る。本世界線の日本にとってソ連は、地政学的な警戒対象であると同時に、「戦時債権の不履行という具体的経済問題を抱えた相手」となる。[^u114] 大戦中のロシアへの軍需供給代金が未払いであれば、日本の銀行団と政府は旧債務の否認に反発し、元老院の領主系金融資本も国交正常化に関与する（検討案）。[^u116]

ロシアの安定は日本にとって必ずしも悪いことではなかった。革命や内戦で極東の統治が崩壊すれば、沿海州・満洲の安全保障問題に日本が巻き込まれる。史実1918年以降のシベリア出兵は、本世界線では前提にできない。[^u093]

## 戦後秩序への影響

ボリシェヴィキの帝政公債否認は、帝政ロシア国債の最大保有国であるフランスと、日本に大きな金融損失を与える。各国のソ連承認をめぐる立場の違いと、米独ソが日英仏の既得権秩序の改定に利害を持つ1930年代の三角関係については、[ソ連承認問題と旧ロシア債務](../diplomacy/soviet-recognition.md)を参照。[^u116] 1917年のロシアがどうなるか（ソ連が成立するか）は、戦間期の米国の対独政策をも左右する最大の分岐とされる。[^u111]

# 史実との比較

| 事項 | 史実 | 本世界線 |
|---|---|---|
| 日露戦争 | 1904〜05年、旅順陥落・日本海海戦の敗北 | なし |
| 血の日曜日事件 | 1905年1月22日（露暦1月9日）、プチロフ工場の争議を発端にガポン神父の請願行進へ発砲 | ほぼ確実に起きる（日付・内容は同一とは限らない） |
| 1905年の帰結 | 十月宣言・国家ドゥーマ設置、1906年国家基本法で皇帝大権を維持 | 限定的改革の約束と軍による鎮圧。実質的な立憲化はほぼ不可能 |
| 陸軍改革 | 日露戦争の教訓による改革 | なし（旧態依然の指揮・訓練） |
| 大戦中の武器 | 不足 | 日米の供給で潤沢、かえって攻勢と損耗が拡大 |
| 1917年 | 二月革命・十月革命 | 同様の流れが有力（同じ指導者・日付・戦線状況とまでは確定しない） |
| 戦争離脱 | 1918年3月3日ブレスト＝リトフスク条約 | 1918年の単独講和が有力 |

史実の1905年は、十月宣言が自由主義者の一部を政権側に引き寄せて反対派を分裂させ、軍の大部分が政府側に残ったことが鎮圧の要因となった。[^u112][^u113] 大戦中の史実の経過としては、1914年タンネンベルクの敗北、1915年の大退却、1916年のブルシーロフ攻勢（墺軍に甚大な損害を与えたが露側も甚大な犠牲）、鉄道が前線補給と国内の食料・燃料供給を両立できなかったこと、1917年のケレンスキー攻勢の失敗と規律崩壊がある。[^u114][^u115]

# 却下・修正された案

* **1905年革命が起きないかもしれない案**：日露戦争がなければ血の日曜日事件や1905年革命への発展、十月宣言・ドゥーマ設置は不確実であり、専制が延命しうるという当初の見通しは、血の日曜日事件はほぼ確実に起き、起きれば帝国の延命は難しいという判断で修正された。[^u093][^u112]
* **1905年危機後の立憲化を分岐点とする案**：1905年危機を固定したうえで、ロマノフ朝が立憲化できたかを分岐点とする提案は、人民を撃った時点で譲歩の余地はないとの判断で実質的に否定された。[^u112][^u113]
* **1917年の戦争離脱を確定させない案**：ロマノフ朝存続・継戦（A）、退位と新政府による継戦（B）、急進化と単独講和（C）の三シナリオを並置し、ボリシェヴィキの政権掌握と1918年単独講和を史実ほど確実ではないとした当初の整理は、軍需が潤沢でも人的損耗は増えるという判断により、二月革命・十月革命・単独講和の流れを有力とする方向へ修正された。[^u100][^u114]
* **共和政ロシアの戦勝国化**：帝政崩壊後の新政府が戦争を戦い抜き、共和政ロシアが戦勝国として1919年の講和会議に参加する案は、ボリシェヴィキ掌握の可能性が高く評価されたことで後退した。[^u113][^u114]
