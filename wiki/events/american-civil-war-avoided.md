# 概要

本世界線の出発点となる第一の分岐点。アメリカ南北戦争が史実（1861〜1865年）よりもあっさりと終わる、あるいはそもそも起きずに南北が和解する。この結果、明治維新の経過は史実のように新政府軍（薩長）に一方的に有利には進まない、というのが世界線全体の起点となる仮説である。[^u001]

南北戦争の不在は、幕末日本に三つの経路で作用する。第一に、米国が1860年代を通じて対日外交・海軍活動を継続できるため、英国の対日貿易独占的地位と「英国＝薩長、仏国＝幕府」という列強の色分けが崩れ、幕府にも別の外交的選択肢が生まれる。第二に、戦時大量生産と戦後の余剰兵器払い下げが縮小し、日本への武器供給構造が変わる。第三に、米国が東アジアにより多くの海軍力を振り向けうるため、幕府にとっては技術導入の好機であると同時に、外国人殺傷や外国船砲撃に対する列強の反応が史実より強くなる危険も生む。[^u001][^u008]

この分岐は、直後に置かれる第二の分岐点である[桜田門外の変の失敗と井伊直弼の押込](sakuradamon-incident-failed.md)と組み合わされて、幕府が1860年代を乗り切る条件を作り出す。また世界線の全期間を通じ、「日本とアメリカ以外の環境・所与の条件は史実どおり」という前提のもと、米国は日本と並んで史実から変化した数少ない国家として扱われる。[^u002][^u047]

# 分岐の内容

## 確定している範囲

* アメリカ南北戦争は「史実より早期に終結する」か「回避されて和解する」。[^u001]
* その帰結として、明治維新は新政府軍に優位には進まない。[^u001]
* 世界線全体の前提として、日本とアメリカ以外の環境・所与の条件（清・朝鮮・欧州列強の内部条件など）は史実どおりとし、両国の変化が第三国に及ぼす影響としてのみ差異を扱う。[^u047]

後続の議論（1870年代の視察団、1880年代の日清交渉、1910年代の世界大戦など）では、一貫して「南北戦争は回避された」ものとして扱われており、事実上「回避」の側が採られている。[^u045][^u080][^u101]

## 時期の設定（検討案）

* 終結時期は「1862年以前」に置くのがよい。1865年の終結が少し早まるだけではなく、薩英接近・長州征討・幕府の軍制改革という重要な出来事が起きる前に、米国の対日外交の条件を変えられるからである。（検討案）[^u001]
* 世界線の暫定年表では「1861年：アメリカ南北戦争回避」とし、米国との外交・通商関係が継続して幕府の軍事近代化に新たな選択肢が生まれる、と整理される。（検討案）[^u002]
* 前年の1860年には万延元年遣米使節（2月日本出発、5月ワシントン到着）があり、この段階で強化された日米関係が戦争回避によってそのまま維持される、という接続が想定されている。（検討案）[^u002]

# 幕末日本への影響

## 列強の勢力均衡

| 項目 | 史実 | 本世界線（検討案を含む） |
|---|---|---|
| 米国の対日関与 | 1861年以降、内戦で大幅に縮小 | 外交・海軍活動を継続 |
| 英国の地位 | 日本貿易で圧倒的地位 | 突出した地位を築く展開が変化 |
| 列強の色分け | 英国が薩長寄り、仏国が幕府寄り | 米国が第三の選択肢として存在し、薩長の外交的優位確保の過程自体が変わりうる |
| 横須賀製鉄所 | 小栗忠順が当初米国の協力を検討したが、南北戦争で困難となり仏国に依頼 | 米国関与の余地が残る |
| 幕府の調達先 | 主に英仏 | 米国からの艦船購入・造船技術導入・海軍教育・軍事顧問招聘が選択肢に |

ただし米国が幕府を必ず支持するとは限らない。幕府との協力を強める可能性と、日本国内の政治対立に中立を保つ可能性は区別される。南北戦争が回避されれば米国の国内政治自体も史実と異なるため、ここで確定するのは「幕府が選べる外交政策の幅が広がる」ことまでである。[^u001][^u002]

## 武器供給の構造

| 世界線 | 幕末日本への影響 |
|---|---|
| 史実（1865年終結） | 戦後の余剰軍用銃（スペンサー銃・シャープス銃など）が輸出され、1868年の戊辰戦争に流入 |
| 1862年頃に早期終結 | 武器の放出が早まりうるが、生産量・種類は史実と異なる |
| 南北戦争そのものを回避 | 戦時大量生産と戦後払い下げが縮小し、武器供給の構造が変化 |

南北戦争がなければ新政府軍も史実と同じ条件では武装できない。ただしこれは幕府軍にも当てはまるので、武器不足だけで新政府軍が不利になるとは断定できない。[^u001]

## 甲鉄艦問題

史実の甲鉄艦（旧ストーンウォール号）は南軍向けに建造され、戦後に米国政府が取得、1867年に幕府が購入した。1868年4月の到着時には戊辰戦争が始まっており、米国は中立を理由に引渡しを保留し、1869年に新政府へ引き渡した。本世界線ではこの艦自体が建造・売却されない可能性があるため、「同じ艦が幕府に渡る」と考えるのではなく、「幕府がより早く米国から有力な軍艦を調達できたか」と問うべきだとされる。[^u001]

## 政治的帰結の見通し

軍事技術や外国の協力が変化しても、新政府軍の優位は近代兵器だけでは説明できない（鳥羽・伏見の戦いで新政府が獲得した「天皇の軍隊」としての正統性が決定的だった）。したがって南北戦争回避それ自体は幕府の存続を保証しない。一方で、米国が1860年代を通じて幕府と密接な関係を築き、海軍の整備や外交的信用を支えたなら、徳川家が新しい中央政府に大きな権限を持って参加する、あるいは王政復古そのものが別の形になる展開も開ける。[^u001]

AIが最初に示した仮想年表は次のとおりである（検討案。後に分岐点②以降の設定で大きく上書きされる）。[^u001]

| 時期 | 想定 |
|---|---|
| 1861〜1863年 | 米国が対日外交関与を維持し、幕府が米国の造船・軍事技術を活用 |
| 1864〜1865年 | 幕府の軍制改革が史実と異なる形で進展。英仏米の競合で薩長と幕府の外交関係も変化 |
| 1866〜1867年 | 第二次長州征討や大政奉還をめぐる交渉の条件が変わる |
| 1868年以降 | 武力衝突が起きても新政府の迅速な全国掌握は難しく、徳川家を含む政治的妥協・長期的な権力分担の余地が広がる |

実際の本世界線では、この後に置かれる[桜田門外の変の失敗](sakuradamon-incident-failed.md)、[水戸藩処分](mito-domain-disposal-1860.md)、[1861年公武協定](../diplomacy/kobu-agreement-1861.md)を経て、[1866年の無血の幕府解体](bloodless-dissolution-1866.md)へと進む。

## 「猶予」ではなく「圧力」になる可能性

南北戦争を回避した米国は、東アジアへ史実より多くの海軍力を振り向けられる。これは幕府にとって軍事技術導入の好機だが、外国人殺害や諸藩の外国船砲撃が起これば、米国を含む列強が史実より強力に反応する危険を意味する。つまり南北戦争の回避は、幕府に与えられた猶予を延ばすとは限らない。1860年代の日本は史実より列強の関与が強い環境で近代化を迫られる可能性があり、「米国が協力者になるか新たな圧力になるか」は大きな分岐とされる。[^u008]

この認識は、1863年頃を「外交・軍事指揮系統の統一の最初の期限」とする見方（[幕藩体制と中央集権化のジレンマ](../concepts/centralization-dilemma.md)参照）につながっている。[^u008]

# 後世への波及

南北戦争の不在は幕末だけでなく、世界線の全期間にわたって前提条件として参照される。各主題の詳細はリンク先に譲り、ここでは要点のみ示す。

| 時期 | 主題 | 南北戦争回避の効き方 |
|---|---|---|
| 1870年代 | [岩倉使節団と欧米視察](iwakura-mission.md) | 米国への関心が強まる余地。ただし回避によって米国のどの産業がどれほど発展したかは別途設定が必要[^u043] |
| 1870年代 | [アメリカ連邦制の受容と領主権の再定義](../institutions/federalism-reception.md) | 修正第13〜15条が史実どおりに成立するとは限らず、州権が史実の1870年代より強く残る。日本の領主たちは「広い州自治と全国共通の通貨・郵便・商取引制度は両立する」と見て領主権存続の論拠にする。奴隷制問題は自動的には解決しておらず、視察団はその矛盾も目にしうる[^u045] |
| 1870〜80年代 | [不平等条約改正](../diplomacy/treaty-revision.md) | 1860年代から日米関係が史実以上に緊密だった可能性[^u046] |
| 1882年 | [1882年漢城危機](imo-incident-1882.md) | 南北戦争のない米国が外交支援・仲介、あるいは戦争抑制を行う可能性[^u047] |
| 1888〜89年 | [対清賠償借款と講和の国際金融](../economy/indemnity-loan.md) | 回避で拡大した可能性のある米系金融の対日・対清関与が追加変数となる。米国の対日協調は独自の外交経緯に左右される[^u072][^u075] |
| 1889年以降 | [対米経済戦略](../economy/us-economic-strategy.md) | 回避した米国も人的物的損失を避けた一方、戦争を通じた連邦財政・銀行制度・鉄道・工業拡張が別の経過をたどる。「追いつくべき相手自体が動いている」[^u080] |
| 1914年以降 | [第一次世界大戦と日本](world-war-one.md) | 連邦政府の権限や国内政治が異なるため、1914年の大統領がウィルソンとは限らない。連邦軍制・徴兵制度も史実と異なりうる[^u101][^u119] |
| 1920年代 | [ワシントン会議と主力艦建造停止条約](../diplomacy/washington-conference.md) | 海軍制度の発展経路が異なり、史実の1916年建艦計画をそのまま採用できない[^u130] |

# 史実との比較

* 1853年ペリー来航、1858年日米修好通商条約により、開国当初の米国は日本に大きな影響力を持っていた。[^u001]
* 1861年の南北戦争勃発で米国は対日関与の資源を大きく制約され、英国が日本貿易で圧倒的地位を占めた。[^u001]
* 1865年の終結後、余剰軍用銃が日本へ輸出され戊辰戦争で使用された。佐賀藩は連発式のスペンサー銃を装備したが、旧幕府側にもスペンサー銃はあり、主力は双方ともエンフィールド銃などの単発銃だった。[^u001]
* 1860年は英仏軍が北京を占領し円明園を破壊した年でもあり、東アジアにおける列強の軍事的圧力は南北戦争の有無にかかわらず強まっていた。[^u008]

# 未決の論点

* 「早期終結」か「回避（和解）」かは明示的には確定していない。後続の議論では回避として扱われている。[^u001][^u002]
* 回避後の米国の具体像（奴隷制・州権問題の解決方法、産業・金融の発展度、対日・対清金融への関与度）は未設定。[^u043][^u045][^u080]
* 米国が幕府の協力者となったのか、新たな圧力となったのか。1860年代の日米関係の具体的な中身（艦船購入・顧問招聘が実際に行われたか）。[^u008]
* 回避された米国の大統領・政党・軍制（1914年時点の大統領がウィルソンかどうかなど）。[^u101][^u119]
