# 概要

1880年代半ば、清の朝鮮内政干渉が強まり廃位の危険が現実味を帯びると、朝鮮国王[高宗](../people/gojong.md)は漢城の日本公使に保護を求めて日本公使館に避難し、そこから政務を執った。[^u056][^u058] 日本は[朝鮮国独立保障（1884年）](../diplomacy/korea-independence-guarantee-1884.md)を掲げていたため、これを「自らが承認した独立国の正統な君主の保護」として受け入れた。[^u056]

高宗の避難によって日本公使館は事実上朝鮮の政権中枢となり、清にとっては公使館をどうにかすることが第一目標となった。[^u058] 1886年、公使館は清の使嗾が疑われる勢力に襲撃された（1886年漢城公使館危機）。この事件を受け、高宗の正式な許可のもと、日本帝国軍が邦人保護を名目に朝鮮へ派兵され、漢城に駐留した。[^u058][^u059] この駐留が、まもなく[袁世凱逮捕事件（1886年）](yuan-shikai-arrest.md)と[日清戦争（1887〜1889）](sino-japanese-war.md)を引き起こす前提となった。

# 背景

## 清の干渉と廃位の危険

清は宗主権の空洞化を恐れて朝鮮の政情不安に積極的に干渉し、李氏王朝内部の事情にも口を出し始めた（ユーザーの設定）。[^u056] 清が自ら冊封した国王を廃位すれば宗属秩序の正統性を損なうため、清はまず王宮警備・軍制・閣僚人事・外交官の任免に介入して高宗の実権を制限しようとした。[^u056] 1885年の清仏戦争終結により清は二正面戦争の恐れから解放され、対朝鮮政策は強硬化した（[清の対朝鮮政策と李鴻章](../diplomacy/qing-korea-policy.md)）。[^u057]

## 亡命構想から公使館避難へ

弱体化した李氏王朝が清を切って日本に亡命する可能性は「まあまあある」とされ（ユーザーの判断）、亡命者の類型として高宗本人、王世子・王族、開化派高官、王族と改革派の共同亡命が検討された。[^u054] そのうえで、清に「飛ばされ」そうになった高宗が日本公使に亡命を希望し、それが認められる展開の方が、日本の軍事介入より可能性が高いとされた（ユーザーの判断）。[^u056] 以後、本世界線では高宗が日本公使館から政権を執っていることが前提となった。[^u058]

# 経過

## 第一段階: 公使館への避難（検討案の経過）

| 段階 | 内容 |
|---|---|
| 清の干渉強化 | 清側が朝鮮軍の指揮系統や閣僚人事に介入し、高宗は王権が脅かされていると判断する |
| 保護要請 | 廃位または拘束を恐れた高宗が、側近や王世子とともに日本公使館へ避難する |
| 正統性の再確認 | 日本は高宗を引き続き朝鮮国王として承認し、身柄の安全を保障すると宣言する |
| 引き渡し要求 | 清は内政への不当介入と非難して身柄引き渡しを求めるが、日本は国王本人の意思に反する引き渡しを拒絶する |
| 日清の対峙 | 公使館の警備強化と清軍の行動で緊張が高まり、外交交渉が始まる |

[^u056]

日本は高宗を日本本土へ連れ出す必要はなく、漢城の公使館に滞在させたまま交渉する方が、朝鮮政府の継続性を主張しやすかった。この局面では「**高宗の身柄を確保した側ではなく、高宗の国王としての権威を政治的に利用できる側が勝つ**」。[^u056] 公使館が日本領になるわけではないため法的な問題は残るが、清軍が公使館に強制的に踏み込めば極めて重大な外交事件となる。日本は清に対し、高宗の地位と自由な政治活動の承認、清軍による王宮・政府機関の統制停止、閣僚任命・外交関係への不干渉、朝鮮の独自条約締結権を要求しうる立場を得た（検討案）。[^u056]

高宗はこれによって、日清間の勢力争いの受け身の対象ではなく、**清から自立するために日本の影響力を利用する政治主体**となった。開化派の政変を成功させる必要すらなくなる一方、高宗が開化派の改革を受け入れる保証はない。[^u056]

## 第二段階: 1886年漢城公使館危機

高宗が公使館に入った瞬間から、日本公使館は朝鮮の政権中枢となる。清が高宗を正統と認める限り、その命令で親清派官僚が更迭されかねない。そこで清にとっては公使館をどうにかすることが第一目標となるが、清が直接手を下す必要はなく、適当な人間に襲撃させればよい（ユーザーの設定）。[^u058]

| 段階 | 内容 |
|---|---|
| 公使館での政務 | 高宗が公使館から命令を発する |
| 反日・反高宗派の運動拡大 | 外国公使館に依存する国王への批判、王宮帰還要求 |
| 公使館襲撃 | 警備兵と襲撃者が交戦し、高宗の安全が脅かされる |
| 日本の緊急対応 | 日本政府が漢城への増援を検討 |
| 清の関与否定 | 清は関与を否定し、日本の行動を内政干渉と非難 |

（検討案の経過）[^u058]

清の狙いは高宗の殺害や王朝廃止ではなく、高宗を日本の保護から引き離すことであった。[^u058] ただし、清中央の命令、現地清国官僚の非公式な関与、朝鮮国内勢力の独自行動は区別されるべきであり、日本が区別せずに清の犯行と断定すれば自らの立場を弱める。[^u058]

1882年・1884年に続く三度目の公使館襲撃であり、今回は国王の身まで危険にさらされたため、日本は朝鮮政府の治安能力に強い疑問を抱いた。[^u058] 国内では[元老院](../institutions/genroin.md)の武家領主が強硬対応を求め、[衆議院](../institutions/house-of-representatives.md)も公使館員・居留民の保護を求めた。商工業者も朝鮮での安全を重視し、元老院の領主層と衆議院の商工・都市勢力が同じ外交要求で一致した。[^u058] 清が直接の戦争を避けて日本の影響力を削ごうとした結果、かえって日本に介入理由を与えるという逆説が生じた。[^u058]

襲撃後の分岐としては、高宗が公使館に残る（日本に継続的な警備・増援の理由）、王宮へ帰還する（清の影響力の再強化）、日本本土への避難を求める（在日の高宗と漢城の別政府の正統性争い）の三つが考えられた。[^u058]

## 第三段階: 高宗の許可による派兵

邦人保護の名目で、高宗の許可のもと朝鮮へ派兵することが決まった（ユーザーの設定）。[^u059] 派兵の根拠は三つあり、独立保障政策との整合上、特に第三が重要とされた。[^u059]

1. 既存の公使館警備権
2. 日本人居留民の生命・財産の保護
3. 朝鮮国王による正式な派兵要請・受け入れ

高宗の要請文は「我が国では政変が発生し、王室と外国人の安全が脅かされている。日本公使館および日本人居留民の保護のため、日本軍の派遣を認める」という趣旨のものと想定された（検討案）。[^u059] 清が、自らも正統と認める国王による外国軍の受け入れを否定するには、宗主権を持ち出すしかない。

| 任務 | 日本側の説明 | 政治的な問題 |
|---|---|---|
| 公使館の増強警備 | 邦人保護 | 既存の権利の延長として説明しやすい |
| 日本人居留地の警備 | 居留民保護 | 朝鮮側の警察権との調整が必要 |
| 高宗の身辺警護 | 国王からの保護要請 | 王室への政治的影響力が強まる |
| 漢城の広域治安維持 | 朝鮮政府の要請 | 朝鮮内政への介入となりうる |
| 清軍との交戦 | 正当防衛・国王保護 | 日清戦争への拡大 |

[^u059]

日本はまず限定派兵で高宗の安全を確保し、清に政治的圧力の停止を求めた。高宗は「日本公使館から政務を執り、日本軍の限定的駐留を自ら承認している現職の朝鮮国王」となったが、日本軍への依存が強まれば日本の要求も拒みにくくなる危険を抱えた。[^u059] 清は清仏戦争を終え、定遠・鎮遠を加えて、日本軍の撤兵と高宗の王宮帰還を要求しうる状況にあり、相互撤兵の押し付け合いで戦争の危険は急上昇した。[^u059]

# 帰結

帝国軍の駐留は高宗にとって奇貨だったが、親清派の捜査を可能にし、清の介入の「証拠」が出るリスクも高めた。[^u060] 日本の後ろ盾を確信した高宗は袁世凱の捕縛へと先走り、事態は[袁世凱逮捕事件（1886年）](yuan-shikai-arrest.md)へ進んだ。[^u061] 後年の整理では「1886年 高宗が日本公使館へ避難。袁世凱捕縛事件が発生」とまとめられている。[^u077]

# 史実との比較

- 史実の1896年2月、高宗は王太子とともに漢城のロシア公使館に避難し、約1年間そこで政務を執った（俄館播遷）。背景は日本の内政介入と1895年の閔妃殺害事件であった。公使館を王権維持の拠点とする発想には史実の対応例がある。[^u054][^u056]
- 史実の1882年壬午軍乱では反乱兵・民衆が日本公使館を襲撃して日本人に死者が出、1884年甲申政変では日本公使館が焼失した。[^u058]
- 史実の1882年済物浦条約は日本公使館警備兵の漢城駐留を認め、1885年天津条約は日清両国の撤兵と再派兵時の相互事前通告を定めた。[^u059]
- 史実の1894年7月には日本軍が朝鮮王宮を武力占領したが、本世界線では逆に高宗自らが日本に軍事的保護を求めており、政治的な出発点が異なる。[^u059]

# 却下・修正された案

- **日本本土への亡命**: 当初は高宗または王世子が日本公使館の保護を経て日本へ渡航し、元老院で滞在資格・保護費用を審議する仮想年表（1886年政変未遂→1887年渡航→1887〜88年審議）が示された。[^u054] その後、高宗を漢城の公使館に留めたまま政務を執らせる方が政府の継続性を主張しやすいとして、公使館避難が前提となった。[^u056][^u058]
- **公使館避難による日清戦争回避**: 清仏戦争中であれば、清が高宗の帰宮と引き換えに軍事介入を控える妥協もありうるとされたが、清仏戦争は1885年に終結するため、その後も同じ譲歩に応じるかは別問題とされた。[^u056][^u057]

# 未決の論点

- 避難の正確な年。検討の過程では「1885年頃」「1886〜1887年」「1886年頃」と揺れており、後の整理では1886年とされる。[^u056][^u057][^u058][^u077]
- 同行者（王世子・側近）の範囲。[^u056]
- 公使館襲撃の実行主体（清中央の命令／袁ら現地官僚の非公式関与／朝鮮勢力の独自行動）の具体的な設定と、襲撃後に高宗が公使館に残ったか王宮に戻ったか。[^u058]
- 派兵の規模と任務範囲、1882年・1885年の協定に相当する取り決めが本世界線でどのような文言だったか。[^u059]
