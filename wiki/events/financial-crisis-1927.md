# 概要

1927年金融危機は、1920年代の日本で金融不安を大規模な信用収縮なしに処理することに失敗した結果として起きた国内の銀行危機である。[^n1][^n2][^e099]

危機の原因は史実と同じである必要はなく、本世界線に固有の構造から説明される。第一次世界大戦期から重工業・海運・海外投資が急拡大したことで、戦時好況期の企業向け融資の不良債権化、長期設備投資を短期預金・短期借入で賄う期間の不一致、そして**領主系銀行による系列企業への過剰融資**が積み重なった。日本は巨額の対外債権を持っていたが、長期の対英債権は国内銀行の短期的な支払能力を保証しなかった。[^e099]

1926年に一部銀行の不良債権問題が表面化し、1927年に取り付け・破綻・信用収縮が起こって実質成長率は−2.0%となる。1928年の銀行整理と資本再編を経て、1929年には国内金融市場がおおむね正常化した。危機後には銀行監督・系列融資の監督・中央銀行の「最後の貸し手」機能などの制度改革が議論された。[^e099] **金本位制から離脱していても、個々の銀行の経営健全性は保証されない**ことを示した事件である。[^e099]

危機は「領主系銀行を政府が救済するのか」をめぐって**近代封建制の経済的正当性が初めて全国政治で問われた事件**である。[^n3][^p001] しかし銀行監督制度の強化は1932年までの大幅強化、1937年までの抜本改革のいずれも実現せず、1937年にも金融制度上の脆弱性が残った。[^n4] 代わりに**領主家資産と領国政府財政の制度的分離**が大きく進み、[^n4]危機への政治的対応は「金融業全体の規制」ではなく「領主家の企業活動から公的財政を保護する」方向へ向かった。[^p008][^p009] 領主家の側では、各家の資産毀損（家ごとに0〜80%）、領主間の相互支援体制の崩壊、1927〜37年に20家の[領主権奉還](../institutions/lordship-surrender.md)という第二の奉還の波が生じた。[^p022][^p023][^p047]

# 1920年代経済の諸条件

## 1920年代経済史の帰結

1920年代の日本経済の経路を決めた5項目の成否は次のとおりである。[^n1][^e098][^e099]

| 事項 | 結果 | 歴史的帰結 |
|---|---|---|
| 第一次世界大戦後の反動恐慌から早期に回復する | 成功[^n19] | 1922年頃までに回復 |
| 1920年代の民間設備投資が継続的に拡大する | 成功[^n20] | 1920年代を通じて資本蓄積が進展 |
| 戦時物価の調整を緩やかに進める | 際立って成功[^n21] | 深刻なデフレを回避 |
| **1920年代の金融不安を大規模な信用収縮なしに処理する** | **失敗**[^n22] | **銀行破綻・信用収縮・一時的な景気後退** |
| 対英戦時債権の回収・借換・再投資が円滑に進む | 成功[^n23] | 回収・借換・海外投資への転換が進展 |

[^e099]

1920年代の日本経済は、実体経済と物価の安定には成功したものの、金融制度の脆弱性が一時的に顕在化した。1920年代後半の金融危機と長期的な物価安定は両立する。[^e099]

この失敗は「危機を未然に防ぐこと、初期段階で収束させることに失敗した」ことを意味し、1930年代まで金融システムが崩壊したままだったわけではない。[^e099] 危機の年1927年は、国民所得の年次表（1927年 −2.0%）と国際収支の積算（1927〜29年の貸倒等 −3億円）に組み込まれている。[^n2][^e099][^e100]

# 原因

本世界線では第一次世界大戦期から重工業・海運・海外投資が急速に拡大しており、次の構造的問題が生じていた。[^n3][^e099]

| 原因 | 内容 |
|---|---|
| 不良債権化 | 戦時好況期に拡大した企業向け融資が焦げ付く |
| 期間の不一致 | 長期の設備投資を短期預金・短期借入で賄う |
| 系列融資 | **領主系銀行による系列企業への過剰融資**（領主系企業集団への融資集中） |
| 国内流動性の不足 | 海外債権を多く保有する一方、国内で利用可能な流動資金が不足 |
| 信用不安の連鎖 | 銀行間の信用不安と預金取り付け |

[^e099]

とりわけ、領主系企業集団の存在のもとでは系列企業への融資集中が大きな問題となった。[^e099] 本世界線の領主家は領内の鉄道・製鉄所・港湾・電力事業などを経営する企業集団を抱え、その系列銀行が集団内の企業に資金を集中させやすい（→[近代封建制](../concepts/modern-feudalism.md)、[領主権](../institutions/lordship-rights.md)）。

## 対外債権と国内流動性

**対英戦時債権が健全であっても、それが長期債権である以上、国内銀行の短期的な支払能力を直接保証するわけではない**。[^e099] これは大戦期から続く構造の帰結である。大戦期の円建て戦時信用では、日本の銀行団が英国政府の円建て債権を保有して輸出企業に預金で代金を払ったため、銀行は換金困難な長期債権を抱えながら国内の短期決済や預金引出しに応じなければならなかった（→[金本位制離脱と管理通貨制](../economy/gold-standard.md)）。対外債権の多くは金ではなく商業信用や売掛金として存在し、直ちに金へ転換できる資産ではなかった。[^e041] 1914〜18年の戦時黒字65億円のうち40億円が円建ての対英売掛債権であった（→[円建て対外債権と円の国際化](../economy/yen-claims.md)）。[^e100]

1925年の通貨制度改正では、発券の裏付けとして商業手形・担保付き貸出・流動性の高い対外債権などの適格資産が重視されたが、商業手形を基準にする運営には、景気が縮むと信用供給まで縮むという欠点があった。[^e047]

| 1929 | +5.0% | 130.6 | 100 | 229.1億円 |

## 国際収支と対外資産

| 年 | 商品貿易 | サービス | 純所得・移転 | 経常収支 |
|---|---:|---:|---:|---:|
| 1927 | −5.5 | 2.5 | 2.0 | −1.0 |
| 1928 | −4.0 | 2.8 | 2.2 | 1.0 |
| 1929 | −3.5 | 3.1 | 2.4 | 2.0 |

（単位：億円）[^e100]

国内銀行が流動性危機に陥れば、対外資産を大量に持つ国でも海外証券や短期債権を売る可能性がある。一方、長期の対英債権や海外直接投資は簡単には換金できない。危機に伴う対外資産の処理は次のとおりである。[^e100]

| 資産処理 | 金額 | 純対外資産への影響 |
|---|---:|---:|
| 海外証券の売却・外貨預金化 | 5億円 | なし |
| 対外資産を用いた外国借入の返済 | 3億円 | なし |
| 輸入代金等への充当 | 2億円 | 経常収支に反映済み |
| 外国債権の貸倒・売却損等 | 3億円 | −3億円 |

[^e100]

このほか、前田家など領主家の国際金融資本は危機で海外資産を失い、海外直接投資は1937年には30億円にとどまった。[^n6][^e100][^p091]

信用収縮は輸入需要も減らすので、金融危機が必ず経常収支を悪化させるわけではない。純対外資産は1926年末79億円から1929年末78億円へと小幅に減るにとどまり、海外資産の流動性や保有主体は変わるが、対外純資産そのものは大きくは崩れなかった。[^e100] 詳細は[国際収支と対外資産（1914〜1937）](../economy/balance-of-payments.md)を参照。

# 危機後の制度改革案

危機後には次の改革案が議論された。[^n3] しかし銀行監督・系列融資の監督を中心とする金融制度の改革は**実現しなかった**（後述「政治的帰結」）。実現したのは、領主家と領国政府の会計・債務の分離という別系統の改革である。[^p008][^p009]

| 改革項目 | 内容 |
|---|---|
| 銀行監督 | 帝国共通の財務報告・検査制度 |
| 系列融資 | 特定企業集団への融資集中を監督 |
| 銀行再編 | 不健全な銀行の合併・清算 |
| 長期金融 | 設備投資向けの長期信用機関を拡充 |
| 中央銀行 | 最後の貸し手機能を制度化 |
| 流動性管理 | 預金と貸出の期間不一致を監督 |

[^e099]

これらの改革が実現していれば1937年の比較的健全で大規模な金融市場につながるはずであったが、銀行監督の大幅強化（1932年まで）と抜本的改革（1937年まで）はいずれも失敗した。1937年の金融部門は、規模は大きいものの制度上の脆弱性を残した市場となった。[^n7][^e099][^p008][^p009] 1937年の金融部門は、マネタリーベース52億円、M2 280億円、銀行部門総資産360億円、国内民間貸出160億円（いずれもGDP400億円基準）で、中央銀行のバランスシートには民間手形の再割引・銀行貸出（GDP比4%）が計上され、通貨供給の増加経路は民間信用の拡大と中央銀行の流動性供給とされる。[^e093][^e099] 改革案で銀行監督が「帝国共通」とされている点は、領国ごとに分立しがちな本世界線の制度の中で、金融監督を帝国レベルに集約しようとしたことを意味する。[^n8]

# 政治的帰結

## 争点化

領主家は領内の銀行・企業を抱えるため、危機は「**領主系銀行を政府が救済するのか**」という巨大な政治問題になった。衆議院では「税金で領主系金融資本を救済するのか」という批判が、元老院では「金融システム全体を守る必要がある」という主張が出た。[^n3][^p001]

## 1927〜1937年の関連事項の成否

| 事項 | 結果 |
|---|---|
| 金融危機を契機に銀行監督制度が大幅に強化される（1932年まで） | 失敗[^n24] |
| 領主家資産と領国政府財政の制度的分離が進展する（1932年まで） | 際立って成功[^n25] |
| 金融危機が領主制そのものに対する大規模な批判運動を引き起こす | 失敗[^n26] |
| 既成三党が大衆政党としての組織を維持・発展させる | 失敗[^n27] |
| 積極財政派が1932年までに政権の中心勢力となる | 成功[^n28] |
| 領主家資産と領国財政の分離が全国的に定着する（1937年まで） | 成功[^n29] |
| 銀行監督制度の抜本的改革が実現する（1937年まで） | 失敗[^n30] |

[^p008][^p009]

## 公私財政分離

公私財政分離は際立った成功を収め、[^n25]公私財産の区分、公会計と家産会計の完全分離、領主家債務を領国政府が当然には承継しない債務分離、領主家企業への公的債務保証の規制、帝国共通の会計基準による領国財政監査などが成立した。領主家の企業が破綻しても、それだけで領国政府が財政破綻したり領主権が失われたりはしない。[^p008] 1927年以降は、法定拠出金のうち領国の人口・歳入に連動する分の負担主体も領主家門から領国政府へ移り、支払能力のない領国には猶予・減額・免除の制度が設けられた。[^n9][^p075] 詳細は[家門会計・法定拠出金と公私財政分離](../economy/household-accounts.md)を参照。

島津家・黒田家の経営危機は、この改革を促した主要な事件である。[^n3][^p039][^p043]

## 政党政治への影響

反領主制運動は広がらず、領主制への批判は廃止論ではなく制度改革として吸収された。[^p008] 1920年代の企業献金・名望家資金で拡大した既成政党は、金融危機と恐慌で組織の維持が難しくなった。[^p008] 1930年の元老院改選は、金融危機と領主金融圏の動揺を強く反映した改選となり、改選直後に国民進歩党・社会民権党[^n10]の開発・社会政策連立内閣が成立した。[^n3] →[政党の系譜と衆議院の議席推移（1876〜1937）](../politics/political-parties.md)、[内閣の系譜と政党内閣の慣行（1867〜1937）](../politics/party-cabinets.md)[^p008][^p023]

# 領主家・華族への影響

## 領主間金融の動揺

| 事項 | 結果 |
|---|---|
| 1927年以降の金融危機によって中小領主家の財政難が広範に発生する | 成功[^n31] |
| 1927年以降の金融危機でも領主間の相互支援体制が維持される | 失敗[^n32] |
| （その他199家）1927年以降の金融危機で存続領主の家産が保全される | 失敗[^n33] |

[^p022][^p023][^p066]

大領主系の金融機関・家産企業が資産を毀損し、中小領主への融資・保証を縮めると、中小領主は奉還、[諸侯共済会](../economy/lord-financial-spheres.md)への加入、公私分離による領国財政の保護という三方向に分かれた。銀行監督の改革が繰り返し失敗していることから、危機は金融制度全体の改革ではなく、領主家の支配関係と領国財政の再編で処理された。[^n3][^p023] 1927年に269家あった領主は1937年に249家となり（20家が奉還）、金融圏の所属家数は黒田系17→6、島津系15→7と大きく減って、諸侯共済会系が40→49へ増えた。[^n11][^p077] ただし財政難が広範に起きても、公私分離が成功していたため家の経営破綻が直ちに奉還にはつながりにくく、奉還は減免制度があっても再建できなかった家に限られた。[^p022][^p075]

家産の推計では、危機前→最低→1937年の実質純資産（億円、1937年価格）は、徳川宗家74.21→66.79→90.16、前田家44.00→29.70→41.58、井伊家27.25→26.57→39.86、島津家23.24→10.46→15.69、黒田家19.63→5.89→9.42である。黒田家は危機後に60%回復しても危機前の半分以下にとどまり、井伊家はほぼ無傷で危機を通過して前田家に並ぶ経済力を得た。[^n13][^p069][^p096] 預金銀行を持たない井伊家・佐竹家が危機に強かったことは、危機の原因を領主系銀行の系列融資に求める見方と整合する。[^p053][^p054]

* **九州の信用収縮**: 島津・細川・黒田の九州三大領主がいずれも危機対応に失敗し、九州では信用収縮が深刻になった。その空白を諸侯共済会・独立系・帝国系の金融機関が埋めた。[^n3][^p043]
* **北海道開発金融**: 福井松平・津軽・黒田などの北海道投資が大きく損なわれ、北海道の開発金融市場は深刻な信用収縮に陥った。一方、北海道新興領主5家は危機を軽微な損失で通過した。[^n14][^p062][^p065]
* **中堅20家**: 地域別にみると、関東・中部・近畿（近畿はとりわけ良好）は危機を回避し、東北・中国（とりわけ深刻）・四国・九州は失敗した。[^n15] 中国の津山松平家は大領主に匹敵する資産の大半を失い、資産売却と債務整理で独立を保った。[^p064] →[中堅・中小領主と北海道新興領主](../economy/minor-lords.md)

## 無領華族・実業家華族

* 1927年以降の金融危機で多数の実業家華族が爵位を返上した。[^n16] 経営する銀行・企業の破綻に対する社会的責任などを理由とする例外的な行為で、返上は実業家華族168家のうち27家（16.1%）である。[^n17][^p035][^p083]
* 存続した実業家華族の家産も保全されず、危機後の有力実業家華族への資産集中も進まなかった。[^n18] この結果、独立系実業資本は少数の総合財閥ではなく、多数の有力な企業集団が並立する構造となった（→[独立系企業集団と資本系統（1937）](../economy/business-groups-1937.md)）。[^p083]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 発生年 | 1927年（昭和金融恐慌） | 1927年[^n2] |
| 通貨制度 | 金輸出禁止下、兌換制度は法制上存続 | 1925年に金本位制を法的に廃止済み |
| 主な原因 | 震災手形の処理、特定商社への過剰融資など | 戦時融資の不良債権化、期間の不一致、領主系銀行の系列融資、長期対外債権と国内流動性の不一致 |
| その後 | 1930年の金解禁と昭和恐慌 | 1928年に回復、1929年に正常化、1930年代は公共投資による浅い恐慌 |
| 制度的帰結 | 1927年銀行法による銀行合同の推進 | 銀行監督の改革は失敗し、領主家資産と領国財政の分離が進む |
| 政治的帰結 | 若槻内閣の総辞職、田中義一内閣の成立 | 領主系銀行の救済が争点化し、1930年に進歩・民権連立内閣[^n3] |

（史実欄の原因は一般的な史実の要約）[^e099]

史実では1920年代を通じて物価の大幅な下落が続いた（日本銀行の卸売物価指数は1920年343.2から1929年219.8、1900年＝100）。本世界線では戦時物価の調整が緩やかに進み、1920〜29年の物価下落は−12.3%にとどまっており、危機は深刻なデフレの中ではなく、比較的安定した物価の下で起こった銀行部門の危機である。[^e098][^e099]
