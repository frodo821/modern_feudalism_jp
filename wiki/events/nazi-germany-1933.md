# 概要

1933年は、国際経済秩序と国際安全保障秩序が同時に再編された年である。最大の転換点はドイツのナチス政権成立であり、1933年1月30日のヒトラー首相就任とそれに続く独裁体制の確立は、本世界線でも史実どおり起きた。[^e012][^e054] ヴェルサイユ条約への反発、世界恐慌と大量失業、米国資本への依存、1931年の銀行危機、議会政治の機能不全、共産主義への反発というナチス台頭の背景は、本世界線でもほぼそのまま残っていたからである。[^e054]

ただし、ナチス政権が成立した時点で、日英はすでに[日英海上通商防衛協定](/diplomacy/anglo-japanese-maritime-defense-agreement.md)と第一追加議定書、円・ポンドの通貨協力、[オタワ会議](/diplomacy/ottawa-conference-1932.md)を通じた経済協力を備えていた。史実のように**ドイツの台頭を契機として日本の外交的孤立が解消され、日独が接近する展開にはならない**。[^e054] 日本は国際連盟に残留し、軍縮・通商秩序の維持側に立った。

ドイツの再軍備をめぐっては、欧州の勢力均衡を重視してドイツに**対仏軍備均等**まで認める米国と、再軍備自体に反対する日英との間に外交的対立が生じた（ユーザー設定）。[^e056] ドイツは1933年10月に史実どおりジュネーヴ軍縮会議を離脱し国際連盟脱退を通告したが、米国を「軍備平等権に比較的理解を示した大国」として扱うようになった。[^e056]

# 背景：1932年末の前提

1932年末までに、本世界線では次の条件が成立していた。[^e054]

* [ロンドン海軍軍縮条約](/diplomacy/london-naval-conference-1930.md)による米英日の海軍総量規制（100:85:65）。
* 日英海上通商防衛協定（1930年）と第一追加議定書（1932年）。
* [1931年の欧州通貨危機](/events/currency-crisis-1931.md)を経た円・ポンド間の通貨協力と、オタワ会議を通じた経済協力の制度化。
* 日本国内での公債による公共資本形成（→[1925年財政原則と恐慌期の公共投資](/economy/fiscal-principles-1925.md)）。
* 中国における[中国諸省聯合](/diplomacy/china-federation.md)と[中華民国](/diplomacy/republic-of-china-canton.md)の軍事的膠着、国共合作の制限付き存続。

満洲事変は起きず、日本は1933年3月の国際連盟脱退通告もしない。[^e054]

# ドイツの制約と接近可能国

## 制約条件（検討案）

1933年のドイツは登録失業者600万人超、工業生産は1928年比で約3分の1減で、夏には金・外貨準備が最低限の輸入の約1か月分にまで落ち込んだ（史実）。[^e055] 本世界線ではこれに日英経済圏の形成が加わる。

| 制約 | 深刻度 | 備考 |
|---|---|---|
| 大量失業 | 非常に高い | |
| 外貨準備不足 | 非常に高い | 日英経済圏形成の影響 |
| 対外債務 | 高い | |
| 工業製品市場 | 高い | 日本との競争強化 |
| 食料 | 中〜高 | |
| 石油・天然ゴム | 非常に高い | |
| 鉄鉱石・非鉄金属 | 高い | |
| 海上輸送 | 中〜高 | 日英の海運影響力 |
| 軍備制限 | 高い | |

[^e055]

**日本の財政拡張の限界が主として国内の信用・供給能力にあるのに対し、ドイツの限界は国際収支にある**。[^e055] 日英が1933年から対独資源輸出を制限するとは考えにくく、ドイツの問題は円・ポンドなど決済通貨の獲得であった。恐慌下で各国が余剰工業生産力の行き先を探すなか、ドイツは特に厳しい立場にあり、ナチス成立の経済的条件は残っていた。[^e046][^e055] 中華民国への経済進出という選択肢もあったが、民国の財政基盤は弱く、ドイツの余剰生産力を吸収できるほどの市場ではなかった。[^e054]

[^e055]

史実以上に重要になるのはイタリア・東南欧・中華民国・米国である。1934年のシャハト新計画以降、ドイツは二国間清算協定で東南欧貿易を拡大した（史実）。本世界線では、資本供給と資源購入を担い、円・ポンドで国際決済を行う比較的開放的な**日英経済協力圏**と、外貨不足のもと清算勘定で管理貿易を行う**ドイツの東南欧経済圏**とが対比される（検討案）。[^e055]

ソ連とドイツは経済的補完性が高いが、ナチスの反共主義と東方拡張思想で関係は不安定である。ソ連は日本・米英からも設備を調達できるため、対独依存の理由は史実以上に弱い。[^e055]

## 中独関係と国共合作（検討案）

全国統一に失敗し、財政が脆弱で、日英が支援する聯合と対立する中華民国にとって、ドイツは工業化・外国権益の再編・日英秩序への対抗で共通利益を持つ相手である。しかし民国はソ連の援助と中国共産党の組織力も必要としており、ドイツが反共を求めれば内部対立が激化する。**1933年のナチス政権成立が、国共合作を再び破綻の危機に追い込む外的要因になる**可能性がある。[^e055]

# 日独関係

史実の日独には、国際秩序への不満、反共主義、軍備制限からの離脱という共通点があった。しかし本世界線の日本は既存の国際経済秩序から大きな利益を得ている。[^e054]

| 争点 | 日本 | ドイツ |
|---|---|---|
| 国際連盟 | 残留 | 脱退へ |
| 海軍軍縮 | 条約体制の維持 | 軍備制限の撤廃 |
| 中国政策 | 聯合・既存契約の保護 | 中華民国への経済進出 |
| 国際貿易 | 市場開放・資源調達 | 外貨不足・輸出市場確保 |
| 英国との関係 | 海上通商防衛同盟 | 欧州外交上の交渉相手 |
| ソ連との関係 | 警戒しつつ通商可能 | ナチスの反共主義 |

[^e054]

日独間で外交的・経済的な協力が行われる余地は残るが、反共主義だけで軍事的に接近する理由は乏しい。むしろ中国では両国が異なる政治勢力を支援しているので、経済的な競争関係が続く。[^e012][^e054]

## 日英同盟の構造問題

英国がドイツとの防衛戦争に入り、ドイツが英国商船を攻撃すれば、1932年の第一追加議定書により日本にも共同防衛義務が生じる。英国自身が始めた侵略戦争であれば日本は免責される。日本政府は英国の欧州外交に無関心ではいられないが、協定は外交政策の共同決定権まで定めていないので、日本が英国の対独政策を拘束できるわけではない。**軍事的義務を共有しているが、外交的意思決定は独立しているという問題**が、1933年以降の日英関係に現れた。[^e054] この欠陥は1935年のエチオピア危機で顕在化する（→[第二次エチオピア戦争と対伊制裁](/events/second-italo-ethiopian-war.md)）。

日本にとってドイツの再軍備は遠い欧州の問題ではなく、英国海軍が欧州に吸収されることで自国の通商防衛に響き、将来自らが負う軍事的義務にも関わる問題であった。このため日本は史実より欧州の安全保障情勢に強い関心を持つ。[^e012][^e056]

# ドイツ再軍備とジュネーヴ軍縮会議

## 米国：対仏均等までの容認

1933年のドイツは、フランス（ポーランド・小協商と提携）、イタリア（オーストリア問題）、ソ連（ナチス政権成立で関係悪化）、英国（日本との防衛同盟）と対立し、日本との軍事的接近も期待できない孤立状態にあった。この観測が正しいなら、ドイツがフランスと同程度の陸軍を持っても欧州の均衡は直ちには崩れない。米国の主要な軍事的懸念は依然としてレッド・オレンジ連合（日英）にあり、独仏均衡で英国が欧州に兵力と関心を割くことは米国の戦略上も不都合ではない。こうして米国は、欧州均衡政策としてドイツに**フランスとの軍備均等**まで認めた。[^e056] ただし基準はフランス本国軍であり、フランスとその同盟国の合計との均等までは認めない。[^e056]

## 日英：再軍備自体に反対

日英の対独政策の基礎は欧州の勢力均衡よりも国際通商秩序の維持にあり、ヴェルサイユ条約による軍備制限を撤廃する積極的理由に乏しい。[^e056]

| 懸念 | 英国 | 日本 |
|---|---|---|
| 欧州での軍事的緊張 | 本国の安全保障 | 英国向け投資・債権の安全 |
| 軍備拡張競争 | 財政負担の増大 | 公共投資・経済成長への悪影響 |
| 海軍再建 | 欧州航路への脅威 | 世界的な通商防衛負担の増大 |
| 領土問題の武力解決 | 欧州秩序の不安定化 | 国際契約秩序への悪影響 |
| ドイツの経済統制 | 欧州市場への影響 | 国際貿易・決済への影響 |

英国は日本との協定で極東方面の負担を軽減できるため、史実より対独宥和の必要性が低い。[^e056]

## 各国の立場（検討案）

| 争点 | 米国 | 日英 | フランス | ドイツ |
|---|---|---|---|---|
| 軍備平等権 | 容認 | 原則容認 | 条件付き容認 | 強く要求 |
| ドイツ陸軍の増強 | 対仏均等まで容認 | 反対 | 反対 | 要求 |
| フランス陸軍の削減 | 支持 | 条件付き支持 | 消極的 | 要求 |
| ドイツ空軍の保有 | 制限付き容認 | 反対 | 強く反対 | 要求 |
| ドイツ海軍の増強 | 慎重 | 強く反対 | 反対 | 要求 |
| ヴェルサイユ条約の一方的破棄 | 反対 | 反対 | 反対 | 選択肢とする |

米国は軍備の平等化をドイツ側の増強でも実現できると考え、日英は既存軍備の削減で実現すべきだと主張した。[^e056]

## 米国主導の妥協案（検討案）

本世界線では、史実の英国のマクドナルド軍縮案に相当する妥協案を米国が主導する。内容は、ドイツの軍備平等権の正式承認、ドイツ陸軍の段階的増強、フランス本国陸軍との均等を最終上限とすること、国際的監督、攻撃的兵器と海軍の別途制限、欧州諸国間の不可侵協定である。日英仏は平等権を将来の目標としては認めつつ、現段階での増強には反対した。[^e056]

## ドイツの離脱

日英仏の反対を突破できず、ドイツは1933年10月14日に軍縮会議を離脱し、19日に国際連盟脱退を通告した（史実どおり）。その後ドイツは、米国を自国の軍備平等権に比較的理解を示した大国として扱い、日英仏をヴェルサイユ体制の維持勢力として批判した。ただしこれだけで米独が同盟関係になるわけではない。[^e056] 米独関係の全体像は[戦間期の米独接近と米国内の宣伝戦](/diplomacy/us-germany-relations.md)を参照。

## 通貨と世界経済会議

1933年4月の米国の金本位制停止で、三国はいずれも金本位制を離れた。日本は1925年に管理通貨制へ移行し公債で公共資本を形成、英国は1931年に金兌換を停止して低金利政策、米国は1933年に金本位制を停止しニューディール政策に向かった。米国の転換は国際的な金本位制復帰の可能性をさらに下げたが、米国の景気回復は世界の資源・工業製品需要を回復させる。日英米は安全保障上は対立しつつ、恐慌脱出の利益は共有していた。[^e054]

1933年6〜7月のロンドン世界経済会議で、管理通貨制の運営経験が約8年になる日本は、金本位制の復活を求める国でも通貨切下げで輸出拡大を優先する国でもなく、**国際決済と貿易金融の安定を重視する債権国**として参加した（検討案）。金本位制復帰には消極的、為替安定・世界物価の回復・関税障壁の縮小・国際信用供与には積極的、通貨政策の統一には慎重、資本形成を伴う公共投資には肯定的であった。[^e054]

# その後の展開（1934〜1936）

次の分岐点は1934年のオーストリア危機と、1935年のストレーザ戦線およびエチオピア侵攻とされた。イタリアはドイツの再軍備には反対しつつ自国の領土拡張は進めたいという矛盾を抱えていた。[^e056] 1935年4月に英仏伊の対独協調としてストレーザ戦線が成立したが、本世界線でも維持できず、エチオピア問題で崩壊した。[^e057][^e059] 米国は対伊制裁に協力せず、その政策は結果的に独伊の孤立を緩和した。1936年秋にはローマ＝ベルリン枢軸が成立した。[^e059] 米独伊は同一陣営ではなく、独伊は領土秩序の変更、米国は欧州の勢力均衡と通商の自由、日英は既存秩序と海上通商の安全をそれぞれ目指していた。[^e059]

ドイツの再軍備と独伊の現状変更政策は、[第二次ロンドン海軍軍縮会議](/diplomacy/second-london-conference.md)で英国が増枠を求める根拠となった。英国はドイツ再軍備自体に反対しているため、史実の英独海軍協定（1935年6月、独海軍を英の35%まで容認）は本世界線では成立しない可能性が高い（検討案）。[^e060]

| 日本の国際連盟 | 1933年3月に脱退通告 | 残留 |
| 日独関係 | 1936年日独防共協定へ接近 | 反共だけでは接近せず、中国で経済的競争 |
| ドイツ再軍備への米国の態度 | 一般軍縮を重視しつつ一定の譲歩 | 対仏均等まで容認（一歩踏み込む） |
| 英国の対独政策 | 宥和、1935年英独海軍協定 | 再軍備自体に反対、対独宥和の必要性が低い |
| 中独関係 | 1920年代末から国民政府と軍事・工業協力 | 中華民国と接近するが、国共合作を揺るがす要因に |

史実では1932年12月11日の五カ国宣言でドイツの軍備平等権が原則承認されたが、それは一般軍縮と各国の安全保障の両立を条件としていた。ルーズヴェルトは1933年8月、軍縮会議の失敗を避けるには一定の譲歩が必要との意向を示している。[^e056]

# 未決の論点

* ドイツの海軍再建の規模と、英独海軍協定が実際に不成立となるか。[^e060]
* ルーズヴェルト政権の対日英政策と米国の通貨政策の詳細、ロンドン世界経済会議の帰結。[^e054]
* 1934年オーストリア危機、1936年ラインラント進駐の本世界線での扱い。
* 中独関係が国共合作に与える影響の具体像。[^e055]
