# 概要

本世界線の中国では、清朝の終わり方そのものが史実と異なる。1889年の[日清戦争](/events/sino-japanese-war.md)敗北で朝鮮宗主権・台湾・澎湖・巨額賠償を失った清朝は、英国主導の賠償金融と英国資本による鉄道開発のもとで末期を迎える。[^u102][^u104] さらに史実で清朝と革命派の間を取りもって共和政移行を実現した[袁世凱](/people/yuan-shikai.md)は、1880年代に失脚し、講和後に処刑されているか、少なくとも政治生命を断たれている（確定）。[^u105]

その結果、北洋軍の人脈を一手に束ねる人物が現れず、清朝の官僚機構と旧北洋系軍隊を継承する**北方の軍事政権**と、革命派・地方共和主義勢力による**南方の共和政権**が併存する経路が有力となる。[^u105][^u107] 中華民国は統一国家として成立しておらず、日英は旧清朝の契約を尊重する北方の軍閥を支援し続ける（確定）。[^u123]

この過程で、清朝・旧債権を守ろうとする英国と、英国系事業へ出資する日本、そして革命派に賭けて新規参入を図る米国資本の利害が衝突し、**辛亥革命に相当する政変は日英米の対中政策を分裂させる最初の重大事件**となる（検討案）。[^u107]

# 背景

## 袁世凱の不在

本世界線では、1886年頃に朝鮮の高宗が日本公使館へ避難し、高宗廃位を企図した疑惑で袁世凱を捕縛したことが、清の朝鮮出兵と日清全面戦争の契機となった（→[袁世凱逮捕事件](/events/yuan-shikai-arrest.md)）。[^u104][^u105] 清朝中央にとって袁世凱は敗戦責任を負わせやすい対象であり、「朝鮮における現地官僚の越権行為が危機を招いた」と説明すれば[李鴻章](/people/li-hongzhang.md)と中央の責任を軽くできる。ただし朝鮮介入の正当性主張と矛盾するため、責任転嫁の時期には検討の余地がある。[^u105]

ユーザーの判断として、袁世凱は清への身柄引渡しの有無にかかわらず1900年代まで生きているはずがなく、生きていても政治生命は終わっている（確定）。設定としては「1889年の講和後、清国へ引き渡された袁世凱が敗戦責任を問われて処刑される」経路が十分に成立し、日本には彼を助命する理由がない。[^u105]

## 多極的な軍制改革

袁世凱がいなければ、北洋新軍の人事・忠誠関係そのものが成立しない。ただし近代陸軍の建設自体は、1889年の敗戦後に李鴻章・張之洞やその他の総督・巡撫によって試みられる。統括者を欠くため、北洋一極集中ではなく**複数の地域軍事勢力が併存する形で1910年代を迎える**（検討案）。[^u105] これがのちの軍閥割拠の土台となり、張作霖のような人物が史実と同じ地位に到達するかも不明となる。[^u106]

## 英国資本による清末の変化

1889年以降、清国の賠償借款は英系金融機関が主導し、北洋の鉄道・港湾には英国権益が先行した（→[中国大陸の利権争奪](/diplomacy/china-concessions.md)）。このため1911年に史実どおり辛亥革命が起き、1912年に共和国が成立するかは未確定とされる。[^u104] 史実の辛亥革命は鉄道国有化問題などと結びついていたため、鉄道を握る外国資本の構図が異なれば清末の経過も変わる。[^u102] 清朝の終わり方は、戦間期の東アジアを左右する最大の分岐である。[^u102]

# 清朝の終わり方

## 想定される経路

袁世凱不在のため、史実の「1912年の清帝退位と袁世凱大総統による形式的統一」という経路は失われる。[^u105] 代わりに次の可能性が挙げられる。[^u104][^u105]

- 君主制の廃止ではなく、立憲君主制への転換。
- 北方の清朝系政府と南方の共和政府が一定期間併存する。
- 北方に近代軍を指揮する複数の有力者が並び立つ。

## 1912年前後の南北二政権（検討案）

| | 北方の軍事政権 | 南方の共和政権 |
|---|---|---|
| 基盤 | 清朝の官僚機構・旧北洋系軍隊を継承 | 革命派と地方の共和主義勢力 |
| 対外姿勢 | 英国・日本の既存金融権益を尊重し、財政支援を求める | 外国権益の改定を掲げ、米国資本などから新規融資を模索 |
| 法的主張 | 清国と合法に結ばれた契約を承継・返済している | 外国金融機関が特定軍閥を支え統一を妨げている |

両者は正統政府の承認、清国債務の継承、鉄道権益の保障をめぐって対立する。[^u107][^u123]

# 国家承継・政府承認・実効支配

ユーザーは、そもそも中華民国を清の後継国家として承認するか自体がよく分からない、と問題を提起した。[^u104] これは次の三層に分けて扱われる（検討案）。[^u104]

| 問題 | 日英にとっての意味 |
|---|---|
| 国家の承継 | 清国の条約・債務・領土上の義務を新国家が継承するか |
| 政府の承認 | 北京・南京など、誰を中国の正統政府として扱うか |
| 実効支配 | 鉄道や鉱山のある地域で、誰が徴税・警察・契約履行を担うか |

日英には、中央政府が変わるたびに既存契約が無効になる事態を避けるため、**中華民国（あるいは後継政権）を清国の継続国家として扱う強い経済的動機**がある。[^u104] 本当の難題は「承認するか」ではなく「**どの政府を中国政府として扱うか**」であり、日本にとっての対中外交は「中国国家の継続を認めるが、実際に契約を履行できる地方政権とどう取引するか」という問題になる。[^u104]

日本は承認問題を単独で決めず、英国との協調で扱う。ただし英国は債務返済と鉄道・港湾権益の保護を優先して実効支配力のある政府・軍閥と積極的に交渉するのに対し、日本は内戦への深入りを避け比較的安定した中央政府の成立を望む。英国が特定軍閥を財政支援しても、その軍閥が敗れれば日本の債権・投資まで危うくなるため、日本が追随するとは限らない。[^u104]

# 革命と米英日の利害衝突

## 米国資本と革命派

辛亥革命が史実どおり起きたなら、米国と英国・日本の利益は完全に衝突し得る。辛亥革命は米国の資本家が援助していたためである（確定）。[^u107] 本世界線では英国が先行して中国の鉄道・港湾・海関に巨大な権益を築いているため、新規参入を狙う米国資本には「既存契約に参加するより、革命で成立する新政府へ融資し、旧来の英国特権を再交渉させた方が有利」という動機が強い。ただし革命派が政権を取れるか、返済できるか、約束を守るかというリスクがあり、米国の大手銀行団まで一斉に革命派へ移るとは限らない。[^u107]

| 主体 | 優先する利益 |
|---|---|
| 英国の既存債権者 | 清国の債務・契約の継続 |
| 日本の銀行・領主系企業 | 英国との共同投資、資源輸送網の安全 |
| 米国の新規参入資本 | 革命政府との新契約による参入拡大 |
| 中国の革命派 | 外国資本からの軍資金、不平等権益の改定 |
| 地方軍閥 | 外国借款による軍備と財源 |

## 門戸開放の政治化

米国は排他的勢力圏を必要とせず、英国が先行獲得した独占的特権を批判して機会均等を要求する方が有利である。これは革命派の「外国独占権益の廃止」と重なるが、中国の経済主権回復と米国企業の自由な参入は同じ目標ではなく、米中間にも対立は残る。[^u107] これは日英米の代理戦争が必ず起きるという意味ではないが、どちらの政権が清国債務を継承し、誰が鉄道利権を保障するかで米英日の政策は対立する。[^u107]

## 大戦による棚上げと再燃

1914年に欧州大戦が始まると、日英米は対独協力のため中国問題を棚上げする。しかし戦後には問題が再燃し、日本が英国の戦時債務の代物弁済として中国の鉄道・港湾資産を取得していれば、米国には「日英が戦争債務の整理を利用して中国の独占権益を強化している」と映る（→[日英戦時債務整理と中国権益の移転](/diplomacy/war-debt-settlement.md)）。[^u107]

本世界線の構図は、**英国が中国に巨大な既得権をもち、日本がその金融的な共同利益者となり、米国が革命後の新規参入と門戸開放を支持する**というものである。皮肉なことに、**1889年の日本が対露戦争を避けるため英国へ先行的に与えた中国権益が、1920年代には日米関係を悪化させる原因になり得る**。[^u107]

# 戦間期への帰結

中華民国は統一国家として成立しておらず、日英は旧清朝の契約を尊重する軍閥への支援をやめられない（確定）。[^u123] 日英の主張は「清国政府と合法に契約し、それを承継・返済しているのが北方政府である」というものであり、米国・共和派の主張は「外国金融機関が債権保全のため特定軍閥の軍事支配を支援し統一を妨げている」というものである。中国全体を代表する政府が存在しないことが、国際協定の当事者問題を生む。[^u123]

将来、統一政権が旧債務を承継し鉄道事業の継続を保障するなら、日英が支援先を変える余地はある。統一派が旧契約の全面否認を掲げるなら困難である（検討案）。[^u123] この対立は1921〜22年の軍縮会議でも解決せず、中国問題（条約・債務・軍閥支援）は決裂した（確定）。[^u125] 1920年代の展開は[戦間期の中国](/diplomacy/interwar-china.md)を参照。

フランスも1889年の対清講和で華南・西南の経済権益を確保しており、インドシナ経済とも結びつくため、中国問題では日英と利害が近い。[^u108]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 袁世凱 | 1894年に帰国、1895年に新建陸軍の訓練を任され北洋軍を掌握、辛亥革命で清朝と革命派の交渉を主導し大総統に | 1880年代に失脚、1889年頃に刑死（または政治生命断絶） |
| 軍制改革 | 袁世凱の北洋軍が中心。張之洞は1895年に自強軍を創設 | 張之洞ら複数の地方官僚による多極的改革 |
| 清朝の終焉 | 1911年辛亥革命、1912年2月清帝退位 | 時期・形態とも未確定。南北二政権の併存が有力 |
| 列強の承認 | 1913年に米国が正式承認、英日露が続く | 誰を正統政府とするかで日英と米が対立 |
| 統一 | 袁世凱死後に北京政府の権威が低下、1926〜28年の北伐 | 統一国家として成立していない |

[^u104][^u105]

史実でも米国人のホーマー・リーやチャールズ・ビーチ・ブースらが1908〜1911年に孫文と接触し軍事的・金融的支援を構想したが、大規模な資金調達には成功しなかった。孫文は武昌起義の際、米国で資金集めをしていた。一方で1911年の湖広鉄道借款には英仏独と並んで米銀行団も参加しており（タフト政権のドル外交）、米金融界全体が革命派を支えたわけではない。米国は1909〜11年に門戸開放と中国の領土・行政上の一体性を掲げた。[^u107]

# 却下・修正された案

- **袁世凱の処遇を未確定の重要問題とする**：清朝崩壊を考える上で袁世凱の処遇を未確定とした当初の整理（U104）は、ユーザーの指摘を受けて「慎重すぎた」と修正され、袁世凱は死亡または政治的に終わっていることが確定した。[^u104][^u105]

# 未決の論点

- 辛亥革命が史実どおり1911年に起きるか、清朝の終わり方（退位／立憲君主制／南北併存）。[^u102][^u104]
- 袁世凱の死亡経路の詳細（朝鮮での処刑か、清への引渡し後の処刑か、亡命後の失脚か）と、清朝による責任転嫁の時期。[^u105]
- 誰を中国の正統政府として承認するか。北方政権が統一に妥協的か否か。[^u104][^u123]
