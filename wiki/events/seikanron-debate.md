# 概要

本世界線の「征韓論争」は、朝鮮が帝国政府の新国書を受理せず日朝交渉が数年にわたって停滞したことを受け、1872〜1873年頃に[元老院](../institutions/genroin.md)で起こった対朝鮮強硬論争である（時期は検討案）。強硬な使節派遣や海軍の示威行動が要求され、1873年前後に強硬論が高まり、1874〜1875年には海軍の示威行動が本格化して[江華島事件](ganghwa-island-incident.md)へとつながった。[^u042]

史実の征韓論との最大の違いは、強硬論の担い手が「旧士族の不満を代弁する政治家」ではなく、[領主権](../institutions/lordship-rights.md)を保障された**現役の世襲統治者たち**である点にある。領主の出自が武家であるため、本世界線の対外政策は史実よりも武断的になりやすい。[^u042]

# 背景

## 武家の名誉観と元老院

江戸時代の大名社会では家格・面目・主従関係・武威が大きな意味を持ち、この価値観は明治の体制移行後も消えなかった。本世界線では島津・毛利・鍋島・徳川などの領主家そのものが元老院に恒久的な地位を持っており、武家社会の政治文化が制度として温存されている。[^u042]

このため、朝鮮が日本の新国書を拒絶したことは、単なる通商上の不利益ではなく「**天皇の権威と帝国の威信に対する侮辱**」として受け止められやすかった。領主たちは領民に課税し警察・司法を統括する統治者でもあり、権威への挑戦に譲歩を続けることを嫌う政治家が現れた。ただし、武家出身だから必ず開戦を支持するわけではなく、領国財政を管理してきた経験から戦費や通商被害を慎重に計算する領主もいた。[^u042]

## 内政優先論の弱さ

史実の1873年の政変では、大久保利通らの「内治優先」論が使節派遣を退けた。本世界線では二つの事情がこれを弱めている。[^u042]

1. 幕府の解体が比較的平和的に進み（[1866年の無血の幕府解体](bloodless-dissolution-1866.md)）、戊辰戦争に相当する全国的内戦の負担が小さい。
2. 領主の地位が保障されているため、廃藩置県による旧支配層の急激な再編も起きていない。

1870年代前半に国内政治が比較的安定し、政府財政と軍備に余裕があれば、内政優先論の説得力は史実より弱まる。ただし領主ごとの税制・司法制度の整理は続いており、内政上の課題が消えたわけではない。[^u042]

## 交渉停滞の責任

[対馬宗家の家役](../diplomacy/tsushima-so-clan.md)が失われたため、朝鮮との交渉停滞は中央政府の直接の責任となった。諸領主は「外交権を中央へ集中させたのに、朝鮮との関係すら正常化できないのか」と政府を批判できる立場にあった。[^u041]

# 構造

## 「国軍を持たない武家領主」

本世界線の領主は独自の近代軍を持たず、国防は[帝国軍](../military/imperial-army.md)が担う。一方で元老院は軍備予算と対外政策を審議する権限を保持している。つまり**自ら軍隊を編成・指揮する負担は減っているのに、武威を重視する政治的価値観と、国家軍への発言権は残っている**という皮肉な構造がある。[^u042]

この構造のもとでは、対朝鮮強硬論が領主連合間の主導権争いと結びつく。ある領主連合が朝鮮への艦隊派遣を提案すると、競合する連合も弱腰と見られるのを避けるために同調し、元老院に強硬策への支持が集まりやすくなる。これは必然ではなく、戦費負担を伴う法案に反対する領主連合が現れれば抑制も働く。[^u042]

史実の明治政府では外交政策を主導したのは比較的少数の政府高官だったが、本世界線では多くの領主が元老院を通じて外交政策に関与し、[寄親・寄子](../concepts/yorioya-yoriko.md)の政治的結合も存在する。そのため対朝鮮政策は政府内部の論争ではなく、元老院の各領主連合が主導権を争う政治問題となった。「領主の武断性」以上に「強硬外交が政治的な競争手段になること」が本世界線の特徴である。[^u042]

## 元老院と衆議院の対立構図

領主たちは国家の軍事的成功を自らの政治的権威や元老院での影響力拡大に結びつけられる一方、戦争の負担は国税として国民全体に課される。このため、1870年代に成立する[衆議院](../institutions/house-of-representatives.md)が対外強硬論に財政面から抵抗する展開が生じうる。[^u042]

**武家領主が主導する元老院と、戦費を負担する納税者を代表する衆議院が、朝鮮政策をめぐって対立する**――これは立憲政治が史実より早く成立した日本だからこそ起こりうる緊張である。[^u042]

## 領主ごとの対外利害（例示）

対朝鮮政策をめぐる領主の利害は、地理・経済条件から次のように想定される（各家の方針は確定していない例示）。[^u037]

| 領主・政治勢力 | 関心を持ちうる問題 |
|---|---|
| 宗家・西日本の通商関係者 | 朝鮮との交易、港湾開放、航路の安定 |
| 毛利家・中国地方の領主連合 | 日本海の安全保障、対馬海峡、朝鮮半島への交通 |
| 島津・鍋島などの領主連合 | 海軍整備、海外貿易、軍需産業 |
| 徳川・前田などの大領主 | 国家財政、産業振興、海外市場、戦費負担 |

これらは単純に開戦派と反戦派に分かれない。毛利家は朝鮮への強い外交的関与を支持しつつ軍事衝突の回避を求め、島津家は海軍拡張を支持しても即時の対清戦争は望まない、といった組み合わせが想定される。[^u037]

# 経過（検討案）

| 時期 | 出来事 |
|---|---|
| 1867〜1869年 | 宗家の家役接収、朝鮮が新国書の受理を拒否 |
| 1870〜1873年 | 日朝交渉の停滞 |
| 1872〜1873年頃 | 元老院で強硬な使節派遣・海軍示威を求める議論（征韓論争） |
| 1873年前後 | 強硬論の高まり。議会で多数を得れば内閣は軍事的圧力を用いる政治的根拠を得る |
| 1874〜1875年 | 海軍の航路調査・測量の拡大、示威行動の本格化 |
| 1875年前後 | [江華島事件](ganghwa-island-incident.md) |

史実より充実した帝国海軍があるため、江華島事件に相当する衝突が1875年より早く起きる可能性すらある。[^u041][^u042]

# 意義

- 征韓論争は、元老院が穏健外交の保証にはならないことを示した。大領主たちは海軍の発展を支え通商拡大にも関心を持っており、交渉停滞が続けば海軍による圧力を支持する勢力が現れる。[^u041]
- 朝鮮開国要求には国内向けパフォーマンスの側面が確実にあり、朝鮮問題は元老院政治において政権の能力を測る問題となった（[不平等条約改正](../diplomacy/treaty-revision.md)参照）。[^u046]

# 史実との比較

| 項目 | 史実（1873年） | 本世界線 |
|---|---|---|
| 強硬論の担い手 | 西郷隆盛・板垣退助ら政府参議。旧士族の不満を背景とする | 元老院の現役世襲領主たち |
| 主張 | 即時出兵から強硬な使節派遣まで一様ではなかった | 強硬な使節派遣と海軍示威 |
| 抑制要因 | 大久保利通らの内治優先論が使節派遣を見送らせた | 内戦負担・廃藩置県がなく内政優先論が弱い。衆議院の財政的抵抗が抑制要因となりうる |
| 帰結 | 明治六年政変、参議の下野 | 1874〜1875年の海軍示威本格化（検討案） |

史実の征韓論政変と板垣らの下野が本世界線でもそのまま起きる保証はなく、1874年頃の[民撰議院設立建白](../institutions/house-of-representatives.md)も同じ人物・同じ文面ではなく、同時期の運動として生じるとされる。[^u026]

# 未決の論点

- 征韓論争の正確な時期と、元老院でどの領主連合が強硬論を主導したか。
- 強硬論が元老院で多数を占めたのか、内閣がどの段階で海軍派遣を決定したのか。
- 衆議院成立前（1870年代前半）に、戦費負担側の抵抗がどの経路で表明されたか。
