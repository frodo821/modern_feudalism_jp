# 概要

1935年10月、イタリアはエチオピアに侵攻した。イタリアの植民地拡張政策や第一次エチオピア戦争の敗北をめぐる背景は本世界線でも大きく変わっていないため、戦争そのものは史実通り発生する。[^e057] 軍事的帰結も史実通りで、イタリアはエチオピアを占領し、1936年5月に併合を宣言した。[^e058][^e059]

史実と異なるのは、日本が国際連盟に残留し、英国と[日英海上通商防衛協定](../diplomacy/anglo-japanese-maritime-defense-agreement.md)を結んでいる点である。日本は連盟の対伊経済制裁に参加したが、英国が海上封鎖や軍事制裁に踏み込めば協定の共同防衛義務によって自国も対伊戦争に巻き込まれるため、連盟内で軍事制裁の**抑制派**となった。[^e058] さらに米国は、日英主導の世界的経済制裁体制という先例を作らせないために制裁に協力せず、イタリアへの石油輸出を通常の商取引として続けた。[^e059]

結果として、連盟の対伊制裁は参加国の経済力こそ史実より大きかったが、軍事的強制力は史実と同程度にとどまった。制裁は1936年7月頃に解除されたが、日英はエチオピア併合を承認せず、ストレーザ戦線は崩壊して独伊が接近した。[^e058][^e059] この危機は、日英協定に「共同防衛義務は存在するが、共同の外交政策決定機構は存在しない」という制度的欠陥があることを初めて明らかにした事件でもある。[^e058]

# 背景

## ストレーザ戦線と英仏の温度差

1933年以降、英国・フランス・イタリアは[ドイツの再軍備](nazi-germany-1933.md)を牽制し、日本も外交的にこれを支持していた。イタリアは対独再軍備への反対と自国の拡張政策という矛盾を抱えており、日英が侵略戦争にどれほど強硬に臨むかが、イタリアの対独接近の時期と理由を左右するとされた（検討案）。[^e056]

エチオピア問題に対する各国の立場は一致しない（検討案）。[^e057]

| 国 | 対独牽制の必要性 | 対伊制裁への態度 |
|---|---|---|
| 英国 | 高い | 侵略阻止を重視 |
| 日本 | 間接的に高い | 国際連盟による制裁を支持 |
| フランス | 非常に高い | イタリアとの関係維持を優先 |
| 米国 | 比較的低い | 制裁への参加に消極的 |
| ソ連 | 高い | 集団安全保障と制裁を支持 |
| ドイツ | ― | 制裁に参加しない |

英国は日本との協定によって極東の安全保障負担が軽減されており、史実ほどイタリアとの妥協を必要としない。このため英仏間の温度差は史実より大きくなる（検討案）。[^e057]

## 日本が制裁に加わる理由

日本はエチオピアを軍事支援する必要はないが、独立国家としての存続を支持する理由がある。日本は国際連盟の加盟国であり、既存の国際契約秩序を重視し、領土拡張よりも通商・投資による海外進出を重視し、紅海・スエズ運河を経由する海上交通に重大な利害を持つ。イタリアの東アフリカ拡張は紅海周辺におけるイタリアの軍事的影響力を拡大するため、日本にとっても無関係な戦争ではない。このため日本は国際連盟の対伊経済制裁に参加した（確定）。[^e057][^e058]

# 日英協定と巻き込みの危険

## 協定はどこで発動するか

イタリアのエチオピア侵攻そのものは協定の発動条件ではない。エチオピアは締約国ではないからである。しかし英国が制裁を実施し、その報復としてイタリアが英国商船に重大な攻撃を加えれば、日本の共同防衛義務が発生しうる。[^e057]

| 事態 | 日英協定の扱い |
|---|---|
| イタリアによるエチオピア侵攻 | 発動しない |
| 日英による経済制裁 | 発動しない |
| イタリアによる英国商船への重大な攻撃 | 発動対象 |
| イタリアによる日本商船への重大な攻撃 | 発動対象 |
| 英国による対伊軍事行動 | 戦争の性格によって判断 |

[^e057]

## 免責条項を援用できない日本

日本の立場では、海上封鎖や軍事制裁は避けたい。日本自身が艦隊を派遣しなくても、英国が派遣しただけで、日本はほぼ確実に戦力を出さなければならなくなるからである（確定）。[^e058] 1932年の第一追加議定書は、海上封鎖の適法性を問わず共同防衛義務を発生させ、例外を締約国自身が開始した侵略戦争に起因する場合に限っている。国際連盟の決議に基づく軍事制裁は侵略戦争ではないため、日本は免責条項を援用しにくい。[^e058]

| 英国の行動 | イタリアの対応 | 日本への影響 |
|---|---|---|
| 経済制裁 | 報復関税 | 共同防衛義務なし |
| 石油禁輸 | 経済的報復 | 共同防衛義務なし |
| 海軍による示威行動 | 外交的抗議 | 軍事的緊張の上昇 |
| 海上封鎖 | 英国商船への報復攻撃 | 共同防衛義務が発生 |
| 軍事制裁 | 地中海における海上戦争 | 共同交戦に至る可能性が高い |

[^e058]

## 日本の制裁政策

日本は国際連盟の内部で軍事制裁の抑制派となった（確定）。[^e058]

| 制裁措置 | 日本の立場 |
|---|---|
| イタリアの侵略認定 | 支持 |
| 武器輸出禁止 | 支持 |
| 新規融資の停止 | 支持 |
| イタリア製品の輸入禁止 | 支持 |
| 石油の輸出禁止 | 条件付き支持 |
| イタリア向け貨物の軍事的臨検 | 反対 |
| スエズ運河の強制的閉鎖 | 反対 |
| 海上封鎖 | 強く反対 |
| 直接的な軍事介入 | 強く反対 |
| エチオピア併合の承認 | 反対 |

[^e058]

日本は、石油輸出国が**自国の輸出を禁止すること**（経済制裁）と、**第三国の石油輸送を海軍によって阻止すること**（軍事制裁）を明確に区別した。米国が石油禁輸に参加しない場合、日本は制裁の実効性が下がることを承知のうえで、軍事的な強制措置への移行に反対した。[^e058]

英仏日米は、それぞれ異なる理由から軍事制裁を避けた。[^e058]

| 国 | 軍事制裁を回避したい理由 |
|---|---|
| フランス | イタリアを対独牽制勢力として維持したい |
| 日本 | 日英防衛協定による対伊戦争への巻き込まれを避けたい |
| 英国 | 地中海での戦争と財政負担を回避したい |
| 米国 | 欧州紛争への関与と日英主導の制裁体制を避けたい |

日本の連盟残留は連盟を史実より強力にしたが、軍事的な強硬化にはつながらなかった。「経済制裁の参加国の経済力は史実より大きいが、軍事的強制力は史実と同程度」である。[^e058]

# 米国の制裁破り

本世界線の米国には制裁を破るメリットがある（確定）。[^e059] 史実の孤立主義・中立政策に加えて、米国には、日英が国際連盟を通じて世界的な経済制裁体制を運用できるという先例を作らせたくない動機がある。米国自身が将来、日英との対立によって同様の経済的圧力を受ける可能性があるからである。また、イタリアとの通商を続ければ、日英などが撤退した市場を米国企業が獲得でき、恐慌からの回復途上の米国経済にも利益がある。[^e059]

| 政策 | 史実 | 本世界線 |
|---|---|---|
| 武器輸出 | 両交戦国に禁止 | 同様 |
| 石油輸出 | 輸出増加の自粛を要求（道義的禁輸） | 通常の商取引として容認 |
| 民間貿易 | 自己責任で継続 | 積極的に維持 |
| 政府向け融資 | 制限を強化 | おおむね同様 |
| 国際連盟との協調 | 限定的 | より消極的 |
| 海上交通の自由 | 中立維持を優先 | 中立国の通商権を強調 |

[^e059]

1935年の中立法そのものは成立したが、道義的禁輸は政権内部や議会の反対で行われず、米国は1935年末から非軍事物資の対伊輸出を継続・拡大した。米国はイタリアの侵略を政治的に支持する必要はなく、中立国としての通商の自由を主張するだけで、結果的にイタリアの戦争継続能力を支えた。[^e059]

日英には米国の制裁破りを阻止できなかった。英国が米国からイタリアへの海上輸送を軍事的に妨害すれば対米対立に発展する危険があり、日本から見ればエチオピアのためにイタリアだけでなく米国との戦争まで引き受けることになりかねない。日本は英国に海上封鎖を強く思いとどまらせ、英国は封鎖を断念した。米国もこの構造を理解して通商を続けることができた。「**日英の海軍力は強大だが、それを経済制裁の強制手段として利用する政治的自由は小さい**」——これは米国にとって重要な外交的発見となった。[^e059]

# 帰結

## 制裁解除と併合不承認の分離

日英には実効性の乏しい制裁を無期限に続ける利益はないが、制裁を解除することと、武力による領土取得を承認することは別問題とされた。[^e059]

| 措置 | 帰結 |
|---|---|
| 国際連盟による経済制裁 | 実効性不足から1936年中（7月頃）に解除 |
| エチオピア併合の承認 | 日英は拒否 |
| ハイレ・セラシエ | 英国が亡命を受け入れる |
| 対伊軍事制裁 | 実施しない |
| 民間通商 | 段階的に再開 |
| 政府間の金融協力 | 当面制限 |

[^e059]

## ストレーザ戦線の崩壊と独伊接近

ストレーザ戦線は本世界線でも維持できない（確定）。それは各国の対独警戒だけで成立した結合であり、国際秩序全般についての合意に基づくものではなかった。[^e059]

| 国家 | ストレーザ戦線に参加する理由 | 維持を困難にする要因 |
|---|---|---|
| 英国 | ドイツの再軍備阻止 | イタリアの侵略 |
| フランス | 対独包囲・安全保障 | 英国との対伊政策の相違 |
| イタリア | オーストリアの独立維持 | エチオピア問題での制裁 |

イタリアには米国との通商関係が残り、ドイツからも経済的な支援を受けられるため、日英仏との関係を維持するためにエチオピアから撤退する動機は弱い。ドイツにとってもイタリアをストレーザ戦線から離脱させる利益は大きく、独伊接近は本世界線でも成立する（史実より早まる可能性もある）。[^e059]

## 米国の外交的位置

この事件によって米国は、[ドイツの対仏軍備均等に理解を示し](nazi-germany-1933.md)、イタリアに対する国際連盟の経済制裁にも協力しなかった国となった。ただし米独伊が同じ陣営を形成したわけではない。ドイツ・イタリアは既存の領土秩序を変更したく、米国は欧州の勢力均衡と通商の自由を維持したく、日英は既存の国際秩序と海上通商の安全を維持したい。目的は異なるが、米国の政策が結果的に独伊の外交的・経済的孤立を緩和する構造が生まれた。[^e059]

## 日英協定への影響

エチオピア危機は、日英協定が成立して以来初めて顕在化した重大な問題であった。1930年の協定は主として第三国からの攻撃に対する相互防衛を想定しており、国際連盟の集団安全保障措置を一方が実施する場合の取り決めがなかった。英国には軍事制裁を実施する外交的自由があるが、その軍事的負担の一部は日本にも及ぶ。日本に英国の外交政策を拒否する条約上の権限はない。「**共同防衛義務は存在するが、共同の外交政策決定機構は存在しない**」。[^e058]

このため日本は、第二追加議定書として、国際連盟の軍事制裁への参加や第三国への海上封鎖に関する事前協議、相手国に共同防衛義務を生じさせるおそれのある軍事行動の事前通告を求める可能性がある（検討案）。日本が求めるのは参戦義務から逃れることではなく、参戦義務が生じる決定に事前に関与することである。[^e058] 詳細は[日英海上通商防衛協定と追加議定書](../diplomacy/anglo-japanese-maritime-defense-agreement.md)を参照。

危機の結果、日英の共同防衛義務は明文化され、国際連盟の集団安全保障は限界を露呈し、ドイツの再軍備も始まっていた。この状況で米国が100：85：65の比率を維持する意思を持つかが、続く[第二次ロンドン海軍軍縮会議](../diplomacy/second-london-conference.md)の課題となった。[^e059][^e060]

# 却下・修正された案

* **制裁継続・長期疲弊案（B案）**：当初は、イタリアが占領・併合を宣言しても日英が承認も制裁解除も拒み、制裁が継続してイタリアが長期的に疲弊する案が自然とされた（史実通り併合のA案、国際的圧力で停戦しエチオピアが存続するC案と比較）。しかし米国の制裁破りと英国の封鎖断念を踏まえ、制裁は1936年中に解除し、併合承認だけを拒否する形に修正された。[^e057][^e059]
* **イタリアの連盟脱退の前倒し**：日英が制裁解除と併合承認を拒み続ければ脱退が1936年末〜1937年に早まりうるとされたが、制裁が1936年7月頃に解除されることになり、脱退表明は史実に準じて1937年12月とされた。[^e057][^e059]
* **ストレーザ戦線が史実以上に成立しやすいという見方**：対独政策から戦線は成立しやすいとされたが、エチオピア問題で維持できる理由に乏しいとして、本世界線でも崩壊することになった。[^e057][^e059]
