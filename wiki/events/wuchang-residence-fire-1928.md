# 概要

武昌公邸火災事件は、1928年6月3日、[中国諸省聯合](../diplomacy/china-federation.md)の実質的指導者[黎元洪](../people/li-yuanhong.md)が、湖北省武昌の公邸で起きた火災により死亡した事件である。出火原因は不明で、遺体は火で激しく損壊していたため直接の死因も特定できない。事件後には陰謀の存在を示唆する「証拠」が見つかったが、その真偽も火災との関係も確認されていない。[^e034]

正式名称は「武昌公邸火災事件」、一般的な通称は「**黎元洪怪死事件**」である。謀殺と断定する「黎元洪謀殺事件」という呼称は、特定の政治的立場をとる新聞や政党が用いる。[^e034] 後世の歴史学でも事故死説・湖北軍内部犯行説・中華民国関与説が並立し、決着していない。[^n1][^e034]

この事件は史実の張作霖爆殺事件（1928年6月4日）に対応する位置にあるが、性格は異なる。張作霖爆殺が日本の対満洲政策の矛盾から生じたのに対し、本件は**聯合自身が抱える地方自治と軍事的中央集権化の矛盾**から生じた事件である。[^e033][^e034] 事件の結果、後継者になれるだけの権力基盤を持つ者は全員が疑惑の対象となり、聯合は1930年になっても最高指導者を持たない暫定集団指導体制にとどまった。[^e035]

# 背景

## 予期された死

聯合では内部の不安定さから軍権が支配力の実態となり、黎元洪が主導権を握っていた。その地位は張作霖と同様に暗殺の危険を抱え、史実と死因は違っても長く命脈を保つ見込みは低かった。[^n2][^e027] 史実の黎元洪は糖尿病・高血圧を患い、1928年6月3日に天津の自宅で脳出血により63歳で死去している。本世界線での死去の日付は史実と同じで、死因と場所が異なる。[^e027][^e033]

1926年には創設者[張謇](../people/zhang-jian.md)が史実どおり死去しており、聯合は1926〜28年に文民・軍事双方の創設世代を失うことになった。[^e027]

## 事件当時の状況

事件は[北伐](northern-expedition.md)の最中に起きた。1926年の湖南政変を契機に聯合は軍事的共同体へ変質し、黎元洪の権力は急拡大していたが、湖南の大部分を中華民国に奪われ、湖北方面で戦線が膠着していた。[^e031][^e032] 湖北軍の強硬派には、他の加盟省が軍事費を負担せず湖北軍ばかりが負担していること、黎元洪の妥協的な姿勢が軍事統合を妨げていること、日英の金融支援に制約があることへの不満が蓄積していた。[^e033]

黎元洪の失脚・死亡は、各勢力に次のような効果をもたらし得た。[^e027]

| 関係勢力 | 黎元洪の失脚・死亡がもたらす効果 |
|---|---|
| 中華民国の統一派 | 聯合の軍事的結束が弱まる |
| 聯合内部の対抗軍閥 | 軍事協議会の主導権が空白になる |
| 湖北軍内部の反対派 | 指揮権の再編が可能になる |
| 共産主義革命勢力 | 既存の軍事・経済秩序が動揺する |
| 日本・英国 | 支援先の安定性が損なわれる |

日本と英国は黎元洪政権の存続で利益を得ており、事件を起こす必然性はない。[^e027][^e033]

| 実行犯 | 不明 |
| 首謀者 | 不明 |
| 外国勢力の関与 | 確認されず |

[^e033][^e034]

## 陰謀の「証拠」

事件後に現れた「証拠」は、互いに異なる複数の陰謀説を支える。[^e034]

1. 湖北軍内の一部将校が黎元洪の排除について協議していたとされる文書。
2. 中華民国の情報機関と湖北軍関係者の接触を示唆する書簡。
3. 公邸関係者による相互に矛盾した証言。
4. 事件直後に所在不明となった軍人や公邸職員の存在。

いずれも文書の真正性・証言の信憑性が十分に確認できず、火災と直接関係しているのかも不明である。黎元洪を排除しようとする陰謀が実在したとしても、それが実行されたとは限らない。[^e034] 捜査機関自体も湖北軍や各省政府の影響下にあり、信頼できる結果は出なかった。[^e035]

# 各勢力の解釈

| 勢力 | 主な見解 |
|---|---|
| 湖北軍主流派 | 軍内部の陰謀を疑い、内部調査を開始 |
| 湖北軍強硬派 | 中華民国による謀略を主張 |
| 両江政府 | 湖北軍内部の権力闘争を疑う |
| 北京政府（聯合中央機関） | 聯合全体に関わる事件として独自調査を要求 |
| 中華民国 | 関与を否定し、聯合内部の抗争を指摘 |
| 中国共産党 | 軍閥政治の矛盾の表れとして宣伝 |
| 日本 | 謀殺の可能性を排除せず、公式な犯人認定は避ける |
| 英国 | 政治的安定と既存契約の履行を優先 |
| 米国 | 聯合の政治的不安定性を示す事件と認識 |
| ソ連 | 聯合内部及び外国勢力間の対立を指摘 |

各勢力の内部でも見解は統一されない。[^e034] 政治宣伝としては、聯合内部で国民党・共産党の謀略説が、中華民国側で日英が代わりの軍事指導者を擁立するために関与したとの説が流布した。[^n3][^e033]

# 後継者問題への影響

## 「無垢の後継者」の不在

この事件で最も重要なのは、**黎元洪の後継者候補であること自体が、謀殺への関与を疑われる理由になる**ことである。[^e034] 有力な将軍が湖北軍の指揮権を握ろうとすれば事件で利益を得た人物として疑われ、軍内部の調査を強行すれば政敵排除のための粛清と疑われる。無垢の後継者になれる人間はいなかった。[^e035]

| 候補の類型 | 疑われる理由 |
|---|---|
| 黎元洪の側近 | 動静に詳しい |
| 湖北軍の有力将軍 | 直接軍権を得る |
| 華北の軍事指導者 | 聯合の主導権を奪取できる |
| 両江の政治指導者 | 軍事優先政策を転換できる |
| 親日英派 | 外国による交代工作を疑われる |
| 民族主義的な軍人 | 中華民国への内通を疑われる |
| 中立的な文民 | 疑惑は少ないが軍権がなく実質的後継者になれない |

[^e035]

黎元洪が単に病死した場合より、権力継承ははるかに難しくなった。両江や北京も、真相が解明されないまま湖北軍の新指導者に聯合全体の主導権を認めることには慎重になる。[^e034]

## 権力の分解

黎元洪の権力は四つに分解され、分散した。[^e035]

| 黎元洪の権力 | 事件後の帰属 |
|---|---|
| 湖北軍最高指揮権 | 湖北軍高級将校による暫定軍事委員会 |
| 湖北省支配権 | 湖北省政府 |
| 聯合軍事協議会の主導権 | 各加盟軍代表による軍事協議会 |
| 加盟省間の政治調整権 | 対外代表権は北京の聯合中央機関、軍事費・対外借款は財政委員会及び両江の金融勢力 |

誰にも権力を独占させたくないという消極的合意による暫定体制である。日英も特定人物を擁立すれば謀殺関与の疑惑を強めるため擁立できず、聯合の既存機関を支援し、対外債務の履行や借款契約は財政委員会を相手とした。[^e035]

## 事件後の推移

| 時期 | 出来事 |
|---|---|
| 1928年6月 | 武昌公邸火災事件 |
| 1928年夏 | 湖北軍内部の指揮権争いと相互告発 |
| 1928年秋 | 聯合軍事協議会による暫定集団指導体制の成立 |
| 1929年 | 軍事費負担と指揮権をめぐる各省間の対立 |
| 1929年末 | 世界恐慌による財政悪化 |
| 1930年 | 中華民国との事実上の休戦。指導体制の再編は未完了 |

[^e035]

事件直後の各地の動きとしては、湖北で軍内部の指揮権争い、両江で湖北軍への軍事費拠出に条件、北京で聯合中央機関の強化の試み、湖南で中華民国側の軍事圧力強化、山西・満洲で聯合加盟の見送り、日英による加盟諸省間の調停開始があった。[^n3][^e033] 漢口の租界では、事件後に租界当局の治安権限が強化された。[^n3][^e037]

事件は聯合の国家化を促すどころか、中央権力の形成を阻害した。1930年の聯合は「**共通の敵と共通の債務によって結びついているが、共通の指導者を持たない政治共同体**」となる。[^e035] 張謇の死で文民的な調整能力を、黎元洪の怪死で軍事的な調整能力まで失った聯合は、深刻な指導者不在に陥り、次の指導者には軍事力だけでなく「事件への関与を疑われていないこと」と「他の加盟省から信任を得られること」が求められるようになった。[^e034]

本世界線では関東軍が存在しなくても、張作霖爆殺や柳条湖事件に相当する事件は起こり得た（→[戦間期の中国](../diplomacy/interwar-china.md)）。本事件はその「相当事件」が、外国資本ではなく中国の連合体の内部矛盾として現れた形である。

# 編集注：却下・修正された案

* **「武昌事件／黎元洪謀殺事件」案（E33）**：死亡場所を武昌とし、実行主体を湖北軍内部の強硬派将校（目的は聯合の軍事的中央集権化）、外国政府の直接関与なしとする明白な暗殺事件の案は、作者の「公邸の火災で死亡、原因は不明だが陰謀の『証拠』が出てきた」案に置き換えられた。明白な暗殺より、確実な死亡事実と真偽不明の証拠が残る事件の方がその後の政治的混乱を説明しやすいからである。ただし湖北軍強硬派の不満は背景として残る。[^e033][^e034]
* **病死・謀殺の二択**：E27の年表案では「1928年 黎元洪死去。病死または謀殺事件」とされていたが、E34で火災による死亡に確定した。[^e027][^e034]
