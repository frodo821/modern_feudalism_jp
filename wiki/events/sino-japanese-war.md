# 概要

本世界線の日清戦争は、史実（1894〜1895年）より約7年早い**1887年に始まり、1889年の下関条約で終結した**戦争である。[^u071][^u077] 発端は東学農民蜂起ではなく、日本公使館に避難して政務を執っていた朝鮮国王[高宗](../people/gojong.md)が、廃位工作への関与を疑って清国の駐朝鮮代表[袁世凱](../people/yuan-shikai.md)を捕縛した[袁世凱逮捕事件（1886年）](yuan-shikai-arrest.md)である。[^u060][^u061] 清朝中央は[李鴻章](../people/li-hongzhang.md)の慎重論を退けて朝鮮征討に踏み切り、[朝鮮国独立保障（1884年）](../diplomacy/korea-independence-guarantee-1884.md)を掲げて漢城に駐留していた日本帝国軍と衝突した。[^u063]

戦争は「高宗の保護」をめぐって始まりながら、清が局地戦の敗北後に全面動員へ進んだことで、**北洋艦隊の存廃と黄海の勢力均衡、さらに台湾・澎湖の帰属をめぐる戦争**へと性格を変えた。[^u064][^u067] 日本は立憲帝国として両院に戦費を説明する必要から早期講和を受け入れられず、順天府（北京）への進軍能力を示したうえで、列強銀行団との金融調整を終えてから講和した。[^u071][^u073]

この戦争は日本の「戦争は勝てば儲かる事業ではない」という学習の出発点となり、本世界線の日本が以後の対露政策で戦争に慎重となる原因にもなった。[^u088] また、日本陸軍にとっては第一次世界大戦まで唯一の大規模実戦経験となった。[^u097]

# 背景

## 1880年代の朝鮮問題

1882年の[漢城危機（壬午軍乱）](imo-incident-1882.md)で日清両軍は対峙したのち「手打ち」となり、1884年には清仏戦争を好機とした日本の介入（[甲申政変](gapsin-coup-1884.md)）と、日本による[朝鮮国独立保障](../diplomacy/korea-independence-guarantee-1884.md)の宣言があった。1885年の清仏戦争終結で二正面の制約を脱した清は対朝鮮政策を強硬化し、宮廷人事への介入や高宗廃位論が浮上した（詳細は[清の対朝鮮政策と李鴻章](../diplomacy/qing-korea-policy.md)）。

## 開戦に至る連鎖（1886年）

| 段階 | 出来事 |
|---|---|
| 1 | 清の干渉と廃位の危険を感じた高宗が漢城の日本公使館に避難し、公使館から政務を執る（[高宗の日本公使館避難と1886年漢城公使館危機](gojong-legation-refuge.md)） |
| 2 | 高宗を擁する日本公使館が襲撃される（清の使嗾が疑われる） |
| 3 | 高宗の正式な許可のもと、邦人保護名目で日本帝国軍が朝鮮に派兵・漢城駐留 |
| 4 | 襲撃捜査で親清派と袁世凱周辺の連絡が判明、日本の行動を確信した高宗が先走って袁世凱を捕縛 |
| 5 | 清の最後通牒（袁の釈放・処罰撤回）、高宗の拒絶。日本は釈放勧告をしない |
| 6 | 清朝中央で強硬論が優勢となり、1886年末〜1887年に朝鮮征討を準備 |

日本政府の公式の立場は「袁世凱の法的地位と訴追の適法性は朝鮮政府と清国政府の間で解決すべき問題である。ただし、その解決を強制するために清国が朝鮮へ軍隊を派遣することは認めない」というものであった。[^n1][^u062] したがって戦争の争点は袁一人の身柄ではなく、「**清朝の宗主権には、朝鮮国王の司法権と統治権を武力で覆す権限があるのか**」となった。[^u062]

## 両国の構造的条件

- **日本側**: 1860年代からの統一国軍、全国標準化された鉄道・通信・金融制度、大領主間の競争で育った軍需産業を持つ（[帝国軍](../military/imperial-army.md)、[全国標準化政策](../institutions/national-standardization.md)）。日本の軍事力の根拠は独自軍を持つ大領主ではなく、「大領主たちが競争しながら作り上げた統一的な国内経済圏」である。[^u044][^u070] 1890年代の帝国軍は史実より強い可能性があるという見通しは、より早い時期の戦争にも引き継がれた。[^u029]
- **清側**: 北洋（李鴻章）と福建・南洋で指揮系統と利害が分かれ、清仏戦争の財政負担も重い。[^u049] 1885年秋に定遠・鎮遠が到着していたが、戦争遂行体制（陸海協同、統一戦略、参謀・兵站、臨時的な海防財政）に弱点を抱えていた。[^u070]
- **清朝中央と北洋の不一致**: 清朝中央は威信のために戦争を始めるが、実際に遂行する北洋軍事体系の責任者である李鴻章は勝算に疑問を持っていた（欽差大臣派遣による権限制限が有力な形態とされる）。[^u063]

# 経過

戦争は1887年前半に始まり、1889年春〜夏の講和で終わった。経過は次のとおりである。[^n2][^u071][^u077]

| 時期 | 戦況 |
|---|---|
| 1886年末〜1887年 | 清朝中央が北洋軍を動員し、袁の釈放、高宗への制裁、日本軍撤兵を要求。日本は元老院・衆議院で軍事費を審議し、高宗への保障を再確認して駐留を継続[^u063] |
| 1887年前半 | 清軍が朝鮮に進出（朝鮮征討）。日本帝国軍と高宗側の朝鮮政府軍に撃退される。清朝中央が追加動員を決定[^u064][^u071] |
| 1887年夏〜秋 | 本格的な陸海戦。最初の本格的な日清海戦が戦争全体の分岐となる。日本が黄海の優位を確保しようとする[^n3][^u070][^u071] |
| 1887年末〜1888年前半 | 日本が北洋軍港（威海衛・旅順）と直隷沿岸に圧力をかける。清から早期講和の打診があるが、日本は応じない[^n3][^u071] |
| 1888年中盤 | 日本が北洋戦力の無力化と台湾・澎湖の割譲を要求。1888年頃の清の講和申し入れは決裂する[^n3][^u071] |
| 1888年後半 | 英仏などと賠償借款・通商権益の事前交渉が進む[^n3][^u077] |
| 1889年春〜夏 | 順天府への軍事的脅威を背景に講和交渉。下関条約締結[^u077] |
| 1889年後半 | 清が外国借款を調達。威海衛撤兵・北洋軍備制限の履行手続きが始まる[^n3][^u077] |

## 第一段階: 朝鮮征討の失敗

清の当初の軍事目標は、袁世凱の救出、高宗への制裁あるいは王位からの排除、清が承認する別の李氏王族の擁立、宗主権の再確認であった。[^u063] しかし高宗は日本帝国軍の保護下にあり、王宮や袁の拘束場所へ向かう清軍は日本軍の警備地域に入らざるを得なかった。清にとって政治的な目標（高宗の屈服）と軍事的な障害（日本軍の排除）が重なったのである。[^u061]

局地戦で撃退された清は、撤兵すれば「国王による清国官員の逮捕を認めたまま宗主権回復に失敗した」ことになり、ベトナムの宗主権を失った直後に朝鮮でも後退するのかという圧力から、かえって引き下がれなくなった。[^u064] こうして清は全力投射以外の選択肢を失い、全面戦争へ移行した。[^u064]

## 戦争目的の段階的拡大

清が全面戦争を決断した瞬間に、日本も清から何を得るかを計算しなければならなくなった。[^u064] 日本の戦争目的は以下のように拡大した。

| 戦争の段階 | 日本の主要な目的 |
|---|---|
| 高宗保護の段階 | 高宗の安全と朝鮮の独立した統治権の保障 |
| 清軍の朝鮮進入 | 清軍の撃退と朝鮮からの撤収 |
| 清国の全面動員 | 清が再び朝鮮へ侵攻できない軍事的条件の確保 |
| 清海軍との本格交戦 | 北洋艦隊の撃破と黄海・朝鮮周辺の制海権確立 |
| 講和交渉 | 朝鮮独立承認、清軍撤収、再介入防止の安全保障措置 |

日本が受け入れられる**最低限の講和条件は「日本近海における清の海軍力の解体」**であり、それは清国海軍の全廃ではなく、黄海・渤海方面から朝鮮へ兵力を投射する能力、すなわち北洋の海上戦力の無力化を意味した。[^u064]

## 元老院の主戦化

最初の衝突のあと清が追加派兵した瞬間に、[元老院](../institutions/genroin.md)は主戦派一色に塗り潰された。[^u067] 領主議員の論理は「自分たちが憲法で保障された権限を持っているからこそ、外国の世襲君主が持つ統治権への武力干渉にも反対する」というものであり、戦争回避派も増強支持へ回った。[^u067] ただし元老院は「戦うか否か」ではなく「どこまで勝つか」で割れた。

| 元老院内の勢力 | 講和条件 |
|---|---|
| 限定講和派 | 朝鮮独立承認・清軍撤退・賠償 |
| 安全保障重視派 | ＋北洋艦隊壊滅・軍備制限 |
| 強硬講和派 | ＋台湾・澎湖などの割譲 |

戦争後半には、これが「軍事的安全保障重視（北洋無力化・渤海方面軍備制限）」「海軍・通商関心（台湾澎湖割譲・開港保障・海上交通）」「財政重視（賠償重視、過度の長期化には反対）」の三勢力に再整理され、三者は一つの講和案にまとまりえた。[^u071] 軍費を負担する大領主は、長期化するほど賠償・経済利益を求めた。[^u064]

## 海戦と黄海の制海権

最大の軍事的分岐は1887年の最初の本格的な日清海戦であった。[^u070] 1887年の清は定遠・鎮遠を擁し、1887年末には英独建造の巡洋艦4隻が北洋に加わる時期で、清の海軍近代化が進行中の衝突であった。[^u064] 日本の必勝は約束されていなかったが、日本が黄海の制海権を確保して清の海上増援を阻止すれば、清は艦隊を短期に補充できない。[^u070]

**清を史実どおり屈服させることは十分可能であり、時間は清の敵で、最初の一当てで局面を打開できなかった時点で清に挽回の手段はなかった**。[^u070][^u071] 清の不利は兵力差ではなく戦争遂行体制の差にあった。

| 清の継戦段階 | 制約 |
|---|---|
| 開戦初期 | 朝鮮展開部隊と北洋軍で対応 |
| 数か月後 | 増援・軍費・海上輸送の調整が必要 |
| 半年以降 | 他地域の部隊・財源に依存、指揮・補給の不統一 |
| 長期化 | 戦費・地方の軍事的自立・列強介入の問題 |

日本側の制約は遠征軍の維持費、疾病、輸送船不足、民間経済への負担であった。[^u070]

## 順天府への圧力

厳しい講和条件を清に呑ませるには、順天府（北京）に行く**意志と行ける可能性**を示す必要があった。[^u068] 実際に北京を占領するのではなく、進軍の意思と能力を清朝中央に信じさせることが講和戦略の核心とされた。北京占領は遷都と継戦の危険、膨大な軍費、国際的負担のため不要かつ有害である。[^u068]

| 必要な軍事的成果 | 清朝にとっての意味 |
|---|---|
| 朝鮮の清軍撃退 | 朝鮮征討の失敗 |
| 北洋艦隊撃破、旅順・威海衛を脅かす | 黄海・渤海防衛の危機 |
| 天津・山海関方面へ進出可能な戦力を示す | 順天府進軍が現実の脅威に |

三段階目に至って清は「朝鮮の宗主権を守るために首都を危険にさらしている」状況となる。[^u068] 元老院では順天進軍をめぐって、台湾割譲と賠償の受諾まで進軍準備で圧力をかけるべきだとする強硬派と、独立・北洋壊滅・十分な賠償で足りるとする慎重派が対立した。[^u068]

## 早期講和の拒否

全面戦争に進展した以上、**早期講和はむしろ日本の側が受け入れられなかった**。[^u071] 立憲帝国として両院に戦費を説明し、国民と領主に負担を求めている以上、撤兵だけで講和すれば成果を説明できず、「今ここで終戦したら、清国は艦隊を再建して数年後に戻ってくるのではないか」という疑念も消えない。[^u071]

| 戦争段階 | 日本が講和に必要と考えうる条件 |
|---|---|
| 清軍の朝鮮派兵 | 清軍撤退と高宗への干渉停止 |
| 朝鮮での局地戦 | 朝鮮独立の明文承認、賠償 |
| 清の全面戦争決断 | 北洋の軍事的脅威除去、再侵攻防止、戦費補償 |
| 清海軍の敗北・沿岸進攻 | 台湾・澎湖割譲、賠償、北洋軍備制限を含む講和 |

ここには「戦争目的を拡大するほど『勝利した』と認める条件が遠ざかる」構造があり、日本政府の早期講和拒否そのものが戦争長期化の独立した要因となった。[^u071]

## 台湾・澎湖と対列強外交

南洋海軍の侵入を防ぐため、台湾の割譲はいずれにせよ要求されることになった。[^u065] ただし台湾を領有しても南洋艦隊は台湾東側を通れるので、目的は南西方面の前進基地確保と清海軍の行動制約である。1887年の台湾は劉銘伝の海防近代化が進んでおり、1895年より攻略が難しい可能性があった。[^u065] 割譲後の統治は帝国特別領とする方針が事実上前提となり、統治制度が未確定であることは割譲要求の障害にならなかった（[新領土の統治制度](../institutions/new-territory-governance.md)、[台湾](../regions/taiwan.md)）。[^u066][^u067]

列強に対しては、割譲後も既存開港場（淡水・安平・基隆・打狗）と外国通商権を尊重し、事業特許（コンセッション）を設ける約束によって反対を抑えた。領事裁判権や外国警察権は与えない。[^u069] 遼東半島の永久割譲には固執せず、台湾・澎湖の領有を認めさせる方針で、列強を一枚岩にさせず三国干渉相当の共同干渉を防いだ。[^u069] 戦争後半には台湾割譲は対外準備まで進んだ国家方針となり、撤回が困難になった。[^u071]

# 講和

講和の本当の制約は清の支払い能力であった。清に講和条件を履行させるには、戦後清の信用を補完し融資する列強との交渉が不可欠であった。[^u072] 清に交渉力はなく、終わり方は日本が決められたが、講和の時期は**軍事的には日本が、金融的には列強との事前調整が決める**構造となった。[^u073] 講和の三条件は、北洋の海上脅威の実質的除去、順天府への脅威の信用、列強銀行団との融資調整であった。[^u073]

こうして1889年（本世界線の明治23年）に下関条約が締結された。主な内容は朝鮮の完全独立と李氏王統の承認、台湾・澎湖割譲、賠償金（1億2,000万庫平両[^n4]）、北洋方面の時限的軍備制限、賠償担保としての威海衛一時占領などで、列強の事業権は条約本体ではなく別協定とされた。[^u077] 条約の詳細は[下関条約（1889年）](../diplomacy/shimonoseki-treaty-1889.md)、金融面は[対清賠償借款と講和の国際金融](../economy/indemnity-loan.md)を参照。

# 結果と影響

- **朝鮮**: 清の宗主権が消滅し、高宗の王位と朝鮮の独立が承認された。日本は宗主国にはならない。[^u077]
- **袁世凱**: 講和後に清へ引き渡され、敗戦責任を問われて処刑されたとみられる（少なくとも政治生命は終わった）。[^n5][^u105]
- **国内政治**: 戦時に大きな軍事的影響力を得た中央政府と、戦争を支持し戦費を負担した元老院とが、戦勝成果をどう配分するかという問題が生じた（[日清戦争後の論功行賞](reward-distribution-1889.md)）。[^u071][^u078]
- **三国干渉の不在**: 遼東半島を割譲させなかったため三国干渉は起きず、対露政策は雪辱ではなく安全保障上の警戒を軸に展開した（[日露関係と対露抑止](../diplomacy/japan-russia-relations.md)）。
- **戦争観**: 賠償は清の支払い能力と列強の金融に制約され、占領・台湾統治・海軍補充にも費用がかかったため、帝国政府と領主は「戦争は勝てば儲かる事業ではない」と学習した。[^u088]
- **軍事的遺産**: 陸軍の実戦経験はこの戦争のみで、旅順攻囲や奉天のような大規模野戦軍による近代火力戦の経験を欠いた。[^u097] 海軍は北洋艦隊との交戦で大型装甲艦の重要性を理解したが、日本海海戦のような決戦の成功体験を持たない。[^u127]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 時期 | 1894〜1895年 | 1887〜1889年 |
| 契機 | 東学農民蜂起と日清両国の派兵 | 高宗による袁世凱逮捕と清の朝鮮征討 |
| 朝鮮王権の立場 | 1894年7月に日本軍が王宮を占領 | 高宗自らが日本に軍事的保護を求め、日本側に立つ |
| 開戦の性格 | 朝鮮での勢力争い | 日本が保障した朝鮮の独立と清の宗主権の衝突 |
| 主要戦場 | 平壌・黄海・旅順・威海衛 | 朝鮮での局地戦→黄海→北洋軍港・直隷沿岸[^n6] |
| 講和 | 1895年4月下関条約（賠償2億両、遼東・台湾・澎湖割譲） | 1889年下関条約（賠償1.2億両[^n4]、台湾・澎湖割譲、遼東は要求せず） |
| 戦後 | 三国干渉、露仏借款 | 三国干渉なし、英系中心の銀行団借款 |

史実でも1894年10月23日に日本は英国の和平案（朝鮮独立保障と賠償中心）を受け入れず、1895年には清の講和使節を全権不備で打ち切っており、清が講和を望んだ時点と日本が講和に応じられる時点は一致していなかった。[^u071] 1894年10月末の日本軍遼東上陸で清は北京の危険を認識し、李鴻章は11月に講和を考え始めている。[^u068] 1895年2月の威海衛での北洋艦隊壊滅が講和判断に大きく影響したが、下関条約は清国海軍の永久禁止を定めていない。[^u064]

# 編集注：未決の論点

- 1887年時点の日本海軍が、定遠・鎮遠を中心とする北洋艦隊を撃破できるだけの戦力を持つか（艦隊構成・兵站能力）。主要海戦・陸戦の具体的な場所と日付は決まっていない。[^u064][^u067][^u070]
- 開戦の正確な日付・宣戦の形式（派兵と宣戦の権限分離、元老院同意の要否）。[^u037]
- 1882年・1885年の協定（済物浦条約・天津条約相当）が本世界線でどのような文言で成立していたか、それが派兵手続きにどう影響したか。
- 威海衛・旅順を占領したか、直隷沿岸に上陸したかなど、順天府への圧力の具体的な形。

# 編集注：却下・修正された案

- **1894年開戦案**: 当初は東学農民蜂起と日清戦争を史実どおり1894年に置く前提で議論が始まった（1894年の帝国軍は史実より強いという見通しを含む）。[^u029][^u037] その後、日本とアメリカ以外の条件は史実どおりとしつつ、1882年の危機がエスカレートしうるという方向へ前提が外され[^u047]、袁世凱逮捕事件を契機とする1887年開戦へ置き換えられた。
- **日本が高宗に袁の釈放を勧告する選択肢**: 一度は日本の対応の一つとして挙げられたが、独立保障の下では背信行為だとして退けられた（詳細は[袁世凱逮捕事件（1886年）](yuan-shikai-arrest.md)）。[^u061][^u062]
- **短期戦・早期講和の見立て**: 清の戦争遂行体制の弱さから「戦争は思ったより短くなる」「清が早期講和を選ぶ」可能性が示されたが、全面戦争に進んだ場合は日本の側が早期講和を受け入れられないとして修正された。[^u070][^u071]
- **1888年後半講和案**: 講和の時期として1888年後半が候補に挙げられたが[^u073]、英仏利権の既成事実化を前提に、講和は1889年と決定された。[^u077]
