# 概要

本世界線でも第一次世界大戦は1914年のサラエボ事件を発端として起こる。サラエボ事件はバルカンの民族問題に起因し、日露戦争の有無とは関係がないためである。[^u094] ただし、日露戦争と（史実規模の）その戦訓を欠いたロシアが参戦するため、東部戦線の経過や戦争の帰結は史実どおりにはならない。

日本は、ロシアを当面の敵としておらず、むしろ1889年の[下関条約](../diplomacy/shimonoseki-treaty-1889.md)以来、対清賠償金融・北洋の鉄道港湾権益・対露抑止・海上通商を英国と共有してきた国家である。そのため参戦の判断基準は対露関係ではなく対英関係にあり、「ドイツが勝てばすべてご破算」という認識から英国側に立って参戦する。[^u095][^u096] 標語的にいえば、**日露戦争には勝っても得るものが乏しいが、第一次世界大戦ではイギリスが負けると失うものが大きい**。[^u095]

日本の貢献の中心は、欧州への大規模な陸軍派遣ではなく、軍需品・商船の供給と、インド洋・太平洋・地中海での海軍協力である。[^u097][^u098] その詳細は[第一次世界大戦期の日本の軍需・海運・海軍協力](../military/wwi-japan-war-effort.md)を参照。戦後、日本は英仏への大口債権国・工業国として講和会議に臨み、[対独賠償と産業賠償](../economy/german-reparations.md)、[日英戦時債務整理と中国権益の移転](../diplomacy/war-debt-settlement.md)が戦間期の主要問題となる。[^u099][^u119]

# 開戦（1914年）

## サラエボ事件と七月危機

ボスニアをめぐるオーストリア＝ハンガリーの支配、セルビア民族主義、南スラヴ統一運動は本世界線でも残っており、1914年6月28日の大公暗殺に相当する事件は発生した。[^u094] ただし「サラエボ事件が起きること」と「それが欧州全体の戦争に拡大すること」は区別される。

| 要素 | 本世界線での見通し |
|---|---|
| サラエボ事件 | 発生 |
| 墺の対セルビア強硬策 | 動機は残る |
| 露のセルビア支援 | 継続する理由が強い |
| 独の墺支援 | 独墺同盟が残れば継続 |
| 英仏の参戦 | 七月危機の展開次第 |
| 戦争の結果・ロシア革命 | 大きく変化する余地 |

日露戦争と1905年の敗戦を経験していないロシアは、バルカンで史実より強硬になる可能性がある（たとえば1908〜09年のボスニア併合危機で譲歩しない）。一方、立憲化していなければ意思決定の仕方も異なるため、強硬化とは決めつけられない。[^n1][^u094]

## 日本の参戦の論理

日本の参戦目的は青島などの領土獲得ではなく、長期的な対英協力の維持である。[^u095] そもそも本世界線ではドイツの膠州湾租借が成立しておらず、攻略すべき青島のドイツ軍港・要塞は存在しない（後述）。[^e038] 英国が講和に追い込まれれば、日本が1889年以来築いてきた北洋の金融・通商秩序も再交渉を迫られかねない。したがってドイツの勝利を阻止すること自体が具体的な外交利益となる。[^u095][^u096]

この判断で鍵を握るのは[元老院](../institutions/genroin.md)である。日露戦争を「勝っても儲からないから戦わない」と判断した元老院が、第一次世界大戦では「負けたら損失が大きすぎるから戦う」と判断する。前者は既存利益を拡大する戦争、後者は既存の経済・外交秩序を維持する戦争として認識されるため、矛盾ではない。[^u096] 元老院の財政慎重派にとっての問いは、**「今ここで戦費を惜しんだ結果、英国が敗北したら、日本はその損失をいくらで埋め合わせられるのか」**であり、英国が敗れれば北洋の対露抑止を日本が自力で維持しなければならなくなる。[^u096] ただしこれは白紙委任ではなく、どの程度の支出で実効があるかが次の争点となる。

政府が議会に示した説明は「英国の戦争を支援する必要はあるが、日本が欧州の陸戦を肩代わりする必要はない」というものであった。[^n1][^u095] 対独宣戦によって日本商船が攻撃対象となり対独貿易が失われる費用や、中立のまま英国へ輸出する経済合理性も考慮されるが、「英国の敗北による経済的損失は限定参戦の費用を上回る」と判断される。[^u095]

なお、議会での戦費論議では「ドイツがフランスに勝つこと」と「英国が世界的な海上優位を失うこと」は同じではない、という区別が重要な論点になる。[^u096]

## 参戦の政治過程

パリ危機（史実の第一次マルヌ会戦、9月6〜12日）を見てから参戦するのでは遅いため、参戦は8月中に決まり、マルヌ前後の危機は既決参戦への支持強化と追加支援の契機として働いた。[^n1][^u095][^u096]

| 時期 | 出来事 |
|---|---|
| 1914年8月 | 英国政府から海軍支援の正式要請。日英で作戦範囲と戦後処理を協議。[元老院](../institutions/genroin.md)・[衆議院](../institutions/house-of-representatives.md)が海軍の限定参戦と臨時軍事費を承認し、対独宣戦。極東・インド洋の海上警備と軍需供給を開始 |
| 1914年9月 | パリ危機を受け、元老院・衆議院が軍需生産の拡張と追加戦費を審議 |
| 1914年末〜1915年 | 地中海への艦隊派遣、英国への船舶供給、陸軍海外派遣が議題に上る。マルヌで独軍が阻止されれば追加派兵は見送りもあり得る |

この世界の政治制度では、英国から軍需品の注文を受けることと帝国軍を海外へ送ることは別々の議会判断になる。元老院の領主系産業資本にとって英国向け軍需輸出は産業発展につながるため、**元老院は軍需供給と海軍協力を支持しつつ、陸軍の大規模派遣には慎重**という立場をとる。[^u098]

## 青島要塞の不在

本世界線では、英国系資本が1889年以来山東・直隷に先行していたため、1897〜98年のドイツの膠州湾租借は英国の反対で成立しなかった。ドイツは宣教師殺害事件相当への賠償・宣教師保護・一部の通商権と、青島での商業上の権利や外国船舶向け補給施設の開放を得たにとどまり、膠州湾の99年租借・山東の排他的鉄道利権・青島の海軍基地はいずれも得られなかった。[^e038][^e039] 青島は1898年頃から英国主導・日英資本の商業港として開発され、清朝崩壊後は山東政府・[中国諸省聯合](../diplomacy/china-federation.md)・英国領事当局の協定に基づく青島行政委員会の特別行政区域となっている（→[青島](../regions/qingdao.md)）。[^e038]

したがって1914年に日本が攻撃すべき青島要塞は存在せず、**青島攻略戦も日本による山東占領も起きなかった**。[^e038] 日本の参戦はドイツ艦艇の排除、英国船舶の護衛、太平洋のドイツ植民地への対応から始まった。[^n1][^u095] これは日本の参戦目的を領土獲得から通商・同盟国支援へ移すものである。

青島がないことは大戦中・大戦後の日中関係も変える。1915年の対華二十一カ条要求に相当するものがあっても山東関係の要求は存在せず、1919年の山東問題、1922年の山東還付、1928年の済南事件も史実の形では起きなかった。[^e038]

なお、本世界線では日英間の金融・通商・対露協調は発達しているものの、史実のような正式な軍事同盟（日英同盟）が存在するとは限らない。[^u095]

# 戦争の経過

## 日本の協力の形

日本陸軍は日清戦争（1887〜1889年）以外に大規模な実戦経験をもたず、観戦武官を当初から派遣していても実際に欧州で軍事行動できるかは別問題であった。[^u097] そのため「日本が英国を救うために参戦する」ことと「日本陸軍が西部戦線で大規模に戦う」ことは切り離して考えられた。[^u097] 政府方針は次のように要約される。[^n1][^u098]

> 英国の敗北を阻止するため、帝国の工業生産と海軍力を最大限活用する。ただし、陸軍の欧州派遣については、軍事的効果と補給能力が確認されるまで保留する。

史実より強い工業国家だからこそ、陸軍を送るよりも英仏の軍需生産を肩代わりする方が戦局に大きく貢献できる、という逆説がある。日本の最大の貢献は「派遣した師団の数」ではなく「連合国へ供給した軍需品と船腹の総量」になる。[^u097][^u098] 加えて、日本海軍がインド洋・太平洋の防衛を引き受け、英海軍を北海・大西洋・地中海へ集中させたことが、戦後の日英関係を規定する第一の要因となった。[^u120] 具体的な数値と任務は[第一次世界大戦期の日本の軍需・海運・海軍協力](../military/wwi-japan-war-effort.md)で扱う。

## アメリカの参戦

アメリカの参戦動機は日本とほぼ同じで、フランスが危うくなれば参戦するというものであった。[^u101] 違いは、日本が1889年以来英国と直接の外交・金融利害を共有しているのに対し、米国は通商利益と欧州の勢力均衡のために参戦を検討する点にある。

- 1914年8月：中立を宣言し英仏との通商を維持。
- 9月：独軍のパリ接近で英仏への金融・軍需支援拡大を議論。
- 1915年：ルシタニア号撃沈で世論が反独に傾くが、参戦には至らず中立国として英仏への軍需供給・金融を続ける。
- 1917年：ドイツの無制限潜水艦作戦とフランスの危機が重なり参戦。[^n5]

本世界線では[南北戦争が起きていない](american-civil-war-avoided.md)ため、1914年の大統領がウィルソンである保証はなく、連邦軍制・徴兵制度も史実と異なり得る。[^u101][^u119] 日米は共同で英国を支える構造をとり、日本が太平洋・インド洋の海軍活動・軍需供給・商船建造を、米国が大西洋の海運・軍需供給・金融・陸軍派遣を担う。ただし米国は「共同交戦国」として独立した立場を保ち、日英と一体化するとは限らない。[^n1][^u101]

## ロシアと東部戦線

日露戦争を経験しなかったロシア軍は、参謀組織・将校教育・兵站・戦術の改革を欠いたまま参戦する。日米から大量の小銃・砲弾が供給されても東部戦線がましになるとは限らず、補充できるからこそ攻勢を続けて人的損耗がかえって増えた。[^u114][^u115] 最悪の場合は「19世紀の軍隊が第一次世界大戦に参戦してそのままミンチになる」展開である。日本の物資供給が皮肉にも消耗戦を長引かせ、ロシア帝国の崩壊を早めた。[^n1][^u115] 革命の経緯は[ロシア帝国の動揺と革命](russian-revolution.md)を参照。

ロシアが早く崩壊するほど連合国の負担は大きくなり、その負担を日米が肩代わりできるかが終戦時期を決める。ロシアが1916年末に攻勢能力を失えば、1917年の西部戦線は史実より厳しくなる。[^u119]

# 戦争規模と終戦シナリオ

## 終戦時期の三つの見通し

戦争の長さについては、次の三つの見通しがある。[^n2][^u119]

| シナリオ | 終戦 | 概要 | 英国財政への影響 |
|---|---|---|---|
| A：早期終結型[^n5] | 1917年 | 米国が1915年頃参戦、日本の軍需供給も早期に立ち上がり、ロシアの全面崩壊前に講和（米国の参戦が1917年と確定したため成立しない） | 史実より軽い余地 |
| **B：長期消耗型**[^n3] | **1918年** | 日米の工業力が連合国を支えるが消耗が続く。1917年ロシア革命、1918年離脱、日米の追加戦力でドイツ敗北。人的損害は史実並み | 史実と同程度かそれ以上 |
| C：戦争激化型 | 1919〜1920年 | ロシア早期崩壊で独が西部戦線に集中、米陸軍動員も遅延 | 史実以上 |

米国の参戦が直ちに戦局を変えるわけではない。史実の米国は1917年4月の参戦時に常備陸軍約13万人で、約200万人を欧州へ送るには1918年までかかった。[^u119] 本世界線でも米国の参戦は1917年であり、1915〜17年に英国の軍需・資金を支える役割は日本に大きくかかった。[^n5]

## シナリオBの年表

シナリオBに沿った経過は次のとおりである。[^n3][^u119]

| 年 | 出来事 |
|---|---|
| 1914年 | 欧州大戦勃発。日本が英国側で参戦し、海軍と軍需工業を動員 |
| 1915年 | 日本と中立国米国の英仏への軍需供給が拡大 |
| 1916年 | ロシア軍が大損害を受け、国内政治危機が深刻化 |
| 1917年 | 米国参戦。ニコライ2世の退位と急進革命。ロシア軍の戦闘能力が崩壊 |
| 1918年 | ロシアが単独講和。日米の工業・人的支援を受けた連合国がドイツを破る |
| 1919年 | 講和会議。対独賠償、英仏の対外債務、日本への現物・技術賠償が争点 |

## 戦争の帰結

この年表の帰結として、英仏は日本と米国に大きな債務を負い、革命ロシアは旧債務を否認し、ドイツには従来以上に重い戦後処理を求める圧力が生じる。[^u119] 日本は戦勝国として、債権国・工業国として講和会議へ参加し、ドイツの工業技術の獲得を重視する。[^u099] 講和会議では、日本がドイツの山東権益を引き継ぐ史実の山東問題は生じない。五四運動に相当する中国の民族主義運動が起きても、その中心は青島の日本への移管ではなく、講和会議で清朝以来の外国権益（特に英国・日本の権益）が維持されたことへの反発と、日英が支える中国諸省聯合の体制への反対となる。[^e029][^e038] ロシアが連合国側に残って戦勝国として講和会議に出る場合は、日英の戦後東アジア秩序に直接関与されるため、日本にとっては脱落よりかえって厄介になり得た。[^n4][^u100]

日本にとってこの戦争は、**自国の産業と貿易を支えてきた国際秩序を維持するため、初めて欧州の勢力均衡へ本格的に関与する戦争**であった。[^u096] 同時に、日露戦争を回避して財政・産業を発展させた日本が、その発展を支えてきた日英関係を守るために参戦する、という1889年以来の政策の延長線上にある。[^u095]

# 編集注：却下・修正された案

- **青島要塞が存在しない「可能性」（前編の検討案）**：ドイツが膠州湾・青島を史実と同条件で取得できるとは限らないという前編の見通し（U95）は、会話ログ2でドイツの租借不成立・青島の英国主導商業港化として確定した。[^u095][^e038]
- **ロシアの継戦による戦局好転**：ロシアが物資を得て1918年まで継戦すればドイツは史実より厳しくなる、という当初の見通し（U100）は、物資が潤沢でも人的損耗が増えるという指摘（U114）により修正された。[^u100][^u114]
- **米国の1915年頃の参戦**：前編で作業仮説として置かれた（U119）が、史実どおり1917年に改めた（作者確定）。[^n5][^u119]
- **共和政ロシアの戦勝国参加**：帝政崩壊後の新政府が戦い抜き講和会議に出る案は、軍の崩壊とボリシェヴィキ掌握の経路が有力視されたことで後退した。[^u114][^u115]
