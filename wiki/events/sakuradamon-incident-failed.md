# 概要

1860年、水戸浪士らによる大老・[井伊直弼](../people/ii-naosuke.md)の襲撃（桜田門外の変）は失敗に終わる。直弼は生き延びるが、事件を機に彦根藩内部で「押込」が行われ、大老としての実権を失う。本世界線では[南北戦争の早期終結](american-civil-war-avoided.md)に続く第二の分岐点であり、ここから幕末史が史実と大きく分かれていく。[^u002]

史実と同じく井伊の強権政治はここで終わるが、幕府が受ける打撃の性質は大きく異なる。最高権力者を白昼に暗殺されたのではなく、襲撃者を撃退したうえで、内部の政治判断によって大老を退任させた形になるからである。幕府は「井伊大老の政策には行き過ぎがあったため幕府自身が政治を改める。しかし武力による幕政への干渉は認めない」と説明でき、尊攘派への妥協と統治権の防衛を両立させられる。[^u002]

この「政策の否定」と「襲撃者への厳罰」の両立という論理は、直後の[水戸藩処分（1860年）](mito-domain-disposal-1860.md)の前提となり、さらに中央集権化の最初の実例へとつながっていく。[^u005]

# 経過

## 確定している骨格

* 桜田門外の変は失敗し、井伊直弼は生存する。[^u002]
* 直弼は押込によって大老としての実権を失う。[^u002]

## 襲撃と押込の詳細（検討案）

以下は骨格に沿って組み立てられた具体像であり、以後の議論でもこの形が前提として扱われている。

| 段階 | 内容 |
|---|---|
| 襲撃 | 1860年3月24日（旧暦3月3日）、水戸浪士らが井伊直弼の行列を襲撃。護衛がこれを撃退し、直弼は負傷しながらも生還する |
| 弾圧路線の阻止 | 事件直後、直弼はさらなる弾圧を命じようとするが、彦根藩の重臣たちが反対する。安政の大獄で諸大名・朝廷との関係はすでに悪化しており、直弼の路線継続は彦根藩そのものの存続にも危険だと判断した |
| 押込 | 重臣たちは直弼を「病気療養」の名目で隔離し、政治的発言を封じる |
| 幕府への届出 | 病気による大老辞任を幕府に届け出る。幕府では老中たちが政権運営を引き継ぐ |
| 家督処理 | 直弼は彦根藩主でもあるため、押込の実施には重臣間の合意と家督処理が要る。当面は藩主名義を残しつつ実権を奪い、のちに隠居・家督相続へ移る |

（検討案）[^u002]

この結果、事件は三層の構図をとる。[^u002]

* **対外的には**、井伊直弼が病気で隠居した。
* **実態としては**、彦根藩重臣による押込が成立した。
* **幕府では**、老中たちが政権運営を引き継ぐ。

押込の主体を彦根藩の家老たちとし、幕府の老中はこれを黙認する、という配置が事件に説得力を与える。幕府は直弼を公然と否定せずに政策転換でき、彦根藩も家名を守るために幕府との協調を選べるからである。これは単なる暗殺未遂ではなく、「彦根藩内部による井伊政権の終結」と位置づけられる。（検討案）[^u002]

## 押込の危うさ

井伊が失脚した事実は広く知られるため、押込の実態が露見すれば幕府の内部対立をさらけ出す危険がある。それでも、最高権力者が暗殺された史実とは政治的衝撃の大きさが違う。[^u002]

# 帰結

## 幕政の再編

井伊失脚後の幕政は、老中主導で次の方向に進む（検討案）。[^u002]

* **安政の大獄の後始末**: 吉田松陰・橋本左内の処刑は取り消せないが、生存している処罰対象者の謹慎解除・復権を進める。
* **人事**: 将軍[徳川家茂](../people/tokugawa-iemochi.md)が正統性を維持し、安藤信正が公武合体と朝廷との関係修復、久世広周が老中として補佐、松平春嶽が諸侯との調整と幕政改革を担う。反井伊派が外部から圧力をかけるのではなく、幕府の内部に戻って改革を進める構図になる。
* **公武合体**: 和宮降嫁の構想は井伊政権時代から存在していたので、直弼の死は公武合体の必要条件ではない。安藤信正らが幕政を引き継げば、幕府は威信を維持したまま公武合体へ移行できる。ただし孝明天皇の条約問題への不満は残るため、和宮降嫁が必ず早まるわけではない。
* **1862年の薩摩**: 史実の島津久光上洛は幕政改革（一橋慶喜の将軍後見職、松平春嶽の政事総裁職就任）を要求するものだった。本世界線で改革派がすでに幕政に復帰していれば、久光の圧力目的の一部が失われ、薩摩は幕府の改革勢力と協調して中央政治参加を求める可能性がある。

これらは後に[1861年公武協定](../diplomacy/kobu-agreement-1861.md)へと収斂していく。

## 一橋慶喜の位置づけの修正

当初の構想では一橋慶喜を「将軍を支える改革派の中心人物」とする案が示されたが、これは後に修正された（「# 却下・修正された案」参照）。水戸徳川家への厳罰が避けられない以上、斉昭の子である慶喜を改革の中心に抜擢するのは不自然であり、幕政改革は家茂を中心に進むことになる。[^u004][^u005]

## 「政策の否定」と「襲撃者の厳罰」の分離

襲撃後の新幕閣は井伊政権を終わらせた側だが、だからといって水戸への処罰が軽くなるわけではない。むしろ新幕閣だからこそ、次の区別を明確にする必要があった。[^u005]

> 井伊直弼の政策が間違っていたという判断と、井伊直弼を武力で排除しようとした者を厳罰に処することは、完全に両立する。

襲撃を軽く処理すれば、「幕府の政策に不満があれば、家臣を脱藩させて幕閣を襲撃しても、藩主家はほとんど責任を問われない」というメッセージが諸大名に伝わってしまう。こうして、事件は[水戸藩処分（1860年）](mito-domain-disposal-1860.md)へと直結する。[^u005]

## 長期的な意味

* 幕府の権威が史実ほど損なわれないため、幕府は朝廷権威を借りた「日本国の改革」として中央集権化に着手する余地を得る（[幕藩体制と中央集権化のジレンマ](../concepts/centralization-dilemma.md)）。[^u003]
* ただし国外の情勢は待ってくれない。1860年は英仏軍の北京占領の年であり、井伊が失脚し水戸の処遇を決めようとしているまさにその頃、清朝は列強に首都を落とされている。[^u008]
* 水戸処分が成功したことは、成長した家茂にとって「幕府の命令に従わない勢力は軍事力で整理できる」という危険な成功体験となり、後の強硬路線の伏線となる。[^u013]

# 却下・修正された案

* **一橋慶喜を改革派の中心とする人事案**: 井伊失脚後に慶喜・春嶽の復権が早まり、慶喜が家茂を支える改革派の中心になるという当初案（U2）は、水戸徳川家の厳罰化に伴い修正された。幕府が水戸の政治的影響力を解体しようとしている最中に斉昭の子を抜擢するのは不自然で、安政の大獄の処分が解除されても政治的信用の回復には時間がかかる。慶喜が将軍候補から排除される可能性すらある。[^u004][^u005]
* **反井伊派政権なら水戸への処罰は軽くなるという想定**: 反井伊派が政権を握っても、罰が軽すぎれば幕府の権威が弱まり、大老襲撃という前例のない事件を軽く扱うことはできない、として退けられた。[^u005]

# 未決の論点

* 生存した井伊直弼のその後。彦根藩内で直弼支持派と押込派の対立が続くか、直弼本人が政治復帰を画策するか、隠居・家督相続はいつ行われるか。[^u002]
* 彦根藩が早くから幕府改革派と協調した場合、史実で戊辰戦争の際に新政府側についた彦根藩の立場がどう変わるか。[^u002]
* 1862年の島津久光上洛が本世界線でどのような形をとり、薩長同盟が成立するか。後の設定では長州征討・薩英戦争は史実どおり起きる方向で扱われている。[^u002]
