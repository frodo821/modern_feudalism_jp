# 概要

袁世凱逮捕事件は、1886年、漢城の日本公使館から政務を執っていた朝鮮国王[高宗](../people/gojong.md)が、清国の駐朝鮮代表（駐箚朝鮮総理交渉通商事宜）[袁世凱](../people/yuan-shikai.md)を朝鮮官憲に命じて捕縛させた事件である。[^u060][^u061] 日本帝国軍の駐留がもたらした捜査の自由から清の介入の「証拠」が出てきたこと、そして「日本は実際に動く」と確信した高宗が先走ったことが、逮捕の原因となった。[^u060][^u061]

事件の本質は、袁個人の身柄をめぐる外交紛争ではなく、**清朝の宗主権と朝鮮王国の主権がどこで衝突するかを明確にした**点にある。[^u060] 朝貢国の君主が宗主国の官員を自国の司法権で裁くことは清にとって受け入れがたく、清朝中央は[李鴻章](../people/li-hongzhang.md)の慎重論を退けて朝鮮征討に踏み切った。[^u061][^u063] こうして本世界線の[日清戦争（1887〜1889）](sino-japanese-war.md)は、東学農民蜂起ではなくこの事件をめぐる外交危機から始まった。[^u060][^u077]

# 背景

- 1885年以降、清は清仏戦争の終結を受けて対朝鮮政策を強め、袁世凱らが宮廷人事に介入し、高宗廃位論が浮上した（[清の対朝鮮政策と李鴻章](../diplomacy/qing-korea-policy.md)）。[^u057]
- 廃位を恐れた高宗は日本公使館に避難し、公使館は清の使嗾が疑われる勢力に襲撃された。その後、高宗の正式な許可のもと日本帝国軍が邦人保護名目で漢城に駐留した（[高宗の日本公使館避難と1886年漢城公使館危機](gojong-legation-refuge.md)）。[^u058][^u059]
- 日本は1884年以来、李氏王統による朝鮮の独立を保障していた（[朝鮮国独立保障（1884年）](../diplomacy/korea-independence-guarantee-1884.md)）。

帝国軍の駐留は高宗にとって奇貨であったが、同時に清の介入の「証拠」が表に出るリスクを高めた（ユーザーの判断）。[^u060] 高宗は清の圧力を受けずに、以前は手を出せなかった親清派官僚や軍人を調査できるようになったからである。

# 経過

## 証拠の三段階

清の関与を示す証拠は、政治的な重みの異なる三段階に区別される。[^u060]

| 段階 | 内容 | 意味 |
|---|---|---|
| 1 | 清側と朝鮮国内の反高宗派との接触 | 朝鮮官僚の処罰の根拠にはなるが、袁の逮捕の正当化には足りない可能性 |
| 2 | 袁世凱ら清の現地当局者による政変・公使館襲撃への関与 | 袁個人の責任追及の根拠 |
| 3 | 李鴻章や清朝中央による命令 | 日清間の国家的紛争 |

どの段階まで証拠が及んだかは決まっていない（未決の論点を参照）。

## 捕縛に至る過程（検討案）

1. **公使館襲撃事件の捜査**: 朝鮮の捜査当局が日本側の協力を得て、襲撃に関与した朝鮮人官僚・軍人を調査する。
2. **清側との連絡の判明**: 反高宗派と袁世凱周辺の接触を示す文書が発見される。ただし指示関係には争いが残る。
3. **召還要求**: 高宗が清の内政干渉を非難し、袁の召還を要求、その外交上の資格を認めないと通告する。
4. **袁の拒否**: 袁は宗主権を根拠に王命への服従を拒む。
5. **捕縛**: 高宗が朝鮮官憲に袁の身柄拘束を命じる。日本軍は警備・支援にあたるが、形式上は朝鮮政府による拘束である。[^u060][^u061]

決定的なのは、**逮捕を命じたのは日本政府ではなく高宗自身**だったことである。[^u060]

## 高宗の先走り

ユーザーの判断として、一連の事件で「日本は実際に動く」と確信した高宗が先走り、捕縛まで進める可能性は高いとされる。[^u061] 高宗から見れば、1882年の漢城危機で日本は清と対峙し、1884年には独立を保障し、1886年には帝国軍を派遣した。それならば日本は清との武力衝突を覚悟してでも王位を保障する、と考えるのは一応合理的であった。

一方、日本政府の計算は公使館と高宗の安全確保までであり、清国官員の逮捕によって宗属関係を強制的に解消することまで承認していたわけではなかった。この認識のずれ（後ろ盾の過信）が危機を生んだ。[^u061] 「**日本は高宗を守るつもりで派兵したが、高宗はその日本軍を後ろ盾に清朝の宗主権そのものに挑戦してしまう**」。戦争を起こすつもりのなかった日本は、自ら保障した朝鮮の独立と高宗の行動によって戦争に引き込まれた。[^u061]

## 清の最後通牒と高宗の拒絶

| 段階 | 内容 |
|---|---|
| 清の最後通牒 | 袁の釈放、処罰の撤回、事件関係者の処分を要求。日本には軍事支援の停止を要求 |
| 高宗の拒絶 | 清の内政干渉を否認し朝鮮の司法権を主張、日本の独立保障を根拠に援助を要請 |
| 清の軍事動員 | 朝鮮の秩序回復と宗主権維持を名目に派兵準備、李鴻章の北洋軍事体系を動員 |
| 日清の対峙 | 日本は朝鮮国王の保護を理由に撤兵を拒否、清は袁の救出と朝鮮政府への制裁を要求 |

（最後通牒以下の段階の具体像は検討案）[^u061]

清から見れば、逮捕は朝貢国の君主が宗主国の官員を裁こうとする重大な秩序違反であり、清は朝鮮征伐までエスカレートしうる（ユーザーの判断）。[^u061] 史実でも1882年に清軍は大院君を拘束して中国へ連行しており、宗主権を根拠とする武力介入の先例があった。

# 法的争点と日本の立場

## 袁の地位

袁の正式な地位は「駐箚朝鮮総理交渉通商事宜」であり、清国総督とも近代的な外交代表とも単純に同一視できない。そのため外交上の免責が及ぶかが争点となった。[^u060][^u062]

| 当事者 | 主張 |
|---|---|
| 高宗政府 | 国王への廃位工作や反乱への関与は朝鮮の法秩序への重大な侵害 |
| 清国政府 | 袁は清の正式な派遣官であり、朝鮮に身柄拘束の権限はない |
| 日本政府 | 朝鮮の独立を承認する以上、高宗政府の司法・治安権を尊重すべき |

逮捕が外交上許されるかという問題と、袁が実際に不当な政治介入を行ったかという問題は別である。[^u060]

## 日本は釈放を勧告しない

日本が朝鮮の独立を保障している以上、日本が袁の逮捕を咎める理由は乏しく、清の要求を呑むよう朝鮮に勧告することさえ背信行為となる（ユーザーの判断）。[^u062] 日本が清の要求を高宗に強制すれば、朝鮮から見れば「清の宗主権を日本が代行している」ことになる。本世界線の独立保障は、少なくとも次の二点を含むと解釈された。[^u062]

- 李氏王朝が清の承認なしに朝鮮を統治できること
- 朝鮮政府が清国の官員に対しても自国の司法権・治安権を行使できること

日本政府の立場は次のように表現される（検討案の文言）。[^u062]

> 袁世凱の法的地位と訴追の適法性は、朝鮮政府と清国政府の間で解決すべき問題である。ただし、その解決を強制するために清国が朝鮮へ軍隊を派遣することは認めない。

これにより日本は、逮捕を無条件に支持しなくても、清の軍事的強制を拒否するという保障の核心を維持できた。

## 日本国内の反応

[元老院](../institutions/genroin.md)では、政府が高宗に譲歩を求めれば相当な批判が出る状況であった。世襲領主権と司法権を憲法で保障する日本帝国にとって、独立を保障した外国君主に司法権の行使を断念させることは説明しにくく、領主議員からは「朝鮮国王の統治権を尊重せよ」という主張が出た。[^u062] 戦争を避けたい議員も「朝鮮の司法権は尊重する、しかし清との戦争は外交で避けよ」と主張できたため、国内対立の軸は「高宗を見捨てるか否か」ではなく、「**保障という既定方針をどれだけの軍事的危険を負って維持するか**」に移った。[^u062]

# 帰結

- 清朝中央では「李鴻章は譲歩を重ねた結果、朝鮮王が清国の官員を捕縛し日本軍がこれを守っている」という強硬論が優勢となり、譲歩の余地は失われた（ユーザーの判断）。[^u063]
- 1886年末〜1887年に清は朝鮮征討を準備し、袁の釈放、高宗への制裁、日本軍撤兵を要求した。征討の目的は高宗の排除と別の李氏王族の擁立へ拡大した。[^u063]
- 1887年に清軍が朝鮮へ進出して日清戦争が始まった。[^u063][^u077]
- 袁自身は戦争中も政治生命を回復できず、1889年の講和後に清へ引き渡されて敗戦責任で処刑される経路が設定として成立している。[^u105]

日清戦争は「日本が朝鮮市場を欲して始める戦争」ではなく、「**日本が保障した朝鮮の独立と、清が維持しようとする宗主権が正面から衝突する戦争**」として性格づけられた。[^u062]

# 史実との比較

- 史実で袁世凱が高宗に逮捕された事実はない。[^u061]
- 史実の袁は1885年に駐箚朝鮮総理交渉通商事宜として派遣され、朝鮮の外交・軍事・人事に強い影響力を行使した。1886年（8月）には、高宗の対露接近を背景に、清軍を派遣して高宗を廃し李氏王族の別人を立てる案（大院君復権案を含む）を李鴻章に示したが、李は認めなかった。[^u057][^u060][^u062]
- 史実の高宗も袁に対抗するため、外務担当機関とは別経路で自主外交を進め、袁の召還を求めていた。[^u060]
- 1885年には清の官僚が、朝鮮に強力な軍隊を送り閔妃周辺を排除する構想を提案していた。[^u061]

# 却下・修正された案

- **袁の身柄をめぐる外交取引**: 清が袁を召還し、日朝側が身柄を引き渡す代わりに清が王位継承・宮廷人事への介入を控える、という収拾案が当初示された。[^u060]
- **日本が高宗に釈放を勧告する選択肢、および「司法権を認めつつ袁の身柄について国際協議を設ける」妥協案**: 日本の対応の選択肢として示されたが[^u061]、独立保障の下では背信行為だとして退けられ、「日本の約束を軽く見すぎていた」と撤回された。[^u062]
- **袁の戦後処遇を未確定とする扱い**: 清末・民国初期の政治を考える際、袁の処遇は未確定の重要問題とされたが[^u104]、日清戦争で清が大敗した以上、袁は処刑されているか、少なくとも政治生命は終わっているとして確定した。[^u105]

# 未決の論点

- 発見された「証拠」がどの段階（現地での接触／袁の関与／清中央の命令）まで及んだか。[^u060]
- 逮捕の実行に日本軍がどこまで関与したか（警備支援か、実際の拘束か）。[^u060]
- 逮捕の正確な月日。袁がどこに拘束され、戦争中どう扱われたか。処刑が朝鮮側の裁判によるのか、清への引渡し後か（引渡し後の処刑が有力な経路）。[^u105]
