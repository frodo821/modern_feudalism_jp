# 概要

[桜田門外の変の失敗](sakuradamon-incident-failed.md)を受け、幕府は1860年に水戸藩を厳しく処分した。井伊直弼が生き延びた以上、襲撃者を出した水戸徳川家が従来どおり御三家の地位を保つことはありえず、少なくとも転封、悪ければ改易となる。藩主は切腹までは求められないものの、改易か、情状が酌量されても蟄居を免れない。そして水戸徳川家と水戸藩士の結びつきを温存することは許されないため、転封は避けられない。[^u004][^u005]

処分を決めたのは井伊直弼本人ではなく、井伊政権を押込によって終わらせた新しい幕閣である。反井伊派の政権であっても、大老襲撃という前例のない事件に軽い処分で臨めば幕府の権威は弱まる。新幕閣は「井伊の政策が誤りだったという判断」と「井伊を武力で排除しようとした者への厳罰」を区別し、後者を徹底した。[^u004][^u005]

この処分は、「御三家でさえ幕府の秩序に背けば領国を失う」「大名家の存続と、その家が特定の領国を世襲統治する権利は別問題である」という前例を作った。本世界線の中央集権化は、全国の藩を一挙に廃止することではなく、まず水戸藩の政治的解体から始まる。没収された旧水戸領は、のちに[1861年公武協定](../diplomacy/kobu-agreement-1861.md)の取引材料となり、[那珂川公爵家](../people/nakagawa-ducal-house.md)の所領となった（[旧水戸領と禁裏御料預地](../regions/former-mito-domain.md)参照）。[^u005][^u006][^u009][^u018]

# 背景

水戸藩は桜田門外の変以前から、幕府の統治秩序に対して三重の問題を抱えていた。[^u004]

| 問題 | 内容 |
|---|---|
| 将軍継嗣問題 | 徳川斉昭らが一橋慶喜を推し、井伊直弼と対立した |
| 戊午の密勅 | 朝廷が幕府を経由せず直接水戸藩へ勅書を下し、水戸藩が朝廷と直結して幕府に対抗しうる構図ができた |
| 大老襲撃 | 水戸脱藩者17名と薩摩藩士1名が大老の行列を襲った |

本世界線では襲撃が失敗したため、幕府は「最高権力者を殺された被害者」ではなく、「襲撃を撃退し、その責任を問う統治者」として振る舞える立場にあった。襲撃者が脱藩者だったという説明だけで藩の責任を免除することはできず、幕府の権威を守るには相当厳格な処分が必要とされた。[^u004][^u005]

# 処分の論理

## 処罰理由の限定

藩主徳川慶篤が大老暗殺を命じた証拠はない。史実の襲撃者たちは脱藩しており、水戸藩内でも鎮派と激派が対立していた。したがって処罰の根拠は「藩主が暗殺を命じたこと」ではなく、「家臣統制の失敗と、幕府の統治秩序を危険にさらした責任」とされる。近世の大名統制では、藩主本人が直接指示していなくとも領主としての責任は免除されない。しかも慶篤はすでに安政の大獄で謹慎処分を受けており、従前の処分を強化する理由は十分にあった。[^u005]

一方で、処罰理由を「戊午の密勅を受け取った罪」にすると、孝明天皇の権威そのものを否定するように見えかねない。そこで処分は「幕府要人への武力襲撃を防止できず、統治責任を果たさなかった罪」に限定された。この筋立てによって、幕府は朝廷への忠誠を示しつつ水戸藩の転封・減封を正当化し、公武合体と両立させることができた。[^u004]

## 処分の目的

目的は水戸徳川家を懲罰することだけではなく、**水戸藩士が再び徳川斉昭・慶篤父子を政治的な旗印として結集できない状態を作ること**にあった。藩主を江戸屋敷に閉じ込めても、家臣団・藩校・藩政機構・領国が従来どおり存続すれば水戸藩の政治構造は残る。そのため藩主家と家臣団の結びつきを断つ処分が必要とされ、家臣の再配置、一部の幕臣編入、藩政幹部の交代まで踏み込むことになった。[^u005]

# 処分の内容

## 確定している範囲

* 水戸徳川家は従来と同じ地位を保てない。[^u004]
* 転封は不可避。[^u005]
* 藩主は切腹には至らないが、改易、または最低でも蟄居。[^u005]

## 処分表（検討案）

| 対象 | 処分 |
|---|---|
| 徳川斉昭 | 永蟄居の継続。水戸藩政への一切の関与を禁止 |
| 徳川慶篤 | 藩主隠居・蟄居。藩政への復帰を禁止 |
| 水戸徳川家 | 水戸35万石を没収し、大幅減封のうえ他国へ転封。家督は幕府が承認した別の一族が継承。御三家相当の政治的特権を停止 |
| 水戸藩重臣 | 家臣統制の責任を追及し、幕府が人事に介入 |
| 襲撃関係者 | 捕縛・処刑・家名断絶などの厳罰 |
| 旧水戸領 | 没収（当初は幕府直轄化または忠実な藩への分割を想定。のち朝廷への献上へ） |

（検討案）[^u005][^u006]

## 御三家の家格をめぐって

完全改易は水戸徳川家を大名として消滅させ、「徳川一門であっても統治秩序を破れば家を失う」という強い前例を作るが、尾張・紀伊両家にも衝撃を与える。そこで完全改易と単純な転封の中間として、「水戸35万石を没収し、水戸徳川家を御三家の地位から外し、別地に小領を与えて家名だけ存続させる」措置がとられる。水戸藩の改易と水戸徳川家の存続は両立しうる、という考え方である。御三家の家格を正式に剥奪する手続きには史実上の先例がなく、幕閣内では御三家の地位を維持するか剥奪するかをめぐって激しい議論が起こる。（検討案）[^u004][^u005]

## 転封先（検討案）

転封先は「旧水戸藩士が再結集しにくいこと」「江戸から監督できること」「受け入れ先に既存の大名がいないこと」を条件に、史実の幕府直轄地から選ぶのが自然とされた。[^u006]

| 候補地 | 利点 | 問題点 |
|---|---|---|
| 甲斐国（甲府周辺） | 1724年以降基本的に幕府直轄で、甲府勤番と代官の行政機構がある。徳川一門を移す制度上の先例がある | 甲府城と甲州街道は江戸防衛上の要地で、城を与えるのは危険。田安家・一橋家の領地もあり調整が必要 |
| 飛騨国（高山周辺） | 幕府直轄地で、山地により水戸から隔絶され、旧藩の人的ネットワークを断ちやすい | 石高が小さく、山林資源を幕府が手放す問題。大規模な家臣団を養えない |
| 駿河国（駿府周辺） | 家康ゆかりの地で、一門の処遇として象徴的 | 東海道の要地で、江戸と京都を結ぶ位置に不穏な一門を置くのは危険すぎる |

推奨案は「**水戸徳川家を8万石に減封し、甲斐国内の幕府領の一部を与える。ただし甲府城は引き続き幕府が管理し、水戸家の藩庁は陣屋とする**」である。すなわち「一つの城を持つ大名から、複数の飛地を持つ小規模な徳川一門への格下げ」となる。家名存続の規模としては5万〜10万石程度が想定され、その中で8万石が選ばれた。ただし甲斐国で8万石をまとめて割り当てられるかは個々の幕府領を精査しないと確定できない。（検討案）[^u006]

## 旧家臣団の処遇（検討案）

* 旧水戸藩士を一括して転封先へ移すことは認めない。幕府が移籍を審査し、問題のない者だけを同行させる。[^u006]
* 残りは幕臣への登用、他藩への再仕官、帰農などに振り分け、大規模な浪人集団を作らないよう扶助や再就職先を確保する。[^u006]
* 水戸藩はもともと藩主が原則として江戸に住む定府制で、家臣にも江戸勤務と国元勤務の別があった。これを利用し、江戸勤務の家臣の一部を幕府へ吸収し、国元に根を張る家臣団は別途整理する。[^u006]
* 家ごとの審査に加え、実際の襲撃への関与、藩内での役職、幕命への服従状況を区別する。恭順する藩士には生活を保障し幕臣登用の道を開く。全員を反逆者として扱えば、水戸の土地と人々の統治自体が難しくなる。[^u006]
* 恭順派を新領地へ移し、尊攘派を処罰・排除し、旧水戸領には幕府の代官・奉行を派遣する。[^u005]

# 実施と経過

処分は1860年中に決定された。老中たちが事件を調査して水戸藩の統治責任を追及し、慶篤の隠居・蟄居、旧水戸領の没収、水戸徳川家の減封転封を決める。[^u005]

処分の実施には軍事的な裏付けが要った。転封が政治的に合理的であることと、幕府が実際に転封を強制できることは別問題である。水戸藩には武装した家臣団があり、1860年の時点で幕府と水戸藩士の間に局地的な武力衝突が起こる可能性があった。それは1868年の戊辰戦争よりも早く始まる幕藩体制の解体過程となりうる。史実の1864年の天狗党挙兵に類似した蜂起が、転封・改易への反発から1860年代前半に起きることも考えられた。[^u005][^u006]

結果として、本世界線の幕府は1860〜1861年に水戸徳川家を減封転封し、旧水戸領の統治機構を再編したうえで、深刻な内乱を回避できたとされる。時間の制約から、まず水戸城を幕府の軍事管理下に置き、領主問題は暫定的に棚上げして朝廷との交渉で最終的な処遇を決める、という順序がとられた。旧水戸領は1861年に朝廷へ献上され、[1861年公武協定](../diplomacy/kobu-agreement-1861.md)の対価となる。[^u008][^u009][^u013]

# 影響

## 中央集権化の前例

| 効果 | 内容 |
|---|---|
| 前例の創出 | 「御三家でさえ幕府に背けば領国を失う」。諸藩にとって恐ろしい先例であると同時に、将来の全国的な再編の政治的根拠となる |
| 領有権の論理 | 「大名家の存続と、その家が特定の領国を世襲的に統治する権利は別問題である」という論理が生まれる |
| 軍事組織の吸収実験 | 恭順する藩士を幕臣に編入し、抵抗する者を排除することで、藩の軍事組織を中央へ吸収する実験となる |
| 関東北部の統治 | 江戸の北東の交通・軍事上の要地を幕府が押さえる |

ただし御三家への処罰はあくまで重大事件への懲罰であり、一般の大名に対して無条件に領地替えや行政権の回収ができることには直結しない。厳罰はかえって諸大名の警戒と結束を招く恐れもあり、全国的改革の先例にするには、恣意的処分ではなく明確な理由と手続きが必要とされた。[^u004][^u006]

## 尊王攘夷運動への影響

尊王攘夷運動そのものは消えない。水戸藩という組織的支柱は失われるが、処分を受けた水戸藩士が各地へ流出し、長州藩や京都の尊攘派との連携を強める可能性がある。徳川斉昭の政治的影響力は、史実とは違った形で終息する。[^u004]

## 一橋慶喜と将軍継承

一橋家は水戸家とは別家であり、水戸藩の処分がそのまま慶喜の失脚を意味するわけではない。しかし父・斉昭の路線と水戸藩の事件が一体として問題視されれば、慶喜を政権中枢に戻すことは非常に難しくなる。幕政改革は家茂を中心に進み、史実で1866年に十五代将軍となった慶喜が将軍候補から外れる可能性さえ生まれた。この事情は[1866年の無血の幕府解体](bloodless-dissolution-1866.md)において、家茂の後継をめぐる朝廷側の判断に影響する。[^u004][^u005][^u015]

## 家茂の「危険な成功体験」

水戸処分の成功は、若い将軍[徳川家茂](../people/tokugawa-iemochi.md)にとって「幕府の命令に従わない勢力は軍事力で整理できる」という危険な成功体験となった。1860年の家茂は数え15歳で、処分自体は老中主導だったが、成長した家茂はこの前例を踏まえて軍制改革に抵抗する藩への強硬策を検討するようになる。ただし水戸処分には「大老襲撃」という正当化があったのに対し、軍制改革への異議はそれ自体が反逆ではない、という決定的な違いがあった。[^u013]

## 皇族領化への道

旧水戸領の処理は、皇族を名目上の領主とする構想と結びつき、最終的には公現法親王を初代とする[那珂川公爵家](../people/nakagawa-ducal-house.md)の創設に至った。幕府が水戸徳川家を追放するために作った枠組みが、幕府失権後には朝廷が直接授けた強固な領主権となる、という皮肉な帰結を生む。[^u007][^u018]

# 史実との比較

* 史実では桜田門外の変で井伊直弼が殺害され、水戸藩は大規模な処分を受けなかった。藩内では鎮派と激派の抗争が続き、1864年に天狗党の挙兵が起きた。[^u005][^u006]
* 慶篤は史実でも安政の大獄で謹慎処分を受けていた。[^u005]
* 幕末には大名の改易・転封は近世初期ほど頻繁ではなく、御三家の処分は相当に強硬な措置である。[^u005]
* 水戸藩の表高は35万石で、常陸国の茨城・那珂・久慈・多賀郡を中心に、行方・新治郡や下野国那須郡に及んでいた。[^u006]

# 却下・修正された案

* **藩主謹慎・家老処罰程度の軽い処分**: 反井伊派政権でも、罰が軽すぎれば幕府の権威が弱まるとして退けられた。[^u005]
* **当初の妥協案（U4）**: 「慶篤に隠居を命じ藩主家を転封、水戸領の大半を幕府直轄領とし、一族に別領を与えて家名存続」とする案は、この処分には藩ぐるみの関与の認定など「さらなる口実」が必要だという留保つきだった。その後、厳罰を前提に転封・蟄居を確定とする方向へ強められた。[^u004][^u005]
* **旧水戸領の直轄・分割案**: 旧水戸領を幕府直轄15万石・譜代への加増配置12万石・既存小藩旗本領の再編8万石に分ける案は、皇族領化の構想に置き換えられた（詳細は[旧水戸領と禁裏御料預地](../regions/former-mito-domain.md)）。[^u006][^u007]

# 未決の論点

* 完全改易か減封転封か、転封先（甲斐国陣屋領8万石は検討案で、採否は明示されていない）、家督を継ぐ「幕府の承認した別の一族」が誰か。[^u006]
* 御三家の家格剥奪の正式な手続き。[^u005]
* 水戸藩士の武力抵抗が実際に起きたか、天狗党類似の蜂起があったか。旧家臣団の具体的な振り分け。[^u005][^u006]
* 処分の決定（1860年）と、転封・領地献上の実施（1861年）の具体的な日程。[^u005][^u007][^u009]
