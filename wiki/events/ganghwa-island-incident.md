# 概要

本世界線でも江華島事件に相当する衝突は起きる。むしろこの世界線では事件が起きる理由が十分に揃っており、起きないとすれば特別な抑制要因が必要なほどであった。[^u041]

1870年代半ば、朝鮮との国交停滞を打開するため、帝国海軍が朝鮮沿岸で軍事的示威を行い、1875年前後に江華島近海で朝鮮側砲台と武力衝突した。翌1876年、軍事的圧力を背景とする日朝条約交渉によって朝鮮は開国した。この「1875年前後の衝突→1876年の開国」が本世界線の基本線である。[^u041]

事件は「1870年代半ばに日本海軍が朝鮮沿岸で軍事的示威を実施し、朝鮮軍と衝突する」という類型のものであり、「1875年9月20日の雲揚号事件」と日時・艦名まで同一とは限らない。[^n1][^u041]

# 背景

## 事件を起こしやすい条件

本世界線の帝国には、史実以上に事件を起こしやすい条件が揃っていた。[^u041]

- 1867年に朝廷政府が成立し、[対馬宗家の外交特権](../diplomacy/tsushima-so-clan.md)を早期に整理している。
- 朝鮮政府が新しい外交文書を受理せず、正式な国交が停滞している（[日朝国書問題](../diplomacy/japan-korea-relations-1870s.md)）。
- 海軍が史実より早く整備され、朝鮮沿岸への示威行動を行う能力がある。
- 毛利・島津・鍋島などの大領主が、[元老院](../institutions/genroin.md)を通じて中央政府の外交政策に圧力をかけられる。
- 統一的な外交・軍事指揮権を持つ中央政府が存在する。

宗家の家役喪失によって交渉停滞の責任を中央政府が直接負うことになり、「外交権を中央へ集中させたのに朝鮮との関係すら正常化できないのか」という批判が軍事的圧力の誘因となった。さらに武家出身の領主たちの[征韓論争](seikanron-debate.md)が、1873年前後に強硬論を高めていた。[^u041][^u042]

## 抑制要因の欠如

事件を回避するには、宗家の従来の外交文書形式を当面維持する、政府が軍事的示威を禁止する、日清間で朝鮮外交の調整に成功する、といった具体的な変更が必要だった。本世界線にはそのような抑制要因が組み込まれていない。[^u041]

また、立憲制度が整っていれば議会が戦争を抑制するとは限らず、元老院の存在は穏健外交を意味しない。大領主は海軍の発展を支え通商拡大にも関心を持っており、交渉停滞が続けば海軍による圧力を支持する勢力が現れる。[^u041]

# 経過

| 時期 | 出来事 |
|---|---|
| 1867〜1869年 | 帝国政府が宗家の朝鮮外交家役を接収。朝鮮が新国書の受理を拒否 |
| 1870〜1873年 | 日朝交渉が停滞。外交的威信と通商利益をめぐる国内議論 |
| 1874年 | 政府が朝鮮への外交圧力を強化。海軍の航路調査・測量活動が拡大 |
| 1875年（前後）[^n1] | 日本艦が江華島近海へ進出。朝鮮側砲台と武力衝突。政府は朝鮮に正式抗議 |
| 1876年 | 軍事的圧力を背景とする日朝条約交渉。朝鮮開国 |

[^n1]: 事件の正確な日時、関与した艦艇と指揮官は未決。1875年より早まる余地もある。
[^u041]

外交権の一元化と帝国海軍の整備が史実より早いため、事件が1875年より早く起きる余地もある。ただし早期の衝突が必ず生じるわけではなく、朝鮮側の政局、日本政府の外交方針、清国の対応にも左右される。[^u041][^u042]

## 「戦争ではなく航路調査」

憲法が正式な宣戦に元老院の同意を要求していても、平時の測量航海や艦隊派遣まで同意を要するとは限らない。政府が「**戦争ではなく航路調査である**」と説明すれば、海軍を派遣すること自体は容易だった。現地で衝突が起きてから議会が報復措置を審議するという順序になる。[^u041]

## 清国の不介入

朝鮮は清国の外交的権威を背景に抵抗したが、1870年代の清朝は朝鮮の内政・外交に原則として不干渉の立場をとっており、即座に軍事介入はしなかった。日本の国軍が史実より強い一方で朝鮮政府がその能力を十分に把握していなかった可能性もあり、こうした非対称が衝突を生んだ。[^u040]

# 事件後の国内政治

事件の経緯が史実に近くても、国内の政治的処理は史実と大きく異なる。帝国政府はすでに元老院（および1870年代に成立する[衆議院](../institutions/house-of-representatives.md)）を持つ立憲国家であり、事件後には次のような立場が現れる。[^u041]

| 政治勢力 | 事件後に取りうる立場 |
|---|---|
| 海軍・対外強硬派 | 朝鮮政府への謝罪・条約締結の要求 |
| 通商重視派 | 開港と通商権確保を優先 |
| 財政重視派 | 長期戦争を避け、限定的な示威にとどめる |
| 立憲主義を重視する勢力 | 艦隊派遣の法的根拠と政府の説明責任を追及 |

これらは別々の政党になるとは限らず、元老院の領主連合や衆議院の勢力が複数の立場を組み合わせる。[^u041]

## 憲法問題

事件の最大の国内的論点は、**江華島事件を口実に、帝国政府が元老院の事前承認なしにどこまで軍事行動を拡大できるのか**という憲法問題である。本世界線の国家は、将軍の独断的な軍権行使を制限したことを成立過程の核心に持つため、この問題は特に重い意味を持つ。派兵と宣戦を別権限とするか、国外派兵にも元老院同意を要するかという論点は、のちの朝鮮危機でも繰り返し問われる（[統帥権](../institutions/supreme-command.md)参照）。[^u037][^u041]

## 国内向けパフォーマンスと条約改正前の焦り

朝鮮に開国を迫る理由には、国内向けパフォーマンスが確実に含まれていた。江華島事件の時点ではまだ欧米との[条約改正](../diplomacy/treaty-revision.md)は実現しておらず、政府には目に見える外交的成果を求める圧力が働いていた。1880年代の条約改正成功による対外的自信は、その後の段階に属する。[^u046]

# 朝鮮開国と日朝条約

1876年、本世界線でも史実の日朝修好条規に相当する条約が軍事的圧力のもとで結ばれ、朝鮮は開国した。史実の同条規は第1款で朝鮮を「自主の国」と規定して清朝の宗主権を否定する意味を持つ一方、日本に有利な不平等条約でもあった。[^u046][^u052]

同様の条項が本世界線でも成立していれば、日本は朝鮮の外交的自立を主張する明文上の根拠を得る。ただし「自主」の意味について日朝清の認識は一致しておらず、日本は近代国際法上の独立と解釈したが、朝鮮と清国は従来の宗属関係と両立する概念として理解する余地を残していた。この曖昧さが、のちの[朝鮮国独立保障（1884年）](../diplomacy/korea-independence-guarantee-1884.md)に至る日本の主張の出発点となる。[^u052][^u055]

欧米に対等な主権を要求しながら朝鮮には軍事的威圧で不平等な条件を求めるという二重基準は、元老院・衆議院で正当化が問われる争点となった。もっとも当時の列強国際秩序ではこうした非対称は珍しくなく、日本の政治家が列強の振る舞いを模倣した面もある。[^u046]

# 史実との比較

- 史実では1875年9月20日、日本の軍艦雲揚号が江華島付近へ進出して朝鮮側砲台から砲撃を受け、報復攻撃で朝鮮側施設を破壊した。日中歴史共同研究の報告書は、交渉が難航した際に日本側外交担当者が測量を名目とする軍艦派遣による威嚇を提案した経緯を説明している。[^u041]
- 史実では事件後に黒田清隆らが派遣され、1876年に日朝修好条規が成立した。[^u041]
- 本世界線では艦名・日時・指揮官は同一とは限らないが、事件類型と1876年開国は共通する。違いは事件後の処理が立憲政治の枠内で行われ、元老院の事前承認をめぐる憲法問題が生じる点である。[^u041]

# 編集注：未決の論点

- 事件の正確な日時、関与した艦艇と指揮官。1875年より早まるか。
- 事件後、政府が元老院の承認なしにどこまで軍事行動を拡大したか。宣戦・派兵の憲法上の区別。
- 1876年の日朝条約の具体的条文（第1款相当の「自主の国」規定を含むか）と、交渉にあたった全権。
