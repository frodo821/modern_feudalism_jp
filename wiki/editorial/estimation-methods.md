# ダイス判定の共通規則

判定は1d100で行い、出目が難易度を上回れば成功、出目が難易度と同値なら失敗とする。出目95以上をクリティカル、5以下をファンブルとして扱う。[^n1] 各記事の表では、クリティカルを「際立って成功」、ファンブルを「大きく失敗」と地の文に近い語で示し、難易度と出目は注記脚注に記す。

# 領主家の経済史と家産

[領主家の経済史と家産（1867〜1937）](../economy/lord-houses-economy.md)の「家産の範囲と経済史の区分」「共通8項目の結果」「純資産の推計」の各節の背後にある手順である。

## 判定の枠組み（領主家の経済史と家産）

### 三つの勘定の区別

領主家の経済を考えるときは、次の三つを別々に扱う。[^p036]

1. 1867年時点の**領国財政**（年貢・専売益など）
2. 近代化の過程で形成された**領主家産**（私有の土地・株式・債券など）
3. 1937年時点の**企業・金融資産からの家産所得**（配当・利子・地代など）

1920年代後半の公私会計分離改革（家門財産と領国財政の分離）の後は、領国政府の税収がそのまま領主家の所得になることはない。そのため、領国のGDPや税収の大きさより、**領主家が自由に投資・融資に回せる資本をどれだけ蓄積したか**が、大領主金融圏の力を決める。1937年について別々に推計すべき指標は、領国GDP、領国政府歳入、領主家純資産、領主家年間所得の四つである。系列企業の総資産や売上高も家産とは区別する。たとえば領主家が株式の50%を持つ企業の総資産を、そのまま領主家の純資産に計上することはできない。[^p036][^p066] 家門会計と領国財政の分離については[家門会計・法定拠出金と公私財政分離](../economy/household-accounts.md)を参照。

### 収入源の変化

| 収入源 | 1867年頃 | 1937年頃 |
|---|---|---|
| 農業 | 年貢・米穀販売 | 私有農地の地代・農業企業収益 |
| 山林 | 木材・林産物 | 林業・製紙企業の収益 |
| 鉱山 | 鉱産物・鉱山経営 | 鉱業・製錬会社の配当 |
| 専売事業 | 特産品の専売益 | 製造・商社事業の収益 |
| 都市不動産 | 地代・町方収入 | 商業地・住宅・工業用地の賃貸 |
| 交通・海運 | 廻船・港湾関連収入 | 鉄道・汽船・倉庫企業の配当 |
| 金融 | 藩札・商人との金融関係 | 銀行・保険・信託・貸付利子 |
| 海外資産 | 限定的 | 海外企業・外債・貿易金融収益 |

[^p036]

石高は初期経済力の参考にとどまる。100万石の領主でも巨額の借財があれば新規投資に回せる資金は限られる。初期条件として、表高・実高、幕末の累積債務、専売益、鉱山・森林、港湾・大都市、既存の工業技術、商人との信用関係、旧家臣団の規模、北海道開拓の機会が考慮された。なお、全国レベルの判定ではすでに幕末債務の整理と家臣団の俸禄整理がともに失敗しているため、すべての大領主が明治初期から潤沢な投資資金を持っていたとはしない。[^p036]

### 共通8項目と固有項目

主要家の判定は、すでに全国レベルで決まっている経済成長や重工業化を再判定するものではない。その成果がどの家に帰属するかを決めるための判定である。共通8項目と基準難易度は次のとおりで、難易度は各家の初期条件に応じて修正された。[^p036][^p037]

| 共通項目 | 基準難易度 |
|---|---:|
| ① 幕末の累積債務を1870年代までに整理する | 45 |
| ② 既存の商業・専売事業を近代企業へ転換する | 30 |
| ③ 1889年までに有力な近代工業資本を形成する | 40 |
| ④ 独自の銀行・金融機関を発展させる | 35 |
| ⑤ 北海道開拓から大きな経済的利益を得る | 45 |
| ⑥ 第一次世界大戦の経済成長を長期資産形成につなげる | 25 |
| ⑦ 海外投資・国際金融への進出に成功する | 45 |
| ⑧ 1927年以降の金融危機で大規模な資産毀損を回避する | 50 |

このほか家ごとに、地域産業の資本化、地域の中小領主を包含する金融圏の形成、他の大領主からの独立または連合といった固有項目が4〜9項目加えられた。[^n1][^p037][^p053]

### 判定の範囲

1937年の領主は249家である。個別に経済史をたどるのは主要25家で、残りは区分ごとにまとめて扱う。[^n2][^p057][^p058][^p064][^p066]

| 区分 | 家数 | 判定方式 |
|---|---:|---|
| A 主要領主家 | 25 | 12〜17項目の個別判定 |
| B 中堅領主 | 20 | 5項目を地域別（7地域）に集団判定 |
| 北海道新興領主 | 5 | 7項目の集団判定 |
| C その他の領主 | 199 | 10項目の全国一括判定 |

主要25家は、徳川宗家・前田・島津・毛利・伊達・細川・黒田・鍋島・尾張徳川・紀伊徳川・那珂川の11家、浅野・岡山池田・鳥取池田・藤堂・福井松平・井伊・佐竹・南部・山内の9家、蜂須賀・松江松平・庄内酒井・津軽・対馬宗の5家からなる。[^n3][^p047][^p057][^p066]

### 家産の計上ルール

| 項目 | 扱い |
|---|---|
| 私有農地・山林 | 計上する |
| 保有企業株式 | 持分価値を計上する |
| 系列企業の総資産 | 全額は計上しない |
| 銀行の預金・貸出総額 | 全額は計上しない |
| 領国政府の公有財産 | 計上しない |
| 領国政府の税収 | 家産所得に計上しない |
| 保有外国資産 | 計上する |
| 領主家自身の債務 | 控除する |
| 諸侯共済会・信託の受託財産 | 実質的な所有家に帰属させる |

[^p066]

このため、全国の粗鋼の約2割を生産する南部系製鉄企業集団や、全国規模の預金銀行を持つ蜂須賀家でも、家門純資産は企業規模よりずっと小さい。[^p055][^p059][^p066]

## 純資産の推計手順

### 資本蓄積モデル

#### 計算式

主要25家の純資産は、次の資本蓄積モデルで算出される。[^n5][^p069]

> W = k × B × G × T × (1 − L) × R

| 記号 | 意味 | 対象期間 |
|---|---|---|
| B | 1867年の相対的な初期家産指数（初期家産規模・幕末債務） | 1867年 |
| G | 1913年までの実質資産成長倍率（財政再建・商業近代化・初期工業化・銀行・固有産業・北海道開拓） | 1867〜1913年 |
| T | 戦時・戦後の成長倍率（戦時資産形成・海外投資） | 1914〜1926年 |
| L | 金融危機による最大の実質純資産毀損率（既設定の範囲の中間値） | 1927〜1932年 |
| R | 危機後から1937年までの回復倍率 | 1933〜1937年 |
| k | 合計を453.6億円に合わせる調整係数 | ― |

石高は初期経済力の参考指標にとどめ、領国の土地や租税徴収権は私有家産に換算しない。企業の総資産も家産にはしない。[^p069]

井伊家には商業網形成と戦時資産形成のクリティカル、津軽家には北海道開拓のクリティカルを反映させた。松江松平家は戦時資産形成がファンブルだったため、1914〜26年の倍率が1未満（0.75）になっている。初期指数・成長倍率・所得率は仮定値であり、小数点以下の精度は設定の確実性を意味しない。[^p069]

### 金融危機前の順位の逆算

上記のパラメータから主要25家以外の家についても1927年時点の純資産を逆算すると、順位はおおむね徳川宗家・前田・井伊・伊達・島津・那珂川・黒田・細川・紀伊徳川・鍋島の順となる。これは記事執筆時にパラメータ表から逆算した参考値で、島津23.24億円・黒田19.6億円は危機前には上位10家に入っていた。

### 資産区分への配分

主要25家の家産を8区分に分けるにあたり、各家の所得構成比を資産区分ごとの基準所得率で割り戻し、純資産総額に合わせて配分した（A = W × (s/r) ÷ Σ(s/r)。sは所得構成比、rは基準所得率）。たとえば電力株と農地では、同じ所得を生むのに必要な資産額が違うため、所得構成比と資産構成比は異なる。[^p070]

# 1937年の就業者数の推計

[1937年の就業構造と社会（労働・教育・住宅・人口）](../economy/labor-society-1937.md)の「就業者数の水準」節の背後にある推計の経緯である。

## 就業者数の修正経緯

就業者数の推計は、就業率46.0%を仮定した3,590万人から出発し、産業ごとの物的検証によって順次減った。[^n6][^e085][^e094]

| 段階 | 就業者 | 内容 |
|---|---:|---|
| 当初（E85） | 3,590万人 | 人口×就業率46%。第一次22%・第二次36%・第三次42% |
| 製造業の検証後（E88） | ― | 製造業978→812万人（−166万人） |
| 商業の検証後（E92） | 3,294万人 | 未配分296万人（失業者ではない） |
| 金融の検証後（E93） | 3,226万人 | 金融・保険・不動産144→76万人 |
| 非政府部門の検証後（E94） | 3,134万人 | 建設215→185万、民間サービス359→310万 |
| 政府部門の検証後（E95） | 3,157万人 | 政府233万人。労働力人口3,496万との差339万（失業率9.7%）は高すぎる |
| 社会構造の変化の反映後（E96） | **3,220万人** | 労働力人口3,300万人、失業率2.4% |

（出典：[^e085][^e088][^e092][^e093][^e094][^e095][^e096]）

当初の3,590万人との差は失業者ではなく、就学の長期化、児童・高齢者労働の減少、家庭内の無償労働、農村の兼業、労働時間の変化などによる。[^e094]

失業率2.4%は労働力人口と雇用推計の差から得た値で、景気について独立した判定を行ったものではない。[^e096] 社会構造の8項目の判定（会話ログ2 E96）を反映する前の政府部門の検証後（E95）の3,157万人から、反映後の3,220万人への雇用の追加は63万人である。[^e095][^e096]
