# 概要

**全国標準化政策**は、1870年代前半から[元老院](/institutions/genroin.md)が主導して進めた、度量衡・貨幣・交通・通信・商法などの全国統一政策である。ユーザーは、標準化の圧力は高く、標準化が弱いと領国間の通商が難しくなる、また欧米を視察すれば標準化は確実に元老院で議論になる、と確定させている。[^u044]

この政策の核心は、「**領主間の競争が激しいからこそ、全国標準化への圧力も強くなる**」という逆説にある。[^u044] 大領主たちは自領の行政・司法・治安の権限は譲りたくないが、自領で作った商品を全国へ売るためには通貨・交通・度量衡・商法の統一を望む。その結果、領主の政治的自治を強く保障したまま、経済制度だけは急速に統一される。標語として「**経営主体は分散していても、制度と規格は全国共通**」と表される。[^u044]

元老院は「領主権を守る機関」であると同時に、「**領主権を維持したまま全国市場を統一する機関**」となった。領主制は近代化の障害になるどころか、領主たち自身が近代化と標準化を進める主体になった。[^u044]

# 背景

## 寄親圏の分裂リスク

大領主を中心とする[寄親圏](/concepts/yorioya-yoriko.md)ごとに貨幣・鉄道規格・商取引の制度が分かれれば、全国の経済発展の妨げになる。そのため中央政府には、鉄道規格・通貨・度量衡・郵便・電信・商法を全国で統一する強い理由があった。これらは領主権を廃止しなくても実現できる改革である。[^u028] 近代化を速める三条件の一つは、「中央政府が市場や技術の全国的な統一を進め、領主間の競争を国内の分断に変えないこと」とされる。[^u028]

## 欧米視察とドイツ関税同盟

1871〜1873年の[岩倉使節団](/events/iwakura-mission.md)が欧州を訪れたのは、ドイツ帝国が成立した直後だった。ドイツでは政治的統一に先立つ1834年に関税同盟が発足し、領邦間の貿易障壁の撤廃と通貨制度の調整を経て1871年の統一に至っていた。「領主家を存続させながら、全国共通の経済制度を作る方法」を探していた領主議員と視察官にとって、ドイツは格好の研究対象になった。[^u044]

アメリカからは、合衆国憲法第1条第8節の州際通商規制・貨幣鋳造・度量衡・郵便の連邦権限が参照された。これは帝国通商条項という憲法改正構想につながった。[^u045] 詳細は[アメリカ連邦制の受容と領主権の再定義](/institutions/federalism-reception.md)を参照。

# 政策の内容

## 1870年代前半の優先政策

| 政策 | 領主たちが賛成する理由 |
|---|---|
| 度量衡の統一 | 領国間の売買や工業製品の規格を共通にできる |
| 貨幣・銀行制度の統一 | 両替費用を減らし、投資と金融取引を容易にする |
| 領国間の関所・通行税の廃止 | 流通の障害を取り除き、広域市場を作れる |
| 鉄道の軌間・接続規格の統一 | 異なる領主の鉄道を相互に直通させられる |
| 郵便・電信制度の統一 | 全国の通信網をつなげられる |
| 商事法・契約法の統一 | 領主の境界を越える取引の法的な不確実性を減らせる |
| 特許・工業規格の整備 | 技術開発の成果を全国市場で使える |

[^u044]

## 経営の分散と規格の統一

必ずしも中央政府がすべての事業を直接経営する必要はない。鉄道は領主家や民間企業が建設してもよいが、軌間・信号・運行規則・線路の接続は帝国の共通基準に従う。銀行も民間や領主系の銀行を認めたまま、貨幣制度と決済規則を統一する。[^u044]

## 制定の手続

1873年頃、元老院に「**度量衡・工業規格調査委員会**」が置かれる（検討案）。中央官僚だけでなく、各領主の工業担当官や商工業者も参加する。委員会が統一規格案を作り、元老院がそれを「例」として制定し、具体的な技術規則は「式」で定める。これは[詔・勅・例・式の法体系](/institutions/legal-system.md)とも整合する。[^u044] 史実の岩倉使節団は成果を『理事功程』などの各省報告書や『米欧回覧実記』にまとめた。本世界線では、視察の成果が元老院の立法活動に直接つながる。[^u044]

視察成果の扱いには費用負担の原則がある。国庫補助を受けた視察の成果は、元老院や中央官庁へ報告し、一定の範囲で公開する。国庫補助を受けた成果を特定の家が独占するのを防ぐためである（検討案）。[^u043]

# 政治力学

## 規格競争

標準化は単なる協調政策ではない。たとえば前田家の経済圏が鉄道や製糸の規格を整えれば、周辺の中小領主も前田家の施設や鉄道網を使うために同じ規格を採る動機を持つ。しかし島津家や毛利家の経済圏が別の規格を採っていれば全国取引の障害になるので、大領主同士が元老院で協議して共通規格を定める理由が生まれる。早く規格を採った領主は、自分の企業や鉄道を全国市場で有利な位置に置ける。こうして標準化は、「**自家の規格を帝国標準として採用させる競争**」となり、大領主が中小領主（寄子）を取り込む手段にもなった。[^u044]

## 司法権との切り分け

領主たちは貨幣や鉄道の標準化には賛成しても、裁判権を中央へ渡したいとは限らない。そこで「**商事法は全国共通、裁判所は領主ごと**」という妥協がとられた。[^u044]

* 契約・手形・会社制度は帝国の例で統一する。
* その法律を適用する第一審の裁判所は各領主が運営する。
* 領主間の商事紛争は帝国裁判所へ上訴できる。

ただし領主ごとに裁判の質が違えば、商人は帝国裁判所による統一的な解釈を強く求める。経済の標準化は、長い目で見れば司法制度の統一まで促す可能性がある。[^u044] 税制や裁判制度の違いが投資や取引の障害になるため、商業分野では中央司法の権限が次第に広がる。[^u045]

## 条約改正への寄与

全国共通の商事法と、外国人にも適用される帝国共通法の整備は、領事裁判権を撤廃する前提にもなった。欧米が求めたのは、外国人がどの法律・手続で裁かれるかを予測できることだった。[^u046] 詳細は[不平等条約改正](/diplomacy/treaty-revision.md)を参照。

# 帰結

## 近代化の循環

1. **大領主間の産業競争**: 鉄道・工業・金融・教育への投資。
2. **領国を越える商取引の拡大**: 輸送・契約・決済の共通化が必要になる。
3. **元老院による全国標準化**: 例・式による共通制度の制定。
4. **全国市場の統合**: 取引費用が下がり、投資機会が広がる。
5. 競争と投資がさらに加速する。

[^u044]

ただし、規格を統一する政治的合意ができても、鉄道建設や工場設備への投資には資本と技術者が必要である。制度の統一だけで物理的な近代化が自動的に進むわけではない。[^u044]

## 日清戦争の軍事力の根拠

1870年代に鉄道・通信・金融・工業規格が全国で統一され、1880年代に国内産業が育っていれば、日清戦争では帝国軍の輸送・兵器調達・軍需物資の供給が全国市場によって支えられる。帝国軍が史実以上の力を発揮できるとすれば、その根拠は独自軍を持つ大領主の存在ではなく、「**大領主たちが競争しながら作り上げた統一的な国内経済圏**」にある。[^u044] 1887年の日清戦争での日本側の強みとしても、全国で標準化された鉄道・通信・金融制度が挙げられる。[^u070] 詳細は[日清戦争（1887〜1889）](/events/sino-japanese-war.md)を参照。

## 重工業化への寄与

本世界線の日本の成長要因の第一は、「1860年代からの近代法制と統一市場（商法・通貨・金融・輸送規格の統一）」とされる。[^u080] 日清戦争後の重工業化でも、各領主が小規模な製鉄所を乱立させれば遊休化するおそれがあった。それを防いで全国的な需要を作るうえで、元老院が早くから鉄道規格と全国市場の統一を実現していたことが効いた。[^u082] 詳細は[重工業化と国力の推移（1870〜1930）](/economy/heavy-industrialization.md)を参照。

## 帝国交通例への発展

1889年の講和後には、賠償金の半額を基金として国道・高速国道・鉄道・港湾を整える15年計画が始まった。その根拠法「帝国交通例」は、元老院が制定した全国共通法として、国道・幹線鉄道を帝国の公共事業と定め、適正補償による用地取得と、領主による恣意的な通行税の禁止を規定した。領主の地方交通網は領主の管理権を残しつつ幹線とつなぐ。1870年代の「規格の統一」は、ここで「網の統一」へ発展した。[^u083] 詳細は[帝国交通整備計画](/economy/transport-plan.md)を参照。

# 史実との比較

* 史実の明治政府は、廃藩置県（1871年）で各藩の政治的独立を消したうえで、中央政府が度量衡・貨幣・郵便・鉄道などを上から統一した。
* 本世界線では藩が領主領として残るため、統一は中央の押し付けではなく、元老院における**領主たち自身の合意**として進む。[^u044]
* ドイツ関税同盟（1834年発足）は、領邦が存続したまま市場を統合した先例として直接参照された。[^u044]

# 未決の論点

* 個々の規格（鉄道の軌間、度量衡の単位系など）の具体的な内容と、どの領主圏の規格が採用されたか。
* 度量衡・工業規格調査委員会の正式な名称と設置年（1873年頃は検討案）。[^u044]
* 商事法の統一と領主の司法権の関係、帝国裁判所の上訴管轄の詳細。[^u044]
* 貨幣の統一の時期と、領主の独自通貨発行を制限する方式。[^u045]
