# 概要

**領主権奉還**とは、領主が自分の[領主権](lordship-rights.md)を自発的に朝廷へ返上し、政府がその見返りに補償を与える制度である。財政難に陥った小藩主の中から、領主権を返上する者が現れた。[^u027]

本世界線では、1866年の所領安堵の約束によって新政府が成立したため、史実の版籍奉還や廃藩置県のような全国一律の措置はとれない。[^u017] 一方で、領主権そのものに財産的な価値があるため、返上・譲渡・補償を制度にすることができた。こうして、廃藩置県を断行しなくても領主制度が少しずつ縮小していく道が開かれた。[^u027]

この制度は、明治政府が領主を敵に回さずに直轄地を広げる手段となった。領主制は「財政健全化のために奉還する小領主」と「領主権を保って元老院で影響力を行使する大領主」の二つに分かれていった。[^u027]

1867年の初叙爵時の領主華族276家のうち、1937年までに**累計60家**が奉還した。[^n1] 奉還の大半は3万石未満の小領主で、30万石以上の大領主と特例公爵領主（徳川宗家・那珂川家）からは1家も出ていない。大領主による金融支援がきわめて効果的に機能したため、奉還は少数にとどまり、むしろ領主間の経済的従属関係が深まった。奉還は1867〜76年の第一の波（20家）と、金融危機後の1927〜37年の第二の波（20家）に集中する。[^p022][^p023]

# 背景

小領主が奉還を選ぶ理由は、次のような判断にある。[^u027]

> 領主権は名誉だが、軍役負担、家臣への俸禄、領内の行政費用を考えると、これ以上維持できない。

本世界線では全国の常備軍がすでに編成されており、旧藩主が独自の軍備を持つ意味は次第に薄れていく。家臣団の俸禄と領内行政の費用が、小領主の財政を特に圧迫した。[^u027]

幕末の段階から、諸侯が困窮したときに中央が行政権を買い取る、権限の移管と引き換えに年金を払う、といった段階的な改革の可能性が想定されていた。[^u017]

## 財政難の小領主の三つの道

財政難に陥った小領主にとって、奉還は唯一の選択肢ではない。[^p021]

1. **国司への行政委託**: 領主権を保ったまま行政実務の一部を国司に委ね、行政費を削る（[廃藩置国と国郡制](kokugun-system.md)）。
2. **寄親への接近**: 大領主の資金・技術・人材の支援を受ける（[寄親・寄子制と大領主間の近代化競争](../concepts/yorioya-yoriko.md)）。
3. **領主権奉還**: 補償を受けて無領華族となる。

| 奉還を促進する要因 | 奉還を抑制する要因 |
|---|---|
| 幕末以来の累積債務 | 大領主による金融支援 |
| 家臣団への俸禄負担 | 家臣の官吏・企業への転職 |
| 近代的行政制度の整備費用 | 国司への行政委託 |
| 帝国政府への法定拠出 | 領国間の共同事業 |
| 農業収入への過度な依存 | 商工業・鉱業による収入 |
| 奉還に伴う年金・公債補償 | 元老院の領主互選への参加資格 |
| 家産を維持したまま奉還できる | 世襲統治権に対する執着 |

[^p021]

小領主自身の領国に経済的価値が乏しくても、元老院の領主互選における一票には政治的価値がある。そのため大領主には、寄子の領主権を維持させる経済的な動機が生まれた。[^p021]

# 制度の内容

## 領主権奉還令

領主が自主的に領主権を返上する場合、政府は領主権奉還令に基づいて次の補償を与える。[^n2][^u027]

| 領主が手放すもの | 政府が保障するもの |
|---|---|
| 世襲的な地方統治権 | 華族の爵位・家格 |
| 領内の徴税権 | 財政状況に応じた年金・公債 |
| 領内官吏の任命権 | 本人や家族が官職に就く資格 |
| 領地の政治的管轄権 | 私有財産と家産の保護 |
| 家臣団を統率する義務 | 家臣の官吏登用や再就職の支援 |

最も重要なのは、**領主権を奉還しても華族の身分を失わない**ことである。奉還を家の没落と結びつけなければ、小領主にも改革を選ぶ余地が生まれる。[^u027]

## 補償の財源と限界

補償に現金だけでなく公債を使えば、政府は一度に巨額の資金を払わずに済む。ただし公債の利払いは将来の国家財政の負担になる。[^u027]

旧領主の債務や家臣団への支払いをどこまで引き受けるかは慎重に決める必要がある。すべての負債を無条件に引き受ければ、財政難の領主ほど奉還した方が得になり、政府財政が圧迫される。[^u027] 実際には補償制度は小領主にとって魅力的なものとなり、帝国政府も奉還領の債務・行政の引継ぎを処理する財政能力を確保した（後述の構造要因を参照）。そのため財政が破綻する前に、自発的に奉還して年金・公債・私有財産の収入で暮らす無領華族の道を選ぶ家も出た。[^p022]

## 法的な位置づけ

[法体系](legal-system.md)の整理の中で、奉還は世襲領主権・相続・領地交換・財政負担とともに封土例（当初案では封土令）で規定される。具体的な手続は封土式などの「式」で定める。[^n3][^u031][^u032]

* 奉還を申し出る際の書式
* 債務と家臣の俸禄の精算
* 地方官への事務の引継ぎ
* 所領内の訴訟・契約の継続
* 領地の収入と中央の税収の清算

[^u031]

## 奉還地の処理

奉還された旧領は、既存領主に再配分されることも、新たな領主家に授封されることもなく、帝国直轄地として存続する。[^p034]

| 判定項目 | 結果 | 帰結 |
|---|---|---|
| 領主権奉還地の既存領主への再配分が行われる | 失敗 | 再配分なし |
| 領主権奉還地に新たな領主家を授封する事例が発生する | 失敗 | 本土での新領主家創設は原則なし |

[^n4][^p034]

これに対し、家門が断絶した領主家の旧領は、他の華族への再授封や既存領主への加増が認められ、断絶領の帝国直轄化は採られなかった。[^n5]奉還は領国統治の維持が困難になったときに行われるが、断絶は領国の財政・行政能力とは関係がないため、両者は区別される（[華族家数の推移と相続・断絶](kazoku-demography.md)）。[^p035]

この結果、本州・四国・九州では奉還地の分だけ帝国直轄地が着実に増え、北海道では新規授封で領主領が広がるという地域的な非対称が生まれた（[新規授封と加増](new-enfeoffment.md)）。[^p034]

# 奉還の推移（1867〜1937年）

## 奉還を左右した構造要因

奉還の多寡を左右した構造要因と、その成否は次のとおりである。

| 要因 | 結果 | 奉還への影響 |
|---|---|---|
| 1867〜1876年に旧家臣団の俸禄負担を円滑に整理する | 失敗 | 増加 |
| 小領主による国司への行政委託制度が広く普及する | 成功 | 大幅に減少 |
| 大領主による中小領主への金融支援が効果的に機能する | 際立った成功 | 極めて大幅に減少 |
| 幕末以来の領主家債務の整理・借換が円滑に進む | 失敗 | 増加 |
| 領主権奉還に対する補償制度が小領主にとって魅力的なものとなる | 成功 | 増加 |
| 帝国政府が奉還領の債務・行政引継ぎを処理する十分な財政能力を確保する | 成功 | 奉還を容易にする |
| 1890年代までに中小領主が共同産業投資から安定した収益を得る | 失敗 | 増加 |
| 農業中心の小領国が近代的な税収基盤を確立する | 成功 | 減少 |
| 第一次世界大戦の経済成長が中小領主にも広く波及する | 成功 | 減少 |
| 1927年以降の金融危機によって中小領主家の財政難が広範に発生する | 成功 | 増加 |

[^n6][^p022]

財政難は広く発生したが、必ずしも奉還にはつながらなかった。金融支援の際立った成功は、全国的な債務整理制度の成功ではなく、**大領主の信用圏に入った家が個別に救済される**形をとった。支援は長期低利融資（家臣団整理・債務返済）、信用保証、財政・会計・産業経営の顧問派遣、旧家臣の受入れ（大領国の行政機関・領主系企業）、共同資産運用、凶作・災害・金融危機時の緊急支援に及んだ。大領主にとって金融支援は、元老院互選での政治的協力をつなぎとめる意味も持った。[^n7][^p022]

| 領主の類型 | 奉還の可能性 |
|---|---|
| 大領主の信用圏に入った小領主 | 低い |
| 行政委託で経費を削減した小領主 | 低い |
| 農業税収が安定した小領国 | 比較的低い |
| 多額の旧債務を抱える独立系小領主 | 高い |
| 産業投資に失敗した中小領主 | 比較的高い |
| 統治より資産運用を重視する領主 | 高い |
| 金融危機で家産が毀損した領主 | 状況次第 |

[^p022]

その後、大領主を中心とする恒常的な金融圏が成立し、中小領主による独立した共同金融組織である諸侯共済会[^n8]も際立って順調に成立した。しかし1927年以降の金融危機では、領主間の相互支援体制は維持されなかった。[^n9]このため1927年以降に第二の奉還の波が生じた（[領主金融圏と諸侯共済会](../economy/lord-financial-spheres.md)）。[^p023]

## 1927〜1937年の第二の波

1927年以降の金融危機では、大領主系の金融機関や家産企業の資産が毀損し、中小領主への融資・保証が縮小した。財政難の領主は奉還・諸侯共済会での共同金融・公私分離による領国財政の保護という三つの方向に分かれた。[^p023]

1927年から1937年にかけて、領主の金融圏所属は269家から249家へ20家減った。とくに黒田系（17→6家）と島津系（15→7家）が大きく弱まり、離れた領主の一部は諸侯共済会系（40→49家）に移った。[^n10] 1936年の元老院選挙の後、1937年までにさらに2家が奉還した。[^n11][^p077][^p078]

1927年以降、領国政府への負担の移管と、法定拠出金の猶予・減額・免除の制度が整えられた（[家門会計・法定拠出金と公私財政分離](../economy/household-accounts.md)）。減免制度は財政難の領国が直ちに奉還に追い込まれることを防いだが、奉還60家という結果は変わらない。むしろ減免を受けても再建できなかった家が奉還に至った、と位置づけられる。[^p075]

奉還せずに存続した中小領主の多くも、家産所得だけでは家門を維持できず、構成員の就業や金融支援に頼っている（[中堅・中小領主と北海道新興領主](../economy/minor-lords.md)）。[^p066]

# 帰結

## 領主制の二極化

| 類型 | 行動 | 例 |
|---|---|---|
| 小領主・財政難の領主 | 領主権を奉還し、華族として年金・公債収入で暮らす。中央の官職・政治・実業へ進む | 一万石級の小藩主 |
| 大領主 | 領主権を保ち、地方行政と税収を管理し続け、元老院の領主互選で国政に関わる | 島津・毛利・徳川・那珂川 |

[^u027]

ただし、大領主だから財政的に安泰とは限らない。家臣団や施設が大きいほど支出も増える。逆に、商業収入や鉱山収入に恵まれた小領主が存続することもある。[^u027]

さらに、[寄親・寄子](../concepts/yorioya-yoriko.md)関係があれば、中小領主は奉還しなくても大領主の経済圏に参加することで存続できる。近代化に成功した領主ほど奉還する理由は薄れる。[^u028] 1937年でも276家中216家が当初からの領主権を保っており、奉還によって領主領が少数の大領域に集約されたわけではない。法的には諸侯は平等だが、経済的には大領主を中心とする階層構造が再形成され、親藩・譜代・外様の解体の後に新しい資本主義的な領主連合が生まれた。[^p022][^p023]

## 元老院への影響

[元老院](genroin.md)の互選定数は有権者数に連動しない固定定数である。奉還した家は領主互選の選挙資格を失い、無領華族互選の選挙人・被選挙人となるが、両互選の定数は変わらない。[^p012][^p021] 奉還が進むと領主互選の議席／有権者比は上がり、無領華族互選は競争が激しくなる。この格差は、功績叙爵による無領華族の急増と重なって元老院の定数改革の一因となった（[元老院の構成と互選制度](genroin-composition.md)）。[^p012][^p021]

奉還家が加わったことで、本来「朝廷側の抵抗権」として設計された無領華族互選は、旧領主層の政治参加の場という性格も帯びた。しかし奉還家が無領華族互選で独自の会派を形成する試みは完全に失敗し[^n12]、旧領主としての結束は崩れて、旧公家系・実業家系・旧寄親系などの会派に分散した。領主時代から寄親と債務関係にあった家は、奉還後も旧寄親の影響下に残りうる。[^p018][^p026]

1920年代に家門構成員に対する家法制定権・家門司法権が全華族の特権となったため、奉還家は奉還で失った家門の司法権を回復できた。このことも奉還家が独自会派を作る動機を弱めた（[家門自治権と家門司法権](family-autonomy.md)）。[^p027]

## 衆議院と直轄地

[衆議院](house-of-representatives.md)では、直轄地域の住民が領主を介さずに中央政府へ政治的要求を出すようになる。奉還地は帝国直轄地として残るため、本土の直轄地は1937年まで着実に広がった。[^u027][^p034]

## 奉還後の旧領主家

奉還した旧領主家は、残された家産で経済的に再起することにはおおむね失敗した。[^n13]領国行政の負担はなくなるが、家門そのものは存続するので、使用人・邸宅・構成員への給付の負担は残る。とくに1927年以降に奉還した家は、1937年になっても債務整理や生活規模の縮小を続けている。1937年の旧領主系無領華族60家の純資産は合計4.80億円（1家平均800万円）にとどまる。[^p083][^p096]

## 近代化の財源

奉還によって中央政府の税収基盤が広がることは、本世界線の近代化を加速する重要な条件とされる。史実より約20年早い近代化が実現できるかは、政治制度以上に、中央政府が安定した財源を確保し、教育・交通・工業へ投資し続けられるかにかかっている。[^u027]

# 史実との比較

* 史実では1869年12月に吉井藩・狭山藩が自発的な廃藩を願い出たのを皮切りに、1871年6月までに14藩が廃藩を申し出た。藩財政の悪化と武士への俸禄の支払いが大きな負担になっていた。本世界線の奉還制度は、この史実の動きを全国的な制度にしたものといえる。[^u027]
* 史実の家禄処分でも、現金と公債による補償が使われた。[^u027]
* 史実の版籍奉還（1869年）は全国一律に藩主の世襲的領主権を否定した。本世界線の奉還は個々の領主の自発的な選択であり、奉還後も華族身分と家格が保たれる点が根本的に違う。[^u017][^u027]
* 史実の旧藩主285家がすべて統治権を失ったのに対し、本世界線では70年間で奉還したのは276家中60家（21.7%）にとどまる。[^p023]

# 編集注：却下・修正された案

* **奉還と同時に元老院の領主議席が消滅する案**: 旧案では奉還で領主議席が消え、華族互選・勅選議員の比重が高まるとされていた。会話ログ3で元老院の互選定数を固定とすることになり、奉還家は領主互選資格を失って無領華族互選の選挙人となるが、定数は変わらない方式に置き換えられた。[^u027][^p012][^p021]
* **奉還は1870〜1890年代に主に進み、残る領主領が少数の大きな領域に集中するという見通し**: 奉還は1867〜76年と1927〜37年の二つの波に分かれ、1937年でも216家が当初からの領主権を保つ形に修正された。[^u027][^p023]
* **中核モデル「101家奉還・残存175家」**: 判定前の比較用モデル（時期別 1867〜89年56・1890〜1913年28・1914〜26年6・1927〜37年11）。金融支援のクリティカルなどを反映して60家に下方修正された。このモデルでは1937年の領主互選の議席／有権者比が80.0%に達するとされていた。[^p021][^p022]
* **60家の時期配分（P22版）**: 1867〜76年20・1877〜89年12・1890〜1913年16・1914〜26年3・1927〜37年9。領主金融圏の判定（危機時の相互支援の失敗）を受けて、1927〜37年を20家とする配分に修正された。[^p022][^p023]
* **近代化の開始は20年早まらないという留保**: 奉還を提起したやりとりで、立憲・地方制度は10〜20年先行しうるが、鉄道・工業化の開始そのものは必ずしも早まらない、という留保が付けられた。[^u027] しかし直後に作者が大領主間の主導権争いを指摘し、近代化全体が史実より速いペースで進む方向に修正された。[^u028]
