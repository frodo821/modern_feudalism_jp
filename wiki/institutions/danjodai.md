# 概要

**弾正台**は、[領主権](lordship-rights.md)を保障された諸侯が存続する明治国家において、中央官僚・国司・領主家の官吏、さらに世襲領主本人の不正や職権濫用を監察し、弾劾する機関である。史実では短命に終わった官庁だが、本世界線では世襲領主が残るため、中央政府が全国に法令を実施させるには領主や国司の行動を監察する仕組みが欠かせず、史実以上に重要な官庁となった。[^u023]

弾正台は**監察・弾劾に特化**し、裁判も処罰も行わない。不正を認定すれば刑部省または[領主権裁定院](lordship-tribunal.md)へ送致し、領主権を直接取り消すこともできない。監察・訴追と裁定・処罰を分けることで、所領安堵の約束と矛盾せずに統治者全員へ共通の法を及ぼす仕組みとなっている。[^u023]

1920年代に華族家門の家門司法権が確立し、帝国・領国・家門の[三元的司法制度](tripartite-judiciary.md)が成立すると、弾正台は司法判断そのものを監督する役割も担うようになった。領国司法・家門司法による決定に不服を唱えて帝国裁判所に提訴し、領国法や華族家法の憲法違反を訴追できる。ただし弾正台自身が判決を取り消したり法規を無効にしたりすることはなく、判断はあくまで帝国裁判所が下す。[^p030][^p031]

長官である**弾正尹**には、親王を臣籍降下させて公爵とした人物が任じられる。弾正尹の家は領地を持たない公爵家とされ、国家財政から俸給を受ける。公爵位は世襲だが、弾正尹の官職は世襲しない。[^u024]

# 設置

弾正台は明治元年（1867年）の夏、太政官官制改革とあわせて設置され、同年9月、第一回帝国議会に先立って初代弾正尹が任命された。[^n1][^u023][^u024]

1867年の官制令は、太政官・弾正台・刑部省・領主権裁定院の権限を定めた。[^n2] 明治改元と同時に太政官の再編が始まり、1867〜1868年に裁定院・弾正台・刑部省の三機関が設けられたことで、領主権を存続させたままでも朝廷政府が全国的な法秩序を形成できるようになった。[^u023][^u024]

# 権限

## 他機関との役割分担

| 官庁 | 職務 |
|---|---|
| 領主権裁定院 | 領地境界、相続、領主権の範囲、領地交換などの紛争を裁定 |
| 弾正台 | 国司・領主・中央官僚の不正や職権濫用を調査・弾劾 |
| 刑部省 | 刑事事件の審理・刑罰の執行 |
| 太政官 | 行政の統括、官吏任免、裁定の執行 |

[^u023]

史実では弾正台と刑部省の権限が重複して対立が生じた。本世界線では最初から弾正台を監察・弾劾に特化させ、捜査や司法の通常業務は刑部省へ分離する。弾正台は独自に調査を行い、不正を認定した場合には刑部省または領主権裁定院へ案件を送る。「**弾正台自身は裁判官にも処刑人にもならない**」。これにより、弾正台が政治的な敵対者を自由に処罰する機関へ変質する危険を抑える。[^u023]

## 監察対象の三段階[^n2]

弾正台が中央官僚しか監察できなければ地方領主の不正は放置され、全国の領主を無制限に監察できれば諸侯が反発する。そこで監察対象は三段階に分けられる。[^u023]

| 対象 | 権限 |
|---|---|
| 中央官僚・国司 | 直接監察。必要に応じて訴追・罷免を請求 |
| 領主家の家臣・領内官吏 | 中央法令違反や重大不正について調査可能。通常の処分は領主に要求 |
| 華族領主本人 | 調査・弾劾は可能。領主権の停止・剥奪には特別な審理と勅裁が必要 |

例として、ある伯爵家が領民に違法な課税をしていた場合、弾正台は調査できるが、伯爵家の領主権そのものを剥奪するには裁定機関による審理と、必要に応じた勅裁を要する。[^u023]

## 領内立入権

領主が調査を拒んだ場合に備え、**弾正台の監察官が領内に入る権利を全国法令として保障する**。これを認めさせられれば、領主が行政権を保有していても、朝廷の監察権は全国に及ぶ。[^u023]

## 直接奏聞権

律令制の弾正台には、一定の場合に太政官を経ずに直接奏聞することが認められていた。本世界線でも、弾正台に太政官の不正を直接天皇へ奏上する権限を与えることが構想された。[^n3] 一方で、弾正尹が皇族出身だからといって常に公正に行動するとは限らないため、訴追対象者の反論権や裁定機関による審理も保障する必要があるとされた。[^u023][^u024]

# 弾正尹

## 人選の論理

弾正台を強力な機関にするほど、長官の人事は政治的に重要になる。[^u023]

| 出身 | 問題 |
|---|---|
| 公家 | 諸侯が朝廷による地方統制を警戒する |
| 旧大名 | 同じ諸侯を監察する際の公平性が問題となる |
| 旧幕臣 | 徳川幕府の監察機構を引き継いだように見える |
| 皇族のまま | 皇族が直接政治責任を負うことになる |
| 領主権を持つ皇族出身華族（那珂川家など） | 利益相反。本人関係の案件から除斥する仕組みが必要 |

このため、**適当な親王を臣籍降下させ、領地を持たない公爵家を立てて弾正尹に就ける**方式が採られた。皇室と血縁でつながりつつ、旧大名家の利害から独立した権威を持たせるためである。[^u023][^u024]

## 初代弾正尹の人選[^n4]

| 候補 | 生没年・1867年時点 | 経歴（史実） | 評価 |
|---|---|---|---|
| 山階宮晃親王 | 1816〜1898年、満50歳 | 伏見宮邦家親王の長男。1864年に還俗し山階宮家を創設。明治政府で議定・外国事務総督 | 年齢と政治経験から制度を立ち上げる長官に適する（採用） |
| 華頂宮博経親王 | 1851〜1876年、満15〜16歳 | 1868年に還俗し華頂宮家を創立、後に弾正尹。徳川家茂の猶子 | 史実との対応は面白いが若年で実務は次官頼み。徳川家を監察する際に微妙な立場 |

初代弾正尹には山階宮晃親王が選ばれた。晃親王は臣籍降下し、宮号の「山階」をそのまま家名として無領の公爵家を創設した。この家を**山階弾正尹家**という。[^n7][^u024]

## 山階弾正尹家

* **領主権を与えない**：弾正尹自身が領主であれば、他家の領主権や領内行政を監察するとき必ず利益相反が生じる。[^u024]
* **国家俸給**：領主としての収入ではなく、国家財政から俸給を支給する。[^u024]
* **官職の非世襲**：公爵という爵位は世襲でも、弾正尹という官職は世襲させない。任命権は天皇に置き、罷免手続きも制度化する。そうしなければ、弾正台そのものが一つの公爵家の世襲的権力になってしまう。[^u024]

同じ皇族出身の公爵でも、[那珂川公爵家](../people/nakagawa-ducal-house.md)は35万石の世襲領主として地方的基盤を持ち、山階弾正尹家は朝廷への奉仕によって地位と俸給を得る。この区分は[華族令](kazoku-ordinance-1867.md)の公爵家の類型に組み込まれ、臣籍降下者の地位は[皇室典範](imperial-house-law.md)で定められる。[^u024]

## 弾正台の職員

職員には旧幕臣や公家出身の実務官僚を登用し、旧藩単位の人事をできるだけ避ける。初代弾正尹の補佐には、旧幕府の司法・監察実務を担った官僚を充てる。完全な中立は不可能でも、諸侯間の利害から一定の距離を取ることができる。[^u024]

# 運用と政治的意味

## 想定される事件

弾正台が太政官や有力諸侯から独立した監察機関になれば、次のような事件が起こりうる。いずれも政治問題となり、特に有力華族の不正を摘発する場合、弾正台は領主家の政治的権威と衝突する。[^u023]

* 薩摩の島津家による軍費の不正流用の調査
* 旧幕臣出身の中央官僚による汚職の告発
* 朝廷の有力公卿と領主家の癒着の追及
* 国司が特定の領主を不当に優遇しているとしての弾劾

## 「廃藩置県の代替」としての弾正台

朝廷は領主権を剥奪しないが、領主による不正や中央法令への違反を監察する。その結果、中央政府の法令が地方に実施され、領民が中央政府へ不服を申し立てる道も開かれる。領主は世襲的統治権を維持していても、以前のように領内で自由に振る舞うことはできなくなる。つまり**領主権を残しながら、その行使を中央政府の法律で制限していく**手段となり、全国の藩を強制的に廃止せずに行政の統一を進めうる。ただし弾正台だけで徴税や軍事の統一が実現するわけではなく、中央法令の制定権や執行機関の整備も必要である。[^u023]

この制度が機能すれば、朝廷政府の権威は勅命を出す力だけでなく、**諸侯を含む統治者全員に共通の法を適用できること**によって支えられるようになる。[^u024]

## 1869年憲法下の役割

1869年の憲法で領主権が行政・徴税・警察・司法を含む包括的な権利として保障されると、その権力を監察できる独立機関として弾正台の重要性はさらに高まる。ただし弾正台が単独で領主の判決を取り消したり領主を処罰したりする制度には、[元老院](genroin.md)の領主議員が強く反対する。そこで三者の分担が想定されている。[^u036]

| 機関 | 役割 |
|---|---|
| 領主裁判所 | 領内の通常事件を審理する |
| 帝国裁判所 | 帝国共通法の事件、領主間事件、法定の上訴事件を扱う |
| 弾正台 | 領主・官吏による違法な権力行使を調査し、適切な裁判所へ訴追する |

例として、那珂川家領で領主が政治的な反対者を恣意的に投獄した場合、弾正台が調査する。これにより、領主の司法権を認めながら、最終的な法秩序を帝国政府に結びつけられる。[^u036]

## 1920年代以降：司法監督権

1921〜1924年頃の華族特権改革で、家門構成員に対する捜査・訴追・第一審裁判の権限（家門司法権）が全華族に認められ、領主の領国司法権と並ぶ独自の司法権となった（→[家門自治権と家門司法権](family-autonomy.md)）。[^p027] 家門司法では当主が司法機関の人事・運営を握るため、裁判の公正性が問題となる。その救済手段とされたのが、当事者の上訴権と弾正台の提訴権である。[^p031]

弾正台の権限は次のように定められた。[^p030][^p031]

| 権限 | 内容 |
|---|---|
| 司法判断への異議提訴 | 領国司法権・家門司法権による決定に不服を唱え、帝国裁判所に提訴できる |
| 違憲訴追 | 家法や領国法の憲法違反を帝国裁判所に訴追できる |
| 公益提訴 | 当事者が上訴しなくても、公益の立場から提訴できる[^n5] |
| 抽象的審査の請求 | 具体的な事件がなくても、家法・領国法そのものを対象に提訴できる[^n5] |
| 執行停止効 | 刑罰が確定した後に弾正台が提訴した場合、提訴の翌日から刑の執行が停止する（提訴当日は停止しない） |

弾正台は当初から「裁判官にも処刑人にもならない」機関として設計されたが、その原則は1937年まで維持されている。判決を取り消す権限は帝国裁判所にあり、弾正台は訴追者・提訴者にとどまる。[^p030] 帝国裁判所の違憲判決は、その効力の範囲（個別適用の排除から全部無効、遡及効・将来効まで）を判決自身が定め、上限はない。[^p031]

華族当主が被告となる場合も第一義的には自家の家門司法権に服するため、当主に有利な判決が自家の裁判で下されても、弾正台の提訴によって帝国の司法的監督が及ぶ。[^p031] 家門構成員の事実上の不逮捕特権（→[家門自治権と家門司法権](family-autonomy.md)）のもとでは、弾正台の提訴が家門司法の濫用を正す主要な経路となる。[^p029]

死刑など不可逆的な刑罰が、確定後の弾正台の提訴当日に執行されうる問題が残っている。[^n6][^p031]

## 関連制度

* 法典編纂機関（格式編纂局・修律館）は、裁定院や弾正台から寄せられた制度上の問題を集約し、法改正案に反映する役割を持つ。[^u031]
* [領主権奉還令](lordship-surrender.md)は「弾正台や領主権裁定院と並ぶ重要な制度」と位置づけられる。[^u027]
