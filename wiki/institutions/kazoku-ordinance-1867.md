# 概要

**1867年華族令**は、明治元年に公布された華族制度の基本法であり、旧公家・旧大名・臣籍降下した皇族を公・侯・伯・子・男の五爵からなる一つの世襲貴族階級に再編した（制度全体は[華族制度と華族令](kazoku-system.md)を参照）。[^u024]

本世界線の明治国家は内戦を経ずに成立したため、華族令は維新の功労者に爵位を与える制度ではなく、**既存の公家・武家の身分秩序を新しい帝国の法制度の下で組み替える制度**として作られた。1867年の初叙爵で功績によって華族となった者はいない。[^p013]

初叙爵の原理は公家と武家で非対称である。旧公家は朝廷における家格をそのまま五爵に移した。旧大名は、徳川将軍家との親疎で決まっていた幕府時代の格式（親藩・譜代・外様、殿席など）を廃止し、領国の規模（表高）を基準に叙爵した。これにより華族令は、**領主権は安堵するが、幕府によって与えられた格式や政治的特権までは安堵しない**という原則を体現し、徳川家を頂点とする武家序列を解体して天皇を頂点とする貴族秩序へ組み替える政治的役割を担った。[^p014][^p015]

初叙爵の結果、華族は**414家**（[領主権](lordship-rights.md)を持つ領主華族276家、持たない無領華族138家）となった。公爵8家のうち領主権を持つのは徳川宗家と[那珂川公爵家](../people/nakagawa-ducal-house.md)の2家だけで、爵位と領主権の分離が数字の上でも明確に表れている。[^p017]

# 背景

## 母集団の確定

戊辰戦争が起きないため、会津・庄内などの処分に伴う領主家の再編や、戦後の新規立藩・改易は発生しない。したがって叙爵の母集団は、慶応年間の大名家を基準に、本世界線固有の事情で個別補正したものとなる。1867年の段階では積極的な新規授封は行わず、旧大名家を中心とした領主制度として出発した。[^p010]

| 身分類型 | 領主権の扱い |
|---|---|
| 親藩・譜代・外様大名 | 原則承認 |
| 徳川宗家 | 承認 |
| 御三卿 | 独立領主として承認[^n1] |
| 那珂川公爵家 | 承認済み |
| 一万石以上の交代寄合・旗本 | 個別審査[^n2] |
| 一万石未満の旗本 | 原則含めない |
| 陪臣・家老 | 独立した領主権を認めない（大名家の所領安堵と抵触するため） |
| 公家 | 原則として無領華族 |
| 皇族 | 皇族のままでは華族に含めない |
| 臣籍降下者 | 授封された場合のみ領主華族 |
| 寺社 | 華族に含めない |

[^p010]

母集団の史料としては、慶応3年（1867年）の『大成武鑑』の翻刻（大名当主名・伺候席・石高・本拠地を掲載）と、小川恭一『江戸幕藩大名家事典』が慶応3年末の武家を「大名家271家、御三卿・付家老・交代寄合など48家、計319家」と分類していることが用いられる。[^p016]

## 功績叙爵がない理由

史実の華族制度は1869年の創設当初から維新の功労者を取り込んでいったが、本世界線では幕府解体が内戦を伴わないため、軍功による新規叙爵の必要がなかった。創設時に華族身分を持たない有能な人物（旧幕臣・藩士・外交官・法律家など）は、世襲爵位を与えずに[元老院](genroin.md)の勅選議員として国政に参加させることができた。このため華族身分は「歴史的家格」、領主権は「世襲的地方統治権」、勅選議員の地位は「個人の能力と天皇の信任」に由来するという三つの原理が区別される。最初の本格的な功績叙爵問題は1889年の日清戦争後に生じる（[功績叙爵と新華族](merit-peerage.md)）。[^p013]

# 旧公家の叙爵

## 家格と爵位の対応

旧公家は、摂関家→公爵、清華家→侯爵、大臣家→伯爵、羽林家→子爵、名家・半家→男爵と、家格をそのまま五爵に移した。維新への功績で爵位を上下させる必要がないため、原則として家格だけで初叙爵が決まる。[^p014]

| 旧家格 | 新爵位 | 家数 | 家名（上位三爵）・例 |
|---|---|---:|---|
| 摂関家 | 公爵 | 5 | 近衛・九条・二条・一条・鷹司 |
| 清華家 | 侯爵 | 9 | 久我・三条・西園寺・徳大寺・大炊御門・花山院・菊亭・醍醐・広幡 |
| 大臣家 | 伯爵 | 3 | 正親町三条・三条西・中院 |
| 羽林家 | 子爵 | 66 | 中山・飛鳥井など |
| 名家 | 男爵 | 29 | 日野・広橋など |
| 半家 | 男爵 | 25 | 勘解由小路など |
| **計** | | **137** | |

[^p014]

江戸時代の堂上公家137家の家格別内訳（摂家5・清華家9・大臣家3・羽林家66・名家29・半家25）は史実の研究に基づく。羽林家と名家は本来官職上の系統の違いでもあり、すべての羽林家が名家より上位だったわけではないが、華族令によってこの区分は明確な爵位の上下関係に転換された。[^p014]

## 無領の臣籍降下家

旧公家137家に、親王が臣籍降下して立てた無領の弾正尹公爵家（[弾正台と弾正尹](danjodai.md)）1家を加えた138家が、創設時の無領華族である。無領公爵は摂関家5家と弾正尹公爵家の計6家となる。[^p017][^u024]

# 旧大名の叙爵

## 幕府時代の格式の廃止

朝廷にとって、武家の家格の多くは徳川家への親しさで決まっていたため、そのまま継承する理由がなかった。華族令は従来の格式を次のように扱った。[^p015]

| 従来の格式 | 華族令での扱い |
|---|---|
| 親藩・譜代・外様 | 公的な身分区分として廃止 |
| 御三家・御三卿 | 徳川家内部の家門としてのみ存続（爵位上の特例なし） |
| 江戸城の殿席 | 廃止 |
| 幕府役職への就任資格 | 廃止 |
| 国持・城持・無城 | 領国の実態を示す参考情報 |
| 石高 | 領主家の規模として考慮 |
| 位階・官職 | 朝廷が再審査（幕府秩序を反映するため爵位にそのまま転換しない） |
| 家の歴史的由緒 | 補助的基準 |
| 皇室との血縁 | 独立した叙爵基準 |

[^p015]

旧大名家にとっては領国を維持できる以上、爵位の再編を受け入れる余地があった。とくに外様大名にとっては、徳川家との関係による身分上の制約がなくなるという利益があった。[^p015]

| | 公家 | 武家 |
|---|---|---|
| 旧秩序の扱い | 継承 | 再編 |
| 初叙爵の基準 | 朝廷における家格 | 領国の規模・特別な由緒 |
| 制度上の変化 | 既存の格式を爵位に転換 | 徳川家中心の身分秩序を解体 |
| 政治的権利 | 元老院の無領華族互選資格 | 領主権・元老院の領主互選資格 |

[^p015][^p018]

## 徳川宗家の公爵

徳川宗家は公爵とされた。旧将軍家としての歴史的地位を認める一方、徳川一門全体に特別な爵位を保障するものではなく、御三家・御三卿に特例は設けない。爵位によって元老院の議決権や互選資格に差は生じないため、宗家を公爵としても憲法上の特権を復活させることにはならない。[^p016][^p015]

## 表高基準（30万石・10万石・3万石）

武家については、将軍家との親疎ではなく現に統治している領国の規模に基づく石高を基準とした。基準には表高（公称石高）を用いる。実高は全国的な再調査が必要であり、史実の叙爵内規が用いた現米（実収）は、領民に重い租税を課す領主ほど高い爵位を得やすくなるという問題がある。[^p015][^p016]

| 爵位 | 武家の初叙爵基準 |
|---|---|
| 公爵 | 徳川宗家、皇族の臣籍降下など特例授爵家（石高による自動叙爵はない） |
| 侯爵 | 表高30万石以上 |
| 伯爵 | 10万石以上30万石未満 |
| 子爵 | 3万石以上10万石未満 |
| 男爵 | 3万石未満 |

[^p015][^p016][^p017]

この基準では、尾張・紀伊徳川家は前田・島津家と同じ侯爵となり、御三卿は一般の10万石級領主と同格となって、旧幕府の序列が明確に解体される。また小領主にも男爵を認めるため、爵位と領主権は完全に独立する。領国を統治する男爵と領国を持たない公爵が並存し、小領国の侯爵家と大領国の伯爵家が並ぶことも制度上の問題とはならない。[^p015][^p016]

## 本世界線固有の補正と個別審査

史料上の名簿には、本世界線の幕末史に合わせて次の補正が加えられ、領主華族は276家となった。[^n4][^p017]

| 領主家 | 史料上の分類 | 本世界線での扱い | 理由 |

| 徳川宗家 | 名簿外 | 公爵 | 旧将軍家の歴史的地位 |
| 那珂川公爵家 | 存在しない | 公爵 | 臣籍降下した皇族の領主家（旧水戸領35万石） |
| 旧水戸徳川家 | 侯爵相当 | 子爵[^n3] | 1860年の減封転封による。転封先は甲斐国陣屋領8万石[^n5] |
| 彦根井伊家 | 伯爵相当 | 侯爵[^n3] | 本世界線では幕末の減封が起こらず35万石を維持した |
| 田安・一橋・清水徳川家 | 名簿外 | 伯爵[^n1] | 各10万石相当の独立領主 |
| 対馬宗家 | 個別審査 | 伯爵[^n3] | 対朝鮮外交・貿易を含む領国の特殊性（[対馬宗家と外交権の一元化](../diplomacy/tsushima-so-clan.md)） |
| 喜連川足利家 | 個別審査 | 子爵[^n3] | 足利将軍家の系譜に由来する歴史的地位を朝廷が独自に評価（徳川幕府の格式継承ではない） |

例外は極力少なくする方針であり、内分分家に独立した領主権を認めるかは個別審査に委ねられた。幕末の政治展開が史実と異なるため、井伊家以外にも石高を補正すべき家がありうる。[^p016][^p017]

## 元老院への接続

華族令による414家の母集団は、[元老院](genroin.md)の定数設計の基礎となった。領主華族276家・無領華族138家のそれぞれ約半数が議員となるよう、1867年の定数は領主互選議員140・華族互選議員70・勅選議員30の計240と定められた。互選の選挙権は領主互選が領主華族当主、華族互選が無領華族当主に限られ、爵位による票数の差はない。爵位は社会的・儀礼的な序列であり、議会における政治的権利とは区別される（詳細は[元老院の構成と互選制度](genroin-composition.md)）。[^p017][^p018][^p014]

1920年代以降、爵位は家門構成員の上限人数を決める基準ともなり、属人的な司法権の規模という法的な意味を帯びるようになる（[家門自治権と家門司法権](family-autonomy.md)）。[^p028]

| 維新功労者 | 1884年に多数叙爵 | 存在しない |

史実の現米15万石・5万石は、年貢率をおおむね4割と仮定すると表高37.5万石・12.5万石に相当する。史実を表高に近似した「40万石以上を侯爵、15万石以上を伯爵、その他の領主を子爵」とする案（B案）も比較されたが、本世界線の趣旨により合う上記の基準（A案）が採られた。史実の叙爵内規については酒巻芳男『華族制度の研究』、浅見雅男『華族誕生』、国立公文書館の華族令資料が参照された。[^p016]

# 編集注：却下・修正された案

* **武家は既存の家格を優先し石高を補助基準とする案**: 公家との一貫性から当初提示されたが、武家の家格は徳川家との親疎で決まっており、朝廷はこれを破壊したいはずだという指摘を受け、石高基準に改められた。[^p014][^p015]
* **B案（表高40万石以上を侯爵、15万石以上を伯爵、その他を子爵）**: 史実の叙爵内規の近似。領主を子爵以上に限ることになり、爵位と領主権の完全な独立という趣旨に合わないとして退けられた。[^p016]
* **徳川宗家を侯爵、または一代限りの公爵とする案**: 世襲公爵とすることで確定した。[^p015][^p016]
* **母集団の仮置き「270家」**: 旧大名265家＋徳川宗家＋御三卿3家＋那珂川家とした作業上の概算で、史料集計により276家に置き換えられた。[^p010][^p017]
* **花山院家を羽林家（子爵）とした例示**: 清華家の誤りで、侯爵に訂正された。[^p014]
* **P15時点の概数**（細川54万石・黒田52万石・井伊35万石を侯爵、会津松平23万石を伯爵とする例示）: 『大成武鑑』の表高に置き換えられた。[^p015][^p016]
