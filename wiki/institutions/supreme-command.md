# 概要

本世界線の天皇には**固有の統帥権がない**。そのため、史実の1930年に起きた統帥権干犯事件は起こりえない。これはユーザーが確定させた設定である。シビリアンコントロールが成立しているとまでは言えないが、**軍が天皇の権威だけを根拠に政府の指令を拒むことはできない**。[^u124]

理由は、この国制が成立した経緯にある。1866年、徳川家茂の死去に際して朝廷は軍事権を回収し、幕府への再委任を拒んだ。ただしその後、天皇が無制約の軍事大権を得たわけではない。諸領主との合意によって統一軍を維持する立憲体制が、1869年の[大日本帝国憲法](/institutions/imperial-constitution.md)として成立した。したがって**帝国軍の権限は、憲法によって構成された国家機関の権限であって、天皇個人に由来する不可侵の統帥大権ではない**。[^u124]

その結果、軍の政治的影響力は消えないものの、元老院・衆議院の政治勢力と結びつくという合法的な制度の内側で行使されるしかない。本世界線の憲政上の論点は、統帥権の独立ではなく「内閣・元老院・軍司令部の権限分配」になる。[^u124]

# 成立の経緯

## 1861年公武協定――軍権は「朝廷からの委任」

本世界線の軍事権は、出発点から「委任された権限」として明文化されていた。[1861年公武協定](/diplomacy/kobu-agreement-1861.md)で幕府は、水戸の旧領を献上する見返りに「全国海防の勅命」を得た。将軍の軍事統率は朝廷からの委任であり、全国常備軍は朝廷の正統性と幕府の軍事行政能力を組み合わせて作られた。[^u009] ユーザーは、この協定が幕府を終わらせうるものであり、将軍は朝廷の裁可のない軍権を失いうる、と確定させている。[^u010]

| 軍事権限 | 担い手（1861年協定の配分案） |
|---|---|
| 軍隊の編成・訓練・人事 | 将軍・幕府 |
| 平時の警備・部隊移動 | 将軍・幕府 |
| 全国規模の動員・対外開戦・諸侯討伐 | 朝廷の裁可が必要 |

[^u010] 協定の最大の曖昧点は「朝廷は将軍への軍事委任を変更・撤回できるか」であった。[^u010] 詳細は[全国常備軍（公武合体軍）](/military/standing-army-1861.md)を参照。

## 1866年――再委任の拒否

ユーザーは、1866年に家茂が死んだ時点で軍権を一時朝廷預かりにすれば、それを覆せる存在はない、と確定させている。[^u015] 朝廷は「徳川宗家の相続」と「将軍への軍事委任」を別の行為と解し、家督相続を認めながら軍事委任の更新を保留した。こうして[無血の幕府解体](/events/bloodless-dissolution-1866.md)が実現した。本世界線で幕府を終わらせた決定的な行為は、「徳川家を倒すこと」ではなく「次の将軍に軍事権を再委任しないこと」である。[^u015]

## 1867〜1869年――諸侯による軍権の制限

諸侯が最も警戒したのは「**天皇の名を借りた太政官が、勅命一つで領主を討伐できる制度**」であった。徳川将軍に与えなかった無制限の軍権を、今度は太政官に与えることにも慎重になる。そこで、国防のための中央常備軍は必要と認めつつ、**軍の指揮権と軍事予算の決定権を区別**し、憲法で軍事権を制約することが求められた。[^u034]

憲法の検討案では、軍事権は次のように規定される。[^u025]

* 天皇は国家軍の最高統帥者とする。ただし、その権限は史実のような広い独立大権ではなく、憲法と議会の手続で制約される。
* 軍隊の常設と軍費の負担は法律で定める。
* 対外戦争には原則として元老院の同意を要する。
* 領主に対する軍事的強制は、司法手続または特別な議決を経なければならない。
* 中央の常備軍は徳川家や有力諸侯の私兵ではなく、帝国の共同財産である。

1869年憲法の領主権条項案では「帝国ノ外交、国防及全国軍ノ統轄ハ、中央政府ノ専管トス」とされ、軍の統轄は天皇個人ではなく中央政府に属する。[^u036]

## 統一国軍の形成

領主たちは独自の軍を持たず、軍費を金で納め、国軍が軍事を独占する。ユーザーは、帝国軍が諸侯の連合軍だという見方は疑わしいと確定させた。[^u030] 1894年頃（本世界線の日清戦争期）の構造は次のとおりである（検討案）。[^u030]

* 天皇・中央政府: 統帥権・軍事予算・国家軍の運営
* 帝国陸軍: 全国的な徴兵・将校教育・統一指揮
* 帝国海軍: 全国的な造船・艦隊運用・海軍教育
* 各領主領の警察・警備隊: 領内の治安（国軍とは別系統）

日清戦争の時点で確定させたい条件として、統一された参謀本部と軍令体系、全国統一の兵器・弾薬・補給規格、中央政府の戦時動員権が挙げられている。[^u029] 詳細は[帝国軍](/military/imperial-army.md)を参照。

# 運用

## 派兵と宣戦

本世界線の開戦は、議会手続を経なければならない。宣戦に元老院の同意、戦費支出に両院の議決が必要なら、政府は議会への説明を避けられない。ただし、派兵（政府の決定）と宣戦（元老院の承認）を別の権限とするか、国外派兵にも元老院の同意を要するかは論点として残る。そこには、1860年代に将軍の軍権を制限した経験が直接影響している。[^u037]

1875年前後の江華島事件では、平時の測量航海や艦隊派遣には元老院の同意が要らない可能性がある。そのため「戦争ではなく航路調査」と説明すれば派遣は容易である。事件を口実に政府が元老院の事前承認なしでどこまで軍事行動を広げられるかは、将軍の独断的な軍権を制限した成立経緯と関わる憲法問題になる。[^u041]

## 戦費という制約

天皇が軍の最高指揮権を持っていても、元老院・衆議院の同意なしに巨額の戦時公債を発行できないなら、政府は開戦を決める前に議会の協力を取り付けねばならない。領主たちが1869年の憲法制定時に、無制限の軍事財政権限を中央へ渡したとは考えにくい。[^u088] 結果として本世界線の日本は、「ロシアと戦えるだけの国力を育てることには積極的でも、実際に戦争することには非常に慎重な国家」になる。[^u088]

## 第一次世界大戦

1914年の参戦は、英国の正式要請を受けて元老院・衆議院が海軍の限定参戦と臨時軍事費を承認し、そのうえで対独宣戦するという手続で行われる（検討案）。[^u095] 陸軍の欧州派遣には、帝国陸軍を欧州へ送る法的根拠、臨時戦費、外国軍司令官の指揮下に置くことの承認範囲、という制度・政治上の障害がある。[^u097] 詳細は[第一次世界大戦と日本](/events/world-war-one.md)を参照。

## 海軍軍縮と軍令部

1920〜1930年代の海軍軍縮でも、統帥権独立がないことは決定的である。[^u124]

* 軍令部が「この比率では帝国を防衛できない」と主張しても、政府が「財政的にそれ以上の軍備は維持できない」と判断すれば、問題は元老院と衆議院での軍事予算の争いになる。
* 軍縮条約が適法に批准され、政府が軍の編制変更を決めれば、軍令部は専門的な反対意見を述べられても、天皇の固有大権でそれを無効にすることはできない。
* 軍令部が軍縮を止めるには、議会や国民を説得するしかない。そして元老院には、領主系の産業資本や財政利益を代表し、海軍軍縮を支持する経済的動機を持つ議員がいる。

1930年のロンドン会議に向けた日本の交渉条件の一つとして、「**統帥権独立の不在**」すなわち軍部が憲法上の独立権限で政府の妥協を拒めないことが挙げられる。[^u132] 金解禁のための緊縮財政という政策目標も存在しない。そのためロンドン会議は、史実のような「金解禁・緊縮財政・海軍軍縮」が一体となった政治闘争ではない。英国と共同で必要とする補助艦を米国がどこまで認めるかという、純粋な海軍戦略・外交問題になる。[^u137] 詳細は[ロンドン海軍軍縮会議（1930）](/diplomacy/london-naval-conference-1930.md)を参照。

# 軍の政治的影響力の経路

統帥権がなくても、軍の政治的な自立がなくなるわけではない。影響力は別の経路で生じうる。[^u124]

| 史実の軍部が使った論理 | 本世界線で考えられる論理 |
|---|---|
| 天皇の統帥大権は政府から独立する | 軍の専門的判断を政府は尊重すべきだ |
| 軍令部の同意なしの軍縮は違憲 | 軍縮は国家防衛上の義務に反する |
| 天皇への直接上奏を通じて政府を牽制 | 元老院の領主議員や軍事委員会へ働きかける |
| 統帥権を根拠に作戦指導への介入を拒む | 参謀機構の組織上の自律性や既定の作戦計画を根拠に抵抗する |

世襲領主が強い政治的権利を持ち、旧武家の軍事的伝統も残っているため、将官が[元老院](/institutions/genroin.md)の有力議員と結びつく可能性はある。しかし「**政府の決定に不満があることと、それに従わなくてよい憲法上の権利を持つことは違う**」。[^u124]

史実で軍が内閣形成に影響を与える手段だった軍部大臣現役武官制にあたる制度がなければ、軍が内閣を組織的に倒す手段もかなり限られる。1930年代の日本で軍が政治的影響力を持とうとすれば、軍令部の憲法解釈ではなく、元老院・衆議院の政治勢力との結合が中心になる。それはクーデター的な軍部政治ではなく、軍事政策をめぐる議会政治の対立として現れる。「**この世界の日本では、軍が政治的に強くても、その強さを合法的な政治制度の中で行使せざるを得ない**」。[^u124]

# 権限構成の想定（検討案）

1869年憲法における軍事権限の具体的な分配は確定していない。一つの仮定として、次の構成が示されている。[^u124]

| 主体 | 権限 |
|---|---|
| 天皇 | 帝国軍の名目的な最高統帥者 |
| 内閣 | 軍事政策と作戦指揮に責任を負う |
| 参謀機関 | 内閣の下で作戦を立案する |
| 元老院・衆議院 | 軍事予算と軍制に関する立法権 |

この構成なら、かなり強い文民統制が成り立つ。逆に、軍の最高司令官が内閣から独立した憲法上の地位を持つ場合や、軍事政策の決定に元老院の特別な同意が必要な場合には、事情が変わる。[^u124]

| 項目 | 史実 | 本世界線 |

# 却下・修正された案

* **天皇の統帥権と諸侯の軍事協力義務**: 当初の比較表では、本世界線の軍事を「天皇の統帥権と諸侯の軍事協力義務」と整理していた。[^u025] その後、諸侯の連合軍は否定されて統一国軍に修正され[^u030]、さらに天皇に固有の統帥権はないことが確定した。[^u124] 「天皇は国家軍の最高統帥権を持つ」という表現は、「名目的な最高統帥者」と読み替えるのが整合的である。
* **領主系予備軍を含む三層軍制**: 帝国常備軍・帝国海軍に、平時は領主が管理し総動員時に編入する領主系予備軍を加える案があった。[^u029] ユーザーの指摘で撤回され、国軍が軍事を独占する形になった。[^u030]
