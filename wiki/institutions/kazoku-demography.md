# 概要

本世界線の華族は、1867年の[華族令](/institutions/kazoku-ordinance-1867.md)による初叙爵で**414家**（[領主権](/institutions/lordship-rights.md)を持つ領主華族276家、持たない無領華族138家）として出発し、1937年末には**770家**（領主華族249家・無領華族521家）となった。この1937年末の値は、1937年の経済・社会構造の確定値の一部である。[^p017][^p035][^p097]

70年間で領主華族は約10%しか減らなかった。本州・四国・九州では[領主権奉還](/institutions/lordship-surrender.md)によって領主家が減ったが、北海道の新規授封がそれを1920年代まで相殺したからである。一方、無領華族は奉還家と[功績叙爵](/institutions/merit-peerage.md)による新華族を受け入れて約3.8倍に増え、1900年代初頭には領主華族を上回った。[^p034][^p035]

養子・非血縁者による家督継承が広く認められ、1920年代に確立した家門自治権がクリティカルの効果を持ったため、華族家の自然断絶は極めて少ない。家数を大きく減らしたのは、1927年以降の金融危機に伴う実業家華族の爵位返上である。[^p035]

華族家数は[元老院](/institutions/genroin.md)の領主互選・無領華族互選の選挙人の数そのものであり、その偏りが元老院の定数改革（240→275→310）を引き起こした。[^p025][^p032]

元老院の互選定数は有権者数に自動連動しない固定定数であり、変更は帝国議会の立法による。そのため華族家数の変化は、そのまま領主と無領華族の「代表密度」の格差となった。定数が1867年のまま据え置かれていれば、1937年の格差は5倍を超えるところだった。無領華族の改革運動を受けて、1924年に華族互選が70から100へ、1936年に110へ増員され、領主互選も1936年に160に増えて領主の制度的過半数が維持された。1936年時点で領主側の代表密度は無領華族の約3倍だが、1924年前後に家門自治権を全華族に広げたことで、この格差は政治的に受け入れられた（[元老院の構成と互選制度](/institutions/genroin-composition.md)）。[^p012][^p025][^p032][^p035]

## 相続制度

| 項目 | 制度 |
|---|---|
| 実子・傍系親族・養子による相続 | 可能 |
| 非血縁者による相続 | 可能 |
| 女性による爵位継承 | 不可 |
| 女性による領主権継承 | 不可 |
| 家督継承者の選定 | 家法による |
| 爵位継承の承認 | 天皇 |
| 領主権継承の承認 | 朝廷による公的承認 |
| 私有財産の相続 | 爵位・領主権の継承とは区別 |

[^p035]

華族家は特定の血統に属する一族というより、**歴史的な家名・爵位・家産・家法を継承する永続的な法的団体**として発展した。直系男子がいなければ娘の配偶者を養子として当主にでき、家門の経営を担ってきた非血縁者を後継者に指定することもできる（制度の細目は検討案）。女性が爵位を継げないことと、女性が家産を相続できないことは別の問題として扱われる。[^p035]

女性による爵位・領主権の継承不可は、1930年代の男女普通選挙の成立と対照的であり、女性政党にとって華族制度の改革が新しい政治課題となりうる（[女性参政権運動と国民協同党](/politics/womens-suffrage.md)）。ただし家族法の改正で男女の相続・財産管理を平等にしても、華族家法への介入は別問題であり、女性の爵位・領主権継承が直ちに認められるわけではない。[^p035][^p081]

## 家門自治権と存続能力

1924年前後に家門自治権が華族全体に広げられた（[家門自治権と家門司法権](/institutions/family-autonomy.md)）。そのクリティカルの効果として、次の家門制度が発達した（検討案）。[^p035]

| 制度 | 存続への効果 |
|---|---|
| 家門会議 | 当主の死亡時にも家門の意思決定を継続 |
| 予備継承者の指定 | 突然の当主死亡による断絶を回避 |
| 家産の団体的管理 | 当主個人の死亡による財産の分散を抑制 |
| 家門内の扶養制度 | 後継者の教育・生活を保障 |
| 家法による継承規則 | 相続紛争を抑制 |
| 家門司法権 | 家督・家産をめぐる紛争を内部で処理 |

[^p035]

こうして、爵位を持つ当主個人が死亡しても家門そのものは直ちに消滅しない、という法理が発達した。[^p035]

## 分家の扱い

既存華族の分家に新たに爵位を与えることは原則として認められず（北海道開拓のための独立分家への授封は例外）、無爵位の分家が本家の家門に所属する慣行も定着しなかった。華族から分家した者は、血縁を保っていても当然には本家の家法や家門司法権に服さず、本家に加わるには個別の登録が必要となる。家門自治権は血縁ではなく登録によって生じる権利であり、華族の血縁者が際限なく司法上の特権を得ることは防がれた。[^p025][^p034][^p035]

| 身分 | 爵位 | 家門所属 |
|---|:---:|---|
| 華族家当主 | あり | 自家 |
| 本家の登録構成員 | 原則なし | 本家 |
| 独立した華族分家 | あり | 独自の家門 |
| 無爵位分家 | なし | 原則として独立 |
| 無爵位分家から本家への加入 | なし | 個別登録による |

[^p035]

## 領主権が消滅したときの旧領の処理

| 領主権消滅の理由 | 旧領国の処理 |
|---|---|
| 自発的な領主権奉還 | 帝国直轄化（再配分・再授封なし） |
| 家門の断絶 | 他家への再授封・既存領主への加増を認める |
| 領主権剥奪 | 未確定 |
| 後継者への通常の継承 | 領国を維持 |

[^p034][^p035]

奉還は領国統治の維持が困難になった場合に行われるのに対し、断絶は領国の財政や行政能力とは関係がない。したがって統治能力を保つ断絶領は別の領主に授封できる。もっとも養子相続と家門自治権が良好に働いたため、断絶領そのものは極めて少数（1937年までに5件）である。[^p035]

## 爵位返上

平時に経済的困窮から爵位を返上した家はほとんどなく（1家）、爵位の維持に常に莫大な費用がかかったわけではない。返上は1927年以降の金融危機で、経営する銀行・企業の破綻に責任を負った実業家華族に集中した（27家、累計叙爵168家の16.1%）。詳細は[功績叙爵と新華族](/institutions/merit-peerage.md)を参照。[^p035]

史実の華族は1907年に1935年の約95%に達し、以後ほとんど増えなかった（1920〜35年の純増+3）。本世界線では維新功労者と日露戦争による叙爵がないため明治期の増加は小さいが、実業家・学者への叙爵が昭和期まで続くため、1920〜30年代にも増加が続いた。史実では旧大名は廃藩置県で統治権を失ったので、「領主華族」と「無領華族」の区別そのものが存在しない。史実の値は森岡清美『華族社会の「家」戦略』による。[^p024][^p025]

# 却下・修正された案

* **領主家数の当初の仮推移**（1867年270→1936年175）と、家数の半分を定数とする連動案: 定数を固定し、276家を母集団とする方式に置き換えられた。[^p012][^p017]
* **奉還101家モデル**（1937年の領主175家）: ダイス判定で金融支援がクリティカルとなったため、奉還60家（残存216家）に下方修正された。[^p022]
* **奉還の時期配分（P22版）**: 1867〜76年20・1877〜89年12・1890〜1913年16・1914〜26年3・1927〜37年9。領主金融圏の判定を受け、1927〜37年に20家とする配分（P23版）に修正された。[^p022][^p023]
* **1937年の無領華族558家・華族総数809家**: 新規授封は反映したが断絶・爵位返上を反映しない段階の値。最終補正（純減39家、断絶領授封+3家）で770家となった。[^p025][^p034][^p035]
