# 概要

本世界線でも、史実と同じく**民撰議院設立建白書**が出された後に**衆議院**が作られた。[^u026] ただし建白書の意味は史実と大きく異なる。1869年（明治3年）頃に[大日本帝国憲法](imperial-constitution.md)がすでに公布され、天皇と諸侯の権限は明文で保障されていた。建白書は、その「**領主のための憲法**」に対する直接の応答として位置づけられる。[^u035]

建白書が求めたのは「立憲政治を始めよ」ではなく、「**すでに存在する立憲政治に人民も参加させよ**」であった。その結果、1870年代中盤の憲法改正で衆議院が設けられ、既存の[元老院](genroin.md)と並ぶ二院制の帝国議会が成立した。[^u034][^u035] 衆議院は律令国・郡を基準とする人口比例の選挙区から選ばれる。元老院が領主権を代表するのに対し、衆議院は租税と軍費を負担する納税者・住民を代表する院である。[^u026]

**第一回衆議院選挙は1876年**に行われた（第一回帝国議会は元老院のみで1867年に開かれている）。衆議院の任期は4年で、任期満了以外の解散事由を持たない。衆議院は元老院の決議に対する拒否権、新内閣に対する組閣拒否権、内閣不信任権、元老院勅令を発出後90日以内に無効とする決議権を持つが、内閣首班を指名することはできない（→[内閣制度と両院関係（首班指名・組閣拒否・不信任・勅令）](cabinet-system.md)）。[^p002] 選挙制度は、男子制限選挙・記名投票から始まり、1924年の納税資格の大幅緩和、1928年の秘密投票の実施を経て、1934〜1935年[^n1]に女性参政権と納税資格の撤廃が実現し、1936年に初の男女普通選挙が行われた。[^p006][^p007][^p008][^p009] 1937年の衆議院は国民進歩党・立憲改進党・国民協同党・社会民権党・日本労農党・立憲保守党を中心とする多党制である。[^p009][^p078]

# 建白書の背景

## 1869〜1874年の経過

憲法の公布から建白書までの5年間に、人々は憲法による統治を実際に経験した。[^u035]

| 年 | 出来事 |
|---|---|
| 1869年（明治3年）頃 | 大日本帝国憲法の公布。元老院が立法機関として確立 |
| 1870〜1872年 | 元老院が軍制・租税・鉄道・商業などの全国共通法を制定。人民は元老院議員を選べない |
| 1871年（明治5年） | 租税負担や領主権をめぐる不満が広がる[^n2][^u026] |
| 1872〜1873年 | 地方の商人・豪農・知識人が、国税や軍費を負担しながら議会に代表を持てないことを問題にする |
| 1874年（明治8年） | 民撰議院設立建白書。憲法改正による衆議院の設置を要求 |

征韓論政変や板垣らの下野が史実どおりに起きたとは限らない。1874年に同じ人物が同じ文面で建白したのではなく、**同じ時期に民撰議院の設立を要求する政治運動が生まれた**のである。[^n3][^u026]

## 批判の論理

建白書の批判は次の三点に集約される。

1. **代表なき負担**: 「領主は元老院で国政に参与し、官吏も勅選議員として議政に参加する。ところが国家の租税を負担する人民には、国政に意見を述べる機関がない」。1860年代から近代的な常備軍が整備されていたため、軍費を負担する商人・地主・農民が政治参加を求める理由は十分にあった。[^u026]
2. **憲法の不完全性**: 「諸侯は憲法によって統治権を保障された。では、その統治を受ける人民の権利は誰が保障するのか」。[^u035]
3. **領主権への統制手段の欠如**: 「領主が立法・行政・警察・司法を握っているのに、領民はその領主を政治的に統制する手段が乏しい」。1869年の領主権が司法権・治安権まで含む包括的なものだったため、この批判が加わった。[^u036]

## 建白書の文案[^n2]

> 帝国憲法既ニ制定セラレ、天皇ノ大権及諸侯ノ領主権ハ明文ヲ以テ保障セラル。
> 然ルニ、天下ノ租税ヲ負担シ、国防ノ軍役ニ服スル人民ハ、未ダ国政ニ参与スルノ権ヲ得ズ。
> 是レ立憲ノ名アリテ、公議ノ実ナキモノナリ。

この主張の要点は、帝国憲法そのものを否定せず、憲法の存在を前提にその理念を人民へ広げることを求めている点にある。[^u035]

## 建白の担い手

* **商人・豪農・知識人**: 国税・軍費を負担しているのに代表を持たない層。[^u026]
* **欧米帰りの領主家官僚・留学生**: 岩倉使節団の時期に大量に派遣された領主家の視察員・留学生が、元老院の議席が領主・華族・勅選に限られていることへの不満から建白に関わったとみられる。[^n2][^u043]
* **一部の大領主**: 元老院で劣勢な領主連合が、衆議院を作ることで政治的な均衡を変えようとして民撰議院運動を支援しうる。「一部の大領主が、人民代表の導入を支持することで、別の大領主の政治的優位を崩そうとする」構図である。[^n2][^u035]

# 衆議院の設置

## 憲法改正

建白書は元老院の廃止を求めなかった。「元老院は諸侯の権利を代表する機関として存続させ、その一方に人民の権利を代表する衆議院を設けよ」という要求であり、二院制が自然な妥協となった。[^u035] 1869年憲法が「帝国ノ立法ハ天皇ノ裁可及元老院ノ議決ニ依ル」と定めていた場合でも、「帝国議会ハ元老院及衆議院ノ両院ヲ以テ組織ス」とする限定的な改正で衆議院を加えられる。領主権の保障や天皇の元首権を変える必要はない。ただし衆議院に予算議決権を与えるなら、元老院との権限配分や軍事費負担の仕組みも改める必要がある。[^u035] 例（制定法）の制定手続は両院の議決と天皇の裁可に改められるが、法形式そのものは変わらない（→[法体系（詔・勅・例・式）と司法制度](legal-system.md)）。

## 年表[^n4]

| 年 | 出来事 |
|---|---|
| 1874年（明治8年） | 建白書に相当する請願。元老院と太政官が衆議院設置の検討を開始 |
| 1875年（明治9年） | 衆議院選挙法の制定。選挙区・選挙資格・議員定数を決定 |
| 1876年（明治10年） | 第一回衆議院議員総選挙。帝国議会が元老院・衆議院の二院制となる |

[^u026][^u034][^p002]

## 選挙制度[^n2]

| 項目 | 内容 |
|---|---|
| 選挙区 | 律令国・郡を基準に人口に応じて設定。領主ごとの割当てはしない（人口の少ない小領主領が過大に代表されるのを避ける） |
| 選挙権 | 初期は史実と同様に一定額以上の納税者に限られる可能性 |
| 選挙管理 | 領主の介入を防ぐため、選挙区画・選挙人名簿・選挙争訟は中央政府か独立した選挙機関が担当 |

[^u026]

初期の選挙制度はさらに次のように具体化された。[^n5] 議員定数300人、律令国・郡を基礎とする人口比例の選挙区（小選挙区と複数人区の混合）、選挙権は満25歳以上・被選挙権は満30歳以上の男子で、一定額以上の直接税を納める者に限る。投票は記名式で、選挙管理は帝国政府が担う。[^p003] 初期の総選挙では領主による恒常的な選挙支配は防がれた。[^n6][^p004] 納税要件に帝国税だけを数えるか領国税も含めるかは明らかでない。[^n7][^p003]

# 衆議院の権限と任期

衆議院の憲法上の地位は次のとおりである。[^p002]

| 項目 | 内容 |
|---|---|
| 任期 | 4年。任期満了以外の解散事由はない（総選挙は1876年から4年ごとに固定） |
| 元老院の決議 | 拒否権を持つ |
| 新内閣 | 元老院の首班指名で内閣が組閣されると、直ちに組閣拒否決議案を諮る。否決すれば信任を表明したことになる |
| 内閣不信任 | 出席議員の半数以上で可決。可決後10日以内に内閣は解散（総辞職）する |
| 元老院勅令 | 発出後90日以内に限り無効を決議できる |
| 首班指名 | 権限なし |
| 議長 | 政党政治の成立後は、慣例上、野党議員から選ばれる |
| 兼職 | 議員は領主を除き他の公職と兼任できず、閣僚にもなれない |
| 議決 | 定足数なし、棄権は欠席扱い、可否同数は可決（1937年末までに定足数を定める憲法改正が成立） |

衆議院は首班を指名できない一方で内閣の存立を拒めるため、本世界線の内閣制度は「元老院首班指名・衆議院消極的信任制」と呼ばれる（分析上の呼称）。野党が拒否・不信任で結束しない限り少数与党内閣も存続でき、少数政党は棄権によって事実上の閣外協力を行える。[^p002] 1936年には、国民協同党46議席が組閣拒否（不承認動議）の採決で棄権し、国民進歩党・立憲改進党の少数与党内閣が成立した。[^n8][^p080][^p081]

衆議院議長を野党から選ぶ慣例は、議会を内閣から独立した機関とみる思想と整合する。議員は閣僚になれないので、政党は議会部門（議員団）と行政部門（首相・閣僚）が分離した形で政党政治を営む。[^p002]

# 選挙制度の変遷（1876〜1936年）

衆議院の選挙制度は次のように変わった。詳細は[衆議院選挙制度の変遷（制限選挙・記名投票から男女普通選挙へ）](../politics/election-system.md)を参照。

| 年 | 変化 |
|---|---|
| 1876年 | 男子制限選挙（直接税納税者）・記名投票で第一回総選挙[^n9][^p003] |
| 1888・1900・1916年 | いずれの時期までにも選挙資格の緩和は実現せず[^n10][^p004][^p006] |
| 1900年代 | 秘密投票の改革案が否決され、公開投票が「立憲政治の原則」として強化される。元老院互選の「投票は公的責任」という思想が持ち込まれたため[^n11][^p006] |
| 1924年まで | 納税資格の大幅緩和（所得税・営業税の納税者にも拡大。有権者は約650万人と推計）。男子普通選挙は実現せず[^n10][^p007] |
| 1926〜1927年 | 秘密投票の導入、1928年の第14回総選挙から実施。元老院互選は記名のまま[^n12][^p008] |
| 1932年まで | 男子普通選挙は不成立[^n13][^p008] |
| 1934年 | 女性に男性と同等の納税資格で選挙権・被選挙権（男女制限選挙）[^n12][^p009] |
| 1935年 | 納税資格の撤廃（男女普通選挙）[^n12][^p009] |
| 1936年 | 第16回総選挙。初の男女普通選挙（有権者は3,500万〜3,800万人程度と推計）[^p009] |

本世界線の日本は、男子普通選挙を経ずに男女普通選挙へ進んだ。1936年の制度は、選挙権満25歳以上・被選挙権満30歳以上、性別要件なし、納税資格なし、無記名の秘密投票、任期4年・解散なしである。[^p009]

詳しい系譜と全年の議席は[政党の系譜と衆議院の議席推移（1876〜1937）](../politics/political-parties.md)を参照。1937年末の与党は国民進歩党・立憲改進党（128議席）で、国民協同党が閣外協力し、政権支持基盤は174議席である。[^p081] 男女普通選挙の衆議院は、農民・労働者・都市中間層の利益を反映する院として、資産所有者と専門エリートを代表する元老院と政策上対立する基礎を持つ。[^p085]

# 衆議院と元老院の対立軸

## 予算

長期的な最大の争点は予算である。元老院は諸侯の領内課税権を尊重しようとし、衆議院は税負担の公平と全国統一の税制を求める。衆議院が「人民が国家へ直接納税する以上、領主が別に課税する権利は制限されるべきだ」と主張し始めると、領主制度そのものが議論の対象になる。後から作られた衆議院が元老院と対等な立法権を持つのか、予算先議権などで少しずつ力を強めるのかが、議会政治の性格を決める。[^u026]

## 司法と平等

憲法が保障する世襲領主権と、衆議院が求める法の下の平等や司法の独立は、長期的な争点になる。[^u036]

## 地方自治への波及

アメリカ連邦制の参照によって、領主権は「憲法が保障する地方政府の自治権」として説明されるようになった。衆議院が成立すると、地方政府にも住民の政治参加を認めるべきだという議論が広がる。領主権は、少しずつ「世襲領主を長とする地方政府の自治権」へ性格を変えていく。[^u045]

## 自由民権運動の性格

この世界の自由民権運動は、単に議会を要求する運動ではない。すでに成立した「領主のための憲法」を「臣民のための憲法」へ改めようとする運動である。[^u034] 逆説的に言えば、「諸侯が自らの権利を保障するために作った憲法が、今度は領民が政治的権利を要求するための根拠になる」。[^u035]

# 外交・戦争における衆議院

衆議院は、戦費を負担する納税者の院として、対外政策で元老院とは異なる行動をとる。

| 時期 | 衆議院の立場 |
|---|---|
| 1870年代 | 朝鮮政策で「武家領主が主導する元老院」と「戦費を負担する納税者を代表する衆議院」が対立する構図[^u042] |
| 1870〜80年代 | 欧米には対等な主権を求め、朝鮮には軍事的威圧で不平等な条件を求める二重基準を、元老院・衆議院がどう正当化するかが争点[^u046] |
| 1887年頃 | 朝鮮王族の亡命受け入れには、費用と外交リスクから慎重論（ただし一様ではない）[^u054] |
| 1886年 | 漢城公使館危機では公使館員・居留民の保護を要求。商工・都市勢力が元老院の領主層と同じ強硬要求で一致しうる[^u058] |
| 日清戦争中 | 戦争が長期化すれば軍費・徴税が問題に[^u068] |
| 1889年 | 下関条約後、「台湾統治例」と賠償金の配分を元老院とともに審議[^u077] |
| 1889年 | 論功行賞では「国民の税金と帝国軍の犠牲による勝利を、なぜ特定の領主家への加増で報いるのか」と反発[^u078] |
| 1889年〜 | 賠償金による国道・鉄道整備は、特定の家への加増ではなく一般の商工業者・住民に利益があるため支持しやすい[^u083] |
| 1890年代 | 対露世論で沸騰しうるが、「帝国予算から全額出せ」となれば冷める[^u088] |
| 1890年代 | 帝国予算の支出に慎重で、英国のための対露戦争の肩代わりは期待できない[^u091] |
| 1914年 | 元老院とともに海軍の限定参戦と臨時軍事費を承認[^n2][^u095]。主要政党が超党派の戦時協力内閣と両院合同戦時政策協議会に参加[^n16][^p006] |
| 1936〜1937年 | 第二次ロンドン会議後の国防費拡大について、元老院・主要政党と合意[^n17][^p009] |
| 1914年〜 | 長期の徴兵や補充兵の海外派遣について、有権者への説明を求める[^u097] |

衆議院は対露論で沸騰しえたが、財源問題で冷めた。政府が臨時軍事費の具体案を示した時点で、対露強硬論は税負担をめぐる対立へ移った。[^u088]

衆議院は元老院とともに首都京都に置かれる。[^u133]

# 史実との比較

* 史実では1874年1月17日、板垣退助・後藤象二郎・江藤新平・副島種臣らが左院に建白書を提出した。有司専制を批判し、納税者の政治参加の権利を説いた。その後、1875年に元老院が設置されたが、帝国議会の開設は1890年まで待たされた。[^u026]
* 史実の衆議院は天皇（内閣）によって解散されえ、議員は閣僚を兼ねられた。本世界線の衆議院には解散がなく、議員は閣僚になれない。史実では1925年に男子普通選挙が実現し、女性参政権は1945年まで認められなかったが、本世界線では男子普通選挙を経ずに1935年頃に男女普通選挙となる。[^p002][^p009]
* 本世界線の建白書は、有司専制ではなく「天皇と諸侯だけで国政を決めてよいのか」という代表制の問題を突く。新しい立法機関を一から作る必要はなく、既存の元老院に衆議院を加えるだけで済むため、史実より約14年早く二院制の帝国議会が成立する。[^u026]
* 幕末段階の構想では、爵位・家格を代表する貴族院と、各領国から選ばれる民選議院の二院制が想定されていた。その際、領主が選挙を支配すれば民選院も領主の影響下に入る危険が指摘されていた。[^u017]

# 編集注：未決の論点

* 議員定数（300は暫定）、選挙区の具体的な区割り、選挙管理機関の形態。[^u026][^p003]
* 制限選挙期の納税要件に、帝国税だけを数えるか領国税も含めるか。[^p003]
* 男女制限選挙（1934年）・男女普通選挙（1935年）の正確な成立年。[^p009]
* 衆議院の予算議決権・予算先議権の有無、元老院との立法権の対等性。[^u026]
* 衆議院が憲法改正に参加できるかどうか。[^u034]
* 建白の具体的な担い手（人物）。史実の板垣らが関わるかどうかは未定。会話ログ3でも人物は決まらず、民権派は全国組織化に失敗して分裂した（ダイス判定：難易度30、出目7・失敗）。[^p004]

# 編集注：却下・修正された案

* **1876年に帝国議会が成立したとする記述**: 前編の年表案では「1876年 第一回衆議院議員総選挙。元老院と衆議院による帝国議会が成立」としていたが、会話ログ3で作者が第一回帝国議会を1867年（元老院のみ）と定めたため、1876年は「帝国議会が二院制になった年」と改めた。[^u026][^p002]
* **設置年の幅**: 「1876年案」と「1870年代中盤」が併存していたが、第一回衆議院選挙は1876年と確定した。[^u034][^p002]
