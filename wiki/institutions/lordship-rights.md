# 概要

**領主権**は、本世界線の日本で旧大名家などの華族家が保持する世襲的な統治権である。1866年の[無血の幕府解体](/events/bloodless-dissolution-1866.md)に際し、朝廷が徳川宗家を含む諸侯の所領を安堵したことに始まり、幕藩体制下の「藩主権」がほぼそのまま「領主権」として認められた。新政府の成立そのものが領主権の保障を前提としていたため、史実の版籍奉還・廃藩置県は起こらず、[近代封建制](/concepts/modern-feudalism.md)と呼ばれる国制の中核となった。[^u015][^u017]

領主権は中央政府から委任された行政権ではなく、朝廷に安堵された**固有の世襲権**とされる。1868年の[廃藩置国](/institutions/kokugun-system.md)で国・郡・村単位に登録され、1869年の[大日本帝国憲法](/institutions/imperial-constitution.md)のもとでは行政・徴税・警察・司法を含む、ほぼ「領邦主権」に近い包括的な権利として保障された。一方、外交と軍事は早くから中央へ移り、領主権は「軍隊を持たないが警察と裁判所を持つ」独特の権利として発展した。[^u021][^u036]

1870年代にはアメリカ連邦制を参照した再定義が進み、領主権は「朝廷から安堵された世襲的権利」から「憲法が保障する統治権」、さらに「世襲領主を長とする地方政府の自治権」へと性格を変えていく。領主権は廃止されず、全国共通法・司法・標準化・財政制度によって徐々に枠づけられ、戦間期には帝国財政と並立する「領国財政」と、元老院が承認する「諸侯の法定拠出」という形で存続している。[^u045][^u126]

# 法的性格

## 固有権としての領主権

領主権の性格を決定づけたのは、1866年の政権移行の論理である。朝廷は「天下の土地は究極的には天皇のものだが、各家の封土は従前どおり安堵する」という伝統的な封建の論理をとった。したがって藩主を中央任命の官僚（史実の知藩事型）に転換することは、新政府が自らの成立時の約束を破ることを意味した。[^u017] 1869年の段階でも、わずか数年前に保障した権利を「地方行政を担当する権利にすぎない」と宣言し直すことは政治的にも法的にも難しく、**領主権は中央政府から委任された行政権ではなく、朝廷によって安堵された世襲的な固有権限**とされた。[^u036]

## 国・領主権・領地の区別

廃藩置国により、次の三概念が区別される。[^u021]

| 概念 | 意味 |
|---|---|
| 国 | 全国共通の地方行政・地理区画（律令国） |
| 領主権 | 朝廷が各華族家に認めた世襲的統治権 |
| 領地 | 国・郡・村によって表示される具体的な支配地域 |

この区別により、一国に複数の領主が存在でき、一つの家が複数国にまたがる領主権を持つこともできる。後には「律令国は領土の区分単位であり、領主権はその区域の全部または一部について設定される別個の権利」と定式化された。[^u021][^u066]

## 爵位との分離

領主権は[華族](/institutions/kazoku-system.md)の爵位とは別個の権利として法制化された。公爵でも無領の家（旧摂関家、弾正尹公爵家）があり、伯爵でも大所領を持つ家がありうる。臣籍降下した皇族も、領地を与えられない限り地方統治権を持たない。[^u021][^u024]

# 変遷

## 前史：那珂川家への授封（1861年）

幕末の1861年、旧水戸徳川家の所領（35万石）に対し、還俗・臣籍降下した公現法親王を祖とする[那珂川公爵家](/people/nakagawa-ducal-house.md)が創設された。当初は幕府派遣の役人が統治する名目的な領主だったが、1866年の幕府失権後に実質的な領主権を取得し、名実ともに大領主となった。那珂川家の領主権は「徳川家に由来せず、朝廷の権威によって直接保証された領主権」であり、新政府も容易に否定できない一方、後の中央集権化の障害にもなりうる特殊な存在である。[^u018]

## 1866年：所領安堵

家茂の死後、朝廷は軍権を一時預かりとし、諸侯に所領安堵を通達した。架空の勅命の骨子は「諸侯は従前の封土を安堵され、軍兵は各々部署を守り、私に軍を動かすべからず」である。所領安堵は諸侯ごとに異なる意味を持った。[^u015]

| 諸侯 | 所領安堵の意味 |
|---|---|
| 雄藩（薩摩・土佐・越前など） | 徳川家を介さずに中央政治へ参加できる |
| 一般の外様 | 従来の領国支配を維持できる |
| 親藩・譜代 | 徳川家への忠誠と家の存続を切り離せる |
| 幕府依存の小藩 | 新政府での待遇保障と引換えに協力 |
| 徳川宗家・御三卿 | 将軍職を失っても家名と所領を保持 |

安堵の交換条件（検討案）は、朝廷が所領・家格・藩主家の存続・家臣の身分俸禄の当面保障・中央政務への参加を保障し、諸侯は新政府への服属・外交権の一元化・全国軍費の負担・藩兵の一部の国家軍への移管を受け入れる、というものである。[^u016]

ここに本世界線の根本的な逆説がある。所領安堵によって幕府解体には成功したが、**諸侯の世襲領国支配はむしろ強く保障され、廃藩置県に相当する改革は一層困難になった**。中央政府には諸侯の領地を一方的に没収する権限がない。[^u015] 「政権交代は史実より穏やかに進む一方、封建制度の解体は史実よりはるかに長期化する」。[^u017]

1866年直後の権限配分の見通しは次のとおりである（検討案）。[^u017]

| 権限 | 帰属先 |
|---|---|
| 領地の世襲・家督相続 | 旧大名家（朝廷の承認を要する） |
| 領内の一般行政 | 旧大名家 |
| 地方税の徴収 | 旧大名家（中央への納付義務あり） |
| 地方の司法・警察 | 当面は旧大名家 |
| 外交・条約締結 | 中央政府 |
| 国家常備軍の統帥 | 朝廷の権威に基づく中央政府 |
| 諸侯の独自軍事行動 | 原則禁止、または許可制 |

## 1867年：明治改元と領主権令

1867年2月13日の[明治改元](/events/meiji-era-proclamation-1867.md)と同日に、軍権の朝廷帰属を確認し「諸侯は旧来の封土を安堵され」と明記する勅命を出す構成が想定されている（検討案）。これにより1866年の安堵が新天皇のもとで再確認され、徳川幕府を否定せずに所領と家格の存続が説明される。「明治が始まっても、日本は依然として領主たちによって分割統治されている」。[^u020]

明治元年春には、華族令と並んで**領主権令**が公布される（時期・名称は検討案）。その内容は、世襲領主権、所領安堵、領主の義務、領主権の裁定の四点である。同年、朝廷は太政官のもとに[領主権裁定院](/institutions/lordship-tribunal.md)を置き、境界・相続・交換・国司との紛争を裁定する唯一の上位機関となった。さらに[弾正台](/institutions/danjodai.md)が領主本人を含めて監察するが、領主権の停止・剥奪には特別な審理と勅裁を要するとされた。[^u022][^u023][^u024]

この段階の政治秩序は「**領主権を温存することが、逆に中央政府の権威を強める**」と要約される。朝廷は諸侯の所領を奪うのではなく保護する政府として自らを位置づけ、諸侯にとって朝廷政府の維持が自らの権利を守る合理的選択となる。[^u022]

## 1868年：国郡単位での登録

1868年（明治2年）の廃藩置国で、藩は行政単位として廃止され、領主権は律令国単位で設定し直された（名称・年は検討案、内容は確定）。複数国にまたがる藩主は従前どおり複数国の領主権を持ち、複数藩にまたがる国や一国未満の小藩は分割または協議で処理する。島津家の場合、薩摩国・大隅国・日向国の一部の領主権を一体として保持しつつ、報告・課税基準・裁判管轄は国ごとに整理される。[^u021]

この登録によって、**領主権の根拠は徳川幕府から朝廷へ移った**。日本は「幕府が認めた藩の集合体」から「朝廷が領主権を配分する律令国の集合体」へ移行した。飛地や錯綜所領は当面そのまま登録され、争いがあれば裁定院が調整する。裁定の過程で石高・村数・税収・境界・継承関係が中央に蓄積され、後の税制・地籍・司法改革の基礎となる。[^u021][^u022] 法令上は当初「封土令」が構想されたが、法体系の整理により「封土例」とその施行規則「封土式」へ置き換えられた（検討案）。[^u031][^u032]

## 1869年：憲法下の領主権

1869年（明治3年）頃に詔で公布された大日本帝国憲法は、天皇と諸領主の合意によって成立した「国制協約」的な憲法であり、その推進主体は自らの統治権の保護を求める諸領主であった。諸侯は天皇に無限の権限を認めることはできず、最も警戒したのは「天皇の名を借りた太政官が勅命一つで領主を討伐できる制度」であった。[^u025][^u034]

この時点の領主権は**行政権だけでなく治安権・司法権も含むかなり強いもの**であり（確定）、ほぼ「領邦主権」に近い。[^u036]

| 権限 | 領主 | 帝国中央政府 |
|---|---|---|
| 一般行政 | 原則として領主 | 全国共通事項 |
| 徴税・地方財政 | 領内の徴税と予算 | 国税・軍費負担 |
| 警察・治安維持 | 領主直属の警察・警備隊 | 広域治安・国家安全保障 |
| 民事裁判 | 領主の裁判機関 | 跨領事件・上訴・共通法 |
| 刑事裁判 | 通常犯罪の審理・処罰 | 国家犯罪・重大事件・上訴 |
| 官吏任免 | 領内官吏を領主が任命 | 中央官吏・国司の任命 |
| 軍事 | 限定的な領内警備 | 帝国陸海軍・対外戦争 |
| 外交・条約 | 原則なし | 帝国中央政府 |

[^u036]

領主は単なる知事ではなく、自領に行政官を置き、税を徴収し、警察を動かし、裁判所を設置できる。一方で独立国家ではないため、外交と本格的な軍事権は中央に属する。ドイツ帝国の構成邦に似るが、領邦の境界が律令国と一致せず一国に複数領主が存在しうる点が大きく異なる。[^u036]

### 憲法の領主権条項（検討案）

仮想条文として次のものが示されている。[^u025][^u036]

* 第三条（基本条項案）「諸侯ノ世襲領主権ハ帝国ノ保障スル所トシ、法律ニ定ムル場合ヲ除ク外、之ヲ侵スコトヲ得ス」
* 第十一条「帝国諸侯ノ世襲領主権ハ、此ノ憲法及例ノ定ムル所ニ依リ、之ヲ保障ス」
* 第十二条「領主ハ其ノ領内ニ於テ、行政、徴税、警察及司法ノ権ヲ行フ。但シ帝国ノ憲法及例ニ違背スルコトヲ得ス」
* 第十三条「帝国ノ外交、国防及全国軍ノ統轄ハ、中央政府ノ専管トス」
* 第十四条「領主権ノ境界、相続及其ノ他ノ争議ハ、法定ノ裁定機関之ヲ審理ス」
* 第十五条「領主権ノ停止、剥奪又ハ変更ハ、憲法ニ定ムル手続ニ依ルニ非サレバ、之ヲ為スコトヲ得ス」

第十一条の「例ノ定ムル所ニ依リ」を広く解釈すれば通常の立法で領主の司法権・警察権を大幅に縮小できるため、諸侯は領主権の基本内容を憲法で直接保障し、その変更には[元老院](/institutions/genroin.md)の領主議員の特別な同意を要求すると考えられる。元老院の議決要件案でも、領主権の一般的変更には特別多数に加えて領主議員の過半数、個別領主の所領変更には当事者の同意または特別裁定手続が必要とされる（「二重の保障」）。[^u026][^u036]

### 領主の司法権と帝国の法秩序

領主の裁判権は認められつつ、帝国法による制約が課される。例として、那珂川家領で殺人事件が起きれば第一審は那珂川家の裁判所が担当するが、明白に全国共通の刑法に反する判決は帝国の上級裁判所へ上訴でき、領主が政敵を恣意的に投獄すれば弾正台が調査する。役割は、領主裁判所＝領内の通常事件、帝国裁判所＝帝国共通法の事件・領主間事件・法定の上訴事件、弾正台＝違法な権力行使の調査と訴追、と分担される。ただし1869年の時点で全国共通刑法や上訴制度が完成しているとは限らず、初期は各領主の従来法を認め、越境事件や領主権争いから中央司法の管轄を広げていく。[^u036]

### 領民からの批判

領主が立法・行政・警察・司法を握る体制は、人民の側からの批判を生む。1874年頃の[民撰議院設立建白書](/institutions/house-of-representatives.md)は「すでに存在する立憲政治に人民も参加させよ」という要求であり、その論点の一つは「領主が立法・行政・警察・司法を握っているのに、領民はその領主を政治的に統制する手段が乏しい」ことにあった。自由民権運動は「領主のための憲法」を「臣民のための憲法」へ改める運動となり、憲法が保障する世襲領主権と、衆議院が求める法の下の平等・司法の独立が長期的な争点となる。[^u035][^u036]

## 1870年代：権限の切り分け

### 軍事権の分離

領主権が存続しても、軍事権まで残るとは限らない。1861年の公武協定以来、全国常備軍の整備が先行していたことに加え、近代常備軍を維持できる領主は少なく、独自軍の維持費と国への軍費の二重負担は合理的でない。このため1870年代に各領主は軍事費負担を金納化して独自軍を縮小し、1880年代には国軍が対外防衛をほぼ独占、領主には警察と限定的な警備組織だけが残る（確定した方向性、年代は検討案）。大領主の競争は軍事力そのものではなく、将官の輩出、兵器・艦船の受注、軍学校への人材送り込み、軍事予算への影響力をめぐるものとなった。「領主制は残っているが、軍隊はすでに近代的な国民国家の軍隊になっている」。[^u030] 1869年憲法は諸領主との合意によって統一軍を維持する立憲体制であり、帝国軍の権限は天皇個人の不可侵の統帥大権ではなく憲法で構成された国家機関の権限とされた（[統帥権](/institutions/supreme-command.md)参照）。[^u124]

### 外交権の分離

外交権もまた領主権から切り離された。対朝鮮外交を家役として世襲してきた[対馬宗家](/diplomacy/tsushima-so-clan.md)の扱いでは、「**奪うのは領主権ではなく外交権**」と整理された。1866年の所領安堵を破棄せずに済み、対馬の世襲領主権は憲法で保障されたまま、国書の作成・発給や日本国代表の派遣は中央政府が接収する。原則は「諸侯の領主権は保障する。しかし、外国との交渉は帝国政府の専権である」。他の領主にとっても、宗家の領主権と朝鮮外交特権は別物という論理は自らの領主権を守る論理として支持できたため、元老院で宗家は孤立した。仮想法令「外交事務統一例」（1868年）は、諸侯が委任なく外国と国交を結ぶことを禁じ、家役廃止で失う既得権には別に例で補償を定めるとする（検討案）。[^u038][^u039]

### 全国標準化

大領主間の産業競争が激しいほど、領国を越える通商のための標準化圧力は高まる（確定）。度量衡、貨幣・銀行制度、関所・通行税の廃止、鉄道の軌間、郵便・電信、商事法・契約法、特許・工業規格が元老院で統一されていく。原則は「経営主体は分散していても、制度と規格は全国共通」、司法では「商事法は全国共通、裁判所は領主ごと」である。元老院は「領主権を守る機関」であると同時に「領主権を維持したまま全国市場を統一する機関」となった（詳細は[全国標準化政策](/institutions/national-standardization.md)）。[^u044]

### 連邦制受容による再定義

領主権を残したまま全国市場と国軍を統一するうえで、アメリカ連邦制はドイツ以上に実務的な参考とされた（確定）。南北戦争が回避されたアメリカでは州権が史実より強く残っている可能性があり、領主たちは「これほど広い自治権を各州に認めても、全国共通の通貨・郵便・商取引制度を運営できる」と見て、それを領主権存続の論拠とした。[^u045]

岩倉使節団に参加した領主議員が帰国後に提案する憲法改正条項として、次の三つが想定されている（検討案）。[^u045]

| 条項 | 文案 |
|---|---|
| 帝国通商条項 | 帝国ハ諸領主ノ領地相互ノ通商、外国貿易、貨幣、度量衡、郵便及全国交通ノ規格ヲ統一スル権ヲ有ス |
| 領主権留保条項 | 此ノ憲法ニ依リ帝国ニ属セシメザル権限ハ、各領主ニ留保セラル |
| 帝国法優越条項 | 帝国憲法及之ニ適合シテ制定セラレタル例ハ、諸領主ノ法ニ優越ス |

領主たちは自治を守るためにこそ、中央政府の権限を明確に定義することを支持する。その結果、領主権の性格は次のように変化する（詳細は[アメリカ連邦制の受容と領主権の再定義](/institutions/federalism-reception.md)）。[^u045]

1. 朝廷から安堵された世襲的権利（1866〜1869年）
2. 憲法によって保障される統治権（1869年憲法以降）
3. 世襲領主を長とする地方政府の自治権（衆議院成立後、住民参加の導入とともに）

領主権は消滅しないが、その権限は憲法と法律によって制限され、領内行政にも住民参加が導入されていく。[^u045]

### 司法権と条約改正

条約改正の条件としても、鍵は全国一律の裁判所ではなく、「外国人にも適用される帝国共通法と、領主の判決を帝国裁判所が審査できる仕組み」であった。英国商人が島津領と徳川領で異なる扱いを受けるなら、列強は領事裁判権の撤廃に慎重になる。[^u046] 長期的に領主権の最大の争点は司法権であり、軍事は統合され、徴税は中央への一定額の納付で妥協できても、裁判官を任命し住民を裁く権利は領主を実質的な統治者にとどめる。商事事件・越境事件から帝国裁判所の権限が拡大し、やがて刑事・領内民事にも共通手続が求められる。「**領主権の衰退は軍事権の喪失よりも、司法権の統一によって進む**」。[^u036]

## 奉還と二極化

財政難の小領主の中には領主権を返上する者が出る（確定）。返上者は爵位・家格を保ち、年金・公債などの補償を受ける（[領主権奉還](/institutions/lordship-surrender.md)）。他方で島津・毛利・徳川・那珂川などの大領主は領主権を維持し、中小領主は大領主を寄親として改革に参加する（[寄親・寄子制](/concepts/yorioya-yoriko.md)）。この結果、1880〜90年代には律令国のかなりの部分が直轄地となり、薩摩・長州・旧徳川領・那珂川領などに強い領主権が残る政治地図が想定される（検討案）。[^u027][^u028]

## 1880年代：新領土と論功行賞

新領土の取得は、「国内の世襲領主権を保障しているのに、新しく獲得した土地には領主が存在しない」という問題を生んだ。国と領主権を分けているため、新領土に必ずしも領主権を設定する必要はなく、統治は世襲領主領・帝国直轄国・帝国特別領の三類型で整理される。1866年に保障されたのは既存諸侯の世襲領主権であって新領土の分配請求権ではない、という論理から「新領土はまず帝国直轄、必要に応じて授封」が基本方針とされた（北海道は開拓負担を引き受ける家に領主権設定あり、樺太は直轄、台湾は帝国特別領）。開拓事業の委託と世襲領主権の授与は別手続きとされ、新領主権の設定と叙爵・議席付与は天皇と元老院の共同承認とする案がある（検討案。詳細は[新領土の統治制度](/institutions/new-territory-governance.md)）。[^u066]

[日清戦争（1887〜1889年）](/events/sino-japanese-war.md)後の[論功行賞](/events/reward-distribution-1889.md)では、1867年以来領主権を整理してきた国家が、再び「誰に何万石を与えるか」で揉めるという皮肉が生じた。領主議員の議席が領主権の規模に連動するなら、加増は元老院の力関係を変える行為となる。最終的には台湾・澎湖を帝国直轄とし、領主家には新領地ではなく陞爵・金銭・国家事業の機会を与える近代的な論功行賞が主流となり、加増・新規授封は例外に限られる（検討案）。[^u078]

戦後の[帝国交通整備計画](/economy/transport-plan.md)でも、領主権は憲法で保障された権利であるため中央が一方的に用地を取り上げることはできない。元老院が制定する「帝国交通例」は、国道・幹線鉄道を帝国の公共事業と定め、用地の適正補償、領主による恣意的な通行税の禁止、領国の地方交通網の管理権の存続を規定し、領主議員自身が合意した「諸領主による共同の国家事業」として正当化される（検討案）。こうして「領主権を取り上げずに、領主たち自身の利益によって経済統合を進める」道が開かれた。[^u083]

## 戦間期：領国財政と法定拠出

1920年代の日本には、帝国政府の財政とは別に、領主の固有財政（領国財政）が存在する。軍事支出には「諸侯の負担枠」があることが確定しており、それは個々の領主が兵を提供する方式ではなく、**元老院が承認した法定拠出制度**として設計される（検討案）。領国の課税能力に応じて拠出額を決め、帝国軍の共通財源に組み入れる。拠出は特定の領主の軍隊を維持するためではなく帝国の統一軍を支えるためのものであり、負担率や算定基準を元老院で決めることで、領主の固有行政に対する中央の恣意的な課税を防ぐ。徴兵・宿営・用地・輸送施設の提供など領国側の現物負担も国防費として評価しうるが、二重計上に注意を要する。[^u126]

1920年の帝国財政モデル（中核ケース、億円／年、検討案）は次のとおりである。[^u126]

| 項目 | 金額 |
|---|---|
| 帝国固有の税・事業収入 | 23.5 |
| 諸侯の帝国への法定拠出 | 2.5 |
| 帝国の恒常歳入合計 | 26.0 |
| 諸侯に残る地方財政収入 | 9.0 |
| 帝国・領国の連結歳入（拠出の二重計上なし） | 35.0 |

連結歳入は国民所得200億円の17.5％にあたる。年間軍事費10億円は国民所得の5％にすぎないが、帝国歳入26億円の約38％を占め、帝国政府にとっては大きな支出項目となる。これは領主制が残るこの世界ならではの財政制約である。[^u126] 財政の詳細は[帝国財政と諸侯の法定拠出](/economy/imperial-finance.md)を参照。

このほか戦間期の領主権は、次のような形で国政に影響している。

* **領主系資本**：大領主の企業集団は1870年代以来継続して機械工業・製鉄へ投資し技術を蓄積したが、独占契約や公共調達の優遇を求めて全国的効率を妨げることもある。1930年には領主系資本の再編・独占規制が経済政策の課題となる。[^u132]
* **対外金融**：元老院の領主系銀行・企業代表議員が中国の軍閥債券など海外債権の保護を求め、日本が金融を通じて中国の内戦に巻き込まれる経路となる。[^u106]
* **災害と共同負担**：関東大震災では被災地の領主・地方行政が一次的な救済責任を負い、中央政府が広域交通・金融・港湾の復旧を支援する。複数領国にまたがる被害には、元老院を通じた共同負担制度が重要となる。[^u133]

# 史実との比較

* 史実では1869年の版籍奉還で藩主の世襲的領主権が否定されて非世襲の知藩事となり、1871年の廃藩置県で地方支配そのものが解消された。本世界線ではこの転換が起きず、領主の地位を守ったまま、経済の発展と全国共通法の普及によって統治権が徐々に法的制約を受ける。[^u017][^u036]
* 史実の華族は1889年憲法のもとで貴族院を通じて国政に参加する名誉的貴族であったが、本世界線の旧大名系華族は地方の財政・行政・住民を統治する領主であり、元老院では「家ごとの代表」として領主権を代表する。[^u017][^u025]
* 比較対象としてはドイツ帝国の構成邦（ただし構成邦が軍を保持した点で異なる）と、アメリカの州（連邦法優位と州の自治）が挙げられる。[^u030][^u045]
* 「1890年代には強大な統一帝国軍を持ちながら、国内ではなお世襲領主が警察・裁判所・行政機構を保持している」という、史実にない立憲国家像となる。[^u036]

# 却下・修正された案

* **領主系予備軍を含む三層軍制**：帝国常備軍＋領主系予備軍・郷土防衛軍＋領主系軍需企業という案は、常備軍を維持できる領主は少なく大領主も国軍の一翼として自軍を維持するとは限らないとの指摘で撤回され、領主は独自軍を持たず軍費を金納し国軍が軍事を独占する設定に改められた。[^u029][^u030]
* **一国一領主への早期整理**：廃藩置国にあたり錯綜所領を早期に整理する方向は、紛争が起きるまで国を分割しない方式に修正された。[^u022]
* **封土令**：令の体系の一部として領主権を「封土令」で定める案は、法形式を詔・勅・例・式に整理する方針により「封土例」へ置き換えられた。[^u031][^u032]
* **行政実務の中央委任型**：旧大名が世襲権と収入を維持しつつ行政・司法・徴税の実務を中央へ委任する制度も可能性として示されたが、その後の議論では1869年の領主権は行政・警察・司法を含む強い権利とされ、実務委任は小領主の国司への行政委託や奉還という限られた形でのみ採用されている。[^u017][^u021][^u036]

# 未決の論点

* 領主権の基本内容を憲法で直接保障するか、「例」に委ねるか。[^u036]
* 国司が領主の命令を取り消せるか、帝国裁判所の設置時期と上訴範囲、全国共通刑法の制定時期。[^u021][^u036]
* 元老院の領主議員の議席数が領主権の規模に連動するか（加増の政治的意味に関わる）。[^u078]
* 1866年の安堵の範囲が徴税・裁判・家臣人事まで含むか（行政権移管時の補償の要否）。那珂川家の1861年の授封条件も同様。[^u018][^u021]
* 衆議院成立後、領内行政への住民参加（領内議会など）がどのような制度で導入されるか。[^u045]
* 諸侯の法定拠出の算定基準と負担率の具体的な数値（1920年モデルは検討案）。[^u126]
