# 概要

**功績叙爵**は、華族でない者を国家・社会への功績によって新たに華族に列する制度である。1867年の[華族令](kazoku-ordinance-1867.md)は既存の公家・武家を再編しただけで功績による叙爵者を出さなかったため、本世界線の最初の功績華族は1889年の[日清戦争](../events/sino-japanese-war.md)後に生まれた。[^p013][^p025]

本世界線の功績叙爵は、史実のような軍人・官僚中心の功績貴族ではなく、**独立系実業家と学者・教育者・医師を積極的に取り込む制度**として発展した。旧公家による叙爵制限運動は成立せず、1920年代以降も基準は厳格化されなかったため、史実では大正期にほぼ止まった華族の拡大が昭和期まで続いた。1867〜1937年の新規叙爵は**累計360家**（実業168・学術教育92・軍事53・官僚27・その他20）に達する。[^p025][^p082][^p096]

新規華族は原則として領主権を持たない無領華族であり、元老院の無領華族互選の選挙人となる。功績叙爵は「元老院の首班指名に間接的に参加できる世襲的な政治資格の付与」という意味を持ち、無領華族の急増は1924年・1936年の元老院定数改革を引き起こした。1937年には実業家華族141家が無領華族の家産の約89%を握る。[^p024][^p026][^p096][^p097]

# 制度の成立

## 叙爵を促進・抑制した事情

| 促進要因 | 抑制要因 |
|---|---|
| 朝廷による領主勢力への対抗の可能性 | 維新功労者への叙爵が存在しない |
| 独立系実業家の成長 | 日露戦争が起きない |
| 日清戦争（1887〜1889年）の勝利 | 勅選議員制度で人材登用ができる |
| 第一次世界大戦での功績 | 既存華族による互選資格の希薄化への反発 |
| 官僚・外交官・学者の活躍 | 勲章・位階で代替できる |

[^p024]

元老院の無領華族互選の定数が固定されているため、新規叙爵は既存の無領華族にとって自らの票の価値を薄めるものであり、既存華族は必ずしも新規叙爵に好意的ではなかった。また、新規叙爵（家数・有権者数が増える）と既存華族の陞爵（爵位別の構成だけが変わる）は区別される。[^p024]

## 叙爵政策の展開（1889〜1937年）

1889年以降の叙爵政策をめぐる主な論点と、その帰結は次のとおりである。

| 判定項目 | 結果 | 帰結 |
|---|---|---|
| 日清戦争後に非華族の軍人・官僚への功績叙爵が制度化される | 成功 | 1889年以降に制度化 |
| 日清戦争後に大規模な一斉叙爵が行われる | 失敗 | 少数の功労者に限定 |
| 既存華族の分家に対する新規叙爵が広く認められる | 失敗 | 原則として認めない |
| 高級官僚・外交官への功績叙爵が恒常化する | 失敗 | 特別な功績がある場合に限定 |
| 独立系実業家への叙爵が積極的に行われる | 際立った成功 | 経済界からの積極的な登用 |
| 学者・教育者・医師等への功績叙爵が普及する | 成功 | 広く叙爵対象となる |
| 第一次世界大戦後に大規模な功績叙爵が行われる | 成功 | 戦後に大規模な叙爵 |
| 朝廷が領主勢力への対抗手段として新規叙爵を活用する | 失敗 | 政治的叙爵には利用されない |
| 旧公家系華族による新規叙爵制限運動が発生する | 完全な失敗 | 制限運動は成立しない |
| 1920年代以降、新規叙爵の基準が厳格化する | 失敗 | 昭和期も功績叙爵が継続 |
| 新規叙爵と新規授封は原則として別個のものとする慣行が定着する | 成功 | 新規華族は原則として無領華族 |

[^n1][^p025]

## 1889年の最初の功績華族

日清戦争後、領主への加増、新規授封、非華族への叙爵がまとめて議論されたが、両院間で規模や基準について合意が成立しなかった（[日清戦争後の論功行賞](../events/reward-distribution-1889.md)）。その結果、功績叙爵の制度そのものは認められたが、実際に叙爵された者は少数に限られた。史実の日清戦争後の新規授爵約36家に対し、本世界線では1889〜1893年の**20家**にとどまる。これが最初の功績華族である。[^p005][^p025]

| 報償の種類 | 日清戦争後の扱い |
|---|---|
| 既存領主への加増 | 強い政治的反対を受ける（北海道での加増は実施） |
| 既存華族への陞爵 | 個別に実施 |
| 非華族への新規授爵 | 特に顕著な功績を挙げた者に限定 |
| 新規授封 | 例外的なものに限定 |
| 勲章・位階 | 広く授与 |
| 金銭・年金 | 一般的な報償手段 |

[^n3][^p025][^p034][^u078]

## 叙爵と授封の分離

新規叙爵と新規授封を原則として別個とする慣行が定着したため、功績華族は原則として領主権を持たない。例外は北海道開拓の功労者で、非華族の開拓功労者に叙爵と授封を同時に行って新領主家を立てた例が11家ある（[新規授封と加増](new-enfeoffment.md)）。これらは功績叙爵360家とは別枠で数える。[^p025][^p034]

# 叙爵の対象

## 実業家華族

独立系実業家への叙爵がきわめて積極的に行われたことで、領主系資本家とは別の経済貴族層が形成された。ただし朝廷が新規叙爵を政治的に活用することはなかったので、これは朝廷が意図的に反領主勢力を育てた結果ではなく、**産業振興・経済発展への貢献が独立した社会的功績として認められた結果**である。実業家華族の政治的立場は一様でなく、領主系企業と協力する家も多い。[^p025]

叙爵は資産額ではなく、国家・社会への貢献を名目とする。[^n4][^p025]

| 功績分野 | 評価対象 |
|---|---|
| 製造業 | 大規模な産業の創設・技術革新 |
| 海運 | 国際航路・商船隊の整備 |
| 金融 | 金融機関の創設・産業金融 |
| 貿易 | 海外市場の開拓 |
| 鉄道 | 交通網の整備 |
| 電力 | 発電・送電事業の普及 |
| 鉱業 | 資源開発・精錬技術 |
| 公益事業 | 教育・医療・社会事業への貢献 |

## 学術・教育華族

学者・教育者・医師への叙爵が普及し、資産規模では説明できない華族層が成立した。対象は医学（感染症対策・公衆衛生・医学研究）、理工学（新技術・工業化）、教育（大学・学校の創設、教育制度の整備）、法学（法体系・司法制度の整備）、農学（農業生産性の向上）、人文科学（学術・文化）に及ぶ。中等教育・職業教育の普及とも整合する。[^p025]

## 軍人・官僚

日露戦争が起きないため大量の軍人華族は生まれず、軍人の叙爵は日清戦争後と第一次世界大戦後に集中する。高級官僚・外交官は長期勤務だけでは爵位を得られず、特別な功績が必要とされた。このため元老院への専門人材の登用は、引き続き勅選議員制度が担った。[^p024][^p025]

## 初叙爵の爵位

功績華族は原則として男爵から始め、その後の特別な功績で陞爵する。初叙爵の爵位別の家数は次のとおりである。[^n6]

| 初叙爵 | 家数 | 主な対象 |
|---|---:|---|
| 公爵・侯爵 | 0 | 新規の功績叙爵では原則授与しない |
| 伯爵 | 5 | 極めて顕著な国家的功績 |
| 子爵 | 45 | 大規模な産業創設・特別な功績 |
| 男爵 | 310 | 一般的な功績叙爵 |
| **計** | **360** | |

[^p025]

1867年の華族414家に新規360家を加えると、陞爵・断絶を反映しない爵位別構成は公8・侯24・伯48・子198・男496の774家となる。[^p028]

## 金融危機と爵位返上

平時の経済的困窮による爵位返上はほとんど起きなかったが、1927年以降の[金融危機](../events/financial-crisis-1927.md)では多数の実業家華族が爵位を返上した。実業家への叙爵が産業・金融への貢献を根拠とする以上、経営する銀行・企業の破綻は爵位保有の正当性に関わる問題となった。返上は企業破綻で自動的に起こるものではなく、社会的責任、債権者との和解に伴う家産制度の解体、事業再建の優先、名誉を維持できないという当主の判断による例外的な行為である。[^p035]

| 判定項目 | 結果 | 帰結 |
|---|---|---|
| 経済的困窮による爵位返上が一定数発生する | 失敗 | 平時にはほとんど発生しない |
| 1927年以降の金融危機で多数の実業家華族が爵位を返上する | 成功 | 1927年以降に集中 |

[^n7][^p035]

返上した実業家華族は**27家**（累計叙爵168家の16.1%）で、1937年に存続する実業家華族は141家となる。[^p035][^p096]

功績華族は存続分で計333家となり、無領華族の約64%を占める。創設時の旧公家系は4分の1に縮小し、無領華族互選は朝廷勢力の代表枠から、多様な経済的・社会的エリートの代表枠へと変質した。[^p025][^p078]

実業家華族141家の純資産は299.04億円で、民間純資産1,680億円の17.8%、無領華族521家の純資産336億円の約89%に当たる。一方、学術・軍人・官僚系の功績華族は資産家というより専門職・給与所得者に近く、当主の退職・死亡後に家門収入が大きく落ち込みうる（[国民資産と富の所有構造](../economy/national-wealth-1937.md)）。[^p083][^p096]

| 判定項目 | 結果 | 帰結 |
|---|---|---|
| 実業家華族が企業株式を家門財産として長期的に保有する | 成功 | 株式の家産化 |

| 実業家華族の間で専門経営者への経営委任が普及する | 成功 | 所有と経営の分離 |
| 学術・軍人・官僚系華族が就業所得や恩給から家産を蓄積する | 失敗 | 家産の蓄積は乏しい |
| 無領華族の間で共同金融・家産管理組織が発達する | 際立った成功 | 華族共済会の成立[^n9] |
| 無領華族の間で専門的な信託・資産運用が普及する | 失敗 | 共同出資・内部管理が中心 |
| 第一次世界大戦の経済成長が実業家華族の家産形成を大幅に促進する | 失敗 | 設備投資・戦後反動・株価下落で長期資産化せず |
| 1927年以降の金融危機で存続実業家華族の家産が保全される | 失敗 | 存続家も家産を毀損 |
| 金融危機後に有力実業家華族への資産集中が進展する | 失敗 | 多数の企業集団が並立 |
| 非実業家系華族の多数が家産所得のみで家門を維持できる | 失敗 | 共同金融への依存 |
| 実業家華族と非華族実業家の間で大きな経済格差が形成される | 成功 | 大資本の所有は華族に集中 |
| 領主系企業と独立系企業の恒常的な共同出資関係が発達する | 成功 | 共同出資企業の発達 |

[^n8][^p083]

その結果、「家門が企業を所有し、専門経営者が事業を運営する同族企業集団」が広く成立した。家門自治権によって株式を家産に組み入れて世代を越えて保有できることも、この形を支えた（[家門自治権と家門司法権](family-autonomy.md)）。成功した非華族の実業家は実業功績叙爵によって華族に移るため、非華族の大資本は育ちにくい。[^p082][^p083][^p084]

1937年の独立系実業家華族を代表するのが、三井・岩崎（三菱）・住友・安田・古河・日本石油系・日本窒素（野口家）・大倉の八企業集団で、中核家門の純資産は計101.0億円（実業家華族全体の約33.8%）である（[独立系企業集団と資本系統](../economy/business-groups-1937.md)）。岩崎家は土佐山内家系海運会社の経営者から独立した実業家華族とされる。[^p086][^p096]

# 政治的影響

## 旧公家との結合

旧公家による叙爵制限運動がまったく成立しなかったのは、旧公家（家格・朝廷人脈・文化的権威）と実業家華族（資本・企業・経済界の人脈）が婚姻・共同出資・文化事業・政治協力で結びつき、新しい無領華族社会を形成したためと解釈される。実際に旧公家と実業家華族の婚姻・経済的連携は広く発達した。[^n10][^p025][^p026]

## 元老院の会派と改革

| 判定項目 | 結果 | 帰結 |
|---|---|---|
| 実業家華族が独自の恒常的な元老院会派を形成する | 成功 | 強固な経済界の代表勢力 |
| 学術・教育系華族が独自の政治会派を形成する | 成功 | 学術系会派の成立 |
| 無領華族の増加によって元老院の議席配分改革運動が発生する | 成功 | 改革運動の中心は無領華族自身 |
| 1924年までに華族互選議員の増員が実現する | 際立った成功 | 1924年に華族互選70→100 |

[^n11][^p026]

定数が不変のままなら、1937年の議席／有権者比は領主互選が無領華族互選の5倍を超えるところだった。新華族の急増を受けて元老院は1924年に華族互選を70から100へ、1936年に110へ増員し、同時に家門自治権などの身分上の特権を領主から全華族へ広げた（[元老院の構成と互選制度](genroin-composition.md)）。1936年の元老院では商工業系の倶楽部（交友倶楽部・興業会）が無領華族の実業家を多く抱える（[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)）。[^p025][^p026][^p078]

# 編集注：却下・修正された案

* **日清戦争後の功績華族「8〜15家程度」**：大規模な一斉叙爵の失敗（P25）を受けて示された推計値。家数の確定集計（P36）で1889〜1893年の新規叙爵が20家とされたため、こちらに統一した（作者確定）。[^p025]
* **新規叙爵の規模シミュレーション（0〜300家）**: ダイス判定前に、1937年の無領華族を198家＋新規叙爵0〜300家とする6通りのモデルが比較された。判定の結果、360家の推計に置き換えられ、のち確定値とされた。[^p024][^p025]
* **1937年の無領華族558家**: 新規授封・断絶・爵位返上を反映する前の値。断絶9家・平時の返上1家・金融危機による返上27家を差し引き、521家に修正された。[^p025][^p035]
* **無領華族家産の集中モデル**（巨大実業家華族20家184.80億円など、上位100家で85%）: 判定前の参考モデルで、危機後の資産集中が失敗したため上記の配分に修正された。[^p082][^p083]
