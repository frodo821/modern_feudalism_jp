# 概要

**領主権裁定院**は、諸侯の[領主権](lordship-rights.md)をめぐる紛争を裁定するために、朝廷が明治元年（1867年）に太政官の下に設置した機関である。[^n1][^u022]

1866年に朝廷が諸侯の所領を安堵した以上、その所領の境界や権利関係を最終的に判断するのも朝廷である、という論理に立つ。幕府時代に将軍が担っていた大名間の裁定機能を朝廷が引き継ぎ、旧幕府の評定所を改組して実務を担わせる。[^u022]

裁定院は「中央政府が領地を取り上げる機関」ではなく、既存の領主権の保障を実効化する機関として発足した。その結果、**明治元年の朝廷政府は、諸侯の領主権を保障する代わりに、その領主権を裁定する唯一の上位機関**となった。史実の急速な廃藩置県とは異なる「司法的な統一を先行させる中央集権化」であり、「領主権を温存することが、逆に中央政府の権威を強める」という政治秩序の要となった。[^u022]

1920年代に華族家門の家門司法権が確立すると、裁定院の役割は広がった。1937年の[三元的司法制度](tripartite-judiciary.md)では、裁定院は領主権・家門司法権などの範囲や効力と、帝国・領国・家門の司法権の**管轄競合**を裁定する機関とされ、競合を主張する側が裁定院に提訴する。[^p031]

# 職務

裁定院の職務は四つに整理される。[^u022]

| 職務 | 内容 |
|---|---|
| 領地境界の裁定 | 律令国・郡・村にまたがる領地の境界や帰属を確定する |
| 領地交換の仲裁 | 飛地や錯綜した所領の交換条件を調整する |
| 領主権の確認 | 家督相続、領主権の継承、領地の分割・統合を審査する |
| 国司と領主の紛争処理 | 中央政府の監督権と各領主の自治権の境界を判断する |

## 「紛争が起きるまで国を分割しない」原則

[廃藩置国](kokugun-system.md)で律令国を復活させても、最初からすべての領地を整理して一国一領主にする必要はない。常陸国なら那珂川家・土屋家・その他の旧大名領をそのまま登録し、飛地も当面は許容する。そのうえで、**境界争いや領地交換の申立てがあった場合にだけ裁定院が調整する**。この方式により、従来の領主権をほぼそのまま温存しながら国郡制への移行を進められ、諸侯は領地再編を一方的に命じられるのではなく、権利を保障される側として制度に参加できる。[^u022]

# 組織

## 評定所の継承

江戸幕府の評定所は、異なる領主の支配下にある者同士の訴訟などを扱う中央裁判機関であった。新政府はこれをゼロから作るのではなく、評定所を朝廷直属の裁定機関に改組し、旧幕臣の実務官僚を引き続き雇用する。[^u022]

## 構成

| 部門 | 構成・職務 |
|---|---|
| 太政官 | 裁定制度の監督、重大事項の勅裁 |
| 領主権裁定院 | 旧評定所の職員＋公家・諸侯の任命委員 |
| 地方調査官 | 石高・地籍・境界の調査 |
| 調停・審理部門 | 領地交換・相続・領主間紛争 |

[^n2][^u022]

この構成は、公家には朝廷による裁判権の確立という利益を、諸侯には自らの領主権を保障する公的な仕組みを与える。[^u022]

# 裁定の効力と執行

裁定院の決定を各領主が履行する義務が定められる。これにより、領主権は従来どおり存在しても、その権利の範囲と正当性を最終的に判断するのは中央政府となる。朝廷にとっては、諸侯を武力で従わせるより摩擦の小さい方法である。[^u022]

ただし裁定を守らない領主が出れば、最終的には軍事・財政上の制裁が必要となり、その点で中央常備軍の存在が意味を持つ。[^n3][^u022]

当面、各領主がどの程度の税を徴収するか、どのような家臣を登用するかはそれぞれの裁量に委ねられる。領主同士が争った場合や、領主権の内容に争いが生じた場合にだけ、朝廷の裁定を仰がなければならない。[^u022]

# 他機関との関係

## 弾正台・刑部省・太政官との分担

1867〜1868年に、裁定院・[弾正台](danjodai.md)・刑部省の三機関が設置され、次のように役割が分けられた。[^n4][^u023]

| 官庁 | 職務 |
|---|---|
| 領主権裁定院 | 領地境界、相続、領主権の範囲、領地交換などの紛争を裁定 |
| 弾正台 | 国司・領主・中央官僚の不正や職権濫用を調査・弾劾 |
| 刑部省 | 刑事事件の審理・刑罰の執行 |
| 太政官 | 行政の統括、官吏任免、裁定の執行 |

弾正台は領主権を直接取り消せない。ある伯爵家の違法課税を弾正台が調査しても、その領主権を剥奪するには裁定機関による審理と、必要に応じた勅裁を要する。弾正台が不正を認定した場合は、刑部省または裁定院へ案件を送致する。監察・訴追と裁定・処罰を分けることで、朝廷が約束した所領安堵との矛盾を抑える。[^u023][^u024]

## 1867年の官制令

明治元年夏の太政官官制改革で、官制令が太政官・弾正台・刑部省・領主権裁定院などの権限を定め、三機関の管轄を整理した。[^n5] 並行して出された領主権令は、世襲領主権・所領安堵・領主の義務とともに「領主権の裁定」を規定した。[^u024]

## 格式編纂局との連携

法典編纂機関（格式編纂局・修律館）は、領主権裁定院や弾正台から寄せられた制度上の問題を集約し、法改正案に反映する役割を担う。1868〜1870年には国郡・封土に関する基本法が整備され、**裁定院が各領主の所領・権限を登録した**。[^u031]

## 憲法上の位置

1869年の[大日本帝国憲法](imperial-constitution.md)の領主権条項には、次の一条が置かれた。[^n6][^u036]

> 第十四条　領主権ノ境界、相続及其ノ他ノ争議ハ、法定ノ裁定機関之ヲ審理ス。

あわせて第十五条で、領主権の停止・剥奪・変更は憲法に定める手続によらなければならないとされた。裁定院は憲法上の「法定ノ裁定機関」として位置づけられる。[^u036] [元老院](genroin.md)の議決要件でも、個別領主の所領変更には当事者の同意または特別裁定手続が必要とされる。[^u026]

## 帝国裁判所との関係

1869年以降は、領主裁判所（領内の通常事件）、帝国裁判所（帝国共通法の事件・領主間事件・法定の上訴事件）、弾正台（違法な権力行使の調査・訴追）という三分の司法体制がとられた。[^u036] 「領主間事件」を帝国裁判所が扱うとする一方で、領主権そのもの（境界・相続など）の争議は裁定機関の管轄とされ、当初は両者の管轄の境界が明示されていなかった。この点は1930年代までに整理され、権限の範囲・効力と管轄の競合は裁定院、事件の裁判・上訴審・違憲審査は帝国裁判所という分担になった（→「1920年代以降の役割」）。[^p031]

## 1920年代以降の役割

1921〜1924年頃の華族特権改革で、家門構成員に対する第一審管轄権と家法制定権が無領華族を含む全華族の特権へ移された（→[家門自治権と家門司法権](family-autonomy.md)）。[^p027] これに伴い、裁定院の裁定対象も領主権から家門司法権へ拡張された。[^n7][^p031] 1937年の司法関係機関の分担は次のとおりである。[^p031]

| 機関 | 権限 |
|---|---|
| 帝国裁判所 | 帝国管轄事件の裁判、上訴審、違憲審査 |
| **領主権裁定院** | 領主権・家門司法権等の範囲や効力、管轄競合の裁定 |
| 弾正台 | 司法判断への異議申立て、違憲訴追 |
| 領国司法機関 | 属地的な捜査・訴追・裁判・刑罰執行 |
| 家門司法機関 | 属人的な捜査・訴追・第一審裁判 |

管轄が競合する典型例は、家門構成員と一般臣民の民事紛争、異なる家門の構成員間の紛争、領国内で家門構成員が起こした事件などである。[^n8][^p027] 帝国裁判所の専管は「例」の明文規定がある場合に限られる（帝国専管明文主義）ため、明文のない事項について帝国・領国・家門のいずれが管轄するかは、裁定院の判断に委ねられる場面が多い。[^p031] 裁定院の裁定に不服がある場合の扱いは明文化されていないが、司法判断の合憲性は最終的に帝国裁判所が担保する。[^n9][^p030][^p031]

## 授封・断絶と裁定院

新規授封・加増は元老院の議決と天皇の承認によるが、授封後の領主権の範囲・効力をめぐる紛争は裁定院が扱う。[^n10][^p033] 北海道では主要港湾都市も領国に編入され、海軍基地の敷地のみ帝国が特別管理するため、領国と帝国の権限の境界を裁く場面も生じる。[^n10][^p034] 断絶した領主家の領国は帝国直轄とならず、他家への再授封・加増が認められた[^n11]ので、相続・継承の確認は引き続き裁定院の重要な職務である。[^p035] →[新規授封と加増](new-enfeoffment.md)

# 中央集権化への効果

## 領地情報の中央蓄積

領主権を裁定するには、各領地の石高、村数、実際の税収、土地の境界、継承関係を記録しなければならない。こうして全国の領地情報が中央に蓄積され、後の全国統一の税制、地籍調査、司法改革の基礎となる。ただし、それらの改革には別途議政機関での合意や法律の制定が必要であり、裁定院が存在するだけで中央政府の徴税権が生まれるわけではない。[^u022]

## 諸侯にとっての合理性

この制度が定着すれば、旧大名にとって朝廷政府を維持することが、自らの領主権を守るための合理的な選択となる。朝廷は諸侯の所領を奪うどころか、それを保護する政府として自らを位置づけられる。[^u022]

## 後年の役割

* **領主権奉還**：[領主権奉還令](lordship-surrender.md)は「弾正台や領主権裁定院と並ぶ重要な制度」と位置づけられ、奉還に伴う権限・債務の整理を要した。[^u027]
* **新領土**：北海道で史実の分領支配が恒久化した背景には、全国的な領主権の登録制度・紛争裁定機関・元老院がそろっていたことがある。新たに領主権を設定した開拓地の境界や権利も、既存の裁定制度で処理できた。[^u066] 北海道の分領支配は恒久的な世襲領主領へ発展した。[^n12][^p034]
* **管轄競合の裁定**：1920年代以降、帝国・領国・家門の三司法権の管轄競合を裁定する（上記）。[^p031]

# 史実との比較

* 史実の評定所は江戸幕府の最高裁判機関の一つで、異なる領主の支配下にある者同士の訴訟などを扱った。本世界線では評定所が朝廷直属の機関に改組され、旧幕臣の実務官僚がそのまま新政府に継承される。[^u022]
* 史実の明治政府は版籍奉還・廃藩置県によって領主権そのものを廃止したため、領主間の権利紛争を裁く常設機関は必要とされなかった。本世界線では領主権の存続が前提であるため、その範囲を裁定する機関が中央集権化の中核となる。[^u021][^u022]

# 編集注：未決の論点

* 正式名称「領主権裁定院」と設置時期（明治元年）は検討案。朝廷が領主間の紛争調停機関を置くこと自体は作者の発案で確定している。[^u022]
* 裁定を履行しない領主に対する制裁の具体的方法（軍事・財政上の手段の発動手続）。[^u022]
* （解決）帝国裁判所の「領主間事件」管轄との境界 → 1937年までに、権限の範囲・効力と管轄競合は裁定院、裁判と違憲審査は帝国裁判所と整理された。[^u036][^p031]
* 裁定院の裁定に対する不服申立ての経路。[^p031]
* 国司と領主の紛争の判断基準（国司が領主の命令を取り消せるか）。[^u021]
* 弾正台・刑部省との三機関分担、1867年の官制令、内部構成、家門間の管轄競合の典型例、授封地をめぐる裁定院の役割は、いずれも検討案の段階にある。[^u023][^u024][^p027][^p033]

# 編集注：却下・修正された案

* **一国一領主への早期整理**：廃藩置国の際に錯綜所領を交換・分割で整理する方向が当初検討されたが、裁定院の設置を受けて、紛争が起きるまで国を分割せず飛地も許容する方式に修正された。[^u021][^u022]
