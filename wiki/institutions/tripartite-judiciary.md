# 概要

本世界線の司法は、**帝国司法権**・**領国司法権**・**家門司法権**という三つの司法権が併存する多元的な制度である。帝国司法権は帝国裁判所が担う全国的な司法権、領国司法権は世襲領主が領国内で行使する属地的な司法権、家門司法権は華族家門が登録構成員に対して行使する属人的な司法権である。[^p030] 三者の権限は1937年までに細部まで定まっている。[^p030][^p031]

帝国司法権は最終的な裁判権を持つが、領国司法権・家門司法権に対して無条件に優先する第一審管轄権を持つわけではない。ある事項を帝国裁判所の専管とするには、「例」（制定法）による明文の規定が必要である（**帝国専管明文主義**）。権限の境界は[領主権裁定院](lordship-tribunal.md)が、司法判断の適法性と合憲性は帝国裁判所が担保し、[弾正台](danjodai.md)が公益の立場から帝国裁判所へ提訴する。[^p031] この構造は「**司法権の帰属は多元的だが、憲法秩序の最終的な判断は一元的である**」と総括される。[^p031]

# 成立の経緯

## 1869年の三本立て

1869年の憲法下の[領主権](lordship-rights.md)は、民事・刑事の裁判権を含む包括的な権利であった。司法は、領内の通常事件を扱う領主裁判所、帝国共通法の事件・領主間事件・法定の上訴事件を扱う帝国裁判所、違法な権力行使を調査・訴追する弾正台の三本立てで始まった。[^n1][^u036] 「商事法は全国共通、裁判所は領主ごと」という妥協のもとで商事事件・越境事件から帝国裁判所の権限が広がり、条約改正でも「領主の判決を帝国裁判所が審査できる仕組み」が鍵となった。[^u044][^u046] 初期の制度は[法体系（詔・勅・例・式）と司法制度](legal-system.md)を参照。

1867年時点の領主司法権には、領国内の一般臣民に対する属地的な司法権と、領主家の家族・家臣団に対する属人的な司法権の双方が含まれていた。[^n1][^p027]

## 1890年代の臣民の権利との調整

領主権と臣民の権利をめぐる対立は、立法によって調整された。[^n2] 調整の内容には、帝国共通の司法手続と上訴制度、領国政府の処分への不服申立て（行政救済）が含まれる。[^n1][^p005] 衆議院の初期政治では、領国の司法制度を憲法上の自治権とみる領主権擁護派と、領主自身が司法権を持つことを臣民の権利保障と矛盾するとみる民権派、広域取引の障害とみる商工業者、全国共通司法を利益とみる改革派領主が対立した。[^n1][^p003]

## 1920年代の家門司法権の分離

1921〜1924年頃の第一次元老院改革で、属人的な司法権（家門構成員に対する第一審管轄権と家法制定権）が全華族の特権へ移され、属地的な領国司法権は「大きすぎる」ため領主固有に残された。[^p027] これによって、領主司法権は「領国司法権」と「家門司法権」に分かれ、後者は無領華族も持つようになった。経緯は[家門自治権と家門司法権（1924年の華族特権改革）](family-autonomy.md)を参照。

# 法体系

## 三法秩序

1937年の法秩序は、帝国法（帝国全域、帝国統治機構）、領国法（属地主義、領主が制定）、華族家法（属人主義、華族家門が制定）の三法が併存する。三者は対等ではない。[^p027]

優先関係の整理[^n1]では、[大日本帝国憲法](imperial-constitution.md)をすべての統治権・自治権の法的根拠とし、その下に帝国法（例・閣例・勅令）、さらに領国法と家法を置く。[^p030] 勅令は例と同等の効力を持つが、独自の予算権を持たない。[^p002] ただし、帝国法が領国法・家法に常に優先するかは定まっていない。[^n3] 憲法が自治権を保障しているため、帝国議会の立法でもそれを侵害できるかが問題になるからである。[^p030]

## 帝国専管明文主義

「ある事項が帝国裁判所の専管であるためには、例による明文の規定が必要である」という法理が成立している。[^p031] 犯罪の重大性や国家的な重要性だけを理由に、帝国が領国司法権・家門司法権を当然に排除することはできない。これは帝国の行政機関が拡張解釈によって領主権や家門司法権を侵害することを防ぐ仕組みでもある。[^p031]

| 事件の性質 | 管轄 |
|---|---|
| 帝国専管であることが例に明記されている | 帝国裁判所の専属管轄 |
| 領国司法権の範囲内 | 領国司法 |
| 家門司法権の範囲内 | 家門司法 |
| 複数の司法権が競合する | 領主権裁定院による裁定 |
| 司法判断に不服がある | 帝国裁判所への上訴・提訴 |

[^p031]

# 手続

## 管轄競合

管轄の競合を主張する側が領主権裁定院に提訴する。裁定院はもともと領主権の範囲・効力の争いを裁定する機関であり、無領華族への家門司法権の拡張に伴い、裁定対象も家門司法権に広がった。[^p031] 構成員と一般臣民の民事紛争や、異なる家門の構成員間の紛争は、典型的な競合事例となる。[^n1][^p027]

## 上訴と弾正台の提訴

* 紛争当事者は、領国司法・家門司法の決定に対して帝国裁判所に上訴できる。[^p030]
* 弾正台は、領国司法権・家門司法権による決定に不服を唱えて帝国裁判所に提訴でき、家法・領国法の憲法違反を訴追できる。[^p030] 当事者が上訴しなくても公益の立場から提訴でき、具体的な事件がなくても法規そのものを対象とすることができる（抽象的違憲審査の請求）。弾正台自身は判決を取り消したり家法を無効にしたりせず、帝国裁判所に判断を求める。[^p030][^p031]
* 華族当主が被告となる場合も第一義的には自家の家門司法権に服し、帝国裁判所への上訴の権利は当然に維持される。当主に自家が無罪判決を下しても、帝国による司法的監督は排除されない。[^p031]

## 刑罰の執行主体

| 第一審 | 確定した司法権 | 刑罰の執行主体 |
|---|---|---|
| 帝国裁判所 | 帝国司法権 | 帝国 |
| 領国裁判所 | 領国司法権（領国内で確定） | 当該領国 |
| 領国裁判所 | 帝国司法権（上訴審で確定） | 帝国 |
| 家門裁判所 | 家門司法権 | 帝国 |
| 家門裁判所 | 帝国司法権 | 帝国 |

[^p030]

刑罰執行権は原則として帝国に帰属する。領主華族は領国自治権の一環として、領国司法権で確定した刑罰に限り執行でき、帝国の司法権で確定した刑罰を執行する権利は持たない。領主は領国司法権に基づいて刑務所等を運営できるが、家門裁判の確定刑を執行することはできない。華族家門は独自の監獄を持たない。[^p030]

## 刑罰の執行停止

| 状況 | 刑罰の執行 |
|---|---|
| 第一審判決後、未確定 | 不可 |
| 上訴による係争中 | 不可 |
| 最終確定後 | 可能 |
| 確定後に弾正台が提訴した当日 | 停止の効力はまだ生じない |
| 弾正台による提訴の翌日以降 | 停止 |
| 再度の最終確定後 | 確定した判断に従う |

[^p031]

刑罰の執行停止と、裁判のための勾留その他の保全処分は別の問題として扱われる。[^p031]

## 違憲判決の効力

違憲判決の効力は判決がその範囲を定め、上限はない（「無限」）。帝国裁判所は判決で次のような効力を定めうる。[^p031]

| 判決の効力 | 内容 |
|---|---|
| 個別適用の排除 | 当該事件に限って法規の適用を否定 |
| 一部無効 | 特定の条項を無効とする |
| 全部無効 | 領国法・家法全体を無効とする |
| 一般的効力 | 当該事件以外にも効力を及ぼす |
| 遡及的効力 | 判決が定めた過去の時点にまで効力を及ぼす |
| 将来的効力 | 判決が指定した時点以降に無効とする |

ただし、遡及効を無制限に認めるかは定まっていない。[^n4][^p031]

# 家門司法と不逮捕特権

家門司法権に第一審管轄権があるため、家門の承認なく外部機関が構成員に強制処分を加えられない、事実上の不逮捕特権が成立している。逮捕状の発付や逮捕・勾留の承認は家門司法機関が行う。[^n1][^p029][^p030] 1937年に包括的な思想取締立法「帝国秩序維持例」[^n5]が成立したが、帝国専管明文主義のもとでは、禁止行為を新たに定めることと、その事件を帝国裁判所の専管とすることは別個の立法事項となる。[^p029][^p031] 詳細は[家門自治権と家門司法権](family-autonomy.md)と[1930年代の政治潮流](../politics/politics-1930s-currents.md)を参照。

# 領国の司法と新領地

北海道で領国に編入された港湾都市でも、一般臣民に対する司法権は領国司法権に属し、海軍基地の管理・軍事施設の警備・国防外交は帝国に属する。[^n1][^p034] 領主権の範囲・効力をめぐる紛争は、新規授封の場合も含めて領主権裁定院の管轄とされる。[^n1][^p033] →[新規授封と加増](new-enfeoffment.md)

# 史実との比較

* 史実の明治憲法下では、大審院を頂点とする司法裁判所と行政裁判所が置かれたが、法律の違憲審査制度はなかった。本世界線では帝国裁判所が領国法・家法の違憲審査権を持ち、弾正台の請求による抽象的審査まで可能である。
* 法規そのものを対象とする抽象的規範統制は、史実では1920年のオーストリア憲法裁判所などに見られるが、本世界線では領主・華族の自治立法を監督する必要から、同時期かそれ以前に類似の機能が生まれている。
* 管轄競合を専門機関が裁定する構造は、史実の権限裁判所（行政と司法の管轄争いを裁く機関。フランスなど）に近いが、本世界線では帝国・領国・家門という統治主体間の境界を裁く点が異なる。
* 史実の弾正台は1871年に廃止されたが、本世界線では存続し、検察官と違憲訴追者を兼ねる独自の司法監督機関となった。

# 編集注：未決の論点

* 帝国裁判所が領国判決を単に維持した場合、刑罰が領国司法権で確定したのか帝国司法権で確定したのか（執行主体の決定）。[^p030]
* 帝国法が領国法・家法に常に優先するか（憲法上の自治権保障との関係）。[^p030]
* 死刑など不可逆的な刑罰が弾正台の提訴当日に執行されうる問題と、特別な猶予期間の有無。[^p031]
* 違憲判決の遡及効を無制限に認めるか。[^p031]
* 家門が強制処分を拒否した場合の救済手続。[^p029]
* 領国内の上訴審の構成（「領国制度による」とされた部分）。[^p030]
