# 概要

本世界線の明治維新の最初の大仕事は、富国強兵や廃藩置県ではなく、**律令と格式の整理**であった。[^n1][^u031] 1867年の時点では、朝廷の律令・格式・先例、幕府の法令・触書・裁判先例、各藩の藩法、寺社の特権、条約上の義務が併存していた。千年以上にわたって積み重なった朝廷の法制に幕府法・藩法・西洋法を接続し、近代国家の統一的な法体系へ作り替えることが求められた。[^u031]

整理にあたっては格を廃止して格式を律令に組み込み、刑事法を特別扱いする必要が薄いことから律も消えた。その結果、法形式は**詔・勅（命令）、例（制定法）、式（施行規則）**の四つに整理された。[^n2][^u032]

この体系のもとで、[大日本帝国憲法](imperial-constitution.md)は詔で公布される最高法規、例は議会の議決と天皇の裁可で制定される法律、式は例の範囲内で出される施行規則と位置づけられる。[^u033] 勅（勅令）については、後に憲法運用のルールが具体化され、元老院勅令・天皇勅令・緊急勅令の三種が**例と同等の効力**を持つ（ただし独自の予算権は持たない）とされた。[^p002] 司法では、包括的な領主権のもとで領主裁判所が存続し、帝国裁判所・弾正台と並ぶ三本立ての体制がとられたが、1920年代の華族特権改革を経て、帝国・領国・家門の三つの司法権が併存する[三元的司法制度](tripartite-judiciary.md)へ発展した。[^u036][^p030][^p031]

# 法形式

## 四つの法形式

| 法形式 | 主な役割 | 近代法上の位置づけ |
|---|---|---|
| **詔**（みことのり） | 改元・践祚・国政の基本方針・憲法公布などの宣言 | 国家の重要な公的宣言。通常の法令の上下関係とは別に扱う |
| **勅** | 天皇の具体的な命令・任免・行政上の指示。立法的な勅令は元老院勅令・天皇勅令・緊急勅令の三種 | 勅令は例と同等の効力（独自の予算権なし）[^p002] |
| **例** | 元老院、後には帝国議会の議決で制定される一般法 | 法律 |
| **式** | 例の施行に必要な手続・事務規則 | 施行規則・行政命令 |

[^u032]

当初の原則は、**詔と勅を例より上位の一般的な立法形式にしない**ことであった。一般国民や領主を継続的に拘束する制度は、原則として例で定める。[^u032] この原則は後の憲法運用でも維持され、勅令は例と「同等」であって例より上位には置かれない。勅令を例より下位に置く効力順位はとられていない。[^n3][^p002]

## 効力関係

効力の順序は次のとおりである。[^n4][^u032][^p002]

1. **帝国憲法・皇室典範**: 国家と皇室の根本規範。両者の相互関係は別に定める。
2. **例**と**勅令**: 例は議会の議決と勅裁による制定法。勅令（元老院勅令・天皇勅令・緊急勅令）は例と同等の効力を持つが、独自の予算権を持たない。
3. **式**（例または勅令に基づく施行規則）: 例・勅令に反してはならない。

任免や儀礼上の個別の勅命は、立法的な勅令とは別に天皇の憲法上の権限に基づく命令として扱われる。[^u032] 1920年代以降は、これら帝国法の下に領国法と華族家法が置かれる三法秩序となるが、帝国法が領国法・家法に常に優先するかは定まっていない（→[三元的司法制度](tripartite-judiciary.md)）。[^n5][^p027][^p030]

詔は効力順位の外にある文書形式である。憲法の公布も詔で行われるが、詔は公布の形式であって、憲法を上書きする無制限の権限ではない。[^u033] 皇室典範を皇室内部の規範とするなら、一般国政の法律とどちらが優越するかを一律に決める必要はない。[^u032]

憲法には次のような原則が置かれる。[^n6]

* 「**式ハ例ノ委任ニ依リ之ヲ定メ、例ニ反スルコトヲ得ス**」（法令の上下関係）
* 「**犯罪及刑罰ハ例ヲ以テ之ヲ定ム**」（罪刑法定主義。刑法を形式上特別扱いしないことと、刑罰に厳格な法律上の根拠を求めることは別の問題である）

[^u032]

## 勅令の種類

憲法運用のルールとして、次の三種の勅令が定められている。[^p002]

| 種類 | 発出主体 | 要件・制約 |
|---|---|---|
| 元老院勅令 | 元老院（天皇の承認の下で発出） | 衆議院は発出後90日以内に限り無効を決議できる |
| 天皇勅令 | 天皇（内閣の輔弼の下で発出） | ― |
| 緊急勅令 | 天皇（内閣不在時に発出） | 内閣発足後に事後の輔弼を要し、後継内閣の同意が得られなければ当然に効力を失う |

いずれも例と同等の効力を持つが、独自の予算権は持たない。そのため元老院が勅令によって衆議院を迂回し、長期にわたって新政策を遂行することは難しい。[^n6][^p002] 日清戦争後の[論功行賞](../events/reward-distribution-1889.md)では、元老院勅令に対する衆議院の無効決議が争点となりうる。[^n7][^p005] 内閣・両院との関係は[内閣制度と両院関係](cabinet-system.md)を参照。

## 閣例と議例

例案は提出者によって**閣例**（内閣提出）と**議例**（議員提出）に区別される。両院の議決が一致しない場合、閣例であれば内閣は修正のうえ元老院に再審議を諮ることができるが、議例は原則として廃案となる。[^p002]

## 例の体系と命名

刑法・民法・商法などはすべて例として制定される。「刑法例」では重複感があるため、「刑例」「民例」「商例」と簡略化される可能性がある。[^u032]

| 例の名称（例示） | 対応する内容 |
|---|---|
| 刑例・民例・商例 | 刑法・民法・商法 |
| 官制例 | 官庁組織 |
| 封土例 | 世襲領主権・相続・領地交換・奉還・財政負担 |
| 国郡例・国郡行政例 | 律令国・郡、国司の権限 |
| 軍制例 | 帝国軍の編制 |
| 華族例 | 華族身分 |

法令番号は、たとえば「**明治五年第二十号例『国郡行政例』**」のように付される。式は省庁ごとに定め、国郡行政例に対する「国郡行政式」、封土例に対する「封土式」（申請書類や領地調査の手続）のように対応させる。こうすれば元老院が細かな行政手続まで審議する必要がない。[^u032]

衆議院が成立した後も、変わるのは例の制定手続（両院の議決と天皇の裁可）だけで、法形式そのものは変わらない。[^u032] 「令」という形式すら残らない。[^u032] ただし帝国議会そのものは元老院単院の段階から存在し、第一回帝国議会は1867年に開かれている。[^p002]

## 本世界線で言及された主な例

| 例の名称 | 年 | 内容 |
|---|---|---|
| 旧法存続例[^n8] | 1867年 | 新しい例ができるまで旧幕府法・旧領主法の効力を当面認める[^u032] |
| 外交事務統一例[^n8] | 1868年（明治2年） | 外国との交際・条約締結の権限を中央政府に専属させ、宗家などの家役を承継・補償する[^u039] |
| 台湾統治例[^n8] | 1889年 | 台湾・澎湖を帝国直轄の特別領とする[^u077] |
| 帝国交通例[^n8] | 1889年頃 | 国道・幹線鉄道を帝国の公共事業とし、用地補償・恣意的な通行税の禁止を定める[^u083] |

外交事務統一例は、宗家を名指しせず一般原則の適用として整理する点に特徴がある（第一条「帝国ノ外国交際及条約締結ノ権ハ中央政府ニ属ス」ほか4条）。[^u039] 新たに取得した領土を「例ノ定ムル所ニ依リ」直轄地または領主権設定地とする憲法条項案もある（→[新領土の統治制度](new-territory-governance.md)）。[^u066]

# 移行の過程

## 旧格式廃止の詔と旧法の存続

最優先の課題は「何が現在も有効な法なのか」を確定することだった。御定書百箇条や幕府の民事先例をその日からすべて無効にすれば、全国の裁判と行政が混乱する。そこで最初に、「**従来の法令・慣行は新たな全国法に抵触しない限り、当面効力を維持する**」という原則が公布された。これは各領主の自治法を当面認めつつ全国共通法を整える方式であり、領主権の維持とも相性がよかった。[^u031]

明治元年（1867年）には、象徴的な「**旧格式廃止の詔**」が出された。[^n6][^u032]

> 古来ノ律令格式及旧幕府ノ法令ヲ整理シ、国家ノ法制ヲ詔勅例式ニ統一ス

ただし旧法令を一斉に失効させるのではなく、旧法存続例で法の空白を避けた。1867年から1870年代にかけて、旧律令格式・幕府の触書・諸藩の法令は新しい例と式へ順に組み入れられていった。[^u032]

## 格式編纂局（修律館）

編纂機関として格式編纂局（修律館）が置かれた。[^n9][^u031]

| 構成員 | 担当分野 |
|---|---|
| 公家・朝廷官人 | 律令・官位・朝廷の先例 |
| 旧幕臣 | 幕府法・裁判・財政・行政 |
| 諸領主の法務官 | 藩法・領主権・地方制度 |
| 洋学者・法律家 | 近代の民法・刑法・商法・国際法 |

この機関は元老院で審議する法案を起草し、領主権裁定院や弾正台から寄せられる制度上の問題も集約する。[^u031]

## 法制改革の年表

| 時期 | 内容 |
|---|---|
| 1867年 | 旧法令の当面の効力を確認。皇室典範・華族令・中央官制。格式編纂局の設置。旧格式廃止の詔 |
| 1868〜1870年 | 国郡・封土・官制・軍制の基本法の整備。領主権裁定院が各領主の所領と権限を登録 |
| 1869年頃 | 憲法を詔で公布し、法形式の効力関係を確定 |
| 1870年代前半 | 全国共通の刑法・裁判制度の整備。商事法など標準化立法 |
| 1870年代中盤 | 衆議院の成立（第一回総選挙は1876年）に伴い、例の制定手続を両院議決に変更 |

[^n10][^u031][^u032]

## 意義

この改革によって、天皇の命令である勅と、領主を含む全国の統治者を拘束する制定法である例が明確に区別された。1861年の公武協定以来の「天皇の権威を根拠とする国家統治」は、議会の合意と天皇の裁可による制定法の体系へ発展した。これは、天皇親政から立憲君主制へ移るための法的な基盤づくりでもあった。[^u032] 本世界線の明治維新は、「廃藩置県ではなく、律令格式の再編纂を通じて諸侯の自治と中央政府の権限を整理する改革」として記憶される。近代法の整備は「律令制の否定」ではなく「律令制の更新」として理解される可能性がある。[^u031]

# 司法制度

## 三つの機関（1869年以降）

1869年頃の領主権は、民事・刑事の裁判権を含む包括的なものだった。そのため司法は次の三本立てとなった。[^n6][^u036]

| 機関 | 役割 |
|---|---|
| **領主裁判所** | 領内の通常事件（民事・刑事）の第一審 |
| **帝国裁判所**（帝国上級裁判所） | 帝国共通法の事件、領主間の事件、法定の上訴事件 |
| **弾正台** | 領主・官吏による違法な権力行使を調査し、適切な裁判所へ訴追する（自らは裁かない） |

たとえば那珂川公爵家の領内で殺人事件が起きた場合、第一審は那珂川家の裁判所が担う。ただし、領主の裁判官が明らかに全国共通の刑法に反する判決を下せば、帝国の上級裁判所に上訴できる。領主が政敵を恣意的に投獄した場合は、弾正台が調査する。[^u036] 初期には全国共通の刑法や上訴制度が完成していないため、各領主の従来法を認めつつ、越境事件や領主権の争いから中央司法の管轄を広げていく。[^u036]

これに先立つ1867年の官制では、[領主権裁定院](lordship-tribunal.md)が領主間の境界・相続・交換の紛争を、刑部省が刑事事件の審理と刑罰の執行を、[弾正台](danjodai.md)が監察と弾劾を担う分担が想定されていた。[^u022][^u023] 裁定院は「司法的統一を先行させる中央集権化」の出発点とされる。[^u022]

## 1920年代以降：三元的司法制度

1920年代前半の第一次元老院改革で、領主司法権のうち属人的な部分（家門構成員に対する第一審管轄権・家法制定権）が全華族の特権に移され、属地的な領国司法権は領主固有に残された。[^p027] その結果、1937年の司法は次の三つの司法権からなる。[^p030][^p031]

| 司法権 | 管轄原理 | 主な権限 |
|---|---|---|
| 帝国司法権 | 帝国法・上級審 | 帝国専管事件の裁判、上訴審、違憲審査、帝国司法・家門司法による確定刑の執行 |
| 領国司法権 | 属地主義 | 捜査・訴追・第一審、領国司法で確定した刑の執行 |
| 家門司法権 | 属人主義 | 登録構成員に対する捜査・訴追・第一審（刑の執行は帝国） |

当初の構想で刑部省が担うとされた刑罰執行は、この段階では帝国に帰属し、領主は領国司法で確定した刑に限って執行できる。帝国裁判所は違憲審査権を持ち、違憲判決の効力範囲は判決自身が定める。帝国裁判所の専管とするには「例」による明文の規定が必要という法理（帝国専管明文主義）が成立し、管轄競合は領主権裁定院が裁定する。弾正台は領国・家門の司法判断と領国法・家法の違憲性を帝国裁判所に提訴できる。[^p030][^p031] 詳細は[三元的司法制度（帝国・領国・家門）](tripartite-judiciary.md)と[家門自治権と家門司法権](family-autonomy.md)を参照。

## 商事法の統一と司法の統一

標準化の過程では「**商事法は全国共通、裁判所は領主ごと**」という妥協がとられた。契約・手形・会社制度は帝国の例で統一し、第一審は各領主の裁判所が担い、領主間の商事紛争は帝国裁判所へ上訴できる。ただし領主ごとに裁判の質が違えば、商人は帝国裁判所による統一的な解釈を強く求める。経済的な標準化は、長い目で見れば司法の統一を促す。[^u044] アメリカの連邦裁判所にならい、領主間紛争・越境事件・帝国法違反を帝国裁判所が審理する構図も参照された。[^u045]

長期的に見ると、最大の争点は司法権である。軍事は統合され、徴税は中央への一定額の納付で妥協できる。しかし司法権を持つ領主は、その地域の実質的な統治者であり続ける。産業化で越境取引が増えると、まず商事事件・越境事件で帝国裁判所の権限が広がり、やがて刑事事件や領内の民事事件にも共通の手続が求められる。「**領主権の衰退は、軍事権の喪失よりも司法権の統一によって進む**」。[^u036]

## 条約改正との関係

欧米諸国が求めたのは、法の名称や構成が自国と一致することではなく、外国人がどの法律・手続で裁かれるかを予測できることであった。本世界線の法体系は、「翻訳可能な程度には整理されつつある」段階にあった。[^n1] 改正の鍵は全国一律の裁判所ではなく、「**外国人にも適用される帝国共通法と、領主の判決を帝国裁判所が審査できる仕組み**」である。英国商人が島津領と徳川領で異なる扱いを受けるなら、列強は領事裁判権の撤廃に慎重になる。[^u046] 詳細は[不平等条約改正](../diplomacy/treaty-revision.md)を参照。

# 史実との比較

* 史実の明治政府は、律令官制を参考に太政官制を整え、1869年に職員令で官制を改革した。[^u031] 初期の法形式は太政官布告・布達・達などさまざまで、1886年の公文式で法律・勅令・閣令・省令に整理された。[^u032]
* 本世界線では1867年の時点から元老院が存在するため、最初から合議による制定法（例）を法体系の中心に置く理由がある。[^u032]
* 史実の弾正台は1869年に設置され、刑部省との権限争いの末に1871年に廃止されて司法省へ統合された。[^u023]

# 編集注：却下・修正された案

* **律令格式の四分類再定義案（U31）**: 律＝全国共通の刑法、令＝官制・地方統治・領主権・軍制・徴税の基本制度、格＝律令を改正・補充する法令、式＝施行細則、と再定義する案が出された。令の体系として官位令・職員令・国郡令・封土令・軍防令・租税令・裁判令も挙げられた。[^u031] しかし作者が「格を廃止し、律も消える可能性がある」と指摘し、詔・勅・例・式の体系へ修正された。古代の律令格式を近代法に無理に対応させすぎていた、というのが修正の理由である。[^u032]
* **律令格式を1880年代の憲法制定時に再整理する案**: 憲法の早期制定（1869年頃）に伴い、年表は読み替えられた。[^u031]
* **勅を例より下位に置く効力順位案**: 当初の検討案では、効力順位を「憲法→例→勅・式」とし、勅は例に反してはならないとしていた。[^u032] 会話ログ3で作者が憲法運用のルールを確定し、勅令（元老院勅令・天皇勅令・緊急勅令）は**例と同等の効力**を持ち、その代わり独自の予算権を持たないと定めたため、勅令の位置は修正された。[^p002]
* **刑部省による刑罰執行**: 1867年の官制案では刑部省が刑事事件の審理と刑罰の執行を担うとされたが、1937年の制度では刑罰執行権は帝国（および領国司法で確定した刑については領国）に帰属すると整理されている。[^u023][^p030]
