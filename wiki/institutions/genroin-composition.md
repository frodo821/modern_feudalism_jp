# 概要

[元老院](genroin.md)の議席は、**領主互選議員**・**無領華族互選議員（華族互選議員）**・**勅選議員**の三種で構成される。領主互選議員は領主権を持つ華族（領主華族）の当主が互選し、無領華族互選議員は領主権を持たない華族（無領華族）の当主だけが互選する。勅選議員は天皇が選任し、天皇の信任がある限り終身在任する。[^p011][^p018][^p002]

互選はいずれも全国一括の一選挙区で行われ、各当主が一票を投じる**顕名の単記投票**である。自己投票は禁止され、当落線上の同数得票者は決選投票、得票者が定数に満たなければ補充投票で決める。[^p019][^p020] 定数は有権者数に自動連動せず、帝国議会の立法でのみ変更される。1867年の創設時は240（領主140・無領華族70・勅選30）、1924年に275（140・100・35）、1936年に310（160・110・40）と改められた。[^p012][^p032]

この制度は、幕府解体時の朝廷と諸侯の妥協を制度化したものである。領主互選枠は諸侯の代表、無領華族互選枠と勅選枠は朝廷側の制度的な対抗枠として設計された。その後、無領華族が急増して代表密度の格差が生じ、1924年と1936年の二度の議席配分改革につながった。[^p018][^p025][^p026]

# 議員種別

| 議員種別 | 選挙権者 | 被選挙資格 | 選出方法 | 任期 | 創設目的 |
|---|---|---|---|---|---|
| 領主互選議員 | 領主華族の当主 | 領主華族の当主 | 互選 | 6年 | 諸侯の代表 |
| 無領華族互選議員 | 無領華族の当主 | 無領華族の当主 | 互選 | 6年 | 朝廷側の対抗勢力 |
| 勅選議員 | ― | ― | 天皇による選任 | 天皇の信任の限り終身 | 天皇による人材登用 |

[^p018][^p002]

* **領主互選の性格**: 領主議員は「領主家が任命する家ごとの代表」ではなく、領主家当主の互選で選ばれる。1867年の有権者約270〜276家に対して定数140で、「領主のおよそ2人に1人が選ばれる互選」が定数設定の根拠とされた。[^p011][^p017] したがって、領主であることと元老院議員であることは同じではない。
* **無領華族互選の限定**: 華族互選の選挙権・被選挙権は無領華族に限られ、領主互選とは相互に排他的である。これは、華族互選が**領主華族に対する朝廷側の抵抗権**として設計されたためである。[^p018]
* **爵位と票の分離**: 爵位は社会的・儀礼的な序列であり、互選の票数とは無関係である。公爵も男爵も一票で、石高や資産による加重もない。[^p018][^p078] 徳川宗家（純資産約90億円）と純資産数十万円の小領主も同じ一票である。[^p077]
* **勅選議員**: 華族身分を持たない有能な人物（幕臣・藩士・外交官・法律家など）を、世襲爵位なしで国政に参加させる手段として機能した。そのため創設時に功績華族を急いで作る必要がなかった。[^p013] 勅選議員は改選されず、定数表の値は各時点の法定定数である。[^p032] 元老院議長は慣例上、勅選議員から指名・任命される。[^p002]
* **その他の資格規定**: 再選に制限はない。当主が交代しても議席は自動的には継承されない。領主権を失った領主互選議員は資格を失う。領主は議員と領主職を兼ねられるが、それ以外の公職との兼任や閣僚就任はできない（検討案を含む）。[^p011][^p002]

## 三原理の区別

華族身分は歴史的な家格に、領主権は世襲的な地方統治権に、勅選議員の地位は個人の能力と天皇の信任に由来する。元老院の三種の議席は、この三原理をそれぞれ代表する（検討案）。[^p013] 1867年の華族令と叙爵の詳細は[1867年華族令と初叙爵](kazoku-ordinance-1867.md)を参照。

# 互選制度

## 確定した互選規則

| 項目 | 内容 |
|---|---|
| 選挙区 | 全国一括 |
| 選挙人 | 領主華族・無領華族それぞれの当主 |
| 投票方式 | 顕名の単記投票（投票内容は投票者氏名とともに公開） |
| 票数 | 一人一票。爵位・石高による差なし |
| 自己投票 | 禁止（最低1人の同輩の信任が必要） |
| 候補者届出 | 不要 |
| 当選要件 | 1票以上を得た者のうち、得票順に定数まで |
| 当落線上の同数 | 決選投票 |
| 定数未充足 | 補充投票 |
| 任期 | 6年、再選無制限 |
| 定数調整 | 自動調整なし |

[^p019][^p020] 領主互選と無領華族互選には同一の制度が適用される。[^p020]

決選投票・補充投票には既当選者を含む全有権者が投票し、既当選者の地位は後続の投票で覆らない。決選投票は当落線上で同数の者だけ、補充投票は未当選者を対象に、定数が満たされるまで繰り返す（検討案）。[^p020]

## 制度の意図

顕名単記制は、朝廷が大領主中心の単一の領主連合による議席独占を警戒したことから採られた。完全連記制と異なり、単記制では大領主が票を集めても一人の当選にしか効かないため、領主連合の政治力は加盟家数に制約される。[^p019] 一方、投票が顕名であるため、票の組織的な配分や投票協定もしやすく、大領主の影響力は完全には排除されない。[^p019]

顕名の投票は、家同士の政治関係を公に表明する行為でもある。寄子が寄親に投票すれば関係の確認、大領主が中小領主に投票すれば代表性の承認、寄親以外への投票は独立の表明、異地域の領主同士の投票は連携の形成を意味する。[^p019] こうして元老院の会派は、当初は政策綱領を持つ組織ではなく、「互選での相互推薦と票の調整を行う領主連合」として生まれた。[^p019] その後の展開は[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)を参照。

## 投票の実際（例示）

定数が有権者の約半数なので、当落線上の得票は非常に少なく、同数処理は毎回の重要な手続となる。

* 1867年型の例（検討案）: 第一回投票で10票5人・5票10人・3票20人・2票30人・1票56人・0票155人となった場合、2票以上の65人と1票の一部で121人が確定し、残る19議席を補充投票で決める。第一回で当選した有力領主が、補充投票で近い領主を推す。互選は複数回の投票を通じた領主間連合の形成の場となる。[^p020]
* 1936年の領主互選の例（検討案）: 選挙人251人・定数160で、3票10人・2票60人・1票101人・0票80人となった場合、2票以上の70人が当選し、1票の101人が残る90議席を決選投票で争い11人が落選する。当選圏に大量の同票候補が生じるため、決選投票での金融圏をまたぐ協力が重要になる。[^p078]

票を一人に集中させるより複数の候補に分散するほうが議席獲得に有利である。徳川系32家なら「4人に8票ずつ」「16人に2票ずつ」「32人に1票ずつ」の三方式がありうる。[^p077]

## 記名投票と衆議院

元老院互選の記名投票（公的責任としての投票）の発想は衆議院選挙にも持ち込まれ、衆議院では1926〜27年に秘密投票が導入される（1928年初実施）まで記名投票が続いた。元老院互選は1937年時点でも顕名のままである。詳細は[衆議院選挙制度の変遷](../politics/election-system.md)を参照。

## 創設時の定数の導出（1867年）

* 1867年の領主華族は276家、無領華族は138家（旧公家137家＋弾正尹公爵家）、計414家（確定。作者確定）。[^p017]
* 領主互選は「約2家に1人」として140。旧構成比（60/25/15）を維持した225議席（135/56/34）案、235議席（135/70/30）案、厳密半数の237議席（138/69/30）案を経て、切りのよい240議席（140/70/30）に落ち着いた。[^p011][^p013][^p017]
* 240議席の構成比は、領主互選58.3%（諸侯側の代表）に対し、無領華族互選29.2%＋勅選12.5%＝41.7%（朝廷側の制度的対抗枠）である。全員表決時の首班指名の過半数は120票で、領主140人が一致すれば単独で指名できる。逆に、朝廷側100人が一致すれば領主20人の協力で別の候補を指名できる。**朝廷が諸侯に過半数を認めつつ、諸侯が一枚岩でない限り影響力を持てる構造**である（検討案）。[^p018]

## 固定定数の原則

定数は有権者数（家数）に連動させず、創設時に固定し、変更は帝国議会の個別立法による。「約2人に1人」は創設時の設定根拠にすぎない。[^p012] 領主権を[奉還](lordship-surrender.md)した家は領主互選の資格を失って無領華族互選の選挙人になるが、両方の定数は変わらない。[^p012][^p021] 新たに領主権を与えられた家（[新規授封](new-enfeoffment.md)）も領主互選の資格を得るだけで、定数は増えない。[^p012] 定数の変更には元老院自身の同意が必要なので、衆議院が領主議席の削減を求めても実現は難しい。定数を憲法本体ではなく元老院の組織を定める議例に委ねる案がある（検討案）。[^p012]

## 二度の改革

議席配分の改革は、領主特権の一部を全華族の特権に移す改革と一体で行われた。領主側は元老院の制度的過半数・領国統治権・領国自治・領主独自の互選制度を守り、無領華族側は互選議席の大幅増と、家法制定権・家門司法権などの属人的な自治権を得た。[^p026][^p031] 後者は[家門自治権と家門司法権](family-autonomy.md)を参照。

* **第一次元老院改革（1921〜1924年、1924年改選から適用）**: 世界大戦後の華族急増を背景に、無領華族互選を70から100へ約43%増やし、勅選を30から35へ小幅に増やした。領主互選は140に据え置いた。[^p026][^p032]
* **第二次元老院改革（1933〜1936年、1936年改選から適用）**: 衆議院の男女普通選挙や定足数の憲法改正と同時期の大規模な憲政改革として行われた。全種別を増員（領主140→160、無領華族100→110、勅選35→40）しつつ、領主の制度的過半数（51.6%）を維持した。[^p026][^p032]

改革の時期区分と背景は AI の整理で、検討案である。[^p026] 定数の数値は確定である。[^p032] 家法・司法上の大きな譲歩があったため、領主議席を大きく増やす必要はなかったとされる。[^p031]

# 首班指名の票数

首班指名は「出席議員の半数以上」の賛成で決まり、棄権者は欠席として数える。[^p002] 全員が投票すれば、240議席時代は120票、310議席時代は155票が必要である。1936年の元老院では最大会派でも63議席で、首班指名には最低三会派の協力が要る。[^p078] 首班指名の制度は[内閣制度と両院関係](cabinet-system.md)、1936年の実例は[1936年の政変と進歩・改進連立内閣](../politics/cabinet-1936.md)を参照。

# 却下・修正された案

* **定数300（領主議員180・華族互選75・勅選45）**: 前編会話ログの仮案。[^u026] 1867年の創設時点としては領主議員180は少なすぎるとされ、240（140/70/30）に置き換えられた。[^p010][^p017] その後、1924年275・1936年310で確定した。[^p032]
* **家ごとの代表と規模別の票配分**: 領主議員は「領主権を持つ家ごとの代表」で、最低一票＋領地規模に応じた追加議決権を与える案があった。[^u025] これは、領主家当主の互選で約2家に1人を選び、爵位・石高に関係なく一人一票とする制度に置き換えられた。[^p011][^p018]
* **華族互選は爵位別で、無領華族「も」参加する**: [^u026] 無領華族限定・全国一括・一人一票に修正された。[^p018][^p019]
* **奉還による議席の消滅・家数に連動する定数**: 奉還すると議席が消え、家数の半分を定数とする連動表（1867年135→1936年88）もあった。[^p010][^p012] 固定定数の互選制に置き換えられた。[^p012][^p021]
* **定数240→270→350案**: 第二次改革で領主180とする案。1936年の領主互選が事実上の全員参加制（議席／有権者比82.6%）になるため退けられた。[^p026][^p031]
* **高爵位者優先の同数処理**: 徳川期の序列を解体した華族令の趣旨に反するとして退けられ、決選投票が採られた。[^p019][^p020]

# 未決の論点

* 当選辞退、任期途中の欠員、当主交代のときの処理。決選・補充投票に全有権者が参加するのは補足案。[^p020]
* 領主互選議員の6年任期と世襲領主権の関係の細則。[^p002]
* 定数を定める法形式（議例か）。[^p012]
* 勅選議員の人選傾向（官僚・司法・軍・学界の構成）。[^p032]
* （作者確定で解決）1867年の276家・414家は御三卿などの扱いに仮定を含む暫定値とされていたが、確定値とされた。[^p017]
