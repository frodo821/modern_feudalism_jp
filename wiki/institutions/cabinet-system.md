# 概要

本世界線の[大日本帝国憲法](imperial-constitution.md)のもとでは、**内閣を成立させる積極的な権限を[元老院](genroin.md)が、内閣の存立を拒む消極的な権限を[衆議院](house-of-representatives.md)が握る**。元老院は内閣首班（首相）を出席議員の半数以上の賛成で指名し、衆議院は新内閣に対して直ちに組閣拒否決議案を諮り、また任意の時点で内閣不信任を決議できる。内閣は両院のどちらも解散できず、衆議院には任期満了以外の解散がない。[^p002]

この仕組みはユーザーが条文に近い形で詳細に確定させたもので、英国型の議院内閣制とも、史実の明治憲法体制とも異なる。分析上の便宜的な呼称として「**元老院首班指名・衆議院消極的信任制**」が使われる（正式名称ではない）。[^p002][^p009] 衆議院の選挙結果だけで政治権力のすべてが動くことはなく、内閣の形成は元老院・衆議院・内閣の三者の交渉によって決まる。1930年代には「首相の選出権は元老院にあるが、政権形成の主導権は衆議院の政党間交渉に移りつつある」と評される段階に達した。[^p081]

内閣と政党の歴史的な展開は[内閣の系譜と政党内閣の慣行（1867〜1937）](../politics/party-cabinets.md)、1936年の実例は[1936年の政変と進歩・改進連立内閣](../politics/cabinet-1936.md)を参照。

# 憲法上の規定

以下はすべてユーザーが確定させた内容である。[^p002]

## 首班指名と組閣

* 内閣の首班指名権は元老院にある。首班に誰を指名するかは元老院の専権事項で、法的な資格要件はない。
* ただし1917年の時点で、**議員経験者から選ぶ**ことが慣習として成立している。
* 首班指名には、元老院の**出席議員の半数以上**の賛成を要する。
* 閣僚の指名は首班の専権事項で、元老院は関与できない。ただし、天皇が閣僚を認証するにあたって元老院に諮問することが慣例となっている。
* 元老院の指名によって新内閣が組閣されたとき、衆議院は**直ちに組閣拒否決議案を諮らなければならない**。衆議院が新内閣を信任する場合は、この決議案を否決することでその意思を表す。

1936年の政権形成をめぐる議論では、組閣拒否決議は「不承認動議」とも呼ばれている。[^p078][^p080]

## 衆議院の権限

* 衆議院は元老院の決議に対して拒否権を持つ。
* 衆議院は内閣の不信任を決議できる。
* 内閣不信任と組閣拒否には、衆議院の**出席議員の半数以上**の賛成を要する。
* 衆議院は任期満了以外の解散事由を持たない。

## 元老院と不信任

* 元老院は内閣の不信任を決議できない。
* ただし元老院は、**後継の首班を指名したうえで、衆議院に内閣の不信任を諮る**ことができる。

## 内閣の解散

本世界線では、内閣の総辞職を「内閣を解散する」と表現する。

| 事由 | 手続 |
|---|---|
| 内閣不信任の可決 | 10日以内に首相の権限で内閣を解散する。10日を過ぎても首相が解散しない場合は、天皇が直ちに解散する |
| 首相の判断 | 首相は不信任決議によらず、いつでも内閣を解散できる |
| 首相の死亡・職務不能 | 天皇が元老院の助言のもとで内閣を解散できる |
| 両院の改選 | 内閣は自動では解散しない。改選後も新衆議院は不信任を決議でき、元老院も後継首班を指名できる |

## 内閣不在時

* 後継内閣が組閣されるまでは、元老院の権限において従前の内閣の方針を継続する。
* 内閣不在時には、**元老院議長が行政を代行する**。

## 勅令

勅令には三つの発出主体がある。

| 種別 | 発出主体と条件 | 統制 |
|---|---|---|
| 元老院勅令 | 元老院が天皇の承認のもとで発出する | 衆議院は発出後**90日以内**に限り、その無効を決議できる |
| 天皇勅令 | 天皇が内閣の輔弼のもとで発出する | ― |
| 緊急勅令 | 内閣不在時に天皇が発出する | 内閣発足後に事後の輔弼を要し、後継内閣の同意が得られなければ当然に効力を失う |

勅令は**例（制定法）と同等の効力**を持つが、**独自の予算権は持たない**。[^p002] 前編の会話ログで整理された法体系では、勅は「天皇の具体的な命令・任免・行政上の指示」で例より下位に置かれていたが、会話ログ3のこの規定が優先する（→[法体系（詔・勅・例・式）と司法制度](legal-system.md)）。[^u032]

## 議決・定足数

* 定足数は特に定めがない。
* 棄権した議員は、その決議を欠席したものとして票数を数える。
* 可否同数の場合は可決とする。
* ナチス・ドイツの成立後、定足数の要件を追加する憲法改正案が審議される（ユーザー設定）。改正は1937年末までに成立した（後述）。

## 両院不一致

* 閣例（内閣提出の例案）について両院が一致しない場合、内閣は修正のうえ元老院に再審議を諮ることができる。
* 議例（議員提出の例案）は原則として廃案となる。

## 兼職の禁止

* 議員は、**領主を除き**、いかなる他の公職とも兼任できず、**閣僚になることもできない**。領主であることは兼任禁止の例外だが、閣僚との兼任は認められない。[^p002]
* したがって、議員が首相・閣僚に就任するには議員職を離れなければならない。[^p081]

## 議長

* 慣例上、元老院議長は勅選議員から指名・任命される。
* 衆議院議長は、政党政治の成立後は慣例上、野党議員から選ばれる。

## 任期と帝国議会の起点

* 衆議院の任期は4年、元老院の任期は6年。ただし勅選議員は天皇の信任の限りにおいて終身身分である。
* 第一回帝国議会は**1867年**に開かれた（この時点の帝国議会は元老院のみ）。第一回元老院改選は大日本帝国憲法の施行後の**1870年**、第一回衆議院選挙は**1876年**である。[^p002]

衆議院には解散がないため、総選挙は4年ごとに固定される。元老院は6年ごとに改選され、1936年が第12回にあたる。[^p002][^p032]

# 制度の政治的帰結（検討案）

以下は、ユーザーの設定からAIが導いた分析である。[^p002]

## 成立しうる内閣の型

両院多数派の支持を受ける政党内閣、衆議院の少数党を中心とする少数派内閣、連立内閣、元老院主導の超党派内閣、官僚・実業家・退役軍人などの専門家内閣が成立しうる。衆議院の諸党は「拒否」では合意できても代わりの首班を指名できず、元老院は望む内閣を衆議院に強制できない。このため**両院間の事前交渉**が決定的に重要になる。衆議院の積極的な信任は要らないので、野党が拒否・不信任で結束しない限り、少数与党内閣も存続できる。[^p002][^p080]

## 政党の議会部門と行政部門の分離

首相・閣僚になるには議員辞職が必要なため、政党は党総裁・衆議院議員団長・元老院議員団長・首相や閣僚・党幹事長からなる**二重の指導体制**を持つ。党の役職は公職ではないので党総裁と首相の兼任はできるが、首相は議決権を持たず、与党議員団を議場で直接率いることもできない。こうして「政党の議会部門と行政部門が分離した政党政治」が生まれる。衆議院議長を野党から選ぶ慣例も、議会を内閣から独立した機関とみる思想と整合する。[^p002]

## 定足数のない議決

定足数がなく棄権が欠席扱いのため、少数政党は棄権によって事実上の閣外協力をしやすい。組閣拒否案への棄権は反対票と違って内閣を助けないので、与党は拒否案の賛成票を上回る反対票を集める必要がある。極端な場合、ごく少数の議員で内閣不信任が成立しうる。[^p002] この問題が1930年代の定足数改憲につながった。

## 元老院の交渉上の優位

内閣不在時には元老院議長が行政を代行するので、組閣交渉を急ぐ必要は比較的小さい。首班指名権と行政代行権により、制度上は元老院のほうが組閣交渉で有利である。ただし勅令には独自の予算権がないため、元老院が衆議院を無視して長期にわたり新政策を遂行することは難しい。[^p002]

# 運用の展開

## 首班指名をめぐる慣行の発達

| 時期 | 慣行 | 根拠 |
|---|---|---|
| 1880年代 | 元老院が首班指名の前に衆議院主要政党の意向を確認する（慣行の形は検討案） | 長期の内閣不在の回避（ダイス判定：難易度35、出目44・成功）[^p004] |
| 1892〜1896年頃 | 最初の本格的政党内閣。政党の指導者が首班に指名され、当該政党を中心に衆議院が組閣拒否を否決する | 1900年までの本格的政党内閣の成立（ダイス判定：難易度35、出目52・成功）。時期は検討案 [^p005] |
| 1890年代 | 選挙結果を首班指名で尊重する「民意尊重の慣例」（仮称）。第一党党首への自動的な指名ではなく、協調性を欠く第一党より第二党や超党派人物を選ぶこともある | 選挙結果を首班指名に反映する慣行の成立（ダイス判定：難易度40、出目71・成功）[^p005] |
| 1917年まで | 首班は議員経験者から選ぶ。天皇が閣僚を認証する際に元老院へ諮問する | ユーザー設定 [^p002] |
| 1936年まで | 首班指名で複数会派の連立交渉が常態化 | ダイス判定：難易度30、出目63・成功 [^p078] |
| 1936年 | 首班指名が倶楽部単位より人物本位の投票になる | ダイス判定：難易度25、出目49・成功 [^p080] |

政党内閣の成立は、憲法上の首班指名権が衆議院に移ったことを意味しない。元老院が特定の政党と結びついた人物を首班に指名する政治慣行が成立した、という意味である。[^p004][^p005]

## 首班指名に必要な票数

元老院の定数は1867年に240、1924年に275、1936年に310である（→[元老院の構成と互選制度（定数240・275・310）](genroin-composition.md)）。[^p032]

* 1867年の240議席では、全員が投票すれば過半数は120票である。領主互選議員140人が一致すれば単独で首班を指名できるが、無領華族互選議員と勅選議員の計100人が一致すれば、領主20人の協力で別の候補を指名できる。諸侯の制度的過半数を認めつつ、領主側が一枚岩でない限り朝廷側も影響力を持つ構造である（検討案）。[^p018]
* 1936年の310議席では、全員が投票すれば首班指名に155票が必要である。1936年の会派構成案（宗交会63・交友倶楽部60・興業会57・諸侯協同会43ほか）では最大の二会派を合わせても123議席で、最低三会派の協力が要る。43議席の諸侯協同会がキャスティングボートを握り、中小領主が政権形成で大きな交渉力を持つ（議席構成は検討案）。[^p078] 会派の詳細は[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)。

元老院の首班指名は人物本位になりやすく、首相の候補は衆議院政党の党首・元党首、元老院の有力領主、実業家華族、元官僚・元法曹、超党派的な元議員などである。元老院出身の首相が衆議院政党に主要閣僚を割り当てる内閣もありうる。「元老院では『どの会派が政権を取ったか』より『どの人物が、どの家門・倶楽部・衆議院政党の支持を得て首相になったか』が政治史の中心になる」とされる（検討案）。[^p079]

## 1936年の実例

1936年の両院同時改選の後、衆議院の政党間協定が先行し、元老院は国民進歩党出身の候補を首相に指名した。成立した国民進歩党・立憲改進党の連立内閣は衆議院300議席中128議席の少数与党だったが、国民協同党46議席が組閣拒否（不承認動議）の採決で棄権したことで乗り切った（票数の案は賛成126・反対128・棄権46）。元老院の初回採決の票数案は180対114・棄権16で、投票者294人の過半147票を上回った。[^p080] 宮廷・勅選議員による会派間の調整機構は成立しておらず（ダイス判定：難易度35、出目11・失敗）、首班指名の調整は元老院の会派間交渉で行われた。[^p078] この内閣は、首相・閣僚を衆議院出身者中心とし、元老院とは公式の与党会派を持たずに案件ごとの個別調整で協力者を確保した。[^p081] 経緯は[1936年の政変と進歩・改進連立内閣](../politics/cabinet-1936.md)を参照。

# 定足数の憲法改正（1933〜1937年）

ナチス・ドイツの成立後、元老院・衆議院の定足数を定める憲法改正案が提出され（ダイス判定：難易度15、出目86・成功）、1937年末までに成立した（ダイス判定：難易度55、出目61・成功）。[^p009] 改正の具体的内容は、ユーザーの当初設定を変える部分なのでAIの暫定案にとどまる（検討案）。[^p009]

| 項目 | 改正前 | 改正後の案 |
|---|---|---|
| 通常議決の定足数 | なし | 総議員の3分の1以上 |
| 首班指名の定足数 | なし | 総議員の2分の1以上 |
| 内閣不信任の定足数 | なし | 総議員の2分の1以上 |
| 組閣拒否の定足数 | なし | 総議員の2分の1以上 |
| 棄権者 | 欠席扱い | 定足数には算入、表決数からは除外 |
| 議決要件 | 出席表決者の半数以上 | 維持 |
| 可否同数 | 可決 | 維持 |
| 衆議院の解散権 | なし | 変更なし |
| 元老院の首班指名権 | あり | 変更なし |

改正の主眼は、権力配分を変えずに議決の正当性を確保することにある。ただしこの案でも、棄権者が多い場合には少数の賛成票で重要決議が成立する余地が残り、重要決議に有効表決数の最低要件を設けるかどうかが課題として残る。[^p009] 改憲の政治的背景は[1930年代の政治潮流（権威主義運動・思想取締・定足数改憲）](../politics/politics-1930s-currents.md)を参照。

# 史実との比較

| 論点 | 史実の明治憲法体制 | 本世界線 |
|---|---|---|
| 首相の選任 | 元老の推薦にもとづき天皇が大命を降下。議会の議決は不要 | 元老院が出席議員の過半数で指名 |
| 下院の内閣統制 | 不信任決議に法的拘束力なし | 組閣拒否・不信任決議で内閣を解散させる |
| 議会の解散 | 天皇（内閣）が衆議院を解散できる | 衆議院・元老院とも解散なし |
| 議員と閣僚 | 兼任可能 | 兼任不可（議員辞職が必要） |
| 勅令 | 緊急勅令・独立命令など広い勅令大権 | 元老院勅令・天皇勅令・緊急勅令。例と同等だが予算権なし。元老院勅令には衆議院の無効決議 |
| 内閣不在時 | ― | 元老院議長が行政を代行 |

史実では衆議院議員が閣僚を兼ねることができ、内閣は衆議院を解散して選挙で民意を問えた。本世界線ではどちらもできないため、政党の指導者は議員を辞めて入閣し、内閣は選挙ではなく両院との交渉で存立を図る。天皇に固有の統帥大権がないこととあわせて、政府と軍の関係も議会の手続の内側に置かれる（→[統帥権（本世界線）](supreme-command.md)）。[^u124]

# 却下・修正された案

* **二院協調型議院内閣制（P1のAI案）**: 当初AIは、「法律上は天皇任命の内閣だが、衆議院の信任を失った内閣は長期に存続できない憲政慣行」と「衆議院多数派の支持と元老院との協調による二院協調型議院内閣制」を提案した。直後にユーザーが憲法上の内閣規定（P2）を確定させ、元老院の首班指名と衆議院の組閣拒否・不信任による制度に置き換えられた。[^p001][^p002]
* **勅は例より下位（前編の法体系）**: 前編では「詔と勅を例より上位の一般的な立法形式にしない」「勅は例に反してはならない」と整理されていた。会話ログ3で、勅令は例と同等の効力を持つ（ただし独自の予算権はない）と改められた。[^u032][^p002]
* **定足数改憲の扱い**: P2の段階では「1937年末時点でなお審議中」とする案もあったが、P9のダイス判定で1937年末までの成立が確定した。[^p002][^p009]
* **1936年の三党連立案**: P9でAIは国民進歩党・立憲改進党・国民協同党の三党連立内閣を第一案としたが、P80の判定で国民協同党の入閣は失敗し、進歩・改進の二党連立と協同党の閣外協力になった。[^p009][^p080][^p081]
