# 概要

**新規授封**は新たな領主家を創設して[領主権](lordship-rights.md)を与えること、**加増**は既存の領主家の領国を広げることをいう。本世界線では、1866年の所領安堵で保障されたのは既存諸侯の領主権であって、新たに獲得した領土に対する分配請求権ではない。したがって新規授封は領主制を維持するために必然的に行われるものではなく、帝国が特定の政治的・行政的目的のために行う例外的な措置である。[^p033][^u066]

1880年代までは[北海道](../regions/hokkaido.md)の開拓が新規授封の最大の機会となり、既存領主家の分家への独立授封と、非華族の開拓功労者への叙爵・授封が広く行われた。日清戦争後には北海道で加増が行われ、第一次世界大戦後にも少数の新規授封があった。新規授封には元老院の承認が必要とされ、1900年以降は例外的措置に限られた（いずれもダイス判定で確定）。[^p034] 一方、本州・四国・九州では、領主権を奉還した旧領国は既存領主にも新しい家にも再授封されず、帝国直轄地として着実に増えた。その結果、**領主制は全国的には縮小しながら、北海道ではむしろ拡大する**という地域的に非対称な発展をたどった。[^p034]

# 原則

## 叙爵と授封の分離

「新規叙爵と新規授封は原則として別個のものとする慣行が定着する」は成功した（ダイス判定：難易度20、出目24・成功）。[功績叙爵](merit-peerage.md)で生まれた新華族は原則として無領華族であり、爵位を得ても領主権は伴わない。[^p025] 大戦後に叙爵された95家のうち授封を受けたのはごく少数である。[^p034]

## 授封の対象地域

| 地域 | 統治形態 | 新規授封の余地 |
|---|---|---|
| 本州・四国・九州の既存領国 | 世襲領主領 | 原則なし |
| 領主権奉還地 | 帝国直轄 | なし（再配分・再授封とも失敗） |
| 北海道 | 領主領と帝国直轄地の併存 | あり |
| [樺太](../regions/karafuto.md) | 帝国直轄の国境地帯 | 原則なし |
| [台湾](../regions/taiwan.md)・澎湖 | 帝国特別領 | 原則なし |

[^p033][^p034]

台湾・澎湖を帝国特別領とすることと、新規叙爵と授封を区別する慣行は、すでに確定した前提として再判定されていない。[^p033] 新領土の統治類型は[新領土の統治制度](new-territory-governance.md)を参照。

## 元老院互選への影響

[元老院](genroin.md)の領主議員は、全国一括の領主互選で、各領主家の当主が1票ずつ投票して選ばれる。互選の議席数は法定で固定されており、奉還や新規授封で領主家の数が変わっても定数は変わらない。[^p012] そのため、領主権の変動は有権者数にだけ影響する。[^p033]

| 領主権の変動 | 領主互選の有権者数 | 華族互選の有権者数 |
|---|---:|---:|
| 既存領主への加増 | 変化なし | 変化なし |
| 無領華族への授封 | +1 | −1 |
| 非華族への叙爵・授封 | +1 | 変化なし |
| 既存領主家の分家への授封・叙爵 | +1 | 変化なし |
| 領主権奉還 | −1 | +1 |
| 領主家の断絶 | −1 | 変化なし |

[^p033]

加増しても当主の票は1票のままだが、分家を独立領主にすれば新しい有権者が生まれる。大領主が分家や旧家臣を独立領主にすれば自らの金融圏・政治会派を拡大できるため、元老院では加増以上に新たな領主家の創設が警戒された（検討案）。[^p033]

## 決定手続

「新規授封に元老院の承認を必要とする制度が確立する」は成功した（ダイス判定：難易度15、出目45・成功）。[^p034] 手続の全体像は次の案が示されている（検討案）。[^p033]

| 行為 | 決定手続 |
|---|---|
| 新規叙爵・陞爵 | 天皇による授爵 |
| 新規授封 | 元老院の議決・天皇の承認 |
| 既存領主への加増 | 元老院の議決・天皇の承認 |
| 領主権奉還 | 領主の申請・帝国による受理 |
| 授封に伴う国費支出 | 通常の予算手続 |
| 領主権の範囲・効力をめぐる紛争 | [領主権裁定院](lordship-tribunal.md) |

衆議院は元老院の決議に対する拒否権を持つ（確定）ため、授封には事実上両院の同意が必要になる。[^p033]

## 北海道開拓期（1869〜1890年代）

既存領主家には旧家臣団・移住希望者・開拓資金・行政経験があり、開拓の担い手として有利であった。旧家臣団の俸禄負担の整理に失敗していたため、北海道は余剰家臣の移住先にもなった。[^p033] 北海道への進出には四つの形態がある。[^p033]

| 進出方式 | 新領主家の成立 |
|---|---|
| 既存領主家への加増 | なし |
| 既存領主家による開拓事業の受託 | なし |
| 領主家分家への独立授封 | あり |
| 開拓功労者への叙爵・授封 | あり（無領華族への授封は判定で否定） |

一般的な分家への新規叙爵は認められていないが、北海道の開拓と統治を担うために独立した家門を創設する場合は、例外として叙爵・授封が認められた。[^p034] 独立分家は法的には本家と対等で、元老院互選でも独立した1票を持つ。ただし開拓資金を本家に頼る分家の多くは本家の政治的影響下に置かれ、北海道進出に積極的な大領主が元老院内でも勢力を広げた（検討案）。[^p034]

北海道の領主は出自によって四類型に分かれる。[^p034]

| 類型 | 成立経緯 | 元老院互選への影響 |
|---|---|---|
| 松前家 | 既存の領主権を維持 | 既存の1票 |
| 本土領主家 | 開拓事業・加増による領国拡大 | 票は増えない |
| 本土領主家の分家 | 開拓地への独立授封 | 新たな1票 |
| 開拓功労者 | 叙爵と授封による領主家創設 | 新たな1票 |

## 日清戦争後の加増（1889年）

論功行賞をめぐる両院の対立は円滑に調整されず（ダイス判定：難易度35、出目24・失敗）、憲政危機となった。[^p005] 功績叙爵の制度化（成功）、大規模な一斉叙爵（失敗）、北海道での加増（成功）を組み合わせると、台湾などの新領土を領主に分配する案は否定されたが、代替として北海道の開拓領を加増する妥協が成立したと解釈される。この結果、「**海外領土は帝国のものとするが、国内の未開拓地については領主への報償として利用できる**」という原則が生まれた（検討案）。[^p034] 経緯は[日清戦争後の論功行賞](../events/reward-distribution-1889.md)を参照。

## 例外化（1900年以降）と大戦後授封

1900年以降、新規授封は例外的措置に限られた。一方、第一次世界大戦後の論功行賞としての新規授封は成功し、1919〜1922年頃に特別な報償として少数の新領主家が創設されたとされる（検討案）。対象は軍人だけでなく、戦時輸送・軍需生産・対外金融で顕著な功績を挙げた人物も含みうる。[^p034]

# 奉還地と断絶領

## 奉還地は直轄のまま

奉還地の既存領主への再配分（出目44、難易度45）と、奉還地への新領主家の授封（出目40、難易度65）はいずれも失敗した。財政的・行政的に維持できなかった領国を再び小領主に与えても同じ問題が起こりうるうえ、帝国政府には奉還領を処理する財政能力があったため、奉還地は帝国直轄地として存続した。[^p033][^p034]

## 断絶領は再授封されうる

「断絶した領主家の領国が他の華族に再授封されず帝国直轄となる」は失敗した（ダイス判定：難易度25、出目23・失敗）。すなわち断絶領は他家への再授封や加増が行われうる。[^p035] 自発的な奉還は領主が統治を維持できなかった結果だが、家門の断絶は財政・行政能力と無関係なので、統治能力のある領国を別の領主に引き継がせることができる、という区別である（検討案）。[^p035]

| 領主権の消滅事由 | 旧領の処理 |
|---|---|
| 自発的奉還 | 帝国直轄化 |
| 家門の断絶 | 再授封・加増を認める |
| 領主権剥奪 | 未確定 |
| 通常の継承 | 領国を維持 |

[^p035]

断絶は養子相続や家門自治権の強化で抑えられ、極めて少数にとどまる。1937年までの領主家の断絶5件のうち、3件が新しい家への授封、2件が既存領主への加増で処理された（家数は作者確定）。[^p035]

# 1937年の新領主

1937年の249領国を経済類型で分けると、「北海道開拓領国」は35家・人口500万人、地域GDP約25億円（1人当たり500円）で、帝国の財政調整交付金を1人当たり17円受けている（P97で一括確定。類型の分類自体は暫定推計とされる）。[^p094][^p097] 北海道に領地があっても経済の中心が本州にある家は、この類型に重複計上されていない。[^p094] 北海道の新規授封領では、開拓初期に一定期間、法定拠出金の免除が認められていた可能性がある（検討案）。[^p075] 領国財政は[領国の類型・財政と財政調整交付金（1937）](../economy/fief-finance-1937.md)を参照。

新規授封で生まれた北海道の新興領主家のうち5家は、授封直後の開拓でいったん深刻な財政危機に陥りながら（ダイス判定：難易度35、出目3・ファンブル）、本州の大領主・本家の金融圏から独立し（難易度55、出目78・成功）、独自の共同組織（仮称「北海道諸侯聯合会」）を作った（難易度40、出目64・成功）。[^p065] 詳細は[中堅・中小領主と北海道新興領主](../economy/minor-lords.md)を参照。

# 史実との比較

* 史実では1869年に北海道の分領支配が始まったが、1871年の廃藩置県で廃止され、開拓使の直轄となった。華族の新規授封という制度は存在せず、新華族はすべて領地を持たない名誉的貴族であった。
* 史実の日清戦争後の恩賞は陞爵・授爵・叙勲・賜金であり、領地の加増は廃藩置県以後選択肢になかった。本世界線では北海道が「国内の未開拓地」として加増の対象になった。[^u078]

# 却下・修正された案

* **規模別3モデル**: 授封抑制型（+5家、1937年221家）、限定的開拓授封型（+20家、236家）、積極的開拓授封型（+40家、256家）は比較用の仮定で、判定結果を受けて中間程度の35家が中核推計とされ、のち確定値となった。[^p033][^p034]
* **重要拠点は帝国、開拓は領主**: 札幌周辺や重要港湾を帝国直轄とする既存の想定は、直轄維持の判定失敗（出目6）により、主要港湾都市も領国に編入され、軍事施設の敷地だけを帝国が管理する形に改められた。[^u066][^p034]
* **新領主の議席付与**: 新領主家の創設が元老院の議席を増やすという旧来の想定は、互選の定数が固定され、新領主家は有権者を増やすだけという制度に置き換えられた。[^u066][^p012][^p033]
