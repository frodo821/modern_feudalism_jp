# 概要

本世界線の日本は、領主権を残したまま全国市場と国軍を統一する必要があった。そのための制度づくりでは、**史実以上にアメリカの連邦制が参考にされた**。[^u045]

アメリカは「地方政府に広い権限を残しながら、全国市場と統一国家を成立させた」国である。その点で、ドイツ帝国の領邦制度以上に実務的な手本になった。[^u045] さらに本世界線では[南北戦争が早期に終結（回避）](../events/american-civil-war-avoided.md)しており、アメリカの州権は史実の1870年代より強く残っている可能性がある。日本の領主たちはこれを見て、「これほど広い自治権を各州に認めても、全国共通の通貨・郵便・商取引制度を運営できるではないか」と考え、領主権存続の強い論拠にした。[^u045]

その結果、本世界線の日本は「**ドイツ帝国型の君主制とアメリカ型の連邦法制を組み合わせた立憲帝国**」となる。領主権も、朝廷から安堵された世襲的権利から、憲法が保障する地方政府の自治権へと、少しずつ性格を変えていった。[^u045]

# 背景

## 受容の経路

アメリカ連邦制の知識は、主に1871〜1873年の[岩倉使節団](../events/iwakura-mission.md)と、それと並行した領主家の視察によってもたらされた。中小領主や商工業者は、アメリカの鉄道会社・銀行・地方自治・土地制度・企業経営に関心を持った。南北戦争が回避されたことで、アメリカへの関心が強まる余地もあった。[^u043] 視察の主体は中央政府・元老院と諸領主・各領主家の政府や企業の三つに分かれ、元老院・諸領主の側は「領主権に適した立憲制度・地方自治・産業政策」を調べた。[^u043]

## 全国標準化との関係

欧米視察の後、元老院では全国標準化が必ず議題になる。[^u044] 領主たちは行政・司法・治安の権限は譲りたくないが、自領で作った商品を全国へ売るために、貨幣・交通・度量衡・商法の統一は望んだ。この「自治は守り、市場は統一する」という要求に、アメリカの州際通商条項は直接応えるものだった。詳細は[全国標準化政策](national-standardization.md)を参照。

# 参照された制度

## 合衆国憲法との対応

合衆国憲法第1条第8節は、連邦議会に州際通商の規制、貨幣の鋳造、度量衡の標準設定、郵便制度、国防などの権限を与えている。これが元老院議員たちの参考になった。[^u045]

| アメリカの連邦制度 | 日本帝国への応用 |
|---|---|
| 州際通商規制権 | 領国間の通商・輸送規格を帝国が統一 |
| 連邦の貨幣鋳造権 | 領主による独自通貨の発行を制限 |
| 度量衡の標準設定権 | 工業規格・商取引規格を全国で統一 |
| 連邦裁判所 | 領主間の紛争、越境事件、帝国法違反を審理 |
| 州政府の自治権 | 領主の行政・警察・司法権を存続させる |
| 連邦法の優位 | 帝国法と領主法が衝突した場合の優先関係を明文化 |

[^u045]

特に重要なのは、**連邦法の優位と地方自治の両立**である。元老院が制定した「例」は領主法に優越する。一方、例によって帝国に与えられていない統治事項は領主が担う。こう整理すれば、司法権や治安権を領主に残しても全国共通の法秩序を作れる。[^u045]

## ドイツとアメリカの組み合わせ

| 参照先 | 取り入れた要素 |
|---|---|
| ドイツ帝国 | 君主制、領邦間の権限分配、元老院の領主代表制度、軍事・外交の統合 |
| アメリカ合衆国 | 連邦法の優位、州際通商、連邦司法、地方自治、憲法上の権限分配 |

[^u045]

憲法の基本的な性格はドイツ帝国憲法（1871年）に近い君主制と領邦連合制の組み合わせである。[^u025] [元老院](genroin.md)は、各邦政府が代表を派遣するドイツの連邦参議院とは異なり、領主互選・無領華族互選・勅選の議員からなる。[^n1] アメリカの上院は州を代表し、日本の元老院は領主家・華族を代表するため、構成原理が違い、そのまま真似はできない。これに対し、連邦裁判所や州際通商の規制はかなり直接に応用できる。[^u045]

# 憲法改正構想

岩倉使節団に加わった領主議員は、アメリカ視察から帰国した後、次の改正を提案した。[^n2][^u045]

* **帝国通商条項**: 帝国ハ諸領主ノ領地相互ノ通商、外国貿易、貨幣、度量衡、郵便及全国交通ノ規格ヲ統一スル権ヲ有ス。
* **領主権留保条項**: 此ノ憲法ニ依リ帝国ニ属セシメザル権限ハ、各領主ニ留保セラル。
* **帝国法優越条項**: 帝国憲法及之ニ適合シテ制定セラレタル例ハ、諸領主ノ法ニ優越ス。

これらが成立すれば、中央政府は何でもできるわけではないが、全国市場を作るのに必要な事項については、領主が反対しても統一的な制度を定められる。領主たちは、自分たちの自治を守るためにこそ、中央政府の権限を明確に定義することを支持する。[^u045] 1869年の[大日本帝国憲法](imperial-constitution.md)第十一条案の「例ノ定ムル所ニ依リ」は、通常の立法で領主権を縮小する余地を残していた。[^u036] 領主権留保条項は、その不安に応える性格を持つ。

# 領主権の再定義

## 三段階の性格変化

| 段階 | 領主権の性格 |
|---|---|
| 1866〜1869年 | 朝廷から安堵された世襲的権利 |
| 1869年憲法以後 | 憲法によって保障される統治権 |
| 衆議院成立・連邦制受容以後 | 世襲領主を長とする地方政府の自治権 |

[^u045]

アメリカの連邦制を学んだ領主たちは、「**地方自治は君主の恩恵として存在するのではなく、憲法によって中央政府から保障される統治権である**」という新しい説明を手に入れた。これは領主にとって都合のよい考え方である。同時に、地方政府の権限が憲法で定義されるなら、領主の権限にも法的な限界がある、ということにもなる。1874年の建白書を経て衆議院ができると、地方政府にも住民の政治参加を認めるべきだという議論が広がる。[^u045]

領主権は消えるのではない。領主は存続するが、その権限は憲法と法律で制限され、領内の行政にも住民の参加が入っていく。そして重要なのは、**この制度が中央政府の押し付けではなく、領主たち自身の利益によって導入される**ことである。[^u045] 詳細は[領主権](lordship-rights.md)を参照。

## 経済への影響

アメリカ型の全国市場統合制度が大領主間の競争と重なると、次のような動きが起きる。[^u045]

* 島津家が製鉄・造船、前田家が鉄道・繊維、鍋島家が機械工業、徳川家が金融・商業に投資し、それぞれの企業が領地の境界を越えて競争する。
* 中央政府は統一通貨・共通商法・鉄道規格・全国通信網を整え、広域事業の障害を取り除く。
* 領主は自領に投資を呼び込むため、道路・学校・警察・裁判制度を改善する。

「**全国共通法による経済統合と、領主自治による地域間競争が同時に働く**」。ただし税制や裁判制度が領主ごとに大きく違えば投資や取引の障害になるため、商業分野では中央司法の権限が次第に広がる。1880年代には、史実以上に経済制度の統一が進む一方で、強い地方自治が保たれる。[^u045] 寄親圏の競争については[寄親・寄子制と大領主間の近代化競争](../concepts/yorioya-yoriko.md)を参照。

## 司法への影響

連邦裁判所にならい、帝国裁判所が領主間の紛争・越境事件・帝国法違反を審理する。[^u045] 条約改正の局面では、全国一律の裁判所ではなく「外国人にも適用される帝国共通法と、領主の判決を帝国裁判所が審査できる仕組み」が改正の鍵とされた。[^u046] 南北戦争が回避されたことで、1860年代から日米関係が史実以上に緊密だった可能性もあり、条約改正交渉では米国との個別交渉が先行すると想定される。[^u046] 詳細は[法体系（詔・勅・例・式）と司法制度](legal-system.md)と[不平等条約改正](../diplomacy/treaty-revision.md)を参照。

## 対外的な説明材料

戦間期、中国権益をめぐって米国から批判されたとき、日本は「近代的な議会制度と強い領主制の併存」を、**米国の連邦制度と比較できる政治構造**として説明する材料に使えた。[^u110]

# 視察団が見た矛盾

南北戦争の回避は、奴隷制問題が自動的に解決されたことを意味しない。日本の視察団は、州権の強さだけでなく、個人の自由と平等をめぐる深刻な矛盾も目にした可能性がある。[^u045] 史実では、南北戦争後の再建期に修正第13〜15条が成立し、特に1868年批准の修正第14条は、州政府に適正手続と法の平等な保護を義務づけて連邦による州権の制約を広げた。本世界線では、これらが同じ時期に同じ内容で成立するとは限らない。[^u045]

# 史実との比較

* 史実の明治政府はドイツ（プロイセン）型の憲法を主に参照し、府県制で中央集権化を進めた。アメリカの連邦制は、地方分権の参照先として本格的に採用されることはなかった。
* 史実の岩倉使節団（1871年12月〜1873年9月）はアメリカ・欧州を回り、『米欧回覧実記』などに成果をまとめた。ドイツ訪問はドイツ帝国が成立した直後だった。[^u044]
* 本世界線では、南北戦争が起きなかったアメリカ、つまり州権の強いアメリカが視察の対象になる。この点が、史実との最も大きな違いである。[^u045]
