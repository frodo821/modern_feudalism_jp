# 概要

本世界線の**大日本帝国憲法**は、名称と「天皇の詔による公布」という形式こそ史実と同じだが、成立の経緯と統治原理がまったく異なる。1866年の[無血の幕府解体](/events/bloodless-dissolution-1866.md)は、諸侯の所領安堵と引き換えに軍事権を朝廷へ回収することで成り立った。そのため、新政府の成立直後から「朝廷が何をできて、何をできないのか」を明文化する要求が諸侯の側から生じ、憲法は1867年の暫定国制協約を経て、1869年（明治3年）頃に詔で公布された。[^u034]

この憲法は、天皇から臣民へ与えられる欽定憲法というより、天皇のもとで諸侯が統治権の分担を確認する**国制協約**の性格を持つ。比較対象は1871年のドイツ帝国憲法に近く、君主制と領邦連合制を組み合わせたものとされる。[^u025] 標語的には「**形式は欽定、成立の実態は協約、統治原理は立憲君主制と領主自治の両立**」と要約される。[^u033]

公布から5年後の1874年には、この憲法が領主の権利ばかりを保障していることへの応答として[民撰議院設立建白書](/institutions/house-of-representatives.md)が出され、1870年代中盤の憲法改正で衆議院が加わって二院制となった。[^u035] その後もこの憲法は、開戦・戦費・軍縮をめぐる議会政治の枠組みとして1930年代まで機能し続ける。天皇に固有の統帥大権がないことは、その最も大きな帰結の一つである。[^u124]

# 制定の経緯

## なぜ早期に制定されたか

ユーザーが確定させた前提は次の三点である。

* 帝国憲法は史実とはかなり性格が変わり、天皇を君として**全領主の総意**に基づくものになる。[^u025]
* 名称はそのまま「大日本帝国憲法」とし、天皇の詔で公布する。[^u033]
* 諸侯は天皇に無限の権限を認めることができない。したがって憲法が史実どおり1880年代末まで制定されないなら、極端に大きな抵抗を別途説明しなければならない。[^u034]

諸侯からすれば、徳川将軍の権力を制限するために朝廷と協力したのに、今度は天皇と太政官が無制限の統治権を持つのでは意味がない。諸侯が最も警戒したのは「**天皇の名を借りた太政官が、勅命一つで領主を討伐できる制度**」であった。[^u034] 史実では自由民権運動が憲法制定を求める主体だったが、本世界線では憲法制定を要求する有力な主体、すなわち諸領主が最初から政権の内部にいる。朝廷側にも、所領安堵を憲法で保障すれば諸侯の協力を安定的に確保できるという動機があった。[^u034]

## 諸侯が求めた制限

元老院で諸侯が要求した事項は次のとおりである。[^u034]

* 領主権の変更には[元老院](/institutions/genroin.md)の同意を必要とする。
* 新たな租税・軍役は制定法で定める。
* 天皇の勅命は、原則として制定法を変更できない。
* 領主の処罰・所領没収には法定の裁定手続を必要とする。
* 元老院の議決なしに国制を変更できない。

1867年の新政府が棚上げできなかった問題と、それに対応する憲法上の規定は次のように整理される。

| 問題 | 憲法上必要となる規定 |
|---|---|
| 天皇と諸侯の関係 | 天皇の元首権と諸侯の領主権の区別 |
| 元老院の権限 | 立法・予算・軍事費に対する同意権 |
| 将軍職の廃止 | 軍権の帰属と中央軍の指揮権 |
| 所領安堵 | 領主権の保障と変更手続 |
| 太政官の統制 | 行政権の範囲と官吏の責任 |
| 法令の制定 | 詔・勅・例・式の効力関係 |

## 年表

| 年 | 出来事 |
|---|---|
| 1867年（明治元年） | 明治改元とともに元老院を設置し、**暫定国制協約**を定める。天皇の権限、領主権の保障、軍事・外交権、元老院の同意事項を規定し、この時点で朝廷の権限はすでに制限される（検討案）[^u034] |
| 1868〜1870年 | 元老院で国制を審議し、諸侯の承認を経て、司法・行政・基本的権利・改正手続を明文化 |
| 1869年（明治3年）頃 | **大日本帝国憲法を詔で公布**。元老院が立法機関として確立[^u035] |
| 1870〜1872年 | 元老院が軍制・租税・鉄道・商業などの全国共通法を制定。人民は議員を選べない |
| 1874年（明治8年） | 民撰議院設立建白書。憲法改正による衆議院設置を要求 |
| 1870年代中盤 | 衆議院設置のための憲法改正、二院制へ（1875年選挙法・1876年第一回総選挙の案もある）[^u026] |

立憲化の順序は「**諸侯による君主権の制限 → 成文憲法の成立 → 人民による政治参加の要求 → 二院制への発展**」となり、衆議院より憲法の方が先に成立する。初期憲法は天皇と諸侯の統治権を整理するものであって、民選議会を必須の構成要素としないためである。[^u034] 1869年という年は「頃」とされた有力案で、以後のやりとりでは一貫してこの年が前提として使われている。[^u037][^u088][^u133]

# 内容

## 成立根拠と公布形式の区別

この憲法では、次の四つを区別する。[^u033]

| 区分 | 内容 |
|---|---|
| 成立根拠 | 天皇の権威と、元老院を通じた諸領主・華族・勅選議員の合意 |
| 制定手続 | 議会の議決と天皇の裁可 |
| 公布形式 | 天皇が「大日本帝国憲法公布ノ詔」を発する |
| 法的効力 | 例・勅・式に優越する帝国の最高法規 |

詔は公布の形式であって、憲法を上書きする無制限の権限ではない。したがって、詔によって公布されても、**詔だけで改正することはできない**。[^u033] 法形式全体の中での位置は[法体系（詔・勅・例・式）と司法制度](/institutions/legal-system.md)を参照。法令の効力順は「帝国憲法・皇室典範 → 例 → 勅／式」で、憲法には「式ハ例ノ委任ニ依リ之ヲ定メ、例ニ反スルコトヲ得ス」「犯罪及刑罰ハ例ヲ以テ之ヲ定ム」といった原則が置かれる（検討案）。[^u032]

公布の詔の文案（検討案）は次のとおりである。[^u033]

> 朕、祖宗ノ大統ヲ承ケ、天下ノ諸侯ト協議シ、帝国ノ国制ヲ定ム。
> 諸侯ノ世襲領主権ヲ保障シ、帝国ノ統一及臣民ノ権利ヲ確立シ、元老院ノ議決ヲ経テ、茲ニ大日本帝国憲法ヲ公布ス。

要点は「天下ノ諸侯ト協議シ」の部分にある。公布時に議決を経るのは元老院のみである（会話ログの文案は「元老院及衆議院ノ議決ヲ経テ」とするが、衆議院のない1869年公布と合わないため、ユーザーの判断により「元老院」の誤記として訂正した）。前文では、1866年の所領安堵、1867年の明治改元、それ以後の議会による国政運営を、一つの連続した国制として確認する。[^u033]

## 基本条項（仮想条文・検討案）

以下は会話の中で示された仮想条文で、確定した正文ではない。[^u025]

* **第一条** 大日本帝国ハ万世一系ノ天皇ヲ君主トシ、諸侯ノ協同ニ依リ統治セラル。
* **第二条** 天皇ハ帝国ノ元首ニシテ、此ノ憲法ノ定ムル所ニ依リ国家ノ統治権ヲ行フ。
* **第三条** 諸侯ノ世襲領主権ハ帝国ノ保障スル所トシ、法律ニ定ムル場合ヲ除ク外、之ヲ侵スコトヲ得ス。
* **第四条** 帝国ノ外交、国防及全国共通ノ政務ハ中央政府之ヲ掌リ、地方ノ政務ハ憲法及法律ノ範囲内ニ於テ諸侯之ヲ行フ。
* **第五条** 帝国ノ立法ハ天皇ノ裁可及帝国議会ノ議決ニ依ル。

第一条の「諸侯ノ協同」が統治の根本原理なら、天皇と諸侯のどちらも一方的に国制を変更できない。天皇は国家統合の君主だが、各領主も憲法上の統治権を持つ存在になる。[^u025] 1869年の原典では第五条にあたる立法条項は「帝国ノ立法ハ天皇ノ裁可及元老院ノ議決ニ依ル」であったと想定される（衆議院設置時に改正）。[^u035]

## 領主権条項（仮想条文・検討案）

1869年頃に保障される[領主権](/institutions/lordship-rights.md)は、行政・徴税・警察・司法を含む包括的な固有権で、ほとんど「領邦主権」に近い。ユーザーはこの時点の領主権が治安権・司法権まで含むことを確定させている。[^u036]

* **第十一条** 帝国諸侯ノ世襲領主権ハ、此ノ憲法及例ノ定ムル所ニ依リ、之ヲ保障ス。
* **第十二条** 領主ハ其ノ領内ニ於テ、行政、徴税、警察及司法ノ権ヲ行フ。但シ帝国ノ憲法及例ニ違背スルコトヲ得ス。
* **第十三条** 帝国ノ外交、国防及全国軍ノ統轄ハ、中央政府ノ専管トス。
* **第十四条** 領主権ノ境界、相続及其ノ他ノ争議ハ、法定ノ裁定機関之ヲ審理ス。（→[領主権裁定院](/institutions/lordship-tribunal.md)）
* **第十五条** 領主権ノ停止、剥奪又ハ変更ハ、憲法ニ定ムル手続ニ依ルニ非サレバ、之ヲ為スコトヲ得ス。

第十一条の「例ノ定ムル所ニ依リ」を広く解釈すれば、通常の立法で領主の司法権・警察権を大きく縮小できてしまう。諸侯はそれを警戒し、領主権の基本的な内容は憲法で直接保障し、その変更には元老院の領主議員による特別な同意を求めるだろう、とされる。[^u036]

## 軍事権の規定

将軍への軍事委任を朝廷が停止したことが、この政体の成立原因だった。したがって、軍事権は最も慎重に規定される。[^u025] 検討案では次のように定める。

* 天皇は国家軍の最高統帥者とするが、その権限は憲法と議会の手続で制約される。
* 軍隊の常設と軍費の負担は法律で定める。
* 対外戦争には原則として元老院の同意を要する。
* 領主に対する軍事的強制は、司法手続または特別な議決を経なければならない。
* 中央の常備軍は徳川家や有力諸侯の私兵ではなく、帝国の共同財産である。

制定時の争点の一つは「軍の指揮権」と「軍事予算の決定権」の区別であった。[^u034] この規定の帰結として、本世界線では天皇に固有の統帥大権が存在せず、帝国軍の権限は「憲法によって構成された国家機関の権限」となる。詳しくは[統帥権（本世界線）](/institutions/supreme-command.md)を参照。[^u124]

## 改正手続

当初の検討案では、改正には天皇の裁可と元老院の3分の2以上の特別多数が必要で、領主権そのものを変更する場合は当事者の同意まで要する「二重の保障」が置かれた。[^u025][^u026] 衆議院成立後の案では、元老院・衆議院それぞれの特別多数と天皇の裁可を要し、領主権の根本的変更にはさらに元老院の領主議員による特別な同意を必要とする。[^u033]

## 制定時の争点

憲法を制定するかどうかへの反対は限られていた。しかし条文の内容には相当の争いがあった。[^u034]

| 争点 | 主な対立 |
|---|---|
| 領主権 | 永続的に保障するか、法律による変更を認めるか |
| 元老院 | 領主議員にどこまで拒否権を与えるか |
| 軍権 | 天皇の統帥権を議会がどこまで制約するか |
| 財政 | 中央政府が直接徴税できるか |
| 地方行政 | 領主と国司の権限の境界 |
| 憲法改正 | 天皇・元老院のどちらにどの程度の拒否権があるか |

「全領主の総意」を全員一致と解すると、一万石の小領主一人でも国家改革を止められる。そのため、諸侯団全体の合意、つまり特別多数として解する必要がある。[^u025]

# 改正と運用

## 1870年代の衆議院設置改正

1869年憲法が立法を「天皇ノ裁可及元老院ノ議決」と規定していた場合、衆議院を加えるには改正が必要になる。ただし「帝国議会ハ元老院及衆議院ノ両院ヲ以テ組織ス」とする限定的な改正で足り、領主権の保障や天皇の元首権は変えずに済む。衆議院に予算議決権を与えるなら、元老院との権限配分や軍事費負担の仕組みも改める必要がある。[^u035] 経緯は[衆議院と民撰議院設立建白書](/institutions/house-of-representatives.md)を参照。

逆説として、「諸侯が自らの権利を保障するために作った憲法が、今度は領民が政治的権利を要求するための根拠になる」。自由民権運動は「領主のための憲法」を「臣民のための憲法」へ改める運動として性格づけられる。[^u034][^u035] また、元老院が憲法の制定主体として特別な地位を保とうとすれば、衆議院が改正に参加できるかどうかが新たな政治問題になる。[^u034]

## アメリカ連邦制を参照した改正構想（検討案）

岩倉使節団でアメリカを視察した領主議員が、帰国後に次の三条項からなる憲法改正を提案する筋書きが示されている。[^u045]

* **帝国通商条項** 帝国ハ諸領主ノ領地相互ノ通商、外国貿易、貨幣、度量衡、郵便及全国交通ノ規格ヲ統一スル権ヲ有ス。
* **領主権留保条項** 此ノ憲法ニ依リ帝国ニ属セシメザル権限ハ、各領主ニ留保セラル。
* **帝国法優越条項** 帝国憲法及之ニ適合シテ制定セラレタル例ハ、諸領主ノ法ニ優越ス。

これにより、領主権は「朝廷から安堵された世襲的権利」から「憲法によって保障される統治権」へと説明が変わる。詳細は[アメリカ連邦制の受容と領主権の再定義](/institutions/federalism-reception.md)を参照。

## 新領土条項（検討案）

日清戦争後の新領土に対応するため、「帝国ノ新タニ取得シタル領土ハ、例ノ定ムル所ニ依リ、直轄地トシ又ハ領主権ヲ設定シテ之ヲ治ム」という条項案が示された。本土と海外領土で異なる統治制度を認めるかどうかは重大な憲法問題になる。[^u066] 詳細は[新領土の統治制度](/institutions/new-territory-governance.md)を参照。

## 開戦・戦費をめぐる運用

* 宣戦に元老院の同意、戦費支出に両院の議決が必要と定められていれば、政府は議会への説明を避けられない。派兵と宣戦を別の権限とするかどうかは論点として残る。[^u037]
* 1875年前後の江華島事件では、平時の測量航海や艦隊派遣に元老院の同意が要らない可能性がある。そのため、事件を口実に政府が元老院の事前承認なしでどこまで軍事行動を広げられるか、という憲法問題が生じる。[^u041]
* 1890年代の対露論議では、1869年憲法が天皇と世襲領主の権限調整で成立した以上、領主たちが無制限の軍事財政権限を中央へ渡したとは考えにくいとされる。天皇が軍の最高指揮権を持っていても、元老院・衆議院の同意なしに巨額の戦時公債を発行できないなら、政府は開戦前に議会の協力を取り付けねばならない。[^u088]
* 1930年前後の海軍軍縮では、適法に批准された条約に基づく政府の編制変更を、軍令部が天皇の固有大権を根拠に無効とすることはできない。[^u124]

## 首都との関係

1869年憲法が天皇と世襲領主の合意で成立したことは、朝廷が京都を離れる積極的な理由を弱めた。皇居・内閣・元老院・衆議院は京都に置かれる（→[首都京都と江戸](/regions/kyoto-edo.md)）。[^u133]

|---|---|---|
| 公布 | 1889年2月11日、上諭を付して公布、別に発布の勅語 | 1869年頃、「大日本帝国憲法公布ノ詔」で公布 |
| 統治原理 | 天皇による統治権の総攬（第4条） | 天皇を君主とし、諸侯が統治権を分担 |
| 成立 | 欽定憲法 | 勅裁を受けた諸侯との国制協約 |
| 制定の推進主体 | 政府（自由民権運動の圧力を受けて） | 自らの統治権を守ろうとする諸領主 |
| 地方制度 | 府県を中央政府が統治 | 世襲領主権と国郡制が併存 |
| 上院 | 皇族・華族・勅任議員による貴族院 | 領主権を代表する元老院 |
| 軍事 | 天皇の統帥大権 | 憲法と議会手続で制約された軍事権、固有の統帥大権なし |
| 改正 | 帝国議会の議決と天皇の裁可 | 天皇の裁可＋元老院（後に両院）の特別多数＋領主権変更は領主議員の特別同意 |
| 財政 | 既定経費・緊急財政措置で政府側に一定の保護 | 無制限の軍事財政権限は中央に与えられていないと解される |

史実では1875年に元老院が設置され、1876年に国憲起草が命じられ、1880年に草案が提出されたが採用されず、起草が本格化したのは1880年代後半だった。[^u034] 1869年は史実では版籍奉還の年であり、藩主の世襲的領主権が否定された年である。本世界線ではその年に、逆に領主権が憲法で保障される。[^u036] 史実の1889年憲法でも、華族は貴族院を通じて国政に参加した。[^u017] ドイツ帝国憲法（1871年）では、特定の構成邦に保障された権利を変更するには、その邦の同意が必要とされていた。[^u025]

# 却下・修正された案

* **1870年代暫定国制法・1880年代成文憲法案**: 1867年の諸侯協約を発展させ、1870年代に暫定的な国制法を作り、1880年代に成文憲法として整理する案が最初に示された。[^u025] その後、1880年代制定（史実どおり1889年公布でもよい）案も出された。[^u033] しかしユーザーが「諸侯は天皇に無限の権限を認められない、1880年代末まで制定されないなら極端な抵抗の説明が要る」と指摘し、1869年頃公布へ修正された。[^u034]
* **貴族院＋民選議院の二院制案**: 幕末段階では、爵位・家格を代表する貴族院と民選議院からなる二院制が想定されていた。[^u017] これは、領主権を代表する元老院を先に置き、のちに衆議院を加える構成に置き換えられた。[^u025][^u026]

# 未決の論点

* 公布年は「1869年（明治3年）頃」で、正確な年月日は未定。暫定国制協約の正式名称と内容も未定。[^u034]
* 条文はすべて仮案である。第1〜5条・第11〜15条・改正三条項・新領土条項の正文化は未定。
* 領主権の基本内容を憲法で直接保障するか、例に委ねるか。[^u036]
* 衆議院が憲法改正に参加できるか、衆議院の予算先議権の有無。[^u034][^u026]
* 開戦権限と戦費支出権限の具体的な規定（派兵と宣戦の分離、緊急勅令による戦費支出の可否、戦時公債発行の議会同意要件）。[^u037][^u088]
* 内閣・元老院・軍司令部の軍事権限の分配。[^u124]
