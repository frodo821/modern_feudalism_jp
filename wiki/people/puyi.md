# 概要

溥儀（1906〜）は清朝の第12代皇帝（宣統帝）である。1908年に光緒帝・西太后が相次いで死去すると2歳で即位し、父の醇親王載灃が摂政として[皇族中心の中央集権化](../events/late-qing-reforms.md)を断行した。[^e018]

史実では1912年2月12日、袁世凱の仲介による南北和議の結果として退位したが、本世界線には[袁世凱](yuan-shikai.md)がおらず、退位と共和政への政権移譲を一体で行う必然性がない。[^e013] 溥儀は**退位しないまま亡命した**。[^e020] 亡命先はロシア帝国で[^e024]、最初の居住地はウラジオストクである。[^e025] ロシアにとって退位していない溥儀は、中国の正統な統治者としての権利を主張できる外交資産であった。[^e024]

しかし1917年のロシア革命で溥儀は保護者を失った。その後の運命は定まっていない。[^n1][^e025] いずれにせよ、清朝崩壊の原因が皇族による集権化の強行だったため、旧清朝の官僚・軍人さえ復辟に消極的で、1930年の溥儀は皇帝の地位を主張しながら中国国内に実効的な支持基盤を持たない。[^e024][^e039]

# 退位しない亡命

## 判断の主体

1911年の溥儀はまだ5歳で、実際の判断は載灃や隆裕太后らが行う。彼らにとっては、革命派に退位を強制されるより、皇帝の地位を保ったまま安全な場所に退避する方が受け入れやすい。[^e020] ここで重要なのは、**皇室の身柄を保護することと、清朝の亡命政府を承認することは別問題**だという点である。[^e020]

## 国内退避案（不採用）

史実でも1911〜12年、清朝の主戦派は宮廷の退避先として熱河・満洲・甘粛を検討し、熱河では受け入れ準備が進み、奉天では皇帝を支持する軍事組織の編成が検討された。[^e020]

| 候補地 | 利点 | 問題点 |
|---|---|---|
| 熱河（承徳） | 離宮があり北京に近い | 独立した財政・軍事基盤が弱い |
| 満洲（奉天） | 清朝発祥の地、王朝支持勢力がある | ロシアの影響力が強い |
| 甘粛 | 清朝に忠実な軍事勢力がある | 経済基盤が弱く北京から遠い |
| 天津租界 | 列強による身柄の保護 | 政府としての活動が困難 |

[^e020]

国内での退避先としては「熱河への一時退避から奉天への宮廷移転」という経路が最も自然であった。これは厳密には亡命ではなく遷都で、満洲に1911年から連続する清朝残存政権が成立する可能性もあった。しかしその場合、清朝は北京の官僚機構と海関税収の大半を失いながら対外債務だけを抱え、**皇帝の正統性と国家の信用力が完全に分離する**。[^e020] 実際にはロシア帝国への亡命が選ばれ、この経路はとられなかった（→「編集注：却下・修正された案」）。[^e024][^e025]

## 受け入れ国の比較

| 国 | 受け入れる動機 | ためらう理由 |
|---|---|---|
| ロシア帝国 | 満洲・モンゴルへの影響力拡大 | 中国共和派との関係悪化 |
| 日本 | 皇室保護、外交上の交渉材料 | 内政干渉とみなされる。関東軍も満洲進出を前提とする大陸政策もない |
| 英国 | 人道的保護、旧清朝との関係 | 必要なのは清朝ではなく、債務と契約を履行できる中国政府 |
| ドイツ帝国 | 中国での政治的影響力 | 具体的利益が限定的 |
| フランス・米国 | 人道的保護 | 積極的に関与する動機が弱い／共和派との関係 |

[^e020]

日露戦争のない本世界線では、ロシアは史実以上に重要な受け入れ候補であった。[^e020]

# ロシア帝国の保護（1912〜1917）

## ウラジオストク

溥儀は1912年、退位しないままウラジオストクへ亡命し、ロシア帝国の保護を受けた。[^e025] 居住地の候補とその後の状況は次のとおりである。

| 居住地 | ロシア側の利点 | 革命後の状況 |
|---|---|---|
| サンクトペテルブルク | 皇帝の直接的な庇護 | 革命の中心地となる |
| クリミア | 皇族の居住・保養に適する | 白軍の支配地域となる |
| イルクーツク | 中国に比較的近い | 内戦に巻き込まれる |
| **ウラジオストク（採用）** | 中国への外交的影響力を維持しやすい | 比較的遅くまで反ボリシェヴィキ勢力が残る |
| ハルビン | 中国国内の王党派と連絡しやすい | ロシアの保護権力が崩壊する |

[^e024]

ハルビンは、本世界線では東清鉄道の権益が史実どおり成立したかが定まっておらず[^n4]、ロシアの勢力圏として史実どおりには成立しない可能性が高いため、居住地から外された。[^e024][^e025]（→[日露関係と対露抑止](../diplomacy/japan-russia-relations.md)）

## ロシアの思惑

ロシアは清朝の復辟を直ちに支援する必要はなく、皇室を保護しておくだけで北京政府への外交的な牽制になる。[^e024] ロシア帝国の対中支援の主眼は満洲の清朝残存勢力に置かれ、北京政府とは別の中国政府を北方に確保することにあった。満洲で清朝が存続すれば外交・金融支援、満洲でも崩壊すればロシア領内で皇室を保護する、という二段構えのうち、後者が実現したことになる。[^e023] 1917年のロシア革命で、この皇室支援は根本から崩れた。[^e023]

# ロシア革命後

二月革命・十月革命の時点で溥儀は11歳であり、再亡命の判断は引き続き皇族・旧臣が行う。溥儀はロマノフ家の一員ではなくロシア帝位の継承権もないので、ボリシェヴィキが同じ扱いをする必然性はない。[^e024] 革命の混乱のなかで死亡した可能性も、生き延びて再亡命した可能性もある。[^n1][^e024][^e025]

## 考えられる展開

| 展開 | 成立条件 |
|---|---|
| 革命・内戦中に死亡 | 退避に失敗し混乱に巻き込まれる |
| ソ連による拘束 | 外交上の交渉材料とされる |
| 中国への送還 | 共和派との関係改善に利用される |
| 白軍とともに再亡命 | 旧臣やロシア側の保護者が健在 |
| 第三国による保護 | 外交交渉を経てロシアから出国 |

[^e024]

史実でもシベリアの白軍政権は1920年に、ウラジオストクの反ボリシェヴィキ政権は1922年に崩壊し、多数のロシア人が中国へ逃れた。[^e024]

## 再亡命先の候補

| 再亡命先 | 可能性 | 政治的意味 |
|---|---|---|
| 日本 | 高い | 皇族として保護、政治活動は制限 |
| 英国 | あり | 人道的保護、中国政治からの隔離 |
| フランス | あり | 旧ロシア亡命者社会に合流し、欧州で生涯を送る |
| 満洲 | 地方政権次第 | 復辟運動の中心になりうる |
| ドイツ | 時期による | 敗戦後は皇室を支援する利益が乏しい |
| 米国 | 比較的低い | 南方共和派との関係が障害 |

[^e024]

## 日本への再亡命

最も有力な経路は、ロシア内戦を経て日本へ再亡命するものである。[^n2][^e024][^e025] 日本は北京・両江・湖北の連合（[中国諸省聯合](../diplomacy/china-federation.md)）を支援しているため復辟は支援できず、受け入れの条件は次のようになる。

- 溥儀の皇族としての待遇を認める。
- 清朝皇帝としての外交的承認は行わない。
- 皇室の財産と生活を保護する。
- 日本国内での復辟運動や亡命政府の活動は認めない。

溥儀自身は退位していないが、日本もその皇帝としての権利を承認しないという曖昧な状態となる。史実と異なり日本には溥儀を使って満洲に国家を建てる必要がないので、溥儀は皇帝を自称しながら政治的にはほぼ無力な亡命皇族として生きることになり、満洲の政治史は清朝皇室の処遇から切り離される。[^e024]

# 中国政治における位置

## 正統性の三すくみ

清朝崩壊後の中国では、正統性の根拠が三つに分かれる。[^e025]

| 主体 | 正統性の根拠 |
|---|---|
| 亡命清朝皇室 | 皇帝の地位と王朝の継続 |
| [中国諸省聯合](../diplomacy/china-federation.md) | 国家機構・実効支配・対外権利義務の承継 |
| [中華民国（広州）](../diplomacy/republic-of-china-canton.md) | 革命と国民主権 |

聯合は皇室の帰還を認める必要がなく、共和国を宣言しなくても清朝の国家機構を運営できる。[^e025] 北京の聯合も南方の中華民国も溥儀を中国の統治者として認めない。[^e024]

## 復辟運動の弱さ

各勢力のなかで溥儀の王朝存続を正面から支持するのは皇室と禁衛軍くらいで、奉天系や馬家軍の年長世代に忠誠派が残る程度である。奉天が溥儀を奉じたとしても、地方軍の指揮権維持・地方財政の皇室からの独立・皇室の政治権限の制限を求め、載灃が望んだ皇族中心の国家にはならない。[^e022] 清朝崩壊の原因が皇族の集権化そのものであったため、旧官僚・旧軍人も復辟には消極的で、運動は小規模にとどまる。[^e024] 1930年時点で亡命清朝皇室は実効的な政治権力を失っている。[^e039]

# 編集注：却下・修正された案

- **清帝の退位の有無**：前編の段階では清帝が退位したかどうか詰め切れていなかった[^e013]が、会話ログ2で退位しないまま亡命することが確定した。[^e020]
- **熱河→奉天への宮廷移転（満洲での清朝存続）**：当初、外国亡命より自然な経路として「北京から熱河へ退避→奉天への宮廷移転→満洲の地方軍・ロシアとの交渉→存続か亡命か」が示され、満洲に1911年から連続する清朝政権が成立する可能性も挙げられた。[^e020] その後の議論で溥儀はロシア帝国の保護下に入ることが確定し、置き換えられた。[^e024][^e025]
- **奉天派が清帝を奉じて東三省を統合する経路**：張作霖に相当する地方軍人が皇室を受け入れ、清帝を奉じる軍事政権として東三省を統合する可能性が示されたが[^e021]、溥儀のロシア亡命確定により採られなかった。[^e025]
- **ペテルブルク・クリミア・イルクーツク・ハルビンでの居住**：いずれも候補に挙がったが、ウラジオストクが選ばれた。ハルビンは東清鉄道問題との関係で外された。[^e024][^e025]
