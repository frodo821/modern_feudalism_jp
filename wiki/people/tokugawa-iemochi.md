# 概要

徳川家茂（1846〜1866）は江戸幕府第14代将軍である。本世界線では、[桜田門外の変の失敗と井伊直弼の押込](/events/sakuradamon-incident-failed.md)ののち、幼少の家茂のもとで老中主導の幕政が[水戸藩処分（1860年）](/events/mito-domain-disposal-1860.md)と[1861年公武協定](/diplomacy/kobu-agreement-1861.md)を推し進めた。成長した家茂は、その成功体験と全国常備軍を背景に、国内の「火種」を軍事力で片端から消そうとする強硬路線に傾いた。[^u013]

1866年、家茂は朝廷の勅許がないまま[第二次長州征討](/events/second-choshu-expedition.md)を強行して敗れた。同年7月の病没は史実どおりである。しかし本世界線では、その死が「将軍への軍事委任の終了」と解釈され、朝廷が後継者への再委任を拒んだことで、徳川幕府は戦争を経ずに終わった。家茂は事実上最後の征夷大将軍となった。[^u014][^u015]

# 生涯

## 若年期と老中主導の幕政（1858〜1861）

家茂は1846年に生まれ、1858年に第14代将軍に就いた。1860年時点では数え15歳にすぎず、初期の重大決定、すなわち水戸藩処分と公武協定は老中たちが主導した。[^u013]

井伊直弼が押込によって失脚したのち、幕政は次のような顔ぶれで再編されたと想定される（検討案）。家茂は将軍としての正統性を保ち、将軍継嗣問題を蒸し返さずに改革を進める立場に置かれた。[^u002]

| 人物 | 想定される役割（検討案） |
|---|---|
| 徳川家茂 | 将軍、正統性の維持 |
| 安藤信正 | 公武合体と朝廷との関係修復 |
| 久世広周 | 老中として補佐 |
| 松平春嶽 | 諸侯の調整、幕政改革 |
| 一橋慶喜 | 改革派の中心（ただし後述のとおり修正） |

一橋慶喜を改革派の中心に据える案は、水戸処分の厳罰化によって不自然になった。慶喜は斉昭の子であり、政治的な信用の回復に時間がかかる。このため、家茂を中心とする幕政改革の比重がより大きくなった。[^u004]

公武協定の締結時、家茂はまだ若年だった。朝廷の権威を借りて諸藩の軍事協力を確保することは幕府にとって魅力的に映り、将来の制度変化までは見通されていなかった。[^u010]

## 強硬路線への傾斜（1862〜1865）

水戸藩を処理しても、すべての火種が消えたわけではない。若い将軍が火種を片端から叩き潰そうと考えても不思議ではなかった。水戸処分が深刻な内乱を招かずに成功したこと自体が、家茂にとって危険な成功体験となった。[^u013]

幕府が警戒した勢力は次のとおりである。[^u013]

| 勢力・地域 | 幕府が警戒する理由 |
|---|---|
| 長州藩 | 尊王攘夷運動、朝廷への政治工作 |
| 薩摩藩 | 独自の軍事力を背景にした幕政への介入 |
| 京都の尊攘派公卿 | 朝廷の権威を使って幕府の政策を制約しうる |
| 諸藩の急進派藩士・浪士 | 藩主の意向と別に武力行動を起こしうる |
| 有力な親藩・譜代大名 | 幕政改革や軍制統一をめぐって幕閣と対立しうる |

ただし1860年の時点で、薩摩や長州が倒幕を目標にしていたわけではない。家茂がこれらすべてを敵視するようになるには、1860年代前半の政治対立の積み重ねが必要だった。[^u013]

想定される経過は次のとおりである（検討案）。[^u013]

- **1860〜1861年**: 水戸徳川家を処分し、旧水戸領の統治機構を再編する。
- **1862年**: 朝廷の裁可を得て[全国常備軍](/military/standing-army-1861.md)を編成する。家茂の周辺で「幕府の命令を実行できる軍隊が整いつつある」という認識が強まる。
- **1863年**: 薩英戦争を受けて「諸藩が独自に軍備を整える時代は終わった。皇国の防衛は朝廷の命を受けた将軍が一元的に担う」と主張する。[^u016]
- **1863〜1864年**: 京都政局に軍事介入し、尊攘派の武装勢力を中央軍で鎮圧して最初の成功を収める。
- **1865年以降**: 軍制改革に抵抗する藩に対し、水戸処分と同様の手法を検討する。

家茂の強硬化は、権力欲から来るものではなかった。国家の安全保障と中央集権化を急ぐうちに軍事的な解決へ傾いていった、という経緯として描かれる。史実の家茂は公武合体を重視し、和宮との婚姻や上洛を通じて朝廷との関係維持に努めた人物であり、その人柄を最初から専制的なものに変えるわけではない。[^u013]

## 危険な転換点

水戸処分には「大老への武力襲撃」という明白な正当化があった。しかし、諸侯が軍制改革に反対することは、それ自体では反逆ではない。しかも中央軍は朝廷の裁可と諸藩の協力で成り立っており、それを異議を唱える諸侯への懲罰に使えば、将軍が協定上の権限を逸脱したと批判される。[^u013]

> 最初は幕府の秩序を守るために軍事力を使い、次第に幕府の政策に反対すること自体を秩序への挑戦とみなす。

家茂はこの区別を見失った。「朝廷が認めた軍事指揮権を使って、朝廷の意向に反する政治的決定を実現してよいのか」という問いに直面し、自ら築いた軍隊をどこまで自由に使えるかを試そうとした。[^u013]

## 第二次長州征討（1865〜1866）

1865年、朝廷は第二次長州征討の勅許を保留した。家茂にとって長州征討は、一藩への懲罰ではなく「中央政府の命令が全国で実効性を持つかを試す事件」であった。長州だけが処罰を免れれば、ほかの藩も命令を軽んじ始める。1866年初頭、家茂は朝廷の停止要求を退けて中央軍を西国へ進めた。長州軍が幕府軍の一部を破ると、諸藩の部隊は藩主への照会と撤収を始めた（経過は[第二次長州征討と最初の憲政危機](/events/second-choshu-expedition.md)）。[^u014]

戦況が悪化して家茂が改めて勅許を求めても、朝廷は出兵の停止と軍権の再確認を条件とする。勅許を得なければ軍を維持できず、勅許を得るには自らの軍事権を縮めなければならない、というジレンマに家茂は陥った。[^u014]

## 死去（1866年7月）

家茂は1866年7月20日（旧暦）、史実どおり病没した。強硬路線をとれた期間はきわめて短い。将軍の敗戦だけでなく、将軍の死そのものが、中央軍の忠誠問題を初めて顕在化させる契機となった。[^u013]

朝廷は「徳川宗家の相続」と「将軍への軍事委任」を別の行為と解し、家督相続を認めながら軍事委任の更新を保留した。軍権は朝廷預かりとなり、諸侯には所領安堵が通達された。こうして[1866年の無血の幕府解体](/events/bloodless-dissolution-1866.md)が進んだ。[^u015]

# 評価

家茂の政治的運命は逆説に満ちている。[^u013]

1. 幕府を守るために軍隊を近代化する。
2. 軍隊を近代化するために朝廷から権威を借りる。
3. 朝廷の権威で諸藩を動員し、中央軍をつくる。
4. その軍隊で国内の反対勢力を抑え、幕府の権威を強めようとする。
5. 最後には朝廷自身がその軍隊の行動を否認する。

家茂は軍隊を保有しながら、それを使う政治的な正統性を失った。さらに、1863年に家茂が掲げた「皇国防衛の一元化」の論理は、1866年に朝廷が「将軍の死で軍事行政を止めるわけにはいかない」として恒久的な軍務機関を置く根拠に転用された。家茂は、軍事権を統一しなければ独立を守れないという原則を自ら確立し、その原則によって徳川家の統治の必然性を失わせたことになる。[^u016]

# 後継問題

本世界線では水戸徳川家が厳罰を受け、斉昭の子である一橋慶喜の政治的立場は不安定である。史実のように慶喜が当然の後継者になるとは限らない。慶喜が宗家を相続したとしても、朝廷は将軍宣下を見送ることができる。慶喜には、委任の再開を交渉する、宗家当主として新政権に参加する、軍事力で将軍職の承認を迫る、という選択肢があった。しかし三つ目は、指揮官が命令を拒む公算が大きく危険であった。[^u015]
