# 概要

張謇（1853〜1926）は、江蘇の実業家・教育者・立憲派の政治家である。本世界線では、清朝崩壊後の1912年に成立した[中国諸省聯合](/diplomacy/china-federation.md)の**創設者・初代「聯合主席」**となる（確定）。[^e026][^e027] 聯合は強力な軍事指導者が他の軍閥を従属させた組織ではなく、各地方政権が清朝以来の対外権利義務を共同管理するための組織であるため、その主導者には軍事力以上に地方間の利害調整能力と対外的な信用が求められた。張謇はその条件に最も適した人物とされた。[^e026]

1912〜26年は「張謇による聯合形成・安定期」と位置づけられる。張謇は聯合の**制度的創設者**であり、軍事的な存立を支える実質的指導者[黎元洪](/people/li-yuanhong.md)との二重構造の一方を担った。[^e026][^e027] 1926年に史実どおり死去すると、聯合は文民的な調整能力を失い、後継者問題と[北伐](/events/northern-expedition.md)の時代に入る。[^e026][^e027]

# 経歴（史実）

史実の張謇は実業家・教育者であり、1909年に江蘇諮議局議長に就任した。清末の立憲運動を主導したが、辛亥革命後は共和制を支持する立場に転じた。地方自治と立憲政治を結びつけて考えていた人物である。[^e026] 1911年の鉄道国有化問題では、立憲政治の早期実現を条件として国有化と外国借款を支持した立憲派の一人であった。[^e026]

本世界線では、1909年の江蘇諮議局議長就任までは史実と同様と考えられる。[^e026] 清末の摂政載灃が皇族中心の集権化を強行し、維持費を地方に負担させたまま人事権と指揮権だけを中央へ移そうとしたことで、王朝を支持していた立憲派まで離反した。[^e018] 両江（江蘇）の立憲派は、皇族の集権化に強く反対する一方で外国資本との関係を壊す動機は乏しく、日英にとって最も信用できる地方政権の担い手になりうる存在であった。[^e022]

# 聯合主席への選出

## 選ばれた理由

本世界線の張謇には、聯合の主導者として次の利点がある。[^e026]

* 皇族中心の中央集権化に反対する政治的立場
* 江蘇の商工業者・地方有力者との強い結びつき
* 旧清朝官僚とも交渉できる経歴
* 外国資本の利用に対する抵抗が比較的小さいこと
* **独自の軍事力を持たず、他の軍閥にとって脅威になりにくいこと**

最後の点が特に重要とされた。特定の軍閥の指導者を代表にすれば、他の軍閥はその人物による中央集権化を警戒する。張謇ならその問題をある程度回避できる。[^e026]

## 聯合観

張謇は地方自治を重視したが、国家の分裂を積極的に望んでいたわけではない。そのため聯合を恒久的な分裂体制ではなく、**将来の中国再統合のための暫定制度**と考える可能性が高い。[^e026] これは、国号と国体を恒久憲法の制定まで留保し、従来の中国国家の対外権利義務を共同管理する暫定機構だと主張する聯合の性格と一致する。[^e025]

# 聯合主席としての役割

## 機構上の地位

聯合主席は、中国諸省聯合代表会議（加盟省政府の代表で構成）の議事、地方間の調整、対外代表を担う。各省は独自の政府・軍隊・財政を維持し、**聯合主席は各省軍の統帥権を持たない**。[^e026] 主席の下には外交委員会（唐紹儀ら外交官）・財政委員会（旧清朝官僚・金融実務家）・軍事協議会（黎元洪ら各省軍代表）・交通委員会（鉄道・水運・郵便）が置かれる。[^e026]

この体制では、聯合の政治的中心は北京にあっても、実際の経済的・政治的な主導権は張謇の基盤である**江蘇**にある。[^e026]

## 権力分担

| 権力基盤 | 担い手 |
|---|---|
| 政治的調整・制度設計 | 張謇 |
| 軍事力・安全保障 | 黎元洪 |
| 金融・経済 | 江蘇・上海の実業家 |
| 外交・国家債務 | 北京の旧清朝官僚 |
| 地方行政 | 各加盟省政府 |

（検討案。[^e027]）

聯合は内部が不安定である以上、軍権が支配力の実態となり、次第に黎元洪が主導権を握る（確定）。[^e027] 張謇の役割は、軍事力ではなく調整と制度によって聯合を成り立たせることにあった。1910年代後半には軍閥間の紛争を背景に黎元洪の発言力が増し、軍事協議会が事実上の最高意思決定機関になっていく（検討案）。[^e027]

## 聯合の訴求力

張謇型の聯合は、どちらにも属さない軍閥への政治的訴求力でむしろ中華民国に勝る可能性があった。聯合加盟は地方軍・地方財政・地方自治を維持したまま対外権利義務の共同管理に参加することであり、軍閥にとって支配権の放棄を意味しないからである。[^e026] 一方で、統一を求める知識人・学生・青年軍人の支持は[中華民国](/diplomacy/republic-of-china-canton.md)に向かった。[^e026]

# 死去と後継問題（1926）

張謇は史実どおり1926年に死去する。これは聯合にとって第一次の大きな政治的危機であり、ちょうど史実で北伐が始まった年に重なる。[^e026] 南方の中華民国が軍事力を蓄えて北伐を計画しているなら、聯合創設者の死去は絶好の機会となる。[^e026]

| 後継者の型 | 聯合の変化 |
|---|---|
| 唐紹儀 | 外交・連省自治を重視する体制の継続 |
| 黎元洪 | 軍事協力の強化 |
| 梁啓超 | 立憲制度と恒久的な国家形成の推進 |
| 華北系軍人 | 軍事的中央集権化 |
| 江蘇系実業家・官僚 | 経済共同体としての性格を維持 |

（E26の検討案。ユーザーは黎元洪が主導権を握る方向を選んだ。[^e026][^e027]）

張謇の死後、黎元洪が聯合の実質的な最高指導者となり、湖南内戦と北伐を経て聯合は外交・経済共同体から軍事的共同体へ変質する。[^e027][^e031] さらに1928年に黎元洪も[武昌公邸火災事件](/events/wuchang-residence-fire-1928.md)で怪死し、聯合は1926〜28年の間に文民・軍事双方の創設世代を失った。**張謇の死去で文民的な調整能力を失い、黎元洪の怪死で軍事的な調整能力まで失った**聯合は、深刻な指導者不在に陥る。[^e027][^e034] 1930年になっても最高指導者は現れず、聯合は軍事協議会による暫定集団指導体制のもとにある。[^e035]

# 評価

張謇の聯合は、強い中央政府を持たずに対外信用と通商秩序を維持するという点で、日英にとって最も都合のよい体制であった。[^e023][^e026] しかしその成立の論理そのもの――独自の軍事力を持たない調整者を頂点に置くこと――が、北伐という軍事的圧力に対して聯合を軍人の指導へ移行させ、張謇の死後は個人の権威に依存しない制度化という課題を残した。[^e027][^e035]
