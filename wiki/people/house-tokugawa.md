# 概要

本世界線の徳川諸家は、1866年の[無血の幕府解体](../events/bloodless-dissolution-1866.md)で将軍職と全国統治権を失ったが、家名と所領を保ったまま近代に入った。徳川宗家は新政府に参加する有力諸侯の一つとなり、尾張・紀伊の両家も諸侯連合政府の一員となった。[^u015]

近代の三家はそれぞれ異なる経済的性格を持つ。徳川宗家は旧幕府の債務を整理して国内金融・産業投資・不動産を中心とする巨大な資産保有型の家となり、1937年には純資産90.16億円で全領主家の首位に立つ。尾張徳川家は明治初期の近代化に失敗したのち、木曽の林業・水力と金融を足がかりに機械・自動車・航空機へ進んだ後発工業資本で、宗家を中心とする**徳川系広域連合**の一翼を担う。紀伊徳川家は林業・製紙・水力発電を中心とする資源・公益事業型の資本で、宗家から経済的・政治的に独立した領主連合を率いる。[^p037][^p045][^p046][^p096]

三家の近代経済史は、共通8項目と家ごとの固有項目の成否によって分かれた。[^n1] 枠組みと全領主家の比較は[領主家の経済史と家産（1867〜1937）](../economy/lord-houses-economy.md)を参照。

# 近代国制における徳川諸家

1866年の政変では「徳川宗家の相続」と「将軍への軍事権の委任」が別の行為とされ、朝廷は宗家の家督相続と所領保有を承認しながら、全国統治権の世襲継承は認めなかった。徳川家は最大の敗者とはならず、領地と家格を保ち、経済力・人脈・旧幕府官僚としての経験によって影響力をしばらく保った。旧幕府の本拠地である江戸は、改称されずに徳川家の本拠地かつ東国最大の商業・金融都市として発展する（[首都京都と江戸](../regions/kyoto-edo.md)）。[^u015]

1867年の華族令は、徳川家を中心とする武家の序列を解体し、天皇を中心とする貴族秩序に組み替える意図を持っていた。徳川宗家は旧将軍家としての歴史的地位を認められて**公爵**とされたが、徳川一門全体に特別な爵位は保障されず、御三家・御三卿に特例は設けられなかった。武家は表高を基準に叙爵され（侯爵30万石以上）、尾張徳川家（61.95万石）と紀伊徳川家（55.50万石）は石高により侯爵相当となる。御三家・御三卿は公的な格式としては廃止され、徳川家内部の家門としてのみ残った。[^n13][^p016][^p017] 華族令の詳細は[1867年華族令と初叙爵（家格と石高による爵位配分）](../institutions/kazoku-ordinance-1867.md)を参照。

幕末の債務整理と大戦期の資産形成でめざましい成功を収めた一方、旧幕府系事業の近代化と海外進出には失敗した。旧幕府の経済機構を温存するのではなく、一度整理したうえで近代的な資本保有主体に転じ、**国内金融・産業投資・不動産を中心とする巨大な資産保有型の領主家**になった。国際的な金融資本ではなく、国内経済に深く根を張った金融資本である。幕末の政治的権威を失った代わりに、近代的な金融・投資資本を形成した家といえる。[^p037]

## 1866〜1880年：旧幕府財産と債務の整理

債務整理の大成功により、旧幕府の資産と債務は次のように区分された。[^n2][^p037]

| 旧幕府の資産・債務 | 帰属 |
|---|---|
| 全国統治に必要な行政施設 | 帝国 |
| 軍艦・兵器・軍事施設 | 帝国 |
| 全国行政・軍事に伴う債務 | 帝国 |
| 徳川宗家固有の所領 | 徳川宗家 |
| 宗家の家産・不動産 | 徳川宗家 |
| 宗家固有の債務 | 徳川宗家 |
| 幕府系商業事業 | 個別に清算・移管 |

幕府の公的債務と徳川宗家の私的債務を明確に区別できたことが、財務再建の成功につながった。既存事業の近代化には失敗したため、旧幕府の御用商人や専売事業をそのまま企業集団にしたわけではなく、旧事業を清算して得た資金を新規投資に回した。ただし、旧幕府直轄地のうちどれだけを宗家領として維持できたかは明らかでない。[^n4][^p036][^p037]

## 1880〜1913年：徳川系金融資本の形成

宗家は自ら工場を経営する産業資本家ではなく、**徳川系銀行・資産管理機関**を通じて多くの企業に出資する投資家として発展した。投資先は工業企業、鉄道・不動産、北海道開発、中小領主への融資である。工業資本の形成は辛うじて成功した程度であったため、島津家や鍋島家のような技術・製造業主導の企業集団にはならなかった。強みは多様な産業に資金を供給し、その収益を家産として蓄積できる点にある。[^n2][^p037]

## 北海道開拓

北海道開拓の成功は、旧幕臣の生活問題を処理する手段であると同時に、新しい資産形成の機会でもあった。宗家は北海道で直接領国を広げるとともに、独立分家や開拓功労者への融資を併用した。[^n2][^p037]

| 投資分野 | 主な収益 |
|---|---|
| 農場・牧場 | 農畜産物販売・地代 |
| 山林 | 木材・製紙原料 |
| 炭鉱 | 石炭販売・鉱業会社配当 |
| 鉄道 | 貨客輸送収益 |
| 港湾周辺不動産 | 賃貸収益 |
| 開拓金融 | 融資利子 |
| 独立分家への出資 | 配当・利子・政治的連携 |

[^p037]

## 第一次世界大戦期の資産形成

大戦期には通常の戦時景気を超える利益を得た。[^n5]徳川系銀行は軍需企業の設備資金、商船建造、輸出企業の運転資金への融資で大きな利益を上げた。国際金融には進出していないため、巨額の対英債権を直接持つのではなく、国内の企業・金融機関を通じて戦時経済の恩恵を受けた。その最大の成果は、戦時利得を消費せず、**戦後も継続的に収益を生む資産へ転換できたこと**である。[^n2][^p037]

| 戦時利益の獲得経路 | 戦後の資産形成 |
|---|---|
| 工業企業への出資 | 工業株式の長期保有 |
| 軍需企業への融資 | 金融資産の拡大 |
| 造船・海運関連投資 | 交通・物流企業の持分 |
| 帝国公債の引受 | 安定した利子所得 |
| 都市経済の成長 | 不動産価値の上昇 |
| 戦時利益の再投資 | 国内企業の経営権・持分取得 |

[^p037]

## 1927〜1937年

全国的な領主間の相互支援体制は1927年以降に動揺したが、宗家自身は大規模な資産毀損を免れた（最大毀損率5〜15%[^n2]）。徳川系金融機関が傘下の中小領主への融資や保証を縮小した可能性はある。他家が経済力を失ったため宗家の相対的地位は上がったが、金融圏どうしの寄子獲得競争には敗れており、危機に乗じて他家の寄子を奪うことはしていない。[^n6]資本蓄積モデルでは、宗家の純資産は1927年の74.21億円から危機中に66.79億円まで下がり、1937年には90.16億円に回復した（1937年価格）。[^p037][^p069]

## 後発工業資本としての発展

尾張家は明治初期の近代化に大きく失敗し、1890年代以降に金融・電力・機械工業で追い上げた**後発工業資本型**の家である。名古屋の商人・実業家が工業化を進める一方、尾張家は債務を抱えて投資できず、繊維工業でも独立系実業家が先行した。「領国経済の発展と領主家自身の経済的成功が一致しない」典型例である。[^n2][^p045]

初期の財政難は、すでに債務整理に成功していた徳川宗家の金融支援で乗り切った。これが後の両家の政治関係を規定する。[^n10][^p045]

転換点は木曽林業・水力の大規模な資本化の成功である。木曽の森林資源と尾張系金融機関（預金・産業金融・証券引受）を組み合わせ、木曽川水系の水力発電・電力供給を起こし、それを繊維・繊維機械・工作機械、さらに中京工業地帯の資本形成につなげた。なお、領主権に基づく森林管理権・水利権と、尾張家が持つ林業会社・電力会社の資産は区別され、家産所得になるのは私有山林の収益・配当・利子である。[^n2][^p045]

| 時期 | 主な展開[^n2] |
|---|---|
| 1890年代 | 繊維・紡績（独立系企業への出資・工場取得） |
| 1900年代 | 繊維機械・工作機械 |
| 1910年代 | 鉄道車両・産業機械 |
| 1920年代 | 自動車・内燃機関 |
| 1930年代 | 航空機・航空発動機 |

[^p045]

主な事業は、繊維機械（紡績機・織機）、工作機械（旋盤・フライス盤・研削盤）、鉄道車両（客車・貨車・電動車）、自動車（貨物・乗用・発動機）、航空機（民間機・軍用機）、航空発動機、電力である。航空機生産能力や軍用機のシェアは明らかでない。[^n4]領主系の機械工業のなかで、尾張家は自動車・航空機・輸送機械を専門とする。[^p045][^p047]

## 金融危機

金融危機では僅差で大規模な資産毀損を避けられなかったが、[^n11] 企業集団の解体には至らず、一時的な工業投資の停滞にとどまった。金融機関は不良債権・評価損、繊維は需要低迷、電力は需要の一時減、機械は設備投資需要の減少、海外資産は評価損を受けたが、林業は維持され、航空工業は1930年代の国防需要で成長した。最大毀損率は15〜25%で、宗家からの支援が続いたとみられる。[^n2][^p045]

## 資源・公益事業型の産業資本

紀伊家は林業・製紙・水力発電を中心とする**資源・公益事業型の産業資本**である。北海道開拓に失敗したため、紀伊半島の既存資源を徹底して開発した。林業は植林・育林・製材・販売を一体とする長期経営である。[^n2][^p046]

| 幕末の基盤 | 近代の事業[^n2] |
|---|---|
| 山林・木材 | 林業・製材会社 |
| 木材流通 | 卸売・建築資材 |
| 和紙・林産物 | 機械製紙 |
| 柑橘・農産物 | 食品加工・販売 |
| 漁業 | 水産加工 |
| 河川・山岳 | 水力発電 |
| 商人信用 | 地域銀行・産業金融 |

[^p046]

木材化学・人造繊維と海運・商業には失敗した。製紙用パルプは事業の一環として発達したが、溶解パルプの大規模化には至らず、人造繊維は主力にならなかった。沿岸海運は自社製品の輸送中心にとどまり、大坂の商業資本は支配できず、販売は独立系の商社・海運会社を経由した。[^n2] 化学繊維は後に福井松平家が担う。[^p046][^p054]

## 水力発電と電力資本

紀伊半島の水力発電の大規模な資本化に成功し、紀伊家は主要な領主系電力資本の一つとなった。畿内の都市や独立系工業企業への売電が重要な収入である。水力発電の主な担い手は鳥取池田・佐竹・尾張徳川・紀伊徳川の四家である。総発電量650億kWhのうち紀伊系のシェアは明らかでない。[^n4][^p046][^p054]

## 金融危機

林業・電力は長期の収益資産だが、設備投資の回収に時間がかかり、資金繰りが悪化した。林業は建設需要の低迷と木材価格の下落、製紙は価格・収益の低下、水力は設備投資債務、地域銀行は不良債権、領主間金融は支援縮小に見舞われたが、山林と発電設備の相当部分は維持された。最大毀損率は20〜35%で、1930年代の景気回復と電力需要の拡大で一定程度回復した。危機後も宗家の金融的支配下には入っていない。[^n2][^p046]

# 徳川諸家の政治経済圏

## 二層構造の徳川系広域連合

旧幕府の家門関係は、そのまま近代の政治関係に引き継がれたわけではない。徳川系の領主勢力は次の二層構造をとる。[^n2][^p045][^p046][^p051]

- **徳川宗家**（全国的な国内金融資本）→ **尾張徳川家**（中部金融圏・工業資本）→ 中部・関東などの協力領主・関連企業・実業家・徳川系諸家
- **紀伊徳川家**（独立した資源・電力資本）→ 紀伊系金融機関 → 畿内・紀伊の協力領主

尾張家は宗家に完全に従属しているわけではない。初期の財政支援や金融機関どうしの資本関係を背景に対外的には共同歩調をとり、元老院では尾張系領主が独自の小会派をつくりつつ、首班指名や重要議案では宗家系と協力する。宗家は尾張家を通じて中部にも影響力を持つ。[^p045]

紀伊家が独立できたのは、明治初期の債務整理に成功して宗家の財政援助を必要とせず、独自の資本を形成できたからである。独立は敵対を意味せず、個別の政策では協力もありうる。徳川一門としての関係は残るが、元老院では異なる政治連合に属する。[^p046]

周辺の大領主も徳川系から独立している。津の藤堂家は尾張徳川家から強固に独立し、[^n12]宗家から独立した紀伊家とともに、畿内・伊勢の領主勢力として宗家中心の広域連合に対抗する基盤になりうる。彦根の井伊家も宗家から独立した領主連合（近江・畿内連合）を形成した。[^n12][^p051][^p053] 両家については[北陸・近畿の領主家（前田・福井松平・井伊・藤堂）](houses-hokuriku-kinki.md)を参照。

## 金融圏の規模

| 金融圏 | 中核家 | 中核家の純資産 | 所属家数 1927年→1937年 | 1936年領主互選の獲得議席[^n2] |
|---|---|---:|---|---|
| 徳川広域連合 | 徳川宗家・尾張徳川家 | 104.34億円 | 33→32 | 20議席（32家中、当選率62.5%） |
| 紀伊・畿内系 | 紀伊徳川家 | 18.14億円 | 9→8 | 5議席（8家中、62.5%） |

[^p069][^p077][^p078]

徳川広域連合は大領主系の金融圏で最大で、中堅領主では佐倉堀田家・川越松平家・明石松平家がこれに属する（関東の中堅は安定した資産保有型で、徳川宗家中心の金融圏に属するのが通例である[^n2]）。[^p064][^p077] 互選では、徳川宗家の推薦候補に票が過剰に集まり、推薦されなかった寄子が落選することもある。[^p078] 金融圏全般は[領主金融圏と諸侯共済会（1867〜1937）](../economy/lord-financial-spheres.md)を参照。

## 元老院での位置

1936年元老院選挙後、徳川宗家と尾張徳川家は**宗交会**に、紀伊徳川家は**六合会**に属する。[^n3]宗交会は徳川系・旧来の大領主・旧幕臣系華族の、明治初期以来の家門間の交際と信用関係にもとづく歴史の長い倶楽部（63議席）で、保守思想の共有を入会条件とせず、開明的な領主や工業資本家も所属する。六合会は東北・四国・山陰などの地域領主による寄り合い所帯である。政治勢力の類型としては、徳川系は「大領主保守派」の支持基盤に数えられる。[^p077][^p079] 詳細は[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)を参照。
