# 概要

北陸と近畿の4家は、いずれも1937年まで[領主権](../institutions/lordship-rights.md)を保った大領主だが、近代の経済的な歩みは大きく異なる。[^p047][^p053]

- **前田家（加賀）**は100万石を超える農業経済から出発し、幕末債務の整理に失敗したまま近代化を進め、国内金融と国際金融を両輪とする金融資本になった。[^n1]1927年以降の金融危機で大きな損失を出したが、1937年にも純資産41.58億円で全領主家の2位にある。[^p038][^p096]
- **福井松平家（越前）**は越前での工業化に致命的に失敗したのち[^n1]、北海道開拓での大きな成功によって再起し[^n1]、当主と家産管理機構・企業統括本部を北海道へ移した。精密機械を主力とし[^n1]、前田家を中心とする北陸連合の地域的中核である。[^p052]
- **井伊家（彦根）**は近江商人の全国商業網を取り込み、総合商社・保険・信託・資産運用を中核とする巨大な商業資本を築いた。商業網の形成・繊維卸売・大戦期の資産形成・金融危機の回避の四つで際立った成功を収め[^n1]、金融危機をほぼ無傷で通過して、1937年には純資産39.86億円の3位に上がった。[^p053][^p096]
- **藤堂家（津）**は伊勢湾や交通の結節点という地理的優位を資本化できなかったが、領国外への投資で繊維・機械工業と金融の独立産業資本を形成し、尾張徳川家から強固に独立した。[^p051]

各家の近代経済史は、共通8項目と各家固有の項目の成否によって概観できる。[^n2] 枠組みと全領主家の比較は[領主家の経済史と家産（1867〜1937）](../economy/lord-houses-economy.md)を参照。

| 1937年純資産 | 41.58億円（2位） | 14.49億円（11位） | 39.86億円（3位） | 6.86億円（21位） |

## 債務を抱えたままの近代化（1867〜1880年）

前田家は初期の財政再建に失敗したが、債務を抱えたまま新規事業に投資した。[^n3]米穀収入は商業・金融資本に、絹織物は製糸・織物工場に、塩・特産品は専売事業の企業化に、山林は林業・製紙に、商人資本は共同出資に、既存の信用関係は銀行設立と借入に振り向けられた。当初は前田家自身の資金調達のために設けた金融機関が、のちに全国的な銀行へ成長した。[^n3][^p038]

## 北陸産業金融圏（1880〜1913年）

前田家を中心とする北陸産業金融圏は、製糸・織物（初期の主力）、銀行・信託（中核）、水力発電（1900年代以降）、電気化学・肥料、製紙・林業（北陸・北海道の資源）、機械工業、農業・食品からなる。水力発電への進出はかろうじて成功したにとどまり[^n6]、全国的な電力支配ではなく、北陸の有力な電力資本という程度である。北海道開拓は開拓金融・農林業での限定的な成功であった。[^n3][^p038][^p052]

## 国際金融資本へ

第一次世界大戦期、日本は英国に巨額の戦時債権を持ったが、前田系金融機関はその民間部門の主要な担い手の一つになった。海外事業は対英戦時金融、海外公債、国際貿易金融（手形割引）、海外企業への出資、国際銀行業務（為替・決済）、海外商業不動産に及び、ロンドンなどに恒常的な金融拠点を置いた。[^n3]前田家の海外資産は日本の純対外資産97.1億円の内数であり、日本全体の対外資産を増やすものではない。[^p038]

那珂川家とともに日本を代表する領主系国際金融資本であるが、前田家が銀行業務・証券投資から海外へ進出したのに対し、那珂川家は工業貿易・技術・事業金融を起点とした点が異なる。[^p047]

## 1927〜1937年の損失

1927年以降の金融危機では、国内企業の債務不履行、中小領主への融資（保証・救済負担）、株価下落、海外金融市場の混乱、為替変動、預金流出によって大きな損失を出した。国際金融への進出そのものが失敗したわけではない（最大毀損率25〜40%）。[^n3]ただし危機の過程で前田系は海外企業への出資などの海外資産の多くを失い、日本の海外直接投資が1937年に30億円にとどまる主な理由となった。[^n7]資本蓄積モデルでは、純資産は1927年の44.00億円から危機中に29.70億円まで下がり、1937年には41.58億円に回復した（1937年価格）。[^p038][^p069]

1927年以前の前田家は中小領主に積極的に融資していたため、危機後は支援能力が低下し、傘下の一部の領主が領主権を奉還したり、諸侯共済会で資金を求めたりした。前田家自身にも、1920年代後半の家門財産と領国財政の分離改革（公私会計分離）を支持する理由が生まれた。家産の損失を領国財政から切り離せば、領主権を維持できるからである。[^n3][^p038]

## 越前の挫折と北海道への本拠移転

福井松平家は、越前での工業化の失敗を北海道で取り返し、家の本拠を北海道に移した家である。[^n10][^p052]

| 時期 | 段階[^n3] |
|---|---|
| 1867〜1870年代 | 旧藩財政の再建（債務整理・商業事業の企業化） |
| 1870〜1880年代 | 越前工業化計画の挫折（大規模設備投資の失敗・家産の毀損） |
| 1880〜1890年代 | 北海道への重点投資（開拓領・山林・農場・資源事業の獲得） |
| 1900年代 | 北海道を基盤とする経済再建（農林業・電力・加工業） |
| 1910〜1920年代 | 繊維・精密機械資本へ発展（戦時利益の再投資・海外進出）。北海道での成功資金を越前に再投資 |

[^p052]

法的には、領主権を奉還せず福井に領国政府を残したまま、当主と家産管理機構が北海道に移った。完全な転封ではなく、**飛地領国を持つ領主家の本拠地変更**であり、北海道を「第二の領国から主たる領国へ発展させた代表的な家」とされる。[^p052]

| 機能 | 1937年の所在[^n3] |
|---|---|
| 当主の主たる居所 | 北海道 |
| 家門の財産管理機関 | 北海道 |
| 系列企業の統括本部 | 北海道 |
| 元老院議員としての活動拠点 | 京都 |
| 越前領国政府 | 福井 |
| 北海道領国政府 | 北海道の領都 |
| 繊維工業の主要拠点 | 越前 |
| 機械工業 | 北海道・越前 |
| 海外貿易拠点 | 敦賀・北海道の港湾 |

[^p052]

北海道の本拠の候補には、札幌周辺（農業開発・行政・金融・企業経営の統括。ただし札幌の授封状況の確定が前提）、室蘭・胆振方面（港湾・石炭輸送・機械工業の産業都市）、旭川・上川方面（内陸開拓地・農林資源）、小樽・後志方面（日本海貿易・商業・物流、敦賀との連携）が挙げられる。[^n10][^p052] 同じく北海道開拓で際立った成功を収めた津軽家は、本拠を移さず弘前・青森・北海道南部の複数拠点型をとった点で対照的である。[^p062] 北海道については[北海道（分領支配）](../regions/hokkaido.md)を参照。

## 精密機械と化学繊維

精密機械工業への進出に際立って成功し[^n1]、福井松平系企業集団は繊維機械（高性能織機・紡績機）、工作機械（精密旋盤・研削盤）、計測機器（工業用測定器・検査機器）、精密機器（時計・計器・精密部品）、光学機器（レンズ・光学計測装置）、産業機械（製紙・化学繊維向け設備）、軸受・工具を手がける。1937年には他の領主系企業に精密加工設備・計測機器を供給する重要な役割を持つ。[^n3] 南部系製鉄企業集団からは精密機械・工作機械用の鋼材を購入する。[^p052][^p055]

化学繊維では、紀伊徳川家・岡山池田家が失敗したのに対し、福井松平家は成功した。北海道の森林資源を越前の人造繊維工業に、越前の繊維機械技術を北海道の一般機械工業に回す分業である。[^n3][^p052]

## 前田家との関係と金融危機

前田家からの独立には失敗したため、福井松平家は前田系の広域金融圏に組み込まれ、その中の地域的中核となった（前田家 → 福井松平家 → 越前・若狭の中小領主・北海道の協力領主）。徳川宗家と尾張徳川家の関係に近い二層構造だが、独自銀行を持たないぶん前田家への金融依存度はより高い。ただし北海道と精密機械で独自の基盤が強く、完全な従属ではない。本拠移転によって、前田系の領主連合は北海道にも政治的影響力を持つことになった。[^n3][^p052]

金融危機では、前田家自身の資産毀損による前田系金融機関の信用収縮、北海道の地価下落と開発債務、繊維輸出価格の下落、海外証券の評価損、精密機械の設備投資需要の低迷が重なった。最大毀損率は25〜40%で、水力は維持された。1930年代の設備投資と再軍備で回復の余地が大きかった。[^n3][^p052]

# 井伊家

## 幕末の背景

井伊家は、1860年に大老[井伊直弼](ii-naosuke.md)が桜田門外の襲撃を生き延びながら、彦根藩重臣の押込によって実権を失った家である。家老たちは家名を守るために幕府との協調を選んだ。[^u002] 近代の井伊家は、この政治的挫折とは対照的に、最も成功した商業資本家門の一つとなる。

## 近江商人との共同出資

井伊家は、近江商人の全国的な商業網を基盤に、**商社・卸売・保険・信託・資産運用を中核とする巨大な商業資本**を形成した。四つの際立った成功はすべて商業資本の形成と維持に関わる。[^n1][^p053]

近江商人との関係は一方的な支配ではなく、独立した商人資本と領主家資本の共同出資による全国的な商業組織である。井伊家は家産・信用・長期投資資金を、近江商人は全国の商業網と経営人材を出し、井伊系総合商社と共同出資企業をつくった。商人の経営上の独立性は一定程度維持される。製造設備ではなく取引網そのものを資本化した点に特色がある。[^n3][^p053]

| 総合商社 | 工業原料・機械・農産物 |
| 小売・卸売 | 全国販売網 |
| 企業出資 | 独立系製造業への少数持分 |
| 物流 | 倉庫・鉄道・貨物 |

## 銀行を持たない金融資本

井伊家は預金銀行の形成には失敗したが、保険料収入を基礎とする長期運用、華族・実業家の家産管理と信託、商社による取引先への信用供与、株式・社債投資、中小領主の資産管理・債務整理によって、非銀行型の金融資本となった。1924年前後の華族特権拡張で確立した家門自治権は、井伊系信託事業の発展機会になった。家法に基づく家産管理、後継者への財産承継、家門企業の株式保全を専門に扱う金融機関である。ただし信託によって家門司法権が金融機関へ移るわけではない。[^n3][^p053] 家門自治権については[家門自治権と家門司法権（1924年の華族特権改革）](../institutions/family-autonomy.md)を参照。

1937年には独立系の保険・証券・信託の巨大企業集団が成立しておらず[^n12]、井伊系金融機関は保険・信託・家産管理の主な担い手の一つである。[^p084]

## 大戦と金融危機

第一次世界大戦期には、貿易の拡大、商品価格の上昇、英国向けの物資供給で大きな利益を得た。自ら工場を建てず、全国の独立系・領主系の製造業者から調達して輸出し、戦時の商業利益と対外債権を国内企業株式・外国債券・土地に転換した。徳川宗家が国内で資産を形成したのに対し、井伊家は国内外に分散した。[^n3][^p053]

金融危機では、中核となる預金銀行を持たないため直接の影響が限られ、信託は分別管理、証券は分散、現預金・公債で流動性を確保していた。1920年代には過度な借入や系列企業への集中融資を避けていた。危機後には経営難企業の株式や事業資産を取得する余力を持ち、他家の寄子を奪うより企業資産の取得で拡大した。最大毀損率は0〜5%である。[^n3][^p053] 資本蓄積モデルでは、純資産は1927年の27.25億円から危機中も26.57億円にとどまり、1937年には39.86億円に伸びた。ほぼ無傷で危機を通過したことで、前田家に匹敵する経済力を得た。[^p069]

首都京都での資産形成には失敗した。井伊家は首都の政治・行政需要に依存せず、彦根を歴史的な本拠として、大坂・江戸などの商業都市と全国の取引拠点で事業を展開する。[^p053]

## 地理的優位を資本化できなかった家

伊勢湾の港湾・工業用地、伊賀・伊勢の鉄道・物流、石油関連施設は、他の領主系・独立系資本や帝国政府が担い、藤堂家の家産所得には結びつかなかった。領国の経済は他の資本が開発し、領国政府は税収を得る。これは領国が未発達だったことを意味しない。[^n3][^p051]

| 1919〜1923年 | 設備投資の失敗・反動不況（大戦の長期資産化に失敗） |

# 金融圏と元老院での位置

## 三つの金融圏

| 金融圏 | 中核家 | 中核家の純資産 | 所属家数 1927年→1937年 | 1936年領主互選の獲得議席[^n3] |
|---|---|---:|---|---|
| 北陸連合 | 前田家・福井松平家 | 56.07億円 | 20→17 | 11議席（17家中） |
| 近江・畿内連合 | 井伊家 | 39.86億円 | 14→15 | 10議席（15家中） |
| 伊勢系 | 藤堂家 | 6.86億円 | 8→7 | 4議席（7家中） |

[^p069][^p077][^p078]

北陸連合は前田家の危機後の支援能力低下で所属家を減らした。井伊家は経済力を大きく伸ばしたが、寄子を積極的には獲得しておらず、所属は1家増えたにとどまる。中堅領主では姫路酒井家が井伊系に属する。[^p077] 近畿の中堅領主は工業化と危機対応に成功した堅実な中堅工業資本で、井伊・紀伊徳川・徳川宗家などの金融圏に属する可能性がある。[^p064] 金融圏全般は[領主金融圏と諸侯共済会（1867〜1937）](../economy/lord-financial-spheres.md)を参照。

## 倶楽部と政治勢力

1936年元老院選挙後、前田家・福井松平家・井伊家は**交友倶楽部**（60議席）に、藤堂家は**興業会**（57議席）に属する。[^n5]交友倶楽部は近江・北陸・都市商業資本・銀行家華族による、商業・金融・共同出資の交際にもとづく倶楽部で、無領華族の加入が多い。興業会は工業系の領主・実業家・技術者華族による比較的新しい倶楽部である。[^p079]

政治勢力の類型としては、井伊家・前田家は「商業金融派」、福井松平家は「産業振興派」の支持基盤に数えられる。[^p077] 井伊家は近江・畿内の領主（家産管理・信用供与）、実業家華族（商業・共同出資）、旧公家系華族（信託・資産管理）とつながり、領主互選だけでなく無領華族互選にも経済的人脈で影響を及ぼす**領主・無領華族横断型の政治勢力**である。政策としては自由貿易、財産権の保護、交通制度の統一、家門自治権の維持を掲げる。[^n3][^p053] 詳細は[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)を参照。

# 編集注：却下・修正された案

- **前田家が1920年代に徳川宗家を上回った可能性（P38）**：判定直後、独自金融93と国際金融97から、前田家は1920年代には徳川宗家を上回る金融資本だった可能性があるとされた。その後の資本蓄積モデル（P69）では、1927年時点でも徳川宗家74.21億円に対し前田家44.00億円で、宗家が上回っている。[^p038][^p069]
- **会話ログ1における前田家の像**：既存の寄親・寄子の例示では前田家を「北陸の産業・交通整備。鉄道・繊維」の担い手とし、北海道では「開拓資本・港湾・交通整備」の投資家としていた。会話ログ3では、繊維は維持しつつ主軸は国内金融と国際金融、水力・電気化学に移り、北海道開拓は49対45の限定的な成功（開拓金融・農林業）とされた。[^p038][^p052]
- **井伊家の位置づけ**：判定前、井伊家は近江商業・金融・繊維を基盤とする追加候補の一つにすぎず、首都京都への近さも強みと見られていたが、京都での資産形成は失敗した。[^p047][^p053]
- **海外直接投資80億円**：会話ログ2では1937年の日本の海外直接投資を80億円と想定していたが、前田系の危機時の海外資産喪失により30億円にとどまるとされた（作者確定）。[^p038]
- **会派名「商工経済会」**：会話ログ3の倶楽部名の第一案では、交友倶楽部の前身にあたる会派を「商工経済会」とし、自由貿易、国際金融、信用秩序、商業法制、財産権を重視する会派として描いていた。[^p078][^p079]
