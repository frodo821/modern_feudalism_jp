# 概要

全国常備軍（公武合体軍、中央軍）は、[1861年公武協定](../diplomacy/kobu-agreement-1861.md)で朝廷が発した「全国海防の勅命」を根拠に、幕府が諸藩から軍費と兵員を集めて編成した常備軍である。軍をつくる権威は天皇に、日常の指揮は将軍と幕府の軍事官僚にあった。しかし兵士の多くは藩籍を保ったまま出向しており、その忠誠は直接には出身藩の藩主に向いていた。[^u009][^u011]

このため、最初に生まれたのは「国軍」ではなく「諸侯連合軍」であった。この構造上の矛盾は、勝っているあいだは隠れていた。しかし、[第二次長州征討](../events/second-choshu-expedition.md)で朝廷の同意を欠いたまま出兵して敗れたとき、そして[徳川家茂](../people/tokugawa-iemochi.md)が死んだときに一気に表面化した。この軍は1866年の[無血の幕府解体](../events/bloodless-dissolution-1866.md)を経て朝廷政府に引き継がれ、のちの[帝国軍](imperial-army.md)の母体となった。[^u012][^u015][^u030]

# 創設の経緯

## 「日本国軍」の構想

幕藩体制のもとでの中央集権化で最大の難所は、軍の統一であった。徳川家の私兵ではなく、朝廷の権威を背景にした「日本国軍」を、藩兵の出向から始め、中央による費用負担、将校の共同養成、新規採用の一本化という段階を踏んでつくる構想が描かれた。ただし指揮権が将軍・朝廷・諸侯政府のどこに属するかは未解決のまま残された（検討案）。[^u003]

対外危機が迫るなかで「国家独立のために軍事費を負担せよ」という要求は通りやすいが、「軍隊を幕府に渡せ」という要求は諸藩に抵抗される。軍事力が地方の実力者に集中した清朝の轍を踏まないためにも、将軍直属軍ではない国家の軍隊という建前が必要だった。[^u008]

## 公武協定による法的根拠

幕府が幕府の権威だけで常備軍を始めるのは難しかった。旧水戸領を皇族領として朝廷に差し出す代わりに天皇の号令を得る、という取引がその解決策である。勅命によって、軍役は「将軍への封建的奉仕」から「皇国防衛のための国家的義務」へと再定義された。[^u009]

負担方式は軍費の納入を基本とし、兵員の供出を補助とした（検討案）。初期の規模は数千人程度の常備歩兵・砲兵・工兵で、そこから段階的に拡大する。[^u009]

| 年 | 段階（検討案） |
|---|---|
| 1861 | 水戸領献上と全国海防勅命 |
| 1862 | 全国軍役改革。軍費の納入基準を定め、諸藩の出向兵と幕府の直募兵で中央常備軍を創設 |
| 1863 | 江戸湾・大坂湾・下関海峡などへの実戦配備。藩の独断の対外軍事行動を制限 |
| 1864〜1866 | 軍役金の恒常財源化。中央による募兵と装備調達の拡大 |

[^u009]

# 組織と忠誠構造

## 三層の区別

忠誠の問題を考えるには、次の三つを分ける必要がある。[^u011]

| 問題 | 本世界線での想定 |
|---|---|
| 誰の権威で軍をつくるか | 天皇 |
| 誰が日常的に指揮するか | 将軍・幕府の軍事官僚 |
| 兵士は誰に忠誠を感じるか | 出身藩の藩主、直属の上官、あるいは将軍 |

藩籍を保ったまま中央軍に出向する藩士の俸禄や家族の生活は、依然として藩主に依存する。将軍の命令と藩主の意向が食い違えば、兵は板挟みになる。[^u011]

## 二重構造: 諸侯連合軍としての実態

1862年に勅命で全国から兵員を集め、江戸近郊で訓練したとする。薩摩藩兵、越前藩兵、尾張藩兵、紀伊藩兵、幕臣部隊などが数百人ずつ参加し、西洋式の訓練を受け、武器の規格もそろえて、作戦では幕府の将校に従う。それでも所属・俸禄・昇進経路が藩ごとに異なるなら、実態は諸侯の軍事同盟に近い。[^u011]

| 層 | 担い手 | 役割 |
|---|---|---|
| 正統性 | 天皇 | 軍創設の正統性、重大な軍事行動の裁可 |
| 指揮 | 将軍・中央軍司令部 | 訓練・作戦・日常的な指揮 |
| 部隊 | 薩摩藩兵・越前藩兵・幕臣部隊など | 俸禄・身分・家族の生活保障は各藩主のもとに残る |

この軍は外国との防衛戦では統一軍として振る舞える。しかし国内の政治紛争では諸藩の連合体に戻ってしまう危険があった。[^u011]

## 将軍と藩主の非対称性

- 将軍の権威は、朝廷から委任された制度上の権限である。
- 藩主の権威は、家臣との継続的な主従関係である。

将軍が諸侯の権限を制限しようとすれば、藩主は「我々は皇国防衛のために兵を出したのであって、徳川家の私兵として差し出したのではない」と主張でき、その主張には一定の説得力があった。[^u011]

## 四種の軍隊の並存（検討案）

創設から最初の10年間には、性格の異なる四種の軍隊が並存すると想定される。[^u011]

| 軍隊 | 実際の忠誠・所属 |
|---|---|
| 従来の藩兵 | 藩主と藩の家臣団 |
| 諸藩から供出された中央軍 | 藩主への忠誠を残しつつ中央司令部の指揮を受ける |
| 幕府が直接雇用した中央軍 | 幕府の俸給・人事制度に依存 |
| 朝廷直属の近衛部隊 | 朝廷・皇室への直接の忠誠（朝廷が裁可権を得たのち創設を求める可能性） |

## 真の常備軍への四条件

諸藩からの出向をやめ、中央が直接雇用する軍へ置き換えるには、少なくとも次の四つの変更が必要とされた。[^u011]

1. 俸給を中央政府が支払い、家族への扶助も中央が担う。
2. 軍籍を藩籍から分け、藩主が兵を勝手に召還できないようにする。
3. 将校の任命権を中央に置き、藩主が自藩出身者の昇進を左右できないようにする。
4. 藩別の編成を解き、出身藩の異なる兵士を同じ部隊に配置する。

ただし、中央政府が勅命によって設置されている以上、新しい軍の忠誠先は必ずしも徳川家にはならない。将軍は軍をつくりながら、自分の家臣ではない兵士を増やしていくことになる。決定的なのは「誰が給金を払い、家族の暮らしを保障し、昇進を決め、除隊を命じられるか」であり、そこを押さえた組織が時間をかけて実質的な忠誠を得ていく。[^u011]

## 旧水戸領での試行（検討案）

旧水戸領では、新しい形式の部隊を試すことができた。幕府に恭順した旧藩士を採用し、領内から直接兵を募る。彼らは水戸徳川家の家臣でも皇族の私兵でもなく、朝廷の裁可でつくられ、幕府が俸給を払い、将軍の軍事官僚が指揮する兵である。ただし旧藩士を大量に入れれば昔の人的なつながりが軍内に残るため、新規募集の兵を中心とし、将校は他地域から配置する方が安定するとされた。[^u011]

# 運用と崩壊

## 初期の成功

1863年の薩英戦争は「一藩の軍備では列強海軍に対抗できず、一藩の紛争で日本全体が責任を問われる」ことを示した。これが将軍主導の軍制改革への支持を広げた。家茂は「諸藩が独自に軍備を整える時代は終わった。皇国の防衛は朝廷の命を受けた将軍が一元的に担う」と主張できた。[^u016]

京都の政局でも、尊攘派の武装勢力を中央軍が鎮圧するような最初の数回の成功が想定される（検討案）。そうした成功は、朝廷の支持と諸藩の協力という前提条件を将軍に忘れさせる危険をはらんでいた。[^u013]

## 「負けるとき」に表面化する忠誠問題

忠誠の矛盾が最初に表面化するのは、幕府が負けるときである。朝廷・幕府・諸藩が「西洋列強に対抗する」という大義で一致しているあいだ、矛盾は隠れている。[^u012]

崩壊は兵士の反乱からではなく、将校の命令拒否から始まると想定される（検討案）。[^u012]

1. 将軍が朝廷の意向に反する軍事行動を命じる。
2. 朝廷が勅裁を欠くとして停止を命じる。
3. 諸藩出身の指揮官が命令の適法性を問題にし、藩主に照会したり行動を一時停止したりする。
4. 最初の敗戦が起き、諸藩が兵員の召還や軍費の支払い停止を検討する。
5. 中央軍が、幕府に従う部隊、朝廷に従う部隊、中立を宣言する部隊に分裂する。

将軍が対朝廷戦の準備を命じた瞬間に、指揮官が「勅許のない出兵には従えない」と拒み、戦う前に政治的に負ける可能性もある。逆に初戦で将軍が優勢なら、忠誠が実力を持つ将軍へ収束する可能性もあった。最大の争点は「朝廷の権威そのものが軍を動かすのか、将軍が握る俸給・人事・指揮系統が勝るのか」である。[^u012]

> 幕府軍は敗北によって軍隊を失うのではなく、敗北によって、それまで軍隊を保有できていた政治的な前提を失う。

[^u012]

## 第二次長州征討と家茂の死

1866年、家茂は勅許のないまま第二次長州征討を強行した。長州軍が幕府軍の一部を破ると、諸藩から供出された部隊では勅許のない作戦に従う義務があるのかが問題となり、藩主への照会や部隊の撤収が始まった（詳細は[第二次長州征討と最初の憲政危機](../events/second-choshu-expedition.md)）。[^u014]

同年の家茂の死去により、朝廷は軍事委任を更新せず「天下兵馬の統轄」を朝廷預かりとして、全軍に現状維持を命じた。朝廷は既存の指揮官をできるだけ留任させ、俸給と身分を保障したうえで、指揮権の名義だけを変更した。こうして軍事衝突を避けた。[^u015]

# その後

1866年以降、朝廷は「皇国防衛は一元的に運営せねばならぬ。将軍の死で軍事行政を止めるわけにはいかない」として、朝廷のもとに恒久的な軍務機関を置いた。幕府が確立した軍事統一の原則が、そのまま朝廷政府に引き継がれた。新政府は薩摩などの軍事指導者を中央軍の幹部に登用するなどの妥協を必要とした。史実の御親兵に相当する、諸侯から独立した軍事基盤をこの常備軍から生み出せるかが、次の争点となった。[^u016]

1867〜1870年には朝廷政府が旧幕府軍を引き継いで中央の軍事行政を統合し、1870年代には各領主が軍費負担を金納化して独自軍を縮小した。1894年までに帝国陸海軍は統一された国家軍となる（[帝国軍](imperial-army.md)を参照）。この長い蓄積は、日清戦争時の帝国軍が史実より強い理由の一つとされる。[^u029][^u030]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 根拠 | 幕府独自の軍制改革（1862） | 朝廷の全国海防勅命（1861年公武協定） |
| 兵の出所 | 主に旗本・御家人からの兵賦 | 全国の諸藩からの出向兵と幕府の直募兵 |
| 給与 | 兵卒の食料は幕府、給金は主家。1866年に金納・直接雇用へ転換 | 軍費の納入を基本とし、中央給与化が国軍化の条件 |
| 崩壊の契機 | 1868年の鳥羽・伏見の敗戦と錦の御旗。淀藩が入城を拒み、津藩が離反 | 1866年の勅許なき長州再征の敗北と家茂の死。軍事委任の不更新 |

史実の幕府は、少なくとも自らの軍事権を朝廷との新たな協定で明示的に制限した状態から出発したわけではない。本世界線では軍権の正統性そのものが朝廷の裁可に結びついているため、崩壊はより構造的なものになる。[^u011][^u012]

# 未決の論点

- 国軍化の四条件（中央給与・軍籍分離・将校任命・混成編成）が1866年までにどこまで実施されたか。[^u011]
- 朝廷直属の近衛部隊が実際に創設されたか。[^u011]
- 1863〜1864年の京都での鎮圧に中央軍が実際に関与したか。[^u013]
- 1866年の解体時に、幕臣部隊・江戸城守備隊・幕府海軍がどう処遇されたか。[^u015]
