# 概要

1936年12月31日に[第二次ロンドン海軍軍縮会議](../diplomacy/second-london-conference.md)の全面決裂でロンドン条約が失効すると、1937年1月から米英日の海軍軍備拡張競争が本格化した。[^e061] この競争の構図は、**米国は海軍の排水量を増やそうとし、日英は海上で運用できる航空戦力を増やそうとする**というものである（検討案）。[^e066] 日英は[航空主兵論](naval-aviation-1935.md)を採用し、米国は戦艦・航空併用論を維持していた。[^e065]

1937年の判定で、米国では仮称「**1937年海軍拡張法（Naval Expansion Act of 1937）**」が成立し（ダイス判定：1d100 > 20、出目99・クリティカル）、英国では大規模海軍拡張予算が承認され（1d100 > 40、出目90）、日本では**軍艦建造への公債発行が条件付きで承認された**（1d100 > 40、出目51）。[^e067] 1936年を100とする実質海軍予算は、1940年に米国300・英国230・日本200に達する見通しである。[^e101][^e102]

日本の1937年の国防費は18.8億円、海軍費は12.8億円である。[^e103] 日本は[1925年財政原則](../economy/fiscal-principles-1925.md)に従い、海軍の経常費を租税と諸侯の法定拠出で賄い、不足は資本支出に限った建設公債で補う。この方式なら、増税も中央銀行の直接引受もなしに1940年までに実質海軍予算を倍増できる。軍拡の制約は財政よりも、工作機械・精密機器・造船工程・熟練労働力という**実物資源**の側にある（1938年以降は予測シナリオ）。[^e101]

# 背景

## 条約失効と建艦の自由

ロンドン条約の失効で、総排水量・艦種別保有量・個艦排水量・主砲口径の制限はすべて消滅し、1922年以来の主力艦建造停止も終わった。各国は1936年中に失効後の建艦計画を策定・予算化し、条約の制限を超える建造は1937年以降に始まった。[^e061] 軍拡の主目的は、米国が日英合算兵力との均衡、英国が対米均衡と独伊への対応、日本が日英共同防衛義務の履行と通商保護である。[^e061]

## 三国の建艦能力の要素（検討案）

| 要素 | 米国 | 英国 | 日本 |
|---|---|---|---|
| 鉄鋼 | 非常に大 | 大 | 大 |
| 大型艦建造設備 | 豊富 | 豊富 | 相当規模 |
| 商船建造 | 拡張余地大 | 非常に大 | 非常に大 |
| 航空機産業 | 非常に大きい潜在力 | 高い技術力 | 拡大段階 |
| 航空発動機 | — | 高い技術力 | 技術的制約が残る可能性 |
| 資源 | 国内に豊富 | 海外依存 | 海外依存＋戦略備蓄 |
| 海外補給網 | — | 非常に充実 | 英国との相互利用 |

[^e066]

造船業に限れば、米国の対日英優位は経済全体ほど大きくない可能性がある。日本の造船業は軍縮期にも商船・海外向け受注で技術と設備を維持しており、一から再建する必要はない。[^e066] 艦艇の建造には鉄鋼・造船設備・重砲製造があればよいが、日英はさらに航空機産業・発動機・航空要員の養成が必要になる。空母を建造しても、航空機の生産と搭乗員・整備員の養成が追いつかなければ運用可能な航空艦隊にはならない。[^e066]

## 日本：軍艦建造公債の条件付き承認

1925年以降の日本の財政原則では、資本形成を伴う支出には公債を発行できるが、経常的な消費支出には原則として発行できない。[^e048] 海軍にとっては「**艦隊を建造する財源より、完成した艦隊を維持する財源の方が問題**」であり、航空主兵論を採る日本では航空機の更新・搭乗員訓練・整備という恒常的支出が重い。[^e066] 出目51は境界に近い成功であり、公債の対象は次のように限定された。[^e067]

| 支出 | 公債発行 |
|---|---|
| 軍艦の新規建造・大規模近代化改装 | 可 |
| 海軍基地・航空基地の建設 | 可 |
| 造船所・航空機工場の設備拡張 | 可 |
| 航空機の新規取得 | 条件付きで可 |
| 航空機の消耗・損失の補充 | 原則不可 |
| 軍人給与・訓練費・燃料弾薬などの経常消費、通常の維持修繕 | 不可 |

1925年に確立した経常予算と資本予算の区別は維持され、開発財政が全面的に軍事財政へ転換するのではなく、民生用公共投資との両立が求められた。[^e067] 公債発行の承認には元老院・衆議院の議決が必要である（→[元老院](../institutions/genroin.md)）。[^e048] 艦艇（軍艦）の建造は1925年財政原則の下で資本的支出として建設公債（建艦公債）の対象となり、給与・燃料・訓練・維持費などの経常費には使えない（作者確定）。この承認に従い、1937年度予算では艦艇建造費約3.5億円が資本会計に計上され、海軍費12.8億円は経常7.0億円＋資本5.8億円（恒久施設2.3億円＋艦艇建造3.5億円）、国防費18.8億円は経常12.3億円＋資本6.5億円となる（作者確定）。艦艇建造費は国民経済計算上は当時の慣行どおり政府最終消費支出として扱い、公的総固定資本形成には含めない（→[1937年度の帝国財政と連結政府財政](../economy/public-finance-1937.md)）。

## 英国：大規模海軍拡張予算

出目90で、財政当局による大幅な縮小なしに継続的な拡張予算が承認された。英国は新造戦艦計画を中止しており、予算は空母・航空部門に重点が置かれる。[^e065][^e067]

## 米国：1937年海軍拡張法

クリティカルの結果、史実で1940年に成立した両洋艦隊法に近い規模の政治的決断が1937年に下された。単なる前倒しではなく、レッド・オレンジ計画と第二次ロンドン会議の決裂を背景とする独自の立法である。特徴は、複数年度の拡張計画の一括承認、造船所・関連工場の設備拡張の予算化、海軍基地・教育施設・航空機生産設備への投資、雇用創出政策としての位置付け、超党派の支持である。[^e067] クリティカルが意味するのは工業力そのものの増大ではなく、**潜在工業力を海軍に振り向ける政治的・財政的障害の除去**であり、従来より大きな連邦財政赤字の容認も含む。[^e067][^e069] 海軍拡張法がニューディールに加わることで、史実の1937〜38年の米国景気後退（いわゆるルーズヴェルト不況）は規模・期間が縮小しうる（検討案）。[^e067]

# 日本の海軍財政

## 1936年の基準

1920年の国防費は国民所得の5%で10.0億円、うち海軍費は3.1%で6.2億円だった。ワシントン・ロンドン軍縮体制の下で負担率は長く安定し、1936年には国民純所得303.6億円に対して国防費15.0億円（4.9%）、海軍費9.5億円（3.1%）、陸軍等5.5億円となった（検討案）。軍縮期にも既存艦の近代化と航空部隊への投資は続けられていた。[^e101]

| 1936年海軍予算の内訳（億円） | 金額 |
|---|---:|
| 人件費・給与・給付 | 2.0 |
| 艦艇・航空機の運用と燃料 | 1.5 |
| 修繕・保守 | 1.2 |
| 訓練・教育 | 0.7 |
| 研究・行政・その他 | 0.8 |
| **経常支出計** | **6.2** |

| **資本支出計** | **3.3** |
| **海軍費合計** | **9.5** |

[^e101]

1936年までは資本支出も経常歳入の範囲で賄われていた。[^e101]

## 1937〜1940年の海軍予算

名目の海軍費は「9.5億円×実質予算指数/100×物価指数/108」で求めた（一般物価指数を海軍調達価格の代用とする）。1937年の値は中核値、1938年以降は予測シナリオである。[^e101][^e103]

| 年 | 実質指数 | 経常支出 | 資本支出 | 海軍費合計（億円） |
|---|---:|---:|---:|---:|
| 1936 | 100 | 6.2 | 3.3 | 9.50 |
| 1937 | 130 | 7.0 | 5.8 | 12.81 |
| 1938 | 155 | 8.0 | 7.8 | 15.82 |
| 1939 | 180 | 9.2 | 9.8 | 19.00 |

実質倍増に対して資本支出は名目で約3.5倍になる。これは建造制限の撤廃を反映したものである。経常支出も、航空隊の拡張、新規採用、燃料、整備要員の増加で増える。[^e101]

## 公債の消化と対外資産

国内銀行の公債保有などから見て、年3〜8億円の新規公債は国内金融市場で十分吸収できる。購入主体の案は、領主家・領主系資産管理機関35%、民間銀行30%、生命保険・信託等20%、一般家計・その他国内企業12%、外国投資家3%で、中央銀行の直接引受は原則として行わない。領主家は拠出金とは別に投資資産として公債を買えるが、購入を強制する制度は置かない（検討案）。[^e101]

97.1億円の純対外資産を売って軍艦を造ることは通常の財源にしない。対外資産は、石油・鉄鉱石・原料炭の輸入、英国などからの工作機械・精密機器の購入、海外資源事業の維持、国際決済の流動性のために維持する。**国内の資金調達は国内の生産資源を動員する手段、対外資産は外国の生産資源を使う手段**として区別される（検討案）。[^e101]（→[国際収支と対外資産](../economy/balance-of-payments.md)）

## 実物資源の制約

財政上公債を発行できることと、実際に軍備を拡張できることは別問題である。1937年以降の日本の財政制約は「資金を集められるか」から「集めた資金に見合う実物資源を、民間経済を圧迫せずに確保できるか」へ移る。[^e070][^e101]

| 分野 | 評価（検討案） |
|---|---|
| 財政 | 相当な余裕 |
| 国内金融市場 | 公債の吸収能力あり |
| 鉄鋼供給 | 比較的強い |
| 非鉄金属・重電 | 非常に強い |
| 電力供給 | 比較的強い |
| 造船工程の標準化 | 弱点 |
| 高精度工作機械 | 輸入依存 |
| 無線・精密機器 | 弱点 |
| 熟練労働力 | 需給が逼迫 |
| 海外資源調達 | 海上交通に依存 |

[^e101]

日英では遊休設備・熟練工の余裕が減りつつあり、軍拡によるインフレ圧力が大きい。米国には遊休生産力が比較的多く残り、当初のインフレ圧力は小さい（検討案）。[^e069] 日英は商船建造を圧迫しすぎると、軍拡の目的である海上通商防衛と矛盾する。[^e067]

# 却下・修正された案

* **1937年度の海軍費を経常10.5億円＋資本2.3億円とする内訳（会話ログ3、P93）**: 会話ログ3の財政再構成では艦艇建造費を経常会計に置き、国防資本支出3.0億円（うち海軍2.3億円）を軍港・工廠・飛行場などの恒久施設中心としていた。これでは建艦公債の承認（E67、出目51・成功）が1937年度予算に表れないため、艦艇建造費約3.5億円を資本会計へ移し、会話ログ2（E101）の経常7.0億円＋資本5.8億円に戻した（作者確定）。[^e067][^e101]
* **1937年日本の工業基盤の暫定推計**: 当初、粗鋼生産能力1,250〜1,450万t、粗鋼実生産1,050〜1,250万t、石炭生産6,000〜7,000万t、商船800〜950万総tとされた。[^e066] → 粗鋼実生産1,150万t・商船900万総tが確定し（ユーザー「数字は確定でよさそう」）、石炭は海外産との競争・水力発電・鉄道電化を考慮して5,700万tへ下方修正された。[^e068][^e069][^e072]
* **GDP対米比**: 中核案28%が確定した後、産業別積算で約42%、補正中核候補38%が示されたが、支出面からの検証を経て生産面の中核推計28.0%が維持された（26〜28%を範囲とする）。[^e068][^e072][^e098]
* **中央政府歳入/GDPの仮定**: 当初は米7%・英20%・日14%で、日本の恒常歳入を米国GDP=100換算で3.92とした。[^e069] → 諸侯の法定拠出は定額ではなく経済力連動であるとの指摘を受けて17%に引き上げ（4.76）、のち円建てで帝国政府経常歳入56.6億円（国民純所得の17%）を中核値とした。[^e070][^e099]
* **領主制による財政動員の制約**: 日本の経済規模が英本国並みでも、領主系企業・領国財政の資産を海軍予算に自由に転用できないため、英国政府並みの財政動員能力は持てないとする見方があった。[^e068] → 拠出が経済力に連動し定期改定されるため資金面の制約は小さく、制約は実物資源の確保と議会による支出統制に移ると修正された。[^e070]

# 未決の論点

* 1937〜40年の具体的な建艦隻数・艦型、造船能力の絶対値。[^e066][^e067]
* 1938年以降の成長率・物価・海軍予算は予測シナリオにとどまり、歴史的事実としては確定しない（1937年より後は一旦後回し）。[^e103]
* 一般物価指数を海軍調達価格の代用としており、軍需・資本財価格指数の設定が必要。[^e069][^e101]
* 公債購入主体の配分は資金循環から積算していない。[^e101]
* 日英技術協力8項目の判定（高精度工作機械の供給・技術移転協定 1d100 > 25、日本の工作機械産業による英国技術の吸収 > 45、造船設計・工業規格の協力 > 30、日本の造船所の建造工程合理化 > 45、無線・精密機器技術協力 > 35、日本国内の高性能通信・精密機器の量産基盤 > 50、軍需物資共同調達制度 > 35、米国の工業設備拡張が予定通り生産能力増加につながる > 20）は振られないまま保留。[^e102][^e103]
* 1937年時点で日本海軍が実際に保有する艦艇と航空戦力。[^e103]
* 米国の1937〜38年景気後退が海軍拡張法でどの程度変化するか。[^e067]
