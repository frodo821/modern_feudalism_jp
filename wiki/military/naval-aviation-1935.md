# 概要

本世界線の米英日は、1922年以来14年間にわたり主力艦の新規起工を停止していた。一方、航空機と航空母艦には1930年まで総量規制すら存在しなかったため、航空兵力の研究が史実より重視される条件が揃っていた。[^e062] 1935年、[日英海上通商防衛協定](../diplomacy/anglo-japanese-maritime-defense-agreement.md)の第一追加議定書（1932年）で設置された日英海軍協議会の共同研究として、退役主力艦と無線操縦式標的艦を用いた**日英共同航空攻撃試験**が行われ、結果は海軍当局の予想を大幅に上回る成功となった。[^n1][^e063]

試験を受けて、1936年に日本海軍と英国海軍が**航空主兵論**を正式に採用した。[^n2] ところが試験結果は米国へ正確に伝わらず、米海軍は不正確な情報から日英の成果を過小評価して、戦艦と空母を併用する従来型の艦隊構想を維持した。[^e064] こうして[第二次ロンドン海軍軍縮会議](../diplomacy/second-london-conference.md)の全面決裂（1936年12月31日条約失効）後の1937年の建艦競争は、**三国が異なる海軍思想に基づいて開始される**ことになった。[^e064]

日本は新造戦艦の全面凍結には至らず、空母艦隊を守る「**防空戦艦**」の建造が承認された。英国は新造戦艦計画を中止した。日英は艦載機の規格共通化と、史実の護衛空母に相当する**通商護衛用小型空母**の開発でも合意した。[^n3][^e065]

# 背景

## 主力艦建造停止と旧式艦

[ワシントン会議](../diplomacy/washington-conference.md)では各国の現有艦艇の保有が認められたため、本世界線では史実のように多数の旧式主力艦が廃棄されず、1930年代に入ると日露戦争以前から第一次世界大戦期に建造された旧式艦の維持費が問題になった。しかも1930年の[ロンドン条約](../diplomacy/london-naval-conference-1930.md)では退役艦の排水量を他艦種へ振り替えられたため、旧式艦を退役させて標的艦に転用する経済的・制度的な理由があった。[^n4][^e062][^e008] 日本は1930年時点で約29万英トンの主力艦を保有しており、その中に実験に供しうる旧式艦があった。[^n5][^e062]

1930年の時点で、日本海軍は条約で大型巡洋艦・大型駆逐艦・潜水艦の上限を受け入れる代わりに、小型護衛艦・航空機・基地航空隊・補給艦・対潜装備へ予算を回し、史実の「条約型重巡＋大型駆逐艦＋長距離魚雷戦」ではなく「軽巡洋艦＋護衛駆逐艦＋空母航空隊＋基地航空隊＋対潜部隊」という英国海軍に近い方向へ伸びると見込まれていた。[^n4][^e001]

## 史実の航空攻撃試験

史実の航空攻撃試験は、本世界線でも同様に行われた。[^e062]

| 年 | 国 | 標的艦・実験 | 結果 |
|---|---|---|---|
| 1921年 | 米国 | 旧ドイツ戦艦オストフリースラント、旧式戦艦アラバマ | 航空爆撃で沈没 |
| 1923年 | 米国 | 旧式戦艦ニュージャージー、ヴァージニア | 航空爆撃で沈没 |
| 1923年 | 英国 | 無線操縦標的艦アガメムノン（航行中） | 模擬爆撃試験 |
| 1930年 | 日本 | 旧式巡洋艦明石 | 直撃を受けても浮き、最後は駆逐艦の魚雷で処分 |
| 1930〜33年 | 日本 | 退役艦艇を使用した一連の実験 | 急降下爆撃の命中精度を研究 |
| 1931年〜 | 米国 | 無線操縦式の旧式駆逐艦、のち旧式戦艦ユタ | 標的艦として使用 |

1921年の時点で航空機による戦艦撃沈はすでに実証されていたが、米海軍は標的艦が回避運動や対空防御を行っていないことを問題視し、実験結果は直ちに戦艦不要論にはつながらなかった。停泊中の旧式艦を沈めただけでは戦艦派を説得できない。[^e062]

## 日英共同航空研究の推移

[^n4][^e062]

| 時期 | 研究の推移 |
|---|---|
| 1921〜25年 | 米国の戦艦爆撃実験を分析 |
| 1925〜29年 | 日英が独自に艦載航空機の研究を進める |
| 1930〜32年 | 日本が旧式巡洋艦を利用した実艦試験を実施 |
| 1933年 | 日英間で航空研究成果の交換を開始 |
| 1934年 | 無線操縦式標的艦による試験（日本が英国の技術協力で整備） |
| 1935年 | 退役主力艦を使用した実弾試験 |
| 1936年 | 艦隊演習と試験結果を踏まえた建艦方針の再検討 |

実験は、停泊中の旧式艦への実弾試験（耐損傷性）、航行中の無人標的艦への模擬攻撃（航空機の対艦攻撃能力）、現役艦隊と航空隊の演習（艦隊防空と運用上の制約）の三つに区別された。[^e062]

## 「沈むか」より「戦えなくなるか」

航空機が戦艦を撃沈できるかという議論自体が、やや戦艦中心の発想である。通商保護を目的とする日本海軍は、敵戦艦を必ずしも沈める必要はなく、航空攻撃で航行・戦闘能力を失わせて修理のために撤退させれば目的を達しうる。逆に戦艦が沈まなかったことも、航空攻撃下で有効に戦闘を継続できる証明にはならない。この認識は、艦隊決戦を重視した史実の日本海軍より、[通商保護を軸とする本世界線の日本海軍](navy-strategy.md)の方が受け入れやすい。[^e062]

# 1935年日英共同航空攻撃試験

1935年の試験は、海軍当局の予想を大幅に上回る成功を収めた。[^n1][^e063]

| 試験項目 | 結果 |
|---|---|
| 停泊中の旧式主力艦への攻撃 | 成功 |
| 無線操縦による航行中の標的艦への攻撃 | 予想を大幅に上回る成功 |
| 大型艦の戦闘能力喪失 | 確認 |
| 艦艇の損害評価 | 従来の想定を大幅に上回る |
| 艦載航空隊の運用能力 | 高い評価 |
| 戦艦による対空防御の評価 | 従来の想定では不十分 |

この結果、試験に立ち会った戦艦重視派も、航空兵力の有効性そのものは否定できなくなった。ただし無人の旧式艦を用いた試験であり、現役艦隊の防空能力や損害対処能力まで否定されたわけではない。[^e063]

1936年までに日英両海軍では次の認識が共有された。[^e063]

* 航空援護のない水上艦隊による制海権の維持は困難である。
* 戦艦の装甲だけでは航空攻撃に対する十分な安全性を確保できない。
* 航空母艦は主力艦に付随する補助艦艇ではなく、独立した主力戦力である。
* 艦隊航空戦力の優劣が、水上艦隊の行動可能性を大きく左右する。
* 新造戦艦の必要性と経済性を再検討する必要がある。

1922年以来主力艦を起工していないため、これから建造する戦艦は既存の建造計画に拘束されにくく、しかも第二次ロンドン会議の全面決裂で空母の総量規制も消滅する。**航空主兵論への転換を妨げる制度上・予算上の既得権が比較的小さい時期に、極めて良好な実験結果が得られた**のである。[^e063]

1937年時点の航空戦力に関する認識は次のように整理される。[^e062]

| 認識 | 1937年時点 |
|---|---|
| 航空機による艦艇の撃沈 | 実証済み |
| 航行中の艦艇への航空攻撃 | 実証済み |
| 大型艦の航空攻撃に対する脆弱性 | 広く認識 |
| 艦隊防空における戦闘機の重要性 | 広く認識 |
| 空母による戦艦の完全な代替 | 論争中 |
| 夜間・悪天候における航空戦力の有効性 | 不十分 |
| 航空兵力のみでの制海権確保 | 未実証 |

# 航空主兵論の採用と米国への誤伝達

## 正式採用と米国への伝達

1936年、日本海軍と英国海軍はともに航空主兵論を正式に採用した。英国の方が既存の戦艦中心の海軍組織と伝統に拘束されやすく、採用の障害は日本より大きかった。一方、試験結果は米国へ正確には伝わらなかった。[^n2][^e063][^e064]

## 艦種の位置付けの逆転

航空主兵論は戦艦の全廃ではなく、艦種の位置付けの逆転である。[^e064]

| 艦種 | 従来 | 航空主兵論採用後 |
|---|---|---|
| 戦艦 | 艦隊の中心 | 航空艦隊の支援・水上戦闘 |
| 航空母艦 | 補助戦力 | 艦隊の中心 |
| 重巡洋艦 | 水上打撃 | 水上戦闘・艦隊護衛 |
| 軽巡洋艦 | 偵察・通商保護 | 艦隊防空・通商保護 |
| 駆逐艦 | 水雷戦・護衛 | 護衛・対潜 |
| 小型護衛艦 | — | 船団護衛 |
| 補給艦 | — | 航空艦隊の継戦能力維持 |

## 日英の航空主兵論の違い

| 項目 | 日本 | 英国 |
|---|---|---|
| 主な任務 | 遠洋通商防衛・艦隊航空戦 | 世界的通商防衛・欧州海域 |
| 空母 | 遠洋活動能力重視 | 多様な海域への適応 |
| 基地航空隊 | 西太平洋中心 | 世界の既存基地網を活用 |
| 既存戦艦 | 段階的に縮小 | 欧州方面で比較的長く維持 |
| 性格 | 空母中心の遠洋海軍 | 空母＋世界的基地航空網の海軍 |

両国とも小型空母を通商護衛用に重視する。[^n4][^e064]

## 米国の誤認

米国への伝達の失敗は、単に情報が伝わらなかったのではなく、**不正確な情報が伝わり、米海軍が日英の成果を過小評価した**ことを意味する。[^e064]

| 項目 | 日英の実際 | 米国の認識 |
|---|---|---|
| 試験結果 | 大成功 | 限定的成功 |
| 航行中標的艦への攻撃 | 高い有効性 | 命中精度に問題 |
| 主力艦の損害 | 予想を大幅に上回る | 旧式艦特有の脆弱性 |
| 日英の思想転換 | 航空主兵論の正式採用 | 航空補助戦力の拡充 |
| 戦艦更新計画 | 大幅見直し | 財政上の理由による延期 |

米海軍は自国も1920年代から試験しているので航空機の有効性自体は否定しないが、日英が一歩進んだ結論に到達したことを認識できず、戦艦と空母を組み合わせた**戦艦・航空併用論**を維持した。[^e064] さらに、誤情報を得た米国は、日本の戦艦建造再開を「従来の海軍思想を維持している証拠」と、英国の戦艦不建造を「財政事情・日英の任務分担」と誤認しうる。[^n4][^e065]

# 1937年以降の建艦方針

## 建艦方針の決定

1936年、日本は新造戦艦計画の全面凍結に至らなかった。英国は新造戦艦計画を全面凍結した。日英は艦載航空機の共同開発・規格共通化に合意し、通商護衛専用の小型空母の開発を開始した。[^n3][^e065]

## 防空戦艦（日本）

日本が全面凍結に至らなかったことは航空主兵論の後退ではなく、**航空主兵論に適合する新しい戦艦の建造承認**と解釈された。日本の新造戦艦計画は「防空艦としての計画」として承認され、戦艦派は戦艦の存在意義を再定義することで建造予算を確保した。[^e065]

防空戦艦の任務は、空母中心艦隊の防空、敵水上艦艇からの空母防護、夜間・悪天候時の水上戦闘、艦隊指揮・通信能力の補完、航空兵力が活動できない状況での通商防衛である。[^e065]

| 項目 | 従来型戦艦 | 防空戦艦 |
|---|---|---|
| 艦隊内の地位 | 主力 | 空母の支援戦力 |
| 設計の優先事項 | 対戦艦戦闘 | 艦隊防護 |
| 主砲 | 最大打撃力 | 水上戦闘能力の確保 |
| 対空兵装 | 補助 | 主要装備 |
| 速力 | 戦列の要求 | 空母への随伴を重視 |
| 隻数 | 艦隊決戦の所要 | 空母艦隊の所要 |

**戦艦という艦種は残るが、戦艦を中心とする艦隊は消滅する**。1937年の対空砲・射撃管制技術の限界から、実際の防空能力は別途評価が必要である。[^e065]

## 英国：新造戦艦の中止

英国は既存戦艦を直ちに廃棄せず、近代化改装で延命しながら空母中心の艦隊へ移行する。基地航空隊と水上艦隊の組合せによって新造防空戦艦は不要と判断した。伝統的には英国の方が戦艦に固執しそうだったが、結果として英国の方が徹底した航空主兵論を採用することになった。[^e065]

## 艦載機の規格共通化

日英の共同開発は同一機種への統一ではなく、**相手国の空母・整備施設で運用可能にすること**を要点とし、両国の航空機産業の独立性は維持される。内容は、艦載機要求規格の共通化、空母発着艦設備の互換性、航空燃料規格の共通化、通信機器の相互運用性、整備機材の共通化、部品の共同調達・互換、操縦員・整備員教育の相互交流、両国企業による開発・生産の分担である。[^e065]

## 通商護衛用小型空母

史実では第二次世界大戦中に急造された護衛空母に相当する艦種を、日英は1937年から計画的に開発する。任務は船団の航空警戒・対潜警戒・航空援護で、日英がともに持つ大規模な商船隊と造船業の技術を活用した比較的安価な空母となる。[^e065]

## 三国の建艦方針（1937年）

| 艦種 | 日本 | 英国 | 米国 |
|---|---|---|---|
| 従来型戦艦 | 新造停止 | 新造停止 | 建造優先 |
| 防空戦艦 | 新規建造 | 既存艦で代用 | 独立艦種として未成立 |
| 大型空母 | 最優先 | 最優先 | 戦艦と並行 |
| 通商護衛空母 | 開発開始 | 開発開始 | 優先度低 |
| 巡洋艦 | 防空・通商保護重視 | 防空・通商保護重視 | 水上戦闘重視 |
| 駆逐艦 | 防空・対潜重視 | 防空・対潜重視 | 艦隊随伴重視 |
| 補給艦 | 重視 | 重視 | 従来型艦隊の所要 |

いずれも計画段階のものである。[^n6]総括すれば、日本は「防空戦艦を伴う空母中心海軍」、英国は「既存戦艦を活用しつつ空母中心へ移行する海軍」、米国は「戦艦と空母を併用する従来型海軍」となる。[^e065]

# 航空要員と航空発動機

空母中心の海軍では、空母の建造→航空機の生産（機体・発動機・予備部品）→人員の養成（搭乗員・整備員・航空管制）を経て初めて運用可能な航空艦隊になる。このため最も深刻な制約は造船能力より**航空要員の養成能力**だと見込まれた。[^n4][^e066] 1937年には、日英の航空発動機技術協力が成功し、日本・英国ともに航空要員養成の拡充が順調に進んだ。[^n7][^e067]

日本は発動機開発の重複投資を抑え、英国は日本の工業基盤で供給能力を拡大する。航空部門の発展見通しは、1937年に共同開発機関の設置と教育施設の拡張、1938年に技術供与の進展と養成人数の増加、1939年に共同開発成果の実用化、1940年に拡張された航空産業と教育制度の定着である。[^n8][^e067] 日英の航空発動機協力・艦載機規格の共通化・航空主兵論の採用は確定している。[^e102] 予算面は[1937年の建艦競争と海軍財政](naval-buildup-1937.md)を参照。

| 1930年代の航空攻撃試験 | 各国が個別に実施 | 日英海軍協議会の共同研究、1935年の退役主力艦試験 |
| 日本海軍の思想 | 艦隊決戦主義・大艦巨砲主義（大和型の建造） | 1936年に航空主兵論を正式採用、防空戦艦を建造 |
| 英国海軍 | キング・ジョージ5世級など新戦艦を建造 | 新造戦艦計画を中止し空母中心へ |
| 米海軍 | 戦艦と空母の併用 | 同じ（日英の転換を過小評価） |
| 護衛空母 | 大戦中に商船改造・急造 | 1937年から計画的に開発 |

# 編集注：未決の論点

* 1935年の試験に使用した旧式主力艦の具体的艦名（本世界線の建艦史確定後に決める）。[^e062]
* 米国への伝達ファンブルが、日英による意図的な偽情報か、米国側の情報収集・分析の失敗かは未確定。[^e064]
* 米国が日英の海軍思想の転換に気付くまで何年かかるか（1930年代後半の判定事項候補）。[^e064][^e065]
* 防空戦艦の実際の性能・艦型、各国空母・護衛空母の完成隻数。[^e065]
