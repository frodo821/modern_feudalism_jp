# 概要

本世界線の帝国海軍には、史実のような艦隊決戦主義・八八艦隊思想は当然には成立していない。日露戦争がなく、日本海海戦の成功体験もないためである。[^u127] 日本海軍は敵艦隊の撃滅よりも、海外の資源と英国との通商に依存する経済を支える**海上交通の維持**のために発展した。[^n1][^u127]

第一次世界大戦の戦訓から日本海軍が求めるのは、**敵戦艦排除能力・艦隊護衛能力・対潜能力**の三つであり、建艦計画の中心は「戦艦を何隻持つか」ではなく「海軍全体でこの三能力をどの程度確保するか」になる。[^u129] 戦艦は否定されず、戦艦に割り当てていた予算をより多様な戦力へ再配分する方向が取られる。

目指す姿は「戦艦の数で勝つ海軍」ではなく、**「敵主力艦を抑止しながら、戦時にも海上交通を止めない海軍」**であり、それは[日英協調](../diplomacy/anglo-japanese-cooperation.md)を軍事的に維持するために必要な能力でもある。[^n1][^u129]

1930年代にはこの思想がさらに具体化した。1930年の[日英海上通商防衛協定](../diplomacy/anglo-japanese-maritime-defense-agreement.md)と1932年の第一追加議定書で日英の共同防衛義務が明文化され、1935年の[日英共同航空攻撃試験](naval-aviation-1935.md)の大成功を受けて、日本海軍は1936年に**航空主兵論**を正式に採用した。1936年末のロンドン条約失効後、日本は「防空戦艦を伴う空母中心海軍」の建設に向かう。[^e063][^e064][^e065]

# 形成の経緯

## 統一国軍としての海軍

1870年代に各領主が軍事費負担を金納化して独自軍を縮小し、1880年代には国軍が対外防衛をほぼ独占した。帝国海軍は全国的な造船・艦隊運用・海軍教育を担う統一国家軍である。[^n1][^u030] 海軍は陸軍以上に発展の余地があり、1861年の[公武協定](../diplomacy/kobu-agreement-1861.md)以来の全国海防課題に加え、島津家・鍋島家の造船・製鉄が領主家の産業として存続した。1880年代には島津家の造船企業、鍋島家の機械工業、旧幕府系の横須賀造船施設などが帝国海軍への納入を競った。[^n1][^u029] 大領主の競争は、独自の軍事力ではなく、将官の輩出や艦船発注の獲得、軍事予算への影響力をめぐるものとなった。[^u030] 陸軍を含む帝国軍全体については[帝国軍](imperial-army.md)を参照。

## 日清戦争（1887〜1889）

1880年代の[日清戦争](../events/sino-japanese-war.md)では北洋艦隊と交戦し、日本の最低限の講和条件は日本近海での清の海軍力の解体に必要な程度とされた。[^u064] この経験から、日本海軍は大型装甲艦の重要性を理解している。戦艦派は存在するが、決戦主義が海軍全体の共通前提にはならない。[^n1][^u127]

## 海上交通依存の経済

1889年以降の日本の経済発展は、海外の鉄鉱石・石炭・石油・綿花と英国との通商関係に依存している。資源を領有ではなく採掘権・長期契約・共同出資で確保する路線を取る以上、国際貿易の自由の維持が経済と安全保障の双方を左右し、日英の海軍・通商協力は経済政策でもある。[^u081]（[資源戦略](../economy/resource-strategy.md)を参照）

この結果、海軍の主要任務は次のように整理される。[^n1][^u127]

| 任務 | 求められる艦艇 |
|---|---|
| 商船・資源輸送路の保護 | 巡洋艦、駆逐艦、護衛艦 |
| 太平洋・インド洋の広域哨戒 | 航続力の大きい巡洋艦 |
| 英国海軍との共同作戦 | 巡洋艦、駆逐艦、補給艦、一定数の主力艦 |
| 台湾・日本本土の防衛 | 潜水艦、沿岸航空戦力、主力艦 |
| 敵主力艦隊への対抗 | 戦艦、巡洋戦艦、航空兵力 |

[元老院](../institutions/genroin.md)は海軍予算の審議に際し、「その戦艦を造ることで、どの輸送路が安全になるのか」と問う。これは史実の八八艦隊構想とはかなり異なる予算政治である。[^n1][^u127]

## 第一次世界大戦の経験

第一次世界大戦で日本海軍は英国の東方海域の防衛を引き受け、インド洋・地中海で護衛任務を経験した。将校たちが実際に経験したのは、戦艦同士の決戦ではなく、商船の護衛、通商破壊艦の捜索、潜水艦対策、長距離航海、共同補給であった。[^u127][^u128] 1914年の派遣規模は、太平洋の独艦艇対策に巡洋艦2〜4隻、インド洋の海上交通保護に巡洋艦2隻・駆逐艦4〜6隻、地中海の輸送船護衛に駆逐艦8〜12隻と旗艦1隻とされ、北洋・日本海の防備には主力艦隊の大部分を保持した。[^n1][^u098] 日本は英国艦隊の戦力を劇的に増やしたわけではないが、英国が世界規模の戦争を遂行するための海軍配置を安定させた。[^n1][^u121] 大戦中の作戦の詳細は[第一次世界大戦期の日本の軍需・海運・海軍協力](wwi-japan-war-effort.md)を参照。[^u120]

限られた戦費で英帝国の東方防衛を支えたという成功体験から、海軍内部には「戦艦を増やすより巡洋艦や駆逐艦を整備した方が、外交上も実務上も価値が大きい」という巡洋艦・駆逐艦派が強まる。[^n1][^u127]

# 戦艦観

## 「戦艦は戦艦にしか沈められない」のではない

列強の戦艦中心主義は、「戦艦は戦艦にしか沈められない」という単純な誤信ではなく、**敵の戦艦を確実に排除し、継続的な制海権を確保するにはこちらにも戦艦が必要だ**という論理に基づいていた。理由は三つある。[^u128]

1. 魚雷や機雷は危険だが、敵主力艦隊を確実に撃滅する手段とは考えられなかった。
2. 戦艦は敵艦を撃沈するだけでなく、敵の水上艦隊の行動そのものを制約できた。
3. 日露戦争と第一次世界大戦の戦訓が、護衛された戦艦部隊の有効性を裏づけるものと解釈された。

戦艦が重要だったのは、沈めなくても敵を封じ込められるからである。英大艦隊はドイツ大洋艦隊を撃滅しなかったが、北海の出口を押さえて海上封鎖を維持した。逆にドイツ艦隊も健在であるだけで英国の作戦を拘束した（fleet in being、現存艦隊）。[^u128]

## 本世界線の日本海軍の教訓

日本海海戦がなく、1920年までに経験した戦争が対清戦争と第一次世界大戦である本世界線の日本海軍は、次のように学習する。[^n1][^u128]

> 戦艦は敵の戦艦を抑えるために必要だが、海上交通を維持する仕事の大部分は戦艦ではできない。

英国との協力が続く限り、英国の主力艦戦力を前提に、日本は巡洋艦・駆逐艦・航空部隊へ比較的多く投資できる。「では英国と分担している我々が、そこまで大量の戦艦を持つ必要があるのか」という疑問を、史実より早く、財政当局や元老院の支持を得ながら提起できる。ただし日英が敵対しない保証はなく、米国との中国問題もあるため、戦艦の完全放棄には海軍側が強く反対する。[^n1][^u128]

## 戦艦を一定数保有する理由

日本が戦艦を一定数保有する理由は三つある。[^n1][^u130]

1. 1889年の日清戦争以後も敵の装甲艦に対抗する必要があり、本土と台湾の防衛を英国へ完全には委ねられない。
2. 英国海軍との共同作戦で戦艦部隊を提供できることに外交的価値がある。
3. 第一次世界大戦で英大艦隊の戦略的重要性を観察している。

ただし、新式戦艦と巡洋戦艦を各8隻そろえる八八艦隊構想を採用する理由は弱く、日本海軍は**少数の有力な戦艦と、多数の巡洋艦・駆逐艦による艦隊**になる。[^n1][^u130]

# 三つの能力

| 能力 | 目的 |
|---|---|
| 敵戦艦排除能力 | 敵の主力艦隊が日本の通商路や英国の東方航路へ進出するのを阻止する |
| 艦隊護衛能力 | 主力艦・巡洋艦・輸送船団を敵の駆逐艦・潜水艦・航空機から守る |
| 対潜能力 | 通商破壊を防ぎ、戦時にも資源と兵員の海上輸送を維持する |

三能力は相互に独立していない。[^u129]

## 敵戦艦を排除する手段

日本海軍は戦艦・潜水艦・航空兵力などを組み合わせ、敵主力艦の行動を複数の手段で制約する。[^n1][^u129]

| 戦力 | 主な役割 | 1920年時点の限界 |
|---|---|---|
| 戦艦 | 敵主力艦との交戦、敵の行動の牽制 | 建造・維持費が大きい |
| 水雷戦隊 | 魚雷攻撃で敵主力艦の行動を制限 | 射程・夜間戦闘・接近時の損害 |
| 潜水艦 | 敵の進出経路の監視、雷撃、接近阻止 | 高速艦隊との協同が難しい |
| 航空母艦・艦載機 | 偵察、索敵、将来の対艦攻撃 | 対戦艦打撃能力はまだ発展途上 |
| 機雷 | 海峡・港湾周辺で敵の行動を妨げる | 外洋での機動戦には使いにくい |

1920年の時点で戦艦をすべて潜水艦や空母へ置き換えるのは早すぎる。[^u129]

## 駆逐艦の取り合い

予算上の最大問題は駆逐艦の取り合いである。駆逐艦には、主力艦部隊の護衛、魚雷による敵主力艦への攻撃、商船団の護衛と対潜という三つの用途があり、決戦重視派も通商保護派も駆逐艦を欲しがる。日本海軍は実際に船団護衛を経験しているので、最初から任務を分け、**艦隊随伴用の高速大型駆逐艦**と**長距離護衛用の比較的安価な艦艇**を別々に整備する。艦艇だけでなく、聴音装置、爆雷、無線通信、護衛隊司令部、船団運航を調整する民間海運機構も必要となる。[^n1][^u129]

# 戦後の帝国海軍三本柱

第一次世界大戦後の帝国海軍は、次の三本柱で構成される。[^n1]

| 柱 | 任務 | 構成 |
|---|---|---|
| 主力艦隊 | 制海権・敵主力艦の牽制 | 戦艦・巡洋艦を中心に、艦隊随伴駆逐艦、偵察航空隊、潜水艦 |
| 海上交通保護部隊 | 商船団・補給路の防衛 | 護衛駆逐艦、小型護衛艦、哨戒艇、掃海艇、航空基地、護衛司令部 |
| 航空・水中戦研究部門 | 対艦攻撃・索敵・対潜技術 | 航空母艦、水上機母艦、潜水艦、魚雷、爆雷、探知装置 |

空母は戦艦の代替ではなく、艦隊の索敵能力を改善する研究開発として始まる。航空機による戦艦撃沈は1920年時点でまだ実証されていないが、偵察航空機の価値は第一次世界大戦で明らかになっている。[^u129]

# 艦隊規模と予算

## 1921年の編制

当初の通商保護重視の編制案は、戦艦4〜6、巡洋戦艦・大型巡洋艦2〜4、軽・重巡洋艦20〜30、駆逐艦60〜90、航空母艦・航空艦1〜3隻で、戦艦・巡洋戦艦は計6〜10隻（35,000トン級8隻としても28万トン）であった。[^u127] 1921年の中核的な規模は次のとおりである。[^n1][^u130]

| 艦種 | 1921年中核案 |
|---|---|
| 戦艦・巡洋戦艦 | 8隻前後（約29万英トン） |
| 巡洋艦 | 25隻前後 |
| 駆逐艦 | 90隻前後 |
| 潜水艦 | 35隻前後 |
| 航空母艦・航空母船 | 2隻前後 |

日本の主力艦排水量は米国の約55%だが、大型艦の保有量と広域警備・護衛任務の遂行能力は別である。[^u130] 会議前の三国比較は[ワシントン会議と主力艦建造停止条約](../diplomacy/washington-conference.md)を参照。

## 予算

1920年度の国防費10億円のうち海軍費は6.2億円（維持・訓練3.5億円、建造・更新2.7億円）で[^n1]、建造費は戦艦だけでなく巡洋艦・駆逐艦・潜水艦・航空機・補給艦・基地施設にも充てられる。1920〜25年には対英仏債権の償還金や対独賠償などから「帝国艦隊更新基金」6億円が別途配分される。[^u126] 財源の構造は[帝国財政と諸侯の法定拠出](../economy/imperial-finance.md)を参照。

## 日英分業とその弱点

日英の共同艦隊で主力艦戦力を確保し、日本単独では通商保護と地域防衛を重視するという分業が考えられる。ただし、日本が巡洋艦と駆逐艦を大量に持っていても、米国が戦艦群を率いて西太平洋へ進出した場合に正面から阻止できるとは限らず、英国の協力が失われたときに独力で制海権を維持できるかという問題は残る。[^n1][^u127]

# 軍縮への態度

この戦略思想のため、日本は1921〜22年のワシントン会議で主力艦の建造停止に積極的に賛成した。米英の戦艦建造競争を止め、浮いた予算を巡洋艦・駆逐艦・航空機・商船護衛へ回せるからである。ただし巡洋艦・駆逐艦の総量制限には応じない。日本の交渉上の強みは、**戦艦の建造競争から降りても自国の海軍戦略を維持できること**にあった。[^u127][^u129] 成立した条約は補助艦・空母の総量を制限しなかったため、主力艦の数より補助艦艇の能力を重視する日本海軍の戦略はむしろ強化された。[^u130][^u131]

1930年代に向けては、主力艦の建造停止で浮いた予算が航空・対潜・護衛戦力へ向かうため、史実より早く空母の重要性が認識される可能性がある。[^n1][^u131] 1930年の建艦能力については、主機・減速歯車・測距儀・射撃指揮装置などの国産化が高性能艦の建造数を左右する。[^u132] 1930年の[ロンドン海軍軍縮会議](../diplomacy/london-naval-conference-1930.md)では、米国が日英を一体の海軍勢力として扱い、海軍全体の総排水量比を100:85:65（米140万・英119万・日91万英トン）とすることで妥協した。日英の現有艦隊は削減されなかった。[^e008]

# 1930年代の展開

## 1930年の艦隊とロンドン条約後の方向性

1930年の三国の現有艦隊は次のとおりである（単位：千英トン）。日本の主力艦29万英トンは1921年の中核案と連続する。[^e008]

| 艦種 | 米国 | 英国 | 日本 |
|---|---:|---:|---:|
| 主力艦 | 510 | 460 | 290 |
| 航空母艦 | 100 | 115 | 105 |
| 重巡洋艦 | 100 | 125 | 80 |
| 軽巡洋艦 | 110 | 235 | 180 |
| 駆逐艦 | 190 | 155 | 155 |
| 護衛艦・小型戦闘艦 | 35 | 65 | 45 |
| 潜水艦 | 65 | 35 | 45 |
| **現有総排水量** | **1,110** | **1,190** | **900** |
| 条約上限 | 1,400 | 1,190 | 910 |

条約で大型巡洋艦・大型駆逐艦・潜水艦の上限を受け入れる代わりに、小型護衛艦・航空機・基地航空隊・補給艦・無線・対潜装備に予算が回り、1930年代の日本海軍は史実の「条約型重巡＋大型駆逐艦＋長距離魚雷戦」ではなく、「**軽巡洋艦＋護衛駆逐艦＋空母航空隊＋基地航空隊＋対潜部隊**」という英国海軍に近い方向へ伸びる。[^n1]8インチ砲1万トン級の重巡洋艦は通商保護に効率がよくないため、日本は6インチ級の高速巡洋艦を増やしたい。潜水艦は漸減邀撃の主力ではなく、交渉上の譲歩材料となる。[^e001]

## 日英共同防衛義務

ロンドン条約署名前日の1930年4月21日に日英海上通商防衛協定が調印され、1932年の第一追加議定書で、一方の商船だけが攻撃された場合や適法な海上封鎖に対しても共同防衛義務が生じること、常設の日英海軍協議会を置くことが定められた（締約国自身の侵略戦争に起因する場合は免責）。[^e053] 「日英分業とその弱点」で挙げた「英国の協力が失われたときに独力で制海権を維持できるか」という問題は、条約上の共同防衛義務によって大きく緩和された。

## 第二次ロンドン会議の決裂

米国は1935年の[第二次ロンドン海軍軍縮会議](../diplomacy/second-london-conference.md)で日英合算との均等を要求し、会議は1936年春に全面決裂した。1936年12月31日に既存の海軍軍備制限はすべて失効し、1922年以来の主力艦建造停止も終わった。日本の軍拡の主目的は、日英共同防衛義務の履行と通商保護である。[^e061][^e062]

## 航空主兵論への転換

1922年以来主力艦を起工しておらず、旧式艦が多く残る本世界線では、退役主力艦を標的とする航空攻撃試験が日英海軍協議会の共同研究として行われた。1935年の試験は大成功に終わり、日本海軍は1936年に航空主兵論を正式採用した。[^n2][^e062][^e063][^e064] 通商保護を目的とする日本海軍にとっては、敵戦艦を沈めなくても航行・戦闘能力を奪えばよく、この認識は艦隊決戦を重視した史実の日本海軍より受け入れやすかった。[^e062]

航空主兵論は戦艦の全廃ではなく、艦種の位置付けの逆転である。[^e064]

| 艦種 | 1920年代 | 1937年以降 |
|---|---|---|
| 戦艦 | 艦隊の中心 | 航空艦隊の支援・水上戦闘（防空戦艦） |
| 航空母艦 | 索敵・研究開発 | 艦隊の中心 |
| 巡洋艦 | 水上打撃・偵察・通商保護 | 艦隊防空・通商保護・艦隊護衛 |
| 駆逐艦 | 水雷戦・護衛 | 防空・護衛・対潜 |
| 小型護衛艦・通商護衛空母 | 船団護衛 | 船団の航空・対潜警戒 |
| 補給艦 | 共同補給 | 航空艦隊の継戦能力維持 |

日本は新造戦艦計画の全面凍結には至らず、[^n3]空母艦隊の防空・空母防護・夜間悪天候時の水上戦闘を担う**防空戦艦**として新造戦艦が承認された。「戦艦という艦種は残るが、戦艦を中心とする艦隊は消滅する」。[^e065] 日本の航空主兵論は遠洋通商防衛と艦隊航空戦を主任務とし、遠洋活動能力を重視する空母と西太平洋中心の基地航空隊を持つ「**空母中心の遠洋海軍**」であり、既存戦艦は段階的に縮小する。[^n1][^e064] 日英は艦載機の規格共通化と通商護衛用小型空母の開発でも合意した。[^n3][^e065] 米海軍は試験結果を不正確に伝えられて日英の転換を過小評価し、戦艦・航空併用論を維持した。[^n2][^e064]

これは「戦後の帝国海軍三本柱」の延長上にある変化である。空母は戦艦の代替ではなく索敵の研究開発として始まったが、航空・水中戦研究部門の成果が1930年代半ばに主力艦隊の構成そのものを変えた。

## 1937年の海軍予算

1936年の海軍費は9.5億円（経常6.2億円、資本3.3億円）で、国民純所得の3.1%と1920年の負担率がほぼ維持されていた。1937年には軍艦建造への公債発行が条件付きで承認され、[^n4]1937年の海軍費は12.8億円、国防費は18.8億円となった。[^e067][^e101][^e103] 実質海軍予算は1940年に1936年の2倍となる見通しで、1940年には国防費の約75%を海軍が占める。[^n5][^e101] 「建造する財源より維持する財源の方が問題」であり、航空主兵論を採る日本では航空機の更新・搭乗員訓練・整備の経常費が重い。航空要員の養成と日英の航空発動機協力はいずれも成功した。[^n4][^e066][^e067] 詳細は[1937年の建艦競争と海軍財政](naval-buildup-1937.md)を参照。

日本は1936年の時点で、経済規模に比べて英米より多くを海軍に注いでいた（海軍費のGDP比 日本2.60%、英国1.63%、米国約0.58%）。[^e102]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 決定的な成功体験 | 日本海海戦（1905年） | なし（日清戦争で北洋艦隊と交戦） |
| 主力艦整備構想 | 日清戦争後の六六艦隊→日露戦争後の八八艦隊 | 八八艦隊を採用する理由は弱い |
| 想定敵と戦略 | 太平洋を横断する米艦隊を日本近海で迎撃 | 英国との分担による海上交通の維持 |
| 大戦の主な経験 | 地中海派遣（マルタ拠点、護衛348回・788隻）など限定的 | インド洋・地中海での船団護衛・通商保護が中心的経験 |
| 1921年1月の第一線艦（日本） | 戦艦6、巡洋戦艦4、軽巡洋艦6、駆逐艦27、通常潜水艦0 | 戦艦・巡洋戦艦8前後、巡洋艦25、駆逐艦90、潜水艦35、空母2前後[^n1] |
| 1930年代の海軍思想 | 大艦巨砲主義・艦隊決戦主義（大和型戦艦の建造） | 1936年に航空主兵論を正式採用、防空戦艦を伴う空母中心海軍 |
| 軍縮条約からの離脱 | 1934年にワシントン条約廃棄を通告、1936年に第二次ロンドン会議を脱退 | 米国の二国標準要求で第二次ロンドン会議が全面決裂、1936年末に全制限失効 |

[^u120][^u127][^u128][^u130]

史実でも機雷・魚雷による戦艦の喪失は日露戦争で既知であった。1904年5月15日、日本は機雷で戦艦「初瀬」「八島」を同日に失い、ロシアも「ペトロパヴロフスク」を機雷で失った。1916年のユトランド沖海戦は決定的撃滅に至らず、英国は潜水艦・機雷の危険から近接封鎖を避けて遠隔封鎖を採用した。史実の日本の決戦主義の問題は、戦艦による敵主力艦の封じ込めという実際の効用を、海軍戦略全体の中心に置きすぎたことにあった。[^u128] また史実の英国では1917年の船団護衛導入に際し、主力艦隊から駆逐艦を引き抜くことへの反対があったが、船団制度は大きな成果を上げた。[^u129]

# 編集注：未決の論点

- 1914〜1918年に日本海軍がどのような艦隊で戦い、戦後にどのような教訓を得たかの具体的な確定。[^u127][^u130]
- 1921年の主力艦の隻数・艦型・総排水量（約29万英トン・8隻前後は暫定）。史実の薩摩型・河内型・金剛型以降の建艦計画が存在するか。[^u126][^u130]
- 主力艦8隻前後と駆逐艦90隻程度を、粗鋼500万t・海軍予算6.2億円で維持できるかの、建造・更新・乗員費用による検証。[^u130]
- 1930年時点の艦隊構成と、航空・水中戦研究部門の成果。（会話ログ2で解決：1930年の現有艦隊は主力艦290千英トン・総排水量900千英トン、航空研究は1935年の日英共同航空攻撃試験と1936年の航空主兵論採用に結実）[^e008][^e063]
- 1935年の試験に使用した旧式主力艦の艦名、防空戦艦の性能・艦型、1937年時点で実際に保有する艦艇と航空戦力。[^e062][^e065][^e103]
- 1937〜40年の具体的な建艦隻数と、米国が日英の思想転換に気付く時期。[^e064][^e067]

# 編集注：却下・修正された案

- **ロンドン会議の焦点（艦種別規制中心の想定）**: 前編では、1930年のロンドン会議は「どの艦艇を制限すると日英の広域海上交通保護体制が維持できなくなるか」が中心論点になると見込まれ（検討案）[^u132]、会話ログ2の初期案でも艦種ごとに比率・例外の異なる条約（重巡は日本が譲歩、軽巡は米100:英105:日80、護衛艦は条約外など）が示された。[^e001] 実際には米国が日英を一体の海軍として扱うことが最大の争点となり、海軍全体の総排水量比100:85:65を定め、艦種別上限は別に規定する形に改められた。[^e006][^e008]
