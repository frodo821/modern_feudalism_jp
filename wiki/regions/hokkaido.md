# 概要

本世界線の北海道は、史実と同じく1869年に蝦夷地から改称され11国86郡が置かれたが、1871年の廃藩置県が起きないため、史実では短命に終わった**分領支配が恒久的な地方統治制度へ発展する**余地を持った地域である。[^u066] 開拓費の負担と引き換えに大領主・中小領主へ一定の統治権が認められ、[新領土の統治制度](../institutions/new-territory-governance.md)における「世襲領主領」と「帝国直轄国」が併存する、帝国内でもっとも多くの新領主家が生まれた地域となった。[^u066]

会話ログ3のダイス判定で、分領支配は恒久的な世襲領主領へ発展し（ダイス判定：難易度25、出目67・成功）、既存領主家が積極的に開拓に参加し（難易度20、出目75・成功）、分家への独立授封（難易度50、出目89・成功）と非華族の開拓功労者への叙爵・授封（難易度60、出目81・成功）が広く行われた。当初想定された重要港湾・軍事拠点の帝国直轄維持は失敗し（難易度15、出目6・失敗）、函館・室蘭・小樽などの主要港湾都市も領国に編入された。[^p034] 本土では奉還地が再授封されず帝国直轄地が増えた一方、北海道では領主制がむしろ拡大するという非対称な発展となった。[^p034] 制度の全体は[新規授封と加増](../institutions/new-enfeoffment.md)を参照。

北海道の授封は、日清戦争後の[論功行賞](../events/reward-distribution-1889.md)において「台湾は駄目でも北海道の未授封地域なら加増できる」という議論の根拠となり、実際に北海道での加増が行われた（難易度40、出目63・成功）。「海外領土は帝国のものとするが、国内の未開拓地については領主への報償として利用できる」という原則が生まれた（原則の定式化は検討案）。[^u078][^p034]

# 成立と制度

## 分領支配の恒久化

史実の明治政府は北海道全域を自力で開拓・統治する財政的余裕がなく、諸藩・寺院・士族などに地域を割り当てる分領支配を行った。本世界線では廃藩置県が起きず、しかも全国的な[領主権](../institutions/lordship-rights.md)の登録制度、紛争裁定機関（[領主権裁定院](../institutions/lordship-tribunal.md)）、[元老院](../institutions/genroin.md)が存在するため、制度的には史実よりも分領支配を継続しやすい条件が揃っている。[^u066]

石狩・十勝・釧路などの国に大領主・中小領主を配置し、開拓費の負担と引き換えに一定の統治権を認めるのが基本形である。領主権は「律令国」とは別個の権利として、国の全部または一部に設定される。[^u066]

## 開拓委託と授封の二段階

北海道では、最初は開拓を委託された領主家が統治し、事業が定着した地域で正式な領主権が認められる、という二段階の手続きが想定される。**開拓事業の委託と世襲領主権の授与は別手続き**であり、開拓に成功すれば自動的に永続的な世襲領主権を得る仕組みにはしない。そうしなければ帝国政府は将来の統治権を際限なく手放すことになるからである。実際に領地を得る家と、投資だけを行う家も区別される。[^u066]

## 元老院の承認と例外化

新規授封には元老院の承認を要する制度が確立し（ダイス判定：難易度15、出目45・成功）、1900年以降、新規授封は例外的措置に限られた（難易度30、出目79・成功）。北海道の新規授封は1869〜1890年代に集中し、第一次世界大戦後に少数の例外的授封があった（難易度65、出目84・成功）。[^p034] 無領華族（旧公家など）への北海道での授封は行われなかった（難易度45、出目17・失敗）。[^p034]

## 恩賞としての領主権新設

1866年以降の帝国は領主たちの権利を保障することで成り立っているが、すべての領主が裕福なわけではない。北海道への進出を認めることは、新しい土地を開拓したい領主家への政治的な恩賞にもなる。[^u066]

# 北海道の領主層

## 四つの類型

| 類型 | 成立経緯 | 元老院互選への影響 |
|---|---|---|
| 松前家 | 既存の領主権を維持 | 既存の1票 |
| 本土領主家 | 開拓事業・加増による領国拡大 | 票は増えない |
| 本土領主家の分家 | 開拓地への独立授封 | 新たな1票 |
| 開拓功労者 | 叙爵と授封による領主家創設 | 新たな1票 |

独立分家は法的には本家と対等だが、開拓資金を本家に頼る家が多く、本家の政治的影響下に置かれやすい。北海道進出に積極的な大領主は、元老院内でも勢力を広げた（検討案）。[^p034] 1867〜1937年の新領主家は35家（独立分家24・非華族11）で、うち31家が1900年までに成立した（家数は作者確定）。[^p034] 旧家臣団の俸禄負担の整理に失敗していたため、北海道開拓は余剰家臣の移住先にもなった。[^p033]

## 福井松平家の本拠移転

福井松平家は北海道開拓でクリティカル（出目96）を出し、本拠地を北海道へ移したと設定された（方向性は確定、移転年・領都・授封範囲は未定）。[^p052] 領主権は奉還せず福井に越前の領国政府を残したまま、当主の居所・家門の財産管理機関・系列企業の統括本部が北海道に移る「飛地領国を持つ領主家の本拠地変更」であり、北海道を第二の領国から主たる領国へ発展させた代表的な家とされる（検討案）。本拠の候補には札幌周辺・室蘭・旭川・小樽が挙がる。北海道の森林資源を越前の人造繊維工業へ、越前の繊維機械技術を北海道の機械工業へ回す分業が想定されている（検討案）。[^p052]

## 津軽海峡経済圏

津軽家は北海道開拓でクリティカル（出目98）を出したが、本拠は弘前に置いたまま、青森と北海道南部に企業・金融拠点を置く複数拠点型とされる。北海道側の農場・山林・水産と津軽側の米穀・銀行を連絡輸送網で結ぶ「津軽海峡経済圏」を築き、1937年の家産所得の50〜65%が北海道由来とされる（検討案）。[^p062] 伊達家から独立した「津軽・北海道領主連合」（1937年に10家所属、検討案）の中核である。[^p062][^p077]

## 北海道新興領主と北海道諸侯聯合会

北海道で新規授封された新興領主のうち5家について、次の判定が行われた。[^p065]

| 判定項目 | 難易度 | 出目 | 結果 |
|---|---:|---:|---|
| 授封後の初期開拓・財政基盤確立 | 35 | 3 | 失敗（ファンブル） |
| 農林鉱業・近代産業の大規模資本化 | 30 | 47 | 成功 |
| 人口流入・交通網・都市形成を家産拡大につなげる | 35 | 73 | 成功 |
| 第一次世界大戦の資産形成 | 30 | 82 | 成功 |
| 1927年以降の金融危機での資産毀損回避 | 55 | 89 | 成功 |
| 本州の旧大領主・本家の金融圏から独立 | 55 | 78 | 成功 |
| 北海道新興領主間で独自の共同金融・政治組織を形成 | 40 | 64 | 成功 |

授封直後に開拓費の膨張と債務累積で深刻な財政危機に陥ったが、1890年代に開拓事業を再編して農林鉱業を伸ばし、1920年代に本家から経済的に独立した。金融危機は軽微な損失で乗り切り、1930年代に相対的な地位を高めた（経過は検討案）。[^p065] 初期の失敗が共同の資金調達を早くから必要とさせ、共同金融・家産管理・産業開発・交通政策・元老院での相互推薦を担う仮称「**北海道諸侯聯合会**」が生まれた。全国的な[諸侯共済会](../economy/lord-financial-spheres.md)とは別の地域組織である（検討案）。[^p065] 5家の純資産は1937年に計15.12億円で、中堅領主を上回る（P96で確定）。[^p096] 家名と授封地は未定である。詳細は[中堅・中小領主と北海道新興領主](../economy/minor-lords.md)を参照。

## 北海道の四系統の領主勢力（検討案）

| 系統 | 主な家 | 性格 |
|---|---|---|
| 本州大領主系 | 徳川宗家・毛利・黒田など | 農林鉱業・土地開発・資源投資 |
| 前田・福井松平系 | 前田・福井松平 | 北陸金融圏の展開、総合開発・精密機械 |
| 津軽・北海道連合 | 津軽 | 開拓金融・海峡物流・農林水産 |
| 北海道新興領主連合 | 新興5家など | 共同金融・地域開発・元老院での政治協力 |

[^p065]

福井松平家と津軽家がいずれも金融危機への対応に失敗したため、1927年以降の北海道開発金融市場は深刻な信用収縮を経験した可能性がある（検討案）。[^p062]

## 当初の想定（検討案）

| 領主家 | 想定される北海道への関与 |
|---|---|
| 松前家 | 既存の所領・交易関係を基盤として道南の統治に関与 |
| 伊達家など東北の領主 | 北海道南部・内陸部の開拓 |
| 前田家 | 開拓資本、港湾、交通整備への投資 |
| 徳川家 | 旧幕臣の再就職先・移住事業 |
| 中小領主 | [寄親](../concepts/yorioya-yoriko.md)となる大領主と共同で開拓事業に参加 |

[^u066]

中小領主が寄親の大領主と共同で参加する形は、本世界線の[寄親・寄子制](../concepts/yorioya-yoriko.md)の延長として位置づけられる。この表は会話ログ1の段階の想定であり、会話ログ3の判定では前田家の北海道事業は限定的な成功にとどまり、毛利・黒田・津軽・福井松平などが主要な担い手となった（上記）。[^p038][^p062]

# 1880年代の政治地図（検討案）

以下は架空の配分例であり、実際の土地利用や先住住民の権利を無視して自由に授封できるという意味ではない。[^u066]

| 国 | 統治形態の例 |
|---|---|
| 渡島国 | 松前家など既存の領主権と帝国直轄地が併存 |
| 石狩国 | 札幌周辺を帝国直轄とし、周辺では領主による開拓を認める |
| 胆振国 | 東北系領主家などによる開拓領が成立 |
| 十勝・釧路・根室国 | 直轄地を中心に、開拓委託地が点在 |
| 千島国 | 国防上の理由から帝国の直接管理を基本とする |

当初の想定では、道都にあたる札幌周辺と重要港湾、国境に面した千島は帝国直轄国、内陸や沿岸の開拓地には世襲領主領と開拓委託地が配置される、という「重要拠点は帝国、開拓は領主」という分担であった。しかし重要港湾・軍事拠点の帝国直轄維持は判定で失敗し（出目6）、主要港湾都市も領国に編入された（→「却下・修正された案」）。[^p034]

## 港湾都市の領国編入

領国に編入されることと、国防施設が領主の指揮下に入ることは別である。[^p034]

| 権限 | 帰属 |
|---|---|
| 港湾都市の一般行政 | 領国政府 |
| 商港の管理・整備 | 領国政府 |
| 港湾使用料等の徴収 | 領国政府 |
| 海軍基地の管理 | 帝国政府 |
| 軍事施設の警備 | 帝国軍 |
| 国防・外交政策 | 帝国政府 |
| 一般臣民に対する司法権 | 領国司法権 |

基地敷地には帝国が特別な管理権を持つため、函館・室蘭・小樽などが領国に属していても統一国軍とは矛盾しない。領主は港湾収入・工業用地・鉄道・倉庫業から大きな利益を得る。どの港湾がどの家に帰属するかは未定である（検討案）。[^p034]

# 経済

* **資源**: 北海道は筑豊・三池と並ぶ国内の石炭供給源とされ、工業化に伴う需要増と製鉄用炭の品質が課題となる。[^u081]（[資源戦略](../economy/resource-strategy.md)参照）
* **交通**: 国力試算における鉄道営業距離は「日本本土・北海道」を対象とし、台湾・朝鮮を含めない。北海道は帝国本土の交通網の一部として[帝国交通整備計画](../economy/transport-plan.md)の対象となる。[^u084]
* 開拓資本・港湾・交通整備への領主系資本（前田家など）の投資が開発を担う。[^u066]

# 1930年代の経済（1937年）

## 北海道開拓領国

1937年の249領国を経済類型で分けると、「北海道開拓領国」は35家・人口500万人で、地域GDPは約25億円（1人当たり500円、全国平均の98%）である。北海道に領地があっても経済の中心が本州にある家は、この類型に含めない（P97で一括確定、分類は暫定推計）。[^p094][^p097]

| 項目（1937年） | 値 |
|---|---:|
| 領国数（家） | 35 |
| 人口 | 500万人 |
| 地域GDP | 25億円 |
| 独自歳入 | 1.40億円（1人28.00円） |
| 帝国の財政調整交付金 | 0.85億円（1人17.00円、独自歳入比60.7%） |
| 帝国への法定拠出金（減免後） | 0.085億円 |
| 公共投資 | 1.50億円 |
| 建設公債純発行 | 1.385億円 |

[^p094]

交付金なしでは経常収支が年0.735億円の赤字となる。交付金は貧困対策ではなく、広大な領域の行政需要に応じたものとされる。交付金4.5億円のうち0.6億円が北海道・開拓地域支援の目的別枠である。[^p094] 北海道の新規授封領には、開拓初期に一定期間、法定拠出金の免除が認められていた可能性がある（検討案）。[^p075] 領国財政は[領国の類型・財政と財政調整交付金（1937）](../economy/fief-finance-1937.md)を参照。

## 石炭

1937年の国内石炭生産5,400万tのうち、北海道は1,950万t（36.1%）を産し、九州（2,550万t、47.2%）に次ぐ産炭地である（常磐500万t、山口・中国地方300万t、その他100万t）。黒田家・毛利家の北海道資源開発を反映して、史実より北海道の比重が大きく引き上げられた（P89で設定、P97で確定）。[^p089][^p097] 国内炭の生産は1930年の約6,000万tから1937年の5,400万tへ減少した。坑内掘りの機械化・集約化の失敗（ダイス判定：難易度40、出目27・失敗）で、九州の古い炭鉱は合理化できずに縮小したが、北海道の新炭田は黒田系・毛利系など領主系企業集団の長期契約に守られて生産を保った。ただしその生産性は低く、鉱業就業者は90万人にのぼる。国内炭は価格面で外国炭に劣るが、長期契約と輸送の都合で自給率は高く保たれている（作者確定）。[^e079][^p089] 製鉄用原料炭1,020万tのうち240万t（23.5%）も北海道産である。[^p089] ただし北海道の1,950万tは個別に検証された値ではない。[^p089]

| 炭田 | 露天掘りの適性 | 想定される開発形態 |
|---|---|---|
| 石狩炭田 | 一部で高い | 露天掘りと機械化坑内掘り |
| 留萌炭田 | 一部で高い | 浅部炭層の開発 |
| 釧路炭田 | 低い | 坑内掘りの合理化 |

[^e078]

会話ログ2では、国内炭鉱の露天掘り開発（ダイス判定：難易度55、出目49・失敗）と坑内掘りの機械化・集約化（難易度40、出目27・失敗）がいずれも失敗し、全国の露天掘り比率は約5%にとどまったとされた。[^e079] 生産量は会話ログ3の再積算で北海道・常磐の開発を前提に引き上げられたが、機械化の失敗は「1930年代の国内炭の減少（約6,000万t→5,400万t）と北海道炭鉱の低生産性」として生かされている（作者確定）。「1930年4,800万t→1937年3,800万t」という旧推計は「却下・修正された案」に移した。[^p089]（→[エネルギー需給と電化（1937）](../economy/energy-1937.md)）

史実でも空知地方に露天掘り炭鉱が存在したが、国内石炭産業の大部分は長く坑内掘りに依存していた。[^e078]

## 石油・鉱物

国内油田の探査・開発はクリティカルで成功した（1d100 > 65、出目100）。[^e081] 会話ログ3の再積算では、1937年の国内原油は60万t（秋田32万t、新潟20万t、北海道5万t、台湾・その他3万t）とされた（確定）。[^p089] クロムなどの金属資源もあるが、1930年代の国内金属鉱山の経営危機（出目1・ファンブル）で国内採掘は大きく縮小した。[^e080][^e081] 1937年の国内鉄鉱石220万tは「国内で調達できる鉄原料」で、採掘した鉄鉱石約60万t（釜石中心）と、化学工業の副産物である硫酸滓や砂鉄など約160万tからなり、北海道での鉄鉱石採掘はわずかである（作者確定）。[^p089]

## 農業

全国的な農地区画整理が1929年までにクリティカルで成功した本世界線では、北海道は大区画化と大型農業機械の導入が進む地域とされる（検討案）。[^e073] 北海道の開墾は主に1920年代までに進み、1929年の全国の耕地約720万haのうち北海道はすでに約95万haを占めた。1930年代は農業基盤整備事業の失敗（ダイス判定：難易度30、出目19・失敗）で本州の未改良耕地およそ40万haが耕作放棄され、全国の耕地は1937年に680万haへ減ったが、北海道の耕地はほぼ横ばいである（作者確定）。[^e074] 1930年代の農村からの労働移動（難易度35、出目55・成功）の一部は、都市ではなく北海道の開拓地に向かった（作者確定）。[^e096] 1937年の耕地680万haのうち北海道は95万ha（水田20万ha・畑等75万ha、全国の14%）を占め、米は20万haで50万t（10a当たり収量は本州の約8割）にとどまる。北海道開拓の効果は小麦・馬鈴薯・豆類・甜菜と、酪農・羊毛・食肉などの畜産に表れている（確定）。[^p088] 庄内酒井家・津軽家・福井松平家などの畜産・農業経営がこれを担った。[^p088]（→[農林水産業の近代化（1900〜1937）](../economy/agriculture-1937.md)）

## 交通と港湾

1937年の鉄道営業距離45,000kmのうち北海道は7,500km（約6分の1）を占める。津軽系・前田福井松平系・北海道新興領主連合が民間鉄道や共同出資会社（仮称「日本開拓鉄道」）を通じて関与している（確定）。[^p090][^p096] 主要港の取扱量は室蘭1,200万t（北海道資源）、小樽850万t（北海道産品・石炭）、函館650万tである（確定）。[^p090] 津軽系海運は海峡連絡と北海道輸送に35万総tを持つ。[^p090]

# 政治的意味

## 元老院の議席構成への影響

当初は、新領主家が増えれば元老院の領主議員も増えると考えられ、**天皇と元老院が共同で新領主権の設定を承認する制度**が検討された。[^u066] 会話ログ3では、領主互選の定数は固定で、新領主家の創設は議席ではなく互選の有権者（各当主1票）を増やすことになった。そのため元老院は加増以上に新領主家の創設を警戒し、新規授封に元老院の承認を要する制度が確立した（ダイス判定：難易度15、出目45・成功）。[^p033][^p034]

1936年の元老院選挙では、北海道新興領主連合が10家中7人を当選させたとされ（検討案）、北海道新興領主・開拓関係華族は倶楽部「**北辰会**」（11議席、名称・議席数とも暫定）を構成する。津軽家も北辰会に属するとされる（検討案）。[^p077][^p078][^p079] 詳細は[元老院の倶楽部政治と1936年元老院選挙](../politics/genroin-clubs.md)を参照。

## 台湾への波及

北海道で開拓に成功した領主家に世襲領主権を与えた前例は、[台湾](taiwan.md)の開発に参加する領主家にも同様の権利を要求させる根拠になりうる。帝国政府はこれを拒否する場合、「北海道と台湾では何が違うのか」を憲法と「例」によって説明しなければならない。[^u066]

## 戦後の加増候補地

日清戦争後、元老院では「台湾は駄目でも、北海道の未授封地域なら加増できるのではないか」という議論が起こりうる。ただし加増は元老院の力関係を変える行為であり、最終的には爵位・勲章・年金中心の近代的な論功行賞が主流となり、加増・新規授封は特別な功績に限られる方向が想定される。[^u078]

# 先住民族（アイヌ）の問題

アイヌの人々が既に生活し土地を利用していた地域を「無主地」と見なして割り振ることには重大な問題がある。領主権を新設するのであれば、先住住民の権利や自治をどう扱うかを本世界線の政府も決めなければならない。[^u066] 世襲領主が行政・司法・治安権を持つ領主領が成立すると、先住民の権利保護が個々の領主の統治に委ねられるおそれがあり、帝国直轄国と領主領で扱いが分かれる可能性もある。

# 却下・修正された案

* **「重要拠点は帝国、開拓は領主」の分担**: 札幌周辺・重要港湾・軍事拠点を帝国直轄とする想定は、直轄維持の判定失敗（難易度15、出目6）により、主要港湾都市も領国に編入し軍事施設の敷地のみ帝国が管理する形に改められた。千島の扱いは改めて判定されていない。[^u066][^p034]
* **新領主家の創設＝議席増**: 新領主家が増えれば領主議員も増えるという想定は、互選定数が固定され新領主家は有権者を増やすだけ、という制度に置き換えられた。[^u066][^p033]
* **石炭生産の旧推計（前編・会話ログ2）**: 1930年の国内生産4,800万t（前編）、1937年の北海道1,450万t（国内生産3,800万t、筑豊1,050万t・三池450万t・常磐350万t・宇部200万t）という記述 → 会話ログ3の再積算で北海道1,950万t・国内生産5,400万t（九州2,550・北海道1,950・常磐500・山口中国300・その他100）に修正。さらに作者確定で1930年の国内生産を約6,000万tとし、1930年代は九州の古い炭鉱の縮小で減少した、とした。[^e079][^p089]
* **国内鉄鉱石220万tの旧内訳（会話ログ3）**: 釜石・北上130、中国40、北海道30、その他20万tという鉱山別の内訳と「国内の鉱山開発には成功している」という説明は、金属鉱山のファンブル（出目1）と合わないため、採掘約60万t＋硫酸滓・砂鉄など約160万tという鉄原料の内訳に改めた（作者確定）。[^e081][^p089]
* **「北海道の耕地拡大によって食料供給を増やした」（会話ログ3）の時期**: 1930年代の拡大と読む余地があったが、北海道の開墾は主に1920年代までとした（作者確定）。[^e074][^p088]
* **原油の旧推計（会話ログ2）**: 国内原油100万tのうち北海道10万t → 国内60万tのうち北海道5万tに修正。[^e081][^p089]

# 未決の論点

* 北海道のどの国・港湾がどの領主家に帰属するか（領国配置）、福井松平家の領都の位置。[^p034][^p052]
* アイヌの土地・権利・自治の扱い。[^u066]
* （解決）北海道の未授封地域を論功行賞の加増に用いるか否か → 用いた（出目63・成功）。[^u078][^p034]
* （解決）新領主の授封の承認権限 → 元老院の承認を要する（出目45・成功）。叙爵は天皇、授封は元老院の議決と天皇の承認という分担は検討案。[^u066][^p033][^p034]
* 新規領主35家・北海道新興領主5家の家名と授封地、北海道に分家を授封した本土領主家の内訳（徳川系が何家かなど）。[^p034][^p037][^p065]
* 北海道の石炭1,950万tや耕地の配置の物理的な検証。[^p089]（耕地の時期の問題は作者確定で解決：開墾は主に1920年代まで）
* 1937年の北海道の農業の具体像（大区画化・大型農機導入の程度。地域別の土地改良の差は検討案にとどまる）。[^e073]
