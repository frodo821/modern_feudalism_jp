# 概要

本世界線の北海道は、史実と同じく1869年に蝦夷地から改称され11国86郡が置かれたが、1871年の廃藩置県が起きないため、史実では短命に終わった**分領支配が恒久的な地方統治制度へ発展する**余地を持った地域である。[^u066] 開拓費の負担と引き換えに大領主・中小領主へ一定の統治権が認められ、重要港湾や国境地域は帝国が直接統治する。結果として北海道は、[新領土の統治制度](/institutions/new-territory-governance.md)における「世襲領主領」と「帝国直轄国」が併存する、帝国内でもっとも多くの新領主家が生まれうる地域となる。[^u066]

北海道の授封は、日清戦争後の[論功行賞](/events/reward-distribution-1889.md)において「台湾は駄目でも北海道の未授封地域なら加増できる」という議論の根拠にもなり、帝国の領主制が新たな封建的権力を創設するかどうかという問題の焦点となる。[^u078]

# 成立と制度

## 分領支配の恒久化

史実の明治政府は北海道全域を自力で開拓・統治する財政的余裕がなく、諸藩・寺院・士族などに地域を割り当てる分領支配を行った。本世界線では廃藩置県が起きず、しかも全国的な[領主権](/institutions/lordship-rights.md)の登録制度、紛争裁定機関（[領主権裁定院](/institutions/lordship-tribunal.md)）、[元老院](/institutions/genroin.md)が存在するため、制度的には史実よりも分領支配を継続しやすい条件が揃っている。[^u066]

石狩・十勝・釧路などの国に大領主・中小領主を配置し、開拓費の負担と引き換えに一定の統治権を認めるのが基本形である。領主権は「律令国」とは別個の権利として、国の全部または一部に設定される。[^u066]

## 開拓委託と授封の二段階

北海道では、最初は開拓を委託された領主家が統治し、事業が定着した地域で正式な領主権が認められる、という二段階の手続きが想定される。**開拓事業の委託と世襲領主権の授与は別手続き**であり、開拓に成功すれば自動的に永続的な世襲領主権を得る仕組みにはしない。そうしなければ帝国政府は将来の統治権を際限なく手放すことになるからである。実際に領地を得る家と、投資だけを行う家も区別される。[^u066]

## 恩賞としての領主権新設

1866年以降の帝国は領主たちの権利を保障することで成り立っているが、すべての領主が裕福なわけではない。北海道への進出を認めることは、新しい土地を開拓したい領主家への政治的な恩賞にもなる。[^u066]

# 関与が想定される領主家（検討案）

| 領主家 | 想定される北海道への関与 |
|---|---|
| 松前家 | 既存の所領・交易関係を基盤として道南の統治に関与 |
| 伊達家など東北の領主 | 北海道南部・内陸部の開拓 |
| 前田家 | 開拓資本、港湾、交通整備への投資 |
| 徳川家 | 旧幕臣の再就職先・移住事業 |
| 中小領主 | [寄親](/concepts/yorioya-yoriko.md)となる大領主と共同で開拓事業に参加 |

[^u066]

中小領主が寄親の大領主と共同で参加する形は、本世界線の[寄親・寄子制](/concepts/yorioya-yoriko.md)の延長として位置づけられる。

# 1880年代の政治地図（検討案）

以下は架空の配分例であり、実際の土地利用や先住住民の権利を無視して自由に授封できるという意味ではない。[^u066]

| 国 | 統治形態の例 |
|---|---|
| 渡島国 | 松前家など既存の領主権と帝国直轄地が併存 |
| 石狩国 | 札幌周辺を帝国直轄とし、周辺では領主による開拓を認める |
| 胆振国 | 東北系領主家などによる開拓領が成立 |
| 十勝・釧路・根室国 | 直轄地を中心に、開拓委託地が点在 |
| 千島国 | 国防上の理由から帝国の直接管理を基本とする |

道都にあたる札幌周辺と重要港湾、国境に面した千島は帝国直轄国、内陸や沿岸の開拓地には世襲領主領と開拓委託地が配置される、という「重要拠点は帝国、開拓は領主」という分担が特徴である。

# 経済

* **資源**: 北海道は筑豊・三池と並ぶ国内の石炭供給源とされ、工業化に伴う需要増と製鉄用炭の品質が課題となる。[^u081]（[資源戦略](/economy/resource-strategy.md)参照）
* **交通**: 国力試算における鉄道営業距離は「日本本土・北海道」を対象とし、台湾・朝鮮を含めない。北海道は帝国本土の交通網の一部として[帝国交通整備計画](/economy/transport-plan.md)の対象となる。[^u084]
* 開拓資本・港湾・交通整備への領主系資本（前田家など）の投資が開発を担う。[^u066]

# 政治的意味

## 元老院の議席構成への影響

新領主家が増えれば元老院の領主議員も増える。新領主を叙爵し議席を与える権限を誰が持つのかという憲法問題が生じ、**天皇と元老院が共同で新領主権の設定を承認する制度**であれば、中央政府が自派の領主を増やして議席構成を変えることを防げる（検討案）。[^u066]

## 台湾への波及

北海道で開拓に成功した領主家に世襲領主権を与えた前例は、[台湾](/regions/taiwan.md)の開発に参加する領主家にも同様の権利を要求させる根拠になりうる。帝国政府はこれを拒否する場合、「北海道と台湾では何が違うのか」を憲法と「例」によって説明しなければならない。[^u066]

## 戦後の加増候補地

日清戦争後、元老院では「台湾は駄目でも、北海道の未授封地域なら加増できるのではないか」という議論が起こりうる。ただし加増は元老院の力関係を変える行為であり、最終的には爵位・勲章・年金中心の近代的な論功行賞が主流となり、加増・新規授封は特別な功績に限られる方向が想定される。[^u078]

# 先住民族（アイヌ）の問題

アイヌの人々が既に生活し土地を利用していた地域を「無主地」と見なして割り振ることには重大な問題がある。領主権を新設するのであれば、先住住民の権利や自治をどう扱うかを本世界線の政府も決めなければならない。[^u066] 世襲領主が行政・司法・治安権を持つ領主領が成立すると、先住民の権利保護が個々の領主の統治に委ねられるおそれがあり、帝国直轄国と領主領で扱いが分かれる可能性もある。

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 1869年 | 蝦夷地を北海道と改称、11国86郡設置。諸藩・寺院・士族に分領支配 | 同様に改称・設置、分領支配開始 |
| 1871年 | 廃藩置県に伴い分領支配廃止、開拓使の直轄へ | 廃藩置県なし。分領支配が恒久化しうる |
| 統治主体 | 開拓使→三県→北海道庁 | 世襲領主領と帝国直轄国の併存 |
| 開拓の担い手 | 開拓使・屯田兵・移民 | 領主家（松前・伊達・前田・徳川など）と寄子の中小領主、旧幕臣の移住 |
