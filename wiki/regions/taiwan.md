# 概要

台湾・澎湖諸島は、本世界線の[日清戦争（1887〜1889）](/events/sino-japanese-war.md)の講和である1889年の[下関条約](/diplomacy/shimonoseki-treaty-1889.md)によって清国から日本帝国へ割譲された。[^u077] 割譲要求の直接の動機は、清の南洋海軍・福建水師の侵入を防ぐ南西方面の前進基地確保である。[^u065]

世襲[領主権](/institutions/lordship-rights.md)を憲法で保障する帝国であっても、台湾は特定の大領主へ授封されず、**帝国直轄の特別領**（帝国特別領）として「例」に基づく総督・長官統治を受ける。[^u066] 統治権（軍事・外交・司法・治安）は帝国が保持する一方、港湾・鉄道・鉱業・製糖業などの事業権は国内の領主系企業と欧米資本に開放され、列強に台湾割譲を容認させる外交上の取引材料ともなった。[^u069]

# 割譲までの経緯

## 戦争目的への組み込み

日清戦争は高宗の保護と朝鮮独立保障をめぐって始まったが、清が局地戦の敗北後に追加派兵し全面戦争へ移行すると、日本の戦争目的は段階的に拡大した。南洋海軍の侵入を防ぐためには台湾はどのみち要求されるとされ、台湾・澎湖割譲は最低講和条件の一つに加えられた。[^u065]

| 最低講和条件（全面戦争段階） |
|---|
| 朝鮮の完全独立承認 |
| 高宗の王位承認と清軍撤退 |
| 北洋艦隊の無力化 |
| 台湾・澎湖諸島の割譲 |
| 戦争賠償金 |
| 通商条約の再整備 |

[^u065]

ただし「強く要求する」ことと「絶対条件にする」ことは別であり、絶対条件化には両院の支持が必要とされた。[^u065] [元老院](/institutions/genroin.md)では、講和条件をめぐって限定講和派・安全保障重視派・強硬講和派が争い、台湾・澎湖割譲は強硬講和派の主張として位置づけられる。[^u067]

## 戦略的意味

* 台湾を領有しても、南洋艦隊は台湾東側を通過できるため完全な封鎖にはならない。目的は南西方面の前進基地確保と清海軍行動の制約である。[^u065]
* 澎湖は台湾海峡の監視と沿岸圧力に直結し、南洋・福建海軍の制約という目的に限れば台湾本島より直接的である。[^u065]
* 獲得の意味として、澎湖による台湾海峡での海軍活動の支援、南西方面の帝国海軍基地整備、清が台湾を対日拠点にする可能性の低減、領主系企業・民間企業への通商投資機会が挙げられる。統治費用と住民の抵抗は問題として残る。[^u067]

## 軍事的困難

1887年の台湾攻略は1895年より難しい可能性がある。1880年代には劉銘伝による海防・近代化事業が進んでおり、1884〜85年の清仏戦争で仏軍が台湾北部攻略に疫病・補給で苦しんだ先例もある。割譲要求に全島占領は不要だが、拒否された場合の圧力能力は必要とされる。[^u065] 台湾割譲は清の領土そのものを失わせる条件であるため早期講和では認めさせにくく、列強との事前交渉と順天府（北京）への進軍能力の誇示が必要となった。戦争後半には対外準備まで進んだ「国家方針」となり、撤回は困難になる。[^u071]

## 対列強外交とコンセッション

日本は台湾割譲を要求する前から、列強に商業上の利益を保証する外交工作を行う（検討案）。説明の骨子は「清国の統治下で認められていた外国商人の通商上の権利は、日本領となった後も尊重する」である。[^u069]

| 列強 | 日本が提示しうる条件 | 交渉上の問題 |
|---|---|---|
| イギリス | 台湾海峡の航行自由、開港場維持、港湾・鉄道投資 | 清国市場への影響と地域の勢力均衡 |
| フランス | 基隆などでの商業特許、台湾北部への投資、インドシナ権益への不干渉 | 清仏戦争直後で台湾への関心が強い |
| ドイツ | 鉄道、機械、軍需・港湾設備の商業契約 | 清国との武器取引や外交関係 |
| ロシア | 通商上の権利と航行の自由 | 日本の海軍力拡大と朝鮮への影響 |
| アメリカ | 開港・通商の平等、投資機会 | 本世界線では対日関係が史実と異なる |

[^u069]

列強すべての支持は必要なく、共同干渉が成立しなければ十分とされた。イギリスが中立、アメリカが既存の対日関係重視、フランスが商業譲歩と引き換えに反対を控えれば、ロシアが警戒しても三国干渉相当の共同圧力は形成しにくい。あわせて「遼東半島の永久割譲には固執しない。その代わり台湾・澎湖諸島の領有を認めさせる」方針がとられた。[^u069] 台湾の特許を与える国と対清融資を担当する国は一致する必要がない。[^u072]

# 統治制度

## 帝国特別領

台湾には既存の清朝行政機構、都市、地域社会、先住民族の諸共同体が存在するため、北海道の分領支配をそのまま持ち込むことはできない。例えば島津家と毛利家に台湾を二分して与えれば、両家の領主権と日本の対外安全保障が密接に結びつき、帝国政府が軍港や海峡防衛を直接管理する際の障害になる。[^u066] このため台湾は[新領土の統治制度](/institutions/new-territory-governance.md)の三類型のうち「帝国特別領」に分類され、特別な「例」による総督・長官統治を受ける。[^u066]

この方針は日清戦争以前から、元老院の領主議員が新領土の有力領主への授封による勢力均衡の変化を警戒するため、合意を得やすいと見込まれていた。[^u037]

## 台湾統治例（検討案）

1889年の下関条約締結と同時期に、台湾・澎湖を帝国直轄の特別領とする「台湾統治例」が制定される。新領土の恒久的な統治制度は中央政府だけでは決められず、元老院・衆議院の関与を要するためである。[^u077]

## 事業権の開放

| 原則 | 内容 |
|---|---|
| 統治権 | 軍事・外交・司法・治安は帝国が保持 |
| 事業権 | 港湾・鉄道・鉱業・製糖業などを領主系企業・民間企業・外国資本に付与 |
| 規制 | 外国資本の参入は認めるが、入札・事業許可・営業規制は帝国の「例」に従う |
| 住民の権利 | 特許による独占・土地取得が住民の権利を侵害しないよう帝国法で規制。事業特許は無制限の土地収用権を意味しない |
| 主権 | 経済的特権は与えても、領事裁判権や外国警察権は与えない |

[^u066][^u069]

コンセッションの種類としては、自由港・開港場（負担小）、事業特許、外国人居留地、租界、租借地（主権制約大）が区別され、台湾では租界・租借地は与えない。[^u069] 例えば、基隆港の港湾整備をイギリス系企業へ委託し一定期間の使用料徴収権を認める、フランス系企業へ鉱業・鉄道事業の特許を与える、といった形が想定される（検討案）。[^u069]

既存の開港場である淡水・安平・基隆・打狗（高雄）における外国通商権は維持される。[^u069]

## 国内領主の関与

大領主たちは台湾領有を支持しても、自ら直接統治したいわけではなく、外国資本と共同で港湾・鉄道・鉱山・製糖業に投資したいと考える。[^u069] 戦後の[論功行賞](/events/reward-distribution-1889.md)においても、台湾・澎湖は帝国直轄領とし、領主家には新領地ではなく爵位の陞叙・金銭的恩賞・国家事業の受注機会を与える方向が想定される。[^u078] 「台湾では欧米資本と領主系企業が競争・協業し、行政・司法・治安は帝国直轄」というのが本世界線の台湾の基本像である。[^u069]

# その後の台湾

* **財政負担**: 日清戦争の経験として、占領・戦後処理・台湾統治・海軍補充にも費用がかかり、「戦争は勝てば儲かる事業ではない」という認識が帝国政府と領主に共有された。[^u088]
* **戦間期**: 日本は中国大陸に大規模な駐屯軍や植民地行政を持たないが、台湾の維持費と朝鮮との安全保障支出は残る。[^u102]
* **海軍の任務**: 1920年代の帝国海軍は、海上交通の保護と並んで台湾・本土防衛を任務とし、本土・台湾の防衛を英国に委ねられないことが戦艦を一定数保有する理由の一つとされる。[^u127][^u130]（[帝国海軍の戦略思想](/military/navy-strategy.md)参照）

# 1937年の台湾経済

## 帝国の国内としての台湾

1937年の日本帝国の経済統計では、台湾・澎湖諸島は国内に含まれる。本世界線の日本は台湾・澎湖を領有するが、朝鮮（独立国）と南樺太は領有しない。英植民地における日本資本の事業は国内生産ではなく海外投資として扱われるのに対し、台湾での生産は国内生産である。[^e072] 人口7,800万人、国内総生産260.26億ドル相当（1937年米国価格基準、対米28.0%）などの1937年の基本指標も台湾を含む値である。[^e097]（→[1937年の日本経済](/economy/economy-1937-overview.md)）

## 砂糖と米の供給地域

台湾は1889年から約半世紀にわたって帝国の統治下にあり、製糖業と農業基盤への投資が続けられた結果、**砂糖と米の重要な供給地域**となっている。[^e072] 土地改良の地域差としては、台湾では灌漑と製糖原料生産の大規模化が進むとされる（検討案）。[^e073]

| 指標（1937年） | 値 |
|---|---:|
| 帝国の耕地570万haのうち台湾 | 70万ha |
| 帝国のサトウキビ作付 | 20万ha |
| サトウキビ生産 | 900万t（単収45t/ha） |
| 砂糖生産（製糖歩留まり11%） | 約99万t（自給率68%） |
| 台湾の製糖原料生産の対米労働生産性 | 45〜60% |

[^e074][^e075]

台湾の製糖原料生産の対米労働生産性（45〜60%）は、帝国の農業全体（30〜40%とされたが後に過大と判断）を大きく上回り、帝国の耕種農業の中では比較的競争力のある部門である。[^e074] 帝国全体の砂糖需要145万tに対する不足分46万tは東南アジアなどから輸入される。[^e075]

史実の1935年前後の日本本土は、米の国内生産約941万tに加え、朝鮮から約121万t、台湾から約71万tを移入していた。本世界線では朝鮮は独立国で台湾は帝国内に含まれるため、台湾産米は国内生産に数えられ、不足分はビルマ・タイ・朝鮮などからの輸入で補われる。[^e072]

## 鉱物資源と交通

* **石炭**: 1937年の国内石炭生産3,800万tのうち「その他・台湾」が300万tを占める。[^e079]
* **石油**: 小規模な石油・天然ガス開発が行われ、国内油田開発のクリティカル成功（ダイス判定：1d100 > 65、出目100）のもとで、1937年に原油8万tを産する。[^e080][^e081]
* **金・銀**: 国内各地と台湾の採算性の高い鉱山が、1930年代の国内金属鉱山の経営危機の中でも維持される。[^e080][^e081]
* **鉄道**: 1937年の帝国の鉄道営業延長32,000km（電化12,800km）は台湾を含む値である。[^e091]

# 史実との比較

| 項目 | 史実 | 本世界線 |
|---|---|---|
| 割譲年 | 1895年（下関条約） | 1889年（下関条約） |
| 同時割譲 | 遼東半島（三国干渉で返還） | 遼東は要求せず、三国干渉なし |
| 戦中の行動 | 1895年3月、講和交渉中に澎湖上陸 | 1887〜88年の戦争中、台湾攻略は劉銘伝の近代化で困難の可能性 |
| 統治機構 | 台湾総督府による軍政・民政、住民の武装抵抗 | 帝国特別領、「台湾統治例」による統治 |
| 外国資本 | 欧米に台湾での商業活動と海峡航行の自由を保障 | 事前に列強へ通商権尊重を通知し、事業特許を積極的に提示 |

[^u065][^u066][^u069]

史実の1895年にも、日本が欧米に台湾での商業活動と台湾海峡航行の自由を保障したことが列強の容認に意味を持ったとする研究がある。本世界線ではこれを計画的に、講和前から行う。[^u069]

# 未決の論点

* 「台湾統治例」の具体的内容（総督・長官の任命権、住民の法的地位、軍政期間の有無）。[^u077]
* 割譲後の住民の抵抗の規模と、先住民族共同体の扱い。[^u066]
* 北海道の授封前例を根拠にした領主家の台湾授封要求への対応と、本土と海外領土で異なる統治制度を認めるかという憲法問題。[^u066]
* 列強に与えた台湾コンセッションの具体的内容。[^u069]
* 1937年の台湾の人口・米の生産量・産業構成など、帝国全体の統計から分離した台湾単独の数値（会話ログ2の積算は台湾を含む帝国全体の値のみ）。[^e072][^e075]
