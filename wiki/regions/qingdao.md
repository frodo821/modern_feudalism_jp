# 概要

青島は山東半島南岸、膠州湾に面した港湾都市である。史実ではドイツが1898年に膠州湾を租借して軍港・要塞を築き、1914年に日本が攻略したが、本世界線では**ドイツの膠州湾租借は成立しない**（確定）。[^e038][^e039] 1889年の[下関条約](/diplomacy/shimonoseki-treaty-1889.md)以来、英国は日本と共同で北洋（山東・直隷）の金融・通商に進出しており、ドイツの租借と山東の排他的鉄道利権は英国系資本の利益を直接侵害するため、英国が清朝に外交的支援を与えてドイツの要求を限定したのである。[^e038][^u076]

青島は1898年頃から、英国主導の日英資本によって**軍港ではなく商業港**として開発され、青島・済南間の鉄道、沿線の鉱山とともに北洋経済圏の主要貿易港となった。清朝崩壊後は、山東政府・[中国諸省聯合](/diplomacy/china-federation.md)・英国領事当局の協定に基づき、**青島行政委員会**が市街地を施政する特別行政区域となる。1930年には英国主導の行政委員会が事実上の施政権を行使しており、日本は領土的権利を持たないが主要な投資国・通商相手国である（確定）。[^e038][^e039]

青島は「**軍事占領を伴わない経済的コンセッションが、政治的混乱によって事実上の外国施政地域へ変化した代表例**」とされる。[^e038] ドイツの軍港が存在しないため、1914年の青島攻略戦、日本の山東占領、対華二十一カ条要求の山東条項、1919年の山東問題、1922年の山東還付、1928年の済南事件は、いずれも史実の形では起こらない。[^e038]

# 前史：北洋の英国権益

前編の設定では、日本は1888年頃から、ロシアに取られたくない地域へ先に別の列強の権益を設定する「既成事実化」を外交方針とし、英国を北洋（山東・直隷の港湾・鉄道・金融）へ、フランスを華南へ誘導した。講和交渉と並行して清国と英系銀行団の間で山東・直隷方面の鉄道建設契約を結ばせ、その資金の一部を賠償支払いに充てるという構想である。[^e038][^u076] このため、英国系資本が山東に先行し、ドイツが史実と同じ条件で膠州湾・青島を取得できるとは限らない、という見通しが置かれていた（→[中国大陸の利権争奪](/diplomacy/china-concessions.md)）。[^u095] 会話ログ2でこれが確定された。[^e038]

# ドイツの膠州湾租借の不成立（1897〜1898）

史実では、1897年に山東省曹州府鉅野県でドイツ人宣教師2名が殺害された事件を契機にドイツが膠州湾を占領し、1898年に99年間の租借権と山東省内の鉄道・鉱山権益を獲得した。[^e038]

本世界線でも宣教師殺害事件に相当する事件は起こり得る。しかし英国の態度が異なるため、ドイツの要求は次のように処理される。[^e038]

| ドイツの要求 | 帰結 |
|---|---|
| 宣教師殺害に対する賠償 | 清朝が受諾 |
| 宣教師の保護 | 清朝が受諾 |
| 通商上の権利拡大 | 一部受諾 |
| 膠州湾の99年間租借 | 英国の反対によって不成立 |
| 山東省の排他的鉄道利権 | 不成立 |
| 青島へのドイツ海軍基地設置 | 不成立 |

[^e038]

英国の外交的反対だけでドイツを撤退させられるとは限らないため、ドイツにも何らかの成果を与える必要がある。そこで**青島における商業上の権利や、外国船舶への補給施設の開放**などを認めることで妥協する。[^e038]

# 商業港としての開発（1898〜1911）

膠州湾は天然の良港で、山東内陸部との鉄道接続によって大きな経済的価値を持つ。史実でも青島港と山東鉄道の開発は一体の事業だった。ドイツが租借しなくても、英国系資本には港湾と鉄道を一体的に開発する十分な動機がある。[^e038]

1898〜1900年頃、清朝と英国系企業の間で次の契約が成立する。[^e038]

* 青島の開港場指定
* 港湾施設の建設・運営権の付与
* 青島・済南間の鉄道敷設権
* 鉄道沿線の鉱山開発権
* 外国人居留区の設置

日本資本は英国系事業への出資を通じて参加する。[^e038] こうして青島は、ドイツの軍港ではなく**日英資本による北洋経済圏の主要貿易港**として発展した。[^e038] 日英にとって山東は北洋方面の鉄道・港湾権益の地であり、日本は英国とほぼ共通の支援先に加えて、副次的に山東の地方政権を支援する。[^e023][^e024]

# 特別行政区域（1912〜）

## 青島行政委員会

1911〜12年の清朝崩壊で、青島の行政権を誰が行使するかが問題となった。山東の地方軍事政権が港湾施設を直接掌握しようとすれば、英国系企業や日本の出資者と対立する。そこで山東政府・中国諸省聯合・英国領事当局の間で、青島の行政・港湾管理に関する協定が結ばれる。[^e038]

| 権限 | 管理主体 |
|---|---|
| 領土主権 | 中国 |
| 外交上の代表 | 中国諸省聯合 |
| 港湾運営 | 英国系港湾会社 |
| 鉄道運営 | 日英系鉄道会社 |
| 市街地行政 | 青島行政委員会 |
| 警察・治安 | 行政委員会直属警察 |
| 海関税 | 中国海関 |
| 周辺農村行政 | 山東地方政府 |

[^e038]

青島行政委員会には、英国領事、山東政府、港湾会社、外国人居留民、中国人商工業者の代表が参加する。英国が主導権を握るが、**法的には英国領でも英国の租借地でもない**。[^e038]

## 1930年の青島

[北伐](/events/northern-expedition.md)と[武昌公邸火災事件](/events/wuchang-residence-fire-1928.md)を経て山東地方政府の政治的安定性が低下すると、青島行政委員会の権限はさらに拡大した。1930年時点では英国主導の行政委員会が事実上の施政権を行使している（確定）。[^e038][^e039]

これは中国全体の租界・外国施政地域に共通する動きである。清朝崩壊後に全中国を実効支配する政府が一度も成立しなかったため、租界・租借地は主権回復によって縮小するのではなく、行政的自立性を強めた。中国側の施政能力の不足を列強が補完するうちに、事実上の直接統治へ移行したのである（→[戦間期の中国](/diplomacy/interwar-china.md)）。[^e037][^e039] 外国施政地域の形態のうち、青島は港湾管理区・鉄道附属地・外国企業の鉱工業地区の性格を併せ持つ。[^e037]

## 上海との比較

| 項目 | 上海 | 青島 |
|---|---|---|
| 成立経緯 | 外国人居留地・租界 | 港湾・鉄道開発契約 |
| 主な外国勢力 | 英米日仏など | 英日 |
| 経済的性格 | 国際金融・貿易・工業 | 港湾・鉄道・鉱業・工業 |
| 行政主体 | 外国人自治機関（工部局） | 行政委託に基づく委員会 |
| 中国側の主権 | 名目上維持 | 名目上維持 |
| 外国の実質的施政権 | 強い | 強い |

[^e038]

青島は上海共同租界に似ているが、成立経緯の異なる都市である。[^e038]

## 批判

中華民国や中国共産党からは、青島は**日英が中国の政治的分裂を利用して経済的支配を拡大している象徴**として批判される。[^e038] 日本は英国ほど行政特権の維持に直接の利益を持たず、英国や国際的行政機関が法的安定性を保障するなら日本自身が行政を担う必要はない、という立場をとる（検討案）。[^e037]

# 連鎖的な帰結

ドイツの青島海軍基地が存在しないことで、以後の歴史は次のように変わる（確定）。[^e038]

| 史実の出来事 | 本世界線での帰結 |
|---|---|
| 1914年の青島攻略戦 | 発生しない |
| 日本による山東占領 | 発生しない |
| 1915年の対華二十一カ条要求 | 山東関係の要求は存在しない |
| 1919年の山東問題 | 史実と同じ形では発生しない |
| 1922年の山東還付 | 発生しない |
| 1928年の済南事件 | 史実と同じ形では発生しない |

[^e038]

* **第一次世界大戦**：日本の参戦目的は青島などの領土獲得ではなく、対英協力と既存秩序の維持となる（→[第一次世界大戦と日本](/events/world-war-one.md)）。[^u095][^e038]
* **五四運動**：五四運動に相当する民族主義運動が起きても、その中心は青島の日本への移管ではなく、パリ講和会議で清朝以来の外国権益が維持されたことへの反発、そして聯合体制への反対である。[^e029][^e038]

# 却下・修正された案

* **「青島要塞が存在しない可能性」（前編の検討案）**：ドイツが膠州湾を取得できるとは限らないという前編の見通しは、会話ログ2で「ドイツの租借は成立しない」と確定した。[^u095][^e038]

# 未決の論点

* ドイツが青島で得た商業上の権利・補給施設利用権の具体的な範囲と、1914年の開戦時のその処理。
* 英国系港湾会社・日英系鉄道会社の具体的な名称と出資比率。
* 1930年代の青島行政委員会の構成と、山東政府との関係の変化。
