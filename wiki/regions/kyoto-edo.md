# 概要

本世界線の日本帝国の首都は**京都**である。1867年に京都で明治政府が成立した後も京都が首都として存続し、皇居・内閣・中央政府・元老院・衆議院は京都に置かれる。[^u133] 首都の所在はそれまで明示的に決まっていなかったが、京都首都という理解が成立経緯と整合することが確認され、採用された（確定）。[^u133]

一方、旧幕府の本拠地である**江戸**は、東京へ改称されることなく「江戸」の名称のまま残り、徳川家の本拠地と旧幕府の行政機構を抱える東国最大の商業・金融・産業都市として発展する（江戸の名称存続は検討案）。[^u133] 本世界線の日本は、**京都を政治首都とし、経済活動が江戸・大坂・京都・名古屋などに分散した多極的な国家**となる。[^u133]

# 京都が首都であり続けた理由

史実の東京奠都は、江戸が旧幕府の政治・行政の中心地であったこと、新政府が東国を統合する必要があったこと、そして天皇が江戸城へ移り太政官も東京へ移転したことによって実現した。正式な遷都宣言はなく、事実上の首都移転であった。[^u133]

本世界線ではこれらの条件が成り立たない。[^u133]

| 史実で東京奠都を促した条件 | 本世界線 |
|---|---|
| 旧幕府勢力を武力で倒し、東国を統合する必要 | 1866年に朝廷が軍事権を回収し、[無血で幕府が解体](../events/bloodless-dissolution-1866.md)された。戊辰戦争はない |
| 江戸城の接収と新たな皇居化 | 徳川家は所領と家格を保障されており、江戸城を接収する政治的必然性がない |
| 新政府による旧体制の一掃 | 1867年に京都で明治政府が成立し、1869年の憲法は天皇と世襲領主の合意で成立した。朝廷が本拠地を京都から移す積極的理由が弱い |

幕末の段階から、政治の焦点は京都にあった。1861年以降、「将軍が勅裁なしに諸侯を討伐できない」体制の下で、幕府と諸藩の争いは「京都における朝廷の裁可をめぐる政治闘争」へと転換していた（検討案）。[^u010] 1866年に徳川家茂が死去すると、朝廷は軍権を預かり、徳川宗家を含む有力諸侯を京都に招集して新体制を協議した（検討案）。[^u015] 1867年の[明治改元](../events/meiji-era-proclamation-1867.md)とともに成立した新政府は、旧幕臣・公家・有力諸侯による諸侯連合政権であった。[^u020]

# 都市の役割

| 都市 | 役割 |
|---|---|
| **京都** | 皇居、内閣、元老院、衆議院、中央官庁 |
| **江戸** | 東国最大の商業・金融・産業都市、旧幕府行政機構の拠点、徳川家の本拠地 |
| **大坂** | 商業金融、製造業、全国物流 |
| **横浜** | 太平洋貿易、外国商社、造船・港湾産業 |
| **神戸** | 西日本の国際貿易、海運・造船 |

（検討案）[^u133]

## 京都

京都は中央官庁・議会・外国公館・軍事機関を抱えるため、人口・行政施設・都市計画が史実より大幅に拡張される（検討案）。[^u133] 政治首都としての京都は、[元老院](../institutions/genroin.md)と[衆議院](../institutions/house-of-representatives.md)からなる帝国議会の所在地であり、領主たちが国政に参与する場でもある。

## 江戸

京都が政治首都であっても、江戸の重要性は小さくならない。徳川家の本拠地と旧幕府の行政機構が残るうえ、関東平野の人口、江戸湾の港湾、東日本の交通網が大きな経済的優位を与える（検討案）。[^u133] 徳川宗家は1866年以降も領主権を持つ公爵家として、旧幕府の官僚・金融・商業ネットワークを基盤とする有力領主圏を形成する（検討案）。[^u028]

明治政府は旧幕府の評定所を領主権裁定院に改組し、旧幕臣の実務官僚を継続雇用するなど、旧幕府の行政機構と人材を中央の制度に取り込んできた（検討案）。[^u022] 政府の地方出先機関の設置や旧幕府機構の整理のため、江戸に大規模な帝国官庁を置く可能性もある（検討案）。[^u133]

江戸は幕末から皇族の居住地としての前例も持つ。旧水戸領に封ぜられた那珂川家の当主（公現法親王）は、1861年の家創設当初、本人は江戸に留まり幕府派遣の役人が領地を統治した（[那珂川公爵家](../people/nakagawa-ducal-house.md)を参照）。[^u018] また1863年には海防軍が江戸湾・大坂湾・下関海峡に配備される構想であった（検討案）。[^u009]

## 経済の分散

本世界線では各領国が産業投資を競ってきたため、経済活動は首都に集中せず、江戸・大坂・京都・名古屋などに分散している可能性がある（検討案）。[^u133]（[寄親・寄子制と大領主間の近代化競争](../concepts/yorioya-yoriko.md)を参照）

# 首都の所在がもたらした帰結

## 関東大震災

1923年の[関東大震災](../events/great-kanto-earthquake.md)は、帝国の首都を壊滅させた災害ではなく、江戸・横浜という帝国最大級の経済圏と国際貿易港を襲った巨大災害となった。皇居・帝国議会・中央官庁は被災せず、京都の中央政府が救援と復興を指揮して政治機構の機能停止を避けた。京都の中央政府は金輸出停止の下で金融緩和と復興支援を行い、金輸出停止の柔軟性が有効だと認識される（検討案）。[^u133][^u137]

## 1930年の国家像

首都京都と金輸出停止の継続という二つの設定により、1930年の日本は「京都を政治首都とする多極的な工業国家であり、金輸出停止の下で世界恐慌に対応している」という姿になる。ロンドン海軍軍縮会議を考えるうえでも、史実の金解禁不況や首都震災の政治的後遺症をそのまま重ねるべきではない。[^u133]

| 江戸の性格 | 政治首都と経済中心の一体化 | 東国最大の経済都市、旧幕府行政機構の拠点 |
| 関東大震災 | 首都を直撃 | 経済圏を直撃、首都は無傷 |

# 未決の論点

- 京都の都市計画と人口拡張の具体像。[^u133]
- 江戸に置かれる帝国官庁の出先の範囲。[^u133]
- 江戸を含む関東の領主権の配置（徳川宗家の所領の範囲、旧幕府直轄地の扱い）。
